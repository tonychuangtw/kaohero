警察特考　114 年 三等考試 警察組織與事務管理　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1下列關於我國警察組織在解嚴後及專業領導時期發展的各項敘述，何者正確？

    1. (A) 管理理論架構為官僚主導模式
    2. (B) 警察績效為穩定的社會秩序
    3. (C) 職權來源包含民意
    4. (D) 運作策略為保甲制度

    正解：(C)

  2. 2內政部警政署獨立的稽核人員，針對各單位施政計畫之經濟性、效率性及效益性進行系統性評估，協助機關進行改善作業，此稱為下列何種審計？

    1. (A) 財務審計
    2. (B) 績效審計
    3. (C) 特種公務審計
    4. (D) 普通公務審計

    正解：(B)

  3. 3下列那個警察機關為警察勤務規劃監督機構，主要負責轄區警察勤務之規劃、指揮、管制、督導及考核，並對重點性勤務，得逕為執行？

    1. (A) 警察派出所
    2. (B) 警察分局
    3. (C) 警察局
    4. (D) 內政部警政署

    正解：(C)

  4. 4下列關於警察勤務運作策略的各項敘述，何者正確？

    1. (A) 值班為守勢勤務
    2. (B) 守望為攻勢勤務
    3. (C) 巡邏為守勢勤務
    4. (D) 備勤為攻勢勤務

    正解：(A)

  5. 5關於下列各項警察勤務策略模式，何者最符合開放社會、風險分攤、部門互動倫理，以及誘因機制建置之精神？

    1. (A) 報案反應（reactive stance）
    2. (B) 機先預警（proactive stance）
    3. (C) 專業化發展（professional）
    4. (D) 公私協力（public private partnership）

    正解：(D)

  6. 6關於下列各項行政組織，何者屬於內政部警政署警察機構之性質？

    1. (A) 警察通訊所
    2. (B) 保安警察第二總隊
    3. (C) 刑事警察局
    4. (D) 鐵路警察局

    正解：(A)

  7. 7下列有關於預測性警政（predictive policing）策略的各項敘述，何者錯誤？

    1. (A) 可有效分析及整合大數據
    2. (B) 可取代情資導向警政
    3. (C) 可更加準確部署資源
    4. (D) 可用於識別犯罪集團成員

    正解：(B)

  8. 8依據不同法系的思想，下列何者屬於海洋法系警察組織的思維？

    1. (A) 中央集權
    2. (B) 強調秩序維護
    3. (C) 業務較為簡要
    4. (D) 視警察為武官

    正解：(C)

  9. 9下列關於警察執法正當合法性（legitimacy）的各項敘述，何者正確？

    1. (A) 分配性正義影響較程序性正義顯著
    2. (B) 強調人民心中的主觀認知與感受
    3. (C) 基於願景來有效激勵追隨者
    4. (D) 美國 1980 年代後主要來源為專業主義

    正解：(B)

  10. 10警察人員參與政治活動之權限，下列何者於法並不禁止？

    1. (A) 於某直轄市市長候選人競選辦事處兼任競選幹事
    2. (B) 於處裡人民陳情案時，介入黨派紛爭
    3. (C) 加入某特定政治團體
    4. (D) 藉由職務上的機會，要求某特定人對某特定立法委員候選人捐款

    正解：(C)

  11. 11有關警察執法倫理的內涵，下列敘述何者正確？

    1. (A) 收受賄賂為第一類有關正直（integrity）的問題
    2. (B) 使用槍械時機為第一類有關正直（integrity）的問題
    3. (C) 作偽證為第二類有關執法難以抉擇（hard choice）的問題
    4. (D) 非法取證為第二類有關執法難以抉擇（hard choice）的問題

    正解：(A)

  12. 12有關警察品操風紀之要求，下列何者錯誤？

    1. (A) 禁止與特定對象或有職務利害關係之相關人員不當接觸交往
    2. (B) 不擅自向外募捐
    3. (C) 禁止非因公查詢並不當使用警政資訊系統（含各機關自建系統）資料
    4. (D) 不得具名指控長官、同事

    正解：(D)

  13. 13根據公務員廉政倫理規範第 4 條規定，下列何者情況公務員在偶發而無影響特定權利義務之虞時，得受贈財物？

    1. (A) 公務員受贈之財物市價為新臺幣 4,500 元
    2. (B) 公務員因喬遷而受贈市值新臺幣 4,500 元之電子產品
    3. (C) 公務員與同單位內多數人受贈市價總額新臺幣 4,500 元之禮品
    4. (D) 公務員在日本公務機關進行年度訪問，受贈市值新臺幣 4,500 元之紀念品

    正解：(D)

  14. 14關於政府採購法適用最有利標的各項敘述，下列何者錯誤？

    1. (A) 應報上級機關核准
    2. (B) 採限制性招標
    3. (C) 適用範圍包含財務與勞務
    4. (D) 評定最有利標之後即決標

    正解：(B)

  15. 15某警校學生於分局實習期間，因遭受某位廠商持續性騷擾而欲提出申訴。此實習學生申訴適用下列何項法規？

    1. (A) 性別平等教育法
    2. (B) 性別平等工作法
    3. (C) 兒童及少年性剝削防制條例
    4. (D) 性騷擾防治法

    正解：(B)

  16. 16警察機關在籌編歲出預算時將不合時宜或暫緩實施之計畫予以刪除，此符合下列何種預算制度之精神？

    1. (A) 單式預算
    2. (B) 複式預算
    3. (C) 零基預算
    4. (D) 設計計畫預算

    正解：(C)

  17. 17警察機關在社會治安網絡中關注其他機關團體的需求並持續進行協調，此為下列何種觀點的網絡管理做法？

    1. (A) 工具觀點
    2. (B) 制度觀點
    3. (C) 互動觀點
    4. (D) 契約觀點

    正解：(C)

  18. 18警察機關與民間銀行共同打詐時簽訂合作書面協議，此做法最符合下列那個協力治理關鍵要素的精神？

    1. (A) 資訊共享
    2. (B) 課責
    3. (C) 參與
    4. (D) 整合

    正解：(B)

  19. 19關於警察組織成員的激勵，下列敘述何者正確？

    1. (A) 需求層次屬於過程觀點
    2. (B) 同情心為公共服務動機的一個面向
    3. (C) 成就感為兩因模式中的保健因子
    4. (D) 厭惡刺激為操作制約理論中的削弱

    正解：(B)

  20. 20下列關於警察組織領導的各項敘述，何者正確？

    1. (A) 轉換型領導的要素為個別關懷
    2. (B) 魅力型領導的要素為動機啟發
    3. (C) 參與型領導的要素為權變獎酬
    4. (D) 交易型領導的要素為才智激發

    正解：(A)

  21. 21就警察機關內部單位之分類而言，有將之區分為業務單位、輔助單位。下列何者非輔助單位？

    1. (A) 法制室
    2. (B) 勤務指揮中心
    3. (C) 公共關係室
    4. (D) 人事室

    正解：(B)

  22. 22內政部警政署掌理全國性警察業務，並辦理：

    1. (A) 災害整備、應變事項
    2. (B) 槍砲彈藥刀械管制之規劃、督導
    3. (C) 跨國犯罪案件查緝之執行
    4. (D) 維護社會秩序事件之執行

    正解：(B)

  23. 23下列何者屬內政部警政署保安警察總隊掌理事項：

    1. (A) 執行食品、藥物安全等相關法令案件之查緝、取締或危害排除
    2. (B) 防止危害國家安全物品出境
    3. (C) 處理違反國家公園、森林與自然保育、環境、水資源保護
    4. (D) 國營及特定事業機構之安全維護

    正解：(D)

  24. 242024 年 0403 花蓮大地震，花蓮地區及中部橫貫公路天祥至太魯閣段災情嚴重。協助該重大災害應變之傳報、督導的警察機關為何？

    1. (A) 民防指揮管制所
    2. (B) 花蓮縣警察局
    3. (C) 保安警察第七總隊
    4. (D) 保安警察第一總隊

    正解：(A)

  25. 25警察消防海巡移民空勤人員及協勤民力安全基金設置管理條例所訂協勤民力人員，其範圍為：

    1. (A) 向警察分駐（派出）所登記、列冊，並管理、運用之巡守隊人員
    2. (B) 於實務訓練期間奉令協助警察機關執行任務之中央警察大學畢業生
    3. (C) 直轄市、縣（市）政府依災害防救法規編組之山地義勇警察隊人員
    4. (D) 於警察機關服勤之替代役人員

    正解：(D)
