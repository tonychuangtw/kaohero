  1. 1다음 ( ) 안에 알맞은 것을 고르십시오.그는 해외여행( ) 국내 여행도 한번 못 해 본 사람이다.

    1. (A) 조차
    2. (B) 말고
    3. (C) 마저
    4. (D) 은커녕

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 「은커녕」接在名詞後，表示「別說…就連…也」，此句說他別說海外旅行，連國內旅行也沒去過，語意通順。

    ❌ (A) 「조차」是「連…都」，語氣偏中性，常接否定，但前面需是極端最低的例子，此處「해외여행조차」無法帶出後句「국내 여행도 못 해 봤다」的對比。

    ❌ (B) 「말고」是「不是…而是」，表選擇排除，與句意不合。

    ❌ (C) 「마저」是「甚至連…也」，多用於最後一個、帶惋惜語氣，無法對比海外與國內。

    📚 出處：韓語補助詞「-은커녕」用法（表讓步的最低限度對比）

  2. 2다음 ( ) 안에 알맞은 것을 고르십시오.그 사람은 나와 다투고 나서 나를 보고도 못 본 ( ).

    1. (A) 편이에요
    2. (B) 탓이에요
    3. (C) 체해요
    4. (D) 듯하다

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 「-ㄴ/는 체하다」表示「假装…」，此句說兩人吵架後對方看到我也裝作沒看見，語意正確。

    ❌ (A) 「편이에요」是「算是…、屬於…」，不能與「못 본」構成慣用語。

    ❌ (B) 「탓이에요」是「是…的錯、因為…」，語意不符。

    ❌ (D) 「듯하다」是「好像…」，文法上應接「못 본 듯하다」而非「못 본 듯하다」前的空格形式，且此處慣用語是「못 본 체하다」。

    📚 出處：韓語慣用表現「-ㄴ/는 체하다」（假装）

  3. 3다음 ( ) 안에 알맞은 것을 고르십시오.방과 후에도 계속 공부하는 걸 보면 그는 꽤 성실한 ( ).

    1. (A) 셈입니다
    2. (B) 법입니다
    3. (C) 지경입니다
    4. (D) 참입니다

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 「-ㄴ/는 셈이다」表示「算是…、等於…」，看到放學後還繼續念書，可推論他算是相當認真，語意通順。

    ❌ (B) 「법이다」是「道理上必然…」，語氣不符推論語境。

    ❌ (C) 「지경이다」是「到了…地步」，多用於負面極端狀況。

    ❌ (D) 「참입니다」是「真是…」，不能接在形容詞後作推論表達。

    📚 出處：韓語慣用句型「-ㄴ/는 셈이다」（算是、等於）
