職能治療師　111 年第二次 小兒職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1有關促進孩童職能參考架構（SCOPE-IT）的重要假設，下列何者錯誤？

    1. (A) 孩童是職能性及社會性的存有（beings）
    2. (B) 使用職能做為治療工具比將職能視為最終目的更為重要
    3. (C) 職能表現會受個人、環境、社會、文化及時間等因素影響
    4. (D) 職能發展是透過一個涉及內在驅力及引導參與的動態過程而產生

    正解：(B)

  2. 2下列敘述何者不是「促進社會參與的參考架構」中有關同儕互動的功能指標？

    1. (A) 能以正向方式接近同儕並主動起始互動
    2. (B) 透過身體姿勢、認知注意力及情緒狀態表現社交取向
    3. (C) 回應同儕的口語及非口語線索
    4. (D) 依賴同儕的協助，對同儕的建議表示附和與妥協

    正解：(D)

  3. 3根據Mosston與Ashworth（2002）所提出關於學習的理論，下列敘述何者錯誤？

    1. (A) 各種教與學的形式可依提供學習策略的直接程度做區分，從直接給予指示到間接引導式作法，排成一序列
    2. (B) 直接策略無法讓學習者有效學習知識與任務
    3. (C) 間接策略讓學習者在決策過程中有較多參與
    4. (D) 間接策略鼓勵學習者主動計劃、執行及評估其表現

    正解：(B)

  4. 4根據「促進學習的四象限模式（the four-quadrant model of facilitated learning, 4QM）」參考架構，「運用心智地圖（mind maps）協助學習者回想任務的步驟」是屬於那一種學習策略？

    1. (A) 預習（priming）
    2. (B) 視覺提示（visual cues）
    3. (C) 記憶術（mnemonics）
    4. (D) 心智想像（mental imagery）

    正解：(B)

  5. 5神經發展治療的使能（enablement）／障礙（disablement）模式主要聚焦在下列那一個領域？

    1. (A) 身體結構與功能
    2. (B) 動作功能
    3. (C) 個體功能
    4. (D) 社會功能

    正解：(B)

  6. 6有關神經發展治療以重複有用的適應性（adaptive）動作經驗創造新的神經元地圖，以利未來取用中樞神經系統中的動作檔案，這個原則是採納那一個理論基礎？

    1. (A) 動態系統理論（dynamic systems theory）
    2. (B) 神經元組選擇理論（the neuronal group selection theory）
    3. (C) 感覺貢獻（sensory contributions）
    4. (D) 動作學習（motor learning）

    正解：(B)

  7. 7關於神經發展治療誘發（facilitation）手法的動作速度，下列敘述何者正確？

    1. (A) 有姿勢或重力不安全感的孩童適合慢速的動作
    2. (B) 低警醒度的孩童適合慢速的動作
    3. (C) 反應慢的孩童適合快速的動作
    4. (D) 每個個案適合的速度不同，不需要因應速度的變化

    正解：(A)

  8. 8新手職能治療師要熟悉並瞭解如何使用參考架構，則最適合應用參考架構的方法為何？

    1. (A) 單一參考架構
    2. (B) 平行運用參考架構
    3. (C) 合併運用參考架構
    4. (D) 依序運用參考架構

    正解：(A)

  9. 9關於原創參考架構的形成，下列敘述何者正確？

    1. (A) 知識的改變只要修正原有架構內的假說，並不需要形成新的參考架構
    2. (B) 發展與說明參考架構的過程不一定需要強烈的學識基礎與進階臨床推理技巧，應以具備豐富的臨床經驗為要
    3. (C) 形成原創參考架構須依照參考架構的結構來系統化組織與排序
    4. (D) 原創參考架構形成的需要主要源自於新興疾病所產生的問題，與社會變遷不相干

    正解：(C)

  10. 10根據Bronfenbrenner's生態系統觀點，關於孩童情境系統的敘述，下列何者錯誤？

    1. (A) 家庭與居家環境是屬於中系統（mesosystem），聯繫孩童與家庭
    2. (B) 巨系統（macrosystem）包含文化信念系統、行為的社會樣態及資源
    3. (C) 在托兒中心的孩童所經驗到的情境是微系統（microsystem）
    4. (D) 青少年的足球社團是屬於微系統（microsystem）

    正解：(A)

  11. 11依據Dunn的感覺處理模式，有關反應型態的敘述，下列何者正確？

    1. (A) 低登錄量（low registration）類型的孩童需要較低的環境刺激強度來使其注意
    2. (B) 感覺尋求（sensation seeking）類型的孩童會由於高反應閾值，不斷尋求強烈感覺刺激
    3. (C) 感覺敏感（sensory sensitivity）類型的孩童有高反應閾值，在環境中容易分心
    4. (D) 感覺逃避（sensation avoiding）類型的孩童有較低警醒度，主動避免討厭的感覺刺激

    正解：(B)

  12. 12關於運用實證實務（evidence-based practice）的益處，不包括下列何者？

    1. (A) 可以幫助臨床工作者做出較好的臨床決策
    2. (B) 能夠幫助專業發展
    3. (C) 符合倫理原則
    4. (D) 能回答多數臨床實務中產生的問題

    正解：(D)

  13. 13有關動作學習的敘述，下列何者錯誤？

    2. (B) 用觸控筆在平板上跟隨移動的目標是屬於封閉式的任務（closed task）
    3. (C) 在動作技巧的認知期，區段練習（blocked practice）較分散練習（distributed practice）適合
    4. (D) 對於已經建立基本動作技巧的孩童，給予動作表現的回饋（knowledge of performance）較動作結果的回饋（knowledge of results）好

    正解：(B)

  14. 14下列那一位學者的理論特別重視社會情境與個體對自身能力的信念對其學習的影響？

  15. 15頭部移動時，視野的影像會隨之改變，稱為：

  16. 16關於matrix model治療感覺調節障礙孩童的模式，下列敘述何者錯誤？

    4. (D) 最後訓練階段以較複雜的認知挑戰活動為主

    正解：(B)

  17. 17神經損傷的孩童，常會因口腔肌肉張力異常，出現舌頭外吐（tongue thrust）的現象，下列那個處理策略最不適切？

    1. (A) 進食時，頭部與頸部的擺位，應該維持正中或稍微屈曲（neck flexion）的姿勢
    2. (B) 餵食時，湯匙應該從正面進入，並將食物放在舌頭中間，抑制舌頭外吐的現象
    3. (C) 在非進食時間，職能治療師可以透過各種口腔活動來促進口腔動作協調性
    4. (D) 在非進食時間，職能治療師可以透過各種口腔活動來促進舌頭側化的能力

    正解：(B)

  18. 18有關擺位的敘述，以下何者最不適切？

    1. (A) 馬桶椅上的擺位須注意有足夠的髖關節彎曲及外展角度
    2. (B) 對於頭部控制不佳且抬頭時會誘發完全伸直模式（full extension pattern）者，建議提供趴式站立架（pronestander）
    3. (C) 餵食擺位須注意減少誘發原始反射的擺位
    4. (D) 餵食擺位須注意頭部支持物不要碰到臉

    正解：(B)

  19. 19一個孩童可以辨識圖卡上的月亮形狀，卻無法識別桌子上月亮形狀積木。這表示孩童很可能有那一種視知覺困難？

    4. (D) 設定明確的行為期望和執行後果，如果孩童失去控制就暫停活動

  37. 37有關日常生活活動評量工具之敘述，下列何者最適切？

  38. 38職能治療師常使用應用行為分析（applied behavior analysis）介入方式訓練自閉症孩童的社交技巧，下列敘述何者錯誤？

  39. 39在社會參與能力評估工具中，關於「兒童職能自我評估（Child Occupational Self-Assessment, COSA）」的敘述，下列何者正確？
