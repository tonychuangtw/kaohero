  1. 1下列何者為一般的電腦系統中負責進行通用運算的主要元件？

    1. (A) CPU
    2. (B) GPU
    3. (C) NPU
    4. (D) TPU

    正解：(A)

  2. 2下列那一項電腦儲存媒介為讀取速度最快的媒介？

    1. (A) DVD
    2. (B) HDD
    3. (C) SSD
    4. (D) USB Stick

    正解：(C)

  3. 3一般個人電腦常常使用那一種無線通訊模組來取代有線通訊模組？

    1. (A) Zigbee
    2. (B) NFC
    3. (C) LoRa
    4. (D) Bluetooth

    正解：(D)

  4. 4UNIX 作業系統中常常用什麼命令指令來檢視文字檔案內容？

    1. (A) md
    2. (B) cat
    3. (C) ls
    4. (D) type

    正解：(B)

  5. 5請問二進位數字「11010.011」轉換為 10 進位後之數字應為下列何者？

    3. (C) 26.375
    4. (D) 26.625

    正解：(C)

  6. 6請問下列二個 16 進位的數字「0xd6fd」和「0x3412」，經過 AND 運算後得到的結果為何？

    3. (C) 11011010

  8. 8作業系統在進行行程上下文切換（Context Switch）時，行程控制區塊（PCB）最主要的功能是完成下列那項工作？

    3. (C) 重新建立虛擬地址空間並載入所有資料
    4. (D) 清除並刷新行程在快取中的所有資料

  9. 9下列那一項描述「開源軟體」的特點？

    1. (A) 用戶必須支付高額授權費用才能使用

    3. (C) 軟體只能在特定的硬體設備上運行

  10. 10給定一份包含姓名和地址的 Microsoft Excel 表單，以及一份邀請函的文件樣版。在 Microsoft Word 中可以使用什麼功能批次產出所有邀請函？

  12. 12給定以下字元出現的頻率：A: 0.5 B: 0.25 C: 0.15 D: 0.10使用霍夫曼演算法（Huffman's Algorithm）生成編碼，在樹狀結構中，若規定左分支編碼為 0，右分支編碼為 1，請問字元 B 的二進位編碼為何？
