初等考試　102 年 初等考試 公民與英文（社會行政組）　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有人認為男女有別，常以「男主外，女主內」形容，顯然這句話是屬於那一個層次的意涵？

    1. (A) 生理性別
    2. (B) 社會性別
    3. (C) 政治性別
    4. (D) 法律性別

    正解：(B)

  2. 2下列那一種節慶活動，最足以表現臺灣傳統社會的社區意識，讓社區居民共同參與？

    1. (A) 跨年晚會
    2. (B) 清明掃墓
    3. (C) 媽祖出巡
    4. (D) 聖誕舞會

    正解：(C)

  3. 3政府於災後發放受災戶慰問金，其作為是在落實那一項社會福利政策？

    1. (A) 國民就業
    2. (B) 醫療補助
    3. (C) 社會救助
    4. (D) 教育助學

    正解：(C)

  4. 4酗酒成性的張三經常抽打十歲女兒，則其女兒的母親應向那一機關提出聲請，以宣告停止張三對女兒行使親權？

    1. (A) 警察機關
    2. (B) 鄉鎮調解委員會
    3. (C) 縣市政府
    4. (D) 地方法院

    正解：(D)

  5. 5某甲想成為總統、副總統之候選人，他應年滿幾歲以上，才有任職資格？

    1. (A) 23 歲
    2. (B) 25 歲
    3. (C) 40 歲
    4. (D) 45 歲

    正解：(C)

  6. 6把自己認同的價值和行為方式改掉，並另外學習一套全新的價值與行為模式，此一過程為何？

    1. (A) 社會同化
    2. (B) 頓悟
    3. (C) 再社會化
    4. (D) 社會革新

    正解：(C)

  7. 7蒐集民意的一般使用方法，大致可分為入戶面訪、電話訪問、郵寄問卷、網路民調以及焦點團體訪談法，其中最為昂貴但是資料內容較為豐富，且訪員是依據戶籍地址找到特定的受訪者進行訪問，稱為下列何者？

    1. (A) 入戶面訪
    2. (B) 電話訪問
    3. (C) 網路民調
    4. (D) 郵寄問卷

    正解：(A)

  8. 8我國的立法委員選舉自民國 97 年改為「單一選區兩票制」，其中的「單一選區」最可能造成的缺點為何？

    1. (A) 賄選與黑金盛行
    2. (B) 政黨派系傾軋
    3. (C) 不利小黨生存
    4. (D) 府會關係失衡

    正解：(C)

  9. 9威龍擔任本次班會主席，面對同學提出「阿里山」旅遊案，依照會議程序，他要如何處理才是正確？

    1. (A) 提案→表決→討論→附議
    2. (B) 提案→附議→討論→表決
    3. (C) 提案→討論→附議→表決
    4. (D) 提案→討論→表決→附議

    正解：(B)

  10. 10下列何人曾以副總統身分，兼任行政院院長？

    1. (A) 吳敦義
    2. (B) 蕭萬長
    3. (C) 呂秀蓮
    4. (D) 連戰

    正解：(D)

  11. 11有一批人民想要成立「婦女」政黨，則應依下列何種法律之規定辦理組黨？

    3. (C) 政黨法
    4. (D) 性別工作平等法

    正解：(B)

  12. 12政府為推動國際人權「自由」、「平等」的核心價值，總統於民國 98 年 4 月 22 日公布兩公約施行法，展現我國落實兩公約的誠意與決心，此兩公約係指：

    1. (A) 聯合國海洋法公約、氣候變化綱要公約
    2. (B) 公民與政治權利國際公約、經濟社會文化權利國際公約
    3. (C) 兒童權利公約、消除對婦女一切形式歧視公約
    4. (D) 生物多樣性公約、瀕臨絕種野生動植物國際貿易公約

    正解：(B)

  13. 13地方政府縣市長近期為了中央補助與地方稅收的經費分配爭議不斷，此類爭議性的經費來源主要是依據何種法律？

  14. 14中國大陸於 2012 年舉行全國人民代表大會，通過由何人擔任國務院總理？
