  1. 1다음 ( )에 가장 알맞은 것을 고르십시오.8 시 비행기가 11 시로 연착되었기 때문에 ( ) 출발할 필요가 없습니다.

    1. (A) 늦게
    2. (B) 절대로
    3. (C) 반드시
    4. (D) 일찍

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 原定 8 點的班機延到 11 點，所以「沒有必要早點出發」，用「일찍（早）」最合理。

    ❌ (A) 「늦게」是晚，說「不必晚出發」與班機延後的因果相反。

    ❌ (B) 「절대로」是「絕對」，多與否定連用強調禁止，不用來說出發時間的早晚。

    ❌ (C) 「반드시」是「務必」，「不必務必出發」語意不通，且與延誤無關。

    📚 出處：韓語副詞辨義—일찍／늦게與時間副詞的因果搭配

  2. 2다음 ( )에 가장 알맞은 것을 고르십시오.ㄱ: 오늘 저녁 때 친구들이 우리 집에 온대요.ㄴ: 오늘 저녁이요? 그럼 저녁은 뭘로 준비해요?ㄱ: 시간 없으니까 그냥 ( ) 음식 준비하면 돼요.

    1. (A) 쉬운
    2. (B) 간단한
    3. (C) 담백한
    4. (D) 소박한

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 「시간 없으니까（因為沒時間）」後面要接「간단한 음식（簡單的菜）」，指不費工、快速做好的料理。

    ❌ (A) 「쉬운」通常修飾事情或問題的難易（쉬운 문제），「쉬운 음식」不自然。

    ❌ (C) 「담백한」是口味清淡，講的是味道，與時間不夠無關。

    ❌ (D) 「소박한」是樸素簡樸，偏整體格調，不是「快速好做」的意思。

    📚 出處：韓語形容詞與名詞搭配—간단하다的用法

  3. 3다음 ( )에 가장 알맞은 것을 고르십시오.영화 티켓을 ( ) 싶은데 여기서 해도 돼요?

    1. (A) 예약하고
    2. (B) 예정하고
    3. (C) 예매하고
    4. (D) 예상하고

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 買票券（電影票、車票）韓語固定用「예매하다（預購）」，符合「티켓을 예매하다」的搭配。

    ❌ (A) 「예약하다」用於訂位、訂房、訂餐廳等保留名額，不用於買票這個動作。

    ❌ (B) 「예정하다」是預定計畫，不能以票券為受詞。

    ❌ (D) 「예상하다」是預測，語意完全不合。

    📚 出處：韓語漢字詞辨義—예매／예약／예정／예상
