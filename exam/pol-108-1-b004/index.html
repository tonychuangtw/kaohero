警察特考　108 年 三等考試 行政法　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1下列何者非行政法之成文法源？

    1. (A) 立法院議決之條約
    2. (B) 中央行政機關訂定之法規命令
    3. (C) 地方行政機關訂定之自治規則
    4. (D) 司法院大法官之解釋

    正解：(D)

  2. 2下列何者非屬法律優位原則之內涵？

    1. (A) 重要事項應由法律規定
    2. (B) 法律不可牴觸憲法
    3. (C) 法規命令不可牴觸憲法
    4. (D) 行政規則不可牴觸法律

    正解：(A)

  3. 3下列何種事項不得以法律授權之法規命令定之？

    1. (A) 人身自由之限制
    2. (B) 行政機關內部人員調動
    3. (C) 空氣污染防制費之收費標準
    4. (D) 電子遊戲場業之輔導管理

    正解：(A)

  4. 4臺中市議會就臺中市社會住宅減免地價稅及房屋稅事件通過自治法規，並經臺中市政府公布施行。該自治法規屬於下列何種性質？

    1. (A) 自治條例
    2. (B) 自治規則
    3. (C) 委辦規則
    4. (D) 特別命令

    正解：(A)

  5. 5關於行政處分之附款，下列敘述何者正確？

    1. (A) 行政機關作成行政處分時，縱無裁量權限，基於公益之必要，亦可為附加一定條件或負擔
    2. (B) 依入出國及移民法准許外國人入境觀光，但附加不得工作之要求，屬於附停止條件之行政處分
    3. (C) 縣政府於核發某建物之使用執照時，要求申請人於 10 日內改善消防設施，否則該執照失效，屬於附終期之行政處分
    4. (D) 附負擔之行政處分，受益人未履行該負擔者，原處分機關得依職權為全部或一部之廢止

    正解：(D)

  6. 6建築主管機關強制拆除某違建時，商請警察機關到場維護秩序，係符合下列何種概念？

    1. (A) 委任
    2. (B) 代行處理
    3. (C) 委託行使公權力
    4. (D) 職務協助

    正解：(D)

  7. 7依公務員懲戒法規定，關於公務員懲戒之敘述，下列何者錯誤？

    1. (A) 同一行為，不受公務員懲戒委員會二次懲戒
    2. (B) 同一行為，不受行政罰之處罰者，不排除得予以懲戒
    3. (C) 同一行為，在刑事偵查或審判中者，不當然停止審理程序
    4. (D) 同一行為，不得同時受刑罰、行政罰及懲戒

    正解：(D)

  8. 8依司法實務之見解，下列何者為行政處分？

    1. (A) 道路交通違規之舉發通知書
    2. (B) 主管機關對於公寓大廈管理委員會所為不予備查之通知
    3. (C) 行政機關對於人民申請案件之補正資料通知
    4. (D) 主管機關對於非競爭者之人民檢舉違反公平交易法之函覆13120-13420

    正解：(A)

  9. 9下列何者非屬一般處分？

    1. (A) 行政院環境保護署發布空氣品質惡化警告
    2. (B) 警察機關對非法集會群眾之強制解散命令
    3. (C) 傳染病發生時，強制撤離特定區域之人民
    4. (D) 公物之設定、變更或廢止

    正解：(A)

  10. 10授益行政處分以書面為之者，下列何者非屬應記載之事項？

    1. (A) 處分之理由
    2. (B) 處分附款之內容
    3. (C) 處分之法令依據
    4. (D) 處分相對人之姓名等足資辨別之特徵

    正解：(A)

  11. 11關於行政處分之作成，下列敘述何者錯誤？

    1. (A) 受委託行使公權力之個人，於委託範圍內得作成行政處分
    2. (B) 行政機關作成行政處分前，均應通知相對人陳述意見
    3. (C) 行政處分除法規另有要式之規定者外，得以言詞為之
    4. (D) 行政內部單位不得以自己名義作成行政處分

    正解：(B)

  12. 12關於行政處分之瑕疵，下列何者得補正？

    1. (A) 行政處分之作成未給予當事人陳述意見之機會者
    2. (B) 行政處分不能由書面處分中得知處分機關者
    3. (C) 行政處分應以證書方式作成而未給予證書者
    4. (D) 行政處分之內容對任何人均屬不能實現者

    正解：(A)

  13. 13關於行政契約之敘述，下列何者錯誤？

    1. (A) 公法上法律關係原則上得以行政契約設定、變更或消滅之
    2. (B) 行政機關不得以行政契約代替行政處分，除非法律另有規定
    3. (C) 除法律另有規定外，行政契約應以書面為之
    4. (D) 行政契約內容之履行將損害第三人之權利者，應經該第三人書面之同意

    正解：(B)

  14. 14公路監理機關委託某汽車修理廠從事轄區內之汽車代檢工作，委託契約書中約定違約之一方應繳納違約金。車廠若對違約金之繳納與監理機關產生爭議時，應如何救濟？

    1. (A) 向民事法院起訴
    2. (B) 向行政法院起訴
    3. (C) 提起訴願
    4. (D) 提起國家賠償訴訟

    正解：(B)

  15. 15下列何者不屬於行政事實行為？

    1. (A) 交通部中央氣象局對外發布氣象預報
    2. (B) 行政院農業委員會發布農漁業資訊
    3. (C) 臺北市政府交通局劃設禁止臨時停車之標線
    4. (D) 公平交易委員會對業者為行業警示

    正解：(C)

  16. 16一行為違反同一行政法義務，數機關均有管轄權者，原則上由何機關管轄？

    1. (A) 逕由共同上級機關指定
    2. (B) 由處理在先機關管轄
    3. (C) 由法定罰鍰額最高機關管轄
    4. (D) 由各該主管機關分別裁處，從一重執行13120-13420

    正解：(B)

  17. 17下列何者非屬裁處罰鍰之審酌考量事項？

    1. (A) 應受責難之程度
    2. (B) 受處罰者之國籍
    3. (C) 因違反行政法上義務所得之利益
    4. (D) 受處罰者之資力

    正解：(B)

  18. 18依訴願法規定，關於訴願管轄之敘述，下列何者正確？

    1. (A) 原行政處分機關於作成行政處分後裁撤者，應向承受其業務之機關或其直接上級機關提起訴願
    2. (B) 不服受委託機關就委託事件所為之行政處分者，應向原委託機關之直接上級機關提起訴願
    3. (C) 不服受委辦機關就委辦事件所為之行政處分者，應向原委辦機關之直接上級機關提起訴願
    4. (D) 不服受委託行使公權力之團體以其團體名義所為之行政處分者，應向原委託機關之直接上級機關提起訴願

    正解：(A)

  19. 19下列何種行政救濟程序相當於訴願程序？

    1. (A) 教師法之申訴
    2. (B) 公務人員保障法之復審
    3. (C) 商標法之異議
    4. (D) 稅捐稽徵法之復查

    正解：(B)

  20. 20下列何項事件在提起行政訴訟前，必須先提起訴願？

    1. (A) 主管機關對兵役體位之判定
    2. (B) 主管機關經依行政程序法所定聽證程序作成之行政處分
    3. (C) 交通事件裁決所作成之裁決
    4. (D) 內政部移民署作成之延長收容處置

    正解：(A)

  21. 21下列何者非屬行政法院審判權範圍？

    1. (A) 律師懲戒之決議
    2. (B) 大學教師升等決定
    3. (C) 健保特約爭議
    4. (D) 公費生契約爭議

    正解：(A)

  22. 22關於行政訴訟之功能，下列敘述何者錯誤？

    1. (A) 保障人民權益
    2. (B) 確保國家行政權之合法行使
    3. (C) 增進司法功能
    4. (D) 紓解請願案件

    正解：(D)

  23. 23關於公法上爭議之救濟，下列敘述何者錯誤？

    1. (A) 除法律另有規定外，得提起行政訴訟
    2. (B) 在司法二元制度下，因公法關係所生之爭議，原則上由行政法院審判之
    3. (C) 立法者得衡酌案件性質與既有制度，規定以普通法院審理公法上之爭議
    4. (D) 為符合平等原則，現行行政訴訟法亦採與普通法院相同之三級三審制

    正解：(D)

  24. 24財政部發布「稅務違章案件裁罰金額或倍數參考表」，使各稽徵機關參照該表所訂倍數裁罰，以避免在個案中罰鍰額度輕重失衡之情形發生。該裁罰倍數參考表之性質為何？

    1. (A) 法規命令
    2. (B) 行政規則
    3. (C) 法律
    4. (D) 職權命令

    正解：(B)

  25. 25關於行政機關剝奪人民財產權之敘述，下列何者錯誤？

    1. (A) 應有法律之依據
    2. (B) 應有公益之目的
    3. (C) 應符合比例原則
    4. (D) 應補償人民所失利益

    正解：(D)
