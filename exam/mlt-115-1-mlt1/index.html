  1. 1下列何種第二度房室傳導阻斷（second degree AV block），無法分辨是 Ｍobitz 第一型或第二型？

    1. (A) 4：3 第二度房室傳導阻斷
    2. (B) 10：9 第二度房室傳導阻斷
    3. (C) 3：2 第二度房室傳導阻斷
    4. (D) 2：1 第二度房室阻斷

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 2：1 第二度房室傳導阻斷時，每個 P 波後固定只有一個 QRS 波，因無法觀察到連續兩個以上成組的 PR 間期變化（文氏現象），故無法判定是 Mobitz 第一型或第二型，需靠希氏束電圖或臨床情境輔助判斷。

    ❌ (A) 4：3 阻斷可觀察連續 PR 間期是否逐拍延長，可區分兩型。

    ❌ (B) 10：9 阻斷同樣有連續 PR 間期變化可供判別。

    ❌ (C) 3：2 阻斷也有兩個以上連續傳導的 PR 間期可比對。

    📚 出處：臨床生理學與病理學－心電圖學，第二度房室傳導阻斷之分型（Mobitz I 與 II）

  2. 2下列對於心電圖之敘述何者錯誤？

    1. (A) 心電圖 P 波為心房再極化波
    2. (B) 心電圖 QRS 波為心室去極化波
    3. (C) 心電圖 T 波為心室再極化波
    4. (D) 心電圖 PR 間期為從 P 波開始到 QRS 波開始的時間

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 心電圖 P 波代表心房去極化（depolarization），並非再極化；心房再極化波通常被 QRS 波遮住而看不到。

    ❌ (B) QRS 波為心室去極化波，敘述正確。

    ❌ (C) T 波為心室再極化波，敘述正確。

    ❌ (D) PR 間期為 P 波開始到 QRS 波開始的時間，敘述正確。

    📚 出處：臨床生理學與病理學－心電圖學，各波型與間期之生理意義
