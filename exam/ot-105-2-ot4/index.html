職能治療師　105 年第二次 心理障礙職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1根據DSM-5，下列那一類診斷不是屬於認知疾患？

    1. (A) 譫妄（delirium）
    2. (B) 特定對象畏懼症（specific phobia）
    3. (C) 失智症（dementia）
    4. (D) 失憶症（amnestic disorders）

    正解：(B)

  2. 2朱伯母最近有喪失興致、體重下降、失眠、自殺意念、情緒低落、不適切罪惡感等問題，已經持續一個月。請問根據DSM-5，她比較可能是得到那一個疾病？

    1. (A) 躁症發作
    2. (B) 恐慌症
    3. (C) 妄想症
    4. (D) 重鬱發作

    正解：(D)

  3. 3根據DSM-IV，有關虛談症（confabulation）的敘述下列何者錯誤？

    1. (A) 患者意圖藉說謊來掩飾其症狀
    2. (B) 患者在回憶往事時，常混淆事情發生的時間、地點和情節，張冠李戴
    3. (C) 患者會將過去可能發生而未發生的生活過程說成確實曾經歷過
    4. (D) 屬於記憶障礙

    正解：(A)

  4. 4根據美國國家酒精濫用與酒精中毒研究所（National Institute on Alcohol Abuse and Alcoholism）制訂的標準，將飲酒行為分三等級，其中，低風險飲酒是指：（每杯以0.6盎司計或含14公克純酒精）

    1. (A) 每日飲酒量男性不超過4杯、女性不超過3杯，且每週飲酒量男性不超過14杯、女性不超過7杯
    2. (B) 每日飲酒量男性不超過4杯、女性不超過3杯
    3. (C) 每週飲酒量男性不超過14杯、女性不超過7杯
    4. (D) 每日飲酒量不分男女均不超過3杯

    正解：(A)

  5. 5卡普南（Kaplan）與沙達克（Sadock）於2003年將防衛機轉分成四類，其中利他主義、幽默、昇華等，是屬於下列那類的防衛機轉？

    1. (A) 自戀的防衛（narcissistic defenses）
    2. (B) 不成熟的防衛（immature defenses）
    3. (C) 神經質的防衛（neurotic defenses）
    4. (D) 成熟的防衛（mature defenses）

    正解：(D)

  6. 6有位病人突然產生極端不安、焦慮的感覺，且附帶有呼吸短促、困難、怕死、發抖、出汗、頭暈等現象，根據DSM-5，他可能屬於何種疾患？

    1. (A) 廣泛性焦慮症（general anxiety disorder）
    2. (B) 妄想症（delusional disorder）
    3. (C) 恐慌症（panic disorder）
    4. (D) 失智症（dementia）

    正解：(C)

  7. 7根據DSM-IV，關於兒童情緒及行為障礙，下列敘述何者錯誤？

    1. (A) 當一個孩子出現易怒、悲傷、退縮、在遊戲中有很多負向情緒，有可能是兒童憂鬱症，需要進一步的觀察評估
    2. (B) 身體疾病也可能造成情緒行為問題，例如糖尿病兒童可能因為遊戲經驗受限、飲食限制，在家中有不當的情緒行為，甚至違抗疾病的治療
    3. (C) 部分情緒障礙兒童合併有其他精神疾病，例如憂鬱症兒童可能合併出現焦慮症
    4. (D) 兒童情緒及行為障礙通常在嬰幼兒時期就有明確、清楚的症狀表現，家長多數可以及早尋求專業協助

    正解：(D)
