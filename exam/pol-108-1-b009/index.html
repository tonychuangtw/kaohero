警察特考　108 年 三等考試 警察學與警察勤務　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1依據民國 107 年 3 月修正公布的「治安顧慮人口查訪作業規定」，刑責區員警針對高再犯之虞治安顧慮人口的查訪，得依據情節輕重報經分局核定增加查訪次數，並以多久期限為一期實施評估？

    1. (A) 每個月評估一次
    2. (B) 每 2 個月評估一次
    3. (C) 每 3 個月評估一次
    4. (D) 每半年評估一次

    正解：(C)

  2. 2依據民國 106 年 04 月 24 日所修訂之「警察機關辦理計程車駕駛人執業登記管理事項作業要點」，有關計程車司機之登記發證作業規定，下列何者正確？

    1. (A) 申請人應於領得講習合格成績單之日起 3 個月內，檢具該成績單及執業事實證明文件，向原申請之警察局辦妥執業登記及領取執業登記證
    2. (B) 縣（市）警察局於辦理登記時，應先審核其合格成績單有無逾期，及其執業事實證明文件登錄事項，如有錯誤、缺漏或不符執業事實等情事者，得先准予領取執業登記證，再限期補正作業
    3. (C) 汽車駕駛人經同一測驗區域之直轄市、縣（市）警察局聯合測驗講習合格者，因故變更執業地時，得至其新變更區域之警察局申請辦理執業登記，並領取執業登記證
    4. (D) 縣（市）警察局於受理登記領證申請後，如無不得辦理或應補正之情形者，應於 3 天內核發執業登記證

    正解：(D)

  3. 3在民國 102 年 12 月 9 日所修正的「少年不良行為及虞犯預防辦法」中有關警察機關的作為，下列何者正確？

    1. (A) 學校、社會團體、各目的事業主管機關（構）得知少年有不良行為或虞犯等情事，應通知警察機關協助處理
    2. (B) 少年虞犯事件與違反社會秩序維護法案件相牽連者，應先送法院處理。經法院裁定不付審理或不付保護處分者，其違反社會秩序維護法部分，若未逾 2 個月，仍得依社會秩序維護法處罰
    3. (C) 法院將少年交付警察機關以外之機構、社會團體或其他適當之人保護管束時，應通知該少年原移送之警察機關
    4. (D) 為強化少年不良行為及虞犯預防績效，得由法務部邀集相關機關或單位及有關少年輔導機構、社會團體或專家學者，舉行「預防少年犯罪協調會報」

    正解：(B)

  4. 4依據民國 102 年 12 月所修正的「性侵害犯罪加害人登記報到查訪及查閱辦法」，有關加害人登記報到查訪之規定，下列何者最為正確？

    1. (A) 監獄遇有加害人屬中等以上再犯危險者，在將判決書函送其戶籍所在地之直轄市、縣（市）主管機關時，應於函文中敘明加害人再犯危險等級
    2. (B) 加害人於預定報到期日前，原登記資料發生異動，應於發生異動之日起 7 日內前往管轄警察分局，辦理異動登記
    3. (C) 加害人有刑法第 87 條之情形者，檢察機關應於受監護處分期間屆滿前 2 個月，將確定之判決書提供其戶籍所在地之直轄市、縣（市）主管機關
    4. (D) 戶籍所在地之直轄市、縣（市）政府警察局於加害人依規定辦理登記後，應當面告知並以書面通知加害人，自登記日起每 3 個月向指定警察分局報到

    正解：(B)

  5. 5警察學的研究顯示：犯罪熱點的辨識與分析，有助於提升警察勤務的效能。下列有關選項，何者最不正確？

    1. (A) 研究發現少數地點集中大量犯罪、犯罪熱點低度甚至無犯罪轉移、犯罪熱點穩定等現象
    2. (B) 民眾向警察的報案資料，可作為辨識與分析犯罪熱點的材料
    3. (C) 情境式的問題導向警政，是警察針對犯罪熱點回應策略的新趨勢
    4. (D) 犯罪熱點比犯罪人更易於變動，不容易辨識與瞄準，以致於不易控制

    正解：(D)

  6. 6受到全球化效應的影響，治安問題跨境化的現象日益嚴重，國際警務合作的重要性隨之提升。下列何者不是國際刑警組織的功能？

    1. (A) 肩負全年無休的情資蒐集工作
    2. (B) 串聯區域合作警務
    3. (C) 辦理專業培訓工作，提升會員國犯罪分析能力
    4. (D) I-24/7 全球警務通訊系統，是國際刑警組織與會員國聯絡的網絡

    本題經考選部公告不計分。

  7. 7有關臺灣警察制度沿革的敘述，下列何者最不正確？

    1. (A) 日本據臺期間，先採軍政，後則全面改以警察作為治安主力
    2. (B) 日據時期，臺灣全面推展現代警察制度，係在中國本土之後
    3. (C) 戒嚴時期，主要是以軍人擔任警政首長
    4. (D) 勤務指揮中心系統係在孔令晟先生擔任署長時所設置的

    正解：(B)

  8. 8國際警察合作是警政部門回應跨境治安問題的重要策略。下列有關國際警察合作能否順利進行的影響因素，何者最為重要？

    1. (A) 政治、法律、文化、能力
    2. (B) 警察績效、警察職權來源
    3. (C) 警察機關所運用的管理思維
    4. (D) 中央集權與地方分權的抉擇

    正解：(A)

  9. 9有關警察權、警察職權、警察權限等概念，下列敘述何者最為正確？

    1. (A) 「警察權」係指：「國家為維持公共安全與秩序，對人民行使命令強制的權力」屬於實定法上的概念
    2. (B) 實質的警察權劃歸由那些機關行使，係屬於行政機關的權限
    3. (C) 專由形式意義的警察機關行使的權力方法，稱為警察職權
    4. (D) 警察法第 9 條有關警察職權的規定，係屬於狹義的警察職權概念

    正解：(C)

  10. 10研究警察的學者多將美國警察機關的工作分為執行性、行政性及輔助性等三類。下列有關其工作內容何者錯誤？

    1. (A) 刑事鑑識屬於執行性的工作
    2. (B) 警察教育屬於行政性工作
    3. (C) 警察通訊屬於輔助性工作
    4. (D) 執行性工作類似我國警察勤務

    正解：(A)

  11. 11根據梅可望先生有關各國警察業務內容的歸納，下列對於警察業務內容的敘述何者錯誤？

    1. (A) 國家安全業務包括：國家元首的保衛、國家機密的防護以及政治情報的蒐集等
    2. (B) 凡有利於防治犯罪的種種措施，均可視為犯罪預防的一環，而這也是警察業務的重點
    3. (C) 公共安寧秩序的保護屬於我國實務上的保安業務
    4. (D) 為民服務是警察業務中最瑣碎的一種，但就效果而言，是影響最深遠的工作

    正解：(B)

  12. 12下列有關 James Q. Wilson 針對美國境內八個社區的實地調查研究發現之敘述，何者正確？

    1. (A) 看守人型態的警察，多以處理犯罪問題居多
    2. (B) 警察執法功能為主的社區，具有社區居民無法決定警察政策的特色
    3. (C) 服務者型態的警察，通常較重視效率及科技的運用
    4. (D) 秩序維護功能為主的社區，居民的社經地位通常較高

    正解：(B)

  13. 13依據民國 107 年 3 月修正發布的「治安顧慮人口查訪作業規定」，為能對查訪對象之個案資料確實保密，當其對治安維護不再有幫助者，內政部警政署至遲應於資料製作完成後多久期限內，將相關電磁紀錄刪除之？

    1. (A) 2 年內
    2. (B) 3 年內
    3. (C) 5 年內
    4. (D) 10 年內

    正解：(C)

  14. 14警察勤務的運作，有依犯罪或聚眾鬥毆的「熱點」、「熱時」預置警力或增加巡邏密度，以強化立即打擊、預防犯罪效果，此作為可歸納係符合何種勤務運作原理？

    1. (A) 迅速原理
    2. (B) 機動原理
    3. (C) 彈性原理
    4. (D) 顯見原理

    正解：(C)

  15. 15下列何者非警察教育條例規定之深造教育？

    1. (A) 警察大學研究所
    2. (B) 研究班
    3. (C) 警監班
    4. (D) 警正班

    正解：(A)

  16. 16依警政署 104 年訂頒「啟動快速打擊犯罪警力計畫」規定，依治安狀況等級啟動快打警力，則如係案發分局除啟動自身分局「快打警力」外，尚須啟動區域聯防分局支援始能解除狀況，屬何等級？

    1. (A) A級
    2. (B) B級
    3. (C) C級
    4. (D) D級

    正解：(C)

  17. 17依「公務員廉政倫理規範」規定，與職務有利害關係者個別餽贈財物市價在新臺幣多少元以下，且係偶發而無影響特定權利義務之虞時，得受贈之？

    1. (A) 300 元
    2. (B) 500 元
    3. (C) 1000 元
    4. (D) 3000 元

    正解：(B)

  18. 18統一一致是單一國警察組織的原則，依我國現行警察法，係採取下列何種統一形式？

    1. (A) 地理性的統一
    2. (B) 種族性的統一
    3. (C) 業務或功能性的統一
    4. (D) 地域與業務的綜合體系

    正解：(D)

  19. 19依梅可望先生的觀點，下列何者不是現代警察的產生因素？

    1. (A) 工業革命以後科學發達
    2. (B) 人民對萬能政府的期待
    3. (C) 民主法治來保障人權
    4. (D) 武器的進步及戰爭的發動

    正解：(D)

  20. 20英國皮爾爵士在成立現代警察之初，定出警民關係的 9 個原則。試問下列何者非為其所強調的原則？

    1. (A) 警察的基本任務是預防犯罪與脫序行為的發生
    2. (B) 為維持民眾對警察的尊敬，警察必須獲得民眾配合守法的意願
    3. (C) 警察必須以討好民眾的方式，以回應社會大眾的期待
    4. (D) 警察只有在以理性說服、提出警告等方式無效的情況下，方得使用武力

    正解：(C)

  21. 21依警察勤務區訪查辦法規定，下列敘述，何者正確？

    1. (A) 治安顧慮人口之查訪依本辦法規定執行訪查
    2. (B) 警察勤務區訪查之目的為達成偵查犯罪、為民服務及社會治安調查等任務
    3. (C) 警察勤務區員警應逐家逐戶依本辦法規定落實實施訪查
    4. (D) 警察勤務區訪查，得以座談會方式實施，惟應將訪查時間及地點，於訪查日 3 日前，以書面通知受訪查者

    正解：(D)

  22. 22下列有關勤務規劃及執行之敘述，何者錯誤？

    1. (A) 利用無線電逃勤或怠勤者，應加重處分
    2. (B) 勤區查察勤務應預訂腹案日誌表並依腹案日誌表實施
    3. (C) 受理偵辦刑案應遵守事前簽辦、事中聯絡及事後報告之辦案程序規定
    4. (D) 勤務規劃應由較了解轄區狀況之資深員警、巡佐或副主管為之，主管負責督導及考核

    正解：(D)

  23. 23下列有關勤前教育之敘述，何者錯誤？

    1. (A) 前一日深夜實施專案勤務時，次日基層勤前教育，得免予舉行
    2. (B) 聯合勤前教育以每月舉行一次為原則
    3. (C) 員警參加勤前教育時間得併計服勤時數，該時段亦可報支超勤時數
    4. (D) 員警於勤前教育開始時已無勤務編排者，除有特殊情形，不得要求參加勤前教育，避免影響同仁權益

    正解：(C)

  24. 24穿著警察制服執行路檢勤務攔查人、車，遇民眾質疑在場全部警察身分，要求出示證件時，如何應處，最為正確？

    1. (A) 應依警察職權行使法規定先停止執行，並向民眾出示證件後，始得繼續執行
    2. (B) 不經查證，逕予放行
    3. (C) 依妨害公務現行犯，逕予逮捕移送法辦
    4. (D) 告知警察著制服執行勤務毋庸再出示證件，請其配合，如仍拒不配合，應依警察職權行使法規定採取必要強制措施及作為

    正解：(D)

  25. 25依「執行值班勤務作業程序規定」，下列有關值宿之敘述，何者錯誤？

    1. (A) 執行值宿勤務時，應依規定領用槍彈（置放於隨手可取之處），穿著整齊制服於值勤臺旁歇息
    2. (B) 各警察機關值宿分駐（派出）所，其值宿時段，由分局長依據實際狀況律定
    3. (C) 區分「值宿所」與「非值宿所」應由各警察機關參據警察勤務條例第 17 條第 2 項規定並依據警力數、地區特性及治安、交通、受理報案件數等因素，據以區分
    4. (D) 經核定為「非值宿所」，如當日實際服勤警力不足，符合值宿所之警力數時，得於 0 時至翌日6 時值班改為值宿

    正解：(D)
