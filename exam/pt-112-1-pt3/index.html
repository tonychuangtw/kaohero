物理治療師　112 年第一次 物理治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1若某一個神經細胞的絕對不反應期（absolute refractory period）為1 ms，而相對不反應期（relative refractoryperiod）為5 ms，此神經細胞能產生連續二個動作電位的最短時間間隔約為多少ms？

    1. (A) 1
    2. (B) 5
    3. (C) 6
    4. (D) 8

    正解：(A)

  2. 2傳統式與針灸式經皮神經電刺激之電刺激參數比較，下列何者正確？

    1. (A) 頻率：針灸式大於傳統式
    2. (B) 脈波時間（pulse duration）：傳統式小於針灸式
    3. (C) 強度：針灸式小於傳統式
    4. (D) 治療時間：傳統式小於針灸式

    正解：(B)

  3. 3有關去神經肌肉對電刺激的反應，下列敘述何者正確？

    1. (A) 基本電位（rheobase）減少
    2. (B) 時值（chronaxie）變短
    3. (C) 肌肉同步收縮且收縮放鬆所需時間較短
    4. (D) 較不容易產生適應現象（accommodation）

    正解：(D)

  4. 4以強化肌肉力量為目的之神經肌肉電刺激，下列何種肌肉收縮效果最佳？

    1. (A) 等張收縮，收縮次數少於10次
    2. (B) 等張收縮，收縮次數10～15次
    3. (C) 等長收縮，收縮次數少於10次
    4. (D) 等長收縮，收縮次數10～15次

    正解：(D)

  5. 5關於功能性電刺激臨床應用之敘述，何者錯誤？

    1. (A) 在步態擺盪期時刺激踝背屈肌，以矯正中風患者的垂足步態
    2. (B) 將電極片放在後三角肌和上斜方肌進行刺激，以改善中風患者的肩關節半脫位
    3. (C) 不明原因的脊柱側彎患者，可將兩電極片置於側彎最凸點的上下方，以減緩側彎情形惡化
    4. (D) 在步態站立期時刺激膝伸直肌，改善中風患者行走的穩定度

    正解：(B)

  6. 6矯正中風後病患垂足步態時，兩塊電極片擺放位置分別為何？

    1. (A) 脛神經，脛前肌
    2. (B) 脛神經，腓腸肌
    3. (C) 腓神經，腓腸肌
    4. (D) 腓神經，脛前肌

    正解：(D)

  7. 7中頻干擾波（interferential currents）之空間掃描式（spatial scanning）波形設定及其所引起的生理反應，何者正確？ ①一組電流頻率（frequency）不變，另一組電流頻率變動 ②主要用來治療較深層的組織問題 ③一組電流強度（amplitude）不變，另一組電流強度變動 ④主要用來治療不確定疼痛位置

    1. (A) ①②
    2. (B) ①④
    3. (C) ③④
    4. (D) ②③

    正解：(C)

  8. 8關於高壓間歇式直流電（high-voltage pulsed current）應用於促進傷口癒合，下列敘述何者正確？

    1. (A) 為達到最佳效果，正負極皆會放置於傷口上
    2. (B) 主動電極會使用面積較小的電極片
    3. (C) 電刺激強度須引起小程度肌肉收縮
    4. (D) 最好採用低電流長時間的方式，進行一整天不中斷的治療

    正解：(B)

  9. 9手術後急性水腫之病患，欲使用高壓間歇式直流電來降低水腫，如何擺放電極最適當？

    2. (B) 負極直接放在水腫區域，正極放在其近端
    3. (C) 正極直接放在水腫區域，負極放在其遠端
    4. (D) 負極直接放在水腫區域，正極放在其遠端

    正解：(B)

    2. (B) 鋅
    3. (C) 銅
    4. (D) 鎂

  11. 11肌電圖生物回饋不適用於下列何種臨床狀況？

    3. (C) 低頭族頸部肌肉出現保護性痙攣（muscle guarding）
    4. (D) 尿失禁患者的骨盆底肌控制訓練

    正解：(B)

  12. 12肌電回饋儀的主動電極應該如何擺放，才能得到較佳的肌電訊號？

    2. (B) 兩個電極位置應與肌纖維的方向平行
    3. (C) 兩個電極位置要儘量分開
    4. (D) 參考電極務必擺放在兩個電極之間

  13. 13下列何者並非Ｈ波傳導檢查能提供的訊息？

  14. 14有關神經肌肉強度－時間曲線（strength-duration curve）檢查，下列敘述何者正確？

    1. (A) 正常的神經肌肉系統通常呈現電刺激強度與波長時間正相關的曲線
    2. (B) 正常神經肌肉的時值（chronaxie）與基本電流強度（rheobase）皆比神經受損肌肉要高
    3. (C) 基本電流強度（rheobase）代表可造成神經肌肉反應的最低電流強度
    4. (D) 時值（chronaxie）代表可造成神經肌肉反應的最短波長

    正解：(C)

  15. 15有關淺層熱之生理效應及治療機轉，下列敘述何者正確？

    2. (B) 血管舒張：溫度上升刺激皮膚溫覺受器，使交感神經活動降低
    3. (C) 代謝速率增加：溫度上升超過45℃，使酵素活性增加
    4. (D) 代謝速率增加：使氧氣飽和血紅素解離曲線向左偏移，解離出更多氧氣

    正解：(B)

  16. 16關於冷療的適應症，下列敘述何者正確？

    1. (A) 減輕扭傷的疼痛
    2. (B) 增加關節活動度
    3. (C) 促進開放性深層傷口之癒合
    4. (D) 增加對扳機點（trigger point）之刺激而減低疼痛

  17. 17移動超音波治療頭的最適當速度，下列何者正確？

    4. (D) 纜線與皮膚須用厚毛巾隔開，不可直接接觸

  23. 23有關以對稱性放置法（contra-planar method）操作短波時，下列敘述何者錯誤？

  24. 24關於腰椎牽引，下列敘述何者正確？

    4. (D) 若病患有症狀周邊化（peripheralization）的現象時，代表為有效牽引

  29. 29針對不同型式的牽張（stretching）運動，下列敘述何者正確？

    2. (B) 循環間歇（cyclic/intermittent）牽張是以快速且短暫的牽張方式，反覆進行高強度的牽張

    4. (D) 高速（high-velocity）牽張特別適用於復健後期的老年人或坐式生活者
