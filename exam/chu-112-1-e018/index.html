    1. (A) 資料會被儲存成類似 JSON 的文件
    2. (B) 是最早出現的資料庫結構
    3. (C) 資料表間可透過主鍵與外鍵建立關係
    4. (D) 是以物件導向的方式來設計資料庫

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 關聯式資料庫以資料表為單位，透過主鍵與外鍵建立資料表之間的關聯。

    ❌ (A) 以類似 JSON 的文件儲存者為文件式 NoSQL 資料庫。

    ❌ (B) 最早出現的是階層式資料庫。

    ❌ (D) 以物件導向方式設計者為物件導向資料庫。

    📚 出處：資料處理．資料庫／關聯式模型

  2. 2某顆 CPU 其系統匯流排傳輸頻率為 1333 MHz，資料寬度為 64 位元，因此其資料頻寬應為：

    1. (A) 10.664 GigaBytes/Sec
    2. (B) 1333 MegaBits/Sec
    3. (C) 85312 MegaBytes/Sec
    4. (D) 10664 MegaBits/Sec

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 1333 MHz×64 bits＝1333×8 MB/s＝10664 MB/s≒10.664 GB/s。

    ❌ (B) 1333 MHz 為頻率而非頻寬。

    ❌ (C) 85312 是以位元為單位的數值。

    ❌ (D) 單位應為 MB/s 而非 Mb/s。

    📚 出處：資料處理．電腦組織／匯流排頻寬
