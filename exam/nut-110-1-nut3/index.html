營養師　110 年第一次 膳食療養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1有關 Crohn's disease 的敘述，下列何者正確？

    1. (A) 是對小麥麩質過敏之疾病
    2. (B) 常出現傾食症候群的症狀
    3. (C) 是一種先天性酵素缺乏的疾病
    4. (D) 常出現腸黏膜發炎的症狀頁次：4－2

    正解：(D)

  2. 2依據 Academy of Nutrition and Dietetics 與 ASPEN 的定義，在非計畫減重的狀況下，一個月體重至少減輕多少以上，即為嚴重體重減輕，屬於營養不良的高危險群？

    1. (A) 3%
    2. (B) 5%
    3. (C) 7.5%
    4. (D) 10%

    正解：(B)

  3. 3蔡小姐 21 歲，患有神經性厭食症，身高 158 公分，體重 40 公斤，平時偏食嚴重，只吃自己認為熱量少不影響體重的食物，經常減少餐次，若多吃就會去催吐，平均每日攝食量約 1,100 大卡。在進行營養診斷記錄時，下列敘述何者錯誤？

    1. (A) 營養診斷之問題（Problem）：熱量攝取不足
    2. (B) 營養診斷之原因（Etiology）：<25%的熱量需求
    3. (C) 營養診斷之原因（Etiology）：經常減少餐次
    4. (D) 營養診斷之症狀（Signs）：BMI =16

    正解：(B)

  4. 4下列何種營養素不是 elemental formula 的組成分？

  7. 7有關暴食症（Bulimia）的診斷標準之敘述，下列何者正確？

    2. (B) 體重顯著下降，且對自己身材的纖瘦沒有感覺
    3. (C) 個案常催吐、不當使用瀉劑或利尿劑，易造成貧血
    4. (D) 個案常發生皮膚乾燥、營養不良等問題，應即時補充熱量與蛋白質等

    正解：(A)

  8. 8有關體重的高原效應（Plateau effect），下列敘述何者錯誤？

    2. (B) 可能與減重過程中脂肪細胞釋放出儲存的毒素有關
    3. (C) 攝取富含植化素的蔬菜和水果有助於突破體重的高原效應
    4. (D) 運用極低熱量飲食（Very low-calorie diet）是突破體重高原效應有效率的方法

    正解：(D)

  9. 9下列有關身體組成的敘述，何者錯誤？

    3. (C) 一般而言，同年齡同性別之正常健康人，體組成中非體脂肪（fat free mass）之比例相似
    4. (D) 非體脂肪（fat free mass）即是瘦體組織（lean body mass）

    正解：(D)

  14. 14健康人飢餓狀態持續一週，其體內能量的利用與適應期內的相關機制之敘述，下列何者錯誤？

  15. 15重症病人常發生腸阻塞（ileus）而延緩腸道營養支持的進展，有關此狀況的敘述下列何者錯誤？

    2. (B) 腸道的絨毛萎縮，影響腸相關淋巴組織的「分泌性免疫細胞」
    3. (C) 給予靜脈營養可維持腸道功能和上皮細胞的 tight junctions
    4. (D) 缺乏灌流的腸道會導致促發炎物質的產生頁次：4－3

    正解：(C)

  16. 16針對手術前後的營養支持與介入注意事項，下列何者錯誤？

    1. (A) 麻醉前六小時應禁止進食固體食物、兩小時前禁止進食清流質食物，以避免吸入性肺炎
    2. (B) 若病人營養不良且預期腸道營養於術後 5-7 天無法順利進展，則手術前、後應給予靜脈營養，直到腸道營養達到目標
    3. (C) 若病人在術後需延長禁食的時間，應該在手術時合併施放胃造口和空腸造口，並使用胃造口灌食、空腸造口引流
    4. (D) 術後經評估，若病人可開始經口進食，也可優先吃固體食物，不一定只能從清流質開始

    正解：(C)

  17. 17消化性潰瘍常見於那一種細菌的感染？
