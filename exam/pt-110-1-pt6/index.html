物理治療師　110 年第一次 心肺疾病與小兒疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1某患者之動脈血氣體分析數值呈現pH=7.6，PaO = 98 mmHg，SaO = 96%，PaCO = 20 mmHg，HCO -= 252 2 2 3mEq/L，代表此患者目前為：

    1. (A) 呼吸性酸中毒（respiratory acidosis）
    2. (B) 呼吸性鹼中毒（respiratory alkalosis）
    3. (C) 代謝性酸中毒（metabolic acidosis）
    4. (D) 代謝性鹼中毒（metabolic alkalosis）

    正解：(B)

  2. 2造成動脈血氧分壓（PaO2）低於正常值的原因，下列何者錯誤？

    1. (A) 肺泡換氣與血液灌流比例不均（ventilation-perfusion mismatching）
    2. (B) 過度換氣（hyperventilation）
    3. (C) 分流（shunt）
    4. (D) 肺水腫

    正解：(B)

  3. 3關於健康人在常氧狀態下之血氧飽和度的判讀，何者正確？

    1. (A) 休息時的血氧飽和度介於60%～80%
    2. (B) 運動時血氧飽和度會增加10%
    3. (C) 運動時血氧飽和度會維持穩定
    4. (D) 運動時血氧飽和度會下降10%

    正解：(C)

  4. 4下列那個肺功能指標常用來評估氣喘患者的疾病嚴重度？

    1. (A) 肺活量（vital capacity）
    2. (B) 功能性殘餘容積（functional residual capacity）
    3. (C) 尖峰呼氣流速（peak expiratory flow rate）
    4. (D) 吸氣儲備容積（inspiratory reserve capacity）

    正解：(C)

  5. 5物理治療師需檢閱病歷了解患者的手術方式。請問下列何種手術方式，患者肺部的併發症最低？

    1. (A) 正中胸骨切開術（median sternotomy）
    2. (B) 前外側開胸術（anterolateral thoracotomy）
    3. (C) 側後開胸術（posterolateral thoracotomy）
    4. (D) 腋下開胸術（axillary thoracotomy）

    正解：(A)

  6. 6最大自主通氣量常用來表示一個人的那種能力？

    1. (A) 心肺適能
    2. (B) 吸氣肌肌力
    3. (C) 肺纖維化程度
    4. (D) 呼吸肌耐力

    正解：(D)

  7. 7關於新生嬰兒與正常成人在呼吸系統的差異之處，何者正確？

    1. (A) 新生嬰兒因肺彈性較差需較用力呼吸，故呼吸效率較差
    2. (B) 新生嬰兒因胸壁彈性較低，使呼吸貯存量下降
    3. (C) 新生嬰兒因肌肉張力較低，需靠呼吸副肌協助呼吸較多
    4. (D) 新生嬰兒因肺循環阻力高，氣體交換較困難

    正解：(A)

  8. 8下圖的器材在臨床的應用為何？

    1. (A) 可選擇阻力漸進做吸氣肌肌力訓練
    2. (B) 使呼氣氣流高過吸氣氣流，而使痰液的黏滯性降低
    3. (C) 呼氣時內部金屬球上升可減少氣道扁塌
    4. (D) 吹嘴搭配吸鼻動作可增加肺部擴張

    正解：(A)

  9. 9氣喘患者的呼吸道在反覆發炎過程會導致氣道重塑（airway remodeling），下列何者不是氣道重塑後的病生理變化？

    1. (A) 氣道阻力增加
    2. (B) 氣道管徑變厚
    3. (C) 肺殘餘量（residual volume）上升
    4. (D) 休息狀態下，會在較低的肺容量下呼吸

    正解：(D)

  10. 10一位診斷有肺氣腫的男性病人進行肺容積縮減手術（lung volume reduction surgery），術後有輕微漏氣現象，下列關於物理治療的敘述，何者正確？

    4. (D) 可從事例行物理治療，沒有特殊限制

  11. 11對於無法維持血氧飽和濃度而需要供氧的患者，治療師必須選擇適合的供氧方式及注意供氧的時機，下列敘述何者正確？

    2. (B) 最常見的供氧方式是用面罩（mask）
    3. (C) Venturi mask比non-rebreathing mask能提供更高濃度的氧氣濃度
    4. (D) 休息時動脈血氧低於55 mmHg或血氧飽和濃度低於88%時須供氧

    正解：(D)

  12. 12下列何種藥物可能為氣喘發作時可使用的支氣管擴張劑？

  20. 20某患者的開心手術病歷報告中包含下列紀錄：「GSV1→OM2，LIMA→LAD」，則此患者的術後物理治療，下列何者錯誤？

    3. (C) 以手握力測試代表肌肉適能時，每手測兩次共4次數值，4次數值的平均值可對照常模估算出年長者的存活率及功能狀態
    4. (D) 測量柔軟度可用坐姿體前彎（sit-and-reach test），表示肩關節及髖關節的柔軟度

    正解：(B)
