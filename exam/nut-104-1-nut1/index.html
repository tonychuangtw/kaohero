營養師　104 年第一次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1角質素（keratin）是屬於下列何種細胞骨架？

    1. (A) 微絲（microfilaments）
    2. (B) 中間絲（intermediate filaments）
    3. (C) 微管（microtubules）
    4. (D) 纖毛（cilia）

    正解：(B)

  2. 2電視台舉辦美食競賽，參賽者吃下了大量的牛排，這對參賽者胃酸分泌會造成下列何種影響？

    1. (A) 停止
    2. (B) 不變
    3. (C) 減少
    4. (D) 增加

    正解：(D)

  3. 3下列何者是食物香味對神經與胃腸的影響？

    1. (A) 經由中樞神經促進胃腸消化
    2. (B) 經由交感神經促進胃酸分泌
    3. (C) 經由腸肌神經叢促進消化液分泌
    4. (D) 經由黏膜下神經叢促進平滑肌活性

    正解：(A)

  4. 4胰臟分泌的消化酵素，要到下列何處才會被活化產生消化功能？

    1. (A) 胃
    2. (B) 小腸
    3. (C) 大腸
    4. (D) 肝

    正解：(B)

  5. 5血管張力素（angiotensin）的前驅物 angiotensinogen，主要是由下列何器官所產生的？

    1. (A) 腎臟
    2. (B) 肺臟
    3. (C) 肝臟
    4. (D) 脾臟

    正解：(C)

  6. 6在抗利尿素（ADH）大量分泌的情況下，腎小管何部位對水分再吸收的百分比為最高？

    1. (A) 近側腎小管
    2. (B) 亨利氏環下行支
    3. (C) 亨利氏環上行支
    4. (D) 集尿管頁次：4－2

    正解：(A)

  7. 7下列何者為腎臟對流機制（countercurrent mechanism）的主要功能？

    1. (A) 增加血中鈉離子濃度
    2. (B) 促進尿素排出體外
    3. (C) 供給腎小管足夠的血液
    4. (D) 維持腎髓質的高張性，進而增加集尿管再吸收水分之驅力

    正解：(D)

  8. 8有關胰島素（insulin）的敘述，下列何者錯誤？

    1. (A) 可降低血糖
    2. (B) 會促進肝細胞膜上葡萄糖轉運子 4（glucose transporter 4）的作用
    3. (C) 會促進肌肉細胞膜上葡萄糖轉運子 4（glucose transporter 4）的作用
    4. (D) 會促進脂肪細胞膜上葡萄糖轉運子 4（glucose transporter 4）的作用

    正解：(B)

  9. 9下列何者是由花生四烯酸（arachidonic acid）轉換合成？

    1. (A) 皮質醇（cortisol）
    2. (B) 腎上腺素（epinephrine）
    3. (C) 雌激素（estrogen）
    4. (D) 前列腺素（prostaglandins）

    正解：(D)

  10. 10有關生長激素（growth hormone）的代謝功能，下列敘述何者正確？

    1. (A) 促進肌肉細胞蛋白質合成
    2. (B) 增加脂肪細胞脂質合成
    3. (C) 降低肝細胞糖質新生（gluconeogenesis）
    4. (D) 增加肌肉細胞吸收葡萄糖

    正解：(A)

  11. 11有關自主神經系統對心臟功能的影響，下列敘述何者錯誤？

    1. (A) 副交感神經系統經由心臟菸鹼接受器（nicotinic receptor）使心跳下降
    2. (B) 交感神經系統經由 β 腎上腺接受器使心跳上升
    3. (C) 腎上腺素分泌不僅會增加心跳，也會增加心臟收縮能力
    4. (D) 交感神經會經由影響竇房結（SA node）的動作電位，使心跳加速

    正解：(A)

  12. 12有關腦循環血流的調控，下列敘述何者錯誤？

    1. (A) 平均動脈壓下降會造成大腦動脈舒張，屬於肌原性調控（myogenic regulation）
    2. (B) 血中二氧化碳濃度降低會造成大腦動脈的血管舒張
    3. (C) 代謝活動最高腦區，腦血流量最大
    4. (D) 腦血流需要隨時維持恆定

    正解：(B)

  13. 13有關紅血球功能的敘述，下列何者錯誤？

    1. (A) 血紅素（hemoglobin）是其細胞內攜帶氧氣的主要蛋白
    2. (B) 骨髓是紅血球的製造場所
    3. (C) 紅血球平均生命週期約為 60 天
    4. (D) 紅血球為無核細胞

    正解：(C)

  14. 14下列何種細胞在骨髓分化成熟？

    1. (A) B 細胞（B cell）
    2. (B) 毒殺型 T 細胞（cytotoxic T cell）
    3. (C) 輔助型 T 細胞（helper T cell）
    4. (D) 調節型 T 細胞（regulatory T cell）

    正解：(A)

  15. 15下列何者會抑制 B 細胞作用？

    1. (A) 毒殺型 T 細胞（cytotoxic T cell）
    2. (B) 輔助型 T 細胞（helper T cell）
    3. (C) 自然殺手細胞（natural killer cell）
    4. (D) 調節型 T 細胞（regulatory T cell）

    正解：(D)

  16. 16箭毒（curare）主要作用在下列何種神經傳導物質之接受器，進而導致骨骼肌無法收縮？

    1. (A) 腎上腺素
    2. (B) 血清胺
    3. (C) 多巴胺
    4. (D) 乙醯膽鹼頁次：4－3

    正解：(D)

  17. 17當我們看遠方物體時，下列敘述何者正確？

    1. (A) 睫狀肌（ciliary muscle）收縮，晶狀體變圓（lens rounded）
    2. (B) 懸韌帶（zonular fiber）拉緊，晶狀體變圓（lens rounded）
    3. (C) 睫狀肌（ciliary muscle）放鬆，晶狀體變扁（lens flattened）
    4. (D) 懸韌帶（zonular fiber）舒張，晶狀體變扁（lens flattened）

    正解：(C)

  18. 18下列何者為正常潮氣呼氣後在肺部內氣體殘留的量？

    1. (A) 肺餘容積（residual volume）
    2. (B) 吸氣容量（inspiratory capacity）
    3. (C) 呼氣儲備容積（expiratory reserve volume）
    4. (D) 功能肺餘容量（functional residual capacity）

    正解：(D)

  19. 19月經週期中動情素濃度的變化，由高到低依次為：

    1. (A) 黃體中期＞排卵前期＞濾泡早期
    2. (B) 排卵前期＞濾泡早期＞黃體中期
    3. (C) 排卵前期＞黃體中期＞濾泡早期
    4. (D) 濾泡早期＞黃體中期＞排卵前期

    正解：(C)

  20. 20下列何者是正常女性的細胞染色體特徵？

    1. (A) 具有一個 X 染色體
    2. (B) 具有貝氏小體（Bar body）
    3. (C) 具有 23 個染色體
    4. (D) 具有 SRY 基因

    正解：(B)

  21. 21轉酮基酶（transketolase）在戊醣磷酸途徑中參與二碳基團之轉移，其所需之輔酶為何？

    1. (A) pyridoxal phosphate
    2. (B) biotin
    3. (C) thiamine pyrophosphate
    4. (D) flavin adenine dinucleotide

    正解：(C)

  22. 22糖解作用（glycolysis）中，下列那些高能化合物可生成 ATP？①fructose-1,6-bisphosphate ②phosphoenolpyruvate③1,3-bisphosphoglycerate ④glyceraldehyde-3-phosphate ⑤dihydroxyacetone phosphate

    1. (A) ①③⑤
    2. (B) ②③④
    3. (C) 僅①⑤
    4. (D) 僅②③

    正解：(D)

  23. 23在糖解作用（glycolysis）中，下列那些酵素催化反應為不可逆？①enolase ②phosphofructokinase-1③aldolase ④glucokinase ⑤pyruvate kinase

    1. (A) ①②⑤
    2. (B) ②③④
    3. (C) ②④⑤
    4. (D) ③④⑤

    正解：(C)

  24. 24下列何者為同質多醣（homopolysaccharide）？

    1. (A) chondrotin sulfate
    2. (B) chitin
    3. (C) hyaluronic acid
    4. (D) keratan sulfate

    正解：(B)

  25. 25關於反式脂肪酸之敘述，下列何者錯誤？

    1. (A) 用於油炸時，較不易氧化酸敗
    2. (B) 每日攝取量達 7 公克以上即危害健康
    3. (C) 可使油脂熔點提高，使油脂在室溫下易呈固態
    4. (D) 常用於改善飽和油脂的硬度與穩定性

    正解：(D)

  26. 26關於血膽固醇濃度的調節，下列敘述何者正確？

    1. (A) 抑制 HMG-CoA reductase 活性可增加膽固醇的生成量
    2. (B) apoE 之基因缺陷是造成家族性高膽固醇血症的重要原因
    3. (C) 細胞中的游離膽固醇會刺激 LDL 受體之合成
    4. (D) 飲食中的膽固醇可以刺激體內膽固醇之分解

    正解：(B)

  27. 27下列何者可直接提供甲基以供磷脂醯膽鹼（phosphatidylcholine）之合成？

    1. (A) S-腺核苷甲硫胺酸（S-adenosylmethione）
    2. (B) 乙醇胺（ethanolamine）
    3. (C) 甲硫胺酸（methionine）
    4. (D) 膽鹼（choline）頁次：4－4

    正解：(A)

  28. 28關於不飽和脂肪酸的氧化過程，下列敘述何者錯誤？

    1. (A) 需要烯醯－輔酶 A 異構酶（enoyl-CoA isomerase）將順式雙鍵轉成反式
    2. (B) 氧化過程通常會產生丙醯輔酶 A（propionyl-CoA）
    3. (C) 和飽和脂肪酸一樣，都在粒線體中進行 β 氧化作用
    4. (D) 多元不飽和脂肪酸的氧化過程需要二烯醯－輔酶 A 還原酶（dienoyl-CoA reductase）參與

    正解：(B)

  29. 29關於 leptin 之敘述，下列何者正確？

    1. (A) 是一種酵素
    2. (B) 主要的作用目標器官是腦部
    3. (C) 後天型肥胖者通常缺少它
    4. (D) 係由腦部產生而作用於脂肪細胞

    正解：(B)

  30. 30在 urea cycle 中，產生 arginine 之酵素反應，同時也可以產生下列何者？

    1. (A) urea
    2. (B) ornithine
    3. (C) fumarate
    4. (D) citrulline

    正解：(C)

  31. 31分析血液樣品中之酵素含量可以診斷多種疾病的進展，檢驗 creatine kinase 可以用於診斷下列何種疾病？

    1. (A) cancer
    2. (B) heart attack
    3. (C) rickets
    4. (D) hepatitis

    正解：(B)

  32. 32兩個多肽，其序列分別為：Ala-Met-Ala-Leu-Gly-Arg-Tyr-Glu-Gly-Ile 以及Ala-Gly-Leu-Ala-Met-Arg-Ile-Gly-Glu-Tyr，下列方法何者可以區分此二序列？

    1. (A) 使用酸進行水解，之後再分析胺基酸組成
    2. (B) 使用 Sanger's reagent 進行反應，之後再分析產物
    3. (C) 使用 trypsin 進行水解，之後再分析各產物之胺基酸組成
    4. (D) 使用 carboxypeptidase 進行水解，之後再分析產物

    正解：(D)

  33. 33關於 DNA 的敘述，下列那些正確？①高溫加熱可使雙股 DNA 分開 ②雙股 DNA 之間的鹼基是藉由氫鍵進行配對 ③加酸或加鹼可使雙螺旋結構 DNA 瓦解 ④某一雙股 DNA 之 G 含量不會等於 C 含量

    1. (A) ①②③
    2. (B) ①②④
    3. (C) ①③④
    4. (D) ②③④

    正解：(A)

  34. 34關於核酸之敘述，下列何者錯誤？

    1. (A) 粒線體與葉綠體擁有自己的 DNA
    2. (B) 哺乳動物細胞的質體具有編譯漿蛋白的功能
    3. (C) E. coli 的染色體為封閉環狀的雙股螺旋 DNA
    4. (D) 大多數植物病毒的基因體為 RNA 所組成

    正解：(B)

  35. 35對於一雙股核酸而言，胞嘧啶（cytosine）通常會與下列何者進行鹼基配對？

    1. (A) 腺嘌呤（adenosine）
    2. (B) 鳥糞嘌呤（guanine）
    3. (C) 胸腺嘧啶（thymine）
    4. (D) 肌苷（inosine）

    正解：(B)

  36. 36下列何種蛋白質具有高遺傳保留性，並且參與真核生物中蛋白質的降解作用？

    1. (A) degradase
    2. (B) ubiquitin
    3. (C) peptidyl transferase
    4. (D) ricin

    正解：(B)

  37. 37關於 cytochrome 的敘述，下列何者錯誤？

    1. (A) cytochrome c 和 cytochrome b 的氧化態在波長 420 nm 吸光值較還原態低
    2. (B) 若抑制劑存在時，光譜吸光值型態有所變動
    3. (C) cytochrome 為含血基質的蛋白質
    4. (D) antimycin A 會抑制電子由 cytochrome c 往 b 流動

    正解：(D)

  38. 38丙酮酸去羧酶（pyruvate decarboxylase）為下列那一個類別的酵素？

    1. (A) 異構酶（isomerase）
    2. (B) 黏合酶（ligases）
    3. (C) 裂解酶（lyases）
    4. (D) 水解酶（hydrolases）

    正解：(C)

  39. 39Cytochrome c 與 coenzyme Q 的標準還原電位（standard reduction potential）相較，下列敘述何者正確？

    1. (A) cytochrome c 較低
    2. (B) 二者一樣
    3. (C) cytochrome c 較高
    4. (D) 無法比較

    正解：(C)

  40. 40下列何者可同時抑制異檸檬酸去氫酶（isocitrate dehydrogenase）和 α-酮戊二酸去氫酶（α-ketoglutaratedehydrogenase）二者活性？

    1. (A) acetyl-CoA
    2. (B) Zn2+
    3. (C) NADH
    4. (D) Mg2+

    正解：(C)
