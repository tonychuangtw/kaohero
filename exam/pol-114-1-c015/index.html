警察特考　114 年 四等考試 中華民國憲法與水上警察專業英文　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1依司法院大法官解釋之意旨，下列何者非各該憲法基本權利之保障範圍？

    1. (A) 依憲法之訴訟權保障，人民於其權利遭受侵害時，得依正當法律程序請求法院救濟
    2. (B) 基於憲法第 11 條關於講學自由之規定，保障大學自治，大學得不設軍事室
    3. (C) 基於憲法之服公職權，公務人員依法銓敘取得之官等俸級
    4. (D) 本於憲法之平等權，人民受他人歧視時應得依法向其請求民事賠償

    正解：(D)

  2. 2依司法院大法官解釋，下列何者與生存權的保障無關？

    1. (A) 有關工資、工作時間、休息、休假、退休、職業災害補償等勞工勞動條件之最低標準
    2. (B) 依三七五減租條例訂定之農地租約中，承租人全年家庭生活費用之認定標準
    3. (C) 藥害救濟制度中，對於受藥害者給予補償的範圍界定
    4. (D) 公立學校教職員退休後再任公立學校教職員，其重行退休時的年資計算標準

    正解：(D)

  3. 3依憲法增修條文及相關法律規定，政黨的行為如危害中華民國的存在，而擬聲請解散之，應由何機關提出？何機關審理？

    1. (A) 內政部提出、行政院審理
    2. (B) 內政部提出、憲法法庭審理
    3. (C) 行政院提出、最高行政法院審理
    4. (D) 行政院提出、憲法法庭審理

    正解：(B)

  4. 4依憲法本文規定，勞資雙方應本下列何種原則，發展生產事業？

    1. (A) 社會和諧
    2. (B) 協調合作
    3. (C) 成本效率
    4. (D) 永續發展

    正解：(B)

  5. 5憲法第 19 條規定，人民有依法律納稅之義務。依司法院大法官解釋，下列敘述何者正確？

    1. (A) 立法機關制定稅法時不得授權行政機關訂定命令予以補充
    2. (B) 行政機關針對稅法之解釋適用，不得發布解釋函令
    3. (C) 立法機關若以法律授權行政機關訂定補充規定，須符合授權明確性要求
    4. (D) 行政機關解釋稅法時得縮減法律賦予人民之租稅優惠範圍

    正解：(C)

  6. 6有關憲法居住自由之保障，下列敘述何者錯誤？

    1. (A) 憲法上的居住自由強調的是住宅的不可侵犯性
    2. (B) 都市更新事項僅涉及人民財產權保障，與居住自由無涉
    3. (C) 居住自由的保護法益，係保障生活空間的隱私權
    4. (D) 人民的居住自由不能衍生出擁有住宅權利

    正解：(B)

  7. 7依據司法院釋字第 631 號解釋意旨，下列何者可能侵害憲法保障之秘密通訊自由？

    1. (A) 檢調機關掛線監聽前未依法申請監聽票
    2. (B) 警察徵用人民私人通訊設備未依法補償其費用
    3. (C) 公立學校禁止學生攜帶手機到校
    4. (D) 郵政公司要求寄件者切結包裹內不含爆裂物

    正解：(A)

  8. 8下列何者違反國家對宗教之中立及寬容原則？

    1. (A) 甲為天主教會設立之私立中學，教育部依法對其所屬教師參加教學研習核發補助金
    2. (B) 乙因宗教因素拒絕手持殺傷性武器，因此向內政部申請服替代役獲准
    3. (C) 丙為全台知名廟宇，當地政府為推廣觀光，而將丙廟宇之介紹收錄於由其觀光局所管理之導覽網站
    4. (D) 丁為地方政府首長，本身為虔誠佛教徒，因此長期以公費供奉其轄區內特定寺廟，並於主持會議時向下屬宣傳教義

    正解：(D)

  9. 9下列何種分類標準，從未在我國釋憲實務中被審查？

    1. (A) 生理性別
    2. (B) 宗教信仰
    3. (C) 種族
    4. (D) 面貌五官

    正解：(D)

  10. 10人民對於確定終局裁判所適用之法令，經司法院解釋宣告違憲，釋憲聲請人據以提起再審之訴者，其再審最長期間 5 年之計算，應否扣除聲請案繫屬司法院大法官審理之期間？

    1. (A) 不應扣除
    2. (B) 應予扣除
    3. (C) 由檢察官定執行刑
    4. (D) 視情形而定

    正解：(B)

  11. 11有關憲法第 10 條保障遷徙自由之敘述，下列何者正確？

    1. (A) 外國人合法進入我國國境後，不受遷徙自由保障
    2. (B) 強制合法入境之大陸地區人民出境，與遷徙自由保障無涉
    3. (C) 對在國內無戶籍之我國國民進入國境，予以限制，與憲法保障遷徙自由之意旨不符
    4. (D) 國家為確保稅收，依法限制欠稅者出境，與憲法保障遷徙自由之意旨並無牴觸

    正解：(D)

  12. 12有關立法院立法委員選舉，各政黨依得票率選出之當選名單中婦女之席次數，下列敘述何者正確？

    1. (A) 不得低於 2 分之 1
    2. (B) 應過半數
    3. (C) 應與男性當選人之席位相同
    4. (D) 不得低於 3 分之 2

    正解：(A)

  13. 13按人民受教育之權利，依其憲法規範基礎之不同，可區分為「受國民教育之權利」及「受國民教育以外教育之權利」。有關前述二種權利，下列敘述何者正確？

    1. (A) 此二種權利皆兼有義務之性質
    2. (B) 只有「受國民教育之權利」兼有義務之性質
    3. (C) 只有受「國民教育以外教育之權利」兼有義務之性質
    4. (D) 此二種權利皆僅有權利之性質

    正解：(B)

  14. 14吊銷駕駛執照處分，可能影響駕駛何種權利？

  15. 15依大法官解釋，有關緊急命令，下列敘述何者錯誤？

    1. (A) 原則上得透過再授權為補充規定即可執行
    2. (B) 緊急命令為直接依憲法授權所發布
    3. (C) 緊急命令為暫時替代或變更法律效力之命令
    4. (D) 如因事起倉促一時無法就細節性、技術性事項鉅細靡遺規範而有待執行機關命令補充，須於立法院完成追認程序

    正解：(A)

  17. 17依我國憲法及增修條文規定，關於立法院對行政院院長提出不信任案，下列敘述何者正確？

  20. 20有關地方自治之憲法保障，下列敘述何者錯誤？

    2. (B) 我國係屬單一國，地方自治係由中央立法保障，並得由中央立法變動之
    3. (C) 依均權原則，事務有一縣之性質者，即屬縣自治事項
    4. (D) 中央得就地方自治事項制定框架性立法，但應保留地方自治團體相當之自主空間

  21. 21依司法院大法官解釋，下列何者違反憲法第 19 條「人民有依法律納稅之義務」規定？

    2. (B) 對於攜帶隨身及不隨身行李物品之入境旅客，均應依照入境旅客攜帶行李物品報驗稅放辦法辦理報驗稅放
    3. (C) 依中華民國政府與美利堅合眾國政府間互免海空運所得稅協定，就聯合航空經營國際運輸之所得，免徵所得稅及營業稅
    4. (D) 使用牌照稅法上明文交通工具免徵使用牌照稅係以「每一團體和機構以 3 輛為限」，財政部另以函釋明示該規定應以同一法人於同一行政區域（同一直轄市或縣（市））內之總分支機構合計 3 輛為限

    正解：(D)

  22. 22依司法院大法官解釋，記者跟追採訪所涉及之憲法保障，下列敘述何者錯誤？

    1. (A) 行動自由雖為憲法所保障，尚非不得以法律或法律明確授權之命令予以適當之限制
    2. (B) 限制新聞採訪者進行跟追，涉及記者行動自由之限制
    3. (C) 只要在公共場域，被跟追者就沒有不受侵擾之行動自由
    4. (D) 大眾所關切並具一定公益性之事務，而具有新聞價值，如須以跟追方式進行採訪，倘依社會通念認非不能容忍者，即具正當理由

    3. (C) 獨立行政機關須為追求憲法上公共利益，所職司任務具有特殊性，立法者方得設置
    4. (D) 獨立行政機關以聽證程序決定重要事項，任務執行績效透明、公開是其得以合憲存在的重要理由
