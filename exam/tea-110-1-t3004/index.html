  1. 1有兩個相似三角形，其面積比為 9：16，問其周長比為何？

    1. (A) 3：4
    2. (B) 4：3
    3. (C) 9：16
    4. (D) 81：256

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 相似形的面積比等於對應邊長比的平方，面積比 9：16 表示邊長比為 3：4；而周長比與邊長比相同，故為 3：4。

    ❌ (B) 把比值倒過來寫了。

    ❌ (C) 9：16 是面積比，不是周長比。

    ❌ (D) 81：256 是面積比再平方，沒有對應的意義。

    📚 出處：幾何—相似形的邊長比、周長比與面積比

  2. 2小潔從 A 點出發，順時針沿著六邊形公園的外圍繞一圈；小銘從 B 點出發，順時針沿著五邊形公園的外圍繞一圈，如下圖：A B問兩人各繞公園一圈後，兩人旋轉的角度相差多少？

    1. (A) 0°
    2. (B) 12°
    3. (C) 180°
    4. (D) 360°

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 沿著任何凸多邊形外圍繞行一圈，轉過的角度總和等於該多邊形的外角和，恆為 360°，與邊數無關，故兩人相差 0°。

    ❌ (B) 12° 沒有任何計算依據。

    ❌ (C) 誤以為六邊形與五邊形的內角和差（720°−540°＝180°）就是旋轉差。

    ❌ (D) 360° 是各自旋轉的總量，不是兩人的差。

    📚 出處：幾何—多邊形的外角和

  3. 3已知 𝑎𝑎、𝑏𝑏、𝑐𝑐 是實數，下列何者恆真？

    1. (A) 3 + 2𝑎𝑎 = 5𝑎𝑎
    2. (B) 𝑎𝑎 + 𝑏𝑏 ≥ 𝑎𝑎 − 𝑏𝑏
    3. (C) |𝑎𝑎| + |𝑏𝑏| = |𝑎𝑎 + 𝑏𝑏|
    4. (D) 𝑎𝑎2 + 4 𝑏𝑏 2 ≥ 𝑎𝑎𝑎𝑎

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 由完全平方的非負性 (a−2b)²≥0 展開可得 a²+4b²≥4ab，對所有實數皆成立。

    ❌ (A) 3+2a=5a 只有 a=1 時成立，並非恆等式。

    ❌ (B) 當 b<0 時 a+b<a−b，不恆成立。

    ❌ (C) 當 a、b 異號時 |a|+|b|>|a+b|，等號只在同號或有一為 0 時成立。

    📚 出處：代數—不等式與恆等式
