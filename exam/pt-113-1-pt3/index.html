物理治療師　113 年第一次 物理治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1當以0.1 ms波長、1 mA強度、頻率1 Hz的方形波刺激肌肉，可每秒產生1個肌肉顫動（twitch），如何調整電流參數以造成強直收縮？

    1. (A) 增加波長
    2. (B) 增加電流強度
    3. (C) 同時增加波長和電流強度
    4. (D) 增加電流頻率

    正解：(D)

  2. 2有關經皮神經電刺激（TENS）之止痛理論，下列何者錯誤？

    1. (A) 門閥理論是指直接刺激C纖維來抑制此疼痛纖維的傳導
    2. (B) 門閥理論可以解釋應用高頻率低強度之經皮神經電刺激的止痛效果
    3. (C) 可促進內生性鴉片類物質之釋放
    4. (D) 可促進局部血管擴張，減少組織缺血所產生的疼痛

    正解：(A)

  3. 3關於神經細胞膜電位的變化，下列敘述何者錯誤？

    1. (A) 靜止膜電位為-60至-90 mV
    2. (B) 去極化作用是由於鈉離子通道打開，鈉離子流入細胞所致
    3. (C) 去極化後回到靜止膜電位前，有一個短暫的細胞膜過度極化時期，稱為絕對不反應期
    4. (D) 再極化作用是由於鉀離子通道打開，鉀離子流出細胞所致

    正解：(C)

  4. 4運用神經肌肉電刺激強化股四頭肌肌力時，下列何種肌肉收縮方式較為適當？

    1. (A) 等速收縮
    2. (B) 等長收縮
    3. (C) 向心收縮
    4. (D) 離心收縮

    正解：(B)

  5. 5關於功能性電刺激電極片的尺寸及放置位置，下列何者正確？

    1. (A) 電極片愈小，電流密度愈小
    2. (B) 兩電極片間之距離愈近，電流在較淺層肌肉組織處流動
    3. (C) 電極片愈小，愈可在不痛狀況下產生最大肌肉收縮
    4. (D) 主動電極之電極片大於分散式電極

    正解：(B)

  6. 6利用干擾波治療尿失禁的應用，下列敘述何者錯誤？

    1. (A) 干擾波是以非侵入式的方式進行治療
    2. (B) 若以四極擺放，四個電極放在肚臍兩側腹部及兩邊大腿內側，膀胱需在四電極的中間位置
    3. (C) 病人的治療姿勢建議採仰臥，雙腳張開屈腿姿勢
    4. (D) 若以雙極擺法，一個電極在後側坐骨粗隆；另一個電極在前側恥骨聯合

    正解：(B)

  7. 7關於高壓間歇式直流電（high-voltage pulsed galvanic current）之敘述，下列何者正確？

    1. (A) 因為高壓，所以不建議用於疼痛控制
    2. (B) 為直流電，故可以協助將藥物導入皮下，作為離子電泳法（iontophoresis）使用
    3. (C) 可誘發去神經肌肉（denervated muscle），做出功能性收縮動作，進而幫助神經生長
    4. (D) 可治療感染性傷口，將陽極當作主動電極放置於鄰近傷口處，可抑制微生物生長

    正解：(B)

  8. 8在臨床上使用高壓間歇式直流電（high-voltage pulsed galvanic current）促進傷口癒合時，下列有關主動電極（treatment electrode）和分散電極 （dispersive electrode）位置之敘述，何者正確？

    1. (A) 主動電極和分散電極皆應置於傷口處
    2. (B) 分散電極應置於傷口處；主動電極應置於傷口旁
    3. (C) 主動電極應置於傷口處；分散電極應置於傷口旁
    4. (D) 主動電極與分散電極應隔日交替放置於傷口處

    正解：(C)

  9. 9以離子電泳法將藥物導入，下列何者應選用正極？

    1. (A) 水楊酸（salicylate）
    2. (B) 來多卡因（lidocaine）
    3. (C) 氯離子
    4. (D) 迪皮質醇（dexamethasone）

    正解：(B)

  10. 10關於離子電泳法的治療原則，下列敘述何者正確？

    1. (A) 正極電極應至少為負極電極的兩倍大
    2. (B) 主動電極應至少為分散電極的兩倍大
    3. (C) 使用連續性直流電治療，以至少30分鐘為原則
    4. (D) 完整皮膚可承受連續性直流電的最大安全電流密度為1 mA/cm2

    正解：(D)

  11. 11下列何者不適合使用肌電回饋儀輔助訓練？

    1. (A) 多產婦的應力性尿失禁（stress incontinence）
    2. (B) 慢性中風的垂足（drop foot）
    3. (C) 下背痛的肌肉防衛性痙攣（muscle guarding）
    4. (D) 失智症患者的緊張性頭痛（tension headache）

    正解：(D)

  12. 12初次利用肌電回饋儀輔助頸因性頭痛病人練習肌肉放鬆，為得到較高的信號增益，應該選用那一種儀器敏感度（sensitivity）最佳？

    1. (A) 1000 μV
    2. (B) 100 μV
    3. (C) 10 μV
    4. (D) 1 μV

    正解：(B)

  13. 13不同疾病患者，其靜止針刺肌電圖檢查（resting needle EMG）與神經傳導速度檢查（NCV）結果之解釋，下列敘述何者錯誤？

    1. (A) 肌病變疾病（myopathic disorder）患者，檢查結果通常EMG異常、NCV正常
    2. (B) 神經失用（neuropraxia）患者，檢查結果通常EMG正常、NCV異常
    3. (C) 軸索完全斷裂（complete axonotmesis）2天內的患者，檢查結果通常EMG異常、NCV異常
    4. (D) 軸索部分斷裂（partial axonotmesis）2至3週的患者，檢查結果通常EMG異常、NCV異常

    正解：(C)

  14. 14關於微粒治療的使用方式，下列敘述何者錯誤？

    1. (A) 治療溫度的設定通常介於38～50℃
    2. (B) 在治療箱中肢體須保持不動，不可進行主動運動，以免粒子飄出

    4. (D) 若有開放性傷口，需以塑膠袋或手套套著，以免感染

    正解：(B)

  15. 15有關蠟療的敘述，下列何者正確？

    2. (B) 蠟療所使用的溫度比水療低
    3. (C) 進行蠟療時手指應保持併攏

  16. 16關於冷療臨床應用的注意事項，下列敘述何者正確？

    2. (B) 對於冷反應過高者（hypersensitivity），可選擇適當的冷療法及增加治療時間，讓病人適應冷療
    3. (C) 冷療後因降低膠原組織伸展的能力，進行牽拉運動可能會傷到肌肉
    4. (D) 冷療因促進新陳代謝，而影響傷口的癒合

    正解：(C)

  17. 17對於不同治療目的，超音波的輸出方式，下列何者最適當？
