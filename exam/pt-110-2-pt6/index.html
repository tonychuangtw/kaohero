  1. 1對於因左側肺部問題而造成急性呼吸衰竭者，何種姿勢能增進其局部換氣而改善患者體內之氧合作用？

    1. (A) 側臥，右側在上
    2. (B) 側臥，左側在上
    3. (C) 正躺（supine）
    4. (D) 趴臥（prone）

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 側臥、患側（左側）在上時，通氣較差的左肺位於依重力分布的上方，可獲得較好的通氣與血流重新分布，改善通氣／灌流配合，進而提升氧合。

    ❌ (A) 右側在上會使健康側受壓、患側在下，通氣更差，無法改善氧合。

    ❌ (C) 正躺無法針對單側肺問題做選擇性通氣改善。

    ❌ (D) 趴臥（prone）主要用於ARDS雙側瀰漫性病變，對單側左肺問題並非首選。

    📚 出處：心肺物理治療學—姿勢擺位與通氣／灌流（V/Q）原理；單側肺疾病採患側朝上側臥。

  2. 2一般人在安靜時的正常呼吸週期，其吸氣時間與吐氣時間的比例為何？

    1. (A) 1：2
    2. (B) 1：3
    3. (C) 2：1
    4. (D) 3：1

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 安靜呼吸時吸氣約1秒、吐氣約2秒（吐氣因彈性回縮較被動而稍長），吸呼比約1：2。

    ❌ (B) 1：3吐氣過長，不符合正常安靜呼吸週期。

    ❌ (C) 2：1表示吐氣短於吸氣，與正常相反。

    ❌ (D) 3：1更不符合正常人安靜呼吸的吸吐比例。

    📚 出處：呼吸生理學—正常呼吸週期（I：E約1：2）；心肺物理治療學呼吸型態章節。

  3. 3檢視患者的胸腔X光片時，下列那個判斷正確？

    1. (A) 有氣體的地方是黑的
    2. (B) 正常人左側橫膈較右側橫膈高
    3. (C) 肋骨角（costophrenic angles）應是鈍角
    4. (D) 後前照（PA view）比側面照（lateral view）可以清楚看到下肺葉的情形

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 胸腔X光片的成像原理：氣體吸收X光最少，底片上呈黑色；骨骼、組織等密度高呈白色。

    ❌ (B) 正常人右側橫膈因下方有肝臟而位置較高，左側較低。

    ❌ (C) 肋膈角（costophrenic angles）正常應為銳角，變鈍表示肋膜腔積液。

    ❌ (D) 側面照（lateral view）較能清楚看到下肺葉（尤其後基底段），PA view對下肺葉顯示較受限。

    📚 出處：胸腔影像學基礎—X光密度成像與橫膈、肋膈角、PA／lateral view差異。

  4. 4關於肺功能測試（lung function test）的敘述，下列何者錯誤？

    1. (A) 肺容積測試，可依據肺活量或全肺量的預測值來區分肺疾病通氣程度
    2. (B) 流速－體積測試（flow-volume test），可依據第一秒用力吐氣量的預測值來區分肺疾病嚴重度
    3. (C) 體積－時間測試（volume-time test），可依據吸入第一秒用力吐氣量的預測值與用力肺活量兩者的比例來區分氣道阻力程度
    4. (D) 擴散容量測試（diffusion capacity test），依據肺活量或全肺量的預測值變化來區分肺疾病嚴重度

    正解：(D)
