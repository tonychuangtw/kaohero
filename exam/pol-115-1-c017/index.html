警察特考　115 年 四等考試 水上警察情境實務概要　考古題與詳解

本卷共 20 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（20 題，建議 60 分鐘）

  1. 1大雨或濃霧天候不佳時，當值人員為確保航安執行瞭望時，下列何者最適當？

    1. (A) 是否裝有雷達
    2. (B) 能見度的情況
    3. (C) 船舶的操縱性能
    4. (D) 航道條件

    正解：(B)

  2. 2中國大陸快艇在連江東引燈塔外 1 浬處炸魚，經海巡艇追到限制水域外距東引燈塔 10 浬處，始停俥受檢，下列處置何者最適當？

    1. (A) 未具管轄權，登檢後放行
    2. (B) 扣留調查並處罰鍰
    3. (C) 逮捕偵訊後移送地檢署法辦
    4. (D) 透過海峽兩岸共同打擊犯罪及司法互助協議模式移交給中國大陸海警

    正解：(C)

  3. 3某當事人遭地方法院函文通報海巡署該當事人限制出境出海，當事人欲搭乘離島交通船從東港至小琉球，已上船船尚未啟航，但當事人認無違法拒絕下船，下列敘述何者正確？

    1. (A) 安檢人員發現後應逕行逮捕，押解至原發布機關偵辦
    2. (B) 通知海巡艇監控該船，如逾越 12 浬界線則認定為出境，立即登檢逮捕押解至原發布機關偵辦
    3. (C) 通知巡防區以雷達監控該船，如逾越 12 浬界線則認定為出境，並通知離島安檢所，將該當事人逮捕押解回臺灣本島至原發布機關偵辦
    4. (D) 安檢人員發現後應告知當事人處分機關之處分書內容及文號，得逕行限制其出海

    正解：(D)

  4. 4海巡艇登檢漁船，發現其載運物品符合海關緝私條例等規定之「私運要件」，下列何者非屬之？

    1. (A) 規避檢查、偷漏關稅或逃避管制者
    2. (B) 未經向海關申報
    3. (C) 向海關申報不實以逃避管制
    4. (D) 運輸貨物進（出）國境

    正解：(C)

  5. 5海巡艇於宜蘭龜山島海域巡邏時，鎖定甲漁船形跡可疑，靠近後發現該船電魚事實，隨即發動登檢並蒐證，當場查獲該船持有電魚設備及漁獲，下列處置何者正確？

    1. (A) 依違反漁業法第 48 條規定移送地方檢察署偵辦並副知漁政機關
    2. (B) 立即拆除電魚設備，將漁獲海拋並錄影存證，移送漁政機關裁處
    3. (C) 實施蒐證並告知船長漁業法第 48 條規定，通報安檢所加強查緝
    4. (D) 依違反漁業法第 44 條規定函送漁政機關裁處

    正解：(A)

  6. 6海洋委員會海巡署艦隊分署布袋海巡隊接獲報案，停泊於麥寮工業港碼頭之貨輪，發生 150 公噸儲油外洩污染，除應立即派員協處外，並應由下列何權責分工機關負責應變？

    1. (A) 交通部
    2. (B) 經濟部
    3. (C) 海洋委員會
    4. (D) 雲林縣政府

    正解：(B)

  7. 7海巡艦艇於港內準備轉向，因障礙物遮蔽而無法確知轉彎處是否有船，此時鳴放號笛，下列何者正確？

    1. (A) 一長聲
    2. (B) 二長聲
    3. (C) 一短聲
    4. (D) 二短聲

    正解：(A)

  8. 8海巡艇登檢本國漁船，發現所有船員之船員證有變造之嫌，經實施人臉辨識，發現船員均為變造他人船員手冊出港。下列處置何者最適當？

    1. (A) 全案依違反漁船船員管理規則，函送農業部裁罰
    2. (B) 全案依違反刑法，移送地方檢察署偵辦
    3. (C) 全案依違反船舶法，函送航港機關裁罰
    4. (D) 全案依違反海岸巡防法，送海洋委員會海巡署艦隊分署裁罰

    正解：(B)

  9. 9海巡艇接獲通報，中國大陸船舶於馬祖東引岸際，因機械故障觸礁擱淺，海巡人員將遇險人員全數救援上岸。該擱淺船，應由下列何機關，命令船長限期移除或得逕行採取處理措施？

    1. (A) 交通部航港局
    2. (B) 海洋委員會海巡署艦隊分署
    3. (C) 連江縣政府
    4. (D) 大陸委員會

    正解：(A)

  10. 10有關 100 噸級海巡艇接獲通報，至花蓮豐濱外海 2 浬戒護我國籍失去動力 CT2 漁船，該船長請求協助拖帶進港。依海岸巡防機關執行海上救難作業程序，下列何者為可進行拖帶要件？

    1. (A) 因船長請託，考量人道救援精神，經艇長評估整體安全性無虞後，以無線電向隊部報備，協助拖帶進港
    2. (B) 船長表示若不拖帶就要找民意代表，為避免糾紛及衍生後遺，經艇長評估整體安全性無虞後，即協助拖帶進港
    3. (C) 該船因機械故障無法自力排除，為進港卸魚，請求拖帶，經艇長評估整體安全性無虞後，協助拖帶進港
    4. (D) 因該船持續漂往礁石區等危險區域，經艇長評估整體安全性無虞後，於船長同意簽拖帶同意書後，協助拖帶遠離危險區

    正解：(D)

  11. 11海巡人員為執行我國籍遠洋漁船失聯搜尋，除利用船用衛星電話、無線電外，還可使用下列那些方式追查船舶位置或動向？

    1. (A) 漁船船位監控系統（VMS）、緊急指位無線電示標（EPIRB）、航行記錄器（VDR）
    2. (B) 漁船船位監控系統（VMS）、緊急指位無線電示標（EPIRB）、船舶自動識別系統（AIS）
    3. (C) 漁船船位監控系統（VMS）、航行記錄器（VDR）、船舶自動識別系統（AIS）
    4. (D) 緊急指位無線電示標（EPIRB）、航行記錄器（VDR）、船舶自動識別系統（AIS）

    正解：(B)

  12. 12海洋委員會海巡署第七巡防區（高雄）接獲民眾電話報案，該民眾於小琉球潛水活動時，發現有潛水客觸摸海龜情事，他已拍照蒐證。下列處置何者最適當？

    1. (A) 立即派海巡人員赴報案人住處了解案情，並向該員表示全案會依法處置
    2. (B) 立即派海巡人員赴報案人住處了解案情，並請報案人回安檢所製作筆錄
    3. (C) 派海巡人員赴報案人住處，請報案人回安檢所製作筆錄，全案依違反「野生動物保育法」併蒐證資料函送屏東地方檢察署偵辦
    4. (D) 派海巡人員赴報案人住處，請其提供蒐證資料，全案依違反「野生動物保育法」函送屏東地方檢察署偵辦

    正解：(C)

  13. 13執行公海漁業巡護任務登檢外籍漁船時，除應主動出示身分證件，並儘可能使用船長能理解之語言與其溝通，必要時使用標準化多語登檢問卷進行詢問。有關登檢時應注意事項，下列何者最不適當？

    1. (A) 可以干涉船長與該國漁船管理當局之聯絡
    2. (B) 除非發現重大違規證據，相關檢查作為必須在 4 小時內完成
    3. (C) 儘可能採取不干涉漁船合法作業之方式進行
    4. (D) 避免對漁獲品質造成不利影響

    正解：(A)

  14. 14某船於澎湖西嶼西北方約 27 浬進水沉沒，經查明該沉沒船舶最高點距海面 9 公尺，位處航道附近，海巡機關基於航行安全應如何處理？

    1. (A) 利用漁民組訓、海上巡邏、岸偵雷達等方式，以掌握船舶後續情況
    2. (B) 由海巡機關責令船東（主）儘速為後續之處理
    3. (C) 立即通報管轄地區之航政主管機關發布航船布告
    4. (D) 海巡機關自行發布航行布告，請過往船隻注意，避免發生危險

    正解：(C)

  15. 15艇長下令因海象不佳但未達報停風力級數，要求航行當值人員於龜山島外 2 浬（風浪較平緩處）近岸航行，並以雷達監控海面狀況，為維護航行安全，當值人員交接班時，下列何者錯誤？

    1. (A) 交班人員應清楚交代潮汐海流海象等對航向航速之影響
    2. (B) 接班人員要清楚本艇附近其他船舶動態及附近是否有礁石區
    3. (C) 接班人員要清楚本艇目前主輔機與通訊設備運行狀況
    4. (D) 交班人員遭遇危及航安情事，提醒接班人員注意並立即交班

    正解：(D)

  16. 16海巡艇接獲通報，新港籍漁船（兼營娛樂漁業）搭載 3 名乘客，並攜帶九孔苗 80 箱，不聽勸阻出港，前往外海從事放流作業。下列處置何者最適當？

    1. (A) 海巡艇前往現場蒐證取締，並將蒐證資料函送臺東縣政府裁處
    2. (B) 海巡艇前往現場蒐證，並勸導勿違反相關規定
    3. (C) 海巡艇前往現場蒐證取締，並將蒐證資料送安檢所處理
    4. (D) 海巡艇前往現場蒐證取締，並將蒐證資料函送海洋委員會海洋保育署裁處

    正解：(A)

  17. 17有關海巡人員執行緝私案件程序注意事項，下列敘述何者錯誤？

    1. (A) 涉案人有 2 人以上者，應採隔離詢問
    2. (B) 在我國鄰接區水域查獲他國籍漁船載運香菸 500 箱，意圖入境，依海關緝私條例移送海關依權責處理
    3. (C) 在領海或內水內查獲他國籍漁船載運香菸 500 箱，意圖入境，違反菸酒管理法之行政罰者，移送主管機關辦理
    4. (D) 在我國鄰接區水域發現他國籍漁船載運洋酒 500 箱，意圖入境，違反菸酒管理法，逕移地方檢察署偵辦

    正解：(D)

  18. 18海洋委員會海巡署第六（臺南）巡防區雷逹操作員發現高雄籍膠筏於曾文溪西南外海 1.5 浬處，疑似違規近岸作業，立即通報臺南海巡隊線上海巡艇，惟該艇正執行安平港外多艘違規滯留貨輪之驅離任務。下列處置何者最適當？

    1. (A) 海巡隊立即緊急調派在港待命艇前往取締，並將蒐證資料函送農業部裁處
    2. (B) 巡防區立即通報第三無人機區就近前往現場蒐證查處，並將蒐證資料函送臺南市政府裁處
    3. (C) 海巡隊立即通報線上海巡艇前往現場蒐證，並將蒐證資料函送臺南市政府裁處
    4. (D) 海巡隊立即通報線上海巡艇前往現場蒐證，並勸導勿違反相關規定

    正解：(B)

  19. 19交通部觀光署大鵬灣國家風景區管理處公告琉球嶼週邊海域高潮線向外延伸 600 公尺之範圍，僅得從事非動力水域遊憩活動。海巡單位接獲通報有民眾駕乘水上摩托車於上述區域內活動，下列處置何者錯誤？

    1. (A) 立即派遣海巡能量（人、車、船），分別自岸際、海上前往通報區域蒐證
    2. (B) 再次確認通報區域是否經水域遊憩活動管理機關公告管理
    3. (C) 蒐證後，以其行為有影響水域遊憩活動民眾安全之虞，移送屏東地方檢察署偵處
    4. (D) 蒐證後，函送交通部觀光署大鵬灣國家風景區管理處裁處

    正解：(C)

  20. 20海巡艦發現外國籍貨船於領海內非錨泊區水域錨泊，經查明係因避風緊急避難，下列處置何者正確？

    1. (A) 通報 VTS，請該船進港避風，協助戒護進港
    2. (B) 要求開啟 VMS 及 AIS，避免發生碰撞
    3. (C) 完整蒐證函送航政主管機關裁處
    4. (D) 通報 VTS，持續由巡防區岸際雷達監控

    正解：(D)
