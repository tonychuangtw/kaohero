警察特考　105 年 三等考試 刑案現場處理與刑事鑑識　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1發生重大刑案，第一線的基層員警奉命抵達現場後，要落實刑案現場保全任務，應採取下列何種正確的作法？

    1. (A) 現場封鎖範圍應視現場環境及事實需要而定，原則以三道封鎖線為準
    2. (B) 立即實施現場封鎖，非經鑑識人員同意，任何人不得進入
    3. (C) 進入現場之指揮官，只負責指揮，所以不需著防護裝備
    4. (D) 現場封鎖，必要時派員於封鎖線內警戒

    正解：(A)

  2. 2面對恐怖攻擊，勘察人肉炸彈客引爆之爆炸案現場，鑑識人員應會同刑事警察局那個單位處理？

    1. (A) 偵一大隊
    2. (B) 偵三大隊
    3. (C) 偵五大隊
    4. (D) 偵七大隊

    正解：(C)

  3. 3警察人員到達刑案現場後，要注意各種跡證及關係位置，下列何者非刑事鑑識手冊所提，要特別注意之易消失的跡證？

    1. (A) 顏色
    2. (B) 溫度
    3. (C) 精液
    4. (D) 氣味

    正解：(C)

  4. 4現場測繪要完整記錄的內容為①重要跡證 ②周圍 ③現場，依照測繪要領，其正確之測繪順序為何？

    1. (A) ①②③
    2. (B) ①③②
    3. (C) ②①③
    4. (D) ②③①

    正解：(D)

  5. 5鑑識人員進入刑案現場，實施勘察採證，下列作法何者錯誤？

    1. (A) 實施勘察時，由現場指揮官先行進入現場，觀察現場內外情況
    2. (B) 採取跡證宜顧及鑑定之需要量，需全部採取者，全部採取，無法採取足夠數量時，應予註明
    3. (C) 對各明顯之跡證或認為需要細密勘察之位置，宜先放置號碼牌或箭號指示
    4. (D) 採取時同時採取鑑定所需比對樣品

    正解：(A)

  6. 6面對槍擊案件之槍枝、彈頭（殼）證物之處理原則，下列何者正確？

    1. (A) 警察機關查獲涉槍案件，為求公正，宜由調查局進行槍枝初步檢視
    2. (B) 有供比對用之不同廠牌子彈者，只需準備一顆送鑑即可
    3. (C) 查獲現場之槍枝，為保全跡證，應直接放入證物盒中保存，無須其他確認動作
    4. (D) 現場彈頭（殼）宜視個案情況留意其上可能之微物跡證，必要時，宜先採集鑑定

    正解：(D)

  7. 7巴黎恐怖攻擊事件中，鑑識人員面對火（炸）藥及爆炸遺留物之處理原則，下列何者正確？

    1. (A) 爆炸後爆裂物或碎片宜酌採 0.5 公克，以紙張包妥送鑑
    2. (B) 爆炸點周遭疑為火（炸）藥附著物，宜全部採集送鑑
    3. (C) 火（炸）藥送鑑時宜先由爆裂物處理人員全部採取送驗，以紙張包妥後置入塑膠證物袋內
    4. (D) 火（炸）藥送鑑時宜直接以塑膠夾鏈袋封裝，運送過程避免碰撞、摩擦、高溫等狀況發生

    正解：(B)

  8. 8有關最近鄭○澤殺警案，被提出再審之關鍵，其中涉及有關槍擊案件對於射擊殘跡證物的鑑識觀念，下列何者正確？

    1. (A) 同案有槍彈證物可供鑑定者，以槍彈證物之鑑定為優先，並將射擊殘跡證物暫時保存，視案情需要，再行送鑑
    2. (B) 採取手部射擊殘跡，宜於案發後 12 小時內儘速採集未經清洗、擦拭、救護之手部殘跡
    3. (C) 採取其他相關之射擊殘跡，宜於案發後 20 小時內儘速採集未經清洗、血跡污染之最外層衣物表面殘跡
    4. (D) 採取射擊殘跡，應以棉花棒沾濕，分別黏取不同部位，並分別標示其採證位置

    正解：(A)

  9. 9有關性侵刑案現場處理時，鑑識人員需採取生物類跡證之參考檢體以供比對，依據刑事鑑識手冊所提之規定，其應遵守的原則，下列何者正確？

    1. (A) 血液採取應由鑑識人員為之，取至少 2 毫升血液，置於含有 EDTA 抗凝劑試管內並冷藏保存
    2. (B) 執行採取時，優先採取血液，其次為唾液檢體
    3. (C) 送鑑時註明採樣人之姓名、出生年月日、身分證統一號碼，並注意個人資料保護
    4. (D) 唾液檢體請被採樣人漱口，再以棉棒擦拭口腔二側黏膜細胞，採樣 3 枝棉棒，乾後置入紙袋保存

    正解：(D)

  10. 10在一被竊賊棄置的車窗上，經過現場處理人員仔細蒐證，採到一枚指紋如下圖，經查證這是一左撇子慣犯所留下左手的指紋，請問該枚指紋是屬於那一種紋型？

    1. (A) 雜型紋
    2. (B) 帳型紋
    3. (C) 尺骨箕
    4. (D) 橈骨箕

    正解：(C)

  11. 11在擄人勒贖的案件中，被害人的手腳、嘴巴及眼睛均被膠帶纏繞，現場處理人員取下膠帶後，在下列的方法中，那一種最適合用來顯現膠帶黏膠面的指紋？

    1. (A) 氰丙烯酸酯法
    2. (B) 寧海德林法
    3. (C) 硫氰酸鉀法
    4. (D) 龍膽紫法

    正解：(D)

  12. 12依據刑法第 185 條之 3，駕駛動力交通工具而吐氣所含酒精濃度達多少以上，處 2 年以下有期徒刑，得併科 20 萬元以下罰金？

    1. (A) 0.25g/L
    2. (B) 0.25mg/L
    3. (C) 0.25g/dL
    4. (D) 0.25mg/dL

    正解：(B)

  13. 13利用 Widmark 微量擴散法來測定血液中酒精濃度時，需要加入下列何種試劑？

    1. (A) K2Cr2O4
    2. (B) CH3COOH
    3. (C) Na2S2O3
    4. (D) I2

    正解：(A)

  14. 14有關服用鴉片類藥物後，在體內代謝情形及其鑑定之敘述，下列何者最適當？

    1. (A) 在尿中檢測到嗎啡存在僅能認定呈嗎啡陽性
    2. (B) 在尿中檢測到海洛因存在僅能認定吸食海洛因
    3. (C) 服用嗎啡後，尿中嗎啡-6-尿甘酸含量比嗎啡-3-尿甘酸含量多
    4. (D) 服用甘草止咳水（Brown mixture）在尿中可檢測到 6-乙醯嗎啡

    正解：(A)

  15. 15下列何種方法適用於刑案現場血斑初步檢測？

    1. (A) Takayama test
    2. (B) Phenolphthalein test
    3. (C) Teichmann test
    4. (D) Florence test

    正解：(B)

  16. 16下列有關毒品性質及依據毒品危害防制條例第 2 條規定之敘述，何者正確？①Nitrazepam 又稱為一粒眠，列為三級 ②Cathine，列為三級 ③Buprenorphine 可用於鴉片類藥物成癮治療替代藥物，列為三級④Methadone 可用於鴉片類藥物成癮治療替代藥物，列為三級

    1. (A) ①②
    2. (B) ②③
    3. (C) ①③
    4. (D) ②④

    正解：(B)

  17. 17有關物件毀損之打印字跡的重現方法，下列敘述何者正確？①可以用半顯現磨除率 RD50，評估顯現方法的優劣 ②利用電解法顯現時，電源供應器的陽極接在金屬檢體，陰極接夾棉球的金屬夾 ③利用 Davis's試劑顯現，主要是鐵與銀離子的氧化還原反應 ④對於塑膠材質上之毀損字跡，可以使用高熱燈泡加熱顯現

    1. (A) ①②③
    2. (B) ②③④
    3. (C) ①②④
    4. (D) ①③④

    正解：(C)

  18. 18衣物服飾是人類穿著不可或缺的日用品，依據路卡交換原理，在任何一個刑案現場，均很容易留下纖維，下列有關刑案現場纖維的採證與鑑識敘述，何者最適當？

    1. (A) 在刑案現場的纖維，可用真空吸取法全部蒐集，以免漏失任何跡證
    2. (B) 棉纖維主要成分是纖維素，具有如竹子狀的結痕
    3. (C) 醋酸纖維是一種衍生纖維
    4. (D) 尼龍（nylon）是己二醇與己二酸合成的纖維

    正解：(C)

  19. 19縱火是現今常被用於犯罪的方法之一，通常是出於報復、摧毀犯罪跡證或是獲取不當的保險利益等，如果火災發生在可疑的環境，必須就起火點進行調查，下列有關火災案件處理與鑑定的敘述，何者最適當？

    1. (A) 通常蒐集縱火劑殘跡都必須由起火點蒐集
    2. (B) 使用 GC/FID 分析法，最適用的前處理萃取溶劑是二氯甲烷
    3. (C) 雖然滯留指數（retention index）會隨分析條件而改變，但仍可排除火場高熱裂解產物的干擾
    4. (D) 選定某一個特定質荷比值的強度重新繪製層析圖，稱為標的化合物層析圖，有助於未知物的比對鑑定

    正解：(A)

  20. 20恐怖活動為數最多的是爆炸案件，不法分子常以貨櫃、車輛、行李、包裹、人員或郵件藏匿運送爆炸物，因此，現場處理人員必須了解爆裂物之採證處理，有關爆裂物案件處理與鑑定的敘述，下列何者最適當？

    1. (A) 混合爆藥的氧化劑通常為鋁粉與鎂粉
    2. (B) 硝酸纖維與硝酸甘油所構成的火藥在爆炸過程仍會發煙
    3. (C) 鉛、銻、鋇、鋁、鎂為射擊殘跡的特性元素
    4. (D) 利用膠黏法採取射擊殘跡時，可以在採樣部位以黏膠面反覆按壓黏取，直到黏性消失為止

    正解：(D)

  21. 21刑事案件或肇事逃逸案件中，經常可以發現破碎的玻璃證物，有關玻璃碎片的處理與鑑定的敘述，下列何者最適當？

    1. (A) 利用真空吸取法採取現場玻璃碎片最為方便快速，廣為現場人員使用
    2. (B) 汽車門窗常用的玻璃為板玻璃（plate glass）
    3. (C) 可以用 Bromoform 與 Bromobenzene 測定玻璃的絕對密度
    4. (D) 利用微波消化法處理玻璃時，可以加入硫酸以溶解玻璃中的 SiO2

    正解：(C)

  22. 22刑事實驗室作為人類個化之 STR 基因型分析系統，下列何者為目前主要的分析方法？

    1. (A) 以液相層析進行 DNA 定序分析
    2. (B) 以液相層析進行 DNA 長度分析
    3. (C) 以毛細管電泳進行 DNA 定序分析
    4. (D) 以毛細管電泳進行 DNA 長度分析

    正解：(D)

  23. 23下列何者是散彈槍的口徑表示方式？

    1. (A) 規範
    2. (B) 規定
    3. (C) 規格
    4. (D) 規約

    正解：(C)

  24. 24在現場勘察中，為了增加主體物與背景的對比，經常使用螢光攝影，下列有關螢光攝影之敘述，何者最適當？

    1. (A) 在白光光源輸出端增加適當的濾色鏡，主要可以增加光源強度
    2. (B) 在白光光源輸出端增加適當的濾色鏡，主要可以過濾背景干擾
    3. (C) 在鏡頭前增加適當的濾色鏡，可以讓短波的螢光通過
    4. (D) 在鏡頭前增加適當的濾色鏡，可以讓長波的螢光通過

    正解：(D)

  25. 25顯微鏡經常於刑事鑑識實驗室使用，許多物證經過顯微鏡的觀察後，往往就有初步的鑑定結果，有關顯微鏡之敘述，下列何者最適當？

    1. (A) 顯微鏡使用之可見光的波長範圍約在 200-700 nm 之間
    2. (B) 凸凹鏡是屬於聚光鏡的一種
    3. (C) 成像偏差產生的原因主要為光的散射現象
    4. (D) 鏡頭蒐集光線的能力和其 NA 值平方成正比

    正解：(D)
