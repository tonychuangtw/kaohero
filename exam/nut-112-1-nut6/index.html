營養師　112 年第一次 食品衛生與安全　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1依據食品中污染物質及毒素衛生標準，下列何者訂有氫氰酸（HCN）限量標準？

    1. (A) 洋芋片
    2. (B) 木薯片
    3. (C) 咖啡豆
    4. (D) 可可豆

    正解：(B)

  2. 2依據食品良好衛生規範準則規定，真空包裝即食食品有下列那種情況時，不可常溫貯存及販售？

    1. (A) 天然酸性食品（pH 小於 4.6）
    2. (B) pH9.0 以上
    3. (C) 水活性在 0.94 以上
    4. (D) 鹽濃度大於 10%的發酵食品

    正解：(C)

  3. 3食品良好衛生規範準則中，有關食品製造業之檢驗及量測管制，下列規定何者錯誤？

    1. (A) 設有檢驗場所者，應具有足夠空間及檢驗設備，供相關檢驗工作進行
    2. (B) 衛生管理相關檢驗工作，得委託具公信力的檢驗機構辦理
    3. (C) 檢驗得採用簡便方法，但應先行向主管機關報備並予記錄
    4. (D) 測定、控制或記錄之測量器或記錄儀，應定期校正其準確性

    正解：(C)

  4. 4有關食品安全衛生管理法中「食品業者衛生管理」章節之條文內容，下列敘述何者錯誤？

    1. (A) 食品業者應實施自主管理
    2. (B) 所有食品業者應設置實驗室，從事食品自主檢驗
    3. (C) 食品或食品添加物的工廠應單獨設立，不得於同一廠址及廠房從事非食品的製造
    4. (D) 食品業者之從業人員應符合食品良好衛生規範準則的規定

    正解：(B)

  5. 5依據食品安全管制系統準則，管制小組應就食品安全管制系統之執行作成書面紀錄，連同相關文件彙整為檔案，妥善保存至少多久？

    1. (A) 產品有效日期後 6 個月
    2. (B) 3年
    3. (C) 5年
    4. (D) 7年頁次：4－2

    正解：(C)

  6. 6下列何種營養素列屬「需適量攝取」之營養素含量宣稱項目？

    1. (A) 鐵
    2. (B) 乳糖
    3. (C) 維生素Ａ
    4. (D) 膳食纖維

    正解：(B)

  7. 7端午節正值氣候炎熱時期易導致食物變質腐敗，下列對於粽子貯藏的敘述，何者正確？

    1. (A) 粽子在長期冷凍貯藏過程中，品質不會發生變化
    2. (B) 粽子若暫不食用，應儘速置於冷藏或冷凍貯藏，可延長食品保存期
    3. (C) 冷凍貯存可視為粽子殺菌的方式之一
    4. (D) 冷凍貯存可以完全抑制粽子內油脂之氧化酸敗

    正解：(B)

  8. 8蛋白中天然存在具有破壞革蘭氏陽性菌細胞壁功能的抗菌物質為：

    1. (A) 乳素（lactenins）
    2. (B) 苯甲酸（benzoic acid）
    3. (C) 溶菌素（lysozyme）
    4. (D) 生物素（biotin）

    正解：(C)

  9. 9微生物也可能會破壞食物中抑制微生物生長的物質，下列敘述何者錯誤？

    1. (A) 黴菌可分解添加於肉品中的苯甲酸
    2. (B) 酵母菌具有破壞二氧化硫的功效
    3. (C) 乳酸菌可分解乳酸鏈球菌素（nisin）
    4. (D) 濃縮糖漿中的醋酸菌可破壞其內的呋喃甲醛（furfural）

    正解：(D)

  10. 10下列有關乳製品腐敗的敘述，何者錯誤？

    1. (A) 苦味通常是耐熱性乳酸菌在溫度較高的情況下產生
    2. (B) 產氣是由異質乳酸發酵菌所引起
    3. (C) 產生黏絲或是質地黏稠是由假單胞菌屬（Pseudomonas）在低溫下產生黏質多醣類
    4. (D) 發霉是由青黴菌（Penicillium）在乳製品表面生長

    正解：(A)

  11. 11下列何者最有可能會造成罐頭食品的腐敗？

    1. (A) 黴菌孢子
    2. (B) 酵母菌
    3. (C) 細菌孢子
    4. (D) 黴菌菌絲

    正解：(C)

  12. 12下列何屬微生物菌種易引起果醬腐敗？

    1. (A) Rhodotorula spp.
    2. (B) Clostridium spp.
    3. (C) Salmonella spp.
    4. (D) Bacillus spp.

    正解：(A)

  13. 13Ames test 使用的沙門氏菌對何種胺基酸具需求性，可以檢測試驗物質是否有致突變的潛在危險？

    1. (A) Glycine
    2. (B) Histidine
    3. (C) Methionine
    4. (D) Phenylalanine

    正解：(B)

  14. 14食品安全風險評估中，下列何者不是風險特徵描述（Risk Characterization）的依據？

    1. (A) 暴露評估
    2. (B) 劑量反應評估
    3. (C) 危害鑑定
    4. (D) 危害特徵描述

    正解：(B)

  15. 15依據健康食品安全評估方法進行 28 天餵食毒性試驗時，至少要有三個劑量組，其中低劑量組之設計原則為何？

    1. (A) 不會引起毒性作用之劑量
    2. (B) 足以引起最低毒性作用之劑量
    3. (C) 足以使試驗動物產生毒性症狀，且會造成死亡之劑量
    4. (D) 足以使試驗動物產生毒性症狀，但不會造成死亡之劑量

    正解：(A)

  16. 16急性毒性試驗之結果可獲得下列何種資料？

    1. (A) IC50
    2. (B) LD50
    3. (C) VSD
    4. (D) NOEL

    正解：(B)

  17. 17下列何者為微生物來源之增稠劑？

    1. (A) 阿拉伯膠（arabic gum）
    2. (B) 瓜爾豆膠（guar gum）
    3. (C) 黃原膠（xanthan gum）
    4. (D) 刺槐豆膠（locust bean gum）

    正解：(C)

  18. 18下列何者為食品乳化劑？

    1. (A) 脂肪酸甘油酯（glycerin fatty acid ester）
    2. (B) 矽樹脂（silicon resin）
    3. (C) 乾酪素（casein）
    4. (D) 甘油（glycerol）頁次：4－3

    正解：(A)

  19. 19用於盛裝與貯存食品之馬口鐵罐，其材料特性，下列敘述何者正確？

    1. (A) 一般之馬口鐵皮為鍍錫鐵皮
    2. (B) 馬口鐵皮上防止罐壁腐蝕之漆塗層為一種低分子樹脂
    3. (C) 以馬口鐵罐盛裝果汁時易溶出鋅
    4. (D) 馬口鐵罐適合盛裝高酸性食品

    正解：(A)

  20. 20依據食品良好衛生規範準則，餐飲業者以氯液進行殺菌時，其施行條件，下列敘述何者正確？

    1. (A) 消毒抹布時，以氯液總有效氯 250 ppm 以下，浸入溶液中 10 分鐘以上
    2. (B) 消毒抹布時，以氯液總有效氯 200 ppm 以下，浸入溶液中 2 分鐘以上
    3. (C) 消毒毛巾時，以氯液總有效氯 250 ppm 以下，浸入溶液中 10 分鐘以上
    4. (D) 消毒餐具時，以氯液總有效氯 200 ppm 以下，浸入溶液中 2 分鐘以上

    正解：(D)

  21. 21某洗碗精成分標示含有乙二胺四乙酸（ethylenediamine tetraacetic acid），該添加物的主要作用為何？

    1. (A) 緩衝溶液之酸鹼度變化
    2. (B) 螯合溶液中金屬離子
    3. (C) 分散溶液污垢
    4. (D) 防止食物殘渣凝固

    正解：(B)

  22. 22我國法規除禁止製造與販售含雙酚 A 之嬰幼兒奶瓶外，針對下列何種塑膠材質之食品容器也訂有雙酚 A 的限量標準？

    1. (A) 聚碳酸酯（polycarbonate, PC）
    2. (B) 聚偏二氯乙烯（polyvinylidene dichloride, PVDC）
    3. (C) 聚醯胺（polyamide, PA）
    4. (D) 聚對苯二甲酸乙二酯（polyethylene terephthalate, PET）

    正解：(A)

  23. 23下列關於黃麴毒素（aflatoxin）之敘述，何者錯誤？

    1. (A) 常在黃麴菌（Aspergillus flavus）污染的食品中發現
    2. (B) 對熱、酸、鹼不具安定性
    3. (C) 此毒素具有高度致癌性
    4. (D) 可對肝、腎等器官造成毒害

    正解：(B)

  24. 24我國訂定組胺酸（Histidine）含量高之魚產品，其組胺酸限量標準為：

    1. (A) 50 ppm
    2. (B) 100 ppm
    3. (C) 200 ppm
    4. (D) 400 ppm

    正解：(C)

  25. 25天然毒素中，何者之主要作用為造成腎臟病變？

    1. (A) Tetrodotoxin
    2. (B) Citrinin
    3. (C) Saxitoxin
    4. (D) Aflatoxin B

    正解：(B)

  26. 26下列那些病原菌所產生的食物中毒症狀具有血便的病徵？①毒素型大腸桿菌 ②志賀毒素型大腸桿菌 ③沙門氏菌 ④小腸結腸炎耶爾辛桿菌

    1. (A) ①②④
    2. (B) ②③④
    3. (C) ①③④
    4. (D) ①②③

    正解：(B)

  27. 27食品經 100°C 加熱 20 分鐘後，仍有可能引起那些細菌性食物中毒？①金黃色葡萄球菌 ②肉毒桿菌 ③仙人掌桿菌嘔吐型 ④痢疾桿菌

    1. (A) ①②
    2. (B) ③④
    3. (C) ①③
    4. (D) ②④

    正解：(C)

  28. 28有關食品加工過程中所產生的污染物之敘述，下列何者錯誤？

    1. (A) 高溫處理富含蔗糖與天門冬醯胺酸之食材，容易產生大量的丙烯醯胺
    2. (B) 油炸含水量高的食材，容易使油炸油的品質下降
    3. (C) 使用全脂黃豆為原料製成的化學醬油，產生的單氯丙二醇最高
    4. (D) 以富含次亞麻油酸的植物油當作油炸油時，最容易產生脂質氧化物

    正解：(A)

  29. 29下列何者不屬於食品加工過程中衍生的有害物質？頁次：4－4

    1. (A) 反式脂肪酸（trans fatty acids）
    2. (B) 丙烯醯胺（acrylamide）
    3. (C) 多環芳香烴化合物（polycyclic aromatic hydrocarbons, PAHs）
    4. (D) 多氯聯苯（polychlorinated biphenyls）

    正解：(D)

  30. 30食品從業人員罹患傷寒，是由下列何種微生物導致？

    1. (A) Staphylococcus aureus
    2. (B) Shigella dysenteriae
    3. (C) Salmonella typhi
    4. (D) Escherichia coli

    正解：(C)

  31. 31弓漿蟲（Toxoplasma gondii）是一種常見的寄生蟲，其最終的寄主是：

    1. (A) 豬
    2. (B) 貓
    3. (C) 老鼠
    4. (D) 狗

    正解：(B)

  32. 32下列何者為引起新型庫賈氏症與狂牛症的致病因子？

    1. (A) 戴奧辛（dioxins）
    2. (B) 多氯聯苯（polychlorinated biphenyls）
    3. (C) 普立昂（prion）
    4. (D) 多環芳香烴化合物（polycyclic aromatic hydrocarbons, PAHs）

    正解：(C)

  33. 33餐具用紫外線照射法，主要檢查餐具是否有下列何種殘留？

    1. (A) 微生物
    2. (B) 蛋白質
    3. (C) 螢光物質
    4. (D) 脂肪

    正解：(C)

  34. 34依據食品良好衛生規範準則，食品從業人員在食品作業場所之管理，下列何者錯誤？

    1. (A) 穿戴整潔工作衣帽
    2. (B) 工作中不可以吸菸
    3. (C) 個人的珍珠奶茶要專區存放
    4. (D) 必要時應戴上口罩

    正解：(C)

  35. 35依據食品安全衛生管理法，食品及餐飲業者如發現產品有危害衛生安全之虞時，應即主動停止製造、加工、販賣等製備程序並辦理回收，並應通報何機關？

    1. (A) 行政院農業委員會農糧署
    2. (B) 直轄市、縣（市）主管機關
    3. (C) 經濟部工業局
    4. (D) 行政院消費者保護會

    正解：(B)

  36. 36依據食品良好衛生規範準則，有關餐飲業之衛生管理，下列何者錯誤？

    1. (A) 製備過程中所使用設備及器具，其操作及維護，應避免污染食品；必要時，應以顏色區分不同用途之設備及器具
    2. (B) 提供之餐具，應維持乾淨清潔，不應有脂肪、澱粉、蛋白質、洗潔劑之殘留；必要時，應進行病原性微生物之檢測
    3. (C) 供應生冷食品者，可與其他食品原料共同於作業區調理、加工及操作
    4. (D) 生鮮水產品養殖處所，應與調理處所有效區隔

    正解：(C)

  37. 37塑膠餐具應避免使用下列何種材質？

    1. (A) 聚乙烯（PE）
    2. (B) 聚碳酸酯（PC）
    3. (C) 聚丙烯（PP）
    4. (D) 聚氯乙烯（PVC）

    正解：(D)

  38. 38下列何者不屬於食品添加物之膨脹劑？

    1. (A) 酒石酸氫鉀
    2. (B) 氯化銨
    3. (C) 碳酸氫銨
    4. (D) 溴酸鉀

    正解：(D)

  39. 39依據連鎖飲料便利商店及速食業之現場調製飲料標示規定，含果蔬汁但含量未達多少者，品名應標示為「○○飲料」或等同意義字樣？

    1. (A) 5%
    2. (B) 10%
    3. (C) 15%
    4. (D) 20%

    正解：(B)

  40. 40依據食品中微生物衛生標準之規定，冷藏或冷凍的殺菌液蛋應檢測的微生物項目為何？

    1. (A) 總生菌數
    2. (B) 腸桿菌科
    3. (C) 沙門氏菌
    4. (D) 單核球增多性李斯特菌

    正解：(C)
