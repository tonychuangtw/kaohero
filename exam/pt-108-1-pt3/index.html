物理治療師　108 年第一次 物理治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何者不是冷療的適⽤症？

    1. (A) 降低痙攣
    2. (B) 急性燒傷
    3. (C) 肌筋膜疼痛症候群
    4. (D) 雷諾⽒症

    正解：(D)

  2. 2關於微粒熱療與熱敷袋的敘述，下列何者錯誤？

    1. (A) 使⽤過後的熱敷袋需要隔30分鐘後，才能再次使⽤
    2. (B) 微粒熱療主要以傳導的⽅式傳熱，較有效率
    3. (C) 微粒熱療較易維持有效治療溫度
    4. (D) 使⽤熱敷袋的部位無法做主動動作

    正解：(B)

  3. 3淺層熱療的傳遞⽅式，下列敘述何者正確？

    1. (A) 傳導：蠟療與紅內線
    2. (B) 對流：⽔療與微粒治療
    3. (C) 輻射：蠟療與紅內線
    4. (D) 傳導：⽔療與紅內線

    正解：(B)

  4. 4有關超⾳波治療儀器波束輸出不平均比值（beam nonuniformity ratio）的敘述，下列何者正確？

    1. (A) 比值越⾼越好，表⽰此儀器輸出會很平均
    2. (B) 比值越⼩越好，表⽰治療頭中央的輸出會⼩於平均輸出
    3. (C) 此比值為5時，若輸出強度為1 Watt/cm2，則熱點強度為5 Watt/cm2
    4. (D) 此比值為5時，若輸出強度為1 Watt/cm2，則熱點強度為0.2 Watt/cm2

    正解：(C)

  5. 5下列何者是全⾝⽔療之⼼臟⾎管⽣理效應？①增加靜脈回流 ②增加⼼輸出量 ③減少靜脈回流 ④減少⼼輸出量 ⑤增加⼼臟容積

    1. (A) 僅①②⑤
    2. (B) 僅③④⑤
    3. (C) 僅①④
    4. (D) 僅②③

    正解：(A)

  6. 6張老先⽣，85歲，處於⻑期臥床狀態，有第4期薦骨壓瘡（pressure sore），壓瘡⼤⼩為15 × 8平⽅公分，⽬前接受傳統傷⼝照護。上週他被轉介到物理治療部⾨，下列那⼀短波治療最能幫助其組織癒合？

    1. (A) 連續式，⿎狀電極（drum electrode），表⾯與治療部位儘量平⾏
    2. (B) 脈衝式，⿎狀電極（drum electrode），中⼼對準傷⼝最深位置
    3. (C) 連續式，⿎狀電極（drum electrode），中⼼對準傷⼝周圍完好⽪膚
    4. (D) 脈衝式，⿎狀電極（drum electrode），中⼼對準傷⼝周圍完好⽪膚

    正解：(B)

  7. 7王同學，21歲，⾜球校隊，在48⼩時前發⽣第⼆級的踝關節內翻扭傷，⽬前外側腳踝腫脹且有中度疼痛，承重時疼痛會加劇，下列何種治療最適合？

    1. (A) 3 MHz，1.5 W/cm2，100%⼯作週期的超⾳波
    2. (B) 1 MHz，1.5 W/cm2，80%⼯作週期的超⾳波
    3. (C) 較⾼輸出功率，20 Hz的間歇式短波
    4. (D) 較低輸出功率，連續式短波

    正解：(C)

  8. 8考量連續式短波儀器運作時輻射暴露的安全問題，⼀般建議物理治療師⾄少應離開運作中的短波儀器多遠的距離？

    1. (A) 30公分
    2. (B) 50公分
    3. (C) 1公尺
    4. (D) 5公尺

    正解：(C)

  9. 9低能量雷射治療可以降低發炎期的組織⽔腫，其最可能的機制為何？

    2. (B) 增加淋巴細胞活性
    3. (C) 增加組織代謝速率
    4. (D) 降低⾎清胺（serotonin）的分泌

    正解：(A)

  10. 10有關紫外線治療⽜⽪癬（psoriasis）的敘述，下列何者錯誤？

    1. (A) 全⾝性照射時，應使⽤第⼀級紅斑劑量（first-degree erythema dose）
    2. (B) 可⽤特定波⻑311～313 nm之UVB治療
    3. (C) 可局部塗抹Psoralen類藥物後進⾏UVA照射，以增加⽪膚對紫外線的吸收
    4. (D) 每週應適度增加治療劑量

    正解：(A)

  11. 11間歇性氣壓式加壓治療（intermittent pneumatic compression）的禁忌症，下列何者錯誤？

    1. (A) 肺⽔腫（pulmonary edema）
    2. (B) ⽪膚感染（superficial infection）
    3. (C) 間歇性跛⾏（intermittent claudication）
    4. (D) 深部靜脈栓塞（deep vein thrombosis）

    正解：(C)

  12. 12關於循環機治療淋巴⽔腫，下列敘述何者正確？

    1. (A) 增加組織間隙之靜⽔壓⾼於淋巴及⾎管之靜⽔壓，可使組織間液回流⾄靜脈或淋巴系統
    2. (B) 增加組織間質之滲透壓⾼於淋巴及⾎管之滲透壓，可使組織間液回流⾄靜脈或淋巴系統
    3. (C) 增加⾎管之靜⽔壓⾼於組織間隙之靜⽔壓，減少⾎管液體滲出⾄組織間
    4. (D) 增加⾎管之滲透壓⾼於組織間隙之滲透壓，減少⾎管液體滲出⾄組織間

    正解：(A)

  13. 13使⽤脊椎牽引時，下列敘述何者正確？

    1. (A) 腰椎以較彎曲的⾓度擺位會將牽拉⼒集中在下腰椎
    2. (B) 腰椎以較正中或伸直的姿勢擺位會將牽拉⼒集中在上腰椎與下胸椎
    3. (C) 頸椎以較屈曲的⾓度擺位會將牽拉⼒集中在下頸椎
    4. (D) 頸椎以較正中或稍微伸直的姿勢擺位會將牽拉⼒集中在頸胸關節

    正解：(C)

  14. 14關於頸椎牽引的牽拉⼒量設定原則，下列敘述何者正確？

    1. (A) 約須使⽤體重1/4的牽拉⼒，才可打開⼩⾯關節
    2. (B) 頸椎牽引療程的初期，應由3～4公⽄的牽拉⼒開始
    3. (C) 頸椎牽引的牽拉⼒最⼤不應超過體重1/2
    4. (D) 頸椎牽引療程中牽拉⼒量的增加，固定以每週1公⽄為單位

    正解：(B)

  15. 15有關微電流之敘述，下列何者正確？

    1. (A) 微電流之強度通常⼩於 1 μA，但患者仍可感受到電流
    2. (B) 微電流之強度通常⼩於 1 mA，且患者不會感受到電流
    3. (C) 微電流因使⽤特殊電流，⼀般電刺激器的電流輸出調低仍不可做為微電流治療使⽤
    4. (D) 因微電流之強度微弱，⼀般電療的禁忌症並不適⽤

    正解：(B)

  16. 16有關磁場治療的臨床應⽤與使⽤注意事項，下列敘述何者正確？

    1. (A) 可讓個案放鬆易於入睡，建議於睡前使⽤中⾼劑量的治療
    2. (B) 與放射治療搭配可以減緩正常組織所受到的傷害
    3. (C) 具有放鬆效果，建議於睡眠時⻑時間使⽤
    4. (D) 在急性期時建議使⽤3毫特斯拉（mT）相當於30⾼斯的治療強度

    正解：(D)

  17. 17有關持續被動關節活動儀（continuous passive motion）的操作，下列敘述何者正確？

    2. (B) 依據患者狀況使⽤時間每⽇可⻑達24⼩時
    3. (C) 可於術後立即使⽤，但必須等⿇醉藥效消退後才可使⽤
    4. (D) 應等患者術後狀況穩定，⾄少1週後才能開始使⽤

    正解：(B)

  18. 18關於電療儀器之空間漏電（leakage current），下列敘述何者正確？

  19. 19下列有關使⽤低頻率經⽪神經電刺激之敘述，何者錯誤？

  20. 20經⽪神經電刺激之電極片可以擺放的部位，下列何者正確？①扳機點 ②疼痛處同⼀神經肌節區域 ③疼痛處同⼀神經⽪節區域
