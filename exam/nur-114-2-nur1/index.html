護理師　114 年第二次 基礎醫學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關濾泡刺激素（follicle-stimulating hormone）的敘述，下列何者錯誤？

    1. (A) 刺激男性合成睪固酮（testosterone）
    2. (B) 作用標的是睪丸的曲細精管（seminiferous tubule）
    3. (C) 刺激女性合成雌激素（estrogen）
    4. (D) 作用標的是卵巢濾泡

    正解：(A)

  2. 2下列結構中，何者直徑最大？

    1. (A) 微絲（microfilament）
    2. (B) 微小管（microtubule）
    3. (C) 中間絲（intermediate filament）
    4. (D) 肌原纖維（myofibril）

    正解：(D)

  3. 3有關肌肉的作用，下列何者與其他三者不同？

    1. (A) 股二頭肌
    2. (B) 半腱肌
    3. (C) 半膜肌
    4. (D) 股薄肌

    正解：(D)

  4. 4在大多數的人，下列那兩者是左冠狀動脈（left coronary artery）的主要分支？

    1. (A) 前心室間動脈（anterior interventricular artery）與邊緣動脈（marginal artery）
    2. (B) 前心室間動脈與迴旋動脈（circumflex artery）
    3. (C) 後心室間動脈（posterior interventricular artery）與邊緣動脈
    4. (D) 後心室間動脈與迴旋動脈

    正解：(B)

  5. 5巨噬細胞是由下列何者分化而成？

    1. (A) 嗜酸性球
    2. (B) 嗜鹼性球
    3. (C) 單核球
    4. (D) 淋巴球

    正解：(C)

  6. 6下列何者與男性陰莖的龜頭，都是由尿道海綿體（corpus spongiosum）構成？

    1. (A) 陰莖球（bulb of the penis）
    2. (B) 陰莖腳（crura of the penis）
    3. (C) 陰莖包皮（prepuce of the penis）
    4. (D) 尿道球腺（bulbo-urethral gland）

    正解：(A)

  7. 7有關左、右腎臟的敘述，下列何者錯誤？

    1. (A) 二者水平位置等高
    2. (B) 二者皆為腹膜後器官
    3. (C) 二者上方皆有腎上腺
    4. (D) 二者的背面皆受第 12 肋骨保護

    正解：(A)

  8. 8下列何者是牙齒的主體結構？

    1. (A) 琺瑯質（enamel）
    2. (B) 牙質（dentin）
    3. (C) 白堊質（cementum）
    4. (D) 齒髓（tooth pulp）

    正解：(B)

  9. 9下列何者內含退化的臍靜脈？

    1. (A) 肝圓韌帶（round ligament of liver）
    2. (B) 鐮狀韌帶（falciform ligament）
    3. (C) 大網膜（greater omentum）
    4. (D) 小網膜（lesser omentum）

    正解：(A)

  10. 10下列何者攜帶的神經纖維刺激耳下腺的分泌？

    1. (A) 顏面神經
    2. (B) 舌咽神經
    3. (C) 動眼神經
    4. (D) 迷走神經頁次：4－2

    正解：(B)

  11. 11次級主動運輸（secondary active transport）的直接動力來自：

    1. (A) 電化學梯度
    2. (B) 三磷酸腺苷（ATP）
    3. (C) 三磷酸鳥苷（GTP）
    4. (D) 滲透壓

    正解：(A)

  12. 12鈣離子活化平滑肌細胞橫橋（cross-bridge）反應，下列何者為其主要作用？

    1. (A) 旋轉肌凝素（tropomyosin）
    2. (B) 旋轉素 C（troponin C）
    3. (C) 肌動蛋白（actin）
    4. (D) 肌球蛋白（myosin）

    正解：(D)

  13. 13下列何者不是下運動神經元（lower motor neuron）損傷的表徵？

    1. (A) 肌肉弛緩性癱瘓（flaccid paralysis）
    2. (B) 肌束顫動（fasciculation）
    3. (C) 肌肉萎縮（muscular atrophy）
    4. (D) 肌肉張力亢進（hypertonia）

    正解：(D)

  14. 14下列何者為清醒狀態（awake state）時，神經傳導物質所媒介的神經元活性表現？

    1. (A) 正腎上腺素（norepinephrine）神經元活性減弱
    2. (B) 血清素（serotonin）神經元活性減弱
    3. (C) 乙醯膽鹼（acetylcholine）神經元活性減弱
    4. (D) γ-胺基丁酸（GABA）神經元活性增強

    本題經考選部公告不計分。

  15. 15下列那個腦區是主要調控褪黑素（melatonin）的分泌？

    1. (A) 視上核（supraoptic nucleus）
    2. (B) 旁室核（paraventricular nucleus）
    3. (C) 視叉上核（suprachiasmatic nucleus）
    4. (D) 外側膝狀核（lateral geniculate nucleus）

    正解：(C)

  16. 16下列何者可將睪固酮轉換為動情二醇（17β-estradiol）？

    1. (A) 濾泡細胞
    2. (B) 萊迪氏細胞
    3. (C) 卵細胞
    4. (D) 卵囊泡膜細胞

    正解：(A)

  17. 17下列何種疾病主要是視錐細胞（cone cells）基因突變異常所致？

    1. (A) 散光（astigmatism）
    2. (B) 色盲（color blindness）
    3. (C) 弱視（amblyopia）
    4. (D) 青光眼（glaucoma）

    正解：(B)

  18. 18下列那一段腎小管（renal tubule）對水的通透度最低？

    1. (A) 近曲小管
    2. (B) 亨利氏管上行枝
    3. (C) 亨利氏管下行枝
    4. (D) 集尿管

    正解：(B)

  19. 19失語症（aphasia）與下列那個腦區受損最為相關？

    1. (A) 視丘（thalamus）
    2. (B) 海馬迴（hippocampus）
    3. (C) 維尼克氏腦區（Wernicke's area）
    4. (D) 前運動皮質（premotor cortex）

    正解：(C)

  20. 20下列那一種刺激會引起最多的唾液分泌？

    1. (A) 甜味
    2. (B) 酸味
    3. (C) 鹹味
    4. (D) 觸覺

    正解：(B)

  21. 21下列何種病灶的發炎反應形式與其他三種最不相同？

    1. (A) 膿胸（empyema）
    2. (B) 急性闌尾炎（acute appendicitis）
    3. (C) 膿瘍（abscess）
    4. (D) 帶狀疱疹（varicella-zoster virus）引起的水泡

    正解：(D)

  22. 22下列何種機制與鬱血性心衰竭（congestive heart failure）患者的肺水腫最為相關？

    1. (A) 肺毛細血管靜水壓增加
    2. (B) 肺毛細血管血漿膠體滲透壓降低
    3. (C) 肺毛細血管通透性增加
    4. (D) 肺臟淋巴管阻塞

    正解：(A)

  23. 23下列何種自體抗體（autoantibody）與全身性紅斑性狼瘡（systemic lupus erythematosus）最相關？

    1. (A) 抗核抗體（anti-nuclear antibody）
    2. (B) 抗肌動蛋白抗體（anti-actin antibody）
    3. (C) 抗粒線體抗體（anti-mitochondrial antibody）
    4. (D) 抗嗜中性球細胞質抗體（anti-neutrophil cytoplasmic antibody）頁次：4－3

    正解：(A)

  24. 24下列那一種人類病原體的大小（size）最小？

    1. (A) 黴菌（fungi）
    2. (B) 普利昂蛋白（prion）
    3. (C) 細菌（bacteria）
    4. (D) 原生動物（protozoa）

    正解：(B)

  25. 25末期大腸直腸癌具有遠端器官的腫瘤轉移。下列何者是大腸直腸癌最常發生轉移的器官？

    1. (A) 肝臟
    2. (B) 胰臟
    3. (C) 脾臟
    4. (D) 心臟

    正解：(A)

  26. 263 歲男性，右側睪丸有一個腫瘤，抽血發現血清中的甲型胎兒蛋白（α -fetoprotein）異常升高，他的睪丸腫瘤最可能是那一種？

    1. (A) 卵黃囊瘤（yolk sac tumor）
    2. (B) 絨毛膜癌（choriocarcinoma）
    3. (C) 淋巴癌（lymphoma）
    4. (D) 胚胎性癌（embryonal carcinoma）

    正解：(A)

  27. 27關於 IgA 腎病變（IgA nephropathy）的敘述，下列何者最不適當？

    1. (A) 又稱為 Berger 氏病（Berger disease），最好發於老年女性
    2. (B) IgA 主要沉積於腎絲球的膈細胞（mesangial cells）的區域
    3. (C) 病人通常會有血尿（hematuria）及蛋白尿（proteinuria）
    4. (D) 是目前世界上最常見的原發性腎病變，也是導致慢性腎病的主要原因之一

    正解：(A)

  28. 28子宮頸癌（cervical cancer）最常見的病理組織形態為何？

    1. (A) 鱗狀上皮癌（squamous cell carcinoma）
    2. (B) 腺癌（adenocarcinoma）
    3. (C) 小細胞癌（small cell carcinoma）
    4. (D) 腺樣囊性癌（adenoid cystic carcinoma）

    正解：(A)

  29. 29小腦天幕疝脫（transtentorial herniation），顳葉內側緣被擠壓時，下列何種變化最少見？

    1. (A) 腦壓上升
    2. (B) 腦萎縮
    3. (C) 瞳孔放大
    4. (D) 視覺皮質缺血

    正解：(B)

  30. 30痛風為尿酸鈉結晶沉積於關節或附近組織造成發炎反應，關於痛風的臨床表現下列何者正確？

    1. (A) 好發於生育年齡女性
    2. (B) 有高尿酸血症的人大部分都會有痛風
    3. (C) 好發於肢體近端大關節
    4. (D) 可能造成腎臟病變的併發症

  31. 31巨環類抗生素（macrolides）最不易引起下列何種副作用？

    3. (C) 耳毒性
    4. (D) 癲癇

  32. 32下列何者不屬於毒蕈鹼拮抗劑（muscarinic antagonist）的臨床適應症？

  34. 34下列藥物中，何者屬於長效型 β2 腎上腺性受體（β2 adrenergic receptor）致效劑，常用於治療氣喘及慢性阻塞性肺病（chronic obstructive pulmonary disease）？

  35. 35關於 Diphenhydramine 的敘述，下列何者錯誤？

  36. 36有關 Angiotensin-converting enzyme inhibitors（ACEIs）用於治療心衰竭的作用機制之敘述，下列何者錯誤？

    3. (C) 減少鈉水滯留

  38. 38下列糖尿病的治療藥物中，何者單獨使用時最可能造成低血糖（hypoglycemia）的風險？

    2. (B) Metformin
    3. (C) Pioglitazone

  45. 45金黃色葡萄球菌常在食材煮熟前就污染了食物，因而造成食物中毒。下列針對該菌造成食物中毒的敘述何者錯誤？

    3. (C) 食物中毒症狀通常伴隨發燒及血便
    4. (D) 臨床用藥以症狀消除為主，不建議抗生素
