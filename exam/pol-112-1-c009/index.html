警察特考　112 年 四等考試 警察法規概要（警察人員・行政警察人員組）　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1依警察法及其施行細則之規定，下列何者屬於警察官規事項？

    1. (A) 警察教育之種類階段
    2. (B) 警察人員之官等俸給職務等階
    3. (C) 警察機關之組織編制
    4. (D) 警察勤務之單位組合勤務方式

    正解：(B)

  2. 2依警察法及其施行細則之規定，下列敘述，何者錯誤？

    1. (A) 保安警察，遇有必要派往地方執行職務時，應受當地行政首長之指揮、監督
    2. (B) 刑事警察兼受當地檢察署檢察官之指揮、監督
    3. (C) 專業警察，由各該事業主管機關就其主管業務指揮、監督之
    4. (D) 保安警察協助配駐地方警察行政業務，應受當地警察機關首長之指揮

    正解：(D)

  3. 3依警察法第 9 條及其施行細則之相關規定，下列敘述，何者錯誤？

    1. (A) 警察法第 9 條所稱依法行使職權之警察，為警察機關與警察人員之總稱，亦即指廣義之警察意義
    2. (B) 發布警察命令，中央由內政部、直轄市由直轄市政府、縣（市）由縣（市）政府為之
    3. (C) 違警處分權之行使，依警察法令規定之程序為之
    4. (D) 協助偵查犯罪與執行搜索、扣押、拘提及逮捕，依刑事訴訟法及調度司法警察條例之規定行之

    正解：(A)

  4. 4公務人員依法享有之權益，應有其救濟管道及保障，因拒絕從事公務人員行政中立法禁止之行為而遭受不公平對待或不利處分，得依下列何法及其他有關法令之規定，請求救濟？

    1. (A) 訴願法
    2. (B) 公務人員保障法
    3. (C) 公務人員考績法
    4. (D) 公務人員行政中立法

    正解：(B)

  5. 5違反社會秩序維護法案件之處罰，於裁處確定後執行。下列有關裁處確定之敘述，何者錯誤？

    1. (A) 經警察機關處分之案件，受處分人未依法聲明異議者，其處分自處分書送達之翌日起，至第 5日期滿時確定
    2. (B) 地方法院或其分院簡易庭關於聲明異議案件之裁定，於裁定宣示或送達時確定
    3. (C) 地方法院或其分院簡易庭關於抗告案件之裁定，於裁定宣示或送達時確定
    4. (D) 撤回聲明異議或抗告之案件，其裁處於撤回書狀到達受理機關或原裁處機關時確定

    正解：(C)

  6. 6依社會秩序維護法之規定，某甲在公共場所或公眾得出入之場所，意圖媒合性交易而拉客，下列有關對某甲調查與裁處及救濟之敘述，何者錯誤？

    1. (A) 處三日以下拘留
    2. (B) 其情節重大者，得加重拘留至五日
    3. (C) 併處新臺幣一萬元以上五萬元以下罰鍰
    4. (D) 若對裁處不服，某甲得提起聲明異議

    正解：(D)

  7. 7依社會秩序維護法之規定，有意圖鬥毆而聚眾之行為者，處新臺幣一萬八千元以下罰鍰，下列有關調查與裁處之敘述，何者正確？

    1. (A) 警察機關與法院因民眾舉報知有違反該行為之嫌疑者，應即開始調查
    2. (B) 警察機關於訊問後，除有繼續調查必要者外，應即作成處分書
    3. (C) 警察機關於訊問後，應即移送該管簡易庭裁定
    4. (D) 有不服者，得向同法院普通庭提起抗告；對於普通庭之裁定，不得再行抗告

    正解：(B)

  8. 8依違反社會秩序維護法案件處理辦法第 63 條之規定，警察機關處理違反社會秩序維護法案件之書表格式，由下列何者訂之？

    1. (A) 行政院
    2. (B) 內政部
    3. (C) 內政部警政署
    4. (D) 內政部警政署刑事警察局

    正解：(C)

  9. 9依據集會遊行法第 6 條之規定，集會、遊行不得在法定之禁制地區及其週邊範圍舉行。但經主管機關核准者，不在此限。下列有關敘述，何者正確？

    1. (A) 副總統官邸屬於法定禁制區，由國家安全局劃定公告。但均不得逾 300 公尺
    2. (B) 國際機場、港口屬於法定禁制區，由交通部劃定公告。但均不得逾 300 公尺
    3. (C) 法院屬於法定禁制區，由內政部劃定公告。但均不得逾 300 公尺
    4. (D) 各國駐華使領館及其週邊範圍列為禁制區，由外交部劃定公告。但不得逾 300 公尺

    正解：(C)

  10. 10下列有關警察法規之性質，何者屬於法規命令之性質？

    1. (A) 拘留所設置基準
    2. (B) 警察機關辦理人民申請集會遊行作業規定
    3. (C) 偶發性及緊急性集會遊行處理原則
    4. (D) 警察遴選第三人蒐集資料辦法

    正解：(D)

  11. 11依據集會遊行法之規定，集會、遊行，經該管主管機關命令解散而不解散者，處集會、遊行負責人或其代理人或主持人下列何種性質之罰則？

    1. (A) 行政刑罰
    2. (B) 行政執行罰
    3. (C) 行政秩序罰
    4. (D) 行政懲戒罰

    正解：(C)

  12. 12下列何者之法律拘束效力最低？

    1. (A) 警察職權行使法
    2. (B) 治安顧慮人口查訪作業規定
    3. (C) 治安顧慮人口查訪辦法
    4. (D) 警察遴選第三人蒐集資料辦法

    正解：(B)

  13. 13警察為維護社會治安，並防制下列治安顧慮人口再犯，得定期實施查訪。下列何者依現行法規定，不屬於治安顧慮人口？

    1. (A) 經列入感訓處分執行完畢之流氓
    2. (B) 受毒品戒治人，經執行完畢或假釋出獄者
    3. (C) 曾犯組織犯罪之罪，經執行完畢或假釋出獄者
    4. (D) 曾犯持有毒品之罪，經執行完畢或假釋出獄者

    正解：(A)

  14. 14下列有關公法上金錢給付義務執行之敘述，何者錯誤？

    1. (A) 行政執行處應隨時提詢被管收人，每月不得少於 3 次
    2. (B) 斷絕營業所必須之自來水、電力或其他能源係間接強制方法
    3. (C) 義務人死亡遺有財產者，行政執行處得逕對其遺產強制執行
    4. (D) 義務人所負公法上金錢給付義務，不因管收而免除

    正解：(B)

  15. 15有關警察法規之法律性質，下列敘述何者錯誤？

    1. (A) 社會秩序維護法有程序法之性質
    2. (B) 警察服制條例無組織法之性質
    3. (C) 警察勤務條例無救濟法之性質
    4. (D) 保全業法有行為法之性質

    正解：(B)

  16. 16下列有關警察機關之說明，何者正確？

    1. (A) 地方警察機關預算標準，由內政部核定施行
    2. (B) 派駐於地方之保安警察，受當地警察機關指揮監督
    3. (C) 警察法所稱依法行使職權之警察，係指警察人員
    4. (D) 勤務督導與獎懲屬於各級警察機關權責範圍

    正解：(D)

  17. 17下列何等行為違反公務人員行政中立法？

    1. (A) 某警官參加公民投票的連署活動
    2. (B) 警校校長拒絕租借場地供辦理選舉活動
    3. (C) 警大教師向同事推崇縣議員候選人
    4. (D) 分局長陪同市長候選人進入寺廟上香

    正解：(D)

  18. 18有關全國性警察業務之說明，何者為非？

    1. (A) 派往地方協助治安之警察，受警政署指揮
    2. (B) 執行海運進口貨櫃走私物品查緝
    3. (C) 可巡邏核二電廠、中部科學園區
    4. (D) 為執行國土保護業務，得查緝濫盜採砂石之行為

    正解：(A)

  19. 19有關警察以科技工具蒐集掌握有事實足認有組織性犯罪之某黑道幫派幹部，駕車外出活動的敘述，何者正確？

    1. (A) 如出於防止犯罪之虞者，合法
    2. (B) 經主管同意，合法
    3. (C) 蒐集之資料如傳遞於其他機關，違法
    4. (D) 蒐集之期間至多兩年

    正解：(D)

  20. 20有關員警為偵辦違反刑事法律案件而遴選第三人秘密蒐集相關資料之敘述，何者正確？

    1. (A) 該管警察分局長無核准權
    2. (B) 遴選之第三人志願與警察合作，視為義警，並得支給實際需要工作費用
    3. (C) 蒐集之資料得依機密檔案管理辦法銷毀
    4. (D) 蒐集資料期間至少兩年

    正解：(C)

  21. 21依據治安顧慮人口查訪辦法，有關查訪治安顧慮人口之敘述，下列何者錯誤？

    1. (A) 曾竊取他人盜伐之紅檜者，屬查訪對象
    2. (B) 查訪性質是行政調查的事實行為
    3. (C) 受查訪人不在家時，得通知鄰居轉達
    4. (D) 受查訪之治安顧慮人口，縱經警察人員考試錄取，經查核後仍不得任用

    正解：(C)

  22. 22如有商號受雇人因執行業務而犯罪，並受判決科刑。請問下列說明何者正確？

    1. (A) 如犯有刑法妨害風化罪，依據社會秩序維護法得對該商號勒令歇業
    2. (B) 如犯有人口販運防制法之罪，依據社會秩序維護法對該商號處以罰鍰
    3. (C) 如犯有妨害秘密罪者，依據商業登記法對該商號勒令歇業
    4. (D) 如犯有妨害性自主罪者，依據公司法對該商號停業處分

    正解：(A)

  23. 23有關社會秩序維護事件之敘述，下列何者正確？

    1. (A) 社會秩序維護法有程序法和救濟法之性質
    2. (B) 地方警察就航空站航廈內違反社會秩序事件有管轄權
    3. (C) 樓上鄰居持續拖拉家具製造噪音應屬環保局所管
    4. (D) 社區管委會為催收管理費，持續按門鈴長達五分鐘滋擾住戶，逕由警察機關裁處

    正解：(A)

  24. 24如負責人縱容少年深夜聚集於其公共遊樂場所，而不即時報告警察機關者，下列有關裁處與其救濟敘述何者正確？

    1. (A) 過失違反者，得准許分期完納罰鍰
    2. (B) 經裁處後執行
    3. (C) 負責人以便簽表示冤枉，警察機關應予駁回
    4. (D) 受處罰人聲明異議經裁定駁回，警察機關不可撤銷原處分

    正解：(D)

  25. 25就室外遊行之申請，對主管機關許可通知書附帶許可限制事項不服，遊行負責人得請求之救濟以何者為正確？

    1. (A) 向原處分上級機關提出
    2. (B) 不服申復者，不可直接提起行政訴訟
    3. (C) 由原處分主管機關受理並決定之
    4. (D) 因申復程序進行，原核定許可之限制事項暫時停止效力

    正解：(B)
