警察特考　108 年 四等考試 法學知識　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1依司法院釋字第 719 號解釋，有關政府採購得標廠商員工逾百人者，應進用一定比例原住民，未進用者令繳代金之規定，係：

    1. (A) 合憲，相關規定對於財產權及營業自由之限制，符合憲法第 7 條平等原則及第 23 條比例原則
    2. (B) 違憲，相關規定優惠原住民族，牴觸憲法第 5 條民族平等原則
    3. (C) 合憲，得標廠商未僱用一定比例之原住民而須繳納代金，其金額如超過政府採購金額者，已有適當之減輕機制，故未違反比例原則
    4. (D) 違憲，以國內員工總人數是否逾 100 人為分類標準，在政府採購市場形成因企業規模大小不同而有差別待遇，違反平等原則

    正解：(A)

  2. 2有關預算案提出與審議之敘述，下列何者錯誤？

    1. (A) 行政院應於會計年度開始 3 個月前提出預算案於立法院
    2. (B) 立法院對行政院所提預算案，不得為增加支出之提議
    3. (C) 對公務員之報酬為年度通案增加，此增加待遇之規定不適用於本屆立法委員
    4. (D) 立法院對行政院所提預算案，不得比照審議法案之方式逐條逐句增刪修改

    正解：(C)

  3. 3憲法基本國策章關於國防之規定，下列敘述何者錯誤？

    3. (C) 全國陸海空軍須超出黨派關係以外，效忠國家
    4. (D) 國家應照顧退伍軍人，輔導其就業，相關經費優先編列

  4. 4依司法院大法官解釋之意旨，部分憲法條文與原則具有本質重要性而為規範秩序存立之基礎，不得予以變更，下列何者不屬之？

    2. (B) 憲法第 25 條國民大會代表全國國民行使政權
    3. (C) 憲法有關權力分立與制衡之原則
    4. (D) 憲法第 2 章保障人民權利

    正解：(B)

  5. 5釋字第 711 號解釋宣告當時藥師法第 11 條「藥師經登記領照執業者，其執業處所應以一處為限。」規定違憲，下列敘述，何者正確？

    1. (A) 上述規定是對職業自由主觀條件之限制
    2. (B) 上述規定的規範目的是為實施醫藥分業，防止租借牌照之不法情事，但考量我國藥師人數不足，並非正當立法目的
    3. (C) 上述規定所採取的手段，未設有合理的例外規定，違反比例原則
    4. (D) 相較於其他各類醫事人員並未限制於單一處所執業，上述規定違反平等原則

    正解：(C)

  6. 6依司法院大法官解釋，下列關於憲法上平等之敘述，何者錯誤？

    1. (A) 憲法第 7 條所宣示之平等，係保障人民在社會地位上之實質平等
    2. (B) 法規範是否符合平等，應視其目的是否合憲，及其分類與目的之達成間是否存有一定程度之關聯性而定
    3. (C) 憲法第 7 條所拘束者不限於立法機關，也包括行政與司法機關
    4. (D) 國家在合乎立法目的之下，得依據事物本質，為合理差別對待

    正解：(A)

  38. 38下列何種情形，結婚為無效？

    1. (A) 甲精神恍惚，由家人安排結婚以沖喜治病
    2. (B) 乙相親結婚後，才發現配偶婚前即已經醫師確診罹患癌症末期
    3. (C) 丙結婚後，才發現妻子與其前配偶的兩願離婚證人欄位係由其前配偶自行簽署
    4. (D) 丁 19 歲，未得法定代理人的同意而結婚，婚後 1 個月丁即懷孕，婚後 3 個月丁的父母發現丁未得其同意而結婚

    正解：(C)

  39. 39甲、乙簽訂 A 車的買賣契約，但就該契約乙非因其過失致意思表示內容錯誤。下列敘述，何者正確？

    1. (A) 乙得因其錯誤而解除買賣契約
    2. (B) A 車的買賣契約為無效
    3. (C) 乙得撤銷其 A 車買賣契約的意思表示
    4. (D) A 車的買賣契約經乙承認，始生效力

    正解：(C)

  40. 40下列有關侵權行為責任之敘述，何者錯誤？

    1. (A) 買到仿冒名牌包，可以向出賣人主張侵權行為
    2. (B) 職棒球員打出全壘打，致觀眾受傷，必須對該觀眾負起侵權行為賠償責任
    3. (C) 租來的車子被竊，承租人就無法使用車輛之利益，可以向竊賊主張侵權行為賠償
    4. (D) 在職場被同事性騷擾，該同事必須負起侵權行為責任

    正解：(B)

  41. 41繼承人自繼承開始時，原則上承受被繼承人財產上之一切權利義務。下列敘述何者錯誤？

    1. (A) 租賃契約雖定有期限，承租人若死亡，其繼承人仍得終止契約
    2. (B) 使用借貸契約存續期間，借用人若死亡，貸與人得終止契約
    3. (C) 合夥契約若無特約約定，合夥人死亡時，其繼承人得繼承之
    4. (D) 定期給付之贈與，因贈與人或受贈人之死亡，失其效力

    正解：(C)

  42. 42甲為受輔助宣告之人，於其父死亡後，未經輔助人同意，與其兄弟姊妹訂立遺產分割之協議契約。試問：甲訂立協議契約之行為，效力如何？

    1. (A) 有效
    2. (B) 無效
    3. (C) 得撤銷
    4. (D) 效力未定

    正解：(D)

  43. 43關於普通抵押權之敘述，下列何者錯誤？

    1. (A) 抵押權之設定須以書面為之，並辦理設定登記
    2. (B) 於抵押權所擔保之債權全部受清償時，則抵押權消滅，抵押權登記應予塗銷
    3. (C) 以抵押權所擔保之債權，經分割其一部者，抵押權不因此而受影響
    4. (D) 抵押標的物僅能以債務人所屬不動產為限

    正解：(D)

  44. 44關於正當防衛，下列敘述何者正確？

    1. (A) 正當防衛不需要有防衛意思亦可成立
    2. (B) 誤想防衛（錯覺防衛）亦可成立正當防衛
    3. (C) 防衛行為所保全之法益必須明顯優越於所侵害之法益
    4. (D) 為保護他人的利益而攻擊不法侵害者，仍屬於正當防衛的範圍

    正解：(D)

  45. 45下列有關罰金刑的敘述，何者正確？

    1. (A) 罰金刑與褫奪公權皆屬從刑規定
    2. (B) 罰金刑主要為剝奪犯罪預備之物
    3. (C) 罰金刑最低從新臺幣 1 千元起算
    4. (D) 罰金刑依刑法規定不可易服勞役

    正解：(C)

  46. 46甲為 A 股份有限公司之股東，下列何者應召開股東會決議之，若甲不同意該決議事項且放棄表決權，可請求 A 公司買回其股份？

    1. (A) A 公司決議變更為閉鎖性股份有限公司
    2. (B) A 公司與 B 公司進行股份交換，使 A 公司成為 B 公司持有股份總數 90%之子公司
    3. (C) A 公司進行減資，減資後，甲所持有股份不足一股
    4. (D) A 公司進行物的分割，新設公司成為 A 公司持有股份總數 100%之子公司

    正解：(D)

  47. 47依消費者保護法之規定，關於企業經營者未經消費者要約而對其郵寄或投遞之商品，下列敘述，何者正確？

    1. (A) 消費者得請求償還處理寄送物所支出之必要費用
    2. (B) 消費者仍負保管義務
    3. (C) 寄送後逾 2 個月未經消費者表示承諾，視為拋棄商品
    4. (D) 消費者有定相當期限通知對方取回商品之義務

    正解：(A)

  48. 48下列關於著作人格權之敘述，何者錯誤？

    1. (A) 著作人格權專屬於著作人本身，不得讓與或繼承
    2. (B) 著作人享有禁止他人竄改其著作之內容致損害名譽之權利
    3. (C) 著作人死亡或消滅者，其著作人格權亦消滅
    4. (D) 共同著作之著作人，得於著作人中選定代表人行使著作人格權

    正解：(C)

  49. 49依全民健康保險法第 27 條之規定，關於民營事業受僱者之保險費負擔之敘述，下列何者正確？

    1. (A) 被保險人及其眷屬自付百分之三十，投保單位負擔百分之七十
    2. (B) 被保險人及其眷屬自付百分之三十，投保單位負擔百分之六十，其餘百分之十，由中央政府補助
    3. (C) 被保險人及其眷屬自付百分之六十，其餘百分之四十，由中央政府補助
    4. (D) 被保險人及其眷屬自付全額保險費

    正解：(B)

  50. 50依家庭暴力防治法之規定，下列事件之陳述何者錯誤？

    1. (A) 甲女每月薪水均全部交給配偶管理，所有花費需控制在 2 千元內，還得逐筆核銷，符合家庭暴力經濟上之不法侵害行為
    2. (B) 乙男常以電子通訊設備長期持續性監視以掌控同居女友行蹤，構成精神上不法侵害及跟蹤行為
    3. (C) 丙男在國中就讀，經常遭受男同學以警告、嘲弄或辱罵之言語及動作，造成丙男心生畏怖，丙男母親得向法院提出保護令之聲請
    4. (D) 丁女對子女施以虐待行為，法官得依職權核定保護令中加害人處遇計畫，並要求實施認知教育輔導、親職教育輔導

    正解：(C)
