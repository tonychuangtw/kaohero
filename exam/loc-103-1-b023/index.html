  1. 1在資料庫產生資料表的 SQL 語法中，如果在 create table 的指令中，加入了 on update cascade，其目的是為了 使得資料庫具有何種特性？

    1. (A) 一致性
    2. (B) 獨立性
    3. (C) 完整性
    4. (D) 安全性

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) ON UPDATE CASCADE 使被參照的鍵值更新時，參照它的資料列一併連動更新，各資料表的值不致互相矛盾，維持的是資料的一致性。

    ❌ (B) 獨立性指資料與應用程式分離，與此無關。

    ❌ (C) 完整性著重資料是否符合定義的規則與限制，而非更新時的同步連動。

    ❌ (D) 安全性著重存取權限的控制。

    📚 出處：關聯式資料庫的參照動作（referential action）

  2. 2在關聯式資料庫（relational database）中，若要表示每個員工（employee）有一個不會和他人重複的編號（id）、一個姓名（name）和很多個電話號碼（tel），我們不會定義成一個關聯：employee（id,name,tel），而是定義成兩個關聯：employeel （id,name）和 employee2 (id,tel）。這樣做的目的是為了符合下列那種正規式（normalform）的要求？第一正規式（first normal form） ＿＿＿ 第二正規式（second normal form）第三正規式（third normal form） ＿＿＿ BC 正規式（Boyce-Codd normal form）

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 第一正規式要求每個屬性值均為單元值（不可有重複群組）；一位員工有多個電話會使 tel 欄位出現多值，故須拆為兩個關聯。

    ❌ (B) 第二正規式處理非鍵屬性對候選鍵的部分相依。

    ❌ (C) 第三正規式處理非鍵屬性間的遞移相依。

    ❌ (D) BC 正規式處理決定因素非候選鍵的情形。

    📚 出處：關聯式資料庫的正規化
