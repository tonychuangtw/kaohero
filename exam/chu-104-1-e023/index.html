  1. 1地政事務所為辦理測量設備更新，乃公開招標採購光學及雷射測量設備一批，並依決標結果與廠商締結買賣契約。請問對此種行為法律性質之敘述，下列何者最為正確？

    1. (A) 此為國庫行政之一種，乃行政輔助行為
    2. (B) 此為國庫行政之一種，乃行政營利行為
    3. (C) 此為國庫行政之一種，乃行政私法行為

    3. (C) 負擔處分

    正解：(B)

  42. 42關於行政罰裁處權時效之起算，下列敘述何者正確？

    1. (A) 自違反行政法上義務之行為終了時起算，但行為之結果發生在後者，自該結果發生時起算
    2. (B) 自違反行政法上義務之行為開始時起算，其行為之結果發生在後者，仍自行為開始時起算
    3. (C) 因行政訴訟經撤銷而須另為裁處者，自原裁處作成之日起算
    4. (D) 因天災、事變或依法律規定不能開始或進行裁處時，自停止原因消滅時重新起算

    正解：(A)

  43. 43下列何者不屬行政處分作成時，原則上應履行之程序事項？

    1. (A) 書面行政處分應記載事實、理由及法令依據
    2. (B) 不利處分作成前應予處分相對人陳述意見
    3. (C) 書面行政處分應表明其為行政處分之意旨及不服該處分之救濟方法、期間及其受理機關
    4. (D) 通知繳納費用

    正解：(D)

  44. 44下列何者不屬行政程序中得不予當事人或利害關係人閱覽之卷宗資料？

    1. (A) 涉及公務機密
    2. (B) 涉及個人隱私
    3. (C) 屬於申請人個人資料
    4. (D) 行政決定前之擬稿

    正解：(C)

  45. 45下列何者不屬訴願審理或決定原則？

    1. (A) 書面審理
    2. (B) 職權調查
    3. (C) 不利益變更禁止
    4. (D) 言詞審理

    正解：(D)

  46. 46下列何者得訂定罰則（行政罰）？

    1. (A) 自治條例
    2. (B) 自治規則
    3. (C) 行政規則
    4. (D) 職權命令

    正解：(A)

  47. 47下列爭議何者不屬訴願救濟之範圍？

    1. (A) 登記機關駁回土地所有權移轉登記之申請
    2. (B) 人民申購政府興建之國民住宅，經主管機關以其資格不符為由否准之
    3. (C) 國有財產署出售國有土地所生之履約爭議
    4. (D) 人民申請建築執照經主管機關否准

    正解：(C)

  48. 48A 有土地一筆遭到徵收，惟土地徵收機關違反土地徵收條例第 20 條第 1 項規定，未於公告期滿 15 日內給付補償價款，A 若欲主張徵收處分對其未發生效力而提起行政訴訟者，其訴訟類型為何？

    1. (A) 撤銷訴訟
    2. (B) 課予義務訴訟
    3. (C) 確認訴訟
    4. (D) 一般給付訴訟

    正解：(C)

  49. 49違反行政法上義務，依行政罰法之規定，下列何種行政罰，其情節輕微，認以不處罰為適當者，得免予處罰？

    1. (A) 法定最高額新臺幣 3000 元以下罰鍰
    2. (B) 法定最高額新臺幣 5000 元以下罰鍰
    3. (C) 沒入
    4. (D) 影響名譽之處分

    正解：(A)

  50. 50下列有關國家損害賠償之請求權人、賠償方法或賠償範圍的敘述，何者錯誤？

    1. (A) 賠償之範圍，就財產上之損害包括所受損失及所失利益
    2. (B) 損害賠償之方法以金錢賠償為原則，以回復原狀為例外
    3. (C) 死亡被害人之父母、配偶或子女，得請求國家損害賠償
    4. (D) 具公務員身分之自然人與法人，不得請求國家損害賠償

    正解：(D)
