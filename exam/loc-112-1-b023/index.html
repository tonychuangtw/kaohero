  2. 2(A<<5)+(A<<2)−A下列何者不屬於 CPU（Central Processing Unit）的構成部分？

    1. (A) 算術邏輯單元（Arithmetic / Logic Unit）
    2. (B) 控制單元（Control Unit）
    3. (C) 主記憶體（Main Memory）
    4. (D) 暫存器（Register）以某智慧型手機晶片執行人臉辨識的過程中，80%的運算時間用於執行捲積（convolution）運算。某研發人員提議在該晶片中加入進行捲積運算的加速器（accelerator）硬體。若該加速器獲得採用，此人臉辨識應用程式能獲得的最大加速（speedup）上限為何？

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 主記憶體位於 CPU 之外，透過匯流排與 CPU 交換資料，不屬於 CPU 的構成部分。

    ❌ (A) 算術邏輯單元負責運算，是 CPU 的核心組件。

    ❌ (B) 控制單元負責指令解碼與時序控制，屬 CPU。

    ❌ (D) 暫存器是 CPU 內部的高速儲存單元。

    📚 出處：計算機組織；CPU 架構。

  3. 3暫存器（Register）以某智慧型手機晶片執行人臉辨識的過程中，80%的運算時間用於執行捲積（convolution）運算。某研發人員提議在該晶片中加入進行捲積運算的加速器（accelerator）硬體。若該加速器獲得採用，此人臉辨識應用程式能獲得的最大加速（speedup）上限為何？

    1. (A) 3倍
    2. (B) 4倍
    3. (C) 5倍
    4. (D) 6倍將十進位數字 11 轉成二進位表示法，下列何者正確？

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 依 Amdahl 定律，可加速部分占 80%，最大加速上限＝1÷(1－0.8)＝5 倍。

    ❌ (A) 3 倍低於理論上限。

    ❌ (B) 4 倍同樣未達上限。

    ❌ (D) 6 倍超過 1÷0.2 的理論極限。

    📚 出處：Amdahl's Law。
