醫事檢驗師　103 年第二次 臨床生理學與病理學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1連接左臂與右臂的電極，組合成下列那種心電圖電極導（lead）？

    1. (A) I
    2. (B) II
    3. (C) III
    4. (D) aVF

    正解：(A)

  2. 2陳舊性心肌梗塞在無併發症的情況下，心電圖上只見到：

    1. (A) 不正常的Q波
    2. (B) ST段上升
    3. (C) ST段下降
    4. (D) T波倒置

    正解：(A)

  3. 3此張心電圖的診斷，下列何者最適當？

    1. (A) 心房性頻脈（atrial tachycardia）
    2. (B) 心房性纖維顫動（atrial fibrillation）
    3. (C) 心室性頻脈（ventricular tachycardia）
    4. (D) 心室性纖維顫動（ventricular fibrillation）

    正解：(C)

  4. 4心電圖中的PR區間的正常範圍是多少？

    2. (B) 0.10秒到0.20秒
    3. (C) 0.10秒到0.25秒
    4. (D) 0.14秒到0.24秒

    正解：(A)

  5. 5在心電圖心軸正常範圍為-30度到90度下，第I導平均QRS波為正向波，第II導平均QRS波也為正向波，則表示：

    3. (C) 心軸左偏位
    4. (D) 極端心軸偏位

    3. (C) 低血鉀症
    4. (D) 低血鈣症

    3. (C) B淋巴細胞（B lymphocyte）
    4. (D) 實質細胞（parenchymal cell），例如肝臟之肝細胞

    正解：(A)

  57. 57下列何者是多囊性卵巢（polycystic ovaries）組織學或生化學上的特徵？

    1. (A) 常出現單側卵巢腫大，至正常大小的兩倍以上

    4. (D) 血液中經常會出現高濃度的雄性激素（androgen）

  61. 61細胞具有毛玻璃狀細胞核（ground-glass nucleus）、細胞核溝（nuclear groove）、細胞核內假性包涵體（nuclear pseudoinclusions），且常有沙狀瘤鈣化小體（psammoma bodies）出現，是下列何種甲狀腺腫瘤的特徵？
