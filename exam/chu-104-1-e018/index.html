初等考試　104 年 初等考試 資料處理大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1Windows 作業系統中「附屬應用程式」下的「系統工具」內有一個「磁碟重組工具」，下列有關此工具的敘述何者錯誤？

    1. (A) 可重新排列分散在磁碟機的資料，使磁碟機運作更有效率
    2. (B) 僅能重組電腦內建的磁碟，無法重組 USB 隨身碟之類的卸除式裝置
    3. (C) 磁碟重組前不須先進行「磁碟分析」作業，可直接執行「磁碟重組」作業
    4. (D) 可以設定排程執行「磁碟重組」作業

    正解：(B)

  2. 2隨著技術演進，為提供各種不同的傳輸應用，越來越多高速傳輸介面問世，下列何者錯誤？

    1. (A) USB 由各家電視業者推出，提供與 DVI 介面相容的影音連接器
    2. (B) SATA 提供 PC 主機板連接硬碟、光碟等各種儲存裝置
    3. (C) HDMI 提供數位裝置、電腦監視器、數位電視等之連接
    4. (D) PCI express 取代 PCI，提供主機板上各種擴充卡、晶片組間的內部連接

    正解：(A)

  3. 3在 Windows 作業系統與 Office 環境中，將下列那一按鍵按住，並利用滑鼠，可以同時選取不相鄰的多個物件？

    1. (A) Alt 鍵
    2. (B) Ctrl 鍵
    3. (C) Enter 鍵
    4. (D) Shift 鍵

    正解：(B)

  4. 4有關 64 位元作業系統的敘述何者錯誤？

    2. (B) 所有應用程式需要全部採用 64 位元版本
    3. (C) 需要安裝在配備有 x64 處理器的電腦
    4. (D) 相關驅動程式需要安裝 64 位元版本

    正解：(B)

  5. 5有關固態硬碟（Solid State Disk/Solid State Drive, SSD）的敘述何者錯誤？

    1. (A) 關掉電源後資料仍然可以保存

    3. (C) 透過低噪音馬達驅動的硬碟
    4. (D) 具有低耗電與抗震等特點

  26. 26為了建構有效率的關聯式資料庫，通常會先進行組織資料的正規化（normalization）程序，以產生正規式（normal form, NF）。下列有關正規化的敘述何者錯誤？

    1. (A) 可刪除重複性、不一致的相依性資料
    2. (B) 一種資料表分割的方法，讓資料庫運作更有效率
    3. (C) 1NF 是解決各欄位與主鍵間沒有部分相依（partial dependencies）的問題
    4. (D) 3NF 要確保各欄位與主鍵間沒有間接相依（indirect dependencies）的問題

    正解：(C)

  27. 27下列何者不是軟體雛型模型的優點？
