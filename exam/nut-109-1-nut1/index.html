營養師　109 年第一次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列有關細胞受器（receptor）和配體（ligand）之作用，何者正確？

    1. (A) 細胞膜上的受器蛋白若無細胞質端，則無法傳遞訊息
    2. (B) 有些受器在細胞核內可以作為轉錄因子
    3. (C) 受器和配體之間是一對一的關係，即一種受器能結合一種配體
    4. (D) 受器接上配體後，訊息傳遞分子必須被磷酸化才能成為活化態

    正解：(B)

  2. 2有關脂溶性維生素的功能敘述，下列何者錯誤？

    1. (A) 維生素 A 促進眼内感光色素的形成
    2. (B) 維生素 K 可使皮膚角質細胞脫落
    3. (C) 維生素 E 抗氧化
    4. (D) 維生素 D 促進鈣的吸收

    正解：(B)

  3. 3口腔分泌的唾液中不含下列何種物質？

    1. (A) HCO3-
    2. (B) 蛋白質（protein）
    3. (C) 澱粉酶（amylase）
    4. (D) 脂肪酸（fatty acid）

    正解：(D)

  4. 4下列何者是血液之成分可將膽固醇送往全身細胞以提供細胞之膽固醇攜帶者？

    1. (A) 低密度脂蛋白
    2. (B) 極低密度脂蛋白
    3. (C) 中密度脂蛋白
    4. (D) 高密度脂蛋白

    正解：(A)

  5. 5某人靜脈血漿的肌酸酐濃度為 0.75 mg/ml，尿液之肌酸酐濃度為 120 mg/ml，24 小時的總尿量為720 ml，則此人之腎絲球濾過率（GFR）約為多少 ml/min？

    1. (A) 70
    2. (B) 80
    3. (C) 95
    4. (D) 125頁次：4－2

    正解：(B)

  6. 6下列何者為支配膀胱逼尿肌（detrusor muscle）的神經？

    1. (A) 體神經
    2. (B) 交感神經
    3. (C) 副交感神經
    4. (D) 下腹神經

    正解：(C)

  7. 7有關腎臟功能的敘述，下列何者錯誤？

    1. (A) 調節全身水分及無機離子之平衡
    2. (B) 能進行糖質新生作用（gluconeogenesis）
    3. (C) 能分泌紅血球生成素（erythropoietin）並在此製造紅血球
    4. (D) 為維持身體酸鹼平衡之重要器官

    正解：(C)

  8. 8腎上腺皮質最外層之小球層（zona glomerulosa）所分泌的激素，最容易造成血漿中何種離子下降？

    1. (A) 鉀
    2. (B) 鈣
    3. (C) 鈉
    4. (D) 氯

    正解：(A)

  9. 9下列何種荷爾蒙有助於骨頭生長板閉合（epiphyseal closure）？

    1. (A) 皮質醇（cortisol）
    2. (B) 生長激素（growth hormone）
    3. (C) 胰島素（insulin）
    4. (D) 雌激素（estrogen）

    正解：(D)

  10. 10有關腎上腺素（epinephrine）的敘述，下列何者錯誤？

    1. (A) 主要由交感神經分泌
    2. (B) 可促進脂肪細胞分解脂肪
    3. (C) 可促進肝臟分解肝醣（glycogenolysis）
    4. (D) 可增加心跳呼吸次數

    正解：(A)

  11. 11心電圖（ECG）中，下列何者代表心房去極化？

    1. (A) P 波
    2. (B) R 波
    3. (C) QRS 複合波
    4. (D) T 波

    正解：(A)

  12. 12下列何者不屬於纖維蛋白溶解系統（fibrinolytic system）？

    1. (A) Plasminogen
    2. (B) Thrombin
    3. (C) Fibrin
    4. (D) Plasmin

    正解：(B)

  13. 13下列何者不是影響微血管和組織液體交換的關鍵因素？

    1. (A) 微血管之靜水壓（hydrostatic pressure）
    2. (B) 小動脈之靜水壓
    3. (C) 血液膠體滲透壓（osmotic pressure）
    4. (D) 組織液之膠體滲透壓

    正解：(B)

  14. 14輔助型 T 細胞（helper T cell）需要與下列何者結合才能被活化，進而啟動後天性免疫反應（adaptive immunity）？

    1. (A) CD8
    2. (B) 腎上腺素
    3. (C) 干擾素
    4. (D) Major histocompatibility complex II

    正解：(D)

  15. 15有關 CD4+ T 細胞的敘述，下列何者錯誤？

    1. (A) 可辨識抗原呈獻細胞的 Major Histocompatibility Complex Class II 分子
    2. (B) 屬輔助性 T 細胞（helper T cell）
    3. (C) 可釋放穿孔素（perforins）
    4. (D) 會被人類免疫缺乏病毒（human immunodeficiency virus, HIV）攻擊破壞

    正解：(C)

  16. 16劇烈運動後容易產生肌肉疲勞現象（muscle fatigue），下列何項敘述為其最可能肇因？

    1. (A) 細胞質內 ATP 含量增加
    2. (B) 肌肉肝醣（muscle glycogen）增加
    3. (C) 細胞質內 ADP 減少
    4. (D) 細胞內磷酸根離子濃度增加

    正解：(D)

  17. 17下列何者是聽覺傳遞路徑？

    1. (A) 半規管－前庭神經
    2. (B) 柯替氏器－前庭神經
    3. (C) 半規管－耳蝸神經
    4. (D) 柯替氏器－耳蝸神經頁次：4－3

    正解：(D)

  18. 18某人接受肺功能測試，其潮氣容積（tidal volume）為 450 ml/breath，呼吸頻率為 14 breaths/min，假設其解剖無效腔（anatomical dead space）為 150 ml，則其每分鐘通氣量（minute ventilation）及肺泡通氣量（alveolar ventilation）各為多少公升？

    1. (A) 8.4、6.3
    2. (B) 8.4、4.2
    3. (C) 6.3、8.4
    4. (D) 6.3、4.2

    正解：(D)

  19. 19有關雄性素分泌的調控機轉，下列敘述何者錯誤？

    1. (A) 游離態雄性素升高對促性腺激素釋放激素（GnRH）的分泌產生抑制作用
    2. (B) 雷迪格細胞（Leydig cells）的激素分泌，受到濾泡刺激素（FSH）所調控
    3. (C) 游離態雄性素升高對黃體刺激素（LH）的分泌產生負回饋抑制作用
    4. (D) 抑制素（inhibin）是由賽特利式細胞（Sertoli cells）所分泌

    正解：(B)

  20. 20罹患修格蘭氏症候群（Sjögren's syndrome）的病人常出現嚴重口乾問題，對此疾病的敘述何者正確？

    1. (A) 是一種免疫失調疾病
    2. (B) 主因是口腔感染寄生蟲
    3. (C) 治療藥物是 atropine
    4. (D) 會增加味覺的敏感度

    正解：(A)

  21. 21下列何者屬異質多醣（heteropolysaccharides）？

    1. (A) 纖維素（cellulose）
    2. (B) 幾丁質（chitin）
    3. (C) 澱粉（starch）
    4. (D) 透明質酸（hyaluronic acid）

    正解：(D)

  22. 222 分子丙酮酸經糖質新生作用生成 1 分子葡萄糖，需消耗多少分子 ATP？

    1. (A) 2
    2. (B) 3
    3. (C) 4
    4. (D) 6

    正解：(D)

  23. 23下列構成醣蛋白之胺基酸中何者可連結醣基？ ①Asn ②Asp ③Lys ④Phe ⑤Ser ⑥Trp⑦Thr ⑧Tyr

    1. (A) ④⑧
    2. (B) ⑥⑧
    3. (C) ①⑤⑦
    4. (D) ②③⑥

    正解：(C)

  24. 24酵母菌進行無氧醣解作用（anaerobic glycolysis），此時丙酮酸會轉成下列何種化合物？

    1. (A) lactate
    2. (B) ethanol
    3. (C) acetate
    4. (D) acetyl-CoA

    正解：(B)

  25. 25細胞膜中主要的脂質成分有 phospholipids, cholesterol 和下列何者？

    1. (A) free fatty acids
    2. (B) triacylglycerols
    3. (C) sphingolipids
    4. (D) wax

    正解：(C)

  26. 26乙醯輔酶 A 羧化酶（acetyl-CoA carboxylase, ACC）可調節脂肪酸合成途徑之進行，關於其調節方式之敘述，下列何者錯誤？

    1. (A) 棕櫚醯輔酶 A（palmitoyl-CoA）之生成可以回饋抑制 ACC 之活性
    2. (B) 細胞質的檸檬酸具有活化 ACC 之作用
    3. (C) ACC 若被磷酸化則會失去活性
    4. (D) 乙醯輔酶 A（acetyl-CoA）具有活化 ACC 之作用

    正解：(D)

  27. 27下列何者是體內合成磷脂絲胺酸（phosphatidylserine）之前質？

    1. (A) 磷脂醯乙醇胺（phosphatidylethanolamine）
    2. (B) 磷脂醯肌醇（phosphatidylinositol）
    3. (C) CDP-二醯甘油（CDP-diacylglycerol）
    4. (D) 心磷脂（cardiolipin）

    正解：(A)

  28. 28膽固醇是動物細胞特有的固醇類，下列何者不是其合成過程的中間產物？

    1. (A) 鯊烯（squalene）
    2. (B) 二羥甲基戊酸（mevalonate）
    3. (C) 丙二醯輔酶 A（malonyl-CoA）
    4. (D) 異戊烯焦磷酸（isopentenyl pyrophosphate）

    正解：(C)

  29. 29下列何者為必需胺基酸（essential amino acids）？

    1. (A) 甲硫胺酸（methionine）
    2. (B) 天門冬胺酸（aspartate）
    3. (C) 絲胺酸（serine）
    4. (D) 麩胺酸（glutamate）頁次：4－4

    正解：(A)

  30. 30白化症（albinism）是一種遺傳性疾病，此疾病為下列何種胺基酸代謝異常所引起？

    1. (A) 色胺酸（tryptophan）
    2. (B) 脯胺酸（proline）
    3. (C) 甲硫胺酸（methionine）
    4. (D) 酪胺酸（tyrosine）

    正解：(D)

  31. 31蛋白質之三級結構中，R 基團-CH2COO 以及-CH2CH2CH2CH2NH3+之間可能形成下列何者？-

    1. (A) 肽鍵
    2. (B) 鹽橋
    3. (C) 酯鍵
    4. (D) 疏水性交互作用

    正解：(B)

  32. 32下列何種胺基酸沒有不對稱碳原子（asymmetric carbon atom）？

    1. (A) serine
    2. (B) glycine
    3. (C) glutamine
    4. (D) leucine

    正解：(B)

  33. 33有關核苷酸（nucleotides）之敘述，下列何者正確？

    1. (A) 核苷酸（nucleotides）結構由 1 個五碳糖（pentose）、1 個含氮鹼基（nitrogenous base group）及至少 1 個磷酸基團（phosphate group）所組成
    2. (B) 核苷（nucleosides）可利用磷酸二酯鍵（phosphodiester bond）形成核苷酸（nucleotides）
    3. (C) 核苷酸（nucleotides）在 280 nm 波長下有較大吸光值
    4. (D) ATP、CTP、GTP 及 UTP 等核苷酸（nucleotides）皆可作為合成 DNA 之原料

    正解：(A)

  34. 34有關 DNA 損傷與其修復機制之敘述，下列何者錯誤？

    1. (A) DNA 光解酶（DNA photolyase）可修復 DNA 氧化傷害
    2. (B) DNA N-醣苷酶（DNA N-glycosylase）可切除錯誤鹼基與去氧核醣間之鍵結
    3. (C) 直接修復（direct repair）可修復化學物質或光化學反應所造成之 DNA 損傷
    4. (D) 核苷酸切除修復（nucleotide excision repair）可切除核苷酸，以修復 DNA 損傷片段

    正解：(A)

  35. 35有關一氧化氮（nitric oxide, NO）與其訊號傳遞（signal transduction）機制之敘述，下列何者正確？

    1. (A) 一氧化氮（nitric oxide, NO）是一種氣體非自由基之訊號分子
    2. (B) 一氧化氮（nitric oxide, NO）可刺激鳥苷酸環化酶（guanylate cyclase）活性
    3. (C) 一氧化氮合成酶（nitric oxide synthase, NOS）需要鉀離子活化後，合成一氧化氮（nitric oxide,NO）
    4. (D) 一氧化氮經由訊號傳遞路徑後，可刺激血管收縮

    正解：(B)

  36. 36有關 intron 之敘述，下列何者正確？

    1. (A) 通常存在於原核生物基因中
    2. (B) 在轉錄作用發生之前會被剪除掉
    3. (C) 可被轉譯，但不會被轉錄
    4. (D) 在單一基因可含有多個 intron

    正解：(D)

  37. 37下列何者不參與 S-腺苷甲硫胺酸（S-adenosylmethionine）之甲基循環（methyl cycle）與單碳循環（one-carbon cycle）？

    1. (A) 維生素 A
    2. (B) 維生素 B6
    3. (C) 維生素 B12
    4. (D) 葉酸（folate）

    正解：(A)

  38. 38青黴素（penicillin）是臨床常用的抗生素，能抑制細胞壁合成導致細菌死亡，其作用為共價結合於胜肽轉基酶（transpeptidase），進而抑制細胞壁合成。請問青黴素屬於何種類型酵素抑制劑？

    1. (A) 非競爭型抑制劑（noncompetitive inhibitor）
    2. (B) 競爭型抑制劑（competitive inhibitor）
    3. (C) 不可逆抑制劑（irreversible inhibitor）
    4. (D) 異位性抑制劑（allosteric inhibitor）

    正解：(C)

  39. 39異檸檬酸去氫酶（isocitrate dehydrogenase）催化產生 β-keto group 中間產物，以進行去羧作用（decarboxylation），需要下列那一個分子的輔助？

    1. (A) thiamine pyrophosphate
    2. (B) NAD+
    3. (C) lipoic acid
    4. (D) FAD

    正解：(B)

  40. 40電子傳遞鏈所產生的質子梯度是橫跨於粒線體的：

    1. (A) 外膜
    2. (B) 內外膜間隙
    3. (C) 內膜
    4. (D) 基質

    正解：(C)
