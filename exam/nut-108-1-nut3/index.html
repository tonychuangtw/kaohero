營養師　108 年第一次 膳食療養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1營養照護流程（Nutrition Care Process，NCP）應該包括那四步驟？

    1. (A) 營養評估、營養診斷、營養介入、營養監測與評值
    2. (B) 營養篩檢、體位測量、監控與評估、紀錄
    3. (C) 營養介入、成效評估、追蹤調查、報告
    4. (D) 體位測量、生化檢驗、臨床症狀紀錄、膳食調查

    正解：(A)

  2. 2營養照護過程中，下列那一個步驟必須訂定明確的目標值？

    1. (A) nutrition assessment
    2. (B) nutrition diagnosis
    3. (C) nutrition intervention
    4. (D) nutrition monitoring

    正解：(C)

  3. 3下列何種檢查最適合用來評估骨質疏鬆症？

    1. (A) 核磁共振攝影（MRI）
    2. (B) 電腦斷層掃描儀（CT）
    3. (C) 空氣置換測定儀（ADP）
    4. (D) 雙能量 X 光吸收儀（DEXA）

    正解：(D)

  4. 4長期服用降血脂藥物 Cholestyramine 容易產生下列何種維生素之缺乏症？

    1. (A) 維生素 C
    2. (B) 維生素 E
    3. (C) 維生素 B1
    4. (D) 葉酸

    正解：(B)

  5. 5下列何類管灌食配方可提供均衡的營養，其蛋白質來源由酪蛋白、乳清蛋白或黃豆分離蛋白組成？

    1. (A) polymeric formula
    2. (B) monomeric formula
    3. (C) modular formula
    4. (D) predigested formula

    正解：(A)

  6. 6靜脈營養輸液中，10%脂肪乳劑提供的熱量為多少 kcal/mL？

    1. (A) 1.1
    2. (B) 2.0
    3. (C) 3.4
    4. (D) 9.0

    正解：(A)

  7. 7預先經過水解，其蛋白質由胜肽組成的腸道營養配方稱為：

    1. (A) modular formula
    2. (B) polymeric formula
    3. (C) predigested formula
    4. (D) blenderized diet formula

    正解：(C)

  8. 8有關食物中普林含量的敘述，下列何者正確？

    1. (A) 干貝屬於低普林食物
    2. (B) 起士屬於高普林食物
    3. (C) 堅果屬於高普林食物
    4. (D) 巧克力屬於低普林食物

    正解：(D)

  9. 9治療類風濕性關節炎，通常併用「疾病修飾抗風濕藥物」（Disease Modifying Anti-RheumaticDrug，DMARD），Methotrexate（MTX）即屬於此類。服用 MTX 通常會降低下列何種營養素血中濃度？

    1. (A) 鐵
    2. (B) 葉酸
    3. (C) 維生素 C
    4. (D) 菸鹼酸

    正解：(B)

  10. 10下列何者不屬於抗發炎飲食的原則？

    1. (A) 多蔬菜及水果
    2. (B) 低 Omega-6 多元不飽和脂肪酸的油脂
    3. (C) 多蛋品及紅肉
    4. (D) 低精緻及加工製品（Processed Food）

    正解：(C)

  11. 11有關 bulimia nervosa 的敘述，下列何者錯誤？

    1. (A) 常使用催吐劑、輕瀉劑、利尿劑及減肥藥丸
    2. (B) 體重過低且 BMI 小於 18
    3. (C) 常有暴飲暴食的行為
    4. (D) 常有牙齒琺瑯質侵蝕狀況頁次：4－3

    正解：(B)

  12. 12兒童減重時，應注意事項為何？①以達到理想體重為目標 ②必要時可使用減重藥物 ③增加體能活動量 ④養成均衡飲食的習慣

    1. (A) ①②
    2. (B) ①④
    3. (C) ②③
    4. (D) ③④

    正解：(D)

  13. 13下列有關便祕的營養治療何者錯誤？

    1. (A) 治療便祕的主要飲食原則為攝取足量的水分及膳食纖維，每天建議至少攝取約 2000 毫升水分
    2. (B) 便祕患者若經飲食評估發現原本飲食已攝取足量膳食纖維時，再補充膳食纖維對於緩解便祕已無多大助益
    3. (C) 每日膳食纖維攝取不足的便祕患者，可逐漸增加纖維素的攝取至 50 公克/天以上
    4. (D) 生活過於靜態之便祕患者，可由增加運動獲得改善

    正解：(C)

  14. 14短腸症候群（short-bowel syndrome）之病患手術後初期通常需利用何種方式給予完整營養需求？

    1. (A) 經口攝食
    2. (B) 鼻胃管餵食
    3. (C) 鼻腸管餵食
    4. (D) 靜脈營養

    正解：(D)

  15. 15關於盲環症候群（blind-loop syndrome）的敘述，下列何者錯誤？

    1. (A) 可能因腸道狹窄所導致
    2. (B) 可能因腸道中細菌過度滋長所導致
    3. (C) 應補充維生素 B12
    4. (D) 宜選用長鏈三酸甘油酯補充熱量

    正解：(D)

  16. 16胃潰瘍患者攝取乳品後對其病情之影響，下列敘述何者正確？

    1. (A) 乳品可中和胃酸，空腹時飲用治療胃潰瘍效果佳
    2. (B) 乳品可抑制胃酸分泌，對治療胃潰瘍效果顯著
    3. (C) 乳品可抑制胃蛋白酶分泌，可藉此治療胃潰瘍
    4. (D) 乳品可能會刺激胃酸分泌，不再考量用於輔助胃潰瘍之治療

    正解：(D)

  17. 17使用果膠治療傾食症候群，可有下列何種好處？

    1. (A) 可加快腸道內容物通過下消化道的時間
    2. (B) 可延緩腸胃道通過時間，且避免胰島素過量分泌
    3. (C) 可增加葡萄糖吸收，同步增加胰島素分泌量
    4. (D) 可避免脂肪痢

    正解：(B)

  18. 18關於妊娠糖尿病，下列敘述何者錯誤？

    1. (A) 肥胖個案熱量攝取建議<1200 大卡/天
    2. (B) 醣類攝取至少達到 175 克/天
    3. (C) 肥胖之妊娠糖尿病患者於產後減重，可減少日後妊娠糖尿病再發生及罹患糖尿病危險性
    4. (D) 妊娠糖尿病血漿血糖控制目標為飯前血糖≦95mg/dL 或 1 小時飯後血糖為≦140 mg/dL

    正解：(A)

  19. 19關於控制腎衰竭患者血鉀濃度的方法，下列何者較不適當？

    1. (A) 限鉀飲食
    2. (B) 血液透析
    3. (C) 口服離子交換樹脂 Kayexalate
    4. (D) 利用靜脈注射給予葡萄糖、胰島素及碳酸鹽

    正解：(C)

  20. 20第二型糖尿病（type 2 DM）患者血壓及血脂的控制目標，下列建議範圍何者錯誤？

    1. (A) 收縮壓＜140 mmHg
    2. (B) LDL-C＜130 mg/dL
    3. (C) 男性 HDL-C＞40 mg/dL
    4. (D) 三酸甘油酯（空腹）＜150 mg/dL

    正解：(B)

  21. 21關於第二型糖尿病（type 2 DM）病患的特徵，下列敘述何者錯誤？

    1. (A) 有時需以胰島素控制血糖
    2. (B) 易發生 DKA（diabetic ketoacidosis）
    3. (C) 與家族遺傳有關
    4. (D) 胰島素敏感度下降

    正解：(B)

  22. 22有關第一型糖尿病（type 1 DM）的特徵，下列敘述那些正確？①體重正常或略輕 ②胰臟 β 細胞受到破壞 ③大多與人體淋巴球抗原（HLA）無關 ④易有酮酸中毒

    1. (A) ①②③
    2. (B) ①②④
    3. (C) ①③④
    4. (D) ②③④

    正解：(B)

  23. 23下列有關血液透析患者的飲食何者錯誤？

    1. (A) 每天蛋白質 1.2 g/kg IBW
    2. (B) 每天水分 750～1000 mL 加上尿液排出量
    3. (C) 60 歲以下者每天熱量 35 kcal/kg IBW
    4. (D) 每天鹽攝取量為 2 至 3 公克

    正解：(D)

  24. 24洗腎之末期腎臟病（End-Stage Renal Disease，ESRD）患者須使用靜脈營養時，下列何者正確？

    1. (A) 須額外補充脂肪乳劑
    2. (B) 須額外補充綜合維生素
    3. (C) 須額外補充礦物質
    4. (D) 按照標準全靜脈營養輸液給予

    正解：(D)

  25. 25臨床上最常用來評估洗腎患者蛋白質營養狀況的指標為：

    1. (A) albumin
    2. (B) prealbumin
    3. (C) transferrin
    4. (D) CRP頁次：4－4

    正解：(A)

  26. 26關於 Acute Glomerulonephritis（AGN）之敘述，下列何者錯誤？

    1. (A) 常因腎臟細菌感染誘發之疾病，且可在病患的尿液培養中找到病菌
    2. (B) 多休息及維持良好營養狀態通常可自癒
    3. (C) 主要是因感染所引發抗體抗原複合體破壞腎臟組織而罹病
    4. (D) 除非出現明顯尿毒或高血鉀現象，否則限蛋白質或鉀對病情無益

    正解：(A)

  27. 27下列何者為得舒（DASH）飲食之特性？

    1. (A) 強調嚴格限制鈉及植物蛋白的高血壓防治飲食
    2. (B) 強調高鉀、高鎂、足夠的鈣、高膳食纖維的高血壓防治飲食
    3. (C) 注重體重控制、限制碳水化合物的高血壓防治飲食
    4. (D) 限制鉀、磷、鈣及蛋白質的高血壓防治飲食

    正解：(B)

  28. 28心衰竭患者使用利尿劑治療時，與下列何種營養素缺乏較無關？

    1. (A) 鉀
    2. (B) 鈣
    3. (C) 鎂
    4. (D) 維生素 B1

    正解：(B)

  29. 29當血壓降低時，誘發下列何種荷爾蒙分泌，可增加細胞外液體積，使血壓上升？

    1. (A) 腎上腺素（epinephrin）
    2. (B) 正腎上腺素（norepinephrin）
    3. (C) 瘦體素（leptin）
    4. (D) 醛固酮（aldosterone）

    正解：(D)

  30. 30有關重症病患在 flow phase 的敘述，下列何者錯誤？

    1. (A) catecholamines 及 cortisol 分泌增加使血液中游離脂肪酸濃度上升
    2. (B) aldosterone 分泌增加，有助於體內水分及鹽分保存，供應循環血液量
    3. (C) 促發炎細胞激素（proinflammatory cytokines）分泌增加，會增加肝臟蛋白質及肝醣合成
    4. (D) counterregulatory hormones 分泌增加，促進肌肉蛋白質分解，增加尿液中磷、鉀、鎂排泄

    正解：(C)

  31. 31劉先生為 45 歲之建築工人，自五樓鷹架跌落之後造成多處骨折和顱內出血，其身高為 165 公分、平日體重 82 公斤，手術之後收治進入加護病房，其血液生化值為 serum albumin 3.5 g/dL、BUN 18 mg/dL、Cr 1.2 mg/dL、CRP 1.5 mg/dL、Na/K/Cl 為 133/3.8/98 mEq/L，醫師建議可以給予鼻胃管灌食，請問灌食配方建議應為下列何者？

    1. (A) 1500 大卡、蛋白質 100 公克
    2. (B) 2000 大卡、蛋白質 80 公克
    3. (C) 2000 大卡、蛋白質 100 公克
    4. (D) 2400 大卡、蛋白質 100 公克

    正解：(A)

  32. 32易發生 bowel ischemia 的重症病人，不應該使用下列何種灌食配方？

    1. (A) arginine-containing formula
    2. (B) n-3 fatty acid containing formula
    3. (C) antioxidants-containing formula
    4. (D) fiber-containing formula

    正解：(D)

  33. 33下列血糖值何者是重症病人血糖控制的目標？

    1. (A) 儘量小於 80 mg/dL
    2. (B) 80～110 mg/dL
    3. (C) 120～140 mg/dL
    4. (D) 150～180 mg/dL

    正解：(D)

  34. 34有關慢性阻塞性肺部疾病（Chronic Obstructive Pulmonary Disease，COPD）營養治療，下列何項敘述錯誤？

    1. (A) 蛋白質占 15～20% kcal
    2. (B) 脂肪占 20～25% kcal
    3. (C) 醣類占 40～55% kcal
    4. (D) 礦物質與維生素的補充依照實際需求

    正解：(B)

  35. 35王小姐為卵巢癌病人，接受 radiation therapy 之後感到腸胃不適、蠕動加快、噁心嘔吐，正餐熱量攝取不足，下列那種點心可建議給王小姐補充以避免腸胃道症狀加重和熱量攝取不足？

    1. (A) 冰淇淋
    2. (B) 芹菜精力湯
    3. (C) 蘋果泥冰沙
    4. (D) 酪梨牛奶

    正解：(C)

  36. 36對於 4 到 6 個月大，併發有肺支氣管發育不良（Bronchopulmonary Dysplasia，BPD）和食道逆流之嬰兒，下列處置何者較佳？

    1. (A) 給予嬰兒麥粉增稠配方
    2. (B) 給予稀釋果汁
    3. (C) 使用仰臥餵食姿勢
    4. (D) 延緩添加副食品至 9 個月大之後

    正解：(A)

  37. 37有關頭頸癌放射線治療病患治療的副作用，下列何者較不常發生？

    1. (A) 嘔吐
    2. (B) 黏膜炎
    3. (C) 味覺改變
    4. (D) 吞嚥困難

    正解：(A)

  38. 38下列何者不是選擇灌食配方應考慮的因素？

    1. (A) 病人的咀嚼能力
    2. (B) 病人的腸胃道功能
    3. (C) 配方是否符合病人需要
    4. (D) 配方的熱量密度

    正解：(A)

  39. 39有關體重控制之減重速度建議，下列敘述何者正確？

    1. (A) 一般而言，27<BMI≦35 減重速度建議每週約減 0.5～1 公斤
    2. (B) BMI>35 者減重速度建議每週減 1～2 磅
    3. (C) 長期穩定的減重，不會減少蛋白質的儲存
    4. (D) 急速減重容易造成嚴重高血壓

    正解：(B)

    2. (B) 認知障礙
    3. (C) 體重過重
