物理治療師　103 年第二次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1執行左側頸部椎間孔壓迫試驗（Foraminal Compression Test），右側有症狀時，則下列有關該症狀之敘述，何者正確？

    1. (A) 症狀表現是疼痛或肌肉痙攣（spasm），為肌肉拉傷
    2. (B) 症狀依神經皮節（dermatome）分布，為神經根症狀
    3. (C) 症狀表現是疼痛或肌肉痙攣（spasm），為神經根症狀
    4. (D) 症狀依神經皮節（dermatome）分布，為肌肉拉傷

    正解：(A)

  2. 2三分鐘抬臂運動測試（three-minute elevated arm exercise test）是用來測試下列那種問題？

    1. (A) 肩旋轉肌肌腱炎（rotator cuff tendinitis）
    2. (B) 腕隧道症候群（carpal tunnel syndrome）
    3. (C) 肩夾擠症候群（impingement syndrome）
    4. (D) 胸廓出口症候群（thoracic outlet syndrome）

    正解：(D)

  3. 3頸部軸向旋轉（axial rotation）的活動度大部分（高達60%）取決於下列何處的頸部關節？

    1. (A) C0-C2
    2. (B) C2-C3
    3. (C) C3-C5
    4. (D) C5-C7

    正解：(A)

  4. 4下列有關頸椎疾病之敘述，何者錯誤？

    2. (B) 頸椎之小面關節疼痛常是頸部揮鞭式創傷（whiplash injury）常見的後遺症
    3. (C) 頸髓病變（myelopathy）的患者在壓迫節以下，不會出現上運動神經元（upper motorneuron）徵候
    4. (D) 頸椎神經根病變（radiculopathy）的患者可能出現深腱反射降低的情形

    正解：(C)

  5. 5下列何者為頸椎間盤前向突出可能之症狀？
