  1. 1A 男與 B 女結婚後，生下一子 B1，B1 五歲時 B 女死亡，嗣 A 男與 23 歲的 C 女結婚，C 女照顧 B1。請問 B1 與 C 女的關係如何？

    1. (A) 因為 A 男在 B 女死亡後與 C 女結婚，且由 C 女照顧 B1，因此 B1 成為 C 女的婚生子女
    2. (B) A 男在 B 女死亡後與 C 女結婚，且由 C 女照顧 B1，如果 C 女認領 B1，B1 就成為 C 女的婚生子女
    3. (C) B1 如果要與 C 女發生法律上的父母子女關係，必須由 C 女收養
    4. (D) B1 與 C 女無法發生法律上的父母子女關係，因為 C 女僅比 B1 大 17 歲

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 繼父母與繼子女之間只是姻親，須經收養才發生法律上的父母子女關係。

    ❌ (A) 再婚與實際照顧都不能使子女成為他方的婚生子女。

    ❌ (B) 認領僅適用於生父對非婚生子女，母方無認領可言。

    ❌ (D) 收養配偶之子女者，只須長於被收養者 16 歲以上即可。

    📚 出處：民法第 1072 條至第 1074 條。

  2. 2連襟間係屬何種親屬？

    1. (A) 二親等之旁系血親
    2. (B) 二親等之旁系姻親
    3. (C) 三親等之旁系血親
    4. (D) 三親等之旁系姻親

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 連襟為配偶之血親（妻之姊妹）之配偶，屬姻親，親等從其配偶之血親計算，為二親等旁系姻親。

    ❌ (A) 雙方之間並無血緣關係。

    ❌ (C) 血親的認定不成立。

    ❌ (D) 親等應為二親等而非三親等。

    📚 出處：民法第 969 條、第 970 條。

  3. 3死亡宣告被撤銷後，因死亡宣告而取得財產之人，應否返還財產？

    1. (A) 不用返還
    2. (B) 若是善意，則返還現存利益即可
    3. (C) 要全數返還
    4. (D) 由法院決定

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 死亡宣告的裁定經撤銷或變更時，因而取得財產者僅於現受利益的限度內負返還責任。

    ❌ (A) 不能完全免除返還義務。

    ❌ (C) 善意者不須全數返還。

    ❌ (D) 返還範圍由法律明定，非法院自由裁量。

    📚 出處：家事事件法第 163 條。
