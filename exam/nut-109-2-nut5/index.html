營養師　109 年第二次 公共衛生營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1衛生福利部公告之「包裝食品營養標示應遵行事項」，下列那個營養素未強制規定標示？

    1. (A) 飽和脂肪酸
    2. (B) 反式脂肪酸
    3. (C) 鈣質
    4. (D) 鈉

    正解：(C)

  2. 2根據第七版的 DRIs，懷孕媽媽與哺乳媽媽的營養需求比較，下列何者錯誤？

    1. (A) 孕期蛋白質建議攝取量比哺乳期高
    2. (B) 孕期跟哺乳期的葉酸建議攝取量都要增加
    3. (C) 孕期第三期跟哺乳期的鐵建議攝取量相同
    4. (D) 哺乳期的鈣建議攝取量跟一般人相同

    正解：(A)

  3. 3衛生福利部訂定之國人膳食營養素參考攝取量（DRIs），19-50 歲男性與女性下列維生素之建議攝取量相同？

    1. (A) 維生素 A、維生素 D
    2. (B) 維生素 E、維生素 K
    3. (C) 維生素 B1、維生素 B2
    4. (D) 維生素 B6、維生素 B12

    正解：(D)

  4. 4有關「國人飲食指標」及「每日飲食指南」，下列敘述何者錯誤？

    1. (A) 融入環保及永續觀念
    2. (B) 每日至少攝取 1/2 全穀類食物
    3. (C) 參考歷年國民營養調查之結果
    4. (D) 以食物為基礎而非以單一營養素作建議頁次：4－2

    正解：(B)

  5. 5依據「學校午餐食物内容及營養基準」 ，有關學校午餐菜單蛋白質食物之供應設計敘述，下列何者錯誤？

    1. (A) 蛋白質應占熱量平均值之 20%
    2. (B) 豆製品可為主菜、副菜或加入飯中
    3. (C) 鼓勵學生在其他餐次攝取牛奶，以符合每日飲食指南建議量
    4. (D) 提高魚類（包括各式海鮮）之供應，但不建議油炸的烹調方式

    正解：(A)

  6. 6世界衛生組織訂定非傳染病（non-communicable disease, NCDs）全球防治目標，於 2025 年降低25%四大非傳染病之過早死亡（premature mortality）。下列何者不是四大非傳染病？

    1. (A) 肥胖
    2. (B) 癌症
    3. (C) 心血管疾病
    4. (D) 慢性呼吸道疾病

    正解：(A)

  7. 7產後媽媽遇到下列何者狀況不適合哺育母乳？

    1. (A) 感冒
    2. (B) 燙染頭髮
    3. (C) 罹患 B 型肝炎
    4. (D) 使用化學治療藥物

    正解：(D)

  8. 8下列何者不符合國民中小學之「校園飲品及點心販售範圍」？

    1. (A) 含鈉量 250 mg 的麵包
    2. (B) 含鈉量 300 mg 的餅乾
    3. (C) 糖占熱量 0.1%的氣泡水
    4. (D) 糖占熱量 20%的保久乳

    正解：(C)

  9. 9教育部透過三級管理來強化校園食品及學校午餐供應品質，下列何者不是屬於三級管理之一？

    1. (A) 學校自主管理
    2. (B) 中央聯合稽查
    3. (C) 地方政府主動督導、監測
    4. (D) 家長或公正人士進行監廚

    正解：(D)

  10. 10下列何者不是營養師的工作範圍？

    1. (A) 抽血作生化檢查
    2. (B) 進行營養教育的推廣
    3. (C) 慢性疾病預防保健工作推展
    4. (D) 發掘需特殊營養補充品的群體

    正解：(A)

  11. 11下列體位測量之敘述何者正確？

    1. (A) 腰臀比可了解體脂肪分布型態
    2. (B) 上臂圍亦可做為人體熱量蛋白質儲存之敏感指標
    3. (C) 與體脂率相比，身體質量指數為較佳評估身體組成之指標
    4. (D) 肩胛骨下方皮脂厚度為社區營養調查最常用來測定皮脂厚度的部位

    正解：(A)

  12. 12下列那一項不是短版（short-form）迷你營養評估（mini nutritional assessment, MNA）量表的篩選項目？

    1. (A) 活動能力
    2. (B) 身體質量指數
    3. (C) 每天液體攝取量
    4. (D) 過去 3 個月內的食量變化

    正解：(C)

  13. 13下列那一項不是 24 小時飲食回憶法的優點？

    1. (A) 節省時間及經費
    2. (B) 民眾負擔小，參與率高
    3. (C) 可直接秤量食物重量，可獲得正確飲食資料
    4. (D) 當收集樣本夠大時，結果可代表族群的平均攝取量

    正解：(C)

  14. 14教育部主要負責學校餐食供應相關業務是那一個單位？

    1. (A) 體育署
    2. (B) 國民健康署
    3. (C) 終身教育司
    4. (D) 國民及學前教育署

    正解：(D)

  15. 15有關碘的生化檢測，下列何者正確？

    1. (A) 尿碘排泄量可推算碘攝取量
    2. (B) 尿碘量主要反映個人長期碘營養狀況
    3. (C) 尿液碘量與甲狀腺腫盛行率呈正相關
    4. (D) 國民營養健康狀況變遷調查中，國人碘的營養狀態主要由 24 小時回憶法估算碘攝取量頁次：4－3

    正解：(A)

  16. 16維生素 B12 缺乏時，會產生下列何種狀況？

    1. (A) 尿中甲醯亞胺麩胺酸（formiminoglutamic acid）排出量增加
    2. (B) 尿液甲基丙二酸（methylmalonic acid）排出量增加
    3. (C) 血漿中同半胱胺酸（homocysteine）濃度下降
    4. (D) 尿液黃尿酸（xanthurenic acid）排出量增加

    正解：(B)

  17. 17使用生物阻抗儀測量體脂肪，下列何者錯誤？

    1. (A) 有低輻射劑量，但可忽略
    2. (B) 測量值容易受身體含水量影響
    3. (C) 體脂肪產生的電阻較瘦體組織為高
    4. (D) 原理為身體組織導電性質不同而估算體組成

    正解：(A)

  18. 18下列那一項檢測項目之結果不會受到飲食的影響？

    1. (A) 前白蛋白（prealbumin）
    2. (B) 血液尿素氮（BUN）
    3. (C) 肌酸酐（creatinine）
    4. (D) 尿酸（uric acid）

    正解：(C)

  19. 19蘋果型肥胖者有較高的機率罹患下列那一種疾病？

    1. (A) 癌症
    2. (B) 冠心病
    3. (C) 腎臟病
    4. (D) 慢性阻塞性肺病

    正解：(B)

  20. 2010 歲男童身體質量指數（BMI=24），該年齡與性別 BMI 20.0-22.6 為過重體位，父母體位正常，請就營養師立場，給予男童和其家長適當的建議為：

    1. (A) 屬於可接受的體位範圍
    2. (B) 需經營養師諮詢執行體重控制計畫
    3. (C) 半年後再請營養師繼續評估及追蹤
    4. (D) 沒有家族史所以無需專業建議與處置

    正解：(B)

  21. 21下列那種問卷施測的方式較適合調查新住民的營養狀況？

    1. (A) 郵寄

    3. (C) 電訪
    4. (D) 網路

  23. 23欲針對國小學童，進行食農教育的課程，下列何種教學設計，可以有效達到較高學習層次的情意領域（affective domain）教學目標？

    1. (A) 認識食農教育的定義與內容
    2. (B) 學員親自下廚製備食物料理
    3. (C) 安排實際參訪在地休閒農場
    4. (D) 訪視農村並體驗農民生活

    正解：(D)

  24. 24個案在完成行為改變目標時，給予自我獎勵，此時個案處於階段性改變理論中的那一期？

    1. (A) 意圖期
    2. (B) 準備期
    3. (C) 行動期
    4. (D) 無意圖期

    正解：(C)

  25. 25張先生已開始採取體重控制行動 8 個月，欲持續維持健康飲食的行為，若以跨理論模式之觀點，下列何者是比較不適合他的介入方法？

    1. (A) 刺激的控制（stimulus control）
    2. (B) 援助關係（helping relationships）
    3. (C) 反制約作用（counterconditioning）
    4. (D) 環境的再評估（environmental reevaluation）

    正解：(D)

  26. 26一個大學生自覺他的家人跟朋友認為他應該要戒除吃宵夜的習慣，此想法屬於下列那一概念？

    2. (B) 依從動機（motivation to comply）
    3. (C) 規範信念（normative beliefs）
    4. (D) 行為結果評價（evaluations of behavioral outcomes）

    正解：(C)

  27. 27下列何者為最適合用來評估社區民眾對問題的了解與解決問題動機之方法？

    3. (C) 人口統計學
    4. (D) 關鍵人訪談

  28. 28依據 Minkler 等人提出的社區組織與社區營造之型態分類，下列有關社區發展模式的敘述，何者正確？

    1. (A) 以社區優勢為基礎，在共識及合作中推動社區活動
    2. (B) 以社區優勢為基礎，在衝突及倡導中推動社區活動
    3. (C) 以社區需求為基礎，在共識及合作中推動社區活動
    4. (D) 以社區需求為基礎，在衝突及倡導中推動社區活動頁次：4－4

    正解：(C)

  29. 29SWOT 為社區營養計畫擬定執行前的行銷原則分析方法之一，請問 “S＂是：

    1. (A) Security

    3. (C) Strengths
    4. (D) Subject

    正解：(C)

  30. 30某營養計畫投入 10 萬元活動經費，辦理 12 場營養健康講座，是屬於下列何種評價？

    1. (A) Effort
    2. (B) Efficiency
    3. (C) Evaluation
    4. (D) Effectiveness

    正解：(B)

  31. 31相較於民國 94-97 年調查結果，102-105 年臺灣國民營養健康狀況變遷調查在 19 歲以上國人資料分析中顯示，與代謝相關的健康問題之盛行率有上升的趨勢，下列何者除外？

    1. (A) 高尿酸
    2. (B) 高血壓
    3. (C) 腰圍過大
    4. (D) 低高密度脂蛋白膽固醇

    正解：(A)

  32. 32比較 82-85 年、94-97 年與 102-105 年 3 次臺灣國民營養健康狀況變遷調查中，19 歲以上成人肥胖與相關疾病變遷的狀況，下列敘述何者錯誤？

    1. (A) 過重加上肥胖盛行率逐年大幅上升
    2. (B) 代謝症候群盛行率呈現上升
    3. (C) 腰圍過大比率逐年大幅上升
    4. (D) 糖尿病盛行率呈現上升

    正解：(A)

  33. 332005～2008 年臺灣國民營養健康狀況變遷調查中，國人食物攝取狀況，下列何者錯誤？

    4. (D) 與前次調查比較，富含醣類的便利食品攝取量增加

    正解：(C)

  34. 34102-105 年臺灣國民營養健康狀況變遷調查中，國人體位現況，下列何者錯誤？

  35. 35下列何種措施可提升國內糧食自給率，保障農民收益與國人糧食安全？

    1. (A) 掌握大宗物資如稻米的安全庫存量與管理機制
    2. (B) 活化優質休耕地，鼓勵種植大豆、地瓜等飼料作物

    4. (D) 依據糧食平衡表，建構國內糧食種類、分級與供應的資料庫

    正解：(B)

  36. 36世界衛生組織工作總計畫（GPW），發起 REPLACE 活動，希望在 2023 年達到下列何種目標？

    1. (A) 全球人口鹽攝取量相對減少 30%
    2. (B) 食物供應中全面消除人工反式脂肪酸
    3. (C) 游離糖攝取量限制在總熱量的 10%以內
    4. (D) 全球人口每日至少食用 5 份水果和蔬菜增加到 50%

    正解：(B)

  37. 37統計假說 H0 : μ1≦μ2、H1 : μ1>μ2，顯著水準為 p < 0.05，當分析結果 p = 0.08 時，下列敘述何者正確？
