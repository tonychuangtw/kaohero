初等考試　103 年 初等考試 土地行政大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列有關特別法與普通法之分辨，何者正確？

    1. (A) 關於規定地價程序，平均地權條例施行細則是平均地權條例之特別法
    2. (B) 關於房屋租用規定，土地法是民法之特別法
    3. (C) 關於土地登記事項，土地登記規則是土地法之特別法
    4. (D) 關於土地稅之徵收，土地法是平均地權條例之特別法

    正解：(B)

  2. 2①行政院決定強化非都市山坡地供為建築使用之限制，②故由內政部研擬相關法律修正草案，③次由立法通過相關法律修正草案，並自④相關修正法案施行之日起，由各級主管機關予以執行。下列對於前述各項行為屬性之分析，何者最正確？

    1. (A) ①政策；②③立法行為；④行政行為
    2. (B) ①②③立法行為；④行政行為
    3. (C) ①政策；②行政行為；③立法行為；④行政行為
    4. (D) ①④行政行為；②③立法行為

    正解：(C)

  3. 3有關都市土地商業區、住宅區、工業區地價指數表之編製，係由何機關辦理？

    1. (A) 行政院
    2. (B) 內政部
    3. (C) 財政部
    4. (D) 直轄市、縣（市）政府

    正解：(B)

  4. 4土地登記規則係依土地法第 37 條規定所訂定，在層級化法律保留原則下，其符合下列何種法律保留？

    1. (A) 憲法保留
    2. (B) 國會保留
    3. (C) 廣義法律保留
    4. (D) 無須保留

    正解：(C)

  5. 5登記人員依照上級主管之指令辦理登記案件時，發現該指令有違法情事，則登記人員對該案件之處置，下列何者最為正確？

    1. (A) 逕依法辦理後再回報上級主管
    2. (B) 逕依上級主管指令辦理，結案後再回報上級主管該指令違法情形
    3. (C) 逕依法辦理，無須回報上級主管
    4. (D) 先就指令違法之情形回報上級主管，若上級主管仍以書面堅持該指令，則應依指令辦理

    正解：(D)

  6. 6甲將一地移轉予乙，丙主張其為該地真正所有權人，甲係無權處分，而乙援引土地法第 43 條規定，認其應受登記公信力之保護。請問：土地登記公信力之構成要件，不包括下列何者？

    1. (A) 須乙為善意第三人
    2. (B) 須該地所有權已登記於乙之名下
    3. (C) 須甲因法律事實而移轉該地予乙
    4. (D) 須該地登記簿之原權利記載事項與實體法律關係不一致

    正解：(C)

  7. 7土地經辦竣假扣押登記後，登記機關即應停止與其權利有關之新登記，則下列何種登記屬之？

    1. (A) 繼承登記
    2. (B) 土地徵收登記
    3. (C) 照價收買登記
    4. (D) 抵押權設定登記

    正解：(D)

  8. 8甲死亡留有一地由其子乙、丙與丁三人共同繼承，則下列敘述何者錯誤？

    1. (A) 倘若乙、丙與丁三人未申辦繼承登記時，終局的會產生失權效力
    2. (B) 一律須由乙、丙與丁三人共同申辦繼承登記
    3. (C) 倘若乙、丙與丁三人於甲死亡逾六個月仍未申辦繼承登記時，亦不生失權效力
    4. (D) 倘若乙、丙與丁三人於甲死亡逾六個月仍未申辦繼承登記者，則須繳納登記罰鍰

    正解：(B)

  9. 9下列有關抵押權登記之敘述，何者錯誤？

    1. (A) 申請普通抵押權設定登記時，登記機關應於登記簿記明擔保債權之金額、種類及範圍
    2. (B) 申請為抵押權設定之登記，其抵押人非債務人時，契約書及登記申請書應經債務人簽名或蓋章
    3. (C) 以一宗或數宗土地權利為擔保之抵押權，因擔保債權分割而申請抵押權分割登記，應由抵押人會同債務人申請之
    4. (D) 抵押權設定登記後，另增加一宗或數宗土地權利共同為擔保時，應就增加部分辦理抵押權設定登記，並就原設定部分辦理抵押權內容變更登記

    正解：(C)

  10. 10登記機關辦理土地登記所收取之登記費、工本費、書狀費與閱覽費，依通說屬規費之性質。下列關於登記相關規費之敘述，何者錯誤？

    2. (B) 登記費與書狀費屬行政規費
    3. (C) 工本費與閱覽費屬使用規費
    4. (D) 登記機關所收取規費應專款專用

    正解：(D)

  11. 11下列有關建物複丈之敘述，何者錯誤？

    1. (A) 建物合併應先辦理建物勘查
    2. (B) 申辦建物分割，建物之分割處無定著可為分隔之樓地板或牆壁，亦得辦理之

    4. (D) 分割後之建物，除將其中一棟維持原建號外，其他各棟以該地段最後建號之次一號順序編列

    正解：(B)

  12. 12土地權利關係人自行擬定或申請變更細部計畫，遭受直轄市、縣（市）政府或鄉、鎮、縣轄市公所拒絕時，得分別向內政部或縣（市）政府請求處理；經內政部或縣（市）政府依法處理後，依都市計畫法第 25 條規定，土地權利關係人如何為救濟？

  15. 15依非都市土地使用管制規則規定，使用地變更編定申請人依法律規定應繳交回饋金者，直轄市或縣（市）政府應於何時通知申請人繳交？

  38. 38依土地法規定，私有土地所有權之移轉、設定負擔或租賃，妨害基本國策者，得如何處置？

    1. (A) 由轄區地政事務所逕行辦理塗銷登記
    2. (B) 由轄區地政事務所報請直轄市、縣（市）政府核定後，辦理逕為塗銷登記
    3. (C) 由轄區地政事務所報請直轄市、縣（市）政府，轉報內政部核定後，辦理逕為塗銷登記
    4. (D) 由中央地政機關報請行政院制止之

    正解：(D)

  39. 39外國人因繼承而取得我國境內之林地，其未於繼承登記完畢之日起三年內出售與本國人者，依土地法規定，直轄市、縣（市）地政機關應如何處理？

    1. (A) 依法徵收
    2. (B) 依法照價收買
    3. (C) 移請財政部國有財產署辦理公開標售
    4. (D) 逕為辦理國有登記

    正解：(C)

  40. 40大陸地區法人從事有助於臺灣地區整體經濟之投資，而取得之不動產物權，應依核定之投資計畫期限及用途使用，並應由何機關定期稽查其使用情形？

    1. (A) 轄區直轄市、縣（市）政府
    2. (B) 內政部
    3. (C) 行政院大陸委員會
    4. (D) 中央目的事業主管機關

    正解：(D)

  41. 41依土地法規定，共有人以多數決處分共有物，應書面通知他共有人，其不能通知者，以公告為之。下列敘述何者錯誤？

    1. (A) 書面通知應視實際情形，以一般之通知書或郵局存證信函為之
    2. (B) 以公告代替通知他共有人者，應以他共有人住址不明或經通知而無法送達者為限
    3. (C) 委託他人代為事先通知，其委託行為無須特別授權
    4. (D) 他共有人已死亡者，基於登記生效主義之考量，仍應以土地登記簿記載之共有人名義為通知或公告之對象

    正解：(D)

  42. 42依土地徵收條例規定，在徵收土地之前，需用土地人勘選用地範圍時，下列敘述何者錯誤？

    1. (A) 應於斟酌事業性質及實際需要之外，從寬決定其用地及範圍
    2. (B) 應儘量避免耕地
    3. (C) 應優先使用無使用計畫之公有土地或國營事業土地
    4. (D) 對於經依都市計畫法變更後，依法得予徵收之農業用地，於變更時，應經目的事業主管機關考量徵收之必要性及公益性

    正解：(A)

  43. 43若人民不服臺北市政府地政局否准更正地籍線之申請，應向何機關提起訴願？

    1. (A) 臺北市政府
    2. (B) 內政部地政司
    3. (C) 內政部
    4. (D) 土地所在地之地政事務所

    正解：(A)

  44. 44若其他法律無特別規定，私法人之受僱人因執行職務之行為，致使私法人違反行政法上義務者，應如何處罰？

    1. (A) 裁處私法人，得併罰因故意或重大過失，未盡防止義務之代表人
    2. (B) 僅裁處私法人即可，不得併罰代表人或受僱人
    3. (C) 僅對受僱人裁罰即可，無須裁處私法人
    4. (D) 僅對代表人裁罰即可，無須裁處私法人

    正解：(A)

  45. 45地政機關公務員辦理地政事務而行使公權力，為謀自己或他人利益而為違法行為致第三人受損害，所生相關法律責任。下列敘述何者錯誤？

    1. (A) 有關行政懲處等行政責任
    2. (B) 貪瀆等相關刑事罪責
    3. (C) 僅該公務員個人應向第三人負擔損害賠償責任
    4. (D) 國家賠償責任

    正解：(C)

  46. 46關於行政機關之行政指導行為，行政程序法有若干法規制，下列敘述何者錯誤？

    1. (A) 若人民不服指導，得因此對其為不利之處置
    2. (B) 注意有關法規規定目的，不得濫用
    3. (C) 人民拒絕接受指導，應即停止
    4. (D) 為指導時，應明示指導目的、內容及負責指導者

    正解：(A)

  47. 47依國家賠償法及其施行細則規定，關於國家賠償之請求權時效，下列敘述何者錯誤？

    1. (A) 知有損害時起，因二年間不行使而消滅
    2. (B) 自損害發生時起，逾五年者消滅
    3. (C) 所稱知有損害，指須知有損害事實及國家賠償責任之原因事實
    4. (D) 自侵害行為發生起，逾五年消滅

    正解：(D)

  48. 48下列有關行政罰之敘述，何者正確？

    1. (A) 數行為違反同一或不同行政法上義務之規定者，從一重處斷
    2. (B) 一行為同時觸犯刑事法律及違反行政法上義務規定者，併罰之
    3. (C) 違反行政法上義務之一行為，除應處罰鍰外，得併為裁處沒入或其他種類行政罰
    4. (D) 一行為違反數個行政法上義務規定而應處罰鍰者，依法定罰鍰額最低之規定裁處

    正解：(C)

  49. 49依土地法第 219 條第 1 項規定，原土地所有權人請求收回被徵收土地，應向該管直轄市或縣（市）地政機關聲請。該管直轄市或縣（市）地政機關經查明合於照徵收價額收回其土地之要件，並層報原核准徵收機關作成准、駁之決定，而函覆該管直轄市或縣（市）地政機關通知原土地所有權人時，此時應以何者為處分機關？

    1. (A) 原核准徵收機關
    2. (B) 直轄市或縣（市）地政機關
    3. (C) 若為准許，則為直轄市或縣（市）地政機關；若為駁回，則為原核准徵收機關
    4. (D) 若為准許，則為原核准徵收機關；若為駁回，則為直轄市或縣（市）地政機關

    正解：(A)

  50. 50故意共同實施違反行政法上義務之行為者，依其行為情節之輕重，如何處罰之？

    1. (A) 分別處罰
    2. (B) 以共同正犯處罰
    3. (C) 視其為正犯、教唆犯或幫助犯而處罰之
    4. (D) 以幫助犯處罰

    正解：(A)
