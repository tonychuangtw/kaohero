導遊領隊　106 年 導遊人員 觀光資源概要　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1鄭經曾因清廷何種變局而率兵渡海攻打大陸東南沿海？

    1. (A) 三藩之亂
    2. (B) 捻亂
    3. (C) 太平天國之亂
    4. (D) 白蓮教之亂

    正解：(A)

  2. 2清雍正元年（西元 1723 年），在諸羅縣的虎尾溪和大甲溪之間增設的廳縣是：

    1. (A) 雲林縣
    2. (B) 彰化縣
    3. (C) 臺灣縣
    4. (D) 淡水廳

    正解：(B)

  3. 3荷治時期，荷蘭人發現臺灣中部有原住民建立的跨族群、跨部落的聯盟組織，領域範圍主要在今天的臺中市、彰化縣北部和南投縣的一部分，史稱：

    1. (A) 大社番王
    2. (B) 半線番王
    3. (C) 沙轆番王
    4. (D) 大肚番王

    正解：(D)

  4. 4「臺灣沃野千里，實霸王之區。若得此地，可以雄其國，使人耕種，可以足其食。……移諸鎮兵士眷口其間，十年生聚，十年教養，而國可富，兵可強，進取退守，真足與中國抗衡也。」這段話是在勸誰攻取臺灣？

    1. (A) 施琅
    2. (B) 何斌
    3. (C) 鄭成功
    4. (D) 濱田彌兵衛

    正解：(C)

  5. 5在參觀國定古蹟「金廣福」的過程中，導遊的介紹內容，以下何者錯誤？

    1. (A) 「金」代表多金多利
    2. (B) 係結合廣東籍與福建籍的墾號
    3. (C) 於十九世紀進入新竹東南山區開墾
    4. (D) 其領袖為陳賴章

    正解：(D)

  6. 6荷治時期為控制漢人的貿易活動與滿足原住民生活所需，將轄下原住民村社的交易權公開招標，商人得標後即可獨占村社的所有交易制度，係指以下何者？

    3. (C) 番大租

    2. (B) 小白宮
    3. (C) 淡水禮拜堂

  8. 8承上題，導遊向觀光團介紹晚清臺灣的西洋傳教史時，以下那一項說明錯誤？

    2. (B) 基督長老教會以大甲溪為界，北部屬加拿大教會傳教區；南部屬英國教會傳教區
    3. (C) 馬偕於淡水設立全臺首座西式醫館
    4. (D) 巴克禮刊行的《臺灣府城教會報》是臺灣第一份報紙

  9. 9以下何者不是日治末期皇民化運動的主要內容？
