營養師　106 年第一次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何者會直接促使鈣離子由內質網釋出？

    1. (A) 三磷酸基醇（IP3）
    2. (B) 二醯甘油（DAG）
    3. (C) 環化腺苷單磷酸（cAMP）
    4. (D) 攜鈣素（calmodulin）

    正解：(A)

  2. 2下列何種激素不是由小腸內分泌細胞產生？

    1. (A) 胃泌素（gastrin）
    2. (B) 分泌素（secretin）
    3. (C) 膽囊收縮素（cholecystokinin）
    4. (D) 血清素（serotonin）

    正解：(A)

  3. 3下列何者可引發腸道基礎電節律（basic electrical rhythm）？

    1. (A) 上皮層（epithelial layer）
    2. (B) 固有層（lamina propria）
    3. (C) 黏膜下層神經叢（submucosal plexus）
    4. (D) 腸肌神經叢（myenteric plexus）

    正解：(D)

  4. 4下列何者是造成每天有大量的水由血液進入腸腔的因素？

    1. (A) 小腸表皮細胞增生需要水
    2. (B) 尚未消化的食物大分子需要攪拌
    3. (C) 胃酸是決定水分泌的主要原因
    4. (D) 氯是決定水分泌的主要離子頁次： 4－2

    正解：(D)

  5. 5下列那個器官能在長期禁食情況下進行糖質新生（gluconeogenesis）？

    1. (A) 脂肪組織
    2. (B) 骨骼肌
    3. (C) 心肌
    4. (D) 腎臟

    正解：(D)

  6. 6腹瀉時，下列何者最不可能發生？

    1. (A) 腎素分泌增加
    2. (B) 醛固酮分泌增加
    3. (C) 心房利鈉肽分泌增加
    4. (D) 抗利尿激素分泌增加

    正解：(C)

  7. 7有關亨利氏環上行支厚段之敘述，下列何者正確？

    1. (A) 為鉀離子的主要分泌部位
    2. (B) 為磷酸根離子的主要重吸收部位
    3. (C) 水分可隨意通透管壁
    4. (D) 為對流放大器（countercurrent multiplier）之一部分

    正解：(D)

  8. 8某關節炎病患長期服用類固醇藥品，最有可能出現的症狀為何？

    1. (A) 血壓下降
    2. (B) 血糖上升
    3. (C) 免疫力上升
    4. (D) 心悸

    正解：(B)

  9. 9有關甲狀腺激素（thyroid hormone）的敘述，下列何者正確？

    1. (A) 三碘甲狀腺素（triiodothyronine）主要在血液中由四碘甲狀腺素（thyroxine）轉換而成
    2. (B) 甲狀腺激素的受器主要位在細胞膜
    3. (C) 甲狀腺激素的受器對三碘甲狀腺素（triiodothyronine）有較高親和力
    4. (D) 半衰期（half life）約數分鐘

    正解：(C)

  10. 10有關飢餓素（ghrelin）的敘述，下列何者錯誤？

    1. (A) 由脂肪細胞分泌
    2. (B) 飢餓狀態分泌較多
    3. (C) 作用在下視丘（hypothalamus）促進食慾
    4. (D) 可促進生長激素分泌

    正解：(A)

  11. 11周邊血管阻力受下列那個因素影響最大？

    1. (A) 血管的長度
    2. (B) 血管的半徑
    3. (C) 血液的含氧量
    4. (D) 血液的黏稠度

    正解：(B)

  12. 12下列何者是竇房結（SA node）與心室肌細胞的膜動作電位變化調控之主要相異處？

    1. (A) 前者動作電位去極化期之主要變化是由於鉀離子內流，而後者則為鈉離子內流
    2. (B) 前者具有自動去極化的膜電位特性，而後者則無
    3. (C) 前者無自動去極化的膜電位特性，而後者則有
    4. (D) 前者具有收縮期的去極化動作電位，而後者則無

    正解：(B)

  13. 13下列何種血管氧氣含量最低？

    1. (A) 動脈弓
    2. (B) 肺動脈
    3. (C) 冠狀動脈
    4. (D) 腸繫膜動脈

    正解：(B)

  14. 14下列何種抗體可通過母體胎盤進入胎兒，提供初生嬰兒免疫力（immunity）？

    1. (A) 免疫球蛋白 A（IgA）
    2. (B) 免疫球蛋白 D（IgD）
    3. (C) 免疫球蛋白 E（IgE）
    4. (D) 免疫球蛋白 G（IgG）

    正解：(D)

  15. 15承上題，此種免疫力（immunity）屬下列何者？

    1. (A) 主動免疫（active immunity）
    2. (B) 被動免疫（passive immunity）
    3. (C) 先天免疫（innate immunity）
    4. (D) 免疫耐受（immune tolerance）

    正解：(B)

  16. 16下列何者是中樞神經系統中最主要的抑制性神經傳遞介質？

    1. (A) 多巴胺（dopamine）
    2. (B) 乙醯膽鹼（acetylcholine）
    3. (C) 血清素（serotonin）
    4. (D) 珈瑪幾丁酸（GABA）頁次：4－3

    正解：(D)

  17. 17下列何者具有類似巨噬細胞的作用，負責執行中樞神經系統的免疫功能？

    1. (A) 星狀細胞（astrocyte）
    2. (B) 寡突細胞（oligodendrocyte）
    3. (C) 微小膠細胞（microglia）
    4. (D) 室管膜細胞（ependymal cells）

    正解：(C)

  18. 18下列何種因素會降低血紅素與氧氣的親和力（affinity）？

    1. (A) pH 值上升
    2. (B) 溫度降低
    3. (C) PCO2 降低
    4. (D) 2,3-DPG 濃度增加

    正解：(D)

  19. 19下列何種細胞分泌雄性素？

    1. (A) 雷迪格細胞（Leydig cells）
    2. (B) 副睪（epididymis）之內皮細胞
    3. (C) 賽特利式細胞（Sertoli cells）
    4. (D) 曲精小管（seminiferous tubules）之上皮細胞

    正解：(A)

  20. 20纖維性囊腫（cystic fibrosis）是一種基因缺陷疾病，請問對那種器官的細胞影響最大？

    1. (A) 腎臟的間質細胞
    2. (B) 骨髓的血液生成細胞
    3. (C) 腦部的神經細胞
    4. (D) 肺部的肺泡細胞

    正解：(D)

  21. 21催化糖解作用之酵素位於細胞內何位置？

    1. (A) 粒線體間質（mitochondrial matrix）
    2. (B) 細胞質（cytosol）
    3. (C) 粒線體內膜（mitochondrial inner membrane）
    4. (D) 溶酶體（lysosome）

    正解：(B)

  22. 22肝醣磷解作用產生之 1 分子 glucose-1-phosphate，經糖解作用形成丙酮酸的過程，可淨獲得多少分子 ATP？

    1. (A) 1
    2. (B) 2
    3. (C) 3
    4. (D) 4

    正解：(C)

  23. 23下列何種反應，可提供五碳醣（pentose）的來源？

    1. (A) citric acid cycle
    2. (B) gluconeogenesis
    3. (C) Embden-Meyerhof pathway
    4. (D) hexose monophosphate shunt

    正解：(D)

  24. 24下列何種核苷酸參與肝醣之合成？

    1. (A) AMP
    2. (B) UDP
    3. (C) GTP
    4. (D) CTP

    正解：(B)

  25. 25人類因缺乏下列何種酵素，因此無法合成 linoleic acid？

    1. (A) Δ5 desaturase
    2. (B) Δ6 desaturase
    3. (C) Δ9 desaturase
    4. (D) Δ12 desaturase

    正解：(D)

  26. 26關於溶質在細胞膜間的運輸，下列敘述何者錯誤？

    1. (A) 紅血球細胞膜上的葡萄糖轉運蛋白（glucose transporter）屬於主動運輸的一種
    2. (B) Na+/K+-ATPase 在人體內所耗能量極大，約占總耗能的四分之一
    3. (C) ABC 轉運蛋白（ABC transporter）是參與藥物排出細胞的一群蛋白質
    4. (D) facilitative transport 需要膜蛋白協助加速運送

    正解：(A)

  27. 27下列何者是奇數碳脂肪酸於氧化分解中特有的產物？

    1. (A) 琥珀醯輔酶 A（succinyl-CoA）
    2. (B) 丙醯輔酶 A（propionyl-CoA）
    3. (C) 丙二醯輔酶 A（malonyl-CoA）
    4. (D) 磷酸烯醇丙酮酸（phosphoenolpyruvate）

    正解：(B)

  28. 28下列何種代謝途徑，不參與脂肪分解產生能量的過程？

    1. (A) β-氧化反應
    2. (B) 檸檬酸循環
    3. (C) 電子傳遞鏈
    4. (D) Cori 氏循環

    正解：(D)

  29. 29尿素循環（urea cycle）中何種中間產物可代謝轉換成尿素（urea）及鳥胺酸（ornithine）？

    1. (A) 白胺酸（leucine）
    2. (B) 丙胺酸（alanine）
    3. (C) 甲硫胺酸（methionine）
    4. (D) 精胺酸（arginine）

    正解：(D)

  30. 30何種胺基酸具有下列特性：為必需胺基酸（essential amino acids）、且屬生酮性胺基酸（ketogenic amino acid）而非生醣性胺基酸（non-glucogenic amino acid）、及具支鏈胺基酸（branched chain amino acid）特性？

    1. (A) 異白胺酸（isoleucine）
    2. (B) 離胺酸（lysine）
    3. (C) 白胺酸（leucine）
    4. (D) 纈胺酸（valine）頁次： 4－4

    正解：(C)

  31. 31當胺基酸的側鏈（side-chain）為-CH3 時，則該側鏈是屬於下列何種基團？

    1. (A) polar group
    2. (B) hydrophilic group
    3. (C) aliphatic group
    4. (D) charged group

    正解：(C)

  32. 32Phenylisothiocyanate 是由 Pehr Edman 研發成功的一種試劑，常用於鑑定下列何者？

    1. (A) 蛋白質的 C-端胺基酸
    2. (B) 蛋白質的肽鍵數目
    3. (C) 蛋白質的雙硫鍵
    4. (D) 蛋白質的 N-端胺基酸

    正解：(D)

  33. 33轉譯後作用（post-translation）蛋白質修飾（protein modification）不包括下列何者？

    1. (A) 延伸過程（elongation）
    2. (B) 鏈折疊（chain folding）
    3. (C) 共價鍵修飾（covalent modification）
    4. (D) 蛋白質剪接（protein splicing）

    正解：(A)

  34. 34RNA 經 processing 過程，可能會出現下列何種結果？

    1. (A) 5'端 mRNA 附著於 poly(A) tail 上
    2. (B) 特定 exons 會插入成熟 mRNA 中
    3. (C) 兩種不同的蛋白質產物來自於單一基因
    4. (D) 兩個不同基因生成相同的蛋白質產物

    正解：(C)

  35. 35Allopurinol 是治療痛風（gout）的常用藥物，它主要是藉由抑制下列何種酵素作用達到緩解痛風症狀？

    1. (A) xanthine oxidase
    2. (B) thymidylate synthase
    3. (C) ribonucleotide reductase
    4. (D) hypoxanthine monooxygenase

    正解：(A)

  36. 36丙酮酸去氫酶複合體（pyruvate dehydrogenase complex）可將丙酮酸（pyruvate）催化成乙醯輔酶-A（acetyl-CoA），此酵素不需要下列何種維生素作為輔酶？

    1. (A) 維生素 B1（硫胺素, thiamine）
    2. (B) 維生素 B2（核黃素, riboflavin）
    3. (C) 維生素 B3（菸鹼酸, niacin）
    4. (D) 維生素 B12（鈷胺素, cobalamin）

    正解：(D)

  37. 37根據 Michaelis-Menten 酵素動力學的理論，下列敘述何者正確？

    1. (A) 穩定狀態假說認為酵素與受質的複合體濃度，在整個反應過程中幾乎維持恆定
    2. (B) 催化反應的一般速率常數 kcat 可代表酵素與受質的鍵結能力
    3. (C) Michaelis 常數 Km 可說明在單位時間下，單位濃度的酵素水解多少受質
    4. (D) Km / kcat 解釋酵素的效率（efficiency）

    正解：(A)

  38. 38下列那一個酵素參與反應時，產物中沒有 CO2？

    1. (A) 丙酮酸去氫酶（pyruvate dehydrogenase）
    2. (B) 蘋果酸去氫酶（malate dehydrogenase）
    3. (C) 異檸檬酸去氫酶（isocitrate dehydrogenase）
    4. (D) α-酮戊二酸去氫酶（α-ketoglutarate dehydrogenase）

    正解：(B)

  39. 39Fluroacetate 為烏頭酸酶（aconitase）的 suicide inhibitor，其屬於下列何種酵素抑制作用？

    1. (A) irreversible inhibition
    2. (B) competitive reversible inhibition
    3. (C) mixed reversible inhibition
    4. (D) uncompetitive reversible inhibition

    正解：(A)

  40. 40下列何者是參與氧化磷酸化（oxidative phosphorylation）的酵素？

    1. (A) fatty acid synthase
    2. (B) pyruvate kinase
    3. (C) FoF1 ATP synthase
    4. (D) phosphofructokinase

    正解：(C)
