  1. 1欲探討飲食攝取與慢性疾病的關係，使用下列何種飲食評估方法最適當？

    1. (A) 24-hour recall
    2. (B) Food frequency questionnaire
    3. (C) Daily food record
    4. (D) Diet history

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 飲食頻率問卷（FFQ）詢問受試者過去一段時間各種食物的攝取頻率，可代表長期、慣常的飲食型態，最適合用於探討飲食與慢性疾病（潛伏期長）的關係。

    ❌ (A) 24 小時回憶法只反映一天攝取，日與日間變異大，無法代表長期飲食。

    ❌ (C) 每日飲食紀錄通常只記錄數天，且記錄行為本身可能改變攝食，不適合長期慢性病研究。

    ❌ (D) 飲食史雖可評估長期習慣，但耗時、需專業訪談，大規模流行病學研究較少採用。

    📚 出處：膳食療養學「營養評估」章節：飲食攝取評估法（FFQ 之適用時機）

  2. 2根據 WHO 的肥胖定義來看 BMI＝38 為何？

    1. (A) Underweight
    2. (B) Overweight
    3. (C) Obese class I
    4. (D) Obese class II

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) WHO 依 BMI 將肥胖分級：BMI 30.0～34.9 為 Obese class I，35.0～39.9 為 Obese class II，≥40 為 class III。BMI 38 落在 35.0～39.9，屬 Obese class II。

    ❌ (A) Underweight 指 BMI＜18.5。

    ❌ (B) Overweight 指 BMI 25.0～29.9。

    ❌ (C) Obese class I 為 BMI 30.0～34.9，38 已超出此範圍。

    📚 出處：WHO 身體質量指數（BMI）分類標準；膳食療養學「肥胖」章節

  3. 3下列何者不是營養篩檢（nutrition screening）的項目？

    1. (A) 體重改變
    2. (B) BMI
    3. (C) 進食量
    4. (D) 藥物

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 營養篩檢在短時間內找出營養不良風險者，項目包括體重變化、BMI（體位）、進食量／食慾改變、疾病嚴重度等；藥物使用不屬篩檢項目，而屬後續營養評估的用藥史。

    ❌ (A) 非預期體重減輕是營養篩檢的核心指標之一。

    ❌ (B) BMI 為基本體位測量，是篩檢必含項目。

    ❌ (C) 進食量減少或不願進食為篩檢常見指標。

    📚 出處：膳食療養學「營養篩檢與評估」章節：營養篩檢項目（如 MST、NRS-2002）
