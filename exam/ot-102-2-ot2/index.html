職能治療師　102 年第二次 職能治療學概論　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1根據Clark及Carson於2001年對職能（occupation）的定義，下列何項不是職能活動？

    1. (A) 用餐（dining）
    2. (B) 夢遊（sleepwalking）
    3. (C) 繪畫（painting）
    4. (D) 滑雪（skiing）

    正解：(B)

  2. 2道德治療（moral treatment）的精神與下列何項之關聯性最低？

    1. (A) 促進職能活動的參與
    2. (B) 庇護所（asylum）的設立
    3. (C) 人道主義（humanitarian approach）
    4. (D) 專科化（specialization）

    正解：(D)

  3. 3下列關於職能治療介入公共衛生（public health）的敘述，何者錯誤？

    1. (A) 介入層次涵蓋社會層面
    2. (B) 對政治上的影響比治療個人來得重要
    3. (C) 介入層次涵蓋沒有疾病的人
    4. (D) 應與其他專業合作

    正解：(B)

  4. 4下列何者非闡述專業哲學基礎需說明之要素？

    1. (A) 生命價值論（axiology）
    2. (B) 知識論（epistemology）
    3. (C) 形上學（metaphysics）
    4. (D) 現象論（phenomenalism）

    正解：(D)

  5. 5下列何者不屬於路德（Rood）理論中，降低肌肉張力的方法？

    1. (A) slow rolling
    2. (B) joint compression
    3. (C) deep tendon pressure
    4. (D) heavy joint compression

    正解：(D)

  6. 6在類化的過程中，病人如果可以學會將6－8樣食材做成沙拉，而類化到可以將6－8樣食材放入午餐盒中，是屬於那一個層級的能力轉移（transfer）？

    1. (A) 近度轉移（near transfer）
    2. (B) 中度轉移（intermediate transfer）
    3. (C) 遠度轉移（far transfer）
    4. (D) 極遠度轉移（very far transfer）

    正解：(B)

  7. 7下列那種動作障礙是由於基底核（basal ganglia）病變而產生的？

    1. (A) 意向性震顫（intention tremor）
    2. (B) 運動失調（ataxia）
    3. (C) 測距不良（dysmetria）
    4. (D) 休息性震顫（resting tremor）

    正解：(D)

  8. 8關於感覺統合理論，下列敘述何者錯誤？

    1. (A) 適應性行為（adaptive response）是感統治療最主要的觀察變項
    2. (B) 感覺統合理論認為治療後的行為改變反應出腦的可塑性（plasticity）
    3. (C) 感覺統合的問題主要來自於周邊的（peripheral）感覺功能失常
    4. (D) 注意力缺失過動症也可能會有感覺統合的問題

    正解：(C)

  9. 9練習（practice）是動作學習（motor learning）理論中一項重要的核心。下列關於練習的種類及定義，何者正確？

    1. (A) Distributed practice指的是練習的種類很多很廣
    2. (B) Part-task practice指的是練習活動的一小部分。如使用Baltimore therapeutic equipment就是一個例子
    3. (C) Mental practice指的是一邊操作一邊用認知的方法記憶所有的步驟
    4. (D) Constant practice指的是連續的練習，中間都不休息

    正解：(B)

  10. 10下列何者最不適合作為評量職能治療成效（outcome）的指標？

    1. (A) 出院
    2. (B) 滿意度
    3. (C) 角色能力
    4. (D) 參與度

    正解：(A)

  11. 11關於感覺統合理論，下列敘述何者錯誤？

    1. (A) 基底核（basal ganglia）主要負責統合各項感覺輸入
    2. (B) 觸覺防禦（tactile defensiveness）是感覺統合障礙的一種
    3. (C) 感覺統合的發展是階層式的（hierarchical）
    4. (D) 愛爾斯（Ayres）是理論的提出者

    正解：(A)

  12. 12注意力缺失過動症（attention deficit hyperactivity disorder）的三個主要核心症狀為活動量高、注意力不足及：
