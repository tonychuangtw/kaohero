警察特考　110 年 四等考試 水上警察情境實務概要　考古題與詳解

本卷共 20 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（20 題，建議 60 分鐘）

  1. 1海巡艦航行中人工操舵轉換為自動操舵，或由自動操舵轉換為人工操舵，應由下列何者操作或在其監督下進行操作？

    1. (A) 值班舵工
    2. (B) 水手長
    3. (C) 當值航行員
    4. (D) 輪機長

    正解：(C)

  2. 2海巡艦艇在我國海域巡邏時，遭遇有敵意之他船機槍掃射，並對海巡艦人員造成生命危害。前述狀況經海洋委員會最高層級長官同意現場指揮官使用二○機砲，該採取以下何項措施反制敵船？

    1. (A) 機砲仍備便
    2. (B) 採警告射擊
    3. (C) 對船體射擊
    4. (D) 應予以擊毀

    正解：(C)

  3. 3海巡艇於臺中大安溪口外 23 浬發現巴拿馬油輪與大陸籍船舶併靠駁油，現場未布放攔油索，如何應處？

    1. (A) 押返二船，依違反臺灣地區與大陸地區人民關係條例裁處罰鍰
    2. (B) 押返二船，依違反海洋污染防治法函送主管機關裁處
    3. (C) 押返二船，依違反海洋污染防治法函送主管機關裁處；陸船另依違反臺灣地區與大陸地區人民關係條例裁處罰鍰
    4. (D) 僅押返陸船，依違反臺灣地區與大陸地區人民關係條例裁處罰鍰

    正解：(C)

  4. 4海巡艦執行海難船舶拖救任務，被拖帶船舶發生船艏輕微偏盪，影響拖帶效率及有造成斷纜之虞時，相關改善措施，下列何者錯誤？

    1. (A) 調整被拖船艏艉吃水，使其成艉傾狀態
    2. (B) 提高拖帶速度或增加拖纜長度
    3. (C) 固定艉軸，增加被拖船艉部阻力及航向穩定性
    4. (D) 使被拖船固定舵角（小於 20 度）

    正解：(B)

  5. 5海巡艇獲報取締違規距岸 3 浬內拖網作業案件有關蒐證重點之敘述，下列何者錯誤？

    1. (A) 漁船船名及以陸地為背景之漁船拖網作業畫面
    2. (B) 以衛星定位儀（GPS）及雷達鎖定違規作業漁船位於經緯度確於距岸 3 浬內海域
    3. (C) 由 GPS 與雷達畫面移至漁船違規畫面時需連續不間斷
    4. (D) 漁船外在特徵與出海作業人數

    正解：(D)

  6. 6海巡人員持地檢署檢察官指揮書查緝漁船走私槍械案件，執行專案海巡艇於通報海域發現該艘我國籍漁船，惟該船拒檢向外海逃離並企圖丟棄證物，下列何種處置適當？

    1. (A) 海巡艇蒐證並廣播停船，必要時警告射擊並強靠登檢該船
    2. (B) 報告隊部增派海巡艇，俟抵達後共同實施雙艇強靠登檢
    3. (C) 海巡艇繼續追緝，待目標船舶自行停航後採取登檢措施
    4. (D) 由其他海巡艇追緝登檢走私漁船，本艇持續蒐證

    正解：(A)

  7. 7海巡艇登檢大陸漁船時，基於安全考量，下列何者適當？

    1. (A) 登檢後立即控制漁船駕駛艙，並關閉主機
    2. (B) 登檢後立即分組檢查各艙間是否有不法事證
    3. (C) 請漁工全數集中到漁船船艏處，再行登檢
    4. (D) 請漁船船長至海巡艇製作登檢紀錄，再行登檢

    正解：(C)

  8. 8海巡艇巡邏時，在綠島東方海域 15 浬處發現漁船正排放濃稠黑色液體，下列處置何者適當？

    1. (A) 立即召集艇上人員進行編組，攜帶手銬及基本武裝，將漁船船長逮捕，並宣讀其應有之權利
    2. (B) 立即攝影蒐證，並進行海水取樣，告知漁船船長違犯事項後，即將該船押解回隊部
    3. (C) 蒐證及製作訪談筆錄、告知船長違犯事項後，函送海洋委員會裁罰
    4. (D) 立即通報勤務指揮中心，取得長官同意後，再行進行採樣、蒐證及後續函送事宜

    正解：(C)

  9. 9東港籍漁船於模里西斯 800 浬外公海作業時，一名菲律賓籍漁工突然持刀追砍多名船員，巡護船奉派馳援，抵達後處置作為，下列何者錯誤？

    1. (A) 開啟水砲，強靠攻堅，逼迫犯嫌投降
    2. (B) 勸服嫌犯投降（心戰喊話）後，進行調查蒐證，並依承辦檢察官指揮事項辦理
    3. (C) 受傷船員，依就近就便原則，接送至鄰近國家就醫或協調友船接送就醫
    4. (D) 船員落海失蹤，參考現場海流資訊，視情採取搜索救助行動

    正解：(A)

  10. 10海巡艇處理海洋油污簡易採樣，在現場外溢油污染中，海水表層之油污染狀態採樣以何種油污較佳？

    1. (A) 新鮮的油污
    2. (B) 風化過的油污
    3. (C) 巧克力顏色的油污
    4. (D) 任何情況的油污皆可

    正解：(A)

  11. 11情資顯示有不知名漁船將以密窩走私大量火腿，同時在海面上有多艘漁船作業，就現場所見何種態樣漁船應列為優先登檢目標？

    1. (A) 觀察位於船艉之漁工，並未認真工作
    2. (B) 觀察位於船艉之漁具，並無作業跡象
    3. (C) 船舯位置的乾舷與水面距離顯有異常
    4. (D) 船艉之船籍港名稱污穢不堪甚難辨明

    正解：(C)

  12. 12海巡艇於花蓮石梯外海 8 浬處海域，登檢 1 艘 CT4 漁船時，發現該船載運 15 位民眾出海賞鯨，經查該船未申請執照經營娛樂漁業，該如何處置？

    1. (A) 蒐證後，函送花蓮縣政府裁處
    2. (B) 蒐證後，押返人船返港調查，再函送花蓮縣政府裁處
    3. (C) 蒐證後，函送行政院農業委員會漁業署裁處
    4. (D) 蒐證後，函送花蓮地方檢察署裁處

    正解：(C)

  13. 13本國籍漁船於小琉球西南方約 12 浬與外籍貨輪發生擦撞，導致 1 名漁船船員落海，幸即時被救起未造成傷亡，海巡艇獲報後趕抵現場處理，應如何處置？

    1. (A) 檢視並保存相關證據，因屬單純民事糾紛，由雙方當事人自行協調賠償等相關事宜
    2. (B) 船舶碰撞可能涉及中華民國刑法毀損罪刑事責任，應將雙方當事人帶返海巡隊製作筆錄
    3. (C) 若經雙方當事人未能當場和解者，應儘量勸戒達成和解，並應將概況填寫於工作紀錄簿備查
    4. (D) 若經雙方當事人當場和解者，應製作調查筆錄，並視狀況檢同相關文件函送主管機關

    正解：(A)

  14. 14海巡艦艇接獲通報我國籍 CT4 漁船機械故障失去動力，要求海巡艦艇協助拖救，有關拖救原則下列何者錯誤？

    1. (A) 請遇難船舶向民間或海上救難組織、海軍申請拖救
    2. (B) 請遇難船舶應通報區漁會及漁業電台，發動漁船互助救援
    3. (C) 經艦艇長判斷拖帶作業危及海巡艦艇及人員安全時，可不實施拖帶
    4. (D) 當遇難船舶無法排除機械故障，且現場海象風力級數達 5 級以上，海巡艦艇即可實施拖帶

    正解：(D)

  15. 15基隆海巡隊接獲通報於野柳外海 3 浬處發出緊急求救訊號，經查北海岸海域線上海巡艇僅一艘，正位於基隆外海巡邏，值勤員獲報後向值日官提出建議，下列何者適當？

    1. (A) 考量黃金救援時間，立即通報行政院國家搜救指揮中心，派機救援
    2. (B) 考量黃金救援時間，立即指揮線上巡防艇，中止巡邏勤務前往救援
    3. (C) 為避免影響巡防艇巡邏勤務，應立即指揮基隆海巡隊緊急出勤救援
    4. (D) 為避免影響巡防艇巡邏勤務，應立即協調淡水海巡隊緊急出勤救援

    正解：(B)

  16. 16高雄海巡隊查緝漁船走私毒品案，拘捕人犯後，接到法院提審票，應於多久時間內將被拘捕拘禁人解交法院？

    1. (A) 8 小時
    2. (B) 16 小時
    3. (C) 24 小時
    4. (D) 48 小時

    正解：(C)

  17. 17海巡艇於馬祖東莒林坳嶼外 2.2 浬處，發現一艘大陸籍船舶，未經許可進入限制水域，並以船上抽砂設備抽取海面下海砂，經登檢扣留後，如何應處？

    1. (A) 押返人、船，依違反刑法加重竊盜罪，移送福建連江地方檢察署偵辦
    2. (B) 押返人、船，依違反漁業法，函送連江縣政府裁處
    3. (C) 押返人、船，依違反臺灣地區與大陸地區人民關係條例，逕行裁處沒入採取海砂、抽砂管及行政罰鍰
    4. (D) 押返人、船，依違反臺灣地區與大陸地區人民關係條例，逕行裁處沒入船舶處分

    正解：(A)

  18. 18臺中海巡隊海巡艇巡邏發現乙艘 CT2 漁船，於大安溪外 6 浬拖網捕魚，經登檢核對該船漁業執照僅核准流網漁業，下列處置何者正確？

    1. (A) 要求漁船停止作業押返偵辦
    2. (B) 要求船主限期拆除拖網設備
    3. (C) 依違反漁業法函送漁政主管機關
    4. (D) 依漁業法移送檢察機關，並副知行政院農業委員會漁業署

    正解：(C)

  19. 19海巡艇扣留越界作業大陸漁船後，留置調查人員依規定應移交主管機關辦理留置，有關得採原船留置情形，下列何者正確？

    1. (A) 轄內大陸地區人民留置處所空間不足者
    2. (B) 扣留船舶基於定期清潔需要，須受留置人協助者
    3. (C) 基於留置調查訊問便利之需要
    4. (D) 基於受留置人親友申請會客之需要

    正解：(A)

  20. 20基於勤務考量，艦長下令擇地錨泊，若水深均合適，選擇下列何種海底地形下錨適當？

    1. (A) 珊瑚礁
    2. (B) 岩質
    3. (C) 砂質
    4. (D) 人工魚礁

    正解：(C)
