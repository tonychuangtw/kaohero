營養師　103 年第二次 團體膳食設計與管理　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1製作水餃皮 100 張（每張 10 公克）約需使用麵粉多少公克？（已知 100 公克麵粉約加冷水 50 公克來揉成麵糰，另外操作耗損約 10%）750 1000 1350 1500

    正解：(A)

  2. 2關於標準食譜之製作敘述，下列何者錯誤？

    1. (A) 以小成大作擴展
    2. (B) 使用因數表做換算
    3. (C) 考慮製備烹調損失
    4. (D) 考慮烹煮時間差異

    本題經考選部公告不計分。

  3. 3自助餐廳每餐供應 600 人，葷菜可以三選一，其中一道為烤肉排，材料為豬里肌肉，每人供應量為 75 公克，肉排收縮率為 15%，則需採購多少公斤的豬里肌肉？15 18 45 54

    正解：(B)

  4. 4下列何種生命週期之男性民眾，在適度活動量下，每人每天所需要的熱量為最多？

    1. (A) 7～10 歲
    2. (B) 13～15 歲
    3. (C) 16～18 歲
    4. (D) 19～30 歲

    正解：(C)

  5. 5下列何者屬於含澱粉最高的點心？

    1. (A) 肉包
    2. (B) 粉圓
    3. (C) 布丁
    4. (D) 洋菜

    正解：(B)

  6. 6依據新版「每日飲食指南」建議，鼓勵增加攝取未精緻的全穀食物，應用於團體膳食供應米飯時，白米搭配糙米比例至少達多少為宜？1：2 1：3 2：1 3：1

    正解：(C)

  7. 7有關冷藏管理方式，下列敘述那些正確？①食品入庫前應清楚標示項目 ②置於不銹鋼盆內之熟食不需加蓋 ③食品應適當包裝 ④生食應置於熟食上方架子①③ ①④ ②③ ②④頁次：4－2

    正解：(A)

  8. 8有關庫房管理之敘述，下列何者錯誤？

    1. (A) 步入型冷凍冷藏庫應設有紅色作業燈
    2. (B) 乾料庫房相對濕度應控制在 70～80%
    3. (C) 食品存放應符合先進先出原則
    4. (D) 步入型冷凍冷藏庫宜於庫外張貼「庫內食品位置放置圖」

    正解：(B)

  9. 9某餐廳依成品特性、用途分為乾料庫房、新鮮材料庫房和非食品庫房，則此種庫房管理為：

    1. (A) 依供應商供應方式分類
    2. (B) 水龍頭倉庫方式
    3. (C) 集中庫房
    4. (D) 分散式庫房

    正解：(D)

  10. 10有關團膳公司進行庫房管理時須考量的條件，下列敘述何者錯誤？

    1. (A) 乾料庫房，溫度控制 5～22℃、濕度 40～60%
    2. (B) 蔬果冷藏庫，溫度控制 1～7℃、濕度 50～65%
    3. (C) 乳品冷藏庫，溫度控制 3～7℃、濕度 80～85%
    4. (D) 冷凍庫，溫度控制-18℃、濕度 75～85%

    正解：(B)

  11. 11關於驗收之敘述，下列何者錯誤？

    1. (A) 驗收可由採購人員擔任
    2. (B) 驗收區應準備秤量器具
    3. (C) 驗收區宜接近前處理區
    4. (D) 驗收不合格的貨品可以拒收

    正解：(A)

  12. 12有關「議價採購」之敘述，下列何者正確？①為一公開之採購方法 ②較適用於緊急採購 ③以競價方式決定廠商 ④較適用於獨家經營貨品之採購 ⑤手續繁複且耗時①② ②④ ①④⑤ ③④⑤

    正解：(B)

  13. 13採購過程中經常會對於所要購買的商品制定「規格」，下列何者不屬於規格中的項目？

    1. (A) 稠度
    2. (B) 包裝
    3. (C) 品種
    4. (D) 等級

    本題經考選部公告不計分。

  14. 14有關驗收肉品時須注意的事項，下列敘述何者錯誤？

    1. (A) 屠體表面要潮濕
    2. (B) 豬肉品級分為上肉、中肉、下肉
    3. (C) 屠體肥肉要白嫩
    4. (D) 屠體瘦肉要赤紅且無粗纖維狀

    正解：(A)

  15. 15蛋黃中何種成分是良好乳化劑之來源？

    1. (A) cholesterol
    2. (B) lecithin
    3. (C) ovomucin
    4. (D) avidin

    正解：(B)

  16. 16下列茶品中，何者屬於全發酵茶？

    1. (A) 紅茶
    2. (B) 綠茶
    3. (C) 包種茶
    4. (D) 烏龍茶

    正解：(A)

  17. 17下列何者不是黃豆加工衍生之食品？

    1. (A) 沙拉油
    2. (B) 麵筋
    3. (C) 醬油
    4. (D) 百頁

    正解：(B)

  18. 18肉豬屠體中那一部位最適合回鍋肉及培根之製作？

    1. (A) 三層肉
    2. (B) 後腿肉
    3. (C) 腰內肉
    4. (D) 胛心肉

    正解：(A)

  19. 19下列何者可以防止澱粉老化？

    1. (A) 添加醋
    2. (B) 添加油
    3. (C) 將澱粉溫度保持於 50℃以下
    4. (D) 將水分含量保持在 15%以上

    正解：(B)

  20. 20下列關於西點常用油脂之敘述，何者正確？酥油又稱為雪白油 丹麥麵包常添加豬油以製造具有層次的產品瑪琪琳約含 6%鹽，以防止黴菌生長 雪白油不含水分與鹽分頁次：4－3

    正解：(D)

  21. 21下列何種方式稽查評鑑廠商，最能了解其作業狀況？

    1. (A) 不定期，無預警式
    2. (B) 定期，無預警式
    3. (C) 不定期，預先告知
    4. (D) 定期，預先告知

    正解：(A)

  22. 22老人安養機構住民 250 人，若廚房只能選購 3 種基本設備，則下列那些為宜？①鼓風式瓦斯炒爐 ②電烤箱 ③蒸庫 ④煎臺 ⑤蒸汽迴轉鍋①②③ ①③⑤ ②③④ ②④⑤

    正解：(B)

  23. 23下列敘述何者錯誤？

    1. (A) 油煙機之抽氣能力以能排氣至少 80%為原則
    2. (B) 刀具、砧板保管箱應有紫外線殺菌設備
    3. (C) 器具、餐具及器皿洗滌消毒設備，至少應具備三槽式洗滌設備
    4. (D) 冷凍及冷藏設備之貯物容積宜在 70%以下

    正解：(A)

  24. 24根據「即食餐食工廠良好作業規範專則」之規定，下列敘述何者錯誤？

    1. (A) 原料處理場、烹調場等場所，其地面應有適當之排水斜度（應在 1/100 以上）及排水系統
    2. (B) 排水溝之側面和底面接合處應有適當之弧度（曲率半徑應在 3 公分以上）
    3. (C) 烹飪場內之天花板至少要離地面 2.0 公尺以上
    4. (D) 管制作業區之室內窗檯，檯面深度如有 2 公分以上者，其檯面與水平面之夾角應達 45 度以上

    正解：(C)

  25. 25下列何者不在人力資源發展計畫中？

    1. (A) 人員配置與排班
    2. (B) 人員招募、甄選
    3. (C) 培育訓練員工
    4. (D) 激勵升遷、調職、解僱員工

    正解：(A)

  26. 26績效評估方法中，常被用於評估一個具有管理潛力的工作人員或中級主管，其中包含人格、工作潛力、人際關係，此評估技術常運用多種評估方法及多位評估人員參與，此評估方法為何？評核中心 排列順序 人與人比較 自我評估

    正解：(A)

  27. 27某館子製作水餃皮一張 6 公克，麵粉吸水量約為 45%，使用 5.5 公斤麵粉約可以製作多少張水餃皮？

    1. (A) 700
    2. (B) 1000
    3. (C) 1300
    4. (D) 1600

    正解：(C)

  28. 28為防食物中毒，關於衛生主管機關建議食品業者作業中注意的五要原則，下列敘述何者正確？

    1. (A) 要注意保存溫度、要新鮮、要洗手、生熟食要分開、要徹底加熱
    2. (B) 生熟食要分開、要徹底加熱、要先進先出、要標示、要洗手
    3. (C) 要標示、要消毒、要注意保存溫度、要新鮮、要洗手
    4. (D) 要先進先出、要洗手、生熟食要分開、要徹底加熱、要消毒

    正解：(A)

  29. 29根據「即食餐食工廠良好作業規範專則」規定，一般作業區域、調理、烹調作業場所及檢查作業檯面之照明應分別保持在多少米燭光以上？110、220、540 110、320、500 120、220、450 150、220、400

    正解：(A)

  30. 30開心農場販賣有機蘋果的情況為：每萬元營業額的用量是 0.2 箱，5 月 10～20 日預估營業額有 150 萬元，本次庫存量有 12 箱，若安全係數為 1.2，則最少應該訂購多少箱？18 20 24 28

    正解：(C)

  31. 31某員工餐廳每月供應 10,000 人份用餐，每份伙食費用 50 元，其中固定成本 10 萬元，目標利潤為 0 元，則變動成本率應為多少%？90 80 70 60頁次：4－4

    正解：(B)

  32. 32依據「食品良好衛生規範」，關於「溫度」的敘述，下列何者正確？

    1. (A) 低溫食品理貨及裝卸貨作業均應在攝氏十五度以下之場所進行
    2. (B) 食品販賣熱藏（高溫貯存）溫度應保持在攝氏五十度以上
    3. (C) 冷凍食品之中心溫度應保持在攝氏負五度以下
    4. (D) 冷藏食品之中心溫度應保持在攝氏七度以上凍結點以上

    正解：(A)

  33. 33關於團體膳食業者用水衛生管理之敘述，下列何者錯誤？

    1. (A) 水塔每二年至少清洗乙次
    2. (B) 國內現行標準正常水質 pH 值 6.0～8.5
    3. (C) 國內現行標準正常自由有效餘氯 0.2～1.0 mg/L
    4. (D) 室外蓄水池距污水管 5 公尺以上

    正解：(A)

  34. 34若某家餐廳每月固定成本約 20 萬元，變動成本占 50%，預估利潤 30 萬元，則每月營業額至少為多少萬元？50 100 150 200

    正解：(B)

  35. 35依據我國食品衛生管理法規定，團膳業者聘用新進人員的體檢項目必需包括下列那些項目？①A 型肝炎②膿瘡 ③肌酸酐 ④結核病 ⑤尿蛋白②③④ ①③⑤ ①②④ ②④⑤

    正解：(C)

  36. 36王先生申請至某團膳公司擔任營養師工作，剛通過面試進入員工體檢階段，則下列檢查項目何者為非必須項目？個人及家族史 齟齒 身高、體重 視力、色盲、聽力

    正解：(B)

  37. 37供膳員工的工作衛生習慣管理，下列何種行為是不被允許？

    1. (A) 同一塊砧板切熟食與生食前需要清洗
    2. (B) 不可用手直接接觸食品
    3. (C) 所有的熟食必須蓋好
    4. (D) 工作時不用手抓、摸頭髮

    正解：(A)

  38. 38何謂 critical limit？

    1. (A) 控制界線
    2. (B) 矯正點
    3. (C) 重要控制點
    4. (D) 風險評估

    正解：(A)

  39. 39有關素食種類的定義，下列敘述何者錯誤？

    1. (A) 全素或純素：只食用不含奶蛋、植物五辛的純植物性製品
    2. (B) 蛋素：食用全素或純素及蛋製品
    3. (C) 植物五辛素：食用不含植物五辛（蔥、蒜、韭、蕎及興渠）的植物性製品
    4. (D) 奶蛋素：食用全素或純素及奶蛋製品

    正解：(C)

  40. 40有關塑化劑的敘述，下列何者錯誤？

    1. (A) 起雲劑是一種非法的食品添加物，可幫助食品的乳化
    2. (B) DEHP 為一種磷苯二甲酸酯類化合物，是塑化劑
    3. (C) 為避免塑化劑的危害，要養成多吃蔬果、多喝開水、多運動，加速塑化劑排出
    4. (D) 不要用保鮮膜包裝油性食物，以避免塑化劑的暴露

    正解：(A)
