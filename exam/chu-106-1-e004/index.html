初等考試　106 年 初等考試 行政學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1就行政學的發展歷程而言，最新的觀點為何？

    1. (A) 管理的觀點
    2. (B) 政治的觀點
    3. (C) 政策的觀點
    4. (D) 公共性的觀點

    正解：(D)

  2. 2下列那位學者提出管理的「額外價值論」學說？

    1. (A) 泰勒（F. Taylor）
    2. (B) 費堯（H. Fayol）
    3. (C) 傅麗德（M. Follett）
    4. (D) 韋伯（M. Weber）

    正解：(C)

  3. 3社會科學自 1960 年代起進入整合理論時期，此一理論崛起的主要原因為何？

    1. (A) 改進傳統理論與行為科學的缺失
    2. (B) 新公共行政理論的崛起
    3. (C) 實證主義的發展，提升科學研究的基礎
    4. (D) 配合大政府思維的出現，解決經濟大蕭條所產生的問題

    正解：(A)

  4. 4關於行政國的敘述，下列何者錯誤？

    1. (A) 瓦爾多（D. Waldo）首先使用，意在強調現代行政成長，可以作為一門學術研究
    2. (B) 形容政府職能擴張，行政部門舉足輕重
    3. (C) 馬可仕（F. Morstein Marx）使用該詞，從科層體制專論說明立法、司法權不復存在
    4. (D) 當前行政國凸顯國家目的的達成，必須藉助行政活動，各國皆然

    正解：(C)

  5. 5賽蒙（H. Simon）的決策理論係屬公共行政研究中的何種典範？

    1. (A) 組織發展
    2. (B) 政治教育
    3. (C) 行政控制
    4. (D) 政治結構

    正解：(C)

  6. 6下列何者係形容「員工將組織的變革作法視為新瓶舊酒，可以刻意忽視，等待改革鋒頭過去，即可安然度過」之組織現象？

    1. (A) 不稀罕效應
    2. (B) 蝴蝶效應
    3. (C) 路徑依賴理論
    4. (D) 彼得原則

    正解：(A)

  7. 7權變學派的管理思潮認為：組織管理基本邏輯為「假如…則…」，上述的「則…」係指？

    1. (A) 管理方案
    2. (B) 外在環境
    3. (C) 因果關係
    4. (D) 自變數

    正解：(A)

  8. 8相對於企業管理，下列關於公共行政的特質之敘述，何者錯誤？

    1. (A) 陽光法案的內涵在於說明公共組織受到高度的公共監督
    2. (B) 許多政府活動具有強迫、獨占與不可避免之本質
    3. (C) 公共組織目標模糊，所以服務人民的市場區隔相對清楚
    4. (D) 公共組織的行動常受法規限制，較缺少彈性

    正解：(C)

  9. 9下列關於黑堡宣言（Blacksburg Manifesto）的敘述，何者最正確？

    1. (A) 透過批判新公共行政的主張，重建官僚體系在治理過程中的正當性
    2. (B) 擔憂採用後實證主義而弱化公共行政的學科基礎
    3. (C) 鼓吹「斥責官僚（bashing bureaucracy）」，建立落實民主行政的機制
    4. (D) 帶動行政論述回歸憲政體制，恢復公共行政在治理過程中的關鍵地位

    正解：(D)

  10. 10依據比特（B. J. Bitter）等人的分類，下列何者屬於「互益類」（mutual benefit）的非營利組織？

    4. (D) 當新政策開始推動時，原有的 SOP 就可能需要被檢討修正

  12. 12下列何者不是「市場失靈」（market failure）形成的原因？

  16. 16民眾對公共事務之關心及了解程度，並非人人相同，有人熟悉常表意見，有人所知不多亦表意見，另有不表意見者，此係民意的那種特性？

  17. 17有關溫特（S. Winter）所提出的一般政策「規劃過程/執行成果」模式，下列敘述何者錯誤？

    1. (A) 自變項為政策規劃與立法過程，例如利害關係團體間的衝突程度
    2. (B) 中介變項可為政策執行過程中的因素，例如基層官僚行為
    3. (C) 政策標的團體的反應與行為也是此模式的中介變項之一
    4. (D) 依變項即為政策執行成果，各利害關係團體通常能就政策執行成敗達成共識

    正解：(D)

  18. 18下列有關公共政策的界定及闡述，何者錯誤？

    1. (A) 公共政策的目的在解決公共問題

    3. (C) 公共政策包含政府所決定作為或不作為的活動
    4. (D) 以法律、命令、計畫、服務或產品等活動表示公共政策的內涵

  19. 19當管理者對於如何達成目標的因果關係信念很明確，但對於決策情境之目標的偏好不一致時，最適合採取下列那一種決策模式？

    4. (D) 組內的差異和組間的差異都最大

  21. 21基層官僚（street level bureaucrats）是政策執行階段的關鍵環節之一，下列敘述何者錯誤？

    4. (D) 基層官僚都存在於地方政府以直接服務民眾

  22. 22有關政策論證（policy argument）的意涵與應用，下列敘述何者錯誤？

    4. (D) 駁斥理由意指反對特定政策主張的依據

  23. 23有關政策方案的可行性分析，下列敘述何者錯誤？

    4. (D) 消極性的倫理作為

    正解：(D)

  46. 46民主國家立法機關強調展現「看守荷包權」，這是屬於對行政機關責任的何種監督？

    1. (A) 管理監督
    2. (B) 司法監督
    3. (C) 政治監督
    4. (D) 公民監督

    正解：(C)

  47. 47下列何者不是黑堡宣言對公務人員角色的期待？

    1. (A) 可執行守門員角色以確保政府重要資訊不外洩
    2. (B) 可發揮公民社會與社群政治的催生者和推動者角色
    3. (C) 可做為行政智慧與經驗的儲存者角色以防組織記憶流失
    4. (D) 可擔任教育者角色以提供民眾有關公共決策的利弊得失資訊

    正解：(A)

  48. 48公務人員倫理行為對憲政運作可以承擔一些角色責任，下列何者不在其中？

    1. (A) 應該向立法、司法和行政部門同時負責
    2. (B) 應規避立法部門的政策合法化議題
    3. (C) 可協助首長發揮協調折衝功能以解決憲政運作爭議
    4. (D) 善用憲法賦與之法定權力以維護憲政民主程序

    正解：(B)

  49. 49根據穆爾（Mark. H. Moore）策略三角分析架構，判斷公共組織方案成功與否的可能性，可從那三個要素切入分析？

    1. (A) 了解內部優勢、建構社會資本、強化創新能力
    2. (B) 資源輸入項目、內部運作效率、外部環境回饋
    3. (C) 澄清公共價值、取得正當性、建立行政運作能力
    4. (D) 概念化能力、人際溝通能力、技術專業能力

    正解：(C)

  50. 50依公務員服務法規定，公務員非依法兼任公營事業機關或公司代表官股之董事，應先如何處理？

    1. (A) 停職
    2. (B) 撤職
    3. (C) 休職
    4. (D) 降職

    正解：(A)
