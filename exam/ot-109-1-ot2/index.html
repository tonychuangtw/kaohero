職能治療師　109 年第一次 職能治療學概論　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1職能治療的專業哲學可以分為那三個重要的領域？

    1. (A) 形而上學（mataphysics）、認識論（epistemology）、價值論（axiology）
    2. (B) 形而上學（mataphysics）、認識論（epistemology）、德行論（virtue ethics）
    3. (C) 認識論（epistemology）、價值論（axiology）、結構主義（structuralism）
    4. (D) 形而上學（mataphysics）、價值論（axiology）、存在主義（existentialism）

    正解：(A)

  2. 2有關職能治療臨床實務所使用的倫理學派，下列何者最不適當？

    1. (A) 德行論（virtue ethics）
    2. (B) 效益論（utilitarianism）
    3. (C) 義務論（deontology）
    4. (D) 後果論（consequentialism）

    正解：(D)

  3. 3有關全人觀點的敘述，下列何者最不適當？

    1. (A) 應定義、評估及治療身體功能，並著重於特定問題
    2. (B) 全人的觀點可以回溯到阿道夫邁耶（Adolf Meyer）所提出的職能治療哲學
    3. (C) 全人的信念意指職能治療的評估與治療應該反映全人的需求
    4. (D) 此方式強調有機體之身體部分與整體間之功能的相關性

    正解：(A)

  4. 4有關臺灣職能治療教育的相關敘述，以下何者錯誤？

    1. (A) 最早的大學部職能治療教育，是民國五十九年的臺大復健醫學系職能治療組
    2. (B) 臺灣職能治療的大學教育必須先通過世界職能治療師聯盟（World Federation of Occupational Therapists,WFOT）的審核方能申請設立
    3. (C) 臺灣的職能治療教育目前設有大學部、碩士班及博士班
    4. (D) 僅就讀職能治療碩士班並不具備有職能治療師執照考的應試資格

    正解：(B)

  5. 5綜觀職能治療的歷史，根據發生的先後順序，職能治療服務的對象依序為何？①生理障礙 ②兒童個案 ③心理疾患

    3. (C) ①③②
    4. (D) ③②①

  9. 9關於Bronfenbrenner’s bioecological model對於職能情境的敘述，以下何者錯誤？

    2. (B) 環境因子分為六個層級
    3. (C) 環境因子會隨著個人扮演角色的改變而有不同的助益
    4. (D) 環境因子包含社區、宗教、家庭等

    正解：(B)

  11. 11對於學齡兒童於校園中的環境因子，以下敘述何者錯誤？

    2. (B) 提供學校教職員敏感度訓練課程，可增加他們對身心障礙學童的支持度與學習需求的敏感度
    3. (C) 改用較輕而易推開的門，可減少身心障礙學童進出教室的環境障礙
    4. (D) 加裝電梯讓使用輪椅之學生可以在校園中進出方便

    正解：(A)

  12. 12職能治療師面對來自不同文化背景的個案，欲促進有效的跨文化互動、醫病關係時，下列何者較不相關？

  14. 14有關情境因素中健康狀態之敘述，以下何者錯誤？

    1. (A) 性別差異對健康狀態的影響包括男性之平均餘命較女性短，而女性較男性多慢性病如關節炎或憂鬱症
    2. (B) 種族差異、教育程度、社經地位間有交互作用，不影響個人健康狀態
    3. (C) 職能治療師應致力於以個案為中心的專業服務，不受性別、年齡、種族、身心障礙等情境因素影響
    4. (D) 每個文化中都有對不同年齡族群既定的社會期待或觀感

    正解：(B)

  15. 15對於精神疾患個案回歸社區時，下列敘述何者錯誤？

    2. (B) 在協助個案轉銜就業時，介入的範疇包含工作環境改造或建議
    3. (C) 介入模式已由機構化轉為回歸社區之促進
    4. (D) 介入的範疇包含支持性就業、就學等，但不包括同儕團體的支持服務

    正解：(D)

  16. 16職能治療介入自閉症的範疇中，與情境因素有關的敘述，下列何者錯誤？

    3. (C) 以增進兒童在自然環境中有適切的行為表現為主，因此強調功能性評估

    正解：(D)
