警察特考　102 年 二等考試 國文　考古題與詳解

本卷共 10 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（10 題，建議 30 分鐘）

  1. 1下列成語與上文文意完全無關的選項是：

    1. (A) 忠言逆耳
    2. (B) 良藥苦口
    3. (C) 掩耳盜鈴
    4. (D) 諱疾忌醫

    正解：(C)

  2. 2太宗嘗謂宰相曰：「流俗有言：『人生如病瘧，於大寒大暑中過歲。』寒暑迭變，不覺漸成衰老，苟不競為善事，虛度流年，良可惜也。」（趙與時《賓退錄》卷一）太宗之言與下列何者近似？

    1. (A) 韶華易逝，為所當為
    2. (B) 烈士暮年，壯心不已
    3. (C) 人生苦短，及時行樂
    4. (D) 與人為善，助人為樂

    正解：(A)

  3. 3依據上文，下列敘述不正確的選項是：

    1. (A) 「欹器」的運用，其象徵意義高於實用功能
    2. (B) 「欹器」的設計，寓有「過猶不及」的意涵
    3. (C) 孔子問守廟者「此為何器」，暗示「君子不器」的道理
    4. (D) 孔子於弟子注水後的感喟，強調「滿招損，謙受益」的道理

    正解：(C)

  4. 4明張潮《幽夢影》：「人莫樂於閒，非無所事事之謂也。閒則能讀書，閒則能遊名勝，閒則能交益友，閒則能飲酒，閒則能著書。天下之樂，孰大於是？」以下對上文的闡述，何者最為貼切？

    1. (A) 強調保持悠閒的心境，才能品味生活的情趣
    2. (B) 反對汲汲營營、忙忙碌碌的人生，強調不計得失、無所事事才是真正的處世哲學
    3. (C) 以「讀書、遊名勝、交益友、能飲酒、能著書」為典型讀書人的五大生活情趣，捨此除外，均非天下之大樂
    4. (D) 讀書、著書為靜態休閒，遊名勝、交益友為動態娛樂，飲酒則關乎養生保健，以此為人生五大樂事，非無所事事者所能做到的生命哲學

    正解：(A)

  5. 5下列敘述正確的選項是：

    1. (A) 漢代興衰的記實：《史記》
    2. (B) 古人藥學的寶典：《本草綱目》
    3. (C) 奇謀異事的祕笈：《聊齋志異》
    4. (D) 異國壯遊的見聞：《老殘遊記》

    正解：(B)

  6. 6下列文句中「數」意義的解釋，何者不正確？

    1. (A) 《荀子．天論》：「天有常道矣，地有常『數』矣。」──法則
    2. (B) 司馬光〈訓儉示康〉：「會『數』而禮勤，物薄而情厚。」──屢次
    3. (C) 《孟子．梁惠王》：「『數』罟不入洿池，魚鱉不可勝食也。」──粗大
    4. (D) 蘇洵〈六國論〉：「勝負之『數』，存亡之理，當與秦相較，或未易量。」──命運

    正解：(C)

  7. 7此詩和下列那一首詩的詩意相近？

    1. (A) 桃之夭夭，灼灼其華。之子于歸，宜其室家。桃之夭夭，有蕡其實。之子于歸，宜其家室
    2. (B) 朝雲浮四海，日暮歸故山。行役懷舊土，悲思不能言。悠悠涉千里，未知何時旋
    3. (C) 嶺外音書絕，經冬復歷春。近鄉情更怯，不敢問來人
    4. (D) 明月何皎皎，照我羅床幃。憂愁不能寐，攬衣起徘徊。客行雖云樂，不如早旋歸。出戶獨彷徨，愁思當告誰？引領還入房，淚下沾裳衣

    正解：(D)

  8. 8（本題題幹與選項都在圖上，請見下圖作答）

    正解：(B)

  9. 9「然窮其所生之地，則絕徼海外之人視之，吾意其亦無以甚異於竹之在江以南」中「窮」字之詞性與字義，與下列選項之「窮」字何者相同？

    1. (A) 君子固「窮」，小人窮斯濫矣（《論語．衛靈公》）
    2. (B) 「窮」則獨善其身，達則兼善天下（《孟子．盡心上》）
    3. (C) 復前行，欲「窮」其林。林盡水源，便得一山（陶淵明〈桃花源記〉）
    4. (D) 接天蓮葉無「窮」碧，映日荷花別樣紅（楊萬里〈曉出淨慈寺送林子方〉）

    正解：(C)

  10. 10（本題題幹與選項都在圖上，請見下圖作答）

    正解：(D)
