  1. 1下列有關 CPU 中斷（interrupt）的敘述，何者正確？

    1. (A) 當某周邊 I/O 設備需要 CPU 服務時，CPU 可對此 I/O 設備發出中斷訊號，然後執行相對應的 I/O 服務程式
    2. (B) 中斷發生時，CPU 會將旗標（flag）狀態值存入一佇列（queue）中
    3. (C) 通常透過 interrupt vector 可以對應到中斷服務程式（interrupt service routine）的起始位址
    4. (D) 中斷 A 發生後 CPU 去執行中斷 A 之服務程式時，若剛好又發生另一個中斷 B，CPU 不允許在中斷 A 的服務程式未結束前，就先跳去執行中斷 B 的服務程式

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 中斷向量（interrupt vector）內存放各中斷服務程式的起始位址，CPU 依中斷編號查表後跳至對應的服務程式。

    ❌ (A) 中斷訊號由 I/O 設備發給 CPU，方向相反。

    ❌ (B) 中斷發生時將旗標與返回位址存入堆疊（stack）而非佇列。

    ❌ (D) 具較高優先權的中斷可插斷正在執行的中斷服務程式，形成巢狀中斷。

    📚 出處：中斷機制與中斷向量

    1. (A) 若 n > 0，則 f(n) = 1 + 4 + 9 + 16 + …. + n*n；否則 f(n) = 0
    2. (B) 若 n > 0，則 f(n) = 0 + 2 + 4 + 6 + …. + 2*n；否則 f(n) = 0
    3. (C) 若 n > 0，則 f(n) = 1 + 2 + 3 + 4 + …. + n；否則 f(n) = 0
    4. (D) 若 n > 0，則 f(n) = n!；否則 f(n) = 1

    正解：(A)
