物理治療師　111 年第二次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列針對下頸椎活動及兩側小面關節之滑動動作的敘述，何者錯誤？

    1. (A) 前彎時，左右小面關節同時向上，向前滑動
    2. (B) 後仰時，左右小面關節同時向下，向後滑動
    3. (C) 向右側彎時，左邊的小面關節會向下滑動
    4. (D) 向右旋轉時，右邊的小面關節會向下滑動

    正解：(C)

  2. 2下列何種神經學症狀與頸椎神經根病變較無直接的相關性？

    1. (A) 出現硬膜徵候（dural sign）
    2. (B) 有感覺異常（paresthesias），感覺過敏（hyperesthesias）之表現
    3. (C) 深腱反射（deep tendon reflexes）降低
    4. (D) 主訴可能為上肢肌肉無力

    正解：(A)

  3. 3有關前位頭部（forward head posture）對顳頜關節所造成的影響，下列敘述何者正確？

    1. (A) 舌骨向下移位
    2. (B) 下頜骨向後及向下移位
    3. (C) 間盤（disc）向後位移
    4. (D) 舌骨下肌（infrahyoids）變短

    正解：(B)

  4. 4有關僵直性脊椎炎的臨床表徵與物理治療介入之敘述，下列何者正確？

    1. (A) 大於三個月的下背痛，活動會使疼痛加劇是診斷標準之一
    2. (B) 關節炎僅發生於中軸關節
    3. (C) 24週的McKenzie運動可能改善早期患者的疼痛、活動度與生活品質
    4. (D) 診斷標準包括X光檢查結果顯示單側2級薦髂關節炎

    正解：(C)

  5. 5一位65歲老先生主訴左邊肩胛內側疼痛，頭頸後仰以及向左轉時，肩胛處疼痛增加，低頭好一些，且手臂沒有疼痛現象，肩關節活動正常，則下列何者較有可能？

    2. (B) 胸椎關節病變
    3. (C) 提肩胛肌肌筋膜疼痛
    4. (D) 胸廓出口症候群

    正解：(A)

  6. 6一位病人主訴右側枕骨到頭頂疼痛，白天跟晚上睡覺時疼痛程度差不多，使用筆記型電腦一小時後會比較不舒服，休息不會比較好，右側枕骨下部位有壓痛點，頭部動作時覺得右邊受限，則下列何者較有可能？

    3. (C) 偏頭痛
    4. (D) 顳頜關節痛

    正解：(B)

  7. 7關於矯正前位頭部（forward head）姿勢的運動，下列何者較不恰當？

  8. 8比較正中神經和尺神經之神經動力學檢查，兩者在身體那個部位、關節的動作差異較大？

    2. (B) 肘關節
    3. (C) 腕關節

  9. 9下列有關鈎狀突（uncinate process）之敘述，何者錯誤？

    3. (C) 此結構是椎體退化的表徵
    4. (D) 與joint of Luschka有關

    正解：(C)

  10. 10有關頸部揮鞭式症候群（whiplash syndrome）的敘述，下列何者正確？

    1. (A) 需要強化胸鎖乳突肌，以恢復頸椎的前凸（lordosis）曲線
    2. (B) 慢性期可藉由有氧運動，來維持患者之活動力
    3. (C) 亞急性期仍不可執行肌肉牽張（stretching），以避免進一步組織傷害
    4. (D) 急性期應維持固定姿勢，減少關節活動，以加速組織癒合

    正解：(B)

  11. 11一位主訴背痛的45歲男子，身體檢查時，出現上半身向左方偏移（lateral shift to left），彎腰程度受限，且重複彎腰多次會讓背痛往右下肢方向漫延。軀幹後仰活動亦受限，重複後仰多次後，中央背痛還是明顯，但臀部及大腿後側的疼痛強度減低。此患者可採用下列那些治療？①矯正側偏（lateral shift correction） ②後伸原則的運動 ③前彎原則的運動

    2. (B) ①③
    3. (C) 僅②
    4. (D) 僅③

    正解：(A)

  12. 12有關腰椎深腱反射與相關神經節，下列何者正確？①跟腱反射與S1 ②內側膕旁肌反射與L4 ③外側膕旁肌與L5 ④脛後肌反射與S2

    2. (B) 僅④
    3. (C) ①③
    4. (D) ②④

  13. 13一名女性患者，主訴臀部、髂骨與薦骨區域之局部疼痛，早晨起床會有晨僵，咳嗽會誘發症狀，軀幹側彎和後仰動作正常，前彎些微受限，感覺功能正常，此患者最可能的問題為何？

    1. (A) 僵直性脊椎炎（ankylosing spondylitis）
    2. (B) 薦髂關節炎（sacroiliac arthritis）
    3. (C) L5～S1椎間盤向後大突出
    4. (D) 臀肌拉傷

    正解：(B)

  14. 14闊背肌、臀大肌、胸腰筋膜是屬於穩定腰椎、骨盆帶及髖關節的那一系統？

    1. (A) 前斜向系統（anterior oblique system）
    2. (B) 後表淺斜向系統（superficial posterior oblique system）
    3. (C) 深縱系統（deep longitudinal system）
    4. (D) 外側系統（lateral system）

    正解：(B)

  15. 15針對腰椎問題之屈曲傾向（flexion bias）的處理原則，下列何者較為正確？

    1. (A) 使用姿勢性牽引時，最好擺在向患側側彎或向健側旋轉
    2. (B) 患者舒緩之姿勢通常是髖屈曲、膝屈曲及腰屈曲
    3. (C) 症狀減輕後，依然應長時間使用背架，以保持腰椎穩定
    4. (D) 使用脊椎縱軸牽引時，脊椎應擺在向患側側彎及旋轉，產生最大的小面關節囊張力

    正解：(B)

  16. 16患者主訴昨日在浴室滑倒跌坐在地上後，出現下背及臀部疼痛，則理學檢查時，下列那些測試與此傷害最相關，可能出現陽性反應？①Thomas氏測試 ②Ober氏測試 ③Gillet氏測試 ④Patrick氏測試

    1. (A) ①②
    2. (B) ①③
    3. (C) ③④
    4. (D) ②④

    正解：(C)

  17. 1765歲男性背痛病人，主訴走路10分鐘後雙小腿會麻痛，檢查時軀幹後仰疼痛症狀增加，平躺時雙膝下墊枕頭可減少症狀，下列何者為最適合此病人之治療策略？

    1. (A) 小腿肌肉干擾波電療
    2. (B) 腰椎之淺層及深層肌肉訓練
    3. (C) McKenzie腰椎後伸運動
    4. (D) 持續臥床休息

    正解：(B)

  18. 18一位25歲患者抱怨右側下背痛，檢查時發現後仰比前彎痛，右側彎比左側彎痛，且後仰加右側彎的複合動作最痛。下列何者為最可能之問題？

    1. (A) 右側小面關節鎖住
    2. (B) 椎間盤向左後方突出
    3. (C) 右側後縱韌帶扭傷
    4. (D) 脊椎狹窄

    正解：(A)

  19. 19一位病患3天前打網球時突然背痛發作，症狀為下背局部疼痛，且腰椎向後伸時較為不舒服，但是坐著加上些許腰椎屈曲能夠立即舒緩症狀。此病患最可能有下列那個問題？

    1. (A) 腰椎間盤突出
    2. (B) 小面關節損傷
    3. (C) 薦髂關節不穩
    4. (D) 背部肌肉拉傷

    正解：(B)

  20. 20有關背痛病人的運動治療原則之敘述，下列何者錯誤？

    1. (A) 根據2004年Audrey之研究，給予下背痛病人符合改善症狀的特定方向運動，較一般性運動治療效果要好
    2. (B) 椎間盤術後運動治療的最佳開始時間是術後滿一個月，且建議從核心穩定運動開始，較不會產生椎間盤環狀纖維裂開後遺症
    3. (C) 側面支撐運動（side propping exercise）可在腰椎負荷較小的情形下，訓練腹橫肌
    4. (D) 腰椎穩定運動除了訓練多裂肌與腹橫肌外，腰方肌的訓練也很重要

    正解：(B)

  21. 21下列有關下背痛的臨床症狀與處置建議，何者最不恰當？

    1. (A) 下背痛發作3天的病人抱怨：「即使是躺著休息或晚上睡覺時都很痛苦」；則病人可能處於發炎期，此時應協助病人找到可以緩解症狀的姿勢
    2. (B) 慢性下背痛患者抱怨最近2週突然背痛加劇且影響睡眠。動作檢查中發現，任何姿勢與動作都無法改變疼痛的強度，此時應建議盡量臥床休息即可
    3. (C) 當病人說「站起來時，疼痛會先增加，但是當完全站直後，疼痛會減緩」，則有可能是韌帶失穩的問題，此時可建議核心穩定運動
    4. (D) 65歲的腰痛病人轉身拿東西時，會瞬間產生腰部僵痛（catching pain），需很緩慢地回到中立姿勢後才能緩解疼痛，可能是小面關節病變，此時可建議屈曲導向（flexion bias）的運動

    正解：(B)

  22. 22將仰躺患者兩側的髂前上棘（ASIS）由內向外推時，會產生何種效果？①將薦髂關節前方打開 ②將薦髂關節後方打開 ③增加前薦髂韌帶張力 ④增加後薦髂韌帶張力

    1. (A) ①③
    2. (B) ②④
    3. (C) ①④
    4. (D) ②③

    正解：(A)

  23. 23在薦髂關節的觸診中，下列何者出現時表示無名骨往前旋轉（innominate anterior rotation）？

    1. (A) 該側髂前上棘（ASIS）較對側低，該側髂後上棘（PSIS）較對側高
    2. (B) 該側髂前上棘（ASIS）較對側高，該側髂後上棘（PSIS）較對側低
    3. (C) 該側髂前上棘（ASIS）和髂後上棘（PSIS）都低於對側
    4. (D) 該側髂前上棘（ASIS）和髂後上棘（PSIS）都高於對側

    正解：(A)

  24. 24關於骨盆前傾（pelvic anterior tilt）及其常見代償性現象，下列何者錯誤？

    1. (A) 髖屈曲肌群緊縮

    3. (C) 距下關節呈現內翻姿勢
    4. (D) 膝關節過度伸直

    正解：(C)

  25. 25有關胸椎駝背類型的敘述，下列何者錯誤？

    1. (A) 骨骼生長失衡的疾病可能導致圓背（round back）的問題
    2. (B) 平背（flat back）的個案通常骨盆傾斜（pelvic inclination）的角度會減少
    3. (C) Dowager's hump通常與停經後婦女的骨質疏鬆無關
    4. (D) Hump back通常與胸椎椎體的楔形（wedging）結構有關

    正解：(C)

  26. 26有關遠端肱二頭肌斷裂（distal biceps tendon rupture）之相關敘述，下列何者錯誤？

    1. (A) 好發於男性
    2. (B) FOOSH（fall on the outstretched hand）常為受傷機制
    3. (C) 在急性期，肘窩會有明顯的水腫與瘀血（swelling and bruising）
    4. (D) 可以用hook test來確認

    正解：(B)

  27. 27接受胸大肌下肱二頭肌腱固定術（subpectoral biceps tenodesis）患者之術後物理治療介入，下列何者最不適當？

    1. (A) 開刀後兩週內即可執行有支持性的鐘擺運動（pendulum exercise）
    2. (B) 開刀後兩週內即可做主動的肘屈曲運動
    3. (C) 開刀兩週後即可開始溫和的肩外展（abduction）等長收縮訓練
    4. (D) 開刀四週後可以開始訓練肩旋轉肌群（rotator cuff）肌力

    正解：(B)

  28. 28有關棒球選手出現肩關節後內側夾擠（posterior internal impingement），下列敘述何者錯誤？

    1. (A) 常見於過肩投球的選手
    2. (B) 易發生於投球的加速期（acceleration）到減速期（deceleration）
    3. (C) 原因是肩旋轉肌群（rotator cuff）於後上方的肩盂（glenoid）產生夾擠現象
    4. (D) 把肩關節帶到外展90度，後伸20度，再做完全外轉動作時，患者會抱怨肩關節後側疼痛

    正解：(B)

  29. 29有關肩峰鎖骨關節（acromioclavicular joint）的敘述，下列何者錯誤？

    1. (A) 是一個平面的滑液關節（synovial joint）
    2. (B) 肩峰鎖骨韌帶（acromioclavicular ligament）控制此關節水平的活動
    3. (C) 喙突鎖骨韌帶（coracoclavicular ligament）控制此關節垂直的活動
    4. (D) 若發現階梯變形（step deformity），則表示僅肩峰鎖骨韌帶（acromioclavicular ligament）斷裂

    正解：(D)

  30. 30有關冰凍肩依不同應激性（irritability）與物理治療策略擬定之敘述，下列何者正確？

    1. (A) 高應激性期病人的主動關節活動度與被動關節活動度相似
    2. (B) 高應激性期病人應避免肌力訓練運動
    3. (C) 低應激性期的病人應給予低強度、短時間的關節活動運動
    4. (D) 高應激性期病人應以減輕疼痛為主、施予級數高的關節鬆動術

    正解：(B)

  31. 31肩關節置換術後物理治療的進程，下列排序何者為佳？①手肘、手腕與手部活動 ②開始肱二頭肌、肱三頭肌及肩胛穩定肌群的肌力訓練 ③肩外轉牽張運動 ④肩關節輔助性主動運動

    1. (A) ②③①④
    2. (B) ②④③①
    3. (C) ①④③②
    4. (D) ①④②③

    正解：(D)

  32. 32在舉手過程中，肩胛骨內側邊緣（medial border）有翻起的現象，下列何者最不相關？

    1. (A) 前鋸肌（serratus anterior）無力
    2. (B) 長胸神經（long thoracic nerve）損傷
    3. (C) 下斜方肌（lower trapezius）無力
    4. (D) 肩胛下神經（subscapular nerve）損傷

    正解：(D)

  33. 33患者在機車摔車意外中，右肩胛骨被拉向前突（protraction），右肩被拉扯往水平內收的位置（horizontaladduction），受傷後阻力測試顯示外展和外轉明顯無力，最可能是下列那條神經受傷？

    3. (C) 肩胛下神經（subscapular nerve）
    4. (D) 背肩胛神經（dorsal scapular nerve）

  34. 34關於運動員的盂肱關節內轉角度喪失（glenohumeral internal rotation deficiency, GIRD），下列何者錯誤？①在肩外展0度時於坐姿下測量，不需固定肩胛骨，以反應整體肩關節動作 ②與對側盂肱關節內轉相比，若某位個案出現內轉角度喪失40度，可視為有盂肱關節內轉角度喪失 ③盂肱關節內轉角度喪失，如未伴隨外轉角度增加，較容易發生肩部傷害 ④盂肱關節內轉角度喪失與前旋轉肌袖（anterior rotator cuff）過緊有關

    1. (A) ①③
    2. (B) ①④
    3. (C) ②③
    4. (D) ②④

    正解：(B)

  35. 35肩峰下夾擠症候群（subacrominal impingement syndrome）和後內側夾擠症候群（posterioral internalimpingement syndrome）皆是肩部損傷。下列何者最可能是兩者的相同處？

    1. (A) 最常發生在游泳選手
    2. (B) 旋轉肌肌腱的內側夾在肱骨頭和盂唇之間
    3. (C) 盂肱關節後關節囊過緊
    4. (D) 疼痛弧出現在肩外展60～120度

    3. (C) 患者新陳代謝率下降，體力不好容易累，給予運動計畫與執行時，要特別注意運動的強度與患者的生命徵象，以免發生意外
    4. (D) 患者體溫會較高，要注意環境的溫度與室內溫度控制，以提高其運動耐受力

    正解：(D)

  76. 76有關燒燙傷患者接受物理治療時機之敘述，下列何者正確？

    1. (A) 大面積燒傷患者，從住院第一天，物理治療師即應參與燒傷團隊的照護
    2. (B) 大面積燒傷合併吸入性嗆傷患者，通常需要等待兩週以上的時間，才可以開始
    3. (C) 植皮手術後，要等手術部位傷口完全癒合後，才可以開始
    4. (D) 要開始行走訓練前，需先確認病人下床活動傷口不再流血，才可以開始

    正解：(A)

  77. 77下列那一個淋巴系統的構造有平滑肌及瓣膜？

    1. (A) 微淋巴管
    2. (B) 前導淋巴管（precollector）
    3. (C) 淋巴管（collector）
    4. (D) 分水嶺上的吻合（anastomosis）

    正解：(C)

  78. 78有關截肢後的幻肢感（phantom limb sensation）之敘述，下列何者正確？

    1. (A) 常出現於已截肢段的遠端部位，肘上截肢的幻肢感最強
    2. (B) 常出現於已截肢段的遠端部位，膝下截肢的幻肢感最強
    3. (C) 常出現於已截肢段的中間部位，肘上截肢的幻肢感最強
    4. (D) 常出現於已截肢段的中間部位，膝下截肢的幻肢感最強

    正解：(A)

  79. 79有關截肢術後的殘肢傷口癒合，下列敘述何者錯誤？

    1. (A) 有抽菸習慣的病患比無抽菸習慣的病患增加傷口感染率
    2. (B) 患有心血管疾病的個案傷口癒合的速率會下降
    3. (C) 患有腎疾病的個案傷口癒合的速率不會下降
    4. (D) 臥床時適當的活動能提升傷口癒合的速率

    正解：(C)

  80. 80一單側膝上截肢（transfemoral amputation）患者使用義肢行走時，在步態站立期會出現義肢膝關節不穩定（instability of the prosthetic knee）的現象，與下列何者較無關？

    4. (D) 承筒的初始屈曲角度不足
