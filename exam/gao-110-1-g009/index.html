  1. 1政府為了實施所得重分配、促進資本形成等目的而課徵租稅，符合下列何種性質？

    1. (A) 租稅的收入性
    2. (B) 租稅的政策性
    3. (C) 租稅的報償性
    4. (D) 租稅的中立性

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 課稅目的若不只是取得財源，而是要引導經濟社會朝特定方向調整（所得重分配、促進資本形成），即屬租稅的政策性（誘導性）功能。

    ❌ (A) 收入性指單純為籌措政府經費而課稅。

    ❌ (C) 租稅具無償性，納稅人並未取得對等的個別報償。

    ❌ (D) 中立性要求課稅不干擾民間決策，與刻意重分配的目的正好相反。

    📚 出處：財政學－租稅的功能與性質。

  2. 2在供給無彈性的完全競爭市場中，政府對買方課徵貨物稅，則此貨物稅的經濟歸宿為何？

    1. (A) 完全由賣方負擔
    2. (B) 完全由買方負擔
    3. (C) 買、賣雙方各負擔一半
    4. (D) 買方負擔 2/3、賣方負擔 1/3

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 經濟歸宿由供需彈性決定，與名義上向誰課無關。供給完全無彈性時，賣方無法減產反應，價格全額下調，稅負完全由賣方承擔。

    ❌ (B) 買方所付價格不會上升，不負擔稅負。

    ❌ (C) 各半只發生在供需彈性相等時。

    ❌ (D) 2:1 的分擔須供給彈性為需求彈性的兩倍。

    📚 出處：財政學－租稅歸宿與供需彈性。

  3. 3對某完全競爭市場的商品課稅，且令 Ed 為該商品的未受補償之價格彈性，而 Es 為其供給的價格彈性。在下列何種情況下消費者的租稅負擔最小？

    1. (A) Ed = -2，Es = 1
    2. (B) Ed = 0，Es = 0.5
    3. (C) Ed = -0.5，Es = 0
    4. (D) Ed = -0.5，Es = 0.5

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 消費者負擔比例 = Es /(Es + |Ed|)。Es = 0 時比例為 0，消費者完全不負擔，租稅負擔最小。

    ❌ (A) 比例為 1/(1+2) = 1/3。

    ❌ (B) 需求完全無彈性，稅負完全由消費者承擔，負擔最大。

    ❌ (D) 比例為 0.5/(0.5+0.5) = 1/2。

    📚 出處：財政學－貨物稅的租稅歸宿公式。
