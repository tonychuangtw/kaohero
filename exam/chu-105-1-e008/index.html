初等考試　105 年 初等考試 社會工作大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列何者不是「中觀」（mezzo）層次的社會工作實施？

    3. (C) 同儕關係
    4. (D) 鄰里關係

    2. (B) 潛在勞動力（Potential Labor Force）
    3. (C) 邊際勞動力（Marginal Labor Force）
    4. (D) 非經濟活動人口（Economically Inactive Population）

    正解：(A)

    2. (B) 家庭結構多元化
    3. (C) 家庭功能逐漸縮小
    4. (D) 家庭支持網絡變薄弱

    正解：(A)
