  1. 1下列何種主要組織相容性複合體（MHC）表現在胎兒衍生的胎盤細胞（fetus-derived placental cells），可以抑制NK細胞對胎盤細胞的毒殺？

    1. (A) HLA-A
    2. (B) HLA-D
    3. (C) HLA-F
    4. (D) HLA-G

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 說明：HLA-G 是胎盤滋養層細胞高度表現的非古典 MHC class Ib 分子，能與 NK 細胞上的抑制性受體（ILT2/ILT4、KIR2DL4）結合，抑制 NK 細胞毒殺，是母胎免疫耐受的關鍵。

    ❌ (A) HLA-A 屬古典 MHC class I，表現於幾乎所有有核細胞，負責呈獻抗原給 CD8⁺ T 細胞，並非胎盤抑制 NK 的主要分子。

    ❌ (B) HLA-D 屬 MHC class II（HLA-DR/DQ/DP），主要表現於抗原呈獻細胞，胎盤滋養層不表現。

    ❌ (C) HLA-F 亦為非古典 MHC class Ib，但主要與 NK 細胞活化／免疫調節有關，抑制毒殺的角色不如 HLA-G 明確。

    📚 出處：Janeway's Immunobiology 母胎免疫耐受章節；Abbas Cellular and Molecular Immunology 非古典 MHC class I（HLA-G 與 NK 抑制）。

  2. 2下列有關T細胞受體下游的訊息傳遞，何者錯誤？

    1. (A) ZAP-70激酶能與T細胞受體ζ鏈已磷酸化的酪胺酸基結合
    2. (B) ZAP-70激酶乙醯化會使T細胞受體的細胞內訊號啟動
    3. (C) ZAP-70激酶聯合NFAT、AP-1及NF-κB三路徑的啟動而促進T細胞分裂
    4. (D) ZAP-70由Fyn或Lck作用而活化

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 說明：ZAP-70 是酪胺酸激酶，其活化依賴 Lck/Fyn 對 ITAM 的磷酸化及自身酪胺酸磷酸化，而非「乙醯化」；乙醯化並非 TCR 訊息啟動的機制，故此敘述錯誤。

    ❌ (A) ZAP-70 的 SH2 區域可與 TCR ζ 鏈 ITAM 上已磷酸化的酪胺酸結合，敘述正確。

    ❌ (C) ZAP-70 活化後可經 PLC-γ、Ras-MAPK 等路徑啟動 NFAT、AP-1 及 NF-κB，促進 T 細胞增生，敘述正確。

    ❌ (D) ZAP-70 由 Src 家族激酶 Fyn 或 Lck 磷酸化而活化，敘述正確。

    📚 出處：Janeway's Immunobiology T 細胞訊息傳遞章節；Abbas Cellular and Molecular Immunology TCR signaling（ZAP-70 磷酸化）。

  3. 3B細胞受體重鏈基因的VDJ重組，下列何種分子負責在V-D junction進行N-nucleotide addition？

    1. (A) TdT（terminal deoxyribonucleotidyl transferase）
    2. (B) RAG1/2
    3. (C) DNA-PKcs
    4. (D) GST（glutathion S-transferase）

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 說明：TdT（terminal deoxynucleotidyl transferase）可不依模板在 V-D、D-J 接合處隨機加入 N-nucleotide，增加重鏈 CDR3 多樣性，故此為正確答案。

    ❌ (B) RAG1/2 負責辨識 RSS 並切斷 DNA、執行 V(D)J 重組，不負責加入 N-nucleotide。

    ❌ (C) DNA-PKcs 屬非同源端接合（NHEJ）修復機制，連接斷端，不加入 N-nucleotide。

    ❌ (D) GST 為解毒酵素（glutathione S-transferase），與 V(D)J 重組無關。

    📚 出處：Janeway's Immunobiology B 細胞發育與 V(D)J 重組章節；Abbas 免疫球蛋白基因重組（TdT 與 N-nucleotide addition）。
