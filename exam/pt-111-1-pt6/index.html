物理治療師　111 年第一次 心肺疾病與小兒疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1圖為A、B、C三位受測者的吐氣體積－時間測試（Volume-Time Test）結果，下列敘述何者正確？

    1. (A) C受測者屬於慢性支氣管炎病人
    2. (B) A受測者屬於肺泡塌陷病人
    3. (C) B受測者屬於肺氣腫病人
    4. (D) C受測者屬於肺纖維化病人

    正解：(A)

  2. 2下列何者會使慢性阻塞性肺疾病患者產生高的通氣灌流比（V/Q）？

    1. (A) 肺泡通氣量與血液灌流量都增加
    2. (B) 氣體擴散能力和血液灌流量都減少
    3. (C) 肺泡可能有足量的通氣量，但血流通過肺微血管較少
    4. (D) 肺泡可能有正常血流灌注量通過，但通氣量卻減少

    正解：(C)

  3. 3有關癌症緩解期的運動建議，下列何者最正確？

    1. (A) 應接受最大運動測試以利強度訂定
    2. (B) 應每天進行阻力運動
    3. (C) 有氧運動強度可設在40%～60%心率儲備量
    4. (D) 多進行高衝擊運動以增加骨密度

    正解：(C)

  4. 4癌症患者在接受癌症治療後，若出現周邊神經異常的副作用，運動訓練項目的選擇以下列何者最合適？

    3. (C) 固定式腳踏車（stationary bike）
    4. (D) 滑步機（elliptical trainer）

    正解：(C)

  34. 34陳先生在5年前被診斷有高血壓，目前定期服藥且血壓控制良好。若陳先生要進行漸進式運動測試（gradedexercise testing），下列測試的注意事項何者適用於陳先生？
