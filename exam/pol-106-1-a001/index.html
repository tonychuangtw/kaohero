警察特考　106 年 二等考試 國文　考古題與詳解

本卷共 10 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（10 題，建議 30 分鐘）

  1. 1下列四副對聯：「旭日芝蘭秀，春風琴瑟和」、「笑指南山作頌，喜傾北海為樽」、「節如風竹清如柏，言可經綸行可師」、「紫閣祥雲物華天寶，朱軒瑞氣人傑地靈」。其性質依序當為：

    1. (A) 春聯、壽聯、喬遷聯、輓聯
    2. (B) 壽聯、春聯、輓聯、喬遷聯
    3. (C) 壽聯、結婚聯、喬遷聯、輓聯
    4. (D) 結婚聯、壽聯、輓聯、喬遷聯

    正解：(D)

  2. 2「欲不得干時，愛不得犯法，貴不得踰親，祿不得踰位。」下列選項最符合上文旨意者為：

    1. (A) 從政有經，而令行為上
    2. (B) 有法度者，不可巧以詐偽
    3. (C) 不別親疏，不殊貴賤，一斷於法
    4. (D) 一天下者，令於天下則行，禁焉則止

    正解：(C)

  3. 3「驕慢已習，方復制之，捶撻至死而無威，忿怒日隆而增怨，逮于成長，終為敗德。孔子云：『少成若天性，習慣如自然。』是也。」本文與下列何者，旨意最為接近？

    1. (A) 君子居必擇鄉，遊必就士，所以防邪辟而近中正也
    2. (B) 木受繩則直，金就礪則利，君子博學而日參省乎己，則知明而行無過矣
    3. (C) 與善人居，如入芝蘭之室，久而自芳也；與惡人居，如入鮑魚之肆，久而自臭也
    4. (D) 騏驥一躍，不能十步；駑馬十駕，功在不舍。鍥而舍之，朽木不折；鍥而不舍，金石可鏤

    正解：(C)

  4. 4勸貴人行樂易，勸富人行樂難。何也？財為行樂之資，然勢不宜多，多則反為累人之具。華封人祝帝堯富壽多男，堯曰：「富則多事。」華封人曰：「富而使人分之，何事之有？」由是觀之，財多不分，即以唐堯之聖，帝王之尊，猶不能免多事之累，況德非聖人而位非帝王者乎？本段文字的主旨是：

    1. (A) 富人宜散財，否則麻煩多
    2. (B) 財多當行樂，以免受災禍
    3. (C) 長壽和子孫，比財富重要
    4. (D) 修養聖德，才能安享快樂

    正解：(A)

  5. 5朱惺公〈瘞菊記〉云：「夫菊之知戀故土者，□也；酣戰風霜者，□也；不貪肥沃者，□也。有此三德，余迺迫其抱屈以死，不亦過乎！爰為收拾殘叢，掘土瘞之。題曰：君子花之塚。」文中三空格，根據文意判斷，依序應填入：

    1. (A) 忠／義／仁
    2. (B) 禮／義／讓
    3. (C) 信／勇／儉
    4. (D) 義／勇／廉

    正解：(D)

  6. 6杜甫雖然謳歌「」，他自己並不甘心做個「」的佳人。因為他既有「」的大願，也有「」的小願。人若沒有了願，就沒有了熱誠，也失去了生活的情趣，恐怕連山水田園之樂，都不能體會了。上文四個空缺處，下列選項排序正確的是：甲：致君堯舜上，再使風俗淳乙：在山泉水清，出山泉水濁丙：但願我與汝，終老不相離丁：天寒翠袖薄，日暮倚修竹

    1. (A) 甲乙丙丁
    2. (B) 乙丁甲丙
    3. (C) 丙甲丁乙
    4. (D) 丁丙乙甲

    正解：(B)

  7. 7「我去看歌劇，打開那演職員表，就更有意思了。除了所有工作人員，上面還常包括了後備演員的名字、照片和介紹。好像已經算準，原來的演員會生病似的。連帕華洛帝這樣偉大的歌唱家，在麥迪遜廣場演唱新曲子時，都帶著歌譜上場。歌譜放在眼前的架子上，他可以從頭到尾完全不看，卻不能不帶。」本文主旨和下列何者最接近？

    1. (A) 濟有深涉，深則厲，淺則揭
    2. (B) 樹成蔭而眾鳥息焉，醯酸而蚋聚焉
    3. (C) 迨天之未陰雨，徹彼桑土，綢繆牖戶
    4. (D) 歲不寒，無以知松柏；事不難，無以知君子

    正解：(C)

  8. 8「我自己在這些歲月中，又體驗過許多難忘的歡樂與哀愁，但是追尋那一段平淡細瑣的往事，總令我髣髴又回到年少的時光，許多與母親共度共享過的吉光片羽，便又陸續似真似幻地閃爍眼前。如此可親，如此溫馨，於溫馨可親之中，又似乎有一種令我心中隱然作痛的甚麼東西參與其間。」上文情境與下列何者最相近？

    1. (A) 依依夢裏無尋處
    2. (B) 當時祇道是尋常
    3. (C) 漸行漸遠漸無書
    4. (D) 明日黃花蝶也愁

    正解：(B)

  9. 9「聖人是非常單純的人：當他走路時，他走路；當他說話時，他說話；當他聽時，他不想；當他走路時，他不做白日夢；當他觸時，他不看；那很難辦到，那正是他為什麼是聖人的原因，那正是為什麼人生多苦的原因。」文中的聖人，最重要的特質是：

    1. (A) 純一寧定，當下即是
    2. (B) 按部就班，循序漸進
    3. (C) 能以簡馭繁，掌握要領
    4. (D) 腳踏實地，不好高騖遠

    正解：(A)

  10. 10承上題，對於人生多苦的原因，詮釋得最貼近的是：

    1. (A) 人生無常，朝聚夕散。世事滄桑，生住異滅
    2. (B) 每個人都不老實，以致大家都不按牌理出牌
    3. (C) 由於在恐懼中度日，使人們不由得自欺欺人
    4. (D) 由於妄想紛飛，才使得人們遭受無謂的痛苦

    正解：(D)
