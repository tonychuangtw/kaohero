初等考試　104 年 初等考試 教育學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列有關「精萃主義」（essentialism）的敘述，何者錯誤？

    1. (A) 力主「磨練」的重要性
    2. (B) 社會承續的文化資產比個人的生活經驗更為重要
    3. (C) 強調過往的經典名著應與當前的實際狀況建立關係
    4. (D) 教育不是生活的模仿，而是生活的預備

    正解：(D)

  2. 2下列那項策略屬於後設認知策略？

    1. (A) 監控策略
    2. (B) 組織策略
    3. (C) 精緻化策略
    4. (D) 複誦策略

    正解：(A)

  3. 3小狗看到主人時會搖尾巴。下列那種訓練方式，可以讓小狗聽到鈴聲時也會搖尾巴？

    1. (A) 主人與鈴聲同時出現
    2. (B) 鈴聲先出現，主人再出現
    3. (C) 主人先出現，再出現鈴聲
    4. (D) 主人先出現，離開後再出現鈴聲

    正解：(B)

  4. 4學校教科書的內容、評量的方式、學生的安置等均有利於原本擁有豐富文化資本的上層階段。此種說法是屬於那種理論的觀點？

    1. (A) 文化再製理論（cultural reproduction theory）
    2. (B) 依賴理論（dependency theory）
    3. (C) 俗民方法論（ethnomethodology）
    4. (D) 抗拒理論（resistance theory）

    正解：(A)

  5. 5「進步主義」（progressivism）主張教育活動應以何者為中心？

    1. (A) 學校
    2. (B) 教師
    3. (C) 學科
    4. (D) 學生

    正解：(D)

  6. 6以常識性知識為研究對象，主要在探討人們日常生活的態度與行為，特別是交談或對話的規則。請問這是採取那種理論觀點來研究教育？

    1. (A) 後現代主義（postmodernism）
    2. (B) 結構功能論（structural functionalism）
    3. (C) 符號互動論（symbolic interactionism）
    4. (D) 俗民方法論（ethnomethodology）

    正解：(D)

  7. 7近代探討社會階層化（social stratification）的理論相當多，主要仍受功能論與衝突論的影響。請問下列那項敘述正確？

    1. (A) 功能論認為擁有權力和利益的成員能夠位居社會的高階層
    2. (B) 衝突論主張社會階層化可分配成員至不同職位中以完成社會責任
    3. (C) 功能論認為社會階層化是因為社會分工所需
    4. (D) 衝突論主張職務功能的重要性和待遇高低有必然的關係

    正解：(C)

  8. 8小華友愛同學的理由，是因為他認為「己所不欲，勿施於人」，請問他屬於郭耳堡（L. Kohlberg）道德發展階段論的何階段？

    1. (A) 階段三
    2. (B) 階段四
    3. (C) 階段五
    4. (D) 階段六

    正解：(D)

  9. 9大明這次段考考不好，所以決定改變方法來準備下次考試。這表示大明具備下列那種能力？

    1. (A) 具有自動自發的能力
    2. (B) 具有後設認知的能力
    3. (C) 具有自我增強的能力
    4. (D) 具有具體運思的能力

    正解：(B)

  10. 10下列那一項敘述不是英國經驗主義大師洛克（J. Locke）的教育學說？

    1. (A) 數學是最有利於培養推理能力的學科
    2. (B) 倡導的理性教育分為智育、德育及美育等三方面
    3. (C) 將選擇教師與擇偶視為同等重要
    4. (D) 只有倔強與任性才是該體罰的對象

    正解：(B)

  11. 11學生在學校中學習社會價值規範及與人相處之道，這是屬於教育的何種社會功能？

    1. (A) 社會化
    2. (B) 選擇
    3. (C) 試探
    4. (D) 分化

    正解：(A)

  12. 12根據艾里克森（E. Erikson）的心理社會發展論，青少年時期所面臨的主要危機是：

    1. (A) 羞愧懷疑
    2. (B) 角色混淆
    3. (C) 缺乏安全感
    4. (D) 孤獨感

    正解：(B)

  13. 13阿慶在國中畢業之後，和他的父親一樣都從事水泥廠的搬運工，這種現象稱為：

    1. (A) 階級再製
    2. (B) 環境再製
    3. (C) 經濟再製
    4. (D) 文化再製

    正解：(A)

  14. 14下列何者不是科層組織結構之具體特徵？

    1. (A) 專業分工
    2. (B) 建立檔案紀錄
    3. (C) 不保障任期
    4. (D) 公正無私

    正解：(C)

  15. 15下列行為養成的歷程是屬於那一種學說？第一步驟：看到垃圾車來時，回家拿垃圾來倒第二步驟：先聽音樂，再看到垃圾車，然後回家拿垃圾出來倒第三步驟：只要聽到音樂，就回家拿垃圾出來倒

    1. (A) 古典制約學習（classical conditioning）
    2. (B) 操作制約學習（operate conditioning）
    3. (C) 嘗試錯誤學習（trial and error）
    4. (D) 觀察學習（observational learning）

    正解：(A)

  16. 16下列有關各國後期中等教育的敘述，何者錯誤？

    1. (A) 德國區分為不同功能與類型的學校，包括文理中學高級部，職業學校與二元制職業訓練
    2. (B) 法國採學區制，學校類型以普通中學為主，綜合中學為輔
    3. (C) 英國不採學區制，學校類型以綜合中學為主，其他類型為輔
    4. (D) 美國採學區制就近入學，學校類型以綜合中學為主，其他類型為輔

    正解：(B)

  17. 17組織中過度依表現升遷，造成有能力的人會升遷到一個無法勝任的職位為止，此種現象稱為：

    1. (A) 帕金森定律
    2. (B) 彼得原理
    3. (C) 形式主義
    4. (D) 寡頭定律

    正解：(B)

  18. 18下列何者不是社會系統理論（social system theory）的要點？

    1. (A) 組織是由制度與個人交互作用而成
    2. (B) 組織與環境關係密切，故需適應環境變遷
    3. (C) 最佳的領導方式需隨情境而易
    4. (D) 外在動機的激勵是系統成功的關鍵

    正解：(D)

  19. 19國中基本學力測驗是依據那一種理論而編製？

    1. (A) 相關原理
    2. (B) 訊息加工論
    3. (C) 潛在特質理論
    4. (D) 傳統測驗理論

    正解：(C)

  20. 20Hersey, P.與 Blanchard, K.H.所提出的領導情境理論，主張領導者的行為必須考量成員的「成熟度」（maturity），依不同的成員成熟度決定領導方式，下列有關此主張的敘述何者正確？

    1. (A) 成員成熟度低，宜採用高關懷、低工作取向
    2. (B) 成員成熟度中等，宜採用高關懷、高工作取向
    3. (C) 成員成熟度高，宜採用高關懷、高工作取向
    4. (D) 成員成熟度低，宜採用低關懷、低工作取向

    正解：(B)

  21. 21構成 1950 年代教育行政理論運動的主要哲學思想是：

    1. (A) 邏輯經驗主義（logical empiricism）
    2. (B) 主觀主義（subjectivism）
    3. (C) 新馬克斯主義（neo-Marxism）
    4. (D) 後現代主義（post-modernism）

    正解：(A)

  22. 22組織興革的策略有多種模式，其中「R-D-D-A 模式」指的是下列那一種歷程？

  23. 23下列那一個國家設置「磁石學校」、「特許學校」並採取發放教育券等措施，以增加學習選擇的多元性？

  24. 24下列那一種組織理論強調領導者應發揮領導引擎或動能的作用？

    3. (C) 有正面的，也有負面的

  30. 30下列何者是奧蘇貝爾（D. Aussbel）有意義學習（meaningful learning）的主要內涵？

    2. (B) 透過適當的教學設計，可以讓學生達成預期的效果
    3. (C) 應幫助學生發現知識的意義，並與原認知結構中的相關內容結合
    4. (D) 建立和諧的學習氣氛，可以提升學習的成效

  31. 31下列何者是講述法最主要的特性？

    4. (D) 學生容易分心，上課秩序不容易維持
