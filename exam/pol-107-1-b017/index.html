警察特考　107 年 三等考試 犯罪偵查　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1申請解除「警示帳戶」，應向何機關申請？

    1. (A) 金融機構
    2. (B) 金融監督管理委員會
    3. (C) 原通報單位
    4. (D) 法院或檢察署

    正解：(C)

  2. 2關於洗錢防制法所規定之「特定犯罪所得」，下列敍述何者錯誤？

    1. (A) 包括特定犯罪而取得之財物
    2. (B) 特定犯罪所得之認定，乃以其所犯特定犯罪經有罪判決為必要
    3. (C) 包括特定犯罪變得之財物
    4. (D) 包括特定犯罪而取得之財產上利益及其孳息

    正解：(B)

  3. 3依據民國 107 年 1 月 3 日修正「組織犯罪防制條例」規定，有關「組織犯罪」之敘述，下列何者錯誤？

    1. (A) 犯罪組織，不以現存者為必要
    2. (B) 犯罪組織，指三人以上，所組成具有持續性及牟利性之有結構性組織
    3. (C) 組織犯罪之被害人或證人於境外時，得利用聲音、影像傳真之科技設備為訊問、詰問
    4. (D) 於偵查或審判中對組織犯罪之被害人或證人為訊問、詰問或對質，得依聲請或依職權在法庭外為之

    正解：(B)

  4. 4刑案現場處理，有關「救護傷患」之敘述，下列何者錯誤？

    1. (A) 警察人員抵達現場後，應視現場狀況，探查是否有人受傷
    2. (B) 受傷者不論其為被害人或加害人，均應迅速予以救護或送醫，並視情形，作必要之保護或戒護
    3. (C) 救護傷患時，應儘量避免破壞現場痕跡，如確屬無法避免時，應為必要之記錄
    4. (D) 警察人員護送傷患就醫時，宜詢問案件發生之事實真相並記錄，傷患衣物，應速棄置處理

    正解：(D)

  5. 5刑案現場處理，有關「現場保全」之敘述，下列何者錯誤？

    1. (A) 實施封鎖時，應派員於封鎖線外警戒。非經現場指揮官同意，任何人不得進入，以免破壞現場跡證
    2. (B) 經許可進入現場者，應著帽套、手套、鞋套或其他裝備
    3. (C) 現場封鎖範圍應視現場環境及事實需要而定，原則以三道封鎖線為準，必要時得實施交通管制
    4. (D) 初期封鎖之範圍宜窄，以避免影響交通，待初步勘察後，視實際需要再行界定封鎖範圍

    正解：(D)

  6. 6為免跡證遭受風吹、雨淋、日曬等自然力所破壞，下列何者非屬初抵現場人員應有之作為？

    1. (A) 設法採取跡證
    2. (B) 使用帳蓬、雨棚或其他物品保全跡證
    3. (C) 為適當之記錄
    4. (D) 移至安全地點

    正解：(A)

  7. 7有關「強制處分與任意處分」之敘述，下列何者錯誤？

    1. (A) 偵查方式，可分為以強制處分進行偵查與任意偵查二類
    2. (B) 強制處分因侵害人民受憲法保障的基本權，須遵守法律保留原則
    3. (C) 任意偵查因未行使強制力，雖無法律明文，檢察官或司法警察亦可使用
    4. (D) 檢察官起訴後，這個階段的調查證據，仍得為強制偵查

    正解：(D)

  8. 8刑案現場無論是如何混亂，初抵現場員警應記住優先處理原則，依序為何？

    1. (A) 實施現場勘察、案情研判、提出偵查計畫等；再救護傷患、逮捕嫌犯、初步訪問（留置目擊證人）、現場保全
    2. (B) 救護傷患、逮捕嫌犯、初步訪問（留置目擊證人）、現場保全等；再實施現場勘察、案情研判、提出偵查計畫
    3. (C) 案情研判、提出偵查計畫、實施現場勘察、現場保全等；再初步訪問（留置目擊證人）、救護傷患、逮捕嫌犯
    4. (D) 救護傷患、實施現場勘察、案情研判、提出偵查計畫等；再逮捕嫌犯、初步訪問（留置目擊證人）、現場保全

    正解：(B)

  9. 9勘察組負責現場勘察、採證與記錄。下列何者非屬「勘察組」之主要任務？

    1. (A) 運用科學技術與方法勘察現場、蒐集證據，作為犯罪偵查或法庭偵審之證據
    2. (B) 研判犯罪嫌疑人進出路線、犯罪時間、方法、手段、工具、犯行、過程等，以明瞭犯罪事實
    3. (C) 採集各類跡證，並依其特性分別記錄、陰乾、冷藏、包裝、封緘，審慎正確處理，避免污染
    4. (D) 依案情需要，對於現場相關處所進行搜查，尋找可能遺留之各種跡證，發掘可能之線索

    正解：(D)

  10. 10下列何種證據的形成，不符合「路卡交換原理」的敘述？

    1. (A) 性侵犯身上有被害人毛髮
    2. (B) 車禍被害人身上有胎痕
    3. (C) 指認人描述嫌犯特徵及過程
    4. (D) 犯嫌鞋底表面沾附之灰塵

    正解：(C)

  11. 11有關「詢問」之敘述，下列何者正確？

    1. (A) 檢警因調查犯罪嫌疑人犯罪情形及蒐集證據之必要，得使用通知書，通知犯罪嫌疑人到場詢問
    2. (B) 經合法通知，無正當理由不到場者，得報請法官核發拘票
    3. (C) 詢問通知書，由司法警察機關主管長官簽名
    4. (D) 司法警察官或司法警察詢問犯罪嫌疑人，完全禁止於夜間行之

    正解：(C)

  12. 12下列有關「證人保護」之敘述，下列何者錯誤？

    1. (A) 證人有依證人保護法規定施以保護之必要者，應請證人書立切結書
    2. (B) 證人保護，僅法官能核發證人保護書，採絕對法官保留原則
    3. (C) 證人保護，時間急迫者，得先採取必要之保護措施，並於 7 日內陳報
    4. (D) 證人保護法規定之保護措施，應就個案狀況需要審慎選定之

    正解：(B)

  13. 13依海關執行毒品控制下交付作業要點規定，有關「控制下交付」之敘述，下列何者錯誤？

    1. (A) 為配合檢察或司法機關依毒品危害防制條例第 32 條之 1 規定偵辦跨國性毒品犯罪案件
    2. (B) 檢警應依據並檢附檢察官核發之偵查指揮書，通知海關配合辦理有關控制下交付作業
    3. (C) 專責單位對檢警完成控制下交付後之偵辦結果應予以追蹤，俾得為必要之處置
    4. (D) 各關接獲控制下交付案件，應即辦理密報登錄，並以密件處理

    正解：(B)

  14. 14依各級警察機關處理刑案逐級報告紀律規定，下列有關「重大刑案之通報時間起算點」之敘述，下列何者錯誤？

    1. (A) 受理他轄發生案件，應即時通報管轄機關並傳送相關資料，管轄機關應於接獲通報後 2 小時內填輸發生通報單
    2. (B) 破獲他轄未通報之案件，除應依單一窗口規定通報發生地轄區分局外，由破獲單位代填輸發破通報單
    3. (C) 刑案紀錄表應於案件發生及破獲後 24 小時內填輸，逾時依認定基準懲處
    4. (D) 經媒體報導社會矚目案件者，於發現犯罪或接獲報案後，應於案件發生 30 分鐘內，完成初報

    正解：(C)

  15. 15下列何種採取潛伏指紋之增顯技術處理法，通常用於非吸水性材質、光滑表面之物件，例如五金、塑膠等？

    3. (C) 硝酸銀法
    4. (D) 碘燻法

  17. 17下列何者為新北市政府警察局首創鑑識與犯罪情資整合「大數據」連結分析，作為追蹤查緝犯罪之偵查利器？

  20. 20中華電信的 IP 分為行動上網（中華電信 emome）及居家寬頻光纖網路（中華電信 HiNet）兩種形式，而 HiNet 所屬的 IP 網段是可以在投單系統中查調，但中華行動上網 emome 所屬的 IP 網段必須發文向中華電信查詢，下列何者非屬該 IP 之查詢依據？

    2. (B) 刑事訴訟法第 231 條第 2 項
    3. (C) 電信事業處理有關機關（構）查詢電信使用者資料實施辦法第 3 條
    4. (D) 通訊保障及監察法第 11 條之 1

    正解：(D)

  21. 21有關「執行電腦搜索應注意事項」之敘述，下列何者錯誤？

    1. (A) 電腦檔案之證據應當場列印，並請受搜索人簽名按指印
    2. (B) 搜索對象如為學校，應會同該校系主任或相當職務人員執行之
    3. (C) 勿安裝或拷貝任何程式、檔案至受搜索人的電腦中
    4. (D) 應讓受搜索人與電腦保持適當距離，避免受搜索人接觸電腦刪除檔案、證據

    正解：(B)

  22. 22依 106 年 11 月 14 日修正之「採驗尿液實施辦法」規定，有關「尿液採驗」之敘述，下列何者正確？

    1. (A) 尿液檢體應分別裝入二瓶尿液容器，每瓶尿液量須達 60 毫升，並由應受尿液採驗人按捺右大拇指指紋封緘
    2. (B) 應受尿液採驗人右大拇指無法按捺指紋時，應依左手大拇指、左食指等之順序捺印指紋，並由採尿人員附註該指名稱
    3. (C) 尿液檢體溫度未達攝氏 32 度或超過攝氏 38 度或內有浮懸物存在或顏色顯有異常者，應重新採尿
    4. (D) 尿液初驗應由管轄檢察官或法院決定之，複驗應送至衛生福利部認可之濫用藥物尿液檢驗機關（構）

    正解：(C)

  23. 23查獲疑似毒品製造工廠時，現場相關物質宜全部採集、秤重，並酌採多少公克（顆）送驗，不滿者，得全部送驗？

    2. (B) 10
    3. (C) 20

  24. 24有關「射擊殘跡證物之處理原則」之敘述，下列何者錯誤？

    1. (A) 採取射擊殘跡，應以黏有雙面碳膠之鋁（銅）座分別黏取不同部位，並分別標示其採證位置
    2. (B) 採取衣物之射擊殘跡，宜於案發後 12 小時內儘速採集未經清洗、血跡污染之最外層衣物表面殘跡
    3. (C) 採取手部射擊殘跡，宜於案發後 12 小時內儘速採集未經清洗、擦拭、救護之手部殘跡
    4. (D) 同案查獲槍彈證物，宜同時採取其彈殼內射擊殘跡備驗

    正解：(C)

  25. 25關於偵辦性侵害案，對犯罪嫌疑人施以身體檢查，下列敘述何者錯誤？

    1. (A) 司法警察對於拘提到案之犯罪嫌疑人，有相當理由認為唾液得作為犯罪之證據時，得採取其唾液
    2. (B) 司法警察因調查犯罪情形之必要，對於傳喚到案之犯罪嫌疑人，得違反其意思，予以照相
    3. (C) 鑑定人因鑑定之必要，得經檢察官之許可，採取犯罪嫌疑人之血液
    4. (D) 檢察事務官因蒐集證據之必要，對拘提到案之犯罪嫌疑人，得違反其意思，採取其指紋

    正解：(B)

  26. 26通訊保障及監察法修正施行後，對警察機關查察賄選，下列敘述何者錯誤？

    1. (A) 最輕本刑為 3 年以上有期徒刑之賄選罪類型，均得聲請通訊監察書
    2. (B) 查察賄選通訊監察書之聲請，應以單一監察對象為限，即以人為單位，一人一監聽票
    3. (C) 查察賄選同一偵查案號下，若數人犯罪即應聲請數張監聽票，一人犯數罪者，則仍為一張監聽票
    4. (D) 對於賄選案類，如有調取通信紀錄之必要時，應依規定向檢察官聲請調取票

    正解：(D)

  27. 27分局受理或接獲分駐所、派出所或其他單位轉報之特殊、重大刑案，除迅速通知偵查隊偵辦外，均應立即報告主管，並轉報那個單位列管？

  30. 30刑案分為重大刑案、特殊刑案及普通刑案，下列何者不是特殊刑案？

    1. (A) 深切影響社會治安、震撼社會人心之案件
    2. (B) 犯罪手段殘酷、情節離奇案件
    3. (C) 竊取槍械、軍火或國防上之重要設施、器材
    4. (D) 新發現之嚴重犯罪手法，必須迅速偵破，予以遏止之案件

  31. 31情報諮詢，下列敘述何者錯誤？

    1. (A) 遴選諮詢對象，以社會各階層、各行業熱心公益及樂於協助維護社會治安人士為原則
    2. (B) 凡經遴選諮詢工作請求合作之對象，應依規定列冊備查，發給證件，但不得給予任何名義
    3. (C) 交付諮詢對象任務，應謹慎保密，講求方法，並應以蒐集危害國家安全、社會犯罪偵防有關情報為要點，不得使其直接參與辦案行動
    4. (D) 諮詢人員提供情報線索，應詳核其動機、目的及可靠性，如因而及時防止治安事故，或偵破重大案件，應立即簽報，予以適當獎勵及支應必要費用

    正解：(B)

    正解：(C)

  33. 33關於勘察採證，下列敘述何者錯誤？

    1. (A) 重大刑案由管轄警察局偵查隊長或其他代理人擔任現場指揮官
    2. (B) 實施現場勘察，於必要時得依相關規定請求支援
    3. (C) 對於任何跡證或線索，均應縝密而為
    4. (D) 必要時，須重返現場數度勘察或重建

    正解：(A)

  34. 34重大刑案發生，除立即偵破外，均應訂定偵查計畫，下列何者非偵查計畫內容？

    1. (A) 犯罪人生活情形
    2. (B) 發現經過或受理報案經過
    3. (C) 偵查實施及分工
    4. (D) 協調聯繫

    正解：(A)

  35. 35偵查人員，如必須實施被害人、檢舉人或目擊證人指認犯罪嫌疑人，下列要領何者錯誤？

    1. (A) 指認前應由指認人先陳述犯罪嫌疑人之特徵
    2. (B) 被指認之數人在外形上不得有重大差異
    3. (C) 實施照片指認，得以單一相片提供指認，但避免提供老舊照片指認
    4. (D) 應為非一對一之成列指認（選擇式指認）

    正解：(C)

  36. 36為調查犯罪情形，通知證人之通知書應於應到時間幾小時前送達？

    1. (A) 12 小時
    2. (B) 24 小時
    3. (C) 36 小時
    4. (D) 48 小時

    正解：(B)

  37. 37刑案證物，子彈、彈頭證物之處理原則，下列敘述何者錯誤？

    1. (A) 以金屬器具直接夾取彈頭，宜以證物袋分別包裝，避免彼此碰撞
    2. (B) 現場子彈、彈頭採取前宜先記錄其原始狀態，並以適當方法採取
    3. (C) 現場彈頭應視個案情況留意其上可能之微物跡證
    4. (D) 若有供比對之同廠牌子彈，應準備 3 顆以上送驗

    正解：(A)

  38. 38筆錄不得竄改、挖補或留空行，下列敘述何者錯誤？

    1. (A) 如有增刪更改，應由製作人或受詢問人在其上蓋章或按指印
    2. (B) 其刪除處應留存原字跡，並應於眉欄處記明更改字數
    3. (C) 詢問犯罪嫌疑人筆錄之製作，應採一人詢問，另一人記錄之方式製作
    4. (D) 檢察官執行詢問、搜索、勘驗時，如無書記官在場，得指定在場執行公務之警察人員製作筆錄

    正解：(A)

  39. 39有關「告訴乃論之罪」之敘述，下列何者錯誤？

    1. (A) 告訴乃論之罪，如果要撤回告訴，應於第二審法院言詞辯論終結前撤回
    2. (B) 以告訴是否為訴訟要件，得將犯罪分為告訴乃論之罪與非告訴乃論之罪
    3. (C) 告訴乃論之罪，不僅是偵查發動的原因，亦是訴訟要件，如有欠缺即無法追訴、處罰
    4. (D) 告訴乃論之罪，如無得為告訴之人，檢察官得依職權指定代行告訴人

    正解：(A)

  40. 40有關拘提，下列敘述何者正確？

    1. (A) 拘提有公務員或軍人之犯罪嫌疑人，不必知照該管機關長官協助執行
    2. (B) 拘票有二聯，執行拘提時，應一聯交被拘提人或其家屬，另一聯交當地里長
    3. (C) 拘票得聲請數通，分交數人分別執行，並得於轄區外執行，不必會同當地警察單位
    4. (D) 偵查犯罪，如有在執行或在押中脫逃者，情況急迫，不及報告檢察官，得逕行拘提之

    正解：(D)

  41. 41司法警察人員執行搜索，下列敘述何者錯誤？

    1. (A) 有人居住或看守之住宅，或其他處所，不得於夜間入內搜索
    2. (B) 日間已開始搜索者，得繼續至夜間
    3. (C) 飲食店或其他於夜間公眾可出入之處所，仍在公開時間內者，夜間亦不得入內搜索
    4. (D) 常用為賭博、妨害性自主或妨害風化之行為者，得入內搜索

    正解：(C)

  42. 42搜索發現可為證據或得沒收之物，得扣押之，發現本案應扣押之物為搜索票所未記載者，亦得扣押之，惟應於執行扣押後多少時間內報告該管檢察官及法院？

    1. (A) 12 小時內
    2. (B) 1 日內
    3. (C) 2 日內
    4. (D) 3 日內

    正解：(D)

  43. 43關於警察機關偵查刑案，下列敘述何者正確？

    1. (A) 檢察官命令移送者，得將全案移送管轄法院或檢察署
    2. (B) 告訴乃論案件，經撤回告訴者，而告訴人已向檢察官告訴者，不必再函送管轄法院或檢察署
    3. (C) 證據證明力薄弱或行為事實是否構成犯罪顯有疑義者，得函送管轄法院或檢察署
    4. (D) 全案雖未調查完畢，但經依法提起自訴或向檢察官告訴者，得函送管轄法院或檢察署

    正解：(C)

  44. 44關於組織犯罪案件之處理，下列敘述何者錯誤？

    1. (A) 犯罪證物之蒐集，應注意公司企劃書、帳冊等物件，必要時並得協請會計專業人員支援解讀
    2. (B) 檢舉人身分資料，應予封存、並附入移送法院審理之文書
    3. (C) 證人或與其密切利害關係之人、檢舉人及被害人，應依證人保護法克盡保密與保護的責任
    4. (D) 偵辦涉及幫派組合成員或有組織犯罪模式之刑案時，應注意蒐證是否符合組織犯罪防制條例之要件

    正解：(B)

  45. 45刑案紀錄表應於受理刑案發生或破獲移送之時起，幾小時內填輸？

    1. (A) 12 小時
    2. (B) 24 小時
    3. (C) 36 小時
    4. (D) 48 小時

    正解：(D)

  46. 46生物跡證的保存原則，下列敘述何者錯誤？

    1. (A) 現場生物跡證，直接置於紙袋保存
    2. (B) 血液、尿液等液態證物，應冷藏保存
    3. (C) 肌肉、骨骼、人體組織等，宜冷凍保存
    4. (D) 上述跡證立即送鑑者，可冷藏暫存

    正解：(A)

  47. 47無被害者犯罪（Crime without victim）此類犯罪型態雖無明顯法益之侵害，但卻存有極大之非法交易市場，下列何者非屬無被害者犯罪？

    1. (A) 墮胎
    2. (B) 賭博
    3. (C) 賄選
    4. (D) 藥物濫用

    正解：(C)

  48. 48擄人勒贖案件中，犯罪的被害者對於加害者產生情感、同情加害者、認同加害者的某些觀點和想法，甚至反過來幫助加害者的一種情結，稱為：

    1. (A) 倫敦症候群
    2. (B) 斯德哥爾摩症候群
    3. (C) 煮蛙效應
    4. (D) 蝴蝶效應

    正解：(B)

  49. 49關於偵查守則，下列敘述何者錯誤？

    1. (A) 偵查刑案以現場為基礎，運用科學器材與方法
    2. (B) 自由、法治、科學、人權為偵查犯罪應遵守之原則
    3. (C) 偵查刑案，本於虛心求證之科學精神，切忌先入為主之主觀判斷
    4. (D) 執行偵查任務人員，如與犯罪嫌疑人、被害人或關係人具有親屬關係，應予迴避

    正解：(B)

  50. 50涉外案件之處理，下列敘述何者錯誤？

    1. (A) 警察偵查犯罪不得任意進入使領館人員之住宅。如認有必要進入者，應事先徵得當事人同意始得進入。進入後未經館長同意者，不得翻閱、借用或影印文件
    2. (B) 發現享有與外交人員相當待遇之外國人員之家屬涉有犯罪嫌疑者，應即陳報內政部警政署轉外交部核辦；同時逕行訊問、搜索等強制作為
    3. (C) 依法逮捕之一般外國人，於逮捕拘提、收容或羈押後，如當事人明示反對通知其本國駐華使領館或駐華機構者，可不必通知
    4. (D) 外國使領館僱用我國籍之職員，如有犯罪嫌疑者，依一般法定程序處理

    正解：(B)
