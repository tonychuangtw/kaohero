護理師　113 年第一次 產兒科護理學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關孕產婦死亡率之敘述，下列何者正確？

    1. (A) 係指一年內每十萬名活產中，於懷孕期間或懷孕終止42天內之婦女死亡數
    2. (B) 係指一年內每十萬名活產中，於第三妊娠期或懷孕終止7天內之婦女死亡數
    3. (C) 係指一年內每十萬名活產中，於第三妊娠期或懷孕終止30天內之婦女死亡數
    4. (D) 係指一年內每十萬名活產中，於懷孕期間或懷孕終止24小時內之婦女死亡數

    正解：(A)

  2. 2有關妊娠期血液檢查之敘述，下列何者正確？

    1. (A) 首次產檢需要篩檢人類免疫缺乏病毒
    2. (B) 第一妊娠期進行母體血液葡萄糖耐受篩檢
    3. (C) 第二妊娠期進行B群鏈球菌篩檢
    4. (D) 第三妊娠期進行德國麻疹抗體濃度價數篩檢

    正解：(A)

  3. 3王先生將成為準父親，有關王先生於配偶孕期之心理變化，下列何者最適當？

    1. (A) 第一孕期最常出現害怕生產的壓力
    2. (B) 第二孕期最擔憂是否能勝任成為父親的角色
    3. (C) 第一孕期常因胎動而感覺與胎兒連成一體
    4. (D) 第二孕期常會想像胎兒模樣及身為父親的形象

    正解：(D)

  4. 4王女士，32歲，妊娠8週，前一胎因21對染色體異常引產，詢問此次有關唐氏症篩檢之敘述，下列何者最合適？

    1. (A) 建議妊娠16～18週之間，可以接受絨毛膜穿刺，確定胎兒染色體是否正常
    2. (B) 建議妊娠11～12週之間，可以接受羊膜腔穿刺，確定胎兒染色體是否正常
    3. (C) 建議妊娠21～24週之間，可以進行母血唐氏症篩檢，確定胎兒染色體是否正常
    4. (D) 建議妊娠15～20週之間，可以接受頸部透明帶的檢測，確定胎兒染色體是否正常

    本題經考選部公告不計分。

  5. 5有關妊娠期的心臟血管系統生理變化，下列敘述何者錯誤？

    1. (A) 出現生理性白血球增多症，白血球數量可增加到15,000/mm3
    2. (B) 妊娠生理性貧血是因紅血球攜鐵蛋白的能力降低所致
    3. (C) 心輸出量增加30～50%，以供應子宮、胎盤需要血流
    4. (D) 血漿中白蛋白降低，使得水分易滯留在血管間隙形成水腫

    正解：(B)

  6. 6有關孕期的營養需求，下列敘述何者錯誤？

    1. (A) 於第三孕期多補充鐵劑
    2. (B) 整個孕期應多補充碘
    3. (C) 磷可參與早期的細胞分裂過程
    4. (D) 鈣質提供胎兒骨骼和牙齒的生長發育

    正解：(C)

  7. 7葉女士，28歲，G1P0，待產過程中突然自然破水，內診發現子宮頸口開8公分、變薄程度80%、先露部位+1。下列何者為最優先之護理處置？

    2. (B) 監測胎心率變化
    3. (C) 提供氧氣
    4. (D) 採平躺增加子宮血流

    正解：(B)

  8. 8陰道生產過程，下列何種情形表示先露部位胎頭已發生著冠（crowning）？

    1. (A) 當子宮收縮時，胎頭顱頂上出現一圈可見的壓痕
    2. (B) 當子宮收縮時，胎頭出現於陰道口，宮縮間歇時，胎頭縮回陰道內
    3. (C) 當子宮收縮時，陰道口膨出可見胎頭，大小呈卵圓形
    4. (D) 當宮縮間歇時，胎頭出現於陰道口且不會縮回陰道內

    正解：(D)

  9. 9有關分娩期預防產後出血的措施，下列何者不適當？

    1. (A) 待產婦在進入第二產程前，開始持續靜脈注射methylergometrine（Methergin）
    2. (B) 胎盤娩出後，檢查胎盤以確認胎盤完整娩出
    3. (C) 在新生兒及產婦狀況穩定下，協助親子立即肌膚接觸
    4. (D) 產後於恢復室觀察，每15分鐘監測產婦的血壓及出血量

    正解：(A)

  10. 10胎兒為頭產式，胎頭呈部分屈曲，其最可能以下列那條徑線通過產道？

    2. (B) 枕額徑（OF）
    3. (C) 枕頦徑（OM）
    4. (D) 頦下前囟徑（SMB）

    正解：(B)

  11. 11劉女士，G1P0，子宮頸開4公分，每3分鐘宮縮一次，無胎頭骨盆不對稱（CPD），使用硬脊膜外麻醉，持續2小時都未見胎頭下降，此時最優先之處置為何？

    2. (B) 評估胎頭大小
    3. (C) 給與ritodrine點滴注射，促進子宮收縮
    4. (D) 評估羊水量

    正解：(A)

  12. 12王女士，初產婦，陰道生產，採純母乳哺育，產後6週重返職場的一週後，主訴發燒38℃，右側乳房情況如圖所示，觸診溫熱且有痛感。最可能的診斷是？

    1. (A) 因為剛剛返回工作狀態，所以最可能是壓力性乳腺管阻塞（blocked ducts）
    2. (B) 因為幾乎整個乳房大面積發紅，所以最可能是乳房腫脹（engorgement）
    3. (C) 因為乳頭可見傷口，所以最可能是乳腺炎（mastitis）
    4. (D) 因為乳房3、4點鐘方向有水囊狀感，所以最可能是乳房膿瘍（breast abscess）

    正解：(C)

  13. 13蔡女士，初產婦，因產程遲滯而行剖腹生產，新生兒出生體重3,800公克。產婦計畫要完全哺餵母乳，擔心自己奶水不足，因為從生產至今已兩天，都沒有脹奶的感覺，而且新生兒幾乎是含著乳房入睡，放下來就哭。有關蔡女士對奶量的擔心，下列措施何者不適當？

    1. (A) 評估新生兒兩天的排尿及排便情況
    2. (B) 告訴產婦產程過長及剖腹生產都會延後脹奶出現的時間，這是正常的
    3. (C) 肯定產婦完全母乳哺育的決定，了解這兩天新生兒吃奶及含乳的情況
    4. (D) 了解產婦執行手擠乳的情況，討論增加手擠奶頻率的可行性

    正解：(B)

  14. 14何女士，G1P1，採陰道分娩，無任何產後合併症，產後4小時，觸診子宮底時發現位於臍上一指且偏右，下列何者為首要的護理措施？

    1. (A) 子宮按摩
    2. (B) 下床活動
    3. (C) 多喝開水
    4. (D) 如廁解尿

    正解：(D)

  15. 15有關產後婦女之情緒照顧，下列護理指導何者不適當？

    1. (A) 初產婦出現哭泣不安及缺乏育兒信心為產後憂鬱症，應儘速就醫
    2. (B) 在接受期（taking-in phase），鼓勵產婦陳述生產經驗，接受其感受，必要時可澄清其疑慮
    3. (C) 在緊執期（taking-hold phase），鼓勵參與及學習新生兒照護
    4. (D) 產婦即使進入放手期（letting-go phase），仍可能有不自覺的哀傷情緒

    正解：(A)

  16. 16婦女產後痛（after pain）主要是評估下列那一個器官或組織之健康問題？

  25. 25王女士罹患梅毒，王女士表示先生如果知道了，他會失去先生，不停掩面哭泣，下列護理措施何者最適當？

  26. 26小花因誤食鐵劑而送醫治療，指導小花媽媽之護理措施，下列敘述何者最適當？

  35. 35小敏妊娠週數26週出生，醫師診斷為壞死性腸炎（necrotizing enterocolitis, NEC），有關其護理照護及處置之敘述，下列何者最不適當？

    2. (B) 嬰兒應該仰睡且以枕頭抬高頭部
    3. (C) 嬰兒的枕頭旁擺放絨毛玩具以增加安全感
    4. (D) 嬰兒應該避免穿過多衣服或用衣物包覆頭部

    正解：(D)

  37. 37有關腮腺炎（mumps）最常見的合併症，下列敘述何者正確？

    1. (A) 無菌性腦膜炎
    2. (B) 肺炎
    3. (C) 熱性痙攣
    4. (D) 續發性皮膚感染

    正解：(A)

  38. 38陳小弟，5歲，罹患扁桃腺炎（tonsillitis），接受扁桃腺切除手術（tonsillectomy），下列術後護理何者正確？

    1. (A) 預防肺擴張不全，鼓勵深呼吸、用力咳嗽
    2. (B) 注意觀察是否有吞嚥或清喉嚨次數增加
    3. (C) 局部熱敷或提供熱食，促進傷口血液循環
    4. (D) 提供含維生素C飲料（如檸檬汁），促進傷口癒合

    正解：(B)

  39. 39有關嬰幼兒呼吸道特性的敘述，下列何者錯誤?

    1. (A) 耳咽管較短且水平，較易受感染
    2. (B) 舌頭在口腔的比例較大，感染後易出現阻塞
    3. (C) 嬰兒喉頭在頸部較高處，較易出現吸入性肺炎
    4. (D) 嬰幼兒胸腔順應性較成人低

    正解：(D)

  40. 40有關川崎氏症病童的治療及其目的，下列敘述何者正確？

    1. (A) 給與阿斯匹靈（aspirin），以促進血小板凝集
    2. (B) 給與免疫球蛋白（IVIG）可有效降低冠狀動脈瘤發生
    3. (C) 給與苯巴比特魯錠（phenobarbital）治療舞蹈症
    4. (D) 給與盤尼西林（penicillin）以預防發炎

    正解：(B)

  41. 41有關嬰幼兒缺鐵性貧血（iron deficiency anemia）之敘述，下列何者正確？

    1. (A) 屬體染色體隱性遺傳疾病
    2. (B) 常發生於6～24個月大的足月兒
    3. (C) 紅血球體積比正常紅血球大
    4. (D) 長期貧血可能導致心跳過慢之代償反應

    正解：(B)

  42. 42小華，6個月，罹患兒童癌症，目前接受化學治療且須治療半年以上，則小華可以接種下列何種疫苗？

    1. (A) 四合一疫苗（Tdap-IPV）
    2. (B) 水痘疫苗
    3. (C) 輪狀病毒疫苗
    4. (D) 麻疹腮腺炎德國麻疹混合疫苗

    正解：(A)

  43. 43小萍診斷為先天性甲狀腺功能低下症，有關血液檢驗值之敘述，下列何者正確？

    1. (A) 甲狀腺素T4高於正常值、甲狀腺刺激素TSH高於正常值
    2. (B) 甲狀腺素T4高於正常值、甲狀腺刺激素TSH低於正常值
    3. (C) 甲狀腺素T4低於正常值、甲狀腺刺激素TSH低於正常值
    4. (D) 甲狀腺素T4低於正常值、甲狀腺刺激素TSH高於正常值

    正解：(D)

  44. 44有關性早熟（precocious puberty）的敘述，下列何者正確？

    1. (A) 男孩在12歲以前、女孩在11歲以前出現第二性徵，即為性早熟
    2. (B) 血清中的LH、FSH、estrogen、testosterone皆正常
    3. (C) 中樞性性早熟可給與leuprolide acetate，以抑制促性腺激素釋放荷爾蒙（GnRH）的分泌
    4. (D) 可以腹部斷層掃描確認是否有中樞性性早熟

    正解：(C)

  45. 45膽道閉鎖（biliary atresia）是嬰兒先天性疾病之一，下列敘述何者錯誤？

    1. (A) 常出現灰白色的大便、暗茶色的尿液
    2. (B) 容易影響脂肪的消化吸收，導致水溶性維生素缺乏
    3. (C) 膽管炎是手術後常見的合併症之一
    4. (D) 提供不需要膽汁消化的中鏈脂肪酸配方奶、高蛋白牛奶為主

    正解：(B)

  46. 46小強罹患先天性巨結腸症（congential megacolon），有關照護和手術之護理指導敘述，下列何者正確？

    1. (A) 保守療法應採低渣、高熱量、高蛋白飲食
    2. (B) 手術前需採肥皂水進行腸道清潔灌腸
    3. (C) 術後若有造瘻口腫脹情形，則是異常現象，須立即通報醫師
    4. (D) 結腸造口的黏膜並無神經，且會比周圍皮膚低

    正解：(A)

  47. 47有關兒童急性腹瀉時，下列護理處置何者最適當？

    1. (A) 給與腸道吸附劑（kaolin-pectin），與食物一起服用
    2. (B) 以雞湯取代配方奶
    3. (C) 水分的補充可給與口服葡萄糖電解質水
    4. (D) 配方奶泡濃一些，減少水瀉的次數

    正解：(C)

  48. 48有關兒童腦神經疾病導致的顱內壓升高（IICP），若無適切介入措施，常會造成兒童生命危險，下列護理措施何者正確？

    1. (A) 可過度換氣讓動脈血中氧氣濃度（PaO2）維持在27～30 mmHg
    2. (B) 應維持病童房間光線明亮，避免病童因頭昏跌倒
    3. (C) 協助抬高床頭約30度，維持頭頸部自然平直
    4. (D) 若有痰液，教導常做深呼吸咳嗽，避免積痰而缺氧

    正解：(C)

  49. 49小英，6歲，罹患重症肌無力（myasthenia gravis），下列護理措施何者不適當？

    1. (A) 鼓勵加強費力的活動，有助改善肌肉力量
    2. (B) 若出現複視情形，需預防跌倒
    3. (C) 觀察是否有呼吸困難或痰液不易咳出情形
    4. (D) 眼瞼下垂是最早出現的症狀

    正解：(A)

  50. 50有關熱性痙攣（febrile convulsion）的敘述，下列何者最不適當？

    1. (A) 發燒介於37～38℃之間，且出現單側性的全身性僵直
    2. (B) 為引起幼兒抽筋或痙攣最常見的原因之一
    3. (C) 發燒是誘發因素，其基礎疾病為感染性病原，如上呼吸道感染
    4. (D) 發作時，若出現牙關緊閉，不可強行將兒童嘴巴打開

    正解：(A)
