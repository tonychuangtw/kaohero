    1. (A) Skype
    2. (B) e-mail
    3. (C) Facebook
    4. (D) Microsoft Access

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) Microsoft Access 為單機的資料庫管理軟體，本身不具傳送檔案給指定對象的通訊功能。

    ❌ (A) Skype 可直接傳送檔案給聯絡人。

    ❌ (B) 電子郵件可夾帶附件傳送。

    ❌ (C) Facebook 的訊息功能可傳送檔案。

  3. 3以下關於資料庫視域（View）及表格（Table）的敍述，何者錯誤？

    1. (A) 表格（Table）是實體資料存放的形式，視域（View）則是使用者依需求定義的虛擬觀察資料窗口
    2. (B) 視域（View）是記錄其定義時的資料查詢結果，並不會隨著其基底表格（Table）內容資料改變而變化
    3. (C) 使用 SQL 語法時，視域（View）及表格（Table）是分別用指令 Create View 及 Create Table 來建立
    4. (D) 刪除表格（Table）時，定義於該表格之視域（View）也同時會被刪除

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 視域為虛擬表格，查詢時才動態取得資料，會隨基底表格內容改變而變化，故本項錯誤。

    ❌ (A) 表格存放實體資料，視域為虛擬的觀察窗口。

    ❌ (C) 兩者分別以 CREATE VIEW 與 CREATE TABLE 建立。

    ❌ (D) 基底表格被刪除時，其上的視域亦失效。
