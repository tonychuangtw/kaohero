警察特考　108 年 三等考試 消防警察情境實務　考古題與詳解

本卷共 20 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（20 題，建議 60 分鐘）

  1. 1就一般居室空間之 A 類火災而言，依火災發展時序，判斷各探測器發出警報之訊息由快至慢排序為下列何者？

    1. (A) 火焰式探測器、差動式探測器、偵煙式探測器
    2. (B) 偵煙式探測器、火焰式探測器、差動式探測器
    3. (C) 差動式探測器、偵煙式探測器、火焰式探測器
    4. (D) 差動式探測器、火焰式探測器、偵煙式探測器

    正解：(B)

  2. 2建築物之防火措施分為主動式防火措施及被動式防火措施，下列何者為主動式防火措施？

    1. (A) 出入口、走廊、樓梯之設置位置
    2. (B) 防火區劃
    3. (C) 內部裝修限制
    4. (D) 滅火設備

    正解：(D)

  3. 3某消防分隊長轄內列管之高層建築物，其總樓地板面積為 6 萬 3 千 5 百平方公尺，依各類場所消防安全設備設置標準之規定，其應設置之消防專用蓄水池有效水量至少應有多少立方公尺以上？

    1. (A) 100
    2. (B) 120
    3. (C) 140
    4. (D) 180

    正解：(B)

  4. 4你為消防分隊長，轄內某一建物內設有 250 m2 之電信機械室，且未設任何自動滅火設備，該機械室平時無人，在考量火災發生後之清理復原問題後，你會建議該場所設置下列何種設備？

    1. (A) 水霧
    2. (B) 泡沫
    3. (C) 二氧化碳
    4. (D) 乾粉

    正解：(C)

  5. 5某日 8 時於某公路隧道內，發生車輛追撞車禍引起火災，你所屬分隊接獲派遣出勤，並指派你擔任初期指揮官。你抵達現場發現出入口已有些許煙竄出，必須立即指揮消防人員進入隧道內執行人命救助及滅火任務。下列搶救作為何者錯誤？

    1. (A) 消防人員（含駕駛）皆需穿著完整消防衣裝備並配戴空氣呼吸器，確認無誤後方可進入隧道救災，並隨時檢視自身空氣瓶量具有能及時返回安全處所之存量
    2. (B) 掌握「順向排煙、順向搶救」原則，避免兩側射水而產生互撞，並要求上風處之單位避免進入隧道內
    3. (C) 成立人員裝備管制站，以掌握進入隧道人數與空氣瓶使用情形，俾即時提供協助
    4. (D) 消防人員應部署 2 組水線分別以直線及噴霧射水相互掩護前進，並隨時注意周遭隧道結構是否有崩塌（含混凝土爆裂及掉落）、路面柏油軟（熔）化及閃燃（flashover）等危險現象發生

    正解：(B)

  6. 6根據消防機關辦理消防安全檢查注意事項，若你為轄區消防分隊長，對於下列危險物品場所或人員，實施檢查或訪視之期程，下列何者錯誤？

    1. (A) 某未達管制量之爆竹煙火販賣場所，每半年至少檢查一次
    2. (B) 某選舉候選人之辦事處，於選舉活動期間，每周至少訪視一次
    3. (C) 某燃氣熱水器承裝業於取得證書起，每半年至少檢查一次
    4. (D) 某液化石油氣製造、儲存及處理場所，每月至少檢查一次

    正解：(A)

  7. 7若你抽查某大樓之火警自動警報設備時，發現下列幾個現象，你應針對那一項要求改善之？

    1. (A) 受信總機前方有 1.5 公尺的淨空
    2. (B) 光電式局限型 2 種探測器之動作時間為 45 秒
    3. (C) 火焰式探測器之動作時間為 40 秒
    4. (D) 定溫式局限型 1 種探測器之動作時間為 45 秒

    正解：(C)

  8. 8總樓地板面積 1000 平方公尺老人社會福利機構，提報自衛消防編組演練及驗證計畫，消防機關受理審查，有關界限時間計算發現有誤，下列何者不是該老人社會福利機構計算延長時間之條件？

    1. (A) 樓地板面積 ×（天花板高度-1.8 公尺）≧200 立方公尺
    2. (B) 初期滅火使用室內消防栓
    3. (C) 寢具類使用防焰製品
    4. (D) 形成各居室不燃化區劃

    正解：(A)

  9. 9你為轄區分隊長，轄內某棟四樓建築，每層樓地板面積為 200 平方公尺，一樓為餐廳、二樓為商場、三樓為補習班、四樓為超市，你會要求那一場所實施防火管理？

    1. (A) 餐廳
    2. (B) 商場
    3. (C) 補習班
    4. (D) 超市

    正解：(C)

  10. 10某化學工廠於夜間發生火災，你為第一梯次到達現場之消防分隊長，若初期無法找到廠區人員，在現場狀況不明下，下列指揮作為何者最不適當？

    1. (A) 要求救災車輛與廠區先保持適當安全距離
    2. (B) 立即派員深入起火廠房內部確認有無人員受困
    3. (C) 留意有無奇怪的聲音或味道
    4. (D) 請求業者到場，協助確認致災物

    正解：(B)

  11. 11某建築物火災現場，指揮官指派搜索小組入室搜救，依規定該搜索小組入室搜索前應登錄管制之資訊，下列何者最不適當？

    1. (A) 姓名
    2. (B) 人數
    3. (C) 年齡
    4. (D) 氣瓶壓力

    正解：(C)

  12. 12某消防分隊長於帶隊搶救一地下室火災時，發現可能有瓦斯滯留狀況，下列該分隊長的救災戰力部署行動，何者最不適當？

    1. (A) 入室部署瞄子時，命令隊員以柱子、水泥牆作為掩護
    2. (B) 若為單支瓦斯鋼瓶噴出火焰時，命令隊員迅速射水滅火、防止延燒
    3. (C) 命令隊員，避免於地下室出入口附近部署水線
    4. (D) 於燃燒瓦斯滅火、止漏後，命令隊員使用檢測儀器，再次確認現場瓦斯濃度

    正解：(B)

  13. 13地下室火警經查證曾有工人施工惟現場無關係人可供確認，梯間已可發現有煙霧逸出情形，若你為現場指揮官，下列敘述何者適當？①可經由乙種搶救圖評估整體環境 ②以滅火攻擊為最優先處置 ③以人員搜救為最優先處置 ④以排煙為最優先處置 ⑤以防止垂直延燒為最優先處置⑥預先考慮退路及所需時間

    1. (A) ②③⑥
    2. (B) ①④⑤
    3. (C) ②④⑤
    4. (D) ①③⑥

    正解：(D)

  14. 14某市發生火災，於火場搶救完畢後，火災原因調查鑑定書中的「火災出動觀察紀錄」，依規定應由何單位填寫製作？

    1. (A) 消防分隊
    2. (B) 消防大隊
    3. (C) 消防局火災調查科
    4. (D) 消防局指揮中心

    正解：(A)

  15. 15鐵製品受熱容易生銹，某一火場發現金屬鐵筒上半部受燒生銹，雖然金屬鐵筒之成分對其生銹之程度會有一些不同，若你為現場火災調查人員，研判此種情形下，該金屬鐵筒至少在受熱多少℃以上時其表面就會急激有氧化物成長？

    1. (A) 500℃
    2. (B) 600℃
    3. (C) 700℃
    4. (D) 800℃

    正解：(B)

  16. 16金屬受熱會產生變色、變形與熔解，但不同的金屬其熔點不同，若你為現場火災調查人員，現場有錫、銀、鋅、鋁，何者之熔點最高？

    1. (A) 錫
    2. (B) 銀
    3. (C) 鋅
    4. (D) 鋁

    正解：(B)

  17. 17照片是某一火場所拍，若你為現場火災調查人員，研判火流之方向，下列何者最適當？（照片標示之「裡」是指距攝影鏡頭較遠處，「外」是指距攝影鏡頭較近處。）裡左 右外

    1. (A) 由左邊往右邊
    2. (B) 由右邊往左邊
    3. (C) 由裡面往外面
    4. (D) 由外面往裡面

    正解：(C)

  18. 18照片是某一場火災中所拍之牆壁鋁窗受燒之痕跡，若你為現場火災調查人員，研判火流之延燒路徑為何？

    1. (A) 從右上往左下延燒
    2. (B) 從右下往左上延燒
    3. (C) 從左上往右下延燒
    4. (D) 從左下往右上延燒

    正解：(B)

  19. 19你利用氣相層析質譜法分析同仁從火場採集的跡證，分析結果發現其中含有中質石油分餾液（medium petroleum distillate，MPD），下列何種化學成分是你判斷跡證中質石油分餾液應該出現的標的化合物（target compound）？

    1. (A) 二氫化茚（Indane）
    2. (B) 正己基環己烷（n-Hexylcyclohexane）
    3. (C) 乙基萘（Ethylnaphthalenes）
    4. (D) 1,3-二甲基萘（1,3-Dimeyhylnaphthalene）

    正解：(B)

  20. 20轄內某建築物發生火災後，你為火災調查人員，奉派至火場進行勘察及相關人等之訪談，下列何者非為詢問初期協助搶救人員的項目內容？

    1. (A) 燃燒位置初期火災狀況及燃燒何物
    2. (B) 搶救情形
    3. (C) 抽菸習慣與菸蒂如何處理
    4. (D) 有無發現易燃物或可疑人物在場等可疑跡象

    正解：(C)
