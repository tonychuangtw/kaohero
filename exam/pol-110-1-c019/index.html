警察特考　110 年 四等考試 火災學概要　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1熱傳導係數是材料導熱能力重要的影響因素之一，有關熱傳導係數，下列敘述何者正確？

    1. (A) 固體物質比液體具有較高熱傳導係數
    2. (B) 氣體比液體具有較高熱傳導係數
    3. (C) 熱傳導係數愈大，物質傳熱速度愈慢
    4. (D) 金屬材料熱傳導係數比非金屬材料熱傳導係數小

    正解：(A)

  2. 2海龍滅火藥劑主要的滅火原理，係控制下列何種燃燒要素？

    1. (A) 可燃物
    2. (B) 氧氣
    3. (C) 連鎖反應
    4. (D) 熱能

    正解：(C)

  3. 3燃燒產生的高溫氣體向上浮起，為下列何種力造成的？

    1. (A) 重力
    2. (B) 庫倫力
    3. (C) 表面張力
    4. (D) 強作用力

    正解：(A)

  4. 4建築物發生火災時，煙的流動方向，主要受到下列何種因素的影響？

    1. (A) 濃度
    2. (B) 亮度
    3. (C) 可視度
    4. (D) 壓力

    正解：(D)

  5. 5有關高樓防火避難安全設計原則，下列敘述何者錯誤？

    1. (A) 內部裝潢儘量不燃化
    2. (B) 足夠的結構耐火性能
    3. (C) 適當的防火區劃
    4. (D) 「單一方向避難原則」的逃生設計

    正解：(D)

  6. 6有關粉塵爆炸，下列敘述何者正確？

    1. (A) 粉塵爆炸係發生於粒子內部之燃燒反應
    2. (B) 浮游粉塵含水分超過一定程度時，爆炸威力會降低
    3. (C) 粉塵爆炸可如氣體般均勻濃度分布
    4. (D) 浮游粉塵，粒徑愈小，發火溫度愈高

    正解：(B)

  7. 7有關硫化氫（H2S）之性質，下列敘述何者錯誤？

    1. (A) 具毒性
    2. (B) 具可燃性
    3. (C) 密度同甲烷，易自然散失
    4. (D) 易產生靜電火花引火

    正解：(C)

  8. 8下列何種材料之熱傳導係數最低？

    1. (A) 銅
    2. (B) 岩棉
    3. (C) 混凝土
    4. (D) 低碳鋼

    正解：(B)

  9. 9有關固體表面與流體間之熱量傳遞，可依牛頓熱對流公式估算，其中自然對流的熱對流係數（W/（m2·K））範圍為：

    1. (A) 10-500
    2. (B) 100-1,000
    3. (C) 5-25
    4. (D) 0.1-1

    正解：(C)

  10. 10高溫物體與低溫物體之間，無媒介物質，熱直接傳至對方之現象稱為：

    1. (A) 熱輻射
    2. (B) 熱對流
    3. (C) 熱傳導
    4. (D) 熱反應

    正解：(A)

  11. 11物體溫度為 227℃，輻射率為 0.1，其輻射強度約為：

    1. (A) 0.015 KW/m2
    2. (B) 15 KW/m2
    3. (C) 0.354 KW/m2
    4. (D) 354 KW/m2

    正解：(C)

  12. 12某烷類氣體燃燒時與理論氧氣量的體積比為 1：2，該氣體的燃燒下限約為多少？

    1. (A) 18.3%
    2. (B) 9.5%
    3. (C) 5.2%
    4. (D) 0.052%

    正解：(C)

  13. 13有關有焰燃燒，下列敘述何者正確？

    1. (A) 分解燃燒與蒸發燃燒不屬於有焰燃燒
    2. (B) 火焰係發生於氣相燃燒區
    3. (C) 僅發生於可燃性氣體
    4. (D) 僅發生於可燃性液體

    正解：(B)

  14. 14有關混合燃燒與擴散燃燒的一般特性，下列敘述何者正確？

    1. (A) 混合燃燒的燃燒速度比擴散燃燒慢
    2. (B) 室內火災引燃天花板煙氣所致之閃燃現象，可視為混合燃燒型態
    3. (C) 蠟燭燃燒為混合燃燒
    4. (D) 瓦斯漏氣燃燒後起火爆炸為擴散燃燒

    正解：(B)

  15. 15下列那一個易燃性氣體之燃燒範圍，其危險性相對較高？

    1. (A) 10%~60%
    2. (B) 6.0%~75%
    3. (C) 16%~50%
    4. (D) 8%~70%

    正解：(B)

  16. 16下列何種物質的特性，有較高的可燃性傾向？

    1. (A) 較高的熱傳導係數（thermal conductivity）
    2. (B) 較低的比熱（specific heat capacity）
    3. (C) 較高的密度（density）
    4. (D) 較高的熱慣性（thermal inertia）

    正解：(B)

  17. 17室內發生閃燃（Flashover）或複燃（Backdraft）時，下列敘述何者正確？

    1. (A) 閃燃觸發主因是氧氣
    2. (B) 複燃引發的關鍵機制是輻射熱
    3. (C) 閃燃一般發生於火災衰退期
    4. (D) 複燃發生前一般處於悶燒狀態

    正解：(D)

  18. 18可燃性物質置於室內燃燒時，可發生閃燃，置於室外燃燒時則否；造成此種差異現象，與下列何者關聯性較高？

    1. (A) 兩者火勢大小之差異
    2. (B) 兩者燃燒速率高低之差異
    3. (C) 兩者火焰是否產生熱輻射
    4. (D) 兩者是否產生輻射能回饋效應

    正解：(D)

  19. 19當非導體之帶電物體，接近接地體時，除帶電物體與接地體之間發生放電外，幾乎同一時間，沿著非導體表面發生如樹枝狀發光之放電，此現象稱為：

    1. (A) 火花放電
    2. (B) 條狀放電
    3. (C) 電暈放電
    4. (D) 沿面放電

    正解：(D)

  20. 20不易累積靜電之導體，係指體積電阻係數（Ω cm）為多少以下之物質？

    1. (A) 1015
    2. (B) 1013
    3. (C) 1011
    4. (D) 109

    正解：(D)

  21. 21影響自然發火之因素，下列敘述何者正確？

    1. (A) 熱傳導度愈大，愈容易傳導熱，愈易起火
    2. (B) 氣體熱傳導度大於液體及固體，故愈易引起燃燒
    3. (C) 同一物質，粉狀蓄熱條件較整塊為佳，故較易起火
    4. (D) 物質含大量水分時，熱傳導度小，故易蓄熱起火

    正解：(C)

  22. 22有關乙炔及其容器之危險性，下列敘述何者錯誤？

    1. (A) 乙炔之分解爆炸，壓力越高，最小點火能量越小
    2. (B) 高壓情況下，乙炔易生聚合反應，升溫發熱，促使分解爆炸
    3. (C) 當乙炔噴出時，丙酮粒子亦一併噴出而發生靜電，其電荷可達 10,000 V 以上
    4. (D) 界限壓力隨容器管徑增加而上升

    正解：(D)

  23. 23有關家用天然氣事故之處置方式，下列敘述何者錯誤？

    1. (A) 關閉天然氣開關
    2. (B) 熄滅附近火源
    3. (C) 迅速打開門窗，使室內空氣流通
    4. (D) 立即關閉電氣開關並拔除電源

    正解：(D)

  24. 24下列無外力加工之事故現象，何者非屬蒸氣爆炸？

    1. (A) 鍋爐破裂
    2. (B) 原油槽之沸溢（Boilover）
    3. (C) 鹽槽爆炸
    4. (D) 天然氣管線外洩爆炸

    正解：(D)

  25. 25爆炸對於消防救災產生潛在之危害，下列敘述何者正確？

    1. (A) 依能量大小分為爆燃及爆轟
    2. (B) 火焰面和衝擊波發展成同一波，稱為爆轟
    3. (C) 氣體燃燒形成之爆炸主要是指擴散燃燒
    4. (D) 爆燃對於人體及周遭物體造成之影響大於爆轟

    正解：(B)
