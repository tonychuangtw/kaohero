營養師　106 年第二次 公共衛生營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1我國每日飲食指南手冊中定義「高鈣豆製品」，是每 7 公克蛋白質鈣質含量至少大於多少毫克之豆製品？

    1. (A) 25
    2. (B) 50
    3. (C) 75
    4. (D) 100

    正解：(C)

  2. 2國人膳食營養素參考攝取量（DRIs）的各項數值中，下列那些數值會高於健康人群的營養素平均需要量？①EAR（estimated average requirement） ②UL（tolerable upper intake levels） ③AI（adequate intakes）④RDA（recommended dietary allowances）

    1. (A) ①②
    2. (B) ①③
    3. (C) ②④
    4. (D) ③④

    正解：(C)

  3. 3關於第七版 DRIs 中對各年齡層蛋白質建議量，下列敘述何者錯誤？

    1. (A) 每單位體重所需蛋白質，以新生兒需求量最高
    2. (B) 1 歲以下嬰兒每公斤體重約 2.1～2.3 公克
    3. (C) 7 歲以後蛋白質的建議量，依性別而有所不同
    4. (D) 青春期（13～18 歲）蛋白質建議量最高，19 歲以後建議量降低

    正解：(C)

  4. 4根據衛生福利部的素食飲食指標建議，每天適度日曬時間為多少分鐘？

    1. (A) 10
    2. (B) 20
    3. (C) 30
    4. (D) 50

    正解：(B)

  5. 5代謝症候群與下列那種慢性疾病相關性最高？

    1. (A) 癌症
    2. (B) 痛風
    3. (C) 糖尿病
    4. (D) 骨質疏鬆頁次： 4－2

    正解：(C)

  6. 6衛生福利部制定「每日飲食指南」之工作是屬於渥太華健康促進五大行動綱領中的那一項？

    1. (A) 建立健康的公共政策
    2. (B) 創造支持性的環境
    3. (C) 重新定位健康服務
    4. (D) 強化社區行動力

    正解：(A)

  7. 7對於嬰兒副食品的添加，下列何者說明與建議錯誤？

    1. (A) 嬰兒在滿 3 個月後要注意鐵質的補充
    2. (B) 應優先給予較不易引起過敏的食品，建議由穀物開始添加
    3. (C) 食用嬰兒配方食品之嬰兒，可於 4～6 個月開始嘗試添加副食品
    4. (D) 每次只添加一種新的副食品，由少量開始，每 1～2 日更換新副食品

    正解：(D)

  8. 8國人下列何種癌症的標準化死亡率呈現下降的趨勢？

    1. (A) 口腔癌
    2. (B) 前列腺（攝護腺）癌
    3. (C) 女性乳房癌
    4. (D) 子宮頸癌

    正解：(D)

  9. 9「學校午餐內容及營養基準」中有關學校午餐菜單設計之規定，下列何者正確？

    1. (A) 主菜選用滷、烤雞腿、豬排等大塊肉，符合學生喜好
    2. (B) 全榖根莖類宜多樣化，增加多種穀類、澱粉蔬菜（芋頭、地瓜）與替代品（甜不辣、米血糕）等食材
    3. (C) 若提供甜品時，以綠豆薏仁湯、紅豆湯、豆花、布丁、稀釋發酵乳為宜，但供應頻率 1 週不超過 1 次
    4. (D) 午餐提供的熱量標準，採「國人膳食營養素參考攝取量」中男、女性，稍低與適度活動度平均值的 2/5

    正解：(D)

  10. 10下列何者不符合國民中小學之「校園飲品及點心販售範圍」？

    1. (A) 100%濃縮還原果汁
    2. (B) 全脂保久乳
    3. (C) 無糖綠茶
    4. (D) 茶葉蛋

    正解：(C)

  11. 11下列何者不屬於衛生福利部「2020 健康國民白皮書」五大飲食目標的人口百分比？

    1. (A) 增加飲食均衡多樣
    2. (B) 增加用好油、少加糖、鹽減量的健康飲食習慣
    3. (C) 減少反式脂肪攝取
    4. (D) 增加含鈣豐富食物每日至少兩份

    正解：(C)

  12. 12下列何項法規，規範辦理特定業務應聘用營養師並訂有人力基準？

    1. (A) 優生保健法
    2. (B) 營養師法及施行細則
    3. (C) 學校衛生法及施行細則
    4. (D) 老人福利法及施行細則

    正解：(C)

  13. 13營養師未能依據每六年提出完成繼續教育證明文件辦理執照更新，仍繼續執業者，請問最高罰鍰為何？

    1. (A) 5 萬元
    2. (B) 3 萬元
    3. (C) 1 萬元
    4. (D) 5 千元

    正解：(A)

  14. 14依據專門職業及技術人員高等考試營養師考試實習認定基準，下列何種餐盒廠家或中央餐廚工廠不符合膳食管理實習場所認定標準？

    1. (A) 經 CAS 優良食品標誌認證
    2. (B) 取得衛生主管機構 HACCP 制度認可
    3. (C) 每餐供餐一千份，每週供餐五天以上，衛生優良審查通過
    4. (D) 聘有餐飲技術士三名以上，及具教學資歷之專職營養師一名以上

    正解：(C)

  15. 15有關迷你營養評估（Mini Nutritional Assessment, MNA）的敍述，下列何者錯誤？

    1. (A) 適用於評估社區及機構中老人的營養狀況
    2. (B) MNA 在使用上可以有兩種格式：MNA-SF（short form）或 full form
    3. (C) MNA-SF（short form）共 6 題，用於營養篩檢
    4. (D) 使用時須要收集空腹血液及尿液

    正解：(D)

  16. 16對於心臟血管健康，血液中脂蛋白-膽固醇濃度，下列那一個是最重要的監控指標？

    1. (A) HDL
    2. (B) IDL
    3. (C) LDL
    4. (D) VLDL頁次：4－3

    正解：(C)

  17. 17對於社區中老人的營養狀況評估何者最為優先？

    1. (A) 核對飲食攝取及消耗情形
    2. (B) 了解目前體重及經常體重
    3. (C) 監控體脂肪變化及蛋白質攝取量
    4. (D) 進行 24 小時飲食回憶問卷及參考建議量

    正解：(B)

  18. 18下列何者最適合用來評估食物頻率問卷（food frequency questionnaire）的效度？

    1. (A) 飲食記錄法（food record）
    2. (B) 食物平衡表（food balance sheet）
    3. (C) 24 小時飲食回憶法（24-hour recall method）
    4. (D) 家戶盤存法（household inventory method）

    正解：(A)

  19. 19使用 24 小時飲食回憶法評估個人營養攝取，在考慮收集天數時，下列何者非主要影響因素？

    1. (A) 受試者的教育程度
    2. (B) 受試者樣本數的大小
    3. (C) 欲研究的營養素種類
    4. (D) 受試者飲食的變異性程度

    正解：(A)

  20. 20安養中心的男性住民，月亮臉、明顯水腫、髮質改變且易被拔起，血清白蛋白和免疫反應皆下降的現象，可能是下列何種問題？

    1. (A) Dermatitis
    2. (B) Marasmus
    3. (C) Kwashiorkor
    4. (D) Marasmic Kwashiorkor

    正解：(C)

  21. 21下列那一個症狀不是缺乏維生素 D 所引起的？

    2. (B) 串珠肋骨
    3. (C) 骨膜出血
    4. (D) 頭骨前囟門密合慢

    正解：(C)

  22. 225 歲女童，其 BMI 值高於同齡女童的肥胖標準，身高位於 50 百分位，無智力遲緩與特殊臉形體態，依據「兒童與青少年肥胖定義及處理原則」，應如何處理？

    1. (A) 隔年再評估
    2. (B) 控制體重不再上升
    3. (C) 須立即轉介小兒科醫師
    4. (D) 必須立即執行減重計畫

    正解：(B)

  23. 23下列有關問卷編製的步驟，何者為正確順序？①預試 ②修訂問卷 ③專家審查 ④編擬問卷題目

    1. (A) ④①③②
    2. (B) ④③①②
    3. (C) ①④②③
    4. (D) ③④②①

    正解：(B)

  24. 24進行試題分析時，公式〔（高分組答對某題的人數）＋（低分組答對某題的人數）〕÷〔（高分組的人數）＋（低分組的人數）〕，為計算下列何種指數？

  25. 25跨理論模式（TTM）中幫助行為改變的過程共十種，若營養師建議糖尿病個案「在冰箱上張貼營養衛教單張提醒自己注意飲食選擇」，是屬於運用下列那一種策略？

  26. 2635 歲林小姐（BMI=27）預計在半年結婚，因此到營養諮詢中心請求營養師協助減重，以下那一項最不適合其現階段需求？

    1. (A) 討論平日飲食內容

  27. 27下列認知（cognitive）學習領域之思考層級，由低至高之順序為何？①評價（evaluation） ②分析（analysis）③整合（synthesis） ④應用（application）

    1. (A) ①②③④
    2. (B) ③②①④
    3. (C) ④②③①

    正解：(C)

  28. 28進行營養教育時，有關教學目標的撰寫，下列敘述何者錯誤？

    1. (A) 以學習者為主體
    2. (B) 每個目標應包含多項學習結果
    3. (C) 明確並有具體的觀察或評量標準

    正解：(B)

  29. 29鼓勵癌症個案說出他接受化療之後對於進食的感覺，下列何種諮商技巧較不適合？

    1. (A) 反映
    2. (B) 指示
    3. (C) 解釋
    4. (D) 聆聽

    正解：(B)

  30. 30某醫院進行高鈣飲食營養講座，同時提供免費的骨質疏鬆症評估。王奶奶雖想參加，但衡量參與此活動要花一個早上的時間，還要搭 45 分鐘的公車，所以決定放棄。王奶奶的評估是屬於社會行銷 4P 中的那一項？

    1. (A) 產品（product）
    2. (B) 價格（price）
    3. (C) 推廣（promotion）
    4. (D) 通路（place）

  31. 31社區民眾經由健康促進系列活動，透過學習、參與、合作等過程，獲得解決社區問題的能力，此一現象比較符合社區營造的那一項概念？
