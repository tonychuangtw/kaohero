醫事檢驗師　112 年第一次 臨床生理學與病理學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何種狀況較不會導致心電圖之 QRS 寬度大於 0.12 秒？

    1. (A) 右束支傳導阻斷（right bundle branch block, RBBB）
    2. (B) 左前分支傳導阻斷（left anterior hemiblock, LAHB）
    3. (C) 心室早期收縮（ventricular premature contraction）
    4. (D) WPW 症候群

    正解：(B)

  2. 2下列何者不是急性心肌梗塞可能的心電圖變化？

    1. (A) AV block
    2. (B) ST 段上升
    3. (C) ST 段下降
    4. (D) P 波延長

    正解：(D)

  3. 3下列心電圖的判讀何者錯誤？

    1. (A) 有竇性心律不整
    2. (B) 有心室早期收縮
    3. (C) 有心房早期收縮
    4. (D) 心跳速率不規則

    正解：(C)

  4. 4心電圖在常規記錄速度下，寬幅為 30 個大格的心電圖中有 8 個 QRS 波，則心跳速率最接近每分鐘幾下？

    1. (A) 60
    2. (B) 112
    3. (C) 96
    4. (D) 88

    正解：(D)

  5. 5下列何者不是心房擴大之心電圖變化？

    1. (A) 右心房擴大時，P 波的持續時間不變
    2. (B) 右心房擴大時，P 波的振幅在下壁導極大於 2.5 mm
    3. (C) 左心房擴大時，心軸可能會右移
    4. (D) 左心房擴大時，P 波持續時間會變長

    正解：(C)

  6. 6下列何種疾病或情形最不可能單以心電圖判讀診斷？

    1. (A) 病人裝置永久性心臟節律器
    2. (B) WPW 症候群
    3. (C) 心臟衰竭
    4. (D) 急性心包膜炎

    正解：(C)

  7. 7下列何者是低血鉀症（hypokalemia）最可能的心電圖變化？

    1. (A) 高而尖的 T 波
    2. (B) QRS 波變寬
    3. (C) ST segment 上升
    4. (D) 出現 U 波

    正解：(D)

  8. 8第二度房室傳導阻斷（AV block）心電圖中出現 4 個 P 波與 3 個 QRS 波，PR 區間依序為 0.12 秒，0.16 秒，0.2秒。此心電圖最可能的診斷為何？

    1. (A) Mobitz 第一型第二度房室傳導阻斷 4：3
    2. (B) Mobitz 第一型第二度房室傳導阻斷 4：1
    3. (C) Mobitz 第二型第二度房室傳導阻斷 4：3
    4. (D) Mobitz 第二型第二度房室傳導阻斷 4：1

    正解：(A)

  9. 9下列心電圖最不可能是何種診斷？

    1. (A) 急性下壁心肌梗塞
    2. (B) 右冠狀動脈發生病變的機會比左冠狀動脈大
    3. (C) 心包膜炎
    4. (D) 心室逃漏性心律（ventricular escape rhythm）

    正解：(D)

  10. 10心房顫動（atrial fibrillation）之心電圖變化為何？

    1. (A) 心房速率 140～250/min，但不規則
    2. (B) 心房速率 140～250/min，非常規則
    3. (C) 心房速率 250～350/min，心室速率規則
    4. (D) 心房速率超過 350/min，心室速率不規則

    正解：(D)

  11. 11正常心電圖，胸導（chest leads）之 QRS 波群，過渡帶（transitional zone）出現在下列何電極導？

    1. (A) V1～V2
    2. (B) V3～V4
    3. (C) V5～V6
    4. (D) V1R～V2R

    正解：(B)

  12. 12成人的神經受傷造成肌肉失去神經支配，大約需經多久時間肌電圖檢查會出現肌纖維震顫電位（fibrillationpotentials）？

  13. 13有關腦波節律的敘述，下列何者錯誤？

    2. (B) 腦幹的上升性網狀賦活系統（ascending reticular activating system）功能減弱時，大腦皮質的神經細胞更容易產生同步的電位活性
    3. (C) 腦幹的上升性網狀賦活系統（ascending reticular activating system）可增強視丘的節律性
    4. (D) 視丘（thalamus）與腦幹的上升性網狀賦活系統（ascending reticular activating system）均可調節腦波節律

    正解：(C)

  14. 14腦波於出生後會隨著年齡而發展，下列敘述何者最不適當？

    4. (D) 三個月大的嬰兒，其睡眠圖譜以動態睡眠為主

    正解：(C)

  20. 20正常成年人的腦波中，較強的α波通常位於：

  22. 22患者因呼吸困難至急診就診，進行血液氣體分析檢查，下列操作何者正確？

    2. (B) 因血管很細不好抽血，直接在頸動脈抽血較易找到血管，而且也相對安全
    3. (C) 送檢的採血管應加入抗凝劑如肝素（heparin）密封、冰浴並快速送檢
    4. (D) 若有延遲送檢會影響分析結果，故採血管在 37°C 保存下，應在 2 小時內完成檢驗

    4. (D) 糖尿病控制不佳的患者，可因酮酸中毒（ketoacidosis）或高滲透壓造成意識不清
