物理治療師　115 年第二次 神經疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1在中風患者動作控制中，那一項姿勢控制異常最可能與反應性平衡控制的受損有關？

    1. (A) 在進行跨越障礙物時，無法準確調整步行速度與抬腳高度
    2. (B) 在靜態站立時，無法維持重心於支撐底面積內，導致姿勢不穩定
    3. (C) 在平坦地面行走時，步伐長度與步頻明顯降低，導致行走速度減慢
    4. (D) 在面對突發性姿勢干擾時，無法進行即時的透過代償跨步恢復平衡

    正解：(D)

  2. 2下列何者不是小腦病變常見的動作控制問題？

    1. (A) 不規則的動作軌跡
    2. (B) 意向性震顫
    3. (C) 僵直
    4. (D) 低肌肉張力

    正解：(C)

  3. 3關於兩點區辨（two-point discrimination）檢查，下列敘述何者錯誤？

    1. (A) 可檢測結合皮質感覺（combined cortical sensation）
    2. (B) 正常指尖測試結果約在 6 公釐以下
    3. (C) 兩點區辨與慢速適應的感覺受器較相關
    4. (D) 若出現異常，與大腦頂葉受損有關

    正解：(C)

  4. 4對於紅繩懸吊運動的敘述，下列何者錯誤？

    1. (A) 透過懸吊系統分擔病患體重，可降低治療師輔助時的負荷
    2. (B) 僅能執行開鍊運動，無法執行閉鎖鍊運動
    3. (C) 可以讓病患擺位在放鬆及舒適的姿勢下做運動
    4. (D) 可作為初步功能觀察或動作控制評估之輔助

    正解：(B)

  5. 5關於使用修正版艾許沃斯氏量表（modified Ashworth scale）與塔爾迪氏量表（Tardieu scale）進行肌張力評估，下列敘述何者最為適當？

    1. (A) 修正版艾許沃斯氏量表主要用來評估患者肌肉痙攣程度，塔爾迪氏量表主要用來評估患者肌張力過低程度
    2. (B) 以塔爾迪氏量表評估時，患者的肢體須主動動作
    3. (C) 修正版艾許沃斯氏量表不可用來區分肌肉內在剛性增加，或神經性牽拉反射過強造成的阻力增加
    4. (D) 在有關節攣縮情況的患者，修正版艾許沃斯氏量表有最佳的肌張力評估精準度

    正解：(C)

  6. 6關於中風個案之肌力評估常用的肌力評估指數（motricity index），下列敘述何者正確？

    1. (A) 滿分 100，最低分是 0，在坐姿下即可施測
    2. (B) 僅評估患側上下肢近端之大肌群
    3. (C) 上肢與下肢有不同加權分數
    4. (D) 僅適合急性期個案使用

    正解：(A)

  7. 7根據布朗斯壯分期，患側能夠執行何種動作代表手部運動功能復原較佳？

    1. (A) 拇指獨立動作
    2. (B) 手指整體抓握
    3. (C) 拇指側握食指
    4. (D) 球狀抓握

    正解：(A)

  8. 8下列那一治療學派的手法屬於神經誘發療法（neurofacilitation approaches）？

    1. (A) 玻巴斯學派（Bobath approach）
    2. (B) 動作再學習學派（motor relearning program）
    3. (C) 任務導向學派（task-oriented approach）
    4. (D) 肌肉再教育學派（muscle reeducation approach）

    正解：(A)

  9. 9根據任務導向模式評估原則，下列那一個敘述最不符合其概念？

    1. (A) 應評估個案在執行功能性動作時所採用的動作策略
    2. (B) 應了解個案機能損傷狀況
    3. (C) 任務導向模式評估主要針對個人及任務兩個層面進行分析，環境不是評估重點
    4. (D) 任務導向模式評估有助擬定個案的治療目標與治療計畫

    正解：(C)

  10. 10讓中風患者一天中的 16 小時皆使用患側手來執行日常生活活動，這種訓練方式比較貼近下列那個臨床治療模式及其相對應之理論基礎？

    1. (A) 本體感覺神經肌肉誘發模式－解剖學理論
    2. (B) 任務導向模式－系統理論
    3. (C) 本體感覺神經肌肉誘發模式－反射鏈理論
    4. (D) 任務導向模式－肌肉再教育理論

    正解：(B)

  11. 11依據圖中裝置的臨床應用，下列何者最可能為治療目標？

    1. (A) 增加肩膀與手肘動作的主動控制能力與協調性
    2. (B) 降低肩關節感覺敏感度以減輕疼痛反應
    3. (C) 培養患者對手部形狀與觸覺的辨識能力
    4. (D) 進行上肢被動牽拉以改善被動關節活動度

    正解：(A)

  12. 12使用功能性電刺激來改善腦中風病患垂足的問題時，最常刺激的肌肉群為何？其臨床使用目的為何？

    1. (A) 刺激脛前肌與腓骨長肌，協助踝關節背屈以改善擺動期的足尖拖地問題
    2. (B) 刺激腓骨長肌，協助產生足外翻以改善著地期的足內翻問題
    3. (C) 刺激股二頭肌與脛後肌，以減少膝關節在著地期的過度伸直
    4. (D) 刺激脛前肌與腓骨長肌，協助踝關節背屈肌離心收縮以利腳掌著地

    正解：(A)

  13. 13單側中大腦動脈出血或阻塞，最有可能出現何種症狀？

    1. (A) 對側肢體感覺喪失
    2. (B) 步態失用（gait apraxia）
    3. (C) 對側偏癱且下肢較上肢嚴重
    4. (D) 雙顳側偏盲（bitemporal hemianopia）

    正解：(A)

  14. 14評估個案認知能力時，若詢問個案「紅茶和咖啡都是飲品，那麼『桌子 』和『椅子』的共同之處是什麼？」，所測驗的是認知功能中的那一個面向？

    1. (A) 判斷力（judgement）
    2. (B) 定向感（orientation）
    3. (C) 抽象思考（abstract thinking）
    4. (D) 工作記憶（working memory）

    正解：(C)

  15. 15下列那一節損傷的個案應不會出現逆行呼吸（paradoxical breathing）現象？①C4 ②C7 ③T1 ④T10

    2. (B) 僅②③④
    3. (C) 僅③④

  16. 16關於脊髓損傷患者輪椅的選擇，何者適合 C6 完全性脊髓損傷患者？

    1. (A) 一定要配置輪椅仰躺或傾倒功能才能協助坐姿減壓
    2. (B) 手動輪椅可以配置梅花輪（pegged pushrim）來協助推行
    3. (C) 手動低背競速型輪椅，較容易達到孤輪（wheelie）等控制
    4. (D) 用吹吸進行非比例型控制電動輪椅，效率較高

    正解：(B)

  17. 17一位 40 歲男性因車禍造成頸部骨折傷害，後續轉至物理治療部門進行評估與治療，經評估該患者左側上下肢之肌力為 5 分，但溫痛覺喪失；右側上下肢肌力為 0 分，但溫痛覺正常，該患者最有可能是下列何種脊髓損傷？

    2. (B) 後髓症候群
    3. (C) 中髓症候群
    4. (D) 布朗－斯夸症候群

    正解：(D)

  18. 18關於脊髓損傷後發生自主神經反射異常之敘述，下列何者錯誤？

    1. (A) 經常發生在脊髓損傷部位高於 T6 以上之患者

    4. (D) 常由於脊髓損傷部位以下之不正常刺激，引發交感神經的過度興奮

    正解：(B)

  19. 19林小姐，28 歲，因車禍導致輕微創傷性腦傷，目前能獨立在家中及社區內行走，但當同時交談或尋找物品時，經常會暫停或明顯減慢步行速度，下列那一項治療最能改善此問題？

    1. (A) 安排逐步提高速度與時間的跑步機訓練
    2. (B) 在跑步機行走訓練時，同時大聲朗讀或回憶資訊
    3. (C) 進行站姿平衡能力訓練，如站立於軟墊或會晃動的平衡板上
    4. (D) 著重高強度的下肢肌力與步行速度訓練

    正解：(B)

  20. 20關於進行性上眼神經核麻痺症（progressive supranuclear palsy）症狀之敘述，下列何者正確？

    1. (A) 患者在疾病初期即會影響眼球動作，尤其左右方向的動作受限比上下方向更顯著
    2. (B) 患者會有明顯的軀幹僵硬症狀，於疾病早期就很容易跌倒
    3. (C) 服用左多巴藥物可顯著改善症狀，且藥效至少可良好維持 5 年以上
    4. (D) 動作症狀皆由單側肢體開始，才進展到雙側肢體

    正解：(B)

  21. 21下列那一種溝通方法最不適合用來幫助中度阿茲海默症患者克服溝通與記憶障礙？

    3. (C) 採用「是」與「否」的方法詢問個案
    4. (D) 採用視、聽、觸覺的輔助

    正解：(A)

  22. 22一位 35 歲女性被診斷為多發性硬化症，她表示每次在炎熱的夏季或洗熱水澡後，都會造成視力模糊、疲倦或肢體無力等症狀，症狀通常在體溫降低後會自行緩解，此狀況為何？

    3. (C) Lhermitte 徵象
    4. (D) Hoffmann 徵象

  25. 25有關顏面神經麻痺所造成的臉部連帶運動（facial synkinesis）之敘述，下列何者正確？

    1. (A) 是指在臉部休息不動時患處肌肉會出現抽動現象
    2. (B) 神經肌肉再訓練方式可能有預防與治療效果
    3. (C) 如果是周邊性顏面神經麻痺造成，神經傳導測試經常是陽性
    4. (D) 實證顯示肉毒桿菌素 A 之治療效果不佳

    正解：(B)

  26. 26下列對肌梭的敘述，何者正確？

    1. (A) 位於肌肉與肌腱交接處
    2. (B) 內含運動神經，可引起梭內肌肉纖維收縮
    3. (C) 主要功能為偵測肌肉的張力狀態
    4. (D) 由 Ib 感覺神經纖維負責傳出感覺訊息

  27. 27根據動作學習原則，欲瞭解個案在訓練過程中是否已真正學會某項動作技能，下列那一種方法最合適？

    1. (A) 觀察個案在訓練過程中的動作表現
    2. (B) 測量個案在訓練過程中單次完成任務的速度與準確性變化
    3. (C) 以保留或轉移測驗評估學習效果
    4. (D) 使用即時生理指標（如心率、肌電圖）判斷動作學習程度

    正解：(C)

  28. 28關於患者在動作學習時，治療師給予回饋的時機，下列敘述何者正確？

    1. (A) 相較於經幾次練習才給予一次回饋，立即回饋對於動作學習的留存（retention）效果較佳
    2. (B) 只在錯誤量達到一定程度才給回饋，會因給的回饋不夠精準而不利學習
    3. (C) 練習時慢慢減少給回饋的頻率，會導致無法得知動作的正確性而不利於學習
    4. (D) 簡單的動作可以練習幾次之後再給一個整體回饋，患者仍可以從回饋中學習

    正解：(D)

  29. 29有關基模理論（schema theory）的敘述，下列何者錯誤？

    1. (A) 是一種開放迴路的學習過程
    2. (B) 病患第一天開始重新學習上肢的動作，其起始和完成的動作，會被記憶在短期記憶
    3. (C) 病患重新學習上肢的動作時，眼睛看著鏡子的動作，動作會被儲存在短期記憶
    4. (D) 基模可以由學習者自己學習建立，或是別人灌輸知識或轉移獲得

    正解：(D)

  30. 30在胚胎時期、嬰幼兒發展時期與成人時期發生的神經可塑性變化，下列敘述何者正確？

    1. (A) 神經膠質細胞生成（gliogenesis）在各時期皆持續發生，神經元生成（neurogenesis）則在進入成人期後停止
    2. (B) 在胚胎時期，神經細胞生成順序依序為神經元（neurons）、神經膠質細胞（glia）、放射狀神經膠質細胞（radical glial cells）
    3. (C) 神經膠質細胞生成（gliogenesis）在進入成人期後，主要發生區域限於腦部及脊髓
    4. (D) 探究胚胎時期起源，神經元（neurons）與神經膠質細胞（glia）是由不同的神經祖細胞（neuralprogenitor cells）分化而成

    正解：(C)

  31. 31王先生在創傷性腦傷後接受物理治療，重新學習與再學習多種功能性動作，下列關於學習誘發之神經塑性的敘述何者錯誤？

    1. (A) 先破壞再建設，長期增強作用（long-term potentiation）發生在長期抑制作用（long-term depression）之後
    2. (B) 特定基因的表現改變，且此改變可能造成後續的突觸、白質變化
    3. (C) 寡突前驅膠細胞（oligodendrocytes precursor cells）增生，產生更多寡樹突細胞與髓鞘
    4. (D) 透過新樹突脊生成、樹突大小變化、樹突形狀變化等，綜合而致新突觸形成（synaptogenesis ）

    正解：(A)

  32. 32陳阿姨為亞急性期中風患者，在接受密集的動作訓練後，其動作功能逐漸恢復。關於其大腦之神經可塑性，下列何者最不可能發生？

    1. (A) 健側大腦之主要動作皮質區，功能性活化上升
    2. (B) 患側大腦之主要動作皮質區，功能性活化上升
    3. (C) 雙側大腦間之功能性連結提高
    4. (D) 患側大腦之主要動作皮質區，無功能性活化訊號

    正解：(D)

  33. 33治療師檢視以下檢查結果，何者較無法說明中風病患肌肉痙攣（spasticity）有增高的趨勢？

    1. (A) 修正版艾許沃斯氏量表（modified Ashworth scale）分數增加
    2. (B) 霍夫曼氏反射（H reflex）檢查之 H/M 比值增加
    3. (C) 鐘擺測試（pendulum test）之小腿擺動次數減少，擺動時間減低
    4. (D) 修正版塔爾迪氏量表（modified Tardieu scale）之 R2 與 R1 差距減少

    正解：(D)

  34. 34使用肌貼技術改善中風患者的動作控制能力，下列敘述何者正確？

    1. (A) 將低張力肌肉群擺在縮短範圍，以近端為固定端貼紮，可以減少重力對肌肉群的拉力
    2. (B) 將低張力肌肉群擺在伸長範圍，以遠端為固定端貼紮，可以增加肌肉群力量
    3. (C) 將高張力肌肉群擺在縮短範圍，以近端為固定端貼紮，可以放鬆肌肉群

    1. (A) 以高強度離心收縮進行膝伸肌訓練以維持關節穩定度
    2. (B) 指導正確的使用三角巾讓肩關節可以充分休息
    3. (C) 以 50～60％儲備心跳率進行原地踏步以降低日常的疲勞程度
    4. (D) 進行短時間、多次重複的深蹲訓練直到大腿肌肉疲勞以增加肌力

    正解：(C)

  69. 69一名 50 歲病患前臂內側不慎遭重物壓傷，經診斷為尺神經二級損傷（桑德連分類法，Sunderlandclassification），若受傷位置距離小指掌骨基部 18 公分，病患小指外展動作之預後如何？

    1. (A) 此情況小指外展動作本來就不受影響
    2. (B) 不需手術，平均二個月左右可恢復動作
    3. (C) 不需手術，平均六個月左右可恢復動作
    4. (D) 此情況不進行手術恐無法恢復動作

    正解：(C)

  70. 70一位 58 歲男性，因突發性眩暈、嘔吐及步態不穩就醫。眼震圖檢查顯示靜態時無眼震，平滑追蹤及掃視正常。測試結果顯示右側半規管功能減弱 100％，左側半規管功能正常，並有自發性眼震，診斷為右側周邊前庭神經炎。下列何者最符合此個案之評估結果？

    1. (A) 在頭部向右快速轉動的頭部脈衝測試（head impulse test）中，眼睛會出現向左的追趕性掃視（catch-upsaccade）
    2. (B) 初期在黑暗環境無注視的情境下進行眼震觀察時，自發性眼震（spontaneous nystagmus）會被抑制
    3. (C) 動態視力檢查（dynamic visual acuity）中，頭部水平轉動時，視力與靜態視力檢查結果一致
    4. (D) 在前庭眼動反射取消測試（vestibulo-ocular reflex cancellation test）中，眼睛無法維持注視在隨著頭部移動的目標上

    正解：(A)

  71. 71一位 48 歲女性，主訴頭暈，尤其在快速轉頭或變換姿勢時更為明顯，理學檢查結果初步判斷為右側水平半規管良性陣發型姿勢性眩暈，下列那一項介入策略最無法改善症狀？

    1. (A) Brandt-Daroff 運動（Brandt-Daroff exercises）
    2. (B) 注視穩定訓練（gaze stabilization exercises）
    3. (C) 耳石復位術（canalith repositioning maneuver）
    4. (D) 前庭習慣化訓練（vestibular habituation exercises）

    正解：(B)

  72. 72魏小姐早上起床坐起來後，眼睛盯著左邊牆上的時鐘，同時迅速地向右側轉身下床時，發現無法清楚看到時鐘上的數字，並且感到頭暈。此現象可能為下列何者異常所導致？

    1. (A) 眼球快速掃視（saccade）
    2. (B) 眼球平滑追蹤（smooth pursuit）
    3. (C) 前庭眼球反射（vestibulo-ocular reflex）
    4. (D) 前庭脊髓反射（vestibulo-spinal reflex）

    正解：(C)

  73. 7345 歲宋先生診斷為左側前庭神經炎患者，有關其前庭復健運動之敘述，下列何者錯誤？

    1. (A) 患者可能出現眩暈或姿勢不平衡的症狀，所以治療師須事先告知患者，並保護患者避免跌倒
    2. (B) 可利用點頭或頭部轉動的方式，給予前庭刺激
    3. (C) 行走時，可利用加快行走速度或改變方向，給予前庭刺激
    4. (D) 治療活動皆應該在平穩地面上執行，以幫助維持平衡

    正解：(D)

  74. 74關於神經肌肉接合處疾病（neuromuscular junction disorders），下列敘述何者正確？

    1. (A) 基蘭－巴瑞氏症候群屬於此類疾病
    2. (B) 重症肌無力是典型的此類疾病
    3. (C) 通常會有感覺異常與遠端肌肉無力
    4. (D) 多發性硬化症屬於此類疾病

    正解：(B)

  75. 75一位 42 歲男性因四肢無力與感覺異常住院，被診斷為基蘭－巴瑞氏症候群，目前處於急性期第二天，四肢近乎完全無法主動活動，正在加護病房接受監測與治療，尚未使用呼吸器。在此階段，最適當的物理治療介入策略為何？

    1. (A) 進行主動－協助關節運動與站立訓練，以維持本體感覺與促進循環
    2. (B) 設計床邊漸進式阻力運動以減緩肌肉萎縮與維持功能
    3. (C) 提供床邊被動關節活動與良好姿勢擺位，以預防關節攣縮與壓瘡
    4. (D) 針對下肢肌群進行功能性電刺激，以促進神經再生

    正解：(C)

  76. 76針對社區高齡者，若欲評估其日常活動中的功能性動作表現與平衡能力，下列那一項測驗最適合？

    1. (A) 巴氏量表（Barthel index）
    2. (B) 功能性前伸測試（functional reach test）
    3. (C) 功能獨立性量表（functional independence measure）
    4. (D) 計時起走測試（timed up-and-go test）

    正解：(D)

  77. 77有關肌少症之敘述，下列何者正確？

    1. (A) 慢肌萎縮較顯著
    2. (B) 肌力會下降尤其是上肢肌力
    3. (C) 增加胰島素抗性
    4. (D) 同時會有維生素 E 缺乏症

    正解：(C)

  78. 7885 歲的吳老先生失智多年，他的日常生活大部分需要依賴外傭幫忙，例如輪椅轉位、上廁所，但平日外傭還是會協助他坐輪椅，推他到公園曬太陽，如果阿公精神好，有時可以勉強在大量協助下扶著公園的欄杆站立30 秒。上個月洗澡的時候在浴室跌倒，右側髖關節骨折，送醫後換了全人工關節。進行居家訪視時，下列處置何者較不適當？

    1. (A) 檢視家中的無障礙環境，確定沒有再跌倒的風險
    2. (B) 教導或確認外傭對於骨折處被動關節執行方式
    3. (C) 距開刀已經一個月，可以教導使用助行器練習行走
    4. (D) 確定吳老先生的日常生活執行方式

    正解：(C)

  79. 79下列何者並不是高齡體適能測驗的測試項目與其測試面向？

    1. (A) 以 30 秒手臂屈舉測量上肢肌力
    2. (B) 以 6 分鐘行走測試測量有氧耐力
    3. (C) 以坐姿前彎測試測量軀幹關節活動度
    4. (D) 以 8 英呎計時起走測試測量動態平衡

    正解：(C)

  80. 80根據行為改變輪（behaviour change wheel）之 COM-B 模型，要促成高齡者養成運動習慣，需要同時考慮那些核心要素？
