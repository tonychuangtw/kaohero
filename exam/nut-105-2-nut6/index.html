營養師　105 年第二次 食品衛生與安全　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何項廣告標示並無涉及療效、誇大或易生誤解？

    1. (A) 調節生理機能
    2. (B) 增強抵抗力
    3. (C) 防止老化
    4. (D) 清心降肝火

    正解：(A)

  2. 2依據「食品良好衛生規範準則」，食品業者設置建築與設施時，工作台面應保持之亮度為多少米燭光以上？

    1. (A) 100
    2. (B) 200
    3. (C) 300
    4. (D) 400

    正解：(B)

  3. 3食品原料處理場、加工或調理場、廁所、消毒洗手室、員工休息室及餐廳等進出口或適當位置，應設置適當數量之洗手台，其最低數不得少於該工作場所最高工作人員數之比例為何？

    1. (A) 十分之一
    2. (B) 十分之二
    3. (C) 十分之三
    4. (D) 十分之四

    正解：(A)

  4. 4現行健康食品管理法依食品安全性評估分為四個類別，除第一類別外，其餘三類皆需檢具下列何項毒性測試資料？

    1. (A) 基因毒性試驗
    2. (B) 28 天餵食毒性試驗
    3. (C) 致癌性試驗
    4. (D) 慢性毒性試驗頁次： 4－2

    正解：(A)

  5. 5關於食品的水活性之敘述，下列何者正確？

    1. (A) 水活性的多寡與自由水的含量成反比
    2. (B) 水活性最能適切表現食品中水的可利用性
    3. (C) 水活性相同的食品，其水分含量亦相同
    4. (D) 在高水活性的環境中，微生物的生長會受抑制

    正解：(B)

  6. 6下列何者是以「抑制機制」來防止一般微生物所造成之腐敗？

    1. (A) 加熱
    2. (B) 真空包裝
    3. (C) 紫外線照射
    4. (D) 添加過氧化氫

    正解：(B)

  7. 7下列何種酵素易造成米糠在室溫下產生酸敗？

    1. (A) 蛋白酶（protease）
    2. (B) 脂解酶（lipase）
    3. (C) 多酚氧化酶（polyphenol oxidase）
    4. (D) 澱粉酶（amylase）

    正解：(B)

  8. 8下列何者不是測量食品中總生菌數的方法？

    1. (A) aerobic plate count
    2. (B) most probable number
    3. (C) standard plate count
    4. (D) total bacterial count

    正解：(B)

  9. 9下列何者為冷凍蔬菜的衛生指標菌？

    1. (A) 大腸桿菌群（coliform）
    2. (B) 大腸桿菌（E. coli）
    3. (C) 腸球菌（Enterococcus）
    4. (D) 李斯特菌（Listeria monocytogenes）

    正解：(C)

  10. 10關於食品輻射照射之敘述，下列何者錯誤？

    1. (A) 可增加食品的保藏性
    2. (B) β 射線和 γ 射線是目前最常用的食品輻射射線
    3. (C) 可用於抑制馬鈴薯發芽，也可以抑制昆蟲、寄生蟲生長
    4. (D) 能破壞食品中污染的微生物並達到高溫滅菌的效果

    正解：(B)

  11. 11下列何者是用來決定不同物質間相對毒性的安全性評估方法？

    1. (A) 急性毒性實驗
    2. (B) 亞急性毒性實驗
    3. (C) 亞慢性毒性實驗
    4. (D) 慢性毒性實驗

    正解：(A)

  12. 12下列何者是微生物性基因毒性測試？

    1. (A) 安姆氏試驗法（Ames test）
    2. (B) 染色體變異試驗（chromosomal aberration test）
    3. (C) 周邊血球微核試驗（peripheral blood micronucleus test）
    4. (D) 姊妹染色體交換試驗（sister chromosome exchange test）

    正解：(A)

  13. 13動物長期致癌性實驗中，下列何者是投藥期間每週應該至少執行一次的檢測項目？

    1. (A) 動物體重測量
    2. (B) 動物尿液檢驗
    3. (C) 動物眼睛檢查
    4. (D) 動物血清生化檢驗

    正解：(A)

  14. 14進行體外哺乳類細胞基因毒性分析時，如果初步試驗結果無觀察到細胞毒性，且受試物質為高溶解物質，則最高劑量應該為多少？

    1. (A) 達到 LD50 的濃度
    2. (B) 達到飽和溶液的濃度
    3. (C) 取 5 mg/mL 或 10 mM 中較低的濃度
    4. (D) 取 5 mg/mL 或 10 mM 中較高的濃度頁次：4－3

    正解：(C)

  15. 15申請增列為我國准用之食品添加物時，下列何者不是申請者所須檢附的資料？

    1. (A) 動物安全性試驗資料
    2. (B) 世界各國准用情形
    3. (C) 食品添加物產地
    4. (D) 規格標準

    正解：(C)

  16. 16食品安全性評估中，小鼠周邊血球微核試驗（peripheral blood micronucleus test）是屬於：

    1. (A) 急性毒性試驗
    2. (B) 慢性毒性試驗
    3. (C) 致突變性試驗
    4. (D) 繁殖試驗

    正解：(C)

  17. 17市面上俗稱的保麗龍是由下列何種塑膠材質所製成？

    1. (A) 聚碳酸酯（polycarbonate, PC）
    2. (B) 聚乙烯（polyethlene, PE）
    3. (C) 聚苯乙烯（polystyrene, PS）
    4. (D) 聚氯乙烯（polyvinylchloride, PVC）

    正解：(C)

  18. 18有關食品添加物之敘述，下列何者錯誤？

    1. (A) 人類具有代謝苯甲酸鹽之能力
    2. (B) 過氧化氫（H2O2）可添加於食品中，但不得殘留
    3. (C) 亞硫酸鹽不可使用於飲料、麵類食品中
    4. (D) 依我國法規，所有人工合成色素均不得使用於食品

    正解：(D)

  19. 19下列何者不是針對食品中抑制黴菌污染所添加的防腐劑？

    1. (A) 丙酸
    2. (B) 乳酸
    3. (C) 己二烯酸
    4. (D) 苯甲酸

    正解：(B)

  20. 20環己基磺醯胺酸鹽（cyclamate）是一種非營養性甜味劑，不得使用於下列何種食品品項？

    1. (A) 截切水果
    2. (B) 特殊營養食品
    3. (C) 代糖錠劑及粉末
    4. (D) 瓜子、蜜餞

    正解：(A)

  21. 21塑膠製碗盤為防止變質及有害物質之溶出，下列何者為較佳之消毒方式？

    1. (A) 100℃熱水
    2. (B) 遠紅外線
    3. (C) 紫外線
    4. (D) 次氯酸鹽水溶液

    正解：(D)

  22. 22餐飲業者之洗滌場所應具有三槽式餐具洗滌殺菌設施，下列洗滌殺菌流程何者正確？

    1. (A) 預洗 → 清洗 → 沖洗 → 消毒
    2. (B) 預洗 → 沖洗 → 清洗 → 消毒
    3. (C) 預洗 → 清洗 → 消毒 → 沖洗
    4. (D) 預洗 → 消毒 → 清洗 → 沖洗

    正解：(A)

  23. 23高溫烘烤後之澱粉類食物，最可能出現下列何種有害物質？

    1. (A) 亞硝胺
    2. (B) 丙烯醯胺
    3. (C) 離胺丙胺酸
    4. (D) 異環胺類化合物

    正解：(B)

  24. 24下列何者與 MeIQx 的生成無關？

    1. (A) 肌酸酐
    2. (B) 甘胺酸
    3. (C) 脯胺酸
    4. (D) 2,5-二甲基吡嗪

    正解：(C)

  25. 25「食品添加物使用範圍及限量暨規格標準」中，下列何者不是正面表列之食品添加物？

    1. (A) 甲醛
    2. (B) 苯甲酸
    3. (C) 己二烯酸
    4. (D) 亞硫酸氫鈉

    正解：(A)

  26. 26為增加顏色鮮豔度，市售吻仔魚常被添加下列何種非法添加物？

    1. (A) borax
    2. (B) rongalite
    3. (C) auramine
    4. (D) fluorescent

    正解：(D)

  27. 27下列寄生蟲何者是經由魚貝類感染？

    1. (A) 迴蟲
    2. (B) 有鈎絛蟲
    3. (C) 中華肝吸蟲
    4. (D) 無鈎絛蟲頁次： 4－4

    正解：(C)

  28. 28有關肉毒桿菌之敘述，下列何者錯誤？

    1. (A) 絕對嫌氣性菌
    2. (B) 產毒條件：pH4.6 以上，Aw 在 0.85 以上
    3. (C) 毒素之毒性強且耐熱到 100℃
    4. (D) 1 歲以下嬰兒避免食用蜂蜜

    正解：(C)

  29. 29李子、櫻桃等核仁中所含的產氰糖苷（cyanogenic glycosides）是：

    1. (A) linamarin
    2. (B) amygdalin
    3. (C) cycasin
    4. (D) dhurrin

    正解：(B)

  30. 30我國規定蘋果汁中之 patulin 含量不得超過多少 ppb？

    1. (A) 40
    2. (B) 45
    3. (C) 50
    4. (D) 55

    正解：(C)

  31. 31我國主管機關最先公告須實施食品安全管制系統的食品產業為何？

    1. (A) 餐盒食品工廠
    2. (B) 水產食品
    3. (C) 肉類加工
    4. (D) 乳品加工

    正解：(B)

  32. 32目前在一般工廠實務中，無菌鋁箔包飲料採用下列何種溶液對其包裝材料進行殺菌？

    1. (A) 75%酒精
    2. (B) 雙氧水溶液
    3. (C) 200 ppm 漂白水
    4. (D) 三氯乙烯酒精

    正解：(B)

  33. 33下列何者是最符合食品安全原則的解凍法？

    1. (A) 室溫解凍法
    2. (B) 冷藏解凍法
    3. (C) 微波爐解凍法
    4. (D) 流水解凍法

    正解：(B)

  34. 34餐廳等作業場所應保持氣閉，但在負壓現象明顯之地區，若使用紗門，較宜使用多少網目之防蟲網？

    1. (A) 100
    2. (B) 64
    3. (C) 32
    4. (D) 16

    正解：(A)

  35. 35下列何種試液可以用來測試洗淨的餐具是否殘留有油脂？

    1. (A) 碘液
    2. (B) 蘇丹四號試液
    3. (C) 寧海準試液
    4. (D) 斐林試驗

    正解：(B)

  36. 36某團膳機構採購不鏽鋼廚具，其規格為 SUS304，此代號所代表的是：

    1. (A) 材質厚度
    2. (B) 材質成分中鉻鎳之比例
    3. (C) 材質批號代碼
    4. (D) 材質表面為鏡面或霧面處理之代碼

    正解：(B)

  37. 37民 國 97 年 間 發 生 中 國 大 陸 三 鹿 集 團 奶 粉 非 法 添 加 三 聚 氰 胺 事 件 後 ， 國 際 食 品 標 準 委 員 會（Codex Alimentarius Commission）規定一般食品的三聚氰胺含量限制為何？

    1. (A) 不得檢出
    2. (B) 0.5 ppm
    3. (C) 1.5 ppm
    4. (D) 2.5 ppm

    正解：(D)

  38. 38依據現行食品添加物之標示規定，下列敘述何者錯誤？

    1. (A) 己酸丙烯酯，僅須標示為「香料」
    2. (B) 山梨醇如做為甜味劑使用，應同時標示「山梨醇」及「甜味劑」
    3. (C) 檸檬酸鈉，應標示「檸檬酸鈉」或「調味劑」
    4. (D) 己二烯酸鉀，應標示「己二烯酸鉀」及「抗氧化劑」

    正解：(D)

  39. 39生食海鮮最可能的食物中毒菌為下列何者？

    1. (A) 仙人掌桿菌（Bacillus cereus）
    2. (B) 腸炎弧菌（Vibrio parahaemolyticus）
    3. (C) 沙門氏菌（Salmonella typhimurium）
    4. (D) 金黃色葡萄球菌（Staphylcoccus aureus）

    正解：(B)

  40. 40民國 102 年 5 月間，媒體驚爆宜蘭羅東當地夜市攤販使用毒醬油事件，其有害原因為何？

    1. (A) 醬油防腐劑添加過量
    2. (B) 醬油鈉鹽含量過高
    3. (C) 化學醬油之副產物
    4. (D) 釀造醬油雜菌污染

    正解：(C)
