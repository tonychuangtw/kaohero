    2. (B) 血液中有較高濃度的低密度脂蛋白膽固醇（low-density lipoprotein cholesterol），其發生率較低
    3. (C) 主要的致病機轉起源於血管內皮受傷所引發的慢性發炎反應
    4. (D) 粥狀動脈硬塊（atheroma）會侵犯血管中層，弱化管壁，造成動脈瘤（aneurysm）的產生

    正解：(B)

  59. 59下列何種癌症是最常見之口腔癌？

    1. (A) 腺癌（adenocarcinoma）
    2. (B) 淋巴癌（lymphoma）
    3. (C) 鱗狀細胞癌（squamous cell carcinoma）
    4. (D) 黑色素瘤（melanoma）

    正解：(C)

  60. 6040歲女性，經常嚴重經痛，腹腔鏡檢查發現骨盆腔腹膜上有許多暗紅色或黃棕色的小結節；顯微鏡檢查出現子宮內膜腺體及出血現象，則下列何者是最可能的診斷？

    3. (C) 轉移性子宮內膜癌（endometrial carcinoma）
    4. (D) 原發性腹膜類子宮內膜癌（endometrioid carcinoma）

  61. 61絕大部分卡波西氏肉瘤（Kaposi sarcoma）的病灶中可見下列何種病毒？

    4. (D) Epstein-Barr病毒（Epstein-Barr virus, EBV）

  62. 62BRAF基因點突變（point mutation）最常出現在下列何種甲狀腺腫瘤？

    3. (C) 乳突狀癌（papillary carcinoma）
    4. (D) 未分化癌（anaplastic carcinoma）

  63. 63下列有關乳房外柏哲德氏病（extramammary Paget disease）的敘述，何者正確？

    2. (B) 可見淋巴癌細胞侵犯皮下組織

    4. (D) 大部分病例在5年內會發生遠處轉移

    正解：(C)

    3. (C) 是由疱疹病毒感染造成咽喉炎後引發的免疫反應所造成
    4. (D) 是由β型溶血性鏈球菌感染造成咽喉炎後引發的免疫反應所造成

    正解：(D)

  66. 66最常引起腦下垂體機能亢進（hyperpituitarism）的原因為下列何者？

    4. (D) 腦下垂體癌（pituitary carcinoma）

  67. 67最常見因營養缺乏而引起的貧血是下列何者？
