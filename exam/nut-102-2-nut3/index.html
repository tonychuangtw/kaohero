營養師　102 年第二次 膳食療養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1發炎反應之急性時期，下列那一個蛋白質可作為營養介入的最好指標？

    1. (A) 運鐵蛋白（transferrin）
    2. (B) C-反應蛋白（C-reactive protein；CRP）
    3. (C) 甲狀腺素運送蛋白（transthyretin；TTHY）
    4. (D) 視網醇結合蛋白（retinol-binding protein；RBP）

    正解：(B)

  2. 2在營養諮詢的過程中，根據階段性行為改變理論（stages of change），處於下列那一個階段的患者經過營養師指導，給予適當可行的飲食計畫就可以有行為改變？

    1. (A) precontemplation
    2. (B) contemplation
    3. (C) preparation
    4. (D) action

    正解：(C)

  3. 3有關 nasoduodenal 路徑之灌食方法、配方選擇與適應症之敘述，下列何者正確？

    1. (A) 適合用於有 gastroparesis 問題的患者，以改善灌食不足之問題
    2. (B) 適合採用 bolus feeding
    3. (C) 適合腹瀉嚴重的患者
    4. (D) 適合使用一般食物製作的管灌飲食頁次：4－2

    正解：(A)

  4. 4為避免再餵食症候群（refeeding syndrome），在早期餵食時應注意下列那些礦物質的補充？

    1. (A) 鉀、磷、鎂
    2. (B) 鉀、磷、鈣
    3. (C) 鈉、磷、鈣
    4. (D) 鉀、鈉、鎂

    正解：(A)

  5. 5下列 30 g/L 之溶液何者滲透壓最高？

    1. (A) 玉米糖漿（corn syrup）
    2. (B) 水解玉米澱粉（hydrolyzed cornstarch）
    3. (C) 果寡糖（fructo-oligosaccharides）
    4. (D) 蔗糖（sucrose）

    正解：(D)

  6. 6肝性腦病變患者可採取下列何種營養支持，以改善其病情？

    1. (A) 補充支鏈胺基酸（BCAA）
    2. (B) 補充色胺酸（tryptophan）
    3. (C) 補充芳香族胺基酸（AAA）
    4. (D) 補充甲硫胺酸（methionine）

    正解：(A)

  7. 7靜脈注射時，葡萄糖濃度大於多少就必須考慮以全靜脈營養（TPN）施行？

    1. (A) 5％
    2. (B) 7％
    3. (C) 9％
    4. (D) 12.5％

    正解：(D)

  8. 8相較於靜脈營養，腸道營養對重症病患營養支持之益處，下列何者錯誤？

    1. (A) 有較好之胃腸屏障功能（gastrointestinal barrier function）
    2. (B) 有較好之胃腸道免疫力（gastrointestinal immunity）
    3. (C) 較容易達到病患熱量需求
    4. (D) 降低感染率

    正解：(C)

  9. 9目前衛生福利部（原行政院衛生署）核准國內可用於青少年的唯一減重藥物是：

    1. (A) orlistat
    2. (B) sibutramine
    3. (C) acomplia
    4. (D) adifax

    正解：(A)

  10. 10若甜度相同，下列何種糖提供之熱量最高？

    1. (A) 葡萄糖
    2. (B) 果糖
    3. (C) 蔗糖
    4. (D) 阿斯巴甜

    正解：(A)

  11. 11憩室病是腸胃道那一部位產生憩室的疾病？

    1. (A) 食道
    2. (B) 胃
    3. (C) 小腸
    4. (D) 大腸

    正解：(D)

  12. 12吸菸對於消化道功能的影響，下列何者錯誤？

    1. (A) 增加食道括約肌壓力
    2. (B) 抑制胰臟重碳酸鹽分泌
    3. (C) 加速胃排空速度
    4. (D) 增加胃酸逆流

    正解：(A)

  13. 13慢性胰臟炎患者，可能會有脂肪痢的情形，下列何措施可改善此種現象？

    1. (A) 補充水溶性型式之脂溶性維生素
    2. (B) 補充水分
    3. (C) 補充胰臟酵素
    4. (D) 補充鉀

    正解：(C)

  14. 14下列何種眼球病變與糖尿病無關？

    1. (A) 老花眼
    2. (B) 視網膜病變
    3. (C) 青光眼
    4. (D) 白內障

    正解：(A)

  15. 15妊娠糖尿病（gestational DM）之診斷：口服 100 公克葡萄糖，2 小時後血糖最低大於多少 mg/dL？

    1. (A) 95
    2. (B) 140
    3. (C) 155
    4. (D) 180

    正解：(C)

  16. 16下列何種疾病可由測量氫（H2）呼出量來做診斷？

    1. (A) 乳糖不耐症（lactose intolerance）
    2. (B) 克隆氏症（Crohn’s disease）
    3. (C) 潰瘍性結腸炎（ulcerative colitis）
    4. (D) 冠心症（coronary heart disease）

    正解：(A)

  17. 17對第 2 型糖尿病的兒童與青少年的營養照顧原則，下列敘述何者錯誤？

    1. (A) 避免過重，需常規運動
    2. (B) 達到血糖與 A1C 目標
    3. (C) 避免高血壓與高血脂的發生
    4. (D) 若未達到目標血糖可使用 metformin 以增加胰島素的分泌頁次：4－3

    正解：(D)

  18. 18下列那二種胰島素的混合劑型可在市面上購得？

    1. (A) 短效型（regular insulin）和中效型（NPH）
    2. (B) 短效型（regular insulin）和中效型（lente）
    3. (C) 中效型（NPH）和長效型（ultralente）
    4. (D) 短效型（regular insulin）和長效型（ultralente）

    正解：(A)

  19. 19末期腎病患者必須依賴磷結合劑（phosphate binders）降低腸道對磷之吸收，其服用磷結合劑的最佳時機為何？

    1. (A) 餐前
    2. (B) 餐間
    3. (C) 餐後
    4. (D) 任何時間點均可

    正解：(B)

  20. 20有關鈣質補充劑對骨鈣影響之敘述，下列何者錯誤？

    1. (A) 額外由鈣質補充劑補充鈣的主要好處，是可以促進副甲狀腺素分泌，進而促進骨鈣的保留
    2. (B) 老年人使用鈣質補充劑後，可改善骨質密度
    3. (C) 鈣質補充劑中檸檬酸鈣的生物利用率比碳酸鈣高
    4. (D) 對於停經後婦女，同時給予鈣質補充劑及女性荷爾蒙，能減少骨質流失的速度

    正解：(A)

  21. 21下列何種生理和臨床症狀，不會出現在神經性暴食症（bulimia nervosa）患者身上？

    1. (A) 無月經症
    2. (B) 體重正常或不足或過重
    3. (C) 脫水和低血鉀
    4. (D) 牙齒琺瑯質腐蝕

    正解：(A)

  22. 22下列何者是慢性腎衰竭最具代表性之指標？

    1. (A) 血壓上升
    2. (B) 水腫
    3. (C) 腎絲球過濾率上升
    4. (D) 腎絲球過濾率下降

    正解：(D)

  23. 23腹膜透析患者常見體脂肪增加現象，其主要原因為何？

    1. (A) 透析液滯留
    2. (B) 鈉滯留導致水分滯留
    3. (C) 可自透析液所含糖分吸收熱量
    4. (D) 食慾變好

    正解：(C)

  24. 24Nephrotic syndrome 患者因腎絲球對蛋白質之通透性變大，導致蛋白質大量流失，有關其治療與症狀之敘述，下列何者錯誤？

    1. (A) 須給予高蛋白質飲食，以彌補蛋白質之流失
    2. (B) 鈉攝取量須限制於每日 3 公克以內
    3. (C) 常合併有高膽固醇血症
    4. (D) 骨質代謝異常是常見症狀

    正解：(A)

  25. 25下列何者不是導致家族性混合型高血脂症（familial combined hyperlipidemia）的原因？

    1. (A) 肝臟過量生成 apo B-100
    2. (B) 肝臟生成肝脂解酶（hepatic lipase）的基因缺陷
    3. (C) 肝臟生成可移除血清 TG 酵素的基因缺陷
    4. (D) 肝臟生成 HMG CoA 還原酶的基因缺陷

    正解：(D)

  26. 26下列何者不是代謝症候群的診斷界定值？

    1. (A) FBG ≥ 100 mg/dL
    2. (B) BP ≥ 130/85 mmHg
    3. (C) TG ≥ 150 mg/dL、HDL-c＞50 mg/dL
    4. (D) Male 腰圍 ≥ 90 cm、Female 腰圍 ≥ 80 cm

    正解：(C)

  27. 27下列何種生化指標，臨床上最常用來預測冠狀動脈粥狀硬化與心肌梗塞的發生風險？

    1. (A) CRP
    2. (B) TNF-α
    3. (C) IL-1
    4. (D) fibrinogen

    正解：(A)

  28. 28下列何種膳食纖維對降低血膽固醇效果較差？

    1. (A) pectin
    2. (B) cellulose
    3. (C) mucilage
    4. (D) guar gum

    正解：(B)

  29. 29有關重症創傷病患剛進入高亢期（flow phase）生理反應之敘述，下列何者正確？

    1. (A) 促進糖質新生作用
    2. (B) 促進肝醣合成作用
    3. (C) 血液游離脂肪酸量降低
    4. (D) 血液 C-reactive protein 量降低頁次：4－4

    正解：(A)

  30. 30下列何者不是重症創傷病患給予過多熱量所造成的併發症？

    1. (A) 肝臟脂肪變性（hepatic steatosis）
    2. (B) 高尿酸
    3. (C) 高血糖
    4. (D) 高二氧化碳生成量

    正解：(B)

  31. 31有關燒傷患者生理變化的敘述，下列何者錯誤？

    1. (A) 蛋白質異化作用增加
    2. (B) 尿液氮排除量降低
    3. (C) 蛋白質由燒傷處流失
    4. (D) 血漿容積不足、心臟輸出量減少

    正解：(B)

  32. 32某男性燒傷病患燒傷前體重為 60 公斤，其燒傷面積為 70％，則其熱量需求量估計為：

    1. (A) 2000 kcal
    2. (B) 4240 kcal
    3. (C) REE×2
    4. (D) REE×3

    正解：(C)

  33. 33飲食生活型態與癌症之發生密切相關，依據 World Cancer Research Fund/American Institute for CancerResearch 收集實證醫學研究報告（2007 年）內容，下列何者最可能增加肺癌發生風險？

    1. (A) beta-carotene supplements
    2. (B) foods containing carotenoids
    3. (C) retinol supplements
    4. (D) foods containing quercetin

    正解：(A)

  34. 34有關照顧食慾降低的癌症病患，下列敘述何者錯誤？

    1. (A) 晚餐供應食物之耐受性最佳
    2. (B) 以少量多餐為佳
    3. (C) 對有腸胃不適噁心、嘔吐之病患給冷食較適當
    4. (D) 對味覺改變之病患應避免給予含苦味之食物

    正解：(A)

  35. 35下列何者不是 cancer cachexia 的臨床表徵？

    1. (A) progressive weight loss
    2. (B) immunosuppression
    3. (C) gall stone
    4. (D) muscle wasting

    正解：(C)

  36. 36評估大於 5 歲唐氏症（Down syndrome）兒童的熱量需求方法，下列何者最適當？

    1. (A) 以實際體重每公斤所需要的熱量來估算總熱量需求
    2. (B) 以實際身高每公分所需要的熱量來估算總熱量需求
    3. (C) 以理想體重每公斤所需要的熱量來估算總熱量需求
    4. (D) 以理想身高每公分所需要的熱量來估算總熱量需求

    正解：(B)

  37. 37用來降低兒童癲癇發作的生酮飲食，其 75％的熱量應來自下列何種營養素？

    1. (A) 蛋白質
    2. (B) 脂肪
    3. (C) 醣類
    4. (D) 礦物質

    正解：(B)

  38. 38有關慢性阻塞性肺部疾病（COPD）的營養處方之敘述，下列何者錯誤？

    1. (A) 碳水化合物約占總熱量的 55％～65％
    2. (B) 脂肪約占總熱量的 30％～45％
    3. (C) 鈣及鎂的攝取量應大於每日建議攝取量（DRI）
    4. (D) 維生素 D 及 K 須額外補充

    正解：(A)

  39. 39美國膳食協會（American Dietetic Association）建立的標準營養照顧程序（nutrition care process）常以A-D-I-M-E 表示，其中「M」是代表：

    1. (A) malnutrition
    2. (B) monitoring
    3. (C) management
    4. (D) motivation

    正解：(B)

  40. 40為避免增加心血管的負擔，脂肪對於長期照護的老年人而言是需要限制的營養素，一般建議脂肪攝取占總熱量的：

    1. (A) 15％～20％
    2. (B) 20％～25％
    3. (C) 25％～30％
    4. (D) 30％～35％

    正解：(B)
