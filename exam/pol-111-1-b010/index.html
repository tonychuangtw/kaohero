警察特考　111 年 三等考試 警察政策與犯罪預防　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1Oscar Newman 是發展情境犯罪預防觀點的先驅，1970 年推出「防衛空間」的觀念，藉由特殊的建築設計，以減低犯罪行為發生的機會，下列何者符合防衛空間的規劃要素？

    1. (A) 環境設計應規劃高牆阻礙，讓有企圖的犯罪者無法順利進入空間遂行犯罪
    2. (B) 屋主或管理者在犯罪發生當下，能夠第一時間拿取防衛器具並採取合宜措施
    3. (C) 不讓外人清楚的了解物理及建築結構以及相關監控設施，才能引君入甕
    4. (D) 建築物設計應建立與社區鄰里親密接觸的正面形象，使其不易受到侵害

    正解：(D)

  2. 2有關犯罪預防相關的理論敘述，下列何者錯誤？

    1. (A) Cohen 和 Felson 的日常活動理論，認為犯罪預防可從合適的標的物、有動機的犯罪者以及缺乏監控三條件，進行犯罪預防策略制定
    2. (B) Wilson 和 Kelling 的破窗理論，認為社區應該加以進行破壞與毀損，讓犯罪者發現該社區無任何值錢的物品可偷竊，方能達到犯罪預防的目標
    3. (C) 理性選擇理論認為犯罪是一種目標導向的行為，因此犯罪預防策略設計應根據犯罪者本身的風險、需求、成本與利益之間的關係來進行設計
    4. (D) 犯罪型態理論強調犯罪者的居住、工作與休閒的地點範圍，犯罪者會在這三個點當中的路徑尋找犯罪機會，不太會遠離自己所熟悉的區域

    正解：(B)

  3. 3毒品與犯罪一直是社會所關切的議題，對於毒品犯罪的介入手段，從執法、處遇及預防缺一不可，有關警政與毒品犯罪的關係，下列何者錯誤？

    1. (A) 新興毒品的檢測不易，為了妥善利用人力，因此將目標放在降低吸食毒品的人口，相關緝毒工作轉由檢察機關與調查局負責
    2. (B) 針對高風險參與犯罪活動之人的毒品施用早期介入，能有效減少犯罪發生，達到犯罪預防的目的
    3. (C) 境外合作與邊境防堵、溯源斷根來減少毒品供給，雖然能夠降低犯罪的發生，但也會出現犯罪移轉的現象
    4. (D) 為掌握最新毒品情資，可規劃建置「毒品查緝情資整合分析資料庫」，整合毒品相關資料

    正解：(A)

  4. 4跨境詐欺犯罪因全球化而崛起，近來更因為新冠肺炎的肆虐而愈趨嚴重，犯罪儼然不再是單純的地區問題，跨境警察合作組織將成為未來跨境犯罪的重要關鍵。針對跨境詐欺犯罪的情境犯罪預防應有的作為，下列何者錯誤？

    1. (A) 放寬二類電信審核與查核，減少匿名性方式來增加犯罪風險
    2. (B) 增加 ATM 的巡邏頻率，強化金融機構攔阻作為，可增加犯罪的阻力
    3. (C) 打擊車手集團，使車手集團經營需耗費大量成本，相對減少犯罪酬賞
    4. (D) 透過法治宣導與法律來激發潛在犯罪者的良心，移除犯罪藉口

    正解：(A)

  5. 5專業化警政模式是警政發展的重要議題，由於社會變遷與全球化效應，目前已經進入第三次的科技工業革命的時代，在這個年代當中，下列何者是第三次專業化警政年代下應有的模式具體作為？

    1. (A) 警察組織應該採用半軍事化結構，強調服從，才能確實執行警察的專業技能
    2. (B) 強調偵查實務與鑑識能力，善用各種偵訊測謊的技巧來進行辦案，展現警察專業
    3. (C) 透過長期訓練、再進行遴選、最後經由嚴格測驗並淘汰，才能篩選出符合專業化警政所需的人力
    4. (D) 應善用當代最新科技來進行犯罪預防及追緝工作，針對新型態犯罪擬定應變策略

    正解：(D)

  6. 6問題導向的警政策略模式中，眾所皆知的就是 S.A.R.A 模式，問題解決的過程應包含掃描、分析、反應及評估，下列針對該模式的敘述何者錯誤？

    1. (A) 分析之目的係為了解問題的特性、成因、嚴重性與範圍，以及研擬解決之道
    2. (B) 評量是整個模式中最後階段，針對採取的策略進行評量，了解是否達成目的
    3. (C) 反應是在可能的解決方案當中，配合實務及分析結果，選擇最適當之策略
    4. (D) 掃描主要是蒐集相關資訊，加以深入研究，才能界定問題範圍

    正解：(D)

  7. 7理性決策模式是由古典經濟學家所提倡，以有限度的理性與直覺來追求利益為目標，下列對於理性決策模式實際執行過程的敘述何者錯誤？

    1. (A) 決策者對於問題及目標都有清楚的認識且互不衝突，但執行上往往隱晦不明
    2. (B) 理性決策以追求組織最大利益為主，因此實際決策過程中所有決策者會有一致性的價值信念來客觀進行決策
    3. (C) 理性決策模式實際執行上會因為時間、勞力及費用有限而干擾
    4. (D) 理性決策模式可以透過資料比對來進行各種理性思維分析，得以尋找出最佳方案，但在實際執行過程當中未必能確實的執行

    正解：(B)

  8. 8警察倫理是警政工作品質的基石，警察人員除了肩負社會治安的工作外，因面對的個體從警察系統擴及到社會大眾，內部倫理與外部倫理有極大的可能產生衝突。Weimer 與 Vining 提出倫理衝突解決策略，下列何者對於倫理衝突處理模式與策略的敘述錯誤？

    1. (A) 為了能夠解決衝突，採用妥協模式將能完美的解決衝突
    2. (B) 透過正式管道提出建議與表達異議，而非四處散播不實情況
    3. (C) 有意無意地洩漏相關機密，並從中阻礙破壞行動
    4. (D) 各種方式反應無效，提出辭呈離職

    正解：(A)

  9. 9第三方警政是結合非犯罪的第三方參與犯罪預防及控制的活動，下列對於第三方警政的相關敘述何者正確？

    1. (A) 第三方警政的概念當中，第一方是指犯罪人，第二方是指警察，第三方則是指其他能夠防止或控制犯罪的人
    2. (B) 第三方警政強調要求非違法的第三方來承擔犯罪預防與控制的責任，但其核心主導權仍然是警察，方能指揮第三方來協助
    3. (C) 第三方警政除了鼓勵第三方民眾主動協助治安管理之外，還可以透過法律規範來強制第三方民眾配合
    4. (D) 有了第三方警政的協助，情境犯罪預防策略不必繼續實施，因為全民皆警，犯罪無所遁形

    正解：(C)

  10. 10政策制定者在構思政策方案時，對於每個政策方案都必須針對各個價值面向進行理性決策思維過程，方能了解政策的可行性程度，下列何者不是政策可行性評估分析所考慮的價值面向？

    1. (A) 政治
    2. (B) 效益
    3. (C) 法律
    4. (D) 時間

    正解：(B)

  11. 11警察政策的規劃、執行與評估，其過程與結果影響警察組織甚鉅，警察組織是一個以達成社會秩序維護與保障社會安全目標的行政團體，下列針對警察組織的敘述何者正確？

    1. (A) 警察組織是一個擁有武力的執法團體，但由於工作有緊急性與危險性，為了保護民眾與自身的安全，其裁量權自由度較高，以個人主義的領導為主
    2. (B) 警察組織是依據法律授權執法，同時也透過法律授權行政命令與規定來處理相關業務
    3. (C) 警察組織隸屬於內政部警政署，重大決策的最上層級為內政部部長
    4. (D) 警察組織中的幕僚層級是蒐集資料、提供意見以供決策層級參考，因此幕僚層級必須直接與民眾接觸，才能了解民眾需求，進而提供意見

    正解：(B)

  12. 12從 1960 年代末期開始，「被害者學」開始成為犯罪學中的一門特殊學科，警察跟犯罪被害者的關係更是密不可分。針對警察對於被害者的支持與預防措施的敘述，下列何者錯誤？

    1. (A) 被害者能夠提供案件偵查的關鍵訊息，而警察能夠儘量提供被害者犯罪案件的相關處理情形，建立彼此的信任，有利被害者安定的感受
    2. (B) 強化警政作為，增加巡邏頻率與強度、預防被害宣導、推動社區警政等，對於被害者來說就是良好的預防和保護措施
    3. (C) 警察應以更積極的態度來處理犯罪被害事件，像是確實簽發報案三聯單、快速處理案件、善意提醒可能的風險訊息與協助資源，可降低重複被害的機會
    4. (D) 警察應依照職責範圍依法辦理，依照程序進行被害者的安置，以超然的專家角色處理犯罪現場，不應感受被害者情緒的變化

    正解：(D)

  13. 13派出所的設置是警察執行勤務規劃下的重要據點，對於警察勤務紮根於社區各個角落有推波助瀾的功用。下列對於派出所的敘述何者正確？

    1. (A) 派出所是第一線的刑事司法單位，與地方有著緊密的鏈結關係，最適用於現代科技化的電腦統計警政政策
    2. (B) 派出所 24 小時運作，與地方緊密結合，派出所員警深入地方、主動服務，與地方民眾建立信任，可提升民眾心理上的安全感受
    3. (C) 派出所制度由美國倡用，隨後由日本將派出所的警察勤務政策引進臺灣，沿用至今
    4. (D) 派出所屬於專責警勤區制度，由於深入地方，因此員警負責各自的轄區，專業分工下，鮮少有勞逸不均的現象

    正解：(B)

  14. 14「新冠肺炎疫情期間假投資詐騙不斷，內政部警政署表示越來越多詐騙集團為規避查緝，將非法金流虛擬化，此類新型態洗錢手法已是警方未來打擊重點。」當警察機關進行重大決策時，理性決策的思維流程最常運用在警察政策的擬定。上述的全國打詐政策，是屬於理性決策思維當中的那個步驟？

    1. (A) 確認問題
    2. (B) 執行與檢討
    3. (C) 擬定方案
    4. (D) 確定目標

    正解：(D)

  15. 15在警察公共政策分析議題中，有以市場機制（解決問題）為中心的政策分析（mechanism-centeredpolicy analysis）取向，這其中包含政府失靈（government failure）的現象。Weimer & Vining 曾提出造成政府失靈的原因，下列何者不是他們所提出的問題？

    1. (A) 直接民主
    2. (B) 代議政府
    3. (C) 官僚體系
    4. (D) 集權政府

    正解：(D)

  16. 16Elmore（1978）將政策執行的組織研究分為四種模式：系統管理模式（systems management model） ＿＿＿ 、官僚過程模式（bureaucratic process model）、組織發展模式（organizational development model）、衝突協調模式（conflict and bargaining model），若用上述四模式與警察機關組織文化相呼應，下列敘述何者正確？

    1. (A) 以官僚過程模式的思維，警察機關發展出以破案為目標及績效掛帥的組織文化是可以預期的
    2. (B) 以組織發展模式的思維，行政人員對例行承辦工作的熟悉，架空了來自長官的控制力量，警察組織基層承辦人與業者的掛勾可能在此情況下產生
    3. (C) 以系統管理模式的思維，社區警政要求警察管理幹部視基層為內在顧客，擴大參與決策，尊重基層意見
    4. (D) 以衝突協調模式的思維，警察組織中的刑事警察與制服警察的衝突妥協，就是屬於此模式

    正解：(D)

  17. 17Fischer 提出公共政策的批判評估（critical evaluation of public policy）四種分析，包含技術印證（technical verification）、情境確證（situational validation）、系統驗證（system vindication）和理性的社會選擇（rational social choice）。若將上述四種分析應用於警察政策評估，下列敘述何者正確？

    1. (A) 測量警力之運用是否有效達成目標，此即「系統驗證」的政策評估
    2. (B) 社區治安問題的認定應重視社區民眾的需求與意見，此即「情境確證」的政策評估
    3. (C) 將警察政策評估提升至總體評估的層次，此即「理性的社會選擇」的政策評估
    4. (D) 警察在維持秩序與保障人權之間的價值澄清與組合，此即「技術印證」的政策評估

    正解：(B)

  18. 18Stone 對於政策分析的觀點與三部分的架構，下列敘述何者錯誤？

    1. (A) 許多的政策決定可用理性模式解釋
    2. (B) 目標指的是政策尋求的價值
    3. (C) 問題指的是目標與現狀的差異
    4. (D) 解決方案指的是處理政策問題的工具

    正解：(A)

  19. 19Peel 爵士在 1829 年創立了第一個現代化警察組織之後，警察成為一種專門職業，其創立地點在下列何處？

  21. 21Reppetto 曾指出警察機關對付犯罪必須靠嚇阻、犯罪偵查及犯罪人的逮捕三項策略來達成。而三項策略也必須靠下列四項勤務活動來達成，下列何者錯誤？

    2. (B) 守勢巡邏（Defensive Patrol）

  22. 22Felson & Clarke 認為「機會」是所有犯罪行為的根本，並列舉出 10 項機會原理，說明機會如何形塑犯罪行為。下列所述各項原理何者錯誤？

    4. (D) 致力減少犯罪機會，可擴大犯罪數量的降幅

  23. 23在警察角色的變遷過程中，警察由傳統秩序維持者轉換到具有社區警政之特點，下列敘述何者錯誤？

    1. (A) 警察的工作範疇不再是以犯罪為中心，也強調為民服務

    正解：(C)

  24. 24少年事件處理法於 2019 年的修正，為自 1997 年以來最大幅度的修正，也是與世界兒少司法權益潮流接軌的重要里程碑。對本次修法重點的敘述，下列何者錯誤？

    1. (A) 廢除觸法兒童準用少年事件處理法之規定
    2. (B) 建置曝險少年司法先行機制
    3. (C) 尊重少年主體權及保障程序權
    4. (D) 引進少年修復式機制

    正解：(B)

  25. 25Sherman 等人針對見警率效能進行名為「Minneapolis 市熱點巡邏實驗」（Minneapolis Hot SpotsPatrol Experiment）的實證檢驗。關於該實驗的研究結果，下列敘述何者錯誤？

    1. (A) 警察如果頻繁且隨機在不同熱點之間輪換巡邏，犯罪預防效果較佳
    2. (B) 如果長時間在同一熱點內巡邏，效果反而有限
    3. (C) 警察停留熱點的時間越長，該熱點就能在警察離開後有越長的時間免於犯罪，但這種關係僅限於某範圍之內
    4. (D) 僅駕警車駛過熱點未做停留，仍有一定程度的犯罪預防效果產生

    正解：(D)
