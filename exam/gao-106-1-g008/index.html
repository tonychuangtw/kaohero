  1. 1假設整個經濟體系只有兩人（A 與 B）兩財（X 與 Y）且生產資源與技術水準固定，如果在目前的資源配2 2 3置下， MRS AXY = ； MRS BXY = ； MRTXY = ，則：3 3 4

    1. (A) 資源配置已達柏瑞圖最適境界
    2. (B) 可透過增產 X 來增進效率
    3. (C) 可透過增產Ｙ來增進效率
    4. (D) 已經找不到可以產生柏瑞圖改善（Pareto improvement）的資源重配置方式

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 兩人的 MRS 均為 2/3，低於 MRT 的 3/4，表示社會生產 X 的機會成本高於消費者願意付出的代價，應減產 X、增產 Y 以提升效率。

    ❌ (A) 效率條件要求 MRS ＝ MRT，本題並未成立。

    ❌ (B) 增產 X 將使偏離更大。

    ❌ (D) 仍存在可改善的重配置方式。

    📚 出處：福利經濟學－生產與交換的整體效率條件。

  2. 2所謂將個人的需求曲線「水平加總」而成社會的總需求曲線，是指：

    1. (A) 在相同的價格下，將每人個別的消費數量加總而得
    2. (B) 在相同的數量下，將每人個別的願付價格加總而得
    3. (C) 在不同的價格下，將每人相同的消費數量加總而得
    4. (D) 在不同的數量下，將每人相同的願付價格加總而得

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 私有財的市場需求為在同一價格下，將各人的需求量沿數量軸相加。

    ❌ (B) 在同一數量下加總願付價格者為公共財的垂直加總。

    ❌ (C) 水平加總以相同價格為前提。

    ❌ (D) 該敘述與任何加總方式均不符。

    📚 出處：財政學－私有財與公共財的需求加總。

  3. 3下列對金融性外部性（pecuniary externality）的敘述，何者正確？

    1. (A) 會造成超額儲蓄的問題
    2. (B) 會造成呆帳過多的可能
    3. (C) 會造成市場失靈的發生
    4. (D) 會造成資源分配的改變

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 金融性外部性透過價格機能改變所得分配與資源配置，但不使私人成本偏離社會成本。

    ❌ (A) 其與儲蓄水準無直接關聯。

    ❌ (B) 呆帳問題屬信用風險。

    ❌ (C) 其不造成效率損失，非市場失靈。

    📚 出處：財政學－技術性外部性與金融性外部性。

  4. 4當財貨為公共財、市場存在正外部性與負外部性的現象時，下列敘述何者正確？

    1. (A) 由市場自行決定的均衡數量均會小於社會的最適數量
    2. (B) 只有正外部性不會造成效率的損失，其餘兩者都會
    3. (C) 三者均可透過寇斯定理（Coase Theorem）來達成社會的最適數量
    4. (D) 三者均會造成市場失靈
