    4. (D) ไปสําแดงสิ่งของต่อเจ้าหน้าที่ด่านศุลกากรก่อนเข้าไต้หวันความขยันความขยันไม่ได้เป็ นเรื่องเกี่ยวกับกรรมพันธุ์ แต่เป็ นพฤติกรรมที่ติดตัวมาเป็ นเวลานาน จึงต้องมี

    正解：(D)

  76. 76ข้อใดเป็ นการปลูกฝั งความขยันที่เหมาะสม

    1. (A) มานะรับจ้างทําการบ้านให้เพื่อน เพื่อหารายได้ระหว่างเรียน
    2. (B) หลังเลิกเรียนนารีช่วยคุณแม่ทํางานบ้านก่อนจะทบทวนบทเรียนและเข้านอนตรงเวลาทุกคืน
    3. (C) อรอนงค์ไม่สนใจเข้าร่วมงานกีฬาสีของโรงเรียน เพราะต้องอ่านหนังสือเตรียมตัวสอบเข้ามหาวิทยาลัยในปี หน้า
    4. (D) เดชาไปโรงเรียนสายเกือบทุกวัน เพราะซ้อมฟุตบอลจนดึกดื่น

    正解：(B)

  77. 77ข้อใดไม่สอดคล้องกับบทความข้างต้น

    1. (A) สุชาติเป็ นคนขยันเหมือนพ่อ เพราะได้รับการถ่ายทอดทางกรรมพันธุ์
    2. (B) เปรมใจเป็ นคนเกียจคร้านเพราะฉะนั้นเธอจะประสบความสําเร็จในชีวิตอย่างแน่ นอน
    3. (C) ชาติชายเป็ นนักกีฬาที่สร้างชื่อเสียงให้โรงเรียน จึงไม่ต ้องสนใจผลการเรียน
    4. (D) ถูกทุกข้อ

    正解：(D)

  78. 78ข้อใดเป็ นกิจกรรมที่เหมาะสมสําหรับการจัดเวลาให้เด็กเข้าร่วม

    1. (A) เล่นตะกร้อ
    2. (B) สูบบุหรี่
    3. (C) เที่ยวกลางคืน
    4. (D) เล่นไฮโล

    正解：(A)

  79. 79ข้อใดเป็ นคําตรงข้ามของคําว่าความขยัน

    1. (A) ความล้มเหลว
    2. (B) ความขัดสน
    3. (C) ความเกียจคร้าน
    4. (D) ความสําเร็จ

    正解：(C)

  80. 80จากบทความข้างต้น การปลูกฝั งความขยันให้บุตร ควรจะเริ่มทําตั้งแต่เมื่อใด

    1. (A) ยังอยู่ในครรภ์
    2. (B) ยังอ่อนวัย
    3. (C) เรียนจบมหาวิทยาลัย
    4. (D) หลังแต่งงาน

    正解：(B)
