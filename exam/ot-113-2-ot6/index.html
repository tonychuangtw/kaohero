  2. 2個案80歲，有心臟病史，因中風導致慣用側右側偏癱，目前僅右手手肘可主動彎曲抬至約胸口高度，可獨立坐穩但無法行走，職能治療師建議下列之處置，何者最不適當？

  12. 12關於表現分析（performance analysis）與任務分析（task analysis）的敘述，下列何者錯誤？

    1. (A) 任務分析的目的為確認影響個體職能表現的潛在因素，如個人因素、環境因素、身體功能等
    2. (B) 表現分析的目的在於減輕個案所碰到的問題
    3. (C) 表現分析用於確認個體執行的是有效率或無效率的任務行動（task action）
    4. (D) 任務分析可確認任務的既有治療價值，以修復潛在的損傷

    正解：(B)

  13. 13職能治療師針對穿襪子進行「活動分析」，下列敘述何者最不屬於此分析？

    2. (B) 根據職能治療實務架構（Occupational Therapy Practice Framework, OTPF, 2014）的過程技巧，如適應技巧（accommodates）不佳，個體無法解決襪子穿上下顛倒的問題
    3. (C) 職能治療師會分析個體平常穿襪子時的情境、有無人協助穿襪子以及穿襪子對個體的意義
    4. (D) 職能治療師會分析穿襪子時需使用的材料、空間以及步驟

    正解：(C)

  18. 18關於標準化表現分析（standardized performance analysis）及非標準化表現分析（nonstandardizedperformance analysis）的比較，下列何者最不適當？

  30. 30下列有關效度（validity）的敘述，何者正確？

    1. (A) 表面效度（face validity）指評估工具可測量到特定理論概念及其潛在之組成
    2. (B) 因素分析（factor analysis）是驗證評估工具之效標效度（criterion validity）的一種方法
    3. (C) 一般來說，若專家認為「評估項目內容與特定主題有關」之一致性達50%，則可宣稱該項目具備內容效度（content validity）
    4. (D) 同時效度（concurrent validity）與預測效度（predictive validity）都屬於效標效度（criterionvalidity）的範疇

    正解：(D)
