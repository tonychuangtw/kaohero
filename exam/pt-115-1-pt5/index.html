物理治療師　115 年第一次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1有關 slouched posture 容易伴隨發生之結構變化，下列敘述何者錯誤？

    1. (A) 前位頭部（forward head）
    2. (B) 胸椎後凸（kyphosis）
    3. (C) 下胸椎的伸肌短縮
    4. (D) 下腰椎的小面關節擠壓

    正解：(C)

  2. 2下列那些治療方法對於緊張性頭痛（tension headache）最為恰當？①放鬆頭直後大肌（rectus capitisposterior major） ②牽張頭長肌（longus capitis） ③訓練前鋸肌（serratus anterior）肌耐力 ④訓練提肩胛肌（levator scapulae）肌耐力

    1. (A) ①②
    2. (B) ③④
    3. (C) ①③
    4. (D) ②④

    正解：(C)

  3. 3有關下頜骨的前突與後縮（protrusion and retrusion of mandible），下列敘述何者錯誤？

    1. (A) 若下頜骨前突幅度為 7.5 毫米，視為正常
    2. (B) 當下頜骨前突時，下頜髁與關節間盤（articular disc）需同時向下向前移動
    3. (C) 顳肌的後束（posterior fiber）可以使下頜骨後縮
    4. (D) 當下頜骨完全後縮時，顳頜關節是處於最鬆弛的位置

    正解：(D)

  4. 4下列何者不是張嘴時顳頜關節發出喀啦（clicking）聲的可能原因？

    1. (A) 顳頜關節之間盤障礙（derangement）
    2. (B) 內翼肌（medial pterygoid）與外翼肌（lateral pterygoid）之間收縮不協調
    3. (C) 顳頜關節之間盤前移
    4. (D) 張嘴時的第一個喀啦聲是由於下頜髁通過顳頜關節之間盤後側

    正解：(B)

  5. 5下列何者可直接判斷是否有 Bakody's sign？

    1. (A) shoulder abduction（relief）test
    2. (B) shoulder depression test
    3. (C) ULTT4（upper limb tension tests 4）
    4. (D) brachial plexus tension test

    正解：(A)

  6. 6下列何種測試是以症狀消失或是降低做為陽性的判斷標準？

    1. (A) 頸椎壓迫測試（spurling test）
    2. (B) 頸椎拉離測試（distraction test）
    3. (C) 上臂神經張力測試（upper limb tension tests）
    4. (D) 魯氏測試（Roos test）

    正解：(B)

  7. 7執行頸椎徒手牽引治療時，若希望縱向拉力能產生於 C5-6 及 C6-7 處，則病患的頸椎應擺在下列那個位置較佳？

  8. 8有關胸椎關節鬆動術之後前向單側脊椎壓力（posteroanterior unilateral vertebral pressure）的敘述，下列何者正確？

    2. (B) 施測者的施力位置在棘突的頂端
    3. (C) 對脊椎會造成旋轉的力量（rotary force）
    4. (D) 施測者對脊椎施以一橫向力量

    正解：(C)

  9. 9根據 Quebec 揮鞭式創傷相關疾患任務小組（The Quebec Task Force on Whiplash Associated Disorders）使用準則，下列何者符合等級 II 之臨床表徵敘述？

    2. (B) 觸診時有壓痛點且頸椎有活動度降低，但無神經病變相關症狀
    3. (C) 頸椎活動度正常，但核磁共振影像顯示椎間盤損傷
    4. (D) 觸診時有壓痛點，但頸椎活動度正常且無神經病變相關症狀

    正解：(B)

  10. 10有關上交叉症候群（upper crossed syndrome）之敘述，下列何者正確？

    2. (B) 過緊的提肩胛肌及前鋸肌、無力的胸小肌及頸部深層屈肌
    3. (C) 過緊的胸大肌及頸部深層屈肌、無力的提肩胛肌及前鋸肌
    4. (D) 過緊的胸小肌及前鋸肌、無力的提肩胛肌及頸部深層屈肌

    正解：(A)

  11. 11一位下背痛患者主訴 1 週前向前彎腰搬約 15 公斤重的工具箱時，出現下背中央疼痛及肌肉僵硬，3 天後向前彎腰漱口時，背痛延伸至右邊臀部及大腿後側，平時於站立姿勢或走路時背痛較為緩解，坐姿及向前彎腰時疼痛特別明顯。近日抱怨 2 天前，在一次打噴嚏後，突然感覺疼痛延伸至右小腿，且患者自覺姿勢因受傷而改變，站立時呈現雙肩水平向左偏移。有關此個案的治療，下列何者不適合？

    4. (D) 在功能性姿勢下進行運動

  12. 12一位腰椎退化（spondylosis）的患者，腰部向右側彎、後仰等動作會增加右大腿後面的針刺感，向前彎時針刺感會減輕或消失。有關此患者的治療，下列何者正確？

    2. (B) 患者側躺左側，肩關節下方墊毛巾，讓腰椎呈現右側彎及左旋轉的姿勢牽引
    3. (C) 患者側躺左側，腰部下方墊毛巾，讓腰椎呈現左側彎及右旋轉的姿勢牽引
    4. (D) 患者側躺右側，腰部下方墊毛巾，讓腰椎呈現右側彎及右旋轉的姿勢牽引

    正解：(C)

  13. 13有關物理治療師評估患者的腹肌耐力，下列敘述何者正確？

    1. (A) 動態耐力的評估為在仰臥下雙腳彎曲平放床面，雙手伸直放身體旁邊，然後縮下巴將上半身提起至肩胛骨離開床面，以每分鐘 25 下的節律進行，計算患者最多可重複的次數
    2. (B) 靜態耐力的表現以等速收縮維持姿勢來評估
    3. (C) 靜態耐力的評估，雙手抱胸前最難，其次是雙手抱頭後，雙手向前伸直為最容易
    4. (D) 在仰臥下雙腳彎曲平放床面，雙手伸直朝向膝關節將上半身提起到肩胛骨離開床面，維持 15 秒鐘，評分為Poor

    正解：(A)

  14. 1462 歲男性病人出現雙側下肢疼麻症狀，腿部症狀比腰部症狀明顯，走路或站立時症狀增加，坐下時症狀減少，下列何者為最有可能的問題？

  15. 15肩盂肱關節（glenohumeral joint）前後方向 X 光攝影，發現盂窩（glenoid fossa）有「空」（empty）的現象。下列何者是最有可能的問題？

  17. 17一位業餘攀岩者在吊掛的時候，肩部被拉扯時產生疼痛，經影像診斷為 SLAP 傷害，攀岩者想先嘗試保守治療，下列治療安排何者錯誤？

  25. 25下列關於骨質疏鬆之敘述，何者錯誤？

    2. (B) 骨質密度檢查結果通常以年輕白種女性資料做標準，區分為正常、骨質缺乏（osteopenia）、骨質疏鬆
    3. (C) 常發生在體重過重的老年人身上
    4. (D) 骨質疏鬆患者易有脊椎、髖部或腕部的骨折

  26. 26關於骨質疏鬆與運動之敘述，下列何者錯誤？

    4. (D) 骨質疏鬆患者若有跌倒風險，則運動治療中需加入平衡訓練，以避免因跌倒而骨折的發生

  31. 31有關傷口處理的敘述，下列何者正確？

    2. (B) 有嚴重動脈硬化的肢體水腫，應給與彈性繃帶或彈性襪，來降低水腫

    4. (D) 糖尿病神經病變的足部潰瘍患者，應克服患肢感覺遲鈍的問題，增加患肢載重的練習

  32. 32有關三級淋巴水腫象皮病（lymphostatic elephantiasis）的敘述，下列何者錯誤？

  33. 33關於腰椎旁肌肉與相對應的轉移痛（referred pain），下列何者正確？

    1. (A) 腰髂肋肌（iliocostalis lumborum）的轉移痛常會出現在脊椎外側，薦椎到臀裂口，小腿後側
    2. (B) 多裂肌（multifidus）的轉移痛常會出現在 T9～T11 的脊椎外側，肋骨後側區域

    4. (D) 腹肌（abdominals）的轉移痛常會出現在 T10 肋骨下緣，脊椎外側，往下到尾椎

    正解：(C)

  34. 34一名患者在四足跪姿下，執行背旋轉肌測試（back rotator test），測試得分為普通（Fair），這是指能完成下列那一項指示？

    3. (C) 在單側手和對側腳同時抬起時，能維持骨盆正中，至少持續 20 秒
    4. (D) 在一隻手抬起時，無法維持骨盆正中

    正解：(A)

  35. 35患者出現尿失禁、排尿困難或鞍狀麻木（saddle anesthesia）等現象，最有可能的是下列那一類腰椎椎間盤突出？

    正解：(B)

  69. 69下列何者不是檢測踝關節韌帶聯合（syndesmosis）的測試？

    3. (C) 腓骨位移測試（fibular translation test）
    4. (D) 外轉壓力測試（external rotation stress test）

    4. (D) 阿基里斯腱慢性病變於手術約 6～10 週後，方可開始患側下肢承重訓練
