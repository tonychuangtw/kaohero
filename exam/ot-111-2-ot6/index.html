職能治療師　111 年第二次 職能治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1職能治療師對於手傷個案處置，應以下列何者為最終目標？

    1. (A) 增加關節活動度
    2. (B) 增進肌肉力量
    3. (C) 進行感覺再教育
    4. (D) 改善職能表現

    正解：(D)

  2. 2王先生是C7脊髓損傷的個案，但仍希望每天外出賣彩券以自食其力，下列何者最適當？

    1. (A) 建議個案使用手推輪椅，以維持肌力
    2. (B) 建議個案使用電動輪椅，以增加行動力
    3. (C) 訓練使用助行器及穿戴支架外出賣彩券
    4. (D) 建議個案請人幫他推輪椅，以方便外出

    正解：(B)

  3. 3林先生是一位慣用右手的國中數學老師，中風後造成右側偏癱，無法用右手拿湯匙吃飯，但可以拿柺杖走路至少30分鐘。下列項目為林先生的工作內容，若林先生仍然慣用右手，何者最可能出現問題？①搭捷運上下班②依照課表時間到各班教室上課 ③上課時站在講台前，用粉筆將課程內容寫在黑板上 ④下課走回辦公室休息 ⑤參加教務、學務、親師等會議 ⑥在辦公室批改作業 ⑦在辦公室吃便當 ⑧約學生或家長懇談

    1. (A) ①②④
    2. (B) ②④⑥
    3. (C) ③⑥⑦
    4. (D) ⑤⑦⑧

    正解：(C)

  4. 4操作物件時，可以平穩且順利地使用手與手腕動作。此定義最符合下列那一種表現技巧（performanceskills）？
