  1. 1下列何者為美國資訊科學學會（American Society for Information Science, ASIS）之前身？

    1. (A) 美國計算機學會（Association for Computing Machinery, ACM）
    2. (B) 美國圖書館學會（American Library Association, ALA）文獻學委員會（Interdivision Committee onDocumentation）
    3. (C) 美國文獻學學會（American Documentation Institute, ADI）
    4. (D) 美國圖書館學會（American Library Association, ALA）資訊科學與自動化委員會（Information Science andAutomation Division）

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 美國資訊科學學會（ASIS）的前身為 1937 年成立的美國文獻學學會（American Documentation Institute, ADI），1968 年改名。

    ❌ (A) ACM 為計算機領域的專業學會，與 ASIS 無淵源。

    ❌ (B) ALA 的文獻學委員會非 ASIS 的前身。

    ❌ (D) ALA 的資訊科學與自動化委員會後來發展為 LITA。

    📚 出處：美國資訊科學學會的沿革

  3. 3「人們會有尋找資訊的需求，源於人們認知到自己既有的知識體系發生異常的狀態或呈現不尋常的狀況」最 符合下列何項資訊行為理論的解釋？

    1. (A) 知識渾沌說（Anomalous State of Knowledge）
    2. (B) 採莓說（Berry-picking Model）
    3. (C) 意義建構論（Sense-making Model）
    4. (D) 資訊搜尋歷程（Information Search Process）

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) Belkin 的知識渾沌說主張使用者因察覺自身知識結構出現異常或不足，而產生資訊需求。

    ❌ (B) 採莓說強調檢索過程中查詢逐步演進、片段蒐集資訊。

    ❌ (C) 意義建構論著重使用者跨越認知鴻溝以建構意義的歷程。

    ❌ (D) 資訊搜尋歷程描述搜尋各階段的情感與認知變化。

    📚 出處：Belkin 的 Anomalous State of Knowledge（ASK）
