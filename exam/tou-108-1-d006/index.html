  1. 1patienter un instant, s’il vous plaît, la porte sera ouverte.

    1. (A) Vouloir
    2. (B) Voulez
    3. (C) Veuillez
    4. (D) Voudriez

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) Veuillez 是 vouloir 的第二人稱複數命令式（不規則形），專用於客套請求，後面直接接原形動詞：Veuillez patienter un instant（請稍候）。

    ❌ (A) Vouloir 是原形動詞，不能單獨放句首當祈使語氣，句子缺少命令式的動詞形態。

    ❌ (B) Voulez 是現在式陳述形，要表達請求須倒裝成疑問句 Voulez-vous patienter ?，不能當命令式用。

    ❌ (D) Voudriez 是條件式，必須與主詞倒裝成 Voudriez-vous patienter ?，不可省略主詞單獨使用。

    📚 出處：法語命令式不規則變化（veuillez / sachez / soyez）

  2. 2A : Pourrais-je avoir un rendez-vous avec M. Dupont ?B : M. Dupont est en rendez-vous. Vous ＿＿＿ laisser votre carte...

    1. (A) devrez
    2. (B) devez
    3. (C) devoir
    4. (D) devriez

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) devriez 是 devoir 的條件式現在時，用來委婉建議「您或許可以留下名片」，符合飯店或辦公室對客人說話的禮貌語氣。

    ❌ (A) devrez 是簡單未來式，表示「您將必須」，語氣是預告義務，對客人失禮。

    ❌ (B) devez 是現在式，表示強制義務「您必須」，命令感太強，不適合服務場合。

    ❌ (C) devoir 是原形，主詞 Vous 後面必須用限定式動詞變化，文法不成立。

    📚 出處：條件式現在時的委婉建議用法（conditionnel de politesse）

  3. 3Comment s’appelle le professionnel qui traite les billets de transports touristiques ?

    1. (A) billettiste
    2. (B) billetteur
    3. (C) billetterie
    4. (D) billeter

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) billettiste 指旅遊業中專責處理機票、車票等票務的從業人員，字尾 -iste 表示人，正是題目問的職稱。

    ❌ (B) billetteur 不是法語旅遊業的正式職稱，標準用語中並無此職業名稱。

    ❌ (C) billetterie 指票務部門、售票處或售票系統，是地點或業務，不是人。

    ❌ (D) billeter 形式上像動詞，並非既有的法語詞，也不能當職業名稱。

    📚 出處：旅遊業職稱字彙（billettiste / agent de voyages / voyagiste）
