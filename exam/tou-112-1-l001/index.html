  29. 29當團員在旅途中發生傷病事故，領隊人員之處理原則下列何者最不適當？

    2. (B) 領隊人員必須協助團員申請或收集相關醫療單據與醫師診斷證明，以備後續保險理賠之需要
    3. (C) 必須向家屬說明相關醫療費用的支付原則，例如因個人疾病所衍生之住院費用，須由團員自行負擔
    4. (D) 發生團員傷病狀況，領隊人員在處理好病人之後，需向其他團員說明狀況，以安撫團員心裡之疑慮或不安

    正解：(A)

  30. 30團員在旅途中突發病症，領隊人員的處理方式，下列何者最不適當？

    2. (B) 若團員狀況嚴重，必須安排就醫，並應尋求當地接待旅行社安排人員在醫院協助及照顧
    3. (C) 若安排團員住院治療，則必須通報出團旅行社及團員家屬
    4. (D) 團員經過治療後，醫生評斷可繼續完成旅程，領隊人員應隨時注意團員狀況，並回報訊息給出團旅行社相關部門

    正解：(C)

  40. 40出國旅遊往往會因為各種主客觀因素，而產生不同類型的旅遊糾紛，下列有關旅遊糾紛之敘述，何者不是歸屬於領隊專業不足之問題？

    1. (A) 不熟悉轉機手續，遲誤中轉班機
    2. (B) 對觀光景點不熟悉，解說介紹有誤
    3. (C) 對退稅手續不熟悉，導致旅客無法辦理退稅
    4. (D) 航空公司機位超售，導致旅客無法成行

    正解：(D)

  41. 41觀光旅遊團體住宿的飯店半夜突然發生火警時，警鈴大響，濃煙密布。領隊人員遇到火警發生危及旅客生命安全，依據緊急處理原則，下列敘述何者錯誤？

    1. (A) 速搭乘電梯至每個樓層，高聲喊叫所有團員逃生
    2. (B) 時間許可之下迅速敲打和自己同一層樓團員的房門
    3. (C) 指引旅客循出口指示方向，由防火梯逃生
    4. (D) 以濕毛巾掩住口鼻以防嗆到，以低姿勢逃離

    正解：(A)

  42. 42領隊人員帶團期間，得知團體所預定的航空公司空服員正醞釀罷工，回程航班可能因而取消或延誤。下列敘述何者錯誤？

    1. (A) 部分團員急於返國，可提出終止旅遊契約要求，請求旅行社先墊付由當地飛返臺灣之機票費用，旅客應於返國後加息償還給旅行社
    2. (B) 在未接獲航空公司正式通知航班取消前，領隊人員仍應依照原訂回程日期及航班時間，帶領團體至機場報到櫃台集合，避免旅客權益受損
    3. (C) 若接獲航空公司正式通知回程航班取消，領隊人員應以維護旅客權益為第一優先考量，妥善處理旅客用餐與住宿問題，並安排轉乘其他航班返國
    4. (D) 航空公司空服員罷工，屬不可抗力或不可歸責於旅行社與旅客雙方當事人之事由，所有因班機延誤或取消而產生的費用，一律向旅客收取支付

    正解：(D)

  43. 43旅客當初繳付訂金及簽定旅遊契約書時，即明白行程中會安排購物行程，而旅遊第 3、4 天，接連的購物站行程。旅客拒絕下車購物，當地導遊就將旅客留置於車上，場面頗為尷尬。下列敘述與處置何者較為適當？

    1. (A) 面對旅客與當地導遊之紛爭，領隊人員應該勸說旅客配合入店購物
    2. (B) 面對旅客與當地導遊之紛爭，領隊人員應該勸說導遊放棄購物行程
    3. (C) 如果行程表中已載明購物行程，領隊人員強制旅客配合入內參觀購物
    4. (D) 如果行程表中已載明購物行程，旅行業者安排旅客前往並無不妥

    正解：(D)

  44. 44歐洲行程，團員常要求領隊人員帶領夜遊活動，以下領隊人員之各個處理選項，何者最不適當？

    1. (A) 歐洲地區常有旅客被搶事件，領隊人員應委婉跟團員說明並婉拒帶領夜遊
    2. (B) 如果團員堅持前往，應告知將貴重物品寄放保險箱，僅攜帶必要錢財物品
    3. (C) 夜遊出門應儘量安排單獨搭乘大眾交通工具，方能分散歹徒覬覦目標
    4. (D) 向團員說明，帶領夜遊純屬服務性質，團員亦應照顧自身安全

    正解：(C)

  45. 45下列何者不是旅行業者經常利用附加費用之方式，轉向團體旅遊旅客收取費用之項目？

  46. 46旅客參加團費新臺幣 3 萬元之泰國 5 天團體；因 OP 作業疏失，未訂妥回程機位，未能按原定 3 月 7 日中午 13：10 起飛之班機返國，導致旅客留滯曼谷，延到 3 月 8 日下午 19：30 才搭機返國。依國外旅遊定型化契約書範本之規定，旅行社除應負擔旅客留滯期間之食宿及其他必要費用之外，應賠償每名旅客新臺幣多少元？
