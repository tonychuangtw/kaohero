警察特考　113 年 三等考試 警察組織與事務管理　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1學者大多認為當代警察的起源，應追溯至英國的工業革命及下列何者？

    1. (A) 憲政體制之改革
    2. (B) 社會制度的轉變
    3. (C) 司法制度之演進
    4. (D) 全球殖民地之擴展

    正解：(B)

  2. 2從我國警察組織之演進觀察，在民國三十八年臺灣宣布戒嚴後，下列何者是戒嚴時期的警政特色？

    1. (A) 地方領導
    2. (B) 業務單純不受干擾
    3. (C) 軍人首長
    4. (D) 社會福利行政之推廣

    正解：(C)

  3. 3依據內政部警政署組織法規定，有關內部單位設置業務單位與輔助單位，下列何者屬於輔助單位？

    1. (A) 勤務指揮中心
    2. (B) 督察室
    3. (C) 保安組
    4. (D) 教育組

    正解：(B)

  4. 4警察行使職權，不得逾越所欲達成執行目的之必要限度，且應以對人民權益侵害最少之適當方法為之。上述為警察執法之何項原則？

    1. (A) 比例原則
    2. (B) 平等原則
    3. (C) 信賴保護原則
    4. (D) 不當聯結禁止原則

    正解：(A)

  5. 5從警政策略與法制而言，警察勤務機構，區分為基本單位、執行機構及下列何者？

    1. (A) 民間協力機構
    2. (B) 即時強制機構
    3. (C) 規劃監督機構
    4. (D) 委託執行機構

    正解：(C)

  6. 6警察勤務區，簡稱警勤區，是警察勤務的基本單位，在警察行政組織職權上屬於：

    1. (A) 事務管轄
    2. (B) 土地管轄
    3. (C) 時效管轄
    4. (D) 層級管轄

    正解：(B)

  7. 7警察身為公務員遇有請託關說時，應如何處理？

    1. (A) 應當場對關說者予以逮捕並移送法辦
    2. (B) 只須對關說者訓示曉以大義
    3. (C) 應於三日內簽報長官並知會政風機構
    4. (D) 在不影響公務運作且未有違法情事下，可視為為民服務

    正解：(C)

  8. 8警察身為公務員遇有受贈財物情事，應依相關規定程序處理，下列敘述何者錯誤？

    1. (A) 公務員不得要求、期約或收受與其職務有利害關係者餽贈財物
    2. (B) 有屬公務禮儀之情形，且係偶發而無影響特定權利義務之虞時，得受贈之
    3. (C) 除親屬或經常交往朋友外，與其無職務上利害關係者所為之餽贈，市價超過正常社交禮俗標準時，應於受贈之日起三日內，簽報其長官，必要時並知會政風機構
    4. (D) 各機關之政風機構應視受贈財物之性質及價值，可各自依職權提出付費收受、歸公、轉贈慈善機構或其他適當建議

    正解：(D)

  9. 9政府機關（構）、部隊、學校、機構或僱用人於公共場所有性騷擾事件發生當時知悉者，應採取各項有效之糾正及補救措施，並注意被害人安全及隱私之維護，下列何者非屬於上述措施？

    1. (A) 協助被害人申訴及保全相關證據
    2. (B) 必要時協助通知警察機關到場處理
    3. (C) 避免媒體採訪並隔離被害人
    4. (D) 檢討所屬場所安全

    正解：(C)

  10. 10關於我國警察組織性別政策之推動以及婦幼保護工作之相關沿革，下列敘述何者正確？

    1. (A) 我國於 1960 年始有女性進入警察組織
    2. (B) 內政部於 2000 年 12 月召開「研商警察機關女性員警政策」後，促成女警政策的法制化
    3. (C) 臺灣地區自 1973 年即有「女子警察隊」之設置
    4. (D) 內政部於 2005 年 9 月全面成立「婦幼警察隊」

    正解：(D)

  11. 11性平三法於民國 112 年修正後，今（113）年 3 月 8 日正式上路，下列敘述何者正確？

    1. (A) 性平三法分別為「性別工作平等法」、「性別平等教育法」以及「性騷擾防治法」
    2. (B) 由於臺灣 MeToo 風潮促使性平三法修法，重點增訂權勢性騷類型，未來雇主、機關首長、負責人、校長等涉性騷擾案件，受害者除了一般性賠償外，還能請求最高 3 倍的「懲罰性賠償」，且於刑事責任部分，加重其刑二分之一，最重達五年
    3. (C) 雇主接獲被害人申訴時，應通知地方主管機關；經調查認定屬性騷擾之案件，並應將處理結果通知地方主管機關
    4. (D) 申訴案件經雇主或地方主管機關調查後，認定為性騷擾，且情節重大者，雇主得於知悉該調查結果之日起三十日內終止勞動契約，惟必須預告予當事人知悉

    正解：(C)

  12. 12我國在提升婦女權益方面通過了多項重要法律，下列何者正確？

    1. (A) 「特殊境遇婦女家庭扶助條例」之立法目的主要為扶助特殊境遇家庭婦女解決生活困難，給予緊急照顧，協助其自立自強及改善生活環境
    2. (B) 「家庭暴力防治法」允許家庭暴力受害者申請最長為一年的保護令
    3. (C) 我國順應世界潮流通過了「消除對婦女一切形式歧視公約施行法」，將 CEDAW 納入國內法
    4. (D) 「婦女權益保障法」要求公私部門中每個管理階層至少有一定比例的女性

    正解：(C)

  13. 13社區警政為警察帶來了潛在的利益，下列何者非屬之？

    1. (A) 當地民眾的支持
    2. (B) 提升警察士氣
    3. (C) 提升員警工作滿足感
    4. (D) 促進各政黨之發展

    正解：(D)

  14. 14警察需要與民間社會協力，才能進一步長久維持良好的治安，此已為各界共識，下列何者非屬於社區警政的範圍？

    1. (A) 各地方成立警友會
    2. (B) 守望相助活動之推展
    3. (C) 警察與保全密切合作
    4. (D) 綠能環境之建設與發展

    正解：(D)

  15. 15警政之推展不只著重犯罪之壓制與偵查，並應強調犯罪之預防，且以社區內民力之運用與各機關之合作，係為世界各先進國家警政發展之主流，此在學理上可稱為：

    1. (A) 脫警察化
    2. (B) 警政社區化
    3. (C) 警察公共原則
    4. (D) 警察職務協助

    正解：(B)

  16. 16警察組織預算制度，下列敘述何者錯誤？

    1. (A) 警政署編列單位預算
    2. (B) 警察廣播電台編列附屬單位預算
    3. (C) 警察消防海巡移民空勤人員及協勤民力安全基金編列附屬單位預算
    4. (D) 雲林縣警察局編列單位預算

    正解：(B)

  17. 17依照規定，警察組織內的各種會計報告、帳簿及重要備查簿，與機器處理會計資料之貯存體暨處理手冊，自總決算公布或令行日起，在警政署、刑事警察局中的財務會計報告各至少保存幾年？

    1. (A) 五年、三年
    2. (B) 十年、五年
    3. (C) 十五年、十年
    4. (D) 二十年、十五年

    正解：(B)

  18. 18警察組織預算執行後必須有相關憑證進行核銷登載，其中收入傳票的性質屬於：

    1. (A) 外來憑證
    2. (B) 原始憑證
    3. (C) 記帳憑證
    4. (D) 內部憑證

    正解：(C)

  19. 19政府採購法第 30 條規定，機關辦理採購應於招標文件中規定投標廠商須繳納押標金，得標廠商必須繳納保證金，關於押標金及保證金規定，下列何者正確？

    1. (A) 勞務採購，以免收押標金、保證金為原則
    2. (B) 押標金的繳納得以現金方式附於投標文件內遞送
    3. (C) 採限制性招標方式，機關直接向廠商邀標、議價，得免收押標金及保證金
    4. (D) 機關允許外國廠商參與之採購，外國廠商來投標不得以外幣繳納押標金，亦不得以外幣進行報價

    正解：(A)

  20. 20政府採購法第 2 條明定政府採購依其性質有工程、財物以及勞務採購三種標的，下列敘述何者正確？

    1. (A) 統包適用於工程、財物及勞務採購
    2. (B) 共同投標適用於工程、財物及勞務採購
    3. (C) 共同供應契約適用於工程、財物及勞務採購
    4. (D) 社團法人臺北市警察之友會理事長為體恤臺北市警察同仁辛苦執勤，於警察節向企業募得款項致贈予同仁禮品之採購為財物採購，必須依政府採購法辦理

    正解：(B)

  21. 21依照政府採購法規定，機關辦理採購時應遵守相關的保密原則，下列敘述何者錯誤？

    1. (A) 機關辦理採購，其招標文件於公告前應予保密
    2. (B) 機關辦理採購得於招標文件公開預算金額，但無論任何情形皆不得公告底價
    3. (C) 機關對於廠商投標文件，除供公務上使用或法令另有規定外，應予保密
    4. (D) 機關於招標文件公告前，若有須公開說明或藉以公開徵求廠商提供參考資料者，為保密原則的例外情形，應刊登政府採購公報或公開於主管機關之資訊網路

    正解：(B)

  22. 22在警察機關後勤管理中，關於警用裝備的維護和保養，下列敘述何者錯誤？

    1. (A) 一級保養主要由使用保管人員負責，包括清潔、潤滑、旋緊、調整及感覺檢查等工作
    2. (B) 二級保養主要由各單位受過專業訓練且具有技術能力人員負責，包括更換不堪用之小總成、分件、旋緊、調整及執行定期潤滑、保養、檢查等工作
    3. (C) 三級保養主要由警察機械修理廠、警察通訊所、民防指揮控制所....等相關單位負責，主要包括主件修理及不堪用總成之翻修或實施巡迴維修
    4. (D) 警用裝備的所有級別保養均由警察機關內部專業技術人員獨立完成，不涉及外部機構或廠商的參與，以確保流程符合規定

    正解：(D)

  23. 23關於採購履約爭議處理程序之「調解」部分，下列敘述何者錯誤？

    1. (A) 機關與廠商就履約爭議事項應先進行協議，協議不成，始得申請調解
    2. (B) 機關如不同意採購申訴審議委員會之「調解建議」，無須報請上級機關核定，得逕以書面向採購申訴審議委員會及廠商說明理由
    3. (C) 機關或廠商對於採購申訴審議委員會提出之「調解方案」，得於送達之次日起十日內，向採購申訴審議委員會提出異議
    4. (D) 調解委員得依職權以採購申訴審議委員會名義提出書面之調解建議

    正解：(B)

  24. 24警察機關為政府機關之一環，若辦理採購發生爭議事件，有關申訴審議程序，下列敘述何者錯誤？

    1. (A) 採購申訴審議委員會於審議時，得囑託具專業之機關、學校、團體或人員鑑定，並得通知相關人士說明
    2. (B) 採購申訴審議委員會辦理審議，不得先行向廠商收取審議費、鑑定費及其他必要之費用
    3. (C) 採購申訴審議委員會得依職權或申請，通知申訴廠商、機關到指定場所陳述意見
    4. (D) 採購申訴得僅就書面審議之

    正解：(B)

  25. 25警察機關為政府機關之一環，為建設均需進行採購行為，下列何者並非政府採購之基本原則？

    1. (A) 應以維護公共利益及公平合理為原則
    2. (B) 對廠商不得為無正當理由之差別待遇
    3. (C) 得基於公共利益、採購效益或專業判斷之考量，為適當之採購決定
    4. (D) 機關採購不得委託法人或團體代辦

    正解：(D)
