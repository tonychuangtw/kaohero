初等考試　104 年 初等考試 財政學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1當每個人對任兩種財貨之消費的邊際替代率均相等時，則該經濟體系已達：

    1. (A) 交換的效率
    2. (B) 生產的效率
    3. (C) 技術的效率
    4. (D) 全面的效率

    正解：(A)

  2. 2效用可能曲線（utility possibility frontier）可從下列那一曲線推導而求得？

    1. (A) 拉佛曲線（Laffer curve）
    2. (B) 供給曲線（Supply curve）
    3. (C) 需求曲線（Demand curve）
    4. (D) 契約曲線（Contract curve）

    正解：(D)

  3. 3公共財搭便車之問題可歸因於公共財具有：

    1. (A) 排他性
    2. (B) 敵對性
    3. (C) 非排他性
    4. (D) 非敵對性

    正解：(C)

  4. 4下列有關俱樂部財（club goods）的敘述，何者錯誤？

    1. (A) 會員過多會產生坐享其成的現象
    2. (B) 在最適量時，滿足薩繆爾遜條件（Samuelson Condition）
    3. (C) 使用人次過多會產生擁擠成本
    4. (D) 可由私人提供

    正解：(A)

  5. 5根據下圖，那一個國家的所得分配較不平均？所得累計百分比（甲）（乙）家戶數累計百分比

    1. (A) 甲國
    2. (B) 乙國
    3. (C) 相同
    4. (D) 無法比較

    正解：(B)

  6. 6在純粹公共財由私人提供的情況下，產生市場失靈是因為：

    1. (A) 政府沒有效率
    2. (B) 外部性
    3. (C) 共有資源（common property resources）造成了公共財的過度使用
    4. (D) 提供公共財的成本太過龐大

    正解：(B)

  7. 7有關金融外部性（pecuniary externality）的敘述，下列何者正確？

    1. (A) 它會改變受此外部性影響的第三者所面臨之價格
    2. (B) 它會改變受此外部性影響的第三者所面臨之生產函數
    3. (C) 它會影響此外部性生產者所面臨之生產函數
    4. (D) 它會降低資源配置效率

    正解：(A)

  8. 8下列有關共有資源（common property resources）的敘述，何者正確？

    1. (A) 由於缺乏財產權，某些稀少性的資源可任由廠商（或民眾）取用，而不必給付價格
    2. (B) 由於缺乏財產權，某些稀少性的資源可由廠商（或民眾）取用，但必須給付價格
    3. (C) 此資源的財產權屬於某一國政府所有，但取用不必給付價格
    4. (D) 此資源的財產權屬於某一國政府所有，取用時必須給付價格

    正解：(A)

  9. 9水災過後使政府尋求解決水患問題的計畫，此現象稱為公共支出的：

    1. (A) 宣示效果（announcement effect）
    2. (B) 位移效果（displacement effect）
    3. (C) 集中效果（concentration effect）
    4. (D) 稽查效果（inspection effect）

    正解：(D)

  10. 10依據鮑莫（W. J. Baumol）的理論，公共支出成長的原因為下列何者？

    1. (A) 位移效果、集中效果、稽查效果
    2. (B) 制輪效果
    3. (C) 公共部門與私人部門要素生產力以及報酬成長的差異
    4. (D) 財政幻覺

    正解：(C)

  11. 11在獨占市場下，若有消費上的外部利益存在，則下列敘述何者正確？

    1. (A) 市場的產出水準一定會大於最有效率的產出水準
    2. (B) 市場的產出水準一定會小於最有效率的產出水準
    3. (C) 市場的產出水準一定會等於最有效率的產出水準
    4. (D) 市場的產出水準可能會大於、等於或小於最有效率的產出水準

    正解：(B)

  12. 12對於私有住宅與國民住宅的敘述，下列何者錯誤？

    1. (A) 前者具有消費的敵對性，後者具有消費的排他性
    2. (B) 前者具有消費的排他性，後者具有消費的敵對性
    3. (C) 前者為私有財，後者為公共財
    4. (D) 兩者均為私有財

    正解：(C)

  13. 13下列何者不是公共中間財（public intermediate goods）所產生的現象？

    1. (A) 可提高社會的生產力
    2. (B) 是生產者免費的投入要素
    3. (C) 可同時提供給多家生產者使用
    4. (D) 可達成社會的交換效率

    正解：(D)

  14. 14若私部門的工資因為勞動的生產力提高而調升，進而帶動公務員薪水調升。假設政府部門提供的公共服務只使用勞動投入，在公共服務提供數量不變情況下，則政府支出規模變化情形為何？

    1. (A) 不變
    2. (B) 縮小
    3. (C) 擴大
    4. (D) 無法確定

    正解：(C)

  15. 15具自然獨占性質之國營事業的「最佳定價法」（first-best pricing），是依據下列何者定價？

    1. (A) 邊際收益等於邊際成本
    2. (B) 平均收益等於邊際成本
    3. (C) 平均成本等於平均收益
    4. (D) 邊際收益等於平均成本

    正解：(B)

  16. 16解釋政府支出常隨著經濟成長而遞增的現象中的「集中效果」（concentration effect），係指中央政府支出的增加率常常較地方政府支出的增加率為：

    1. (A) 高
    2. (B) 相等
    3. (C) 低
    4. (D) 不確定

    正解：(A)

  17. 17麥契爾（A. H. Meltzer）與李嘉德（S. F. Richard）認為公共支出增加的原因之一為：

    1. (A) 人口增加，提高社會成本
    2. (B) 公共支出中資本部分日益減少
    3. (C) 公共財的價格下跌
    4. (D) 政府稅收減少

    正解：(A)

  18. 18關於公共選擇理論所提的競租（rent seeking）行為，下列敘述何者錯誤？

    1. (A) 用賄賂手段進行競租，「賄賂」行為本身並不會產生無效率
    2. (B) 競租理論是由杜洛克（G. Tullock）所提出的
    3. (C) 當要素需求完全不具彈性，需求曲線垂直時，表示要素使用沒有機會成本
    4. (D) 競租導致錯誤政策，是主要社會成本的來源

    正解：(C)

  19. 19有關林達爾均衡（Lindahl equilibrium）的說明，下列何者正確？

    1. (A) 均衡成立時，具有柏瑞圖最適的性質
    2. (B) 均衡成立時，投票者同意均分公共財的提供成本
    3. (C) 若採一致決，則均衡不可能成立
    4. (D) 只需投票者過半數之同意，均衡即可成立

    正解：(A)

  20. 20X 財貨的需求為 P＝10-2X，而 X 財貨的供給為 P＝4＋X；X 是每年財貨 X 的數量，P 是每單位的價格。假設每生產一單位 X 會對社會帶來外部成本$3，則 X 財貨的社會最適產量應為何？

    1. (A) 1 單位
    2. (B) 2 單位
    3. (C) 3 單位
    4. (D) 4 單位

    正解：(A)

  21. 21下列何者屬於政府興建中部科學園區實質的效果？

    1. (A) 實質國內生產毛額增加
    2. (B) 物價水準上升
    3. (C) 房租上漲
    4. (D) 名目工資上升

    正解：(A)

  22. 22成本效益分析中，支出計畫所產生的經濟效益與計畫目的無直接關係，且沒有市場價格者，稱之為：

    1. (A) 直接有形利益
    2. (B) 直接無形利益
    3. (C) 間接有形利益
    4. (D) 間接無形利益

    正解：(D)

  23. 23一個計畫今天要支出 1,000 元，1 年後回收 660 元，2 年後回收 484 元，折現率為 10%，則效益成本比率（benefit-cost ratio）為：

    1. (A) 0
    2. (B) 0.1
    3. (C) 1
    4. (D) 144

    正解：(C)

  24. 24一項灌溉計畫，期初投入 2,000 萬元，往後每年均可產生 100 萬元的淨利益，在淨現值（net present value）法下，如折現率為多少時，就可以投資？

    1. (A) 大於 0%
    2. (B) 大於 5%
    3. (C) 小於 5%
    4. (D) 大於 10%

    正解：(C)

  25. 25當其他條件不變，若公共投資增加，導致價格顯著下降時，該項公共投資的價格需求彈性愈大，其效益會如何？

    1. (A) 愈小
    2. (B) 相等
    3. (C) 愈大
    4. (D) 二者無關

    正解：(C)

    正解：(A)

  27. 27有關社會保險的敘述，下列何者錯誤？

    1. (A) 社會保險是社會安全中涵蓋範圍最廣的項目
    2. (B) 社會保險為僅提供某特定人群的選擇性福利措施
    3. (C) 社會保險是政府為了改善市場所產生的無效率，建立的強制性保險制度
    4. (D) 社會保險的主要經費來源為被保險人所繳交的保費

    正解：(B)

  28. 28下列何者無法建立社會保險政策的合理性？

    1. (A) 逆選擇（Adverse selection）問題的存在
    2. (B) 所得重分配
    3. (C) 父權主義（Paternalism）

    正解：(D)

  29. 29政府對競爭市場上商品課稅時，將使：

    1. (A) 均衡產量增加
    2. (B) 市場價格下跌
    3. (C) 社會剩餘減少
    4. (D) 生產者剩餘增加

    正解：(C)

  30. 30下列何者不是實施兩稅合一的主要理由？

    1. (A) 可以增加政府的稅收
    2. (B) 可以緩減對企業舉債與募股的扭曲
    3. (C) 可以緩減對企業保留盈餘與發放股利決策的扭曲
    4. (D) 可以緩減重複課稅之情況

  31. 31租稅的中立性原則是指租稅的課徵應：

    1. (A) 遵循垂直公平原則
    2. (B) 使所有項目稅率均等
    3. (C) 追求最高經濟效率
    4. (D) 追求稅收最大的目標

    正解：(C)

  32. 32假設橫軸代表稅率，縱軸代表稅收，稅率上升而稅收卻下滑的情況，出現在：

    1. (A) 拉佛曲線（Laffer curve）最高點的右側
    2. (B) 拉佛曲線（Laffer curve）最高點的左側
    3. (C) 單峰式偏好最高點的右側
    4. (D) 單峰式偏好最高點的左側

    正解：(A)

  33. 33當一國的稅收所得彈性大於 1，則隱含該國整體稅制之：

    2. (B) AT 小於 MT，且稅制的自動穩定功能較佳
    3. (C) AT 大於 MT，且稅制的自動穩定功能較差
    4. (D) AT 小於 MT，且稅制的自動穩定功能較差

    正解：(B)

  34. 34政府向銷售者課商品稅，其供給彈性與租稅負擔的關係為何？

    1. (A) 完全彈性時，全由消費者負擔
    2. (B) 完全彈性時，全由銷售者負擔
    3. (C) 完全無彈性時，全由消費者負擔
    4. (D) 完全無彈性時，消費者與銷售者負擔各半

  35. 35傳統上，關於間接稅的敘述，下列何者正確？
