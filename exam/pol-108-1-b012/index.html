警察特考　108 年 三等考試 犯罪偵查學　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1有關檢警聯繫配合辦案，下列敘述何者正確？①警察接獲報案，不論是否屬其管轄責任之案件，應先受理並做必要處置，並迅速通知管轄分局所屬分駐派出所處理②檢察事務官或法警拘捕人犯或執行搜索、扣押時，得憑證明文件請求當地警察機關協助，受請求警察機關不得拒絕③警察機關對於違反社會秩序維護法之行為，同時涉嫌違反刑事法律或少年事件處理法，於移送檢察官或少年法庭審理時，應於移送（報告）書上，以明顯戳記註明被移送人行為同時違反社會秩序維護法④司法警察機關對於其移送案件之被告受羈押者，認為有帶同被告外出繼續追查贓證、其他正犯或共犯之必要時，得報請檢察官核發偵查指揮書，交警察機關帶同被告繼續查證，惟應於當日下午 11 時前解交檢察官

    1. (A) ①②③
    2. (B) ②③④
    3. (C) ①②④
    4. (D) ①③④

    正解：(B)

  2. 2警察機關偵查刑案，得函送管轄法院或檢察署者，下列敘述何者錯誤？

    1. (A) 告訴乃論案件，經撤回告訴，或尚未調查完竣，而告訴權人已向檢察官告訴者
    2. (B) 犯罪證據不明確，但被害人堅持提出告訴者
    3. (C) 證據證明力薄弱或行為事實是否構成犯罪顯有疑義者
    4. (D) 全案雖未調查完畢，但經依法提起自訴或向檢察官告訴者

    正解：(D)

  3. 3有關犯罪案件管轄責任區分，下列敘述何者正確？

    1. (A) 竊車恐嚇取財：由車輛發現地之警察機關負責偵辦
    2. (B) 網鴿恐嚇取財：由被害人工作地或飼養鴿子之所在地之警察機關偵辦
    3. (C) 境外犯罪，以被害人之居住地、工作地、家屬居住地，依序之警察機關為管轄機關
    4. (D) 網路詐欺案件，涉及帳戶匯款，比照經濟詐欺案件涉及帳戶匯款之管轄律定，即以帳戶開立人工作地之警察機關負責偵辦

    正解：(C)

  4. 4有關告訴乃論案件，下列敘述何者正確？①未逾越 6 個月之告訴期間。但得為告訴之人有數人者，其一人遲誤期間者，效力不及於他人②撤回告訴應於第二審辯論終結前③犯罪被害人已死亡者，依刑事訴訟法第 233 條第 2 項規定，得為告訴之人行使告訴權，不得與被害人明示之意思相反④委任代理代行告訴之案件，警察人員認為必要時，得命告訴權人本人到場

    1. (A) ①②③
    2. (B) ②③④
    3. (C) ①②④
    4. (D) ①③④

    正解：(D)

  5. 5依警察偵查犯罪手冊規定，情報之處理程序，下列何者為正確？①分析 ②研判 ③運用 ④登記

    1. (A) ②①③④
    2. (B) ①②④③
    3. (C) ④①②③
    4. (D) ②①④③

    正解：(C)

  6. 6現場應依任務需要，將現有人員（擔任警戒任務者外）區分為調查組及勘察組，下列何者非屬調查組之任務？

    1. (A) 對於現場附近之環境、交通狀況及案發當時之天候、風向、氣溫等進行必要之觀察
    2. (B) 研判犯罪嫌疑人進出路線，犯罪時間、方法、手段、工具、犯行、過程等，以明瞭犯罪事實
    3. (C) 訪問被害人、報案人、發現人或其他關係人，了解案發時及案發前後，有無發現任何可疑之人、事、物等，俾發掘可能之線索
    4. (D) 如案情需要，對於現場相關處所進行搜查，尋找可能遺留之各種跡證

    正解：(B)

  7. 7警察為調查犯罪嫌疑人犯罪情形及蒐集證據，得使用通知書通知其到場接受詢問，有關通知書之送達及詢問的敘述，下列何者正確？

    1. (A) 應受送達人拒絕收領而無法律上理由者，得將通知書留置於送達處所，將送達情形於送達證書記明後附卷
    2. (B) 送達人應製作送達證書，交應受送達人簽名、蓋章或按指印；如未獲會晤應受送達人者，不得將文書交予有辨別事理能力之同居人或受僱人代收
    3. (C) 經合法通知到場者，應依原定時間及處所即時詢問，不得拖延；惟其選任之辯護人於指定時、地未到場者，不得即時詢問，以維嫌疑人權益
    4. (D) 經通知到場之犯罪嫌疑人，於詢問完畢後囑其返回，必要時由其家屬帶回，不得派員送返

    正解：(A)

  8. 8有關辯護人在場之限制，下列敘述何者錯誤？

    1. (A) 辯護人在警察機關不得檢閱卷宗、證物或抄錄、攝影，惟得許其於執行搜索、扣押、勘驗或勘察時在場，以維當事人權益
    2. (B) 辯護人接見犯罪嫌疑人時，司法警察人員應在場，防止發生湮滅、偽造、變造證據或勾串共犯或證人
    3. (C) 詢問證人非有必要時，犯罪嫌疑人及辯護人不得在場；證人指證犯罪嫌疑人時，該犯罪嫌疑人之辯護人得在場
    4. (D) 辯護人有無於司法警察官或司法警察詢問犯罪嫌疑人時在場，應於詢問筆錄內記明

    正解：(A)

  9. 9為確保指認犯罪嫌疑人之正確性，下列敘述何者錯誤？

    1. (A) 犯罪嫌疑人係社會知名人士、與指認人互相熟識、曾與指認人長期近距離接觸或為經當場或持續追緝而逮捕之現行犯或準現行犯者，得以單一指認方式為之
    2. (B) 實施指認，應指派非案件偵辦人員辦理，但因情況急迫或事實上之原因不能為之，而有全程連續錄音及錄影者，不在此限
    3. (C) 實施指認，應依指認人描述之犯罪嫌疑人特徵，安排三名以上於外型無重大差異之被指認人，供指認人進行真人選擇式列隊指認
    4. (D) 指認應於設置單面鏡之偵詢室或適當處所進行，並全程連續錄音及錄影。但有急迫情況且經記明事由者，不在此限

    正解：(C)

  10. 10有關疑似性侵害案件證物袋及相關證物鑑定後保管及後續處理流程，下列敘述何者正確？①被害人血液及胚胎，於鑑定後由實驗室保存 6 個月後銷毀②案件經告訴、自訴或警察機關移送者，證物袋及相關物證，應留存警察機關證物室，低溫冷藏保管③性侵害案件被害人採證後無法聯繫或未報案者，其證物袋及相關證物送刑事局鑑定後，鑑定書依法保存④證物袋及相關證物自採樣蒐集起，存放保管 1 年 6 個月後，仍無法聯繫被害人或查無其他證據者，證物得進行銷毀

    1. (A) ①②③
    2. (B) ②③④
    3. (C) ①②④
    4. (D) ①③④

    正解：(D)

  11. 11刑案現場數位證物，處理時應注意事項，下列敘述何者正確？①電腦主機：現場蒐證完畢後，移除電源及其他連接線材②儲存裝置：勿複製任何檔案至儲存裝置，以保持證物完整性③行動裝置：現場查扣行動裝置，應立即關機以隔絕其通訊及網路功能④網路設備：應先立即中斷網路設備運作，並查看所有連接之設備（注意以無線方式連接之行動裝置），以蒐集相關資料

    1. (A) ①②
    2. (B) ②③
    3. (C) ③④
    4. (D) ①④

    正解：(A)

  12. 12有關刑案現場數位證物的扣押，下列敘述何者錯誤？

    1. (A) 執行扣押時，以扣押整套電腦設備為宜，包含電腦主機、螢幕、鍵盤、電源線及其他連接線等設備
    2. (B) 數位證物查扣、代保管或搬運，應於包裝盒或機體上足以改變其內資料之接口施以封緘，證物交接並應維持證物監督鏈之完整
    3. (C) 扣押物品時，避免使用原扣押物的包裝或紙箱，以免扣押證物受損，影響其證據力，尤其是電腦主機內含所有重要證據，更須小心拆裝搬運
    4. (D) 數位證物採取後應先進行初篩程序，並評估證物送鑑刑事局之必要性，以決定送鑑之先後順序

    正解：(C)

  13. 13檢察官對於司法警察官或司法警察移送或報告之案件，認為調查未完備者，所採取的措施，下列敘述何者錯誤？

    1. (A) 將卷證發回命其補足
    2. (B) 發交其他司法警察官或司法警察調查
    3. (C) 得限定時間命其補足或調查
    4. (D) 逕行簽結

    正解：(D)

  14. 14刑案現場有各種搜尋方式，偵查人員發現現場屍體有槍傷，隨即尋找彈頭等物證，此方法之運用屬於下列何種搜尋法？

    1. (A) 連結式
    2. (B) 線條式
    3. (C) 放射式
    4. (D) 分區式

  15. 15偵查理論有所謂四面向連結理論，下列何者不屬於四面向連結理論的面向？

    2. (B) 犯嫌

    4. (D) 人證

  16. 16偵查技術可依動、靜態屬性，分為動態/功勢及靜態/非功勢兩類，下列何者屬於動態/功勢之技術？①布建諮詢 ②查訪 ③測謊 ④犯罪剖繪

    3. (C) ①②④

  17. 17針對特定犯罪過程，作分格影像畫面之慢速觀察，以確定犯罪行為細節及順序，以重建歹徒犯罪過程，係屬於何種錄影監視影像之觀察法？

    1. (A) 特定目標比對法
    2. (B) 犯罪過程比對法
    3. (C) 時間區段比對法
    4. (D) 逐一畫面分析法

  18. 18有關犯罪剖繪與地緣剖繪原理之論述，下列何者正確？①犯罪現場反映犯罪者人格 ②簽名特徵都很類似 ③地緣剖繪有引用犯罪型態理論 ④地緣剖繪適用於連續性犯罪的偵查

    1. (A) ①②③④
    2. (B) ①②③
    3. (C) ①③④
    4. (D) ②③④

    正解：(C)

  19. 19有關現場勘察與搜尋之論述，下列何者錯誤？

    1. (A) 若基於找尋歹徒入侵路線及可能遺留之跡證，則應由內而外
    2. (B) 若要找尋歹徒逃脫時所掉落之跡證，則應由近而遠
    3. (C) 若欲尋找可能的兇器，則應由低而高
    4. (D) 若基於採證目的而搜尋跡證，則應由顯至潛

    正解：(A)

  20. 20被跟監對象四周街道巷弄均部署跟監者，並隨對象移動而移動全面監控，係屬下列何種跟監方法？

    1. (A) 三角跟監法
    2. (B) 平行跟監法
    3. (C) 方陣跟監法
    4. (D) 定線跟監法

    正解：(C)

  21. 21司法警察甲因他人之告發，而懷疑乙涉嫌性侵被害人丙，下列有關實施通知之偵查作為，何者正確？①乙經合法通知，無正當理由不到場者，得報請檢察官核發拘票 ②甲為調查犯罪情形及蒐集證據之必要，得使用通知書通知丙到場說明 ③通知書，應記載無正當理由不到場者，得命拘提 ④通知書，由司法警察官簽名

    2. (B) ①②③

    4. (D) ①②

  22. 22有關現場勘察採證之論述，何者正確？①重大刑案由管轄警察分局長或其代理人擔任現場指揮官②刑案現場任務編組的調查組長，可由資深之偵查人員擔任 ③刑案現場任務編組的勘察組長，可由偵查隊長擔任 ④刑警大隊長抵達現場後，應立即從事犯罪調查工作

    1. (A) ①②③④
    2. (B) ①②③
    3. (C) ①②④
    4. (D) ①②

    正解：(D)

  23. 23有關拘提或逮捕及其後處置之論述，下列何者錯誤？

    1. (A) 有事實足認為犯刑法第 185 條之 3 不能安全駕駛罪之犯罪嫌疑重大，經被盤查而逃逸，而情況急迫者，司法警察得逕行拘提之
    2. (B) 司法警察逮捕犯罪嫌疑人，得逕行搜索其立即可觸及之處所
    3. (C) 司法警察逮捕刑法第 185 條之 3 不能安全駕駛罪之現行犯者，得經檢察官之許可不予解送
    4. (D) 司法警察因調查犯罪情形及蒐集證據之必要，得違反逮捕到案犯罪嫌疑人之意思，採取其指紋

    正解：(C)

  24. 24有關司法警察調查犯罪之論述，下列何者正確？①司法警察知有犯罪嫌疑者，應即開始調查②於其管轄區域內，應受司法警察官或檢察官之命令偵查犯罪 ③實施調查犯罪有必要時，應封鎖犯罪現場並為即時之勘察 ④檢察官對其所移送之案件，認為調查未完備者，得發交其他司法警察調查

    1. (A) ①②③④
    2. (B) ①②③
    3. (C) ①②④
    4. (D) ②③④

    正解：(C)

  25. 25有關組織犯罪防制條例所稱「犯罪組織」之論述，下列何者正確？①犯罪組織必須有 3 人以上②限於以實施強暴、脅迫、詐術、恐嚇為手段或最重本刑逾 5 年有期徒刑之刑之罪 ③組成必須具有持續性及牟利性之有結構性組織 ④犯罪組織須有內部管理結構性為必要
