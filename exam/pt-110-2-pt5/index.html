物理治療師　110 年第二次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1有關內臟痛（visceral pain）的轉移痛（referred pain）位置，下列敘述何者錯誤？

    1. (A) 心臟痛可轉移痛至胸椎第二節
    2. (B) 胃痛可轉移痛至胸椎第六到第八節
    3. (C) 消化性潰瘍痛常轉移痛至胸椎第四到第六節
    4. (D) 腎臟痛常轉移痛至胸椎第七到第八節

    正解：(D)

  2. 2一位45歲女性上班族，工作時必須長時間打電腦，主訴兩邊肩頸僵硬，且有時額頭會有箍緊的感覺；上班日早上起床時不會痛，到傍晚時分症狀增加。對於這位上班族，下列建議何者較不恰當？

    1. (A) 配戴合適的閱讀用眼鏡，確保視力清晰
    2. (B) 調整辦公桌電腦高度，保持視線高於水平以仰視螢幕
    3. (C) 調整滑鼠位置，讓上臂靠近身體，儘量減少手臂向前伸
    4. (D) 定時起身活動

    正解：(B)

  3. 3觀察一位50歲的辦公族，發現有前位頭部（forward head）、下巴前突、圓肩姿勢，下列那些肌肉通常有緊縮的現象？①枕骨下肌（suboccipital） ②胸鎖乳突肌（sternocleidomastoid） ③胸小肌（pectoralis minor）

    1. (A) 僅①②
    2. (B) 僅①③
    3. (C) ①②③
    4. (D) 僅②③

    正解：(C)

  4. 4有關顳頜關節有喀嗒（clicking）聲響症狀，下列敘述何者正確？

    1. (A) 張嘴時喀嗒聲越晚出現，表示間盤（disc）的位置越在後面
    2. (B) 閉嘴時的喀嗒聲，通常是因附著在間盤（disc）的組織太緊
    3. (C) 張嘴時的喀嗒聲，表示間盤（disc）脫位
    4. (D) 喀嗒聲比較可能發生在高動性（hypermobile）關節

    正解：(D)

  5. 5下列那一頸部肌肉的疼痛，可能會在臉頰或顳頜關節處產生轉移痛（referred pain）？

    1. (A) 胸鎖乳突肌（sternocleidomastoid）
    2. (B) 斜角肌（scalene）
    3. (C) 頭夾肌（splenius capitis）
    4. (D) 頸半脊肌（semispinalis cervicis）

    正解：(A)

  6. 6下列何者為連結至頸椎第二節之肌肉組織？①後頭直小肌（rectus capitus posterior minor） ②下頭斜肌（obliques capitus inferior） ③後頭直大肌（rectus capitus posterior major）

    1. (A) 僅①②
    2. (B) 僅①③
    3. (C) 僅②③
    4. (D) ①②③

    正解：(C)

  7. 7病患仰臥時，治療師將病患頭頸擺在後伸及側彎至左側，然後再將頭部轉到左側，維持30秒的時間，觀察是否有暈眩或眼球震顫的現象。此測試主要可評估下列那項問題？

    4. (D) 頸髓壓迫

    正解：(B)

  8. 8有關頸椎之上小關節面（superior facets）之方向組合，包括下列何者？①向前 ②向後 ③朝上 ④朝下

    2. (B) ②③
    3. (C) ②④

  9. 9一位患者車禍後抱怨常有頭痛的情形，治療師評估後發現患者維持前位頭部（forward head）的姿勢，且上頸椎的肌肉較無力，相較而言，下列何項治療較不恰當？

    1. (A) 上頸伸肌牽張（stretching）運動
    2. (B) 頸椎深層屈肌（deep flexor muscles）之肌力訓練
    3. (C) 利用壓力生物回饋儀（pressure biofeedback unit）訓練頸部淺層屈肌肌力
    4. (D) 頸椎姿勢矯正訓練

    正解：(C)

  10. 10病人開口時，若下頜向左側移動，可能為下列何種問題？

    1. (A) 右側顳頜關節盤前移
    2. (B) 右側顳頜關節盤後移
    3. (C) 左側顳頜關節盤前移
    4. (D) 左側顳頜關節盤後移

    正解：(A)

  11. 1135歲搬運工作員，6個月前搬運水泥磚時，不慎拉傷下背組織。經檢查發現：姿勢外觀並無異常；站姿下重複前彎時，動作受限且在動作終端時出現下背疼痛；站姿下重複後仰時，活動正常且無症狀；躺姿下檢查與站姿檢查結果相同。此患者是屬於McKenzie分類的那一類問題？

    2. (B) 失能症候群（dysfunction syndrome）
    3. (C) 排列異常症候群（derangement syndrome）
    4. (D) 退化症候群（degenerative syndrome）

    正解：(B)

  12. 1275歲婦女，主訴經常感到腰痠背痛。視診時發現背部有明顯的Gibbous畸形，經DXA檢查後T-score為-2.8。此婦女最可能有下列何問題？

    4. (D) 舒爾曼病（Scheuermann's disease）

    正解：(C)

  13. 13一名40歲男性，因右側腰部疼痛尋求物理治療，檢查發現主動腰椎前彎角度受限，且有疼痛弧（painful arc）現象，向右側彎又發同側神經輻射症狀，阻力測試出現踝背屈無力，膝反射降低，下列何者為最有可能之診斷？

    2. (B) 腰部肌肉拉傷
    3. (C) 椎間盤突出壓迫L4神經根
    4. (D) L4、L5小面關節退化

    正解：(C)

  14. 14關於腰椎伸直症候群（lumbar extension syndrome）的症狀特色，下列何者正確？

    1. (A) 作為伸直活動支點的椎節，其上一節通常活動過度
    2. (B) 在年輕患者身上可發現站姿時腰椎前凸減少
    3. (C) 可在呈現較大腰椎前凸程度的失穩椎節附近，發現表淺肌肉收縮活性增加的現象
    4. (D) 此原發性功能失調，源於髖伸直肌的收縮比率遠大於腰椎伸直肌的收縮比率

    正解：(C)

  15. 15有關右側薦骨前旋失能（sacral anterior nutation dysfunction），下列敘述何者正確？

    1. (A) 坐姿前彎測試會在左側出現陽性反應
    2. (B) 觸診時，相較於對側，右側髂前上棘位置較為向下向前
    3. (C) 觸診時，相較於對側，右側薦骨底位置較為向前向下
    4. (D) 腰椎彈壓測試為陽性

    正解：(C)

  16. 16下列何者為最常見的脊椎椎骨退化症狀？

    1. (A) 脊椎關節活動度增加，急性關節疼痛
    2. (B) 脊椎關節活動度減少，起床時關節僵硬

    4. (D) 脊椎關節活動度減少，急性關節疼痛

    正解：(B)

  17. 17站立時出現明顯之腰椎過度前凸（lumbar lordosis）及骨盆前傾姿勢，檢查結果最可能為下列那條肌肉過緊？

  18. 18站立時呈現腰薦角度（lumbosacral angle）過大、過度腰前凸（lordosis）、骨盆前傾過大、髖屈曲角度增加的姿勢所導致之腰椎下段區域疼痛，其疼痛來源較不可能是下列何者？

    4. (D) 下段腰椎神經根受刺激

  19. 19一位50歲的男性主訴左臀部及後大腿疼痛、站立向前取物持續15分鐘後或行走時症狀加劇，仰躺膝下墊枕頭時症狀減少，打噴嚏或咳嗽時疼痛沒有增加。檢查發現其呈現搖擺背（swayback）姿勢，仰躺時被動直膝抬腿45度伴隨足背屈時，症狀無變化，俯臥以手撐起軀幹後仰時疼痛會增加。下列何者為最可能的診斷？

  20. 20一位65歲男性背痛病人，主訴一個月以來，走路10分鐘後雙小腿會麻痛。檢查時軀幹後仰疼痛症狀增加，平躺時雙膝下墊枕頭症狀可減少。下列何者為病人最可能之疼痛來源？

  21. 21屈膝平躺時，進行下背穩定性運動訓練，下列動作，由易至難之排列為何？①膝蓋向外側打開再合起 ②縮緊腹部 （drawing-in maneuver） ③其中一腳伸直膝關節後，抬腿至45° ④其中一腳跟延著床面來回伸直彎曲膝關節

  23. 23觸診時發現右側坐骨粗隆內上緣組織較左側緊繃，此問題可能與下列何種情況有關？①右側薦骨基部（sacralbase）較淺 ②右側薦骨基部較深 ③薦骨向右旋轉 ④薦骨向左旋轉 ⑤右側薦骨前屈 ⑥右側薦骨後仰

  24. 24關於長短腳量測的敘述，下列何者錯誤？

    1. (A) 結構性長短腳問題可用仰臥起坐測試（supine-to-sit test）來確定
    2. (B) 若痛側腳在仰臥時較長，坐起後較短，表示該側可能為無名骨（innominate）向前旋轉
    3. (C) 當懷疑薦髂關節有問題時，可進一步施行腿長測試
    4. (D) 腿長測試若兩側相差1～1.3公分為正常範圍

    正解：(A)

  25. 25關於右胸椎側彎（right thoracic curve）之敘述，下列何者錯誤？

    3. (C) 右側背部肌肉可能會拉長
    4. (D) Adam's前彎測試可觀察到右側背部拱起（hump）

    正解：(A)

  26. 26棒球投手做投擲動作時，最容易在揮臂後期（late cocking）到加速期（acceleration）間受傷，下列敘述何者錯誤？

    1. (A) 在揮臂準備後期，肩關節產生最大的外展及外轉角度
    2. (B) 在揮臂準備後期，若肩關節前方出現疼痛，可能是因為前向不穩定（anterior instability）
    3. (C) 加速期時，相較於其他肌肉，肱二頭肌活化程度最高
    4. (D) 從揮臂準備後期到加速期，如果肩關節後方出現不舒服，可能與後側關節囊或旋轉肌群有關

    正解：(C)

  27. 27肩關節前向不穩定（anterior instability）患者經過手術修復後之物理治療介入，下列何者最不適當？

    1. (A) 術後6週內，應儘量避免用患側拿重物
    2. (B) 術後6週內，為免牽扯到盂肱關節肌肉，不鼓勵訓練肩胛肌肉
    3. (C) 術後12週，應避免在外展90度下的外轉動作，其他各方向的關節活動則無限制
    4. (D) 術後24週，可執行增強式運動（plyometric exercises）

    正解：(B)

  28. 28接受旋轉肌群縫合病人，術後的輔助性主動運動宜由下列那一個方向開始？

  29. 29觀察肩胛肱骨節律（scapulohumeral rhythm）時，下列敘述何者錯誤？

    2. (B) 在手臂舉高與放下的過程中，皆可觀察肩胛肱骨節律的控制
    3. (C) 肩胛肱骨節律與肌肉控制有關，但與肩部各關節的活動度無關
    4. (D) 舉手速度會影響肩胛肱骨節律

    正解：(C)

  30. 30當患者主訴向下梳後腦的頭髮時有困難，則下列那些肩關節動作可能受限？①後伸 ②外展 ③內轉 ④外轉

  31. 3125歲患者主訴在舉手至60～120度之間肩部前方有疼痛情形，並告知5年前因車禍而肩部脫臼，這5年來曾經有3次脫臼復發。檢查時發現，外展阻力測試有疼痛及無力的現象，則下列那些測試最可能出現陽性反應？

    1. (A) 驚恐與復位測試（apprehension and relocation test）、肩鎖關節水平內收測試（acromioclavicular horizontaladduction test）
    2. (B) Hawkins-Kennedy夾擠測試（impingement test）、抬離測試（lift-off test）
    3. (C) 驚恐與復位測試（apprehension and relocation test）、Hawkins-Kennedy夾擠測試（impingement test）
    4. (D) 肩鎖關節水平內收測試（acromioclavicular horizontal adduction test）、抬離測試（lift-off test）

    正解：(C)

  32. 32若患者疼痛位於肩部前外側，則下列那一個症狀無法協助判斷此患者可能有肱二頭肌肌腱發炎的問題？

    2. (B) 抬離測試（lift-off test）為陽性
    3. (C) 手臂從舉高過頭位置慢慢放下時，出現肩部前側疼痛，有時比舉高手臂的動作還痛
    4. (D) 肩關節後伸動作伴隨肘關節伸直時，肩部前側出現疼痛

    正解：(B)

  33. 33後肩關節囊緊繃（posterior capsule tightness）最可能導致肩關節那些方向的活動度減少？

    4. (D) 鐘擺運動適用於周邊水腫患者，有助於改善組織循環

  36. 36有關胸廓出口症候群（thoracic outlet syndrome）的治療，下列敘述何者錯誤？

    1. (A) 進行橫膈膜的腹式呼吸訓練有助於改善症狀
    2. (B) 應矯正頸部與肩部之姿勢
    3. (C) 初期應加強斜角肌、胸大肌與胸小肌的肌力訓練

    2. (B) 應將受傷的部位擺位在縮短的狀態，以促進傷口早期癒合，降低後期發生關節攣縮
    3. (C) 對於頭頸部燒燙傷患者，原則上應讓其頭部擺位在稍微後仰的位置；若有插管時，則應將其頸部擺在正中姿勢
    4. (D) 患者出院後，因傷口已癒合，睡覺時的擺位應以舒服為原則，才能得到完全的休息

    正解：(C)

  76. 76下列何者不是幫助傷口組織獲得充分氧氣灌注的做法？

    1. (A) 抬高傷口肢體，主動肌肉收縮，避免發生水腫
    2. (B) 將包覆傷口的壞死組織清除
    3. (C) 保持溫暖、提供足夠水分、戒菸、控制疼痛及焦慮，可預防周邊動脈收縮
    4. (D) 補充維生素C及鋅，以提升紅血球攜帶氧的能力

    正解：(D)

  77. 77有關乳癌術後手掌淋巴水腫患者，其淋巴引流運動的執行順序，下列何者正確？①肩胛骨運動 ②腹式呼吸 ③頸部關節活動度 ④穿上彈性袖套 ⑤肘關節活動度 ⑥腕關節和手指頭的運動

    1. (A) ④②③①⑤⑥
    2. (B) ②⑥⑤①③④
    3. (C) ④②⑥⑤①③
    4. (D) ④③②①⑤⑥

    正解：(A)

  78. 78造成截肢的主要成因，依百分比排序由大至小為何？①創傷 ②周邊血管疾病 ③惡性腫瘤

    1. (A) ①②③
    2. (B) ②①③
    3. (C) ①③②
    4. (D) ②③①

    正解：(A)

  79. 79關於截肢手術後患者出現幻肢痛（phantom limb pain）的敘述，下列何者錯誤？

    1. (A) 通常在截肢術後一週內開始出現
    2. (B) 上肢出現的機率較下肢高，且持續時間也較長
    3. (C) 在截肢前有經歷肢體疼痛的患者，其發生率會較高
    4. (D) 術後立即硬式包紮（immediate postoperative rigid dressing），可以減少其發生率

    正解：(D)

  80. 80下列那些是膝上截肢（transfemoral amputation）患者於義肢側的步態擺盪期（swing phase）可能出現的異常問題？①碰撞聲（audible impact） ②環繞步態（circumduction gait） ③跳躍式步態（vaulting gait） ④軀幹傾向義肢側（trunk lean toward prosthetic side）

    1. (A) 僅①②③
    2. (B) 僅②④
    3. (C) ①②③④
    4. (D) 僅①③④

    正解：(A)
