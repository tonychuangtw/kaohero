營養師　114 年第二次 生理學與生物化學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1關於骨骼肌在中度運動（moderate exercise）期間提供三磷酸腺苷（ATP）來源的順序，下列何者優先？

    1. (A) 磷酸肌酸（creatine phosphate）
    2. (B) 肝醣（glycogen）
    3. (C) 葡萄糖（glucose）
    4. (D) 脂肪酸（fatty acid）

    正解：(A)

  2. 2關於心肌的興奮－收縮耦合（excitation-contraction coupling）的敘述，下列何者錯誤？

    1. (A) 以鈣誘發性鈣釋放（calcium-induced calcium release）機制來活化細肌絲
    2. (B) 雷恩諾鹼接受器（ryanodine receptors）活化可回收鈣離子
    3. (C) L型鈣離子通道（L-type Ca 2+ channels）為電位感受器（voltage sensor）
    4. (D) 流入細胞質的鈣離子會促使肌漿網（sarcoplasmic reticulum）釋放出更大量的鈣離子

    正解：(B)

  3. 3有關平滑肌之橫橋活化（cross-bridge activation）過程的敘述，下列何者正確？

    1. (A) 鈣離子與攜鈣素（calmodulin）結合，導致肌凝蛋白（myosin）磷酸化
    2. (B) 鈣離子與旋轉素（troponin）結合，導致肌凝蛋白（myosin）磷酸化
    3. (C) 鈣離子與攜鈣素（calmodulin）結合，導致旋轉肌球素（tropomyosin）磷酸化
    4. (D) 鈣離子與旋轉素（troponin）結合，導致旋轉肌球素（tropomyosin）磷酸化

    正解：(A)

  4. 4關於人類細胞膜蛋白的敘述，下列何者最適當？

    1. (A) 嵌入膜蛋白（integral membrane proteins）只具有非極性（nonpolar）特性
    2. (B) 嵌入膜蛋白（integral membrane proteins）不具雙極性（amphipathic）特性
    3. (C) 周邊膜蛋白（peripheral membrane proteins）具有非極性（nonpolar）特性
    4. (D) 周邊膜蛋白（peripheral membrane proteins）不具雙極性（amphipathic）特性

    正解：(D)

  10. 10下列關於腎臟之敘述，何者最適當？

    3. (C) 輸尿管利用混和運動（mixing movement）及重力將尿液經腎門（hilum）送至膀胱儲存
    4. (D) 供應腎臟的血液來自於腹主動脈（abdominal aorta）的腎動脈分枝

  11. 11關於腎元（nephron）之敘述，下列何者錯誤？

    2. (B) 腎絲球微血管的基底膜（basal lamina）為帶負電醣蛋白，蛋白質常會被阻礙而無法通過，但可進入鮑氏囊（Bowman's capsule）
    3. (C) 腎絲球微血管的內皮細胞有較大的窗孔（fenestrae），因此其對水及一些可通透溶質之通透度較一般骨骼肌微血管高
    4. (D) 腎絲球過濾之濾液會進入腎小管中，而未被過濾之微血管血液則經出球小動脈（efferentarteriole）流出

    正解：(B)

  12. 12關於排尿（micturition）的敘述，下列何者正確？

  44. 44有關真核生物轉譯作用（translation）的敘述，下列何者正確？

    1. (A) 真核生物與原核生物轉譯作用之起始胺基酸皆為甲醯甲硫胺酸（formyl methionine）
    2. (B) 轉譯作用中的延伸過程（elongation），是將新加入之單一胺基酸加至含多個胺基酸之多胜肽（polypeptide）上
    3. (C) 轉譯作用中的延伸過程（elongation），核糖體會沿著mRNA移動，每次移動距離為1組密碼子（codon）
    4. (D) 轉譯作用中的終止過程遇到終止密碼子（stop codon）後，需要供給ATP協助水解已合成之多胜肽（polypeptide）

    正解：(C)

  45. 45G蛋白（G protein）需依序與下列何者結合活化後，進行訊息傳遞？
