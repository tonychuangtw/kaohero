  29. 29下列關於我國對於外籍航空器或外籍民用航空運輸業之規定敘述，何者正確？

    2. (B) 外籍航空貨運承攬業未依規定設立分公司營運者，不得委託國內之航空貨運承攬業，代為執行或處理業務
    3. (C) 外籍航空公司依條約或協定，或基於平等互惠原則，可定期飛航往返於我國境內一地與境外機場，按有償方式載運客貨、郵件

    正解：(C)

    2. (B) 客、貨運運價，由汽車運輸業同業公會與相關工會按客、貨運價準則共同擬訂，須報請該管公路主管機關核定
    3. (C) 公路主管機關對於汽車運輸業，得徵收公路營運費，撥充運輸獎助之用，但不得用於公路養護

  36. 36下列關於公路安全管理之敘述，何者錯誤？

    2. (B) 公路主管機關為維護公路行車安全，得會同當地地方政府於公路兩側勘定範圍，公告禁止或限制公、私有廣告物
    3. (C) 廣告物有礙行車安全者，得商請當地建築主管機關限期修改或強制拆除，且不須給予補償
    4. (D) 公路主管機關於公路發生災害或修護期間，得公告限制或禁止車輛通行該路段

    2. (B) 鐵路改建工程局
    3. (C) 國道新建工程局
    4. (D) 運輸研究所

    正解：(D)

  49. 49通過直轄市之省道，如係快速公路系統，其管轄權通常屬於：

    1. (A) 省政府公路主管機關
    2. (B) 中央政府公路主管機關
    3. (C) 直轄市公路主管機關
    4. (D) 直轄市與省政府協調共管

    正解：(B)

  50. 50下列關於公路監理業務之敘述，何者正確？

    1. (A) 汽車及電車之考驗發照，由中央公路主管機關統一辦理，不得委託相關法人、團體辦理
    2. (B) 汽車檢驗及汽車駕駛考驗人員之考核及監督管理等事項之辦法，得由地方政府自行訂定之
    3. (C) 民營汽車駕駛人訓練機構之設立，經地方公路主管機關核准籌設並立案後，始得對外招生
    4. (D) 民營汽車駕駛人訓練機構之管理辦法，由交通部會同教育部定之

    正解：(D)
