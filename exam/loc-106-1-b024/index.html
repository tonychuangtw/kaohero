  1. 1十進位數 26.75 相當於：

    1. (A) 二進位數 11010.11
    2. (B) 八進位數 32.3
    3. (C) 十六進位數 1A.6
    4. (D) 三進位數 222.21

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 26＝11010₂，0.75＝0.11₂，故 26.75＝11010.11₂。

    ❌ (B) 八進位應為 32.6（32.3₈＝26.375）。

    ❌ (C) 十六進位應為 1A.C（1A.6₁₆＝26.375）。

    ❌ (D) 222.21₃≈26.78，與 26.75 不等。

    📚 出處：進位制的轉換。

  2. 2啟動個人電腦的程式稱為 BIOS（Basic Input Output System），BIOS 存放在那裡？

    1. (A) 硬碟
    2. (B) MBR（Master Boot Record）
    3. (C) CPU
    4. (D) ROM（Read Only Memory）

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) BIOS 燒錄於主機板的 ROM（或快閃記憶體）中，開機時最先執行。

    ❌ (A) 硬碟須先由 BIOS 初始化才能存取。

    ❌ (B) MBR 位於硬碟，由 BIOS 讀取。

    ❌ (C) CPU 不儲存程式。

    📚 出處：電腦的開機流程。
