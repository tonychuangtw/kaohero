  1. 1處理器在執行程式時，目前正在或即將被執行的指令的位址，儲存在下列那一元件？

    1. (A) 加法器（adder）
    2. (B) 程式計數器（program counter）
    3. (C) 多工器（multiplexer）
    4. (D) 一般暫存器（general purpose register）

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 程式計數器保存下一道（或目前）要執行的指令位址，每取一道指令便自動遞增。

    ❌ (A) 加法器負責算術運算與位址計算。

    ❌ (C) 多工器負責在多路訊號中選擇其一。

    ❌ (D) 一般暫存器存放運算用的資料而非指令位址。

    📚 出處：計算機組織；處理器的基本元件。

  2. 2有關共享記憶體多處理器（shared memory multiprocessor）的敘述，下列何者錯誤？

    1. (A) 提供單一實體記憶體位置空間（address space）給多處理器使用
    2. (B) 於多處理器上的所有程序（process）必須共享同一虛擬記憶體位置空間（address space）
    3. (C) 若任一處理器存取任一記憶體中的一個字組（word），所花費的時間皆相同，則稱之為一致的記憶體存取（uniform memory access, UMA）若不同處理器存取記憶體中的同一個字組（word），所花費的時間可能不同，則稱之為非一致的記憶體
    4. (D) 存取（nonuniform memory access, NUMA）

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 此項錯誤：共用的是「實體」位址空間；各程序仍有各自獨立的虛擬位址空間，不必共享。

    ❌ (A) 敘述正確，共享記憶體多處理器提供單一實體位址空間。

    ❌ (C) 敘述正確，存取時間一致者為 UMA。

    ❌ (D) 存取時間依處理器而異者為 NUMA，同屬正確敘述。

    📚 出處：計算機組織；共享記憶體多處理器。

  3. 3發掘程式中指令階層平行性（instruction-level parallelism）有助於提升程式執行效能，其可由硬體或是軟體 的機制來達成。下列何者需要依賴純軟體的方式，以發掘指令階層平行性進而提升程式效能？

    1. (A) 很長指令字（Very Long Instruction Word, VLIW）架構
    2. (B) 超純量（superscalar）架構
    3. (C) 動態管道排程（dynamic pipeline scheduling）
    4. (D) 亂序執行（out-of-order execution）

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) VLIW 由編譯器在編譯期就把可平行執行的運算打包進同一道長指令，硬體不做動態排程，完全依賴軟體。

    ❌ (B) 超純量由硬體在執行期決定同時發射哪些指令。

    ❌ (C) 動態管道排程屬硬體機制。

    ❌ (D) 亂序執行同樣由硬體動態完成。

    📚 出處：計算機組織；指令階層平行性。
