警察特考　104 年 三等考試 海巡法規　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1為確保船舶所有人履行海域污染之民事賠償責任，依海洋污染防治法規定，船舶所有人對於總噸位一百五十噸以上之化學品船，應依船舶總噸位投保責任保險。有關責任保險額度之制定，下列何者正確？

    1. (A) 中央主管機關會商財政部
    2. (B) 中央主管機關會商經濟部
    3. (C) 中央主管機關會商金融監督管理委員會
    4. (D) 中央主管機關會商國家發展委員會

    正解：(C)

  2. 2行為人在中華民國專屬經濟海域和大陸礁層內，從事破壞我國主權權利之行為時，應受刑事處罰。有關該項不法行為，下列敘述，何者正確？

    1. (A) 故意或過失破壞自然生態
    2. (B) 不遵守法令規定，排洩廢棄物
    3. (C) 未經許可，從事人工島嶼設施之建造
    4. (D) 未經許可，從事海洋科學研究

    正解：(B)

  3. 3海關執行緝私任務，認為違反海關緝私條例情事業已發生者，得行使搜索、扣押權。執行時應遵守之事項，下列敘述，何者錯誤？

    1. (A) 搜索身體時，應有關員 2 人以上在場
    2. (B) 須聲請搜索票，始得搜索關係場所
    3. (C) 在船舶實施搜索時，應邀同其管理人在場見證
    4. (D) 在運輸工具內查獲私貨而情節重大者，為繼續勘驗與搜索，得扣押該運輸工具

    正解：(B)

  4. 4行政執行官訊問義務人後，認其有履行義務之可能，卻故不履行，而有拘束其人身自由之必要者，行政執行處應向法院聲請，對其為強制處分之裁定，依行政執行法規定，該項處分之定位，下列敘述，何者正確？

    1. (A) 留置
    2. (B) 管收
    3. (C) 管束
    4. (D) 羈押

    正解：(B)

  5. 5海洋污染防治法第 49 條規定，執行機關於首次裁罰處分送達後，污染行為人屆期仍未改善，得按日連續處罰，有關連續處罰之性質，下列敘述，何者正確？

    1. (A) 行政執行法第 31 條第 1 項之怠金
    2. (B) 行政執行法第 31 條第 2 項但書之特殊怠金
    3. (C) 行政罰法之罰鍰
    4. (D) 滯納金

    正解：(B)

  6. 6依海關緝私條例之規定，下列敘述，何者錯誤？

    1. (A) 自違反本條件情事發生已滿 5 年者，不得再為處罰
    2. (B) 處罰之處分確定後，5 年內再犯海關緝私條例之行為者，其罰鍰得加重二分之一
    3. (C) 裁處沒入之貨物，不以屬於受處分人所有為限
    4. (D) 所處罰鍰以貨價為準者，進口貨物按完稅價格計算，出口貨物離岸價格計算

    正解：(B)

  7. 7依中華民國領海及鄰接區法規定，外國特定船舶通過我國領海時，應受我國管制。關於管制方式，下列敘述，何者錯誤？

    1. (A) 載運核物質之外國船舶，由行政院原子能委員會會同海岸巡防機關，全程監管
    2. (B) 載運有害物質之外國船舶，由行政院環境保護署會同海岸巡防機關，全程監管
    3. (C) 外國公務船舶，由外交部會同海岸巡防機關，全程監控
    4. (D) 外國軍用船舶，由國防部通飭所屬，全程監控

    正解：(C)

  8. 8公務人員之配偶為公職候選人時，依公務人員行政中立法規定，得從事之政治行為，下列事項，何者正確？

    1. (A) 在大眾傳播媒體具銜廣告
    2. (B) 對職務相關人員表達指示
    3. (C) 在辦公場所散發公職候選人之徽章
    4. (D) 於下班時間，公開為公職候選人站台

    正解：(D)

  9. 9海巡機關人員於查獲未經許可進入臺灣地區之大陸人民時，對其處置方式，下列敘述，何者錯誤？

    1. (A) 得逕行強制其出境
    2. (B) 於強制出境前，得暫予收容，並得令其從事勞務
    3. (C) 若其所涉案件已進入司法程序者，應先經司法機關之同意
    4. (D) 若僅違反社會秩序維護法，於調查後，免移送簡易庭裁定

    正解：(D)

  10. 10海巡機關人員依法執行職務，遇拒絕停船檢查並加速逃逸時，為順利控制涉案船舶，得採取之措施，下列敘述，何者錯誤？

    1. (A) 帶隊官應即下達並完成警戒部署，注意維護人員安全
    2. (B) 應與該船保持距離以雷達監控
    3. (C) 全程錄影拍照存證
    4. (D) 丟擲催淚手榴彈

    正解：(D)

  11. 11巡防機關人員於夜間實施監卸漁獲勤務時，認為漁船之漁具及漁網使用狀態可疑，涉嫌走私漁獲進入臺灣地區，遂登船實施檢查及搜索，查獲管制進口物品。有關登檢程序，下列敘述，何者正確？

    1. (A) 因無檢察官之指示，程序違法
    2. (B) 因違反夜間禁止搜索之限制，程序違法
    3. (C) 因有正當理由，認有違法之虞，程序合法
    4. (D) 因有必要，認有違法之虞，程序合法

    正解：(C)

  12. 12依臺灣地區與大陸地區人民關係條例之規定，主管機關對私運大陸地區人民非法入境之我國船舶所有人，得沒入其船舶。有關該條規定之要件，下列敘述，何者正確？

    1. (A) 因其故意，致使第三人以其船舶從事使大陸地區人民非法入境之行為
    2. (B) 因其過失，致使第三人以其船舶從事使大陸地區人民非法入境之行為
    3. (C) 明知該船舶得沒入，為規避沒入之裁處而取得所有權者
    4. (D) 明知該船舶得沒入，變更所有權登記予第三人者

    正解：(C)

  13. 13違反國家安全法第 2 條之 1 規定應成立同法第 5 條之 1 第 1 項之洩密罪，試問該罪之構成要件，下列敘述，何者錯誤？

    1. (A) 主觀要件須意圖危害國家安全或社會安定
    2. (B) 須為大陸地區公務機關蒐集、交付公務上應秘密之資料
    3. (C) 須為大陸地區人民蒐集、交付公務上應秘密之資料
    4. (D) 須為大陸地區行政機關發展組織

    正解：(C)

  14. 14依國家安全法所定海岸管制區的範圍，下列敘述，何者正確？

    1. (A) 距海岸線 500 公尺以內之地區
    2. (B) 以海岸之海水低潮線起算 500 公尺以內之地區
    3. (C) 以海岸之海水高潮線起算 500 公尺以內之地區
    4. (D) 以海岸之海水低潮線以迄高潮線起算 500 公尺以內之地區及近海沙洲

    正解：(D)

  15. 15海巡機關查獲我國籍漁船違規走私，但無其他犯罪行為，依據海岸巡防法規定，應由下列何機關予以處罰？

    1. (A) 海巡機關
    2. (B) 海關
    3. (C) 縣市政府
    4. (D) 行政院農業委員會漁業署

    正解：(B)

  16. 16我國籍漁船停在碧砂漁港內發生舷外機失竊，該案件的調查應由下列何機關負責？

    1. (A) 警察機關
    2. (B) 海巡機關
    3. (C) 漁港管理機關
    4. (D) 交通部航港局

    正解：(A)

  17. 17一艘 CT5 的大陸漁船未經許可於新竹外海 10 浬處捕魚，被海巡機關查獲後帶岸處置，應由下列何機關予以處罰？

    1. (A) 海巡機關
    2. (B) 海關
    3. (C) 新竹縣政府農業處
    4. (D) 行政院農業委員會漁業署

    正解：(A)

  18. 18依據行政執行法，關於公務員欲在夜間進行行政執行，下列敘述何者正確？

    1. (A) 基於安全考量，禁止在夜間進行
    2. (B) 尊重當事人意願，如當事人同意即可夜間進行
    3. (C) 考量行政效率，無論任何情況行政機關決定即可夜間進行
    4. (D) 維護執行人員權益，逢例假日禁止夜間執行

    正解：(B)

  19. 19海巡人員甲因選舉事件，受到長官記申誡乙次，甲認為長官處理不公平，得依下列何項法律提出救濟？

    1. (A) 公務人員保障法
    2. (B) 訴願法
    3. (C) 公務人員行政中立法
    4. (D) 刑事訴訟法

    正解：(A)

  20. 20關於我國公布第一批專屬經濟海域暫定執法線之敘述，下列何者正確？

    1. (A) 該線係依據中華民國專屬經濟海域及大陸礁層法授權訂定
    2. (B) 該線是我國與日本談判劃定專屬經濟海域界線
    3. (C) 該線是由 8 個點 7 個線段構成
    4. (D) 該線是作為我國海域執法依據，保護漁民權益之措施

    正解：(D)

  21. 21外國人欲在我國專屬經濟海域開發人工島，應檢具相關資料向何機關申請？

    1. (A) 行政院
    2. (B) 內政部
    3. (C) 行政院環境保護署
    4. (D) 經濟部

    正解：(B)

  22. 22關於臺灣、澎湖地區之「領海」與「禁止水域」之敘述，下列何者正確？

    1. (A) 首次公布時間，領海早於禁止水域
    2. (B) 水域面積，領海小於禁止水域
    3. (C) 外界線長度，領海小於禁止水域
    4. (D) 領海與禁止水域之法定公布機關相同

    正解：(B)

  23. 23關於國家安全法之敘述，下列何者正確？

    1. (A) 依據國家安全法施檢時，係以司法警察身分執行職權
    2. (B) 受檢對象無正當理由拒絕檢查，應移送地方法院檢察署偵辦
    3. (C) 施檢須要檢查婦女身體時，限由女性海巡人員行之
    4. (D) 施檢須要檢查婦女身體時，限由女性人員行之

    正解：(B)

  24. 24外國籍船舶走私菲律賓生產之檳榔 200 公斤，被海巡艇在距岸 8 浬處發現可疑後逃逸，經緊追於距岸 25浬處查獲。依據海關緝私條例，下列何者處置正確？

    1. (A) 可處罰，處以罰鍰
    2. (B) 可處罰，應沒入船舶
    3. (C) 不可處罰，因非我國籍船舶
    4. (D) 不可處罰，已超出管轄海域

    正解：(A)

  25. 25外國船舶在基隆港外海觸礁並造成海洋污染，在損害賠償未履行前，得由下列何機關限制其船員離境？

    1. (A) 海巡機關
    2. (B) 基隆市政府
    3. (C) 基隆港港口管理機關
    4. (D) 中央環保機關

    正解：(C)
