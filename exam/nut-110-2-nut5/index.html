營養師　110 年第二次 公共衛生營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1我國第八版國人膳食營養素參考攝取量中，建議懷孕婦女葉酸的攝取量應為多少微克？

    1. (A) 200
    2. (B) 400
    3. (C) 600
    4. (D) 800

    正解：(C)

  2. 2我國國人膳食營養素參考攝取量對鐵質的建議敘述，下列何者錯誤？

    1. (A) 國人日常膳食中之鐵質攝取量，不足以彌補婦女懷孕、分娩失血及泌乳時之損失
    2. (B) 建議婦女從懷孕第 3 期至分娩後 2 個月內，每日另以鐵鹽供給 30 毫克之鐵質
    3. (C) 19～50 歲的建議值有性別上的差異
    4. (D) 所採用的建議量是足夠攝取量

    正解：(D)

  3. 3依據衛生福利部公告之「包裝食品營養標示應遵行事項」，下列敘述何者錯誤？

    1. (A) 個別營養素得列於所屬營養素項下標示，如各個脂肪酸得列於脂肪項下標示
    2. (B) 包裝份數值只能以整數標示
    3. (C) 膳食纖維以公克或 g 標示
    4. (D) 糖含量為必須標示之項目頁次：4－2

    正解：(B)

  4. 4對相同性別、年齡層之健康人群而言，同一種營養素的建議量，下列何者最高？

    1. (A) adequate intakes
    2. (B) estimated average requirement
    3. (C) recommended dietary allowance
    4. (D) tolerable upper intake levels

    正解：(D)

  5. 5衛生福利部在飲食指標建議，素食者可透過下列何種方式補充維生素 D？

    1. (A) 多攝取藻類食物
    2. (B) 多攝取堅果類食物
    3. (C) 多攝取全穀雜糧類食物
    4. (D) 每天適度日曬時間 20 分鐘

    正解：(D)

  6. 6國內母乳哺育推廣計畫，下列何者錯誤？

    1. (A) 限制母乳代用品廣告
    2. (B) 推動全國母嬰親善醫療院所認證評鑑
    3. (C) 公共場所應設置哺（集）乳室供民眾使用
    4. (D) 各縣市均已成立母乳庫，供特殊需求嬰兒使用

    正解：(D)

  7. 7關於幼兒期營養的說明與建議，下列何者錯誤？

    1. (A) 未精製穀類應占全穀雜糧類三分之一
    2. (B) 飲用果汁要適量，1 天不超過 240 c.c.
    3. (C) 2 歲以下兒童不宜飲用低脂或脫脂乳品
    4. (D) 為促進生長發育，建議儘量食用動物性蛋白質

    正解：(D)

  8. 8有關衛生福利部國民健康署肥胖防治計畫之敘述，下列何者錯誤？

    1. (A) 推動健康促進之場域包括職場、學校、社區，不包括醫院
    2. (B) 利用社會認知模式之自我監控之原理，鼓勵民眾「天天量體重」
    3. (C) 健康體重管理計畫之核心概念為「聰明吃、快樂動、天天量體重」
    4. (D) 根據社會生態模式之環境可及性，以健康美食地圖介紹各縣市健康產品之健康訴求與特色

    正解：(A)

  9. 9關於學校食物供應相關工作規範，下列敘述何者正確？

    1. (A) 經濟部以優惠價格撥售學校用餐食米
    2. (B) 學校餐飲從業人員應為食品營養相關科系畢業
    3. (C) 每天應抽檢各餐廳餐具之澱粉性及脂肪性殘留，並記錄之
    4. (D) 合作社負責蒸包子、煮茶葉蛋人員，每學年須參加衛生（健康飲食）講習至少 8 小時

    正解：(D)

  10. 10依據營養師法，有關營養師執業與罰則之敘述，下列何者錯誤？

    1. (A) 營養師應向執業所在地直轄市或縣（市）主管機關申請執業登記，領有執業執照，始得執業
    2. (B) 營養師執業，應接受繼續教育，並每 3 年提出完成繼續教育證明文件，辦理執業執照更新
    3. (C) 營養師將其證照租借他人使用者，廢止其營養師證書
    4. (D) 營養諮詢機構申請人須具營養師資格

    正解：(B)

  11. 11依據「不適合兒童長期食用之食品廣告及促銷管理辦法」，下列敘述何者錯誤？

    1. (A) 脂肪所占熱量為總熱量 35%之食品不適合未滿 12 歲兒童長期食用
    2. (B) 鈉含量每份為 200 mg 之食品不適合未滿 12 歲兒童長期食用
    3. (C) 不得對兒童以贈送、加購玩具或以玩具為獎勵等方式為促銷
    4. (D) 不得於 17 時至 21 時之兒童頻道刊播廣告

    正解：(B)

  12. 12國人代謝症候群的體位測量指標為何？

    1. (A) 身體質量指數≧24
    2. (B) 體脂肪比：男性≧25%，女性≧30%
    3. (C) 腰圍：男性≧90 cm，女性≧80 cm
    4. (D) 腰臀圍比：男性≧0.9，女性≧0.85

    正解：(C)

  13. 13檢測尿液排泄量以評估維生素是否缺乏，下列組合何者正確？

    1. (A) 菸鹼酸：檢測甲基丙二酸量（methylmalonic acid）
    2. (B) 維生素 B6：檢測氮—甲基菸鹼酸（N-methylnicotinamide）
    3. (C) 葉酸：檢測甲醯亞胺麩胺酸量（formiminoglutamic acid）
    4. (D) 維生素 B12：檢測黃尿酸量（xanthurenic acid）

    正解：(C)

  14. 14下列何者為社區營養調查時較適合用來評估體脂率的方法？

    1. (A) 身體總鉀量
    2. (B) 身體質量指數
    3. (C) 生物電阻分析法
    4. (D) 單一部位皮脂厚度測量頁次：4－3

    正解：(C)

  15. 15貧血與下列何項營養素缺乏無關？

    1. (A) 鐵
    2. (B) 鉻
    3. (C) 鈷
    4. (D) 葉酸

    正解：(B)

  16. 16迷你營養評估量表（Mini Nutritional Assessment；MNA）常用於篩檢營養不良高危險群，關於此量表的敘述，下列何者錯誤？

    1. (A) 需搭配血液生化數值
    2. (B) 完整的 MNA 評估包含小腿圍測量
    3. (C) 可由一般照護者或是醫護人員使用
    4. (D) 內容分成營養篩檢及一般評估兩部分

    正解：(A)

  17. 17迷你營養評估量表（MNA）中對老年人飲食的評估不包含：

    1. (A) 每天蔬果攝取
    2. (B) 每週早餐次數
    3. (C) 每天蛋白質攝取
    4. (D) 每天液體攝取量

    正解：(B)

  18. 18當鐵在身體內貯存量用盡，下列那一個血清中指標會首先出現異常？

    2. (B) 鐵蛋白（ferritin）
    3. (C) 血紅素（hemoglobin）
    4. (D) 運鐵蛋白（transferrin）

    正解：(B)

  19. 19紅血球麩胺基硫還原酶活性係數（EGRAC）可用來評估那一種維生素的營養狀況？

    1. (A) 維生素 B1
    2. (B) 維生素 B2
    3. (C) 維生素 B6

  20. 20有關食物頻率問卷（food frequency questionnaire）的敘述，下列何者正確？

    1. (A) 可精確估計個人每日食物攝取量
    2. (B) 可正確評估個人營養素攝取量
    3. (C) 可了解國民長期食物消費狀況
    4. (D) 可了解個人長期飲食型態

    正解：(D)

  21. 21滿意度調查問卷之答案選項：非常滿意、滿意、普通、不滿意、非常不滿意，屬於下列何種量尺？

    2. (B) 次序量尺（ordinal scale）
    3. (C) 等距量尺（interval scale）
    4. (D) 比率量尺（ratio scale）

    正解：(B)

  22. 22飲食行為問卷中詢問「常喝含糖飲料會影響健康，請問你每週喝含糖飲料幾次？」此題目設計有何缺失？

    1. (A) 題目具暗示作用
    2. (B) 題目涉及個人隱私
    3. (C) 題目詢問兩個以上概念
    4. (D) 題目超出受試者理解能力

    正解：(A)

  23. 23有關教材編製的步驟，下列何者為正確順序？①試驗 ②推廣使用 ③編輯整理 ④收集與選擇資料

    2. (B) ④③①②

  24. 24有關教案設計之敘述，下列何者錯誤？

    4. (D) 訂定教育目標時，可先依據教育對象之心理社會因子來設定

  25. 25某大學營養學系與附近國小合作，在校園內推動天天 5 蔬果活動，此類跨組織的合作稱之為：

    正解：(A)

  29. 29社區關懷據點的營養師為改善獨居老人的營養狀況，因此對該區民眾規劃「迷你營養評估量表（MNA）營養篩檢分數達 12 分以上者，由目前的 50%提高到 70%」 ，則目前所進行的營養計畫階段是屬於：

  30. 30某國小營養師提出「回家吃晚飯」系列活動，設計「30 分鐘準備一餐的食譜」，在高年級的課外活動教授學生動手做餐食，中年級學生教授洗米煮飯、洗碗技巧，低年級學生教授擺置餐具，並制定下列活動目標，請問何者不屬於過程目標？
