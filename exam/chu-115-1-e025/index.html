    2. (B) 物件導向書目紀錄功能需求（FRBR object-oriented, FRBRoo）
    3. (C) 文書連續性模式（Records Continuum Model）
    4. (D) 國際文獻工作委員會概念參考模型（CIDOC CRM）

    正解：(A)

  44. 44書目紀錄功能需求（FRBR）將書目著錄，分為三組實體描述，下列敘述何者錯誤？

    1. (A) 將一筆書目紀錄分成不同獨立的實體，並建立實體的關連性
    2. (B) 第一組為作品、表現形式、具體呈現與單件的關係著錄
    3. (C) 第二組為作品與個人、團體負責者之間的關係著錄
    4. (D) 第三組為作品所有屬性描述與書目關係的建立

    正解：(D)

  45. 45在語意網中，下列何種 W3C 標準是用來標記（markup）資料？

    1. (A) OWL
    2. (B) XML
    3. (C) SPARQL
    4. (D) SWRL

    正解：(B)

  46. 46下列何者不是「鏈結開放資料」（linked open data）的主要概念與目的？

    1. (A) 為實現機器學習的願景而設計的方法
    2. (B) 是發布結構化資料的方式
    3. (C) 所鏈結之資料皆為機器可讀
    4. (D) 利用全球資訊網為不同來源資料建立彼此之間的鏈結

    正解：(A)

  47. 47資源描述框架（RDF）的設計目的是以結構性的框架靈活地描述資訊，下列敘述何者錯誤？

    1. (A) 有形式化的語義和可證明的推論
    2. (B) 有一個簡單的資料模型
    3. (C) 使用基於 HTML 的語法
    4. (D) 任何人均可使用 RDF 描述資源

    正解：(C)

  48. 48基於關鍵字的文字內容視覺化，常見的分析原則是詞頻，即越是重要的單字，其在文件中出現的頻率越高，可以反應文字內容的重點。下列何者不是以關鍵字為主的視覺化技術？

    1. (A) 標籤雲（Tag Cloud）
    2. (B) 主題河流（ThemeRiver）
    3. (C) 文件卡片（Document Cards）
    4. (D) 文件散（DocuBurst）

    正解：(B)

  49. 49下列何者不為鏈結資料（linked data）四原則之一？

    1. (A) 使用統一資源標誌符（URIs）作為任何事物的標識
    2. (B) 使用超文本傳輸協定暨統一資源標誌符（HTTP URIs）讓任何人皆可以查找到這些名稱
    3. (C) 當有人找到任何 URI 時，使用資源描述框架（RDF）及語意查詢語言（SPARQL）等標準提供有用的資訊
    4. (D) 儘可能提供相關的數位物件識別碼（DOI），以讓人可以發現更多的事物

    正解：(D)

  50. 50圖書館的運作特質對於鏈結資料（linked data）資料集的長期保存上有許多優勢，下列敘述何者錯誤？

    1. (A) 品質控制的特質
    2. (B) 長期維護的承諾
    3. (C) 可以作為圖書館目前服務工作的延伸
    4. (D) MARC 格式無須調整即可直接支援鏈結資料集

    正解：(D)
