職能治療師　115 年第二次 職能治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1職能治療師以非標準化表現分析（nonstandardized performance analysis）評估個案自我進食活動的表現，下列何者不是必要的步驟？

  17. 17關於職能治療在社區中的介入，下列敘述何者錯誤？

    1. (A) 職能治療師應該具備文化和政治的意識和敏感度，有時需要帶領服務對象挑戰職能不公，倡議健康政策議題
    2. (B) 根據 Scaffa 博士（2002）的定義，社區健康（community health）必須是一群居住鄰近地區的人，在生理、情緒、社會和靈性上獲得安適感
    3. (C) 職能治療師可以進行社區營造（community building）的介入，設計團體活動促使社區成員參與，促進成員間的連結，培養團體凝聚力，增進社區感
    4. (D) 設計社區計畫的第一步是，確認一個需求未被滿足的族群，不限年齡層，只要是參與社區生活受限者皆是可以服務的對象

    正解：(B)

  18. 18以人類職能模式（Model of Human Occupation, MOHO）的觀點，個案失能的原因可能來自內在因子或外在因子。下列失能的例子中，何者的內在因子影響較小？

  21. 21兒童的氣質（temperament）可能會影響日後心理健康。對於氣質的描述，下列何者錯誤？

    1. (A) 氣質（temperament）是由先天與後天共同形塑出來的人格，與因應型態有高度關聯
    2. (B) 困難型氣質（difficult temperament）者可能會遭遇社會與行為困難，並有罹患心理健康問題的風險
    3. (C) 根據 Dyson 等人（2012）針對學齡前兒童的研究，兒童有比較高度正向的情緒與努力控制（effortfulcontrol），會傾向去尋求支持，使用主動的認知因應策略
    4. (D) 根據 Dyson 等人（2012）針對學齡前兒童的研究，兒童有比較高度負向的情緒，對於新的或壓力的情境會有高度警覺性，傾向使用逃避的因應策略

    正解：(A)

  22. 22有關方案服務的地理位置與使用空間之敘述，下列何者正確？

    2. (B) 地方性非營利組織由於稅金之緣故，通常不願意分享或提供社區空間來執行方案
    3. (C) 考量方案執行之場地時，需將參與者之場地與空間可近性（accessibility）納入考量
    4. (D) 當進行方案場地規劃時，需將場地租金納入經費預算表，而清潔費不需要事前納入

    正解：(C)
