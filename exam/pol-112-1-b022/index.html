警察特考　112 年 三等考試 警察組織與事務管理　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1有關警察核心任務，以下何者為非？

    1. (A) 治安
    2. (B) 交通
    3. (C) 防災
    4. (D) 預防犯罪

    正解：(C)

  2. 2警察組織運作經常重視各階層或層級的領導，請問同時考量領導者個人與情境因素的領導理論為何？

    1. (A) 特質領導理論
    2. (B) 權變領導理論
    3. (C) 領導角色理論
    4. (D) 領導行為理論

    正解：(B)

  3. 3以下何者不屬於需求理論的類別？

    1. (A) 需求層級理論
    2. (B) 資訊傳遞過程理論
    3. (C) 雙因子理論
    4. (D) 存在關係成長理論

    正解：(B)

  4. 4以古典組織理論詮釋組織，韋柏（Weber）的官僚組織（Bureaucracy）經常被提及，請問以下何者不是韋柏官僚組織的特點？

    1. (A) 重視人性的需求
    2. (B) 責任與分工清楚
    3. (C) 重視控制與權威
    4. (D) 層級節制

    正解：(A)

  5. 5有關警察組織結構設計的重要概念，以下何者為非？

    1. (A) 組織結構設計是警察組織為達成目標之手段
    2. (B) 警察組織結構無固定最好之形式
    3. (C) 警察組織的目標經常是單一的
    4. (D) 警察組織目標因環境改變而異

    正解：(C)

  6. 6有關社區警政或社區警察組織設計策略的敘述，下列何者錯誤？

    1. (A) 案件導向
    2. (B) 問題導向
    3. (C) 先發導向
    4. (D) 整合社區資源

    正解：(A)

  7. 7警察組織設有廉政部門，有關警察組織的廉政分工、名稱與運作，以下何者有誤？

    1. (A) 警政署下設有政風處
    2. (B) 警政署下設有廉政會報
    3. (C) 廉政會報每年召開一至兩次會議
    4. (D) 廉政會報會議紀錄應公開

    正解：(A)

  8. 8廣義的治安服務包括公共財（public goods）與私有財（private goods）項目在內，有關公共財與私有財的陳述，以下何者有誤？

    1. (A) 公共財由私人提供通常會有不足
    2. (B) 治安事項屬私有財部分，特別是可確定受惠範圍或人群者，可由私人（如保全公司）提供
    3. (C) 私人提供公共財可能出現道德風險問題
    4. (D) 警察提供治安私有財事項不會有爭議

    正解：(D)

  9. 9請問有關警察分局（特別是直轄市的警察分局）業務分工陳述，以下何者為誤？

    1. (A) 行政組辦理勤務規劃督考、公共關係（含警友會）、正俗業務、志工團隊組訓運用
    2. (B) 督察組辦理勤務執行之督導考核、員警風紀維護、特種警衛與一般警衛派遣、集會遊行、秩序維護、動員召集、保安警備等事項
    3. (C) 偵查隊辦理違反社會秩序維護法處理與行政處分、拾得物處理、拘留所管理、犯罪偵防、犯罪再犯機制策劃與執行、刑事案件偵訊等
    4. (D) 警備隊辦理警察勤務之指揮、調度、協調、聯繫與最新治安狀況之通報管制、受理民眾與 110通報案件之派遣、管制事項

    正解：(D)

  10. 10有關內政部警政署所編列之「警政署所屬單位預算」，請問以下何者有誤？

    1. (A) 民防指揮管制所在該預算書下編列
    2. (B) 國道公路警察局在該預算書下編列
    3. (C) 警察廣播電臺在該預算書下編列
    4. (D) 泰安警光山莊在該預算書下編列

    正解：(D)

  11. 11以下何者是正確的法律名稱？

    1. (A) 內政部警政署組織法
    2. (B) 內政部警政署組織規程
    3. (C) 內政部警政署組織條例
    4. (D) 內政部警政署組織章程

    正解：(A)

  12. 12有關警察的本質，下列敘述何者錯誤？

    1. (A) 是一種以法律為依據的行政作用
    2. (B) 是國家政權的部分
    3. (C) 警察法所稱警察，指警察機關與警察人員之總稱
    4. (D) 我國現用的「警察」一詞，係引用自日本語

    正解：(B)

  13. 131987 年後陸續解嚴、終止動員戡亂，直到 1992 年臺灣警備總司令部撤銷止，此期間我國警政組織發展也受到影響；以下何者為警察機關因應 1992 年之轉型而隨之調整？

    1. (A) 內政部警政署與臺灣省警務處分立
    2. (B) 淡水水上警察隊擴編成立水上警察局
    3. (C) 各縣市警察局增設安檢科，承接機場、港口安檢工作
    4. (D) 警力擴編增加，戶政業務回歸民政單位

    正解：(D)

  14. 14警察分駐所、派出所為勤務執行機構，其設置目的為組合警勤區、形成治安面及供作服務站。我國現行三級制警察機關中，未設警察分局之鄉、鎮、市、區得設置分駐所。下列機關何者目前未設置分駐所？

    1. (A) 桃園市政府警察局
    2. (B) 新竹市警察局
    3. (C) 苗栗縣警察局
    4. (D) 新竹縣政府警察局

    正解：(B)

  15. 15有關內政部警政署政風室之職掌，下列何者錯誤？

    1. (A) 定期財產申報受理
    2. (B) 會同監標監驗
    3. (C) 內部管理業務考核
    4. (D) 機關設施安全維護

    正解：(C)

  16. 16經濟部水利署臺北水源特定區，是國內第一個經由都市計畫法設立之水源保護區，負責管理新店溪集水區水源，為協助維護安全，目前由下列那一個機關派駐警力？

    1. (A) 保二總隊
    2. (B) 保三總隊
    3. (C) 保六總隊
    4. (D) 保七總隊

    正解：(D)

  17. 17有關社會治安網絡的推展策略，下列敘述何者錯誤？

    1. (A) 組織間是相互依賴關係，互動規則是由成員共同認定的
    2. (B) 政府不再擁有特權跟支配性，仍可以引導網絡的運作
    3. (C) 地方治安治理網絡以地區特性為基礎，有賴中央制定一體適用的治安計畫
    4. (D) 社會治安整治策略，各自均可形成個別的網絡，實現其個別功能

    正解：(C)

  18. 18警察的兩大任務是危害防止及人權保障，實務上要平衡兩者，下列何者具有憲法位階效力，為最優先考量與適用？

    1. (A) 比例原則
    2. (B) 平等原則
    3. (C) 保留原則
    4. (D) 信賴原則

    正解：(A)

  19. 19我國財務審計制度，是經由客觀地蒐證，加以進行審查與驗證。下列敘述何者錯誤？

    1. (A) 政府機關審計權為監察院之職權之一
    2. (B) 審計機關組織採一條鞭制
    3. (C) 公部門財務審計為利用內部獨立審計人員進行審查
    4. (D) 公部門績效審計針對施政計畫進行系統性評估

    正解：(C)

  20. 20有關各機關預算之執行，依預算法之規定，下列何者正確？

    1. (A) 總預算內各政事及計畫之經費，得互相流用。但行政院第一預備金不在此限
    2. (B) 歲出分配預算，業務科目經費不足，得辦理流用。但流用為用人經費，流出數額不得超過原預算數額百分之二十
    3. (C) 重大工程之投資計畫，超過四年未動用預算者，其預算應重行審查
    4. (D) 會計年度結束後，國庫賸餘不得轉入下年度

    正解：(C)

  21. 21政府採購法制定時，參酌先進國家作法及世界貿易組織政府採購協定規定，加入採最有利標決標之機制。以下敘述何者錯誤？

    1. (A) 機關依招標文件規定之評審標準，綜合評選擇定最佳決標對象
    2. (B) 價格可以納入評選項目，適當提高預算的規模
    3. (C) 得標者可以是分數高、品質好、價格高且合理
    4. (D) 鼓勵廠商從事非價格之競爭，避免惡性低價搶標

    正解：(B)

  22. 22依政府採購法第 12 條規定，採購金額達查核金額以上時，應報請上級機關派員監辦。所稱上級機關依同法第 9 條規定，指機關直屬之上一級機關。有關下列機關之上一級監辦機關何者為錯誤？

    1. (A) 內政部警政署為內政部
    2. (B) 航空警察局為交通部民航局
    3. (C) 臺北市政府警察局為臺北市政府
    4. (D) 臺灣警察專科學校為內政部警政署

    正解：(B)

  23. 23對於機關辦理採購之申訴，下列敘述何者正確？

    1. (A) 廠商對於公告金額以上採購異議之處理結果不服，得提出申訴
    2. (B) 提起申訴得準用民事訴訟法第 70 條規定，委任代理人為之
    3. (C) 申訴審議委員會應於收受申訴書之次日起三十日內完成審議
    4. (D) 審議判斷，視同訴願決定

    正解：(A)

  24. 24對於機關辦理採購之爭議處理期限，下列敘述何者錯誤？

    1. (A) 對招標文件規定提出異議者，為自公告或邀標之次日起等標期之四分之一
    2. (B) 對招標文件規定之釋疑或補充提出異議者，為接獲機關通知之次日起七日
    3. (C) 對採購過程、結果提出異議者，為接獲機關通知或公告之次日起十日
    4. (D) 招標機關應自收受異議之次日起十五日內為適當之處理

    正解：(B)

  25. 25Robertson 指出協力型公共治理的觀念架構，有關政府與非營利組織之間發展有效夥伴關係的脈絡中，下列四個關鍵課題何者錯誤？

    1. (A) 互動時的互惠天性，牽動人們面對彼此信任的感受
    2. (B) 知識與技術之應用，促進人們對培力的經驗
    3. (C) 所追求的旨趣之調和，影響人們獲取的經濟利益
    4. (D) 追求持續發展，展現出人們調適的能力

    正解：(C)
