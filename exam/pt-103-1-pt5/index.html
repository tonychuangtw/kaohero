物理治療師　103 年第一次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何者不是診斷胸廓出口症候群（thoracic outlet syndrome）相關症狀的測試？

    1. (A) EAST test
    2. (B) Military brace test
    3. (C) Adson’s maneuver
    4. (D) Ludington’s test

    正解：(D)

  2. 2胸廓出口症候群（thoracic outlet syndrome）常伴隨其它症狀，下列何者不包括在內？

    1. (A) 筋膜疼痛及頸部病變
    2. (B) 頸部病變及神經病變
    3. (C) 肩關節脫臼及神經病變
    4. (D) 姿勢錯誤及神經病變

    正解：(C)

  3. 3在acceleration injury的慢性期時，下列何種現象較不常見？

    1. (A) 頸長肌（longus colli）痙攣
    2. (B) 頸椎過度前凸（hyperlordosis）
    3. (C) 頸椎不穩定
    4. (D) 頭部前置（forward head）

    正解：(B)

  4. 4類風濕性關節炎患者併發顳頜關節功能不良（TMJ dysfunction）之機率為：

    1. (A) 女性大於男性
    2. (B) 男性大於女性
    3. (C) 無性別差異
    4. (D) 性別差異和年紀有關

    正解：(A)

  5. 5下列有關顳頜關節功能不良（TMJ dysfunction）的敘述，何者錯誤？

    1. (A) 不協調的顳頜關節動作通常是雙邊
    2. (B) 症狀有關節活動限制及肌肉痠痛
    3. (C) 症狀是可逆轉的
    4. (D) 早晨起床時，疼痛及關節活動度限制較明顯

    正解：(A)

  6. 6下列有關頸椎中軸延伸（axial extension）之敘述，何者錯誤？

    1. (A) 是頸椎的後收（retraction）動作
    2. (B) 頭部需做出屈曲動作
    3. (C) 頸椎前凸（cervical lordosis）弧度會變大
    4. (D) 上胸椎後凸（kyphosis）弧度會變小

    正解：(C)

  7. 7頸部側彎動作有嚴重角度限制時，下列何者是最可能的原因？

    1. (A) 後頸部韌帶受傷
    2. (B) 下頸椎（C4-C7）關節囊太緊
    3. (C) 前頸部韌帶受傷
    4. (D) 上頸椎（C0-C2）關節囊太緊

    正解：(B)

  8. 8在仰躺姿勢下，使用壓力回饋測試儀器（pressure biofeedback unit）評估頸椎，下列敘述何者正確？

    1. (A) 儀器放置於額頭，主要測量頸椎多裂肌（multifidus）肌肉功能
    2. (B) 儀器放置於後頸部，主要測量頸椎頸長肌（longus colli）肌肉功能
    3. (C) 儀器放置於額頭，主要測量頸椎頸長肌（longus colli）肌肉功能
    4. (D) 儀器放置於後頸部，主要測量頸椎多裂肌（multifidus）肌肉功能

    正解：(B)

  9. 9針對頸椎狹窄症（cervical spinal stenosis）進行擺位牽引治療時，頭頸部應置於：

    1. (A) 前彎及側彎至疼痛側
    2. (B) 後仰及側彎至疼痛側之對側
    3. (C) 後仰及側彎至疼痛側
    4. (D) 前彎及側彎至疼痛側之對側

    正解：(D)

  10. 10下列有關髖關節彈響症狀（snapping hip）之敘述，何者錯誤?

    1. (A) 可能是髂腰肌（iliopsoas）肌腱在大轉子（greater trochanter）上移動造成彈響聲（snapping）
    2. (B) 髖關節由完全屈曲角度做伸直動作時，在髖屈曲45°角度下，有可能發生彈響聲（snapping）
    3. (C) 須檢查闊筋膜張肌（tensor fascia lata）以及臀大肌，因為這些肌肉也會涉入
    4. (D) 給予髖關節外展（abduction）阻力測試時，通常不會痛

    正解：(A)

  11. 11以觸摸方式如何找到股骨頭（the head of femur）？

    1. (A) 在前上腸骨棘（anterior superior iliac spine）正下方處
    2. (B) 在鼠蹊韌帶（inguinal ligament）中央的下方約1-2公分處
    3. (C) 在股骨大轉子（greater trochanter）內側3-4公分處
    4. (D) 在奈勒敦連線（Nelaton line）中央的下方3-4公分處

    正解：(B)

  12. 12下列各方向之重複性過度負荷中，何者最可能是腰椎環狀纖維（annulus fibrosus）疲勞性斷裂之誘因？

    1. (A) 對稱性腰椎前彎
    2. (B) 對稱性腰椎後彎
    3. (C) 不對稱性腰椎前彎
    4. (D) 不對稱性腰椎後彎

    正解：(C)

  13. 13王太太陳述當她直挺身體走路大約只能維持20分鐘或只能走約50公尺，接著就會出現臀部與大腿後側的疼痛，此時需要身體前傾以舒緩症狀。此情形最有可能的病變為何？

    2. (B) 椎間盤突出
    3. (C) 脊椎狹窄
    4. (D) 小面關節病變

    正解：(C)

  14. 14呼吸動作會影響脊椎的穩定度。下列何者的功能不因呼吸動作而影響脊椎的穩定度？

    2. (B) 腹斜肌
    3. (C) 骨盆底肌
    4. (D) 臀大肌

  15. 15椎間盤突出（disc protrusion）在急性發作兩天內，下列做法何者正確？

    1. (A) 需完全臥床休息兩天，避免在其他姿勢下進行活動
    2. (B) 臥床休息時間不宜太長，可讓患者站立或從事步行活動
    3. (C) 以臥床休息為原則，期間輔以短暫的坐姿休息
    4. (D) 所有患者要儘快開始於趴臥姿進行利用前臂撐起（forearm support）的麥氏運動（McKenzie’s extension in lying exercise）

    正解：(B)

  16. 16下列何者是腰椎伸直症候群（extension syndrome）患者常見之慣用姿勢？

    1. (A) 腰椎屈曲姿（flexed posture）
    2. (B) 腰椎前凸姿（lordotic posture）
    3. (C) 腰部姿勢沒有異常
    4. (D) 腰部姿勢雖不正常，然無固定的不良姿勢

    正解：(A)

  17. 17一位病患敘述其最近腳的外側出現針刺的感覺，原地跳躍小腿明顯無力，臀部肌肉有萎縮現象，直膝抬腿的動作受限，懷疑其腰椎神經根可能出現壓迫。此現象最可能與那一節腰椎神經根有關？

    2. (B) L4

  18. 18當轉子滑囊炎（trochanteric bursitis）急性期過後疼痛減緩，下列何者應積極予以牽拉？

    1. (A) 內收大肌（adductor magnus）
    2. (B) 闊筋膜張肌（tensor fascia latae）
    3. (C) 臀小肌（gluteus minimus）
    4. (D) 髂腰肌（iliopsoas）

    正解：(B)

  19. 19患者在直膝抬腿（straight leg raise; SLR）測試中出現陽性測試結果時，下列敘述何者錯誤？

    1. (A) 在SLR時藉著髖關節內轉可以將梨狀肌處於鬆弛位置，以排除梨狀肌的干擾
    2. (B) 施測者一手放在受測者受測邊的前上髂骨棘（anterior superior iliac spine），一手支撐受測邊的足後
    3. (C) 膕旁肌的問題會出現在髖關節抬高約50°到70°的位置，而薦髂關節（sacroiliac joint）的問題約出現在抬高70°到90°的位置
    4. (D) 為鑑別是腰部還是臀部損傷，可將下肢抬到末端範圍後再加上膝屈曲，如髖關節屈曲角度增加，則傷害可能在臀部

    正解：(A)

  20. 20下列有關Patrick’s test的敘述，何者錯誤？

    1. (A) 檢查結果呈陽性是指檢查受測側膝部在碰到床面時出現疼痛
    2. (B) 若檢查結果呈陽性，則可能代表髂腰肌（iliopsoas）痙攣（spasm）
    3. (C) 若檢查結果呈陽性，則可能代表薦髂關節（sacroiliac joint）失能（dysfunction）
    4. (D) 又稱Jansen’s test

    正解：(A)

  21. 21關於髖關節韌帶的敘述，下列何者錯誤？

    1. (A) 髂股韌帶位於髖關節前方，是最強的一條
    2. (B) 髖關節韌帶的作用是防止髖關節過度後伸
    3. (C) 坐骨股骨韌帶位於髖關節後方，可限制髖關節外轉
    4. (D) 恥骨股骨韌帶位於髖關節前方，可限制髖關節外展

    正解：(C)

  22. 22患者在Noble’s compression test中出現陽性測試結果時，下列敘述何者錯誤？

    1. (A) 此檢查目的在評估患者是否有髂脛束摩擦症候群（iliotibial band friction syndrome）
    2. (B) 檢查姿勢為患者仰躺，膝關節與髖關節屈曲到90度，施測者大拇指壓在患者受測側股骨外髁（lateral condyle）上
    3. (C) 當維持拇指壓力時，病人慢慢伸直膝關節，在膝屈曲60到70度時有嚴重疼痛產生時就是陽性測試
    4. (D) 患者通常會指出檢查所誘發的疼痛與平時所感到的疼痛相同

    正解：(B)

  23. 23站立時下列何肌肉收縮會產生腰椎前凸？

  40. 40下列關於影響肩旋轉袖重建術（repair of the rotator cuff）之術後復健因素的敘述，何者正確？

    1. (A) 慢性或非外傷型（atraumatic）的旋轉袖肌群損傷比急性外傷類之旋轉袖肌群受損，復健進程較慢
    2. (B) 曾接受肩部類固醇注射治療之患者，復健進程較快
    3. (C) 肌腱至肌腱（tendon to tendon）重建手術比肌腱至骨頭（tendon to bone）重建手術，復健進程較快
    4. (D) 若病人之肩活動度受限，在保護範圍內（protected ROM）之早期復健運動時程應縮短，以利活動度之恢復

    正解：(A)
