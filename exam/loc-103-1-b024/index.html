  1. 1在電腦系統中，有關快取記憶體（cache）的敘述何者正確？

    1. (A) 可加大程式定址的空間
    2. (B) 可當 CPU 執行指令的暫存區，來加快 CPU pipeline 的處理速度
    3. (C) 當 CPU 在 cache 中找不到其所需的資料時，會先等待作業系統將資料由主記憶體或硬碟中移入 cache 中，然後 CPU 再到 cache 存取資料，繼續動作
    4. (D) 通常是一種可以內容來定址的記憶體（Content Addressable Memory）

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 快取以標籤（tag）比對的方式判斷所要的資料是否在快取中，屬以內容定址的記憶體（CAM）。

    ❌ (A) 擴大定址空間是虛擬記憶體的功能。

    ❌ (B) CPU 執行指令的暫存區是暫存器與管線暫存器，非快取的定位。

    ❌ (C) 快取失誤時由硬體的記憶體階層自動搬移資料，並非由作業系統介入。

    📚 出處：快取記憶體的運作原理

  2. 2某電腦有 32K 記憶體，若記憶體每個位元組的位址以 16 bits 來表示，採 16 進位表示法，第一個位元組之位 址為 0000，則最後一個位元組之位址應為：

    1. (A) 7EFF
    2. (B) 7FFF
    3. (C) 8000
    4. (D) 8FFF

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 32K＝32,768 個位元組，位址自 0000 起算至 32,767，換算為十六進位即 7FFF。

    ❌ (A) 7EFF 對應 32,511，未涵蓋全部位元組。

    ❌ (C) 8000 為 32,768，已是第 32,769 個位址。

    ❌ (D) 8FFF 遠超出 32K 的範圍。

    📚 出處：記憶體定址與進位轉換

  3. 3有關程式計數器（Program Counter）的敘述，下列何者正確？

    1. (A) 儲存 CPU 執行某程式時，已執行的指令之個數
    2. (B) 儲存 CPU 執行的程式之起始位址
    3. (C) 儲存 CPU 下一個要執行的指令之位址
    4. (D) 可設計在快取記憶體（cache）中來加快 CPU 對其之存取速度

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 程式計數器儲存 CPU 下一個要提取執行的指令位址，每取一次指令即自動遞增。

    ❌ (A) 已執行的指令個數不由 PC 記錄。

    ❌ (B) 程式起始位址只是 PC 的初值，非其持續的內容。

    ❌ (D) PC 是 CPU 內部的專用暫存器，不置於快取中。
