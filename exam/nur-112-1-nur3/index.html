護理師　112 年第一次 內外科護理學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1罹患腦下垂體腫瘤病人，醫師建議使用伽馬刀療法，下列何者顯示病人已了解本項治療？

    1. (A) 治療時我的頭部會有一個切開傷口
    2. (B) 治療時我不會疼痛也不會流血
    3. (C) 治療後我的頭部會有留一條小型引流管
    4. (D) 治療後我的腦瘤會立即消失

    正解：(B)

  2. 2與阿茲海默症病人的溝通技巧，下列何者不適宜？

    1. (A) 若病人只能說出單字或短句，照顧者也要用簡單、易了解的字彙或圖片與其溝通
    2. (B) 當病人出現眼神避開時，表示不了解溝通內容
    3. (C) 溝通時，應該使用低音量、高音調及緩慢的速度
    4. (D) 可以善用拍打和擁抱的觸覺刺激，協助病人表達

    正解：(C)

  3. 3有關多發性硬化症病人的自我照顧之護理指導，下列敘述何者錯誤？

    1. (A) 鼓勵病人多攝取水分和高纖食物，預防便秘
    2. (B) 依排定如廁時間表，提醒病人如廁
    3. (C) 減少社交參與，避免造成身體心像紊亂
    4. (D) 若出現複視，可以使用眼罩遮住一眼，緩解複視

    正解：(C)

  4. 4有關腦腫瘤病人術後發生尿崩症，下列敘述何者正確？

    1. (A) 尿比重會比正常人高
    2. (B) 會有尿量多、血漿滲透壓下降
    3. (C) 因抗利尿素（ADH）分泌不足所致
    4. (D) 可能有低血鈉導致抽搐症狀

    正解：(C)

  5. 5有關顱內壓升高的藥物治療，下列敘述何者錯誤？

    1. (A) 類固醇治療可用於腦瘤引起的血管性腦水腫
    2. (B) Mannitol 滲透性利尿劑若出現反彈現象會使腦水腫更嚴重
    3. (C) 巴比妥酸鹽可降低腦組織代謝及使得血流均勻供應腦部
    4. (D) 顱內壓升高病人皆須給與抗痙攣藥物以預防抽搐發作

    正解：(D)

  6. 6有關巴金森氏症病人的日常活動指導，下列敘述何者錯誤？

    1. (A) 行走時使用底面積較寬的助行器維持平衡
    2. (B) 漸進式運動計畫以增加病人肌肉力量，鼓勵全關節運動
    3. (C) 鼓勵病人以寬步伐行走，行走時身體直立，提醒腳跟先著地
    4. (D) 因身體僵硬，鼓勵坐深且柔軟的椅子

    正解：(D)

  7. 7進行意識評估，病人無法自動睜眼，叫喚才會睜開眼睛，人、地定向感清楚，但時間回答錯誤，能遵照指示做出正確的動作，其 GCS 昏迷量表，下列何者正確？
