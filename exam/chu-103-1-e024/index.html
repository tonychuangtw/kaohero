  45. 45在一個機關、學校或公司等單位內部，採用纜線或無線方式將電腦連成網路，使得一些非對外公開性的資料，能夠更容易被組織內部的使用者所存取。此種網路型態稱為：

    1. (A) TCP/IP
    2. (B) Internet
    3. (C) Intranet
    4. (D) ICT

    正解：(C)

  46. 46下列那一種研究法，最適合大學圖書館調查館藏支援教師學術研究之程度？

    1. (A) 資料探勘（Data Mining）法
    2. (B) 引文分析（Citation Analysis）法
    3. (C) 歷史研究（Historical Research）法
    4. (D) 疊慧（Delphi）法

    正解：(B)

  47. 47下列那一項敘述屬於齊夫定律（Zipf’s Law）？

    1. (A) 探討文獻分散現象
    2. (B) 研究科學生產力分布
    3. (C) 描述文獻成長模式
    4. (D) 分析詞彙平衡特性

    正解：(D)

  48. 48「一個網站或是網路物件被找到的能力，包含網站被使用者找到的能力，以及網站提供使用者查找所需資訊的能力」，是屬於下列那個名詞的定義？

    1. (A) 權威性（Authority）
    2. (B) 可靠性（Credibility）
    3. (C) 能見度（Visibility）
    4. (D) 尋獲度（Findability）

    正解：(D)

  49. 49彼得．柏克（Peter Burke）在他所著的《知識社會史：從古騰堡到狄德羅》一書中，認為歐洲近代的早期，能大量累積知識的歷史因素有三，下列何者錯誤？

    1. (A) 女性受教權的提升
    2. (B) 工具書和百科全書的大量產出
    3. (C) 圖書館數量的增加
    4. (D) 可供人民使用的專業知識越來越多

    正解：(A)

  50. 50有關 Green Computing 的描述，下列何者正確？

    1. (A) 螢幕以綠色字體顯示，以保護操作人員的視力
    2. (B) 機構不得監視員工的電腦使用行為
    3. (C) 盡量使用綠色紙張列印文件
    4. (D) 以環保態度來處理電腦使用與耗材問題

    正解：(D)
