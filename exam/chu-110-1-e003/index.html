初等考試　110 年 初等考試 法學大意（一般行政組）　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1關於歐陸法系和英美法系的區別，下列敘述何者錯誤？

    1. (A) 屬於歐陸法系的國家不以歐洲國家為限
    2. (B) 歐陸法系國家之判決對後案沒有法律拘束力，但有事實上拘束力
    3. (C) 歐陸法系法官審判時的主要法源是成文法
    4. (D) 英美法系為案例法國家，因此沒有成文法

    正解：(D)

  2. 2法律與道德有相似及相異之處，下列敘述何者錯誤？

    1. (A) 道德與法律相同，均是一種成文規範
    2. (B) 道德的成立或變遷與法律不同，不需經過一定程序修改
    3. (C) 法律是以國家公權力作為後盾，道德則無
    4. (D) 道德有時會影響法院對於個別法律的解釋

    正解：(A)

  3. 3關於行政機關之適用法律，下列敘述何者正確？

    1. (A) 行政機關適用法律須經人民申請，始得為之
    2. (B) 行政機關原則上應獨立適用法律，不受上級指揮監督
    3. (C) 行政機關於法定範圍內，行使合義務之裁量權
    4. (D) 行政機關在執行法律之際，不得發布命令

    正解：(C)

  4. 4下列判決文字運用了何種解釋方法？「依其規定之內容乃須有所謂的『治理』……。而所謂『治理』乃指『管理』（趙錫如主編辭海第 576頁）……」

    1. (A) 文義解釋
    2. (B) 體系解釋
    3. (C) 歷史解釋
    4. (D) 目的解釋

    正解：(A)

  5. 5依中央法規標準法第 21 條，法規廢止之事由不包括下列何者？

    1. (A) 機關裁併，有關法規無保留之必要者
    2. (B) 法規違反國際人權公約，而無繼續施行之必要者
    3. (C) 法規規定之事項已執行完畢，無繼續施行之必要者
    4. (D) 同一事項已定有新法規，並公布或發布施行者

    正解：(B)

  6. 6依地方制度法第 27 條，自治規則得使用之名稱，不包括下列何者？

  7. 7依憲法及增修條文規定，關於大法官之組成及職權，下列敘述何者正確？

  8. 8依司法院大法官解釋，人民參加下列何種考試，不在憲法第 18 條應考試權的保障範圍內？

  11. 11依憲法規定及司法院大法官解釋，關於人身自由之敘述，下列何者錯誤？

    1. (A) 遣送出境前之強制收容屬於人民身體自由之剝奪，收容事由應以法律直接規定或法律具體明確授權之命令定之
    2. (B) 基於防疫目的之強制隔離，已屬人身自由之剝奪
    3. (C) 「除現行犯之逮捕由法律另定外，非經司法或警察機關依法定程序，不得逮捕拘禁」之規定屬於憲法保留事項
    4. (D) 遣送出境前之暫時收容雖非刑事逮捕拘禁，仍應由法院為之，始符憲法第 8 條之意旨

    正解：(D)

  12. 12依憲法及司法院大法官解釋，關於言論自由的敘述，下列何者錯誤？

    1. (A) 言論自由在於保障資訊之自由流通，使人民有取得充分資訊及自我實現之機會
    2. (B) 商業廣告係利用傳播方法，宣傳商品效能，以達招徠銷售為目的，不受言論自由之保障
    3. (C) 公共場所於不妨礙其通常使用方式之範圍內，亦得供人民之言論表達及意見溝通
    4. (D) 言論自由具有實現自我、溝通意見、追求真理之功能

    正解：(B)

  13. 13依憲法增修條文及司法院大法官解釋，關於總統之地位與職權，下列敘述何者錯誤？

    1. (A) 總統於戒嚴或緊急命令生效期間，不得解散立法院
    2. (B) 總統雖為國家元首，但完全不具最高行政首長地位
    3. (C) 總統為決定國家安全有關大政方針，得設國家安全會議及所屬國家安全局，其組織以法律定之
    4. (D) 總統發布行政院院長與依憲法經立法院同意任命人員之任免命令及解散立法院之命令，無須行政院院長之副署

    正解：(B)

  14. 14道路交通管理處罰條例規定，汽車駕駛人無駕駛執照而駕駛者，處新臺幣六千元以上一萬二千元以下罰鍰，並當場禁止其駕駛。下列敘述何者正確？

    2. (B) 主管機關對於是否當場禁止違規駕駛人駕駛，應依法律授權目的行使裁量權
    3. (C) 對於初次違規之駕駛人，主管機關皆應裁處最低罰鍰額度，以符合比例原則
    4. (D) 對於具有特殊情形之個案，不適用統一裁罰基準表決定罰鍰額度，並未違法

    正解：(D)

  20. 20有關瑕疵行政處分效力之敘述，下列何者正確？

    2. (B) 行政處分違反公共秩序善良風俗者，無效
    3. (C) 無效行政處分，係自發現無效事由時起，向將來失效；得撤銷行政處分經撤銷後，有溯及失效的效果
    4. (D) 行政機關作成瑕疵行政處分，不得本於職權撤銷該處分，僅得由行政法院為之

    正解：(B)

  26. 26甲死亡後留下數筆存款及土地，其子女乙、丙、丁、戊為繼承人。甲遺囑中表示四大房子孫要團結，故不得分割遺產。下列敘述何者正確？

  32. 32關於民法規定正當防衛、緊急避難與自助行為之敘述，下列何者正確？

    2. (B) 因避免自己之配偶、或直系血親三親等內之親屬，受到身體或自由上之急迫危險所為之家族集體自助行為，致生他人之生命身體或財產損害者，不負賠償責任
    3. (C) 對於現時或 24 小時內已發生之不法的人身侵害，為防衛自己、配偶或家屬之權利所為的行為，不負損害賠償之責
    4. (D) 為保護自己權利，對於他人之自由或財產施以拘束、押收或毀損者，不負損害賠償之責。但以不及受法院或其他有關機關援助，並非於其時為之，則請求權不得實行或其實行顯有困難者為限

    正解：(D)

    正解：(C)

  37. 37下列何者非屬最高限額抵押權所擔保原債權之法定確定事由？

    1. (A) 擔保債權之範圍變更或因其他事由，致原債權不繼續發生者
    2. (B) 最高限額抵押權所擔保之債權，其請求權已因時效而消滅
    3. (C) 最高限額抵押權人聲請裁定拍賣抵押物
    4. (D) 債務人或抵押人經裁定宣告破產確定者

    正解：(B)

  38. 38甲男乙女為夫妻，有丙、丁二子。丙有戊、己二子。丙先於甲死亡。甲死亡時，戊依法拋棄繼承。己之應繼分為何？

    1. (A) 三分之一
    2. (B) 四分之一
    3. (C) 五分之一
    4. (D) 六分之一

    正解：(A)

  39. 39關於刑事訴訟法第 155 條第 2 項所定「無證據能力、未經合法調查之證據，不得作為判斷之依據。」下列敘述何者正確？

    1. (A) 這是證據之證明力的規定
    2. (B) 證據能力是由法院本於確信自由判斷
    3. (C) 這是關於嚴格證明的規定
    4. (D) 只要經過合法調查的證據資料，均有證據能力

    正解：(C)

  40. 40檢察官以被告甲在警詢中自白、購毒者乙在偵查中之證言等證據，起訴甲販賣毒品罪。甲在第一審受命法官準備程序期日，陳述其在警詢時之自白，是被強暴脅迫所為，下列何人要就甲在警詢中係出於自由意志之自白，指出證明方法？

    1. (A) 甲
    2. (B) 檢察官
    3. (C) 法官
    4. (D) 乙

    正解：(B)

  41. 41被告經法官訊問後，犯罪嫌疑重大，而有羈押原因，非予羈押顯難進行訴訟。然下列何項原因，不得單獨成為羈押被告原因？

    1. (A) 逃亡或有事實足認為有逃亡之虞者
    2. (B) 有事實足認為有湮滅、偽造、變造證據或勾串共犯或證人之虞者
    3. (C) 所犯為死刑、無期徒刑或最輕本刑為五年以上有期徒刑之罪者
    4. (D) 所犯為死刑、無期徒刑或最輕本刑為五年以上有期徒刑之罪，有相當理由認為有逃亡、湮滅、偽造、變造證據或勾串共犯或證人之虞者

    正解：(C)

  42. 42下列何項供述，依刑事訴訟法規定有證據能力？

    1. (A) 被告在警察詢問時，依自由意志所為供述
    2. (B) 檢察官未為權利告知，訊問後被告所為供述
    3. (C) 檢察官不待被告通知之律師到場，訊問後被告所為供述
    4. (D) 被告於警詢被刑求取供後，隨即被移送檢察官，檢察官立刻訊問後被告所為供述

    正解：(A)

  43. 43下列何者不屬刑法第 21 條第 1 項規定依法令之行為？

    1. (A) 司法警察逮捕通緝犯
    2. (B) 路人甲逮捕現行犯
    3. (C) 父母管教滿 20 歲之子女
    4. (D) 檢察官執行死刑

    正解：(C)

  44. 44下列何者非屬刑法第 22 條規定之業務上正當行為？

    1. (A) 醫生為病人開刀
    2. (B) 拳擊手依比賽規則打傷對方
    3. (C) 棒球投手故意投觸身球傷害打擊者
    4. (D) 護士為病人打針

    正解：(C)

  45. 45有關刑法第 23 條正當防衛之敘述，下列何者正確？

    1. (A) 侵害已經結束，仍得主張正當防衛
    2. (B) 互毆可以主張正當防衛
    3. (C) 對警察依法逮捕之行為可以主張正當防衛
    4. (D) 防衛行為過當者，得減輕或免除其刑

    正解：(D)

  46. 46下列何者非屬於刑法第 24 條（緊急避難）明文列出之利益？

    1. (A) 生命
    2. (B) 財產
    3. (C) 名譽
    4. (D) 自由

    正解：(C)

  47. 47有關刑法第 62 條自首之敘述，下列何者錯誤？

    1. (A) 自首必減輕其刑
    2. (B) 自首可以言詞或書面為之
    3. (C) 自首可請人代理向警察機關為之
    4. (D) 通緝犯自行投案，不是自首

    正解：(A)

  48. 48公務員甲犯貪污治罪條例第 4 條第 1 項第 5 款對於違背職務之行為收受賄賂罪，則關於其自首或自白敘述，下列何者正確？

    1. (A) 於犯罪後自首，即應減輕或免除其刑
    2. (B) 在偵查中自白，得減輕或免除其刑
    3. (C) 在偵查中自白，如有所得並自動繳交全部所得財物者，減輕其刑
    4. (D) 在偵查中自白，如有所得並自動繳交全部所得財物者，減輕或免除其刑

    正解：(C)

  49. 49依刑法第 10 條第 2 項規定之公務員定義，執行職務中之警察人員屬於下列何者？

    1. (A) 身分公務員
    2. (B) 授權公務員
    3. (C) 派遣公務員
    4. (D) 委託公務員

    正解：(A)

  50. 50甲、乙二人遊手好閒，某日謀議如何殺害甲之父親，以早日繼承財產，甲即帶乙返家，甲在外把風，由乙進入實施殺害行為，其二人係犯何罪？

    1. (A) 共犯殺人罪
    2. (B) 甲犯殺害直系血親尊親屬罪，乙犯殺人罪
    3. (C) 共犯殺害直系血親尊親屬罪
    4. (D) 甲犯幫助殺人罪，乙犯殺人罪

    正解：(B)
