初等考試　102 年 初等考試 運輸學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列何者並不是運輸管制措施之主要類型？

    1. (A) 報酬率管制
    2. (B) 虧損比管制
    3. (C) 價格管制
    4. (D) 服務品質管制

    正解：(B)

  2. 2下列何種定價法也被稱為雷姆西定價法（Ramsey pricing）？

    1. (A) 最大利潤定價法
    2. (B) 邊際成本定價法
    3. (C) 次佳定價法
    4. (D) 平均成本定價法

    正解：(C)

  3. 3下列何種運輸方式較不可能被歸類成副大眾運輸？

    1. (A) 隨停公車
    2. (B) 需求反應式運輸系統
    3. (C) 計程車
    4. (D) 公車捷運系統

    正解：(D)

  4. 4運輸建設的投資都相當龐大，一旦停止使用，難以改為其他用途，且殘值偏低，此係屬何種特性？

    1. (A) 固定成本
    2. (B) 變動成本
    3. (C) 會計成本
    4. (D) 沉沒成本

    正解：(D)

  5. 5人們為了從事某種社經活動而搭乘各種運具，此種運輸需求稱為：

    1. (A) 社會需求
    2. (B) 經濟需求
    3. (C) 引申需求
    4. (D) 尖峰需求

    正解：(C)

  6. 6下列何者不屬於改善交通安全的 3E 政策？

    1. (A) 工程（Engineering）
    2. (B) 教育（Education）
    3. (C) 效率（Efficiency）
    4. (D) 執行（Enforcement）

    正解：(C)

  7. 7下列何者不是海運提單在國際貿易之主要功能？

    1. (A) 貨物收據
    2. (B) 契約之憑證
    3. (C) 營運調度之依據
    4. (D) 有價證券

    正解：(C)

  8. 8都市大眾捷運系統（MRT）屬於何種路權型態？

    1. (A) A 型
    2. (B) B 型
    3. (C) C 型
    4. (D) D 型

    正解：(A)

  9. 9以下何者並不是政府需對運輸業者管制之主要原因？

    1. (A) 具沉沒成本高之特性
    2. (B) 具有外部成本與外部效益之特性
    3. (C) 具有公共財之特性
    4. (D) 具有高度競爭之特性

    正解：(D)

  10. 10根據商港法之規定，商港公共基礎設施之興建維護費用，是由下列何種經費來源支付？

    1. (A) 自由貿易港區基金
    2. (B) 航商自籌經費
    3. (C) 航港建設基金
    4. (D) 海運安定基金

    正解：(C)

  11. 11下列何者不屬於公路運輸的特徵？

    1. (A) 機動性高
    2. (B) 及門運輸服務
    3. (C) 專用路權
    4. (D) 公共性高

    正解：(C)

  12. 12廠商生產的產品藉由良好的運輸系統，適時地由產地運送至市場，使消費者能購買享用，這是運輸所能創造的何種效用？

    1. (A) 形式效用
    2. (B) 時間效用
    3. (C) 消費效用
    4. (D) 乘數效用

    正解：(B)

  13. 13交通部臺灣鐵路管理局是屬於何種組織型態？

    1. (A) 行政型組織
    2. (B) 特別型組織
    3. (C) 公司型組織
    4. (D) 社會型組織

    正解：(A)

  14. 14永續運輸是現今世界發展的潮流，下列何者不是永續運輸的目標？

    1. (A) 節省能源
    2. (B) 降低污染
    3. (C) 增加私人運具的使用
    4. (D) 提升生活品質

    正解：(C)

  15. 15下列何者屬於運輸系統服務範圍的指標？

    1. (A) 移動性
    2. (B) 易行性
    3. (C) 可及性
    4. (D) 快速性

    正解：(C)

  16. 16下列何者不是運輸規劃中交通量指派常用之方法？

    1. (A) 全數分派法
    2. (B) 旅次行為分派法
    3. (C) 容量限制分派法
    4. (D) 多重路徑比例分派法

    正解：(B)

  17. 17高速公路上之高承載車輛專用道設施，是屬於何種運輸系統管理策略？

    1. (A) 降低需求策略
    2. (B) 減少供給策略
    3. (C) 降低需求並減少供給策略
    4. (D) 降低需求並增加供給策略

    正解：(C)

  18. 18下列何種運輸系統具備專用運輸的特性？

    1. (A) 管道運輸系統
    2. (B) 水路運輸系統
    3. (C) 公路運輸系統
    4. (D) 航空運輸系統

    正解：(A)

  19. 19海上運輸運送糖、鹽、水泥、穀物、煤、礦砂等原物料是採用那一種船舶？

    1. (A) 雜貨船
    2. (B) 貨櫃船
    3. (C) 散裝船
    4. (D) 笨重船

    正解：(C)

  20. 20以航空器從事空中遊覽、勘察、照相、消防、搜尋、救護、拖吊、噴灑等營業性的飛航屬於：

    1. (A) 民用航空運輸業
    2. (B) 航空貨運承攬業
    3. (C) 直昇機運輸業
    4. (D) 普通航空業

    正解：(D)

  21. 21捷運系統軌道旁的另一類似鋼軌的設備，俗稱為第三軌，是屬於何種設施？

    1. (A) 集電設施
    2. (B) 軌道設施
    3. (C) 導引設施
    4. (D) 支撐設施

    正解：(A)

  22. 22航空站提供飛機起降相關作業活動的空間部分稱為：

    1. (A) 陸側
    2. (B) 空側
    3. (C) 航側
    4. (D) 滑行道

    正解：(B)

  23. 23何種運輸服務型態之客、貨運運價屬於報備制？

    1. (A) 公路
    2. (B) 鐵路
    3. (C) 國內航空
    4. (D) 海運

    正解：(D)

  24. 24下列何種海運貨櫃裝卸方法，適合進行公路與海運的聯運？

    1. (A) LO/LO
    2. (B) FO/FO
    3. (C) RO/RO
    4. (D) CO/CO

    正解：(C)

  25. 25鐵路貨物運輸之背載運輸作業方式，將貨櫃放置於鐵路平車上之運輸方式稱為：

    1. (A) COFC
    2. (B) FOFC
    3. (C) DOFC
    4. (D) TOFC

    正解：(A)

  26. 26各國政府對於運輸事業的經營皆有一定程度的管制，這是因為運輸供給具有何種特性？

    1. (A) 規模經濟
    2. (B) 產銷單位一致
    3. (C) 可存儲
    4. (D) 資本固定

    正解：(A)

  27. 27政府進行運輸費率的管制，通常是基於公平合理的原則，但仍常採取什麼策略，以促使業者增加運能並維持服務品質？

    1. (A) 環保管制
    2. (B) 安全管制
    3. (C) 牌照監理
    4. (D) 補貼

    正解：(D)

  28. 28下列何種運輸系統具備最低的單位運量運輸成本？

    1. (A) 鐵路運輸系統
    2. (B) 公路運輸系統
    3. (C) 航空運輸系統
    4. (D) 水路運輸系統

    正解：(D)

  29. 29在進行客運旅次的旅行成本分析時，通常僅計算什麼成本？

    1. (A) 維修成本
    2. (B) 時間成本
    3. (C) 運具成本
    4. (D) 實際支出成本

    正解：(D)

  30. 30運輸成本分析中，常見的回程運輸所產生的成本是屬於：

    1. (A) 聯合成本
    2. (B) 非聯合共同成本
    3. (C) 直接成本
    4. (D) 間接成本

    正解：(A)

  31. 31在貨物運輸中，商品運輸需求的產生必須符合何種條件？

    1. (A) 商品在產地的生產成本低於商品在市場消費者可以接受的價格
    2. (B) 商品在產地的銷售價格低於商品在市場消費者可以接受的價格
    3. (C) 商品在產地的生產成本和商品由產地運至市場的運費二者之和高於商品在市場消費者可以接受的價格
    4. (D) 商品在產地的生產成本和商品由產地運至市場的運費二者之和低於商品在市場消費者可以接受的價格

    正解：(D)

  32. 32下列何者不是智慧型運輸系統（ITS）改善交通擁擠常用的方法？

    1. (A) 提供即時交通資訊
    2. (B) 提供公車站牌路線圖
    3. (C) 事故自動偵測
    4. (D) 採用電子收費系統

    正解：(B)

  33. 33下列何者不屬於公路法所規範的道路及其用地範圍之各項設施？

    1. (A) 鄉道
    2. (B) 市區道路
    3. (C) 縣道
    4. (D) 省道

    正解：(B)

  34. 34我國的高速鐵路是屬於鐵路法規定的何種經營型態？

    1. (A) 國營鐵路

    3. (C) 民營鐵路

  35. 35下列何種策略或作法不符合永續運輸的概念？

    1. (A) 油價補貼
    2. (B) 港口民營化
    3. (C) 使用者付費
    4. (D) 無障礙設施

    正解：(A)

  36. 36甲國的航空器得在乙國的航空站降落，並裝載乙國之客貨郵件回航甲國之權利，但不得將來自甲國之客貨郵件在乙國航空站卸下，係指國際航權協定所稱之第幾航權？

    1. (A) 第一航權
    2. (B) 第二航權
    3. (C) 第三航權
    4. (D) 第四航權

  37. 37下列何者並不屬於運輸規劃程序中所指的 3C 原則？

    1. (A) Comprehensive
    2. (B) Continuous
    3. (C) Collective
    4. (D) Coordinated

    正解：(C)

  38. 38下列那個系統不屬於鐵路列車自動控制系統的一部分？

    1. (A) ATC
    2. (B) ATO
    3. (C) ATP
    4. (D) ATT

    正解：(D)

  39. 39根據民用航空運輸業管理規則，下列何者為民用航空運輸業以飛機直接載運客、貨、郵件，取得報酬之業務？

    1. (A) 定期航空運輸業務
    2. (B) 不定期航空運輸業務
    3. (C) 飛機運輸業務
    4. (D) 直昇機運輸業務

    正解：(C)

  40. 40在大眾運輸事業補貼辦法中，大眾運輸事業補貼由相關機關辦理，請問下列敘述何者錯誤？

    1. (A) 鐵路運輸業：由中央主管機關辦理
    2. (B) 船舶運送業：由中央主管機關辦理
    3. (C) 公路汽車客運業：由直轄市、縣（市）政府辦理
    4. (D) 市區汽車客運業：由直轄市、縣（市）政府辦理

    正解：(C)

  41. 41私有建築物附設之停車空間，得供公眾收費停車使用，這是下列何項法令的規定？

    1. (A) 道路交通安全處罰條例
    2. (B) 停車場法
    3. (C) 建築法
    4. (D) 道路交通管理處罰條例

    正解：(B)

  42. 42根據道路交通事故處理規範所定義之交通事故類型，若交通事故僅有財物損失之事故是指下列何種交通事故？

    2. (B) A2 類
    3. (C) A3 類
    4. (D) A4 類

    正解：(C)

  43. 43根據道路交通管理處罰條例對於慢車種類及名稱之規定：經型式審驗合格，以電力為主，最大行駛速率在每小時二十五公里以下，且車重（不含電池）在四十公斤以下之二輪車輛，是指下列何種車輛？

    3. (C) 腳踏自行車

  44. 44根據我國民用航空法的定義，下列何者不屬於航空運輸業？

    2. (B) 普通航空業
    3. (C) 航空貨物集散站經營業
    4. (D) 飛機製造業

    正解：(D)

  45. 45根據公路法對不同運輸業者之定義，下列何者錯誤？

    1. (A) 公路汽車客運業：在核定路線內，以公共汽車運輸旅客為營業者
    2. (B) 巿區汽車客運業：在核定區域內，以公共汽車運輸旅客為營業者
    3. (C) 汽車貨運業：在核定路線內，以載貨汽車運送貨物為營業者
    4. (D) 汽車貨櫃貨運業：在核定區域內，以聯結車運送貨櫃貨物為營業者

  46. 46臺灣高鐵系統所使用之鋼軌重量最有可能是多少 kg/m？

    1. (A) 30
    2. (B) 40
    3. (C) 50
    4. (D) 60

    正解：(D)

  47. 47下列那一項運輸系統計畫是以 BOT 的模式推動？

    1. (A) 臺北捷運
    2. (B) 桃園機場捷運
    3. (C) 高雄捷運
    4. (D) 國道三號高速公路建設

    正解：(C)

  48. 48根據鐵路法之規定：旅客無票乘車或持用失效乘車票，應補收票價；如無正當理由者，並得加收百分之多少的票價？

    1. (A) 百分之五十
    2. (B) 百分之六十
    3. (C) 百分之七十
    4. (D) 百分之八十

    正解：(A)

  49. 49根據公路法的定義，下列何者錯誤？

    1. (A) 國道：指聯絡二省（市）以上，及重要港口、機場、邊防重鎮、國際交通與重要政治、經濟中心之主要道路
    2. (B) 專用公路：指各公私機構申請公路主管機關核准興建，專供其本身運輸之道路
    3. (C) 鄉道：指聯絡鄉（鎮、市）及鄉（鎮、市）與村、里、原住民部落間之道路
    4. (D) 省道：指聯絡縣（市）及縣（市）與重要鄉（鎮、市）間之道路

    正解：(D)

  50. 50下列何者並非管道運輸之特性？

    2. (B) 無空載運輸成本

    4. (D) 運輸可靠度高

    正解：(A)
