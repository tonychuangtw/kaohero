警察特考　114 年 四等考試 海巡法規概要（一般警察・水上警察人員輪機組組）　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1近年來我政府將防範及查處中共滲透各機關列為重點宣導工作，請問若海巡人員將公務上的秘密文書交付中共情工人員，依國家安全法如何處罰？

    1. (A) 處一年以下有期徒刑、拘役或新臺幣三十萬元以下罰金
    2. (B) 處六月以上五年以下有期徒刑，得併科新臺幣三百萬元以下罰金
    3. (C) 處一年以上七年以下有期徒刑，得併科新臺幣一千萬元以下罰金
    4. (D) 處七年以上有期徒刑，得併科新臺幣五千萬元以上一億元以下罰金

    正解：(C)

  2. 2有關國家安全法所規定之檢查，請問下列敘述何者錯誤？

    1. (A) 對於入出境之船舶得作清艙檢查
    2. (B) 對於進口之貨櫃得於目的地實施落地檢查
    3. (C) 對於航行境內船舶，旅客於登船時得查驗身分證明
    4. (D) 對於旅客攜帶之手提行李由檢查人員實施搜索檢查

    正解：(D)

  3. 3為確保海防及軍事設施安全，得由國防部會同內政部指定海岸或重要軍事設施地區，劃設為什麼區？

    1. (A) 保護區
    2. (B) 禁止區
    3. (C) 管制區
    4. (D) 要塞區

    正解：(C)

  4. 4有關國家安全法對於海岸管制區的規定，下列何者正確？

    1. (A) 海岸管制區公告範圍是指海水高潮線以內之地區及近海沙洲
    2. (B) 是由國防部會同內政部根據海防實際需要而公告
    3. (C) 海岸特定管制區全天候均實施管制
    4. (D) 人民入出海岸管制區，應向海巡機關申請許可

    正解：(B)

  5. 5下列何者非海岸巡防機關？

    1. (A) 海洋委員會
    2. (B) 海洋委員會海巡署
    3. (C) 海洋委員會海洋保育署
    4. (D) 海洋委員會海巡署教育訓練測考中心

    2. (B) 內政部

    4. (D) 海洋委員會

  7. 7下列何項違法行為，海巡機關無法以主管機關身分對其裁罰？

    2. (B) 大陸船舶於我方限制水域內捕魚

    正解：(A)

  8. 8有關海洋委員會海巡署安檢人員的掌理事項及職權，下列何者正確？

    2. (B) 在新竹南寮漁港得依法實施安全檢查，包括查緝走私偷渡

  9. 9海巡機關為執行職務，得設置受理報案專線電話，民眾無故撥打海巡專線電話，經勸阻不聽或故意謊報案件者，可為何種處分？處：

    4. (D) 處新臺幣五十萬元以上五千萬元以下罰鍰

    正解：(B)

  39. 39在發生海洋污染事件時，各機關為能立即掌握及清除、處理海洋污染，須代為支出龐大應變清除及處理等費用，請問此費用名稱為何？

    1. (A) 海洋基金
    2. (B) 海洋資助基金
    3. (C) 海洋污染防治基金
    4. (D) 海洋潔淨清理基金

    正解：(C)

  40. 40利用海洋設施從事探採油礦、輸送油品達中央主管機關公告之規模者，依法應於每年何時向地方主管機關申報監測紀錄備查？

    1. (A) 一月、四月、七月、十月
    2. (B) 三月、六月、九月、十二月
    3. (C) 六月、十二月
    4. (D) 三月、九月

    正解：(A)

  41. 41依海洋污染防治法施行細則之規定，中央主管機關應就全國性海域水體，設置海域環境水質監測站，並於每年何時公布前一年之海域環境水質檢測資料？

    1. (A) 一月十五日前
    2. (B) 四月十五日前
    3. (C) 六月八日前
    4. (D) 九月十日前

    正解：(B)

  42. 42依海岸巡防機關器械使用條例規定，下列何者不是得使用「砲以外器械」的情形？

    1. (A) 對航行海域內之船舶或其他運輸工具，有事實足認其承載人員，有藉該次航行觸犯死刑、無期徒刑或最輕本刑三年以上有期徒刑之罪之虞，經命其停止航行、回航，而抗不遵照，為阻止其繼續行駛時
    2. (B) 航行海域內之船舶或其他運輸工具，其承載人員涉嫌在我國領域內觸犯內亂、外患、海盜、殺人或走私槍械、毒品之罪，經實施緊追、逮捕而抗不遵照或脫逃時
    3. (C) 所防衛之土地、建築物、工作物、車、船、航空器遭受危害時
    4. (D) 海巡機關人員之生命、身體、自由、裝備遭受危害或脅迫，或有事實足認為有受危害之虞時

    正解：(B)

  43. 43海巡機關人員執行職務，確認已無其他手段制止時，得於必要限度內用砲，請問何者為用砲下令權責長官？

    1. (A) 海洋委員會主任委員
    2. (B) 國防部部長
    3. (C) 內政部部長
    4. (D) 海洋委員會海巡署署長

    正解：(D)

  44. 44依海岸巡防機關器械使用條例規定，有關海洋委員會組成調查小組之敘述，下列何者正確？

    1. (A) 為求公正，有關調查的申請，僅能由海洋委員會依職權為之，所屬海巡機關無法申請
    2. (B) 調查小組得就使用時機、過程及相關司法責任，進行調查及提供意見
    3. (C) 調查小組得提供海巡機關使用器械之教育訓練及倫理促進等建議事項
    4. (D) 調查小組組織及運作方式，由海巡機關定之

    正解：(C)

  45. 45海巡機關人員依海岸巡防機關器械使用條例規定使用器械，致第三人生命或財產遭受損失時，第三人得請求補償，請問補償項目、基準、程序是由誰定之？

    1. (A) 行政院
    2. (B) 國防部
    3. (C) 海洋委員會
    4. (D) 海洋委員會海巡署

    正解：(C)

  46. 46大陸船舶未經許可進入臺灣地區限制或禁止水域，主管機關得逕行驅離或扣留其船舶，請問下列何者非屬應扣留之要件？

    1. (A) 驅離無效
    2. (B) 涉及走私
    3. (C) 從事非法漁業行為
    4. (D) 拒絕停船受檢

    正解：(D)

  47. 47海洋委員會海巡署巡防艇分別在馬袓南竿西南方 2 浬查獲 A 大陸船及在澎湖七美西南方 60 浬查獲B 大陸船違法抽砂，請問應依何法處罰該 2 艘大陸抽砂船？

    1. (A) 均依臺灣地區與大陸地區人民關係條例處罰
    2. (B) A 大陸船依土石採取法處罰、B 大陸船依中華民國專屬經濟海域及大陸礁層法處罰
    3. (C) A 大陸船依臺灣地區與大陸地區人民關係條例處罰、B 大陸船依中華民國專屬經濟海域及大陸礁層法處罰
    4. (D) 均依土石採取法處罰

    正解：(B)

  48. 48有關大陸抽砂船經確定遭沒收後之處置方式，下列何者錯誤？

    1. (A) 視個案情節需要拍賣或變賣
    2. (B) 專案報准廢棄
    3. (C) 專案報准由有需求之機關購買留供公用
    4. (D) 專案報准為其他適當之處置

    正解：(C)

  49. 49海洋委員會海巡署巡防艇在澎湖外海 6 浬處發現 1 艘大陸漁船越界捕魚且拒檢，經巡防艇強力扣留並帶返，有關後續處分請問下列敘述何者錯誤？

    1. (A) 得對船上人員裁處留置 3 個月以內之處分
    2. (B) 得裁處沒入漁具漁獲之處分
    3. (C) 得依噸位裁處罰鍰
    4. (D) 經調查係從事非法漁業行為，則應沒入該艘船舶

    正解：(A)

  50. 501 艘我國籍漁船於臺中外海疑似違規捕魚，經巡防艇 3 度廣播停船受檢，該船均拒絕檢查，請問下列處罰何者為宜？

    1. (A) 國家安全法有拒絕檢查之處罰規定且為刑事罰，基於先刑事後行政原則，應優先以國家安全法處罰
    2. (B) 海岸巡防法有拒絕檢查之處罰規定，因本案為海巡人員執法，故應優先以海岸巡防法處罰
    3. (C) 漁業法有拒絕檢查之處罰規定，因本案事涉違規捕魚，故應優先以漁業法處罰
    4. (D) 因上開三法均有拒絕檢查之處罰規定，故應擇一重處

    正解：(C)
