  1. 1關聯式資料庫（relational database）中有兩個表格為 students 和 takes，這兩個表格只共用屬性 id，當要用此屬性連接兩個表格時，只要取出兩個表格皆出現的資料列（tuple），則應該使用下列那個 SQL指令（根據 ISO 頒布的 SQL 標準語法）？

    1. (A) SELECT * FROM students NATURAL INNER JOIN takes;
    2. (B) SELECT * FROM students LEFT OUTER JOIN takes USING (id);
    3. (C) SELECT * FROM students RIGHT OUTER JOIN takes ON students.id = takes.id;
    4. (D) SELECT * FROM students NATURAL FULL OUTER JOIN takes;

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) NATURAL INNER JOIN 依同名屬性 id 自動比對，且只保留兩表皆有的配對列。

    ❌ (B) LEFT OUTER JOIN 會保留左表中無配對的列。

    ❌ (C) RIGHT OUTER JOIN 會保留右表中無配對的列。

    ❌ (D) FULL OUTER JOIN 兩側無配對的列都會保留。

    📚 出處：SQL 的連接運算。
