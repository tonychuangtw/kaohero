營養師　113 年第二次 團體膳食設計與管理　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1有關營利性和非營利性團膳的敘述，下列何者正確？

    1. (A) 營利性團膳之食材成本百分比較非營利性團膳高
    2. (B) 營利性團膳較常配合消費者喜好而改變菜單內容
    3. (C) 營利性團膳較非營利性團膳常使用循環菜單
    4. (D) 公立學校學童午餐屬於營利性團膳機構的一種

    正解：(B)

  2. 2幼兒園每日供應包含早點、午餐及午點，4～6歲兒童此三餐次之脂肪攝取總量不得超過多少公克？

    1. (A) 23
    2. (B) 27
    3. (C) 30
    4. (D) 33

    正解：(A)

  3. 3某醫院500位員工以自助餐的方式用餐，員工可從15道菜中任選3道菜，平均每道菜應設計多少人份？

    1. (A) 45
    2. (B) 75
    3. (C) 100
    4. (D) 225

    正解：(C)

  4. 4有關循環菜單之敘述，下列何者最不適當？

    1. (A) 依機構適合之天數設計循環菜單依序循環使用
    2. (B) 循環菜單使用多次可增加員工操作熟練度
    3. (C) 嚴格遵守循環週期內，應盡量避免連續2天相同菜餚
    4. (D) 若遇颱風或節慶時不須修正菜單

    正解：(D)

  5. 5有關2019年新版食物代換表內容，下列敘述何者正確？

    1. (A) 3份（Ex）蝦米為45公克
    2. (B) 雞蛋屬於低脂－豆魚蛋肉類
    3. (C) 2.5份（Ex）雞胸肉為87.5公克
    4. (D) 豬大腸屬於中脂－豆魚蛋肉類

    正解：(A)

  6. 6依教育部公告之「學校午餐食物內容及營養基準」，下列關於午餐設計應注意事項，何者正確？

    1. (A) 每日至少有2種以上蔬菜供應
    2. (B) 油炸品頻率1週不超過3次
    3. (C) 公告菜單只需呈現菜餚名稱
    4. (D) 應儘量避免提供甜品，供應頻率1週不超過2次

    正解：(A)

  7. 7有關食品包裝標示之敘述，下列何者正確？

    1. (A) 營養標示中的「糖」是指食品製造過程中額外添加之單醣和雙醣的總和
    2. (B) 大豆沙拉油依規定應標示含有致過敏性內容物警語
    3. (C) 使用基因改造食品原料若終產品已不含轉殖基因片段或轉殖蛋白質者得免全標示
    4. (D) 需經復水的產品若未有營養宣稱，則可用復水前或後為標示基準，並須註明其復水方式

    正解：(D)

  8. 8團膳業者選擇的食材供應商應落實三級品管制度，下列何者錯誤？

    1. (A) 對於供應食材皆須主動進行源頭管理並記錄
    2. (B) 自設檢驗室逐批檢驗食材屬於第一級品管制度
    3. (C) 團膳業者進行稽查抽驗屬於第三級品管制度
    4. (D) 將食材送交第三方驗證單位檢驗屬於二級品管制度

    正解：(C)

  9. 9若櫛瓜的生廢棄率為5%，收縮率為15%，1人份供應80公克，今要供應500人份，則最適採購量為多少台斤？

    1. (A) 43
    2. (B) 50
    3. (C) 72
    4. (D) 83

    正解：(D)

  10. 10下列何者不屬於驗收時使用之工具或檢測試劑？

    1. (A) 磅秤
    2. (B) 餘氯試劑
    3. (C) 雙氧試劑
    4. (D) 溫度計

    正解：(B)

  11. 11庫房管理設有「庫房管制卡」，下列何者不屬於此卡的紀錄項目？

    1. (A) 進／出貨日期
    2. (B) 結餘量
    3. (C) 撥發量
    4. (D) 保存期限

    正解：(D)

  12. 12下列何種蔬菜適合貯存於陰涼乾燥的地方？

    1. (A) 南瓜
    2. (B) 萵苣
    3. (C) 菠菜
    4. (D) 青豌豆

    正解：(A)

  13. 13製備1份綜合水果沙拉，內含可食之五爪蘋果50 g、香吉士32.5 g、紅西瓜45 g、泰國芭樂 56 g、葡萄乾5g、低脂原味優格70 g和乳酪絲6 g，這份沙拉含有幾份（Ex）水果和乳品類？

    1. (A) 水果1.5 Ex和乳品類0.33 Ex
    2. (B) 水果2.0 Ex和乳品類0.33 Ex
    3. (C) 水果1.5 Ex和乳品類0.5 Ex
    4. (D) 水果2.0 Ex和乳品類0.5 Ex

    正解：(C)

  14. 14為了提升油炸油的穩定與品質，有關調整油脂物化特性的方法，下列何者正確？

    1. (A) 提高食用油的酸價
    2. (B) 選擇已產生聚合作用的油脂
    3. (C) 選擇發煙點較高的油炸油較為安全
    4. (D) 添加乳化劑降低油脂黏度以增加炸油穩定性

    正解：(C)

  15. 15有關冷凍食品的特性和應用之敘述，下列何者錯誤？

    1. (A) 冷凍裹粉產品可在凍結狀態下直接下鍋油炸，但一次下鍋量不宜過多以免油溫驟降影響品質
    2. (B) 部分小體積的冷凍調理食品（例如湯圓等）可不需解凍直接加熱調理
    3. (C) 冷凍肉品的保存期限通常較冷藏肉品更長
    4. (D) 冷凍肉品如需緊急使用，可在包裝完整的情形下浸泡於流動之溫熱水中加速解凍

    正解：(D)

  16. 16有關豆製品之敘述，下列何者錯誤？

    1. (A) 盒裝豆腐可以直接冷藏
    2. (B) 同重量的百頁豆腐與板豆腐熱量相近
    3. (C) 隔天使用的板豆腐需冷藏
    4. (D) 豆干及干絲烹煮前先加以川燙以去除可能殘留的過氧化氫

    正解：(B)

  17. 17關於食物製備方法之敘述，下列何者錯誤？

    1. (A) 宮保是指在菜品中加入乾辣椒
    2. (B) 開陽白菜是指在白菜中加入乾蝦米
    3. (C) 魚香是指在菜品添加爆香的小魚乾
    4. (D) 回鍋肉是指將白煮豬肉再切片回鍋煸炒

    正解：(C)

  18. 18下列那一種魚肉的鐵質最高？

    1. (A) 鮪魚
    2. (B) 鱈魚
    3. (C) 旗魚
    4. (D) 鮭魚

  19. 19配膳熱食菜餚之保溫設備其溫度宜保持在：

    3. (C) 40°C～60°C
    4. (D) ≧60°C

  20. 20依食品安全管制系統準則規定之供膳單位應成立管制小組，下列敘述何者正確？

    1. (A) 管制小組人員至少應有2名，且負責人或其指定人員為必要之成員
    2. (B) 成員應曾接受中央主管機關認可之訓練機關（構）辦理之相關課程至少30小時，並領有合格證明書
    3. (C) 從業期間應持續接受與本系統有關之訓練，每3年累計至少8小時
    4. (D) 執行之工作應作成書面紀錄，連同相關文件彙整為檔案，妥善保存至少3年

    正解：(B)

  21. 21某便當工廠最近不良率增加，可用下列何種圖表來確認最大的影響因素？

    1. (A) 柏拉圖
    2. (B) 散布圖
    3. (C) 管制圖
    4. (D) 特性要因圖

    正解：(A)

  22. 22有關學校餐廳管理內容，下列敘述何者正確？

    1. (A) 學校辦理餐飲衛生業務只能由營養師擔任督導人員
    2. (B) 餐飲從業人員每學年應參加衛生講習至少16小時
    3. (C) 每週至少1次餐飲衛生自主檢查表紀錄，紀錄應留存3年
    4. (D) 每餐供應之餐食均須標示日期及餐別，冷藏10℃留存48小時

    正解：(C)

  23. 23團膳公司在每餐製備完成的成品中，抽存乙份貯留備檢，應放置保存於下列何種狀況？

    2. (B) 冷藏2天
    3. (C) 冷凍1天
    4. (D) 冷凍2天

  24. 24有關細菌性食品中毒，下列敘述何者錯誤？

    1. (A) 生鮮魚貝類易遭腸炎弧菌污染，只要經60℃以上並加熱15～20分鐘即可殺死腸炎弧菌
    2. (B) 製備人員手部有傷口膿瘡直接處理食物，易致金黃色葡萄球菌感染
    3. (C) 米飯於室溫下長期不當貯存，最容易導致沙門氏菌污染中毒
    4. (D) 真空包裝調味豆乾因殺菌不完全，易致肉毒桿菌中毒

    正解：(C)

  25. 25有關HACCP的危害因子，下列敘述何者正確？

    1. (A) 抗生素殘留是物理性因子
    2. (B) 炸油酸價過高是物理性因子
    3. (C) 蔬菜裡面有沙子是化學性因子
    4. (D) 烤雞肉中心溫度不足是生物性因子

    正解：(D)

  26. 26若每人每餐以0.3平方公尺（m2）來估算，試問欲設計供應300人份的廚房，下列何者為最適宜的廚房面積？（1m2 = 0.3025坪）

  27. 27廚房設計規劃中烹煮設備的排列方式與說明，下列敘述何者錯誤？

    1. (A) 廚房主要設備靠牆排成一直線為直線型排列
    2. (B) 於空間較小或不宜採直線排列的廚房可選擇 L形排列
    3. (C) 背對背排列適用於小型廚房，又稱島嶼式排列
    4. (D) 平行排列指廚房主要烹煮設備及工作檯橫置於廚房中間，兩工作檯中無通道

    正解：(D)

  28. 28有關管理員工績效策略，下列敘述何者錯誤？

    1. (A) 工作動機與能力均強者，則給予工作表現機會及適當獎勵
    2. (B) 工作動機與能力均弱者，則給予直接降級、甚至資遣解僱
    3. (C) 工作動機強但能力不足者，則給予訓練、任務指派協助其發展
    4. (D) 工作能力強但動機弱者，則給予直接回饋與獎酬、參與團隊工作

    正解：(B)

  29. 29關於勞工工作時間分配，依勞動基準法規定，下列敘述何者正確？

    1. (A) 雇主應置備勞工出勤紀錄（應逐日記載），並保存3年
    2. (B) 每日正常工作時間為12小時，每週工作總時數不得超過48小時
    3. (C) 針對無工會之事業單位，經勞資會議同意後，得將8週內之正常工作時數加以分配
    4. (D) 雇主得視勞工照顧家庭成員需要，允許勞工彈性調整工作開始及終止之時間在2小時範圍內

    正解：(C)

  30. 30自助餐廳去年1年的損益表顯示，總營業額500萬元，固定費用占35%，利潤為125萬元，此餐廳損益平衡點的營業額與下列何者最接近？
