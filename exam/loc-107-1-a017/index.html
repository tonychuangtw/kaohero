  1. 1下列那一組值會使矩陣 M = ⎢⎢a 0 3⎥⎥ 為“歪斜對稱”（skew-symmetric）矩陣？⎢⎣b c 0⎥⎦

    1. (A) a = 1, b = 2, c = 3
    2. (B) a = 1, b = -2, c =- 3
    3. (C) a = -1, b = -2, c = -3
    4. (D) a = -1, b = 2, c = -3

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 歪斜對稱要求 Mᵀ = −M，即對角線為 0 且 M_ij = −M_ji；依矩陣上三角元素 1、2、3 可得 a = −1、b = −2、c = −3。

    ❌ (A) 三個值的正負號全與對稱位置相同，不符定義。

    ❌ (B) b、c 的符號雖對，a 的符號有誤。

    ❌ (D) b 的符號有誤。

    📚 出處：歪斜對稱（skew-symmetric）矩陣的定義。

  2. 2微分方程式(2xy3-3y)dx-(3x-3x2y2+6y)dy = 0 其解為何？（選項中 k 為任意常數）

    1. (A) x2y3+3xy+3x2 = k
    2. (B) x2y3-3xy+3y2 = k
    3. (C) x2y3-3xy-3y2 = k
    4. (D) x2y3+3xy-3x2 = k⎡1 − 2 3 ⎤

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 令 F = x²y³ − 3xy − 3y²，則 ∂F/∂x = 2xy³ − 3y、∂F/∂y = 3x²y² − 3x − 6y = −(3x − 3x²y² + 6y)，與原式完全相符。

    ❌ (A) 對 y 偏微後不含 −6y 項。

    ❌ (B) 對 x 偏微後的符號與原式不合。

    ❌ (D) 對 y 偏微的結果與原式不符。

    📚 出處：正合微分方程式。
