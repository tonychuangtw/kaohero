初等考試　111 年 初等考試 行政學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1行政學的研究，若以實證典範為基礎，下列何者錯誤？

    1. (A) 重視客觀性
    2. (B) 重視解釋和預測的作用
    3. (C) 強調規範的層面
    4. (D) 強調行為的觀察

    正解：(C)

  2. 2關於巴納德（C. Barnard）對於溝通的看法，下列何者錯誤？

    1. (A) 應善用社群媒體以擴大溝通效果
    2. (B) 溝通管道應廣為人知
    3. (C) 溝通路線應盡量直接而簡短
    4. (D) 兼顧正式與非正式的溝通管道

    正解：(A)

  3. 3關於新公共管理（New Public Management）運動的描述，下列何者錯誤？

    1. (A) 《新政府運動》（Reinventing Government）一書被視為是觸發新公共管理運動的代表作
    2. (B) 提倡企業型政府的概念
    3. (C) 主張政府扮演操槳者的角色
    4. (D) 推崇顧客導向的政府

    正解：(C)

  4. 4如果你是支持「權變理論（contingency theory）」的學者，你會認同下列那一項敘述？

    1. (A) 管理組織的方法存在一套最佳解方
    2. (B) 組織為一個由封閉到開放的連續體
    3. (C) 重視組織的穩定單一性
    4. (D) 鼓勵為達目的不擇手段

    正解：(B)

  5. 5學者韋伯（M. Weber）認為，官僚制度的正當合理性（legitimacy），主要是來自於那一種權威（authority）？

    1. (A) 傳統權威
    2. (B) 合法合理權威
    3. (C) 超人權威
    4. (D) 情勢權威

    正解：(B)

  6. 6依據賽蒙（H. Simon）的理論，組織成員在做決策時，很難獲得最佳選擇，常只能追求滿意的決策，其主因為何？

    1. (A) 決策者的自私自利
    2. (B) 決策者的有限理性
    3. (C) 組織的溝通不良
    4. (D) 組織的保守文化

    正解：(B)

  7. 7依據系統理論之觀點，開放系統能永續發展是因為具有下列何種作用？

    1. (A) 反熵作用（negative entropy）
    2. (B) 霍桑效應作用（Hawthorne effect）
    3. (C) 非正式組織作用（informal organization）
    4. (D) 激勵作用（motivation）

    正解：(A)

  8. 8有關全球化對公共行政之影響，下列敘述何者錯誤？

    1. (A) 引進治理的概念
    2. (B) 重視公民參與
    3. (C) 公私協力日顯重要
    4. (D) 強化科層體制的正當性

    正解：(D)

  9. 9下列那一項行為最有可能違反公務員廉政倫理規範？

    1. (A) 教育局督學到國小視察，校長恰為其大學同學。校長為表達感謝及敘舊，作東邀請督學和學校其他主管到校外餐廳聚餐並暢飲一番
    2. (B) 住院病人家屬為感謝某公立醫院內科病房全體醫護人員之辛勞，於中秋節贈送市價約 800 元文旦一箱，由內科部主任代表同仁收受
    3. (C) 某市政府科長喜獲麟兒，其直屬長官為表賀忱及感謝其平日工作辛勞，贈與一只金鎖片祝福平安富貴
    4. (D) 年節將近，印刷廠老闆送一本月曆給與其平常有業務往來的某區公所課長，並強調該月曆很熱門搶手，而課長欣然接受

    正解：(A)

  10. 10為確保公務人員行政中立，公務人員在推動各項政策時，應遵循下列何種原則？

    3. (C) 公共選擇原則
    4. (D) 依法行政原則

    正解：(D)

    正解：(D)

  12. 12為原住民舉辦特考，藉其服公職的過程來強化政府對原住民的回應力，這是下列何種行政責任之確保途徑？

  15. 15下列何者為矩陣組織的優點？
