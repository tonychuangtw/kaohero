職能治療師　107 年第二次 小兒職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列關於早產兒張力發展的敘述，何者錯誤？

    1. (A) 受孕後年齡（postconceptional age）太小的早產兒易呈現低張力
    2. (B) 在足月前，早產兒張力的發展方向為由尾到頭（caudocephalic），由遠端到近端（distal to proximal）
    3. (C) 極度早產兒達足月年齡時，會與一般足月新生兒一樣，出現明顯的生理性屈曲張力
    4. (D) 睡眠狀態和生病都可能造成早產兒的低張力

    正解：(C)

  2. 2早產兒小文喝奶時，常出現血氧飽和度低於80％的情況。下列何項處置最適用在解決小文的喝奶問題？

    2. (B) 選擇質地較軟的奶嘴進行餵奶
    3. (C) 喝奶時提供下頷和臉頰支持
    4. (D) 喝奶時使用外在節律控制法（external pacing）

    正解：(D)

  3. 3有關震動刺激（vibration）的敘述，下列何者錯誤？

    1. (A) 屬於深壓（deep pressure）的一種型態
    2. (B) 由本體接受器（proprioceptors）來接收震動刺激的訊息
    3. (C) 有些個案不知道或無法表示他們已接受足夠的震動刺激
    4. (D) 震動刺激並無傷害性，個案可長時間持續使用

    正解：(D)

  4. 4驗證參考架構的效能（efficacy）時，下列敘述何者錯誤？

    1. (A) 可利用基礎科學形式之研究（basic scientific inquiry）探討驗證
    2. (B) 可利用應用型之研究（applied research）探討驗證
    3. (C) 可驗證整個參考架構的效能，如參考架構的信度（reliability）、應用性（applicability）與特定性（specificity）
    4. (D) 可驗證參考架構中組成要素的效能，如評估的部分是否能正確地找到問題或治療介入的成效是否符合理論假設

    正解：(A)

  5. 5有關長期處於Marcia所提的各種「認同狀態（identity state）」中所可能產生的不良後果，下列敘述何者正確？
