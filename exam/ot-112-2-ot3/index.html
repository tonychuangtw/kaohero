  19. 19一般而言，痙攣（spasticity）與高張（hypertonus）這兩種不正常的肌肉張力，最主要的不同點為何？

    1. (A) 前者通常會伴隨協同動作模式（synergy pattern）的出現，後者則無
    2. (B) 前者指的是主動肌與拮抗肌的張力同時增加，後者指的是主動肌張力增加與拮抗肌的張力減少
    3. (C) 前者主要是因為前運動皮質（premotor cortex）受損所產生，後者主要是因為錐體系統（pyramidal system）受損所導致
    4. (D) 前者的發生通常有彈簧刀現象（clasp-knife phenomenon），後者則無此現象

    正解：(D)

  20. 20有關肌肉張力的評估，下列敘述何者正確？

    2. (B) 測量上肢張力時，並沒有要求個案須保持特定姿勢，只要能方便治療師抓握欲量測的肢體即可
    3. (C) 為了提高評估結果的信度，建議在前後測時應選擇同一時間測量，如：同在早上施測
    4. (D) 測量個案痙攣（spasticity）時，治療師應在關節活動度的範圍內，以慢速移動個案的肢體，避免個案受傷

    正解：(C)

    3. (C) 後天免疫不全症候群（AIDS）
    4. (D) 吉蘭巴瑞症候群（Guillain-Barré syndrome）

    正解：(D)

  79. 79關於截肢患者以彈性繃帶塑形的敘述，下列何者錯誤？

    1. (A) 主要以螺旋環狀包紮為主
    2. (B) 壓力要由遠端向近端漸降
    3. (C) 8字型包紮法每層繃帶要重疊覆蓋約1/3到1/2繃帶寬
    4. (D) 極短肘下截肢者要包到肘關節以上

    正解：(A)

  80. 80針對手部燒燙傷之患者，下列各時期手部固定副木（resting hand splint）之穿戴時程表或擺位何者正確？

    1. (A) 在急性期為避免阻礙組織之修復，建議一日穿戴時間不超過3次，每次時間不超過40分鐘
    2. (B) 在植皮期應讓患者的手部固定在一舒服不受力之姿勢，以避免植皮皮膚受牽扯而使植皮失敗
    3. (C) 在植皮期患者應全日穿戴副木3～10日，將依外科醫師植皮方式特殊考量決定穿戴時間
    4. (D) 在復健期，建議日間活動時穿戴副木，而夜間休息時則應限制副木之使用

    正解：(C)
