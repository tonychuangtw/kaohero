初等考試　113 年 初等考試 財政學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1關於國家有機體論的敘述，下列何者正確？

    1. (A) 政府是個人達成目的之工具
    2. (B) 個人目的凌駕社會目的
    3. (C) 社會目的凌駕個人目的
    4. (D) 一項抉擇是否有利於個人，不須社會判定，而以個人的自利動機判定

    正解：(C)

  2. 2關於完全競爭市場的敘述，下列何者正確？

    1. (A) 個別廠商有定價的能力
    2. (B) 課徵商品的從量稅不會造成效率的損失
    3. (C) 個別廠商的最適生產決策為邊際收入等於邊際成本
    4. (D) 個別廠商對商品的定價大於邊際收入

    正解：(C)

  3. 3政府適時介入矯正市場失靈，屬於何種政府財政功能？

    1. (A) 利他功能
    2. (B) 配置功能
    3. (C) 保險功能
    4. (D) 排他功能

    正解：(B)

  4. 4私人自願提供公共財的數量，通常較社會最適的數量為：

    1. (A) 高
    2. (B) 低
    3. (C) 相同
    4. (D) 無法判斷

    正解：(B)

  5. 5存在市場失靈情況且決策受其限制下，追求社會福利極大化的公營事業，其訂價法為下列何者？

    2. (B) 平均成本訂價法
    3. (C) 次佳理論訂價法
    4. (D) 最大利潤訂價法

    正解：(C)

  6. 6中央政府的支出規模較地方政府更具顯著擴張的情形，稱為：

    1. (A) 集中效果
    2. (B) 位移效果
    3. (C) 檢查效果
    4. (D) 擴大效果

    正解：(A)

  7. 7財政部之財政統計年報，將公共支出依政事別區分為：

    2. (B) 移轉性與非移轉性兩種
    3. (C) 一般政務、國防、教育科學文化、經濟發展、社會福利、社區發展與環境保護、退休撫卹、債務、其他，共9種
    4. (D) 社會福利、經濟發展、耗源性與非耗源性等 4 種

    正解：(C)

  8. 8公共財之財源由全民負擔，個人享受公共財時感覺負擔較輕，進而要求政府多提供公共財，而造成公共支出水準上升，此為：

    2. (B) 恩格爾法則
    3. (C) 華格納法則

  10. 10關於政府對其提供之財貨或勞務採「兩部定價法」的敘述，下列何者錯誤？

    2. (B) ③④
    3. (C) ②③
    4. (D) ①④

  17. 17下列何者是造成公共財會有坐享其成（free riding）問題的主要原因？
