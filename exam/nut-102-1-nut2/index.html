營養師　102 年第一次 營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列有關激素對醣類代謝調節的敘述，何者錯誤？

    1. (A) Insulin 促進肝醣合成
    2. (B) Thyroxine 促進腸道對葡萄糖的吸收
    3. (C) Glucocorticoid 降低組織對葡萄糖的利用
    4. (D) Glucagon 促進肝醣合成

    正解：(D)

  2. 2下列有關可溶性（soluble）膳食纖維的敘述，何者正確？

    1. (A) 寒天中的洋菜膠（agarose）不屬之
    2. (B) 可以增加血膽固醇濃度
    3. (C) 可以促進食物由胃排空的速度
    4. (D) 可以減少腸道葡萄糖的吸收頁次：4－2

    正解：(D)

  3. 3醣類完全氧化可產生：

    1. (A) carbon, nitrogen and hydrogen
    2. (B) water, carbon dioxide and energy
    3. (C) water and urea
    4. (D) ammonia and water

    正解：(B)

  4. 4下列有關 glucose 在人體之代謝的敘述，何者錯誤？

    1. (A) glucose 在肝臟及肌肉中可合成為 glycogen
    2. (B) glucose在red blood cell中可經citric acid cycle代謝為CO2
    3. (C) glucose 進入 adipocyte 需受 insulin 之促進
    4. (D) glucose 經 glycolysis 可代謝為 pyruvate

    正解：(B)

  5. 5下列有關胺基酸的敘述，何者錯誤？

    1. (A) 豆類的限制胺基酸為離胺酸（lysine）
    2. (B) 穀類的限制胺基酸為離胺酸
    3. (C) 穀類與豆類混合的飲食可提供各類胺基酸
    4. (D) 芝麻、黃豆及小麥混合的飲食可提供各類胺基酸

    正解：(A)

  6. 6下列有關飲食蛋白質消化吸收的敘述，何者正確？

    1. (A) 必須將蛋白質完全分解為胺基酸才能被小腸絨毛吸收
    2. (B) 以被動擴散的方式與葡萄糖共同被吸收
    3. (C) 脂肪族胺基酸與芳香族胺基酸被吸收後由乳糜管回到肝臟
    4. (D) 所需之消化酵素來自胃、胰臟、小腸細胞

    正解：(D)

  7. 7下列有關長期攝取高蛋白飲食（高於總熱量的 35%）之敘述，何者錯誤？

    1. (A) 必須攝取較多的維生素B6、鋅、鐵等營養素 B
    2. (B) 可能會因此而攝取較多的飽和脂肪、膽固醇
    3. (C) 動物性蛋白質中的胺基酸增加鈣自尿液流失
    4. (D) 葉酸、鎂、膳食纖維攝取量充足

    正解：(D)

  8. 8下列有關服用單一胺基酸補充劑之敘述，何者正確？

    1. (A) 會擾亂小腸胺基酸吸收的機制，造成胺基酸的不平衡
    2. (B) 如為必需胺基酸，會很快被人體吸收利用，併入體蛋白
    3. (C) 如為非必需胺基酸，氮會很快由腎臟排除，不會造成腎臟毒害
    4. (D) 運動員可因此而增加肌肉質量

    正解：(A)

  9. 9早期因嬰兒奶粉配方組成不佳，僅含低量必需脂肪酸，餵食嬰兒後，造成皮膚乾燥脫屑，添加下列何種脂肪酸後獲得改善？

    1. (A) 亞麻油酸（linoleic acid）
    2. (B) 棕櫚酸（palmitic acid）
    3. (C) 硬脂酸（stearic acid）
    4. (D) 油酸（oleic acid）

    正解：(A)

  10. 10何種脂肪酸在乳脂肪（Dairy fats）中含量較多？

    1. (A) 短鏈
    2. (B) 中鏈
    3. (C) 長鏈
    4. (D) 反式

    正解：(A)

  11. 11下列有關膽固醇的敘述，何者錯誤？

    1. (A) 可經陽光照射，在皮膚上形成維生素 D
    2. (B) 主要運輸型態為游離膽固醇
    3. (C) 可於肝臟代謝成膽酸
    4. (D) 可轉換成性激素

    正解：(B)

  12. 12脂肪到達小腸會分泌何種激素刺激膽囊釋出膽汁及胰臟分泌脂肪酶？

    1. (A) Cortisol
    2. (B) Cholecystokinin
    3. (C) Testosterone
    4. (D) Glucagon頁次：4－3

    正解：(B)

  13. 13建議攝取量（recommended dietary allowance, RDA）是表示：

    1. (A) 滿足特定年齡層或性別的健康人群中之 50%人口的營養素攝取量之平均值
    2. (B) 因資料不足，對某特定年齡層大約可以使所有人維持一定的營養狀態
    3. (C) 滿足某一年齡層或性別的健康人群中之 97～98%人的一天營養素攝取量
    4. (D) 對大多數健康者，每日營養素的最大可攝取量

    正解：(C)

  14. 14下列有關褐色脂肪組織的敘述，何者正確？

    1. (A) 於粒線體中進行氧化磷酸化作用
    2. (B) 在體內的含量與白色脂肪組織一樣多
    3. (C) 細胞數目會隨著成長而增加
    4. (D) 只產熱，不產生 ATP

    正解：(D)

  15. 15若要降低呼吸商則應增加何種營養素之攝取？

    1. (A) 脂肪
    2. (B) 醣類
    3. (C) 蛋白質
    4. (D) 維生素

    正解：(A)

  16. 16已知一碗榨菜肉絲麵含有醣類、脂質及蛋白質，各為 70、20 及 10 公克，其可提供的熱量約為：

    1. (A) 750 kJ
    2. (B) 1100 kJ
    3. (C) 1600 kJ
    4. (D) 2100 kJ

    正解：(D)

  17. 17下列那三種維生素可顯著降低高同半胱胺酸血症患者的血漿同半胱胺酸濃度？

    1. (A) 葉酸、維生素B12、維生素B6 B B
    2. (B) 葉酸、維生素A、維生素B6 B
    3. (C) 生物素、維生素B12、維生素C B
    4. (D) 維生素E、維生素D、維生素B6 B

    正解：(A)

  18. 18惡性貧血的病人通常是缺乏下列何者而導致維生素吸收不良？

    1. (A) 維生素 C
    2. (B) R protein
    3. (C) intrinsic factor
    4. (D) 膽汁分泌

    正解：(C)

  19. 19下列何者在臨床上，有降低 LDL 膽固醇的作用？

    1. (A) Thiamin
    2. (B) Niacin
    3. (C) Riboflavin
    4. (D) Biotin

    正解：(B)

  20. 20下列何者可生成 1 mg 之菸鹼素？

    1. (A) 6 mg 酪胺酸
    2. (B) 60 mg 酪胺酸
    3. (C) 6 mg 色胺酸
    4. (D) 60 mg 色胺酸

    正解：(D)

  21. 21下列何組蔬果類可為維生素 A 之良好來源？

    1. (A) 菠菜、番茄、紅心蕃薯
    2. (B) 蘿蔔、冬瓜、芭樂
    3. (C) 蘋果、草莓、鳳梨
    4. (D) 高麗菜、竹筍、黃瓜

    正解：(A)

  22. 22下列何種營養素過量與造成鈣沈積在軟組織有關？

    1. (A) 維生素 K
    2. (B) 維生素 D
    3. (C) 維生素 A
    4. (D) 維生素 E

    正解：(B)

  23. 23下列那一種型式的維生素 E 具有最強的生理活性？

    1. (A) alpha-tocopherol
    2. (B) delta-tocotrienol
    3. (C) beta-tocopherol
    4. (D) alpha-tocotrienol

    正解：(A)

  24. 24新生兒因腸道無菌之故，通常補充的營養素為何？

    1. (A) 鐵
    2. (B) 碘
    3. (C) 維生素 D
    4. (D) 維生素 K

    正解：(D)

  25. 25下列何者具有調控基因表現之作用，進而維持上皮細胞正常分化？

    1. (A) 維生素 A
    2. (B) 維生素 E
    3. (C) 維生素 K
    4. (D) 維生素 C

    正解：(A)

  26. 26存在於骨骼中最主要的礦物質為：

    1. (A) calcium, magnesium
    2. (B) sodium, magnesium
    3. (C) calcium, zinc
    4. (D) phosphorus, calcium

    正解：(D)

  27. 27當吃了高鹽飲食後，體內將如何調節以維持血鈉於正常濃度？

    1. (A) 腎臟降低對鈉的再吸收
    2. (B) 小腸降低鈉吸收
    3. (C) 小腸促進鈉吸收
    4. (D) 促進抗利尿激素分泌頁次：4－4

    正解：(A)

  28. 28下列有關影響飲食中鈣質吸收的敘述，何者錯誤？

    1. (A) 飲食中磷含量過高
    2. (B) 飲食中含高量核酸
    3. (C) 飲食中含高量植酸
    4. (D) 飲食中含高量草酸

    正解：(B)

  29. 29所謂 DASH 飲食需要特別控制下列何者之攝取量？

    1. (A) Calcium
    2. (B) Magnesium
    3. (C) Potassium
    4. (D) Sodium

    正解：(D)

  30. 30下列何種礦物質與葡萄糖耐受性不良有關？

    1. (A) Chromium
    2. (B) Cobalt
    3. (C) Copper
    4. (D) Manganese

    正解：(A)

  31. 31婦女及幼兒為貧血的高危險群，若長期服用高量的鐵補充劑，可能會造成何種不良影響？

    1. (A) 大量鐵堆積於真皮層而使皮膚黝黑
    2. (B) 降低 LDL 之產生
    3. (C) 血鐵蛋白被大量消耗因而不足
    4. (D) 大量氧化血漿中的高密度脂蛋白

    正解：(D)

  32. 32下列有關碘缺乏之敘述，何者錯誤？

    1. (A) 藉每日 50 微克之補充，可以逐漸改善碘缺乏症狀
    2. (B) 甲狀腺腫大是碘缺乏時甲狀腺的適應性增生反應
    3. (C) 孕婦缺乏碘可能影響胎兒的生長與心智發展
    4. (D) 缺碘孕婦所生之嬰兒的生長與心智發展不足現象稱為呆小症

    正解：(A)

  33. 33下列有關食物中非血基質鐵的消化吸收之敘述，何者正確？

    1. (A) 胃酸會幫助鐵離子還原為亞鐵離子，促進其於小腸吸收
    2. (B) 含銅蛋白藍胞漿素會將鐵離子還原為亞鐵離子，促進與運鐵蛋白之結合
    3. (C) 茶與咖啡中之多酚可結合鐵，促進其吸收
    4. (D) 小腸吸收的鈣會與運鐵蛋白結合而阻礙鐵的吸收

    正解：(A)

  34. 34下列有關母乳與牛乳的成分比較，何項成分母乳較高？①乳糖 ②乳清蛋白 ③亞麻油酸 ④鈣

    1. (A) ①②
    2. (B) ③④
    3. (C) ①②③
    4. (D) ①②③④

    正解：(C)

  35. 35下列有關兒童喜愛的西式快餐，例如漢堡特餐（包括牛肉漢堡、薯條、可樂等）的敘述，何者正確？

    1. (A) 營養素含量均衡，適合兒童之攝取
    2. (B) 纖維質含量足夠，適合兒童之攝取
    3. (C) 鈣磷比值大於 2，鈣質吸收良好
    4. (D) 鈣磷比值低於 1，不利於鈣質的吸收

    正解：(D)

  36. 36與成年期比較，老年期需增加下列何種營養素之攝取？

    1. (A) Vitamin B6
    2. (B) Vitamin C
    3. (C) Vitamin E
    4. (D) Calcium

    正解：(A)

  37. 37下列何種營養素不需因熱量需求的增加，而相對增加其需要量？

    1. (A) Thiamin
    2. (B) Riboflavin
    3. (C) Pyridoxine
    4. (D) Niacin

    正解：(C)

  38. 38運動時，何者是決定以脂質作為主要能量來源的主要因素？

    1. (A) 運動強度與持續時間
    2. (B) 飲食的成分
    3. (C) 體內能量的儲存量
    4. (D) 運動種類

    正解：(A)

  39. 39青春期女性運動選手最容易缺乏的營養素為：

    1. (A) 脂質、維生素 C
    2. (B) 鈣質、鐵質
    3. (C) 鈣質、蛋白質
    4. (D) 鐵質、蛋白質

    正解：(B)

  40. 40大蒜含有下列何種植物化學成分，具有免疫調節、降血脂、降血糖、降血壓及抗癌等保健效能？

    1. (A) Indoles
    2. (B) Catechins
    3. (C) Organosulphides
    4. (D) Saponins

    正解：(C)
