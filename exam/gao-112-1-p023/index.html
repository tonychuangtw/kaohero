  1. 1在設計管線式（pipeline）處理器時，需搭配各式軟硬體的設計機制，以減少管線因 data hazard 損失的運算效能。下列優化運算效能的技術，何者不能於編譯器（compiler）上實施？

    1. (A) Data forwarding
    2. (B) Instruction scheduling
    3. (C) Register renaming
    4. (D) Software pipelining

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 資料前饋（data forwarding）是把執行結果直接送回前一級管線的硬體旁路電路，屬處理器資料路徑的設計，編譯器無從實施。

    ❌ (B) 指令排程由編譯器重排指令順序以避開相依，屬編譯期技術。

    ❌ (C) 暫存器重新命名可在編譯期分配不同暫存器以消除假相依。

    ❌ (D) 軟體管線化由編譯器重組迴圈，屬編譯期最佳化。

    📚 出處：計算機組織—管線危障與資料前饋。

  2. 2將時間切割成很多小片段，讓 CPU 不停地在許多程序（Process）之間切換執行，每位使用者以為自己的程序一直持續在執行，這種作業系統稱為：

    1. (A) 多元（Multi-programming）系統
    2. (B) 分時（Time-sharing）系統
    3. (C) 多執行緒（Multi-thread）系統
    4. (D) 即時（Real-time）系統

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 將 CPU 時間切成時間片輪流分配給各程序，使每位使用者感覺程式持續執行，即分時系統。

    ❌ (A) 多元程式規劃著重記憶體中同時載入多個程式以提高 CPU 使用率，未必以時間片輪轉。

    ❌ (C) 多執行緒是單一程序內的並行執行單位，非作業系統的分類。

    ❌ (D) 即時系統以在期限內完成工作為目標。

    📚 出處：作業系統—系統類型與 CPU 排程。

  3. 3在記憶體階層架構裡，下列敘述何者錯誤？

    1. (A) 主記憶體通常使用隨機存取記憶體（RAM）
    2. (B) CPU 裡面的暫存器（Registers）存取速度最快
    3. (C) 硬碟屬於輔助記憶體
    4. (D) 在 CPU 與主記憶體之間可以使用快閃記憶體（Flash memory）來提昇系統的效能

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 錯誤：CPU 與主記憶體之間使用的是速度更快的 SRAM 快取記憶體；快閃記憶體屬非揮發性儲存，速度遠慢於 DRAM，置於此處反而降低效能。

    ❌ (A) 正確：主記憶體使用 DRAM 等隨機存取記憶體。

    ❌ (B) 正確：暫存器位於階層最頂端，存取最快。

    ❌ (C) 正確：硬碟屬輔助（次級）記憶體。

    📚 出處：計算機組織—記憶體階層。
