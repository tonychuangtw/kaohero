職能治療師　107 年第一次 心理障礙職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1某憂鬱症患者表示，在參加完團體治療後，覺得在團體中就某方面來說，好像重新體驗和了解所成長的家庭生活，請問該團體是發揮了那一個療效因子？

    1. (A) 家庭重現（corrective recapitulation of the primary family group）
    2. (B) 存在性因子（existential factors）
    3. (C) 傳達資訊（imparting information）
    4. (D) 人際學習（interpersonal learning）

    正解：(A)

  2. 2在DSM-5（精神疾病診斷準則手冊第五版）中關於第一型雙相情緒障礙症（bipolar I disorder）的鬱症發作（major depressive episode）的描述，下列那一項行為，較不可能屬於鬱症發作？

    1. (A) 整天無精打采
    2. (B) 專注力降低
    3. (C) 自尊膨脹或誇大
    4. (D) 食慾增加

    正解：(C)

  3. 3根據DSM-5（精神疾病診斷準則手冊第五版），鬱症（major depressive disorder）的診斷，至少要有準則A中所列的症狀五項以上，而且，這些症狀必須同時出現至少多少時間？

    1. (A) 兩週
    2. (B) 一個月
    3. (C) 六週
    4. (D) 兩個月

    正解：(A)

  4. 4根據研究調查，下列四種診斷中，何種診斷族群最不常與其他三種疾患同時發生？

    1. (A) 自閉症類群障礙症（autism spectrum disorder）
    2. (B) 對立反抗症（oppositional defiant disorder）
    3. (C) 注意力不足／過動症（attention-deficit/hyperactivity disorder）
    4. (D) 行為規範障礙症（conduct disorder）

    正解：(A)

  5. 5有關DSM-5之修訂目標，下列敘述何者正確？①以類別（categorical）診斷為主 ②以向度（dimensional）診斷為主 ③增加診斷之效度 ④將研究結果整合

    1. (A) ①③④
    2. (B) ②③④
    3. (C) 僅②③
    4. (D) 僅①④

    正解：(B)

  6. 6關於DSM-IV到DSM-5變革中提到的向度（dimensional）及類別（categorical）診斷，下列何者正確？

    1. (A) 向度診斷方式提出12個科學性驗證標準（validators）以供現行的類別中增加新的相關疾病類別
    2. (B) 使用向度診斷方式衍生出很多未分類（NOS）之診斷
    3. (C) 使用類別診斷方式導致共病診斷變少
    4. (D) 用類別診斷之方式衍生出很多定義太狹窄之診斷

    正解：(D)

  7. 7關於DSM-5中對於五軸診斷的修改，何者正確？

    1. (A) DSM-5中改為一到三軸診斷
    2. (B) 將兒童或青少年時期的診斷與成人精神診斷分為不同軸向
    3. (C) 建議參考世界衛生組織失能評估表（WHO Disability Assessment Schedule, WHODAS）作為失能狀況的整體評量
    4. (D) 移除彼此沒有相關性的一到三軸（心理疾病、行為及一般生理狀況診斷）

    正解：(C)

  8. 8根據DSM-5（精神疾病診斷準則手冊第五版），下列關於智能不足（intellectual disabilities）診斷標準的描述，何者錯誤？

    1. (A) 嚴重程度的診斷是根據概念（concept domain）、社會（social domain）及實務（practical domain）這三個領域在智力與適應功能上的缺損程度
    2. (B) 智力功能的缺損可能包含推理（reasoning）、問題解決（problem solving）、抽象思考（abstractthinking）等
    3. (C) 智力與適應功能缺損的發生（onset），可能在生命中的任何時期
    4. (D) 智力功能的缺損須經由臨床評估及標準化的測驗確認

    正解：(C)

  9. 9根據DSM-5的診斷準則中，下列各種精神症狀的呈現，何項無法符合思覺失調症（schizophrenia）的診斷標準？

    1. (A) 妄想、僵直行為（catatonic behavior）
    2. (B) 幻覺、胡言亂語
    3. (C) 負性症狀、行為混亂
    4. (D) 胡言亂語、僵直行為（catatonic behavior）

    正解：(C)

  10. 10關於思覺失調症個案之幻覺（hallucinations）症狀描述，下列何者錯誤？

    1. (A) 幻覺是思覺失調症個案最常見的知覺障礙，特別發生在疾病的急性期
    2. (B) 個案經歷的幻覺經驗不影響其現實認知
    3. (C) 個案出現負性症狀、認知障礙及較無法處理外在環境的刺激等，會降低其處理幻覺的能力而造成較多的失能
    4. (D) 明顯或較為頻繁的幻覺不能代表疾病的嚴重性

    正解：(B)

  15. 15下列對於行為治療與認知行為治療的敘述何者正確？①行為治療重視以增強物為策略來改變行為 ②認知行為治療重視以增強物為策略來改變行為 ③行為治療主要是要改變造成某種行為的信念 ④認知行為治療主要是要改變造成某種行為的信念 ⑤行為治療以發展情緒覺察的知識基礎為主 ⑥認知行為治療以發展問題解決的知識基礎為主

  18. 18有關班杜拉（Bandura）的社會學習理論，下列敘述何者錯誤？

    2. (B) 如果個案能夠觀察模仿對象的每個步驟並練習到完成，便能增進自我效能感

  19. 19有關梅欽鮑姆（Donald Meichenbaum）的認知行為矯正法（cognitive behavior modification），下列敘述何者正確？①自我指導方法（self-instructional methods）是以勝任學習模式（mastery learning model）為基礎發展的 ②自我指導方法是以因應模式（coping model）為基礎發展的 ③放聲思考法（Think Aloudprotocol）較注重技巧勝任（skill mastery）的問題解決方式 ④放聲思考法（Think Aloud protocol）是較注重勝任策略（mastery strategy）的問題解決方式

  20. 20有關貝克（Beck et al, 1979）等人提出的認知層級（levels of cognition），下列敘述何者錯誤？

  21. 21下列有關認知行為理論的敘述何者錯誤？

    2. (B) 班度拉（Bandura）認為有兩種類型的期待與行為的改變有關：對結果的期待（outcome expectation）及對自我能力的期待（efficacy expectation）
    3. (C) 貝克（Beck）的認知治療主要用於憂鬱症的個案
    4. (D) 艾里斯（Ellis）認為由父母或社會所灌輸的不合理信念（irrational beliefs）是心理疾病的根源

    3. (C) 當看到或想到酸梅就會流口水
    4. (D) 當巧克力放入口中會產生口水

    正解：(A)

  73. 73病患可經由試誤學習來改善處理事務的表現，但判斷力或衝動控制仍有缺失，依據艾倫（Allen）認知障礙參考架構下列何者是病患適合的認知形式（cognitive mode）？

    1. (A) 2.6～2.8
    2. (B) 3.0～3.4
    3. (C) 4.4～4.6
    4. (D) 5.0～5.2

    正解：(D)

  74. 74下列關於角色扮演（role playing）的敘述，何者錯誤？

    1. (A) 源自人類職能模式
    2. (B) 將生活中面對的問題，在治療情境中演出呈現
    3. (C) 經由他人的觀點與回饋可學習到對問題的洞察力（insight）
    4. (D) 可提升面對問題的自信、降低焦慮

    正解：(A)

  75. 75在團體中有一成員老是喜歡主動幫忙或搶其他病友的工作，或幫忙職能治療師做一些雜事，要不然就是常常要上廁所、喝水或問職能治療師問題。根據前述判斷，下列何者錯誤？

    1. (A) 這些行為都是為了想引起團體成員的注意
    2. (B) 要立刻制止病人這類行為
    3. (C) 繼續進行團體，不給予過多的注意力
    4. (D) 應考量這位病人的需求，適時引導他的行為

    正解：(B)

  76. 76當職能治療師懷疑個案可能有自殺的想法或是企圖時，第一步的處理方式為：

    1. (A) 請個案暫停職能治療活動，因為職能治療室中有太多危險的物品
    2. (B) 直接詢問個案是否有自殺的意念或是計畫，並詳細了解其想法
    3. (C) 仔細觀察個案的行為表現，並請個案身邊的人協助觀察
    4. (D) 了解個案的壓力源、心理狀態及最近生活的概況，並告知個案隨時可以尋求職能治療師的協助

    正解：(B)

  77. 77陳先生，人際關係紊亂，常因別人之言語而過度敏感，情緒易因生活中之壓力而明顯起伏，有多次自殺史。治療者在介入陳先生之治療時，首要步驟為：

    1. (A) 評估陳先生社交技巧
    2. (B) 以理情療法改變陳先生之錯誤認知
    3. (C) 進行放鬆技巧訓練
    4. (D) 建立治療關係

    正解：(D)

  78. 78在營造健全的社區復健環境上，下列何者無法提升個案的自我肯定？

    1. (A) 增加對個案社福資助
    2. (B) 對個案有同理心
    3. (C) 對個案表達接受
    4. (D) 減少個案社會參與之障礙

    正解：(A)

  79. 79下列何者不是艾倫（Allen）認知障礙團體規劃時，須考量的重要核心因素？

    1. (A) 個案的認知障礙程度
    2. (B) 環境的規劃與支持程度
    3. (C) 活動的類型與所需的工具
    4. (D) 個案的疾病診斷

    正解：(D)

  80. 80下列關於團體動力的敘述，何者錯誤？

    1. (A) 成員的角色會隨職能治療師的領導方式而改變
    2. (B) 在建議式領導下（advisory leadership），職能治療師稍微介入，成員即可扮演不同角色並達成團體目標
    3. (C) 當成員不願意扮演某角色時，職能治療師應採取參與式領導（participatory leadership）
    4. (D) 促進式領導（facilitative leadership）介於指導式領導（directive leadership）和建議式領導（advisoryleadership）之間

    正解：(C)
