營養師　104 年第一次 膳食療養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1有關巨球性貧血（macrocytic anemia）的敘述，下列何者錯誤？

    1. (A) 包括巨紅芽貧血（megaloblastic anemia）和惡性貧血（pernicious anemia）
    2. (B) 與葉酸和維生素 B12 缺乏有關
    3. (C) 亦屬於缺鐵性貧血的一種
    4. (D) 與 DNA 合成受影響有關

    正解：(C)

  2. 2有關氮平衡的敘述，下列何者錯誤？

    1. (A) 氮平衡是在反應氮攝取量、尿排出量與其他氮排除量的平衡
    2. (B) 腎功能改變對此值影響不大
    3. (C) 需要收集受測者 24 小時尿液以幫助計算
    4. (D) 負氮平衡是表示氮攝取量小於氮排除量

    正解：(B)

  3. 3下列有關營養診斷的敘述，何者錯誤？

    1. (A) 每位病人之營養診斷以 1 個為原則
    2. (B) 是要確認出營養師可以解決或改善的營養問題
    3. (C) 包括營養問題（P）、原因（E）及症狀或徵候（S）
    4. (D) 臨床問題是營養診斷的分類之一

    正解：(A)

  4. 4長期使用史他汀類藥物（Statin drugs）會破壞下列何者而造成細胞傷害？

    1. (A) 細胞核
    2. (B) 輔酶 Q10
    3. (C) 乙醯輔酶 A
    4. (D) 脫氫酶

    正解：(B)

  5. 5降血糖藥物 Acarbose 會抑制下列何種酵素之活性？

    1. (A) α-amylase
    2. (B) β-lipase
    3. (C) α-glucosidase
    4. (D) α-isomaltase

    正解：(C)

  6. 6選擇營養支持種類時，腸道營養優於靜脈營養的原因很多，下列何者錯誤？

    1. (A) 能保持腸道黏膜的完整性與其屏障功能
    2. (B) 維護免疫功能
    3. (C) 較能降低異化代謝反應
    4. (D) 不用擔心 refeeding syndrome 的發生

    正解：(D)

  7. 7長期服用抗驚厥藥（anticonvulsants）會造成下列何種營養素之缺乏？

    1. (A) 甲硫胺酸
    2. (B) 亞麻油酸
    3. (C) 維生素 D
    4. (D) 鈣

    正解：(C)

  8. 8重症患者使用全靜脈營養時，葡萄糖的輸入速度每分鐘最快不要超過：

    1. (A) 5 mg/kg BW
    2. (B) 50 mg/kg BW
    3. (C) 500 mg/kg BW
    4. (D) 5 g/kg BW

    正解：(A)

  9. 9下列有關 eating disorder 的敘述，何者錯誤？

    1. (A) 非特定性的 eating disorder 患者即使無暴飲暴食，也會在飯後催吐
    2. (B) anorexia nervosa 患者即使體重過輕，也覺得自己過重
    3. (C) binge-eating disorder 患者有暴飲暴食後催吐的習慣
    4. (D) bulimia nervosa 患者有 lanugo hair 的問題

    正解：(D)

  10. 10下列何者屬於成人肥胖症？

    1. (A) BMI＝26
    2. (B) 臀圍 95 公分
    3. (C) 腰圍 95 公分
    4. (D) 體脂肪 24%

    正解：(C)

  11. 11下列有關第二型骨質疏鬆（type II 或 age-related osteoporosis）的特徵敘述，何者正確？

    1. (A) 發生於 50～60 歲之間
    2. (B) 身高下降
    3. (C) 只影響樑骨（trabecular）骨質，不影響皮質骨（cortical）骨質
    4. (D) 很少發生在女性

    正解：(B)

  12. 12補充下列何種微量礦物質，會增加骨頭中膠原蛋白和彈性蛋白交錯結合（cross linking）結構的穩定性？

    1. (A) 氟
    2. (B) 錳
    3. (C) 銅
    4. (D) 鎂頁次：4－3

    正解：(C)

  13. 13有關低渣飲食之敘述，下列何者錯誤？

    1. (A) 適用於腹瀉、腸炎患者
    2. (B) 多配合高蛋白、高熱量飲食
    3. (C) 補充奶類作為蛋白質來源
    4. (D) 以果汁代替水果

    正解：(C)

  14. 14有關幽門桿菌（Helicobacter pylori）的敘述，下列何者正確？

    1. (A) 增加罹患 Crohn's disease 的危險性
    2. (B) 可以抗生素治療其感染
    3. (C) 感染部位在小腸黏膜
    4. (D) 是造成胃炎的濾過性病毒

    正解：(B)

  15. 15有關迴腸造口術患者應注意之事項，下列敘述何者錯誤？

    1. (A) 避免可能產生不良氣味的食物
    2. (B) 注意水份攝取是否足夠，以避免腎結石發生
    3. (C) 減少容易產氣的食物，如豆類、洋蔥
    4. (D) 減少蔬菜、水果攝取，以減少糞便體積

    正解：(D)

  16. 16有關腸胃道疾病之症狀，下列何者敘述正確？

    1. (A) 食道鬆弛並非引起吞嚥困難之可能原因
    2. (B) 吃高脂飲食引起胃痛，可能為胃潰瘍前兆
    3. (C) 享用大餐後一小時，產生心灼熱，主要可能原因為胃食道逆流
    4. (D) 進食時腹痛如絞，可能為十二指腸潰瘍症狀

    正解：(C)

  17. 17膽泥（biliary sludge）之形成，最常發生於下列那些族群？①長期使用 TPN 之病人 ②長期使用鼻胃管之病人 ③長期使用鼻空腸管之病人 ④長期採極低熱量飲食減肥者 ⑤暴飲暴食者 ⑥嗜食肉食者 ⑦嗜食甜品飲料者 ⑧素食者

    1. (A) ①⑥⑦
    2. (B) ②④⑧
    3. (C) ③⑤⑥
    4. (D) ①③④

    正解：(D)

  18. 18關於糖尿病的急性併發症 DKA（diabetic ketoacidosis）與 HHS（hyperglycemic hyperosmolar state）的敘述，下列何者正確？

    1. (A) DKA 常發生在第 2 型糖尿病病患
    2. (B) HHS 血中 pH 值正常
    3. (C) HHS 不需考慮施打胰島素治療
    4. (D) DKA 血糖通常會高至 600 mg/dL 以上

    正解：(B)

  19. 19關於第 1 型糖尿病的兒童及青少年體重未能正常增加的可能原因，下列何者錯誤？

    1. (A) 胰島素不足
    2. (B) 血糖控制不佳
    3. (C) 血壓偏高
    4. (D) 熱量過度限制

    正解：(C)

  20. 20關於糖尿病病患的飲食建議，下列敘述何者正確？

    1. (A) 醣類種類比醣類總量對血糖的影響更大
    2. (B) 纖維質攝取建議量大於一般健康人
    3. (C) 建議糖尿病病患避免食用含果糖及蔗糖的食物
    4. (D) 若纖維質攝取量＞5 克，需將纖維質攝取量一半當作醣類攝取量

    正解：(D)

  21. 21有關糖尿病病患的營養醫療紀錄，下列敘述何者錯誤？

    1. (A) 紀錄不具法律效力，但可作為給付的依據
    2. (B) 紀錄可以作為醫療團隊成員溝通之工具
    3. (C) 紀錄有很多不同形式，可依不同場域及是否使用電子病歷而定
    4. (D) 紀錄內容應包括 ADIME（assessment, diagnosis, intervention, monitoring & evaluation）

    正解：(A)

  22. 22有關慢性腎臟病（CKD）病患透析前（predialysis）的營養治療，下列何者錯誤？

    1. (A) 限制鈉鹽攝取
    2. (B) 增加鈣質攝取
    3. (C) 限制蛋白質攝取
    4. (D) 增加鉀鹽攝取

    正解：(D)

  23. 23下列有關透析液的敘述，何者正確？

    1. (A) 腹膜透析液含高濃度葡萄糖
    2. (B) 腹膜透析液的電解質含量與血漿相同
    3. (C) 血液透析液含高濃度的葡萄糖
    4. (D) 血液透析液的電解質含量較血漿低

    正解：(A)

  24. 24減緩腎臟疾病惡化之進展，與下列何者之控制無關？

    1. (A) 膳食蛋白質
    2. (B) 血清鎂
    3. (C) 血壓
    4. (D) 血清磷

    正解：(B)

  25. 25有關 nephrotic syndrome 之營養治療，下列何者較適當？

    1. (A) 0.8 公克蛋白質／公斤／天
    2. (B) 適度限鉀至小於 2 公克
    3. (C) 嚴格限鈉至小於 1 公克
    4. (D) 嚴格限水至每日 750 毫升頁次：4－4

    正解：(A)

  26. 26有關 atherogenesis 之敘述，下列何者錯誤？

    1. (A) 慢性發炎反應使血管壁受損
    2. (B) 進入血管內層的吞噬細胞吞噬氧化型 LDL，形成泡沫細胞
    3. (C) 橫紋肌細胞進入血管內層，發生微小鈣化（microcalcification），形成動脈粥狀斑（plaque）
    4. (D) 血脂異常會增加動脈粥狀硬化危險性

    正解：(C)

  27. 27下列那些是胰島素的功能？①促進脂肪分解 ②促進肝醣合成 ③促進脂蛋白脂解酶活性 ④促進糖質新生

    1. (A) ①②
    2. (B) ②③
    3. (C) ①④
    4. (D) ②④

    正解：(B)

  28. 28關於血壓的敘述，下列何者錯誤？

    1. (A) 當血壓為 120～139/80～89 mmHg 是正常值，通常不需處理
    2. (B) 成年人血壓值達 140～159/90～99 mmHg 屬高血壓
    3. (C) 第一階段高血壓（Stage 1 hypertension）除修正生活習慣外，建議使用利尿劑處理
    4. (D) 若併用兩種藥治療高血壓時，需留意姿態性低血壓（orthostatic hypotension）的發生

    正解：(A)

  29. 29下列何種脂蛋白，主要運送飲食中的三酸甘油酯？

    1. (A) chylomicron
    2. (B) VLDL
    3. (C) LDL
    4. (D) HDL

    正解：(A)

  30. 30燒燙傷患者通常較不需補充下列何種營養素？

    1. (A) 維生素 A
    2. (B) 維生素 C
    3. (C) 鐵
    4. (D) 鋅

    正解：(C)

  31. 31下列何種估算能量需求的方式，最符合高代謝狀態的患者之所需？

    1. (A) 直接以每日每公斤體重需求 35～40 大卡估算
    2. (B) 依據 DRIs 的需求量估算
    3. (C) 按照氮平衡（nitrogen balance）的方法估算
    4. (D) 以間接熱量測量法（indirect calorimetry）估算

    正解：(D)

  32. 32下列何者是重症患者在外傷壓力（stress）下會產生的現象？

    1. (A) 腸道蠕動增加
    2. (B) 高血糖
    3. (C) 食慾增加
    4. (D) 體蛋白質分解減少

    正解：(B)

  33. 33重症患者在嚴重損傷（injury）後立即產生的代謝反應期稱為：

    1. (A) ebb phase
    2. (B) flow phase
    3. (C) acute response phase
    4. (D) adaptive response phase

    正解：(A)

  34. 34下列那些維生素是患有纖維囊腫（cystic fibrosis）小孩最容易缺乏的？

    1. (A) 維生素 A、E、C
    2. (B) 水溶性維生素和 K
    3. (C) 維生素 A、D、E、K
    4. (D) 脂溶性維生素和 B12

    正解：(C)

  35. 35下列何者不是上呼吸道的構造？

    1. (A) 口腔
    2. (B) 鼻腔
    3. (C) 咽
    4. (D) 喉

    正解：(A)

  36. 36胃癌病患手術後的營養問題，下列何者較不常見？

    1. (A) 脫水
    2. (B) 蛋白質消化異常
    3. (C) 脂肪吸收不良
    4. (D) 傾食症候群

    正解：(B)

  37. 37有關癌症病人之營養照護目標，下列敘述何者錯誤？

    1. (A) 預防營養素缺乏
    2. (B) 保留肌肉組織
    3. (C) 增加脂肪組織
    4. (D) 提高生活品質

    正解：(C)

  38. 38關於嬰兒生長發育的敘述，下列何者正確？

    1. (A) 出生後幾天體重稍微減輕，通常到滿月時才會回復至出生時的體重
    2. (B) 4～6 個月的體重通常是出生體重的 2 倍
    3. (C) 1 歲的身高通常是出生的 2 倍
    4. (D) 3 歲的身高通常是出生的 3 倍

    正解：(B)

  39. 39對於吞嚥困難（dysphagia）的老人，下列何種類型的飲料或食物較有助於改善進食困難的問題，並減少嗆到的機率？

    1. (A) 烘烤乾燥的食物
    2. (B) 不含渣的稀釋果汁
    3. (C) 完整的高纖食物
    4. (D) 果泥或糊狀質地的食物

    正解：(D)

  40. 40阿茲海默氏症（Alzheimer's disease）患者常有體重減輕的問題，下列何者是可能的主要原因之一？

    1. (A) 未按時服用藥物
    2. (B) 休息時代謝率降低
    3. (C) 日常飲食常攝取不足
    4. (D) 進食時常過度咀嚼

    正解：(C)
