  1. 1關於 SSL 敘述，下列何者錯誤？

    1. (A) 在電子商務應用中，一般消費者並沒有憑證，因此無法利用 SSL 對商家做使用者認證
    2. (B) SSL 可提供資料的隱私性
    3. (C) SSL 是採用公開金鑰加密演算法，達到資料完整性（data integrity）保護
    4. (D) 採用 SSL 的網站，並不代表該網站應用程式之安全

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 此項錯誤：SSL 的資料完整性靠訊息驗證碼（MAC／雜湊）達成，公開金鑰僅用於身分驗證與金鑰交換。

    ❌ (A) 敘述正確，一般消費者無憑證，故無法以 SSL 對其做使用者認證。

    ❌ (B) 敘述正確，SSL 以對稱式加密提供隱私性。

    ❌ (D) 敘述正確，傳輸加密不等於網站應用程式安全。

    📚 出處：SSL/TLS 的安全服務。

  2. 2電子商務需要安全服務，下列敘述何者錯誤？

    1. (A) 消費者與商家雙方應做到相互認證（mutual authentication）
    2. (B) 消費者與商家雙方應做到不可否認性（non-repudiation）
    3. (C) 電商平台利用 TLS/SSL 只能確保資料傳輸之安全性
    4. (D) 消費者信用卡付款資訊，商家無法看到，只有雙方的信用卡公司才可以看到

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 此項錯誤：在 SSL/TLS 架構下商家看得到信用卡資訊；使卡號對商家隱藏的是 SET 協定。

    ❌ (A) 敘述正確，雙方應相互認證。

    ❌ (B) 敘述正確，交易應具不可否認性。

    ❌ (C) 敘述正確，TLS/SSL 只保障傳輸過程的安全。

    📚 出處：電子商務的安全需求；SSL 與 SET 的比較。

  3. 3關於非對稱式加密（Asymmetric cryptography）的敘述，下列何者錯誤？

    1. (A) 非對稱式加密可以做到使用者認證的功能
    2. (B) 非對稱式加密比對稱式加密安全
    3. (C) 非對稱式加密可以提供金鑰管理之功能
    4. (D) 非對稱式加密可以提供數位簽章的功能

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 此項錯誤：安全性取決於金鑰長度與演算法設計，非對稱式加密在相同安全強度下速度慢，並非必然較安全。

    ❌ (A) 敘述正確，可用於使用者認證。

    ❌ (C) 敘述正確，可解決金鑰分配與管理的問題。

    ❌ (D) 敘述正確，數位簽章即建立於非對稱式加密。

    📚 出處：對稱式與非對稱式加密的比較。
