本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1當治療師在示範組裝一個玩具時，一面說：「這樣好像不對，是哪裡做錯了？」一面檢查作品；接著又說：「嗯！這裡好像怪怪的。」根據促進學習的四象限模式，治療師這樣做的目的主要是什麼？

    1. (A) 促使孩童產生動作
    2. (B) 讓孩童知道任務的目標
    3. (C) 讓孩童知道哪裡做錯了
    4. (D) 示範如何進行高階認知程序

    正解：(D)

  2. 2職能治療師所使用的參考架構，其基本要素包括那些部分？①理論基礎 ②診斷分類 ③功能／失能連續體 ④功能與功能障礙指標 ⑤評估 ⑥關於改變的假說 ⑦實務應用

    1. (A) 僅①②③④⑤⑥
    2. (B) ①②③④⑤⑥⑦
    3. (C) 僅①③④⑤⑥⑦
    4. (D) 僅①③④⑥⑦

  3. 3關於參考架構中理論基礎的定義（definitions）與假說（postulates），下列敘述何者正確？

    1. (A) 假說是用來陳述理論中的一個主要概念
    2. (B) 根據Mosey所提的定義分類，循環定義（circular definition）是最能解釋理論概念的定義形式
    3. (C) 假設（hypothesis）是用來檢驗理論的一種特定的假說，通常是可觀察且可測量的
    4. (D) 功能定義（functional definition）是可測量且能以某種方式來量化或質化

    正解：(C)

  4. 4對於有焦慮與憂鬱的學齡兒童，職能治療師使用活動與職能來介入的敘述，下列何者正確？

    2. (B) 職能治療的介入要讓兒童在學校中的特定教室進行活動
    3. (C) 有焦慮與憂鬱症狀的兒童完全無法展現所有學校相關職能上的能力
    4. (D) 初次呈現的活動可設計能引起高度興趣但低度個人意義的分級挑戰活動

    正解：(D)

  5. 5當兒童在小組活動中需要參與多種角色來達成一個共同目標，這是觀察兒童社會參與的那一種互動形式？

  7. 7有關坐姿骨盆束帶的敘述，下列何者錯誤？

    2. (B) 對於骨盆控制良好的孩童，骨盆束帶從椅面成90度伸出並與地面垂直，繞於前上髂嵴（anteriorsuperior iliac spine, ASIS）下
    3. (C) 對於骨盆有正中排列但無法維持者，骨盆束帶應綁在前上髂嵴上，並以與地面平行的方式固定於椅背
    4. (D) 對於骨盆容易旋轉或歪斜者，可以使用四點固定且加襯墊的骨盆束帶

  11. 11下列有關最佳挑戰點理論（Theory of Optimal Challenge Point）的內容，何者錯誤？

    2. (B) 在較多情境干擾的情況下練習，會增加一個任務的類別性困難度（nominal difficulty）
    3. (C) 最佳挑戰點是要讓孩童能對一個特定的動作技巧有最好的學習所需要任務困難度
    4. (D) 能夠達到成功的任務表現取決於孩童的技巧程度及任務的類別性困難度（nominal difficulty）

  13. 13根據 生物力學參考架構 ，有關坐姿擺位，下列何者錯誤？

  14. 14有關於肌肉張力的敘述，下列何者錯誤？

  18. 18關於感覺系統的敘述，下列何者錯誤？

  20. 20根據Dunn對「感覺處理（sensory processing）」所提出的概念模式，下列敘述何者正確？

    1. (A) 對感覺輸入的敏感度閾值低者可能會出現反應不足的行為（hypo-responsive behaviors），如：昏昏欲睡
    2. (B) 對感覺輸入的敏感度閾值高者可能會出現感覺尋求（sensory seeking）行為以代償其敏感度不足
    3. (C) 對感覺輸入的敏感度閾值低者可能會以低登錄（low registration）方式代償其敏感度過高

    正解：(B)

  21. 21有關兒童侷限誘發動作療法（constraint-induced movement therapy, CIMT）和手－臂雙側密集療法（Hand-Arm Bimanual Intensive Therapy, HABIT）的治療原則，下列何者最不適當？

    1. (A) CIMT結合任務導向訓練手法（task-oriented training approaches），強調重複及大量練習特定動作活動
    2. (B) HABIT應用雙側手活動（bimanual activities），強調區段練習（blocked practice）以達到功能性目標
    3. (C) CIMT藉由侷限健側手和動作塑造（shaping）技巧，提供至少大於30小時的訓練時間促進患側手功能
    4. (D) HABIT根據個別孩童能力調整任務難度，提供至少大於60小時以上的訓練時間可讓神經產生改變

    正解：(B)

  23. 23有關職能治療師協助兒童學習從杯子喝水的介入策略，下列敘述何者正確？

    1. (A) 對於神經肌肉損傷（neuromuscular impairments）兒童，採用杯蓋有防漏閥（nonspill valves）的杯子可降低難度
    2. (B) 若兒童有伸直姿態（extensor posturing）和較差的頭部控制能力，可學習先從鴨嘴杯（spoutedcup）喝水以降低難度
    3. (C) 若採用剪口杯（cut-out cup），或許能降低兒童喝水時頭頸的伸張（extension）角度，讓治療師較易觀察動作
    4. (D) 當兒童從開口杯（open cup）喝水時，應採用半躺姿勢，藉由重力作用協助將液體滑入咽腔（pharyngeal space）

    正解：(C)

    2. (B) 急性期穿著的壓力衣壓力應比微血管壓稍高（30～35 mmHg），每天穿23小時直到疤痕成熟
    3. (C) 住院期的牽張（stretches）活動持續到個案做出完整主動關節活動幅度，一般大約需半年時程
    4. (D) 門診期進行監督式有氧（aerobic）和漸進式阻力（progressive resistance）訓練計畫，有助於復健

    正解：(D)

  74. 74職能治療師運用認知導向日常職能表現（Cognitive Orientation to daily OccupationalPerformance, CO-OP）介入來幫助自閉症兒童建立職能表現行為技能，下列敘述何者錯誤？

    1. (A) CO-OP是以認知理論及動機理論為基礎
    2. (B) 需要兒童本身具備足夠的內在動機及觀察學習的能力
    3. (C) 證據顯示用於各種程度的自閉症兒童均效果卓越
    4. (D) 終極目標是自閉症兒童可以類化學到的新技能到日常生活當中

    正解：(C)

  75. 75下列描述腦性麻痺的感覺動作問題，何者正確？

    1. (A) 肌肉張力隨著肢體動作發生速度改變而改變，為痙攣型腦性麻痺
    2. (B) 不正常原始反射出現比率極高，但會隨著年齡增長逐漸整合消退
    3. (C) 常伴隨感覺處理功能障礙，特別是前庭覺、本體覺及觸覺
    4. (D) 運動失調（dyskinetic）腦性麻痺包含athetoid, choreoathetoid, and dystonic三大類，影響主動性動作控制

    正解：(A)

  76. 76自主神經異常反射（autonomic dysreflexia）最容易出現在那一種個案身上？

    1. (A) 脊髓損傷
    2. (B) 肌肉萎縮症
    3. (C) 燒傷
    4. (D) 自閉症

    正解：(A)

  77. 77脊髓損傷的兒童在最低薦髓段（S4-S5）不具感覺與運動機能，根據美國脊髓損傷協會障礙機能損傷分級法（American Spinal Injury Association Impairment Scale, ASIA ImpairmentScale），其屬於那一級？

    1. (A) AIS A
    2. (B) AIS B
    3. (C) AIS C
    4. (D) AIS D

    正解：(A)

  78. 78對於腦性麻痺徐動型（athetosis）的孩童，應選擇下列那類玩具最適當？

    1. (A) 不須操作的玩具
    2. (B) 較重或可提供較大阻力的玩具
    3. (C) 玩法固定、變化性較小的玩具
    4. (D) 重量較輕的玩具

    正解：(B)

  79. 79早產兒沙沙在妊娠年齡（gestational age）27週時出生，在沙沙出生13週之後，她的受孕年齡（postmenstrual age）是：

    1. (A) 13週
    2. (B) 14週
    3. (C) 27週
    4. (D) 40週

    正解：(D)

  80. 80下列評估工具適用於腦性麻痺的孩童和青少年，何者的適用年齡最小？

    1. (A) 墨爾本單側上肢功能評估測驗（Melbourne Assessment of Unilateral Upper Limb Function）
    2. (B) 上肢技巧品質測驗（Quality of Upper Extremity Skills Test）
    3. (C) 傑柏森－泰勒手功能測驗（Jebson Taylor Test of Hand Function）
    4. (D) 腦性麻痺生活品質測驗－青少年（Cerebral Palsy Quality of Life-Teen）

    正解：(B)
