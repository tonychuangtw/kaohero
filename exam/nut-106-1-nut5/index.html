營養師　106 年第一次 公共衛生營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1膳食營養素參考攝取量（Dietary Reference Intakes, DRIs）在建議攝取量（Recommended Dietary Allowance,RDA）時，滿足特定年齡層及性別的健康人群中 97~98%的人一日所需攝取量，其計算公式為何？

    1. (A) Estimated average requirement (EAR) +1SDEAR
    2. (B) Estimated average requirement (EAR) + 2SDEAR
    3. (C) Adequate intake (AI) + 1SDAI
    4. (D) Adequate intake (AI) + 2SDAI

    正解：(B)

  2. 2第七版國人膳食營養素參考攝取量（Dietary Reference Intakes, DRIs）關於 19～50 歲成人體位及熱量修訂原則，下列何者正確？

    1. (A) 體重的參考值是以 BMI＝22 做為標準計算
    2. (B) 熱量建議量以足夠攝取量為基準，以避免肥胖
    3. (C) 參考美國 DRIs 的數據、臺灣民眾熱量攝取量和身體活動量
    4. (D) 熱量建議依身體活動分為「低」、「稍低」、「適度」與「高」四級

    正解：(D)

  3. 3衛生福利部訂定 103 年新版「兒童生長曲線百分位圖」可評估生長發育狀況，下列敘述何者錯誤？

    4. (D) 部分生長曲線圖的繪製乃根據世界衛生組織跨國的調查資料而定頁次： 4－2

    正解：(B)

  4. 4根據「不適合兒童長期食用之食品廣告及促銷管理辦法」，下列何者屬於不適合未滿 12 歲兒童長期食用食品？
