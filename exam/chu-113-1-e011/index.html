    2. (B) 國立大學及私立大學之設立、變更或停辦，由行政院核定或調整之
    3. (C) 教育部得就未設有專科部之縣（市），核准大學附設專科部
    4. (D) 大學得設立分校、分部

    正解：(B)

  46. 46依據原住民族教育法之規定，指原住民族之一般教育及民族教育，屬於下列何者的定義？

    1. (A) 原住民族教育
    2. (B) 民族教育
    3. (C) 一般教育
    4. (D) 原住民族學校

    正解：(A)

  47. 47依據偏遠地區學校教育發展條例之規定，偏遠地區學校編制內合格專任教師，下列何者不是聘任方式之一？

    1. (A) 聯合甄選
    2. (B) 介聘
    3. (C) 接受公費生分發
    4. (D) 偏遠地區鄉鎮推薦

    正解：(D)

  48. 48依據中央法規標準法之規定，下列何者是法律的名稱？

    1. (A) 條例
    2. (B) 辦法
    3. (C) 細則
    4. (D) 綱要

    正解：(A)

  49. 49法規命令之內容應明列其法律授權之依據，並不得逾越法律授權之範圍與立法精神。這是指法規的何種法律原則？

    1. (A) 法律優越原則
    2. (B) 比例原則
    3. (C) 法律保留原則
    4. (D) 明確性原則

    正解：(C)

  50. 50依據學校訂定教師輔導與管教學生辦法注意事項之規定，教師基於導引學生發展之考量，衡酌學生身心狀況後，得採取一般管教措施，下列敘述何者錯誤？

    1. (A) 口頭糾正
    2. (B) 在教室內適當調整座位
    3. (C) 要求靜坐反省
    4. (D) 要求站立反省。但每次不得超過 2 堂課，每日累計不得超過 3 小時

    正解：(D)
