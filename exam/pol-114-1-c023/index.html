警察特考　114 年 四等考試 犯罪學概要　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1涂爾幹（Émile Durkheim）認為犯罪在社會中的功能是什麼？

    1. (A) 破壞社會秩序，無正面意義
    2. (B) 是社會異常現象，必須完全根除
    3. (C) 有助於強化社會凝聚力與促進社會變遷
    4. (D) 個人病態行為，與社會結構無關

    正解：(C)

  2. 2下列何者不是古典犯罪學派的核心主張？

    1. (A) 理性選擇
    2. (B) 自由意志
    3. (C) 利害計算
    4. (D) 生物特徵

    正解：(D)

  3. 3龍布羅梭（Cesare Lombroso）的天生犯罪人理論主要基於什麼假設？

    1. (A) 犯罪是社會學習的結果
    2. (B) 犯罪者具有退化性生理特徵
    3. (C) 犯罪由經濟壓力引起
    4. (D) 犯罪與法律執行無關

    正解：(B)

  4. 4在標籤理論中，什麼因素導致次級偏差的形成？

    1. (A) 個人內在動機
    2. (B) 社會對犯罪者的污名化與排斥
    3. (C) 遺傳基因的影響
    4. (D) 缺乏教育機會

    正解：(B)

  5. 5下列何者不是修復式程序的要件？

    1. (A) 認知並尋求瞭解因該事件所造成的損害
    2. (B) 參與各方必須在瞭解修復式程序如何進行後，自願參加
    3. (C) 被告需要在法庭上對其被起訴罪名認罪
    4. (D) 必須要以說真話為基礎

    正解：(C)

  6. 6蘇哲蘭（Edwin Sutherland）的差別接觸理論強調犯罪行為的學習主要來自什麼？

    1. (A) 媒體宣傳
    2. (B) 經濟壓力的刺激
    3. (C) 與犯罪者的親密互動
    4. (D) 遺傳傾向

    正解：(C)

  7. 7破窗理論（Broken Window Theory）如何解釋違規行為對犯罪率的影響？

    1. (A) 無關緊要，不影響整體犯罪
    2. (B) 導致社區失序，吸引更嚴重犯罪
    3. (C) 減少居民對犯罪的恐懼
    4. (D) 促使警察加強執法

    正解：(B)

  8. 8在新刑罰學（New Penology）的理論架構下，下列那一項最能反映其核心特徵？

    1. (A) 聚焦於風險管理與群體控制，而非個人矯治
    2. (B) 強調對犯罪者的個別化改造與復歸
    3. (C) 優先考慮被害人的補償與修復
    4. (D) 主張恢復傳統的應報性懲罰

    正解：(A)

  9. 9社區警政（Community Policing）的主要目標是什麼？

    1. (A) 實施嚴格的法律執行
    2. (B) 增加逮捕率
    3. (C) 建立警察與社區的信任與合作
    4. (D) 減少警力投入

    正解：(C)

  10. 10下列那項政策最符合選擇性無害化（Selective Incapacitation）理念？

    1. (A) 針對高風險再犯者實施嚴格監禁
    2. (B) 對所有犯罪者施以長期監禁
    3. (C) 縮短所有刑期
    4. (D) 增加社區矯正項目

    正解：(A)

  11. 11司法院近來在研議設計刑事案件量刑準則（Sentencing Guidelines），其主要目的是：

    1. (A) 完全剝奪法官裁量權
    2. (B) 廢除最低刑度
    3. (C) 作為死刑的替代方案
    4. (D) 減少量刑歧異

    正解：(D)

  12. 12關於兩極化刑事政策，下列敘述何者正確？

    1. (A) 對所有犯罪均採取嚴厲刑罰
    2. (B) 完全廢除死刑
    3. (C) 輕微犯罪寬容化，重大犯罪嚴罰化
    4. (D) 僅適用於少年犯罪

    正解：(C)

  13. 13三振法案（Three-Strikes Law）主要的刑事政策目的是：

    1. (A) 降低監禁人口
    2. (B) 減少輕罪累犯
    3. (C) 嚴格打擊累犯
    4. (D) 減輕初犯刑度

    正解：(C)

  14. 14社區刑罰的優點不包括下列何者？

    1. (A) 減少犯罪標籤效應
    2. (B) 完全消除再犯風險
    3. (C) 降低監獄擁擠情形
    4. (D) 成本低於機構處遇

    正解：(B)

  15. 15轉向處分（Diversion）主要適用於何類犯罪者？

    1. (A) 重大暴力犯罪
    2. (B) 組織犯罪首腦
    3. (C) 恐怖主義犯罪
    4. (D) 少年或輕微犯罪者

    正解：(D)

  16. 16「應報刑論」的思想基礎最可能源自何種理論？

    1. (A) 功利主義
    2. (B) 康德哲學
    3. (C) 實證犯罪學
    4. (D) 標籤理論

    正解：(B)

  17. 17集體效益（Collective Efficacy）較高的社區，犯罪率通常：

    1. (A) 較高
    2. (B) 較低
    3. (C) 無關聯
    4. (D) 僅影響經濟犯罪

    正解：(B)

  18. 18在社會學習理論中，「差別增強」的意義是：

    1. (A) 選擇性地學習社會正當價值
    2. (B) 選擇性結交朋友
    3. (C) 選擇性地獎勵或懲罰某些行為
    4. (D) 選擇不同犯罪目標

    正解：(C)

  19. 19關於犯罪熱點（Hot Spots），下列敘述何者錯誤？

    1. (A) 警方應平均分配巡邏資源
    2. (B) 犯罪集中於特定地理區域
    3. (C) 可透過數據分析識別
    4. (D) 與日常活動理論相關

    正解：(A)

  20. 20下列何者屬於批判犯罪學的觀點？

    1. (A) 法律反映統治階級利益
    2. (B) 犯罪人應接受更嚴厲懲罰
    3. (C) 犯罪與基因高度相關
    4. (D) 犯罪率可透過監控科技降低

    正解：(A)

  21. 21關於女性主義犯罪學，下列敘述何者正確？

    1. (A) 僅關注女性被害者
    2. (B) 忽略性別結構對犯罪的影響
    3. (C) 批判傳統犯罪學理論以男性視角為中心
    4. (D) 主張女性犯罪率與男性無異

    正解：(C)

  22. 22在控制理論中，赫胥（Travis Hirschi）提出的四種社會鍵不包括下列那項？

    1. (A) 依附（Attachment）
    2. (B) 承諾（Commitment）
    3. (C) 參與（Involvement）
    4. (D) 壓力（Stress）

    正解：(D)

  23. 23一般化犯罪理論（General Theory of Crime）認為犯罪的主因是：

    1. (A) 低自我控制
    2. (B) 社會不平等
    3. (C) 文化衝突
    4. (D) 心理疾病

    正解：(A)

  24. 24中立化技巧中，犯罪者常用的「被害者的否定」指的是什麼？

    1. (A) 認為受害者罪有應得
    2. (B) 將責任推給家庭與社會等非個人因素
    3. (C) 否認犯罪行為的存在
    4. (D) 強調經濟困難帶來的影響

    正解：(A)

  25. 25貧困且人口流動率高、無法吸引居民長期居住的社區，Shaw & McKay 會將此區域稱為：

    1. (A) 同心圓區域（concentric neighborhoods）
    2. (B) 封閉型區域（gated neighborhoods）
    3. (C) 轉型區域（transitional neighborhoods）
    4. (D) 高風險區域（at-risk neighborhoods）

    正解：(C)
