護理師　113 年第三次 內外科護理學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列診斷檢查敘述何者錯誤？

    1. (A) 腰椎穿刺將針頭插入 L3～L4 之蜘蛛膜下腔
    2. (B) 腰椎穿刺後需要臥床休息，加強水分攝取
    3. (C) 腦波檢查前病人需要洗頭並且不可以擦髮油
    4. (D) 經股動脈進行腦血管攝影後，可立即下床活動，避免下肢血栓形成

    正解：(D)

  2. 2有關重症肌無力病人發生膽鹼激性危象之敘述，下列何者錯誤？

    1. (A) 因 Mestinon 使用過量而失去阻斷作用

    3. (C) 病人會出現血壓上升、心搏過速
    4. (D) 病人會出現支氣管分泌增加、腹部疼痛和腹瀉

    正解：(C)

    2. (B) 教導使用 desmopressin（DDAVP）鼻噴霧劑時勿憋氣，並須確認藥劑確實有吸入肺部
    3. (C) 教導病人睡前少喝水，減少夜晚環境上的刺激
    4. (D) 教導病人用藥的方式、劑量、時間及副作用，並定期返院追蹤

    正解：(B)

  44. 44有關糖尿病病人足部護理的指導，下列何者正確？①每日以溫水清洗足部前須以手背測試水溫，以防燙傷②修剪趾甲應剪短於足趾末端，以防甲溝炎 ③平日於足部與足趾間及腳跟龜裂處，塗抹保養乳液，以免皮膚過於乾燥 ④不可擅自用手或剪刀，將足部硬繭或雞眼剝除

    1. (A) ①②
    2. (B) ①④
    3. (C) ②③
    4. (D) ③④

    正解：(B)

  45. 45有關庫欣氏症候群（Cushing’s syndrome）的臨床表徵，下列何者正確？

    4. (D) 葡萄糖新生減少

  46. 46有關腦下垂體中風之臨床表徵，下列何者錯誤？

  47. 47有關敗血性休克導致的系統性炎性反應症候群（SIRS）其診斷的四個條件中，需含二項或以上，下列條件何者正確？①體溫大於 38℃或小於 36℃ ②心跳小於 60 次／分 ③呼吸速率大於 20 次／分，或 PaCO2小於 40 mmHg ④白血球大於 12000/uL 或小於 4000/uL
