營養師　102 年第二次 團體膳食設計與管理　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1依據 2002 年通過之「學校衛生法」，第 23 條規定高級中等以下學校，班級數在多少以上須設置營養師？

    1. (A) 20 班
    2. (B) 30 班
    3. (C) 40 班
    4. (D) 50 班

    正解：(C)

  2. 2下表為某自助餐銷售分析表，則菜單中的烤雞腿的預估份數為何？菜餚名稱 預估份數 實際銷售份數 未出售份數 未出售份數百分比烤雞腿 ？ 450 50 10％

    1. (A) 250
    2. (B) 500
    3. (C) 750
    4. (D) 1000

    正解：(B)

  3. 3下列何組食物之可食重量的蛋白質量是相同的？

    1. (A) 白帶魚 30 公克，脫脂奶 1 杯
    2. (B) 玉米粒 100 公克，紅蘿蔔 400 公克
    3. (C) 玉米粒 200 公克，紅蘿蔔 200 公克
    4. (D) 三層肉 50 公克，豆腐 50 公克

    正解：(B)

  4. 4欲供應炒高麗菜 200 份，每份成品熟重 50 公克，已知高麗菜的廢棄率為 10％，膨縮率為 80％，則需準備多少公斤高麗菜？

    1. (A) 10
    2. (B) 12
    3. (C) 14
    4. (D) 16

    正解：(C)

  5. 5下列何者是菜單設計上較不優先考量的因素？

    1. (A) 預算控制
    2. (B) 季節
    3. (C) 供應型態
    4. (D) 員工人數的多寡頁次：4－2

    正解：(D)

  6. 6欲供應蘿蔔 1000 人份，已知每份

    1. (A) P. 100 公克，E.P. 85 公克，則應採買多少量？A. 85 公斤
    2. (B) 100 公斤
    3. (C) 125 公斤
    4. (D) 150 公斤

    正解：(B)

  7. 7下列何種庫存管理方法之每次進貨量均是相同？

    1. (A) 經濟型訂貨法（Economic Order Quantity Method）
    2. (B) 先進先出法（First In First Out Method）
    3. (C) 最小及最大庫存量訂貨法（Minimum-Maximum Method）
    4. (D) ABC 分類法（ABC Method）

    正解：(C)

  8. 8下列何者不是食物成本控制不當的原因？

    1. (A) 廢棄率太高
    2. (B) 採買、驗收不佳
    3. (C) 利潤的比率
    4. (D) 份量控制不當

    正解：(C)

  9. 9豆乾、干絲等豆製品驗收後，下列何者是正確之貯存方式？

    1. (A) 用水浸泡存放
    2. (B) 存放在乾貨庫
    3. (C) 存放在室溫下
    4. (D) 入冷藏室存放

    正解：(D)

  10. 10滷雞腿的一人份成品供應量為 90 公克，收縮率 20％，熟廢棄率 10％，欲供應 500 人份應購買多少雞腿？

    1. (A) 34 公斤
    2. (B) 55 公斤
    3. (C) 62.5 公斤
    4. (D) 66 公斤

    正解：(C)

  11. 11下列何者不是遵守 FIFO 的主要優點？

    1. (A) 以利食物充分循環利用
    2. (B) 以利盤點的方便
    3. (C) 避免食物過期腐敗
    4. (D) 方便撥發

    正解：(B)

  12. 12採購生鮮魚、肉類時，應如何判斷肉質的鮮度？

    1. (A) 若豬的屠體成蒼白、柔軟、有滲水狀況，最適合烹調或加工
    2. (B) 若豬屠體肌肉的 pH 值偏低，表示在剛死亡的僵直期，是鮮味最佳時期
    3. (C) 新鮮的魚身有海藻味，腹部應有彈性
    4. (D) 冷凍的鮪魚或鰹魚若利用流水式解凍易有橙色肉的發生

    正解：(C)

  13. 13食物採購原則不包含下列那一項？

    1. (A) 適值
    2. (B) 適量
    3. (C) 適時
    4. (D) 最低價格

    正解：(D)

  14. 14公立學校餐廳在何狀況下必須以公開招標方式辦理採購？

    1. (A) 大量採購具獨占性食材時
    2. (B) 供應商有三家或三家以上時
    3. (C) 採購金額在新臺幣二十萬元以上時
    4. (D) 採購金額在新臺幣一百萬元以上時

    正解：(D)

  15. 15下列何種加工品的原物料不是黃豆？

    1. (A) 素雞
    2. (B) 百頁
    3. (C) 烤麩
    4. (D) 千張

    正解：(C)

  16. 16前處理後的原料須在幾小時內加工調理完畢？

    1. (A) 2
    2. (B) 3
    3. (C) 4
    4. (D) 5

    正解：(A)

  17. 17皮蛋呈現半透明膠狀，是因蛋白的酸鹼（pH）值為何？

    1. (A) pH 值 3.0 以下
    2. (B) pH 值 5.0～7.0
    3. (C) pH 值 8.0～10.0
    4. (D) pH 值 11.9 以上

    正解：(D)

  18. 18下列那種穀類胚芽所占的比例最大？

    1. (A) 胚芽米
    2. (B) 小麥
    3. (C) 燕麥
    4. (D) 玉米頁次：4－3

    正解：(D)

  19. 19製作油飯以何種米為原料最適宜？

    1. (A) 稉米
    2. (B) 秈米
    3. (C) 長糯米
    4. (D) 圓糯米

    正解：(C)

  20. 20一盤肉絲炒麵，油麵用了 180 公克，瘦肉（熟重）75 公克，高麗菜（可食量）50 公克，油 1 大匙，此盤肉絲炒麵提供多少熱量？

    1. (A) 465 大卡
    2. (B) 495 大卡
    3. (C) 535 大卡
    4. (D) 565 大卡

    正解：(D)

  21. 21下列有關魚類烹調之敘述，何者錯誤？

    1. (A) 在煎炸魚之前可加入少許鹽，以避免煎炸時魚肉分散
    2. (B) 花枝應由內面做切割以產生捲曲花紋
    3. (C) 肉質細緻且脂肪少之魚類宜用乾熱法
    4. (D) 淡水魚多為養殖，易含有寄生蟲，要完全煮熟

    正解：(C)

  22. 22不鏽鋼餐具有不同等級，常用的一種等級 18/8 是指：

    1. (A) 18％鎳、8％鉻
    2. (B) 18％鉻、8％鎳
    3. (C) 18％碳、8％鋅
    4. (D) 18％鋅、8％碳

    正解：(B)

  23. 23速食店經營原則 Q.S.C.V.中的 S 是指：

    1. (A) 衛生
    2. (B) 品質
    3. (C) 價值
    4. (D) 服務

    正解：(D)

  24. 24高速發酵機生產「有機生肥」僅適用於那一類的廚餘？

    1. (A) 肉類之廚餘
    2. (B) 葉菜類與漿果類水果之廚餘
    3. (C) 含肉與蔬果之廚餘
    4. (D) 含粗根植物之廚餘

    正解：(D)

  25. 25食品洗滌區應設立在何處？

    1. (A) 一般作業區
    2. (B) 污染作業區
    3. (C) 準清潔作業區
    4. (D) 清潔作業區

    正解：(A)

  26. 26下列何者是正確之廚房動線規劃？

    1. (A) 主動線應預留寬度 130～145 cm
    2. (B) 附屬走道寬度 75～90 cm
    3. (C) 工作人員動線與生產動線相同
    4. (D) 工作推車預留動線寬度≧50 cm

    正解：(B)

  27. 27下列何者會增加人事成本？

    1. (A) 使用標準食譜及循環菜單
    2. (B) 高的生產力
    3. (C) 良好的廚房設施及流程管理
    4. (D) 工作場所意外事件

    正解：(D)

  28. 28安排廚務工作時，需要注意到員工的疲累現象，因此會建議技巧性工作和非技巧性工作的工作時數分配比例。建議技巧性工作和非技巧性工作之比值為何？

    1. (A) 15％：85％
    2. (B) 50％：50％
    3. (C) 60％：40％
    4. (D) 75％：25％

    正解：(D)

  29. 29下列有關餐飲業成本控制的敘述，何者錯誤？

    1. (A) 一般而言採用桌邊服務的人事成本較速食服務為高
    2. (B) 使用循環菜單者比單點菜單者之工作人員操作會較有效率
    3. (C) 人事成本占營業收入 55％～65％
    4. (D) 績效獎金制度可以激勵員工士氣，增加生產力，相對人事成本比也可能會上升

    正解：(C)

  30. 30下列何者屬於固定成本？

    1. (A) 水電費
    2. (B) 設備折舊費用
    3. (C) 膳食材料費
    4. (D) 加班費頁次：4－4

    正解：(B)

  31. 31A 大學餐廳 4 月的膳食銷售營業額為 2,853,000 元，月初的食材存貨金額為 57,600 元，本月進貨金額為1,100,000 元，至月底食材存貨金額為 73,460 元，該餐廳的員工薪水為 967,080 元，員工教育訓練費為 10,000元，員工旅遊補助 20,000 元，員工膳食費 30,000 元，租金 60,000 元，稅金 142,650 元，設備折舊費用 115,000元，水電瓦斯費用 162,400 元，清潔劑等用品費用 33,490 元，則 A 大學餐廳 4 月份的營業利潤為何？

    1. (A) 343,400 元
    2. (B) 282,840 元
    3. (C) 228,240 元
    4. (D) 217,680 元

    正解：(C)

  32. 32承上題，A 大學餐廳 4 月份的食材成本、人事成本、其他營運費用及營業利潤各占銷售營業額的百分比為何？

    1. (A) 35％、40％、15％、10％
    2. (B) 38％、36％、18％、8％
    3. (C) 36％、38％、12％、14％
    4. (D) 40％、36％、14％、10％

    正解：(B)

  33. 33發生食物中毒事件，除了消化系統外，最常見的問題是：

    1. (A) 代謝系統
    2. (B) 感官系統
    3. (C) 排泄系統
    4. (D) 神經系統

    正解：(D)

  34. 34油性塗料、酚樹脂塗料、乙烯樹脂塗料及環氧樹脂塗料常用為下列何種食品容器的塗料？

    1. (A) 紙器餐具
    2. (B) 不鏽鋼餐具
    3. (C) 美奈皿餐具
    4. (D) 瓷器餐具

    正解：(A)

  35. 35調理場中，食品及移動性器具至少應離地面幾公分以上？

    1. (A) 15
    2. (B) 30
    3. (C) 45
    4. (D) 60

    正解：(B)

  36. 36廚房內空氣中二氧化碳含量應為多少？

    1. (A) 0.01％以下
    2. (B) 0.15％以下
    3. (C) 0.30％以下
    4. (D) 0.50％以下

    正解：(B)

  37. 37防治病媒蚊蟲進入廚房餐廳中，較不理想的方法是：

    1. (A) 每天噴灑殺蟲劑於廚房中
    2. (B) 請專家（Pest Control Operator; PCO）協助
    3. (C) 有效管理垃圾與廢棄物
    4. (D) 裝置捕殺蚊蟲器材

    正解：(A)

  38. 38餐飲業加熱保溫食品不得低於攝氏幾度？

    1. (A) 50
    2. (B) 65
    3. (C) 80
    4. (D) 85

    正解：(B)

  39. 39依據「學校餐廳廚房員生消費合作社衛生管理辦法」之規定，下列敘述何者正確？

    1. (A) 餐廳是指各級學校教職員工、學生依合作社法成立製作食品之法人組織
    2. (B) 學校的餐飲衛生督導人員必須是領有營養師執業執照 3 年以上的資格
    3. (C) 學校採盒餐供應者保留的樣本至少兩份，冷凍保存 48 小時以備查驗
    4. (D) 學校食品製作用的刀具及砧板須以明顯顏色做為區分

    正解：(D)

  40. 40選購加工肉品的正確知識為：

    1. (A) 添加物中不能含有抗壞血酸鹽
    2. (B) 香腸中添加亞硝酸鹽是為了抑制沙門氏桿菌的生長
    3. (C) 火腿或臘肉添加了亞硝酸鹽，正常狀況是會呈現紅褐色並且出油
    4. (D) 市售的白玉香腸是不添加硝的生鮮香腸，務必要以冷凍狀態保存

    正解：(D)
