營養師　115 年第一次 營養學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1人體攝入富含蛋白質的食物後，主要是由那個器官開始消化蛋白質？

    1. (A) 口腔
    2. (B) 胃
    3. (C) 腸道
    4. (D) 肝臟

    正解：(B)

  2. 2下列何者含有反式脂肪酸？

    1. (A) 葵花油
    2. (B) 牛油
    3. (C) 豬油
    4. (D) 花生油

    正解：(B)

  3. 3成年人每日基礎代謝率（BMR）約1,200大卡， 約相當於5,000 kJ。ATP水解產生的能量約50kJ/mol，ATP的分子量是551 g/mol。估計每天基礎代謝率需要的ATP總量，下列那一個數值最不合理？

    1. (A) 約100莫耳（mol/day）
    2. (B) 約55公克（g/day）
    3. (C) 約5,000 千焦（kJ/day）
    4. (D) 約55公斤（kg/day）

    正解：(B)

  4. 4下列營養素之組合，何者降低高同半胱胺酸血症之效果最佳？

    1. (A) 維生素B 1、維生素B 2、維生素B 3
    2. (B) 維生素E、維生素C、生物素
    3. (C) 維生素B 12、葉酸、維生素B 6
    4. (D) 泛酸、卵磷脂、維生素K

    正解：(C)

  5. 5下列何者為人體皮膚可用來合成維生素D 3的原料？

    1. (A) 7-oxycholesterol
    2. (B) 7-dehydrocholesterol
    3. (C) ergosterol
    4. (D) cholecalciferol

    正解：(B)

  6. 6低鹽飲食的病人，尿中的氯會與何種礦物質同時降低？

    1. (A) 鈣
    2. (B) 磷
    3. (C) 鉀
    4. (D) 鈉

    正解：(D)

  7. 7根據最新版「國人膳食營養素參考攝取量」，哺乳期婦女相較懷孕第三期婦女不需要額外增加下列那些營養素的攝取？①蛋白質 ②葉酸 ③維生素E ④維生素B 12 ⑤鋅 ⑥鐵

    1. (A) ①②③
    2. (B) ②⑤⑥
    3. (C) ③④⑥
    4. (D) ①④⑤

    正解：(B)

  8. 8下列何者不是造成老年人食量減少的主要原因？

    1. (A) 神經內分泌的變化
    2. (B) 服用藥物造成味覺和嗅覺改變
    3. (C) 憂鬱
    4. (D) 運動量增加

    正解：(D)

  9. 9有關乙醇對維生素A代謝的影響，下列何者最適當？

    1. (A) 會抑制肝臟對視黃醇的氧化
    2. (B) 以競爭性抑制視黃醇轉換
    3. (C) 在小腸促進視黃醇去氫酶的活性
    4. (D) 提高視黃醇轉換為視黃醛的速率

    正解：(B)

  10. 10下列何種營養素的耗盡不是運動造成疲勞的主要原因？

    1. (A) 蛋白質
    2. (B) 碳水化合物
    3. (C) 水分
    4. (D) 電解質

    正解：(A)

  11. 11有關憩室炎患者急性期的飲食調整，下列何者最適當？

    1. (A) 多補充蔬果
    2. (B) 多選擇全穀
    3. (C) 多選擇豆類
    4. (D) 多補充水分

    正解：(D)

  12. 12下列何者的熱量較高且較難消化？

    1. (A) 米粉不含湯半碗
    2. (B) 小湯圓20粒
    3. (C) 蘿蔔糕50克
    4. (D) 年糕30克

    正解：(B)

  13. 13有關海藻糖的敘述，下列何者正確？

    1. (A) 可分解為葡萄糖和果糖
    2. (B) 在小腸由海藻糖酶分解
    3. (C) 與蔗糖甜度相同
    4. (D) 不會被吸收代謝，故無熱量

    正解：(B)

  14. 14測量鮮奶的升糖指數（GI）時，應攝取幾杯鮮奶？（四捨五入至整數）

    1. (A) 1杯
    2. (B) 2杯
    3. (C) 3杯
    4. (D) 4杯

    正解：(D)

  15. 15Leucine脫胺作用（deamination）後的碳骨架（carbon skeleton）無法形成下列何種物質？

    1. (A) cholesterol
    2. (B) fatty acid
    3. (C) glucose
    4. (D) ketones

    正解：(C)

  16. 16下列何種情況是「負氮平衡」狀態？

    1. (A) 胰島素分泌增加時

    3. (C) 健身練重訓的過程
    4. (D) 疾病復原期

  17. 17下列何者為hyperphagia的意思？

    1. (A) over-eating
    2. (B) increased cell number
    3. (C) increased cell size
    4. (D) difficulty swallowing

    正解：(A)

  18. 18Harris-Benedict equations可以用於預測下列何者？

    1. (A) resting metabolic rate（RMR）
    2. (B) ideal body weight
    3. (C) osteoporosis
    4. (D) atherosclerosis

    正解：(A)

  19. 19總能量之消耗是由不同physical activity level（PAL）乘上何者估計而得？

    1. (A) resting metabolic rate

    4. (D) thermic effect of food

    正解：(A)

  21. 21下列何者的滲透壓感測器（osmoreceptors）會偵測到體內滲透壓的升高，促使抗利尿激素分泌以保留水分？

    1. (A) hypothalamus
    2. (B) hippocampus
    3. (C) pituitary gland
    4. (D) cerebral cortex

    正解：(A)

  22. 22關於鉀離子的排泄，下列何者正確？

    1. (A) 鉀主要經由糞便排出，尿液中排泄量較少
    2. (B) 腎臟遠端小管和集尿管能依身體需求排出或再吸收鉀離子
    3. (C) 鉀離子排泄量與體內鉀攝取量無關
    4. (D) 酸中毒（acidosis）會促進鉀離子的排泄

    正解：(B)

  23. 23有關膳食鐵的吸收，下列何者正確？

    1. (A) 鐵在小腸刷狀緣的吸收是藉由簡單擴散和主動運輸
    2. (B) 長期服用制酸劑者會降低血基質鐵（heme iron）的吸收
    3. (C) 飲食中的植酸或草酸較不影響血基質鐵（heme iron）的吸收
    4. (D) 同時攝取深綠色蔬菜和全穀類有利於鐵的吸收

    正解：(C)

  24. 24教育部訂定的「學校午餐食物內容及營養基準」中，高中男生午餐的食物內容目標值，下列何者錯誤？
