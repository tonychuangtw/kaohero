  1. 1甲君擬購買相鄰兩塊土地合併建築，請問在此目的下所評估出的價值，以貨幣金額表示者，稱為：

    1. (A) 正常價格
    2. (B) 限定價格
    3. (C) 特定價格
    4. (D) 特殊價格

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 限定價格包括「以不動產合併為目的」所形成的價值；甲合併相鄰兩地後可整體建築、提高效用，只對甲這個特定買方成立，屬限定價格。

    ❌ (A) 正常價格是一般市場上、無特殊動機的雙方所形成的合理價值，不考慮合併帶來的增值。

    ❌ (C) 特定價格是具有市場性的不動產在「特定條件」下形成的價值，合併目的另歸限定價格。

    ❌ (D) 特殊價格是針對不具市場性的不動產（如宗教建築、古蹟）所估的價值。

    📚 出處：不動產估價技術規則第2條：價格種類（限定價格之合併目的）

  2. 2有一筆建地面積 1,000 坪，預期興建為住宅大樓後的總銷售金額為 3.8 億元，若營建施工費為 1億元，管理銷售及規劃設計等費用為 1,100 萬元，合理利潤率為 16%，資本利息綜合利率為 2%，請問該筆建地每坪單價約為：

    1. (A) 210 萬元
    2. (B) 420 萬元
    3. (C) 21 萬元
    4. (D) 42 萬元

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 土地開發分析法：V＝S÷(1＋R)÷(1＋i)－(C＋M)。38,000萬÷1.16÷1.02≈32,116萬；扣除營建費10,000萬與管銷規劃費1,100萬，得土地總價約21,016萬元，÷1,000坪≈21萬元／坪。

    ❌ (A) 210萬元是小數點錯位（以100坪計算）的結果。

    ❌ (B) 420萬元與正確計算差距過大，未依公式扣除利潤、利息與成本。

    ❌ (D) 42萬元約為正確值兩倍，計算有誤。

    📚 出處：不動產估價技術規則：土地開發分析法計算公式

  3. 3不動產面臨道路之寬度，此屬於影響不動產價格之何種因素？

    1. (A) 個別因素
    2. (B) 區域因素
    3. (C) 一般因素
    4. (D) 特別因素

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 個別因素指不動產本身條件所造成的價格差異，臨路寬度、面積、形狀、深度等屬之，同一區域內不同宗地會因此價格不同。

    ❌ (B) 區域因素是影響整個近鄰地區價格水準的因素，如交通、公共設施、商圈。

    ❌ (C) 一般因素是影響全面性不動產價格的社會、經濟、行政因素，如利率、稅制。

    ❌ (D) 估價規則上的價格影響因素分為一般、區域、個別三類，沒有「特別因素」。

    📚 出處：不動產估價技術規則第2條：個別因素、區域因素、一般因素之定義

    1. (A) 建物價格日期當時價值未來每年折舊提存率，得依下列方式計算：等速折舊型：d = ；(1 + i ) n − 1(1 − s ) / N償債基金型： d =1 − (1 − s ) n / Ni
    2. (B) 建物折舊提存費，得依下列方式計算：等速折舊型： C × (1 − s ) × ；償債基金型：(1 + i ) n − 1C × (1 − s ) ×N
    3. (C) 不動產構成項目中，於耐用年數內需重置部分之重置提撥費，按其利息及按該支出之有效使用年期及耗損比率分年攤提
