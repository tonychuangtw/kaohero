(D) อ่อนเพลีย หงุดหงิดอยู่อย่างปลอดภัยเมือเจอแผ่นดินไหวทุกปี ในไต้หวันจะมีการเกิดแผ่นดินไหวและในแต่ละปี จํานวนครังในการเกิดก็มีมากน้อยต่างกันไป อีกทังยังไม่สามารถพยากรณ์ล่วงหน้าได้ เหมือนเช่นสภาพอากาศ แต่การเกิดแผ่นดินไหวในไต้หวันสร้างความเสียหายไม่มากนัก อาจจะรู ้สึกโคลงเคลงเล็กน้อยเมืออยู่บนทีสูงเพราะอาคารบ้านเรือนของทีนี ได้รับการออกแบบโดยคํานวณเผือเหตุการณ์เหล่านี ไว้แล้วเมือพบเจอกับเหตุการณ์แผ่นดินไหวสิงแรกทีควรทําคือ อย่าตืนตระหนก ตังสติให้ดี ถ้าอยู่ภายในอาคารห้ามใช้ลิฟต์เด็ดขาด ให้ยืนชิดกําแพงทีมีคานคําหรือหลบอยู่ใต้เฟอร์นิเจอร์ทีแข็งแรง เช่นโต๊ะ ถ้าอยู่ภายนอกอาคารให้พยายามหลีกเลียงการอยู่ใกล้พืนทีอาคารและสิงก่อสร้างทีอาจจะล้มหรือร่วงหล่นลงมาได้ ส่วนใหญ่แผ่นดินไหวจะเกิดไม่นาน ๒-๓ นาทีก็ผ่านไปแล้ว

    正解：(A)

  76. 76จากบทความนี เหตุการณ์ใดทีมักจะเกิดขึนทุกปี

    1. (A) พายุไต้ฝ่ ุน
    2. (B) โรคระบาด
    3. (C) แผ่นดินไหว
    4. (D) การประท้วง

    正解：(C)

  77. 77จากบทความนี การพยากรณ์ล่วงหน้าสามารถใช้ได้กับเรืองใด

    1. (A) พายุไต้ฝ่ ุน
    2. (B) โรคระบาด
    3. (C) แผ่นดินไหว
    4. (D) การประท้วง

    正解：(A)

  78. 78หากเกิดแผ่นดินไหวขณะทีตัวคุณอยู่ในอาคารสิงใดทีไม่ควรทํามากทีสุด

    1. (A) หลบใต้โต๊ะ
    2. (B) หลบใต้คาน
    3. (C) หายใจเข้าออกลึกๆ ช้าๆ
    4. (D) วิงไปลงลิฟต์เพือลงจากอาคารให้เร็วทีสุด

    正解：(D)

  79. 79หากเกิดแผ่นดินไหวขณะทีตัวคุณอยู่ภายนอกอาคารสิงใดทีควรทํามากทีสุด

    1. (A) รีบเดินออกห่างจากตัวอาคาร
    2. (B) รีบเดินเข้าไปหาทีกําบังในอาคาร
    3. (C) กรีดร้องให้คนช่วย
    4. (D) ห้ามขยับเขยือนอย่างเด็ดขาด

    正解：(A)

  80. 80จากบทความนี ข้อใดกล่าวถูกต้องเกียวกับแผ่นดินไหวในไต้หวัน

    1. (A) นานๆ จะเกิดสักครังแต่จะรุนแรงมาก
    2. (B) ทางการจะแจ้งให้ทราบล่วงหน้าเพือหยุดงานและหยุดเรียน
    3. (C) บ้านเรือนทีนี มีการออกแบบเพือรองรับเหตุการณ์นี
    4. (D) แต่ละครังทีเกิดจะมีการสันสะเทือนเป็ นเวลานาน

    正解：(C)
