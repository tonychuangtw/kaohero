醫事檢驗師　110 年第二次 臨床生理學與病理學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列心電圖最可能診斷為何種心臟疾病？

    1. (A) 心房早期收縮（premature atrial contraction）
    2. (B) 心室早期收縮（premature ventricular contraction）
    3. (C) 心室顫動 （ventricular fibrillation）
    4. (D) 心房顫動 （atrial fibrillation）

    正解：(D)

  2. 2心電圖記錄顯示導程I, II 有許多雜訊，但導程III則為正常。連結發生異常的電極最可能位於：

    1. (A) 右臂
    2. (B) 左臂
    3. (C) 右腿
    4. (D) 左腿

    正解：(A)

  3. 3心臟的傳導系統中，下列何者的傳導速度比左束支（left bundle branch）慢？

    1. (A) 希氏束（bundle of His）
    2. (B) 房室結（atrioventricular node, AV node）
    3. (C) 右束支（right bundle branch）
    4. (D) 蒲金氏纖維（Purkinje fiber）

    正解：(B)

  4. 4心電圖PR區間（PR interval）大於0.20秒時，最可能的診斷為何？

    1. (A) 第一度房室傳導阻斷
    2. (B) 第二度房室傳導阻斷
    3. (C) 完全房室傳導阻斷
    4. (D) 伍爾夫－巴金森－懷特症候群（Wolff–Parkinson–White syndrome）

    正解：(A)

  5. 5當病患胸痛合併冒冷汗，心電圖顯示胸前導程V1、V2、V3的ST segment上升時，最可能表示那一條冠狀動脈發生急性阻塞？

    1. (A) 左前降支
    2. (B) 左迴旋支
    3. (C) 右前降支
    4. (D) 右冠狀動脈

    正解：(A)

  6. 6下列何者為急性心包膜炎最可能的心電圖變化？

    1. (A) 廣泛性ST segment下降
    2. (B) 廣泛性ST segment上升
    3. (C) 局部性ST segment下降
    4. (D) 局部性ST segment上升

    正解：(B)

  7. 7下列何者是最典型陳舊型心肌梗塞心電圖特徵？

    2. (B) ST segment 下降
    3. (C) QT 區間延長
    4. (D) 出現Q波

    1. (A) 1.2
    2. (B) 1.5
    3. (C) 1.8
    4. (D) 2.0

    2. (B) 40～90
    3. (C) -40～-5
    4. (D) 5～40

  10. 10此張心電圖的診斷下列何者最恰當？

  20. 20有關人體酸鹼之緩衝系統作用過程，下列何者正確？

    1. (A) 碳酸酐酶（carbonic anhydrase）可在腎小管及紅血球把二氧化碳及水合成碳酸，之後再分解成重碳酸離子
    2. (B) 重碳酸離子會由細胞移出至血漿，同時有鉀離子移入細胞以求電化學平衡
    3. (C) 重碳酸離子可由肺部直接吐出，而二氧化碳由腎小管排出以調節體內酸鹼度
    4. (D) 酸鹼若達到恆定時，正常人的pH值約為7.25～7.30

    正解：(A)

  21. 21有關血液氣體分析時血液採檢及送驗過程如何影響分析結果，下列敘述何者正確？

    1. (A) 血液氣體分析之採血管須加入肝素（heparin），一般抽2～3 mL的血加10～15 mg肝素
    2. (B) 採血管若加入太多肝素（heparin），可能會使 上升12～25%

    4. (D) 採血管在37℃下存放時，血液中 每小時減少30～40 mmHg

    正解：(C)
