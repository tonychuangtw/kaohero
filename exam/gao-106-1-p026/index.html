  1. 1下列何者為視訊壓縮之標準？

    1. (A) MIDI
    2. (B) JPEG
    3. (C) MPEG
    4. (D) TIFF

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) MPEG 是動態影像專家群制定的視訊與音訊壓縮標準。

    ❌ (A) MIDI 為電子樂器數位介面，記錄演奏指令而非影音波形。

    ❌ (B) JPEG 是靜態影像的壓縮標準。

    ❌ (D) TIFF 為靜態影像的檔案格式。

    📚 出處：計算機概論－多媒體壓縮標準。

  2. 2透過美國標準資訊交換碼（American Standard Code for Information Interchange，ASCII）來儲存"National"字串，需要多少個位元組（bytes）？

    1. (A) 8
    2. (B) 16
    3. (C) 32
    4. (D) 64

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) ASCII 每個字元占 1 個位元組，字串 National 共 8 個字元，故需 8 個位元組。

    ❌ (B) 16 是誤以每字元 2 個位元組計算。

    ❌ (C) 32 與字串長度不符。

    ❌ (D) 64 是字串的位元數而非位元組數。

    📚 出處：計算機概論－字元編碼。

  3. 3若將十六進位數字 270716 轉換十進位，應為下列何者？

    1. (A) 1479
    2. (B) 9991
    3. (C) 23407
    4. (D) 10011100000111

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 2707 十六進位 = 2×4096 + 7×256 + 0×16 + 7 = 8192 + 1792 + 7 = 9991。

    ❌ (A) 1479 與各位權值計算不符。

    ❌ (C) 23407 高估甚多。

    ❌ (D) 該值為二進位表示法，非十進位數值。

    📚 出處：計算機概論－數字系統轉換。
