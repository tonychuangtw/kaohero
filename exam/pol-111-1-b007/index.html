警察特考　111 年 三等考試 警察法規　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1警察任務為依法維持公共秩序，保護社會安全，防止一切危害，促進人民福利。下列敘述何者正確？

    1. (A) 偵查人口販運事件時，應遵守刑事訴訟法之規定
    2. (B) 就戶口查察之執行，應依行政執行法規定行之
    3. (C) 刑事警察受檢察官之命執行職務時，如有廢弛職務情事，檢察官得逕予懲處
    4. (D) 警察人員可逕至海巡機關管轄區內依法執行搜索、逮捕、扣押、拘提，無需知會當地海巡機構

    正解：(A)

  2. 2有關警察職務內容之敘述，下列何者錯誤？

    1. (A) 警察依法協助偵查犯罪，係應檢察機關請求而為之，亦適用行政程序法職務協助規定
    2. (B) 森林法第 32 條後段規定「未設森林警察者，應由當地警察代行森林警察職務。」所謂代行，係依法規將權限一部分委託不相隸屬行政機關執行之行政委託；故應將此代行事項及其法規依據公告之，並刊登政府公報或新聞紙
    3. (C) 縣政府工務局執行違章建築拆除時，如有遭遇抗拒之虞，可依行政執行法第 6 條請求警察機關協助其執行
    4. (D) 參與地方政府公共安全聯合稽查小組之警察人員，於執行取締違規休閒娛樂服務業聯合稽查時，應著制服或出示證件表明身分，就涉及賭博、色情等業務違規行為，可逕依社會秩序維護法或刑法等規定取締查處50740-5094051140、51340-51440

    正解：(A)

  3. 3關於直轄市政府警察組織之敘述，下列何者正確？

    1. (A) 直轄市政府警察局為二級地方行政機關
    2. (B) 直轄市政府警察局長係比照簡任 13 職等職務，由直轄市長任免之
    3. (C) 直轄市警察機關之員額編制，應符合內政部警政署所定警察機關員額設置參酌基準
    4. (D) 直轄市政府警察局組織規程，由直轄市政府定之

    正解：(D)

  4. 4下列何者為行使警察法第 9 條警察權限之警察人員？

    1. (A) 法務部行政執行署執行拘提、管收之行政執行人員
    2. (B) 內政部移民署依入出國及移民法規定實施暫時收容之執行人員
    3. (C) 具有刑事訴訟法第 230 條及第 231 條司法警察官或司法警察身分之憲兵
    4. (D) 依替代役實施條例執行特定警察勤務之服警察替代役人員

    本題經考選部公告不計分。

  5. 5依照現行法令規定，有關警察人員退休與撫卹之敘述，下列何者錯誤？

    1. (A) 警察人員之退休與撫卹，除警察人員人事條例外，亦適用公務人員退休撫卹法
    2. (B) 警正以下擔任具有危險及勞力等特殊性質職務者，其退休年齡，得依照公務人員退休法之規定酌予降低
    3. (C) 警察人員在執行勤務中，遭受暴力或意外危害，致全失能、半失能或在執行勤務中殉職者，其子女應給與教養至成年。如已成年仍在學者，繼續教養至其取得學位畢業為止
    4. (D) 警察人員曾領有勳章、獎章者，於退休時可加發退休金；如於執行勤務中殉職，亦可加發撫卹金

    正解：(A)

  6. 6下列何者非警察人員依法應遵守之義務？

    1. (A) 派出所基層警員對於所轄分局長所為加強酒駕取締之命令
    2. (B) 刑事警察對於當地法院檢察官之指揮監督
    3. (C) 保安警察第四總隊員警奉派前往臺北市執行集會、遊行秩序維持勤務時，應受臺北市長之指揮、監督
    4. (D) 經直屬長官口頭指示，協助特定人民團體借用閒置廳舍辦理競選募款餐會

    正解：(D)

  7. 7警察人員從事下列行為，何者不違反公務人員行政中立法規定？

    1. (A) 於上班時穿戴標示特定公職候選人之徽章
    2. (B) 參與公民投票提案之連署
    3. (C) 以公務電子信箱轉寄反對特定政黨資訊
    4. (D) 於選舉委員會發布選舉公告日起至投票日止之選舉期間，秉持公正、公平之立場，允許公職候選人或其支持者前來該機關之造訪活動

    正解：(B)

  8. 8警察人員不得假借職務上之權勢，庇護竊盜、贓物、性交易、賭博。下列敘述何者錯誤？

    1. (A) 有具體事實，嚴重影響警譽時，遴任機關或其授權機關、學校應予免職
    2. (B) 免職處分尚未確定前，仍應先行予以停職
    3. (C) 對於停職處分不服者，應向內政部警政署提起訴願
    4. (D) 對於免職處分不服者，應向公務人員保障暨培訓委員會提起復審

    正解：(C)

  9. 9有關警察依法實施臨檢之敘述，下列何者錯誤？

    1. (A) 防止犯罪、或處理重大公共安全或社會秩序事件之必要，得由分局長指定特定路段，進行車輛攔停並查證駕駛人或乘客之身分
    2. (B) 外國人未能出示外僑居留證者，應立即帶往勤務處所查證其身分，但對其留置，不得逾 3 小時
    3. (C) 凌晨發現未開車燈且車速忽快忽慢之車輛，得予以攔停，並檢查引擎、車身號碼或其他足資識別之特徵
    4. (D) 人民拒絕接受實施查證身分並已有自傷行為時，得對之使用警銬

    正解：(B)

  10. 10警察依法查證人民身分時，下列敘述何者錯誤？

    1. (A) 如發現相對人冒用他人身分證明文件時，可依社會秩序維護法第 66 條規定，處 3 日以下拘留或新臺幣 1 萬 8 千元以下罰鍰
    2. (B) 得命相對人提出身分證明文件，並詢問其真實姓名、出生年月日、出生地、國籍、住居所、身分證統一編號、職業、工作場所或手機號碼等
    3. (C) 相對人雖未攜帶國民身分證，亦可請其出示全民健康保險卡或駕駛執照等附有個人頭像照片之身分證明文件
    4. (D) 相對人不願陳述真實姓名亦不提出身分證明文件並有企圖逃逸行為，致顯然已無法查證其身分時，即可實施強制力將其帶往鄰近派出所查證之50740-5094051140、51340-51440

    正解：(B)

  11. 11依警察職權行使法第 9 條規定，警察可使用攝影、錄音或以其他科技工具來蒐集參與者現場活動。下列何者是同條規定所允許之蒐集對象？

    1. (A) 街頭賣藝等群聚活動
    2. (B) 臺北市捷運地下街某商店內數人使用大聲公抗議消費糾紛
    3. (C) 立法委員候選人率多名助選人員聚集在臺北市 101 大樓廣場前散發傳單
    4. (D) 為迎接大甲鎮瀾宮媽祖活動而在十字路口多方人馬對峙並產生肢體衝突時，圍觀信徒及路過行人

    正解：(D)

  12. 12室外集會遊行參與者行為恐對公共安全或秩序有危害之虞時，警察依法所可採取之資料蒐集手段，不包括下列何者？

    1. (A) 對於集會遊行參與者於集會遊行期間所為網路線上直播，進行側錄
    2. (B) 就集會遊行期間集會遊行參與者所有活動，施予全程錄音
    3. (C) 於集會遊行開始之際，在集會遊行場所明顯處架設監視攝影機
    4. (D) 逕請電信業者提供參與者在集會遊行開始前曾經使用通訊軟體之對話紀錄

    正解：(D)

  13. 13依現行法規定，有關集會遊行之敘述，下列何者正確？

    1. (A) 擬於立法院大門前道路舉辦室外集會之申請，應於 6 日前向臺北市政府警察局提出
    2. (B) 大甲媽祖遶境遊行活動屬於大型室外群眾集會，依法須申請集會遊行許可
    3. (C) 數百名群眾聚集在國際機場入境大廳並有使用大聲公煽惑群眾圍堵出入口情形時，應立即採取人牆隔離群眾，維持公共秩序，但於施予制止或命令解散未果後，方可強制驅離
    4. (D) 對於臺北市政府警察局所為遊行許可所核定遊行路線限制有所不服時，應於收受通知書之日起6 日內以書面附具理由提出經臺北市政府警察局向內政部警政署提出訴願

    正解：(C)

  14. 14警察職權行使法第 14 條規定，警察得通知特定人於指定時間到指定場所進行調查或執行鑑識措施。下列敘述何者錯誤？

    1. (A) 本條之通知到場，僅係觀念通知性質之事實行為，並非具有下命性質之行政處分
    2. (B) 可採取電話、手機簡訊等方式敘明事由通知之，不限於書函通知
    3. (C) 依本條執行之鑑識措施，例如量身高體重、照相、採取指紋或掌紋等，但不包括採集尿液或毛髮等行為
    4. (D) 經依本條通知到場而無正當理由拒不到場者，可依行政執行法科處怠金

    正解：(D)

  15. 15社會秩序維護法第 42 條規定，對於現行違反本法之行為人，警察人員得即時制止其行為，並得逕行通知到場；其不服通知者，得強制其到場。下列敘述何者錯誤？

    1. (A) 違反本法之行為人正有攻擊、毀損行為時，警察役役男得使用警棍即時制止其行為
    2. (B) 警察人員已確悉其姓名、住所或居所而無逃亡之虞者，即得不強制其到場
    3. (C) 經依本條通知到場而無正當理由拒不到場者，應報請檢察官簽發拘提，以強制其到場
    4. (D) 經合法通知仍無正當理由不到場者，警察人員可逕依本法裁處之

    正解：(C)

  16. 16有關行政執行法及社會秩序維護法之執行程序，下列敘述何者錯誤？

    1. (A) 行政執行，除法律另有規定外，不因聲明異議而停止執行
    2. (B) 義務人得於執行程序終結前聲明異議，執行機關認其無理由者，送直接上級主管機關於 30 日內決定之，其直接上級主管機關為法務部
    3. (C) 社會秩序維護法處罰之執行，由警察機關為之。罰鍰逾期未完納者，由警察機關依法移送行政執行
    4. (D) 裁定停止營業或勒令歇業確定之案件，警察機關應於確定後即以執行通知單，命被處罰人於通知送達之翌日起，停止或歇閉其營業

    正解：(B)

  17. 17警察人員執行職務時依法得使用警械。下列敘述何者錯誤？

    1. (A) 為避免非常變故，維持社會治安，警察於必要時得併使用警銬、瓦斯槍或警棍
    2. (B) 警察機關配備警械種類及規格表之訂定，係針對警械使用之細節性及技術性事項所為之行政規則
    3. (C) 服務於臺北市中正一分局警察役役男在執行集會、遊行勤務時，擅自使用未經警察機關配發瓦斯槍致使參與遊行群眾及路人受傷時，依法應由臺北市政府對於受傷民眾支付醫療費、慰撫金、補償金或喪葬費
    4. (D) 當警察違法使用警械致人民受有財產損失時，受害人民經與賠償義務機關進行協議不成後，依法應向普通法院提起國家賠償訴訟50740-5094051140、51340-51440

    正解：(B)

  18. 18針對行政執行行為之救濟，下列敘述何者正確？

    1. (A) 義務人或利害關係人對執行命令、執行方法等情事，得於執行程序終結前，向執行機關申訴
    2. (B) 行政執行，除法律另有規定外，不因聲明異議而停止執行
    3. (C) 行政執行行為之救濟，在法律程序上為司法審查
    4. (D) 針對救濟，執行機關認其有理由者，應即移送上級機關審議

    正解：(B)

  19. 19有關警械之使用，下列敘述何者正確？

    1. (A) 有關警械之種類及規格，由內政部定之
    2. (B) 警察人員執行職務時，為避免非常變故，維持社會治安時，僅能使用警棍，不能使用槍械
    3. (C) 警械非經內政部或其授權之警察機關許可，不得定製、售賣或持有，違者由警察機關沒入
    4. (D) 警察人員使用警棍指揮後，應將經過情形，即時報告該管長官

    正解：(C)

  20. 20依據警察職權行使法，有關身分查證之規定，下列敘述何者錯誤？

    1. (A) 警察進入公眾得出入之場所，應於營業時間為之，並不得任意妨礙其營業
    2. (B) 警察於公共場所或合法進入之場所，得對於合理懷疑其有犯罪之嫌疑或有犯罪之虞者，查證其身分
    3. (C) 警察依規定查證人民身分，得採取攔停人、車、船及其他交通工具
    4. (D) 警察攔停車輛，交通工具之駕駛人或乘客有異常舉動而合理懷疑其將有危害行為時，不得強制其離車

    正解：(D)

  21. 21行為人違反社會秩序維護法相關處罰規定，下列敘述何者錯誤？

    1. (A) 違反本法行為，不問出於故意或過失，均應處罰。但出於過失者，不得罰以拘留，並得減輕之
    2. (B) 二人以上，共同實施違反本法之行為者，分別處罰。其利用他人實施者，依其所利用之行為處罰之
    3. (C) 違反本法之行為未遂者，得減輕處罰
    4. (D) 幫助他人實施違反本法之行為者，得減輕處罰

    正解：(C)

  22. 22為了保障人民集會、遊行之自由，維持社會秩序，下列敘述何者錯誤？

    1. (A) 經許可集會、遊行之負責人或代理人對於集會處所、遊行路線於使用後遺有廢棄物或污染者，未清理者應處罰鍰
    2. (B) 集會、遊行經該管主管機關命令解散而不解散者，處集會、遊行負責人罰鍰
    3. (C) 集會、遊行經該管主管機關命令解散而不解散，仍繼續舉行者，首謀者處二年以下有期徒刑或拘役
    4. (D) 參加集會、遊行人員攜帶木棍、竹棒等物品，經現場執勤員警認定足以危害他人生命、身體、自由，不問屬於何人所有，均得扣留並依法處理

    正解：(C)

  23. 23有關警察預防他人生命、身體之危險，執行管束時，下列敘述何者正確？

    1. (A) 警察對於民眾實施管束，應於危險或危害結束時經報告長官後，終止管束，管束時間最長不得逾 24 小時
    2. (B) 警察對人民實施查證身分或其他詢問，得依管束之規定，令其供述
    3. (C) 考量警察人員之安全與民眾權益，所為必要之管束時，僅得檢查受管束人之身體
    4. (D) 警察依法實施管束時，遇有攻擊、毀損行為之虞時，於必要時，得對其使用警銬

    正解：(D)

  24. 24有關民眾申請集會、遊行及依司法院釋字第 718 號解釋意旨，下列敘述何者正確？

    1. (A) 因特殊原因未經召集而自發聚集，且無發起人或負責人之偶發性集會，無須申請許可
    2. (B) 遊行跨越二個以上警察局轄區者之集會、遊行，應向內政部警政署申請許可
    3. (C) 申請室外集會、遊行，如合理懷疑有危害國家安全、社會秩序或公共利益者，得為不予許可
    4. (D) 室外集會、遊行，應由負責人填具申請書及檢具集會處所、遊行路線之所有人或管理人之同意文件，於 6 日前向主管機關申請許可

    正解：(A)

  25. 25有關行政執行法，下列敘述何者錯誤？

    1. (A) 人民因執行機關依法實施即時強制，致其生命、身體或財產遭受特別損失時，得請求補償
    2. (B) 損失補償，應以金錢為之，並以補償實際所受之特別損失為限
    3. (C) 對於執行機關所為損失補償之決定不服者，得依法提起民事訴訟
    4. (D) 損失補償，應於知有損失後，二年內向執行機關請求之。但自損失發生後，經過五年者，不得為之

    正解：(C)
