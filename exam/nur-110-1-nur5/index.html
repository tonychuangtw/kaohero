護理師　110 年第一次 精神科與社區衛生護理學　考古題與詳解

  1. 1依據現行精神衛生法，基於對精神病人的保護，經專科醫師診斷或鑑定，屬嚴重病人者，應置保護人一人。專科醫師應開具診斷證明書交付保護人，此保護人應考量嚴重病人利益。依條文敘述保護人可為：①監護人 ②法定代理人 ③同居人 ④配偶 ⑤父母 ⑥家屬 ⑦心理師

    1. (A) ①③④⑤⑦
    2. (B) ①②③⑤⑥
    3. (C) ①②④⑤⑥
    4. (D) ②③④⑥⑦

    正解：(C)

  2. 2當病人服用下列何種藥物時，護理師需教導病人有關體重增加之副作用？

    1. (A) Alprazolam（Xanax）
    2. (B) Propranolol（Inderal）
    3. (C) Olanzapine（Zyprexa）
    4. (D) Venlafaxine（Efexor）

    正解：(C)

  3. 3黃先生，55 歲，被診斷為思覺失調症，與案母同住，服藥不規則，須由案母提醒他吃藥。一個月前，案母因病過世，黃先生認為鄰居透過社區的 LINE 群組說他的壞話，因此作勢要攻擊鄰居。黃先生最可能有以下何種症狀？

    1. (A) 關係妄想（delusion of reference）
    2. (B) 誇大妄想（delusion of grandeur）
    3. (C) 虛無妄想（nihilistic delusion）
    4. (D) 嫉妒妄想（delusion of jealousy）

    正解：(A)

  4. 4有關兒童精神疾病的敘述，下列何者正確？

    1. (A) 語言障礙症（language disorders）常在上小學後被發現
    2. (B) 輕度智能不足（mild intellectual disability）常在幼稚園時被發現
    3. (C) 精神疾病的病徵與兒童的年齡、發展階段沒有關係
    4. (D) 侵擾行為、衝動控制及行為規範障礙症（disruptive, impulse control and conduct disorder）是和同儕互動中被發現

    正解：(D)

  5. 5在生物化學研究中，憂鬱症病人最可能缺乏那些神經傳導物質？

    1. (A) 多巴胺（dopamine）和甲狀腺素（thyroxine）
    2. (B) γ-胺基丁酸（γ-aminobutyric acid; GABA）和乙醯膽鹼（acetylcholine）
    3. (C) 皮質醇（cortisol）和腎上腺素（epinephrine）
    4. (D) 血清素（serotonin）和正腎上腺素（norepinephrine）

    正解：(D)

  6. 6對有聽幻覺（auditory hallucination）、被害妄想（delusion of persecution）的病人進行溝通時，下列回應何者較適當？

    2. (B) 你說有人要害你，其實這是你的想像
    3. (C) 你說有人害你，可是你還活得好好的
    4. (D) 你這是幻聽、妄想的精神症狀，藥物可以改善

    正解：(A)

  7. 7對憂鬱症的病人進行「人際關係心理治療」，下列敘述何者較適當？

    1. (A) 進行人際關係心理治療時，不需合併藥物治療
    2. (B) 認為憂鬱症病人常見的問題是角色轉換困難、人際糾紛
    3. (C) 人際關係心理治療者主要對憂鬱症病人進行錯誤認知的分析
    4. (D) 治療過程中著重分析憂鬱症病人早期的生活事件頁次：8－2

    正解：(B)

  8. 8病人服用抗精神病藥物，有關錐體外徑副作用（extrapyramidal symptoms; EPS）之敘述，下列何者正確？

    1. (A) 會有體溫升高至 41℃以上，與肌肉僵硬
    2. (B) 出現斜頸、牙關緊閉和舌頭收縮，稱之為遲發性不自主運動
    3. (C) 出現坐立不安、來回走動或原地踏步是出現靜坐不能（akathisia）的現象
    4. (D) 出現鼓嘴、不斷眨眼和做鬼臉，是屬於急性肌肉緊張異常（acute dystonia）的現象

    正解：(C)

  9. 9環境治療應用於急性住院病房之敘述，下列何項較適當？

    1. (A) 提高環境刺激，以照護躁症病人感官增加之需求

    3. (C) 多種感官刺激的環境不適合失智症個案的照護
    4. (D) 運用環境治療設計的原則於「住院生活作息表」及「生活討論會」

    正解：(D)

  10. 10當罹患思覺失調症病人不斷敘述他的妄想內容時，下列何項護理措施較適當？

    1. (A) 引導病人談與妄想內容有關的情緒與感受
    2. (B) 告訴病人不要胡思亂想，症狀就會慢慢不見
    3. (C) 強烈質疑病人的妄想內容，讓病人感到自我矛盾與錯亂
    4. (D) 儘量不要跟病人討論以免加重病情

    正解：(A)

  11. 11廖先生診斷為躁症，入院後常只吃一口飯，就四處去找病友，說要監督別人有無浪費食物，下列何項護理措施較適當？

    2. (B) 為了讓病人好好吃完一頓飯，需安排與其他病人一起在餐廳用餐
    3. (C) 因為病人不容易專心，讓他每天只吃一頓就好
    4. (D) 用靜脈注射營養品來補充熱量，平時隨便他愛吃多少都沒關係

    正解：(A)

  12. 12躁症發作（manic episode）的典型臨床特徵，下列何者較適當？

    3. (C) 自殺意念

  13. 13王先生，在家因覺得有人要害他、跟蹤他而不敢睡覺，故由父親帶來住院，住院後仍覺得周遭的人不懷好意，護理師提供之照護措施，下列何者正確？①同理並接受病人感受 ②主動積極接觸關懷病人 ③評估妄想對病人生活干擾的程度 ④不要與病人爭辯妄想的真實性

    4. (D) ②③④

  14. 14有關妄想症（delusional disorder）的敘述，下列何者正確？

  15. 15牛先生，最近被診斷為憂鬱症，醫師開立服用 sertraline（Zoloft®）藥物治療，有關 Zoloft 之敘述，下列何者正確？①選擇性血清素回收抑制劑（SSRIs） ②血清素－正腎上腺素回收抑制劑（SNRIs）③一般持續服用 2 週以上才有療效出現 ④服藥會有嗜睡、噁心嘔吐等副作用

    2. (B) ①②④
    3. (C) ①③④
    4. (D) ②③④

  16. 16王小姐診斷為妄想症（delusional disorder），認為自己的伙食被下毒，而拒絕食用，下列護理措施何者最適切？

    3. (C) 保證醫院食物沒毒，請病人不必多想
    4. (D) 護理師直接食用以證明食物沒有毒

  17. 17鬱症發作（depressive episode）的典型臨床特徵，下列何者較適當？

    1. (A) 意念飛躍
    2. (B) 自我價值感低
    3. (C) 怕獨處而活動多
    4. (D) 無睡眠障礙頁次：8－3

  18. 18王小姐被診斷為憂鬱症，她最常使用的防衛機轉，下列敘述何者正確？

    2. (B) 內射（introjection）
    3. (C) 否認（denial）
    4. (D) 合理化（rationalization）

  19. 19有關社交焦慮症（social anxiety disorders）之敘述，下列何者較適當？

    1. (A) 病人會反覆的出現突發性的害怕失控或即將發瘋的感受
    2. (B) 因病人對任何的社交情境均會感受到焦慮，故病人的焦慮型態為漂浮型焦慮
    3. (C) 病人會因自覺身處於被觀察的社交情境而引發焦慮
    4. (D) 對於合併有肥胖症的病人而言，社交焦慮症引發的恐懼、焦慮或逃避行為與肥胖症有關

    正解：(C)

  20. 20病人因反覆出現強迫性思考及持續洗手的行為，而入院治療，下列敘述何者較適當？

    1. (A) 病人的強迫性思考內容常為無意義的
    2. (B) 護理目標以直接中止病人的洗手症狀為最優先考量
    3. (C) 洗手行為是病人藉此內射出其內在強迫性思考的手段
    4. (D) 須評估病人自我傷害的可能性，必要時可戴手套洗手

    正解：(D)

  21. 21有關創傷後壓力症（post-traumatic stress disorder; PTSD）病人的治療處置，下列何者較適當？

    1. (A) 若採用藥物治療，治療重點為以鋰鹽來緩解病人情緒症狀
    2. (B) 若採用精神分析治療，治療重點為採用家庭系統學說來說明家庭間病態的溝通
    3. (C) 若採用行為治療，治療重點為以洪水法協助病人逐步控制侵入性的創傷事件影像
    4. (D) 若採用認知治療，治療重點為引導病人修正對創傷事件起因與結果的扭曲認知

    正解：(D)

  22. 22張小姐被診斷為做作型人格障礙症（histrionic personality disorder），護理師應事先了解病人的特性，才能客觀的與病人建立治療性關係，下列何者是張小姐較可能出現的行為？①利用自己身體外觀來吸引他人注意 ②展現快速轉變和膚淺表現的情緒 ③衝動、易怒、具攻擊性 ④常以不適當的性挑逗與他人交往

    1. (A) ①②③
    2. (B) ②③④
    3. (C) ①③④
    4. (D) ①②④

    正解：(D)

  23. 23照顧罹患身體症狀及相關障礙症的病人，須特別評估隨著症狀表現而來的附帶收獲（secondary gain），下列何項描述較適當？

    1. (A) 附帶收獲是指表現出身體症狀便可以直接避免面對心理衝突或壓力
    2. (B) 應儘量不要太關注病人的身體症狀，以避免不當的增強附帶收獲
    3. (C) 以抗精神病（antipsychotics）藥物進行催眠會談，在過程中給予暗示及建議
    4. (D) 鼓勵病人持續關注身體症狀，以關注病人的身體症狀為主要護理措施

    正解：(B)

  24. 24護理師在精神科急性病房照顧王老先生期間，王老先生常表示她就像是自己的女兒一樣，並以「女兒」稱呼護理師。對此狀況之解釋，下列敘述何者較適當？

    4. (D) 這表示病人對護理師極高之評價

    正解：(A)

  25. 25依據 DSM-5 所訂定之標準，物質使用障礙症（substance use disorders）中，有關耐受性（tolerance）的敘述，下列何者正確？

    1. (A) 使用物質過量或過久，會花時間去尋找使用的物質
    2. (B) 因物質使用嚴重，而產生了生理上的依賴，一旦停止使用，會導致身心不適
    3. (C) 使用物質造成身體傷害，明知使用物質對身體有傷害仍持續使用
    4. (D) 指腦部及身體已適應較高的物質濃度，因此需要更多的物質，才能達到原來的效果

    正解：(D)

  26. 26美沙冬（Methadone）可作為海洛因（Heroin）的替代治療藥物之原因，下列敘述何者錯誤？

    3. (C) 提升日常生活功能後，較能正常就業
    4. (D) 不會造成依賴頁次：8－4

  27. 27酒精成癮的病人，因長期缺乏下列何種維生素，導致維尼克氏腦症（Wernicke’s encephalopathy），出現意識障礙、眼肌麻痺、運動失調症狀？

  28. 28根據精神疾病診斷準則手冊（diagnostic and statistical manual of mental disorders：DSM-5），有關譫妄（delirium）的敘述，下列何者正確？

    2. (B) 病程慢性化，且症狀逐漸惡化
    3. (C) 所產生的認知困擾，包含失去定向感、語言、視覺空間能力
    4. (D) 移除致病導因後，通常無法完全恢復

    正解：(C)

  29. 29關於認知障礙症病人之臨床症狀，下列何者正確？

    1. (A) 定向感障礙部分，通常先發生對人物的定向感障礙
    2. (B) 記憶力減退部分，通常先發生遠期的記憶障礙
    3. (C) 感覺知覺障礙部分，較少出現日落症候群
    4. (D) 語言功能部分，可能出現語言整合、理解及表達能力減退，或出現失語症

    正解：(D)

  30. 30對於暴食症（Bulimia Nervosa）病人的特徵之敘述，下列何者錯誤？

    4. (D) 暴食症狀與不當補償行為同時出現，並持續一個月可達診斷標準

    正解：(D)

  31. 31王小弟，5 歲，診斷為自閉症類群障礙症（Autism Spectrum Disorder），下列護理措施何者錯誤？

  32. 32黃先生 43 歲，診斷為思覺失調症，症狀經常反覆惡化，兩個月前才剛出院返家，今日又因拒服藥、自我照顧能力差、暴力攻擊家人而入院，下列敘述何者正確？

  33. 33有關復元（recovery）的敘述，下列何者正確？

  34. 34有關社區精神心理衛生護理的敘述，下列何者正確？
