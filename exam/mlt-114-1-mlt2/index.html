  1. 1遺傳性球狀紅血球增多症（hereditary spherocytosis, HS）是因為紅血球某些膜蛋白出問題。目前用以篩檢HS 的 eosin-5-maleimide binding method，主要是針對下列何者做量化評估？

    1. (A) α-spectrin
    2. (B) β-spectrin
    3. (C) Ankyrin-1
    4. (D) Band 3

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) eosin-5-maleimide（EMA）會專一性結合紅血球膜上的 Band 3（陰離子交換蛋白 AE1），HS 病人因 band 3 或 spectrin/ankyrin 等膜蛋白缺損，EMA 結合量下降，以流式細胞儀定量螢光強度即可篩檢 HS。

    ❌ (A) α-spectrin 缺損雖也可見於 HS，但 EMA 主要標的並非 α-spectrin 本身。

    ❌ (B) β-spectrin 缺損時 EMA 結合亦可能下降，但它不是 EMA 的直接結合對象。

    ❌ (C) Ankyrin-1 為垂直連結蛋白，EMA 試驗並非藉由測定 ankyrin-1 量來判讀。

    📚 出處：Hoffman Hematology 紅血球膜疾病章節；EMA binding test 原理（Band 3 為主要標的）。

  2. 2當發生血管內溶血性貧血時，下列何種現象最先出現？

    1. (A) Serum haptoglobin 上升
    2. (B) Hemosiderinuria
    3. (C) Serum bilirubin 下降
    4. (D) Hemoglobinuria

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 血管內溶血時游離血紅素直接釋入血漿，血紅素超過 haptoglobin 結合容量後由腎臟排出，故 hemoglobinuria 最早且最直接出現。

    ❌ (A) Haptoglobin 會與游離血紅素結合而被網狀內皮系統清除，血管內溶血時是下降而非上升。

    ❌ (B) Hemosiderinuria 是血紅素被腎小管細胞吸收後分解成含鐵血黃素，數天後才隨尿液排出，出現時間晚於 hemoglobinuria。

    ❌ (C) 溶血時血紅素分解增加，血清 bilirubin（間接型）會上升而非下降。

    📚 出處：Hoffman Hematology 溶血性貧血章節；血管內溶血之血漿／尿液標記時序。

  3. 3有關再生不良性貧血（aplastic anemia）病人的周邊血液，下列敘述何者錯誤？

    1. (A) Normochromic, normocytic RBC
    2. (B) Reticulocytosis
    3. (C) Absolute neutrophil count 下降
    4. (D) Thrombocytopenia

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 再生不良性貧血是骨髓造血幹細胞衰竭，紅血球生成不足，網狀球計數應為下降（reticulocytopenia），故「reticulocytosis」敘述錯誤。

    ❌ (A) 因血紅素合成正常，紅血球呈 normochromic normocytic，此敘述正確。

    ❌ (C) 白血球前驅細胞受抑，absolute neutrophil count 下降，正確。

    ❌ (D) 巨核細胞受抑造成血小板減少，正確。

    📚 出處：Hoffman Hematology 再生不良性貧血章節；周邊血三血球低下併網狀球低下。
