警察特考　113 年 三等考試 行政學　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1有關政府、私人企業和非營利組織三個部門的敘述，下列何者正確？

    1. (A) 政府提供的財貨稱為公共財
    2. (B) 三個部門之間具備相互倚賴性
    3. (C) 私人企業不提供社會服務
    4. (D) 非營利組織不得有事業收入

    正解：(B)

  2. 2有關促成新公共管理思潮的原因，下列何者錯誤？

    1. (A) 政府規模與財務負擔過大，卻無法滿足民眾需求
    2. (B) 小政府的主張成為顯學
    3. (C) 公部門為了提高競爭優勢，希望提升行政效率
    4. (D) 民主行政的概念興起，民眾參與的需求出現

    正解：(D)

  3. 3下列何者非屬修正理論時期（1930～1960）的行政學？

    1. (A) 韋伯（M. Weber）的官僚體制理論
    2. (B) 賽蒙（H. Simon）的理性決策理論
    3. (C) 馬斯洛（A.H. Maslow）的需要層級理論
    4. (D) 何茲伯格（F. Herzberg）的激勵保健兩因理論

    正解：(A)

  4. 4有關民營化（privatization）的理論基礎，下列敘述何者錯誤？

    1. (A) 藉由民營化提高經營效率
    2. (B) 提高政府財政自由度
    3. (C) 避免政黨與事業機構掛勾
    4. (D) 符合新自由主義之思潮

    正解：(B)

  5. 5認為謊言是絕對無法接受的，屬於下列那一種倫理途徑？

    1. (A) 功利主義式倫理
    2. (B) 對形式原則的義務
    3. (C) 權利倫理
    4. (D) 亞里斯多德倫理

    正解：(B)

  6. 6有關於吉伯特（C. E. Gilbert）之「行政責任分析架構」所探討的四種確保行政責任之途徑，下列敘述何者錯誤？

    1. (A) 人事體系之雙重隸屬監督機制屬於內部正式確保途徑
    2. (B) 行政人員自律屬於內部非正式確保途徑
    3. (C) 傳播媒體屬於外部正式確保途徑
    4. (D) 遊行抗議屬於外部非正式確保途徑

    正解：(C)

  7. 7甲、乙和丙都是某機關的薦任科員，他們對於機關長久以來的升遷措施感到不滿，而想要聯合起來，積極的採取行動來改變現況。這三人的結合最接近於下列何種團體？

    1. (A) 混合團體
    2. (B) 垂直共棲團體
    3. (C) 水平防守團體
    4. (D) 水平攻擊團體

    正解：(D)

  8. 8下列激勵理論，何者主張「人可能同時存在多種需求，每種需求皆具績效效果，而且較高層次的需求無法被滿足時會退而尋求較低層次需求之滿足」？

    1. (A) 何茲伯格（F. Herzberg）之激勵保健兩因理論
    2. (B) 阿德福（C. Alderfer）之 ERG 理論
    3. (C) 馬斯洛（A. H. Maslow）之需要層級理論
    4. (D) 佛洛姆（V. H. Vroom）之期望理論

    正解：(B)

  9. 9依中央行政機關組織基準法之規定，中央行政機關名稱定名為「分署」或「分局」者，屬於：

    1. (A) 獨立機關
    2. (B) 二級機關
    3. (C) 三級機關
    4. (D) 四級機關

    正解：(D)

  10. 10在多元主義政治邏輯下，政府機關面對的公共服務對象具有多元意涵，其中一種見解是將公共服務對象視為理性抉擇者（rational choicer）。此理性抉擇者的意涵為何？

    1. (A) 接受政府提供直接服務之人
    2. (B) 主動參與公共事務的知識者
    3. (C) 媒合各方利益的政策掮客
    4. (D) 追求自身利益極大化的政策買方

    正解：(D)

  11. 11關於「目標與關鍵結果法」（Objective and Key Results）之敘述，下列何者錯誤？

    1. (A) 管理週期內聚焦於處理最重要的議題
    2. (B) 目標要保持彈性以因應環境變遷
    3. (C) 目標由上而下設定
    4. (D) 核心理念在於衡量而非獎懲

    正解：(C)

  12. 12有關我國一般公務人員和警察人員的人事制度，下列敘述何者正確？

    1. (A) 都採官職職等併立制
    2. (B) 都適用公務員服務法
    3. (C) 都屬於人事一條鞭制
    4. (D) 均分簡、薦、委三個官等

    正解：(B)

  13. 13有關年金給付的「確定提撥」（defined contribution）制，下列敘述何者錯誤？

    1. (A) 原則上，在職時存入的錢與退休後領出的錢有對等關係
    2. (B) 需要承擔貨幣貶值以及投資不利的風險
    3. (C) 具有世代互助及所得重分配的優點
    4. (D) 雇主無法保證員工退休金給付之數額

    正解：(C)

  14. 14有關我國政府預算制度之敘述，下列何者最符合「新公共管理」學派所強調的彈性原則？

    1. (A) 主計機關得派員調查各機關預算執行情形
    2. (B) 政府不得於預算所定外處分公有財物
    3. (C) 行政院應於年度開始 9 個月前，訂定下年度之施政方針
    4. (D) 政府預算中應設置預備金

    正解：(D)

  15. 15有關「地方稅法通則」內容之敘述，下列何者錯誤？

    1. (A) 該通則賦予地方政府開徵地方稅之法源依據
    2. (B) 地方政府欲開徵地方稅，其地方稅自治條例應經地方民意機關完成三讀立法程序
    3. (C) 地方政府得依規定，調高某些地方稅之稅率
    4. (D) 為落實地方自治，只要獲得地方議會同意，地方稅之開徵範圍即無限制

    正解：(D)

  16. 16一般而言，組織結構設計的基本考量因素中，下列何者較不重要？

    1. (A) 專業分工
    2. (B) 控制幅度
    3. (C) 科層組織
    4. (D) 工作年資

    正解：(D)

  17. 17假設一部門主管認為常常到部屬辦公室走動、觀察，部屬的工作績效便能獲得提升。此主管可能是在實踐下列何者？

    1. (A) 彼得原則
    2. (B) 穀倉效應
    3. (C) 霍桑效應
    4. (D) 需求層次理論

    正解：(C)

  18. 18政府電子治理中，依照服務對象有所謂的 G2B、G2C、G2E、G2G 等政府服務，下列敘述何者正確？

    1. (A) 一般民眾網路報稅屬於 G2E 服務
    2. (B) 政府機關之間電子公文系統屬於 G2C 服務
    3. (C) 政府機關供民眾使用的無障礙網頁設計屬於 G2G 服務
    4. (D) 政府透過網路系統進行電子採購與招標屬於 G2B 服務

    正解：(D)

  19. 19有關國家發展委員會公共政策網絡參與平臺運作機制的介紹，下列何者錯誤？

    1. (A) 提點子者限定需具備我國身分證或居留證
    2. (B) 提案範圍以國家發展委員會之業務職掌為限
    3. (C) 為落實開放政府的政策工具
    4. (D) 提議應獲得一定人數之附議，以展現其公共性

    正解：(B)

  20. 20理性的決策至少包括下列四個步驟，依其先後順序，下列何者正確？①蒐集論據 ②做出決策③執行決策 ④找出問題

    1. (A) ①②③④
    2. (B) ②①③④
    3. (C) ④①②③
    4. (D) ②④③①

    正解：(C)

  21. 21大數據分析運用在民意探詢上日益增加，最常見用來表達民意偏好的指標不包括下列何者？

    1. (A) 網路聲量
    2. (B) 網路好感度
    3. (C) 網路滲透率
    4. (D) 社群活躍度

    正解：(C)

  22. 22有關社會企業的特色，下列敘述何者錯誤？

    1. (A) 重視組織本身在經濟上的持續性
    2. (B) 高度依賴政府財源的挹注
    3. (C) 堅持社會目標與回應社會需求
    4. (D) 基於永續與企業精神運作

    正解：(B)

  23. 23有關行政程序法中的「聽證」相關規定，下列敘述何者正確？

    1. (A) 聽證紀錄必須以文字為之，不得以錄音、錄影輔助
    2. (B) 除法律另有規定外，聽證應公開以言詞為之
    3. (C) 聽證終結後，即使行政機關尚未做成決定，都不得再為聽證
    4. (D) 聽證與公聽會具有相同的法律程序和效力

    正解：(B)

  24. 24下列何者較符合「興建營運移轉模式」（BOT）的執行模式？

    1. (A) 推動過程不存在資訊不對稱的疑慮
    2. (B) 規劃階段的交易成本極低
    3. (C) 政府獨力承擔營運期間的風險
    4. (D) 特許期滿，民間業者將營運資產移轉給政府

    正解：(D)

  25. 25下列議題中，何者較不適合從「跨域治理」的視角加以分析？

    1. (A) 衛生福利部與農業部之間農藥殘留的爭議
    2. (B) 基隆市政府交通局與交通部之間捷運路線的規劃
    3. (C) 慈善團體與嘉義縣政府社會局聯手打造食物銀行
    4. (D) 文化部聽取國立歷史博物館的策展規劃簡報並指示修正事項

    正解：(D)
