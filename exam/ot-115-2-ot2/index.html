職能治療師　115 年第二次 職能治療學概論　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何項領域或機構，職能治療人員的投入最晚？

    1. (A) 軍事醫院（military hospital）
    2. (B) 生理障礙（physical disablities）
    3. (C) 社會心理障礙（psychosocial dysfunction）
    4. (D) 小兒科（pediatrics）

    正解：(D)

  2. 2職能治療部門組長，接獲院方想要發展新的心肺職能治療服務，但過往沒有相關經驗，下列作法，何者較不適切？

    1. (A) 安排職能治療部門的讀書會，增進專業知能
    2. (B) 參加專業組織相關主題課程研習
    3. (C) 聘請專家教學指導
    4. (D) 因為欠缺相關經驗，基於執業倫理，婉拒院方發展新領域

    正解：(D)

  3. 3職能治療部門主管察覺某治療師與個案面談的技巧未達標準時，其處理的方式，下列何者最適切？

    1. (A) 與之約定要限期改善，否則將嚴加處罰（如考績不佳、扣薪水）
    2. (B) 採漸進式紀律方法，先口頭告知提醒，若仍未達標準，罰則愈來愈重
    3. (C) 主管與治療師共同討論，制訂提升專業能力的目標、行動計畫與改善期程
    4. (D) 專業考評未達標準的紀錄，雙方簽名，存放到治療師人事資料中存檔

    正解：(C)

  4. 4關於臨床各領域職能治療服務之描述，下列何者錯誤？

    1. (A) 醫療院所內的職能治療部門提供服務之收費可能來自於公部門，例如健保或社會補助
    2. (B) 私人設立之職能治療所，收入來源限於自費
    3. (C) 提供個案職能治療服務的過程，包括提供個案有關申請補助的諮詢
    4. (D) 服務的收入來源不限於醫療機構

    正解：(B)

  5. 5有關職能治療先驅與其貢獻的配對，下列何者正確？

    1. (A) 阿道夫邁耶（Adolf Meyer）發展對精神疾患的精神生物療法（psychobiological approach）

    3. (C) 威廉羅許登頓（William Rush Dunton, Jr.）設計對結核病患者的運動及治療方案
    4. (D) 蓋瑞凱爾霍夫納（Gary Kielhofer）提出職務再設計的概念

    正解：(A)

  8. 8有關 clients-and-environments-as-a-whole 之運用，下列敘述何者錯誤？

    1. (A) 職能治療師若未將環境因素納入考量，則會過度聚焦於個案的表現
    2. (B) 家屬可能因為職能治療師未考量 clients-and-environments-as-a-whole 而拒絕採納居家環境改造的建議
    3. (C) clients-and-environments-as-a-whole 考量環境改造的建議是否符合個案的居家需求，而非與個案討論其角色、意義或從事的職能活動
    4. (D) 進行評估或臨床介入時，職能治療師應檢視是否符合 clients-and-environments-as-a-whole

    正解：(C)

  14. 14有關調整職能情境因子以改善個人之職能表現，下列敘述何者最適切？

    1. (A) 通用設計（universal design）的概念強調移除障礙而促進可取得性或可就近性的設計
    2. (B) 無障礙設計（accessible design）強調適用於各年齡層、能力、體型及文化等符合人體工學特性於產品或環境設計中
    3. (C) 電梯按鈕加上點字系統即是有利於促進視障者社會參與之無障礙設計（accessible design）
    4. (D) 不論無障礙設計或通用設計皆無法直接促進 Person-Environment-Occupation 之成效

    正解：(C)

  15. 15對於情境因素之敘述，下列何者最不適切？

    1. (A) 注重 Person-Environment-Occupation 三者間的關連性

    3. (C) 個案的職能表現及職能參與不理想時，可透過環境因子的調整以提升 Person-Environment-Occupation 的成效
    4. (D) 環境中的文化與社會層面的因子與個案的信仰、價值觀的養成無關

    正解：(D)
