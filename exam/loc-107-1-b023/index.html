    1. (A) 左右兩眼看到不同角度的影像
    2. (B) 左右兩眼看到不同亮度的影像
    3. (C) 左右兩眼看到不同顏色的影像
    4. (D) 左右兩眼看到不同大小的影像

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 立體感源於雙眼視差：左右眼看到略有角度差異的影像，大腦融合後產生深度知覺。

    ❌ (B) 亮度差異不產生立體感。

    ❌ (C) 顏色差異僅是分離左右影像的技術手段，非立體感的成因。

    ❌ (D) 大小差異屬單眼深度線索，非 3D 電影的原理。

    📚 出處：雙眼視差與立體視覺。

  2. 2請問取樣頻率 48K 赫茲、取樣大小為 16 bits 的 45 秒聲音檔，在不壓縮且不包含其他資訊的情況下，其資料量約為多少？

    1. (A) 4,320 Bytes
    2. (B) 4,320 bits
    3. (C) 4,320 KBytes
    4. (D) 4,320 Kbits

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 48,000 × 16 × 45 = 34,560,000 bits = 4,320,000 Bytes ≈ 4,320 KBytes。

    ❌ (A) 4,320 Bytes 少了三個數量級。

    ❌ (B) 4,320 bits 更小。

    ❌ (D) 4,320 Kbits 的單位有誤。

    📚 出處：數位音訊的資料量計算。

    3. (C) 111111012
    4. (D) 111111002

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 3 的 8 位元表示為 00000011，取補數加 1 得 11111101。

    ❌ (B) 10000011 為符號大小表示法的 −3。

    ❌ (D) 11111100 為 −4。

    📚 出處：二補數表示法。
