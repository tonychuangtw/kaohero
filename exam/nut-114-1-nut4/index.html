▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1關於速食店供膳特色之敘述，下列何者錯誤？

    1. (A) 利用前處理過的食物提供顧客點餐後快速服務
    2. (B) 利用大量產銷的方式可降低成本
    3. (C) 供應餐次較一般餐廳固定
    4. (D) 提供顧客一致性的服務

    正解：(C)

  2. 2有關醫院供膳常見問題，下列何者錯誤？

    1. (A) 常須配合病患喜好更改菜單而增加菜單開立困難度
    2. (B) 大型醫院膳食備餐與送餐皆較為費時易導致供餐溫度不足
    3. (C) 大型醫院餐食因疾病飲食種類多而增加配膳複雜性
    4. (D) 醫院餐食多須配合營養支持療養，在主食及菜色選擇與變化上較有限制

    正解：(A)

  3. 3有關食材使用量之計算方式，下列敘述何者錯誤？

    1. (A) 購買量＝AP/（1－生廢棄率）
    2. (B) 生品可食率＝EP/AP×100%
    3. (C) 熟廢棄率＝（熟品重－熟品可食重）/熟品重×100%
    4. (D) 生廢棄率＝1－生品可食率

    正解：(A)

  4. 4下列何者不是選擇性菜單的優點？

    1. (A) 可依消費者喜好
    2. (B) 菜單內容變化多
    3. (C) 食材成本較低
    4. (D) 盤餘剩量較少

    正解：(C)

  5. 5下列那些蔬菜屬於綠色葉菜類蔬菜？①菠菜 ②皇宮菜 ③韭菜花 ④大頭菜

    1. (A) ①②
    2. (B) ①③
    3. (C) ②③
    4. (D) ③④

    正解：(A)

  6. 6有關「學校午餐食物內容及營養基準」，國小4～6年級午餐每人蔬菜類供應量目標值為多少份？

    1. (A) 1份
    2. (B) 1.5份
    3. (C) 2份
    4. (D) 2.5份

    正解：(C)

  7. 7有關食品標章的敘述，下列何者錯誤？

    1. (A) 「三章一Q」包含「有機農產品標章」、「CAS台灣優良農產品標章」、「產銷履歷農產品標章」及「臺灣農產生產溯源QR Code」
    2. (B) 取得校園食品標章之點心食品一份應在250大卡之下
    3. (C) 產銷履歷農產品應包含標章、品名、追溯碼、資訊公開方式、驗證機構名稱等內容
    4. (D) CAS是針對國產農產品之生產製造工廠的一種認證制度

    正解：(D)

  8. 8有關「食品追溯追蹤系統」，下列何者錯誤？

    1. (A) 食品業者需保存產品原材料、半成品及成品之來源相關文件5年以上
    2. (B) 進貨單需載明出貨日期或批號
    3. (C) 產品資訊應包含淨重、容量、數量或度量
    4. (D) 使用三章一Q食材即是可追溯食材來源良好選擇之一

    正解：(B)

  9. 9團膳公司依照自己訂定的採購規格挑選出條件最優及價格最低的廠商進行交易，此為何種採購方法？

    2. (B) 議價採購
    3. (C) 比價採購

  10. 10某廚房每年冷凍雞腿需求2,000箱，流通成本為10％，每箱採購成本為500元，每次訂購成本為5元，安全庫存量為20箱，經濟訂購量（economic order quantity, EOQ）為何？

  11. 11有關驗收注意事項，下列何者錯誤？

    3. (C) 單價高的食材採抽樣檢查且抽樣量要足夠
    4. (D) 確認送貨單上食材的品項、品質與金額無誤

    正解：(C)

  12. 12有關蔬果類貯存時的變化，下列何者正確？

    1. (A) 貯存溫度的高低與貯存時間成正比
    2. (B) 蔬菜利用不透氣塑膠袋密封包裝以增加貯存性
    3. (C) 含硫的蔬菜如洋蔥若貯存的濕度太高易發生辣臭的刺激味

    正解：(C)

  13. 13市售花生豬血糕包含豬血糕70g和花生粉26g，分別提供幾份全穀雜糧類和油脂與堅果種子類？

  17. 17有關蔬菜類的前處理，下列何者正確？
