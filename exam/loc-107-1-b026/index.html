  1. 1下列反應得到的產物，何者不具光學活性（optically inactive）？H3C-

    1. (A) O ＿＿＿ I + OH -
    2. (B) Br + CH3SH
    3. (C) I + CN-
    4. (D) -H ＿＿＿ H ＿＿＿ + CNH3C ＿＿＿ Cl

    正解：(A)

  2. 2根據坎-殷高-普利洛（Cahn-Ingold-Prelog）命名系統，下列那一取代具有最高優先性？

    1. (A) –NH2
    2. (B) –NHCH3
    3. (C) –CH2NH2
    4. (D) –CH2NHCH3

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 先比較第一原子：−NH₂ 與 −NHCH₃ 的 N（原子序 7）優於 −CH₂− 的 C；再比較 N 上的取代原子，−NHCH₃ 為 (C, H) 勝過 −NH₂ 的 (H, H)。

    ❌ (A) −NH₂ 的 N 上取代原子次序較低。

    ❌ (C) 第一原子為碳，次序低於氮。

    ❌ (D) 第一原子同為碳，次序低於氮。

    📚 出處：Cahn-Ingold-Prelog 次序規則。

  3. 3下列何者有鏡像異構物（enantiomer）？CH3 ＿＿＿ CH2CH3

    1. (A) C6H5 ＿＿＿ N ＿＿＿ CH2CH = CH2
    2. (B) C6H5 ＿＿＿ N ＿＿＿ CH2CH = CH2CH2CH3 ＿＿＿ CH2CH3CH3
    3. (C) N

    4. (D) (R)-3-氯-1-丁烯（(R)-3-chloro-1-butene）
