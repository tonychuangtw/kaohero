職能治療師　108 年第一次 小兒職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列有關視知覺發展之敘述，何者正確？

    1. (A) 3～4歲的孩童能區辨⾃⼰⾝體的左和右
    2. (B) 5歲的孩童能區辨鏡像（例如：「b」和「d」）之不同
    3. (C) 6歲的孩童能區辨垂直線、⽔平線和斜線
    4. (D) 6歲的孩童可以由視覺了解環境的⽅向性

    正解：(C)

  2. 2下列關於⽅向感（directionality）的敘述，何者正確？

    1. (A) 等同於側化（laterality）
    2. (B) ⼤約六歲發展完成
    3. (C) 是指對⾃⼰⾝體左右的概念
    4. (D) 是了解外物與⾃⾝在空間中之相對位置的能⼒

    正解：(D)

  3. 3除了動態三指握法（dynamic tripod）外，下列那些也是屬於成熟型態的握筆法？①側邊三指握法（lateraltripod） ②動態四指握法（dynamic quadrupod） ③側邊四指握法（lateral quadrupod）

    1. (A) 僅①②
    2. (B) 僅②③
    3. (C) 僅①③
    4. (D) ①②③

    正解：(D)

  4. 4在判斷嬰兒的睡眠狀態，下列那⼀項不是參考的指標？

    2. (B) 對外在刺激的反應
    3. (C) ⼼跳規律性
    4. (D) 呼吸規律性

    正解：(C)

  5. 5下列那⼀項較不屬於雙側整合（bilateral integration）的問題？

    3. (C) 個案會避免做跨越⾝體中線的動作
    4. (D) 左右區辨不佳

    正解：(A)

  6. 6考量兒童的先天氣質（innate temperament）對其⼼理社會功能表現之影響時，下列敘述何者正確？

    2. (B) 臨床介入應以儘量協助兒童修正其先天氣質以適應其環境為主
    3. (C) 影響個案的⼼理社會功能表現重要因素之⼀，是個案和其主要照顧者彼此間的先天氣質是否契合
    4. (D) 先天氣質的元素包括了趨避性（approach/withdrawal tendencies）、注意⼒分散度（distractibility）、記憶⼒（memory）及感覺閾值（sensory threshold）等

    正解：(C)

  7. 7下列那⼀項⽇常⽣活功能評估量表，是根據兒童可完成⽇常⽣活活動之百分比來計分？

    4. (D) 克—⾙⽒⽇常⽣活量表（Klein-Bell Activities of Daily Living Scales）

  8. 8強強喜歡和同伴們玩躲避球，這是屬於那⼀種遊戲？

  18. 18下列有關促進社會參與參考架構（frame of reference to enhance social participation）的理論基礎，何者錯誤？
