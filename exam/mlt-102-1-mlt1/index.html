  2. 2下列有關心室肌肉細胞動作電位之敘述，何者最為適當？

    1. (A) Phase 0 時，動作電位變化主要是細胞膜對鈣離子通透性增加所導致
    2. (B) Phase 1 時，動作電位變化主要是細胞膜對鈉離子通透性增加所導致
    3. (C) Phase 2 時，動作電位變化主要是細胞膜對鈣離子通透性減少所導致
    4. (D) Phase 3 時，動作電位變化主要是細胞膜對鉀離子通透性增加所導致

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 心室肌動作電位 Phase 3 為快速再極化期，此時延遲整流鉀通道（IKr、IKs）大量開放，細胞膜對鉀離子通透性增加，鉀離子外流使膜電位快速回到靜止值。

    ❌ (A) Phase 0 是快速去極化期，主因是快速鈉通道開放、細胞膜對「鈉離子」通透性急遽增加，不是鈣離子。

    ❌ (B) Phase 1 是短暫初期再極化，來自鈉通道去活化加上短暫外向鉀流（Ito），鈉通透性此時是下降而非增加。

    ❌ (C) Phase 2 平台期是 L 型鈣通道開放、鈣離子「內流增加」與鉀外流達成平衡所致，並非鈣通透性減少。

    📚 出處：臨床生理學－心肌電生理，心室肌動作電位 Phase 0～4 之離子基礎

  3. 3當心室再極化開始，心電圖會產生何種波形？

    1. (A) P
    2. (B) QRS
    3. (C) T
    4. (D) U

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) T 波代表心室再極化（ventricular repolarization）。心室去極化結束後進入再極化，在心電圖上形成 T 波，方向通常與 QRS 主波同向。

    ❌ (A) P 波代表心房去極化，發生在心室電活動之前。

    ❌ (B) QRS 複合波代表心室去極化，是心室收縮前的電活動，非再極化。

    ❌ (D) U 波位於 T 波之後，一般認為與浦金氏纖維或乳頭肌延遲再極化有關，並非心室再極化的起始波形。

    📚 出處：臨床生理學－心電圖學，心電圖各波與心臟電活動之對應
