職能治療師　103 年第一次 心理障礙職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1小春與不熟悉的人相處時，十分害怕，認定自己一定會出糗，自取其辱，導致焦慮不已。根據DSM-IV，小春可能是那種疾病？

    1. (A) 強迫症（obessive compulsive disorder）
    2. (B) 社交恐懼症（social phobia）
    3. (C) 廣泛性焦慮症（generalized anxiety disorder）
    4. (D) 創傷後壓力症候群（posttraumatic stress disorder）

    正解：(B)

  2. 2根據DSM-IV，有關行為疾患（conduct disorder），下列何者為錯誤？

    1. (A) 常會霸凌或威脅他人
    2. (B) 主動和人打架
    3. (C) 相關症狀須出現超過24個月
    4. (D) 破壞各種物品

    正解：(C)

  3. 3根據DSM-IV，失智症的蔣伯伯鬍渣滿下巴，兒子拿起伯伯多年來經常使用的電動刮鬍刀給他，伯伯反問兒子：「這個是什麼？」。從他的反應看來，請問這是什麼症狀的表現？

    1. (A) 失語症
    2. (B) 失用症
    3. (C) 執行功能障礙
    4. (D) 辨識不能

    正解：(D)

  4. 4根據DSM-IV，有關精神分裂症之敘述，下列何者正確？

    1. (A) 緊張型精神分裂症主要表徵為精神運動性障礙，包含過多的運動活動或木僵。亦有語言、動作的模仿行為。未有明顯之妄想或幻覺現象產生
    2. (B) 精神分裂症與妄想性疾患最大的區別在於是否出現任何知覺形式的幻覺
    3. (C) 初發年齡早的個案，病前適應較差，教育成就較低，具較明顯的負性症狀及認知能力損害，其預後亦較差
    4. (D) 精神分裂症的症狀表現及病程無性別差異。在統計上，男女兩性之罹病率、初發時間、症狀表現及預後均無明顯差異

    正解：(C)

  5. 5躁症患者與憂鬱症患者有何相同處？

    2. (B) 覺得自己是個糟透的人
    3. (C) 出現妄想
    4. (D) 講話速度變快

    正解：(A)

    3. (C) 男性企圖自殺的比例高於女性
    4. (D) 獨居者、離婚及喪偶者的自殺比例較高

  7. 7依據世界衛生組織國際健康功能與身心障礙分類系統（ICF）的概念，個案小王偶爾會發生的視幻覺是屬於那部分的問題？
