物理治療師　111 年第二次 物理治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1在電刺激參數設定中，若休息時間為 20 毫秒，電流作用週期（duty cycle）為 20％，則刺激時間為多少毫秒？

    1. (A) 4
    2. (B) 5
    3. (C) 20
    4. (D) 100

    正解：(B)

  2. 2何者不是經皮神經電刺激的止痛作用機制？

    1. (A) 下行疼痛控制理論（descending pain control theory）
    2. (B) 門閥控制理論（gate control theory）
    3. (C) 適應理論（adaptation theory）
    4. (D) 內源性鴉片疼痛控制理論（endogenous opiate pain control theory）

    正解：(C)

  3. 3下列何種臨床情境較不適合使用神經肌肉電刺激？

    1. (A) 長期石膏固定致肌肉無力萎縮
    2. (B) 腓總神經斷裂造成的垂足步態
    3. (C) 腦血管病變造成肩關節半脫臼
    4. (D) 頭部外傷引起的異常高肌張力

    正解：(B)

  4. 4利用神經肌肉電刺激來降低水腫時，電刺激強度的最低要求為何？

    1. (A) 達可見的肌肉收縮即可
    2. (B) 20%最大自主等長收縮（MVIC）
    3. (C) 40%最大自主等長收縮（MVIC）
    4. (D) 60%最大自主等長收縮（MVIC）

    正解：(A)

  5. 5功能性電刺激對於下半身癱瘓之脊髓損傷個案的臨床療效，下列敘述何者錯誤？

    2. (B) 促進脊髓白質再生
    3. (C) 改善體能狀況
    4. (D) 降低肌肉痙攣（spasticity）

    正解：(B)

    4. (D) 主動電極使用之電極片小於分散式電極

    正解：(C)

  7. 7向量干擾波一組電流頻率為 f，另一組電流頻率為 f+△f，則干擾後波差頻率（beat frequency）為何？

    2. (B) (f + f+ △f) / 2
    3. (C) △f
    4. (D) (f/ 2) + △f

  80. 80一位痙攣型雙邊麻痺（spastic diplegia）國中生，上肢精細動作控制能力不佳，使用電腦鍵盤輸入時，不僅無法同時按下 2 個按鍵，且經常在按下某鍵後，因來不及放開而重複輸入多次；按壓滑鼠左鍵進行雙擊時，也常因重複按壓的動作太慢而失敗。針對這些使用電腦的困擾，下列策略何者無效？

    1. (A) 設定並啟用「相黏鍵」功能
    2. (B) 設定鍵盤功能選項的「篩選鍵」
    3. (C) 在滑鼠設定選項中，調慢「連按二下滑鼠的時間」
    4. (D) 選用加大按鍵的大型鍵盤

    正解：(D)
