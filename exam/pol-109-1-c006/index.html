警察特考　109 年 四等考試 法學知識　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1依憲法增修條文規定，經濟及科學技術發展，應與下列何者兼籌並顧？

    1. (A) 資源與環境保護
    2. (B) 教育與文化維護
    3. (C) 人文與文化促進
    4. (D) 環境及生態保護

    正解：(D)

  2. 2憲法基本國策之法律性質，需視其規定內容而定。下列何者錯誤？

    1. (A) 有些屬於方針條款
    2. (B) 得為解釋適用憲法之依據
    3. (C) 得為立法裁量之界線
    4. (D) 均不具有強制拘束力

    正解：(D)

  3. 3依司法院釋字第 690 號解釋，有關主管機關得於必要時，對曾與傳染病病人接觸或疑似被傳染者，採行必要處置之規定，與下列何者無涉？

    1. (A) 人身自由
    2. (B) 健康權
    3. (C) 居住遷徙自由
    4. (D) 表意自由

    正解：(D)

  4. 4依司法院大法官解釋，關於學術自由，下列何者正確？

    1. (A) 學術自由之權利主體限於在我國從事相關學術工作之自然人，不包括學術研究機構
    2. (B) 大學教師升等資格之審查，其決定應基於客觀專業知識與學術成就予以考量，此亦屬學術自由之保障
    3. (C) 有關向政府申請研究計畫之補助、研究人員之組成、預算之籌措分配、研究成果之發表等，非屬學術自由之保障範圍
    4. (D) 針對學生選擇科系與課程之自由，以及學生自治等事項，不受學術自由之保障

    正解：(B)

  5. 5依據司法院釋字第 631 號解釋之意旨，關於秘密通訊自由，下列何者錯誤？

    1. (A) 秘密通訊自由旨在確保人民就通訊之有無、對象、時間、方式及內容等事項，有不受國家及他人任意侵擾之權利
    2. (B) 秘密通訊自由乃憲法保障隱私權之具體態樣之一，受憲法第 12 條之保障
    3. (C) 通訊監察書應由客觀、獨立行使職權之法官核發，方符合憲法所要求之合理、正當程序
    4. (D) 通訊監察之採行，應嚴格限縮限於通訊監察書上所載受監察人，若同時涉及侵害無辜第三人之秘密通訊自由，即屬違憲

    正解：(D)

  6. 6依司法院大法官解釋，關於集會遊行自由，下列何者錯誤？

    1. (A) 室外集會、遊行對於他人之生活安寧與安全、交通秩序、居家品質或環境衛生難免有不良影響，故應受較多限制
    2. (B) 集會遊行自由係以集體方式表達意見，國家應提供適當集會場所，並保護集會、遊行之安全，使其得以順利進行
    3. (C) 緊急性及偶發性集會遊行，不適用申請許可之規定
    4. (D) 法律規定主管機關如認集會、遊行在將來有可能「危害國家安全、社會秩序或公共利益」，即得否准，並不違憲

    正解：(D)

  7. 7依司法院大法官解釋，有關憲法所禁止之恣意差別待遇，下列何者錯誤？

    1. (A) 監督寺廟條例之規範對象僅限於部分宗教，係考量不同宗教教義與性質之差異，所為之合理差別待遇
    2. (B) 總統副總統選舉罷免法採行之連署制度，係立法者為避免耗費社會資源，所為之合理差別待遇
    3. (C) 對未成立法律上婚姻關係之異性伴侶所為之贈與，需課徵贈與稅之規定，係合理之差別待遇
    4. (D) 榮民之女若已結婚，則不可繼承該榮民之農場耕地配耕權，屬恣意之差別待遇

    正解：(A)

  8. 8依憲法及增修條文規定，下列何者違反平等原則之要求？

    1. (A) 對科學、藝術工作者之生活，依國民經濟之發展，提高其待遇
    2. (B) 給予原住民族與非原住民族相同之政治參與機會與資源
    3. (C) 規定立法委員選舉中，政黨選舉票之當選名單，婦女當選比例不得低於二分之一
    4. (D) 總統依據憲法第 52 條享有刑事豁免權

    正解：(B)

  9. 9依司法院大法官解釋，原稅捐稽徵法第 19 條第 3 項規定，稅捐稽徵機關核定之稅捐處分，對公同共有人之其中一人為送達者，即對全體公同共有人發生送達效力，違反下列何項原則？

    1. (A) 租稅法定主義
    2. (B) 租稅平等原則
    3. (C) 正當程序原則
    4. (D) 程序公開原則

    正解：(C)

  10. 10依司法院大法官解釋，有關收養自由，下列何者正確？

    1. (A) 法人得為收養自由之權利主體
    2. (B) 收養自由係為保障被收養人而非收養人之人格自由發展
    3. (C) 收養為我國家庭制度之一環
    4. (D) 禁止已有子女或養子女者收養大陸地區人民之規定一律違憲

    正解：(C)

  11. 11司法院大法官解釋已經承認之非明文憲法權利，不包括下列何者？

    1. (A) 隱私權
    2. (B) 環境權
    3. (C) 名譽權
    4. (D) 性行為自由

    正解：(B)

  12. 12依司法院大法官解釋，有關民法規定人民名譽受侵害時，得請求回復名譽之適當處分，下列何者正確？

    1. (A) 名譽權為民法上之權利，但並非憲法上之權利
    2. (B) 國家為保障人民名譽權，得對加害人之不表意自由進行限制
    3. (C) 法院令加害人負擔刊載被害人勝訴判決啟事之費用，侵害加害人之人性尊嚴，違憲
    4. (D) 法院令加害人公開道歉，並不違憲

    正解：(B)

  13. 13依司法院大法官解釋，關於性行為自由之限制，下列何者錯誤？

    1. (A) 性行為自由與個人之人格有不可分離之關係
    2. (B) 國家得基於保護婚姻與家庭制度之目的，對人民之性行為自由加以限制
    3. (C) 國家對於性行為自由之限制，應符合法律保留原則
    4. (D) 性交易行為係性行為自由之一種，國家對性交易行為加以處罰係違憲

    正解：(D)

  14. 14下列何一官員之產生不適用「由總統提名、經立法院同意而任命」之程序？

  23. 23依司法院大法官解釋，有關司法院之規則制定權，下列何者錯誤？

    1. (A) 本於司法自主性，最高司法機關得就審理程序有關技術性、細節性事項訂定規則
    2. (B) 於司法行政監督之範圍內，最高司法機關得就司法行政事務發布命令
    3. (C) 為維護審判獨立，最高司法機關所發布之命令不得涉及審判上之法律見解
    4. (D) 司法行政機關得發布命令，就法官之辦案績效予以考查

    正解：(C)

  24. 24依司法院大法官解釋，關於大法官解釋對於原因案件之救濟效力，下列何者錯誤？

    1. (A) 確定終局裁判所適用之法規與憲法意旨不符者，聲請人得以該解釋為理由請求聲請案件再審
    2. (B) 確定終局裁判所適用之法規與憲法意旨不符，但定期失效者，於修法前，聲請人仍得以該解釋為理由請求聲請案件再審
    3. (C) 違憲法令定期失效的宣告，並不影響法令違憲的本質認定，故所有在系爭解釋作成時尚未逾越再審期間的確定案件，皆得以該解釋為由提起再審
    4. (D) 法規經大法官宣告違憲者，其他聲請主張同一法規違憲，經大法官決議受理但未被系爭解釋併案審理者，該其他聲請人亦得提起再審

    正解：(C)

  25. 25關於財產權保障之主體，下列何者錯誤？

    1. (A) 保障財產權代表保障人格的自由發展，故自然人為財產權保障之主體
    2. (B) 財團法人以一定財產為基礎而得獨立行為，故財團法人為財產權保障之主體
    3. (C) 非法人團體不具有法人資格，無權利能力，故非法人團體並非財產權保障之主體
    4. (D) 國家為行使公權力之主體，故國家非財產權保障之主體

    正解：(C)

  26. 26下列有關著作權侵害之敘述，何者錯誤？

    正解：(B)

  36. 36有關法律之適用，下列何者正確？

    1. (A) 憲法位階高於法律，因此應該優先適用
    2. (B) 同一事項，普通法與特別法皆有規定時，應優先適用特別法
    3. (C) 基於因地制宜之考量，地方自治法規與中央法規不一致時，應優先適用地方自治法規
    4. (D) 為了解決法律漏洞的問題，只要附帶理由，法院即可透過類推適用之方法作成裁判

    正解：(B)

  37. 37下列何者並非法律漏洞之補充方法？

    1. (A) 目的性擴張
    2. (B) 類推適用
    3. (C) 目的性限縮
    4. (D) 反面解釋

    正解：(D)

  38. 38依憲法及憲法增修條文之規定，下列何者為總統之職權？

    1. (A) 任免立法院院長
    2. (B) 立法院開會時列席陳述意見
    3. (C) 對於立法院決議之法律案提出覆議
    4. (D) 發布緊急命令

    正解：(D)

  39. 39憲法第 172 條規定，命令與法律牴觸者無效。上述規定係符合下列何項原則？

    1. (A) 比例原則
    2. (B) 法律保留原則
    3. (C) 法律優位原則
    4. (D) 信賴保護原則

    正解：(C)

  40. 40下列有關父母子女關係之敘述，何者正確？

    1. (A) 甲、乙為夫妻，乙與丙男生下一子Ｘ，丙不得提起婚生否認訴訟
    2. (B) 生父若已死亡，非婚生子女不得提起認領子女之訴
    3. (C) 子女成年後，若欲更改姓氏，須得父母雙方之同意
    4. (D) 父母就未成年子女的打工收入，有使用收益與處分之權

    正解：(A)

  41. 41A 向 B 購買違章建築，下列何者正確？

    1. (A) 因 B 無法移轉違章建築所有權，屬於法律不能，所以買賣契約無效
    2. (B) 因違章建築違反法令，所以 A 不可以向法院聲請強制執行
    3. (C) 當建管單位拆除該違章建築，A 可向 B 主張權利瑕疵擔保
    4. (D) 兩人所買賣者是事實上處分權，所以買賣契約有效

    正解：(D)

  42. 42下列何種情形，甲原則上須就乙之行為連帶負責？

    1. (A) 土地所有人甲委託營建商乙，在自己土地上蓋房屋，甲必須對乙施工所造成之傷害行為
    2. (B) 當事人甲對律師乙的執行職務行為所引發的損害
    3. (C) 公司甲對其職員乙所為非執行職務之侵害行為
    4. (D) 車行甲必須對靠行司機乙所引發的傷害行為

    正解：(D)

  43. 43關於留置權之敘述，下列何者與民法物權編規定不符合？

    1. (A) 債權之發生與該留置物無需有牽連關係
    2. (B) 屬於法定之擔保物權
    3. (C) 不適用於不動產
    4. (D) 不得與債權人債務人間之約定相牴觸

    正解：(A)

  44. 44甲對乙表示：「現贈與你 A 車一部，做為你明年考上大學代步之用，如果明年你考不上大學，則應返還A 車與我。」此一贈與契約，附有何種約款？

    1. (A) 附停止條件之贈與
    2. (B) 附解除條件之贈與
    3. (C) 附始期之贈與
    4. (D) 附終期之贈與

    正解：(B)

  45. 45某甲在去年 7 月間，分別竊取了乙、丙、丁三人置放在機車座墊下的財物，經查獲後，檢察官就三案一併起訴，法院就三個竊盜行為，分別宣告「5 個月有期徒刑，得易科罰金」。竊盜罪之法定刑為「5 年以下有期徒刑，拘役或 500 元以下罰金」。關於本案，下列何者正確？

    1. (A) 三罪屬於累犯
    2. (B) 三罪屬於連續犯
    3. (C) 法院仍得同時就本案宣告緩刑
    4. (D) 如果法院定執行刑為 8 個月有期徒刑，則最終不得易科罰金

    正解：(C)

  46. 46關於刑法適用領域之各項原則中，不論是外國人或中華民國人民，只要犯罪之行為或結果在中華民國領域內即適用之，此原則為下列何種原則？

    1. (A) 屬地原則
    2. (B) 屬人原則
    3. (C) 世界原則
    4. (D) 保護原則

    正解：(A)

  47. 47關於驅逐出境處分，下列何者錯誤？

    1. (A) 性質上為保安處分
    2. (B) 性質上為刑罰之從刑
    3. (C) 對於外國人受有期徒刑以上刑之宣告者，得於刑之執行完畢或赦免後為之
    4. (D) 驅逐出境之處分，於裁判時一併宣告之

    正解：(B)

  48. 48消費者保護團體以自己名義提起團體訴訟，其標的價額超過多少金額時，超過部分得免繳裁判費？

    1. (A) 60 萬
    2. (B) 50 萬
    3. (C) 30 萬
    4. (D) 20 萬

    正解：(A)

  49. 49下列何者非屬公司監察人之職權？

    1. (A) 列席董事會並表達意見
    2. (B) 召集股東臨時會
    3. (C) 得委任律師、會計師，調查公司各項財務業務文件
    4. (D) 通知董事或董事會停止違反法令、章程之行為，倘董事或董事會不停止，即可將其解任

    正解：(D)

  50. 50事業單位違反勞動基準法及其他勞工法令規定時，下列何者錯誤？

    1. (A) 勞工依法僅得向主管機關或檢查機構申訴
    2. (B) 主管機關或檢查機構於接獲申訴後，應為必要之調查，並於 60 日內將處理情形，以書面通知勞工
    3. (C) 主管機關或檢查機構應對申訴人身分資料嚴守秘密，不得洩漏足以識別其身分之資訊
    4. (D) 雇主不得因勞工為前項申訴，而予以解僱、降調、減薪、損害其依法令、契約或習慣上所應享有之權益，或其他不利之處分

    正解：(A)
