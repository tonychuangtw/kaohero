職能治療師　112 年第二次 職能治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1一位8歲國小學童，因有寫字問題，經導師轉介給職能治療師進行評估。治療師想採用一套常模參照測驗來檢定學童手部精細動作是否有明顯落後情況。下列那一項測驗最適當？

    2. (B) Bruininks-Oseretsky Test of Motor Proficiency, Second Edition
    3. (C) Assessment of Motor and Process skills
    4. (D) Manual Ability Measure

    2. (B) 僅①③

  8. 8有關職能治療師進行職能分析（occupational analysis）與活動分析（activity analysis）之敘述，下列何者最適當？

  21. 21職能治療師在執行評估與介入時，需有文化敏感性，全面地考量個案的環境、社會、文化等因素，下列何者最不符合集體式社會主義（collectivist societies）的思維？

  27. 27特定職能治療轉銜計畫中，有關成長經驗對於「身心障礙學生工作行為發展」的敘述，下列何者錯誤？

    2. (B) 因解決同儕問題的經驗不足，以致在工作場所看到上司稱讚同事容易忿忿不平且自覺被歧視
    3. (C) 因成長過程需要復健經常請假，以致在工作場所忽略準時和出席率的重要性
    4. (D) 因同學經常協助雜事處理，以致忽略工作場所中善後的重要性

    正解：(A)

  28. 28有關效應值（effect size）的敘述，下列何者錯誤？

    1. (A) 可用來描述二種不同介入方法的治療成效差異
    2. (B) Cohen's d、Hedge's g、勝率（odds ratio）都是治療療效實證常用的效應值指標
    3. (C) Number needed to treat（NNT）指：使一名患者產生正向成效所需的治療人數
    4. (D) 概似率（likelihood ratio）指：兩組或多組之間特定結果的風險差異估計值

    正解：(D)

  29. 29職業輔導評量人員撰寫職業評量報告時，會涵蓋下列那些內容？①轉介目的 ②家族成員 ③安置場所建議 ④評估測驗解釋與分析 ⑤薪資建議

    1. (A) 僅①③④

    3. (C) 僅①④⑤
    4. (D) ①②③④⑤

  30. 30有關Valpar Component Work Samples（VCWS）工作樣本之敘述，下列何者正確？

    1. (A) Methods-Time Measurement（MTM）為「一個受過訓練的工作者，使用正確的工具、儀器以及材料，以一定的速度維持每天4小時的時間標準」
    2. (B) 整合工作者資格檔案（Composite Worker Qualifications Profile, composite WQP）為整合一個以上的VCWS測驗結果以確認受測者最低的WQP層級
    3. (C) Methods-Time Measurement（MTM）有「考慮施測者的學習速率」的標準，調整之MTM標準為判斷受測者進入競爭性職場之能力依據
    4. (D) VCWS同時為效標參照以及常模參照測驗，但常模參照僅適合第一次施測工作樣本時使用

    正解：(D)

  31. 31評量人員撰寫職業輔導評量報告時，下列敘述何者最適當？

    1. (A) 數個相似向度的測驗結果有衝突時，不需尋求衝突的原因，應再立即測試另一相似向度的測驗
    2. (B) 評量人員應以受測者、就服員以及其他相關人員能夠理解的話語來解釋測驗結果
    3. (C) 評量人員建議的就業方向應聚焦於一種職類，讓受測者與其他相關人員有明確的決定方向
    4. (D) 因每位受測者施測的測驗差異性不大，建議可將測驗的結果製作成固定的格式，提升撰寫報告的效率

    正解：(B)

  32. 32有關手功能評估測驗的敘述，下列何者正確？

    1. (A) Purdue Pegboard Test是以完成一定數量所需要的時間來評分
    2. (B) Box and Block Test是以在一定時間內完成的數量多寡來計分
    3. (C) Jebsen-Taylor Hand Function Test是以在一定時間內完成的數量多寡來計分
    4. (D) Crawford Small Parts Dexterity Test是以在一定時間內完成的數量多寡來計分

    正解：(B)

  33. 33下列關於「活動分析」（activity analysis）與「職能分析」（occupational analysis）比較之敘述，何者錯誤？

    1. (A) 活動分析強調身體功能與結構（body functions and structures）分析，職能分析重視活動的各種面向
    2. (B) 活動分析為分析一個活動所有可能的執行方式，職能分析則分析某人執行某一個活動的方式
    3. (C) 當我們要整體瞭解一個活動可能的治療效益（therapeutic use）時，活動分析比職能分析更適合
    4. (D) 活動分析與職能分析都會分析一個活動的活動要求與表現技巧（activity demands and performance skills）

    正解：(A)

  40. 40有關神經肌肉接合處的敘述，下列何者錯誤？

    1. (A) 是運動終板和肌纖維膜侵入式緊密結合之處
    2. (B) 神經傳導物質為乙醯膽鹼（acetylcholine）

    2. (B) 親身體驗（direct experience）：強調親身體驗活動，建立對自我效能與自我控制的信心
    3. (C) 同儕互惠（mutual beneficence）：設計多種活動，讓參與者互動，並且互相擔任指導者與被教導者，建立互惠關係
    4. (D) 個人探索（personal exploration）：設定團體活動的難度不斷挑戰參與者的潛能

    正解：(B)
