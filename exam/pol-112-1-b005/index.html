警察特考　112 年 三等考試 社會學與社會工作　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1著有經典巨著「社會學的想像」（Sociological Imagination）是那一位社會學家？

    1. (A) 馬克思（Karl Marx）
    2. (B) 韋伯（Maximilian Karl Emil Weber）
    3. (C) 哈伯瑪斯（Jürgen Habermas）
    4. (D) 米爾斯（C. Wright Mills）

    正解：(D)

  2. 2於十九世紀，率先提出「社會學」一詞的是那一位社會學者？

    1. (A) 孔德（Auguste Comte）
    2. (B) 托克維爾（Alexis de Tocqueville）
    3. (C) 涂爾幹（Émile Durkheim）
    4. (D) 馬提諾（Harriet Martineau）

    正解：(A)

  3. 3在社會工作的方法中，社會工作者有意識使用工作者與成員的人際關係、成員間的人際關係，協助每一個成員可充分地利用其能力與力量。此種工作方法，學者稱為什麼？

    1. (A) 社會個案工作
    2. (B) 社會團體工作
    3. (C) 社區工作
    4. (D) 個案管理

    正解：(B)

  4. 4依據「專科社會工作師分科甄審及接受繼續教育辦法」規定，專科社會工作師分為那五科？①醫務 ②心理衛生 ③兒童、少年、婦女及家庭 ④長期照顧 ⑤身心障礙 ⑥老人

    1. (A) ①②③④⑤
    2. (B) ②③④⑤⑥
    3. (C) ①②③⑤⑥
    4. (D) ①②③④⑥

    正解：(C)

  5. 5提出科層體制（或稱官僚體制，Bureaucracy）是那一位社會學家？

    1. (A) 紀登斯（Anthony Giddens）
    2. (B) 韋伯（Max Weber）
    3. (C) 柏格（Peter Berger）
    4. (D) 齊美爾（Georg Simmel）

    正解：(B)

  6. 6社會學者馬克斯（Karl Marx）指出：被壓迫者會將剝削合理化且歸咎自己，並傾向維護促成剝削的現行政治及社會體系。這個敘述是下列那一個觀點？

    1. (A) 社會流動（Social mobility）
    2. (B) 錯誤意識（False consciousness）
    3. (C) 社會結構功能論（Social structural functionalism）
    4. (D) 種族不平等（racial inequality）

    正解：(B)

  7. 7下列那一位社會學家提出：偏差行為對社會運作具有一定的功能。

    1. (A) 韋伯（Max Weber）
    2. (B) 涂爾幹（Émile Durkheim）
    3. (C) 墨頓（Robert Merton）
    4. (D) 高夫曼（Erving Goffman）

    正解：(B)

  8. 8下列何者觀點主張：偏差行為來自社會標籤化的過程，不管是否實際做出偏差行為，而擁有標籤化偏差行為權力的人，就是製造偏差行為的源頭。

    1. (A) 結構緊張論（Stucturalr strain theory）
    2. (B) 社會控制論（Social control theory）
    3. (C) 符號互動論（Symbolic interactionism）
    4. (D) 社會衝突論（Social conflict theories）

    正解：(C)

  9. 9下列何者觀點主張：貧窮是透過家庭一代傳給一代，成為一種貧窮循環的狀態；而貧窮者的價值觀是其陷入貧窮的重要因素。

    1. (A) 貧窮的社會流動（Social mobility of poverty）
    2. (B) 貧窮文化（Culture of poverty）
    3. (C) 貧窮衝突論（Conflict theories of poverty）
    4. (D) 貧窮功能論（Functionalism of poverty）

    正解：(B)

  10. 10下列那一個概念是主張：將原為犯罪而科處刑罰的行為，修正為犯罪行為但不施刑罰，而以其他非刑罰的措施替代。

    1. (A) 修復式正義
    2. (B) 除刑不除罪
    3. (C) 犯罪的社會控制
    4. (D) 亂世用重典

    正解：(B)

  11. 11亞洲第一個同性婚姻合法化的國家為何者？

    1. (A) 泰國
    2. (B) 新加坡
    3. (C) 臺灣
    4. (D) 汶萊

    正解：(C)

  12. 12下列那一位學者著有「人類行為與社會環境」一書，並主張人生從嬰兒期到成人晚期分為八個發展階段，每一階段都受到較早階段之影響。

    1. (A) 艾瑞克森（E. Erikson）
    2. (B) 佛洛伊德（S. Freud）
    3. (C) 皮亞傑（J. Piaget）
    4. (D) 柏格（Peter Ludwig Berger）

    正解：(A)

  13. 13Lowenberg、Dolgoff 與 Harington 提出社會工作倫理抉擇的優先順序，其認為最重要、最優先考慮的是那一項倫理原則？

    1. (A) 自主自由原則
    2. (B) 保護生命原則
    3. (C) 最小傷害原則
    4. (D) 生活品質原則

    正解：(B)

  14. 14「社區總體營造」一詞最早何時被提出？

    1. (A) 民國 57 年內政部訂定「社區發展工作綱要」
    2. (B) 民國 61 年「十年計畫」
    3. (C) 民國 83 年文建會在立法院的施政報告
    4. (D) 民國 94 年「臺灣健康社區六星計畫」

    正解：(C)

  15. 15下列那一位被認為是社會個案工作之母，並於 1917 年發表「社會診斷」一書？

    1. (A) 芮奇孟（Mary Richmond）
    2. (B) 佛洛伊德（Sigmund Freud）
    3. (C) 艾瑞克森（E. Erikson）
    4. (D) 皮亞傑（Jean Piaget）

    正解：(A)

  16. 16目前政府政策對於有貧窮、犯罪、失業、物質濫用、未成年親職、有嚴重身心障礙兒童需照顧、家庭照顧功能不足等易受傷害風險的家庭稱之為：

    1. (A) 折衷家庭
    2. (B) 曝險家庭
    3. (C) 脆弱家庭
    4. (D) 危機家庭

    正解：(C)

  17. 17下列何者概念是學者 Jonathan Bradshaw 提出的社會福利需求之一，是由專家或學者定義出來的需求？

    1. (A) 規範性需求（normative need）
    2. (B) 感覺性需求（felt need）
    3. (C) 表達性需求（expressed need）
    4. (D) 比較性需求（comparative need）

    正解：(A)

  18. 18學者諾曼強森（Norman Johnson）提出「福利多元主義」（welfare pluralism），其中由非營利組織所提供的福利服務，係屬於那一種屬性？

    1. (A) 公共化
    2. (B) 商品化
    3. (C) 家戶化
    4. (D) 志願化

    正解：(D)

  19. 19學者 Richard Titmuss 將社會政策區分為殘補福利模式、工業表現成就模式及制度再分配模式，其中「工業表現成就模式」是屬於社會安全體系裡面的那一個制度？

    1. (A) 社會救助制度
    2. (B) 社會保險制度
    3. (C) 社會補償制度
    4. (D) 福利服務制度

    正解：(B)

  20. 20聯合國兒童權利公約的四大基本原則是指那四大權益保障？①禁止歧視 ②兒童最佳利益③生存及發展 ④尊重兒童意見 ⑤遊戲權

    1. (A) ②③④⑤
    2. (B) ①③④⑤
    3. (C) ①②③④
    4. (D) ①②③⑤

    正解：(C)

  21. 21依據「國民小學與國民中學未入學或中途輟學學生通報及復學輔導辦法」規定，直轄市、縣（市）政府對中輟生復學後不適應一般學校課程者，因應學生不同需求所提供之多元教育輔導措施，下列何者錯誤？

    1. (A) 慈輝班
    2. (B) 就業考照班
    3. (C) 資源式中途班
    4. (D) 合作式中途班

    正解：(B)

  22. 22依據 Kadushin 及 Martin（1988）提出的「支持性服務」、「補充性服務」及「替代性服務」觀點，下列敘述何者錯誤？

    1. (A) 家庭經濟補助是屬於補充性服務
    2. (B) 收養是屬於替代性服務
    3. (C) 發展遲緩兒童社區療育服務是屬於支持性服務
    4. (D) 托育服務是屬於替代性服務

    正解：(D)

  23. 23對於不適宜在家庭教養之兒少，依據「兒童及少年福利與權益保障法施行細則」第 10 條之規定，應以下列那一項安置場域為優先考慮？

    1. (A) 適當之親屬
    2. (B) 與兒少有長期正向穩定依附關係之第三人
    3. (C) 登記合格之寄養家庭
    4. (D) 核准立案之安置及教養機構

    正解：(A)

  24. 24Ernest Greenwood 認為專業社會工作必須具備五種基本特質，下列何者錯誤？

    1. (A) 一套理論知識體系
    2. (B) 專業權威
    3. (C) 志願服務
    4. (D) 專業文化

    正解：(C)

  25. 25以下敘述是那一個理論的觀點？強調家庭成員間的權力關係應視彼此之間擁有的資源多寡來評斷。社會經濟資源較多的家庭成員往往能避免付出勞力，且對於家庭共同決策具有相對較大的影響力。

    1. (A) 資源交換論
    2. (B) 家務分工論
    3. (C) 代間轉移論
    4. (D) 婚姻品質論

    正解：(A)
