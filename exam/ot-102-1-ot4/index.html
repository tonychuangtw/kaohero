  1. 1下列何者不是評估病患抽象思考能力之測驗方式？

    1. (A) 要求病患找出相關單字間相似或差異處
    2. (B) 請病患解釋何謂「此地無銀三百兩」
    3. (C) 要求病患從1數到10、背誦英文字母表
    4. (D) 請病患計劃明日將執行的工作

    正解：(C)

  2. 2病患在使用抗精神病藥物後出現錐體外徑症候群（EPS）。職能治療師在其出院準備過程中，可建議病患回家後：

    1. (A) 多喝水、維持足夠的睡眠及均衡的營養
    2. (B) 避免過度激烈之運動
    3. (C) 避免長時間曝曬在陽光底下
    4. (D) 避免使用較需出力的工具或較尖銳的工具

    正解：(D)

  3. 3一位青少年個案第一次參加職能治療之烹飪團體，治療師觀察到他有明顯之衝動及暴力行為，無法遵守團體規則。依此推斷，此個案最可能的診斷為？

    4. (D) 對立性反抗疾患（oppositional defiant disorder）

    正解：(A)

  4. 4在否認階層的防禦機轉，其特徵是將不愉快或不能接受的壓力源、衝動或情感擋在意識層次之外，有時會將其不當歸因為外在原因。下列何項防禦機轉不屬於此階層？
