警察特考　112 年 三等考試 行政法與警察行政違規調查裁處作業　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1甲因違反某行政法規，而將裁罰新臺幣 3 萬元至 15 萬元罰鍰。甲抗辯不知法規，主管機關認為有理由，按其情節，得減輕處罰。下列何者正確？

    1. (A) 此時最低可裁罰新臺幣 3 萬元罰鍰
    2. (B) 此時最低可裁罰新臺幣 1 萬 5 千元罰鍰
    3. (C) 此時最低可裁罰新臺幣 1 萬元罰鍰
    4. (D) 此時最低可裁罰新臺幣 5 千元罰鍰

    正解：(C)

  2. 2證券交易法第 66 條第 2 款規定：「證券商違反本法或依本法所發布之命令者，除依本法處罰外，主管機關並得視情節之輕重，為下列處分，並得命其限期改善：……二、命令該證券商解除其董事、監察人或經理人職務。……」此處之解除職務，其法律性質為何？

    1. (A) 其為剝奪或消滅資格、權利之處分，自係行政罰
    2. (B) 其為向未來維持行政秩序所必要之管制性不利處分，並非行政罰
    3. (C) 其為行政執行措施
    4. (D) 其為行政處分之廢止

    正解：(B)

  3. 3關於行政罰上的「狀態責任」，下列何者正確？

    1. (A) 狀態責任係一種結果責任，故其追究即不以構成故意、過失為前提
    2. (B) 行為責任人應同時為狀態責任人，狀態責任係法律之特別規定
    3. (C) 性質上係以對物的狀態具有事實管領力者，得以負責之觀點，課予回復原狀者，其性質即屬狀態責任
    4. (D) 狀態責任係一種代位責任，故得減輕處罰

    正解：(C)

  4. 4甲公務員不服其服務機關考績丙等之不利處分，於提起行政救濟後，依政府資訊公開法向服務機關要求調閱考績委員會之會議紀錄，服務機關否准後，於通知 A 公務員的公文中註記此為行政程序法第 174 條之程序行為，應連同考績丙等之不利處分一併救濟。甲服務機關之註記是否正確？

    1. (A) 不正確，此為對公務員所為之人事行政行為，本無行政程序法程序規定之適用
    2. (B) 不正確，依政府資訊公開法規定申請行政機關提供行政資訊之權利，屬實體權利，行政機關拒絕提供者，應屬行政處分之性質
    3. (C) 正確，閱覽卷宗請求權屬程序權利，自有行政程序法第 174 條之適用
    4. (D) 正確，閱覽卷宗請求權屬程序權利，本應有特別之救濟程序

    正解：(B)

  5. 5臺灣地區與大陸地區人民關係條例第 95 條之 3 規定，依本條例處理臺灣地區與大陸地區人民往來有關之事務，不適用行政程序法之規定。有關本條之解釋，下列何者正確？

    1. (A) 此一規定涉及有關外交行為、軍事行為或國家安全保障事項之行為，自不適用行政程序法
    2. (B) 因為臺灣地區與大陸地區人民關係條例有關程序事項之規定，有較行政程序法更嚴格之程序規定，故可以排除行政程序法之適用
    3. (C) 此一規定僅排除行政程序法程序規定之適用，行政程序法關於行政行為之實體規定仍有適用
    4. (D) 行政程序法為普通法，其他法律自優先適用

    正解：(C)

  6. 6有關行政程序法規範的迴避，下列何者錯誤？

    1. (A) 申請迴避之理由僅「釋明」為已足，無庸「證明」
    2. (B) 被申請迴避之公務員在其所屬機關就該申請事件為准許或駁回之決定前，毋庸停止行政程序
    3. (C) 行政程序法並未如同各種訴訟法規定，賦予違反迴避明確之效果
    4. (D) 否准迴避之申請時，得於五日內提請上級機關覆決

    正解：(B)

  7. 7行政機關之送達證書，僅蓋有大廈管理委員會圖戳代收，並未一併由該管理員以受僱人之身分簽名或蓋其私章，其送達是否生效？

    1. (A) 已生效，大廈管理委員會本係應送達處所之有權接收郵件者
    2. (B) 已生效，既有送達證書，即已生送達之效力
    3. (C) 未生效，應送達處所之接收郵件人員應指自然人，送達證書無自然人之簽章自不生效
    4. (D) 未生效，大廈管理委員會及其管理員非應送達處所之有權接收郵件人員

    正解：(C)

  8. 8行政執行法第 17 條之 1 規定，義務人為自然人，其滯欠合計達一定金額，已發現之財產不足清償其所負義務，且生活逾越一般人通常程度者，行政執行處得依職權或利害關係人之申請對其核發下列各款之禁止命令。有關禁止命令，下列何者錯誤？

    1. (A) 禁止購買、租賃或使用一定金額以上之商品或服務
    2. (B) 禁止搭乘特定之交通工具
    3. (C) 禁止進入特定之高消費場所消費
    4. (D) 禁止出境、出海

    正解：(D)

  9. 9甲與行政機關締結行政契約，並約定自願接受執行，因未履約而遭行政機關追討違約金，下列何者正確？

    1. (A) 此為公法上金錢給付義務之執行，自得移送行政執行分署依行政執行法追討違約金
    2. (B) 行政機關得以該契約為強制執行之執行名義，移送行政執行分署
    3. (C) 行政機關得以該契約為強制執行之執行名義，向行政法院提起給付訴訟
    4. (D) 行政機關得以該契約為強制執行之執行名義，聲請行政法院強制執行

    正解：(D)

  10. 10下列何者係視同訴願決定？

    1. (A) 依公務人員保障法所為之再申訴決定
    2. (B) 律師懲戒委員會之懲戒決議
    3. (C) 民間之公證人懲戒委員會之懲戒決議
    4. (D) 政府採購申訴審議委員會之審議判斷

    正解：(D)

  11. 11甲公司申請進口管制藥品遭主管機關予以否准，其除提起行政救濟外，甲公司欲提起暫時性權利保護，應提起下列何者？

    1. (A) 原否准處分停止執行
    2. (B) 假處分
    3. (C) 假扣押
    4. (D) 假執行

    正解：(B)

  12. 12行政訴訟法第 10 條規定，選舉罷免事件之爭議，除法律別有規定外，得依本法提起行政訴訟。請問有關此一條文之解釋，下列何者正確？

    1. (A) 所謂法律別有規定，係指公職人員選舉罷免法、總統副總統選舉罷免法而言
    2. (B) 選舉無效之訴得依行政訴訟法提起行政訴訟
    3. (C) 當選無效之訴得依行政訴訟法提起行政訴訟
    4. (D) 依行政訴訟法提起之選舉罷免訴訟，其訴訟類型不以撤銷訴訟、確認訴訟及給付訴訟為限

    正解：(A)

  13. 13土地法第 68 條第 1 項規定：「因登記錯誤遺漏或虛偽致受損害者，由該地政機關負損害賠償責任。但該地政機關證明其原因應歸責於受害人時，不在此限」。有關此一條文之解釋，下列何者錯誤？

    1. (A) 該條規定為國家賠償法之補充規定，關於國家賠償的要件自應優先適用國家賠償法
    2. (B) 該規定文義既未明示以登記人員之故意或過失為要件，原則上自應由地政機關就登記不實之結果，負無過失之賠償責任
    3. (C) 除非該地政機關能證明其原因應歸責於受害人，否則即應負損害賠償責任
    4. (D) 該不實登記是否因受害人以外之第三人行為所致，皆不影響該條規定之適用

    正解：(A)

  14. 14依行政程序法之規定，下列何者非屬書面之行政處分得不記明理由之情形？

    1. (A) 處分相對人無待處分機關之說明已知悉作成處分之理由者
    2. (B) 一般處分經公告或刊登政府公報或新聞紙者
    3. (C) 有關專門知識、技能或資格所為之考試、檢定或鑑定等程序
    4. (D) 行政處分所根據之事實，客觀上明白足以確認者

    正解：(D)

  15. 15依最高行政法院裁判見解，人民如依政府資訊公開法請求政府機關提供政府資訊遭拒，而欲循序提起行政訴訟以資救濟，應提起何種類型之行政訴訟？

    1. (A) 撤銷訴訟
    2. (B) 確認訴訟
    3. (C) 一般給付訴訟
    4. (D) 課予義務訴訟

    正解：(D)

  16. 16A 所有之土地被徵收，其對徵收補償價額不服，依土地徵收條例第 22 條第 2 項規定以書面提出異議，經主管機關為維持原補償價額之查處，A 對於該查處結果如有不服，應提起何種類型之行政訴訟以資救濟？

    1. (A) 撤銷訴訟
    2. (B) 課予義務訴訟
    3. (C) 確認訴訟
    4. (D) 一般給付訴訟

    正解：(B)

  17. 17依最高行政法院及司法院大法官解釋，下列何者非屬行政契約？

    1. (A) 公路監理機關與汽車修理業所締結之委託辦理汽車定期檢驗合約書
    2. (B) 退除役軍職人員與臺灣銀行所訂立之優惠存款契約
    3. (C) 中央健康保險署與醫事服務機構所締結之全民健康保險特約醫事服務機構合約
    4. (D) 地方主管機關與都市計畫區域內人民所締結之都市計畫回饋措施協議書

    正解：(B)

  18. 18依行政罰法之規定，關於行政罰裁處程序之敘述，下列何者正確？

    1. (A) 扣留物於案件終結前無留存之必要者，原則上應毀棄之
    2. (B) 物之所有人對於扣留不服者，得向扣留機關之上級機關聲明異議
    3. (C) 行政機關所為之裁處，係根據客觀上明白且足以確認之事實者，仍應給予受處罰者陳述意見之機會
    4. (D) 行政機關為命令歇業之裁罰性不利處分前，原則上應依受處罰者之申請，舉行聽證

    正解：(D)

  19. 19依最高行政法院庭長法官聯席會議決議之見解，下列何者為行政處分？

    1. (A) 公立高中以下學校或主管機關對所屬（轄）教師所為之年終成績考核或平時考核獎懲
    2. (B) 人民團體職員異動，而依人民團體法第 54 條規定將職員簡歷冊報請主管機關核備，主管機關所為核備之行為
    3. (C) 公寓大廈管理委員會成立後依公寓大廈管理條例及相關子法規定向主管機關報備，主管機關所為同意報備之行為
    4. (D) 檢舉人以第三人違反公平交易法規定而向公平交易委員會檢舉，該會對檢舉人所為「檢舉不成立」之函文

    正解：(A)

  20. 20依行政執行法之規定，關於行政執行程序，下列何者錯誤？

    1. (A) 行政執行原則上不得於夜間為之；但日間已開始執行者，得繼續至夜間
    2. (B) 執行時有遭遇抗拒之虞者，執行機關得於必要時請求其他機關協助執行
    3. (C) 公法上金錢給付義務人經合法通知而無正當理由不到場，其滯欠金額合計新臺幣 5 萬元，且已出境三次者，得限制住居
    4. (D) 拘提、管收之聲請，應向行政執行分署所在地之地方行政法院為之

    正解：(D)

  21. 21依行政執行法之規定，下列何者非屬直接強制方法？

    1. (A) 收繳、註銷證照
    2. (B) 斷絕營業所必須之自來水
    3. (C) 封閉建築物
    4. (D) 對於人之管束

    正解：(D)

  22. 22依最高行政法院庭長法官聯席會議決議之見解，人民不服行政執行分署對其所為具有行政處分性質之執行命令，依行政執行法第 9 條規定聲明異議遭駁回後，應以何機關為訴願管轄機關？

    1. (A) 行政執行署
    2. (B) 法務部
    3. (C) 行政院
    4. (D) 毋庸另行提起訴願，即得提起行政訴訟

    正解：(D)

  23. 23依行政程序法之規定，關於公務員迴避之敘述，下列何者正確？

    1. (A) 公務員於該事件，曾為證人之配偶者，應自行迴避
    2. (B) 當事人申請公務員迴避經行政機關駁回者，得於 30 日內提請上級機關覆決，受理機關原則上應於 10 日內為適當之處置
    3. (C) 當事人申請公務員迴避而不服行政機關之決定者，原則上僅得於對實體決定聲明不服時一併聲明之
    4. (D) 被申請迴避之公務員在其所屬機關為准許或駁回之決定前，應先行停止職務。但有急迫情形，仍應為必要處置

    正解：(C)

  24. 24依行政訴訟法之規定，下列何者非屬行政法院得不經言詞辯論，逕以判決駁回之情形？

    1. (A) 原告之訴欠缺權利保護必要
    2. (B) 原告之訴有誤列被告機關以外之當事人不適格情形
    3. (C) 原告之訴依其所訴之事實，在法律上顯無理由
    4. (D) 原告之起訴係基於濫用訴訟程序之目的，且事實上或法律上之主張欠缺合理依據

    正解：(D)

  25. 25依行政罰法規定，關於裁處權時效，下列何者正確？

    1. (A) 同時觸犯刑事法律及違反行政法上義務規定之行為，經緩起訴處分確定者，其裁處權時效司法機關將案件移送至管轄之行政機關時起算
    2. (B) 行政罰之裁處因訴願程序經撤銷而須另為裁處者，其裁處權時效自訴願決定送達裁處相對人時起算
    3. (C) 因天災而停止進行之裁處權時效，自天災原因消滅之當日起，與停止前已經過之期間合併計算
    4. (D) 如法規不以發生某種結果為處罰要件時，縱實際上發生結果，仍應以行為終了時為裁處權時效之起算日

    正解：(D)
