  1. 1下列何者為典型中央處理器（processor）必須具備的部分？

    1. (A) 輸入單元
    2. (B) 輸出單元
    3. (C) 儲存單元
    4. (D) 控制單元

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 中央處理器由算術邏輯單元與控制單元組成，控制單元負責指令的解碼與各部件的協調，是必備的部分。

    ❌ (A) 輸入單元屬周邊裝置，不在處理器內。

    ❌ (B) 輸出單元同屬周邊裝置。

    ❌ (C) 儲存單元指主記憶體，位於處理器之外（處理器內僅有暫存器與快取）。

    📚 出處：計算機概論；電腦的五大單元。

  2. 2建構於國家高速網路與計算中心的臺灣杉三號，擁有 900 個計算節點，共 50,400 個計算核心（Cores）。依照電腦的分類，臺灣杉三號屬於：

    逐題詳解（免費試讀）

    ✅ (B) 臺灣杉三號以大量計算節點與核心進行高效能平行運算，屬超級電腦系統。

    ❌ (A) 嵌入式系統為特定用途的小型控制系統。

    ❌ (C) 超純量是處理器的微架構設計，非電腦的分類。

    📚 出處：計算機概論；電腦的分類。

  3. 3有關計算機結構之敘述，下列何者正確？

    1. (A) SCSI 是一種計算機體系結構，可利用多個指令流對多個數據流進行操作
    2. (B) RISC 代表遞迴指令集計算機（recursive instruction set computer）
    3. (C) CISC 代表完整指令集計算機（complete instruction set computer），它具有大量指令集
    4. (D) SIMD 代表單指令流、多數據流

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) SIMD 為 Single Instruction stream, Multiple Data stream，即單指令流、多數據流。

    ❌ (A) SCSI 是周邊設備的介面標準，非計算機體系結構；多指令流多數據流者為 MIMD。

    ❌ (B) RISC 代表精簡指令集計算機（reduced instruction set computer）。

    ❌ (C) CISC 代表複雜指令集計算機（complex instruction set computer）。

    📚 出處：計算機結構；Flynn 分類法。
