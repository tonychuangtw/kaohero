醫事檢驗師　115 年第二次 微生物學與臨床微生物學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1有關 Hugh and Leifson's Oxidative-Fermentative（OF）培養基的敘述，下列何者正確？

    1. (A) carbohydrate 和 peptone 比例為 1：5
    2. (B) carbohydrate 和 peptone 比例為 5：1
    3. (C) 指示劑為 phenol red
    4. (D) 指示劑為 neutral red

    正解：(B)

  2. 2有關生物安全操作櫃的敘述，下列何者正確？

    1. (A) 第一類生物安全操作櫃適用於生物安全等級第四級的實驗室
    2. (B) A 型第二類生物安全操作櫃適用於有毒化學物質的操作
    3. (C) B 型第二類生物安全操作櫃 70％空氣通過 HEPA 再循環
    4. (D) 第三類生物安全操作櫃提供操作人員最高級保護

    正解：(D)

  3. 3有關細菌基因組（genome）的敘述，下列何者最不適當？

    1. (A) 細菌的基因組包含染色體（chromosome）以及 mobilome（mobile genetic elements）
    2. (B) 細菌在複製的過程中有可能失去質體（plasmid）
    3. (C) Transposable elements 可以在質體以及染色體間移動
    4. (D) Insertion sequence（IS）經常攜帶多種抗藥性基因

    正解：(D)

  4. 4下列何者最適於區分 Acinetobacter baumannii 與 Acinetobacter lwoffii？

    1. (A) 運動性（motility）
    2. (B) 氧化酶（oxidase）反應
    3. (C) β溶血（β-hemolysis）反應
    4. (D) 葡萄糖氧化（glucose oxidizer）

  16. 16有關金黃色葡萄球菌（Staphylococcus aureus）的致病因子敘述，下列何者錯誤？

    2. (B) 蛋白質 A（protein A）會使宿主血液中的 fibrin 產生凝集並附著於菌體表面而逃避吞噬細胞的作用

    4. (D) Löwenstein-Jensen

    正解：(B)

  59. 59下列關於β-內醯胺酶抑制劑（β-lactamase inhibitor）之敘述，何者最不適當？

    1. (A) 單獨使用時效果很弱
    2. (B) 作用機制為直接抑制細菌細胞壁合成
    3. (C) 結合β-lactam 類抗生素使用時具協同效果（synergy）
    4. (D) 會與β-lactamase 結合使之失效

    正解：(B)

  60. 60下列何者不是細菌對β-lactam 類抗生素產生抗藥性的主要原因？

    1. (A) 產生β-lactamase
    2. (B) PBPs 改變
    3. (C) 降低抗生素之吸收
    4. (D) 細菌分裂速率增加

    正解：(D)

  61. 61下列何種細菌最不常見於泌尿道感染？

    1. (A) 腐生葡萄球菌（Staphylococcus saprophyticus）

    3. (C) 綠膿桿菌（Pseudomonas aeruginosa）
    4. (D) 流行性感冒嗜血桿菌（Haemophilus influenzae）

    正解：(D)

  62. 62淋病患者的採檢流程，下列何者最不適當？

    1. (A) 生殖道採檢拭子有兩套，其一可直接抹片檢查
    2. (B) 採檢後檢體運送要保持低溫
    3. (C) 接種檢體於 chocolate agar 或 modified Thayer-Martin agar
    4. (D) 接種之培養基置入 3～5％二氧化碳培養箱

    正解：(B)

  63. 63一位養豬場獸醫師手指浮腫且出現紫斑，反覆發燒，經血液培養為革蘭氏陽性桿菌，Columbia blood agarplate（BAP）上呈現α-溶血，catalase (－)，oxidase (－)，具 gelatinase，最可能為下列何種病原菌？

  68. 68患者因肩頸處出現明顯的色斑（如圖 1），色斑表面不凸起但有脫屑的現象。Wood's lamp 檢查呈現黃綠色螢光。KOH 直接鏡檢，可發現約 4～8 μm 的 budding yeasts，以及分隔的菌絲，呈意大利麵和肉丸狀外觀（如圖 2），此致病菌最可能是下列何者？

  69. 69以病患頭髮染色鏡檢發現髮軸（hair shaft）充滿關節孢子（arthroconidia），具 endothrix 特徵，最可能為下列何種真菌感染？

  72. 72有關暗色絲狀菌病（phaeohyphomycosis）的特性，下列敘述何者最適當？

    2. (B) 病原的菌絲較寬且沒有中隔（septa），生長速度較快
    3. (C) 受感染組織的病理切片可見褐色銅板狀的硬化體（sclerotic bodies）
    4. (D) 病原的菌絲中具有黑色素

  76. 76有關疾病與病原菌之配對，下列何者最不適當？

    2. (B) Q 熱（Query fever）／貝氏考克斯菌（Coxiella burnetii）
    3. (C) 鼠咬熱（rat-bite fever）／念珠狀鏈桿菌（Streptobacillus moniliformis）
    4. (D) 回歸熱（relapsing fever）／伯氏疏螺旋體（Borrelia burgdorferi）

  77. 77為測定高壓蒸氣滅菌法的效果，常用的生物指示劑為下列何者？

  78. 78有關使用抗生素所引起之偽膜性腸炎（pseudomembranous colitis）的敘述，下列何者最不適當？

    1. (A) 皆為外源性（exogenous）感染之疾病
    2. (B) 常由艱難梭狀桿菌（Clostridioides difficile）所引起
    3. (C) 糞菌移植（fecal microbiota transplantation）通常具療效
    4. (D) 可以甲硝達唑（metronidazole）或萬古黴素（vancomycin）治療

  79. 79有關使用暗視野顯微鏡觀察微生物之敘述，下列何者最適當？

    1. (A) 須製片染色
    2. (B) 微生物體表會出現螢光
    3. (C) 常用於綠膿桿菌的檢測
    4. (D) 主要用於螺旋體的觀察

    正解：(D)

  80. 80有關革蘭氏染色法（Gram stain）在臨床微生物診斷上之應用，下列何者最不適當？

    1. (A) 細菌培養過久而老化會改變菌體的染色性
    2. (B) 革蘭氏染色法不適用於對臨床檢體的直接染色鏡檢
    3. (C) 抑制菌體細胞壁合成之抗生素，容易造成革蘭氏陽性細菌對脫色液之敏感性增加
    4. (D) 嗜中性球之細胞核經革蘭氏染色後，常呈粉紅色

    正解：(B)
