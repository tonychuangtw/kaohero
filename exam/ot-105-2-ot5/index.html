職能治療師　105 年第二次 小兒職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1依據馬斯洛（Maslow）的理論，下列需求滿足的順序何者正確？

    2. (B) 生理需求先於愛與歸屬感
    3. (C) 自尊在自我實現之後
    4. (D) 愛與歸屬感在自尊之後

    正解：(B)

    3. (C) 8～9歲
    4. (D) 11～12歲

    3. (C) 在此遊戲類型中個體主要是和他人產生互動
    4. (D) 此遊戲類型對認知的發展幾乎沒有影響

    4. (D) 提供單一視覺訊息

  5. 5關於半邊痙攣型腦性麻痺兒童（spastic hemiplegia）的手部功能，有關目前的研究發現，下列何者正確？

  17. 17有關各種遊戲型態（types of play）的功能之敘述，下列何者正確？

    4. (D) 建構遊戲（constructional play）使個案對各種生活角色有更進一步的認識

  18. 18根據柴特林（Zeitlin）等人所提出的適應參考架構（coping frame of reference），下列有關適應型態的敘述，何者正確？

    4. (D) 適應型態是後天習得的行為模式而非先天的人格特質
