初等考試　115 年 初等考試 運輸學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1若某機場跑道方位為 18/36，表示機場周邊最可能盛行何種風向？

    1. (A) 東北風與西南風
    2. (B) 東南風與西北風
    3. (C) 東風與西風
    4. (D) 北風與南風

    正解：(D)

  2. 2關於道路平面交叉之敘述，何者錯誤？

    1. (A) 交角以直角為佳
    2. (B) 斜交時其相交銳角不宜小於 60 度
    3. (C) 宜避免大於四支交叉狀況
    4. (D) 路口交通量大時宜採用環形交叉

    正解：(D)

  3. 3公路上情況良好時，車輛所能維持的最大安全速率稱為：

    1. (A) 可運行速率
    2. (B) 設計速率
    3. (C) 行車速率
    4. (D) 速限

    正解：(B)

  4. 4客座利用率是鐵路運輸的重要營運指標，其計算方式為：

    1. (A) 延人公里 ÷ 客座公里
    2. (B) 延人公里 ÷ 班次數
    3. (C) 旅客人數 ÷ 客座數
    4. (D) 旅客人數 ÷ 客座公里

    正解：(A)

  5. 5鐵路法定義之高速鐵路係指列車營運速度達每小時 200 公里以上之鐵路，台灣高鐵系統的最高營運速度是每小時多少公里？

    1. (A) 200
    2. (B) 250
    3. (C) 300
    4. (D) 350

    正解：(C)

  6. 6關於桃園國際機場興建中的第三跑道，下列敘述何者正確？

    1. (A) 跑道長度 4000 公尺，可起降大型飛機
    2. (B) 跑道方位與既有兩條跑道不同，以因應各種風向之運作
    3. (C) 位於既有的北跑道與南跑道之間
    4. (D) 利用機場既有用地，無須新增用地

    正解：(A)

  7. 7在鐵路路線上劃設若干閉塞區間，同一時間內一個閉塞區間只允許一部列車通過，此種閉塞區間隔離方法是：

    1. (A) 隔地法
    2. (B) 隔人法
    3. (C) 隔空法
    4. (D) 隔時法

    正解：(A)

  8. 8有關 RO/RO 船的敘述，何者錯誤？

    1. (A) 又稱作滾裝船
    2. (B) 需藉由船上或碼頭邊的起重設備將貨物吊掛搬運
    3. (C) 專門載運有輪貨物，例如汽車、卡車或拖車等之船舶
    4. (D) 英文全名為 Roll-on/Roll-off Ship

    正解：(B)

  9. 9其他條件不變下，當旅行時間縮減 1/2 時，可使運輸服務的圓周範圍改變多少？

    1. (A) 不變
    2. (B) 減少 1/4
    3. (C) 增加 4 倍
    4. (D) 減少 4 倍

    正解：(C)

  10. 10下列何者與 PIEV 的說明無關？

    1. (A) 指在人－車處理系統中，駕駛人從看、聽、感受蒐集到之交通情報，經思考、判斷以致決策並採取反應行動的過程
    2. (B) P：認知、I：辨明、E：激起情緒、V：執行意志
    3. (C) 一般人的 PIEV 時間約是 0.5 秒至 4 秒
    4. (D) 一般人兩眼直視時，明視錐角的範圍介於 3°至 5°之間

    正解：(D)

  11. 11複合運輸中鐵路僅擔任港口與其附近地區或內陸城市之間的鐵路貨櫃運輸，稱為：

    1. (A) 陸橋作業
    2. (B) 迷你陸橋作業
    3. (C) 微陸橋作業
    4. (D) 鐵路運載貨櫃作業

    正解：(C)

  12. 12COFC 指的是那一種複合運輸方式？

    1. (A) 將貨櫃連同拖車由鐵路載運
    2. (B) 僅將拖車由鐵路載運
    3. (C) 僅將貨櫃由鐵路載運
    4. (D) 將貨櫃內的貨物卸下，再將貨物以鐵路載運

    正解：(C)

  13. 13垂直運輸系統中的電梯運行設計，與那一種運輸系統運行方式最為相似？

    1. (A) 管道運輸
    2. (B) 海運運輸
    3. (C) 航空運輸
    4. (D) 公車系統

    正解：(D)

  14. 14（本題題幹與選項都在圖上，請見下圖作答）

    正解：(B)

  15. 15下列何種運輸方式不具「空車回程」特性？

    1. (A) 管道運輸
    2. (B) 航空運輸
    3. (C) 輪船運輸
    4. (D) 鐵路運輸

    正解：(A)

  16. 16正等邊三角形一般屬於何種交通標誌？

    1. (A) 警告標誌
    2. (B) 禁制標誌
    3. (C) 指示標誌
    4. (D) 施工標誌

    正解：(A)

  17. 17造成人員當場或 24 小時內死亡之交通事故，被歸為那一類交通事故？

    1. (A) A1
    2. (B) A2
    3. (C) A3
    4. (D) A4

    正解：(A)

  18. 18在車輛行進中遇到非預期或較複雜的資訊、路況，可能影響駕駛人辨識或認知其潛在危險性，駕駛人仍得以充分、有效地變換適當車道、車速、車向或停止，完成安全駕駛所需之距離。此為何種視距？

    1. (A) 停車視距
    2. (B) 超車視距
    3. (C) 轉向視距
    4. (D) 應變視距

    正解：(D)

  19. 19港口貨櫃吞吐量常使用 TEU 為單位，TEU 係指長度為多少的貨櫃？

    1. (A) 10 英尺
    2. (B) 12 英尺
    3. (C) 20 英尺
    4. (D) 40 英尺

    正解：(C)

  20. 20以提供貨物運輸服務為主的公司，被視為何種物流？

    1. (A) 第一方物流
    2. (B) 第二方物流
    3. (C) 第三方物流
    4. (D) 第四方物流

    正解：(B)

  21. 21下列何者屬 B 型路權之公共運輸系統？

  22. 22下列何者未提供自由貿易港區服務？

  23. 23臺灣現有的海空聯運自由貿易港區為：

  32. 32抑制機車成長與使用的策略中，那一項屬於經濟行為的手段？

    1. (A) 機車停車全面收費

    3. (C) 強化車籍管理

    正解：(A)

  33. 33運輸業管制的原因中，下列何者與經濟學理相關？

    1. (A) 運輸業勞動條件的規範
    2. (B) 運輸業投入之固定沉沒成本大，具高度獨占力
    3. (C) 運輸安全影響社會、國家大
    4. (D) 提供弱勢公眾行的機會

    正解：(B)

  34. 34我國航空市場於民國那一年開放天空（開始放寬部分航空管制項目）？

  41. 41有關運輸業「共同成本」的敘述，下列何者錯誤？

    2. (B) 同時產出之多種產品的邊際成本無法明確分擔至消費單位
    3. (C) 又稱為可分割成本
    4. (D) 例如鐵路客車同時載客及貨物或包裹，為服務這兩種產品而產生的成本稱之
