初等考試　112 年 初等考試 會計審計法規大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1第一預備金於何種預算中設定之？

    1. (A) 總預算
    2. (B) 特別預算
    3. (C) 追加預算
    4. (D) 公務機關單位預算

    正解：(D)

  2. 2總預算案應於會計年度開始幾個月前由立法院議決？

    1. (A) 1
    2. (B) 2
    3. (C) 3
    4. (D) 4

    正解：(A)

  3. 3行政院應於年度開始幾個月前，訂定下年度之施政方針？

    1. (A) 3
    2. (B) 6
    3. (C) 9
    4. (D) 11

    正解：(C)

  4. 4附屬單位預算應編入總預算者，在營業基金以外之其他特種基金為何？

    1. (A) 盈餘之應解庫額
    2. (B) 虧損之由庫撥補額
    3. (C) 資本由庫收回額
    4. (D) 由庫撥補額

    正解：(D)

  5. 5為國內外機關、團體或私人之利益，依所定條件管理或處分者，為何種基金？

    1. (A) 信託基金
    2. (B) 營業基金
    3. (C) 作業基金
    4. (D) 普通基金

    正解：(A)

  6. 6誤付透付之金額及依法墊付金額，或預付估付之賸餘金額，在會計年度結束後繳還者，均視為結餘，轉帳加入下年度之何項？

    1. (A) 收入
    2. (B) 支出
    3. (C) 資產
    4. (D) 負債

    正解：(A)

  7. 7各機關有何種情形時，得經行政院核准動支第二預備金？

    1. (A) 國防緊急設施或戰爭
    2. (B) 依法律增設新機關時
    3. (C) 依法律增加業務或事業致增加經費時
    4. (D) 因應政事臨時需要必須增加計畫及經費時

    正解：(D)

  8. 8各機關執行歲出分配預算遇經費有不足時，應報請何者核定，始得支用第一預備金？

    1. (A) 審計機關
    2. (B) 上級主管機關
    3. (C) 中央主計機關
    4. (D) 中央財政主管機關

    正解：(B)

  9. 9政府各機關辦理政策及業務宣導之預算，應多久於機關資訊公開區公布宣導主題、媒體類型、期程、金額、執行單位等事項？

    1. (A) 按週
    2. (B) 按月
    3. (C) 按季
    4. (D) 按年

    正解：(B)

  10. 10依預算法第 83 條，特別預算係由何者提出？

    1. (A) 各機關
    2. (B) 各主管機關
    3. (C) 行政院
    4. (D) 總統

    正解：(C)

  11. 11各機關因何種情形得請求提出追加歲出預算？

    1. (A) 重大災變
    2. (B) 國家經濟重大變故
    3. (C) 不定期或數年一次之重大政事
    4. (D) 所辦事業因重大事故經費超過法定預算時

    正解：(D)

  12. 12預算法第 88 條有關附屬單位預算之執行彈性，其規定每筆數額營業基金幾億元以上，其他基金幾億元以上者，應送立法院備查？

    1. (A) 3，2
    2. (B) 3，1
    3. (C) 5，3
    4. (D) 5，2

    正解：(B)

  13. 13經濟部智慧財產局之分配預算，應由下列何者核定？

    1. (A) 該局主計室
    2. (B) 經濟部會計處
    3. (C) 行政院主計總處
    4. (D) 財政部

    正解：(C)

  14. 14下列何者非屬單位預算之預算彈性機制？

    1. (A) 追加預算
    2. (B) 經費流用
    3. (C) 動支第一預備金
    4. (D) 超支併決算

    正解：(D)

  15. 15由特定營業基金所編製，作為其編製預算之依據者為何？

    1. (A) 事業計畫
    2. (B) 施政計畫
    3. (C) 事業計畫總綱
    4. (D) 業務計畫

    正解：(D)

  16. 16營業基金預算中，以下何者不須編入總預算？

    1. (A) 盈餘應解庫額
    2. (B) 虧損由庫撥補額
    3. (C) 公積轉帳增資額
    4. (D) 資本由庫收回額

    正解：(C)

  17. 17下列何者並非預算法強制要求行政院應編製之資料？

    1. (A) 綠色國民所得帳
    2. (B) 國民幸福指數
    3. (C) 稅式支出
    4. (D) 移轉性支付

    正解：(B)

  18. 18會計報告、帳簿及重要備查帳或憑證內之記載，繕寫錯誤於事後發現且影響結數者，該如何處置？

    1. (A) 由原登記員更正，並於更正處簽名或蓋章證明
    2. (B) 由主辦會計更正，並於更正處簽名或蓋章證明
    3. (C) 無需處理，等待錯誤於後續年度自動抵銷
    4. (D) 另製傳票更正之

    正解：(D)

  19. 19非政府機關代理政府事務者，其報告與會計人員之報告發生差額時，應由何者加編差額解釋表？

    1. (A) 會計人員
    2. (B) 出納人員
    3. (C) 內部稽核人員
    4. (D) 審計人員

    正解：(A)

  20. 20依據會計法規定，各該政府主計機關之會計總報告，與其政府之公庫、財物經理、徵課、公債、特種財物及特種基金等主管機關之報告發生差額時，應由何者製表解釋之？

    1. (A) 該管審計機關
    2. (B) 該政府主計機關
    3. (C) 該政府財政主管機關
    4. (D) 該政府政風機關

    正解：(A)

  21. 21根據會計法規定，內部審核之範圍為何？

    1. (A) 事前審核、事後複核
    2. (B) 財務審核、財物審核、工作審核
    3. (C) 報表審核、遵循審核、作業審核
    4. (D) 書面審核、實地抽查

    正解：(B)

  22. 22關於審計之各種章則及書表格式，由何者定之？

    1. (A) 監察院
    2. (B) 審計部
    3. (C) 審計處
    4. (D) 立法院

    正解：(B)

  23. 23有關會計人員行使內部審核之職權，下列敘述何者錯誤？

    1. (A) 得查閱簿籍、憑證暨其他文件
    2. (B) 得檢查現金、財物
    3. (C) 在取得機關主辦會計之同意下，即可封鎖各項有關簿籍、憑證或其他文件
    4. (D) 遇有詢問相關業務時，相關負責人不得隱匿或拒絕

    正解：(C)

  24. 24下列何者並非普通公務之會計事務？

    1. (A) 公務歲計之會計事務
    2. (B) 公務出納之會計事務
    3. (C) 公務債務之會計事務
    4. (D) 公務財物之會計事務

    正解：(C)

  25. 25根據會計法規定，各種會計報告、帳簿及重要備查簿，與機器處理會計資料之貯存體暨處理手冊，自總決算公布或令行日起，在分會計、附屬單位會計之分會計至少應保存幾年？

    1. (A) 20 年
    2. (B) 10 年
    3. (C) 5年
    4. (D) 2年

    正解：(C)

  26. 26決算所列各項應收款、應付款、保留數準備，於其年度終了屆滿幾年，而仍未能實現者，可免予編列？

    2. (B) 2
    3. (C) 3
    4. (D) 4

  27. 27直轄市山地原住民區之會計屬下列何種？

    3. (C) 附屬單位會計
    4. (D) 附屬單位會計之分會計

    正解：(A)

  28. 28歲入收支登記簿為何種帳簿？

    2. (B) 特種序時帳簿

    4. (D) 明細分類帳簿

  29. 29各單位會計機關及各附屬單位會計機關半年度報告之編送，應於期間經過後幾日內送出？

    3. (C) 15

  30. 30下列有關各機關或基金應辦理結帳之時點，何者錯誤？

    4. (D) 會計事務之主管或主辦人員交代時

  31. 31計畫、預算之執行與控制之審核，係稱為何者？

  32. 32會計佐理人員辦理交代，應由何者監交？

    2. (B) 主辦會計人員

  33. 33主辦會計人員之請假或出差，應呈請該管上級機關之主辦會計人員或主計機關指派人員代理；其期間不逾幾個月者，得自行委託人員代理？

    2. (B) 2
    3. (C) 3
    4. (D) 4

  34. 34立法院應於審核報告送達後幾個月內完成其審議？

  35. 35審計機關審核政府總決算，應注意何項效能？

  36. 36附屬單位決算中關於營業基金決算之主要內容，下列何者錯誤？

    2. (B) 實際預計之比較
    3. (C) 現金流量之情形
    4. (D) 盈虧撥補之擬議

    正解：(B)

  37. 37國庫之年度出納終結報告，應於年度結束後幾日內，分送中央主計機關及審計機關查核？

    1. (A) 10 日內
    2. (B) 15 日內
    3. (C) 20 日內
    4. (D) 25 日內

    正解：(D)

  38. 38依決算法第 25 條規定，審計機關審核決算時，如有修正之主張，應即通知原編造決算之機關限期答辯。逾期不答辯者，審計人員應如何處置？

    1. (A) 應報告該管審計機關，通知各該機關長官處分承辦人員
    2. (B) 應予催告
    3. (C) 視為同意修正
    4. (D) 呈請監察院核辦

    正解：(C)

  39. 39臺北市政府之總會計制度的設計、會商及核定機構，依序分別為何？

    1. (A) 臺北市政府主計處、臺北市審計處、臺北市政府
    2. (B) 臺北市政府主計處、臺北市審計處、審計部
    3. (C) 行政院主計總處、審計部、臺北市政府
    4. (D) 臺北市政府主計處、臺北市審計處、行政院主計總處

    正解：(D)

  40. 40各機關經管現金、票據、證券、財物或其他資產，如有遺失、毀損，或因其他意外事故而致損失者，經審計機關查明未盡善良管理人應有之注意時，何者應負損害賠償之責？

  41. 41依審計法規定，公務機關分配預算，如與法定預算或有關法令不符者，審計機關應如何處置？

  44. 44中央政府年度總決算，應由審計部於行政院提出後幾個月內完成其審核，並提出審核報告於立法院？

  46. 46各機關對於審計機關之聲復決定不服時，得聲請覆議。聲請覆議，以幾次為限？

  48. 48審計人員發覺各機關人員有財務上不法或不忠於職務上之行為，其涉及刑事者，應移送下列那一單位辦理，並報告於監察院？
