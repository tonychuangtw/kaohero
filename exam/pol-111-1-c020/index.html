警察特考　111 年 四等考試 海巡法規概要（一般警察・水上警察人員輪機組組）　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關懲治走私條例所規定之「管制物品」，下列何者係由行政院公告？

    1. (A) 管制物品項目及其數額
    2. (B) 管制品項及管制方式
    3. (C) 管制進出口物品稅則
    4. (D) 管制進出口物品及管制方式

    正解：(B)

  2. 2依海岸巡防法等規定，海巡機關與海關經常合作破獲走私案件，有關雙方之協調聯繫，下列敘述何者正確？①通商口岸查緝走私工作由海關辦理 ②兩機關間依法令須相互委託執行之事項，應依行政執行法相關規定辦理 ③兩機關間相互請求協助事項所需經費，彼此各分攤一半 ④海域、海岸、河口及非通商口岸，由海巡機關負責查緝及調查

    1. (A) ①②③
    2. (B) ①②④
    3. (C) ①④
    4. (D) ②④

    正解：(C)

  3. 3依海岸巡防法等規定，海岸巡防機關與交通部及所屬機關間之協調聯繫辦法，下列何者正確？

    1. (A) 依任務需要彼此派駐人員，以建立協商機制
    2. (B) 依相關法規彼此提供氣象、水文、車籍、船籍資料
    3. (C) 有關通信資源，因涉及機密與個資，彼此不互相提供
    4. (D) 彼此提供影響海域安全之預警及雷情資料

    正解：(B)

  4. 4甲基於謀財害命，趁乙在花蓮岸際沙灘遊玩時，持刀殺死乙後逃逸，依海岸巡防法等規定，本案犯罪調查權責，下列敘述何者正確？

    1. (A) 由警察機關調查
    2. (B) 由海巡機關調查
    3. (C) 警察與海巡機關均可調查，故由先到場者主政
    4. (D) 民眾先向那一機關報案，即由其全程偵辦

    正解：(A)

  5. 5依海岸巡防機關器械使用條例等規定，海巡人員使用器械時，下列敘述何者正確？

    1. (A) 執行搜索、扣押時，遇有抗拒之行為者，得使用捕繩
    2. (B) 使用火箭彈時，應報告署長做合理判斷，於必要限度內使用
    3. (C) 使用瓦斯噴霧器後，不必將經過情形，即時報告該管長官
    4. (D) 使用警棍後，應將經過情形，即時報告該管長官

    正解：(A)

  6. 6依海岸巡防機關器械使用條例規定，海巡人員在登臨可疑船舶時，得命該船舶之特定人，從事一定之行為，下列敘述何者正確？①得命船員停止舉動 ②得命船員將該船舶全部動力關閉 ③船員可以自由活動 ④得命船員高舉雙手

    1. (A) ①②
    2. (B) ②④
    3. (C) ①④
    4. (D) ②③

    正解：(C)

  7. 7依據相關法令，海巡人員執行職務並依規定使用器械致人傷亡者，下列敘述何者正確？

    1. (A) 海巡人員執行職務並依規定使用器械致人死亡者，除給與一次慰撫金新臺幣 200 萬元外，並核實支付喪葬費，最高以新臺幣 30 萬元為限
    2. (B) 海巡人員執行職務並依規定使用器械致人身心中度障礙者，除支付醫療費外，並給與新臺幣 100 萬元之一次慰撫金
    3. (C) 海巡人員執行職務並依規定使用器械致人傷亡者，其醫療費、慰撫金等，由巡防機關編列預算及募款支應之
    4. (D) 海巡人員執行職務並依規定使用器械致人傷亡者，其醫療費、慰撫金等，由巡防機關編列預算及海巡人員支應之

    正解：(B)

  8. 8依海岸巡防法及其相關法令規定，民眾惡意打電話向 118 專線報案，影響海巡機關之運作，下列敘述何者正確？

    1. (A) 故意謊報案件者，第一次處新臺幣 5 千元以上 1 萬元以下罰鍰
    2. (B) 第二次撥打報案專線電話經勸阻不聽者，處新臺幣 6 千元以上 1 萬 2 千元以下罰鍰
    3. (C) 本案應移請警察機關偵辦
    4. (D) 本案應移送地方檢察署偵辦

    正解：(B)

  9. 9我國籍漁船總噸位 30，在臺東綠島東方海域拖網捕魚，相關處罰規定，下列敘述何者正確？

    1. (A) 該漁船若於距岸 50 浬拖網捕魚，則應依中華民國專屬經濟海域及大陸礁層法移送主管機關裁處
    2. (B) 該漁船若於距岸 22 浬拖網捕魚，則應依中華民國領海及鄰接區法移送主管機關裁處
    3. (C) 該漁船若於距岸 10 浬拖網捕魚，則應依漁業法移送主管機關裁處
    4. (D) 該漁船若於距岸 2 浬拖網捕魚，則應依漁業法移送主管機關裁處

    正解：(D)

  10. 10依相關法令規定，外國籍貨輪航經我國臺中領海內，欲下錨停泊，下列敘述何者正確？

    1. (A) 該貨輪若不聽從海巡人員登臨檢查，則依中華民國領海及鄰接區法處罰
    2. (B) 該貨輪若不聽從海巡人員登臨檢查，則依中華民國專屬經濟海域及大陸礁層法處罰
    3. (C) 該貨輪若係機械故障而錨泊檢修，在停船或下錨後，應即通知當地航政主管機關
    4. (D) 該貨輪若屬機械故障而錨泊檢修，在停船或下錨後，應即通知當地海巡機關

    正解：(C)

  11. 11依中華民國領海及鄰接區法等規定，下列何者為我國領海基線？

    1. (A) 小蘭嶼 1（T16）至小蘭嶼 2（T17）
    2. (B) 金門 1（T6）至金門 2（T7）
    3. (C) 漁翁島（T12）至西洞尾（T13）
    4. (D) 吉貝（T10）至空殼嶼（T11）

  12. 12依政府護漁標準作業程序等規定，有關政府護漁作為，下列敘述何者正確？

    1. (A) 我國經濟海域範圍以外，已非政府護漁之範圍
    2. (B) 在臺日協議海域中，我國漁船只有在特別合作海域內才可以捕魚
    3. (C) 在臺日協議海域中，日本漁船只有在特別合作海域內才可以捕魚
    4. (D) 外國漁船未經許可進入我國專屬經濟海域捕魚，應送請漁業主管機關依法處分

    正解：(D)

  13. 13依中華民國專屬經濟海域及大陸礁層法等規定，在我國專屬經濟海域從事海洋科學研究，應遵守及配合之相關規定，下列敘述何者正確？

    1. (A) 應經地方政府之許可，並應接受其管制
    2. (B) 逾規定期限提出申請，且未敘明正當理由者，不予受理
    3. (C) 外國大學校院或學術研究機構，一律向外交部提出申請許可
    4. (D) 相關許可辦法，由科技部會同外交部及教育部定之

    正解：(B)

  14. 14依中華民國專屬經濟海域及大陸礁層法等規定，欲在我國專屬經濟海域從事人工島嶼、設施之建造、使用，應遵守及配合之相關規定，下列敘述何者正確？

    1. (A) 相關許可辦法，由海洋委員會會同科技部及外交部定之
    2. (B) 主管機關為內政部
    3. (C) 應向地方政府申請許可，並應接受其管制
    4. (D) 外國學術研究機構，應向外交部申請許可，並應接受其管制

    正解：(B)

  15. 15依懲治走私條例規定，走私行為之相關處罰，下列敘述何者正確？

  18. 18依海岸巡防法等規定，海關及海巡人員執行查緝走私之相關作為，下列敘述何者正確？

    1. (A) 海關執行查緝走私，得依海岸巡防法之規定，實施路檢
    2. (B) 海巡人員執行查緝走私，遇有急迫情形時，得於管轄區域外蒐集證據，並應立即知會海關

  19. 19依據重大海洋油污染緊急應變計畫之規定，有關應變層級之決定，下列敘述何者正確？

    1. (A) 因海難事件導致海洋污染發生，海洋委員會接獲通報後，決定所需之應變層級
    2. (B) 非因海難事件導致海洋污染發生，行政院環境保護署接獲通報後，決定所需之應變層級
    3. (C) 非因海難事件導致海洋污染發生，交通部接獲通報後，決定所需之應變層級
    4. (D) 因海難事件導致海洋污染發生，交通部接獲通報後，決定所需之應變層級

  20. 20依海洋污染防治法規定，船舶載有重油 250 公噸擱淺於岸際有外洩之虞，船長及船舶所有人未能於主管機關指定之期間內抽除油料，下列處罰何者正確？

  21. 21依據海洋污染防治法相關規定，對於海域環境監測項目之選擇，包括那些？①海域生物 ②海域水質 ③海域棄置 ④海域水文

  22. 22依海洋污染防治法規定，從事海洋棄置應向中央主管機關申請許可，下列何類行為係該法所指之「海洋棄置」？

    1. (A) 利用船舶或海洋設施焚化油品或其他物質，再排放入海洋
    2. (B) 排放廢（污）水、油、廢棄物、有害物質至海洋
    3. (C) 直接或間接將物質或能量引入海洋環境，造成天然資源或自然生態損害之行為
    4. (D) 利用船舶、航空器或其他設施，運送物質至海上傾倒、排洩或處置

    正解：(D)

  23. 23依相關法令規定，大陸貨輪因失去動力漂進我國限制水域內，另一大陸拖船獲報後欲前來拖救，對於該大陸拖船之救援行動，下列敘述何者正確？

    2. (B) 該大陸拖船應向我國海巡機關提出申請，獲得許可後方可進入我國海域執行拖救
    3. (C) 該大陸拖船應向我國大陸委員會先以電話緊急提出申請，獲得許可後方可進入我國海域執行拖救，書面文件則後補
    4. (D) 該大陸拖船應向我國交通部提出申請，獲得許可後方可進入我國海域執行拖救

    正解：(D)

  24. 24大陸漁船越界至我國禁（限）制水域捕魚，依臺灣地區與大陸地區人民關係條例及其施行細則之規定，下列何者正確？

    2. (B) 使用毒物、炸藥或其他爆裂物、電氣或使用底拖方式採捕水產動植物，係屬非法漁業行為
    3. (C) 實際在我國水域執行安全維護、緝私及防衛任務之機關，得逕行驅離或扣留大陸船舶、物品，留置其人員或為必要之防衛處置
    4. (D) 對執行登檢任務之船艦有敵對行為者，得沒入之

  30. 30依國家安全法，海岸巡防機關於必要時，得依其職權實施檢查，下列何者為非？

    1. (A) 岸際觀浪民眾及其所攜帶之物品
    2. (B) 入出境之旅客及其所攜帶之物件
    3. (C) 入出境之船舶之船員及其所攜帶之物件
    4. (D) 航行境內之船筏所載運之物品

    正解：(A)

  31. 31依海關緝私條例處分之緝私案件，應製作處分書送達受處分人。受處分人如不服處分者，得於收到處分書之翌日起算幾日內，以書面向原處分海關申請復查？

    2. (B) 7日
    3. (C) 14 日
    4. (D) 30 日

    正解：(D)

    2. (B) 加重三分之一
    3. (C) 加重一倍
    4. (D) 加重二倍

  33. 33我國籍漁船私運貨物，於我國海域 18 浬處，經海巡機關追緝逃出 24 浬外，為規避查緝將其所載運之貨物拋棄於海中，依海關緝私條例之規定，行為人如何處罰？

    2. (B) 處新臺幣三萬元以上十五萬元以下罰鍰
    3. (C) 處新臺幣五萬元以上二十萬元以下罰鍰
    4. (D) 處新臺幣十萬元以上二十萬元以下罰鍰

  34. 34稽徵關員明知為走私物品而放行，依懲治走私條例之規定如何處罰？

  35. 35我國籍漁船私運大麻種子進口，依懲治走私條例之規定如何處罰？

    4. (D) 處五年以下有期徒刑，得併科新臺幣三百萬元以上罰金

    正解：(A)

  36. 36我國籍漁船載運走私物品，經海岸巡防機關於海上攔檢發現，船員持械拒捕並傷害登檢之海巡人員遭致重傷，依懲治走私條例之規定如何處罰？

    3. (C) 處無期徒刑或七年以上有期徒刑，得併科新臺幣一千萬元以下之罰金
    4. (D) 處無期徒刑或十年以上有期徒刑，得併科新臺幣八百萬元以下之罰金

    正解：(D)

  37. 37任職於某部隊之現役軍人包庇走私，依懲治走私條例之規定如何處罰？

  38. 38依中華民國第一批領海基線、領海及鄰接區外界線之公告，澎湖海域之花嶼、貓嶼、七美嶼等基線是採何種基線？

    正解：(C)
