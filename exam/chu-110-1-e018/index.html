    1. (A) 組合語言（Assembly Language）
    2. (B) C 程式語言（C Language）
    3. (C) Python 語言（Python Language）
    4. (D) 結構化查詢語言（Structured Query Language）

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 組合語言以助憶符號一對一對應機器指令，是四者中最接近機器碼的低階語言。

    ❌ (B) 該語言雖接近硬體，仍屬高階語言。

    ❌ (C) 該語言為直譯式的高階語言。

    ❌ (D) 該語言是資料庫查詢用的宣示性語言。

  2. 2當電腦的電源關閉之後，請問下列設備何者所儲存的資料也會跟著消失？

    1. (A) 基本輸入輸出系統（BIOS）
    2. (B) 隨機存取記憶體（RAM）
    3. (C) 固態硬碟（SSD）
    4. (D) 隨身硬碟（USB Flash Drive）

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 隨機存取記憶體屬揮發性記憶體，斷電後資料即消失。

    ❌ (A) 基本輸入輸出系統存於非揮發性晶片中。

    ❌ (C) 固態硬碟採快閃記憶體，斷電後資料保留。

    ❌ (D) 隨身碟同樣採快閃記憶體，資料不會消失。

    📚 出處：計算機概論——揮發性與非揮發性記憶體
