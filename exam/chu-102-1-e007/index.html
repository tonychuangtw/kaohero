本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1國民年金法有關保險費負擔比例，被保險人為符合法定身心障礙資格領有證明者，下列何者負擔比例是錯誤的？

    1. (A) 輕度身心障礙者負擔百分之四十五，中央主管機關負擔百分之二十七點五，直轄市主管機關或縣（市）主管機關負擔百分之二十七點五
    2. (B) 中度身心障礙者負擔百分之三十，中央主管機關負擔百分之七十
    3. (C) 極重度及重度身心障礙者，由中央主管機關全額負擔
    4. (D) 極重度及重度身心障礙者，由中央主管機關負擔百分之八十

    正解：(D)

  2. 2國民年金法第 40 條及第 41 條規定領取身心障礙或老年年金給付者死亡時，其遺屬得請領遺屬年金給付。受領遺屬年金給付之順序何者正確？

    2. (B) ①配偶及子女②父母③兄弟、姊妹④祖父母⑤孫子女

    4. (D) ①配偶及子女②父母③祖父母④孫子女⑤兄弟、姊妹

    正解：(D)

  3. 3老人福利法中有關老人經濟安全保障方面，下列敘述何者錯誤？

  4. 4社會救助法中規定生活扶助，可視低收入戶成員若屬三種特定情形，主管機關得依其原領取現金給付之金額增加補助。這三種情形不包括下列那一項？

    3. (C) 生活扶助以現金給付為原則
    4. (D) 主管機關得對低收入戶成員增加現金給付金額補助，但最高不得逾百分之四十

    正解：(B)
