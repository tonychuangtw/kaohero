營養師　105 年第二次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何者與胞吞作用（endocytosis）密切相關？

    1. (A) 鑲嵌蛋白（integrin）
    2. (B) 鈣黏附蛋白（cadherin）
    3. (C) 接合蛋白（connexin）
    4. (D) 網格蛋白（clathrin）

    正解：(D)

  2. 2關於食慾的調節，下列敘述何者正確？

    1. (A) 脂肪分泌瘦體素（leptin）促進食慾
    2. (B) 肝臟分泌飢餓素（ghrelin）促進食慾
    3. (C) 消化道分泌膽囊收縮素（cholecystokinin）抑制食慾
    4. (D) 大腦分泌神經胜肽 Y（neuropeptide Y）抑制食慾

    正解：(C)

  3. 3下列何種激素對胰泌素（secretin）有加強作用，可增加胰臟碳酸氫根的分泌？

    1. (A) 膽囊收縮素（cholecystokinin, CCK）
    2. (B) 血管收縮素（angiotensin）
    3. (C) 類升糖素胜肽（glucagon-like peptide, GLP）
    4. (D) 葡萄糖依賴型胰島素控制胜肽（glucose-dependent insulinotropic peptide, GIP）

    正解：(A)

  4. 4關於膽汁的組成與特性，下列敘述何者正確？

    1. (A) 含有膽色素（bilirubin），主要來自於破壞的白血球
    2. (B) 含有碳酸氫根，受到胃泌素刺激而分泌
    3. (C) 在迴腸藉由鈉連結運輸蛋白（Na+-coupled transporter）吸收回到肝臟
    4. (D) 大部分都由糞便排泄出去頁次： 4－2

    正解：(C)

  5. 5有關血管收縮素 II（angiotensin II）的作用，下列敘述何者錯誤？

    1. (A) 可增加醛固酮（aldosterone）之分泌
    2. (B) 可使血管平滑肌收縮
    3. (C) 可引發動物之飲水行為
    4. (D) 可刺激腎素（renin）之分泌

    正解：(D)

  6. 6有關亨利氏環下行支的特性，下列敘述何者正確？

    1. (A) 可分泌氫離子
    2. (B) 可分泌鉀離子
    3. (C) 水分可隨意通透管壁
    4. (D) 抗利尿素（antidiuretic hormone）可提高此處對水分的通透性

    正解：(C)

  7. 7當血液 pH 值降低時，腎臟可藉由下列何種胺基酸的代謝以調節 pH 值？

    1. (A) 精胺酸（arginine）
    2. (B) 甘胺酸（glycine）
    3. (C) 絲胺酸（serine）
    4. (D) 麩醯胺酸（glutamine）

    正解：(D)

  8. 8下列何種荷爾蒙主要藉由細胞核內受體傳遞訊息？

    1. (A) 抗利尿素（antidiuretic hormone, ADH）
    2. (B) 腎上腺素（epinephrine）
    3. (C) 促黃體生成素（luteinizing hormone, LH）
    4. (D) 睪酮素（testosterone）

    正解：(D)

  9. 9在長骨的生長過程中，下列何種荷爾蒙可促進軟骨細胞（chondrocytes）分化？

    1. (A) 腎上腺素（epinephrine）
    2. (B) 胰島素（insulin）
    3. (C) 類胰島素一號生長因子（insulin-like growth factor 1）
    4. (D) 體抑素（somatostatin）

    正解：(C)

  10. 10有關醛固酮（aldosterone）的敘述，下列何者錯誤？

    1. (A) 屬於礦皮質素（mineralocorticoid）
    2. (B) 由腎上腺皮質（adrenal cortex）所產生
    3. (C) 血管收縮素 II（angiotensin II）刺激其分泌
    4. (D) 作用於腎臟，進行鈉離子及水分的排出，以維持血壓的穩定

    正解：(D)

  11. 11如果一正常人之心跳速率為 60 次／分鐘，而心輸出量為 6 公升／分鐘，其心搏出量為多少公升／次？

    1. (A) 0.1
    2. (B) 3.6
    3. (C) 36
    4. (D) 360

    正解：(A)

  12. 12有關血管血小板凝集（platelet aggregation）反應的敘述，下列何者錯誤？

    1. (A) 正常狀態下，血管內皮細胞分泌一氧化氮（NO）會抑制血小板凝集
    2. (B) 正常狀態下，血管內皮細胞分泌前列腺素 I2（prostaglandin I2）會抑制血小板凝集
    3. (C) 血管破裂時，三磷酸腺苷（ATP）的產出增加會促進血小板凝集
    4. (D) 血管破裂時，血栓素 A2（thromboxane A2）的產出增加會促進血小板凝集

    正解：(C)

  13. 13有關凝血（clotting）路徑中凝血酶（thrombin）功能的敘述，下列何者錯誤？

    1. (A) 促進纖維蛋白（fibrin）形成
    2. (B) 活化第 13 凝血因子（factor XIII）
    3. (C) 對凝血酶（thrombin）的形成有正回饋的促進作用
    4. (D) 第 12 凝血因子可促進凝血酶原（prothrombin）轉化形成凝血酶的作用

    正解：(D)

  14. 14發炎物質組織胺（histamine）主要是由下列何者所分泌？

    1. (A) 嗜酸性球（eosinophils）
    2. (B) 肥大細胞（mast cells）
    3. (C) 單核球（monocytes）
    4. (D) 嗜中性球（neutrophils）頁次：4－3

    正解：(B)

  15. 15進食時，小腸會分泌下列何種荷爾蒙增加胰島素（insulin）分泌？

    1. (A) 胃泌激素（gastrin）
    2. (B) 類升糖素胜肽–1（glucagon-like peptide 1）
    3. (C) 類胰島素二號生長因子（insulin-like growth factor 2）
    4. (D) 胃動素（motilin）

    正解：(B)

  16. 16下列何處為負責掌控清醒與睡眠生物時鐘的腦區？

    1. (A) 視丘
    2. (B) 下視丘
    3. (C) 小腦
    4. (D) 大腦前額葉

    正解：(B)

  17. 17下列那一區域的皮膚，其感覺神經元的接（感）受面積（receptive field）最小？

    1. (A) 後背
    2. (B) 嘴唇
    3. (C) 上手臂
    4. (D) 大腿

    正解：(B)

  18. 18下列何者為血漿中最主要的緩衝劑（buffer）？

    1. (A) 蛋白質
    2. (B) 銨根離子（NH4+）= -
    3. (C) 磷酸根離子（HPO4 ）
    4. (D) 重碳酸根離子（HCO3 ）

    正解：(D)

  19. 19有關懷孕時期分泌激素的變化，下列敘述何者錯誤？

    1. (A) 人體絨毛膜性腺激素（hCG）是懷孕早期階段生成的激素
    2. (B) 泌乳激素（prolactin）的分泌會隨懷孕週數增加而減少
    3. (C) 懷孕 3 個月後，胎盤會取代黃體分泌激素的功能
    4. (D) 動情素（estrogen）的血中濃度在懷孕末期，分娩前會升到最高

    正解：(B)

  20. 20奧運體操女選手在進行長期的激烈運動訓練期間，容易造成下列何種現象？

    1. (A) 骨質疏鬆
    2. (B) 暫時停經
    3. (C) 肢端肥大
    4. (D) 乳房變大

    正解：(B)

  21. 21在肌肉內，肝醣合成是由下列何種酵素催化 glucose →glucose-6-phosphate？

    1. (A) glucokinase
    2. (B) protein kinase
    3. (C) lactokinase
    4. (D) hexokinase

    正解：(D)

  22. 22於血糖降低時肌肉中肝醣無法直接作為血糖來源，乃因缺乏下列何種酵素？

    1. (A) glycogen phosphorylase
    2. (B) glycogen synthase
    3. (C) UDP- glucose pyrophosphorylase
    4. (D) glucose-6-phosphatase

    正解：(D)

  23. 23α-D-glucopyranose 和 β-D-glucopyranose 互稱為：

    1. (A) 對掌異構物（enantiomer）
    2. (B) 異位體（anomer）
    3. (C) 表異構物（epimer）
    4. (D) 光學異構物（optical isomer）

    正解：(B)

  24. 24下列何種酵素可催化糖質新生作用（gluconeogenesis）之起始反應（pyruvate → oxaloacetate）？

    1. (A) phosphoenolpyruvate carboxykinase
    2. (B) pyruvate kinase
    3. (C) pyruvate carboxylase
    4. (D) pyruvate dehydrogenase

    正解：(C)

  25. 25關於三酸甘油酯經由糖質新生作用產生葡萄糖之過程，下列敘述何者正確？

    1. (A) 其甘油可轉變成糖質新生的中間物，並使用於葡萄糖之合成
    2. (B) 其脂肪酸經降解後產生的乙醯輔酶 A 是糖質新生的原料
    3. (C) 其脂肪酸經降解後產生的乙醯輔酶 A 可進入 TCA 循環
    4. (D) 其脂肪酸經降解後產生的乙醯輔酶 A 可進入乙醛酸循環

    正解：(A)

  26. 26關於長鏈脂肪酸的 β-氧化作用，下列敘述何者錯誤？

    1. (A) 反應中所參與的酵素複合物含有生物素
    2. (B) FADH2 是氧化過程中的電子攜帶者
    3. (C) NADH 是反應過程所需的電子攜帶者
    4. (D) 15 個碳的脂肪酸至少會產生一分子的丙醯輔酶 A（propionyl-CoA）頁次： 4－4

    正解：(A)

  27. 27下列何者不是三酸甘油酯的生理功能？

    1. (A) 形成細胞膜上的基本成分
    2. (B) 可提供熱能也可貯存能量
    3. (C) 具絕緣功能以對抗低溫環境
    4. (D) 可保護內臟免於機械性傷害

    正解：(A)

  28. 28下列何者是合成固醇類荷爾蒙的重要前質？

    1. (A) 維生素 D
    2. (B) 膽酸
    3. (C) 醌類
    4. (D) 膽固醇

    正解：(D)

  29. 29關於胰島素的敘述，下列何者正確？

    1. (A) proinsulin 經切割後產生 C-peptide 以及胰島素
    2. (B) 胰島素會使許多與代謝相關的關鍵調控酵素磷酸化
    3. (C) 胰島素會結合至 G-protein coupled receptors
    4. (D) 胰島素是由胰臟的 α-細胞產生

    正解：(A)

  30. 30每個 α-螺旋大約含有多少胺基酸殘基？

    1. (A) 2.0
    2. (B) 3.0
    3. (C) 3.6
    4. (D) 4.4

    正解：(C)

  31. 31Valine 是一種具有非極性側鏈之胺基酸，其在下列何種 pH 中是以 zwitterionic form 的型式存在？

    1. (A) 1
    2. (B) 4
    3. (C) 7
    4. (D) 14

    正解：(C)

  32. 32酸、鹼以及加熱可以使蛋白質失去生物功能，此作用稱之為：

    1. (A) denaturation
    2. (B) esterification
    3. (C) hydrogenation
    4. (D) amidation

    正解：(A)

  33. 33對原核生物與真核生物而言，DNA 甲基化反應主要分別發生於 DNA 的何種鹼基上？

    1. (A) adenine；thymine
    2. (B) adenine；cytosine
    3. (C) guanine；thymine
    4. (D) guanine；cytosine

    正解：(B)

  34. 34下列何種 DNA 修復機制常會伴隨發生轉錄作用？

    1. (A) 光修復（photoreactivation）
    2. (B) 鹼基剪除修復（base excision repair）
    3. (C) 複製作用（replication）
    4. (D) 核苷酸剪除修復（nucleotide excision repair）

    正解：(D)

  35. 35嘌呤是經由 guanine deaminase/xanthine oxidase 催化代謝為 xanthine，然後再經由下列何種酵素形成尿酸（uric acid）？

    1. (A) xanthine oxidase
    2. (B) urease
    3. (C) deaminase
    4. (D) dihydrofolate reductase

    正解：(A)

  36. 36糖化皮質類固醇（glucocorticoids）被認為具有抗發炎的功能，是因為它能抑制下列何種蛋白質轉移至細胞核內誘發發炎基因表現？

    1. (A) TNF（tumor necrosis factor）
    2. (B) PDGF（platelet-derived growth factor）
    3. (C) NF-κB（nuclear factor-κB）
    4. (D) IκBα（inhibitor-kappa Bα）

    正解：(C)

  37. 37下列那些代謝過程會產生 NADH？①糖解作用 ②肝醣合成 ③五碳糖磷酸途徑 ④檸檬酸循環 ⑤脂肪酸氧化 ⑥脂肪酸合成 ⑦脂肪酸去飽和系統

    1. (A) ①①①
    2. (B) ①①①
    3. (C) ①①②
    4. (D) ①①④

    正解：(B)

  38. 38在檸檬酸循環中的去羧作用下產生 β-keto group 中間產物的酵素是：

    1. (A) 丙酮酸去氫酶（pyruvate dehydrogenase complex）
    2. (B) 異檸檬酸去氫酶（isocitrate dehydrogenase）
    3. (C) 丙酮酸去羧酶（pyruvate decarboxylase）
    4. (D) α-酮戊二酸去氫酶（α-ketoglutarate dehydrogenase）

    正解：(B)

  39. 39下列何者可消除電子於傳遞鏈流動時所創造的質子梯度？

    1. (A) dinitrophenol（DNP）
    2. (B) cyanide
    3. (C) CO2
    4. (D) methylene blue

    正解：(A)

  40. 40下列何者是調節檸檬酸循環的最重要因子？

    1. (A) acetate/acetyl-CoA
    2. (B) ADP/ATP
    3. (C) succinate/succinyl-CoA
    4. (D) NAD+/NADH

    正解：(D)
