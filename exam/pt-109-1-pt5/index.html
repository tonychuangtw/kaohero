物理治療師　109 年第一次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1頸部結構觸診時，其對應的脊椎椎體位置，下列何者正確？

    1. (A) 舌骨（hyoid bone）－C1
    2. (B) 甲狀軟骨（thyroid cartilage）－C2
    3. (C) 第一環狀軟骨（first cricoid ring）－C4
    4. (D) 頸動脈結節（carotid tubercle）－C6

    正解：(D)

  2. 2個別頸椎觸診時，相對於其他節頸椎結構與動作之敘述，下列何者正確？

    1. (A) 第6節頸椎會因頸椎屈曲及伸展動作有最明顯位移
    2. (B) 第7節頸椎會因頸椎屈曲及伸展動作有最明顯位移
    3. (C) 第1及6節頸椎棘突（spinous process）最明顯
    4. (D) 第5及6節頸椎棘突（spinous process）最明顯

    正解：(A)

  3. 3有關揮鞭式症候群（whiplash syndrome）的敘述，下列何者正確？

    1. (A) 急性期早期活動的目的是要增加頸部肌力
    2. (B) 亞急性期患者會因為頸屈肌群緊繃而導致頸椎前凸（lordosis）角度變平
    3. (C) 亞急性期治療目標在於讓頸部肌肉多休息，避免僵硬
    4. (D) 亞急性期需要強化胸鎖乳突肌肌力

    正解：(B)

  4. 4有關頸椎活動度的敘述，下列何者正確？

    1. (A) C0～C1主要動作是執行轉頭約45度
    2. (B) C1～C2主要是點頭的動作，約前彎5度與後伸直10度
    3. (C) 頸椎在冠狀面（coronal plane）上之正常總活動度約為145～150度
    4. (D) 頸椎在矢狀面（sagittal plane）上之正常總活動度約為130～135度

    正解：(D)

  5. 5下圖為一頸痛患者之頸椎核磁共振影像，患者主訴為頸痛、下肢無力以及感覺異常，治療師發現有Babinski異常現象，則下列何者為最可能之問題？

    4. (D) 頸椎神經根受壓迫，脊髓未受壓迫

    正解：(B)

  6. 6患者主訴頸部主動關節活動度（active range of motion）受限，X光顯示頸椎鈎狀關節（uncinate joints or jointsof Luschka）有增生性骨刺之退化變化，則其頸部活動度受限最大的動作最可能是下列何者？

  7. 7患者因椎間孔狹窄壓迫左側C6神經根，抱怨左手大拇指和食指疼痛。下列何者較能緩解其症狀？

    2. (B) 下頸椎後伸
    3. (C) 上頸椎向右側旋轉
    4. (D) 頸椎向左側彎

  8. 8下列何測試不是用以評估頸椎上運動神經元（upper motor neuron）傷害？

    3. (C) Romberg測試
    4. (D) Bikele's現象

  9. 9因前位頭部姿勢（forward head posture）造成的頸痛處理原則，下列何者最不恰當？

    1. (A) 加強頸部深屈肌（deep neck flexors）的控制訓練
    2. (B) 上斜方肌（upper trapezius）可能被拉長或縮短，進行上斜方肌被動牽張（stretch）前需詳盡評估
    3. (C) 日常活動時需配戴頸圈（cervical collar），防止頸部不必要的肌肉活動升高，並可幫助頸部維持正確姿勢
    4. (D) 對於多數病人而言，須教導正確的動作策略，降低提肩胛肌（levator scapulae）的代償活動

    正解：(C)

  10. 10對於腰部脊椎狹窄（spinal stenosis）患者，下列何動作最容易誘發或加重其神經症狀？

  17. 17根據Saal（1996）研究，下列那些因素可預測腰椎間盤突出患者接受保守治療會有正向的療效？①男性 ②高中畢業以上教育程度 ③交叉直膝抬腿測試（crossed straight leg raise test）呈陰性反應 ④對類固醇療法（corticosteroid treatment）反應不佳

  27. 27有關僵直性脊椎炎（ankylosing spondylitis）與胸椎管狹窄（thoracic spine stenosis）問題的鑑別診斷，下列敘述何者錯誤？

  29. 29有關腰椎的穩定訓練之肌肉再教育，下列敘述何者錯誤？

  30. 30下列關於顳頜關節疼痛或關節障礙的敘述，何者最不恰當？
