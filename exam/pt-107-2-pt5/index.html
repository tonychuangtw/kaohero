物理治療師　107 年第二次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何者為典型頸椎之鈎狀突（uncinate processes）的最主要功能？

    1. (A) 提供椎動脈（vertebral artery）通過其中
    2. (B) 提供椎體間的養分傳送
    3. (C) 協助分散頸椎負重壓力
    4. (D) 限制椎間盤向側面位移

    正解：(D)

  2. 2一位45歲病患敘述頸椎後仰時會增加手麻感覺，但頸椎屈曲及適當休息後通常會減緩症狀，則下列何項問題最有可能？

    1. (A) 頸椎退化（cervical spondylosis）
    2. (B) 頸椎椎管狹窄（cervical spinal canal stenosis）
    3. (C) 頸椎間盤突出（cervical disc herniation）
    4. (D) 頸椎淺層肌肉拉傷（cervical superficial muscle strain）

    正解：(B)

  3. 3根據Sjaastad針對頸因性頭痛（cervicogenic headache）所提出的主要診斷標準，下列何者錯誤？

    1. (A) 只有單側頭痛，且不會換邊
    2. (B) 疼痛程度會隨著頭頸的姿勢而改變
    3. (C) 頸椎的活動度有明顯減少
    4. (D) 雙側頸部、肩部和上臂有模糊的疼痛感覺

    正解：(D)

  4. 4根據Panjabi針對脊椎穩定度之維持所提出的次系統控制理論，神經和回饋機制是屬於下列那一個次系統？

    1. (A) 被動次系統
    2. (B) 主動次系統
    3. (C) 控制次系統
    4. (D) 中央次系統

    正解：(C)

  5. 5關於澳洲學者Gwendolen Jull所提出的顱頸屈曲測試（cranio-cervical flexion test）之描述，下列何者正確？

    1. (A) 主要目的是測試所有頸屈曲肌群之肌力與肌耐力
    2. (B) 需使用生物壓力回饋儀（pressure biofeedback unit），並將之置於下頸椎部位
    3. (C) 患者仰臥時，主要是需做出一個下巴收回且抬頭離開床面的動作
    4. (D) 一般沒有症狀之正常人表現為應至少能在26毫米汞柱下持續10秒收縮，且沒有任何代償動作

    正解：(D)

  6. 6有關維持頸椎前凸（lordosis）之訓練方法，下列何者正確？

    1. (A) 同時加強胸鎖乳突肌（sternocleidomastoid）及多裂肌（multifidus）肌力訓練
    2. (B) 同時放鬆胸鎖乳突肌（sternocleidomastoid）張力及加強多裂肌（multifidus）肌力訓練
    3. (C) 同時加強胸鎖乳突肌（sternocleidomastoid）肌力訓練及放鬆多裂肌（multifidus）張力
    4. (D) 同時放鬆胸鎖乳突肌（sternocleidomastoid）及多裂肌（multifidus）張力

    正解：(B)

  7. 7一位20歲男性於早晨醒來時出現急性頸椎鎖定（acute locking of the cervical spine），且相關症狀包括喉嚨疼痛，則下列敘述何者錯誤？

    1. (A) 常見於頸椎C2～C3
    2. (B) 可能造成頸長肌（longus colli）肌肉痙攣
    3. (C) 可能是椎間盤向後突出造成
    4. (D) 可考慮加入牽引治療

    正解：(C)

  8. 8下列有關椎動脈測試（vertebral artery test）之陽性反應，何者正確？

    1. (A) 下頸椎產生疼痛感
    2. (B) 頸椎活動度受限
    3. (C) 眼球震顫（nystagmus）
    4. (D) 流冷汗（cold sweat）

    正解：(C)

  9. 9所謂的頸部馬鞭式創傷（Whiplash injury）多半發生於被後車追撞時，則通常會造成頸椎的何種動作而導致傷害？

    1. (A) 過伸（hyperextension）
    2. (B) 過屈（hyperflexion）
    3. (C) 旋轉
    4. (D) 側彎

    正解：(A)

  10. 10下列那一個測試無法評估上頸椎不穩定的情形？

    1. (A) 旋轉翼狀韌帶壓力測試（rotational alar ligament stress test）
    2. (B) 頸椎之側向剪力測試（lateral shear test）
    3. (C) Sharp-Purser 測試
    4. (D) 韌帶磨損測試（ligament abrasion test）

    正解：(D)

  11. 11下列關於退化性脊椎滑脫（spondylolisthesis）的敘述，何者錯誤？

    1. (A) 通常在老年女性族群最常見
    2. (B) 可能會伴隨間歇性小腿疼痛的症狀
    3. (C) 多數患者脊椎滑脫程度會小於33%
    4. (D) 通常會有明顯坐骨神經拉張的徵狀（sciatic tension sign）

    正解：(D)

  12. 12有關人體維持標準直立站姿之必要條件，下列何者錯誤？

    1. (A) 踝關節的穩定度主要是由比目魚肌（soleus muscle）所提供
    2. (B) 膝關節穩定度是由後十字韌帶、膝後關節囊以及膕旁肌（hamstrings）和腓腸肌（gastrocnemius muscle）等共同組成
    3. (C) 若膝關節無法完全伸直，則股四頭肌群扮演主要的穩定角色
    4. (D) 髖關節在放鬆的站姿下，主要由髂股韌帶（iliofemoral ligament）提供穩定度，不需要依賴肌肉出力

    正解：(B)

  13. 13關於脊椎椎體的敘述，下列何者正確？

    1. (A) 腰椎椎體呈楔形，前邊較後邊略短
    2. (B) 椎間盤的營養交換是透過椎體的血管直接供應
    3. (C) 主要影響椎體強度的是皮質骨成分，骨質流失後將影響脊椎負荷能力
    4. (D) 髓核（nucleus pulposus）主要可承受壓力負荷，環狀纖維（annulus fibrosus）則可承受拉張外力

    正解：(D)

  14. 14關於腰椎椎間盤突出症狀的敘述，下列何者錯誤？

    1. (A) 最常見為後外向突出，引起的疼痛可能延伸至臀部或大腿
    2. (B) 腰椎第二節以下的正後向突出，會出現走路不穩、失去平衡，但不會有膀胱失調、鞍狀麻木（saddleanesthesia）等症狀
    3. (C) 前向突出可能會壓迫到前縱韌帶而引起腰痛，但不會有神經症狀
    4. (D) 好發於腰椎第四、第五節之間或腰椎第五節、薦椎第一節之間

    正解：(B)

  15. 15下列關於腰椎狹窄症狀的敘述，何者錯誤？

    1. (A) 泛指椎管（spinal canal）、神經根管（nerve root canal）或是椎間孔狹窄等，可能導致神經症狀
    2. (B) 常見症狀包括背痛、下肢疼痛、暫時性動作失調及感覺異常等
    3. (C) 會造成間歇性小腿疼痛，於走路時加劇，需停止行走，原地站立以紓解症狀
    4. (D) 身體後仰可能導致症狀加劇

    正解：(C)

  16. 16下列何者屬於僵直性脊椎炎的臨床症狀表現？①好發年齡通常超過40歲 ②體重不明原因減輕 ③晨僵（morning stiffness） ④胸椎僵硬 ⑤腳跟痛 ⑥發燒

    1. (A) 僅①②③
    2. (B) 僅③④⑤
    3. (C) 僅②③④
    4. (D) 僅③④⑥

    正解：(B)

  17. 17在執行主動腰椎前彎動作檢查時，下述何項判斷最不適當？

    1. (A) 於前彎後回復直立的動作過程中，出現異常脊椎節律，可能為小面關節卡住問題
    2. (B) 由側面觀察前彎動作時，若脊椎弧度出現銳角型急彎，代表局部椎節的活動度偏高
    3. (C) 若是於前彎過程出現持續偏歪的現象，通常表示因為小面關節內軟骨夾擠或關節囊受限而無法向前滑動
    4. (D) 若身體偏移發生於接近最大前彎動作範圍時，則可能是已定型的脊柱側彎所致

    正解：(C)

  18. 18患者主訴由胸、背到骨盆都有觸痛感，被動直膝抬腿測試呈現陽性反應，可長坐（long sitting）接受檢查，但對輕微的關節動作檢查有劇烈的疼痛反應；則可懷疑是下列何者？

    1. (A) 胸椎椎管腫瘤
    2. (B) 自體免疫系統失調
    3. (C) 社會心理障礙等非器質性問題
    4. (D) 多重器官失能

    正解：(C)

  19. 19下背痛患者趴站於床緣時，對其腰椎後方加壓會引發疼痛；若患者主動後舉雙腳、抬離地面時，再對其腰椎後方加壓則不會引發症狀。則此患者最有可能的問題是下列何者？

    1. (A) 腰椎椎節不穩
    2. (B) 腰椎間盤突出
    3. (C) 腰椎中央管狹窄
    4. (D) 僵直性脊椎炎

    正解：(A)

  20. 20一位20歲棒球隊學生抱怨參加6週的棒球夏令營後，無法持續練習接球動作超過半個小時；疼痛在下背部及臀部，偶而會傳到右大腿與膝關節後面。疼痛加劇的動作包括接滾地球、開車、上課，走路則較舒服。下列敘述何者正確？

    1. (A) 其疼痛屬於過度訓練之運動傷害，不適用麥氏（McKenzie）背痛分類系統來評估
    2. (B) 初步推測其為伸直導向（extension bias）的背痛患者
    3. (C) 初步推測其為屈曲導向（flexion bias）的背痛患者
    4. (D) 初步推測其為無承重導向（non-weight bearing bias）的背痛患者

    正解：(B)

  21. 21患者主訴晨間背部僵硬，打高爾夫球時感到持續性的右側背痛，特別在準備揮桿擊球時會立即感到右下背局部刺痛，但無腳麻或無力的情形，則最有可能是下列何者？

    1. (A) 骨質疏鬆壓迫性骨折
    2. (B) 神經根壓迫
    3. (C) 脊髓血流供應不足
    4. (D) 小面關節夾擠

    正解：(D)

  22. 22關於脊椎的退化階段（phase of degeneration），下列何者錯誤？

    1. (A) 可分為三個時期：早期失能期（early dysfunction phase）、中期不穩定期（intermediate instabilityphase）、晚期穩定期（final stabilization phase）
    2. (B) 早期失能期（early dysfunction phase），症狀多為可逆的，且病因多為滑液囊炎（synovitis）
    3. (C) 中期不穩定期（intermediate instability phase）的成因主要是因為前側關節囊的鬆弛
    4. (D) 椎間盤破裂的位置如果在較外側，較易復原，反之則較難

    正解：(C)

  26. 26單腳站姿下檢查站立側的骨盆排列，下列何者為陰性反應？①髂骨前旋（ilium anteriorly rotated） ②髂骨後旋（ilium posteriorly rotated） ③薦骨反屈（sacrum counternutation） ④薦骨前屈（sacrumnutation）

  27. 27若顳頜關節發生關節盤向前脫位且可復位（anterior disc displacement with reduction）的情況，則下列敘述何者錯誤？

    1. (A) 可能產生交互喀啦聲（reciprocal click）
    2. (B) 閉嘴時發生的喀啦聲，代表關節盤復位
    3. (C) 下顎前突（jaw protrusion）有助於減輕喀啦聲的產生
    4. (D) 關節盤的向前脫位與外翼肌（lateral pterygoid）的拉扯有關

    正解：(B)

  28. 28下列關於脊椎駝背後凸症（Scheuermann's Disease）之敘述，何者正確？

    1. (A) 剛開始有關節僵硬的現象，經一段時間後會較緩和
    2. (B) 是一種類風濕性疾病
    3. (C) 增加上頸椎的前凸（lordosis）可以防止駝背的惡化
    4. (D) 導因於脊椎終板（vertebral endplates）之弱化

    正解：(D)

  29. 29有關凸側在右的胸椎脊柱側彎，下列敘述何者正確？

    1. (A) 胸椎椎體會轉向右側，彎腰時可以發現右側背部的肋骨會往後高起，胸椎棘突會朝向左側
    2. (B) 胸椎椎體會轉向右側，彎腰時可以發現左側背部的肋骨會往後高起，胸椎棘突會朝向右側
    3. (C) 胸椎椎體會轉向左側，彎腰時可以發現左側背部的肋骨會往後高起，胸椎棘突會朝向右側
    4. (D) 胸椎椎體會轉向左側，彎腰時可以發現右側背部的肋骨會往後高起，胸椎棘突會朝向左側

    正解：(A)

  30. 30仰躺時，屈曲膝關節與髖關節，進行下胸椎與腰椎的多裂肌（multifidus）核心穩定評估，下列敘述何者錯誤？

    1. (A) 若發現問題也可以用類似的動作進行訓練
    2. (B) 多裂肌收縮通常可產生往同側方向的旋轉
    3. (C) 希望測試較高位置的多裂肌時，需將下肢與骨盆抬得更高
    4. (D) 治療師用一手感受肌肉的收縮，另一手在個案膝部提供阻力並觀察脊椎是否穩定

    正解：(B)

  31. 31在肩外展過程，盂肱關節關節囊會隨著外展角度增加而扭曲更嚴重，下列何者可以減少關節囊扭曲？

  36. 36下旋（downward rotation）的肩胛骨可能造成部分肌肉變短，除了：

  76. 76有關燒燙傷部位在前頸部、前胸與上肢的病人，其擺位方式，下列何者錯誤？

    2. (B) 將手肘擺在伸直與旋後（supination）的位置
    3. (C) 以枕頭墊在病人的頭部，給予舒服的支撐，以協助安穩的睡眠
    4. (D) 用副木將手腕擺在後伸、掌指關節屈曲、指間關節伸直與大拇指外展的位置

    正解：(C)

  77. 77生產過程對骨盆底肌的可能影響，不包含下列何者？

    2. (B) 骨盆底肌會直接受到極大的牽張（stretching）
    3. (C) 可能採取會陰切口術（episiotomy incision）
    4. (D) 胎兒通過產道時，可能造成陰道撕裂

    正解：(A)

  78. 78有關骨質疏鬆的運動注意事項，下列何者正確？

    2. (B) 避免髖關節阻力訓練，可能會造成股骨頸骨折
    3. (C) 避免過多上下階梯等脊椎載重運動，可能會造成脊椎壓迫性骨折
    4. (D) 避免快走運動，可能會造成股骨頸骨折

  79. 79有關骨質疏鬆防治的民眾教育內容，下列何者正確？①要攝取足夠的維生素D與鈣質 ②可與醫療人員諮詢，進行骨密度檢查，需要時應配合用藥 ③要有健康的生活型態，包括適量的飲酒與不抽菸

    2. (B) 僅②③
    3. (C) ①②③
    4. (D) 僅①③
