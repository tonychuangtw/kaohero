營養師　107 年第二次 膳食療養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1營養危險因子中，何者屬於心理及社會因素？

    1. (A) 吞嚥困難
    2. (B) 語言障礙
    3. (C) 感官功能障礙
    4. (D) 行動困難

    正解：(B)

  2. 2測量血清或尿液中 Methylmalonic acid（MMA）的濃度得以評估那一個營養素的營養狀態？

    1. (A) 維生素 B6
    2. (B) 維生素 B12
    3. (C) 維生素 B1
    4. (D) 維生素 B2

    正解：(B)

  3. 3有關生化值之敘述，下列何者正確？

    1. (A) C-reactive protein（CRP）為發炎指標，有助於監測和了解疾病之嚴重程度
    2. (B) 白蛋白（Albumin）的正常值是 3.5~5.0 mg/dL，半衰期為 12 至 16 天
    3. (C) 糖化血色素（HbA1C）的正常值是 5~7%，因此建議糖尿病個案之糖化血色素控制在 7%以下
    4. (D) 血中膽固醇正常值為 200 - 240 mg/dL

    正解：(A)

  4. 4下列何者最需要給予靜脈營養支持？

    1. (A) 胃輕癱（Gastroparesis）
    2. (B) 克隆氏症（Crohn's Disease）
    3. (C) 腸閉鎖（Intestinal Atresia）
    4. (D) 神經性厭食症（Anorexia Nervosa）

    正解：(C)

  5. 5有關全靜脈營養輸出液敘述，下列何者錯誤？

    1. (A) 給予>6 mg/kg/min 的 dextrose 易發生肝功能不正常
    2. (B) 通常會添加 aspartate 在全靜脈營養輸液中
    3. (C) 脂肪給予最高量不得超過 2 g/kg/day
    4. (D) 三酸甘油酯>400 mg/dL 需停止給予脂肪輸液

    正解：(B)

  6. 6抗癌化療藥物 Cisplatin 對血液電解質的影響，下列何者正確？

    1. (A) Hypocalcemia
    2. (B) Hyponatremia
    3. (C) Hyperkalemia
    4. (D) Hypermagnesemia

    正解：(A)

  7. 7選用 blenderized tube feeding（BTF）的時候，那些病人較不適宜？①對多種食物過敏者 ②使用bolus feeding 者 ③每日限水小於 900 mL 者 ④使用 PEG（percutaneous endoscopic gastrostomy）者 ⑤使用 PEJ（percutaneous endoscopic jejunostomy）者

    1. (A) ①②③
    2. (B) ①③⑤
    3. (C) ②③⑤
    4. (D) ①②④

    正解：(B)

  8. 8下列何者不是使用靜脈營養時常見的併發症？

    1. (A) hyperglycemia
    2. (B) aspiration
    3. (C) cholestasis
    4. (D) infection

    正解：(B)

  9. 9陳小姐患有中度暴食症，請問評估其每日飲食攝取量的方法，下列何者較適當？

    1. (A) 24 小時飲食回憶法
    2. (B) 7 日飲食紀錄
    3. (C) 飲食頻率
    4. (D) 飲食史

    正解：(B)

  10. 10有關成人接受胃繞道手術（Gastric Bypass）手術後所產生之營養問題及處置，下列敘述何者錯誤？

    1. (A) 手術後病人飲食進展由清流質飲食逐漸進展至正常飲食，並建議以少量多餐方式進食
    2. (B) 術後因為進食之食物繞過部分的胃而進入小腸，故仍有可能發生傾食症候群（dumpingsyndrome）
    3. (C) 病人術後進食後，最常見之腸胃消化道症狀為嚴重腹瀉
    4. (D) 術後可能容易有多種維生素礦物質缺乏的情形，建議補充符合成人劑量之維生素礦物質補充劑

    正解：(C)

  11. 11有關厭食症個案常併發的身體問題，包括那些？①骨質疏鬆症 ②月經停止 ③高血壓 ④食道炎 ⑤水腫 ⑥便祕

    1. (A) ①②④⑤
    2. (B) ①②⑤⑥
    3. (C) ②③④⑤
    4. (D) ①③④⑥

    正解：(B)

  12. 12營養介入（nutrition intervention）應該包含那兩步驟？

    1. (A) 計畫與執行
    2. (B) 評估與計畫
    3. (C) 調查與監督
    4. (D) 介入與評估

    正解：(A)

  13. 13下列那一時期為女性骨骼質量達到顛峰之時期（peak bone mass）？

    1. (A) 青春末期
    2. (B) 大約 30 歲時
    3. (C) 正在停經時期
    4. (D) 停經之後

    正解：(B)

  14. 14評估退化性關節炎嚴重程度時，下列何者是重要的指標？

    1. (A) 每日生活活動力
    2. (B) 小腸吸收不良的程度
    3. (C) 血糖的控制
    4. (D) 氮的平衡頁次：4－3

    正解：(A)

  15. 15對於嚴重急性胰臟炎併發器官衰竭、胰臟壞死、胰臟外積液（fluid collection）的病患剛開始腸道營養治療且腸胃道耐受性差時，下列何者配方較為適宜？

    1. (A) 空腸灌食元素或預解配方
    2. (B) 胃灌食元素或預解配方
    3. (C) 空腸灌食聚合配方
    4. (D) 胃灌食聚合配方

    正解：(A)

  16. 16有關發炎性腸道疾病－克隆氏病（Crohn's disease）飲食原則，下列何者正確？

    1. (A) 病患由於發炎及藥物的使用，可能造成肌肉的流失，蛋白質的攝取量得以增加至 1.3-1.5g/kg/day
    2. (B) 避免增加葉酸、維生素 B6 及維生素 B12 的攝取，減少腸黏膜發炎現象
    3. (C) 避免補充乳酸菌，以減少腸道蠕動
    4. (D) 多補充乳製品，以增加鈣的攝取量

    正解：(A)

  17. 17有一 55 歲男子，具有 10 年以上糖尿病史，最近一次的回診中，發現其體重為 93 公斤，以其身高 170 公分計算，BMI 達 32.2，超音波檢查發現有肝臟腫大及脂肪肝現象，患者堅稱無飲酒習慣，肝炎檢查亦排除病毒感染之可能性。生化檢驗值為：空腹血糖值 160 mg/dL、三酸甘油酯 520mg/dL、膽固醇 260 mg/dL、白蛋白 4.2 g/dL、膽紅素總量 1 g/dL、天門冬胺酸轉胺酶 65 U/L、丙胺酸轉胺酶 80 U/L、鹼性磷酸酶 118 U/L、糖化血色素 A1C 9.1%。下列何種治療對該患者病情沒有幫助？

    1. (A) 維持理想體重、規律運動
    2. (B) 採用低熱量均衡飲食
    3. (C) 服用胰脂解酶促進劑
    4. (D) 採用高纖飲食

    正解：(C)

  18. 18威爾森氏症患者初期需限制下列那些食物？

  27. 27下列有關腎臟移植患者於手術後 2 個月的飲食，何者錯誤？

    1. (A) 每天膽固醇攝取量應低於 300 毫克
    2. (B) 每天蛋白質攝取量為每公斤理想體重 1 公克

    4. (D) 水份每天攝取 2 公升頁次： 4－4

  28. 28透析患者須補充下列那些維生素？①維生素 A ②維生素 B 群 ③維生素 C ④維生素 K

  29. 29心臟衰竭營養治療策略，下列何者不適當？

    1. (A) 依病情嚴重度給予限鈉飲食，鈉攝取最高不可超過 3 公克/天
    2. (B) 限水飲食< 2000 毫升/天
    3. (C) 因攝食不佳，需補充鎂、鈣、維生素 B1

    正解：(C)

  30. 30有關 CVD 病患生活型態調適的建議重點，下列敘述何者錯誤？

    1. (A) 飲食中飽和脂肪占總熱量 5-6%、減少反式脂肪酸攝取，以降低 LDL-C
    2. (B) 採用 DASH 飲食且鈉的攝取小於 2400 mg/天，以降低血壓
    3. (C) 體能活動 3-4 次/週，40 分鐘/次，以降低 LDL-C 與血壓
    4. (D) 建議補充維生素 E，避免 LDL 氧化，以預防 CVD

    正解：(D)

  31. 31下列何種因子在心因性惡病質（cardiac cachexia）病人血液中含量最高，與身體質量指數呈負相關，可作為心衰竭嚴重度的標記與死亡率的指標？

    1. (A) 白細胞介素-1（interleukin-1）
    2. (B) 白細胞介素-6（interleukin-6）
    3. (C) 脂聯素（adiponectin）
    4. (D) 兒茶酚胺（catecholamines）

    正解：(C)

  32. 32根據 OmniHeart Trial 的結果，發現下列何種飲食型態降血壓及血膽固醇的效果最好？

    1. (A) 原型的 DASH 飲食
    2. (B) DASH 飲食中部分醣量（約總熱量的 10%）由蛋白質或單元不飽和脂肪取代
    3. (C) DASH 飲食＋低蛋白飲食（蛋白質攝取量占熱量的 12%，1/3 為植物來源）
    4. (D) DASH 飲食＋高不飽和脂肪飲食（脂肪攝取量占熱量的 31%，大多數為單元不飽和脂肪）

    正解：(B)

  33. 33對於加護中心的重症病患，決定是否開始提供營養支持時，優先考慮的條件為何？

  38. 38有關慢性阻塞性肺疾病（COPD）的敘述，下列何者錯誤？

    1. (A) 血液中的 Leptin 常因急性發作而降低
