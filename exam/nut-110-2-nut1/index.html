營養師　110 年第二次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何者會抑制胃酸分泌？

    1. (A) 胃泌素（gastrin）
    2. (B) 體抑素（somatostatin）
    3. (C) 組織胺（histamine）
    4. (D) 乙醯膽鹼（acetylcholine）

    正解：(B)

  2. 2胃的接受性放鬆（receptive relaxation）是經由腸道神經元分泌的何種物質所造成？

    1. (A) 腎上腺素與一氧化氮
    2. (B) 血清素與一氧化氮
    3. (C) 組織胺與乙醯膽鹼
    4. (D) 兒茶素與乙醯膽鹼

    正解：(B)

  3. 3有關皮質醇（cortisol）的敘述，下列何者正確？

    1. (A) 由腎上腺髓質細胞合成
    2. (B) 其受體僅位於細胞膜表面
    3. (C) 在血液中其半衰期較腎上腺素長
    4. (D) 合成後通常儲存於細胞內特定的囊泡中

    正解：(C)

  4. 4下列關於昇糖素（glucagon）的敘述，何者正確？

    1. (A) 通常進食後分泌
    2. (B) 由胰島 beta 細胞分泌
    3. (C) 促進肝臟與骨骼肌肝醣的水解
    4. (D) 可增加血漿酮體頁次：4－2

    正解：(D)

  5. 5關於光線活化視網膜錐細胞（cone cells）的敘述，下列何者正確？

    1. (A) 誘發鈉離子管道打開
    2. (B) 誘發錐細胞去極化
    3. (C) 誘發光色素（photopigment）快速合成
    4. (D) 活化 cGMP 磷酸雙酯解酶（phosphodiesterase）

    正解：(D)

  6. 6對於氣喘（asthma）病患常見的氣管內氣流梗塞症狀，刺激其氣管平滑肌上那一種自主神經系統（autonomic nervous system）受器可導致氣管舒張，而達到緩解氣喘症狀的效果？

    1. (A) 毒蕈鹼（muscarinic）受器 M3 亞型
    2. (B) 腎上腺素受器（adrenoceptor）beta 2 亞型
    3. (C) 腎上腺素受器 beta 1 亞型
    4. (D) 腎上腺素受器 alpha 1 亞型

    正解：(B)

  7. 7下列何者不是影響具兩性潛能的原始性器官（double genital duct system）發育成男性內外部生殖器官的關鍵物質？

    1. (A) 睪固酮（testosterone）
    2. (B) 二氫睪固酮（dihydrotestosterone）
    3. (C) X 染色體
    4. (D) 5α 還原酶（5α reductase）

    正解：(C)

  8. 8下列何者最容易導致粥狀動脈硬化？

    1. (A) 血中高密度脂蛋白膽固醇過低
    2. (B) 血中低密度脂蛋白膽固醇過高
    3. (C) 血中高密度脂蛋白膽固醇過高
    4. (D) 血中低密度脂蛋白膽固醇過低

    正解：(B)

  9. 9關於擴散（diffusion）的敘述，下列何者錯誤？

    1. (A) 氧分子與養分（nutrients）經由簡單擴散來進出周邊微血管
    2. (B) 非極性分子（nonpolar）無法經由簡單擴散來通透細胞膜
    3. (C) 大部分極性分子（polar）為非常緩慢擴散或不通透入細胞內
    4. (D) 二氧化碳與脂肪酸可經由擴散方式來迅速通透入細胞內

    正解：(B)

  10. 10關於平滑肌細胞結構與特性的敘述，下列何者正確？

    1. (A) 具有橫紋（striations）和肌節（sarcomeres）
    2. (B) 具有單細胞核和進行細胞分裂（cell division）能力
    3. (C) 不具有原肌凝蛋白（tropomyosin）的功能性結構
    4. (D) 不具滑動收縮機制（sliding-contraction mechanism）

    正解：(B)

  11. 11關於骨骼肌、平滑肌和心肌細胞的比較，下列何者錯誤？

    1. (A) 肌漿網（sarcoplasmic reticulum）數量發達程度以骨骼肌細胞最優
    2. (B) 平滑肌細胞不具有 T-小管（transverse tubule）
    3. (C) 三種肌肉細胞內皆具有粗絲（thick filament）與細絲（thin filament）
    4. (D) 刺激直接支配肌肉細胞之神經，皆可產生興奮或抑制收縮之效應

    正解：(D)

  12. 12下列何者為最有利於人體消化的脂肪形式？

    1. (A) 攪拌促進油滴聚集
    2. (B) 靜置促進油滴分散
    3. (C) 增加體積的大油滴
    4. (D) 增加表面積的小油滴

    正解：(D)

  13. 13粽子吃多了容易產生消化不良的症狀，下列何種情形最不可能發生？

    1. (A) 刺激膽汁分泌，逆流引起胃發炎
    2. (B) 刺激胃酸分泌，逆流引起食道發炎
    3. (C) 抑制小腸分節運動，產生嘔吐
    4. (D) 抑制胃排空，產生脹氣

    正解：(C)

  14. 14正常成年人腎臟可將被過濾的葡萄糖 100%再吸收，但糖尿（glycosuria）患者尿中卻會測得葡萄糖，則其腎過濾液中葡萄糖濃度最可能處於下列何種狀態？

    1. (A) 大於腎絲球囊足細胞（podocytes）最大轉運量（transport maximum, Tm）
    2. (B) 大於集尿管上皮細胞之最大轉運量
    3. (C) 大於遠端腎小管周圍微血管最大轉運量
    4. (D) 大於近端腎小管上皮細胞最大轉運量

    正解：(D)

  15. 15患者的動脈 pH7.35，且其血氧分壓（PO2）55 mmHg，血二氧化碳分壓（PCO2）52 mmHg，此患者最可能是屬於何種酸鹼失衡現象？

    1. (A) 代謝性鹼中毒（metabolic alkalosis）
    2. (B) 代謝性酸中毒（metabolic acidosis）
    3. (C) 呼吸性鹼中毒（respiratory alkalosis）
    4. (D) 呼吸性酸中毒（respiratory acidosis）

    正解：(D)

  16. 16靜脈做菊糖（inulin）注射，之後測得尿液的生成速率是 150 ml/hr，並分別測得菊糖在尿液和血漿的濃度為 25 mg/ml 及 0.5 mg/ml，試問菊糖的清除速率（clearance of inulin）為何？

    1. (A) 62.5 ml/min
    2. (B) 125 ml/min
    3. (C) 150 ml/min
    4. (D) 3 ml/min頁次：4－3

    正解：(B)

  17. 17下列何者是活化補體並針對病原體進行破壞的機制？①調理作用（opsonization） ②募集白血球（leukocyte recruitment） ③組織胺的分泌（histamine secretion） ④膜攻擊複合體（membraneattack complex）

    1. (A) ①②④
    2. (B) ①③④
    3. (C) ②③④
    4. (D) ①②③

    正解：(A)

  18. 18耐力訓練的運動員其休息時心率約每分鐘 40 到 60 次，比未受訓練的人低。其低心率最主要的原因為下列何者？

    1. (A) 副交感神經活性較高，而抑制竇房結（SA node）
    2. (B) 顯著較低的平均動脈壓（mean arterial pressure）
    3. (C) 顯著較高舒張末期心室容積（end diastolic volume）
    4. (D) 顯著較低的總周邊阻力（total peripheral resistance）

    正解：(A)

  19. 19在運動控制的局部階層（local level） ，下列何者不是局部感覺訊息輸入（local afferent inputs）的來源？

    1. (A) 運動神經元（motor neurons）所控制的肌肉
    2. (B) 鄰近的肌肉
    3. (C) 運動神經元
    4. (D) 肌腱、關節和皮膚（tendons, joints and skin）

    正解：(C)

  20. 20氣體交換可分為外呼吸和內呼吸，下列敘述何者錯誤？

    1. (A) 外呼吸在支氣管進行，內呼吸在肺泡之間進行
    2. (B) 外呼吸指氧氣從肺泡擴散到微血管時，二氧化碳同時逆向擴散到肺泡，並被排出體外
    3. (C) 內呼吸指氧氣經循環系統運送至各組織擴散到細胞，同時二氧化碳以相反方向擴散到血液中
    4. (D) 內呼吸指細胞內的營養素在粒線體中與氧氣發生反應，釋放能量並產生二氧化碳

    正解：(A)

  21. 21動脈中的 PGI3（prostacyclin I3）有可能由下列何種脂肪酸經代謝後所產生？

    1. (A) arachidonic acid
    2. (B) oleic acid
    3. (C) linoleic acid
    4. (D) EPA

    正解：(D)

  22. 22關於細胞膜的敘述，下列何者錯誤？

    1. (A) 膜內外在構造上具備不對稱性
    2. (B) 膜內外在功能上有所不同
    3. (C) 具極性或帶電荷溶質可直接穿過細胞膜進入細胞
    4. (D) 脂雙層是細胞膜的基本結構單位

    正解：(C)

  23. 23下列何者是「branched-chain」胺基酸？

    1. (A) Arginine
    2. (B) Valine
    3. (C) Methionine
    4. (D) Tryptophan

    正解：(B)

  24. 24當一短鏈 RNA 分子與特定 mRNA 發生互補作用時，進而抑制其轉譯作用，則此 RNA 分子稱為下列何者？

    1. (A) antisense RNA
    2. (B) missense RNA
    3. (C) nonsense RNA
    4. (D) senseless RNA

    正解：(A)

  25. 25下列何者為檸檬酸循環代謝反應中，唯一結合於粒線體膜之酵素？

    1. (A) 烏頭酸酶（aconitase）
    2. (B) 異檸檬酸去氫酶（isocitrate dehydrogenase）
    3. (C) 琥珀酸去氫酶（succinate dehydrogenase）
    4. (D) 蘋果酸去氫酶（malate dehydrogenase）

    正解：(C)

  26. 26當電子於粒線體內膜流動時，complex I 和 complex II 共可將多少個 H+從粒線體基質送往內外膜間隙？

    1. (A) 10
    2. (B) 8
    3. (C) 6
    4. (D) 4

    正解：(D)

  27. 27關於胰島素對醣類代謝的調節，下列敘述何者正確？

    1. (A) 降低肝臟中肝醣合成酶（glycogen synthase）活性
    2. (B) 增加肝臟中葡萄糖激酶（glucokinase）活性
    3. (C) 降低肝臟與肌肉中丙酮酸去氫酶（pyruvate dehydrogenase complex）活性
    4. (D) 增加肝臟與肌肉中肝醣磷酸化酶（glycogen phosphorylase）活性

    正解：(B)

  28. 28關於肝醣之代謝的敘述，下列何者正確？

    1. (A) c-AMP 會活化肝醣合成作用
    2. (B) Ca2+無法活化 glycogen phosphorylase
    3. (C) Glycogen synthase 之活性會受昇糖素（glucagon）之抑制
    4. (D) Glycogen synthase 之活性主要表現於肝臟及腦部

    正解：(C)

  29. 29關於去氧糖（deoxy sugar）的敘述，下列何者錯誤？

    1. (A) 是單醣環上的一個羥基（hydroxyl group）被氫原子取代
    2. (B) DNA 結構含有 2-deoxyribulose
    3. (C) L-fucose 出現在糖蛋白中
    4. (D) 2-deoxyglucose 實驗上常作為葡萄糖代謝的抑制劑頁次：4－4

    正解：(B)

  30. 30關於五碳糖磷酸途徑（pentose phosphate pathway）的敘述，下列何者錯誤？

    1. (A) 主要功能為，產生還原當量以供生成能量之代謝使用
    2. (B) 需要維生素 B1, B2, niacin 等的參與
    3. (C) 產生 NADPH 及核糖磷酸以供其他代謝使用
    4. (D) 缺乏葡萄糖 6-磷酸脫氫酶（glucose 6-phosphate dehydrogenase），是一種遺傳疾病，會引起紅血球溶解，造成溶血性貧血

    正解：(A)

  31. 31人體因缺乏那一個去飽和酶（desaturase），無法將飲食中亞麻油酸（linoleic acid）轉換為 α-次亞麻油酸（linolenic acid）？

    1. (A) Δ6 desaturase
    2. (B) Δ9 desaturase
    3. (C) Δ12 desaturase
    4. (D) Δ15 desaturase

    正解：(D)

  32. 32膽固醇可代謝成為膽酸（bile acid），膽酸經腸肝循環（enterohepatic circulation）可再利用。關於膽酸的敘述，下列何者錯誤？

    1. (A) 膽酸在小腸作用量不足易造成脂肪瀉（steatorrhea）
    2. (B) 膽酸於大腸的排泄增加，為降低血中膽固醇濃度的機制之一
    3. (C) 膽酸分泌後主要於迴腸（ileum）吸收
    4. (D) 膽酸經腸道菌作用後的代謝物中，chenodeoxycholic acid 屬於次級膽酸

    正解：(D)

  33. 33組合成蛋白質分子的基本單元為下列何者？

    1. (A) 多胜肽（polypeptides）
    2. (B) 胺基酸（amino acids）
    3. (C) 酵素（enzymes）
    4. (D) 核苷酸（nucleic acids）

    正解：(B)

  34. 34非必需胺基酸（non-essential amino acids）的合成過程與下列那個反應最有關？

    1. (A) Ketogenesis
    2. (B) Gluconeogenesis
    3. (C) Transamination
    4. (D) Desaturation

    正解：(C)

  35. 35欲估算某純化蛋白質的分子量大小，不可採用下列那種分析方式？

    1. (A) Western blot
    2. (B) Electrospray ionization
    3. (C) Gel filtration chromatography
    4. (D) Mass spectrometry

    正解：(B)

  36. 36營養與基因間的交互作用不包括下列何者？

    1. (A) 營養素可以影響基因表現
    2. (B) 基因變異（基因多型性）可影響營養素的代謝或需求
    3. (C) 營養素可影響表觀遺傳（epigenetics） （DNA 或組蛋白的甲基化或乙醯化）
    4. (D) 營養素可以直接改變 DNA 序列

    正解：(D)

  37. 37關於荷爾蒙與細胞二級訊號（secondary messenger）的對應，下列何者錯誤？

    1. (A) 降鈣素（calcitonin）與 cyclic AMP
    2. (B) 昇糖素（glucagon）與 cyclic GMP
    3. (C) 一氧化氮（nitric oxide）與 cyclic GMP
    4. (D) 促甲狀腺素（thyroid-stimulating hormone）與 cyclic AMP

    正解：(B)

  38. 38何者可提供嘌呤（purine）生合成環狀結構之 C 來源？

    1. (A) 葡萄糖（glucose）
    2. (B) 甲硫胺酸（methionine）
    3. (C) N10-甲醛四氫葉酸（N10-formyl-tetrahydrofolate）
    4. (D) 丙酮酸（pyruvate）

    正解：(C)

  39. 39根據 IUB（Internal Union of Biochemistry）酵素的分類系統，細胞凋亡相關的 caspase 酵素會降解蛋白質，分類上屬於下列何者？

    3. (C) 水解酶（hydrolase）
    4. (D) 氧化還原酶（oxidoreductase）

    正解：(C)

  40. 40治療高血膽固醇的藥物「史他汀類（Statins）」是合成膽固醇酵素 HMG-CoA reductase 的競爭型抑制劑（competitive inhibitor）。關於此類藥物的作用特性，下列敘述何者錯誤？

    1. (A) 構造上，Statin 與 HMG 有高度相似的立體構型
    2. (B) 作用時，Statin 是結合在酵素的催化中心（active site）
    3. (C) Statin 藥物與 HMG-CoA reductase 的結合是不可逆反應（irreversible）
    4. (D) 此類藥物不會改變 HMG-CoA reductase 的最大反應速率 Vmax

    正解：(C)
