職能治療師　104 年第一次 職能治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1治療師獲知同仁或其他專業人員從事不法或不倫理的事時，應該向有關當局報告，是下列那一種倫理原則？

    1. (A) 慈悲／慈善 （beneficence）
    2. (B) 誠實／真實（veracity）
    3. (C) 忠誠（fidelity）
    4. (D) 正義／公正（justice）

    正解：(C)

  2. 2經常需負重約5公斤，偶爾需負重約10公斤，此種體能需求等級為何？

    1. (A) 靜態

    3. (C) 中度
    4. (D) 重度

    4. (D) 遠端非及物性動作（distal intransitive）

    正解：(B)

  4. 4頭部翻正（neck righting）反應為下列那一級之反射或反應？

    3. (C) 脊髓反射（spinal-level reflexes）
    4. (D) 中腦反應（midbrain-level reactions）

    4. (D) 觸覺反應和本體反應

  7. 7肌肉痙攣（spasticity）依其嚴重程度可分為輕微（mild），中度（moderate），及嚴重（severe），下列敘述何者正確？

    1. (A) 牽引性反射（stretch reflex）在前四分之一的動作範圍內產生者，評定為嚴重肌肉痙攣
    2. (B) 缺乏主動動作甚至產生關節攣縮者，評定為中度肌肉痙攣
    3. (C) 拮抗肌群間的張力產生明顯的不平衡者，評定為輕微肌肉痙攣
    4. (D) 被動拉動時產生明顯阻力，無法達到正常被動關節活動度角度者，評定為輕微肌肉痙攣

    正解：(A)
