警察特考　103 年 三等考試 偵查法學與犯罪偵查　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1司法警察偵查犯罪時，在下列何種情形下而情況急迫者，得逕行拘提之：

    1. (A) 因現行犯之供述，而未有事實足認為共犯嫌疑重大者
    2. (B) 經被盤查而逃逸者且所犯最重本刑為一年以下有期徒刑之罪者
    3. (C) 在押中之脫逃者
    4. (D) 有事實足認為有逃亡之虞者

    正解：(C)

  2. 2境外犯罪的管轄係依何種順序之警察機關負責管轄：

    1. (A) 被害人之工作地、被害人之居住地、被害人家屬居住地
    2. (B) 被害人之居住地、被害人之工作地、被害人家屬居住地
    3. (C) 被害人家屬居住地、被害人之工作地、被害人之居住地
    4. (D) 被害人之居住地、被害人家屬居住地、被害人之工作地

    正解：(B)

  3. 3刑案現場的封鎖範圍以三道封鎖線為原則外，必要時得作適當處置，下列處置何者較為適當？

    1. (A) 驅散觀看群眾
    2. (B) 實施交通管制
    3. (C) 成立現場指揮中心
    4. (D) 劃設新聞媒體採訪區

    正解：(B)

  4. 4有關簽名特徵，下列敘述何者錯誤？

    1. (A) 它的成因是心理的特徵
    2. (B) 它具有強迫的性質
    3. (C) 它在整個犯罪過程中可能是多餘的
    4. (D) 犯罪人的簽名特徵並非固定而會經常改變

    正解：(D)

  5. 5關於原始現場，下列敘述何者最正確？

    1. (A) 除自然變化外，原來發生之刑案而未經人為及其他因素改變之場所
    2. (B) 經過自然天候等改變而未經人為及其他因素改變之場所
    3. (C) 動物的踐踏咬食而未經人為及其他因素改變之場所
    4. (D) 除救、醫護人員的救援醫護而未經其他人為及其他因素改變之場所

    正解：(A)

  6. 6對於同類型的個案行為加以累積，並對個案進行犯罪形成、犯罪模式、犯罪行為特徵及人格特質等做深層的解析研究，歸納出犯罪類型的行為特徵，此種技術稱為：

    1. (A) 心理描繪技術
    2. (B) 特殊行為描繪技術
    3. (C) 犯罪手法描繪技術
    4. (D) 人格描繪技術

    正解：(A)

  7. 7從事整體性犯罪調查策略之規劃，以確認犯罪組織所從事各種犯罪、呈現犯罪組織之存在、辨認控制犯罪組織之所有成員，而成功瓦解其犯罪組織。此偵查策略稱為：

    1. (A) 擒賊擒王策略
    2. (B) 企業化偵查策略
    3. (C) 蠶食偵查策略
    4. (D) 開放監控策略

    正解：(B)

  8. 8下列敘述何者非屬勘察原則的內涵？

    1. (A) 由左而右
    2. (B) 由近而遠
    3. (C) 由前而後
    4. (D) 由明顯到潛伏

    正解：(C)

  9. 9有關刑案移送用紙規定，直轄市政府警察局所轄分局採用之用紙為：

    1. (A) 調查書
    2. (B) 移送書
    3. (C) 報告書
    4. (D) 通緝書

    正解：(C)

  10. 10下列何者不是新修正之通訊保障及監察法內容？

    1. (A) 通信紀錄納入規範
    2. (B) 監聽票一案一卷
    3. (C) 監錄內容顯然與監察目的無關者，不得作成譯文
    4. (D) 增訂調取通信紀錄採令狀主義

    正解：(B)

  11. 11依據毒品危害防制條例第 32 條之 1 及第 32 條之 2 規定，目前警察機關運用控制下交付之偵查作為，下列敘述何者正確？

    1. (A) 目的上僅限偵辦跨國性毒品及槍枝犯罪
    2. (B) 程序上得由檢察官向最高法院檢察署提出偵查計畫書
    3. (C) 偵查計畫書內容無須記載毒品數量
    4. (D) 偵查計畫書須經最高法院檢察署檢察總長核可後，始能實施

    正解：(D)

  12. 12司法警察人員進行犯罪嫌疑人之詢問時，須遵守以下那些規定，請選出正確者：①夜間經拘提或逮捕到場而查驗其人有無錯誤者，得於夜間實施 ②被告或犯罪嫌疑人須由通譯傳譯，因等候其通譯到場致未予詢問者，其等候時間不得逾 4 小時 ③對於被告之請求對質，除顯無必要者外，不得拒絕 ④詢問被告或犯罪嫌疑人時應全程連續錄影及錄音

    1. (A) ①②
    2. (B) ②③
    3. (C) ①③
    4. (D) ①④

    正解：(C)

  13. 13有關司法警察人員執行搜索任務，下列敘述何者錯誤？

    1. (A) 執行搜索時，得命保管人提出或交付應扣押之物，如無正當理由拒絕提出交付或抗拒扣押者，得用強制力扣押之
    2. (B) 旅店在公開時間內者，夜間得入內搜索
    3. (C) 有明顯事實足信為有人在內犯罪而情形急迫者，司法警察人員雖無搜索票，仍得逕行搜索住宅或處所
    4. (D) 經檢察官同意之搜索，得不使用搜索票，但執行人員應出示證件，並將其同意之意旨記載於筆錄

    正解：(D)

  14. 14依據警察偵查犯罪手冊，下列何者不是警察機關偵查刑案，得函送管轄法院或檢察署之規定？

    1. (A) 證據證明力薄弱或行為事實是否構成犯罪顯有疑義者
    2. (B) 犯罪證據不明確，但被害人堅持提出告訴者
    3. (C) 告訴乃論案件，經撤回告訴，或尚未調查完竣，而告訴權人已向檢察官告訴者
    4. (D) 全案經調查完畢，認有犯罪嫌疑者

    正解：(D)

  15. 15依據警察偵查犯罪手冊，有關電腦犯罪案件電腦鑑識應注意事項，下列敘述何者錯誤？

    1. (A) 重大特殊案件之電腦證物遭毀損、刪除、格式化或經加密無法解讀，得將證物送刑事警察局通訊監察科鑑識解析
    2. (B) 鑑識前應先將重要資料備份，以完整保存證據，必要時可全部備份
    3. (C) 電腦鑑識時應於備份資料執行非破壞性鑑識，必要時得於原始資料鑑識解析
    4. (D) 電腦資料、檔案或證據被設定密碼，應將所設定之密碼解密

    正解：(A)

  16. 16下列何者為實施被害人指認犯罪嫌疑人之要領？

    1. (A) 指認前得由指認人先陳述犯罪嫌疑人特徵
    2. (B) 實施指認，得於偵訊室或適當處所為之
    3. (C) 指認前必須告訴指認人，犯罪嫌疑人並不一定存在於被指認人之中
    4. (D) 實施指認不需拍攝被指認人照片，但應製作紀錄表附於筆錄

    正解：(C)

  17. 17下列有關刑案紀錄之處理運用規定，何者錯誤？

    1. (A) 刑案紀錄表應於受理刑案發生或破獲移送之時起，24 小時內填輸
    2. (B) 警察機關接到司法機關之起訴書後，應檢件分送被告之戶籍地警察機關辦理註記
    3. (C) 犯罪嫌疑人移送法辦者，移送單位於發文移送翌日起 2 日內，將該移送書電子檔上傳刑事警察局
    4. (D) 凡遇軍車牌遺失，應於 4 小時內報由刑事警察局建檔

    正解：(A)

  18. 18警察人員依照偵查不公開原則及偵辦刑案新聞注意要點偵辦刑案，須遵守下列那些規定，請選出正確者：①現行犯已經逮捕，其犯罪事證查證明確者，無須經首長核可，發布新聞 ②對於現時難以取得或調查之證據，為被告犯罪嫌疑人行使防禦權之必要，可請求社會大眾協助提供證據 ③對於媒體報導與偵查案件事實不符時，可對外澄清 ④查獲未滿 18 歲之犯罪嫌疑人，於進行逮捕或押解移送等公開場合時，應配戴頭套

    1. (A) ①②③
    2. (B) ①③④
    3. (C) ①②④
    4. (D) ②③④

    正解：(D)

  19. 19警察人員到達刑案現場後，進行刑案現場保全及封鎖工作，下列敘述何者錯誤？

    1. (A) 實施刑案現場保全時，立即實施現場封鎖，非經現場指揮官同意，任何人不得進入
    2. (B) 室外現場宜使用帳篷、雨棚或立即移至安全處所，以免跡證遭受自然力破壞
    3. (C) 現場封鎖得使用現場封鎖帶、警戒繩索、標示牌、警示閃光燈或其他器材，以達成保全現場為原則
    4. (D) 初期封鎖之範圍宜廣，待初步勘察後，視實際需要再行界定封鎖範圍

    正解：(B)

  20. 20有關新修正之通訊保障及監察法相關規定，下列何者正確？

    1. (A) 檢察機關受理之緊急監察案件，應於 3 日內陳報該管法院補發通訊監察書
    2. (B) 通訊監察結束後，檢察官、綜理國家情報工作機關應於 14 日內主動通知受監察人
    3. (C) 依規定執行通訊監察所取得之內容或所衍生之證據與監察目的無關者，不得作為司法偵查、審判之證據
    4. (D) 內政部每年應向立法院報告通訊監察執行情形

    正解：(C)

  21. 21警方以釣魚偵查方式偵辦兒童及少年性交易防制條例第 29 條「散布促使人為性交易之訊息罪」案件，下列何者正確？

    1. (A) 如果是誘捕偵查則屬非法
    2. (B) 如果是誘捕偵查所得之證據並無證據能力
    3. (C) 可向行為人主動談及性交易邀約內容，誘使行為人同意性交易
    4. (D) 如果是陷害教唆則屬非法，故無證據能力

    正解：(D)

  22. 22有關警察機關處理家庭暴力案件相關執法作為，請選出正確者：①警察人員發現家庭暴力罪之現行犯，得逕行逮捕之 ②應依保護令保護被害人至被害人或相對人之住居所，確保其安全占有住居所、汽車、機車或其他個人生活上、職業上或教育上必需品 ③依保護令執行交付未成年子女時，得審酌權利人及義務人之意見，決定交付時間、地點及方式 ④警察機關於法院核發緊急保護令前，為保護被害人及防止家庭暴力之發生，必要時應派員於被害人住居所守護

    1. (A) ①②③
    2. (B) ①②④
    3. (C) ①③④
    4. (D) ②③④

    正解：(D)

  23. 23有關警察機關偵辦組織犯罪之規定，下列敘述何者正確？

    1. (A) 檢察機關、司法警察機關為保護檢舉人，對於檢舉人之身分資料，應另行封存，另案附入移送法院審理之文書內
    2. (B) 證人之姓名、性別、年齡、出生地、職業、身分證字號、住所或居所或其他足資辨別之特徵等資料，應由警察機關辦理封存，不得閱卷
    3. (C) 犯罪證物之蒐集，必要時得協請會計或資訊等專業人員支援解讀
    4. (D) 對組織犯罪案件之證人或與其有密切利害關係之人、檢舉人及被害人，應依警察職權行使法克盡保密與保護的責任，並注意公務員洩密之刑事責任

    正解：(C)

  24. 24依據警察機關辦理性侵害案件處理原則與性侵害犯罪加害人登記報到查訪及查閱辦法，下列有關警察機關偵辦性侵害案件之敘述，何者錯誤？

    1. (A) 詢問性侵害案件被害人，應選擇適當處所，並採隔離詢問，以一次詢畢為原則，非有必要，不得再次詢問
    2. (B) 受理性侵害案件被害人為女性時，應由女性警察人員處理為原則，如有需要，得通知偵查隊到場協助
    3. (C) 加害人未依規定辦理登記，管轄警察局應檢齊相關資料函請所屬直轄市、縣（市）主管機關依規定處罰
    4. (D) 加害人登記報到期間，管轄警察局應每個月對加害人實施查訪一次

    正解：(B)

  25. 25依據警察偵查犯罪手冊相關規定，有關警察機關執行電腦搜索應注意事項，下列敘述何者錯誤？

    1. (A) 搜索對象如為學校，應會同地檢署檢察官執行之
    2. (B) 勿安裝或拷貝任何程式、檔案至受搜索人的電腦中
    3. (C) 應讓受搜索人與電腦保持適當距離
    4. (D) 搜索應審慎為之，以免影響受搜索人權益

    正解：(A)
