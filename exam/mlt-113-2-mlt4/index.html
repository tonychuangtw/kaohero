  1. 1下列有關主要組織相容性複合體（major histocompatibility complex, MHC）的敘述，何者錯誤？

    1. (A) MHC class I由一條α chain和一條β2-microglobulin組合而成
    2. (B) MHC class II由一條α chain和一條β chain組合而成
    3. (C) MHC class I可結合8～10個胺基酸組成的胜肽抗原
    4. (D) MHC class II可結合2～5個胺基酸組成的胜肽抗原

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 說明：MHC class II 結合的胜肽較長，約 13～18 個胺基酸（甚至更長），因兩端開放無固定長度限制，故「2～5 個胺基酸」的敘述錯誤。

    ❌ (A) MHC class I 由多型性的 α chain（α1、α2、α3）與非共價結合的 β2-microglobulin 組成，敘述正確。

    ❌ (B) MHC class II 由 α chain 與 β chain 兩條鏈組成異二聚體，敘述正確。

    ❌ (C) MHC class I 的胜肽溝兩端閉合，結合約 8～10 個胺基酸的短胜肽，敘述正確。

    📚 出處：Janeway's Immunobiology 第 3 章抗原呈現（MHC class I 與 class II 結構及結合胜肽長度）。

  2. 2下列何種細胞激素由樹突細胞和巨噬細胞分泌，可促使T細胞往Th1分化？

    1. (A) IL-4
    2. (B) IL-6
    3. (C) IL-10
    4. (D) IL-12

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 說明：IL-12 由樹突細胞與巨噬細胞分泌，可誘導 T 細胞往 Th1 分化並促進 IFN-γ 產生，為 Th1 分化的關鍵細胞激素。

    ❌ (A) IL-4 促使 naive T 細胞往 Th2 分化，不促進 Th1。

    ❌ (B) IL-6 與 TGF-β 共同誘導 Th17 分化，非 Th1。

    ❌ (C) IL-10 為免疫抑制性細胞激素，抑制 Th1 反應與抗原呈現。

    📚 出處：Janeway's Immunobiology 第 10 章 T 細胞亞群分化（IL-12 誘導 Th1；IL-4 誘導 Th2）。

  3. 3下列分子與其配體（ligand）的組合，何者錯誤？

    1. (A) ICAM-1：DC-SIGN
    2. (B) CD2：LFA-3
    3. (C) VCAM-1：VLA-4
    4. (D) ICAM-3：LFA-1

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 說明：DC-SIGN（CD209）的配體是 ICAM-3（及 ICAM-2），並非 ICAM-1；ICAM-1（CD54）的配體為 LFA-1（CD11a/CD18）與 Mac-1，故此組合錯誤。

    ❌ (B) CD2 與 LFA-3（CD58）結合，屬 T 細胞與 APC 間黏附作用，正確。

    ❌ (C) VCAM-1 與 VLA-4（integrin α4β1）結合，介導淋巴球附著與遷移，正確。

    ❌ (D) ICAM-3（CD50）與 LFA-1 結合，為初始 T 細胞與 DC 黏附的重要配對，正確。

    📚 出處：Janeway's Immunobiology 第 3 章黏附分子（integrin 與 Ig superfamily 配對）；Abbas Cellular and Molecular Immunology 淋巴球活化與遷移章節。
