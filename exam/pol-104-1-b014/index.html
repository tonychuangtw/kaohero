警察特考　104 年 三等考試 中華民國憲法與消防警察專業英文　考古題與詳解

本卷共 60 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（60 題，建議 180 分鐘）

  1. 1我國憲法基本上已揭示了國家形式，下列何者不屬之？

    1. (A) 民主國
    2. (B) 法治國
    3. (C) 君主國
    4. (D) 共和國

    正解：(C)

  2. 2依據地方制度法規定，直轄市市長如何產生？

    1. (A) 由市民依法選舉之
    2. (B) 由行政院院長任命
    3. (C) 由市議員選舉之
    4. (D) 由內政部民政司派任

    正解：(A)

  3. 3直轄市政府辦理之自治事項有無違背憲法、法律、中央法規發生疑義時，得聲請何者解決？

    1. (A) 司法院
    2. (B) 立法院
    3. (C) 行政院
    4. (D) 監察院

    正解：(A)

  4. 4直轄市議會或縣議會議長，其產生方式為何？

    1. (A) 人民直接選舉之
    2. (B) 由市長提名經議會同意之
    3. (C) 議會議員互選之
    4. (D) 立法院院長提名經議會同意之

    正解：(C)

  5. 5下列何者不是縣市申請合併改制為直轄市之法定必要程序？

    1. (A) 擬訂改制計畫
    2. (B) 縣市議會同意
    3. (C) 縣市住民公民投票同意
    4. (D) 內政部報請行政院核定

    正解：(C)

  6. 6依憲法增修條文第 10 條第 3 項之規定：「國家對於人民興辦之中小型經濟事業，應扶助並保護其生存與發展。」下列何者主要目的在於實踐此一目標？

    1. (A) 中小企業發展條例
    2. (B) 科學技術基本法
    3. (C) 營業秘密法
    4. (D) 公平交易法

    正解：(A)

  7. 7下列關於基本權主體之敘述，何者正確？

    1. (A) 凡自然人均應享有基本權，因此不分國籍，外國人也都可享有全部我國憲法所賦予之基本權
    2. (B) 私法人可作為基本權之主體，因此私法人亦得主張宗教自由、選舉自由與政治選舉權
    3. (C) 地方自治團體可主張享有工作權，而要求不經中央許可發行彩券
    4. (D) 自然人及私法人為權利義務之主體，固均為憲法保護之對象，但為貫徹憲法對人格權及財產權之保障，於一定條件下，非法人團體亦為基本權主體

    正解：(D)

  8. 8憲法第 8 條規定，人民非經法定程序，不受逮捕、拘禁及審判，係屬下列何種權利之保障內容？

    1. (A) 居住自由
    2. (B) 遷徙自由
    3. (C) 生存權
    4. (D) 人身自由

    正解：(D)

  9. 9依司法院解釋，有關平等之敘述，下列何者錯誤？

    2. (B) 平等原則不只拘束行政權與司法權，也可以拘束立法權
    3. (C) 貨物稅條例規定僅對設廠機製之清涼飲料品課徵貨物稅，而未對非設廠機製者課徵貨物稅，不違反平等原則
    4. (D) 大陸地區人民經許可進入臺灣地區者，非在臺灣地區設有戶籍滿 10 年，不得擔任公務人員，違反平等原則

    正解：(D)

  12. 12憲法第 16 條規定，人民有請願、訴願及訴訟之權，針對上述基本權，下列敘述何者正確？

    2. (B) 此之訴訟僅指公法事件之爭議
    3. (C) 訴願之標的為所有行政行為
    4. (D) 訴願為法院外之救濟途徑

  13. 13關於憲法第 22 條之基本權保障概括規定，下列敘述何者錯誤？

    2. (B) 個人工作選擇之自由受憲法第 22 條保障
    3. (C) 個人自主控制個人資料之權利受憲法第 22 條保障
    4. (D) 個人之名譽權受憲法第 22 條保障

    正解：(B)

  14. 14有關集會與結社自由之敘述，下列何者正確？

    1. (A) 憲法之集會自由規定，不及於遊行之自由
    2. (B) 集會與結社之不同處，在於集會為組成長期間之團體
    3. (C) 集會自由兼具消極防禦侵害權與積極請求集會地點之公物利用權
    4. (D) 人民團體之命名權，非屬憲法第 14 條結社自由所保障之範疇

    正解：(C)

  15. 15下列涉及人民工作權之法律規定，依司法院解釋，何者已侵害人民之工作權？

    1. (A) 限制中醫師不得以西藥製劑或西藥成藥為人治病

    3. (C) 對於曾因觸犯故意殺人、搶劫、搶奪、強盜、恐嚇取財、擄人勒贖、妨害性自主等特定罪名並經判決罪刑確定之人，禁止其辦理營業小客車駕駛人執業登記
    4. (D) 禁止非視覺功能障礙者從事按摩業

    正解：(D)

  16. 16司法院釋字第 696 號解釋，對於所得稅法關於夫妻非薪資所得強制合併計算之規定，與單獨計算稅額比較，認為有增加稅負之情形，宣告相關規定違憲。本號解釋違憲審查之基準為何？
