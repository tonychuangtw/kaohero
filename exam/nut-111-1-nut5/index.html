營養師　111 年第一次 公共衛生營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1衛生福利部食品藥物管理署公告之「包裝食品營養標示應遵行事項」，下列敘述何者錯誤？

    1. (A) 固體（半固體）以公克或 g 標示，液體以毫升、mL 或 ml 標示
    2. (B) 熱量以大卡、Kcal 或 kcal 標示
    3. (C) 鈉以公克或 g 標示
    4. (D) 膳食纖維以公克或 g 標示

    正解：(C)

  2. 2根據第八版國人膳食營養素參考攝取量，懷孕期需要增加某些營養素攝取，下列何者例外？

    1. (A) 維生素 B12
    2. (B) 葉酸
    3. (C) 鈣
    4. (D) 鋅

    正解：(C)

  3. 3下列何者出自於衛生福利部國民健康署之「素食飲食指標」？

    1. (A) 含糖飲料應避免，多喝開水更健康
    2. (B) 健康體重要確保，熱量攝取應控管
    3. (C) 太鹹不吃少醃漬，低脂少炸少沾醬
    4. (D) 口味清淡保健康，飲食減少油鹽糖頁次：4－2

    正解：(D)

  4. 4每日飲食指南中，有關營養素占總熱量範圍之敘述，下列何者正確？

    1. (A) 醣類 50~60%
    2. (B) 脂質 20~25%
    3. (C) 蛋白質 10~14%
    4. (D) 多元不飽和脂肪酸 10~20%

    正解：(A)

  5. 5針對居住在社區具有獨立行動能力者，下列那個社區營養計畫較不適合？

    1. (A) 定點集聚式供餐服務
    2. (B) 送餐到家服務
    3. (C) 盛產食物補助
    4. (D) 營養諮詢

    正解：(B)

  6. 6下列何者不屬於 2025 年衛生福利政策白皮書中的健全青少年健康發展策略？

    1. (A) 倡議多喝白開水與低脂牛奶，取代含糖飲料
    2. (B) 倡議校園外周邊店家應提供無糖飲品及避免供應高油、高糖、高鹽之食物及點心
    3. (C) 限定國中小及高中職校園內依據「國民營養法」及「校園飲品及點心販售範圍」 ，販售健康食品
    4. (D) 推廣生活化運動（如走路或騎自行車上下學、走樓梯取代搭電梯等） ，鼓勵參與運動性社團，促進身體活動

    正解：(C)

  7. 7在工廠工作的林媽媽以母乳哺餵 5 個月大的嬰兒，在她上班時段，除原規定休息時間外，雇主每日另給她二次哺乳時間，每次以 30 分鐘為度，此乃依據下列何種法規？

    1. (A) 勞動基準法
    2. (B) 就業服務法
    3. (C) 性別工作平等法
    4. (D) 兒童及少年福利與權益保障法

    正解：(A)

  8. 8聯合國兒童基金會及世界衛生組織皆鼓勵純母乳哺育到出生後幾個月？並持續哺餵至幾歲？

    1. (A) 4 個月；1 歲
    2. (B) 4 個月；2 歲
    3. (C) 6 個月；1 歲
    4. (D) 6 個月；2 歲

    正解：(D)

  9. 9行政院於 2016 年起跨部會推動落實「食安五環」改革方案，不包括下列何者？

    1. (A) 提高查驗能力
    2. (B) 重建消費者信心
    3. (C) 加重惡意黑心廠商責任
    4. (D) 源頭控管，設立毒物管理機構

    正解：(B)

  10. 10國民飲食營養狀況監測調查是隸屬於衛生福利部之下那一機關的業務？

    1. (A) 疾病管制署
    2. (B) 國民健康署
    3. (C) 社會及家庭署
    4. (D) 食品藥物管理署

    正解：(B)

  11. 11下列那一個法，規定全國各級學校供應膳食者，應提供衛生、安全及營養均衡之餐食，實施營養教育，並由營養師督導及執行？

    1. (A) 營養師法
    2. (B) 學校衛生法
    3. (C) 國民營養法
    4. (D) 國民教育法

    正解：(B)

  12. 12迷你營養評估量表（MNA）包括下列何者？

    1. (A) 近 3 個月體重減輕百分比
    2. (B) 與同齡者健康狀況之比較
    3. (C) 吞嚥及消化道功能狀況之評估
    4. (D) 近 3 個月進食的六大類食物與份量

    正解：(B)

  13. 13以食物平衡表可以計算出下列何種數值？

    1. (A) 每人每日營養素參考攝取量
    2. (B) 每人每日平均可獲量
    3. (C) 每人每日攝取量
    4. (D) 每人每日需要量

    正解：(B)

  14. 14WHO 按骨密度（BMD）判定「骨量減少」（osteopenia），下列何者為其 T-score 範圍？

    1. (A) -1~1
    2. (B) -2.5~-1
    3. (C) -3~-2.5
    4. (D) <-3

    正解：(B)

  15. 15下列何者無法測試維生素 B6 的營養狀況？

    1. (A) 希林氏測驗（Schilling test）
    2. (B) 色胺酸負荷試驗（tryptophan loading test）
    3. (C) 甲硫胺酸負荷試驗（methionione loading test）
    4. (D) 紅血球轉胺酶活性（erythrocyte transaminase activities）

    正解：(A)

  16. 16下列何者不是我國評估代謝症候群（metabolic syndrome）的指標？

    1. (A) BMI≧27
    2. (B) 腰圍：男性≧90 cm、女性≧80 cm
    3. (C) 收縮血壓≧130 mmHg／舒張血壓≧85 mmHg
    4. (D) HDL 膽固醇：男性＜40 mg/dL、女性＜50 mg/dL頁次：4－3

    正解：(A)

  17. 17下列何種膳食調查方法，需計算實際進食人數？

    1. (A) 飲食記錄法
    2. (B) 食物秤重盤存法
    3. (C) 食物攝取頻率法
    4. (D) 24 小時飲食回憶法

    正解：(B)

  18. 18關於雙能量 X 光吸收測量（dual-energy x-ray absorptiometry, DEXA）的敘述，下列何者錯誤？

    1. (A) 適用於嬰兒體組成的評估
    2. (B) 可用來測量骨密度和體脂肪
    3. (C) 具備放射劑量低、執行時間短等優點
    4. (D) 所推算出來的體組成數據，與水下秤重法（underwater weighing）結果呈現高度相關

    正解：(A)

  19. 19WHO 之 0~5 歲兒童生長曲線圖，下列敘述何者錯誤？

    1. (A) 適用全球 0~5 歲的健康兒童
    2. (B) 臺灣目前採用此兒童生長標準
    3. (C) 選取餵食配方奶，處於營養良好的 0~5 歲兒童所繪製
    4. (D) 選取母親不吸菸，在良好健康環境成長的 0~5 歲兒童所繪製

    正解：(C)

  20. 20依據跨理論模式（Transtheoretical Model），如果一個人飲食行為改變階段正處於行動期中，請問有利於改變歷程的介入方法，下列何項較不適用？

    2. (B) 刺激控制
    3. (C) 增強管理
    4. (D) 反制約

    正解：(A)

  21. 21問卷調查題目： 「我願意為了控制體重而少喝含糖飲料 □非常同意 □同意 □無意見 □不同意□非常不同意」，屬那一類問卷？

  23. 23某問卷營養知識題共有 15 題，高分組（27 人）中答對第 1 題的人數有 25 人，低分組（27 人）答對第 1 題的人數有 12 人，請問第 1 題的難度分析結果為何？

    2. (B) 恰當
    3. (C) 太簡單
    4. (D) 不知總受試人數，故無法判斷

    正解：(B)

  24. 24「當看到媒體報導，有民眾因長期嗜飲高含糖飲料而導致血糖異常的新聞時，我便開始減少飲用含糖飲料。」根據健康信念模式（Health Belief Model） ，上述情境屬於下列那一項行為影響因素？

    1. (A) 自覺罹患性（perceived susceptibility）
    2. (B) 自覺嚴重性（perceived severity）
    3. (C) 自覺障礙（perceived barriers）
    4. (D) 行動線索（cues to action）

    正解：(D)

  25. 25依據計畫行為理論（Theory of Planned Behavior），「利用重要他人（例如：父母、師長或醫事人員等），對個人飲食行為的看法或意見之影響力，促使不良飲食行為的改善」 ，屬於下列那一項行為影響因素？

    3. (C) 依從動機（motivation to comply）
    4. (D) 知覺力量（perceived power）

    正解：(A)

  26. 26情意（affective）學習領域中，①價值評定（valuing） ②接受（receiving） ③反應（responding）④組織（organization）等層級，由低至高的順序為何？
