警察特考　102 年 三等考試 國文　考古題與詳解

本卷共 10 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（10 題，建議 30 分鐘）

  1. 1諸葛亮〈前出師表〉：「臣本布衣，躬耕於南陽，苟全性命於亂世，不求聞達於諸侯。先帝不以臣卑鄙，猥自枉屈，三顧臣於草廬之中，諮臣以當世之事，由是感激，遂許先帝以驅馳。」作者心意與下列那個選項最為貼近？

    1. (A) 士為知己者死，女為悅己者容
    2. (B) 劍外忽傳收薊北，初聞涕淚滿衣裳
    3. (C) 山不厭高，海不厭深。周公吐哺，天下歸心
    4. (D) 枯桑知天風，海水知天寒。入門各自媚，誰肯相為言

    正解：(A)

  2. 2「世有周子，儁俗之士，既文既博，亦玄亦史，然而學遁東魯，習隱南郭；竊吹草堂，濫巾北岳。誘我松桂，欺我雲壑。雖假容於江皋，迺纓情於好爵。」（孔稚珪〈北山移文〉）文中「周子」的心態，與下列選項相近的是：

    1. (A) 當其欣於所遇，暫得於己，快然自足，不知老之將至（王羲之〈蘭亭集序〉）
    2. (B) 老當益壯，寧移白首之心？窮且益堅，不墜青雲之志（王勃〈滕王閣序〉）
    3. (C) 志深軒冕，而泛詠臯壤；心纏幾務，而虛述人外（《文心雕龍．情采》）
    4. (D) 危邦不入，亂邦不居；天下有道則見，無道則隱（《論語》）102年公務人員特種考試警察人員考試、 30110-30710

    正解：(C)

  3. 3中國傳統戲劇的種類豐富，表演方法多樣，根據下列這首以數字嵌首的詩歌描述，請選出與它演出性質相符合的劇種：一人一仙分身段，兩手靈活交替換，三條引首上中下，四肢關節各有線，五指乾坤大運搬，六字訣法六神生，七星腳步要穩定，八音神咒護身形，九天知聞眾符令，十指能移百萬兵。

    1. (A) 布袋戲
    2. (B) 傀儡戲
    3. (C) 歌仔戲
    4. (D) 皮影戲

    正解：(B)

  4. 4「教養是一種內在自我的教育，對自己在宇宙與社會裡的定位有清楚的掌握與認知，對周遭生物的生存權利有敏感度，對別人的感受有所尊重，具強烈的正義感，知道如何節制自己，擁有具有目標的人生觀，是有擇善原則的社會人。」（黃崑巖《談教養》）下列選項何者無涉上文旨意？

    1. (A) 克己復禮之謂仁
    2. (B) 夫禮者，自卑而尊人
    3. (C) 三人同行，宜當擇善
    4. (D) 內修行義，莫矜伐掩人

    正解：(C)

  5. 5下列對聯所緬懷歌詠的人物，錯誤的是：

    1. (A) 「三顧頻煩天下計／兩朝開濟老臣心」：諸葛亮
    2. (B) 「數點梅花亡國淚／二分明月故臣心」：李後主
    3. (C) 「一門父子三詞客／千古文章八大家」：三蘇父子
    4. (D) 「志在高山，志在流水／一客荷樵，一客聽琴」：伯牙、鍾子期

    正解：(B)

  6. 6（本題題幹與選項都在圖上，請見下圖作答）

    正解：(D)

  7. 7文中「欲取飲者，皆洗心志」，這是說要喝澧泉的人，都必須：

    1. (A) 等待神意
    2. (B) 清心寡慾
    3. (C) 專心一意
    4. (D) 洗淨身體

    正解：(B)

  8. 8（本題題幹與選項都在圖上，請見下圖作答）

    正解：(D)

  9. 9下列選項何者正確？

    1. (A) 「觀物有疑」，源於視力不佳
    2. (B) 「冥冥而行」，指行事不光明
    3. (C) 「蹞步之澮」，指個性急躁之人碎步快走
    4. (D) 「厭目而視」，源於情勢亂其官能

    正解：(D)

  10. 10最符合本段主旨的選項是：

    1. (A) 處世判斷應眼見為憑，不可人云亦云
    2. (B) 只要心定慮清，可免於錯覺的影響，認清事實
    3. (C) 若以憎恨之眼，充耳不聞處世，則無法獲取他人認同
    4. (D) 行事問心無愧者，即使不幸身處幽暗，仍應企盼光明的到來

    正解：(B)
