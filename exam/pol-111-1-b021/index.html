警察特考　111 年 三等考試 行政法與警察行政違規調查裁處作業　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1行政程序法有關利害關係人之規定，不包括下列何者？

    1. (A) 書面之行政處分應送達已知之利害關係人
    2. (B) 行政機關作成限制或剝奪人民自由或權利之行政處分前，應給予利害關係人陳述意見之機會
    3. (C) 在行政程序中，利害關係人得申請閱覽卷宗
    4. (D) 因可歸責於利害關係人之事由，致程序有顯著延滯者，由其負擔因延滯所生之費用

    正解：(B)

  2. 2甲直轄市政府與乙直轄市政府可能發生之法律關係，不包括下列何者？

    1. (A) 行政契約關係
    2. (B) 職務上協助
    3. (C) 權限之委託
    4. (D) 權限之委任

    正解：(D)

  3. 3下列何種情形，行政機關不得依申請准為公示送達？

    1. (A) 應為送達之處所不明者
    2. (B) 於有治外法權人之事務所為送達而無效者
    3. (C) 於外國為送達，不能囑託該國管轄機關以雙掛號發送者
    4. (D) 對於不特定人之送達

    正解：(D)

  4. 4關於行政程序委任代理人之敘述，下列何者錯誤？

    1. (A) 每一當事人得委任三位代理人
    2. (B) 申請之撤回，須受特別授與代理權始得為之
    3. (C) 代理人於最初為行政程序行為時已確定者無須提出委任書
    4. (D) 代理權授與之撤回，經通知行政機關後，始對行政機關發生效力

    正解：(C)

  5. 5甲某日收受乙機關對其所作成之非授予利益之行政處分，於下列何種情況下，該行政處分無效？

    1. (A) 乙機關未給予甲陳述意見之機會
    2. (B) 乙機關承辦該事件之公務員應迴避而未迴避
    3. (C) 應以證書之方式作成而未給予證書
    4. (D) 該行政處分之內容違反法律保留原則

    正解：(C)

  6. 6甲機關作成行政處分，核發乙一筆補助款後，始發現乙不符合請領之資格。下列有關行政機關追回該補助款之敘述，何者正確？

    1. (A) 甲機關不必考量相關情事，皆得撤銷原處分，請求乙返還
    2. (B) 甲機關之上級機關無權撤銷原處分
    3. (C) 甲機關應於知悉該處分違法後 5 年內撤銷原處分，請求乙返還
    4. (D) 甲機關於撤銷原處分後，欲請求乙返還時應以行政處分為之

    正解：(D)

  7. 7關於行政處分附款之敘述，下列何者錯誤？

    1. (A) 行政機關作成行政處分有裁量權時，得為附款
    2. (B) 行政機關作成行政處分無裁量權時，不得為附款
    3. (C) 保留行政處分之廢止權得作為附款
    4. (D) 保留負擔之事後變更得作為附款

    正解：(B)

  8. 8甲向主管機關乙申請設廠之許可，若甲已大致符合法律所規定之設廠要件，僅欠缺一個要件時，下列敘述何者錯誤？

    1. (A) 乙得對甲為行政指導，輔導其如何符合該要件
    2. (B) 乙得對甲作成許可之處分，並附有工廠設備須向本國廠商購買之負擔
    3. (C) 乙得與甲簽訂行政契約，約定於甲符合該要件時，核發其許可
    4. (D) 乙得對甲作成許可之處分，並附有於甲符合該要件時，處分始生效力之條件

    正解：(B)

  9. 9甲依法向主管機關乙申請企業紓困貸款補助，於行政程序中甲申請閱覽卷宗，惟乙拒絕其閱覽。甲對於乙拒絕之表示，不得單獨提起救濟之理由，下列敘述何者正確？

    1. (A) 因該表示為行政程序中之處置
    2. (B) 因該表示為觀念通知
    3. (C) 因該表示未侵害甲之權利
    4. (D) 因甲無權申請閱覽卷宗

    正解：(A)

  10. 10下列有關行政契約之敘述，何者正確？

    1. (A) 行政契約違法時，皆為無效
    2. (B) 行政契約一部無效時，原則上全部無效
    3. (C) 行政機關不得與人民約定自願接受執行
    4. (D) 行政契約得以書面或言詞為之

    正解：(B)

  11. 11甲公司刊登不實廣告，違反法律規定，依行政罰法規定，可能受到處罰或主管機關得追繳其所受財產上之利益者，不包括下列何者？

    1. (A) 甲公司
    2. (B) 甲公司之董事乙
    3. (C) 代言該不實廣告的丙
    4. (D) 致使甲公司違反行政法上義務之職員丁

    正解：(D)

  12. 12甲對於行政機關之行為，得請求損失補償者，不包括下列何者？

    1. (A) 乙警員駕駛警車因過失違法撞傷甲
    2. (B) 消防人員丙為救助甲之鄰居需穿過甲屋而破壞甲屋之門窗
    3. (C) 主管機關撤銷其違法核予甲之設廠許可，然甲之信賴值得保護
    4. (D) 因法律變更，主管機關為維護公益而廢止先前核予甲之營業許可

    正解：(A)

  13. 13關於行政罰法規定輕微案件得免予處罰之規定，下列敘述何者正確？

    1. (A) 適用對象為應受法定最高額新臺幣五千元以下罰鍰之處罰
    2. (B) 得對違反行政法上義務者施以糾正，並作成紀錄，命其簽名
    3. (C) 得公布違反行政法上義務者之姓名或名稱
    4. (D) 得對違反行政法上義務者施以講習或輔導教育

    正解：(B)

  14. 14依廢棄物清理法規定，在指定清除地區內拋棄紙屑者，處新臺幣（下同）1,200 元以上 6,000 元以下罰鍰。若 17 歲的甲違反前揭規定，主管機關乙欲減輕其處罰時，乙得於下列何種罰鍰額度內行使裁量權？

    1. (A) 600 元以上 3,000 元以下
    2. (B) 400 元以上 2,000 元以下
    3. (C) 300 元以上 1,500 元以下
    4. (D) 240 元以上 1,200 元以下

    正解：(A)

  15. 15關於行政罰裁處權之時效規定，下列何者錯誤？

    1. (A) 行政罰之裁處權，因三年期間之經過而消滅
    2. (B) 裁處權時效自違反行政法上義務之行為終了時起算
    3. (C) 因免刑而應處以行政罰者，裁處權時效自免刑之裁判確定日起算
    4. (D) 行政罰之裁處因行政訴訟經撤銷而須另為裁處者，裁處權時效自原裁處被判決撤銷之日起算

    正解：(D)

  16. 16下列有關行政執行之敘述，何者正確？

    1. (A) 義務人死亡時，得對其繼承人之財產為強制執行
    2. (B) 日間開始執行者，於夜間到來時，應停止執行
    3. (C) 義務人對於執行方法聲明異議，其就主管機關所為聲明異議之決定，不得提起救濟
    4. (D) 義務人懷胎 5 月以上或生產後 2 月未滿者，不得管收

    正解：(D)

  17. 17人民不履行行政法上之義務，於行政執行時得處怠金者，為下列何種情形？

    1. (A) 命甲自行拆除違章建築，而甲不自行拆除
    2. (B) 命乙公司停止營業，而乙公司不為停止
    3. (C) 通知丙限期補繳稅款，而丙逾期仍不繳納
    4. (D) 命丁撲殺其已得傳染病之犬隻，而丁不為撲殺

    正解：(B)

  18. 18下列何者非行政執行機關核發禁止為特定投資命令之要件？

    1. (A) 義務人為自然人
    2. (B) 義務人之滯欠合計達一定金額
    3. (C) 已發現之財產足以清償其所負義務
    4. (D) 義務人之生活逾越一般人通常程度者

    正解：(C)

  19. 19關於行政執行之拘提，下列敘述何者正確？

    1. (A) 義務人顯有逃匿之虞者，執行員得逕行拘提之
    2. (B) 義務人經拘提到場，法院應即為必要之調查
    3. (C) 拘提後，義務人已履行全部義務，應即釋放之
    4. (D) 義務人經拘提到場，符合管收要件者，應將之送交管收所

    正解：(C)

  20. 20關於訴願期間之敘述，下列何者正確？

    1. (A) 訴願之提起，應自行政處分達到之日起算三十日內為之
    2. (B) 利害關係人提起訴願者，自行政處分公告期滿後，已逾一年者，不得提起
    3. (C) 訴願之提起，以受理訴願機關收受訴願書之日期為準
    4. (D) 誤向原行政處分機關以外之機關提起訴願者，以該機關知悉之日，視為提起訴願之日

    正解：(C)

  21. 21關於訴願參加，下列敘述何者錯誤？

    1. (A) 申請參加訴願，應以書面向受理訴願機關為之
    2. (B) 通知參加訴願，應記載法定事項送達於參加人
    3. (C) 通知參加訴願應通知訴願人以書面陳述意見
    4. (D) 訴願決定對於經受理訴願機關通知其參加而未參加者亦有效力

    正解：(C)

  22. 22關於訴願代理之敘述，下列何者錯誤？

    1. (A) 委任二人以上為訴願代理人，縱約定不得單獨代理，訴願代理人仍得單獨代理
    2. (B) 訴願代理人事實上之陳述，經到場之訴願人本人即時更正者，不生效力
    3. (C) 訴願代理權因訴願人本人死亡、破產或喪失訴願能力而消滅
    4. (D) 訴願委任之解除，應由訴願人以書面通知受理訴願機關

    正解：(C)

  23. 23甲針對下列何種事件提起行政訴訟，有起訴期間之限制？

    1. (A) 甲請求與其締結行政契約之機關履行義務
    2. (B) 甲申請建造執照而主管機關未予回覆
    3. (C) 甲認為原行政處分無效
    4. (D) 甲認為主管機關就其徵收案件未依限補償，原徵收處分已失其效力

    正解：(B)

  24. 24甲因違規被乙機關裁處新臺幣（下同）10 萬元罰鍰，甲不服提起訴願，受理訴願機關丙機關認為應裁處 7 萬元而非 10 萬元罰鍰，遂變更原處分。甲若仍不服，續提起撤銷訴訟時，下列有關被告之敘述，何者正確？

    1. (A) 應併列乙機關與丙機關為被告
    2. (B) 由甲選擇列乙機關或丙機關為被告
    3. (C) 只列乙機關為被告
    4. (D) 只列丙機關為被告

    正解：(D)

  25. 25關於行政訴訟撤回起訴之規定，下列何者錯誤？

    1. (A) 原告於對公益之維護無礙時，得於判決確定前撤回訴之全部或一部
    2. (B) 原告撤回起訴時，被告已為本案之言詞辯論者，應得其同意
    3. (C) 訴之撤回，應以書狀為之，但於期日得以言詞為之
    4. (D) 訴之撤回，被告於期日到場，未為同意與否之表示者，視為同意撤回

    正解：(D)
