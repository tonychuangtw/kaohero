警察特考　102 年 四等考試 警察勤務概要　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關警察勤務，下列敘述何項錯誤？

    1. (A) 每日勤務時間為 24 小時，0 時至 6 時為深夜勤，18 時至 24 時為夜勤，餘為日勤。延長服勤、停止輪休或待命服勤，酌予補假
    2. (B) 勤務交接時間，由警察分局定之
    3. (C) 服勤人員每日勤務以 8 小時為原則；必要時，得視實際情形酌量延長之
    4. (D) 服勤人員每週輪休全日 2 次，遇有臨時事故得停止之；並得視治安狀況需要，在勤務機構待命服勤

    正解：(B)

  2. 2依據警察勤務條例，警勤區之劃分，除依據人口數外，不應參酌下列何種條件？

    1. (A) 治安狀況、地區特性
    2. (B) 警力多寡、工作繁簡
    3. (C) 貧富分布、經濟條件
    4. (D) 交通電信設施、未來發展趨勢

    正解：(C)

  3. 3警察職權行使法所稱警察機關主管長官，係指何種職務以上長官？

    1. (A) 內政部部長
    2. (B) 地區警察分局長
    3. (C) 警察局局長
    4. (D) 警政署署長

    正解：(B)

  4. 4有關警察實施家戶訪查，下列何者錯誤？

    1. (A) 警勤區員警家戶訪查，應嚴守行政中立，並不得利用權力、機會或方法使他人加入政治團體或參與協助政黨
    2. (B) 警勤區員警家戶訪查所得資料，應保守秘密，不得洩漏
    3. (C) 警勤區員警實施家戶訪查，只要告知訪查事由即可，不需要著制服
    4. (D) 警察家戶訪查，應尊重當事人之權益，依誠實方法為之，不得逾越訪查目的之必要範圍，並應與訪查目的具有正當合理之關聯

    正解：(C)

  5. 5警察勤務對於民眾私人行為和民事上的法律關係，原則是不予干預，這是何種原則？

    1. (A) 警察目的原則
    2. (B) 警察適合性原則
    3. (C) 警察比例原則
    4. (D) 警察公共原則

    正解：(D)

  6. 6下列何者是警察勤務規劃監督及重點性勤務執行機構，負責規劃、指揮、管制、督導及考核轄區各勤務執行機構之勤務實施，並執行重點性勤務？

    1. (A) 派出所
    2. (B) 分駐所
    3. (C) 警察分局
    4. (D) 縣市警察局

    正解：(C)

  7. 7警察勤務之實施，應晝夜執行，普及轄區，並以那一類警察為中心，其他各種警察配合之？

    1. (A) 行政警察
    2. (B) 刑事警察
    3. (C) 交通警察
    4. (D) 外事警察

    正解：(A)

  8. 8警察應視轄區面積及治安、地理、交通情形實施巡邏，下列何者非警察巡邏勤務方式？

    1. (A) 船巡
    2. (B) 空中巡邏
    3. (C) 騎巡
    4. (D) 潛水巡邏

    正解：(D)

  9. 9下列何者是警察行使職權的錯誤執行方式？

    1. (A) 警察行使職權，得逾越所欲達成執行目的之必要限度，且應以對人民權益侵害最適當方法為之
    2. (B) 警察行使職權已達成其目的，或依當時情形，認為目的無法達成時，應依職權或因義務人、利害關係人之申請終止執行
    3. (C) 警察行使職權時，應著制服或出示證件表明身分，並應告知事由
    4. (D) 警察行使職權，不得以引誘、教唆人民犯罪或其他違法之手段為之

    正解：(A)

  10. 10警察勤務執行前，應舉行勤前教育。下列何種類型，不是制式勤前教育？

    1. (A) 基層勤前教育
    2. (B) 聯合勤前教育
    3. (C) 專案勤前教育
    4. (D) 分段勤前教育

    正解：(D)

  11. 11警察遴選第三人秘密蒐集特定人相關資料，下列敘述何者正確？

    1. (A) 只能由縣市警察局長核准後實施
    2. (B) 蒐集工作結束後，警察應與第三人終止合作關係。但有事實，而有繼續進行蒐集必要且經核准者，得繼續合作關係
    3. (C) 於相關法律程序中作為證據使用時，應依民事相關訴訟法之規定
    4. (D) 該第三人為證人者，並不適用關於證人保護法之規定

    正解：(B)

  12. 12依據各級警察機關勤務指揮中心作業規範，下列那個單位沒有設立勤務指揮中心？

    1. (A) 內政部警政署
    2. (B) 新北市政府警察局
    3. (C) 新北市政府警察局新莊分局
    4. (D) 林口警察分駐所

    正解：(D)

  13. 13行政警察勤務區之劃分，下列何種業務警察得配合劃分責任區？

    1. (A) 交通警察、消防警察
    2. (B) 刑事警察、外事警察
    3. (C) 森林警察、環保警察
    4. (D) 國境警察、鑑識警察

    正解：(B)

  14. 14司法院釋字第 535 號解釋文中對警察勤務條例敘述，下列何者錯誤？

    1. (A) 警察勤務條例已非單純組織法，實兼有行為法之性質
    2. (B) 對人實施臨檢須有相當理由足認其行為已構成或即將發生危害者為限，且均應遵守比例原則，不得逾必要程度
    3. (C) 臨檢進行時，必須出示證件表明其為執行人員之身分
    4. (D) 臨檢進行前，不需要對在場者告以實施之事由

    正解：(D)

  15. 15保安警察派駐地方執行職務時，兼受縣市長指揮監督。其與當地警察機關之聯繫，下列敘述何種錯誤？

    1. (A) 保安警察依指揮監督機關首長之命令，執行特定警察業務，對當地警察機關居於輔助地位
    2. (B) 保安警察與當地警察機關基於治安或業務需要，得互請協助，關於勤務分配應會商行之
    3. (C) 保安警察協助地方治安，執行特定警察業務，對當地警察機關居於主導地位
    4. (D) 保安警察協助配駐地方警察行政業務，應受當地警察機關首長之指導

    正解：(C)

  16. 16下列何種情形，有關警察機關扣留之物得予變賣之敘述錯誤？

    1. (A) 有腐壞或價值重大減損之虞
    2. (B) 經通知 1 個月內領取，且註明未於期限內領取，將予變賣，而所有人持有人或保管人未於期限內領取
    3. (C) 保管、照料或持有所費過鉅或有其困難
    4. (D) 扣留期間逾 6 個月，無法返還所有人、持有人或保管人，且不再合於扣留之要件

    正解：(B)

  17. 17警勤區劃分，下列敘述何者正確？

    1. (A) 依自治區域，以一村里劃設一警勤區；村里過小者，得以二以上村里劃設一警勤區；村里過大者，得將一村里劃設二以上警勤區
    2. (B) 依自治區域，以二村里劃設一警勤區；村里過小者，得以三以上村里劃設一警勤區；村里過大者，得將二村里劃設三以上警勤區
    3. (C) 依人口疏密，以 1000 人口或 500 戶以下劃設一警勤區
    4. (D) 依人口疏密，以 3000 人口或 800 戶以下劃設一警勤區

    正解：(A)

  18. 18警察於公共場所或指定處所、路段，由服勤人員擔任臨場檢查或路檢，執行取締、盤查及有關法令賦予之任務，稱為什麼勤務？

    1. (A) 地區守望
    2. (B) 街頭巡邏
    3. (C) 臨檢
    4. (D) 備勤

    正解：(C)

  19. 19有關警察勤務，下列敘述何者錯誤？

    1. (A) 勤區查察為個別勤務，由警勤區員警專責擔任
    2. (B) 巡邏、臨檢、守望、值班及備勤為共同勤務，由服勤人員按勤務分配表輪流交替互換實施之
    3. (C) 共同勤務得視服勤人數及轄區治安情形，採用巡邏及其他方式互換之，但均以臨檢為主
    4. (D) 警察勤務條例依據警察法第 3 條規定制定之

    正解：(C)

  20. 20勤區查察方式的改變是因應社會變遷有所調整而改變，下列敘述何者錯誤？

    1. (A) 以往戶口查察有侵犯民眾隱私之嫌
    2. (B) 於警勤區內，由警勤區員警執行之，以家戶訪查方式為之
    3. (C) 擔任犯罪預防、為民服務及社會治安調查等任務
    4. (D) 家戶訪查辦法，由內政部警政署刑事警察局定之

    正解：(D)

  21. 21警勤區之基本資料，所謂「一圖」是何者正確？

    1. (A) 警勤區轄境圖
    2. (B) 治安斑點圖
    3. (C) 家戶訪查圖
    4. (D) 人口動態趨勢圖

    正解：(A)

  22. 22警察分局每半年應實施警勤區員警家戶考詢 1 次，考詢內容不包括下列對象或狀況？

    1. (A) 轄區重要人士
    2. (B) 轄區治安概況
    3. (C) 轄區重大或連續犯罪人口
    4. (D) 轄區家暴或失蹤人口

    正解：(D)

  23. 23警察勤務條例之規定適用於各縣市警察局。至於本條例之於各專業警察機關之勤務為何？

    1. (A) 各專業警察機關執行各該專屬勤務時準用之
    2. (B) 各專業警察機關另行制定各該專屬勤務之規定
    3. (C) 各專業警察機關執行各該專屬勤務時，因地制宜，有些適用，有些不適用
    4. (D) 各專業警察機關執行各該專屬勤務時，不需要有類似警察勤務條例之規定

    正解：(A)

  24. 24員警於捷運車站巡邏，發現一名疑似精神疾病之男子，在月台上意圖自殺，應該採取何種處置？

    1. (A) 私人行為，不予干涉
    2. (B) 聯絡捷運保全人員，向前制止其行為
    3. (C) 依警察職權行使法規定，為保護其生命，得暫予管束
    4. (D) 依社會秩序維護法規定，命令其離開車站

    正解：(C)

  25. 25依據警察職權行使法，警察執行勤務於公共場所或合法進入之場所，得對民眾查證其身分，下列敘述何者錯誤？

    1. (A) 合理懷疑其有犯罪之嫌疑或有犯罪之虞者
    2. (B) 有事實足認其對已發生之犯罪或即將發生之犯罪知情者
    3. (C) 有事實足認為防止其本人或他人生命、身體之具體危害，有查證其身分之必要者
    4. (D) 不論是否為營業時間，警察都可以進入公眾得出入之營業場所

    正解：(D)

  26. 26員警執行巡邏勤務時，接獲民眾兇殺案件報案，當第一時間抵達現場，發現有人死亡，有人受傷，下列何種處置作為應該最優先？

    1. (A) 報告分局長
    2. (B) 通知葬儀社
    3. (C) 通報消防單位派救護車，將傷者送醫
    4. (D) 通知家屬

    正解：(C)

  27. 27我國警察勤務條例的敘述，下列何者正確？

    1. (A) 最新修正時間是民國 96 年 7 月
    2. (B) 是依據警察法第 4 條規定制定
    3. (C) 總共條文 30 條
    4. (D) 各級警察機關應擬定實施細則，陳報其上級警察機關核准施行

    正解：(D)

  28. 28對於轄區治安顧慮人口家戶訪查不遇，下列作法何者錯誤？

    1. (A) 以書面或電話再約定時間查訪
    2. (B) 最好於晚上 10 點前實施家戶訪查
    3. (C) 申請拘票，拘提之
    4. (D) 如果行蹤不明，應通報協尋

    正解：(C)

  29. 29警勤區員警對於新遷入人口、失蹤人口、身分不明人口以及有刑案紀錄者實施家戶訪查時，下列那一事項是正確的？

    1. (A) 新遷入人口基本資料將由勤區查察處理系統，主動以新增訊息方式通知，警勤區員警接獲通知後，應主動於 3 個月內實施現地訪查
    2. (B) 警勤區員警接獲受理失蹤人口報案通報後，應於 3 日內前往訪問關懷家屬，並至少每 3 個月訪查 1 次
    3. (C) 警勤區員警應隨時使用電腦核對治安顧慮人口等特別具有記事人口資料，於戶卡片目錄註記「記事 1」，並依警察勤務條例實施查訪
    4. (D) 身分不明人口如經比對或查詢無法得知身分時，為因應個人資料保護法之施行，處理人員不得以數位相機拍下該個案照片，而是應盡速利用大眾傳播工具，加以宣導、查尋

    正解：(B)

  30. 30有關家戶訪查對於屢查不遇人口通報作業程序，下列事項何者是正確的？

    1. (A) 家戶訪查應於日間行之，但屢查不遇人口（3 次以上），經與受查訪人約定時間查察（得於任何時間）者，不在此限
    2. (B) 有關居住事實之認定、虛報遷徙登記、撤銷遷出等業務，依戶籍法施行細則第 2 條之 1 暨戶籍法第 25 條、第 54 條規定均屬警察機關權責
    3. (C) 警察機關對虛報遷徙人口處理，僅於家戶訪查發現疑似未按址居住情事時，基於協助互惠原則，得將查訪情形通報戶政事務所依權責查處
    4. (D) 警勤區員警可以連線勤區查察處理系統，擬訂勤區查察腹案日誌表。利用間接訪查詢問訪查未遇人口可能在家時段，再次擬訂腹案日誌表，並於戶卡片副頁及日誌表註記第 2 次查訪，儘量規劃同時段前往查訪後，將日誌表陳請分駐（派出）所所長核定，納入勤務編排

    正解：(C)

  31. 31警察職權行使法對於攔檢盤查的依據，在該法第 6 條有明確的規定，其部分內容略為：「其地點由警察機關主管長官指定之」，有關指定的要件內容，下列那一項非屬之？

    1. (A) 處理重大公共安全而有必要者
    2. (B) 以防止犯罪而有必要者
    3. (C) 處理社會秩序事件而有必要者
    4. (D) 以偵查犯罪而有必要者

    正解：(D)

  32. 32有關警察職權行使法第 3 條第 3 項之規定，主要是在禁止以引誘教唆違法手段達到警察目的，因而，警察執勤若使用「陷害教唆」的執勤方式應該被禁止。該條文的規定係要求警察執法應遵守下列那項原則？

    1. (A) 警察目的原則
    2. (B) 誠信原則
    3. (C) 比例原則
    4. (D) 保留原則

    正解：(B)

  33. 33依據警察勤務條例及學者專家之著作，有關勤務督導之規定下列何者正確？①各級警察機關為激勵服勤人員工作士氣，指導工作方法及考核勤務績效，應實施勤務督導及獎懲 ②黎明、黃昏、暴風、雨、雪、重要節日及特殊地區，應加強勤務督導 ③勤務督導分為駐區督導、專業督導及聯合督導④根據各國警察監督的方法，可分為外勤及內勤兩類。外勤的監督方法包括警用電話（無線電話）的使用、巡邏箱（線）使用、實地考察等；內勤監督方法包括上下班及請假查考、工作數量記載、工作辛苦程度等等

    1. (A) ①②③
    2. (B) ②③④
    3. (C) ①②④
    4. (D) ①③④

    2. (B) 警察機關為掌握全般治安狀況，發揮勤務指揮管制功能，設置三級勤務指揮中心，其中警察局與港務警察局勤務指揮中心屬於第二級

    4. (D) 各級勤務指揮中心自民國 68 年開始創立，三級開設時，由總值日官督導運作；非辦公時間由執勤官代理之

  39. 39依據警察職權行使法第 15 條第 3 項規定訂定之「治安顧慮人口查訪辦法」，有關查訪項目、查訪次數、查訪期間等之規定，下列敘述何者錯誤？

    2. (B) 治安顧慮人口由戶籍地警察機關每個月實施查訪 1 次。必要時，得增加查訪次數。戶籍地警察機關發現查訪對象不在戶籍地時，應查明及通知所在處所之警察機關協助查訪；其為行方不明者，應通報直轄市、縣（市）政府警察局協尋
    3. (C) 警察實施查訪，應選擇適當之時間、地點，以家戶訪問或其他適當方式為之，並應注意避免影響查訪對象之工作及名譽
    4. (D) 警察實施查訪，應於日間為之。但與查訪對象約定者，不在此限。實施查訪時，必須著制服，並告知事由

  40. 40有關警察職權行使法第 9 條「蒐集公共活動參與者現場活動資料」之規定，下列何者正確？

    2. (B) 本條文賦予警察在集會遊行或公共活動中，有權攝影、錄音，此乃係因應人民言論之權利意識高漲所造成的立法結果
    3. (C) 依本條文第 2 項及第 3 項規定，為調查犯罪或其他違法行為，得保存攝影錄音資料之規定看來，本條職權之行使，具有促進人民福利之作用
    4. (D) 依本條文規定所蒐集之資料，於活動結束後，應立即儲存於警政資料庫，俾利其他公務機關使用

    正解：(A)
