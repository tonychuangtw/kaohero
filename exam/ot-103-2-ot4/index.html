本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1脂肪肝是屬於DSM-IV診斷中的那一軸？

    1. (A) 第一軸（Axis I）
    2. (B) 第二軸（Axis II）
    3. (C) 第三軸（Axis III）
    4. (D) 第四軸（Axis IV）

    正解：(C)

  2. 2阿姨常常覺得她的摩托車沒有熄火，車鑰匙插在鎖孔上，車子就要被偷走。不論在家裡或外出，她總是要一再一再地去檢查摩托車，若不能馬上去看，壓力就大到快崩潰，即便晚上睡覺時也一樣。根據DSM-IV，請問她可能有什麼傾向？

    1. (A) 廣泛性焦慮症（generalized anxiety disorder）
    2. (B) 幽閉恐懼症（specific phobia）
    3. (C) 解離症（dissociative disorder）
    4. (D) 強迫症（obssesive compulsive disorder）

    正解：(D)

  3. 3根據DSM-IV，有關物質關聯疾患，下列敘述何者錯誤？

    1. (A) 物質用量要越來越大才能達到想要的效果，稱之為：耐受性
    2. (B) DSM-Ⅳ將咖啡因（caffeine）列入成癮物質之一
    3. (C) 物質關聯疾患分別包括物質使用疾患及物質誘發疾患兩大類
    4. (D) 安非他命（amphetamines）易有依賴、濫用、中毒和戒斷症狀

    正解：(B)

  4. 4根據DSM-IV，失智症的蔣伯伯鬍渣滿下巴，兒子拿起伯伯的電動刮鬍刀給他，伯伯熟練地刮完鬍子，兒子指著刮鬍刀問他：「這個是什麼？」。伯伯說：「這個，咦？這個就是…，咦？就是那個…什麼」。請問這是什麼症狀的表現？

    2. (B) 失用症
    3. (C) 執行功能障礙
    4. (D) 失憶症

    正解：(A)

  5. 5根據DSM-IV，下列有關躁症的敘述那些正確？①躁症的特質是過度的欣快感、慷慨、易怒、分心及活動量增加 ②對於個案的行為表現要多給讚美及認同 ③環境應儘量單純，減少使個案分心的事物 ④活動應具結構化，可給予活動量大之短程活動

    4. (D) ①②④
