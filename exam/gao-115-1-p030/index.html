  1. 1若 W 代表燃油汽車數量，I 代表所得，X 代表燃油汽車價格，Y 代表汽油價格，Z 代表電動汽車價格。市場對燃油汽車的需求函數為 W = a + bI + cX + dY + eZ，其中 a、b、c、d、e 為固定的參數或數值。根據以上關係，對燃油汽車需求的敘述，下列何者正確？

    1. (A) 當燃油汽車為劣等商品（inferior good），b > 0
    2. (B) 根據供給法則，c < 0
    3. (C) 根據所得效果，d > 0
    4. (D) e > 0，代表燃油汽車與電動汽車兩者為替代品

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) e > 0 表示電動汽車價格上升時燃油汽車需求增加，兩者互為替代品。

    ❌ (A) 劣等財是所得增加、需求減少，係數應為 b < 0。

    ❌ (B) c < 0 反映的是需求法則（自身價格與需求量反向），不是供給法則。

    ❌ (C) d 衡量的是汽油這個互補品的價格效果，互補品漲價使需求減少（d < 0），與所得效果無關。

    📚 出處：經濟學—需求函數與需求移動因素（替代品、互補品、正常財與劣等財）。

  2. 2甲對商品 X 的需求價格彈性為-0.8，這表示：

    1. (A) 商品 X 的價格上升 1 單位，甲對商品 X 的需求會減少 0.8 單位
    2. (B) 以絕對值而言，該價格彈性大於 0.5，表示甲對商品 X 的需求為有彈性的（elastic）
    3. (C) 隨商品 X 的價格上升，甲對商品 X 的支出會上升
    4. (D) 商品 X 的替代品增加時，以絕對值而言，該彈性的大小會下降

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 彈性絕對值 0.8 < 1 屬缺乏彈性，價格上升時需求量減少的幅度小於漲價幅度，總支出因而上升。

    ❌ (A) 彈性是百分比對百分比的比值，不是「價格漲 1 單位、數量減 0.8 單位」。

    ❌ (B) 判斷有無彈性的分界是 1 不是 0.5，0.8 < 1 為缺乏彈性。

    ❌ (D) 替代品增加會使需求更富彈性，絕對值上升而非下降。

    📚 出處：經濟學—需求價格彈性的定義及其與總支出的關係。

  3. 3若政府對市場進行干預，干預對市場影響的敘述，下列何者正確？

    1. (A) 有效的數量管制，為將數量上限訂在超過市場均衡數量的水準
    2. (B) 以量制價為政府藉由調節供需數量達到平穩價格的措施
    3. (C) 農產品的保價收購，為價格上限（price ceiling）的價格管制措施
    4. (D) 臺灣曾施行的三七五減租，為價格下限（price floor）的價格管制措施

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 以量制價是政府透過調節供給或需求的數量（如釋出庫存、開放進口）來平穩價格。

    ❌ (A) 數量上限若訂在均衡數量之上不具拘束力，等於沒有管制。

    ❌ (C) 農產品保價收購保障價格不低於某水準，屬價格下限。

    ❌ (D) 三七五減租限制地租不得超過主要作物收穫量的 37.5%，是價格（租金）上限。

    📚 出處：經濟學—政府的價格管制（價格上限與價格下限）與數量管制。
