  1. 1N 位元二的補數（2's complement）能夠表示之負整數中，下列何者是能代表的最小負整數？

    1. (A) -2N
    2. (B) -2N-1
    3. (C) -2N-1
    4. (D) -2N-1-1

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) N 位元二的補數的表示範圍為 −2^(N−1) 至 2^(N−1)−1，最小的負整數為 −2^(N−1)。

    ❌ (A) −2^N 超出 N 位元所能表示的範圍。

    ❌ (B) −2^N−1 同樣超出表示範圍。

    ❌ (D) −2^(N−1)−1 比最小值再小 1，無法表示。

    📚 出處：二的補數的表示範圍。

  2. 2下列存放資料的裝置中，何者具有非揮發性（nonvolatility）？

    1. (A) 快閃記憶體（flash memory）
    2. (B) 靜態隨機存取記憶體（static random-access memory，SRAM）
    3. (C) 動態隨機存取記憶體（dynamic random-access memory，DRAM）
    4. (D) 處理器暫存器（register）

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 快閃記憶體斷電後資料仍保留，屬非揮發性儲存裝置。

    ❌ (B) SRAM 斷電後資料消失，屬揮發性。

    ❌ (C) DRAM 須持續更新且斷電即失，屬揮發性。

    ❌ (D) 處理器暫存器斷電後內容即消失。

    📚 出處：記憶體階層；揮發性與非揮發性。

  3. 3有關中央處理器（central processing unit, CPU）與圖形處理器（graphics processing unit, GPU）的比較，下列何者錯誤？

    1. (A) GPU 是用來增強特定運算的加速器，因此它不需要具備執行所有 CPU 工作的能力
    2. (B) CPU 強調利用多緒處理來隱藏記憶體延遲，GPU 則強調利用多層的快取來克服記憶體存取時的延遲時間
    3. (C) GPU 記憶體的設計著重提高頻寬
    4. (D) GPU 比 CPU 可容納更多的執行緒（threads）

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 此項錯誤：CPU 以多層快取克服記憶體延遲，GPU 則以大量執行緒切換隱藏延遲，兩者的敘述恰好對調。

    ❌ (A) 敘述正確，GPU 為特定運算的加速器。

    ❌ (C) 敘述正確，GPU 記憶體設計著重高頻寬。

    ❌ (D) 敘述正確，GPU 可同時容納遠多於 CPU 的執行緒。

    📚 出處：計算機組織；CPU 與 GPU 架構的比較。
