警察特考　102 年 三等考試 警察學與警察勤務　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1下列有關警察任務、警察業務和警察勤務的敘述，何者正確？

    1. (A) 警察任務是警察勤務具體化的結果
    2. (B) 警察任務是警察業務具體化的結果
    3. (C) 警察勤務的推動，須仰賴警察業務的實施
    4. (D) 警察勤務是完成警察任務的手段

    正解：(D)

  2. 2依警察職權行使法規定，為維護治安之必要時，依規定以監視器蒐集之資料，除因調查犯罪嫌疑或其他違法行為，有保存之必要者外，至遲應於資料製作完成時多久期間內銷毀之？

    1. (A) 3 個月內
    2. (B) 6 個月內
    3. (C) 1 年內
    4. (D) 2 年內

    正解：(C)

  3. 3警勤區員警家戶訪查時，下列何事項不宜實施？

    1. (A) 提供家戶成員生涯規劃之分析與建議
    2. (B) 指導家戶生活安全維護事項
    3. (C) 訪詢家戶生活安全需求事項
    4. (D) 告知防範危害事故相關作為

    正解：(A)

  4. 4我國在解嚴後，停止軍職轉任，警政回歸專業，警察專業背景出任首任警政署長者為誰？

    1. (A) 顏世錫
    2. (B) 盧毓鈞
    3. (C) 莊亨岱
    4. (D) 孔令晟

    正解：(C)

  5. 5國營事業民營化之後，例如臺灣糖業公司，其警衛保安工作已交由民間保全擔任。民營化之前，係由下列那一警察單位負責？

    1. (A) 保一總隊
    2. (B) 保二總隊
    3. (C) 保三總隊
    4. (D) 保四總隊

    正解：(B)

  6. 6以下何項不是以整體做系統式之規劃，達成預防犯罪於未然的警政策略？

    1. (A) 社區警政（community policing）
    2. (B) 問題導向警政（problem-oriented policing）
    3. (C) 環境設計警政（environmental design policing）
    4. (D) 強勢警力巡邏（intensive patrol）

    正解：(D)

  7. 7有關治安顧慮人口之查訪，下列何項敘述錯誤？

    1. (A) 戶籍地警察機關每個月實施查訪 1 次
    2. (B) 警察實施查訪應注意避免影響查訪對象之工作及名譽
    3. (C) 警察對於在社會上已享有一定程度聲望與地位之查訪對象，應即中止實施查訪
    4. (D) 警察實施查訪，應於日間為之。但與查訪對象約定者，不在此限102年公務人員特種考試警察人員考試、

    正解：(C)

  8. 8下列何單位無權發布警察命令？

    1. (A) 內政部
    2. (B) 直轄市政府
    3. (C) 縣（市）政府
    4. (D) 鄉鎮公所

    正解：(D)

  9. 9漢朝時期執行治安類似今日警察者稱為：

    1. (A) 執金吾
    2. (B) 錦衣衛
    3. (C) 捕快
    4. (D) 巡捕

    正解：(A)

  10. 10下列何者非屬家戶訪查的任務？

    1. (A) 犯罪預防
    2. (B) 為民服務
    3. (C) 政治偵防
    4. (D) 社會治安調查

    正解：(C)

  11. 11警察勤務區員警對於轄內新遷入居民，應於多久期間內實施現地訪查？

    1. (A) 1 個月內
    2. (B) 2 個月內
    3. (C) 3 個月內
    4. (D) 6 個月內

    正解：(A)

  12. 12依警察勤務條例規定，警勤區劃分的主要依據為何？

    1. (A) 自治區域、治安狀況
    2. (B) 人口疏密、面積廣狹
    3. (C) 自治區域、人口疏密
    4. (D) 治安狀況、面積廣狹

    正解：(C)

  13. 13依警察勤務條例規定，下列何者是執行重點性勤務的機構？

    1. (A) 警察勤務區
    2. (B) 警察派出所
    3. (C) 警察分駐所
    4. (D) 警察分局

    正解：(D)

  14. 14警察使用指導的手段，愈接近下列何種警察功能的履行？

    1. (A) 執行法律
    2. (B) 秩序維護
    3. (C) 服務民眾
    4. (D) 打擊犯罪

    正解：(B)

  15. 15警察機關透過領導、訓練和文化的培養，以防範員警工作偏差的作法，最屬於下列何種課責機制？

    1. (A) 官僚
    2. (B) 法律
    3. (C) 專業
    4. (D) 政治

    正解：(C)

  16. 16下列有關資訊統計的警政管理系統（Compstat）的敘述，何者最為正確？

    1. (A) 它是一個中央集權的警政管理技術
    2. (B) 它是一個革命性的警政管理方法
    3. (C) 它只適用在警察機關的治安管理
    4. (D) 它強調治安資訊之統計，不談治安策略

    正解：(B)

  17. 17依規定全國警察機關、學校列警正四階警員總數，不得逾其下列何種員額總數二分之一？

    1. (A) 編制員額
    2. (B) 預算員額
    3. (C) 現有員額
    4. (D) 合理員額

    正解：(A)

  18. 18警察「菁英族」的考選與任用，是下列何國的制度？

    1. (A) 美國
    2. (B) 英國
    3. (C) 日本
    4. (D) 法國

    正解：(C)

  19. 19警察機關組織的「陀螺現象」，是指下列何種問題？

    1. (A) 警察升遷的瓶頸問題
    2. (B) 警察基層單位的問題
    3. (C) 警察教育訓練的問題
    4. (D) 警察執法倫理的問題

    正解：(B)

  20. 20下列有關美國警察演進歷程的敘述，何者正確？

    1. (A) 政治干涉時期的警察組織設計採分權與地區化
    2. (B) 專業化警察時期的警察功能限縮在犯罪的預防
    3. (C) 社區警政時期的勤務運作主要採集中派遣方式
    4. (D) 社區警政時期的警察績效評核以犯罪數據為主

    正解：(A)

  21. 21下列有關警察歷史的敘述，何者正確？

    1. (A) 1829 年美國的皮爾（Robert Peel）爵士創立現代化的警察
    2. (B) 1905 年中國成立的第一個現代警政機構為湖南保衛局
    3. (C) 1920 年代英國的和麥（August Vollmer）推動警察專業化改革
    4. (D) 二次大戰後，德國和日本警察引進分權化並限縮警察權力

    正解：(D)

  22. 22國家為維持公共安全與秩序，必要時得對人民行使命令強制的權力，稱為：

    1. (A) 警察權
    2. (B) 警察職權
    3. (C) 警察權限
    4. (D) 警察裁量

    正解：(A)

  23. 23不論警政策略經歷如何變遷更迭，下列那一項仍被各國視為不可或缺的警察勤務？

    1. (A) 刑事偵查
    2. (B) 臨檢
    3. (C) 巡邏
    4. (D) 勤區查察

    正解：(C)

  24. 24根據警察法第 3 條第 2 項，以下何者非由縣（市）立法事項？

    1. (A) 關於警察勤務機構設置、裁併及勤務之實施事項
    2. (B) 關於警察常年訓練之實施事項
    3. (C) 關於縣（市）義勇警察、駐衛警察之組設、編練、派遣、管理等事項
    4. (D) 關於縣（市）警察役男之組設、編練、派遣、管理等事項

    正解：(D)

  25. 25在我國中央系統的警政制度下（centralized police system），下列有關縣市警察局長之派任敘述何項正確？

    1. (A) 縣市長有權向警政署點名要求人選
    2. (B) 警政署可以不顧縣市長意見逕行指派局長
    3. (C) 警政署向縣市長協調指派局長
    4. (D) 由縣市長指派一位副局長升任

    正解：(C)
