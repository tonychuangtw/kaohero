  1. 1各項訂定 CPU 指令集架構的策略，下列何者屬於 CISC（Complex Instruction Set Computer）處理器的設計方針？

    1. (A) 透過指令編碼並允許不同指令，可擁有不同的指令長度，以減少程式碼占用的記憶體空間
    2. (B) 維持所有指令皆有相同長度的編碼，以便於設計 pipeline 架構的處理器
    3. (C) 僅有指定的 load/store 指令可讀寫記憶體內容，其他指令皆僅能使用暫存器作為運算元，以便編譯器進行最佳化
    4. (D) 配置較多的一般用途暫存器，並透過編譯器進行暫存器配置，以提升運算效能

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 變動長度的指令編碼是 CISC 的典型設計，用常用指令的短編碼換取較小的程式碼體積。

    ❌ (B) 固定長度編碼以利管線化，是 RISC 的設計方針。

    ❌ (C) load/store 架構是 RISC 的核心特徵。

    ❌ (D) 大量通用暫存器搭配編譯器配置同屬 RISC 的設計取向。

    📚 出處：計算機結構；CISC 與 RISC。

  2. 2有一個 4-bit 加法器，包含二個 4-bit 的輸入訊號 A 與 B，一個 1 bit 的進位輸入訊號（carry-in）Cin，要利用此加法器進行減法運算 5-3，其輸入的訊號為何？

    1. (A) A = (0101)2 B = (1011)2 Cin = 0
    2. (B) A = (0101)2 B = (1100)2 Cin = 0
    3. (C) A = (0101)2 B = (1100)2 Cin = 1
    4. (D) A = (1101)2 B = (0011)2 Cin = 1

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 減法以加上減數的二補數實現：3 的一補數為 1100，Cin＝1 補上加 1，等同加上 −3 的二補數 1101，故 A＝0101、B＝1100、Cin＝1。

    ❌ (A) B＝1011 與 3 的一補數不符且未設進位。

    ❌ (B) 缺少 Cin＝1，結果少 1。

    ❌ (D) A 應為被減數 5（0101），該選項將 A、B 對調。

    📚 出處：數位邏輯；二補數減法。

  3. 3在資料庫中同時執行多筆交易（Transactions），系統保證每一筆交易皆不知其他同步執行之交易，此特性為何？

    1. (A) 不可分割性（Atomicity）
    2. (B) 一致性（Consistency）
    3. (C) 隔離性（Isolation）
    4. (D) 持久性（Durability）

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 隔離性保證並行執行的交易彼此互不干擾，其中間結果不會被其他交易看見。

    ❌ (A) 不可分割性指交易全部完成或全部不做。

    ❌ (B) 一致性指交易前後資料庫皆滿足完整性限制。

    ❌ (D) 持久性指交易一經確認即永久保存。

    📚 出處：資料庫系統；ACID 特性。
