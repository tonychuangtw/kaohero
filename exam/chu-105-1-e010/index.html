  1. 1依憲法增修條文規定，考試院設院長、副院長、考試委員，由總統提名，經下列何者同意任命之？

    1. (A) 國民大會
    2. (B) 行政院
    3. (C) 立法院
    4. (D) 司法院

    正解：(C)

  2. 2我國現行的人事分類制度，就其性質而言，係屬下列何種制度？

    1. (A) 品位分類制度
    2. (B) 職位分類制度
    3. (C) 品位分類與職位分類兩制合一的制度
    4. (D) 品位分類與職位分類兩制分離的制度

    正解：(C)

  3. 3依考試院組織法第 9 條規定，考試院置秘書長一人，其任用方式為何？

    1. (A) 特派
    2. (B) 特任
    3. (C) 比照簡任第十四職等
    4. (D) 列簡任第十四職等

    正解：(B)

  4. 4中華民國國民年滿幾歲，具有公務人員考試法所定應考資格者，才得應公務人員考試法之考試？

    1. (A) 16 歲
    2. (B) 18 歲
    3. (C) 20 歲
    4. (D) 23 歲

    正解：(B)

  5. 5就人力資源管理學理而言，政府人事人員不須負責的人事管理工作是？

    2. (B) 職場上性騷擾防治宣導
    3. (C) 人力遴選
    4. (D) 同仁福利規劃

    正解：(A)

  6. 6下列何者不是政治途徑所認為公共人事行政應特別關注的事項？

    1. (A) 公務員對國家的忠誠性
    2. (B) 相應於社會階層之代表性
    3. (C) 政治與行政的分立
    4. (D) 強化政務領導

  7. 7一般而言，下列何者不是職位分類的依據？

    2. (B) 繁簡難易
    3. (C) 教育條件
    4. (D) 責任輕重

  8. 8下列何者為常務人員？①行政院人事行政總處人事長 ②內政部人事處長 ③法務部廉政署署長 ④中華文化總會會長 ⑤公務人員保障暨培訓委員會專任委員 ⑥臺北市文山區區長 ⑦總統府資政

    2. (B) ②③⑥

  9. 9為了擴大公共機關完成使命的能力，而研訂有目的性的人力資源行政與政策議題解決方案，此稱之為：
