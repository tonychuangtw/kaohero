  1. 1組成乳糖的兩個單糖是下列何種醣化鍵（glycosidic bond）結合？

    1. (A) α 1-4 glycosidic bond
    2. (B) β 1-4 glycosidic bond
    3. (C) γ 1-4 glycosidic bond
    4. (D) δ 1-4 glycosidic bond

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 乳糖由一分子葡萄糖與一分子半乳糖以 β 1-4 醣化鍵結合而成，此鍵可被乳糖酶（lactase）水解。

    ❌ (A) α 1-4 鍵為麥芽糖、直鏈澱粉等的鍵結形式，非乳糖。

    ❌ (C) 自然界無 γ 型醣化鍵，為虛構選項。

    ❌ (D) 無 δ 型醣化鍵，亦為虛構選項。

    📚 出處：生物化學／營養學「醣類」章節，雙醣結構（乳糖 β 1-4）

  2. 2在肌肉及脂肪組織，可被胰島素調控，進行葡萄糖吸收的載體蛋白為何？

    1. (A) 葡萄糖載體蛋白 1（glucose transport protein 1, GLUT1）
    2. (B) 葡萄糖載體蛋白 2（glucose transport protein 2, GLUT2）
    3. (C) 葡萄糖載體蛋白 3（glucose transport protein 3, GLUT3）
    4. (D) 葡萄糖載體蛋白 4（glucose transport protein 4, GLUT4）

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) GLUT4 主要分布於肌肉與脂肪組織，平時存於細胞內囊泡，胰島素訊號使囊泡移至細胞膜，促進葡萄糖攝入，為胰島素調控的關鍵載體。

    ❌ (A) GLUT1 幾乎普遍存在於各細胞，負責基礎葡萄糖攝取，不受胰島素調控。

    ❌ (B) GLUT2 見於肝臟、胰島 β 細胞與腸道基底側，屬低親和力、不依賴胰島素的載體。

    ❌ (C) GLUT3 主要在中樞神經與胎盤，親和力高，不依胰島素調控。

    📚 出處：生物化學「葡萄糖運輸蛋白 GLUT 家族」；胰島素訊息傳遞

  3. 3糖解作用（glycolysis）產生的 NADH（nicotinamide adenine dinucleotide）是藉由何種系統進入粒線體？

    1. (A) 經由 glycerol-3-phosphate shuttle system 或 citrate-aspartate shuttle system
    2. (B) 經由 citrate-aspartate shuttle system 或 malate-aspartate shuttle system
    3. (C) 經由 glycerol-3-phosphate shuttle system 或 malate-aspartate shuttle system
    4. (D) 經由 malate-aspartate shuttle system 或 malate-succinate shuttle system

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 細胞質 NADH 無法直接穿過粒線體內膜，須靠甘油-3-磷酸穿梭系統（glycerol-3-phosphate shuttle）或蘋果酸-天門冬胺酸穿梭系統（malate-aspartate shuttle）將還原當量送入粒線體。

    ❌ (A) citrate-aspartate shuttle system 並非標準名詞，正確者為 malate-aspartate shuttle。

    ❌ (B) 同樣誤列 citrate-aspartate shuttle system。

    ❌ (D) malate-succinate shuttle system 不存在，屬虛構名稱。

    📚 出處：生物化學「糖解作用與氧化磷酸化」章節，NADH 穿梭系統
