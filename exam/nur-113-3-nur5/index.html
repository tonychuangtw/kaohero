護理師　113 年第三次 精神科與社區衛生護理學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關治療性關係之特性，下列敘述何者正確？

    1. (A) 鼓勵護理師進行深度自我開放
    2. (B) 治療性關係之各期不連續且不重疊
    3. (C) 關係的維持具有彈性，無需設定明確目標
    4. (D) 學習建立新行為是工作期常見主題

    正解：(D)

  2. 2在執行精神病人保護約束時，護理人員告知每 15 分鐘會來探視病人，並確實按時探視，此符合下列那項倫理原則？

    1. (A) 知情同意
    2. (B) 行善
    3. (C) 守信
    4. (D) 自主

    正解：(C)

  3. 3王先生罹患慢性思覺失調症，精神症狀穩定，但局部功能退化，具有復健潛能，需積極復健治療，下列安排何者最適合？

    1. (A) 日間住院治療
    2. (B) 慢性住院治療
    3. (C) 護理之家療養
    4. (D) 急性住院治療

    正解：(A)

  4. 4有關鋰鹽 Lithium（Lidin ）的敘述，下列何者最正確？®

    1. (A) 主要是促進躁症病人腦部兒茶酚胺（catecholamine）的分泌及活化
    2. (B) 口服用藥只需服用大約 2 天，療效通常就非常明顯與穩定
    3. (C) 需要嚴格限制食鹽攝取量，以免鋰鹽在腎臟的清除率過高
    4. (D) 服用一天後若出現腸胃症狀，例如噁心、嘔吐，建議可進餐時服用鋰鹽

    正解：(D)

  5. 5王先生，20 歲，診斷妥瑞氏症，護理師問他： 「你今年幾歲？」王先生答：「幾歲？」接著問：「現在做什麼工作？」王先生答：「什麼工作？」這是屬於下列那一種症狀？

    1. (A) 音韻連結（clang association）
    2. (B) 回音性言語（echolalia）
    3. (C) 言語貧乏（poverty of speech）
    4. (D) 言語持續（perseveration）

    正解：(B)

  6. 6有關認知行為治療的特徵，下列敘述何者最適切？

    1. (A) 運用心理分析以解決問題

    3. (C) 運用人際互動關係以解決問題
    4. (D) 運用學習理論以解決問題

    正解：(D)

  7. 7團體治療中，成員 A 抱怨女兒天天工作忙常見不到人，表示自己辛苦撫養小孩很不值得。成員 B 表示自己女兒也很忙，建議父母要學習自己照顧自己，以上的團體互動最符合何項團體療效因素？

    1. (A) 存在因素
    2. (B) 原生家庭經驗再現
    3. (C) 發展社交技巧
    4. (D) 利他性

    正解：(A)

  8. 8高小姐罹患「雙相情緒障礙症」，因情緒高昂，整天在家裡不停翻箱倒櫃忙進忙出，表示自己是神力女超人，不需進食，晚上不睡覺一直打電話給警局要一起去拯救世界，故家人帶她入院治療，下列高小姐護理問題何者適切？①營養攝取不足 ②現存性自我傷害 ③睡眠型態紊亂 ④恐懼

    2. (B) ①③
    3. (C) ②④
    4. (D) ③④

  9. 9有關思覺失調症（schizophrenia）的敘述，下列何者最適切？

    1. (A) 思考、知覺及行為障礙的疾病
    2. (B) 常有記憶力減退，無法照顧自己
    3. (C) 很少會有幻覺干擾
    4. (D) 在疾病前趨期以正性精神症狀為主

    正解：(A)

  10. 10陳小華，20 歲診斷為思覺失調症，在高中二年級即出現幻聽，常覺得別人在議論他，大家都知道他在想什麼，拒絕與人接觸，不願意上學，自我照顧變差。下列何者屬於正性精神症狀？

    1. (A) 拒絕與人接觸
    2. (B) 不願意上學
    3. (C) 持續出現幻聽
    4. (D) 自我照顧變差

    正解：(C)

  11. 11有關妄想症狀的護理措施，下列敘述何者最適切？

    2. (B) 和病人辯論妄想內容的正確性
    3. (C) 藥物治療以鎮靜安眠藥物為主
    4. (D) 要儘早面質及修正妄想的內容

    正解：(A)

  12. 12陳先生，因鬱症發作，情緒低落，有自殺行為而住院，每日皆會哭泣。有關家屬的照護，下列何項最適宜？

    1. (A) 協助家屬瞭解病人目前的狀況
    2. (B) 勸導家屬暫停探望病人
    3. (C) 給家屬保證，治療後就不會再發病
    4. (D) 建議家屬避免與其他親友互動頁次：4－2

    正解：(A)

  13. 13有關疾病與核心症狀配對的描述，下列何者最適切？

    1. (A) 社交焦慮症：病人會迴避開放的空間，因而導致外出受限
    2. (B) 創傷後壓力症：病人會出現「回憶重現（flashback）」的症狀
    3. (C) 特定畏懼症：病人會對許多事物有過多的焦慮與擔憂
    4. (D) 廣泛性焦慮症：病人會出現重複的行為或心智活動

    正解：(B)

  14. 14王女士，遭遇嚴重土石流而家園全毀，倖存後診斷為創傷後壓力症（posttraumatic stress disorder） ，下列敘述何者最不適切？

    1. (A) 應等待病人做好心理準備才進行危機處理，預後較佳
    2. (B) 對人有疏離或與他人疏離，無法感到幸福與被愛
    3. (C) 無法記得創傷事件的一個重要情節
    4. (D) 可能會有恐懼、驚恐、憤怒、罪惡感和羞愧

    正解：(A)

  15. 15畏避型人格障礙症（avoidant personality disorder）臨床特徵的敘述，下列何者最適切？

    1. (A) 害怕被批評或被拒絕，避免涉及人際接觸的工作場合
    2. (B) 害怕失去支持或認可，會努力去討好順從他人
    3. (C) 利用自己身體外觀來吸引他人注意
    4. (D) 需要過度的讚美，並認為自己有特權

    正解：(A)

  16. 16有關身體症狀障礙症（somatic symptom disorder）的敘述，下列何者較不適切？

    1. (A) 與人格特質有關，但與生活壓力無關
    2. (B) 藉此引起周遭他人的注意
    3. (C) 藉此獲得親朋好友的支持與同情
    4. (D) 以身體症狀掩飾情緒困擾

    正解：(A)

  17. 17林同學高中生，近半年常在週末深夜 3～4 點回家，功課一落千丈，精神顯得恍惚、視覺模糊、協調性變差、心跳過速、血壓升高，近來常常夜尿頻繁而求診泌尿科，診斷為物質濫用導致的間質性膀胱炎。林同學最有可能使用下列那種毒品？

    2. (B) Ｋ他命
    3. (C) 大麻

    正解：(B)

  18. 18有關自閉症類群障礙症（autism spectrum disorder）的描述，下列何者正確？

    1. (A) 會因為要獲得情緒喜悅而與同伴交往
    2. (B) 對一成不變的生活常規顯得不耐煩
    3. (C) 可能會出現刻板或重複的動作

    正解：(C)

  19. 19有關社區精神心理衛生的護理過程，下列敘述何者最適切？

    1. (A) 重視社區成員的整體心理健康
    2. (B) 服務進行方式為一對一的個人關係

    4. (D) 病人的家庭有經濟問題時，通常不用評估

    正解：(A)

  20. 20洪小弟，6 歲，一年多來出現不自主的眨眼睛、裝鬼臉或聳肩膀，會發出「哼、哼、哼」的聲音。洪小弟的狀況最可能是下列那個問題？

    3. (C) 智能不足（Intellectual Disability）

    正解：(D)

  21. 21陳女士，診斷為阿茲海默症，經住院治療後準備出院。家屬顯得焦慮，不知道如何照顧陳女士，頻頻詢問其他病友家屬的照護意見。下列護理措施何者最適切？

    4. (D) 告知家屬每個病人情況不同，不需聽取他人的意見

    正解：(C)

    3. (C) 由醫療人員直接提供健康決策以解決健康問題
    4. (D) 增進掌控自己健康及健康決定因子的能力

    正解：(C)
