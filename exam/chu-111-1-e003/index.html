初等考試　111 年 初等考試 法學大意（一般行政組）　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1關於法律與命令的區別，下列敘述何者錯誤？

    1. (A) 法律係由立法機關制定，而命令則由各機關訂定
    2. (B) 通則為法律，細則為命令
    3. (C) 法律與命令，均需經過總統公布後生效
    4. (D) 以命令限制人民之權利義務，應有法律授權

    正解：(C)

  2. 2依地方制度法規定，委辦規則與法律牴觸者無效。此為何種行政法基本原則之展現？

    1. (A) 法律明確性原則
    2. (B) 法律保留原則
    3. (C) 法律優位原則
    4. (D) 法律安定性原則

    正解：(C)

  3. 3下列何者為憲法明文規定的基本權利？

    1. (A) 性行為之自主決定
    2. (B) 非現役軍人不受軍事審判
    3. (C) 姓名權
    4. (D) 婚姻自由

    正解：(B)

  4. 4關於法律優位原則，下列敘述何者錯誤？

    1. (A) 行政命令牴觸憲法時，行政命令無效
    2. (B) 行政命令牴觸法律時，行政命令無效
    3. (C) 法律牴觸憲法時，法律無效
    4. (D) 法律牴觸國際法時，法律無效

    正解：(D)

  5. 5人民因犯罪嫌疑被逮捕拘禁時，其逮捕拘禁機關應將逮捕拘禁原因，以書面告知本人及其本人指定之親友，並至遲於 24 小時內移送該管法院審問。此為下列那一種憲法原則之內涵？

    1. (A) 罪刑法定原則
    2. (B) 正當法律程序原則
    3. (C) 法律保留原則
    4. (D) 法律明確性原則

    正解：(B)

  6. 6當法律規範有漏洞時，可以運用法律補充之方法使其完全。下列何者非屬法律補充之方法？

    1. (A) 類推適用
    2. (B) 文義解釋
    3. (C) 目的限縮
    4. (D) 法律續造

    正解：(B)

  7. 7某法律規定：「本法自公布日施行。」若總統於民國 110 年 6 月 1 日公布該法，則該法應於何日生效？

    1. (A) 6月1日
    2. (B) 6月2日
    3. (C) 6月3日
    4. (D) 6月4日

    正解：(C)

  8. 8關於我國現行中央政府體制，下列敘述何者錯誤？

    1. (A) 總統對行政院院長有人事任免權
    2. (B) 修憲後因立法院喪失對行政院院長的同意權，行政院不再對立法院負責
    3. (C) 總統享有被動的國會解散權
    4. (D) 我國中央政府體制既不是總統制，也不是內閣制

    正解：(B)

  9. 9關於公法與私法之區別，下列敘述何者錯誤？

    1. (A) 救濟之方式不同，公法適用行政爭訟，私法則適用民事訴訟
    2. (B) 強制執行之依據不同，公法適用行政執行法與行政訴訟法，私法適用強制執行法
    3. (C) 損害賠償管道不同，公法適用國家賠償法，私法適用民法
    4. (D) 勞動基準法之規範客體為私法上僱傭關係，故屬純粹的私法

    正解：(D)

  10. 10下列何者非屬我國憲法或憲法增修條文賦予大法官之職權？

    1. (A) 解釋憲法
    2. (B) 統一解釋法律及命令
    3. (C) 審理總統、副總統之罷免
    4. (D) 審理政黨違憲之解散

    正解：(C)

  11. 11關於刑法第 19 條第 3 項之規定，下列敘述何者錯誤？

    1. (A) 學理上稱之為原因自由行為
    2. (B) 本項須行為人在實際實行犯罪時具備完全行為責任能力狀況
    3. (C) 現行立法模式，在學理上有稱為例外模式
    4. (D) 本項須行為人因故意或過失自行招致無責任能力或限制責任能力狀況

    正解：(B)

  12. 12下列何者是憲法最高性的直接展現？

    1. (A) 行政院之施政不得牴觸立法院三讀通過，總統公布之法律
    2. (B) 法院之判決，不得不適用法規或適用不當
    3. (C) 立法院通過之法律，不得牴觸憲法
    4. (D) 行政機關之管轄權，不得違反其組織法規，非依法規不得設定或變更

    正解：(C)

  13. 13依司法院大法官解釋，有關自由民主憲政秩序，下列敘述何者錯誤？

    1. (A) 係指憲法中具有本質之重要性而為規範秩序存立之基礎者
    2. (B) 憲法增修條文如與憲法中具有本質重要性之規範相衝突，依後法優於前法之原則，增修條文之效力優先
    3. (C) 其內涵包括憲法規定之民主共和國原則與國民主權原則
    4. (D) 凡憲法設置之機關，均有遵守自由民主憲政秩序之義務

    正解：(B)

  14. 14依憲法及公民投票法規定，有關我國公民投票制度，下列敘述何者正確？

    1. (A) 是憲法上依法行政原則的實現
    2. (B) 因為是對事、而非對人的投票，所以普通、平等、直接之投票方法不適用
    3. (C) 現行制度不只有全國性，也有地方性之公民投票
    4. (D) 為確實監督國家政策之落實，得針對預算與人事事項提案發起公民投票

    正解：(C)

  15. 15有關比例原則之敘述，下列何者錯誤？

    1. (A) 須採取之方法應有助於目的之達成
    2. (B) 多種同樣達成目的之方法中，須採取對人民權益損害最少者
    3. (C) 須採取之方法所造成之損害不得與欲達成目的之利益顯失均衡
    4. (D) 一行為違反數行政法上義務，應採取最輕之處罰規定

    正解：(D)

  16. 16下列事項，何者不適用我國行政程序法之程序規定？

    1. (A) 外交部與外國之建交行為
    2. (B) 撤銷進出口廠商營業登記之行為
    3. (C) 廢止土地徵收之行為
    4. (D) 再生能源發電設備生產電能躉購費率之審定行為

    正解：(A)

  17. 17下列關於執行上級命令之行為不罰之敘述，何者錯誤？

    1. (A) 明知上級公務員之命令為違法而執行之，不得阻卻違法
    2. (B) 以下達之命令為下級公務員之職務範圍內，始得主張阻卻違法
    3. (C) 下級公務員執行不符法定程式之命令，亦得阻卻違法
    4. (D) 命令之形式雖不以書面為限，但仍以具備法定程式為必要

    正解：(C)

  18. 18人民申請換發汽車行車執照，卻遭公路監理機關以違規罰鍰尚未繳清為由，拒絕換發行車執照。此舉可能違反下列何種行政上之一般法律原則？

    1. (A) 不當聯結禁止原則
    2. (B) 比例原則
    3. (C) 誠實信用原則
    4. (D) 信賴保護原則

    正解：(A)

  19. 19有關損失補償之敘述，下列何者錯誤？

    1. (A) 因公益而特別犧牲財產上之利益，國家應依法律規定辦理補償
    2. (B) 損失補償是針對國家的合法行為而干預人民之財產權所生之填補措施
    3. (C) 現行法下，行政徵收不以公用之目的為限
    4. (D) 基於平等原則，只要國家對財產權有所限制，即應給予補償

    正解：(D)

  20. 20有關公共設施國家賠償責任的敘述，下列何者錯誤？

    1. (A) 須賠償義務機關有故意或過失，始成立國家賠償責任
    2. (B) 公共設施委託民間團體管理，因管理欠缺導致人民人身自由或財產受有損害，國家亦負賠償責任
    3. (C) 於開放山域的自然公物，經管理機關對公物為適當的警告或標示，人民仍從事冒險或具危險性活動而受有損害，國家不負賠償責任
    4. (D) 建築中的公共設施未開放公用，即非屬公共設施

    正解：(A)

  21. 21下列關於民事訴訟上當事人能力之敘述，何者正確？

    1. (A) 當事人能力為訴訟成立要件之一，若當事人欠缺當事人能力，法院應逕行以訴不合法裁定駁回其訴
    2. (B) 非法人團體因不具權利能力，因此不具有當事人能力
    3. (C) 無當事人能力人所為之訴訟行為，其效力得經取得能力之人承認而治癒
    4. (D) 當事人於訴訟中死亡時，法院應即以當事人能力有欠缺而裁定駁回其訴

    正解：(C)

  22. 22下列關於行政罰的敘述，何者錯誤？

    1. (A) 違反行政法上義務之行為，以處罰故意為原則，過失行為之處罰以法律有明文規定為限
    2. (B) 滿十四歲以上，未滿十八歲人之行為，得減輕處罰
    3. (C) 不得因不知法規而免除行政處罰責任
    4. (D) 違反行政法上義務之行為非出於故意或過失者，不予處罰

    正解：(A)

  23. 23下列行政訴訟法所定之訴訟種類，何者非以行政處分為程序標的？

    1. (A) 撤銷訴訟
    2. (B) 申請遭否准之訴訟
    3. (C) 怠為處分訴訟
    4. (D) 一般給付訴訟

  24. 24下列有關訴願要件之敘述，何者錯誤？

  25. 25下列事件何者為人民不服時可提起訴願的標的？

    正解：(C)

    4. (D) 當事人於和解之意思已甚接近，得聲請法院於當事人表明之範圍內，定和解方案，於法院將和解方案送達兩造時，視為和解成立

  28. 28違反行政法上義務，得予行政處罰之法源依據，下列何者錯誤？

  29. 29下列關於民事訴訟法上公開審理、言詞審理及直接審理原則之敘述，何者正確？

    1. (A) 言詞辯論，應由訴訟代理人以言詞聲明當事人與關係人人數，以及相關證據資料為其程序之開始
    2. (B) 當事人應就訴訟關係，為事實上之陳述，其訴訟代理人應就訴訟關係，為法律上之陳述。兩者相異者，以訴訟代理人之陳述為準
    3. (C) 法官非參與為判決基礎之辯論者，不得參與判決
    4. (D) 原告提出之攻擊或防禦方法，涉及被告之營業秘密者，僅得由法院以職權逕行裁定為審理不公開與判決不公開

    正解：(C)

  30. 30下列有關訊問刑事被告應告知事項之敘述，何者正確？

  35. 35依民法第 758 條第 1 項規定，不動產物權行為以登記為要件。關於不動產物權行為，下列敘述，何者錯誤？

  39. 39甲立遺囑遺贈其所有之房屋一棟於乙。惟該房屋因丙之過失致毀損滅失。一年後，甲死亡。下列敘述，何者正確？

    4. (D) 乙得向甲之繼承人請求債務不履行之損害賠償

    正解：(C)

  40. 40下列關於偵查中羈押之敘述，何者正確？

    1. (A) 被告犯罪嫌疑重大，檢察官即可羈押
    2. (B) 被告涉嫌公然侮辱罪，檢察官亦可羈押
    3. (C) 如果被告有反覆實行同一竊盜犯罪之高度可能性，法院可裁定羈押
    4. (D) 即使被告有勾串共犯的可能，法院也不可以裁定羈押

    正解：(C)

  41. 41下列關於刑法第 136 條聚眾妨害公務罪構成要件之敘述，何者正確？

    1. (A) 行為主體限於公務員執行職務之相對人
    2. (B) 行為地限於公共場所或公眾得出入之場所
    3. (C) 聚集人數須達 5 人以上
    4. (D) 首謀及下手實施強暴脅迫，因而致公務員於死或重傷，與傷害致死或傷害致重傷罪，數罪併罰

    正解：(B)

  42. 42下列關於嚴格證明法則之敘述，何者錯誤？

    1. (A) 嚴格證明與自由證明並不相同
    2. (B) 嚴格證明法則涉及證據能力及有無經合法調查證據之程序
    3. (C) 犯罪事實存在之認定需要嚴格之證明
    4. (D) 自由證明與自由心證之意義相同

    正解：(D)

  43. 43被告以外之人於審判外之書面或言詞陳述，其有無證據能力之判斷，應依何種法則判斷之？

    1. (A) 自白法則
    2. (B) 傳聞法則
    3. (C) 自由心證法則
    4. (D) 意見法則

    正解：(B)

  44. 44依刑事訟法第 27 條規定，被告或犯罪嫌疑人得隨時選任辯護人，不包括下列何種情形？

    1. (A) 受司法警察調查時
    2. (B) 法院審理準備程序
    3. (C) 受上級長官調查時
    4. (D) 移送檢察官調查時

    正解：(C)

  45. 45下列關於貪污治罪條例相關法條之敘述，何者錯誤？

    1. (A) 對於公務員違背職務之行為，要求、期約或收受賄賂或其他不正利益者，構成犯罪
    2. (B) 對於公務員職務上之行為，要求、期約或收受賄賂或其他不正利益者，不構成犯罪
    3. (C) 對於主管或監督之事務，明知違背法令等規定，直接或間接圖自己或其他私人不法利益，因而獲得利益者，構成犯罪
    4. (D) 對於非主管或監督之事務，明知違背法令等規定，利用職權機會或身分圖自己或其他私人不法利益，因而獲得利益者，構成犯罪

    正解：(B)

  46. 46甲犯侵占罪，尚未被發覺，妻子乙為庇護甲而出面向警方表示係其犯罪，乙是否符合刑法自首要件？

    1. (A) 不符合，因警方並非偵查機關，向警方自首，於法未合
    2. (B) 符合，因犯罪既尚未被發覺，乙出面向警方坦承犯行，當屬自首
    3. (C) 不符合，因乙非侵占罪行為人，乙自無自首問題
    4. (D) 符合，因可以轉換成乙所犯頂替罪之自首

    正解：(C)

  47. 47關於刑法上之故意犯與過失犯，下列敘述何者正確？

    1. (A) 行為非出於故意者，即係出於過失
    2. (B) 間接故意犯與有認識過失犯之罪質相當
    3. (C) 刑法以處罰故意犯為原則，但過失犯情節嚴重者，仍應與故意犯同視
    4. (D) 過失犯之處罰以法律有明文者為限

    正解：(D)

  48. 48下列有關刑法第 138 條侵害公務上掌管文書物品罪之敘述，何者錯誤？

    1. (A) 甲收到法院寄發之傳票後，將之撕毀，甲成立本罪
    2. (B) 甲撕毀警員乙依法制作之談話筆錄，甲成立本罪
    3. (C) 甲與警員乙發生拉扯，致乙所穿制服毀損，甲不成立本罪
    4. (D) 警員乙將經扣押之物交由該物之所有權人甲暫時保管，甲故意將之毀損，甲成立本罪

    正解：(A)

  49. 49刑法第 17 條因犯罪致發生一定之結果，而有加重其刑之規定者，如行為人不能預見其發生時，不適用之。依實務見解，下列敘述何者錯誤？

    1. (A) 必須行為人主觀上有預見結果發生
    2. (B) 本條在學理上稱為加重結果犯
    3. (C) 必須刑法條文有特別規定才有適用
    4. (D) 基礎犯罪與發生結果間須具備因果關係

    正解：(A)

  50. 50行政程序法第 3 條第 3 項明列特定事項不適用該法之程序規定，下列何種行為即屬該法所定排除之事項？

    1. (A) 內政部移民署依法禁止本國人出境
    2. (B) 高雄市警察局員警依據集會遊行法規定命令群眾立即解散
    3. (C) 國防部將部隊連級主官調任為內部單位參謀
    4. (D) 私立大學依據該校規定對特定學生為記過處分

    正解：(C)
