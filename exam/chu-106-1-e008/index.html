初等考試　106 年 初等考試 社會工作大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列那一項並非人群服務組織的案主？

    1. (A) 人群服務組織
    2. (B) 人群服務網絡中的他組織
    3. (C) 人群服務組織內的人員
    4. (D) 環境中各種組織

    本題經考選部公告不計分。

  2. 2有關殘補式（residual）社會福利型式的敘述，下列何者錯誤？

    1. (A) 問題出現之後才開始提供的福利措施
    2. (B) 不需要經過資產調查
    3. (C) 屬於反應式（reactive approach）助人方式
    4. (D) 提供單親家庭貧窮者配給點券（coupon）

    正解：(B)

  3. 3臺灣社會工作界最早出現的專業人員在何種領域工作？

    1. (A) 身心障礙福利服務
    2. (B) 醫院
    3. (C) 老人福利服務
    4. (D) 家庭福利服務

  4. 4有關美國 1960 年代社會改革的敘述，下列何者錯誤？

    1. (A) 新政（New Deal）是代表性的福利政策
    2. (B) 醫療救助（Medicaid）是針對低收入的健康保障
    3. (C) 公共政策反映出來的關鍵價值是社會責任
    4. (D) 對貧窮作戰（War on Poverty）是這個年代的重要成果

    正解：(A)

  5. 5對於慈善組織會社（C.O.S.）的慈善作法，下列那一項敘述錯誤？

    1. (A) 由勞動階級所主導
    2. (B) 對貧窮問題採個人歸因、家庭歸因
    3. (C) 將貧民分為值得協助與不值得協助
    4. (D) 派友善訪問員訪問貧民

    正解：(A)

  6. 6下列有關臺灣 1970 年代社會工作人員在政府體制內建制過程的敘述何者錯誤？

    1. (A) 臺中縣政府以社工員來從事貧戶服務及輔導的模式受到臺灣省政府的肯定而開始

    3. (C) 在臺灣省政府完成臺灣省推行社會工作員制度計畫後，全臺各縣市陸續完成社會工作人員建制
    4. (D) 各縣市政府在完成社會工作人員建制之初，其所聘任的社工員皆以正式人員晉用之

  7. 7下列有關赫爾館的描述，那一個敘述是符合事實？

    4. (D) 赫爾館的工作主要是在貧困區域進行物資發放

  8. 8一名國中少女告訴你她在半強迫的狀態下與男友發生關係，並且希望你幫她保密，此時你告訴案主因為法律規定的緣故，你必須通報性侵害防治中心，這時候你所採取的舉動合乎下列何者的概念？

    3. (C) 第三步驟：協助案主將生活適應上的一些故事和行為中的偏差傾向連結起來，以發覺不良行為問題之所在

  45. 45有關家庭社會工作的工作方法，下列敘述何者錯誤？

    1. (A) 家庭社會工作可以利用個案工作的方法造成個人改變，進而影響家庭互動體系
    2. (B) 利用倡導的方法改變社會觀念、促使政策改變，不屬於家庭社會工作的一環
    3. (C) 家庭會談可以界定家庭中每個人對問題的看法，屬於家庭社會工作的一環
    4. (D) 家庭社會工作可以利用團體工作的方法，服務具有類似困擾的對象

    正解：(B)

  46. 46下列何者不是家庭應有的功能？

    1. (A) 社會化
    2. (B) 治療
    3. (C) 經濟
    4. (D) 照顧

    正解：(B)

  47. 47下列何者是 Hancock 及 Duhlru（1986）對「健康城市」的定義？

    1. (A) 短期的創造城市之社會環境，同時強化社區資源，使人們能相互競爭，以期落實其生活功能並發揮其潛能
    2. (B) 持續的創造城市之個人環境，同時強化個人資源，使人們能相互競爭，以期落實其生活功能並發揮其潛能
    3. (C) 長期的創造城市之社會環境，同時強化個人資源，使人們能相互競爭，以期落實其生活功能並發揮其潛能
    4. (D) 持續的創造並增進城市之物理及社會環境，同時強化社區資源，使人們相互支持，實行其所有的生活功能並達到最大的潛能

    正解：(D)

  48. 48有關少數族群的種族歧視問題，下列敘述何者錯誤？

    1. (A) 種族歧視同時存在著顯著面和隱蔽面
    2. (B) 種族歧視形成存在著個體式和制度式
    3. (C) 個體式的種族歧視較不明顯
    4. (D) 制度式的種族歧視隱蔽於各種結構中

    正解：(C)

  49. 49依據老人福利法之規定，下列何種老人不屬於直轄市、縣（市）主管機關需進行安置之對象？

    1. (A) 遭受疏忽、虐待
    2. (B) 獨居
    3. (C) 遭受遺棄
    4. (D) 無人扶養以致生活陷於困境

    正解：(B)

  50. 50社會工作實務靈性（spirituality）主要是立基於下列何種觀點？

    1. (A) 全人觀點
    2. (B) 行為修正觀點
    3. (C) 問題解決觀點
    4. (D) 綜融性實務觀點
