營養師　109 年第二次 營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何種膳食纖維（dietary fiber）為可溶性纖維？

    1. (A) 樹膠（gum）
    2. (B) 木質素（lignin）
    3. (C) 纖維素（cellulose）
    4. (D) 半纖維素（hemicellulose）

    正解：(A)

  2. 2下列何者有助於維持血糖的恆定？

    1. (A) 肌肉肝醣水解，釋出葡萄糖於血液循環
    2. (B) 脂肪組織水解，釋出游離脂肪酸供肝臟生糖作用（gluconeogenesis）
    3. (C) 骨骼肌利用葡萄糖丙胺酸循環（glucose-alanine cycle）排除肌肉內的氨，換得葡萄糖
    4. (D) 腦細胞釋出酮體供肝臟生糖作用

    正解：(C)

  3. 3下列何者不是葡萄糖的特性？

    1. (A) 是一種水溶性物質
    2. (B) 與半乳糖經 α 鍵結組成乳糖
    3. (C) 是組成蔗糖的成分
    4. (D) 甜度比麥芽糖高

    正解：(B)

  4. 4人體無法消化食物中的棉籽糖（raffinose）和水蘇四糖（stachyose），是因為我們的消化道缺乏那一種酵素？

    1. (A) α-glucosidase
    2. (B) β-glucosidase
    3. (C) α-galactosidase
    4. (D) β-galactosidase

    正解：(C)

  5. 5下列何種多醣的結構中含有最高比例的 glucose α1-6 glucose 鍵結？

    1. (A) 支鏈澱粉
    2. (B) 幾丁質
    3. (C) 直鏈澱粉
    4. (D) 肝醣頁次：4－2

    正解：(D)

  6. 6下列何種食物不是 high-quality protein 的來源？

    1. (A) 雞蛋
    2. (B) 黃豆
    3. (C) 玉米
    4. (D) 章魚

    正解：(C)

  7. 7下列何種神經傳導物質，不是由酪胺酸（Tyrosine）代謝而產生？

    1. (A) Dopamine
    2. (B) Epinephrine
    3. (C) Norepinephrine
    4. (D) Serotonin

    正解：(D)

  8. 8下列何種胺基酸，無法參與糖質新生（Gluconeogenesis）作用？

    1. (A) 苯丙胺酸（Phe）與酪胺酸（Tyr）
    2. (B) 白胺酸（Leu）與離胺酸（Lys）
    3. (C) 甲硫胺酸（Met）與半胱胺酸（Cys）
    4. (D) 色胺酸（Trp）與酪胺酸（Tyr）

    正解：(B)

  9. 9在不同的生命期中，下列何者每天每公斤體重所需要的蛋白質量最高？

    1. (A) 老年婦女
    2. (B) 肥胖男性
    3. (C) 健康幼童
    4. (D) 新生嬰兒

    正解：(D)

  10. 10下列何者不是體內蛋白質的功能？

    1. (A) 荷爾蒙（hormone）
    2. (B) 體液平衡（fluid balance）
    3. (C) 酸鹼平衡（acid-base balance）
    4. (D) 節省醣類消耗（carbohydrate-sparing）

    正解：(D)

  11. 11有關魚油之敘述，下列何者正確？

    1. (A) 魚油中的 EPA 與 DHA 是人體不能合成的 ω-3 必需脂肪酸
    2. (B) 補充魚油有抗發炎、抗血栓與降低三酸甘油酯的功效
    3. (C) 基於食品安全考量，孕婦不應吃魚，而應補充魚油，以免受甲基汞與重金屬危害
    4. (D) 牛初乳和母乳皆含有 EPA 與 DHA，有助嬰兒的腦部與視網膜發育

    正解：(B)

  12. 12實證醫學證實，下列何者有助於降血膽固醇及 LDL-Cholesterol？

    1. (A) 降低攝取飽和脂肪酸，以多元不飽和脂肪酸取代
    2. (B) 降低攝取飽和脂肪酸，以碳水化合物取代
    3. (C) 降低膽固醇攝取
    4. (D) 使用生酮飲食

    正解：(A)

  13. 13人體內維生素 D 的合成，主要與下列那一種脂質有關？

    1. (A) 必需脂肪酸
    2. (B) 單元不飽和脂肪酸
    3. (C) 膽固醇
    4. (D) 磷脂質

    正解：(C)

  14. 14有關體內自行合成的膽固醇，下列敘述何者最為正確？

    1. (A) 大約占人體所有膽固醇的 1/3
    2. (B) 其含量不會受到飲食中脂肪型態的影響
    3. (C) 植物體中的 sitosterol 可以減少體內膽固醇合成
    4. (D) 在體內循環系統的脂蛋白中，LDL 的含量最多

    正解：(D)

  15. 15下列何種脂蛋白（lipoprotein）所含之三酸甘油酯比例最高？

    1. (A) Chylomicrons
    2. (B) Very low density lipoprotein（VLDL）
    3. (C) Low density lipoprotein（LDL）
    4. (D) High density lipoprotein（HDL）

    正解：(A)

  16. 16下列何種食物最容易增加飽足感？

    1. (A) 低熱量密度
    2. (B) 低纖維
    3. (C) 高脂
    4. (D) 高果糖含量

    正解：(A)

  17. 17一位 40 歲男性，體重為 70 公斤，身高為 180 公分，則其每日基礎代謝率為多少 kcal？

    1. (A) 1344
    2. (B) 1512
    3. (C) 1680
    4. (D) 1848頁次：4－3

    正解：(C)

  18. 18有關食慾控制的敘述，下列何者錯誤？

    1. (A) 當 cholecystokinin（CCK）分泌增加時，會有飢餓感
    2. (B) 當咀嚼食物時，會有飽食感
    3. (C) 當胃部膨脹時，會有飽食感
    4. (D) 當 ghrelin 分泌增加時，會有飢餓感

    正解：(A)

  19. 19有關維生素 B1、B2 或 B3 之敘述，下列何者錯誤？

    1. (A) 能量代謝增加時，可能需要增加這 3 種維生素的攝取
    2. (B) 未經烹調的魚或貝類因含有硫胺酶（thiaminase），會破壞維生素 B1 的結構
    3. (C) 脂肪酸進行 beta-oxidation 的過程中，需要維生素 B2 以核黃素單核苷酸（FMN）的型式擔任輔酶
    4. (D) 維生素 B3 之建議攝取量，是以菸鹼素當量（niacin equivalent）表示

    正解：(C)

  20. 20下列那些維生素直接或間接參與穀胱甘肽（glutathione）的代謝，因而被認為具有間接的抗氧化能力？

    1. (A) 維生素 B1、B2、葉酸
    2. (B) 維生素 B2、B3、B6
    3. (C) 維生素 B2、B6、葉酸
    4. (D) 維生素 B1、B3、B12

    正解：(B)

  21. 21下列何種維生素在高濃度情形下，容易造成鐵活化成促氧化物質？

    1. (A) Folate
    2. (B) Ascorbic acid
    3. (C) Pantothenic acid
    4. (D) Cobalamin

    正解：(B)

  22. 22下列那一族群最可能有維生素 B12 營養不良狀態？

    1. (A) 萎縮性胃炎之老年人（atrophic gastritis of elderly adults）
    2. (B) 蛋奶素哺乳婦以母乳哺育之嬰兒
    3. (C) 運動員增加對維生素 B12 營養需要量
    4. (D) 孕婦增加對維生素 B12 營養需要量

    正解：(A)

  23. 23下列何種器官與骨骼健康的關係最為密切？

    1. (A) 肺臟
    2. (B) 腎臟
    3. (C) 胃臟
    4. (D) 胰臟

    正解：(B)

  24. 24下列何者產品富含 vitamin E？

    1. (A) 小麥胚芽油
    2. (B) 奶油
    3. (C) 豬油
    4. (D) 牛油

    正解：(A)

  25. 25下列何者是參與鈣質恆定的組合？

    1. (A) 昇糖激素＋維生素 A
    2. (B) 副甲狀腺素＋維生素 D
    3. (C) 腎上腺素＋維生素 E
    4. (D) 甲狀腺素＋維生素 K

    正解：(B)

  26. 26下列何種礦物質在體內的含量最少？

    1. (A) 鈣
    2. (B) 鎂
    3. (C) 硫
    4. (D) 鐵

    正解：(D)

  27. 27下列每份食物中，何者的鎂含量最少？

    1. (A) 綠葉蔬菜
    2. (B) 堅果
    3. (C) 豆類
    4. (D) 白米

    正解：(D)

  28. 28下列每 100 公克的食物中，何者的鈣營養密度最高？

    1. (A) 綠色葉菜
    2. (B) 魚蝦
    3. (C) 乳製品
    4. (D) 全穀類

    正解：(C)

  29. 29依據第七版「國人膳食營養素參考攝取量」的建議，懷孕婦女每日需增加下列那些微量營養素的攝取？

    1. (A) 鐵、碘、硒及鋅
    2. (B) 鐵、鉬、硒及鋅
    3. (C) 鐵、硒、鋅及氟
    4. (D) 碘、硒、氟及鋅頁次：4－4

    本題經考選部公告不計分。

  30. 30微量礦物質的定義為何？

    1. (A) 人體必需的有機物質
    2. (B) 每日所需攝取量少於 100 毫克
    3. (C) 占體內礦物質總含量的 10%以下
    4. (D) 占人體體重的 1%以下

    正解：(B)

  31. 31下列那二種微量元素分別協助膠原蛋白（collagen）與粘多醣（mucopolysaccharide）的形成，以維持結締組織（connective tissue）的完整？

    1. (A) 鐵與鋅
    2. (B) 鋅與銅
    3. (C) 銅與錳
    4. (D) 錳與硒

    正解：(C)

  32. 32碘是人體甲狀腺激素（thyroid hormones）的組成成分之一，從 thyroxine（T4）轉換成有生理活性的 triiodothyronine（T3），需要何種微量元素的協助？

    1. (A) 鉻
    2. (B) 硒
    3. (C) 銅
    4. (D) 鐵

    正解：(B)

  33. 33有關酒精對孕婦與胎兒的影響，下列敘述何者最為正確？

    1. (A) 會中斷氧氣在臍帶中的輸送，影響胎兒的中樞神經發育
    2. (B) 使細胞分裂增快，細胞數目增加，促進子代生長
    3. (C) 會影響營養素利用，讓母體營養變差，但不影響胎兒的營養
    4. (D) 造成胎兒紫斑症候群，嚴重者髖關節骨折

    正解：(A)

  34. 34小明是國小 4 年級學生，不喜歡吃蔬菜。下列何者方法最不適合用來增加小明的蔬菜攝取量？

    1. (A) 將蔬菜切碎混入其他食材中
    2. (B) 利用其他香料蓋過蔬菜的特殊味道
    3. (C) 以漢堡作為交換獎勵的條件
    4. (D) 讓小明參與食物採購與烹調製作的過程

    正解：(C)

  35. 35有關老年人肌少症（Sarcopenia）的敘述，下列何者正確？

    1. (A) 肌肉量減少，但肌肉強度不變
    2. (B) 可利用阻力或重量訓練，以增加肌力
    3. (C) 蛋白質及維生素 E 攝取不足，造成肌肉流失
    4. (D) 因肌肉肝醣的流失，造成行動力障礙

    正解：(B)

  36. 36下列何者是最具生物活性之天然維生素 E？

    1. (A) α-tocotrienol
    2. (B) β-tocotrienol
    3. (C) α-tocopherol
    4. (D) β-tocopherol

    正解：(C)

  37. 376 個月大的嬰兒食用副食品時，應注意下列何者？

    1. (A) 可在此時添加蛋類，以增加蛋白質攝取
    2. (B) 柳橙汁不宜做為嬰兒的副食品
    3. (C) 副食品最好與配方奶混合於奶瓶中餵食，以方便幼兒攝取
    4. (D) 可每天添加一種新的單一成分，以利多元營養素之取得

    本題經考選部公告不計分。

  38. 38有關暴食症（binge eating disorder）行為或症狀的敘述，下列何者正確？

    1. (A) 肥胖症
    2. (B) 在兒童或青少年期不會出現經常性的節食行為
    3. (C) 壓力、憂鬱和沮喪通常不會造成暴食的行為
    4. (D) 偏愛在短時間內攝取大量的高油或高醣類的零食

    正解：(D)

  39. 39從事 1 小時以上 70% VO2 max 中高強度的運動前，最適合攝取的食物種類為何？

    1. (A) 碳水化合物
    2. (B) 蛋白質
    3. (C) 脂肪
    4. (D) 纖維

    正解：(A)

  40. 40適合糖尿病人攝取的奶粉主要含下列何者？

    1. (A) 銅
    2. (B) 鐵
    3. (C) 鉻
    4. (D) 鈣

    正解：(C)
