職能治療師　114 年第二次 生理障礙職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列那一種介入方式較強調讓個案自己設立目標、計劃如何達成目標、監控自己的表現與進展，職能治療師則擔任一個coach的角色？

    1. (A) 矯治策略（remedial strategy）
    2. (B) 代償策略（compensatory strategy）
    3. (C) 後設認知策略（metacognitive strategy）
    4. (D) 動作控制策略（motor control strategy）

    正解：(C)

  2. 2職能治療師進行居家治療時，何種作為最不適當？

    1. (A) 給予環境改造建議前，會考慮病患的經濟狀況
    2. (B) 尊重病患的家庭文化
    3. (C) 每天早晚都致電給家屬，追蹤病患進步狀況
    4. (D) 安排到府服務時間時，考慮病患居家作息時間

    正解：(C)

  3. 3為了展現專業技術服務（skilled services），下列何者最符合良好的病歷紀錄中治療計劃的範例？

    1. (A) 病患的前臂固定在滑車上重複外展動作15分鐘
    2. (B) 病患用患手將圓柱積木由某一端移至另一端
    3. (C) 由於病患的肩關節活動度差，職能治療師指導病患使用長柄夾具拿取高櫃上的藥罐，並依病人進步狀況調整放置藥罐高度
    4. (D) 利用垂直塔的活動來訓練病患的肩關節活動度

    正解：(C)

  4. 4「9孔插棒測驗中，病患用右手在20秒內完成，左手則需23秒」應屬於SOAP病歷紀錄的何種部分？

    1. (A) 主訴（subjective）
    2. (B) 客觀觀察（objective）
    3. (C) 評估（assessment）
    4. (D) 計畫（plan）

    正解：(B)

  5. 5一名正中神經損傷個案，正在練習扣鈕釦的活動。職能治療師請個案先練習大鈕釦的穿脫，再依序練習中鈕釦、小鈕釦。治療師乃依據何種功能進行此活動分級？

    1. (A) 精細動作協調能力
    2. (B) 肌力
    3. (C) 心肺功能
    4. (D) 肌耐力

    正解：(A)

  6. 6個案用單手刷牆面油漆時，動作為水平橫向塗刷，職能治療師改變其刷子由小刷子，更改為大刷子，活動中其他條件均一致。前述最有可能是在活動需求的那一面向難度增高？

    1. (A) 工作記憶
    2. (B) 雙手協調性
    3. (C) 肩膀水平內收與外展的力量
    4. (D) 上肢動作速度

    正解：(C)

  7. 7職能治療師建議個案使用智慧型手機及應用程式，以提醒每天應進行的血糖檢測、運動方案及職能活動，個案在居家執行一段時間後，治療師持續再評估個案在自然情境中的執行情形，治療師最主要運用下列何項教與學的模式？

    1. (A) 促進式提示（facilitative prompts）
    2. (B) 增強（reinforcement）
    3. (C) 引導（guidance）
    4. (D) 自我監測輔助（self-monitoring aids）

    正解：(D)

  8. 8職能治療師作為學習促進者的主要方式為何？

    1. (A) 在治療過程中提供教與學
    2. (B) 建立跨專業團隊以提供全人照護
    3. (C) 整合並導入最新治療方式以提升個案的獨立性
    4. (D) 優化行政管理及轉銜流程

    正解：(A)

  9. 9有關職能治療的介入與環境中的安全性考量，下列何者為最佳措施？

    1. (A) 鎖骨下靜脈裝有肺動脈導管（Swan-Ganz catheter）的個案，宜多做肩關節活動，避免該處血液循環不佳
    2. (B) 裝有呼吸調節器及導管（endotracheal tube）的個案，宜採用非口語方式溝通
    3. (C) 治療室地板應採用拋光地板，才容易維持清潔
    4. (D) 橈動脈裝有動脈壓力監測導管（arterial monitoring line）個案，宜經常伸直和屈曲手腕，避免腕關節僵直

    正解：(B)

  10. 10依據美國「Healthy People 2030」，下列那些是影響人們健康狀態的重要指標（indicators）？①心理健康（mental health） ②社會因子（social determinants） ③健康服務的取得（access to health services） ④營養、身體活動及肥胖（nutrition, physical activity,and obesity）

    1. (A) 僅①④
    2. (B) 僅①②③
    3. (C) 僅②③④
    4. (D) ①②③④

    正解：(D)

  11. 11有關機器輔助治療（robot-assisted therapy）運用於動作訓練的優點，下列何者最適宜？

    1. (A) 能提供主動或被動的動作模式，且重複性高的訓練方式
    2. (B) 能提供多元的情境轉換，提升個案的學習動機
    3. (C) 僅運用在上肢動作訓練，但可降低所需的職能治療師人力，進而減少治療成本
    4. (D) 以功能性活動訓練為主，可藉由觀察個案活動的執行，有效轉移學習成效至日常生活

    正解：(A)

  12. 12本體神經肌肉誘發術（PNF）中，所謂的交互抑制（reciprocal inhibition）是指下列何者？

    1. (A) 主動肌（agonist muscle）收縮以產生抑制拮抗肌（antagonist muscle）的作用
    2. (B) 主動肌（agonist muscle）與拮抗肌（antagonist muscle）同時收縮
    3. (C) 將肌肉拉長並維持數秒鐘之後再放鬆，可促進肌肉收縮
    4. (D) 主動肌（agonist muscle）先進行等長收縮，之後再由拮抗肌（antagonist muscle）進行等長收縮

    正解：(A)

  13. 13有關老化相關理論中之活動理論（activity theory）的主要建構，下列敘述何者最適切？

    1. (A) 主張老人常持續參與自覺重要的活動
    2. (B) 主張成功老化來自於老人可成功地完成任務（task）
    3. (C) 主張老人活動參與的程度與安適感（well-being）有密切正相關
    4. (D) 主張老人活動是個人－環境－職能（person-environment-occupation）三者互動下所產生之結果

    正解：(C)

  14. 14腦中風右側偏癱3年的個案，右上肢近端及遠端動作為布氏第二階段，感覺完全喪失而常意外刮傷。3個星期前跌倒導致左側手腕骨折，術後轉介至職能治療，左側手部及手腕出現過度敏感，關於感覺功能介入的敘述，下列介入何者較不適切？

    1. (A) 針對右側上肢進行感覺功能再教育，提升對環境的感知、減少意外
    2. (B) 教導隨時注意保護右側上肢、避免傷害
    3. (C) 建議個案針對左上肢進行輕拍以降低敏感
    4. (D) 針對敏感的左上肢進行按摩，並提供由輕柔到深壓的刺激

    正解：(A)

  15. 15職能治療師進行個案體表感覺功能（exteroceptive sensation）評估時的敘述，下列何者正確？

    1. (A) 手指尖輕觸刺激時，應儘量每次間隔時間一致
    2. (B) 觀察到個案無法感受到手機震動而漏接電話，最可能是本體覺（動作察覺）缺損
    3. (C) 每次輕觸時，就會詢問個案是否有刺激，並應告知其正確與否
    4. (D) 記錄多次觸碰時，正確回應的比例，且「完好（intact）」需達100％正確率

    正解：(D)

  16. 16職能治療師使用二點辨識覺測試盤（Disk-Criminator）進行手傷個案手指靜態兩點分辨覺篩檢評估，下列敘述何者正確？

    1. (A) 先從較小的距離（如2 mm）開始測試，依據個案反應縮小或放大距離
    2. (B) 兩個刺激點的連線必須垂直於神經走向進行施測
    3. (C) 正確區辨的最小距離，在指尖若為5或6 mm代表正常等級區辨能力
    4. (D) 觸壓時間約1秒，不可停留過久

    正解：(C)

  17. 17下列何者屬於Warren的視知覺處理階層模式（hierarchy of visual perception）之樣式辨認（pattern recognition）行為表現？

    1. (A) 可以辨認出以不同方式擺置的杯子
    2. (B) 治療活動進行中，轉而去看旁邊發生的事，停止自己的活動
    3. (C) 眼球追視到視野的某一部分
    4. (D) 可以清楚辨識3公尺遠的指標

    正解：(A)

  18. 18有關視力（visual acuity）評估之敘述，下列何者錯誤？

    1. (A) 使用視力檢查表檢測，Snellen分數20∕50表示標準視力者在50英呎即可看清的字母，但個案在20英呎才能看清
    2. (B) 可使用佩里羅布森（Pelli-Robson）對比敏感度表來檢測個案的視覺對比敏感度
    3. (C) 屈光異常（refractive error）導致遠視，影像投射於視網膜後，無法聚焦，需配戴凸透鏡矯正
    4. (D) 評估時要請個案將頭部保持固定，眼球持續注視某一移動物體

    正解：(D)

  19. 19有關意念運動性失用症（ideomotor apraxia）的敘述，下列何者錯誤？

    1. (A) 日常活動動作呈現笨拙遲鈍
    2. (B) 可利用侷限－誘發動作治療（constraint-induced movement therapy）介入
    3. (C) 建議可使用Árnadóttir OT-ADL Neurobehavioral Evaluation來評估
    4. (D) 個案無法在要求下模仿刷牙的動作，但卻會自己在盥洗時正確使用牙刷

    正解：(B)

  20. 20個案瞭解兩種顏色的手套是不同的，卻無法說出個別顏色的名稱。個案最有可能出現下列何種知覺問題？

  21. 21習慣學習（habit learning）屬於那一種學習能力？

    3. (C) 前瞻學習（prospective learning）

  22. 22有關認知相關理論引導職能治療實務操作之敘述，下列何者正確？

    2. (B) 四象限介入模式（quadraphonic approach）之特色同時包括微觀認知能力的矯治如注意力，及宏觀職能的表現如日常活動

    4. (D) 任務導向模式（task-oriented approach）強調在多重情境中練習

  27. 27有關一個代謝當量（metabolic equivalent, MET）的定義，下列何者正確？

  28. 28關於透過神經發展性治療（neurodevelopmental therapy, NDT）降低痙攣的敘述，下列何者正確？

    1. (A) 需要X光攝影來確認骨折位置及類型
    2. (B) 骨折需要固定約3～5週，期間上肢不應該有任何動作，以免影響癒合
    3. (C) 出現水腫時，可利用抬高、彈性繃帶纏繞、未受傷肢段之主動關節運動等方式降低水腫
    4. (D) 復位後要維持正確的排列（alignment）

    正解：(B)

  77. 77如圖所示，要求患者用拇指與食指緊夾住一張紙，當職能治療師嘗試抽走紙張時，患者拇指指間關節會出現明顯彎曲才能夠避免該紙張被抽走，這代表下列那一條神經最有可能受損？

    1. (A) 橈神經
    2. (B) 尺神經
    3. (C) 正中神經
    4. (D) 肌皮神經

    正解：(B)

  78. 78關於骨折後「early mobilization」之敘述，下列何者正確？

    1. (A) 骨折初期水腫嚴重時，建議可利用抗重力性的動作（against-gravity movement）來消除水腫
    2. (B) 骨折初期至骨癒合期，建議可加強徒手關節鬆動（joint mobilization）活動來避免患肢僵硬的發生
    3. (C) 骨折初期至骨癒合期，建議可給予漸進式阻力性訓練（progressive resistanceexercise program）以減少肌力的流失
    4. (D) 職能治療師以被動移動個案患肢，同時個案主動維持姿勢的等長收縮模式以促進循環及骨癒合

    正解：(D)

  79. 79身體動力型（body-powered）肘上截肢（transhumeral）義肢雙重操控方式（dual control），下列何者正確？

    1. (A) 末端裝置的打開：好手手動調整開合
    2. (B) 肘關節鎖住與開啟：肩胛下壓（depression）與肩關節內收（adduction）同時伸展（extension）
    3. (C) 上臂內外旋：肩胛外展（scapular abduction）與肩關節屈曲（shoulder flexion）控制肘旋轉盤達成
    4. (D) 肘關節屈曲：於肘關節解開的情況下，肩胛外展（scapular abduction）與肩關節屈曲（shoulderflexion）

    正解：(D)

  80. 80職能治療師教導臉部燒傷的個案要練習開口咧嘴、噘唇抿嘴活動的主要治療目的為何？

    2. (B) 維持下巴顳顎關節活動度，預防併發異位性骨化
    3. (C) 避免嘴角疤痕攣縮，預防併發小口畸形
    4. (D) 改善咀嚼能力，預防併發吞嚥困難

    正解：(C)
