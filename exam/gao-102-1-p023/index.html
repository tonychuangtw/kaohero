  1. 1下列何者（約略）等於 240 bytes？

    1. (A) 1 megabytes 或 106 bytes
    2. (B) 1 gigabytes 或 109 bytes
    3. (C) 1 terabytes 或 1012 bytes
    4. (D) 1 petabytes 或 1015 bytes

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 2 的 40 次方約為 10 的 12 次方，即 1 terabyte。

    ❌ (A) 1 megabyte 約為 2 的 20 次方。

    ❌ (B) 1 gigabyte 約為 2 的 30 次方。

    ❌ (D) 1 petabyte 約為 2 的 50 次方。

    📚 出處：計算機概論－儲存容量單位。

  2. 2全加器之進位輸出其布林函數（Boolean function）為：

    1. (A) C = xy ’z + x ’yz + xy
    2. (B) C = xy ’z + x ’yz + x ’y
    3. (C) C = xy ’z + x ’y ’z + xy
    4. (D) C = x ’y ’z + x ’yz + x ’y

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 全加器進位輸出為多數函數，可寫成 xy 加上 x 與 y 相異時由進位輸入決定的兩項，即 xy'z ＋ x'yz ＋ xy。

    ❌ (B) 末項 x'y 會在 x 為 0 時錯誤產生進位。

    ❌ (C) x'y'z 一項在兩輸入皆為 0 時仍產生進位，錯誤。

    ❌ (D) 缺少 xy 項且含錯誤的 x'y 項。

    📚 出處：數位邏輯－全加器。

  3. 3下列關於記憶體階層（memory hierarchy）的描述，何者正確？

    1. (A) 由於現今記憶體較為便宜，所以每一層記憶體的容量應該儘量接近
    2. (B) 為了避免 CPU 存取不到資料，所以每一層記憶體的容量應該一樣大
    3. (C) 當 CPU 要存取的資料不在快取記憶體時，系統會發生分頁錯誤（page fault）的中斷
    4. (D) 如果一筆資料沒有被儲存在主記憶體（main memory）的話，就一定不會出現在快取記憶體內

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 快取的內容取自主記憶體，主記憶體沒有的資料不會出現在快取中。

    ❌ (A) 越接近處理器的層級越貴越小，容量不會接近。

    ❌ (B) 各層容量本就設計成逐層放大。

    ❌ (C) 快取失誤稱為 cache miss，分頁錯誤發生於主記憶體層級。

    📚 出處：計算機組織－記憶體階層。
