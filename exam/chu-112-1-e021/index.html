本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1A 國出口香蕉到 B 國，並從 B 國進口蘋果。如果

    1. (A) B 兩國因政治原因中斷貿易，相對貿易中斷前，貿易中斷後，下列敘述何者正確？A. A 國的生產可能曲線外移
    2. (B) A 國生產的香蕉會減少

    4. (D) 經歷與該國發生技術進步下的相同經濟成長

    正解：(D)

  42. 42若政府擴大預算赤字時，該國將會面臨：

    1. (A) 淨資本流出減少和本國通貨升值
    2. (B) 淨資本流出增加和本國通貨升值
    3. (C) 淨資本流出減少和本國通貨貶值
    4. (D) 淨資本流出增加和本國通貨貶值

    正解：(A)

  43. 43當一國因政局動盪而發生資本逃避時，該國通貨會面臨：

    1. (A) 實質利率上升與實質匯率貶值
    2. (B) 實質利率下跌與實質匯率貶值
    3. (C) 實質利率上升與實質匯率升值
    4. (D) 實質利率下跌與實質匯率升值

    正解：(A)

  44. 44古典學派主張短期總合供給曲線是垂直線，而凱因斯學派主張短期總合供給曲線具有正斜率。造成這兩學派有前述主張差異的原因是下列那一項？

    1. (A) 古典學派認為工資調整速度很快，而凱因斯學派認為勞動市場存在著到期時間不一的工資契約
    2. (B) 古典學派認為物價調整速度很快，而凱因斯學派認為債券與貨幣是完全替代
    3. (C) 古典學派認為商品市場是完全競爭，而凱因斯學派認為經濟的主要干擾來自需求面
    4. (D) 古典學派認為經濟的主要干擾來自供給面，而凱因斯學派認為民眾具有貨幣幻覺（money illusion）

    正解：(A)

  45. 45當經濟體系存在膨脹缺口時，下列那一項變動有助於達到充分就業的產出水準？

    1. (A) 減稅
    2. (B) 政府支出增加
    3. (C) 自發性投資增加
    4. (D) 自發性消費下降

    正解：(D)

  46. 46貨幣供給量不變及流動速度不變，物價水準上升時，會使下列那個選項下降？

    1. (A) 每筆交易的平均貨幣成本
    2. (B) 實質總產出
    3. (C) 利率
    4. (D) 家庭和廠商花費的支出

    正解：(B)

  47. 47有關貨幣功能，下列敘述何者錯誤？

    1. (A) 小真為買皮鞋而在百貨公司各櫃位比較價格，這時貨幣扮演的是計價的單位
    2. (B) 樟宜將手頭多餘現金拿去買債券以準備未來花費，這時貨幣扮演的是計價的單位
    3. (C) 老李拿到年終獎金興奮地去買一部電動機車，這時貨幣扮演的是交易的媒介
    4. (D) 眼看美元可能升值，大方將新臺幣存款轉成美元存款，這時貨幣扮演的是價值的儲藏

    正解：(B)

  48. 48在無政府部門及無進出口之簡單凱因斯模型中，若自發性消費大於零，則下列選項何者正確？①平均消費傾向一定小於邊際消費傾向。②邊際消費傾向一定大於邊際儲蓄傾向。

    1. (A) 只有①正確
    2. (B) 只有②正確
    3. (C) ①、②皆正確
    4. (D) ①、②皆不正確

    正解：(D)

  49. 49下列因素何者最有可能使實質貨幣需求曲線向左移動？

    1. (A) 實質 GDP 增加

    4. (D) 政府國庫券利率下跌

  50. 50中央銀行為對抗經濟衰退可採取的最有效寬鬆性貨幣政策工具為何？
