初等考試　103 年 初等考試 公務員法大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1依公務人員任用法規定，公務人員於任用後喪失中華民國國籍時，應如何處理？

    1. (A) 撤職
    2. (B) 停職
    3. (C) 免職
    4. (D) 資遣

    正解：(C)

  2. 2依公務人員任用法規定，下列何者之任用，另以法律定之？

    1. (A) 教育人員
    2. (B) 司法人員
    3. (C) 審計人員
    4. (D) 警察人員

    本題經考選部公告不計分。

  3. 3下列對於政務官特徵之敘述，何者錯誤？

    1. (A) 政務官不須銓敘，亦無任用資格限制
    2. (B) 政務官隨政黨更迭而進退，除有法定任期者外，無身分保障
    3. (C) 政務官無升遷、考績及退休問題，但可依「政務人員退職撫卹條例」給與離職儲金
    4. (D) 對政務官僅能為撤職之懲戒

    正解：(D)

  4. 4各機關首長自退休案核定之日起至離職日止，不得任用或遷調人員，但下列何者不受此項規定之限制？

    2. (B) 委任官之遷調
    3. (C) 考試及格人員分發任用
    4. (D) 薦任官之遷調

    正解：(C)

  5. 5下列何者為公務人員考績法之主管機關？

    1. (A) 銓敘部
    2. (B) 行政院
    3. (C) 立法院
    4. (D) 總統府

  6. 6依公務人員任用法規定，機關長官得在本機關任用：

    3. (C) 甥侄
    4. (D) 兄弟

  7. 7下列何者無法取得升任薦任第六職等任用資格？

    2. (B) 晉升薦任官等訓練合格
    3. (C) 委任升薦任考試及格
    4. (D) 二年年終考績列甲等

  8. 8公務人員兼具我國及他國雙重國籍，依公務人員任用法規定：

    1. (A) 應撤銷任用，其任職期間之職務行為，不失其效力；業已依規定支付之俸給及其他給付，不予追還
    2. (B) 應撤銷任用，其任職期間之職務行為，不失其效力；業已依規定支付之俸給及其他給付，應予追還
    3. (C) 應撤銷任用，其任職期間之職務行為，失其效力；業已依規定支付之俸給及其他給付，不予追還
    4. (D) 應撤銷任用，其任職期間之職務行為，失其效力；業已依規定支付之俸給及其他給付，應予追還

    正解：(B)

  9. 9公務員違法經營商業或投機事業者，依公務員服務法之規定，應先予如何處置？

    1. (A) 免職
    2. (B) 停職

    4. (D) 休職

  10. 10有關公務員兼職規定，下列何者正確？

    4. (D) 依法令或經指派兼職者，於離去本職時，仍得繼續兼職

    2. (B) 一百五十萬股
    3. (C) 一百一十萬股
    4. (D) 一百萬股

  12. 12軍官甲主辦國軍武器採購，退役後隨即轉往擔任原任職務相關之軍品廠商公司顧問，每月領取新臺幣五萬元顧問費。甲是否違反公務員服務法？如有違反，應如何處罰？

    1. (A) 違反公務員服務法，處二年以下有期徒刑，得併科新臺幣一百萬元以下罰金
    2. (B) 違反公務員服務法，處二年以下有期徒刑，得併處新臺幣一百萬元以下罰鍰
    3. (C) 雖擔任顧問領受顧問費，如未向原任職單位關說施壓圖利廠商，未違反公務員服務法
    4. (D) 軍職人員非屬公務員服務法適用範圍，未違反公務員服務法

    正解：(A)

  13. 13公務人員下列何種行為不受公務人員行政中立法之限制？

    4. (D) 以私人薪資對特定政黨為捐款之行為

  14. 14下列對於公務人員行政中立之敘述，何者錯誤？

    4. (D) 公務人員不得兼任公職候選人競選辦事處之職務

    3. (C) 考績委員會委員每滿四人應有二人由本機關受考人票選產生之

    3. (C) 行為後之態度

  23. 23依公務員懲戒法規定，有關公務員停止職務之敘述，下列何者錯誤？

    1. (A) 依刑事訴訟程序被通緝或羈押者，其職務當然停止
    2. (B) 停止職務之公務員，在停職中所為之職務上行為，不生效力
    3. (C) 停止職務之公務員，未受撤職或休職處分或徒刑之執行者，主管長官得斟酌是否准其復職
    4. (D) 主管長官對於所屬公務員，依規定送請監察院審查而認為情節重大者，亦得依職權先行停止其職務

    正解：(C)

  24. 24下列有關懲戒處分之敘述，何者錯誤？

    1. (A) 同一事件經主管長官已為處分後，復移送公務員懲戒委員會審議者，其原處分不失其效力
    2. (B) 同一行為，在刑事偵查或審判中者，不停止懲戒程序
    3. (C) 懲戒處分應以犯罪是否成立為斷，公務員懲戒委員會認有必要時，得議決於刑事裁判確定前，停止審議程序
    4. (D) 同一行為已為不起訴處分或免訴或無罪之宣告者，仍得為懲戒處分

    正解：(A)

  25. 25下列對於公務人員考績之敘述，何者正確？

    1. (A) 公務人員考績分為年終考績、另予考績、專案考績
    2. (B) 專案考績係指各官等人員，於同一考績年度內，任職不滿一年，而連續任職已達六個月者辦理之考績
    3. (C) 年終考績以一百分為滿分，九十分以上為甲等
    4. (D) 年終考績指各官等人員，於每年年終考核其前一年一至十二月任職期間之成績

    正解：(A)

  31. 31下列對於各種懲戒處分之敘述，何者正確？

    1. (A) 撤職，除撤其現職外，並於一定期間內停止任用，其期間至少六個月
    2. (B) 申誡，以口頭或書面為之
    3. (C) 減俸，自減俸之日起，一年內不得晉敘、升職或調任主管職務
    4. (D) 休職，休其現職，停發薪給，並不得在其他機關任職，其期間為三個月以上

    正解：(C)

  34. 34下列對於公務員懲戒程序之敘述，何者錯誤？

    2. (B) 九職等或相當於九職等以下公務員之記過或警告，由主管長官逕行決定
    3. (C) 九職等或相當於九職等以下公務員之撤職、休職、降級、減俸，由主管長官逕送公務員懲戒委員會審議
    4. (D) 十職等以上之公務員，須主管長官先連同證據送請監察院審查成立後，再移送公務員懲戒委員會

    4. (D) 因原議決適用法規顯有錯誤，聲請再審議之期間，為自原議決書送達之日起三十日內為之

  43. 43受理軍事單位上校編階之主官財產申報之機關（構）為下列何者？

    1. (A) 監察院
    2. (B) 行政院
    3. (C) 所屬機關之政風單位
    4. (D) 考試院

    正解：(C)

  44. 44公職人員利益衝突迴避法施行細則由何機關訂定？

    1. (A) 考試院會同司法院、監察院定之
    2. (B) 行政院會同考試院、監察院定之
    3. (C) 司法院會同行政院、考試院定之
    4. (D) 監察院會同考試院、司法院定之

    正解：(B)

  45. 45營造廠負責人承包縣政府三億元工程，該負責人兄長為縣長，法務部認定違反公職人員利益衝突迴避法，應處：

    1. (A) 新臺幣一億元至二億元罰鍰
    2. (B) 新臺幣一億元至二億元罰金
    3. (C) 新臺幣三億元至九億元罰鍰
    4. (D) 新臺幣三億元至九億元罰金

    正解：(C)

  46. 46國民小學校長因聘用孫女擔任學校工友遭人檢舉，法務部審查認定該校長所為違反公職人員利益衝突迴避法，依同法規定應處：

    1. (A) 新臺幣一百萬元以上五百萬元以下罰金
    2. (B) 新臺幣一百萬元以上五百萬元以下罰鍰
    3. (C) 新臺幣一百萬元以上五百萬元以下怠金
    4. (D) 新臺幣一百萬元以上五百萬元以下公益金

    正解：(B)

  47. 47依公職人員財產申報法規定，職務列簡任第十二職等或相當簡任第十二職等以上各級政府機關首長申報財產，其受理財產申報之機關（構）為：

    1. (A) 司法院
    2. (B) 監察院
    3. (C) 所屬機關（構）之政風單位
    4. (D) 法務部

    正解：(B)

  48. 48公職人員應申報之珠寶、古董、字畫及其他具有相當價值之財產，其每項（件）價額多少，即應申報？

    1. (A) 每項（件）價額達新臺幣五萬元者
    2. (B) 每項（件）價額達新臺幣十萬元者
    3. (C) 每項（件）價額達新臺幣十五萬元者
    4. (D) 每項（件）價額達新臺幣二十萬元者

    正解：(D)

  49. 49公職人員財產申報法所定應申報財產之人員，故意隱匿財產為不實之申報者，得處以最高罰鍰：

    3. (C) 新臺幣四百萬元
    4. (D) 新臺幣五百萬元

  50. 50依公職人員利益衝突迴避法之規定，公職人員知有利益衝突者應如何處理？
