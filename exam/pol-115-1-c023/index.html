警察特考　115 年 四等考試 犯罪學概要　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1在犯罪統計的研究中，「犯罪黑數」（dark figure of crime）指的是已經發生但未被發現，或雖經發現但未向警察機關報案的犯罪數量，然犯罪黑數與報案意願有高度關聯，當「報案意願」提高時，對於官方統計數據會產生何種影響？

    1. (A) 犯罪黑數將不斷擴大
    2. (B) 政府統計的犯罪率會逐漸下降，主要是因為警察能更有效地破案
    3. (C) 較能呈現真實的犯罪量體，但官方統計數據會呈現上升趨勢
    4. (D) 即使報案意願增加，對於官方統計數據沒有任何影響

    正解：(C)

  2. 2下列各項犯罪指標界定之敘述，何者錯誤？

    1. (A) 犯罪率係指在特定時間及特定地區內每十萬人口中，計算受理刑案之發生件數
    2. (B) 犯罪人口率係以每十萬人口中計算犯罪人數
    3. (C) 監禁率係指每十萬人口中計算監禁的人數
    4. (D) 破獲率係指當年度破獲案件人數，與同年刑事案件人數之比例

    正解：(D)

  3. 3有關犯罪行為與偏差行為二者之敘述，下列何者錯誤？

    1. (A) 偏差行為是偏離社會規範（social norms）之行為
    2. (B) 偏差行為的範疇要比犯罪行為的範疇廣泛得多
    3. (C) 並非所有偏差行為均是犯罪
    4. (D) 所有的犯罪行為均是偏差行為

    正解：(D)

  4. 4根據內政部警政署警政統計，對暴力犯罪所指之案件類型的定義，下列何者非其所指之暴力犯罪？

    1. (A) 故意殺人
    2. (B) 擄人勒贖
    3. (C) 妨害自由
    4. (D) 強制性交

    正解：(C)

  5. 5有關犯罪學理論中之犯罪古典學派，下列對其學派與理論之發展敘述何者正確？

    1. (A) 犯罪古典學派之主要代表人物是義大利學者費利（Enrico Ferri, 1856-1928）及加洛法洛（Roffaella Garofalo, 1852-1943）
    2. (B) 犯罪古典學派主張每一種犯罪均應採不定期刑
    3. (C) 犯罪古典學派其認為人類一直在追求享樂主義（hedonism）、追求功利主義（utilitarianism），追求最大的快樂和最少的痛苦
    4. (D) 犯罪古典學派最大的優點是強調犯罪人的個別差異

    正解：(C)

  6. 6John Braithwaite 提出的「明恥整合理論」，修復式司法的核心理論基礎。該理論認為：傳統刑事司法程序常對加害者進行「烙印式羞辱」，容易將加害者排除在守法社會之外，運用「明恥整合」來推動修復式司法實務，其主要運作方式為何？

    1. (A) 譴責加害者的犯罪行為並促其負起責任，在程序結束後，再將其納入守法社群
    2. (B) 強制行為人入獄服刑，直到其表現出完全的悔意，才能達到明恥目的
    3. (C) 只強調被害人的損失賠償，並不要求加害者參與討論，避免勾起不好的回憶
    4. (D) 公開揭露加害者的犯罪細節，以達成一般威嚇，以敬效尤

    正解：(A)

  7. 7有關犯罪生物學理論之敘述，下列何者錯誤？

    1. (A) 學者龍布羅梭（Cesare Lombroso,1835-1909），引用進化論來解釋犯罪人之所以較同代退化，乃因隔代遺傳（atavistic）或祖型重現的一種結果
    2. (B) 研究體型與犯罪論者，一個最基本原則乃認為體型和個性、性情有密切關聯，進而影響犯罪
    3. (C) 研究基因和遺傳缺陷論者，主張犯罪乃由於基因和遺傳缺陷的一種結果，基本上認為有其父，必有其子。父母親的外表、舉止和性情均有遺傳給兒女的傾向
    4. (D) 鉛、鎘、銅等毒物質致環境污染，並導致人嚴重疾病、死亡，或者探討食物添加物和犯罪關係之研究，非屬犯罪生物學之研究領域

    正解：(D)

  8. 8莫頓（Merton）的「古典緊張理論」，主要探討社會結構中「文化目標」與「合法手段」之間的關係。當個體認同成功的目標，卻發現自己缺乏受教育或就業等合法手段，轉而採取參與「詐欺」集團，來獲取財富時，這屬於莫頓所定義的哪一種適應方式？

    1. (A) 創新（innovation）
    2. (B) 順從（conformity）
    3. (C) 退縮（retreatism）
    4. (D) 反抗（rebellion）

    正解：(A)

  9. 9有關柯恩（Albert K. Cohen）之幫派副文化理論，下列之敘述何者錯誤？

    1. (A) 柯恩是一位典型的緊張理論犯罪學家
    2. (B) 其理論的基本論點認為，低階層青少年的犯罪行為，事實上是對中產階級文化和價值觀的一種反抗
    3. (C) 其理論認為低階層小孩由於不能達到中產階級衡量尺度（middle-class measuring rods）, 內心產生衝突和挫折，而以街角小孩的角色（the corner boy role）、進取小孩的角色(the college boyrole )和偏差小孩(the delinquent boy role)的三種方式來解決
    4. (D) 柯恩認為青少年的犯罪副文化，只有 4 種特徵，包括具功利性（utilitarian） 、邪惡性（malicious）、負面性（negativistic）和獨特性（uniqueness）

    正解：(D)

  10. 10有關學者 Merton 的緊張理論，與 Agnew 的一般化緊張理論的理論內容概念之敘述，下列何者錯誤？

    1. (A) Merton 的緊張理論強調犯罪是社會結構下產物，而 Agnew 則強調個體經歷緊張和壓力下容易犯罪
    2. (B) Merton 認為犯罪是文化目標與文化手段分配不均的結果，而 Agnew 則認為緊張壓力來自於個人產生的負面狀態所產生
    3. (C) Merton 統整出五種不同的社會適應類型，而 Agnew 則說明四種不同的壓力來源
    4. (D) 兩者皆認為是因為低階層的青少年因為所處的環境、身分地位低下所導致的結果

    正解：(D)

  11. 11根據山普森（Sampson）與勞伯（Laub）的年齡逐級理論，理論核心提及所謂「轉折點」（TurningPoints）之概念，是指某些個體在成年後，因為某些特殊的生命事件，讓原本具有偏差行為傾向的個體脫離犯罪，下列何者不屬於該理論所強調的關鍵轉折點？

    1. (A) 個體進入青春期後，生理特徵的快速發育，使個體結束偏差行為念頭
    2. (B) 進入一段良好的的婚姻關係，為了家庭而不再涉入犯罪
    3. (C) 入伍從事軍隊服役，受到軍隊紀律化洗禮，了解守規的重要性
    4. (D) 入社會後擁有穩定的工作，對於犯罪行為則不再熱衷

    正解：(A)

  12. 12艾克斯（Akers）的「社會學習理論」與蘇哲蘭（Sutherland）「差別接觸理論」的理論核心，有相當程度的關聯性。請問下列對兩人理論敘述何者正確？

    1. (A) 兩人皆主張犯罪行為是遺傳導致，並非後天學習而來
    2. (B) 蘇哲蘭強調犯罪學習的「內容與過程」，而艾克斯則加入「操作制約」的強化與懲罰機制，以進一步優化理論
    3. (C) 艾克斯認為與犯罪人的接觸是唯一的犯罪原因，後續的技巧與犯罪酬賞並無強化作用
    4. (D) 蘇哲蘭的理論可以解釋所有犯罪的成因，但艾克斯的理論僅能解釋學習犯罪的過程

    正解：(B)

  13. 13根據高佛森（Gottfredson）與赫胥（Hirschi）於 1990 年提出的「犯罪一般性理論」，其核心概念，關於「犯罪性」（criminality）與「犯罪行為」（crime）的區分，下列敘述何者正確？

    1. (A) 犯罪性是指個人在特定時間點受環境誘惑而產生的偏差動作
    2. (B) 犯罪性是指個人具有「低自我控制」傾向，而犯罪行為則是此傾向遇到合適機會時的展現
    3. (C) 犯罪行為是與生俱有的，與後天的機會無關
    4. (D) 犯罪性是出生就決定的，不會隨著年齡增長而大幅改變

    正解：(B)

  14. 14某少年因在學校遭受同儕霸凌，嘲笑家裡貧窮，進而產生了對社會不公平感受與憤怒的負面情緒。為了擺脫自卑心態與改善自身經濟情況，加入詐欺集團擔任車手。根據 Agnew 的一般緊張理論，該少年所經歷的緊張來源是下列哪一項？

    1. (A) 正向刺激的移除
    2. (B) 期望與實際成就間的差距
    3. (C) 負面刺激的出現
    4. (D) 目標與成就間的差距

    正解：(C)

  15. 15學者 David Finklhor 及 Nancy Asdigian（1996），提出三項重複被害之被害人個人特徵，下列何者非其所指之個人特徵？

    1. (A) 標的弱點因素（target vulnerability）
    2. (B) 標的滿足因素（target gratifiability）
    3. (C) 標的憎惡因素（target antagonism）
    4. (D) 標的引誘因素（target attraction）

    正解：(D)

  16. 16標籤化理論主張，當少年因為偏差行為進入到刑事司法系統後，容易遭到負面標籤，轉而投入更多的犯罪活動。當前我國司法系統處理少年案件時，所採取之「轉向處遇」，將案件移送機構輔導而非刑罰，其目的為何？

    1. (A) 透過司法的嚴厲懲罰來達成威嚇，讓少年不再涉入犯罪
    2. (B) 透過轉向處遇的矯正手段，來強化少年的自我控制力
    3. (C) 轉向處遇讓少年培養更多的技能，累積更多求職技巧
    4. (D) 避免負面標籤，讓少年套上前科的烙印，而陷入自我認同犯罪人的角色

    正解：(D)

  17. 17Brantingham 與 Faust 所出的目標導向之三級犯罪預防模式，是近年主流模式，該模式係以三個層次的具體犯罪預防工作，來達到犯罪預防的目標，請問下列敘述何者正確？

    1. (A) 初級犯罪預防是指在犯罪發生之前期，馬上介入來阻止更大的危害發生
    2. (B) 次級預防就是將犯罪者送入刑事司法系統，予以干預、矯治與輔導，避免再犯
    3. (C) 三級預防就是透過各種犯罪預防的手段與環境設計，使得全民共同參與抑制犯罪，降低犯罪的發生可能
    4. (D) 該模式是依犯罪發生的時間點與介入對象不同，將預防分為初級、次級、三級預防。強調在不同階段採取不同策略，以降低犯罪發生率與再犯率

    正解：(D)

  18. 18性侵害犯罪人出獄後回歸社區，我國性侵害犯罪防治法規定了一系列監督與輔導措施。下列何者不屬於我國目前的社區處遇政策？

    1. (A) 須經鑑定評估後，有再犯之風險，得施以強制治療
    2. (B) 定期向警察機關辦理登記與報到
    3. (C) 對保護管束之人，經報請許可，得施以科技設備監控
    4. (D) 永久性、且完全公開於網路，供民眾任意檢索之性侵犯個資

    正解：(D)

  19. 19學者 Ronald Clarke 與 John Eck 於 2003 年，歸納出 25 項情境犯罪預防策略模式，該 25 項策略涵蓋了 5 大原則，下列何者不是增加犯罪風險的具體作為？

    1. (A) 增加警政巡邏與設置 CCTV，強化正式監控力道來達到犯罪預防效果
    2. (B) 透過燈光、圍籬或者專人監督，讓預謀犯罪者認為感到不可恣意妄為，降低其犯罪意圖
    3. (C) 管制通道作為，增加身分辨識與障礙物的架設，都能夠減少犯罪人的侵害
    4. (D) 透過對於物品的實名制，讓匿名性程度降低，亦能使得犯罪市場被擾亂

    正解：(C)

  20. 20關於「無被害者犯罪」的除罪化主張，其核心立論在於「刑法謙抑原則」與「法益保護思想」。下列何者最符合支持此類行為「除罪化」的理論理由？

    1. (A) 除罪化使犯罪黑數浮出檯面，便於政府進行犯罪預防政策預定
    2. (B) 簡化刑事司法訴訟流程，使司法人員能有更多時間強化專業
    3. (C) 增加法律的威嚴性，使大眾對法律產生敬畏之心
    4. (D) 個體對其身體與意識擁有自主權，倘若未直接侵害他人法益，不應用道德制高點，以刑罰強加干預

    正解：(D)

  21. 21犯罪分析中的「犯罪熱點」（hot spots）是指犯罪發生頻率，顯著高於其他地區的特定地理區域。根據犯罪學理論，下列哪一項最能解釋犯罪熱點的成因？

    1. (A) 因為社會解組導致居民互相猜疑而形成犯罪熱點
    2. (B) 該地區居民的教育程度普遍較低，沒有犯罪預防常識導致
    3. (C) 生活在該地區居民的心理疾患比例，比其他地區較高，因此形成犯罪熱點
    4. (D) 因為該地區內具備吸引犯罪者的特徵，如：較少的監控或警察巡邏

    正解：(D)

  22. 22跨境電信詐欺犯罪主要是利用境外機房撥打電話，並透過多層轉帳的洗錢手法逃避查緝。目前政府採取「限制金融帳戶轉帳額度」與「要求金融機構針對異常跨境匯款進行警示與攔阻」，這些手段即是應用了情境犯罪預防中的哪一項策略？

    1. (A) 減少犯罪誘因
    2. (B) 增加犯罪阻力
    3. (C) 增加犯罪風險
    4. (D) 移除犯罪藉口

    正解：(B)

  23. 23倡議嚇阻主義者認為，要能確保嚇阻效果，避免犯罪之發生，刑罰必須具備三個要素，下列何者非其所指之三要素？

    1. (A) 刑罰之迅速性
    2. (B) 刑罰之有效性
    3. (C) 刑罰之確定性
    4. (D) 刑罰之嚴厲性

    正解：(B)

  24. 24有關我國對兒童受虐、家庭暴力、性騷擾等案件所設立之保護專線，下列何者正確？

    1. (A) 165 保護專線
    2. (B) 168 保護專線
    3. (C) 113 保護專線
    4. (D) 116 保護專線

    正解：(C)

  25. 2520 世紀末興起的修復式司法概念，是近年來我國刑事司法系統推行的重點。許多學者均大力推倡，並強調由「報應」轉向「修復」。關於修復式司法的核心概念，下列敘述何者錯誤？

    1. (A) 譴責犯罪者的行為，但接納犯罪者未來能復歸社會
    2. (B) 以烙印式羞辱來立威，透過法律讓犯罪者與社會永久隔離
    3. (C) 被害人、加害人及社區成員的共同參與，透過彼此對話來填補損害
    4. (D) 實務上會以 VOM、FGC 以及審判循環圈

    正解：(B)
