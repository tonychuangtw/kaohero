護理師　115 年第三次 精神科與社區衛生護理學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1在精神科聯繫照會過程中，直接處理病人或家屬的問題是屬於下列那個階段？

    1. (A) 介紹前期
    2. (B) 介紹期
    3. (C) 工作期
    4. (D) 結束期

    正解：(C)

  2. 2有關妄想症（delusional disorder）的臨床表徵，下列何者正確？

    1. (A) 通常是在青春期發病
    2. (B) 常用抵消的防衛機轉
    3. (C) 經常合併聽幻覺及視幻覺
    4. (D) 通常能維持日常生活功能

    正解：(D)

  3. 3下列何者是認知行為治療的方法之一？

    1. (A) 環境治療
    2. (B) 人格重塑
    3. (C) 心理演劇
    4. (D) 社交技巧訓練

    正解：(D)

  4. 4有關服用選擇性血清素再吸收抑制劑（selective serotonin reuptake inhibitor, SSRI）的敘述，下列何者正確？

    1. (A) 比三環抗鬱劑更具鎮靜作用，因此建議睡前服用
    2. (B) 治療初期若出現腸胃不適、噁心或腹瀉，宜由小劑量逐漸增加
    3. (C) 若服用含有酪胺（tyramine）的食物，常會引起高血壓危象（hypertension crisis）
    4. (D) 半衰期短的 SSRI 宜立即停用，但半衰期長的 SSRI 需緩慢逐漸減量

    正解：(B)

  5. 5有關 DSM-5 精神疾病診斷準則（Diagnostic and Statistical Manual of Mental Disorders, DSM-5），下列敘述何者正確？

    1. (A) 取消多軸向評估（multiaxial assessment），加入層面的（dimensional）概念
    2. (B) 只有分子遺傳學，取消社會－文化－性別研究領域的實證資料
    3. (C) 使用整體功能評估量表（global assessment of functioning scale）評估病人
    4. (D) 維持和第四版一致的診斷類別及診斷準則

    正解：(A)

  6. 6團體治療隨著進展可以區分為初期、工作期與結束期，下列何項最符合工作期的狀態？

    1. (A) 成員共同制定團體的規範
    2. (B) 成員出現過度討好的行為
    3. (C) 成員察覺到他人的需要並給予回饋表達關心
    4. (D) 成員避開討論不愉快或衝突的問題

    正解：(C)

  7. 7精神分析學派認為憂鬱症病人，最易運用下列何項防衛機轉？

    1. (A) 內射（introjection）
    2. (B) 隔離（isolation）
    3. (C) 合理化（rationalization）
    4. (D) 昇華（sublimation）

    正解：(A)

  8. 8林同學，診斷為雙相情緒障礙症（bipolar disorder），之前從未有過躁症發作，近兩個月開始會在輕躁發作與鬱症發作之間轉換，讓林同學非常的困擾。依據 DSM-5 診斷準則，林同學屬於雙相情緒障礙症的何項診斷分類？

    1. (A) 第一型雙相情緒障礙症（bipolar Ⅰ disorder）
    2. (B) 第二型雙相情緒障礙症（bipolar Ⅱ disorder）
    3. (C) 循環型情緒障礙症（cyclothymic disorder）
    4. (D) 躁鬱症（manic-depressive psychosis）

    正解：(B)

  9. 9陳太太，28 歲，診斷為思覺失調症，住院二個月後情緒穩定，但仍有妄想症狀，認為先生有外遇，沒有病識感，覺得自己不需要吃藥。她表示出院後要自己獨居。有關出院準備計畫的護理措施，下列何項最適當？

    2. (B) 給予病人現實感，無法自己獨居
    3. (C) 澄清妄想症狀，先生沒有外遇
    4. (D) 安排病人轉到慢性病房繼續住院

    正解：(A)

  10. 10下列有關思覺失調症正性症狀之敘述，何者正確？

    2. (B) ②③④

    4. (D) 僅②④

  12. 12有關思覺失調症病因的敘述，下列何者最適切？

  14. 14我國政府實施「減害計畫」，其中的一項重點計畫為「美沙冬替代療法」，下列敘述何者正確？①將口服藥物「美沙冬」做為毒品「海洛因」的替代物 ②病人必須每天到門診，在醫護人員監督下服用美沙冬 ③美沙冬療程通常持續數年 ④病人不可免於戒斷之痛苦，且其職業與社會功能會退化

  15. 15有關解離性失憶症（dissociative amnesia）的敘述，下列何者正確？

    4. (D) 主因為外傷性腦傷或神經系統疾病所引起

  16. 16張先生為長期飲酒、反覆入院戒酒之患者，此次入院後第三天開始出現噁心、厭食，並大量嘔吐之症狀，下列何者為最優先的護理措施？

    3. (C) 監測電解質與體液平衡
    4. (D) 給與抗痙攣藥物

    正解：(C)

  17. 1773 歲已退休的何先生，與太太、長子同住，近半年來漸漸容易遺忘剛剛做過的事，會重複問家人現在的日期和時間，到附近餐廳吃飯卻不知如何付帳。近幾個月何先生懷疑妻子外遇，不理會家人的解釋，上週趁兒子上班時，跟蹤妻子外出買菜，並毆打逼問妻子，兒子發現母親傷痕累累後，將何先生送醫治療。下列何項溝通方式最為適當？

  18. 18承上題，照顧何先生的過程中，下列何項護理措施最適當？

  39. 39有關醫療院所對於手術切除器官之處理方法，下列何者最適當？

    1. (A) 可燃的感染廢棄物用黃色容器收集，採用掩埋法處理
    2. (B) 可燃的感染廢棄物用黃色容器收集，採用焚化處理
    3. (C) 可燃的感染廢棄物用紅色容器收集，採用掩埋法處理
    4. (D) 可燃的感染廢棄物用紅色容器收集，採用焚化處理

    正解：(D)

  40. 40陳先生與陳太太，育有 1 子及 1 對雙胞胎女兒，目前與太太、子女及其父母同住。依據博薩得（Bossard）家庭關係複雜性定律，陳先生的家庭關係複雜數為何？

    2. (B) 15
    3. (C) 21
    4. (D) 28

  41. 41有關口服避孕藥的敘述，下列何者最適當？

    2. (B) 服用事前避孕藥者，若忘記服藥，可於 12 小時內補吃
    3. (C) 一般婦女於月經來潮第 7 天開始服用
    4. (D) 建議計畫懷孕者，應停藥 1 個月後再懷孕

    正解：(B)

  42. 42有關新住民及其子女之健康照護服務的策略，下列何者錯誤？

    1. (A) 對有發展遲緩之新住民子女，提供早期療育服務並追蹤管理
    2. (B) 新住民孕婦經超音波篩檢，胎兒有異常者，可補助產前遺傳診斷檢查
    3. (C) 初入臺灣 6 個月內的懷孕新住民，未能享有產檢補助服務
    4. (D) 將新住民其子女全面納入嬰幼兒健康保障系統

  43. 43有關新生兒及嬰兒的檢查和篩檢服務之敘述，下列何者最不適當？

    1. (A) 新生兒出生後滿 48 小時或哺乳滿 24 小時後採血檢查先天性代謝疾病
    2. (B) 提供新生兒父母「嬰兒大便卡」以利辨識膽道閉鎖
    3. (C) 出生後 24～60 小時即可做聽力初篩，未通過應進行複篩
    4. (D) 從 1 歲開始，提供兒童預防保健服務至 7 歲前，共 7 次

    正解：(D)

  44. 44國中新生張同學診斷有先天性心臟病之法洛氏四重症（Tetralogy of Fallot），定期至醫院門診追蹤，護理師在其入學後即收案進行個案管理，下列照護措施，何者最不適當？

    1. (A) 可透過電訪及家訪與家長聯繫，了解家長對學生疾病與健康的態度及家庭生活
    2. (B) 與醫療機構聯繫以確認運動分級，並協助與體育老師溝通說明
    3. (C) 確認學生疾病認知，並告知做好疾病自我管理
    4. (D) 因青少年先天性心臟病猝死很常見，建議限制戶外運動

    正解：(D)
