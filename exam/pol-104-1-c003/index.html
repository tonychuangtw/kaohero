警察特考　104 年 四等考試 行政法概要　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列有關法律保留原則之敘述，何者錯誤？

    1. (A) 干預人民自由權利之行為，應保留給具民主正當性之國會以法律規定
    2. (B) 國會得以法律授權主管機關發布命令，針對剝奪人民生命或限制人民身體自由之事項為補充之規定
    3. (C) 國會得以法律授權主管機關發布命令，對限制人民財產權之事項為補充規定
    4. (D) 何種事項應以法律直接規範或得委由命令予以規定，與所謂規範密度有關，應視規範對象、內容或法益本身及其所受限制之輕重而容許合理之差異

    正解：(B)

  2. 2下列有關地方自治與法律保留之敘述，何者錯誤？

    1. (A) 除法律另有規定外，直轄市法規、縣（市）規章就違反地方自治事項之行政業務者，得規定處以罰鍰或其他種類之行政罰
    2. (B) 直轄市法規、縣（市）規章就違反地方自治事項之行政業務者，得規定處以罰鍰，最高以新臺幣 20 萬元為限，並得規定連續處罰之
    3. (C) 直轄市法規、縣（市）規章就違反地方自治事項之行政業務者，得規定勒令停工或其他一定期限內限制或禁止為一定行為之不利處分等行政罰
    4. (D) 自治條例經各該地方立法機關議決後，如規定有罰則時，應分別報經行政院、中央各該主管機關核定後發布

    正解：(B)

  3. 3依司法院釋字第 525 號解釋，下列關於信賴保護原則之敘述何者錯誤？

    1. (A) 信賴保護原則攸關憲法上人民權利之保障
    2. (B) 信賴保護原則適用於授益行政處分之撤銷或廢止，以及行政法規之廢止或變更
    3. (C) 因公益之必要廢止法規或修改內容將導致人民信賴利益受損時，不得廢止或修改該法規
    4. (D) 法規係因主張權益受損害者以不正當方法或提供不正確資料而發布者，其信賴不值得保護

    正解：(C)

  4. 4關於行政機關行使裁量權，下列敘述何者錯誤？

    1. (A) 行政機關行使裁量權而作成之行政處分，若法規無明文規定，不得添加附款
    2. (B) 行政機關為協助下級機關或屬官行使裁量權，得訂定裁量基準
    3. (C) 裁量行政仍應受法律之拘束
    4. (D) 行政規則可能因行政機關行使裁量權，而間接對外發生法律效力

    正解：(A)

  5. 5下列有關信賴保護原則之敘述，何者錯誤？

    1. (A) 經廢止或變更之法規有重大明顯違反上位規範情形者，無信賴保護原則之適用
    2. (B) 因違法授益行政處分之撤銷而主張權益受損害者，若曾於處分作成時提供重要之錯誤資料，無信賴保護原則之適用
    3. (C) 主張信賴保護者僅為期待而未有表現已生信賴之事實表現者，無信賴保護原則之適用
    4. (D) 出於國家財政能力之負擔以及整體社會公益之考量，行政得隨時廢止或變更法規，不受信賴保護原則之拘束

    正解：(D)

  6. 6下列案件，公務員於依公務人員保障法提起救濟後，何者不得提起行政訴訟？

    3. (C) 請求調任同一機關之其他單位
    4. (D) 有侵占公款之嫌已提起公訴而被停職

    正解：(C)

  21. 21關於行政處分廢棄之敘述，下列何者錯誤？

  27. 27下列關於行政處分廢止之敘述，何者錯誤？

    2. (B) 合法授益行政處分若附負擔，而處分相對人未履行該負擔，原處分機關得依職權廢止該行政處分

    3. (C) 應以受託機關或其直接上級機關為訴願管轄機關
    4. (D) 應以原委託機關或其直接上級機關為訴願管轄機關

    正解：(C)

  43. 43訴願人不服原處分機關命其工廠停工之行政處分，提起訴願。受理機關認為訴願有理由，應如何處理？

    1. (A) 撤銷原處分
    2. (B) 命原處分機關撤銷原處分
    3. (C) 訴願不受理
    4. (D) 駁回訴願

    正解：(A)

  44. 44人民申請健保給付，主管機關駁回時，應依行政訴訟法提起何類型之訴訟？

    1. (A) 撤銷訴訟
    2. (B) 課予義務訴訟
    3. (C) 確認之訴
    4. (D) 一般給付之訴

    正解：(B)

  45. 45下列何者應由行政法院審理？

    1. (A) 機車騎士因路面坑洞受傷請求國家賠償
    2. (B) 公務員懲戒案件
    3. (C) 民眾因妨害社會安寧秩序被裁處罰鍰，不服而提起救濟
    4. (D) 建商因申請建築物使用執照，遲遲未獲核發而提起救濟

    正解：(D)

  46. 46針對下列何者，享有訴權而得提起行政訴訟？

    1. (A) 請求行政機關拆除全市之違章建築
    2. (B) 一般消費者請求公平交易委員會取締誇大不實的廣告
    3. (C) 公務人員申請退休金，未獲發給
    4. (D) 請求設置社區公園

    正解：(C)

  47. 47國家賠償法第 2 條第 2 項規定，公務員於執行職務行使公權力時，因故意或過失不法侵害人民自由或權利者，國家應負損害賠償責任。下列敘述何者錯誤？

    1. (A) 應以該公務員所屬機關為賠償義務機關
    2. (B) 應先以書面向賠償義務機關請求之
    3. (C) 公務員有故意或重大過失時，賠償義務機關對之有求償權
    4. (D) 賠償請求權，自請求權人知有損害時起，至遲因 5 年間不行使而消滅

    正解：(D)

  48. 48有關向行政法院提起撤銷訴訟之要件，下列敘述何者正確？

    1. (A) 針對行政機關違法或不當行政處分之事件
    2. (B) 須先經撤銷訴願之程序
    3. (C) 提起撤銷訴願已逾 2 個月期間，不為決定
    4. (D) 延長訴願決定期間已逾 1 個月期間，不為決定

    正解：(B)

  49. 49因公益而特別犧牲之補償請求權，係基於下列何種原則？

    1. (A) 比例原則
    2. (B) 平等原則
    3. (C) 信賴保護原則
    4. (D) 行政自我拘束原則

    正解：(B)

  50. 50依據國家賠償法第 5 條之規定，何者為國家損害賠償之補充法？

    1. (A) 行政程序法
    2. (B) 訴願法
    3. (C) 民法
    4. (D) 民事訴訟法

    正解：(C)
