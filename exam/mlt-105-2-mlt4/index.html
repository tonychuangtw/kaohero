    2. (B) 沙克疫苗是去活性小兒麻痹疫苗
    3. (C) 沙克疫苗之施打可以造成群體免疫
    4. (D) 沙賓疫苗可誘發IgA抗體產生

  61. 61肝炎病毒中，目前已有疫苗可施打預防疾病為何？

    1. (A) HAV 及 HBV
    2. (B) HAV 及 HCV
    3. (C) HBV 及 HCV
    4. (D) HCV 及 HDV

    正解：(A)

  62. 62關於以聚合酶連鎖反應（PCR）進行呼吸道病毒的快速分子檢測，下列敘述何者錯誤？

    1. (A) 若檢測對象為病毒之RNA則需要加上反轉錄（reverse transcription, RT）前步驟
    2. (B) 可以設計多對專一序列之引子建立檢測多重病毒之平台（multiplex PCR）
    3. (C) 可以應用real-time PCR技術縮短檢測時間
    4. (D) 可以用來區分A型或B型流感病毒，但無法進一步用此方法區分A型流感病毒之亞型（subtypes）

    正解：(D)

  63. 63世界衛生組織（WHO）每年皆會根據世界各地的疫情監測建議流感病毒疫苗之病毒株，以下那一種病毒，尚未被WHO建議用來製造季節性流感病毒之疫苗？

  68. 68有關B型肝炎病毒感染，下列敘述何者錯誤？

    4. (D) 長期慢性感染可能導致肝癌或肝硬化

  73. 7365歲的老王出車禍造成其左側肋骨斷裂 12天後老王的身體左側劇痛，並在該處出現泡狀皮疹（vesicular rash），症狀持續數週。泡狀皮疹最有可能是由以下何病因引起？

    2. (B) 狂犬病毒入侵人體後，首先感染周邊神經細胞或肌細胞，然後沿神經細胞入侵中樞神經系統
