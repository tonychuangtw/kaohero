物理治療師　111 年第二次 神經疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何項動作控制理論強調控制系統有階層之分，其最高階層是抽象規則（abstract rules），可用低階不同肢體部分來執行，得到同樣的動作模式？

    1. (A) 階層理論（hierarchical theory）
    2. (B) 動作程式理論（motor programming theory）
    3. (C) 系統理論（systems theory）
    4. (D) 動態系統理論（dynamical systems theory）

    正解：(B)

  2. 2讓前庭損傷患者在治療室練習平地原地踏步，以降低動作時的眩暈感，依照Gentile的任務分類方法，其依環境分類為何？

    1. (A) 靜態變化
    2. (B) 動態變化
    3. (C) 靜態一致
    4. (D) 動態一致

    正解：(C)

  3. 3下列敘述，何者較能確認有動作學習的發生？

    1. (A) 動作練習過程中，錯誤率降低
    2. (B) 動作練習10分鐘、休息2分鐘、再次練習時，錯誤率降低
    3. (C) 動作練習10分鐘、休息2分鐘、再次練習時，動作練習時間縮短
    4. (D) 上肢動作練習20分鐘、接著步態訓練30分鐘，接著進行上肢動作，此時錯誤率降低

    正解：(D)

  4. 4有關亞當的閉鏈式動作學習理論（Adam's closed-loop theory），下列敘述何者錯誤？

    1. (A) 強調利用動作過程中的回饋訊息，來增強動作的感知痕跡（perceptual trace）
    2. (B) 主張若在學習的過程中犯錯則不利於學習，若給予指引則有利於學習
    3. (C) 適用於解釋慢速、線性的動作，無法解釋快速的動作是如何學習
    4. (D) 可用此理論解釋為何去感覺神經的動物仍可產生熟練的動作

    正解：(D)

  5. 5有關神經塑性的說明，下列何者最為適當？

    1. (A) 在中樞神經系統中，目前只在大腦中有證據指出具神經塑性
    2. (B) 大腦塑性的可能機轉主要以神經細胞新生（neurogenesis）為主
    3. (C) 依據促進大腦塑性的概念，治療師不應給予太多不必要的練習，以免妨礙皮質重組
    4. (D) 神經塑性可能是「限制誘發動作治療」產生效果的原因

    正解：(D)

  6. 6有較佳的患側上肢動作功能恢復的成人中風病患，在偏癱側上肢動作時，最常伴隨下列那一種腦部活化模式？

    1. (A) 受損的腦半球（ipsilesional hemisphere）會高度活化，另一側腦半球幾乎不活化
    2. (B) 受損對側腦半球（contralesional hemisphere）會高度活化，另一側腦半球幾乎不活化
    3. (C) 兩側大腦半球會同時高度活化
    4. (D) 兩側大腦半球會同時低度活化

    正解：(A)

  7. 7使用修正式艾許沃斯量表（modified Ashworth scale）評估一名上運動神經元損傷患者，被動移動關節時，阻力發生在關節活動度前1/2。下列關於此評估在國際健康功能與身心障礙分類系統（ICF）的面向與分數何者正確？

    2. (B) 活動限制（activity limitation）、1+
    3. (C) 身體功能（body function）、1+
    4. (D) 活動限制（activity limitation）、1

    正解：(C)

  8. 8使用巴氏量表評估中風患者的移位能力，下列關於此評估在國際健康功能與身心障礙分類系統（ICF）的面向與分數何者正確？

    4. (D) 活動限制（activity limitation）、得分越低失能程度越低

    正解：(B)

  13. 13訓練偏癱病患由患側翻向健側的能力，下列何者較符合神經發展治療（NDT）的技巧原則？

  14. 14訓練一名無法主動翻身的中風患者，首先利用被動動作到主動－協助動作，再給予適合的阻力，最後請患者主動翻身至健側，此方式最可能是下列那個本體感覺神經肌肉誘發技巧？

  16. 16患者剛開始進行中風急性後期（PAC）訓練，雖已可行走，但患側於站立期膝關節會過度伸直（backknee）。經評估發現，下肢僅肌力較差，張力、本體感覺、活動度等均大致正常。下列何訓練最適合此患者？

    3. (C) 溫差測驗（caloric test）時，測試患側時的眼球震顫程度較健側更加嚴重
    4. (D) 閉眼站在軟墊上時，無法維持超過3秒

    正解：(B)

  72. 72在前庭復健中讓患者坐在治療球上，利用球的彈性上下震動，並要求患者維持坐姿平衡，其主要目的是訓練病患何種能力？

    1. (A) 前庭－眼球反射（vestibulo-ocular reflex）
    2. (B) 前庭－自主傳導（vestibular-autonomic projections）
    3. (C) 前庭－脊髓反射（vestibulo-spinal reflex）
    4. (D) 眼球平滑追視功能（pursuit）

    正解：(C)

  73. 73關於重症肌無力（myasthenia gravis）的敘述，下列何者錯誤？

    1. (A) 是一種自體免疫系統性疾病
    2. (B) 身體產生抗體攻擊乙醯膽鹼接受器，使肌肉無法有效收縮
    3. (C) 男女比例為3：1
    4. (D) 肌肉無力的症狀，會先出現在近端肢體

    正解：(C)

  74. 74一名高中生，於一個月前出現感冒症狀，之後不藥而癒。突然在兩週前上課時感到嚴重疲倦不適，緊急送醫。送醫後狀況急速惡化，原本送醫時還能自行走入醫院，但晚間便已無法挪動手腳，隔日清晨送入加護病房使用人工呼吸器救治。歷經了兩週的治療，現在已逐漸恢復健康與手腳動作。下列何者最符合上述症狀之診斷？

    1. (A) 腦血管毛毛樣病（Moyamoya disease）
    2. (B) 基蘭－巴瑞氏症候群（Guillain-Barré syndrome）
    3. (C) 肌萎縮性側索硬化症（amyotrophic lateral sclerosis）
    4. (D) 慢性脫髓鞘多發性神經炎（chronic inflammatory demyelinating polyneuropathy）

    正解：(B)

  75. 75林姓治療師發現一名個案頻繁跌倒，希望找出其跌倒原因。經評估與檢視後，認為跌倒可能與體感覺及前庭覺衝突有關。若要證明該論點，下列何種測試最為適合？

    1. (A) 計時起走測試（Time up and go test）
    2. (B) 感覺整合與平衡臨床測試（Clinical Test of Sensory Interaction and Balance）
    3. (C) 6分鐘行走測試（6-minute walk test）
    4. (D) 30秒起坐測試（30-second chair rise test）

    正解：(B)

  76. 76根據長照2.0的SOF衰弱（frailty）定義，下列何者不是服務對象？

    1. (A) 65歲男性，80公斤，近一年體重無明顯變化，但每天都感覺很疲憊，20秒完成5次椅子坐站
    2. (B) 70歲女性，50公斤，近一年無刻意減重，但體重減少了2.5公斤，一週約有3～4天會感覺很疲憊，20秒完成5次椅子坐站
    3. (C) 75歲女性，75公斤，近一年無刻意減重，但體重減少了2.5公斤，感覺精神還好不會疲倦，12秒完成5次椅子坐站
    4. (D) 75歲男性，70公斤，近一年無刻意減重，但體重減少了5公斤，一週約有1～2天會感覺很疲憊，10秒完成5次椅子坐站

    正解：(C)

  77. 77在社區帶領患有糖尿病的高齡長者運動時，下列關於運動時之注意事項，那些正確？①每次運動前後要監控血糖，運動前血糖應控制在100～240 mg/dL ②有氧運動宜採取漸進式增加負荷 ③阻力訓練以持續的肌肉等長收縮為主 ④伸展運動宜採取彈震式伸展為主 ⑤在運動過程中出現低血糖現象，應立即補充短時間可增高血糖之食物

    1. (A) 僅①②⑤
    2. (B) ①②③⑤
    3. (C) ②④⑤
    4. (D) ①③④

    正解：(A)

  78. 78監測50位社區健康老年人的體適能或運動強度，下列何者較為適合？

    1. (A) 心跳
    2. (B) 呼吸頻率
    3. (C) 血壓
    4. (D) 血氧

    正解：(A)

  79. 79陳姓實習生幫平常沒有運動習慣的林婆婆進行測試，發現林婆婆的單腳站立測試秒數僅有0.7秒，正在規劃介入療程時，臨床指導老師建議隔天再測一次，而隔天檢測結果為12秒。此表現落差可能與測試流程有關，下列何者為第一天最可能的檢測流程？

    1. (A) 屈臂測試→坐姿體前彎測試→單腳站立測試→抓背測試
    2. (B) 抓背測試→單腳站立測試→股四頭肌肌力測試→起走測試
    3. (C) 3公尺起身行走測試→屈臂測試→坐姿體前彎測試→單腳站立測試
    4. (D) 六分鐘行走測試→30秒坐站測試→股四頭肌肌力測試→單腳站立測試

    正解：(D)

  80. 80對於失智症長者之居家環境改造，下列何者最不適當？

    1. (A) 鼓勵保持正常生活方式，樓梯儘量不加裝門鎖，方便長者走出戶外
    2. (B) 保持光線充足且亮度一致，但利用屏風掩飾廚房，以免危險
    3. (C) 在臥室、客廳等較常出現的環境中，放置家人照片或大時鐘來增加現實導向
    4. (D) 在電源開關、臥室、浴室或是衣櫃門貼上明顯標示，以增進認知及辨識

    正解：(A)
