    1. (A) 酒會、茶會或園遊會通常不安排座位或座次，賓客或坐或立，自由交談取食，氣氛活潑
    2. (B) 主人依例立於會場入口處迎賓，一一握手歡迎，盡情長談
    3. (C) 女士們參加園遊會可戴帽並攜帶陽傘
    4. (D) 酒會、茶會可安排主人致歡迎詞

    正解：(B)

  45. 45進入溫泉旅館裸湯應注意泡湯禮儀，下列敘述何者正確？

    1. (A) 包裹毛巾入湯
    2. (B) 洗淨身體後進入湯池
    3. (C) 在泡湯池中多搓揉身體
    4. (D) 團員一起打水仗同樂

    正解：(B)

  46. 46某個案在冬天登山旅遊，被發現全身僵硬、雙腳的感覺遲鈍，皮膚外觀有部分水泡，下列何項處置最適當？

    3. (C) 以接近體溫溫水回復溫度
    4. (D) 患肢擦上凡士林保護皮膚

  47. 47下列何種創傷最需要用彈性繃帶包紮？

  48. 48至西元 2019 年為止，下列何處最不容易找到自動體外心臟電擊去顫器（AED）？

  49. 49高齡的團員出現便祕情況時，下列敘述何者錯誤？

  50. 50關於時差的敘述，下列何者錯誤？
