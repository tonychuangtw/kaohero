護理師　115 年第三次 產兒科護理學　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關以家庭為中心的產科護理，下列敘述何者最適當？

    1. (A) 產婦必須於樂得兒（LDR）進行待產、分娩及產後恢復
    2. (B) 協助母親及其家庭成員參與新生兒孕育與出生歷程
    3. (C) 鼓勵父親參與配偶分娩，性別平等工作法之 5 天陪產檢及陪產假，須於分娩前請完
    4. (D) 要求每位母親產後即刻進行母嬰肌膚接觸

    正解：(B)

  2. 2李女士，G1P0，產檢無特殊狀況，有關其妊娠期婦女之健康照護，下列敘述何者正確？

    1. (A) 洗澡時應採盆浴，促進舒適及代謝
    2. (B) 避免飲酒而影響胎兒腦部細胞生長
    3. (C) 避免旅遊，以免過度疲倦引發不適
    4. (D) 避免有性行為，以減少早產的發生

    正解：(B)

  3. 3李女士於妊娠 12 週時測 B 型肝炎表面抗原（HBsAg）為陽性，依衛生福利部國民健康署孕婦健康手冊的建議，下列護理指導何者錯誤？

    1. (A) 孕婦施打 B 型肝炎疫苗使胎兒獲得被動免疫
    2. (B) 新生兒出生後 24 小時內施打 B 型肝炎免疫球蛋白（HBIG）
    3. (C) 新生兒出生後 24 小時內施打 B 型肝炎疫苗第一劑
    4. (D) 出生滿 12 個月時，幫嬰兒檢驗 B 肝表面抗原及抗體

    正解：(A)

  4. 4對於低風險孕婦妊娠早期（8～16 週）的超音波檢查，通常不包括下列那項評估？

    1. (A) 胎兒數量
    2. (B) 胎兒大小
    3. (C) 胎盤位置
    4. (D) 預產期

    正解：(C)

  5. 5有關胎盤的組成與功能，下列敘述何者正確？

    1. (A) 絨毛間腔（intervillous space）能進行母體與胎兒血液交換
    2. (B) 胎盤母體面是由絨毛膜板（chorionic plate）所形成
    3. (C) 隨著胎盤的成熟，胎盤障壁（placental barrier）會逐漸增厚
    4. (D) 細胞滋養層（cytotrophoblast）負責孕期胎盤荷爾蒙分泌

    正解：(A)

  6. 6懷孕婦女應避開攝取重金屬含量較高的魚類，下列建議何者正確？

    1. (A) 吃鮭魚肉，但不要攝取鮭魚卵
    2. (B) 可吃旗魚肉或旗魚製品
    3. (C) 可吃肉食性魚類，例如鯊魚或油魚等
    4. (D) 可吃小型魚，如鯖魚或鱸魚等

    正解：(D)

  7. 7有關 Bishop 計分法之敘述，下列那些正確？ ①計分項目包括子宮頸的擴張、變薄、位置、堅硬度及胎頭下降高度 ②計分項目包括羊水量、胎動頻率、胎兒心跳變異性、胎兒呼吸運動、胎兒身體張力 ③常用於評估引產成功率 ④分數越高代表胎兒成熟度越高，妊娠週數越大會接近生產

    1. (A) ①④
    2. (B) ②③
    3. (C) ②④
    4. (D) ①③

    正解：(D)

  8. 8王女士，G1P0，懷孕 41 週。目前子宮頸口擴張 9 公分，胎兒高度為+1，主訴：「我現在痛起來，會有想上大號的感覺。」正常情況下，此時其胎心率最有可能出現下列那種現象？

    1. (A) 早期減速
    2. (B) 晚期減速
    3. (C) 變異性減速
    4. (D) 變異性變小

    正解：(A)

  9. 9有關胎兒娩出的過程，當右枕前位（ROA）的胎兒已完成外回轉（external rotation）。正常情況下預期的娩出機轉，下列敘述何者正確？

    1. (A) 胎頭向右轉 45°復位，使左肩位於恥骨聯合下方
    2. (B) 胎頭向左轉 45°復位，使右肩位於恥骨聯合下方
    3. (C) 右肩先娩出，左肩再娩出
    4. (D) 左肩先娩出，右肩再娩出

    正解：(D)

  10. 10有關陪產員（doula）角色功能，下列敘述何者錯誤？

    1. (A) 利用呼吸法、冥想等協助待產婦度過生產階段
    2. (B) 協助胎心音監測，提供給待產婦參考
    3. (C) 提供心理及情緒支持，幫助生產過程順利進行
    4. (D) 擔任與待產婦、伴侶及醫護人員之溝通橋梁

    正解：(B)

  11. 11有關腰椎硬膜外麻醉之敘述，下列何者錯誤？

    1. (A) 麻醉後須監測生命徵象及胎心音
    2. (B) 麻醉後若有低血壓應採左側臥並給與快速輸液
    3. (C) 麻醉後易噁心、嘔吐及搔癢
    4. (D) 適用於產前出血及凝血機能異常者

    正解：(D)

  12. 12張女士，陰道生產後一週，主訴全身發熱不舒服，耳溫 37.8℃，但身體其他部位沒有明顯疼痛情況。若是發熱不適症狀與乳房或哺乳有關，下列何者為最可能的評估結果？

    1. (A) 乳房觸診和懷孕前相仿，但有乳汁滴出來
    2. (B) 乳房觸診如水囊狀沉重飽脹，乳汁會滴出來
    3. (C) 乳房局部發紅，有膿樣液體感，可以擠出濃稠乳汁
    4. (D) 兩側乳房腫脹，上緣明顯可見，觸感堅實，乳汁不易流出來

    正解：(D)

  13. 13吳女士，陰道生產娩出 4,300 公克之男嬰，會陰四度裂傷，輕微內痔，每日水分攝取 2,500 c.c.，下列何者是導致其便秘的最可能原因？

    1. (A) 每日水分攝取不足
    2. (B) 會陰四度裂傷
    3. (C) 輕微內痔
    4. (D) 腹壓增加

    正解：(B)

  14. 14有關子宮內避孕器（intrauterine devices）的敘述，下列何者正確？

    1. (A) 使子宮內膜產生增生反應，干擾受精卵著床
    2. (B) 教導婦女以手指伸入陰道確認尾線是否存在
    3. (C) 建議每 2 年更換避孕器
    4. (D) 裝置後出現骨盆腔疼痛是正常現象

    正解：(B)

  15. 15有關餵奶後的嬰兒排氣之敘述，下列何者正確？

    1. (A) 將嬰兒俯趴在一手前臂上，頭低腳高，另一手輕拍嬰兒背部
    2. (B) 餵配方奶時不要中斷，以免影響喝奶量，喝完後協助嬰兒排氣
    3. (C) 排氣時一定要聽到打嗝排氣的聲音，否則放回床上嬰兒會吐奶
    4. (D) 哺餵母乳時，如果一直有「嘖嘖」聲，表示可能吸入空氣而需要排氣

    正解：(D)

  16. 16陳女士至醫院照顧媳婦，向護理師表示：「你教導的我都會，我們住一起，阿孫我會照顧沒關係。」下列敘述何者最適當？

    1. (A) 陳女士對嬰兒照護的知識與技能不一定正確，須提供完整的衛教
    2. (B) 以產婦接受衛教的意願為主，當產婦提出需求時再衛教
    3. (C) 透過產婦丈夫協調，請陳女士不要插手新生兒照護
    4. (D) 同理陳女士的付出，討論照護方式的異同，並適時指導

    正解：(D)

  17. 17健康足月的新生兒睡覺應採何種姿勢，才能降低嬰兒猝死症候群（sudden infant death syndrome, SIDS）發生的風險？

    1. (A) 側臥
    2. (B) 趴睡
    3. (C) 躺臥
    4. (D) 半坐臥

    正解：(C)

  18. 18護理師進行新生兒沐浴時，下列何項措施最不適當？

    1. (A) 新生兒沐浴前護理師應先洗淨雙手
    2. (B) 使用水龍頭持續沖洗方式沐浴，以維持體溫
    3. (C) 宜先沐浴再餵奶
    4. (D) 室溫維持在 24～27℃左右

    正解：(B)

  19. 19有關新生兒先天性代謝異常篩檢的採血注意事項，下列敘述何者錯誤？

    1. (A) 初次篩檢時機為出生後 48 小時
    2. (B) 最佳採血部位為後腳跟兩外側
    3. (C) 以針穿刺採血部位後需將第一滴血擦拭掉
    4. (D) 未符合篩檢條件者可延後至出生後 2 個月採血

    正解：(D)

  20. 20有關 Rh 因子激敏反應（Rh sensitization）之敘述，下列何者正確？

    1. (A) 通常發生於 Rh 陽性之母親懷有 Rh 陰性之胎兒時，或 Rh 陰性之母親懷有 Rh 陽性之胎兒時
    2. (B) 母親間接性昆氏試驗（indirect Coomb's test）陰性者，於產後 72 小時內需給與母親肌肉注射 300 μgRhoGAM
    3. (C) 若母親及父親均為 Rh 陰性，仍會產生 Rh 因子激敏反應
    4. (D) 間接性昆氏試驗（indirect Coomb's test）是為檢測胎兒體內 Rh 陽性抗體數

    正解：(B)

  21. 21王女士懷孕 41 週，醫師建議引產，下列敘述何者錯誤？

    1. (A) 引產藥物 oxytocin 初始須採用高劑量，促使宮縮愈密
    2. (B) 使用 PGE2 可促進子宮頸之成熟與軟化
    3. (C) Misoprostol（Cytotec）易引起子宮過度收縮
    4. (D) 胎頭骨盆不相稱（CPD）為引產禁忌症

    正解：(A)

  22. 22張女士，30 歲，G1P0，妊娠 24 週產檢的血壓量測值為 118/78 mmHg，尿蛋白與尿糖測試均為陰性(-)。妊娠28 週產檢檢測血壓值為 140/96 mmHg，間隔四小時再測之血壓值 145/100 mmHg，尿蛋白為 1+，尿糖仍為(-)，水腫(++)，依據上述相關症狀的敘述，下列何者為張女士最可能之診斷？

    1. (A) 慢性高血壓（chronic hypertension）
    2. (B) 妊娠高血壓（gestational hypertension）
    3. (C) 子癇前症（preeclampsia）
    4. (D) 白袍高血壓（white coat hypertension）

    正解：(C)

  26. 26有關厭食症的敘述，下列何者錯誤？

  27. 27小丁，10 個月大，3 歲姊姊餵他吃果凍，結果發生咳嗽，聲音嘶啞，有意識但呼吸困難，請問此時的急救處理為何？

  28. 28小華，2 歲 10 個月，有關其發展評估的敘述，下列何者正確？

    4. (D) 此階段正在發展物體恆存概念，最喜歡玩躲貓貓遊戲

  29. 29有關兒童給藥時之特別注意事項，下列敘述何者錯誤？

    4. (D) 肌肉注射時若兒童睡著，必須要先喚醒兒童

  30. 30執行新生兒身體評估時，下列何項反應，需要做進一步的檢查？

  31. 31小花，1 歲大，女生，足月產，出生體重 3,020 公克，身高 45 公分，下列敘述何者最符合此年齡層的生長發展？

  33. 33曉鈴，14 歲，診斷第一型糖尿病入院，有關其護理照護措施，下列敘述何者錯誤？

  34. 34陳小妹出生後 24 小時內未解胎便，醫師檢查發現其直腸末端出現盲端，肛門無出口，診斷為肛門閉鎖（imperforate anus）。有關手術後的護理照護措施，下列敘述何者不適當？

    4. (D) 護理指導術後肛門擴張術的照護事項

    正解：(A)

  35. 35陳小妹，7 歲，因腦瘤復發，發生骨頭及肺部轉移，治療無效，面臨死亡時，有關陳小妹之瀕死護理，下列敘述何者最適當？

    1. (A) 出現臨終嘎聲時，應協助抽痰，維持呼吸道通暢
    2. (B) 對光線很敏感，應降低室內光線，減少光線刺激
    3. (C) 依醫囑靜脈注射 morphine，減少不必要的口服藥
    4. (D) 出現呼吸變慢、費力時，應給與插管、使用呼吸器

    正解：(C)

  36. 36有關於罹患先天性梅毒病童的診斷及照護措施，下列敘述何者最適當？

    1. (A) 初期出現鼻塞及鼻炎症狀，變為膿性及黏液性鼻分泌物
    2. (B) 因病童應適當隔離，教導家屬避免接觸病童
    3. (C) 病童的皮膚表面剝落處，可以塗敷不含酒精的優碘（iodine）消毒
    4. (D) 梅毒感染第三期為非傳染期，不需隔離

    正解：(A)

  37. 37有關兒童傳染病的隔離方式與隔離時間，下列敘述何者正確？

    1. (A) 水痘採接觸隔離，直到水疱結痂脫落後 24 小時
    2. (B) 猩紅熱採呼吸道隔離，直到開始抗生素治療後 24 小時
    3. (C) 麻疹採呼吸道隔離，直到疹子痂皮脫落後 24 小時
    4. (D) 德國麻疹採呼吸道隔離，直到疹子消失後 24 小時

    正解：(B)

  38. 38小強，11 歲，罹患氣喘，尖峰呼氣流速值（peak expiratory flow rate）個人最佳值為 240 L/min。某天早上，其尖峰呼氣流速值為 160 L/min，到傍晚上升為 200 L/min，小強目前尖峰呼氣流速的變異度（variance）之相關敘述，下列何者正確？

    1. (A) 變異度為 16.7％，早上尖峰呼氣流速值處於紅燈區
    2. (B) 變異度為 22.2％，早上尖峰呼氣流速值處於黃燈區
    3. (C) 變異度為 28％，傍晚尖峰呼氣流速值處於綠燈區
    4. (D) 變異度為 30％，傍晚尖峰呼氣流速值處於紅燈區

    正解：(B)

  39. 39有關扁桃腺切除（tonsillectomy）術後病童避免傷口出血之護理指導，下列敘述何者不適當？

    1. (A) 避免清喉嚨
    2. (B) 不宜用力咳嗽
    3. (C) 避免擤鼻涕
    4. (D) 仰臥幫助止血

    正解：(D)

  40. 40小東，7 歲，依醫囑服用毛地黃（digoxin），有關小東的護理處置，下列敘述何者錯誤？

    1. (A) 建議多食用香蕉，增加鉀離子，避免引發毛地黃中毒
    2. (B) 心尖脈低於 70 至 80 次／分鐘，則不給毛地黃
    3. (C) 毛地黃應與食物一起服用，以增加吸收量
    4. (D) 常見的毛地黃中毒症狀為噁心、嘔吐或厭食

    正解：(C)

  41. 41缺鐵性貧血是兒童常見的貧血，下列敘述何者錯誤？

    1. (A) 口服鐵劑時，應避免與制酸劑和牛奶一起使用
    2. (B) 症狀為皮膚蒼白、疲倦，症狀不明顯且不易被發現
    3. (C) 可多補充肝臟、肉類、全穀類及深綠葉蔬菜等食物
    4. (D) 採 Z 字型肌肉注射鐵劑，注射後均勻搓揉以利吸收

    正解：(D)

  42. 42兒童罹患白血病，處於復發狀態，醫師建議執行骨髓移植，移植前須經人類白血球抗原配對，下列何者是最佳的骨髓提供者？

    1. (A) 爸爸或是媽媽
    2. (B) 奶奶或是爺爺
    3. (C) 大兩歲的哥哥
    4. (D) 同卵雙胞胎姐姐

    正解：(D)

  43. 43有關高胱胺酸尿症（homocystinuria）之敘述，下列何者錯誤？

    1. (A) 是一種體染色體顯性遺傳
    2. (B) 會出現水晶體脫垂和眼睛的病變
    3. (C) 對維生素 B6 反應不佳者，需限制甲硫胺酸食物
    4. (D) 禁喝母奶，採用特殊配方奶粉

    正解：(A)

  44. 44小傑，3 歲，罹患威爾姆氏腫瘤（Wilms tumor），下列敘述何者最不適當？

    1. (A) 此為兒童時期常見的腹部腫瘤
    2. (B) 腎臟切除術為首要的治療方式
    3. (C) 每班確實進行腹部觸診的護理評估
    4. (D) 嚴密監測腎臟功能及血壓值的變化

    正解：(C)

  45. 45全奶濃度 14％，每 30 c.c.約含有 20 大卡的熱量。若每 4 小時需進食配方奶 90 c.c.，當濃度為半奶時，則每日由配方奶所獲得的熱量約為多少大卡？

    1. (A) 120
    2. (B) 140
    3. (C) 160
    4. (D) 180

    正解：(D)

  46. 46球球，4 歲，明欲執行腸道手術，今晚需進行手術前大量清潔灌腸，有關執行大量清潔灌腸，下列何者最適當？

    1. (A) 採左側臥，右膝屈曲姿勢
    2. (B) 溶液溫度保持 37～38℃
    3. (C) 一般灌腸液體為蒸餾水
    4. (D) 灌腸筒液面與兒童肛門距離為 15～20 公分

    正解：(A)

  47. 47王小弟，8 個月，因重複泌尿道感染入院求治，診斷為膀胱輸尿管逆流，有關其抗生素的使用，下列護理指導何者正確？

    1. (A) 體溫正常即可停用抗生素，以免長期用藥產生副作用
    2. (B) 抗生素停用前的尿液培養檢查至少兩次呈現陰性
    3. (C) 從導尿管取尿，若單一病原達 10 菌落數，推定為泌尿道感染
    4. (D) 慢性感染時，低劑量抗生素持續服用至成年

    正解：(B)

  48. 48小妮，出生時罹患脊髓脊膜膨出（myelomeningocele），有關其手術前的護理措施，下列敘述何者錯誤？

    1. (A) 協助維持仰臥姿勢，並抬高床頭，以促進末梢血循
    2. (B) 觀察小妮神經學各項功能之狀況
    3. (C) 保持臀部與會陰處乾淨，避免膨出的囊沾到排泄物
    4. (D) 使用無菌生理食鹽水紗布覆蓋膨出的囊，以避免囊袋破裂

    正解：(A)

  49. 49張小弟，9 歲，罹患裘馨氏假肥大性肌失養症（Duchenne's pseudohy-pertrophic muscular dystrophy），有時走路較為困難，下列護理指導何者正確？

    1. (A) 儘早給與坐輪椅，避免常跌倒骨折
    2. (B) 出現逐漸退化的肌肉無力現象，須關注病童及家屬心理反應
    3. (C) 避免游泳，以免感染
    4. (D) 為避免呼吸依賴，呼吸有異常者夜眠仍不宜使用呼吸器

    正解：(B)

  50. 50有關顱內壓升高（increased intracranial pressure, IICP）晚期徵候之庫欣氏三病徵（Cushing'striad），下列敘述何者錯誤？

    2. (B) 血壓上升（hypertension）
    3. (C) 心跳徐緩（bradycardia）
    4. (D) 呼吸變慢或不規則（respiratory depression）

    正解：(A)
