本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1關於含鐵食物的消化吸收，下列敘述何者錯誤？

    1. (A) 紅肉的血基質（heme）可直接被吸收入小腸上皮細胞
    2. (B) 植物類食物中的Fe2+較Fe3+難吸收
    3. (C) 小腸上皮細胞吸收的鐵會經由運鐵蛋白（transferrin）運送至骨髓造血

    正解：(B)

  5. 5關於自主神經系統（autonomic nervous system）的敘述，下列何者錯誤？

    2. (B) 交感神經系統節前神經纖維短，節後神經纖維長；反之，副交感神經系統節前神經纖維長，節後神經纖維短
    3. (C) 交感神經系統節前與節後神經末梢釋放的神經傳遞物質為腎上腺素（epinephrine）
    4. (D) 交感神經系統調控的反應又可稱為「fight-or-flight反應」；副交感神經系統調控的反應又可稱為「digest-or-rest反應」

    1. (A) 皮質醇（cortisol）與膽固醇（cholesterol）
    2. (B) 雌激素（estrogen）與膽固醇（cholesterol）
    3. (C) 正腎上腺素（norepinephrine）與色胺酸（tryptophan）
    4. (D) 甲狀腺素（thyroxine）與碘（iodine）

    正解：(C)

  46. 46下列何者主要可藉由DNA結合蛋白作用於荷爾蒙反應元件（hormone response element），調控特定基因的表現？

    2. (B) 兒茶酚胺（catecholamines）
    3. (C) 昇糖素（glucagon）
    4. (D) 視網酸（retinoic acid）

    正解：(D)

  47. 47實驗課上某生分別配製了胃蛋白酶（pepsin）與胰蛋白酶（trypsin）酵素溶液，但忘記標示酵素名稱。下列何者可最快速且經濟的方法，分辨此二酵素溶液？

    1. (A) 取適量酵素溶液與白蛋白進行水解反應1小時後，測量胺基酸產物種類
    2. (B) 取適量酵素溶液與白蛋白在pH=2條件下進行水解反應後，利用雙脲試劑（Biuret reagent）進行呈色反應和比較
    3. (C) 利用單株抗體的專一性進行抗體與酵素的免疫分析反應（ELISA）後，測量特定波長的吸光值
    4. (D) 取適量酵素溶液與白蛋白在37℃下進行水解反應後，利用比色法測量產物肽鏈（peptide）的呈色反應

    正解：(B)

  48. 48參與粒線體電子傳遞鏈反應的NADH或FADH2來自於下列何者？①檸檬酸循環 ②糖解作用 ③脂肪酸β氧化作用

    2. (B) 僅①③
    3. (C) 僅②③
    4. (D) ①②③

  49. 49酵素動力學最常用的公式是： ，關於Km與Vmax的單位說明，下列何者正確？

    4. (D) 只有Km是濃度單位，如mol/L

  50. 50關於丙酮酸去氫酶激酶（pyruvate dehydrogenase kinase, PDK）在生化代謝調節的敘述，下列何者錯誤？
