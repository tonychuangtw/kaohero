    2. (B) MP4
    3. (C) MPEG
    4. (D) ZIP

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) ZIP 是一般用途的無失真檔案壓縮格式，適用於任何檔案類型，並非專為視訊設計。

    ❌ (A) MOV 是 Apple QuickTime 的視訊容器格式。

    ❌ (B) MP4 是 MPEG-4 Part 14 定義的視訊容器格式。

    ❌ (C) MPEG 是專為動態影像與聲音制定的一系列壓縮標準。

  2. 2將關聯式資料庫中多個表單（table）中的資料，依值（value）的內容，做多欄位（field）合併查詢的功能，稱為：

    1. (A) Join operation
    2. (B) Project operation
    3. (C) Product operation
    4. (D) Select operation

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) Join（合併）運算依共同欄位的值，把兩個以上的關聯表結合成一個新關聯，是多表多欄位查詢的核心運算。

    ❌ (B) Project（投影）是從單一關聯中選取部分「欄位」。

    ❌ (C) Product（卡氏積）是不加條件地把兩關聯的每列兩兩配對。

    ❌ (D) Select（選擇）是從關聯中篩選符合條件的「列」。

    📚 出處：關聯代數的基本運算

  3. 3某計算機系統以 n 位元（bit）暫存器儲存有號整數（signed integer），並以二補數（two’s complement）編碼。此系統所能表示的整數數值範圍為何？

    1. (A) [-2n-1-1, 2n-1]
    2. (B) [-2n-1, 2n-1-1]
    3. (C) [-2n-1, 2n-1]
    4. (D) [-2n, 2n]

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) n 位元二補數可表示的範圍為 −2^(n−1) 至 2^(n−1)−1，負數比正數多一個，因為零只有一種表示法。

    ❌ (A) 負值下限與正值上限均偏移一位。

    ❌ (C) 正值上限應為 2^(n−1)−1。

    ❌ (D) 2^n 的範圍超出 n 位元所能表示的數量。

    📚 出處：二補數表示法
