警察特考　113 年 三等考試 警察學與警察勤務　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1依據民國 112 年公布施行之「犯罪被害人權益保障法」，下列敘述何者正確？

    1. (A) 犯罪被害人權益保障法主管機關為內政部
    2. (B) 提供犯罪被害人關懷協助相關資訊為警政主管機關權責
    3. (C) 犯罪被害人權益保障之宣導為警政主管機關權責
    4. (D) 推動犯罪被害人之福利服務為警政主管機關權責

    正解：(B)

  2. 2執行路檢勤務時，查獲某自小客車後車廂置放一把刀械，請問置放下列何種刀械，警察需採取的執法措施為優先查詢有否攜帶許可證？

    1. (A) 蝴蝶刀
    2. (B) 藍波刀
    3. (C) 鋼筆刀
    4. (D) 彈簧刀

    正解：(C)

  3. 3行政院於民國 111 年 12 月 29 日核定「強化全民國防兵力結構調整方案」調整兵力結構，建立四大防禦區塊，賦予各部隊及系統明確的任務，請問下列何者非屬於其民防系統之組成？

    1. (A) 民防團隊
    2. (B) 保安警察
    3. (C) 義務役後備軍人
    4. (D) 替代役

    正解：(C)

  4. 4依據「各級警察機關處理刑案逐級報告紀律規定」，下列何者之發生與破獲，逾一小時通報刑事警察局偵防中心及警政署勤務指揮中心視為遲報？

    1. (A) 失竊物總值達新臺幣 90 萬元案件
    2. (B) 一般外國旅客失竊案件
    3. (C) 跟蹤騷擾案件
    4. (D) 重傷害案件

    正解：(D)

  5. 5我國集會遊行法基於對外交代表保護及不得侵犯，將使領館區列為禁制區，並規範不得在禁制區及其週邊範圍舉行集會遊行，此與下列何者相關？

    1. (A) 巴塞爾外交關係公約
    2. (B) 維也納外交關係公約
    3. (C) 華盛頓外交關係公約
    4. (D) 日內瓦外交關係公約

    正解：(B)

  6. 6依據「執行拘提逮捕解送使用戒具實施辦法」，下列敘述何者錯誤？

    1. (A) 執行拘提、逮捕或解送時，對於被告或犯罪嫌疑人是甫生產後之婦女以及少年，一律不應使用戒具
    2. (B) 警察人員於依法執行拘提、逮捕或解送職務時，得對被告或犯罪嫌疑人使用戒具
    3. (C) 使用戒具，以手銬為原則。但被告或犯罪嫌疑人有被劫持之虞情形時，得合併使用腳鐐、聯鎖或束繩等
    4. (D) 使用戒具時，除應遵守比例原則，不得逾必要之程度外，另應注意避免公然暴露所使用之戒具

    正解：(A)

  7. 7依據內政部警政署所訂之「警察機關勤務督察實施規定」，下列敘述何者正確？

    1. (A) 各級督察人員之督勤次數，每月每人不得少於 4 次，每次不得少於 2 小時
    2. (B) 勤務督導區分為駐區督導、隨機督導、專案督導及聯合督導等四類
    3. (C) 督導應掌握重點，但例假日、災變、勤務交接及用膳時間應減少督導，以免影響勤務運作
    4. (D) 依工作需要派遣配合實施之聯合督導，若非督察人員則除勤務督導外，以督導主管業務為原則

    正解：(D)

  8. 8「問題導向警政」（Problem-Oriented Policing）是以「問題」解決為導向的警察勤務作為，下列何者並非形成「問題」的要素？

    1. (A) 事件反覆發生
    2. (B) 期待警方處理
    3. (C) 事件具獨特性
    4. (D) 事件具社區性

    正解：(C)

  9. 9下列有關警察勤務之敘述何者正確？

    1. (A) 落實勤務執行，始能達成警察任務，而勤務規劃為主要推動力量
    2. (B) 督導人員督導發現重大優良事蹟，可當場頒發獎金即時獎勵
    3. (C) 各級督導人員除因勤務性質報准得著便服督勤外，應一律穿著制服
    4. (D) 警察局為勤務規劃監督機構，負責轄區警察勤務之規劃、指揮、管制、督導及考核，對重點性勤務，需交由責任區警察分局執行，不可越俎代庖

    正解：(C)

  10. 10內政部為保障各警察機關實施輪班輪休服勤人員之健康權，特訂定「警察機關輪班輪休人員勤休實施要點」，依據該要點規定，執行稽查、取締違反森林法或野生動物保育法勤務之警察人員服勤時數為下列何者？

    1. (A) 不得連續超過 2 日；每月超時服勤時數不得超過 100 小時
    2. (B) 不得連續超過 3 日；每月超時服勤時數不得超過 100 小時
    3. (C) 不得連續超過 2 日；每月超時服勤時數不得超過 120 小時
    4. (D) 不得連續超過 3 日；每月超時服勤時數不得超過 80 小時

    正解：(B)

  11. 11依據「警察機關輪班輪休人員勤休實施要點」，警察人員服勤時數以每日 8 小時為原則，但執行下列何種勤務，超時服勤時間不受每日不得超過 16 小時限制？

    1. (A) 刑事警察單位執行刑案偵查
    2. (B) 執行食安相關法令案件之勤務
    3. (C) 偵辦陳報內政部警政署列管之重大刑案或特殊刑案專案
    4. (D) 實際擔負內部管理及應變處置之主管勤務

    正解：(C)

  12. 12依據治安顧慮人口查訪辦法，有關治安顧慮人口之查訪，下列敘述何者正確？

    1. (A) 警察發現治安顧慮查訪對象有違法之虞時，應以勸告或其他適當方法，促其不再犯
    2. (B) 曾犯森林法所定森林主副產物贓物罪者，屬治安顧慮人口查訪對象
    3. (C) 對於已在社會上享有一定程度聲望與地位之查訪對象，為避免影響查訪對象之名譽，應主動改為夜間實施查訪
    4. (D) 曾犯槍砲彈藥刀械管制條例所定運輸槍砲彈藥刀械之罪者，屬治安顧慮人口查訪對象

    正解：(A)

  13. 13在警察勤務運作原理中，提出警察勤務應該主動先發式（proactive）的發現問題，而不是被動反應式（reactive）的處理問題，前述是屬於下列何種勤務原理？

    1. (A) 隨機原理
    2. (B) 散在原理
    3. (C) 機動原理
    4. (D) 活用原理

    正解：(C)

  14. 14依警察勤務區訪查作業規定第 2 點規定，下列何者並非記事人口？

    1. (A) 依性侵害犯罪防治法第 7 條、第 41 條規定，應登記、報到之加害人
    2. (B) 依性侵害犯罪防治法第 42 條規定，應登記、報到之加害人
    3. (C) 依家庭暴力防治法第 48 條規定，應實施查訪之相對人（加害人）
    4. (D) 依跟蹤騷擾防制法第 5 條規定，經警察機關書面告誡後二年內，再為跟蹤騷擾行為者

    正解：(D)

  15. 15下列何者警察機關係執行警察法第 5 條第 1 款拱衛中樞、準備應變及協助地方治安之保安警察業務？

    1. (A) 內政部警政署保安警察第二總隊
    2. (B) 內政部警政署保安警察第三總隊
    3. (C) 內政部警政署保安警察第四總隊
    4. (D) 內政部警政署保安警察第七總隊

    正解：(C)

  16. 16警察以輔導、協助、勸告、建議或其他不具法律上強制力之方法，促請特定人為一定作為或不作為之行為，為何者警察手段？

    1. (A) 指導
    2. (B) 服務
    3. (C) 代履行
    4. (D) 強制

    正解：(A)

  17. 17下列何者為警察職權行使法規定的警察職權？

    1. (A) 代履行
    2. (B) 蒐集資料
    3. (C) 間接強制
    4. (D) 行政罰

    正解：(B)

  18. 18依據集會遊行法第 25 條規定，經許可之集會、遊行而有違反許可事項、許可限制事項者，該管主管機關得予警告、制止或命令解散，此項職權規定賦予警察機關何者空間？

    1. (A) 行政罰
    2. (B) 即時強制
    3. (C) 發布抽象法令
    4. (D) 行政裁量

    正解：(D)

  19. 19依據警察職權行使法第 6 條規定，警察於公共場所或合法進入之場所，得對於下列何者之人查證其身分？

    1. (A) 滯留於有事實足認有陰謀、預備、著手實施重大犯罪或有人犯藏匿之處所者
    2. (B) 合理懷疑其有違反行政罰之虞者
    3. (C) 合理懷疑其對已發生之犯罪或即將發生之犯罪知情者
    4. (D) 有事實足認為防止其本人或他人生命、身體及財產之具體危害，有查證其身分之必要者

    正解：(A)

  20. 20關於警察勤務制度、事權及法令之規定，下列何者正確？

    1. (A) 警察勤務制度，由中央立法並執行，不能交由直轄市、縣（市）執行
    2. (B) 警察勤務制度，指警察業務之單位組合勤務方式之基本原則事項
    3. (C) 直轄市警察勤務機構設置、裁併及勤務之實施事項，由中央立法，再交由直轄市執行
    4. (D) 警察勤務條例之規定，於各專業警察機關執行各該專屬勤務時準用之

    正解：(D)

  21. 21公共安全、秩序維護與危害防止任務不再專由形式的警察組織行使，其他機關依據職權法規分別行使命令強制權力，此為何者警政發展？

    1. (A) 警察權集中化
    2. (B) 警察權專業化
    3. (C) 警察權分散化
    4. (D) 警察權兩極化

    正解：(C)

  22. 22關於警勤區訪查之敘述，下列何者正確？

    1. (A) 警勤區訪查之目的為達成刑案查緝、為民服務及社會治安調查等任務
    2. (B) 警勤區員警實施訪查，應遵守平等原則，有正當理由，得為差別待遇
    3. (C) 警勤區員警實施訪查時，應著制服或出示服務證表明身分，並告知訪查目的；經由所長核准以社區座談會方式實施訪查者，於訪查日二日前以書面通知受訪查者
    4. (D) 記事人口，於登記或通知後開始查訪，查訪次數依各警察局保安業務主管單位規劃辦理

    正解：(B)

  23. 23關於警察權的敘述，下列何者正確？

    1. (A) 民主法治政體，警察權力的基礎，源自統治者實施統治權的作用
    2. (B) 警察法第 3 條規定的警察事權，為中央與地方機關警察權限的橫向分配
    3. (C) 專由形式意義的警察機關行使的權力方法，稱為警察職權
    4. (D) 警察裁量是在法的空間內所為的自由決定，如有裁量瑕疵，係由行政機關自行監督審查

    正解：(C)

  24. 24依據執行巡邏勤務中盤查盤檢人車作業程序規定，警察執行巡邏勤務中盤查盤檢人車時，受盤查人如當場陳述理由，表示異議，下列作業內容何者錯誤？

    1. (A) 異議有理由，警察立即停止盤查盤檢，當場放行，或更正執行行為
    2. (B) 異議無理由，則繼續執行
    3. (C) 受盤查人請求時，填寫警察行使職權民眾異議紀錄表一式三聯
    4. (D) 將表示異議者帶往勤務處所，製作警察行使職權民眾異議筆錄一式三聯

    正解：(D)

  25. 25關於地方政府警察局勤務實施細則之敘述，下列何者正確？

    1. (A) 臺中市政府警察局勤務實施細則，由內政部警政署擬定
    2. (B) 臺北市政府警察局勤務實施細則，陳報臺北市政府核准施行
    3. (C) 嘉義縣警察局勤務實施細則，陳報內政部警政署核准施行
    4. (D) 臺南市政府警察局勤務實施細則的法律依據為警察職權行使法

    正解：(C)
