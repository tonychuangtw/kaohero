職能治療師　109 年第一次 小兒職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1關於促進兒童職能的參考架構（SCOPE-IT）中的評估指引，下列敘述何者正確？

    1. (A) 確認孩童、照顧者與教育者各方對評估過程的動機與期望
    2. (B) 以機構和學校為中心
    3. (C) 以由下而上的評估方向，著重於檢視孩童職能表現的組成要素
    4. (D) 在標準化的治療空間評估職能表現

    正解：(A)

  2. 2關於「促進社會參與的參考架構」敘述，下列何者錯誤？

    1. (A) 此參考架構以獲得與行為理論為基礎
    2. (B) 認為與主要照顧者在嬰幼兒初期之關係，是影響孩童社會發展之基礎
    3. (C) 主張孩童應發展習慣與常規，讓自己被他人所接受，並成功參與社會
    4. (D) 主張孩童應培養良好口語表達能力，這是被同儕接納、發展友誼須具備之基本技能

    正解：(D)

  3. 3有關習慣（habits）與常規（routines）之敘述，下列何者錯誤？

    1. (A) 來自建立固定常規之家庭的孩童，能展現較佳學前社會能力
    2. (B) 處於生活結構鬆散家庭的孩童，可擁有較強的時間調整能力與應變能力
    3. (C) 孩童會透過學習模仿照顧者的行為，該行為會成為孩童與他人互動或維持互動的習慣
    4. (D) 協助學步期孩童建立常規，可讓家庭提高對孩童的照顧效率、減少壓力

    正解：(B)

  4. 4職能治療師在團體遊戲中讓一般孩童或較年長的手足示範合宜的遊戲規則與互動技巧，鼓勵身心障礙孩童觀察模仿適當的社交行為，以促進其社會參與能力的正向改變。此介入策略主要運用下列那項理論？

    1. (A) Skinner的行為理論
    2. (B) Freud的心理分析理論
    3. (C) Bandura的社會學習理論
    4. (D) Piaget的認知發展理論

    正解：(C)

  5. 5根據「促進學習的四象限模式（the four-quadrant model of facilitated learning, 4QM）」參考架構，「使用聲光科技或影片展示模擬任務」是屬於象限一的那種學習策略？

    1. (A) 明確的指示與說明（explicit instruction and explanation）
    2. (B) 示範（demonstration）
    3. (C) 身體指導（physical patterning）
    4. (D) 心智想像（mental imagery）

    正解：(B)

  6. 6職能治療師運用「促進學習的四象限模式（the four-quadrant model of facilitated learning, 4QM）」協助小美學習自己扣釦子，當小美忘記自發性的用記憶口訣自我提示關鍵步驟時，治療師問小美：「你可以對自己說什麼來幫助你回想呢？」此為何種跨越象限的中間策略？

    1. (A) 帶領策略（leading strategies）
    2. (B) 監控策略（monitoring strategies）
    3. (C) 定向策略（orienting strategies）
    4. (D) 消退策略（fading strategies）

    正解：(C)

  7. 7關於神經發展治療中的操作（handling）手法，下列敘述何者正確？

    1. (A) 職能治療師需以雙手來控制孩童的動作，主要是確保其安全考量
    2. (B) 操作的控制關鍵點（key points of control）需在身體近端
    3. (C) 主要確保孩童執行任務時，使用的是適當的肌肉協同
    4. (D) 執行操作手法的手，一次只能控制一個關節，確保姿勢排列適當

    正解：(C)

  8. 8職能治療師在治療5歲有四肢癱瘓（quadriplegia）腦性麻痺的個案時，在仰躺姿勢將個案的兩側下肢與軀幹擺成完全屈曲的姿勢，同時輕拉其雙手引導碰觸雙腳，所利用的手法目的為何？

    1. (A) 抑制（inhibition）
    2. (B) 誘發（facilitation）
    3. (C) 準備與誘發（preparation and facilitation）
    4. (D) 抑制與誘發（inhibition and facilitation）

    正解：(D)

  9. 9職能治療師對一個有觸覺防禦的腦性麻痺孩童，讓他趴在最喜歡的毛毯上，同時鼓勵他抬頭並伸取前方放在毛毯上的各式玩具。這是使用那種參考架構？

    1. (A) 依序使用參考架構
    2. (B) 平行使用參考架構
    3. (C) 單一使用參考架構
    4. (D) 合併使用參考架構

    正解：(D)

  10. 10與感覺調節有關的治療介入，下列敘述何者正確？

    1. (A) 對於有重力不安全感的孩童，可給予大量快速垂直升降活動，避免雙腳接觸地面，讓孩童在空中練習抗地心移動頭及身體
    2. (B) 對於過度警醒的孩童可使用輕度或間歇式的碰觸以減低警醒度
    3. (C) 對於前庭系統警醒度較高的孩童，可運用快速、不規則及旋轉的動作，以減低警醒度
    4. (D) 職能治療師可運用交互推拉或雙臂承重等活動增加本體覺輸入，以調整警醒度

    正解：(D)

  11. 11在獲得參考架構中，行為的主要決定因素是下列何者？

    1. (A) 環境情境
    2. (B) 孩童認知能力
    3. (C) 發展技巧的連結
    4. (D) 感覺刺激

    正解：(A)

  12. 12大明因為打了阿龍，被老師罰站，之後大明變本加厲，更常趁老師不在時故意欺負阿龍，且引以為樂。有關上述情境，下列何者正確？

    1. (A) 處罰是大明行為的替代性增強（vicarious reinforcement）
    2. (B) 處罰是大明行為的正增強
    3. (C) 大明不適當的行為是經由塑造（shaping）而來的
    4. (D) 老師應加強處罰來消除大明的不當行為

    正解：(B)

  13. 13丁丁看到珍珍乖乖排隊玩滑梯受到老師稱讚，因此也跟著耐心排隊。此行為獲得屬於那種策略？

    1. (A) 正增強（positive reinforcement）
    2. (B) 負增強（negative reinforcement）
    3. (C) 替代性增強（vicarious reinforcement）
    4. (D) 塑造（shaping）

    正解：(C)

  14. 14關於國際健康功能與身心障礙分類系統（ICF）中的情境因素，下列敘述何者正確？

    1. (A) 環境因素總是正面影響孩童參與生活的能力
    2. (B) 宗教和心靈活動是屬於產品科技類的環境因素
    3. (C) 支持與關係僅從家人而來
    4. (D) 職能治療師提供以個案為中心的服務時，關注的情境面向就等同於環境因素

    本題經考選部公告不計分。

  15. 15下列處理肌肉張力過低的方法，何者不是以「神經發展治療參考架構」為依據？

    1. (A) 引導孩童做小幅度的慢速動作
    2. (B) 多使用抗重力的直立姿勢，如坐姿或站姿
    3. (C) 給予壓迫（compression）或牽引（traction）等觸覺與本體覺刺激
    4. (D) 給予快速的前庭覺刺激

    正解：(D)

  16. 16孩童隨著口腔動作技巧的發展，開始可以吃各種不同的食物，下列何者為一般職能治療師最晚讓孩童嘗試的食物？

    1. (A) 薯泥
    2. (B) 燉軟的肉
    3. (C) 蘋果泥
    4. (D) 果汁

    正解：(B)

  17. 17有關口腔過度敏感的問題，下列敘述何者錯誤？

    1. (A) 有觸覺敏感的孩童比較容易出現口腔敏感的狀況
    2. (B) 常出現於早期有鼻胃管餵食經驗的孩童，例如早產兒
    3. (C) 通常出現於神經損傷孩童，少發生於發展遲緩孩童
    4. (D) 職能治療師可以提供持續且穩定的刺激（例如深壓），來改善口腔敏感的問題

    正解：(C)

  18. 18處理孩童拒絕食物、挑食等行為問題，下列那個治療策略最不適切？

    1. (A) 提供孩童選擇的機會，讓孩童有自我控制感，增加參與動機
    2. (B) 對於好的行為，可以透過正增強來維持
    3. (C) 對於不好的行為，建議忽略或重塑該行為，不建議使用負增強或處罰
    4. (D) 增強的策略建議以有實體的物件為佳（例如玩具），不建議使用口頭鼓勵或讚美

    正解：(D)

  19. 19在執行手功能訓練時，職能治療師特別強調反覆地練習功能性的活動，治療過程中，透過增強物的提供與回饋，提升孩童的動作表現。上述最符合那種治療策略？

    1. (A) 生物力學治療模式（biomechanical practice model）
    2. (B) 神經發展治療模式（neurodevelopmental therapy）
    3. (C) 動作學習治療模式（motor learning practice model）
    4. (D) 任務導向治療模式（task-oriented practice model）

    正解：(C)

  20. 20有關座椅擺位原則，以下何者最正確？

    1. (A) 椅背高度建議至肩峰（acromion）位置
    2. (B) 軀幹側邊支持（lateral trunk support）需比骨盆檔板（pelvic blocks）優先考慮
    3. (C) 要使用軀幹束帶（trunk harness）時，需同時考慮骨盆固定帶（pelvic belt）的使用
    4. (D) 提供最多附加支持物以維持穩定為原則

    正解：(C)

  21. 21有關影響肌肉張力的因素，下列何者最不適合用來降低肌肉張力？

    1. (A) 提供慢速的搖晃
    2. (B) 提供較低溫的環境
    3. (C) 將頭與身體擺在非誘發原始反射的姿勢
    4. (D) 提供輕柔的音樂

    正解：(B)

  22. 22關於孩童空間視知覺發展的敘述，下列何者錯誤？

    1. (A) 空間概念的發展順序為垂直距離，之後是水平距離，然後是對角線距離
    2. (B) 區分鏡像或反向數字和字母的能力一般在5歲左右發展成熟
    3. (C) 對於自己身體的左右概念一般在6～7歲時建立
    4. (D) 對於外部物體空間中所在位置與自身關係的概念一般在8歲時建立

    正解：(B)

  23. 23有關動作技巧獲得參考架構的描述，下列何者正確？

    1. (A) 練習的重點應該在動作形式（patterns of movement）而不是行動（actions）
    2. (B) 刻意練習（deliberate practice）的目標是讓孩童由試驗找出解決動作問題的方法
    3. (C) 使用集中練習（massed practice）對長期動作學習的效果，比隨機練習（random practice）要好
    4. (D) 要讓練習有效，就必須在特定時段和環境中進行

    正解：(B)

  24. 24有關動作練習的回饋給予，下列敘述何者最不適切？

    1. (A) 動作學習後期，應鼓勵孩童利用內在回饋使動作技巧更進步
    2. (B) 學習初期，每次動作後都給予回饋對於學習有幫助
    3. (C) 對於年紀小的孩童，回饋的內容應該要簡短，且提供有關動作結果的資訊
    4. (D) 除了口語外，也可利用視覺、觸覺等提供回饋

    正解：(B)

  25. 25有關Schmidt提出的動作技巧學習理論，下列敘述何者最不適切？

    1. (A) 看到籃球進框，是一種結果知識（knowledge of results）的回饋
    2. (B) 關於練習結果的抽象概念稱為基模（schema）
    3. (C) 基模（schema）是固定的，不會因為練習而改變
    4. (D) 學習某個動作技巧時，提供些微不同的視覺輸入、運動覺、環境聲音都有助於基模建立

    正解：(C)

  26. 26以下何者不屬於視覺認知功能？

  27. 27關於感覺區辨的描述與處理，下列何者錯誤？

    2. (B) 症狀會隨著一天中時間的不同而改變
    3. (C) 觸覺區辨能力通常與動作運用障礙（dyspraxia）同時發生
    4. (D) 觸覺區辨能力可以在前庭本體活動中同時提供大量的觸覺刺激而改善

    正解：(B)

  28. 28發展源自感覺統合理論，強調警醒程度、自我調節、認識自我的活動量狀態，學習運用感覺策略，達成最佳功能性狀態的治療為：

  31. 31下列那一個評估工具，僅能評量視知覺的能力，無法測得手眼協調或視動整合能力？

    3. (C) 行為介入對於日常生活功能的預後有幫助
    4. (D) Towbin等人（2007）指出其伴隨癲癇的比率頗高

    正解：(A)

  77. 77下列有關聽覺障礙孩童所使用的助聽器及人工電子耳的敘述，何者錯誤？

    1. (A) 聽覺障礙孩童使用助聽器或人工電子耳，是依據聽覺障礙的種類及程度來選擇
    2. (B) 與使用助聽器或電子耳的孩童說話時，指令應該儘量簡短，以使用單字為佳
    3. (C) 剛開始應選擇人較少且較安靜的環境配戴助聽器，再逐漸增加配戴時間
    4. (D) 人工電子耳最佳的植入時間是孩童4歲以前，因4歲前植入獲得語言的機會最大

    正解：(B)

  78. 78下列那項口腔動作及自我餵食技巧，在1歲一般發展孩童身上尚無法看到？

    1. (A) 獨立用手指拿東西吃（finger-feeding）
    2. (B) 開始出現旋轉咀嚼的動作（rotary chewing movement）
    3. (C) 舌頭會舔下嘴唇的果醬
    4. (D) 用杯子喝水時，上下顎已能穩定（internal jaw stabilization）

    正解：(D)

  79. 79下列何者不是判別有身體運用不能（somatodyspraxia）的6歲孩童常見之臨床表徵？

    1. (A) 執行快速交替動作（rapidly alternating movements）有困難
    2. (B) 維持小飛機的姿勢（prone extension）有困難
    3. (C) 拇指依序碰觸其餘各指指尖（sequential finger touching）有困難
    4. (D) 仰躺屈曲（supine flexion）維持30秒有困難

    正解：(B)

  80. 80下列關於Takata發展的「The Play History」和Knox發展的「Knox Preschool Play Scale」的比較，何者錯誤？

    1. (A) 兩項評估工具的發展者皆為職能治療師
    2. (B) 兩者都只適用於評估0～6歲孩童的遊戲行為
    3. (C) 兩者都需使用自然觀察法
    4. (D) 兩者都是具有不錯信度和效度的評估工具

    正解：(B)
