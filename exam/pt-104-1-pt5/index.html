物理治療師　104 年第一次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列何者為第7頸椎神經根所主宰的主要動作？

    1. (A) 肩關節外展（shoulder abduction）
    2. (B) 肘關節屈曲（elbow flexion）
    3. (C) 腕關節屈曲（wrist flexion）
    4. (D) 大拇指伸直（thumb extension）

    正解：(C)

  2. 2與胸廓出口症候群（thoracic outlet syndrome）相關之解剖構造，最不可能包括下列何者？

    1. (A) 鎖骨下血管
    2. (B) 臂神經叢下幹（lower trunk）
    3. (C) 臂神經叢外索（lateral cord）
    4. (D) 前斜角肌（anterior scalenus）

    正解：(C)

  3. 3下列有關頸椎的敘述，何者錯誤？

    1. (A) 椎間盤退化是個體自然老化現象，但與營養、工作姿勢以及遺傳因子有關
    2. (B) 頸椎椎間盤突出（herniation）可能造成脊髓（spinal cord）壓迫
    3. (C) 有頸部神經張力異常的患側肩膀通常較低
    4. (D) 頸椎側滑（cervical lateral glide）可用來治療上肢神經張力異常的問題

    正解：(C)

  4. 4頸因性頭痛之主要運動治療不包括下列何者？

    1. (A) 改善肩胛肌群之穩定控制能力
    2. (B) 增加枕骨下肌之柔軟度
    3. (C) 增強頸椎後收（retraction）之肌力
    4. (D) 增加胸鎖乳突肌（sternocleidomastoid）之肌力

    正解：(D)

  5. 5覆膜韌帶（tectorial membrane）是下列那條韌帶之延伸？

    1. (A) 後縱韌帶（posterior longitudinal ligament）
    2. (B) 前縱韌帶（anterior longitudinal ligament）
    3. (C) 項韌帶（nuchal ligament）
    4. (D) 頸十字韌帶（cruciform ligament）

    正解：(A)

  6. 6下列有關頸部揮鞭症候群（Whiplash Syndrome）急性期治療的敘述，何者不適當？

    1. (A) 關節鬆動術1-2級（grades I-II）
    2. (B) 可適當使用軟頸圈（soft cervical collar）支持
    3. (C) 限制胸椎活動
    4. (D) 放鬆斜方肌（trapezius）張力

    正解：(C)

  7. 7下列有關使用壓力回饋測試儀器（pressure biofeedback unit，如Stabilizer）以評估頸椎功能之敘述，何者正確？

    1. (A) 測量頸椎淺層肌肉功能
    2. (B) 測試儀器放置於額頭
    3. (C) 基準點壓力為40 mmHg
    4. (D) 達到壓力標的值時，應能維持5～10秒

    正解：(D)

  8. 8下列有關頸椎小面關節之敘述，何者錯誤？

    2. (B) 小面關節的問題常會有轉移痛到對側
    3. (C) 小面關節的問題可能會使局部肌肉痙攣（spasm）
    4. (D) 下巴前凸（poking chin）的姿勢常會增加小面關節上的壓力

    正解：(B)

  9. 9根據學者Janda與Jull敘述肌肉不平衡時，過大的腰椎前凸（lordosis）可能與下列何者相關？

    2. (B) 腹肌緊縮
    3. (C) 豎脊肌（erector spinae）無力
    4. (D) 臀大肌（gluteus maximus）緊縮

    正解：(A)

  10. 10接受左邊後外側切入（posterolateral approach）全髖關節置換手術的病患，術後一週時，最不宜做下列何動作？

    4. (D) 以左腳為軸向左轉

    正解：(D)

  11. 11下列有關Craig’s 測試評估股骨前傾（femoral anteversion）之敘述，何者錯誤？

    1. (A) 患者俯臥，膝屈曲到90度，測試者觸摸股骨大轉子後側部分，將受試者髖關節被動地內轉以及外轉直到其大轉子跟測試床平行或是在最外側位置
    2. (B) 檢查者量測受試側小腿與垂直假想線之間的角度以測量前傾（anteversion）角度
    3. (C) 幼兒之股骨前傾角度較成人小
    4. (D) 成年人股骨前傾角度之正常值是介於8到15度

    正解：(C)

  12. 12下列有關椎間盤髓核（nucleus pulposus）位置的敘述，何者正確？

    1. (A) 各部位脊椎之髓核均位於椎間盤之中心位置
    2. (B) 胸椎部位的髓核位於椎間盤之中間偏後方的位置
    3. (C) 腰椎部位的髓核位於椎間盤之中間偏後方的位置
    4. (D) 腰椎部位的髓核位於椎間盤之中間偏前方的位置

    正解：(C)

  13. 13下列關於腰椎小面關節夾擠（facet joint impingement）問題的敘述，何者正確？

    2. (B) 通常休息不動時也會疼痛

    4. (D) 通常每一個方向的腰部動作活動度都會受限

    正解：(C)

  14. 14王先生今年40歲，今晨因急性背痛到物理治療部門就診，下列症狀中，何者最需考慮立即安排轉診？

  20. 20下列有關慢性髖退化性關節炎的敘述，何者正確？

    4. (D) 關節內活動（joint play movement）測試時，會發現活動度不足（hypomobility）

  21. 21為降低習慣性彎腰工作者之椎間盤突出（disc protrusion）再發率，應建議工作者於工作中執行下列何種動作？

    2. (B) 在執行彎腰動作或用力的同時，應伴隨深呼吸屏息動作，以便增加腹壓藉以降低腰部負荷
    3. (C) 刻意中斷持續性彎腰動作，至少每個小時進行數次雙手插腰後伸動作
    4. (D) 至少每個小時進行數次立姿彎腰到底的動作，以維持軀幹柔軟度

    正解：(C)

  30. 30如圖，病人採坐姿，雙手支撐於治療球上，進行將身體向上撐起之訓練。關於此一訓練之敘述，下列何者正確？
