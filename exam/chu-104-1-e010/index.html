初等考試　104 年 初等考試 人事行政大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1公務人員身分非依法定程序不得免職、降級處分，確保不受政黨輪替之影響，此乃屬人事制度的下列那種特色？

    1. (A) 人性化
    2. (B) 專業化
    3. (C) 彈性化
    4. (D) 永業化

    正解：(D)

  2. 2依人事管理條例規定，下列何者並非我國各級人事管理機構之法定名稱？

    1. (A) 人事局
    2. (B) 人事處
    3. (C) 人事室
    4. (D) 人事管理員

    正解：(A)

  3. 3下列何者非屬公務人員保障暨培訓委員會依法應辦理或委託辦理之訓練事項？

    1. (A) 公務人員考試錄取人員訓練
    2. (B) 升任官等訓練
    3. (C) 行政中立訓練
    4. (D) 一般管理訓練

    正解：(D)

  4. 4下列那一項不是我國現行考銓制度的特色？

    1. (A) 官等和職等併立
    2. (B) 每一職務僅能列一個職等
    3. (C) 初任係以考試方式為之
    4. (D) 俸給制度採俸點制

    正解：(B)

  5. 5下列何者是職位分類制度的主要特點？

    1. (A) 以工作職務和責任為分類基礎
    2. (B) 以資歷為中心
    3. (C) 根據設官分職的原則，劃分任職文官之品級秩等
    4. (D) 此分類制度其管理措施頗富有彈性

    正解：(A)

  6. 6下列何者不是品位分類人事制度的特點？

    1. (A) 同工同酬
    2. (B) 簡單易行
    3. (C) 富於彈性
    4. (D) 晉升幅度較大

    正解：(A)

  7. 7中央行政機關的組織以命令定之者，依法其內部單位之分工職掌，以下列何種名稱定之？

    1. (A) 處務規程
    2. (B) 組織規程
    3. (C) 辦事細則
    4. (D) 作業準則

    正解：(C)

  8. 8依法規規定，行政院進用之機要人員員額，最多不得超過幾人？

    1. (A) 2 人
    2. (B) 5 人
    3. (C) 10 人
    4. (D) 18 人

    正解：(C)

  9. 9公務人員之調任，必要時得認定其職系專長，並得依其職系專長調任，但認定項目不包括下列何者？

    1. (A) 考試
    2. (B) 學歷
    3. (C) 語言
    4. (D) 訓練

    正解：(C)

  10. 10某甲為初任委任之公務人員，其經銓敘部銓敘審定合格後，係由何機關任命之？

    1. (A) 各主管機關
    2. (B) 銓敘部
    3. (C) 考試院
    4. (D) 總統

    正解：(A)

  11. 11專為說明每一職務之工作性質及責任之文書為：

    1. (A) 職務列等表
    2. (B) 職系說明書
    3. (C) 職務說明書
    4. (D) 職等標準

    正解：(C)

  12. 12公務人員特種考試之四等考試及格者，取得委任第幾職等任用資格？

    1. (A) 第一職等
    2. (B) 第三職等
    3. (C) 第四職等
    4. (D) 第五職等

    正解：(B)

  13. 13某中央機關 A 技士，現敘薦任第六職等年功俸六級 535 俸點，自願降調 B 機關擔任委任第一至三職等書記的職務，依規定其核敘俸給應該為何？

    1. (A) 五職等年功俸十級 520 俸點，照支 535 俸點
    2. (B) 五職等年功俸十級 520 俸點，改支 520 俸點
    3. (C) 三職等年功俸八級 415 俸點，照支 535 俸點
    4. (D) 三職等年功俸八級 415 俸點，改支 415 俸點

    正解：(A)

  14. 14各機關辦理陞遷時，如同一序列中人數眾多，下列何項標準不是公務人員陞遷法所訂之排定高低序列的主要標準？

    3. (C) 學歷證照
    4. (D) 官稱官階

    正解：(C)

  15. 15依公務人員陞遷法之規定，初任各官等之主管職務，應由各主管機關實施何種訓練？

    3. (C) 公務人員專業訓練

  16. 16臺北市政府交通局局長在派任下列職務時，何者需經甄審或甄選程序？

    3. (C) 科長
    4. (D) 主任秘書

  17. 17依公務人員考試法規定，關於公務人員考試的敘述，何者為正確？

    2. (B) 具體應考資格明訂於公務人員考試法條文中

    4. (D) 允許因公務貪污罪服刑出獄者報考
