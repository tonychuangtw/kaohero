警察特考　113 年 三等考試 行政法　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1關於行政法之法源，下列敘述何者正確？

    1. (A) 最高行政法院大法庭之裁定，對提案庭提交之事件有拘束力
    2. (B) 最高行政法院庭長法官聯席會議之決議，於大法庭制度實施後，即停止適用
    3. (C) 最高行政法院經大法庭徵詢程序統一之法律見解，依法有通案拘束下級法院之效力
    4. (D) 最高行政法院選編之判例，有裁判全文可查考者，其法律見解有通案拘束下級法院之效力

    正解：(A)

  2. 2依據司法院關於層級化法律保留原則相關解釋之意旨，下列敘述何者正確？

    1. (A) 行政機關強制將感染流行性疾病之確診者隔離於特定處所一定期間，得以法律或法律授權之法規作為依據
    2. (B) 行政機關於流行性疾病傳播期間禁止公務員出國旅行，僅得依法律規定，不得以法律授權之法規作為依據
    3. (C) 行政機關公布違反居家隔離要求而有可能感染流行性疾病人民之姓名，得以法律或法律授權之法規作為依據
    4. (D) 行政機關對因可能感染流行性疾病而居家隔離之人民提供餐點及服務，僅得依據法律，不得以法規命令定之

    正解：(C)

  3. 3依司法院解釋意旨，對人民違反行政法上義務之行為處以罰鍰，涉及對人民財產權之限制，下列敘述何者錯誤？

    1. (A) 罰鍰是立法者針對應予非難之違反行政法上義務行為給予之處罰
    2. (B) 立法者預留視違規情節輕重而予處罰之範圍，係屬立法形成自由
    3. (C) 立法者所設定之裁量範圍均應儘量放寬予行政機關決定，以避免造成個案處罰顯然過苛而有情輕法重之情形
    4. (D) 處罰應視違規情節之輕重程度而為裁量，俾符合憲法責罰相當原則

    正解：(C)

  4. 4依現行法規定，下列何者非屬公法人？

    1. (A) 國家運動訓練中心
    2. (B) 南投市
    3. (C) 高雄市那瑪夏區
    4. (D) 臺北翡翠水庫管理局

    正解：(D)

  5. 5法令規定直轄市人口低於 200 萬人者，其處、局、委員會之總數不得超過 29 個；高於 200 萬人者，總數則不得超過 32 個，此與下列何種地方自治團體之權限相關？

    1. (A) 地方立法自主權
    2. (B) 地方財政自主權
    3. (C) 地方組織自主權
    4. (D) 地方空間設置自主權

    正解：(C)

  6. 6同一醫療器材申請事件，衛生福利部食品藥物管理署及經濟部產業發展署均有管轄權時，下列敘述何者錯誤？

    1. (A) 由受理在先之機關管轄
    2. (B) 由衛生福利部及經濟部協議決定管轄
    3. (C) 由衛生福利部食品藥物管理署及經濟部產業發展署協議決定管轄
    4. (D) 由行政院指定管轄

    正解：(B)

  7. 7關於公務員停職之規定，下列敘述何者正確？

    1. (A) 主管機關對於所屬公務員依規定送請監察院彈劾，認為有免除職務等情節重大之虞者，得依職權先行停職
    2. (B) 公務員停職後復職者，服務機關毋庸補給其停職期間之本俸（年功俸）或相當之給與
    3. (C) 公務員停職期間，亦同時喪失公務人員身分
    4. (D) 停職期間為 6 個月以上，3 年以下

    正解：(A)

  8. 8依公務員服務法之規定，下列何者構成公務員違反不得兼任他項公職或業務之義務？

    1. (A) 勞動部專員業餘時間無償兼任社區大學志工講師，雖未妨礙本職工作，仍報服務機關備查
    2. (B) 臺灣士林地方檢察署檢察官於業餘時間撰寫法庭小說並委由商業出版社出版販售，獲取相當報酬
    3. (C) 擁有導遊執照之臺中市和平區公所科員，在公餘時間偶爾接受旅行社委託，以按件計酬方式擔任原住民文化導遊，賺取薄利
    4. (D) 衛生所醫師依法令兼任私立醫療院所之定期駐院醫師，並就兼任部分獲有薪資

    正解：(D)

  9. 9下列何種案件之審理程序，依法有參審員之設置？

    1. (A) 行政法院之收容聲請事件程序
    2. (B) 行政法院之都市計畫審查程序
    3. (C) 懲戒法院職務法庭之法官懲戒案件
    4. (D) 憲法法庭之總統彈劾案件

    正解：(C)

  10. 10關於行政立法之敘述，下列何者錯誤？

    1. (A) 訂定法規命令之機關須為授權法律所明定之機關
    2. (B) 訂定法規命令之機關若無權限，該命令應為無效或得撤銷
    3. (C) 法律授權行政機關訂定法規命令，以補充法律規定之不足者，該機關不得另發布行政規則替代之
    4. (D) 法律雖無轉委任授權，機關仍得委由其所屬機關逕行發布相關規章

    正解：(D)

  11. 11下列何者與行政自我拘束原則無直接關聯？

    1. (A) 行政機關頒布法規命令
    2. (B) 行政規則間接對外發生效力
    3. (C) 人民請求平等適用法律
    4. (D) 違反建築法事件統一裁罰基準表

    正解：(A)

  12. 12關於行政處分之轉換，下列敘述何者正確？

    1. (A) 對違法行政處分之信賴利益，顯然大於撤銷所欲維護之公益者，該處分不得轉換
    2. (B) 經當事人陳述意見後，得轉換法律效果對當事人更為不利之處分
    3. (C) 行政機關得將違法行政處分轉換為與原處分具有類似實質及程序要件之其他行政處分
    4. (D) 羈束處分於通知當事人陳述意見後，得轉換為裁量處分

    正解：(A)

  13. 13內政部移民署許可港澳居民在臺定居之申請，為下列何種行政處分？

    1. (A) 確認處分
    2. (B) 下命處分
    3. (C) 形成處分
    4. (D) 羈束處分

    正解：(C)

  14. 14甲依法規申請補助，主管機關在法定處理期間經過後才作出申請否准之處分，甲接獲處分後未於不變期間內提起訴願，上級機關得否依職權撤銷該處分之理由為何？

    1. (A) 基於依法行政，處分不得違反包括處理期間在內所有上位階法規，上級機關應依職權撤銷
    2. (B) 因甲未進行救濟，該處分既已確定，上級機關不得依職權撤銷
    3. (C) 法定處理期間並非行政處分之合法要件，上級機關不得以逾越該期間為理由撤銷該處分
    4. (D) 不論其信賴是否值得保護，上級機關皆得依職權撤銷

    正解：(C)

  15. 15依行政程序法規定，行政機關與人民締結之行政契約，下列何者非契約無效之事由？

    1. (A) 行政機關與人民締結之雙務行政契約，未約定人民給付之特定用途
    2. (B) 依法應經其他行政機關同意之行政處分，以行政契約代替時，其締結未經該其他機關同意
    3. (C) 行政機關對於行政處分所依據之事實，未經職權調查即認為不能確定，而締結行政契約以代替行政處分
    4. (D) 依法應以甄選或其他競爭方式決定行政契約當事人時，未予參與競爭者表示意見之機會

    正解：(B)

  16. 16下列何者為行政事實行為？

    1. (A) 軍校招生錄取之通知
    2. (B) 政府發放消費券之宣導通知
    3. (C) 汽車燃料使用費之繳納通知
    4. (D) 公務人員考績之通知

    正解：(B)

  17. 17下列何者為行政罰？

    1. (A) 發展觀光條例規定檢查結果不合規定，違反公共安全情節重大者，得命其定期停止營業
    2. (B) 海洋污染防治法規定限制船舶及相關船員離境之處分
    3. (C) 廠商因借用或冒用他人名義或證件投標，主管機關依政府採購法規定，將之刊登於政府公報
    4. (D) 主管機關依廢棄物清理法規定，命民營機構清除土地上之感染性事業廢棄物

    正解：(C)

  18. 18A 餐廳因違規營業，經主管機關依法作成勒令停業之行政處分。關於該處分之行政執行，下列敘述何者正確？

    1. (A) 主管機關為原處分機關，亦為執行機關
    2. (B) 主管機關應先向行政法院取得執行名義
    3. (C) 本案屬於行為義務之不履行
    4. (D) 主管機關得優先對 A 餐廳採取斷水斷電之執行方法

    正解：(A)

  19. 19依政府資訊公開法規定，下列何者之會議紀錄應主動公開？

    1. (A) 客家委員會
    2. (B) 公平交易委員會
    3. (C) 海洋委員會
    4. (D) 國家發展委員會

    正解：(B)

  20. 20關於訴願之敘述，下列何者正確？

    1. (A) 訴願以書面審查為原則，受理訴願機關認為必要時，亦得通知相關人進行言詞辯論
    2. (B) 原行政處分之執行，因提起訴願而停止
    3. (C) 訴願事件之行政處分經原處分機關自行撤銷者，受理訴願機關應作成有理由之決定
    4. (D) 訴願有理由者，受理訴願機關得視事件之情節，作成逕為變更原行政處分之決定，其變更亦得較原處分不利

    正解：(A)

  21. 21下列何者非屬相當於訴願之程序？

    1. (A) 行政執行法之聲明異議
    2. (B) 公務人員保障法之復審程序
    3. (C) 針對大學退學處分向學校提起之申訴
    4. (D) 犯罪被害人不服補償審議會決定所申請之覆議

    正解：(C)

  22. 22關於行政訴訟制度之敘述，下列何者錯誤？

    1. (A) 原告主張對其不利之行政處分未經合法送達，應提起確認無效訴訟
    2. (B) 原告提起行政訴訟之確認訴訟，須有即受確認判決之法律上利益
    3. (C) 公法上契約成立後，情事變更，非當時所得預料，而依其原有效果顯失公平者，行政法院得依當事人聲請，為變更原有效果之判決
    4. (D) 人民在提起一般給付訴訟之行政訴訟類型時，得合併請求國家賠償

    正解：(A)

  23. 23關於行政訴訟法上暫時權利保護之敘述，下列何者正確？

    1. (A) 為保全公法上金錢給付之執行，得聲請假處分
    2. (B) 一旦提起行政訴訟後，即停止原處分或決定之執行
    3. (C) 針對得聲請停止執行之處分或決定，即不得聲請假處分
    4. (D) 行政訴訟繫屬中，行政法院不得依職權裁定停止執行，一律必須待當事人之聲請

    正解：(C)

  24. 24關於國家賠償責任之成立要件，下列敘述何者錯誤？

    1. (A) 凡公務員執行職務時侵害人民自由或權利，不問公務員是否有故意或過失，由國家承擔賠償責任
    2. (B) 執行職務者，為受託行使公權力之民間團體或個人，即視為委託機關之公務員，由國家承擔賠償責任
    3. (C) 公共設施之設置或管理有欠缺，致損害人民身體或財產權利，不問設置人或管理人有故意或過失，由國家承擔賠償責任
    4. (D) 公共設施委託民間團體或個人管理，因管理欠缺致人民身體或財產權利受損，由國家承擔賠償責任

    正解：(A)

  25. 25依司法院解釋意旨或憲法法庭裁判，下列何者不構成特別犧牲？

    1. (A) 都市計畫指定公共設施保留地對土地所有人造成之限制
    2. (B) 於私有土地上形成之公用地役關係
    3. (C) 主管機關依道路交通管理處罰條例規定，公告禁止在騎樓擺設攤位
    4. (D) 供農田水利設施照舊使用之土地未獲設定為公物且未以私法關係取得使用權源

    正解：(C)
