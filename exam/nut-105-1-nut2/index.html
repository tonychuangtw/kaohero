營養師　105 年第一次 營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1關於乳糖不耐症的敘述，下列何者錯誤？

    1. (A) 相較北美白種人，亞洲及非洲人種發生機率通常較高
    2. (B) 相較於牛奶，通常食用發酵乳品（如：優格或優酪乳）之耐受性較佳
    3. (C) 攝食含有乳糖的乳製品時，同時攝食其他類別之食物，也無法緩解乳糖不耐之情形
    4. (D) 相較於牛奶，起司在製造過程通常乳糖會流失，故起司也屬於耐受性較佳的食品

    正解：(C)

  2. 2為維持健康，每人每日均須維持一定量碳水化合物的攝食，美國 RDA 即建議成年人每天至少需攝食 130克以上可食碳水化合物，則訂定此一標準的根據是：

    1. (A) 避免肥胖
    2. (B) 可滿足腦部及中樞神經系統對葡萄糖的需求，避免依賴酮體做為能量來源
    3. (C) 預防糖尿病
    4. (D) 由每日所需總熱量換算而來

    正解：(B)

  3. 3下列何種糖與心血管疾病發生風險的正相關性最高？

    1. (A) 果糖
    2. (B) 麥芽糖
    3. (C) 乳糖
    4. (D) 寡糖

    正解：(A)

  4. 4下列人體何種器官，與 amylose 及 amylopectin 的消化分解無關？

    1. (A) 口腔
    2. (B) 胃
    3. (C) 胰臟
    4. (D) 小腸頁次： 4－2

    正解：(B)

  5. 5下列何種胺基酸的結構中含有硫？

    1. (A) 異白胺酸
    2. (B) 羥丁胺酸
    3. (C) 半胱胺酸
    4. (D) 色胺酸

    正解：(C)

  6. 6下列何者是決定蛋白質品質的重要因素？

    1. (A) 價格與方便性
    2. (B) 生產履歷
    3. (C) 衛生安全
    4. (D) 胺基酸組成

    正解：(D)

  7. 7當蛋白質長期攝取不足時，易發生下列何種狀況？

    1. (A) 細胞免疫功能增加
    2. (B) 自體免疫功能增加
    3. (C) 細胞內液增加
    4. (D) 細胞外液增加

    正解：(D)

  8. 8肌肉可釋放 pyruvate 及下列何種物質進入 Cori cycle 進行糖質新生作用？

    1. (A) Alanine
    2. (B) Lactate
    3. (C) Acetate
    4. (D) Ketone

    正解：(B)

  9. 9下列何種油脂為水溶性，只需極少量膽汁即可吸收，吸收後直接進入肝門循環？

    1. (A) 游離膽固醇
    2. (B) 磷脂質
    3. (C) 中鏈三酸甘油酯
    4. (D) 必需脂肪酸

    正解：(C)

  10. 10在動物體內能轉換成前列腺素的花生四烯酸，可由下列何種脂肪酸合成？

    1. (A) 油酸
    2. (B) 棕櫚酸
    3. (C) 亞麻油酸
    4. (D) 二十碳五烯酸

    正解：(C)

  11. 11在禁食或飢餓一段時日後，血糖及胰島素下降，乙醯輔酶 A 堆積。此時，下列何者為體內肌肉及腦部之主要熱量來源？

    1. (A) 葡萄糖
    2. (B) 乳酸
    3. (C) 酮體
    4. (D) 胺基酸

    正解：(C)

  12. 12負責將肝臟三酸甘油酯運送到周邊器官的主要脂蛋白（lipoproteins）是：

    1. (A) 低密度脂蛋白
    2. (B) 極低密度脂蛋白
    3. (C) 高密度脂蛋白
    4. (D) 乳糜微粒

    正解：(B)

  13. 13一位婦女，體重為 68 公斤，身高為 150 公分，則其體型屬於下列何類型？

    1. (A) 體重稍輕
    2. (B) 標準體重
    3. (C) 體重稍重
    4. (D) 肥胖

    正解：(D)

  14. 14下列有關測定能量消耗的方法，何者錯誤？

    1. (A) 利用直接熱量測定儀，測量體熱的流失
    2. (B) 利用間接熱量測定儀，測量二氧化碳及尿素氮排出量
    3. (C) 利用放射線標定的氫及氧，收集血液與尿液以評估二氧化碳排出量
    4. (D) 利用身高、體重、性別、年齡及活動量套用公式計算

    正解：(B)

  15. 15王先生 48 歲，身高 170 公分，體重 86 公斤，則依照衛生福利部的標準，他的正常體重範圍是多少公斤？

    1. (A) 53.5～69.1
    2. (B) 52～69.3
    3. (C) 63～70
    4. (D) 65～71.5

    正解：(A)

  16. 16下列有關身體組成測量方法的敘述，何者正確？

    1. (A) 以水中測量體重的方法評估身體組成時，可得到體表面積
    2. (B) 利用生物電阻（bioelectrical impedance）評估身體組成時，電阻越小表示脂肪越多
    3. (C) 以全身電導度法（TOBEC）評估身體組成時，可測得全身瘦體組織的量
    4. (D) 以雙能 X 光吸收法（DEXA）評估身體組成時，會暴露於輻射線

    正解：(D)

  17. 17下列何者不是維生素 B12 缺乏導致惡性貧血所伴隨之臨床症狀？

    1. (A) 巨球性紅血球特徵
    2. (B) 升高血漿同半胱胺酸濃度
    3. (C) 神經病變
    4. (D) 小球性紅血球特徵頁次：4－3

    正解：(D)

  18. 18攝取下列那一群組食物，能夠提供健康 20 歲男性每日葉酸最佳參考攝取量？

    1. (A) 1 杯柳橙汁，1 份炒菠菜，1 份炒豬肝，1/2 杯黑豆
    2. (B) 1 杯全脂牛奶，1 份雞胸肉，1 碗白米飯，1 份草莓
    3. (C) 1 杯豆漿，1 份瘦絞牛肉，1 份馬鈴薯，1 根香蕉
    4. (D) 1 杯優酪乳，1 顆水煮蛋，1/4 杯綠蘆筍，1 個白饅頭

    正解：(A)

  19. 19泛酸為下列何種生化分子之重要結構？

    1. (A) 丙酮酸（pyruvate）
    2. (B) 檸檬酸（citric acid）
    3. (C) 同半胱胺酸（homocysteine）
    4. (D) 輔酶 A（coenzyme A）

    正解：(D)

  20. 20血色素沉著症（hemochromatosis）之病人不應攝取高劑量的維生素 C，可能是因為維生素 C 參與下列何種營養素的代謝？

    1. (A) 鐵
    2. (B) 鋅
    3. (C) 錳
    4. (D) 穀胱甘肽

    正解：(A)

  21. 21能夠反應飲食維生素 D 攝取量與日照效應，代表個體維生素 D 營養狀態之生化檢測指標為：

    1. (A) 血清 ergocalciferol 濃度
    2. (B) 皮下組織 cholecalciferol 含量
    3. (C) 肝臟 1,25-(OH)2 D3 含量
    4. (D) 血清 25-(OH)D3 濃度

    正解：(D)

  22. 22下列何者是成人個體產生維生素 D 缺乏之臨床疾病？

    1. (A) 骨質疏鬆症（osteoporosis）
    2. (B) 軟骨症（osteomalacia）
    3. (C) 佝僂症（rickets）
    4. (D) 高血鈣症（hypercalcemia）

    正解：(B)

  23. 23下列何種營養素協助再生維生素 E 的抗氧化特性？

    1. (A) 維生素 C
    2. (B) 維生素 B1
    3. (C) 維生素 B6
    4. (D) 維生素 A

    正解：(A)

  24. 24下列何種維生素可由腸道微生物合成？

    1. (A) 生物素、維生素 K
    2. (B) 維生素
    3. (C) 維生素 EC.維生素 B6、維生素 A
    4. (D) 維生素 D、葉酸

    正解：(A)

  25. 25下列何者不是影響骨質疏鬆的因子？

    1. (A) 更年期
    2. (B) 年齡
    3. (C) 肝功能
    4. (D) 荷爾蒙

    正解：(C)

  26. 26下列何種飲食不會影響鈣離子的吸收？

    1. (A) 高磷食物
    2. (B) 高纖食物
    3. (C) 高鉀食物
    4. (D) 高植酸食物

    正解：(C)

  27. 27鉛被認為會干擾體內一些礦物質的作用，下列何者除外？

    1. (A) 鈣（calcium）
    2. (B) 鐵（iron）
    3. (C) 硒（selenium）
    4. (D) 鋅（zinc）

    正解：(C)

  28. 28人體骨骼中主要是由下列那些礦物質組成？

    1. (A) 氮、磷、鉀
    2. (B) 鈉、鉀、氯
    3. (C) 鈣、磷、鎂
    4. (D) 磷、硫、碘

    正解：(C)

  29. 29老年人宜補充富含抗氧化劑的食材，下列何組食材在同重量時為較佳的選擇？

    1. (A) 芭樂＋洋蔥
    2. (B) 西瓜＋洋菜
    3. (C) 甘蔗＋白菜
    4. (D) 枇杷＋芥菜

    正解：(A)

  30. 30下列何者是吃純素的青少年最不容易缺乏的營養素？

    1. (A) 鋅
    2. (B) 膽固醇
    3. (C) 維生素 A
    4. (D) 鈣頁次： 4－4

    正解：(C)

  31. 31關於維生素 A 和類胡蘿蔔素的敘述，下列何者正確？

    1. (A) 植物所製造的類胡蘿蔔素都可以轉換成維生素 A
    2. (B) 攝取過量的維生素 A 會造成肝及腦部的損害
    3. (C) 對於長期吸菸者，攝取較多的維生素 A 會明顯改善肺功能
    4. (D) 吃過多含胡蘿蔔素的食物會造成肝中毒

    正解：(B)

  32. 32小芬是一個 16 歲的高中女生，體檢發現她有缺鐵性貧血，則下列那一個早餐組合最適合她？

    1. (A) 烤肉三明治（里肌肉、蕃茄片、生菜葉）＋鮮榨柳丁汁 1 杯
    2. (B) 燒餅油條＋甜豆漿 1 杯
    3. (C) 高麗菜水煎包 2 個＋米漿 1 杯
    4. (D) 牛肉漢堡（牛絞肉、洋蔥末、酸黃瓜）＋奶茶 1 杯

    正解：(A)

  33. 33依照民國 100 年「國人膳食營養素參考攝取量（DRIs）」修訂第七版的標準，7～9 歲的學童，每日蛋白質的攝取建議量約為多少公克？

    1. (A) 20
    2. (B) 40
    3. (C) 60
    4. (D) 80

    正解：(B)

  34. 34老年人的 sarcopenia 是指體組成中何種成分的減少？

    1. (A) fat
    2. (B) water
    3. (C) bone
    4. (D) muscle

    正解：(D)

  35. 35大蒜的保健成分大多數具刺激味，其屬於：

    1. (A) 含硫化合物
    2. (B) 含鋅化合物
    3. (C) 含銅化合物
    4. (D) 含磷化合物

    正解：(A)

  36. 36紅麴已被發現具有降血膽固醇與血壓等功效，但是某些紅麴會產生對肝腎造成傷害之物質，此物質為何？

    1. (A) 橘黴素（citrinin）
    2. (B) γ-胺基丁酸（GABA）
    3. (C) monacolin K
    4. (D) 黃麴毒素（aflatoxin）

    正解：(A)

  37. 37脂解酶（lipase）為腸道中之重要分解酵素，可以促進脂肪的消化，下列何者為其分解產物？

    1. (A) 過氧化物
    2. (B) 游離脂肪酸
    3. (C) 反式脂肪酸
    4. (D) 不飽和脂肪酸

    正解：(B)

  38. 38蜂膠為蜜蜂採集植物之樹脂、精油與樹枝雜草末等以分泌之唾液加以混合後作為蜂巢之用，人類於數百年前發現蜂膠具有抗菌、抗病毒等功效，主要之貢獻物質為何？

    1. (A) 芬多精
    2. (B) 葉綠素
    3. (C) 花青素
    4. (D) 酚類化合物

    正解：(D)

  39. 39對於增加運動選手的肌肉量而言，下列何種方法是最安全的？

    1. (A) 攝取三倍的蛋白質或補充劑
    2. (B) 攝取適當蛋白質，並持續加強肌力訓練
    3. (C) 主要以蛋白質做為肌肉能量的來源，相對地降低碳水化合物的攝取
    4. (D) 在青春期時服用荷爾蒙

    正解：(B)

  40. 40進行 60 公尺的短跑時，下列何者為主要的能量來源？

    1. (A) carbohydrate 與 phosphocreatine
    2. (B) ATP 與 phosphocreatine
    3. (C) fat 與 protein
    4. (D) carbohydrate 與 fat

    正解：(B)
