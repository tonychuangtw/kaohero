警察特考　108 年 四等考試 國文　考古題與詳解

本卷共 10 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（10 題，建議 30 分鐘）

  1. 1下列各組選項，前後「」內語詞意義相同的是：

    1. (A) 我不懂這句話的「意思」／這部電影真的很有「意思」
    2. (B) 請他們格外當心，不可「大意」／請簡要說明本文「大意」
    3. (C) 陳教授近年致力於「東西」文化交流／思念是一種很玄的「東西」
    4. (D) 有著「非常」的遭遇可以顯出「非常」的氣節／此人相貌「非常」，只可激，不可說

    正解：(D)

  2. 2「報紙不增張，像是罐頭中的沙丁魚；報紙增張後，像是泡了水的麵包。」根據上文，報紙增張前後的比較，主要在說明：

    1. (A) 為增加銷售量，報紙常浮誇事實而乏公信力
    2. (B) 無論張數的多寡，報紙都以民生需求為優先
    3. (C) 報紙的張數雖然增加，內容卻未能同步提升
    4. (D) 報紙是讀者的精神食糧，加量才能滿足需求

    正解：(C)

  3. 3「如果一個人無法跟上同伴們的腳步，很可能他聽見的是另外一種鼓聲，那麼，就讓他隨著他所聽見的節拍去吧！」下列敘述，何者與上句意旨最相近？

    1. (A) 缺乏團隊精神的人，就讓他離開，不必強留
    2. (B) 品味有雅俗之別，不可以用相同標準來要求
    3. (C) 鐘鼎山林天性不同，應依自己的步伐走向目標
    4. (D) 人生短暫，寧可慢下腳步欣賞，不要隨人起舞

    正解：(C)

  4. 4為將之道，當先治心。泰山崩於前而色不變，麋鹿興於左而目不瞬，然後可以制利害，可以待敵。（蘇洵〈權書．心術〉）依據上文，下列選項何者符合「為將」的修養？

    1. (A) 洞燭機先
    2. (B) 驍勇善戰
    3. (C) 忍耐守靜
    4. (D) 制敵千里

    正解：(C)

  5. 5始皇嘗議欲大苑囿，東至函谷關，西至雍、陳倉。優旃曰：「善。多縱禽獸於其中，寇從東方來，令麋鹿觸之足矣。」始皇以故輟止。（《史記．滑稽列傳》）根據上文，優旃使秦始皇改變主意的勸說方法是：

    1. (A) 揭示道理
    2. (B) 委婉諷喻
    3. (C) 將心比心
    4. (D) 直言極諫60140-6054080140-8074014140-14440

    正解：(B)

  6. 6楚有養狙以為生者，楚人謂之狙公。旦日，必部分眾狙於庭，使老狙率以之山中，求草木之實，賦什一以自奉；或不給，則加鞭箠焉。群狙皆畏苦之，弗敢違也。一日，有小狙謂眾狙曰：「山之果，公所樹與？」曰：「否也，天生也。」曰：「非公不得而取與？」曰：「否也，皆得而取也。」曰：「然則吾何假於彼，而為之役乎？」言未既，眾狙皆寤。其夕，相與伺狙公之寢，破柵毀柙取其積，相攜而入於林中，不復歸。狙公卒餒而死。郁離子曰：「世有以術使民而無道揆者，其如狙公乎？惟其昏而未覺也；一旦有開之，其術窮矣。」（劉基《郁離子》）下列敘述，何者錯誤？

    1. (A) 狙公養猴的寓言就像是統治者治理人民
    2. (B) 人民面對無理剝削的情況，是會起而反抗
    3. (C) 狙有覺醒的意識，是因為受了教育，而有思想的啟蒙
    4. (D) 統治者靠權術役使百姓，一旦人民覺悟，政權就會崩潰

    正解：(C)

  7. 7下列詩詞，何者不是表達對歷史的感嘆？

    1. (A) 功蓋三分國，名成八陣圖。江流石不轉，遺恨失吞吳
    2. (B) 興亡千古繁華夢，詩眼倦天涯。孔林喬木，吳宮蔓草，楚廟寒鴉
    3. (C) 搖落深知宋玉悲，風流儒雅亦吾師。悵望千秋一灑淚，蕭條異代不同時
    4. (D) 長安一片月，萬戶擣衣聲。秋風吹不盡，總是玉關情。何日平胡虜？良人罷遠征

    正解：(D)

  8. 8下列景物的描寫，何者不是由近而遠，逐層推移？

    1. (A) 河水一片浩渺，河水之外是爛泥的荒灘，荒灘之外是稻田、房舍
    2. (B) 在鄉下小路隔著水田望去，先有門闕，再有庭，再隱約見到庭後的堂屋
    3. (C) 窄窄巷道一轉，巷後藏有三兩家堂屋，堂屋後還有田，田後竟更有山，豁然開朗
    4. (D) 遠處，秧針半吐的水田，如棋盤一樣整齊排列；近處，無心散落的綠色棋子，閒閒地被灑在局外

    正解：(D)

  9. 9「生命發生的聲音有些是聽不見，卻看得見的。某些聲音可以在心中滋長，甚至變得很喧囂，很龐巨，耳畔卻沒有任何聲響。」下列選項，不屬於這種將聲音視覺化描寫的是：

    1. (A) 嚼口香糖的漢子／把手風琴拉成／一條那麼長的無人巷子
    2. (B) 馬蹄聲，孤獨又憂鬱地自遠至近，灑落在沉默的街上，如白色的小花朵
    3. (C) 走在春日喧囂的山林小徑上，耳畔清靜，蹲下來，卻能看見熱鬧鼎沸的聲音
    4. (D) 黑暗中，遙遠的妳突然哭泣不再說話，只把話筒貼在胸口，用噗噗的心跳回答我殷切的呼喚

    正解：(D)

  10. 10「近年來，從美國科技業開始，許多產業都出現了不同角色結盟的工作團隊：擅長技術的『工匠』、了解市場『行腳商人』，再搭配善於經營管理的『總管』。他們有時選擇自行掛牌創業，但也可能以團隊為單位應徵一間公司，甚至說服企業主資助他們成立新事業。創業或是聘雇對他們來說，純粹是資源取得方式的不同。由於他們具備獨立研發、銷售與運作的能力，得以和大企業保持一種對等的合作關係，並非像傳統上班族僅能仰賴組織，當個聽命行事的員工。上述的結盟，我們稱之為『最小戰鬥單位』，在未來的職場，這將成為一股最堅實的勢力！」下列敘述，何者最符合本文的看法？

    1. (A) 人工智慧興起，技術人員將因無法展現專長，漸被淘汰
    2. (B) 未來職場需結合不同專業人才，分工合作發揮整體戰力
    3. (C) 自行創業對「最小戰鬥單位」而言，最能讓團隊發揮所長
    4. (D) 不同角色結盟的工作團隊，因仰賴企業支持，須聽命行事

    正解：(B)
