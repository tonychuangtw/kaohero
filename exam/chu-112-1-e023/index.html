初等考試　112 年 初等考試 土地行政大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1自治條例應分別冠以各該地方自治團體之名稱，依地方制度法之規定，關於地方自治規範之名稱，下列何者正確？

    1. (A) 在直轄市稱直轄市規章
    2. (B) 在縣稱縣法規
    3. (C) 在縣轄市稱市規章
    4. (D) 在鄉稱鄉規約

    正解：(D)

  2. 2依行政法人法規定，行政法人是指國家及地方自治團體以外，由中央目的事業主管機關，為執行特定公共事務，依法律設立之公法人。下列敘述何者並非其所稱特定公共事務須符合之條件？

    1. (A) 需與中央機關或地方政府辦理事項之業務有高度重疊
    2. (B) 所涉公權力行使程度較低者
    3. (C) 具有專業需求或須強化成本效益及經營效能者
    4. (D) 不適合由政府機關推動，亦不宜交由民間辦理者

    正解：(A)

  3. 3依地方制度法之規定，縣（市）政府為辦理上級機關委辦事項，依其法定職權所訂定之委辦規則與憲法牴觸者，由下列何者予以函告無效？

    1. (A) 法務部
    2. (B) 委辦機關
    3. (C) 司法院憲法法庭
    4. (D) 地方立法機關

    正解：(B)

  4. 4為保障民眾不動產交易安全，若直轄市或縣（市）擬立法規範不動產相關管理事項，對違反規定之不動產業者進行裁罰，其應以下列何種自治法規為之？

    1. (A) 自律規則
    2. (B) 委辦規則
    3. (C) 自治規則
    4. (D) 自治條例

    正解：(D)

  5. 5有關行政主體及行政機關之敘述，下列何者錯誤？

    1. (A) 行政機關，係指代表國家、地方自治團體或其他行政主體表示意思，從事公共事務，具有單獨法定地位之組織
    2. (B) 行政主體在行政法上享有權利、負擔義務，具有一定職權，且得設置機關以便行使，並實現行政上任務
    3. (C) 鄉公所以及縣政府、直轄市等都屬於行政機關
    4. (D) 國家、直轄市山地原住民區、行政法人等都屬於行政主體

    正解：(C)

  6. 6公職人員執行職務時，得因其作為或不作為，直接或間接使本人或其關係人獲取利益者，即屬於利益衝突。有關利益衝突之敘述，下列何者正確？

    1. (A) 公職人員有利益衝突者，經長官裁決後，始需迴避
    2. (B) 公職人員不得假借職務上之權力、機會或方法，圖本人之利益。但關係人之利益不在此限
    3. (C) 公職人員之關係人並非屬機關人員，故無關說、請託或以其他不當方法圖得利益之禁止問題
    4. (D) 公職人員或其關係人，皆不得與公職人員服務之機關或受其監督之機關為買賣、租賃、承攬等交易行為

    正解：(D)

  7. 7依區域計畫法之規定，違反該法第 15 條第 1 項之管制使用土地，處新臺幣 6 萬元以上 30 萬元以下罰鍰，但機關內部決定不論個案情節輕重，一律課 6 萬元罰鍰。此稱為下列何者？

    2. (B) 裁量逾越

    4. (D) 裁量濫用

  8. 8有關測量之辦理機關，下列何者錯誤？

    1. (A) 地籍測量如用航空攝影測量，應由中央地政機關統籌辦理
    2. (B) 辦理異議複丈業務，得由主管機關委任所屬登記機關辦理之
    3. (C) 基本控制測量由國土測繪法之直轄市、縣（市）主管機關辦理，加密控制測量由國土測繪法之中央主管機關辦理
    4. (D) 土地複丈及建築改良物測量之業務，由土地所在地之直轄市或縣（市）登記機關辦理

    正解：(C)

  9. 9依地籍測量實施規則規定，有關地籍調查之規定，下列敘述何者正確？

    2. (B) 共有土地之界址，經共有人過半數及其應有部分合計過半數同意者，得由共有人中一人代表指界
    3. (C) 共有土地為公寓大廈基地並設有管理委員會者，應由公寓大廈管理委員會到場指界
    4. (D) 因法院拍賣而取得之土地，尚未登記完畢者，權利人得到場指界

    正解：(D)

    4. (D) 租稅法定原則

    正解：(A)

  35. 35關於自辦市地重劃，依獎勵土地所有權人辦理市地重劃辦法所定之程序，下列何者其性質為行政處分？

    1. (A) 勘選擬辦重劃範圍
    2. (B) 核准成立重劃會
    3. (C) 召開重劃會成立大會
    4. (D) 測量、調查及地價查估

    正解：(B)

  36. 36有關行政處分之撤銷，下列敘述何者錯誤？

    1. (A) 撤銷係對違法之行政處分
    2. (B) 撤銷對公益有重大危害者，不得撤銷
    3. (C) 撤銷一律不得請求信賴利益損失補償
    4. (D) 撤銷應自原處分機關或上級機關知有撤銷原因時起 2 年內為之

    正解：(C)

  37. 37依行政程序法第 22 條規定，下列所述有行政程序之行為能力者，何者錯誤？

    1. (A) 依民法規定，有行為能力之自然人
    2. (B) 依民法規定，有意思能力之自然人
    3. (C) 行政機關由首長或其代理人、授權之人為行政程序行為者
    4. (D) 外國人依其本國法律無行政程序之行為能力，而依中華民國法律有行政程序之行為能力者，視為有行為能力

    正解：(B)

  38. 38受理訴願機關審酌事證後，認為訴願有理由，訴願機關之決定，下列何者錯誤？

    1. (A) 逕為變更之決定
    2. (B) 發回原處分機關另為處分
    3. (C) 撤銷原處分之全部或一部
    4. (D) 為不受理之決定

    正解：(D)

  39. 39依訴願法規定，訴願之決定，自收受訴願書之次日起，原則上應於幾個月內作成決定？

    1. (A) 1 個月
    2. (B) 2 個月
    3. (C) 3 個月
    4. (D) 4 個月

    正解：(C)

  40. 40土地所有權人 A 因其所有之土地被依法徵收，A 不服徵收處分而提起訴願；該土地之地上權人 B 如欲參加訴願，下列敘述何者正確？

    1. (A) B 僅是事實上之利害關係人，不得參加訴願
    2. (B) B 得以法律上利害關係人地位參加訴願
    3. (C) B 應以訴願人地位參與訴願程序
    4. (D) A 依法不得提起訴願，故 B 亦不得參與訴願

    正解：(B)

  41. 41被徵收土地所有權人對於內政部所為之徵收處分如有不服，應如何救濟？

    1. (A) 應先向主管機關提出異議，不服異議結果，始得提起訴願救濟
    2. (B) 應先向主管機關提出異議，不服異議結果，主管機關得提請地價評議委員會復議，不服復議結果者，即得提起訴願救濟
    3. (C) 得直接提起訴願救濟
    4. (D) 應先向地價評議委員會提出異議，不服異議結果，即得提起訴願救濟

    正解：(C)

  42. 42開發者依國土計畫法規定取得使用許可後，違反國土計畫法規，而主管機關疏於執行時，下列有關其爭訟之敘述，何者正確？

    1. (A) 公益團體得經一定程序後向行政法院提起訴訟
    2. (B) 公益團體得以主管機關怠於執行職務之行為向普通法院提起訴訟
    3. (C) 受害人民得依法提起撤銷訴訟
    4. (D) 受害人民得提起一般給付訴訟請求執行

    正解：(A)

  43. 43對於下列何處分不服者，依行政訴訟法規定，應以地方法院行政訴訟庭為第一審管轄法院？

    1. (A) 稅捐機關核課新臺幣 50 萬元地價稅之課稅處分
    2. (B) 縣政府核准非都市土地變更編定後，發現申請人提供不正確資料致使其依該資料作成行政處分，爰撤銷該處分
    3. (C) 縣政府對不動產估價師作出警告之懲戒處分
    4. (D) 縣政府對地政士作出停止執行業務 2 個月之懲戒處分

    正解：(C)

  44. 44土地所有權人依土地法第 69 條規定申請登記機關更正土地登記事項，經登記機關駁回。該土地所有權人不服經循序提起行政訴訟時，其應提起何種類型之訴訟？

    1. (A) 一般給付訴訟
    2. (B) 撤銷訴訟
    3. (C) 課予義務訴訟
    4. (D) 確認訴訟

    正解：(C)

  45. 45依國家賠償法之規定，有關國家賠償之請求程序，下列敘述何者錯誤？

    1. (A) 應先以書面向賠償義務機關請求
    2. (B) 賠償義務機關可不與請求權人協議，直接訴請訴訟
    3. (C) 賠償義務機關拒絕賠償，請求權人得提起損害賠償之訴
    4. (D) 損害賠償之訴，適用民事訴訟法之規定

    正解：(B)

  46. 46依國家賠償法規定，下列何種情形非屬國家賠償之成立要件？

    1. (A) 公共設施委託民間團體或個人管理時有欠缺
    2. (B) 公共設施因設置有欠缺致人民之財產受損害
    3. (C) 受託管理者已就使用自然公物為適當之警告
    4. (D) 公共設施因設置有欠缺致人民人身自由受損害

    正解：(C)

  47. 47甲所有權人在乙市的都市計畫範圍內土地採取土石，違反乙市依都市計畫法所發布之命令，乙市主管機關丙處甲罰鍰之外，並勒令其恢復原狀，甲卻拒不恢復原狀者，得按次處罰。下列敘述何者正確？

    1. (A) 丙對甲之採取行為，若予按次處罰，將違反一行為不二罰原則
    2. (B) 丙對甲之工地處所，得採取強制斷水或斷電之裁罰性行政處分
    3. (C) 若甲拒不恢復原狀後，主管機關裁處前，罰則變動為處罰額度較重者，應適用舊法予以處罰
    4. (D) 依行政罰法，罰鍰為金錢制裁，並不以故意或過失為責任要件

    正解：(C)

  48. 48下列何者非屬行政罰法所稱之行政罰？

    1. (A) 行政機關依行政執行法第 30 條規定處 5 萬元怠金
    2. (B) 行政機關依區域計畫法第 21 條規定處 6 萬元罰鍰
    3. (C) 行政機關依爆竹煙火管理條例第 32 條規定逕予沒入
    4. (D) 行政機關依營造業法第 62 條規定予以警告處分

    正解：(A)

  49. 49一行為同時觸犯刑事法律及違反行政法上義務規定者，下列敘述何者錯誤？

    1. (A) 依刑事法律處罰之
    2. (B) 如經不起訴處分、緩起訴處分確定，得依違反行政法上義務規定裁處之
    3. (C) 緩起訴處分確定且經命向公庫支付一定金額，該金額不得於行政罰鍰中扣抵
    4. (D) 經法院判決無罪確定，仍得依違反行政法上義務規定裁處之

    正解：(C)

  50. 50國土計畫法所定國土保育費之性質，為下列何者？

    1. (A) 行政規費
    2. (B) 使用規費
    3. (C) 工程受益費
    4. (D) 特別公課

    正解：(D)
