本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1基於業務性質考量，某些公務人員之任用，除適用公務人員任用法外，尚另以特別之任用或人事條例規範者，下列何者錯誤？

    2. (B) 人事人員任用條例
    3. (C) 警察人員人事條例
    4. (D) 關務人員人事條例

    正解：(B)

  2. 2下列有關我國人事機構具有幕僚單位性質的敘述，何者錯誤？

    4. (D) ①③④

  4. 4依中華民國憲法增修條文與考試院組織法之規定，下列有關考試院之敘述，何者錯誤？

    2. (B) 重新核定
    3. (C) 自始無效
    4. (D) 個案決定

    正解：(A)

  42. 42公務員服務法第 14 條常被稱為旋轉門條款，下列敘述何者正確？

    1. (A) 公務員於其離職後 3 年內，不得擔任與其離職前 5 年內之職務直接相關之營利事業董事、監察人、經理、執行業務之股東或顧問
    2. (B) 公務員於其離職後 5 年內，不得擔任與其離職前 5 年內之職務直接相關之營利事業董事、監察人、經理、執行業務之股東或顧問
    3. (C) 公務員於其離職後 3 年內，不得擔任與其離職前 3 年內之職務直接相關之營利事業董事、監察人、經理、執行業務之股東或顧問
    4. (D) 公務員於其離職後 5 年內，不得擔任與其離職前 3 年內之職務直接相關之營利事業董事、監察人、經理、執行業務之股東或顧問

    本題經考選部公告不計分。

  43. 43下列關於公務員對於保守政府機關機密事件之義務，何者正確？

    1. (A) 限於主管事務，不得洩漏
    2. (B) 無論是否為主管事務，均不得洩漏
    3. (C) 得於長官同意下，對外公開說明
    4. (D) 得於輿論壓力下，公開說明

    正解：(B)

  44. 44公務人員生雙胞胎，依公教人員保險法規定可請領幾個月的生育給付？

    3. (C) 4 個月
    4. (D) 6 個月

    2. (B) 不經言詞辯論，以判決駁回

    4. (D) 各級學校之軍訓教官

    2. (B) 監察院
    3. (C) 考試院
    4. (D) 總統府

    正解：(C)

  48. 48有關公務員懲戒法規定之免除職務處分，下列敘述何者錯誤？

    1. (A) 公務員懲戒法規定之免除職務處分與公務人員考績法規定之免職處分法律效果相當
    2. (B) 公務員懲戒法之免除職務處分有剝奪當事人憲法上應考試服公職權利之效果
    3. (C) 公務員受免除職務處分不適用公務人員保障法程序
    4. (D) 公務員受免除職務處分應經懲戒法院判決

    正解：(A)

  49. 49公務員在特定情況下，可以參加與其職務有利害關係者的飲宴應酬，但不包括下列何種活動？

    1. (A) 公務禮儀確有必要參加之活動
    2. (B) 民俗節慶公開且一般人均能參加活動

    4. (D) 因訂婚、結婚舉辦之活動，且未超過正常禮俗標準

    正解：(C)
