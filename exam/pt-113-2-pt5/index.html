物理治療師　113 年第二次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1檢查胸椎旋轉主動動作時，下列敘述何者錯誤？

    1. (A) 胸椎旋轉角度約35度到50度，是胸椎主要動作
    2. (B) 檢查主動旋轉動作時，需注意不要有肩胛骨動作的介入
    3. (C) 因為小面關節形狀的關係，上胸椎的旋轉角度比下胸椎小
    4. (D) 測試時，可請患者坐著以減少髖關節參與動作

    正解：(C)

  2. 2患者出現單側棘上窩（supraspinous fossa）局部疼痛，以及C8/T1皮節區（dermatome）出現持續轉移痛或感覺異常（paresthesia），最有可能是下列何種問題？

    1. (A) 棘上肌肌腱炎（supraspinatus tendinitis）
    2. (B) 第一肋骨症候群（first rib syndrome）
    3. (C) 第四胸椎症候群（T4 syndrome）
    4. (D) 上斜方肌肌筋膜疼痛（upper trapezius myofascial pain）

    正解：(B)

  3. 3用壓力回饋儀（pressure biofeedback unit）測試顱頸屈曲（craniocervical flexion）的動作表現，若一位年輕個案可以用正常動作達到28 mmHg之壓力數值；耐力測試時，最佳可達 24 mmHg、維持10秒、重複5次，對於深層顱頸屈肌表現的判讀為下列何者？

    1. (A) 動作表現未達正常，耐力未達正常預期值
    2. (B) 動作表現正常，耐力未達正常預期值
    3. (C) 動作表現未達正常，耐力達到正常預期值
    4. (D) 動作表現正常，耐力達到正常預期值

    正解：(B)

  4. 4有關改善顳頜關節障礙之治療建議，下列何者不恰當？

    1. (A) 腹式呼吸訓練，而非用嘴巴呼吸
    2. (B) 將舌頭輕頂於上顎的前部，顳頜關節肌肉比較不緊張
    3. (C) 矯正前位頭部姿勢（forward head posture）
    4. (D) 咬牛肉乾以訓練咀嚼肌肌耐力

    正解：(D)

  5. 5顳頜關節的關節盤脫位將產生喀啦聲（clicking），下列何組織在口部閉合時可以使關節盤穩定地緊靠著關節突（articular eminence）移動？

    1. (A) 內翼肌（medial pterygoid）內側頭
    2. (B) 內翼肌（medial pterygoid）外側頭
    3. (C) 外翼肌（lateral pterygoid）上側頭
    4. (D) 外翼肌（lateral pterygoid）下側頭

    正解：(C)

  6. 6學者伊格拉希（Iglarsh）將顳頜關節的關節盤脫位分為4個階段，下列敘述何者正確？

    1. (A) 第1階段是關節盤輕微的向後脫位，可能伴隨輕微的疼痛
    2. (B) 第2階段的喀啦（clicking）聲響僅發生在張口晚期（later on opening）
    3. (C) 第3階段的喀啦（clicking）聲響發生在張口晚期和閉口早期（earlier on closing）
    4. (D) 第4階段的關節盤已無法復位，雖沒有喀啦（clicking）聲響，但為最痛的階段

    正解：(C)

  7. 7於仰躺下測試患者右邊第一肋骨的尾向（caudal）活動度時，下列何者為較佳的擺位？

    1. (A) 屈曲頸椎，向右側彎並向左轉
    2. (B) 伸直頸椎，向右側彎並向左轉
    3. (C) 屈曲頸椎，向右側彎並向右轉
    4. (D) 伸直頸椎，向左側彎並向右轉

    正解：(A)

  8. 8針對胸椎後凸（kyphosis）過大的運動治療，下列何者錯誤？

    1. (A) 胸大肌牽張運動
    2. (B) 下斜方肌肌力訓練
    3. (C) 菱形肌牽張運動
    4. (D) 闊背肌牽張運動

    正解：(C)

  9. 9有上頸椎（C1-C2）關節障礙者，下列何種動作最常引起疼痛或可用以檢測動作受限程度？

    1. (A) 頸部屈曲到底再做旋轉
    2. (B) 頸部旋轉45度後，再低頭
    3. (C) 頸部後仰到底再做旋轉
    4. (D) 頸部旋轉45度後，再後仰

    正解：(A)

  10. 10有關咀嚼肌肉受傷的轉移痛（referred pain），下列何者正確？

    1. (A) 咬肌（masseter）在上頜骨到頭部前端區域，以及耳部上方
    2. (B) 外翼肌（lateral pterygoid）在臉頰到顳頜關節處
    3. (C) 內翼肌（medial pterygoid）在臉頰、下頜骨到頭部前端區域，以及耳部
    4. (D) 二腹肌（digastric muscle）在下頜骨後側到顳頜關節

    正解：(B)

  11. 11一位下背痛患者主訴1週前向前彎腰搬約15公斤重的工具箱時，出現下背中央疼痛及肌肉僵硬，3天後向前彎腰漱口時，背痛延伸至右邊臀部及大腿後側，平時於站立姿勢或走路時背痛較為緩解，坐姿及向前彎腰時疼痛特別明顯。近日抱怨2天前，在一次打噴嚏後，突然感覺疼痛延伸至右小腿，且患者自覺姿勢因受傷而改變，站立時呈現雙肩水平向左偏移。下列敘述何者正確？

    1. (A) 讓患者執行反覆的前彎動作測試，通常可發生症狀向中央移動（centralization）的現象
    2. (B) 讓患者直接執行反覆的向後仰腰的動作測試，可能會使疼痛強度惡化且範圍擴大
    3. (C) 先執行骨盆水平向右移動之後，再執行反覆向後仰腰的動作測試，通常可發生症狀向中央移動（centralization）的現象
    4. (D) 此患者的症狀為典型的脊椎退化（spondylosis）

    正解：(B)

  12. 12下列那些下背痛患者，站姿時症狀較惡化，前彎時症狀較緩解？①腰椎退化性關節炎 ②脊椎狹窄 ③肌肉拉傷

    1. (A) ①②③
    2. (B) 僅①②
    3. (C) 僅②③
    4. (D) 僅③

    正解：(B)

  13. 13有關腰椎相關之動態伸肌耐力測試（dynamic extensor endurance test），下列敘述何者正確？

    1. (A) 患者俯臥，上半身在床的外面且向前彎曲約30度並以椅子支撐，測試開始時，患者雙手抱胸前執行背部伸直到與骨盆和下肢呈直線，以每分鐘25下的頻率執行，計算最多可執行的次數
    2. (B) 此測試主要以等速收縮能力來評估背肌耐力
    3. (C) 測試靜態耐力表現，雙手擺放的位置有3種，在頭後為最困難，在胸前為其次，在身體兩旁為最簡單
    4. (D) 測試靜態耐力表現，患者雙手在身體兩旁，可執行背部伸直到胸骨離開床面，維持15秒，評分為poor

    正解：(A)

  14. 14有關給予屈曲導向（flexion bias）的腰椎患者牽引治療，下列敘述何者正確？

    1. (A) 牽引前將脊椎擺在屈曲姿勢，可使椎間孔空間增加
    2. (B) 針對伴隨脊椎狹窄的患者，應降低腰椎牽引力道以減少對神經根的刺激
    3. (C) 採用姿勢性牽引，病患應擺在側彎向痛側，旋轉向痛側
    4. (D) 採用姿勢性牽引，病患應擺在側彎遠離痛側，旋轉向非痛側

    正解：(A)

  15. 15下列有關腹橫肌收縮測試之敘述，何者正確？

    1. (A) 測試姿勢採平躺且雙腿伸直
    2. (B) 雙手拇指置於兩側髂嵴（iliac crest），感受腹橫肌收縮狀態
    3. (C) 受測者微縮小腹時，施測者明顯感覺到肌肉鼓起，代表腹橫肌收縮
    4. (D) 受測者微縮小腹時，施測者感到有一層薄膜拉緊感，代表腹橫肌收縮

    正解：(D)

  16. 16下背痛病人的疼痛分布於腰薦部及臀部，於久坐、久坐站起、軀幹前彎及咳嗽時增加，走路時症狀減緩，下列何項動作檢查最容易減緩此患者症狀？

    2. (B) 重複軀幹後仰
    3. (C) 閉眼單腳站立
    4. (D) 下肢神經張力檢查

    正解：(B)

  17. 17下列何者較不常出現於椎間盤退化的早期？

    1. (A) 脊椎節間的活動度增加
    2. (B) 小面關節囊發炎腫脹
    3. (C) 神經根症狀
    4. (D) 肌肉痙攣

    正解：(C)

  18. 18針對下背痛患者施予胸腰筋膜之側縫（lateral raphe）按壓時，可能鬆動的肌群為下列何者？①闊背肌②下後鋸肌 ③腹內斜肌

    1. (A) ①②③
    2. (B) 僅②③
    3. (C) 僅①③
    4. (D) 僅①②

    正解：(A)

  19. 19以X-Ray影像判讀腰椎滑脫（spondylolisthesis）之嚴重等級，應選擇下列何者？

    1. (A) 前後觀影像（anterior-posterior view）
    2. (B) 後前觀影像（posterior-anterior view）
    3. (C) 側面觀影像（lateral view）
    4. (D) 斜面觀影像（oblique view）

  20. 20有關長短腳病患兩側薦髂關節之受力變化，下列何者正確？

    1. (A) 長腳側薦髂關節剪力增加、短腳側薦髂關節壓迫增加
    2. (B) 長、短腳側之薦髂關節皆剪力增加
    3. (C) 長腳側薦髂關節壓迫增加、短腳側薦髂關節剪力增加
    4. (D) 長、短腳側之薦髂關節皆壓迫增加

    正解：(A)

  21. 21執行直膝抬腿測試檢查下肢肌群柔軟度，下列敘述何者正確？

    1. (A) 當膝關節伸直時，髖關節屈曲若達60度，即為正常
    2. (B) 此測試結果呈現陽性時，若彎曲膝關節可以增加髖關節屈曲角度，代表髖伸肌或髖關節囊太緊
    3. (C) 執行此測試過程中，若發生過多骨盆後傾的動作，會出現偽陰性測試結果
    4. (D) 腰伸肌太緊會造成骨盆後傾的姿勢，容易出現偽陽性的測試結果

    正解：(C)

  22. 22下列關於胸椎後凸相關之肩關節位置不良的敘述，何者正確？

    1. (A) 肩胛骨下轉造成肩盂上轉
    2. (B) 下垂的肱骨呈現微微外展姿勢
    3. (C) 肩關節囊上部張力因肱骨位置改變而增加
    4. (D) 肩關節旋轉肌群鬆弛

    正解：(B)

  23. 23關於脊柱側彎之身體前彎測試，下列敘述何者正確？

    1. (A) 進行測試時，結構性脊柱側彎患者會出現背部隆起（hump）
    2. (B) 進行測試時，雙手要叉腰
    3. (C) 出現的背部隆起（hump）是脊柱本身
    4. (D) 進行測試時，功能性脊柱側彎患者之凹側會出現背部隆起（hump）

  24. 24下列何者是搖擺背（swayback）最可能伴隨出現的姿勢變化？

    1. (A) 前位頭部（forward head）
    2. (B) 胸椎後凸（kyphosis）減少
    3. (C) 髖關節過度屈曲（flexion）
    4. (D) 骨盆後移（posterior shifting）

    正解：(A)

  25. 25下列有關肩關節前向不穩定的敘述，何者錯誤？

    1. (A) 前向不穩定是肩關節不穩定中最常見的
    2. (B) 班卡氏病變（Bankart lesion）是前向不穩定常見的傷害
    3. (C) 肩胛下肌撕裂也容易造成前向不穩定
    4. (D) 可用jerk test 特殊測試來檢測前向不穩定

    正解：(D)

  26. 26下列何者不是肩胛下肌的測試？

    4. (D) 熊抱測試（bear-hug test）

    正解：(B)

  27. 27下列何者與肩關節次發性夾擠（secondary impingement）的發生最不相關？

    1. (A) 肩峰鎖骨關節骨刺

    3. (C) 肩胛肱骨節律異常
    4. (D) 翼狀肩胛（scapular winging）

    正解：(A)

  28. 28患者仰躺，將兩側肩膀後伸，以肘關節撐起上半身，執行自我肩關節鬆動術（shoulder self-mobilization）的運動，有助於增加肱骨在肩關節腔內那一方向的滑動？可用以改善肩關節那一動作的活動度？

    2. (B) 向前；外轉
    3. (C) 向後；內轉
    4. (D) 向上；伸直

    正解：(B)

  29. 29有關肩旋轉肌的撕裂傷害，於接受手術修復後，影響復健進展的因素，下列何者正確？

    1. (A) 若為慢性肩夾擠造成的撕裂傷害，較急性外傷造成的撕裂傷害，其復健進度的進展更快
    2. (B) 年紀越大者復健進度的進展較快
    3. (C) 撕裂範圍越大者復健進度的進展較快
    4. (D) 修復型態為肌腱至骨頭（tendon to bone）的手術，較肌腱至肌腱（tendon to tendon）的手術，其復健進度的進展更快

    正解：(D)

  30. 30有關肩關節後向不穩定手術的術後固定姿勢，下列何者正確？

    4. (D) 稍後伸（extension）、內收、不旋轉（neutral rotation）

  31. 31肱骨骨幹骨折後，發現手腕與手指伸直肌力變弱，最可能是下列那條神經受傷？

  32. 32一位長時間於肩屈曲及內轉姿勢下進行臥推運動（bench press exercise）健身的大學生，最近開始抱怨肩關節疼痛，但無任何外傷的病史，其最有可能是下列何者所造成？

  33. 33下列有關正常肩關節的敘述，何者正確？①在額狀面上，肱骨頭與肱骨幹形成一向上夾角約135度，稱之為傾斜角（angle of inclination） ②在水平面上，肱骨頭相對於手肘內外軸之夾角約30度，稱之為前轉角（angle of anteversion） ③肩胛胸廓關節不是真正的關節，屬於功能性的關節 ④肩胛肱骨節律（scapulohumeral rhythm）是指在上臂外展動作中，肩胛與肱骨活動度比例為2：1

    1. (A) ①②③
    2. (B) ②③
    3. (C) ①②④
    4. (D) ①③

    正解：(D)

  34. 34下列關於冰凍肩之敘述，何者錯誤？

    1. (A) 女性好發率高於男生
    2. (B) 糖尿病、中風、創傷等原因造成冰凍肩是屬於原發性冰凍肩
    3. (C) 被動關節活動度測試，不同時期會有不同的終末感覺
    4. (D) 病人主動及被動活動度均受限，以外轉方向受限最大

    正解：(B)

  35. 35有關在仰躺姿勢下，檢查肩關節被動關節活動度之象限測試（quadrant test），下列敘述何者正確？

    1. (A) 手臂高舉過頭，在外轉姿勢下做肩內收動作，會在外展角度約60度時出現肘部略往前移，此時上臂會外轉，即為象限位置

    1. (A) 站在旁邊等待救護車到來，以免觸法
    2. (B) 執行CPR，以免選手心跳停止
    3. (C) 確認該選手全身各部位有無出血
    4. (D) 趕快去拿AED，以備不時之需

    正解：(C)

  73. 73下列那一項目不是短跑選手膕旁肌拉傷後，重返運動場（return to play）之標準？

    1. (A) 跑步時沒有疼痛
    2. (B) 載重弓箭步測試（weight-bearing lunge testing）為陰性
    3. (C) 運動所需的髖關節屈曲角度正常
    4. (D) 髖、膝關節肌力正常

    正解：(B)

  74. 74下列嚴重燒燙傷併發症之相關敘述，何者正確？

    1. (A) 高代謝現象會導致身體質量指數下降，使抵抗力下降
    2. (B) 感染問題常伴隨多重器官衰竭，為物理治療介入之禁忌
    3. (C) 傷後24小時後始出現心輸出下降15%的狀態
    4. (D) 高代謝現象會改變體溫調節，室內溫度應調節至低於一般舒適溫度

    正解：(A)

  75. 75關於燒燙傷復健期的敘述，下列何者錯誤？

    1. (A) 疤痕的客觀性評估可採用超音波掃描儀評估疤痕厚度
    2. (B) 疤痕的主觀性評估可採用「患者與觀察者疤痕評估量表」（Patient and Observer Scar AssessmentScale）或「渥太華疤痕評量」（Ottawa Burn Scar Assessment）
    3. (C) 復健期傷口疼痛會漸緩，取而代之的是皮膚感覺異常，最常見為搔癢感
    4. (D) 傷口位置於前頸，前胸，腋窩，容易產生疤痕攣縮，影響關節活動度

    正解：(B)

  76. 76下列針對壓瘡危險因子的解決方式，何者正確？

    1. (A) 在會陰部皮膚塗上防護軟膏，可以減輕潮濕問題所造成的壓瘡風險
    2. (B) 床頭保持低於30度，可以減輕患者因移動功能喪失所造成的壓瘡風險
    3. (C) 每2小時重新調整病人擺位，可以減輕營養不良所產生的壓瘡風險
    4. (D) 避免以拖拉方式進行床上移位，可以減輕患者因移動功能喪失所造成的壓瘡風險

    正解：(A)

  77. 77下列何者不是壓力治療（compression therapy）的禁忌症？

    1. (A) 深層靜脈栓塞（thrombosis）
    2. (B) 蜂窩性組織炎（cellulitis）
    3. (C) 急性局部感染
    4. (D) 靜脈傷口（venous wound）

    正解：(D)

  78. 78有關截肢後出現的幻肢痛（phantom limb pain）之敘述，下列何者錯誤？①可能是因截肢導致大腦的不良神經可塑性（maladaptive neuroplasticity）造成的 ②不會影響義肢穿戴和功能表現 ③可能造成永久症狀和失能的狀態 ④其病因已確認

    1. (A) ①②
    2. (B) ①③
    3. (C) ②③
    4. (D) ②④

    正解：(D)

  79. 79有關截肢術後期的處置，下列敘述何者正確？①膝下截肢患者最常出現的是膝屈曲攣縮 ②膝上截肢患者最常出現的是髖屈曲和內收攣縮 ③當膝上截肢患者平躺時，可建議在殘肢部位下使用枕頭墊高，促進血液循環 ④當膝上截肢患者長時間坐姿時，不建議在殘肢部位下使用枕頭墊高，避免關節攣縮

    1. (A) ①②
    2. (B) ③④
    3. (C) ②③
    4. (D) ①④

    正解：(D)

  80. 80有關右膝上截肢患者之義肢步態訓練，下列敘述何者錯誤？

    1. (A) 訓練目標是順暢、有效能的步態，以達到未來生活功能為目的
    2. (B) 在單腳支撐期時，義肢側不應有過多的搖擺
    3. (C) 在站立期，義肢側要執行水平面上的骨盆向前旋轉，以達到重量能傳達到整個義肢足部
    4. (D) 健側和義肢側有對稱的步長並非訓練的目標

    正解：(D)
