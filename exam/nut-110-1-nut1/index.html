營養師　110 年第一次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何種離子在正常情況下，其細胞內濃度大於細胞外？

    1. (A) 鈉
    2. (B) 鉀
    3. (C) 氯
    4. (D) 鈣

    正解：(B)

  2. 2煮菜時加味精（monosodium glutamate）促進食慾，是利用下列何種生理作用？

    1. (A) 刺激舌頭上的鮮味受器
    2. (B) 活化胃蛋白酶
    3. (C) 促進胰蛋白酶分泌
    4. (D) 由鼻腔嗅覺受器偵測

    正解：(A)

  3. 3母乳可增加嬰兒的抵抗力，嬰兒的小腸會透過下列何種方式吸收母乳中的抗體，進而產生作用？

    1. (A) 分解以提供嬰兒足夠的胺基酸
    2. (B) 合成以提供嬰兒新的補體蛋白
    3. (C) 胞吞以提供嬰兒完整的免疫蛋白
    4. (D) 中和以提供嬰兒中性的胺基酸

    正解：(C)

  4. 4下列何者是人體在營養素從腸胃道進入血液的吸收期（absorptive state）主要的能量來源？

    1. (A) 膽固醇
    2. (B) 脂肪酸
    3. (C) 胺基酸
    4. (D) 葡萄糖

    正解：(D)

  5. 5在激烈運動中，下列何種器官血流量不增反減？

    1. (A) 骨骼肌
    2. (B) 皮膚
    3. (C) 心臟
    4. (D) 大腦

    本題經考選部公告不計分。

  6. 6發炎反應（inflammatory response）中，下列何種白血球可進入受感染區域並活化成巨噬細胞（macrophages）？

    1. (A) 淋巴球（lymphocyte）
    2. (B) 單核球（monocyte）
    3. (C) 嗜中性球（neutrophil）
    4. (D) 嗜鹼性球（basophil）

    正解：(B)

  7. 7下列那一腦區主控自主神經活性？

    1. (A) 邊緣系統
    2. (B) 下視丘
    3. (C) 視丘
    4. (D) 大腦皮質頁次：4－2

    正解：(B)

  8. 8肺活量（vital capacity）的定義為下列何者？

    1. (A) 為肺部可容納的最大氣體量
    2. (B) 為平靜吸氣後，再用力吸氣所能吸入的最大氣體量
    3. (C) 為平靜呼氣後，再用力呼氣所能呼出的最大氣體量
    4. (D) 為最大吸氣後，再呼氣所能呼出的最大氣體量

    正解：(D)

  9. 9某乙為訓練有素的鉛球擲遠選手，於完美操作與複製每一次的投擲技巧的條件下，假設第一次擲遠 11 磅鉛球可達 10 米距離；倘若於接下來的第二次擲遠 25 磅鉛球需達近乎 10 米或以上的距離，則某乙的骨骼肌系統會產生什麼作用以達到此目標？

    1. (A) 延遲續發性動作電位的傳導，進而延長肌肉收縮時間
    2. (B) 延長終板電位（end-plate potential）的過極化（hyperpolarization）現象
    3. (C) 神經末端的活性區域（active zone）發生彼此融合作用
    4. (D) 會連續徵召（recruitment）更多不同的運動單位元

    正解：(D)

  10. 10關於平滑肌細胞和心肌細胞特徵的敘述，下列何者錯誤？

    1. (A) 相鄰近平滑肌細胞之間皆不具間隙連接（gap junction）
    2. (B) 相鄰近心肌細胞之間皆有間隙連接
    3. (C) 部分心肌與平滑肌細胞具有節律器電性（pacemaker activity）
    4. (D) 心肌與平滑肌細胞之收縮皆需有細胞外鈣離子參與

    正解：(A)

  11. 11聞到食物的香味時，下列何者不是引起胃酸分泌的原因？

    1. (A) 腸神經活性的增加
    2. (B) 腸類親鉻細胞（enterochromaffin-like cell）分泌的組織胺（histamine）
    3. (C) D 細胞分泌的體抑素（somatostatin）
    4. (D) G 細胞分泌的胃泌素（gastrin）

    正解：(C)

  12. 12關於腎元（nephron）的敘述，下列何者錯誤？

    1. (A) 每個腎臟約有 100 萬個腎元，是腎臟的功能單位
    2. (B) 由腎小球（renal corpuscle）和腎小管（renal tubule）所組成
    3. (C) 皮質腎元（cortical nephrons）及近髓質腎元（juxtamedullary nephrons）具有長度相同的亨利氏環（loop of Henle）
    4. (D) 近曲小管（proximal tubule）上皮細胞含有百萬微絨毛（microvilli）以增加腎小管吸收面積

    正解：(C)

  13. 13治療痛風（gout）藥物二丙磺胺苯甲酸（probenecid）可與抗生素盤尼西林（penicillin）共同使用，以促進抗生素的效果，並降低腎臟中毒（nephrotoxicity）的可能性。下列何者為其主要作用原理？

    1. (A) 可抑制腎臟對盤尼西林的過濾量
    2. (B) 可增加肝臟對盤尼西林的代謝
    3. (C) 可增加腎小管對盤尼西林的再吸收
    4. (D) 可抑制腎小管對盤尼西林的分泌

    正解：(D)

  14. 14尿素載體（urea transporters）主要表現在那一區段的腎小管？

    1. (A) 髓質部近曲小管（proximal convoluted tubule）
    2. (B) 外側髓質部亨利氏環下降枝（descending limb of the loop of Henle）
    3. (C) 內側髓質部亨利氏環上升枝（ascending limb of the loop of Henle）
    4. (D) 髓質部遠曲小管（distal convoluted tubule）

    正解：(C)

  15. 15迴腸的活動力終止是受到下列何種作用影響？

    1. (A) 續發性蠕動（secondary peristalsis）
    2. (B) 排便反射（defecation reflex）
    3. (C) 胃迴腸反射（gastroileal reflex）
    4. (D) 腸間反射（intestino-intestinal reflex）

    正解：(D)

  16. 16下列何者在懷孕時由胎盤分泌，可作用在母體脂肪細胞進行脂質分解？

    1. (A) 人類胎盤泌乳素（human placental lactogen）
    2. (B) 人類絨毛膜促性腺激素（human chorionic gonadotropin）
    3. (C) 雌二醇（estradiol）
    4. (D) 助孕酮（progesterone）

    正解：(A)

  17. 17下列何者受下視丘–腦下垂體–軸（hypothalamus-pituitary gland axis）調控分泌？

    1. (A) 醛固酮（aldosterone）
    2. (B) 皮質酮（cortisol）
    3. (C) 腎上腺素（epinephrine）
    4. (D) 副甲狀腺激素（parathyroid hormone）頁次：4－3

    正解：(B)

  18. 18心肌細胞的正常收縮，在心電圖 QRS 波至 T 波期間由胞外進入胞內的鈣離子，大部分會藉由下列何者排出至胞外？

    1. (A) 雷恩諾鹼受體（ryanodine receptor）
    2. (B) 肌漿網鈣離子幫浦（calcium ATPase pump on sarcoplasmic reticulum）
    3. (C) 鈉－鈣交換蛋白（Na+/Ca2+ antiporter）
    4. (D) L 型鈣離子通道（L-type calcium channel）

    正解：(C)

  19. 19關於光傳導（phototransduction）過程的敘述，下列何者正確？

    1. (A) 光線刺激造成 all-trans retinene 構型轉變成 11-cis retinene
    2. (B) 光色素（photopigment）活化造成轉導素（transducin）活化
    3. (C) cGMP phosphodiesterase 活化造成 GTP 轉變成 cGMP
    4. (D) cGMP 濃度下降讓 Na+/Ca2+通道打開，造成膜電位去極化

    正解：(B)

  20. 20有關過度換氣（hyperventilation），何者正確？

    1. (A) 換氣過多而導致動脈二氧化碳分壓過低
    2. (B) 換氣過多而導致動脈二氧化碳分壓過高
    3. (C) 適度運動時的換氣增加也是一種過度換氣
    4. (D) 使用完全緩和腹式呼吸法無法改善

    正解：(A)

  21. 21糖解作用代謝中，下列何者酵素催化之反應為不可逆？

    1. (A) 葡萄糖磷酸異構酶（glucose phosphate isomerase）
    2. (B) 醛醇酶（aldolase）
    3. (C) 三碳糖磷酸異構酶（triose phosphate isomerase）
    4. (D) 丙酮酸激酶（pyruvate kinase）

    正解：(D)

  22. 22酸及鹼可以使蛋白質變性，主要是因為其可破壞蛋白質之：

    1. (A) 氫鍵及肽鍵
    2. (B) 鹽橋及氫鍵
    3. (C) 肽鍵及鹽橋
    4. (D) 鹽橋及疏水性交互作用

    正解：(B)

  23. 23一位嬰兒經診斷後發現患有遺傳性 hyperammonemia，其尿液有過高 glutamine 及 creatinine 含量，該嬰兒可能是下列何種酵素失去功能？

    1. (A) Carbamoyl phosphatase
    2. (B) Ornithine transcarbamolylase
    3. (C) Argininosuccinate synthetase
    4. (D) Argininosuccinate lyase

    正解：(B)

  24. 24關於葡萄糖代謝的敘述，下列何者正確？

    1. (A) 昇糖素（glucagon）會促進肝醣合成作用
    2. (B) 糖解作用需要 NADP+
    3. (C) 經糖解作用後，葡萄糖會分解成 2-碳的物質
    4. (D) 於紅血球中，糖解作用的終產物為丙酮酸（pyruvic acid）

    正解：(D)

  25. 25關於血糖調控的敘述，下列何者錯誤？

    1. (A) 昇糖素（glucagon）可活化肝臟之糖質新生作用
    2. (B) 昇糖素（glucagon）可活化肝醣合成作用
    3. (C) 葡萄糖皮質素（glucocorticoids）可抑制肝外組織對葡萄糖的利用
    4. (D) 葡萄糖皮質素（glucocorticoids）可增強胺基酸異化作用以供應糖質新生之用

    正解：(B)

  26. 26糖解作用、肝醣合成與分解作用等，主要在細胞那一個位置發生？

    1. (A) 內質網
    2. (B) 高爾基體
    3. (C) 細胞質
    4. (D) 粒線體

    正解：(C)

  27. 27脂肪酸從細胞質進入粒線體進行 beta-氧化作用，須先轉換成醯基脂肪酸-輔酶 A（fatty acyl-CoA） ，再透過那一個轉移酶與肉鹼共價結合進入粒線體內？

    1. (A) Carnitine acyltransferase I
    2. (B) Carnitine acyltransferase II
    3. (C) Acyl-CoA：cholesterol acyltransferase（ACAT）
    4. (D) Lecithin：cholesterol acyltransferase（LCAT）

    正解：(A)

  28. 28大腦不利用脂肪酸作為能量來源的主要原因為何？

    1. (A) 大腦內缺乏氧化代謝脂肪的酵素
    2. (B) 大腦缺乏粒線體
    3. (C) 甘油無法跨越血腦障蔽
    4. (D) 脂肪酸無法跨越血腦障蔽頁次：4－4

    正解：(D)

  29. 29關於血漿中膽固醇轉移蛋白（cholesterol ester transfer protein, CETP）的敘述，下列何者錯誤？

    1. (A) CETP 是 HDL 逆向膽固醇運送的必要蛋白質
    2. (B) CETP 受抑制時，會造成血液中 HDL 濃度下降
    3. (C) CETP 是協助將 HDL 上的膽固醇酯轉移給 LDL 的重要蛋白質
    4. (D) CETP 同時可將 LDL 上三酸甘油酯轉移給 HDL，易產生體積較小與密度較高的 LDL 顆粒

    正解：(B)

  30. 30果糖主要利用何種方式進入小腸細胞？

    1. (A) active transport
    2. (B) facilitated diffusion
    3. (C) pinocytosis
    4. (D) simple diffusion

    正解：(B)

  31. 31關於胺基酸結構的敘述，下列何者正確？

    1. (A) Serine, threonine 和 leucine 屬於極性胺基酸
    2. (B) Lysine, arginine 和 histidine 屬於帶正電的胺基酸
    3. (C) Tyrosine, valine 和 tryptophan 屬於芳香族胺基酸
    4. (D) Glycine, proline 和 lysine 屬於非極性胺基酸

    正解：(B)

  32. 32若想要知道患者體內是否有新冠肺炎的病毒蛋白，可以使用那一種方式偵測？

    1. (A) 醫學影像技術
    2. (B) 酵素結合免疫吸附分析法（ELISA, Enzyme-linked immunosorbent assay）
    3. (C) 電子顯微鏡（Electron microscope）
    4. (D) 酵素動力學（Enzyme Kinetics）

    正解：(B)

  33. 33關於嘧啶（pyrimidine）分解的敘述，下列何者正確？

    1. (A) 分解之最終產物為水溶性物質
    2. (B) 分解之最終產物為尿酸（uric acid）
    3. (C) 分解異常會導致痛風性關節炎（gouty arthritis）
    4. (D) 若二氫嘧啶去氫酶（dihydropyrimidine dehydrogenase）缺乏，會導致酸尿症（aciduria）

    正解：(A)

  34. 34關於人類 DNA 的複製修補或與環境交互作用，下列敘述何者正確？

    1. (A) 遺傳物質 DNA 只存在細胞核
    2. (B) 細胞週期（cell cycle）過程中可監控 DNA 是否受損
    3. (C) 沒有修復的體細胞 DNA 突變將會垂直傳遞給下一代
    4. (D) RNA 病毒在人體可複製但不會嵌入人類染色體

    正解：(B)

  35. 35關於人類端粒（telomere）的敘述，下列何者正確？

    1. (A) 為富含 T 與 G 鹼基之重複序列
    2. (B) 出生時序列長度不到一千鹼基對（kilobases）
    3. (C) 不會被任何酵素合成的一段 DNA 序列
    4. (D) 此序列延長與癌症形成有關

    正解：(A)

  36. 36下列何者不會參與真核生物（eukaryotes）蛋白質轉譯作用（translation）？

    1. (A) GTP
    2. (B) mRNA（messenger RNA）
    3. (C) 肽基轉移酶（peptidyl transferase）
    4. (D) 50S 核糖體（ribosome）

    正解：(D)

  37. 37關於細胞色素 P450（cytochrome P450）的敘述，下列何者錯誤？

    1. (A) 結構含有血基質（heme），主要包含 monooxygenase（mixed-function oxidase）
    2. (B) 除肝臟解毒，也參與固醇類荷爾蒙生成、膽酸合成與維生素 D 活化
    3. (C) 可從 NADH 或 NADPH 接受電子
    4. (D) 分布僅限於細胞內質網

    正解：(D)

  38. 38下列何者水解所釋出的自由能（ΔG）最多？

    1. (A) ATP
    2. (B) 甘油-3-磷酸（glycerol-3-phosphate）
    3. (C) 磷酸肌酸（creatine phosphate）
    4. (D) 磷酸烯醇丙酮酸（phosphoenolpyruvate）

    正解：(D)

  39. 39酵素動力學（enzyme kinetics）無法闡明酵素的何種性質？

    1. (A) 酵素的一級結構
    2. (B) 酵素催化反應所需的輔酶
    3. (C) 酵素的反應速率和平衡常數
    4. (D) 酵素抑制劑的作用機制

    正解：(A)

  40. 40以酵素催化反應而言，相較於沒有酵素存在時，酵素約可加快多少倍數的反應速率？

    1. (A) 約 50～100 倍
    2. (B) 約 1,000～5,000 倍
    3. (C) 約 10,000～50,000 倍
    4. (D) 106 倍以上

    正解：(D)
