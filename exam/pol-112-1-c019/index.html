警察特考　112 年 四等考試 火災學概要　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1下列何者之熱傳導係數最小？

    1. (A) 銅
    2. (B) 鐵
    3. (C) 水
    4. (D) 二氧化碳

    正解：(D)

  2. 2居室空間中引發全面性燃燒，下列何者為最主要的熱傳原因？

    1. (A) 自然對流
    2. (B) 強制對流
    3. (C) 熱輻射
    4. (D) 熱傳導

    正解：(C)

  3. 3下列何種氣體，非為 INERGEN（IG541）滅火藥劑的主要成分？

    1. (A) 氮
    2. (B) 氬
    3. (C) 二氧化碳
    4. (D) 氟

    正解：(D)

  4. 4在密閉空間注入不燃性氣體，使空間氧氣之濃度降低，進而使燃燒無法持續而熄滅，此種滅火方法為：

    1. (A) 移除法
    2. (B) 冷卻法
    3. (C) 窒息法
    4. (D) 抑制法

    正解：(C)

  5. 5當 100 克的碳完全燃燒時，理論上需要大約多少立方公尺的空氣？

    1. (A) 0.9
    2. (B) 1.9
    3. (C) 2.9
    4. (D) 3.9

    正解：(A)

  6. 6植物油中，一般碘價數大者，油脂越容易氧化，起火之危險也越大。相同環境條件下，下列何者最易氧化發熱起火？

    1. (A) 亞麻仁油
    2. (B) 樟腦油
    3. (C) 葵花油
    4. (D) 花生油

    正解：(A)

  7. 7與水接觸能放出易燃性氣體的物質稱為：

    1. (A) 親水性物質
    2. (B) 禁水性物質
    3. (C) 水溶性物質
    4. (D) 自熱物質

    正解：(B)

  8. 8大樓起火後因產生煙氣溫度較外界為高，此時可能會造成大樓內部一股向上的氣流，此現象稱為：

    1. (A) 拉穿效應
    2. (B) 複燃現象
    3. (C) 閃燃現象
    4. (D) 煙囪效應

    正解：(D)

  9. 9可燃性固體之微粒子浮游於空氣中，遇到火焰或放電火花而產生爆炸之現象稱為：

    1. (A) 高壓氣體爆炸
    2. (B) 粉塵爆炸
    3. (C) 蒸氣爆炸
    4. (D) 分解爆炸

    正解：(B)

  10. 10有關熱傳導，下列敘述何者錯誤？

    1. (A) 熱傳導為熱流在固體內部傳遞的過程
    2. (B) 熱傳導對於固體表面火勢之蔓延具有影響
    3. (C) 兩個不同溫度之物體相互接觸時，熱由低溫物體流向高溫物體
    4. (D) 傳導物體的截面積越大，傳導的熱量越多

    正解：(C)

  11. 11熱透過流動介質，將熱量由一處傳到另一處的現象稱為：

    1. (A) 熱輻射
    2. (B) 熱傳導
    3. (C) 熱對流
    4. (D) 熱變化

    正解：(C)

  12. 12甲、乙輻射體的溫度分別為 1000K、250K，甲輻射體之輻射熱為乙之幾倍？

    1. (A) 4倍
    2. (B) 16 倍
    3. (C) 64 倍
    4. (D) 256 倍

    正解：(D)

  13. 13若把空氣中的氮氣換成氦氣，其對於甲烷的燃燒性質有何明顯影響？

    1. (A) 發火溫度降低
    2. (B) 燃燒上限升高
    3. (C) 燃燒範圍擴大
    4. (D) 最小發火能量升高

    正解：(D)

  14. 14可燃物如獲充分之氧氣供應，其可燃成分燃燒殆盡，稱為何種燃燒型態？

    1. (A) 定常燃燒
    2. (B) 完全燃燒
    3. (C) 蒸發燃燒
    4. (D) 均一系燃燒

    正解：(B)

  15. 15木造屋火災非完全燃燒時的產物，下列敘述何者錯誤？

    1. (A) 會產生 CO
    2. (B) 會產生水氣
    3. (C) 燃燒過程中會產生可燃性中間產物
    4. (D) 不產生 CO2

    正解：(D)

  16. 16引火源種類中，下列何者不是微火源？

    1. (A) 線香
    2. (B) 火柴燃燒
    3. (C) 熔接火花
    4. (D) 香煙

    正解：(B)

  17. 17定溫式探測器於火災發生時作動，熱主要是以何種方式傳遞？

    1. (A) 傳導熱
    2. (B) 對流熱
    3. (C) 輻射熱
    4. (D) 蒸發熱

    正解：(B)

  18. 18空氣在某一溫度下，實際所含水蒸氣量與飽和蒸氣量之比，稱為：

    1. (A) 有效濕度
    2. (B) 絕對濕度
    3. (C) 實效濕度
    4. (D) 相對濕度

    正解：(D)

  19. 19對於半斷線處，下列敘述何者錯誤？

    1. (A) 截面積增加
    2. (B) 電阻值增加
    3. (C) 易產生過熱
    4. (D) 易產生電氣火花

    正解：(A)

  20. 20有關液體之帶電，下列敘述何者正確？

    1. (A) 燈油、汽油、酒精等可燃性液體均容易產生液體帶電
    2. (B) 液體與管路、油槽壁或過濾固體表面流動摩擦所發生
    3. (C) 液體靜止中，不會因氣泡上昇或沉澱而發生靜電
    4. (D) 液體不會因流動與其他液體表面發生摩擦而發生靜電

    正解：(B)

  21. 21爆炸性物質含下列何種成分愈多，敏感性愈高？

    1. (A) 碳基（CO）
    2. (B) 硝基（NO2）
    3. (C) 氨基（NH2）
    4. (D) 硫基（SO2）

    正解：(B)

  22. 22有關建築火災 t 理論，快速火災成長係指多少秒內達到約 1MW？

    1. (A) 75 秒
    2. (B) 100 秒
    3. (C) 150 秒
    4. (D) 300 秒

    正解：(C)

  23. 23液體變化為氣體之物理現象中，若變化速度至為急速時，因能量於極短時間內釋出，即形成爆炸稱為：

    1. (A) 粉塵爆炸
    2. (B) 分解爆炸
    3. (C) 炸藥爆炸
    4. (D) 蒸氣爆炸

    正解：(D)

  24. 24盛裝液體的儲槽受熱突然破裂，導致液體迅速氣化、膨脹所引起之爆炸稱為：

    1. (A) 粉塵爆炸
    2. (B) 分解爆炸
    3. (C) 沸騰液體膨脹蒸氣爆炸
    4. (D) 水蒸氣爆炸

    正解：(C)

  25. 25有關爆炸的破壞效果，下列敘述何者錯誤？

    1. (A) 衝擊波（爆風）對物體造成的破壞效果為單方向由爆心向外
    2. (B) 對爆源附近物體造成的直接破壞效果由爆轟波的壓力決定
    3. (C) 衝擊波（爆風）可對遠距離物體造成破壞效果
    4. (D) 低壓狀態之瓦斯爆炸，破片效果（最初的破片效果）較小

    正解：(A)
