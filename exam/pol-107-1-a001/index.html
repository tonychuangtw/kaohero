警察特考　107 年 二等考試 國文　考古題與詳解

本卷共 10 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（10 題，建議 30 分鐘）

  1. 1下列「 」中的詞語，與今日口語慣用的詞義兩兩相同的選項是：

    1. (A) 風簷展書讀，古道照「顏色」／給他一點「顏色」瞧瞧
    2. (B) 「規矩」誠設，不可欺以方圓／不遵守「規矩」的人，往往令人望而生厭
    3. (C) 一日聲名遍天下，滿城「桃李」屬春官／張老師教書三十年，如今已「桃李」滿天下
    4. (D) 巍巍乎！其有成功也；煥乎！其有「文章」／閱讀好「文章」，讓人有如沐春風的感覺

    正解：(C)

  2. 2武松自到單身房裡，早有十數個一般的囚徒來看武松，說道：「好漢，你新到這裡，包裹裡若有人情的書信並使用的銀兩，取在手頭，少刻差撥到來，便可送與他，若吃殺威棒時，也打得輕。若沒人情送與他時，端的狼狽。我和你是一般犯罪的人，特地報你知道。豈不聞『 』？我們只怕你初來不省得，通你得知。」上文空缺處最適合填入的是：

    1. (A) 兔死狐悲，物傷其類
    2. (B) 皮之不存，毛將焉附
    3. (C) 城門失火，殃及池魚
    4. (D) 得道多助，失道寡助

    正解：(A)

  3. 3好主管的特質之一是懂得廣納眾言。下列歷史故事中的在上位者，何者與上述特質最為接近？

    1. (A) 西伯陰行善，諸侯皆來決平。於是虞、芮之人有獄不能決，乃如周
    2. (B) 封（諸葛）亮武鄉侯，開府治事。頃之，又領益州牧。政事無巨細，咸決於亮
    3. (C) 漢王授我上將軍印，予我數萬眾，解衣衣我，推食食我，言聽計用，故吾得以至於此
    4. (D) （文帝）每朝，郎官上書疏，未嘗不止輦受其言。言不可用，置之；言可受，採之，未嘗不稱善

    正解：(D)

  4. 4「在閱讀時，書中的圖畫與書中的文字有著相互關聯性。如果在某一個人物的傳記中有一張那個人物和一隻狗在樓梯上的圖畫，依據人類理性思考的慣用模式，讀者會將圖畫理解為對那個人的生活的描述，樓梯則被視為是背景，而那隻狗就僅僅是那個人物所擁有的寵物。也就是說，在那張圖畫中，樓梯、狗，都是次要客體，重要性次於那個人物本身。但若同樣的圖畫出現在一本雜誌的房地產廣告裡面，樓梯就會成為建築中最吸引人的部分；而若是同樣的圖畫出現在一本關於養狗的書中，書中的那張圖畫就一定是在描述那隻狗。」下列選項，何者最符合本文旨意？

    1. (A) 圖畫出現的處所影響讀者注意圖畫的方式
    2. (B) 人類慣用思考方式是文字為主，圖畫次之
    3. (C) 傳記中用人物圖畫記述人物，加強真實感
    4. (D) 書中圖畫的採用須慎選，避免與文意不合

    正解：(A)

  5. 5「一九九八年印尼海域發現『黑石號』阿拉伯沉船，有唐代長沙窯瓷碗，學者研判『黑石號』是從揚州（一說廣州）出發，滿載準備銷往西亞的中國器物，目的地是波斯灣的伊朗港口席拉夫，在行經蘇門答臘海域時撞上暗礁而沉沒。『黑石號』上來自中國南北瓷器中，還有三件用伊朗進口鈷料描繪而成的青花瓷，將過去青花瓷的生產時代上推了數百年。」下列敘述，較符合上文旨意的是：

    1. (A) 黑石號沉船因負載有鈷料的青花瓷，所以打撈艱難
    2. (B) 黑石號沉船是一趟提前結束的旅程，故未能到達阿拉伯
    3. (C) 黑石號的故事，可見人類體能挑戰自然環境壓力的危險性
    4. (D) 黑石號的故事，讓我們認識古代海上絲路與文化的交互往來

    正解：(D)

  6. 6朱自清論「說話」道：中國人對於說話的態度，最高的是忘言……。其次是慎言，寡言，訥於言。……慎言是小心說話，小心說話自然就少說話，少說話少出錯兒。寡言是說話少，是一種深沉或貞靜的性格或品德。訥於言是說不出話，是一種渾厚誠實的性格或品德。這兩種多半是生成的。第三是修辭或辭令。至誠的君子，……用不著多說話，說話也無須乎修飾。只知講究修飾，嘴邊天花亂墜，腹中矛戟森然，那是所謂小人。……我們是介在兩者之間的平凡的人，沒有那偉大的魄力，可也不至於忘掉自己。只是不能無視世故人情，我們看時候，看地方，看人，在禮貌與趣味兩個條件之下，修飾我們的說話。這兒沒有力，只有機智；真正的力不是修飾所可得的。我們所能希望的只是：說得少，說得好。下列選項與上文旨意牴觸的是：

    1. (A) 「吉人之辭寡，躁人之辭多」，可概括上文之旨
    2. (B) 真正的力不是修辭或辭令可得，而是出於真誠的情意
    3. (C) 朱自清認為平凡人應該少說多做，說太多有不真誠之嫌
    4. (D) 說話的兩個較高層次都是少言，較低層次則在批評言不由衷

    正解：(C)

  7. 7「每一個人都有往事，無論快樂或悲傷都有那一番遭遇。可是人常常把往事的境遇拿來在現在中做為索求的藉口，當他一點也沒有索求到時，他便感到痛苦。人往往如此無恥，不斷地拿往事來欺詐現在。為什麼人在每一個現在中不能企求新的生活意義呢？生命像一根燃燒的木柴，那一端的灰燼雖還具有木柴的外形，可是已不堪撫觸，也不能重燃，唯有另一端是堅實和明亮的。」文中作者對人的行為觀察和判斷，下列敘述正確的是：

    1. (A) 人不能從往事中汲取教訓
    2. (B) 人往往眷戀過往忽視目前
    3. (C) 人為挽回過去須付出代價
    4. (D) 人的生命短暫應及時行樂

    正解：(B)

  8. 8下列作品，何者描述了音樂中的情感？

    1. (A) 水調數聲持酒聽，午醉醒來愁未醒。送春春去幾時回？臨晚鏡，傷流景
    2. (B) 記出塞，黃雲堆雪。馬上離愁三萬里，望昭陽，宮殿孤鴻沒。絃解語，恨難說
    3. (C) 獨倚危檣情悄悄，遙聞妃瑟泠泠。新聲含盡古今情。曲終人不見，江上數峰青
    4. (D) 擬把疏狂圖一醉，對酒當歌，強樂還無味。衣帶漸寬終不悔，為伊消得人憔悴

    正解：(C)

  9. 9鄭經詩：「胡虜腥塵遍九州，忠臣義士懷悲愁。既無博浪子房擊，須效中流祖逖舟。故國山河盡變色，舊京宮闕化成丘。復仇雪恥知何日，不斬樓蘭誓不休。」下列選項最接近前文意旨的是：

    1. (A) 秦時明月漢時關，萬里長征人未還。但使龍城飛將在，不教胡馬度陰山
    2. (B) 力拔山兮氣蓋世。時不利兮騅不逝。騅不逝兮可奈何！虞兮虞兮奈若何
    3. (C) 烽火照西京，心中自不平。牙璋辭鳳闕，鐵騎繞龍城。雪暗凋旗畫，風多雜鼓聲。寧爲百夫長，勝作一書生
    4. (D) 靖康恥，猶未雪；臣子恨，何時滅？駕長車，踏破賀蘭山缺。壯志飢餐胡虜肉，笑談渴飲匈奴血。待從頭，收拾舊山河，朝天闕

    正解：(D)

  10. 10「今朝廷命官，既已輕任刺史、縣令，而又促數于更易。且刺史、縣令，遠者三歲一更，近者一二歲再更。故州縣之政，苟有不利於民，可以出意革去其甚者，在刺史則曰：『明日我即去，何用如此？』在縣令亦曰：『明日我即去，何用如此！』當愁醉醲，當饑飽鮮，囊帛櫝金，笑與秩終。」（孫樵〈書褒城驛壁〉）下列選項，最能傳達本文意旨的是：

    1. (A) 笑罵由他笑罵，好官我自為之
    2. (B) 用人如走馬燈，政務難有建樹
    3. (C) 清官誤國可恨，蓋因剛愎自用
    4. (D) 貪官自知有病，不敢公然為非

    正解：(B)
