營養師　109 年第一次 公共衛生營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1國民飲食指南中的「全穀根莖類」更改為「全穀雜糧類」，旨在強調未精製穀物之攝取。下列關於全穀雜糧類的敘述，何者錯誤？

    1. (A) 可提高鉀攝取量
    2. (B) 可提高維生素 D 攝取量
    3. (C) 可提高膳食纖維攝取量
    4. (D) 三餐應以穀物為主食，其中未精製穀物應占 1/3 以上

    正解：(B)

  2. 2根據國民飲食指標建議，每日飲食中「添加糖」攝取量不宜超過總攝取熱量多少百分比？

    1. (A) 5
    2. (B) 10
    3. (C) 15
    4. (D) 20

    正解：(B)

  3. 3依據第七版「國人膳食營養素參考攝取量（DRIs）」建議，婦女懷孕後增加蛋白質攝取克數何時最多？

    1. (A) 懷孕第一期
    2. (B) 懷孕第二期
    3. (C) 懷孕第三期
    4. (D) 哺乳期

    正解：(D)

  4. 4下列何種礦物質不在「國人膳食營養素參考攝取量（DRIs）」表中？

    1. (A) 鈉
    2. (B) 鋅
    3. (C) 碘
    4. (D) 硒

    正解：(A)

  5. 5下列那一項不是長期照護的國際潮流？

    1. (A) 原居養老
    2. (B) 機構式照護
    3. (C) 整合式照顧模式
    4. (D) 消費者導向之服務

    正解：(B)

  6. 6下列何者為「老化指數」之定義公式？

    1. (A) （0～14 歲＋65 歲以上人口）/（15～64 歲人口）×100%
    2. (B) （0～14 歲人口）/（15～64 歲人口）×100%
    3. (C) （65 歲以上人口）/（15～64 歲人口）×100%
    4. (D) （65 歲以上人口）/（0～14 歲人口）×100%頁次：4－2

    正解：(D)

  7. 7下列何者不符合國民中小學之「校園飲品及點心販售範圍」？

    1. (A) 鮮乳
    2. (B) 米漿
    3. (C) 保久乳
    4. (D) 加糖優酪乳

    正解：(B)

  8. 8我國目前使用的兒童生長曲線，下列敘述何者正確？

    1. (A) 0～5 歲生長曲線之訂定，乃採用世界衛生組織調查餵食母乳，並在良好健康環境兒童之生長情形
    2. (B) 5 歲以上兒童生長曲線之訂定，乃採用我國國民營養調查資料
    3. (C) 包括男孩、女孩身長（高）、體重、頭圍與胸圍等生長指標的百分位圖
    4. (D) 身長（高）、體重、頭圍與胸圍生長曲線標準圖上均有代表同年齡層之第 3、15、50、85、97百分位五條曲線

    正解：(A)

  9. 9食鹽中添加碘以預防甲狀腺腫大頗具成效，我國所添加的為何？

    1. (A) 碘酸鉀 33.3 ppm
    2. (B) 碘酸鉀 66.6 ppm
    3. (C) 碘酸鈉 33.3 ppm
    4. (D) 碘酸鈉 66.6 ppm

    正解：(A)

  10. 10考取營養師，未向當地衛生局申請執業登記，即開始團膳營養師的工作，依營養師法規定之處罰為何？

    1. (A) 沒有相關罰則
    2. (B) 處 1 萬元以上 5 萬元以下罰鍰
    3. (C) 處 3 萬元以上 15 萬元以下罰鍰
    4. (D) 處 1 個月以上 1 年以下停業處分

    正解：(B)

  11. 11依據醫事人員執業登記及繼續教育辦法第 7 條，營養師應於執業執照屆滿前幾個月內提出更新？

    1. (A) 1
    2. (B) 3
    3. (C) 6
    4. (D) 12

    正解：(C)

  12. 12下列何者可同時作為心臟和肝臟功能檢測的生化指標？

    1. (A) 肌酸激酶（creatine kinase）
    2. (B) 丙胺酸轉胺酶（glutamate pyruvate transaminase）
    3. (C) 麩胺酸轉胺酶（glutamate oxaloacetate transaminase）
    4. (D) 葡萄糖-6-磷脫氫酶（glucose-6-phosphate dehydrogenase）

    正解：(C)

  13. 13下列何者不是評估葉酸營養狀況的生化檢查？

    1. (A) Serum folate
    2. (B) Erythrocyte folate
    3. (C) Histidine loading test
    4. (D) Methionine loading test

    正解：(D)

  14. 14下列皮膚症狀與可能缺乏的營養素，何者錯誤？

    1. (A) 毛囊性表皮角化症可能是缺乏維生素 A
    2. (B) 鱗狀皮膚乾燥症可能是缺乏礦物質鋅
    3. (C) 點狀皮下出血可能是缺乏維生素 C
    4. (D) 傷口不易癒合可能是缺乏礦物質鎂

    正解：(D)

  15. 15有關主觀性整體營養評估（subjective global assessment, SGA），下列敘述何者錯誤？

    1. (A) 需了解個案近期食慾變化
    2. (B) 需了解個案腸胃症狀
    3. (C) 需了解體重變化情形
    4. (D) 需測量肌酸酐濃度

    正解：(D)

  16. 16當尿中黃尿酸（xanthurenic acid）排泄量增加時，可能為何種營養素缺乏？

    1. (A) 維生素 B1
    2. (B) 維生素 B2
    3. (C) 維生素 B6
    4. (D) 葉酸

    正解：(C)

  17. 17骨質疏鬆是重要的健康議題，關於骨質狀況檢測，下列敘述何者錯誤？

    1. (A) 「可攜式定量超音波骨密度儀」用於篩檢
    2. (B) 「可攜式定量超音波骨密度儀」可測量跟骨的骨質狀況
    3. (C) 「雙能量 X-光吸收儀」（DEXA）的檢測結果用於骨質疏鬆的臨床診斷
    4. (D) 骨質疏鬆症的判定，通常依據「雙能量 X-光吸收儀」（DEXA）檢測結果與同齡族群的 T-score比較頁次：4－3

    正解：(D)

  18. 18關於 24 小時飲食回憶法（24-hour recall method）之優缺點，下列敘述何者錯誤？

    1. (A) 可用來估算族群平均營養素攝取量
    2. (B) 屬於簡單、方便、省時、省經費的評估方法
    3. (C) 容易因調查天數增加，而使被調查者改變原有的飲食習慣
    4. (D) 需仰賴短期記憶，對於記憶力較差者（例如：老年人）較不適用

    正解：(C)

  19. 19評估幼兒的生長狀況，下列何種方法最佳？

    1. (A) 體重
    2. (B) 身高
    3. (C) 重高指數
    4. (D) 生長曲線

    正解：(D)

  20. 20下列何者可以評估短期體內蛋白質變化？

    1. (A) 前白蛋白（pre-albumin）
    2. (B) 氮平衡（nitrogen balance）
    3. (C) 視網醇結合蛋白（retinol-binding protein）
    4. (D) 肌酸酐身高指數（creatinine-height index, CHI）

    正解：(C)

  21. 21測試問卷「內部一致性」之敘述，下列何者正確？

    1. (A) 指相同問卷於不同時間點，測量不同受試者的一致性
    2. (B) 用以表示測驗分數與外在效標的符合程度
    3. (C) 可以 α 係數（Cronbach’s α coefficient）表示
    4. (D) 可解釋建構效度

    正解：(C)

  22. 22比較電話問卷調查法和面對面問卷調查法的特性，下列敘述何者錯誤？

    1. (A) 電話問卷調查法時效性較佳
    2. (B) 面對面問卷調查法較耗費人力及時間

    4. (D) 面對面問卷調查法不易取得替代樣本

    正解：(D)

  23. 23衛生機關安排乳房攝影車在各地巡迴篩檢，是考量民眾覺得到醫院不便。此與個人健康信念模式的那一個構成要素較為無關？

    3. (C) 自覺利益
    4. (D) 自我效能

  24. 24營養教育規劃，請學童繪製「多吃蔬果好處的海報」的活動，這是將下列那一個心理社會因子納入教育活動中？

    3. (C) 情緒激發（emotional arousal）
    4. (D) 預期結果（outcome expectations）

  25. 25一個 30 歲曾嘗試多次減重的個案說：「我現在對減重失去信心，我覺得我什麼都做不好，它不只影響我，也影響我的家人」，營養師回應：「雖然你現在對減重感到沮喪，你仍然擁有過去減重前的特質，如果你可以回憶起過去是什麼讓你成功改變行為的，你將可再次達到健康生活的目標」，則營養師採用的是下列何種行動反應？

    1. (A) 歸因（attributing）
    2. (B) 面質（confronting）
    3. (C) 解釋（interpreting）
    4. (D) 探問（probing）

    正解：(A)

  26. 26營養師說：「當你看到奶茶卻無法克制想買的念頭，你不妨深呼吸，告訴自己奶茶不適合我，還是喝一杯開水吧。」此時營養師所說的內容較符合下列何種諮商技巧？

  27. 27某大學營養科系，定期訪視社區安養機構，舉辦營養衛教活動。今年度的衛教內容為教導長者認識鈣質、蛋白質等營養密度高的食物，以提升長者生活品質，下列何項評估可了解此目的是否達成？

  28. 28下列社區計畫評價的敘述，何者正確？

  29. 29當使用三角檢驗法（triangulation）來進行社區需求評估時，其涵蓋的資料來源不包括下列何者？

  32. 32102～105 年國民營養健康狀況變遷調查，維生素的營養狀況，下列敘述何者錯誤？

  33. 33世界衛生組織說明非傳染病的四大危險因子包括：不健康飲食、缺乏運動、抽菸和下列何者？
