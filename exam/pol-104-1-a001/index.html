警察特考　104 年 二等考試 國文　考古題與詳解

本卷共 10 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（10 題，建議 30 分鐘）

  1. 1下列選項中「」的成語，何者使用正確？

    1. (A) 我們做事情應該實事求是，若能「自反而縮」就能光明正大而問心無愧
    2. (B) 他日行一善，助人無數，功德真是「擢髮難數」，值得大家景仰與效法
    3. (C) 許爺爺身體健朗，兒孫都是一方碩彥，成就非凡，稱得上是「福壽全歸」的代表了
    4. (D) 賈先生得到諾貝爾文學獎，只見賓客盈門，道喜之聲連連不絕，當真是「眾口鑠金」，好不熱鬧

    正解：(A)

  2. 2「扶搖直上在殷殷的風中，／效鴻鵠之志，／向寒冷的高處；／區區一線羈絆如何／牽制廣闊的追尋？／奮發而卓絕，／擁抱乾淨的天空。」（焦桐〈風箏〉）下列詩詞名句，何者最接近本詩所傳達的心境？

    1. (A) 我欲乘風歸去，又恐瓊樓玉宇，高處不勝寒
    2. (B) 盪胸生層雲，決眥入歸鳥。會當凌絕頂，一覽眾山小
    3. (C) 俱懷逸興壯思飛，欲上青天覽明月
    4. (D) 試上高峰窺皓月，偶開天眼覷紅塵，可憐身是眼中人

    正解：(C)

  3. 3李白〈春夜洛城聞笛〉：「誰家玉笛暗飛聲，散入春風滿洛城。此夜曲中聞折柳，何人不起故園情？」下列詩句何者與此詩所感嘆之情緒相近？

    1. (A) 盤飧市遠無兼味，樽酒家貧只舊醅
    2. (B) 故鄉今夜思千里，霜鬢明朝又一年
    3. (C) 柳汀斜對野人窗，零落衰條傍曉江
    4. (D) 羌笛何須怨楊柳，春風不度玉門關

    正解：(B)

  4. 4「滄浪之水清兮，可以濯吾纓；滄浪之水濁兮，可以濯吾足。」下列選項何者最接近上文意旨？

    1. (A) 寧為玉碎，不為瓦全
    2. (B) 與世推移，不滯於物
    3. (C) 鞠躬盡瘁，死而後已
    4. (D) 近朱者赤，近墨者黑

    正解：(B)

  5. 5下列何者最適宜作野臺戲戲臺的對聯：

    1. (A) 數千年間治亂興衰都歸大手筆／幾萬里中見聞考核頗費小才華
    2. (B) 綺窗似畫屏攝進滿眼詩情畫意／帷幕如玉帶牽來萬里秀水青山
    3. (C) 古往今來頃刻間已過千秋世事／天涯海角平方地可走萬里河山
    4. (D) 真豪傑無私無畏敢鋸孽龍頭角／是英雄有膽有識能拔猛虎口牙

    正解：(C)

  6. 6「單一面向的觀看往往不能察見真相。有些人常將傳統觀念視同退步落後，深入探究後始知不然。所謂進步落伍，一言斷定是不恰當的。人生代代無窮已，我們之所以得有如今，必然來自於許多前人付出的累積，並非我們只靠一己之力就忽然擁有全部了。」本文意旨與下列選項何者最相近？

    1. (A) 世間利弊相倚，禍福相生，別期望人生諸事「一稈雙穗」大祥瑞
    2. (B) 人貴在知且敬其所來自，我們最好多多去認識前人，免得誤以為所擁有的都是理所當然
    3. (C) 都市，意味著工作與受教機會，意味著生活機能，交通便捷，但是寸土寸金，居大不易
    4. (D) 生活還有另一種選擇，人在城市，心在自然原野。在滿足物質欲望的同時，還要尋找精神性的價值，以安身立命

    正解：(B)

  7. 7《周易．繫辭下》：「善不積不足以成名，惡不積不足以滅身。小人以小善為无益而弗為也，以小惡為无傷而弗去也。故惡積而不可揜，罪大而不可解。」其意與下列何者相同？

    1. (A) 為善無近名，為惡無近刑
    2. (B) 窮則獨善其身，達則兼善天下
    3. (C) 為之於未有，治之於未亂。合抱之木，生於毫末；九層之臺，起於累土；千里之行，始於足下
    4. (D) 國家將興，必有禎祥；國家將亡，必有妖孽。見乎蓍龜，動乎四體。禍福將至，善，必先知之；不善，必先知之。故至誠如神

    正解：(C)

  8. 8「唐開元中，將軍裴旻居喪，詣吳道子請於東都天宮寺畫神鬼數壁，以資冥助。道子答曰：『吾畫筆久廢，若將軍有意為吾纏結舞劍一曲，庶因猛勵以通幽冥。』旻於是脫去縗服，若常時裝束。走馬如飛，左旋右轉，揮劍入雲，高數十丈。若電光下射，旻引手執鞘承之，劍透室而入。觀者數千人，無不驚慄。道子於是援毫圖筆，颯然風起，為天下之壯觀。道子平生繪事，得意無出於此。」以下選項，何者最接近上文意旨？

    1. (A) 藉由舞劍氣勢，鍛鍊其筋肉始能作畫
    2. (B) 圍觀群眾之喝采，激勵畫家創作靈感
    3. (C) 舞劍的氣勢，與作畫之意象旁通觸發
    4. (D) 靈感的聚斂，常來自不可預知的神啟

    正解：(C)

  9. 9東坡與李端叔的一封信說得特別好：「得罪以來，深自閉塞，扁舟草屨，放浪山水間，與漁樵雜處，往往為醉人所推罵，且自喜漸不為人識。」穿著草鞋，跟漁民樵夫混雜在一起，被醉漢推罵，從名滿天下的蘇軾變成無人認識的一個世間的凡夫俗子，東坡的□□□□，正在他的被誣陷、受詬辱之後，可以「自喜漸不為人識」吧。（蔣勳〈寒食帖〉）上文中，□□□□內，最適合填入的詞語是：

    1. (A) 當頭棒喝
    2. (B) 急中生智
    3. (C) 脫胎換骨
    4. (D) 惶悚不安

    正解：(C)

  10. 10依據上文，蘇東坡「自喜漸不為人識」的心境，以下列何項說明最為貼近？

    1. (A) 千秋萬歲名，寂寞身後事
    2. (B) 但願人長久，千里共嬋娟
    3. (C) 採菊東籬下，悠然見南山
    4. (D) 理會是非遣，性達形迹忘

    正解：(D)
