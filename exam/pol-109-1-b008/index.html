警察特考　109 年 三等考試 警察情境實務　考古題與詳解

本卷共 20 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（20 題，建議 60 分鐘）

  1. 1警察執法應基於人權保障與公益公序的衡平，司法院大法官有諸多解釋與警察執法密切相關，對於司法院大法官解釋有關警察職權的解釋既屬審查「抽象規範」的成果，屢屢帶動警察法制重大變革，下列敘述何者正確？

    1. (A) 釋字第 166、251 號解釋違警罰法違反憲法第 23 條，而將之轉型為社會秩序維護法
    2. (B) 檢肅流氓條例經釋字第 385、523、631 等號解釋後，終於將該條例廢止，而制定組織犯罪防制條例
    3. (C) 集會遊行法因釋字第 454、718 號解釋而完成修法，刪除偶發性與緊急性集會遊行之申請規定
    4. (D) 釋字第 535 號解釋審查警察勤務條例臨檢規定之合憲性，促成警察職權行使法制定的臨門一腳

    正解：(D)

  2. 2你是分局偵查隊分隊長，處理一精神障礙無法完全陳述之某甲涉嫌竊盜案，下列處理程序何者錯誤？

    1. (A) 向甲進行權利告知後，經甲主動表明無須選任辯護人，且要求即時詢問，應即逕行詢問
    2. (B) 應通知甲之法定代理人、直系或三親等內旁系血親或家長、家屬為甲選任辯護人。但不能通知者，不在此限
    3. (C) 若甲未經選任辯護人，應通知法律扶助機構，指派律師到場並交付委任狀後開始詢問
    4. (D) 等候律師逾 4 小時仍未到場，得逕行詢問

    正解：(A)

  3. 3A 工廠負責人甲為感謝轄區派出所員警維護治安、交通，主動表示欲捐贈 10 臺桌上型電腦供派出所汰換老舊電腦，更新警察裝備，下列敘述何者錯誤？

    1. (A) 應先查詢 A 工廠及甲從事營業項目，不得有與警察職務或業務上有往來、監督關係或為利害關係人
    2. (B) 受贈電腦係民間捐贈財物，仍應列入機關財產登記
    3. (C) A 工廠負責人甲之捐贈活動後，應備具相關文件，向派出所所轄之直轄市、縣（市）主管機關核備
    4. (D) 因派出所電腦已足夠，且廳舍空間有限，為善用社會資源，經徵詢甲同意後，可將 3 臺電腦移轉分局偵查隊使用

    正解：(C)

  4. 4你擔任備勤時，奉令前往某餐廳處理打架滋事，到場後得知甲因酒醉與乙發生口角後，以拳頭毆打乙成傷，嗣乙於警詢中表示不願對甲提出告訴，下列敘述何者錯誤？

    1. (A) 可將甲依法實施管束
    2. (B) 將甲帶回管束時，得檢查受管束人之身體及所攜帶之物
    3. (C) 因乙不提告訴，不得依照社會秩序維護法處罰
    4. (D) 將甲帶回管束者，應開立管束通知書，告知依法可以提審

    正解：(C)

  5. 5轄區居民到派出所報案指稱，其就讀高中女兒甲（17 歲）與男網友乙外出已 2 天沒有回家，行動電話關機，音訊全無，疑被網友乙誘拐脅迫，你受理報案時，下列處置何者不適當？

    1. (A) 請報案人提供甲之照片，主動公開通報協尋
    2. (B) 甲有被誘拐脅迫之虞，受理時應實施緊急查尋
    3. (C) 過濾失蹤人甲的背景資料，以利查尋
    4. (D) 發現案件可能涉及刑案時，應立即通報刑事單位

    正解：(A)

  6. 6你擔任備勤時，奉命處理交通事故，到場後發現事故地點在私人停車場內且沒有人受傷，下列何項處置最適當？

    1. (A) 繪製現場圖並拍攝現場照片，依 A3 類交通事故成案
    2. (B) 依據各造當事人意願，協助記錄交換聯絡方式，並指導自行拍照記錄
    3. (C) 為釐清肇事經過，主動調閱私人停車場監視器以保全證據
    4. (D) 向當事人說明事故地點非屬道路範圍，為單純民事案件，警方完全不介入處理50720-51120

    正解：(B)

  7. 7據報轄區內某養生館暗藏春色，經調查蒐證後聲請搜索票執行取締，當場查獲 1 名本國籍女子及1 名以觀光名義來臺之外籍女子與男客從事性交易，下列處置何者錯誤？

    1. (A) 養生館負責人容留媒介性交易，除涉刑法妨害風化罪嫌外，另依違反就業服務法移送主管機關處理
    2. (B) 該外國女子與申請來臺目的不符，依法毋須經違反社會秩序維護法之裁處，逕送內政部移民署專勤隊處理
    3. (C) 本國女子及男客依社會秩序維護法處理
    4. (D) 該場所可運用第三方警政，報請目的事業主管機關廢止或撤銷營業登記，或斷水斷電

    正解：(B)

  8. 8甲女前來派出所報案指稱：因欲與同居男友乙分手而遭乙男毆傷，乙男並持續對其與幼女有跟蹤騷擾行為，故前來派出所求助，你受命接辦協助被害人，下列處置何者正確？

    1. (A) 請其先去驗傷，待取得診斷證明再來報案
    2. (B) 本案屬親密關係，應填寫臺灣親密關係暴力危險評估表
    3. (C) 本案非配偶關係，無法適用家庭暴力防治法聲請保護令
    4. (D) 本案屬同居關係，家庭暴力防治法之保護不及於其未成年子女

    正解：(B)

  9. 9你是派出所所長，在實施偵查犯罪時，指導所屬同仁有關通知犯罪嫌疑人到場接受詢問之處置，下列敘述何者錯誤？

    1. (A) 通知書指派員警送達者，原則上應於非例假日之日間行之
    2. (B) 通知書之送達，對於無急迫性或時效性之案件，以郵務送達方式為原則
    3. (C) 通知書應由地區警察派出所所長或其相當職務以上長官簽章，以派員或郵寄方式送達犯罪嫌疑人
    4. (D) 為調查犯罪情形及蒐集證據，得使用通知書，通知犯罪嫌疑人到場接受詢問

    正解：(C)

  10. 10你是派出所所長，接獲報案於轄區 KTV 包廂內有發生槍擊案，現場有人槍擊受傷，你帶班抵達現場，該包廂內僅剩意識昏迷之傷者。你除了呼叫救護車之外，關於該槍擊現場的調查，下列何項不在你的考慮之內？

    1. (A) 開了幾槍
    2. (B) 現場人數
    3. (C) 開槍方向
    4. (D) 槍枝價值

    正解：(D)

  11. 11你是偵查隊分隊長，率隊依法執行某公寓詐騙機房之數位證物的搜索與扣押，下列處置何者正確？

    1. (A) 要求犯罪嫌疑人說明數位證物之內容並示範操作方式
    2. (B) 複製執行程式及檔案於數位證物中，以免破壞原始資料
    3. (C) 不能整套電腦扣押，宜針對重要之設備機件實施扣押，以符合比例原則
    4. (D) 現場電腦為網路連線狀態時，擷取與案情相關之即時通訊對話紀錄、點對點分享資料

    正解：(D)

  12. 12你是偵查隊分隊長，已取得法官核發之搜索票而帶隊前往甲的住所執行毒品搜索，執行時，甲的兒子乙表示要外出上班，且恰逢甲的毒品下線丙按門鈴要找甲。此時採取下列何種作為最適當？

    1. (A) 不得封鎖甲的住所
    2. (B) 乙並非搜索目標，不得禁止其外出
    3. (C) 禁止丙進入甲的住所，並命丙離開
    4. (D) 讓丙進入甲的住所，並對其身分查證

    正解：(D)

  13. 13你執行交通稽查勤務時，發現懸掛「使」、「外」字車輛有違規行為時，下列處理程序何者錯誤？

    1. (A) 均應依法取締，與一般車輛違規處理方式相同
    2. (B) 經認定屬於嚴重危害道路交通安全者，得暫代保管車輛牌照或駕駛執照
    3. (C) 「使」、「外」字車輛享有不受侵犯之豁免權，應予適當禮遇，不宜逕行移置保管
    4. (D) 涉及肇事時，車輛應由檢警完成蒐證、勘驗後再予領回

    正解：(C)

  14. 14你帶班執行取締酒後駕車勤務，有關勤務部署階段之作為，下列何者最不適當？

    1. (A) 在稽查地點前方設置告示牌、警示燈及交通錐等警示設施
    2. (B) 在稽查地點適當位置設置攝影機，針對受測者接受檢測過程取景攝影
    3. (C) 視現場道路條件及交通流量等狀況，得設置警示、導引設施，以「縮減車道方式」進行
    4. (D) 巡邏車應停放在受檢車輛後方適當位置，為勤務人員創造安全區域50720-51120

    正解：(B)

  15. 15暑假期間，轄內部分青少年駕駛汽、機車嚴重超速、闖紅燈等違規行為頻仍，因而發生多起交通事故，你是交通分隊長，奉令加強稽查取締，並對當場不能或不宜攔截舉發者，採用非固定式科學儀器採證舉發。有關非固定式科學儀器採證違規，下列敘述何者錯誤？

    1. (A) 非固定式科學儀器採證違規之執勤地點、項目，應由機關主官核定後執行
    2. (B) 採用非固定式科學儀器取締超速或低於最低速限時，於一般道路應於 100 公尺至 300 公尺間設立明顯警示牌
    3. (C) 員警拍照採證時應著制服，但經過機關主官核准，可穿著便衣執勤
    4. (D) 採用非固定式科學儀器於高速公路取締超速行為時，應於 100 公尺至 500 公尺間設立明顯警示牌

    正解：(D)

  16. 16依憲法第 8 條第 1 項規定：「人民身體之自由應予保障。除現行犯之逮捕由法律另定外，非經司法或警察機關依法定程序，不得逮捕拘禁。非由法院依法定程序，不得審問處罰。非依法定程序之逮捕、拘禁、審問、處罰，得拒絕之。」其所稱「依法定程序」，係指凡限制人民身體自由之處置，國家機關所依據之程序，須以法律規定，其內容更須正當，始符下列何者之要求？

    1. (A) 依法行政原則
    2. (B) 正當法律程序
    3. (C) 正當行政程序
    4. (D) 一事不再理

    正解：(B)

  17. 17甲於夜間攜帶開山刀 1 把在公園內閒逛，經巡邏員警盤查，甲無正當理由，隨即將甲帶回派出所接受調查，你是派出所所長，如何指示同仁處理本案？

    1. (A) 應逕行移送地方檢察署檢察官偵辦
    2. (B) 應以書面通知甲及其指定之親友，得依法聲請提審
    3. (C) 開山刀應予扣押
    4. (D) 訊問後應立即作成處分書

    正解：(B)

  18. 18某日，派出所警員甲在值班時，有一名東南亞女子乙到派出所報案，指述其遭先生家暴，有關甲的處置，下列何者錯誤？

    1. (A) 由於乙的中文溝通能力不佳，因此評估須尋求通譯人員到派出所協助，甲除製作相關書面紀錄，並應記載協助之通譯人員姓名、聯絡電話等資料
    2. (B) 告知乙應於在臺灣地區居（停）留期限屆滿前 2 個月內檢具護照、外僑居留證、戶籍謄本及保護令等相關資料，親自或委託他人向內政部移民署各直轄市、縣（市）服務站申請延期
    3. (C) 告知外籍配偶在臺灣地區團聚及居留期間，如遭受保證人（配偶）家庭暴力，並取得法院核發保護令者，無須辦理換保手續
    4. (D) 由於乙表明相關身分證明文件無法取回，因此甲乃聯繫乙住（居）所地警察分駐（派出）所派員陪同乙取回相關資料

    正解：(B)

  19. 19你是分局偵查隊分隊長，帶領偵查隊同仁處理重大刑案現場時，有關刑案現場處理，下列敘述何者錯誤？

    1. (A) 第一位抵達重大刑案現場之員警所採取的行為，攸關案件偵查能否成功
    2. (B) 刑案現場處理，如無法避免破壞跡證時，得對現場為最大的搬動，並應確實記錄細節及其最後位置
    3. (C) 救護傷患是最先被派抵現場人員的首要任務，然在實施救護時，應儘量避免破壞現場跡證
    4. (D) 現場依救護病患、保全現場、保全證據、確認被害人、確認犯罪嫌疑人等優先順序處理

    正解：(B)

  20. 20公職人員競選活動期間，各候選人競爭劇烈，甲候選人指控乙透過夾報散發黑函，並以網際網路大量發送意圖使其不當選，下列處置何者不適宜？

    1. (A) 選舉文宣是否違法，應由選舉委員會選監小組及管轄地檢署檢察官認定
    2. (B) 發現疑似黑函文件，現場應先行蒐證，並另行查明發送人員身分
    3. (C) 在派報點發現疑似黑函夾報情事，立即查扣全部疑似黑函文件
    4. (D) 網路發送黑函，宜由甲候選人先行提告，再依網路犯罪案件偵辦

    正解：(C)
