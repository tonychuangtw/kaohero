  1. 1根據貨幣數量學說，如果明年預估的經濟成長率為 5%，物價膨脹率推估為 3%，貨幣的流通速度沒有改變下，中央銀行的貨幣成長目標應訂在：

    1. (A) -2%
    2. (B) 2%
    3. (C) 8%
    4. (D) 15%

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 由交易方程式 MV＝PY，取成長率得 %ΔM＋%ΔV＝%ΔP＋%ΔY；流通速度不變（%ΔV＝0），故 %ΔM＝3%＋5%＝8%。

    ❌ (A) −2% 是把兩個成長率相減再變號，方向與公式相反。

    ❌ (B) 2% 是 5%−3%，誤把物價膨脹當成應扣除的項目。

    ❌ (D) 15% 是 5%×3% 之類的誤算，無公式依據。

    📚 出處：貨幣數量學說（交易方程式 MV＝PY）

  2. 2根據 Tobin q 理論，下列敘述何者正確？

    1. (A) Tobin q = (建構資本市場的重置成本) / (建購資本市場的市場價值)
    2. (B) Tobin q = (建構資本市場的重置成本) / (建購資本市場的票面價值)
    3. (C) Tobin q 與資本邊際生產力、利率、折舊率有關
    4. (D) 根據 Tobin q 理論可知，如果政府採投資抵減，會抑制民間的投資

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) Tobin q＝資本的市場價值÷重置成本；而市場價值取決於資本未來收益，故 q 與資本邊際生產力、利率（折現率）及折舊率均有關。

    ❌ (A) 分子分母顛倒，q 應為市場價值除以重置成本。

    ❌ (B) 分母應為重置成本而非票面價值，且分子分母同樣顛倒。

    ❌ (D) 投資抵減降低資本的實質取得成本，會提高 q 而「促進」投資。

    📚 出處：J. Tobin q 理論

  3. 3根據 Tobin q 的投資理論，投資的決策建構在資本市場價值與重置成本的關係上，在下列何條件下企業會願意投資？

    1. (A) q > 1
    2. (B) q < 1
    3. (C) q = 0
    4. (D) q < 0

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) q＞1 表示既有資本的市場價值高於重新購置的成本，企業新增資本立即增值，故願意投資。

    ❌ (B) q＜1 時買現成企業比新建便宜，企業不會新增投資。

    ❌ (C) q＝0 表示資本毫無市場價值，更不會投資。

    ❌ (D) 市場價值與重置成本皆為正值，q 不可能為負。

    📚 出處：Tobin q 投資理論
