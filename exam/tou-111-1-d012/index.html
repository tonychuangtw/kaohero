  78. 78Когда один из пассажиров, по словам второго рассказчика, продолжал упорно нажиматькнопку вызова бортпроводника?

    2. (B) Во время турбулентности.
    3. (C) Во время посадки.
    4. (D) Во время обеда.

    正解：(B)

  79. 79Какой поступок пассажиров НЕ вызывает у сотрудников авиакомпании ненависти?

    1. (A) Их спрашивают о точном месте, которое сейчас пролетает самолет.
    2. (B) Просят дополнительную порцию еды.
    3. (C) Умоляют пересадить в бизнес-класс.
    4. (D) Просят кока-колу во время обеда.

    正解：(D)

  80. 80По какому поводу одна пассажирка весь полет ходила по проходу в рассказе третьейстюардессы?

    2. (B) У неё серьёзная головная боль.
    3. (C) У неё клаустрофобия.
    4. (D) Она хочет похудеть.
