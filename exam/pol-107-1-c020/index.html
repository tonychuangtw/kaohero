警察特考　107 年 四等考試 海巡法規概要（一般警察・水上警察人員輪機組組）　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1有關海岸巡防法第 2 條所列之用詞定義，下列敘述何者正確？

    1. (A) 海岸管制區︰指由國防部會同海岸巡防機關、經濟部根據海防實際需要，就臺灣地區海岸範圍內劃定公告之地區
    2. (B) 海岸︰指臺灣地區之海水低潮線以迄高潮線起算 500 公尺以內之岸際地區及近海沙洲
    3. (C) 海域︰指中華民國領海及鄰接區法、中華民國專屬經濟海域及大陸礁層法規定之領海、大陸礁層及專屬經濟海域
    4. (D) 臺灣地區︰指臺灣、澎湖、金門、馬祖及我國政權所及之其他地區

    正解：(B)

  2. 2有關巡防機關人員執行海岸巡防法第 4 條所定查緝走私、非法入出國事項，下列敘述何者正確？

    1. (A) 遇有急迫情形時，應於管轄區域外，逕行調查犯罪嫌疑人之犯罪情形及蒐集證據
    2. (B) 得將查緝結果，連同緝獲私貨，移送海關處理
    3. (C) 因而發現犯罪嫌疑者，得依法移送主管機關辦理
    4. (D) 必要時得於最靠近進出海岸之交通道路，實施檢查

    正解：(D)

  3. 3依據海岸巡防法第 10 條第 2 項之規定，下列何者人員非屬執行第 4 條所定犯罪調查職務時，視同刑事訴訟法第 230 條之司法警察官？

    1. (A) 薦任職
    2. (B) 上尉
    3. (C) 警監
    4. (D) 高級關務員

    正解：(C)

  4. 4依海岸巡防法規定，巡防機關掌理事項，下列何者錯誤？

    1. (A) 海岸管制區之管制及安全維護
    2. (B) 入出港船舶之安全檢查
    3. (C) 海岸查緝所有犯罪調查
    4. (D) 海洋事務研究發展

    正解：(C)

  5. 5依海岸巡防法規定，巡防機關人員執行查緝非法入出國事項，得於管轄區域外，逕行調查犯罪嫌疑人之犯罪情形及蒐集證據之情況，下列何者正確？

    3. (C) 有正當理由，認有違法之虞時
    4. (D) 遇有急迫之情形時

  6. 6巡防機關人員執行職務時，下列何者情形非屬得使用警棍指揮之時機：

    2. (B) 查緝走私

    4. (D) 指揮交通

  7. 7海岸巡防機關器械使用條例第 3 條第 2 項所稱器械之種類及規格，由何者定之？

    2. (B) 海洋委員會海巡署
    3. (C) 行政院
    4. (D) 行政院會同司法院

  8. 8依海岸巡防機關器械使用條例，巡防機關人員執行職務使用器械後之賠（補）償責任，下列敘述何者錯誤？

    1. (A) 巡防機關人員執行職務時，依本條例規定使用器械，因而致第三人受傷、死亡或財產損失者，由各該巡防機關支付醫療費、慰撫金、喪葬費或其他補償金
    2. (B) 巡防機關人員執行職務時，違反本條例使用器械之規定，因而致人受傷、死亡或財產損失者，由各該巡防機關支付醫療費、慰撫金、喪葬費或其他賠償金；其出於故意之行為，該管巡防機關應向其求償
    3. (C) 巡防機關人員執行職務依本條例規定使用器械致第三人之財產損失者，應以金錢補償其實際所受之財產損失
    4. (D) 醫療費、慰撫金、喪葬費、補償金或賠償金之標準，由行政院定之

    正解：(D)

  9. 9巡防機關人員對涉嫌走私之船舶，依法執行登臨，其抗不遵照時，得使用之器械，下列何者錯誤？

  14. 14扣押與搜索同為對物的強制處分手段，二者雖同屬干預財產權的強制手段，但扣押的權利干預效應，有時更甚於搜索。針對「扣押」，海關緝私條例係以專章規範該類強制處分之要件與程序，有關該章之內容，下列敘述何者正確？

    4. (D) 扣押之貨物或運輸工具，因解送困難或保管不易者，應由海關查封後，交其所有人、管領人或持有人具結保管，或交當地公務機關保管

    4. (D) 大陸地區

    正解：(D)

  36. 36依據臺灣地區與大陸地區人民關係條例規定大陸船舶未經許可進入臺灣地區禁止水域，主管機關對留置之大陸地區人員，經調查後，移由下列何機關強制出境？

    1. (A) 國防部
    2. (B) 內政部移民署
    3. (C) 海洋委員會海巡署
    4. (D) 行政院大陸委員會

    正解：(B)

  37. 37海洋污染防治法第 3 條所列之用詞定義，下列敘述何者正確？

    1. (A) 污染行為：指依聯合國國際海事組織所定國際海運危險品準則所認定之損害行為
    2. (B) 污染行為人：指造成污染行為之自然人、公私場所之負責人、管理人及代表人；於船舶及航空器時為所有權人、承租人、經理人及營運人等
    3. (C) 海洋棄置：指排放、溢出、洩漏廢（污）水、油、廢棄物、有害物質或其他經中央主管機關公告之物質
    4. (D) 排洩：指海洋實驗之投棄或利用船舶、航空器、海洋設施或其他設施，運送物質至海上傾倒、排洩或處置

    正解：(B)

  38. 38海洋污染防治法第 10 條所涉海洋污染事件之處理，下列敘述何者正確？

    1. (A) 為處理重大海洋污染事件，行政院環境保護署得設重大海洋污染事件處理專案小組
    2. (B) 為處理一般海洋污染事件，縣市政府得設海洋污染事件處理工作小組
    3. (C) 為處理重大海洋油污染緊急事件，中央主管機關得擬訂海洋油污染緊急應變計畫，報請行政院環境保護署核定之
    4. (D) 緊急應變計畫，應包含分工、通報系統、監測系統、訓練、設施、處理措施及其他相關事項

    正解：(D)

  39. 39海洋污染防治法第 6 章中有關防止船舶對海洋污染，下列敘述何者正確？

    1. (A) 海洋污染防治法第 26 條規定船舶得設置防止污染設備，避免污染海洋
    2. (B) 船舶對海洋環境有造成污染之虞者，港口管理機關應禁止其航行或開航
    3. (C) 港口管理機關或執行機關於必要時，應會同中央主管機關查驗我國及外國船舶之海洋污染防止證明書或證明文件、操作手冊、油、貨紀錄簿及其他經指定之文件
    4. (D) 船舶之廢（污）水、油、廢棄物或其他污染物質，除依規定得排洩於海洋者外，應留存船上或排洩於岸上收受設施

    正解：(D)

  40. 40我國漁船航行至大陸地區，應遵守之規定，下列何者錯誤？

    1. (A) 未經主管機關許可，不得航行至大陸地區
    2. (B) 不得私行運送大陸地區人民前往臺灣地區及大陸地區以外之國家
    3. (C) 不得使大陸地區人民非法進入臺灣地區
    4. (D) 違反直航大陸地區之我國漁船所有人為法人者，亦須連帶受罰，且不得作免責之抗辯

    正解：(D)

  41. 41大陸籍漁船所有人明知船長以其船舶從事載運大陸地區人民非法進入我國，且以之為主要目的者，遭查緝時，該船舶得由下列何機關沒入之？

    1. (A) 海洋委員會海巡署
    2. (B) 行政院大陸委員會
    3. (C) 行政院農業委員會漁業署
    4. (D) 交通部

    正解：(A)

  42. 42依海洋污染防治法規定，中央主管機關指定之公私場所從事油輸送行為者，應先提出足以處理海洋污染之緊急應變計畫及賠償污染損害之財務保證書。有關財務保證書之保證額度應由中央主管機關與下列何機關會商定之？

    1. (A) 財政部
    2. (B) 內政部
    3. (C) 金融監督管理委員會
    4. (D) 經濟部

    正解：(C)

  43. 43依海洋污染防治法規定，船舶之清艙，致污染海域者，船舶所有人應採取相關措施，下列何者錯誤？

    1. (A) 於施工區域周圍水面，設置攔除浮油設備
    2. (B) 於施工區內備置廢油、廢水收受設施
    3. (C) 防止廢油、廢水排洩入海
    4. (D) 其他經地方主管機關指定之措施

    正解：(D)

  44. 44針對違反海關緝私條例之「處罰」，下列敘述何者正確？

    1. (A) 依本條例規定裁處沒入之貨物或物品，不以屬受處分人所有為限
    2. (B) 船舶、航空器、車輛或其他運輸工具所載貨物，經海關查明有未列入艙口單或載貨清單者，處船長、管領人 4 千元以上 6 萬元以下罰鍰。責任歸屬貨主者，得併同處罰船長
    3. (C) 船舶、航空器、車輛或其他運輸工具，所載貨物如較艙口單或載貨清單所列者有短少時，處船長或管領人 3 萬元以下罰鍰
    4. (D) 船舶在沿海 24 海里界內，或經追緝逃出界外，將貨物或貨物有關文件毀壞或拋棄水中，以避免緝獲者，處船長及行為人各 1 萬元以上 5 萬元以下罰鍰，並得沒收該船舶

    正解：(A)

  45. 45海岸巡防機關人員使用器械時，應遵守之事項，下列敘述何者正確？

    1. (A) 應依規定一律穿著制服
    2. (B) 執行職務時得使用警棍，制止被查緝者逃亡
    3. (C) 如非情况急迫，應注意勿傷及致命部位
    4. (D) 應基於事實需要，合理使用器械，急迫時，得逾越必要程度

    正解：(C)

  46. 46外國船舶通過中華民國領海，有下列何種情形，非屬無害通過？

    1. (A) 遵守我國海洋污染防治法及其相關規定，避免造成污染
    2. (B) 船舶設置防止污染設備，並備置海洋污染防止證明書
    3. (C) 通過時，將漁具妥為收藏，未置入水中且未採捕水產植物
    4. (D) 進行測量活動

    正解：(D)

  47. 47海洋污染防治法第 7 章中有關損害賠償責任，下列敘述何者正確？

    1. (A) 船舶對海域污染產生之損害，船舶使用人應負賠償責任
    2. (B) 船舶總噸位 400 噸以上之一般船舶及總噸位 150 噸以上之油輪或化學品船，其船舶使用人應依船舶總噸位，投保責任保險或提供擔保，並不得停止或終止保險契約或提供擔保
    3. (C) 污染損害之賠償請求權人，得直接向責任保險人請求賠償或就擔保求償之
    4. (D) 外國船舶因違反本法所生之損害賠償責任，雖未履行或有不履行之虞，然基於公民與政治權利國際公約第 12 條「人人進入其本國之權，不得無理褫奪」，港口管理機關亦不得限制船舶及相關船員離境

    正解：(C)

  48. 48依海岸巡防機關器械使用條例巡防機關人員執行船舶安全檢查，遭遇攻擊時，依法得使用下列何種器械？

    1. (A) 警棍
    2. (B) 手銬
    3. (C) 槍
    4. (D) 煙霧彈

    正解：(B)

  49. 49有關海關緝私條例第 2 條至第 5 條所列之用詞定義，下列敘述何者正確？

    1. (A) 稱通商口岸，謂民間對外貿易之港口、機場或商埠
    2. (B) 稱私運貨物進口、出口，謂規避檢查、偷漏關稅或逃避管制，未經向海關申報而運輸貨物進、出國境
    3. (C) 稱報運貨物進口、出口，謂依關稅法及有關法令規定，向港務公司申報貨物，經由通商口岸進口或出口
    4. (D) 依本條例所處罰鍰以貨價為準者，進口貨物按離岸價格計算，出口貨物按完稅價格計算

    正解：(B)

  50. 50有關海岸巡防法第 5 條第 1 項規範巡防機關人員職權之行使，下列敘述何者錯誤？

    1. (A) 有正當理由，認乘載人員有嚴重不法之虞時，即得以武力令其配合回航
    2. (B) 對航行海域內之船舶，有正當理由，認有違法之虞時，即得命船舶出示航海紀錄
    3. (C) 對進出海域之船舶及其載運人員、物品，有正當理由，認有違法之虞時，即得依法實施檢查
    4. (D) 對進出通商口岸之人員，有正當理由，認有違反安全法令之虞時，即得依法實施安全檢查

    正解：(A)
