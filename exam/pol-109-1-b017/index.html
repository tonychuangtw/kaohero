警察特考　109 年 三等考試 犯罪偵查　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1刑案知識庫資料運用之敘述，下列何者錯誤？

    1. (A) 知識庫突破以往文字敘述方式，改以流程圖詮釋刑案流程，使用者可以了解處理階段並可進一步瀏覽詳細資料
    2. (B) 提供多重條件邏輯運算之全文智慧檢索功能，並配合相關字詞運用，提供更為寬廣及靈活運用之查詢方式
    3. (C) 知識庫提供兩種查詢角度，其一「以人查案」係鎖定案件類型後，系統會列出符合案件之所有刑案或嫌疑人資料
    4. (D) 刑案知識庫資料運用相當廣泛，舉凡查贓資訊、應受尿液採驗、ｅ化報案、刑事犯罪資料網站、國人出入境等

    正解：(C)

  2. 2觀察屍體外部變化可推斷死亡時間的方法中，下列何者不包含在內？

    1. (A) 屍體痙攣
    2. (B) 屍體溫度
    3. (C) 屍斑
    4. (D) 死後僵硬

    正解：(A)

  3. 3現場勘察應遵循之步驟，下列何者錯誤？

    1. (A) 從戶外逐步勘察至戶內現場中心
    2. (B) 由近而遠，以現場為中心，向外延伸，由點而線，由平面至立體
    3. (C) 由天花板開始勘察，依次是牆壁、窗、門，而後及於地面
    4. (D) 由明顯者先行勘察，再逐步搜查潛伏之跡證

    正解：(C)

  4. 4依據內政部警政署訂頒之警察偵查犯罪手冊之規定，有關司法警察人員現場封鎖，下列敘述何者錯誤？

    1. (A) 實施犯罪調查，必要時得封鎖犯罪現場，並為即時之勘驗
    2. (B) 實施犯罪現場封鎖時，應派員於封鎖線外警戒，非經現場指揮官同意，任何人不得進入
    3. (C) 實施犯罪現場封鎖時，現場警戒人員，應觀察圍觀群眾之可疑動靜，蒐集有利破案之情報線索，必要時得以錄影方式為之
    4. (D) 犯罪現場封鎖範圍及層數，原則上以三道（層）封鎖線為準，但應視現場環境及事實需要而定

    正解：(A)

  5. 5關於案情研判，下列敘述何者錯誤？

    1. (A) 應以調查、訪問、觀察、搜索及現場勘察等資料為依據
    2. (B) 應先找出問題或爭議點，假設各種狀況，尋求合理、正確的答案
    3. (C) 案件性質的研判如果錯誤，一切偵查行動將落空
    4. (D) 旨在了解犯罪嫌疑人的犯罪成因、類型及模式

    正解：(D)

  6. 6有關偵訊工作，下列敘述何者正確？

    1. (A) 製作筆錄，以脅迫、利誘、詐欺或其他不正當方法詢問，最為有效
    2. (B) 偵訊室內部裝設應力求簡樸，除了必須用品外，玻璃杯、煙灰缸、大頭針或其他危險物均不得放置
    3. (C) 筆錄製作完成後，重新詢問並要求受詢問人照筆錄朗讀再予以錄音
    4. (D) 筆錄製作完成後，擺在辦公桌上任由同事或記者翻閱

    正解：(B)

  7. 7有關逮捕拘提人犯戒護注意事項，下列何者錯誤？

    1. (A) 現行犯必要時一定要上戒具，最好設鐵欄杆銬住，亦可銬住椅子，以防偷襲或偷逃
    2. (B) 人犯上廁所戒護時要盯著看，保持在目視範圍內，不要有不好意思看之心態
    3. (C) 重刑犯一律戴上安全帽以防止其有自殺之行為
    4. (D) 長途押解人犯在車內以反銬為宜，防範人犯勒住駕駛頸部，趁機脫逃

    正解：(A)

  8. 8有關「現場勘察與搜尋」，下列敘述何者錯誤？

    1. (A) 現場勘察與搜尋係針對有形、可用肉眼觀察的，不包括無形的、潛在的、肉眼看不見的跡證
    2. (B) 戶外犯罪現場比戶內更易於受到污染，所以必須掌握蒐證時效
    3. (C) 戶外犯罪現場勘察應儘量避免於夜間進行
    4. (D) 現場的搜尋可彈性施以兩種以上之搜尋方式，也要兼顧視線高度之搜尋，物證或許位於頭部以上的位置

    正解：(A)

  9. 9關於「地緣剖繪技術」之敘述，下列何者錯誤？

    1. (A) 地緣剖繪技術主要用來預測犯罪者可能的住處和再次犯罪的地區，前者有助於犯罪偵查，後者有助於犯罪預防
    2. (B) 本項技術適用於連續性的犯罪，例如性侵害、縱火和爆炸事件，再結合資料庫偵查技術過濾清查，進而鎖定犯嫌
    3. (C) 地緣剖繪除對靜態的犯罪時間、地點進行統計分析外，如能結合犯罪者的心理剖繪，將會使結果更加正確
    4. (D) 犯罪者以住家為中心向外擴散犯罪，距離住家愈遠，犯罪案件數愈多

    正解：(D)

  10. 10關於合法通訊監察之聲請作業，下列敘述何者錯誤？

    1. (A) 偵查人員為偵辦通訊保障法案件經所屬機關首長核准後，逕向法院聲請通訊監察書
    2. (B) 法院核准後，由執行人員持通訊監察書及登記表，至各警察局刑警大隊通訊監察組投單
    3. (C) 通訊監察組審核確認符合後，透過「投單作業管理系統」上傳通訊監察書至刑事警察局通訊監察科（或調查局）
    4. (D) 刑事警察局（或調查局）審核確認通訊監察書核准之監察門號無誤後，始設定上線監察

    正解：(A)

  11. 11GPS 衛星定位與追蹤器運用於犯罪偵查，下列敘述何者錯誤？

    1. (A) 將電子追蹤器置於欲追蹤對象的車輛、身上或擄人勒索的交款袋，避免偵查行動曝光，降低人員危險及破案難度
    2. (B) 船舶追蹤器，漁船出港後通常數日至數週，無從更換電池，多以鋰電池作為電力來源
    3. (C) 將汽車追蹤發射器安裝於車輛底盤，再撥接追蹤器內行動電話，透過衛星定位系統，將監視狀況顯示電子地圖上
    4. (D) 全球衛星定位系統如有可能進入並探測他人封閉生活領域事物，或者跟監時日過久，宜由法院授權後為之

    正解：(B)

  12. 12有關「刑案現場攝影」之敘述，下列何者錯誤？

    1. (A) 現場當受傷者因緊急救護需移動身體時，仍應先行攝影記錄受傷者之原始狀態，並將移動情形記錄在筆記
    2. (B) 刑案現場攝影在景物效果上特別強調真實性與完整性
    3. (C) 刑案現場攝影，應多使用廣角或望遠鏡頭拍攝現場全貌
    4. (D) 以遠、中、近距離的拍攝程序，將現場與各物證間作連結以顯示其相對位置，以確保物證的證據能力

    正解：(C)

  13. 13有關刑案現場之「物證」，下列敘述何者錯誤？

    1. (A) 許多罪犯在作案之行為時，有一定之犯行特徵，物證即可幫助了解其犯罪模式
    2. (B) 刑案現場，對於物證的紀錄方式僅有筆記及現場描繪兩種
    3. (C) 為確保日後之鑑定工作不生混淆，所有物證均必須作適當標記
    4. (D) 每項物證之適當包裝方式，全依證物之類型而定，絕不可以將不同物證裝在一個包裝袋，以免造成污染

    正解：(B)

  14. 14有關「陷害教唆」和「誘捕偵查」之敘述，下列何者錯誤？

    1. (A) 陷害教唆，係指行為人原不具犯罪之故意，純因警察之設計教唆，使萌生犯意，而實行犯罪構成要件之行為者
    2. (B) 提供機會型誘捕，係指行為人原本即有犯罪之意思，其從事犯罪構成要件行為之犯意，並非他人所創造
    3. (C) 國家機關誘捕偵查作為是否合於正當法律程序，應考量有無法律依據或事前監督、事後審查機制
    4. (D) 刑事偵查技術上所謂之「釣魚偵查」，依此方式所蒐集之證據資料，不具證據能力

    正解：(D)

  15. 15通訊監察對第三人之秘密通訊自由形成侵害，於是在通訊保障及監察法訂定幾項原則加以制約，下列何者錯誤？

    1. (A) 無令狀原則
    2. (B) 最後手段原則
    3. (C) 重罪原則
    4. (D) 期間限制原則

    正解：(A)

  16. 16依偵查不公開作業辦法規定，有關「偵查不公開」之敘述，下列何者錯誤？

    1. (A) 偵查不公開，包括偵查程序、內容及所得之心證均不公開
    2. (B) 有關勘驗、現場模擬或鑑定之詳細時程及計畫，不得公開或揭露之
    3. (C) 偵查機關及偵查輔助機關首長，應指定該機關有關人員 3 至 5 人，組成偵查不公開檢討小組
    4. (D) 影響社會大眾生命、身體、自由、財產之安全，有告知民眾注意防範之必要，仍不得公開或揭露資訊

    正解：(D)

  17. 17有關「管束」之敘述，下列何者錯誤？

    1. (A) 意圖自殺，非管束不能救護其生命
    2. (B) 暴行或鬥毆，非管束不能預防其傷害
    3. (C) 警察依規定管束時，得檢查受管束人之身體及所攜帶之物
    4. (D) 管束時間最長不得逾 48 小時

    正解：(D)

  18. 18依通訊保障及監察法規定，公務員或曾任公務員之人無故洩漏或交付監察通訊所得應秘密之資料，處幾年以下有期徒刑？

    1. (A) 1年
    2. (B) 3年
    3. (C) 5年
    4. (D) 10 年

    正解：(B)

  19. 19司法警察官或司法警察詢問犯罪嫌疑人，不得於夜間行之，其例外情形之敘述，下列何者錯誤？

    1. (A) 經受詢問人暗示同意者
    2. (B) 於夜間經拘提或逮捕到場而查驗其人有無錯誤者
    3. (C) 經檢察官或法官許可者
    4. (D) 有急迫之情形者

    正解：(A)

  20. 20司法警察雖無搜索票，逕行搜索被告、犯罪嫌疑人之住宅或其他處所，應於執行後多少天內報告該管檢察官及法院？

    1. (A) 1日
    2. (B) 2日
    3. (C) 3日
    4. (D) 5日

    正解：(C)

  21. 21徒步跟蹤人員應防止被察覺，如遇不利情況時，應採取因應作為，下列敘述何者錯誤？

    1. (A) 對象在行進間突然停止，轉身反顧，或反身往回頭走，執行人員應保持自然行走，並視情況通知其他人員跟蹤
    2. (B) 對象搭乘大眾交通工具，僅乘坐一段即下車，試探執行人員有何行動，執行人員應儘量避免與其正面接觸
    3. (C) 對象突然進入建築物，經由另一出口或後門溜走，誤導並發覺執行人員跟監，執行人員應視狀況繼續跟蹤
    4. (D) 對象製造突發事故，陷執行人員不利時，應設法儘速撤離，必要時得表明身分及採取反擊動作

    正解：(C)

  22. 22依據內政部警政署訂頒之警察偵查犯罪手冊與刑事鑑識手冊規定，有關司法警察人員勘察採證之規範，下列敘述何者正確？

    1. (A) 勘察採證，現場應依任務需要，除擔任警戒任務者外，將現有人員區分為偵查組與調查組
    2. (B) 勘察採證之偵查組，得由資深之偵查人員擔任組長，勘察採證之調查組，得由資深之鑑識人員擔任組長
    3. (C) 遇有可疑為非病死案件，應報請該管檢察官及法醫實施勘驗
    4. (D) 勘察爆裂物爆炸現場時，應會同刑事警察局爆裂物處理人員處理

    正解：(D)

  23. 23依據警察偵查犯罪手冊規定，有關司法警察機關執行刑案現場查訪及調查，下列敘述何者正確？

    1. (A) 重大刑案之現場指揮官，由管轄警察局局長或其代理人擔任
    2. (B) 重大刑案之現場，由管轄警察分局偵查隊長或其代理人督同所屬人員負責現場搜索及證物保全
    3. (C) 重大刑案之現場，由管轄警察局刑警大隊大隊長、鑑識中心主任、鑑識科科長或其代理人督同所屬人員負責現場調查及勘察採證
    4. (D) 重大刑案之現場，由管轄警察分局長或其代理人督同所屬人員負責現場搜索及現場調查

    正解：(C)

  24. 24依據警察偵查犯罪手冊規定，重大刑案發生除立即偵破外，均應訂定偵查計畫。有關偵查計畫之內容，下列敘述何者錯誤？

    1. (A) 應包括犯罪發生或發現之時間、地點、發現經過或受理報案經過
    2. (B) 應包括勘察搜索環境、擬訂搜索任務、步驟、決定搜索時間、地點、對象
    3. (C) 應包括現場勘察情形（含跡證鑑定情形）
    4. (D) 應包括偵查實施及分工

    正解：(B)

  25. 25司法警察（官）因偵查殺人棄屍案件之需要，以證人身分依法通知詢問證人甲，於警詢過程中，根據證人甲之供稱，發現證人甲涉有本宗殺人棄屍共犯之重嫌。依據內政部警政署訂頒之警察偵查犯罪手冊之規定，下列敘述何者正確？

    1. (A) 應將甲改列犯罪嫌疑人身分，告知緣由及相關權利事項後，針對其涉犯之部分續行警詢，並製作犯罪嫌疑人之警詢筆錄
    2. (B) 應將甲維持證人身分，針對其涉犯之供述內容續行警詢，並製作證人之警詢筆錄
    3. (C) 應將甲改列犯罪嫌疑人身分，告知緣由及相關權利事項，必要時應徵得甲之同意後，針對其涉犯之部分重新詢問，並製作犯罪嫌疑人之警詢筆錄
    4. (D) 應將甲並列證人及犯罪嫌疑人身分，續行警詢，針對其供述內容是否涉及其本身涉犯部分之不同，分別製作證人及犯罪嫌疑人之警詢筆錄

    正解：(C)

  26. 26依據刑事訴訟法及警察偵查犯罪手冊規定，有關偵查中之辯護人於司法警察官或司法警察詢問犯罪嫌疑人時之權限，在不違反偵查不公開原則及不影響偵查秩序者，下列敘述何者錯誤？

    1. (A) 偵查辯護人得於詢問時在場陳述意見
    2. (B) 偵查辯護人得於詢問時以手寫方式札記詢問要點
    3. (C) 偵查辯護人得於詢問完畢後檢閱卷宗資料
    4. (D) 偵查辯護人得於詢問完畢後協助犯罪嫌疑人閱覽筆錄

    正解：(C)

  27. 27依據刑事訴訟法之規定與最高法院及內政部警政署之實務見解，下列何者非屬強制偵查？

    1. (A) 鑑定
    2. (B) 相驗
    3. (C) 勘驗
    4. (D) 勘察

    正解：(D)

  28. 28司法警察（官）甲任職於某縣市警察局刑警大隊第 A 偵查隊（簡稱刑大偵 A 隊），因偵查網路詐欺集團刑事案件之需要，擬聲請通訊監察該網路詐欺集團之相關共犯。依據通訊保障及監察法與內政部警政署訂頒之警察偵查犯罪手冊之規定，下列敘述何者正確？

    1. (A) 網路詐欺犯罪非屬得通訊監察之犯罪，不得聲請通訊監察該網路詐欺集團之相關共犯
    2. (B) 辦理通訊監察聲請案件，得由該刑大偵 A 隊隊長從嚴審核決行後，備文逕向該管檢察署檢察官提出聲請
    3. (C) 辦理通訊監察聲請案件，得由該刑大偵 A 隊隊長從嚴審核決行後，備文逕向該管地方法院法官提出聲請
    4. (D) 辦理通訊監察聲請案件，其聲請因不合法定程序，經法院駁回者，不得聲明不服

    正解：(D)

  29. 29依據警察偵查犯罪手冊規定，有關司法警察人員偵查刑案移送遞解之規範，下列敘述何者正確？

    1. (A) 犯罪證據不明確，但被害人堅持提出告訴者，應將案件移送檢察署
    2. (B) 行為事實是否構成犯罪顯有疑義者，應將案件移送檢察署
    3. (C) 全案經調查完畢，認有犯罪嫌疑者，得將案件函送檢察署
    4. (D) 告訴乃論案件，尚未調查完竣，而告訴權人已向檢察官告訴者，得將案件函送檢察署

    正解：(D)

  30. 30依據少年事件處理法與警察偵查犯罪手冊規定，司法警察（官）處理少年刑事案件而詢問涉犯少年時，司法警察（官）於詢問涉犯少年前，依法令應先向涉犯少年履行告知義務。有關告知義務應先告知之事項，下列敘述何者錯誤？

    1. (A) 應先告知其所涉之觸犯刑罰法律事實及法條或有少年事件處理法第 3 條第 1 項第 2 款各目事由
    2. (B) 得保持緘默，無須違背自己之意思而為陳述
    3. (C) 得請求調查有利之證據
    4. (D) 得選任律師為辯護人，如依法令得請求法律扶助者，得請求之

    正解：(D)

  31. 31依據警察偵查犯罪手冊規定，有關網路犯罪案件之搜索計畫內容，下列敘述何者錯誤？

    1. (A) 應包括現場狀況，如勘察現場、畫現場圖、載明現場人數
    2. (B) 應包括搜索項目，如擬訂搜索項目、標的
    3. (C) 應包括搜索任務，如搜索何種犯罪型態網站
    4. (D) 應包括決定搜索之時間、地點、對象

    正解：(D)

  32. 32依據刑事鑑識手冊規定，有關各種刑事鑑識工作項目之分類，下列敘述何者正確？

    1. (A) 人體體液內酒精濃度之鑑定，係屬生物鑑識工作項目
    2. (B) 毒品之鑑定，係屬微物鑑識工作項目
    3. (C) 重大刑案現場勘察與重建，係屬綜合鑑識工作項目
    4. (D) 工具痕跡之鑑定，係屬化學鑑識工作項目

    正解：(C)

  33. 33依據刑事鑑識手冊規定，有關刑案現場初步處理，下列敘述何者錯誤？

    1. (A) 現場為室內時，應注意犯罪嫌疑人進入和逃離現場之路線及方法
    2. (B) 注意犯罪嫌疑人是否藏匿於現場或混雜於圍觀群眾中
    3. (C) 實施刑案現場保全，應視案件情況及人員裝備，立即實施現場封鎖，必要時派員於封鎖線外警戒
    4. (D) 採集各類跡證，避免污染，並掌握時效，送請警察局鑑識中心、鑑識（課）或相關單位鑑定

    正解：(D)

  34. 34依據刑事鑑識手冊規定，有關司法警察機關現場勘察人員對於車輛實施勘察採證，下列敘述何者錯誤？

    1. (A) 原則上應用搜索票或鑑定許可書
    2. (B) 出於自願性同意者，無須聲請搜索票或鑑定許可書，但應使用勘察採證同意書
    3. (C) 有急迫情形者，應報請檢察官指揮實施勘察採證
    4. (D) 必要時得先逕行實施勘察採證，實施完畢後 3 日內陳報檢察官補行審查

    正解：(D)

  35. 35依據刑事鑑識手冊規定，有關司法警察機關執行去氧核醣核酸採樣條例強制採樣之程序，下列敘述何者正確？

    1. (A) 執行採樣前，應先取得檢察官核發之鑑定許可書
    2. (B) 執行採樣時，應優先採取毛髮樣本，其次為唾液樣本，再其次為血液樣本
    3. (C) 執行採樣時，唾液及毛髮樣本得由司法警察（官）執行採取，血液樣本應由刑事鑑識人員執行採取
    4. (D) 執行採樣完畢後，執行採樣機關應製作採樣證明書發給被採樣人

    正解：(D)

  36. 36依據最高法院 99 年度台上字第 6278 號刑事判決之見解，有關司法警察機關因調查犯罪情形之必要，通知犯罪嫌疑人到場實施警詢，下列敘述何者正確？

    1. (A) 該約談通知係屬強制處分
    2. (B) 該約談通知應使用約談通知書，不得臨時使用電話通知
    3. (C) 該約談通知書應於命到場前 24 小時送達
    4. (D) 犯罪嫌疑人經合法通知，無正當理由不到場者，得逕行拘提

    正解：(A)

  37. 37依據刑事訴訟法規定，有關拘束人身自由之強制處分，下列敘述何者正確？

    1. (A) 拘提有「有令狀之強制處分」與「無令狀之強制處分」之分，逮捕係屬「無令狀之強制處分」
    2. (B) 拘提與逮捕均分別各有「有令狀之強制處分」與「無令狀之強制處分」之分
    3. (C) 拘提係屬「有令狀之強制處分」，逮捕係屬「無令狀之強制處分」
    4. (D) 刑事訴訟法第 76 條、刑事訴訟法第 88 條之 1 均屬「無令狀之強制處分」

    正解：(C)

  38. 38依據刑事訴訟法規定，司法警察官或司法警察因偵查犯罪之需要，依法通知證人甲實施警詢時，下列敘述何者錯誤？

    1. (A) 證人不能到場，得於聽取當事人及辯護人之意見後，就證人之所在地詢問之
    2. (B) 證人之所在地與本案承辦之司法警察機關間有聲音及影像相互傳送之科技設備而得直接詢問，經該司法警察機關認為適當者，得以該設備詢問之
    3. (C) 當事人及辯護人得於警詢證人時在場並得詰問之
    4. (D) 證人恐因陳述致自己受刑事追訴或處罰者，得拒絕證言

    正解：(B)

  39. 39依據刑事訴訟法規定，有關偵查中之程序規範，下列敘述何者正確？

    1. (A) 搜索票應由檢察官核發，拘票應由檢察官核發，鑑定留置票應由法官核發，鑑定許可書應由法官核發
    2. (B) 搜索票應由法官核發，拘票應由檢察官核發，鑑定留置票應由檢察官核發，鑑定許可書應由法官核發
    3. (C) 搜索票應由法官核發，拘票應由法官核發，鑑定留置票應由檢察官核發，鑑定許可書應由檢察官核發
    4. (D) 搜索票應由法官核發，拘票應由檢察官核發，鑑定留置票應由法官核發，鑑定許可書應由檢察官核發

    正解：(D)

  40. 40依據刑事訴訟法規定，有關鑑定留置之規範，下列敘述何者錯誤？

    1. (A) 鑑定留置，原則上應用鑑定留置票，偵查中由該管檢察官核發，審判中由管轄法院核發
    2. (B) 被告抗拒鑑定留置者，得使用強制力，但不得逾必要之程度
    3. (C) 被告如經合法逮捕到場，其期間未逾 24 小時，而有鑑定留置之必要者，得不使用鑑定留置票
    4. (D) 因鑑定被告心神或身體之必要，得預定 7 日以下之期間，將被告送入醫院或其他適當之處所

    正解：(A)

  41. 41依據刑事訴訟法、警察偵查犯罪手冊與刑事鑑識手冊相關規定，有關司法警察人員對於住宅實施勘察採證，實施勘察採證前，應先取得勘察採證標的權利人之同意，如勘察採證標的權利人不同意時，現場指揮官如仍認有實施之必要者，下列敘述何者錯誤？

    1. (A) 得改以報請警察局局長核可實施證據保全方式為之
    2. (B) 得改以報請該管檢察官實施現地勘驗方式為之
    3. (C) 得改以報請該管檢察官核發鑑定許可書方式為之
    4. (D) 得改以聲請核發搜索票，依令狀搜索或扣押方式為之

    正解：(A)

  42. 42依據刑事訴訟法規定，司法警察官或司法警察因偵查案件之必要，擬採檢被告口腔內之假牙，俾益鑑定比對後以資作為證據資料使用。有關採檢被告口腔內假牙之措施，下列敘述何者正確？

    2. (B) 應依據刑事訴訟法第 205 條之 1 之鑑定規定
    3. (C) 應依據刑事訴訟法第 205 條之 2 之鑑定規定
    4. (D) 應依據刑事訴訟法第 213 條之勘驗規定

    正解：(B)

  43. 43依據警察機關實施指認犯罪嫌疑人注意事項規定，有關警察機關實施指認犯罪嫌疑人之程序，下列敘述何者正確？

    1. (A) 實施指認犯罪嫌疑人程序時，原則上應全程連續錄音，必要時全程連續錄影
    2. (B) 實施指認犯罪嫌疑人程序時，原則上應指派案件偵辦人員辦理，但遇情況急迫時，得指派非案件偵辦人員辦理
    3. (C) 實施指認犯罪嫌疑人程序時，原則上應安排 6 名以上於外型無重大差異之被指認人，進行真人選擇式列隊指認
    4. (D) 實施指認犯罪嫌疑人程序時，原則上應事先向指認人說明犯罪嫌疑人之特徵，並提供相關照片以供指認人參考，俾益提升指認之準確性

    正解：(C)

  44. 44依據警察職權行使法規定，警察為防止犯罪，認有必要，得實施跟蹤監視。有關跟蹤監視，下列敘述何者正確？

  47. 47犯罪偵查理論中有所謂「桌腳理論」。「桌腳理論」認為犯罪偵查就像建造一張桌子，四個桌腳（四項偵查重點）都很重要，沒有這四根桌腳（四項偵查重點），案件很難偵破。因此，提出了犯罪偵查的四項偵查重點（桌腳）。下列何者非屬此四項偵查重點（桌腳）之一？

  48. 48有關司法警察（官）實施刑事訴訟法第 131 條之 1 之同意搜索，下列敘述何者正確？

    正解：(A)
