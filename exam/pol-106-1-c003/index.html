警察特考　106 年 四等考試 行政法概要　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

    2. (B) 信賴保護原則
    3. (C) 比例原則
    4. (D) 明確性原則

    正解：(C)

  2. 2依據行政程序法第 4 條之規定，行政行為應受下列何者之拘束？

  35. 35關於行政契約，下列敘述何者正確？

    1. (A) 非有法律具體明確授權，行政機關不得與人民締結行政契約
    2. (B) 行政契約係指其內容為設定、發生或變更公法上法律關係之契約
    3. (C) 行政契約以口頭締結為原則
    4. (D) 行政契約準用民法規定之結果為無效者，行政契約效力未定

    正解：(B)

  36. 36關於給付行政之法律保留，下列何者正確？

    1. (A) 給付行政並未侵害、限制人民權利，無須適用法律保留原則，行政機關得逕行為之
    2. (B) 給付行政仍屬國家高權行政，仍應全面適用法律保留原則，無法律不得為之
    3. (C) 給付行政受法律規範之密度，較限制人民權益者寬鬆，但若涉及公共利益之重大事項者，仍應有法律依據
    4. (D) 給付行政措施若經行政院院會通過，則無須法律依據

    正解：(C)

  45. 45關於行政罰之責任條件，何者正確？

    1. (A) 違反行政法上義務之行為，出於故意或過失者，均可處罰
    2. (B) 違反行政法上義務之行為，除法律有規定處罰過失者外，僅處罰出於故意者
    3. (C) 行政罰係採無過失責任
    4. (D) 行政罰僅處罰故意行為，但違反保護他人之法律者，推定其有故意

    正解：(A)

  46. 46公務員違法侵害人民權利而致國家賠償時，公務員所屬機關得否向該違法之公務員求償？

    1. (A) 不可求償，以免造成公務員畏縮不敢勇於任事
    2. (B) 若公務員有故意或重大過失，則可求償
    3. (C) 若公務員自認違法，則可求償
    4. (D) 不問公務員是否有過失均可求償，因國家賠償僅屬代位責任

    正解：(B)

  47. 47行政院大陸委員會委託財團法人海峽交流基金會處理兩岸文書認證事務，若財團法人海峽交流基金會違法侵害人民權利，人民應以何者為國家賠償訴訟之被告？

    4. (D) 本案為民事糾紛，不得提起國家賠償訴訟

    正解：(A)

  48. 48行政院大陸委員會委託財團法人海峽交流基金會處理兩岸文書認證事務，若財團法人海峽交流基金會受託作成處分時，違法侵害人民權利，人民欲提起行政爭訟，應以何者為行政訴訟之被告？

    1. (A) 財團法人海峽交流基金會
    2. (B) 行政院
    3. (C) 行政院大陸委員會
    4. (D) 總統

    正解：(A)

  49. 49國家賠償應以回復原狀或金錢賠償為優先？

    1. (A) 國家賠償僅能以金錢賠償為之
    2. (B) 國家賠償除法律另有規定外，僅能回復原狀
    3. (C) 國家賠償與民事賠償相同，以回復原狀為原則；無法回復原狀者則以金錢賠償之
    4. (D) 國家賠償以金錢賠償為原則。但以回復原狀為適當者，得依請求，回復損害發生前原狀

    正解：(D)

  50. 50下列何者不適用公務人員保障法？

    1. (A) 教育部專門委員
    2. (B) 內政部常務次長
    3. (C) 國立中山大學簡任秘書
    4. (D) 國家通訊傳播委員會委員

    正解：(D)
