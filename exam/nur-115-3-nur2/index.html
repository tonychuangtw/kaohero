護理師　115 年第三次 基本護理學與護理行政　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1一位剛診斷為癲癇的病人向護理人員表達他內心的擔心和害怕，以及自己無法接受疾病帶來的改變，此疾病階段護理人員給與的措施，下列何者不適當？

    1. (A) 介紹病友分享經驗使病人感覺不孤單
    2. (B) 邀請病人一起參與擬定護理計畫
    3. (C) 陪伴與傾聽病人述說擔心和害怕
    4. (D) 儘可能地滿足病人生理上的需求

    正解：(B)

  2. 2下列何者是影響健康的社會環境因素？

    1. (A) 暴露於污染的空氣中誘發氣喘發作
    2. (B) 基於宗教信仰而拒絕接受輸血治療
    3. (C) 因廁所過於髒污無法忍受而選擇憋尿
    4. (D) 高熱量飲食攝取導致肥胖人口增加

    正解：(B)

  3. 3幼兒流鼻水、呼吸喘、痰液增加且體溫超過 39℃。根據上述症狀，阻斷其傳播感染鏈的措施，下列敘述何者正確？

    1. (A) 給與個案充足的營養，提高其個體抵抗力
    2. (B) 提供針對沙門氏菌的抗生素治療，以阻斷感染源
    3. (C) 妥善處理其糞便，以阻斷感染窩
    4. (D) 阻斷三斑家蚊傳播的傳染途徑

    正解：(A)

  4. 4有關內科無菌技術操作，下列敘述何者正確？

    1. (A) 執行鼻胃管護理時不需要戴手套進行
    2. (B) 照顧水痘病人後應執行 1～2 分鐘的洗手
    3. (C) 口罩不用時可掛在頸部以利再度使用
    4. (D) 接觸病人分泌物後使用非酒精性乾洗手液洗手

    正解：(B)

    2. (B) 腹部傷口紅、腫
    3. (C) 眼睛感到酸、脹
    4. (D) 血壓 188/110 mmHg

    正解：(D)

  6. 6照護過程中，王先生拒絕吃藥。有關護理人員的回應，下列何者是應用治療性溝通技巧？

    4. (D) 「您趕快把降血壓的藥吃下去，就可以出去散步了。」

    正解：(C)

  7. 7病人手術後第一天，以焦點記錄法 D.A.R.T.格式記錄其傷口疼痛問題，下列何者呈現此紀錄格式「D」的內容？

    3. (C) 個案皺著眉頭一臉痛苦

    正解：(C)

  8. 8某糖尿病病人，因足部傷口感染入院，在護理計畫步驟中，下列何者屬於情意性護理目標（attitudeobjective）？
