  1. 1在 Linux 作業系統中，要顯示或設定網路裝置的組態，應輸入下列何指令？

    1. (A) ipconfig
    2. (B) ls -l
    3. (C) netstat
    4. (D) ifconfig

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) Linux／UNIX 傳統上以 ifconfig（interface configuration）顯示或設定網路介面卡的 IP、遮罩、啟停等組態，新版多改用 ip addr。

    ❌ (A) ipconfig 是 Windows 的指令，Linux 沒有這支。

    ❌ (B) ls -l 只是以長格式列出檔案與目錄，與網路無關。

    ❌ (C) netstat 用來查看連線狀態、路由表與監聽埠，只能看不能設定介面組態。

    📚 出處：資料處理．作業系統／Linux 網路管理指令

  2. 2下列那一個排班演算法，稱為「護送現象」？

    1. (A) 先到先做排班
    2. (B) 最短工作期程先做排班
    3. (C) 先到後做排班
    4. (D) 優先權排班

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 護送現象（convoy effect）指一個執行時間很長的行程排在前面，後面一堆短行程只能乾等，平均等待時間被拉高，這是先到先做（FCFS）非搶佔且不看工作長度的必然結果。

    ❌ (B) SJF 讓短工作先做，正是用來消除護送現象的排班法。

    ❌ (C) 「先到後做」並非標準排班演算法名稱。

    ❌ (D) 優先權排班的典型副作用是低優先權行程的飢餓（starvation），不是護送現象。

    📚 出處：資料處理．作業系統／CPU 排班（FCFS 與 convoy effect）

  3. 3那種伺服器具有階層式、根目錄與樹形結構，能提供「單一簽入」的主要服務？

    1. (A) WWW
    2. (B) AP
    3. (C) DNS
    4. (D) LDAP

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) LDAP（輕量目錄存取協定）以根目錄往下延伸的階層式樹狀結構存放使用者與資源資訊，是企業目錄服務（如 AD）的基礎，可集中認證而達成單一簽入（SSO）。

    ❌ (A) WWW 伺服器提供網頁內容，本身不做目錄與認證。

    ❌ (B) AP（應用程式）伺服器執行商業邏輯，認證仍需倚賴目錄服務。

    ❌ (C) DNS 雖也是階層式樹狀命名，但只做名稱對 IP 的解析，不提供帳號認證與單一簽入。

    📚 出處：資料處理．網路服務／目錄服務 LDAP
