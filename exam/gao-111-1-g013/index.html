  1. 1甲公司產銷三聯合產品：X、Y 及 Z。三產品可分別再進一步加工為 X1、Y1 及 Z1。相關資訊如下：①X 的售價 ②X 分攤到的聯合成本 ③Y 加工為 Y1 的分離成本 ④X1 的售價。若甲公司考慮是否將 X 進一步加工為 X1，應考慮之攸關資訊為何？

    1. (A) 僅②③
    2. (B) 僅①④
    3. (C) 僅①②④
    4. (D) 僅①③④

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 是否再加工屬「分離點後」的決策，攸關者為增額收入與增額成本，即①X 的售價與④X1 的售價之差額。

    ❌ (A) ②聯合成本為沉沒成本，③是 Y 的分離成本，與 X 的決策無關。

    ❌ (C) 聯合成本無論加工與否均已發生，不攸關。

    ❌ (D) ③屬 Y 的分離成本，非 X 加工所需支出。

    📚 出處：成本會計—聯合產品分離點後之再加工決策。

  2. 2甲公司有一員工餐廳對其 2 個生產部門提供餐飲服務，餐飲服務在 300,000 到 500,000 份攸關範圍內，預計固定成本$200,000，預計變動成本每份$1。下列為 X1 年度相關資料：預計年度使用量A生產部門 100,000份B生產部門 400,000份實際年度使用量A生產部門 80,000份B生產部門 320,000份若公司採用雙重分攤率法分攤成本時，A 部門及 B 部門各應分攤多少？

    1. (A) A 部門為$112,000；B 部門為$448,000
    2. (B) A 部門為$120,000；B 部門為$480,000
    3. (C) A 部門為$140,000；B 部門為$560,000
    4. (D) A 部門為$150,000；B 部門為$600,000

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 雙重分攤率法下，固定成本按預計使用量分攤：A = 200,000 × 100,000/500,000 = 40,000、B = 160,000；變動成本按實際使用量分攤：A = 80,000、B = 320,000。合計 A 為 120,000、B 為 480,000。

    ❌ (A) 固定成本誤按實際使用量分攤。

    ❌ (C) 變動成本誤按預計使用量計算。

    ❌ (D) 兩項成本皆按預計使用量計算。

    📚 出處：成本會計—支援部門成本之雙重分攤率法。

  3. 3丙公司本年度 7 月份直接原料進貨$100,000，直接人工成本$104,000，製造費用$84,840，存貨相關資料如下:7月初 7月底直接原料 $135,300 $155,300在製品 234,300 183,140製成品 68,700 100,700則丙公司 7 月份之銷貨成本為何？

    1. (A) $80,000
    2. (B) $268,840
    3. (C) $288,000
    4. (D) $320,000

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 直接原料耗用 = 135,300 + 100,000 − 155,300 = 80,000；製造成本 = 80,000 + 104,000 + 84,840 = 268,840；製成品成本 = 234,300 + 268,840 − 183,140 = 320,000；銷貨成本 = 68,700 + 320,000 − 100,700 = 288,000。

    ❌ (A) 80,000 為直接原料耗用數。

    ❌ (B) 268,840 為當期製造成本。

    ❌ (D) 320,000 為製成品成本。

    📚 出處：成本會計—製造成本流程與銷貨成本表。
