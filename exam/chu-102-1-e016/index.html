初等考試　102 年 初等考試 保險學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列何種準備金在人壽保險公司之負債項目中所占比率最大？

    1. (A) 未滿期保費準備金
    2. (B) 賠款準備金
    3. (C) 特別準備金
    4. (D) 保單責任準備金

    正解：(D)

  2. 2保險費結構中之附加保費（loading premium），其組成內容之安全費係指下列何種準備金？

    1. (A) 賠款準備金
    2. (B) 特別準備金
    3. (C) 責任準備金
    4. (D) 未滿期保費準備金

    正解：(B)

  3. 3下列何種人身保險在相同投保條件下，女性比男性保險費為高？

    1. (A) 傷害保險
    2. (B) 定期壽險
    3. (C) 終身壽險
    4. (D) 年金保險

    正解：(D)

  4. 4我國保險法規定，保險人知悉解除原因後，其解除權經過一個月不行使而消滅。前述一個月期間，法律上稱之為：

    1. (A) 消滅時效
    2. (B) 除斥期間
    3. (C) 等待期間
    4. (D) 寬限期間

    正解：(B)

  5. 5下列何者非屬於我國財產保險公司經營之保險商品？

    1. (A) 傷害保險
    2. (B) 健康保險
    3. (C) 責任保險
    4. (D) 年金保險

    正解：(D)

  6. 6超額損失合約再保險係以下列何者作為分保基礎？

    1. (A) 自留額
    2. (B) 保險價額
    3. (C) 保險金額
    4. (D) 損失金額

    正解：(D)

  7. 7危險管理工具中之「損失控制」（loss control），主要方法包括：①危險自留 ②損失抑減 ③損失預防④危險迴避

    1. (A) ①③
    2. (B) ②③
    3. (C) ③④
    4. (D) ②④

    正解：(B)

  8. 8根據人壽保險被保險人投保初期生存或死亡資料，其所編製之生命表稱之為：

    1. (A) 綜合生命表
    2. (B) 選擇生命表
    3. (C) 國民生命表
    4. (D) 終極生命表

    正解：(B)

  9. 9下列何種行銷方式已成為保險行銷的一種新趨勢，在我國人身保險之業績比重已躍居首位？

    1. (A) 保險經紀人代理人通路
    2. (B) 傳統業務員行銷通路
    3. (C) 職團行銷通路
    4. (D) 銀行保險通路

    正解：(D)

  10. 10有關保險之敘述，下列何者不正確？

    1. (A) 保險可以避免危險事故發生，轉嫁損失於被保險人
    2. (B) 保險是一種互助性持續性的經濟制度
    3. (C) 就法律觀點，保險是一種契約行為
    4. (D) 就財務觀點，保險是共同醵金後，合理重新配置之財務再分配

    正解：(A)

  11. 11某保險公司對於未滿期保費準備金採「二十四分法」計算，倘該公司三月份之簽單保險費為 2,400 萬元，則該月「未滿期保費準備金」為何？

    1. (A) 500 萬元
    2. (B) 700 萬元
    3. (C) 900 萬元
    4. (D) 1,100 萬元

    正解：(A)

  12. 12投保財產保險之保險金額係依契約雙方當事人之合議，但就核保的角度而言，保險金額範圍之決定，基本上仍須受限於：

    1. (A) 保險價額
    2. (B) 保險金
    3. (C) 保險費率
    4. (D) 保險費

    正解：(A)

  13. 13大數法則（law of large numbers）之運用在保險經營上極為重要，此原理說明「危險」與「不確定性」隨著投保單位數的增加而：

    1. (A) 增加
    2. (B) 降低
    3. (C) 不變
    4. (D) 不一定

    正解：(B)

  14. 14下列何者屬於危險管理工作在損失發生後（post-loss objectives）的目標？

    1. (A) 減少心理憂懼
    2. (B) 維持企業繼續生存
    3. (C) 節省經營管理成本
    4. (D) 滿足外界強制性的義務

    正解：(B)

  15. 15有關專屬保險代理人制度，下列敘述何者正確？

    1. (A) 專屬保險代理人可為一個以上保險人代理保險業務
    2. (B) 在我國並無專屬保險代理人之組織
    3. (C) 專屬保險代理人係基於被保險人之利益，洽訂保險契約或提供相關服務之人
    4. (D) 通常人壽保險實務上較常採用專屬保險代理人

    正解：(D)

  16. 16保險契約之要保人或被保險人，對於保險標的無保險利益者，對於保險契約效力有何影響？

    1. (A) 保險人得終止契約
    2. (B) 保險契約失效
    3. (C) 保險人得解除契約
    4. (D) 保險契約停效

    正解：(B)

  17. 17保險人交付再保險費於再保險人，再保險人提供財務融通，並對於保險人所承擔「顯著危險」所致之損失，負擔賠償責任之契約稱為：

    1. (A) 轉分再保險
    2. (B) 預約再保險
    3. (C) 財務再保險
    4. (D) 溢額合約再保險

    正解：(C)

  18. 18保險公司支付給業務員之佣金費用，將轉嫁至要保人，通常屬於下列何種項目之構成部分？

    1. (A) 簽單保險費
    2. (B) 滿期保險費
    3. (C) 保單價值準備金
    4. (D) 附加保險費

    正解：(D)

  19. 19下列何者為我國保險公司目前之監理主管機關？

    1. (A) 中央銀行
    2. (B) 金融監督管理委員會
    3. (C) 財政部
    4. (D) 經濟部

    正解：(B)

  20. 20人壽保險的保險費定價因素有預定死亡率、預定利率、預定費用率。假設其他條件不變，只調整利率因素，則利率高的保單對其保險費有何影響？

    1. (A) 保險費一樣
    2. (B) 保險費降低
    3. (C) 保險費調高
    4. (D) 保險金額變高

    正解：(B)

  21. 21下列何者為傷害保險核保的最主要因素？

    1. (A) 年齡
    2. (B) 職業
    3. (C) 健康
    4. (D) 性別

    正解：(B)

  22. 22損害填補原則的主要目的在於：

    1. (A) 找出導致損失的有效原因
    2. (B) 向有賠償責任的第三人求償
    3. (C) 避免道德危險
    4. (D) 讓受益人或被保險人所受損失得以受到補償

    正解：(D)

  23. 23年金受領人有一人以上，但年金金額的給付係繼續到最後受領人死亡為止者，該種年金稱為：

    1. (A) 連生及最後生存者年金（joint life and survivor annuity）
    2. (B) 定期生存年金（temporary life annuity）
    3. (C) 單生年金（single life annuity）
    4. (D) 連生年金（joint life annuity）

    正解：(A)

  24. 24舊協會貨物保險條款中之水漬險大致與 1982 年協會貨物保險條款（Institute Cargo Clauses, I.C.C.）中之何者類似？

    1. (A) I.C.C. (A)
    2. (B) I.C.C. (B)
    3. (C) I.C.C. (C)
    4. (D) I.C.C. (D)

    正解：(B)

  25. 25下列何種保險費有「多退少補」的內涵？

    1. (A) 分類保險費
    2. (B) 賦課制保險費
    3. (C) 定額保險費
    4. (D) 平準保險費

    正解：(B)

  26. 26下列何者非保險費率釐定的原則？

    1. (A) 適當性
    2. (B) 公平性
    3. (C) 安全性
    4. (D) 穩定性

    正解：(C)

  27. 27下列何者非保險合作社的自有資金？

    1. (A) 基金
    2. (B) 公積金
    3. (C) 股金
    4. (D) 資本公積

    正解：(D)

  28. 28定值保險與不定值保險的差別在於：

    1. (A) 損失金額的認定時機不同
    2. (B) 理賠金額的認定時機不同
    3. (C) 保險價額的認定時機不同
    4. (D) 保險金額的認定時機不同

    正解：(C)

  29. 29終身壽險未指定受益人者，依保險法規定其保險金如何處理？

    1. (A) 作為要保人的遺產
    2. (B) 作為被保險人的遺產
    3. (C) 存入保險人特定帳戶
    4. (D) 充繳國庫

    正解：(B)

  30. 30保險價額 400 萬元，保險金額 200 萬元之住宅火災及地震基本保險，發生 60 萬元之火災損失，在 60%的共保條款下，保險公司應理賠多少？

    1. (A) 30 萬元
    2. (B) 36 萬元
    3. (C) 50 萬元
    4. (D) 60 萬元

    正解：(C)

  31. 31規章費率（manual rate）屬於下列何種方法所制定的費率？

    1. (A) 分類法（class rating method）
    2. (B) 個別法（individual rating method）
    3. (C) 增減法（merit rating method）
    4. (D) 判斷法（judgement rating method）

    正解：(A)

  32. 32將保險有效契約保額除以國民所得之比率，就是：

    1. (A) 保險滲透度
    2. (B) 保險密度
    3. (C) 普及率
    4. (D) 投保率

    正解：(C)

  33. 33下列何種再保險安排，原保險公司有分出選擇權但再保險公司無再保選擇權？

    1. (A) 臨時再保
    2. (B) 預約再保
    3. (C) 合約再保
    4. (D) 比率再保

    正解：(B)

  34. 34下列何者的法律效果與其餘三者不同？

    1. (A) 保險人破產時
    2. (B) 保險期間屆滿
    3. (C) 保險標的物非因保險事故完全滅失
    4. (D) 惡意複保險

    正解：(D)

  35. 35下列何者為危險大量原則的內涵？

    1. (A) 讓投保案件的損失幅度相類似
    2. (B) 讓保險公司能依所收的保險費負擔賠償責任
    3. (C) 讓大數法則的運作更好
    4. (D) 將危險較大的契約利用再保險來處理

    正解：(C)

  36. 36在海難中，船長為避免船舶及貨物之共同危險所為處分而直接發生之損害及費用，稱為：

    1. (A) 單獨海損
    2. (B) 共同海損
    3. (C) 施救費用
    4. (D) 損害防止費用

    正解：(B)

  37. 37損害填補原則有其例外不適用之情況，大致有那些？①定值保險 ②重置成本保險 ③人壽保險 ④不定值保險

    1. (A) ①②③④
    2. (B) ①②③
    3. (C) ②③④
    4. (D) ①③④

    正解：(B)

  38. 38下列何者符合我國保險法第 146 條規定，保險業資金運用之範圍？ ① 存、放款 ② 國外投資 ③ 不動產④從事主管機關規定之衍生性商品交易

    1. (A) 僅①③④
    2. (B) 僅①②③
    3. (C) 僅②③④
    4. (D) ①②③④

    正解：(D)

  39. 39人壽保險契約訂立後，於保單到達翌日後幾日內要保人可撤銷保險契約？

    1. (A) 5 日
    2. (B) 7 日
    3. (C) 10 日
    4. (D) 15 日

    正解：(C)

  40. 40對於損失頻率低、損失幅度大之危險，一般主要採下列何種危險管理方法？

    1. (A) 危險自留
    2. (B) 損失控制
    3. (C) 自己保險
    4. (D) 購買保險

    正解：(D)

  41. 41廠房設備發生火災導致營業中斷利潤受損，是屬於財產危險中的：

    1. (A) 直接損失
    2. (B) 間接損失
    3. (C) 自然損失
    4. (D) 市場損失

    正解：(B)

  42. 42要保人對於同一保險利益，同一保險事故，同一保險期間與數保險人訂立數個保險契約之行為，稱為：

    1. (A) 複保險
    2. (B) 共同保險
    3. (C) 超額保險

  43. 43為保險金而故意縱火，是屬於何種危險因素（hazard）？

  44. 44風險資本（RBC），係指依照保險業實際經營所承受之風險程度計算而得之資本，人壽保險業包括那些風險項目？①資產風險 ②保險風險 ③利率風險 ④其他風險

    3. (C) 僅①②④
    4. (D) 僅①③④

  45. 45下列何者不屬於強制汽車責任保險的承保範圍？

    1. (A) 乘客的傷亡責任

  46. 46下列何者敘述錯誤？

    1. (A) 財產保險之損失機會發生較不規律，故經營之風險程度高

  47. 47下列有關受益人的敘述何者錯誤？

  48. 48下列有關保險契約中之「受益人」之敘述何者正確？

  49. 49下列有關賠款分攤原則之敘述，何者錯誤？
