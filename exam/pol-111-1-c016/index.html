警察特考　111 年 四等考試 海巡法規概要（警察人員・水上警察人員輪機組組）　考古題與詳解

本卷共 50 題，其中 50 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1依據海岸巡防法規定，下列那一事務非為海巡機關執行事項？

    1. (A) 海洋環境之保護及保育
    2. (B) 海上救難、海洋災害救護及海上糾紛之處理
    3. (C) 漁業巡護及漁業資源之維護
    4. (D) 海上交通秩序之管制及維護

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 海岸巡防法第4條所定「執行事項」一款，僅列海上交通秩序之管制及維護、海上救難、海洋災害救護及海上糾紛之處理、漁業巡護及漁業資源之維護等目；「海洋環境保護及保育」係同條另行列舉之掌理事項，不屬該款所稱執行事項。

    ❌ (B) 海上救難、海洋災害救護及海上糾紛之處理，明列為執行事項之一目。

    ❌ (C) 漁業巡護及漁業資源之維護，亦列於執行事項。

    ❌ (D) 海上交通秩序之管制及維護，為執行事項所列首目。

    📚 出處：海岸巡防法第4條。

  2. 2依海岸巡防法規定，海巡機關人員為執行職務，必要時得進行身分查證及資料蒐集；其職權之行使及權利救濟，除法規另有規定者外，準用何項法令規定？

    1. (A) 警察職權行使法第二章及第四章
    2. (B) 立法院職權行使法第二章及第三章
    3. (C) 警察職權行使法第三章及第五章
    4. (D) 立法院職權行使法第四章及第五章

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 海岸巡防法第5條規定，海巡機關人員為執行職務，必要時得進行身分查證及資料蒐集；其職權行使及權利救濟，除法規另有規定外，準用警察職權行使法第二章（身分查證及資料蒐集）及第四章（救濟）之規定。

    ❌ (B) 立法院職權行使法規範立法委員議事權限，與海巡執法職權無關。

    ❌ (C) 警察職權行使法第三章為即時強制、第五章為附則，非本條準用範圍。

    ❌ (D) 同屬立法院職權行使法，適用對象錯誤。

    📚 出處：海岸巡防法第5條；警察職權行使法第二章、第四章。

  3. 3甲為現職公務人員，請問依公務人員行政中立法規定，甲不得從事下列何項行為？

    1. (A) 公開為小舅子乙先生公職候選人，進行站台、助講
    2. (B) 替兄長的兒子在大眾傳播媒體具銜或具名廣告
    3. (C) 陪同三妹丙小姐一起去臺北市萬華區進行街訪遊行或拜票
    4. (D) 家族共推甲先生參選市議員，並依法辦理事假或休假後從事選舉造勢活動

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 公務人員行政中立法第9條禁止公務人員為支持特定候選人「在大眾傳播媒體具銜或具名廣告」；法定放寬僅限配偶或二親等以內血親、姻親登記為候選人時，得於非上班時間為其站台、助講、遊行或拜票。兄長之子為三親等旁系血親，且具銜具名廣告本不在放寬之列。

    ❌ (A) 小舅子為二親等姻親，得於非上班時間站台、助講。

    ❌ (C) 三妹為二親等血親，陪同遊行、拜票在放寬範圍內。

    ❌ (D) 依第11條，登記為公職候選人者本應請事假或休假從事競選活動，長官不得拒絕。

    📚 出處：公務人員行政中立法第9條、第11條。

  5. 5依海岸巡防法等相關規定，海巡機關人員執行查緝走私、非法入出國及其他犯罪調查職務，必要時得於最靠近進出海岸之交通道路，實施檢查；海巡機關人員為執行職務，必要時得進行身分查證及資料蒐集，下列敘述何者錯誤？

    2. (B) 行經指定路段者，其指定，以防止犯罪，或處理重大公共安全或社會秩序事件而有必要者為限，指定應由海巡人員為之
    3. (C) 檢查時令其出示身分證明文件，顯然無法查證身分時，海巡人員得將該人民帶往勤務處所查證；帶往時非遇抗拒不得使用強制力，且其時間自攔停起，不得逾三小時，並應即向該管勤務指揮中心報告及通知其指定之親友或律師
    4. (D) 海巡機關人員對進出港區人員、交通工具及物品之檢查，足認其已違反走私、非法入出國及其他違法情事或已有具體徵候顯示有違法之虞者，始得為之

    正解：(B)

    2. (B) 未經路線劃定許可，在中華民國大陸礁層從事海底電纜或管道之舖設、維護或變更者，處新臺幣二千萬元以上一億元以下罰鍰，並得禁止使用或令其拆除
    3. (C) 在中華民國大陸礁層舖設維護變更海底電纜或管道之路線劃定許可辦法規定，本辦法所稱主管機關為海洋委員會
    4. (D) 在中華民國大陸礁層從事海底電纜或管道之舖設、維護或變更，其路線之劃定，應經中華民國政府之許可；其許可辦法，由行政院定之

    正解：(C)

  50. 50依海洋污染防治法、漁業法等相關規定，海巡人員執行勤務時，於棉花嶼東方 18 浬發現大陸漁船甲與駁油船乙接駁石油，經登檢該艘大陸漁船甲，發現該船使用電氣作業採捕魚類，則兩船除違反臺灣地區與大陸地區人民關係條例外，下列處置何者正確？
