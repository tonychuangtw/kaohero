  1. 1下列有關不動產買賣之敘述，何者錯誤？

    1. (A) 不動產仲介公司用與不特定之消費者簽定同類委託銷售不動產而先予擬定之契約，屬於定型化契約不動產買賣除標的物及價金外，該房地之交付時間、所有權移轉登記時期、價金之給付方式等，通常亦為契約成立之必要之點
    2. (B) 居間人已為報告或媒介而契約不成立者，居間人支出之費用均得請求償還
    3. (C) 約定之違約金是否過高，可斟酌當事人所受損害情形，及債務人如能依約履行時債權人可享受之
    4. (D) 一切利益

    正解：(C)

  2. 2下列有關從物之敘述，何者錯誤？

    1. (A) 所有權狀為房地不動產之從物
    2. (B) 屋頂平台為主物大樓建築之從物
    3. (C) 土地共有人出賣房地全棟時，買賣契約效力及於另一共有人原所同意之同宗建築基地依法留設法定保留空地及退縮地之使用權等從權利在內
    4. (D) 主物之處分及於從物，於主物與從權利之關係，亦可適用

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 錯誤：屋頂平台是區分所有建築物的共用部分（構成建物本身的一部分），屬共有部分，不是獨立於主物之外、常助主物效用的「從物」。

    ❌ (A) 正確：本題採權狀附屬於房地、輔助證明權利並隨房地移轉的見解，視為房地之從物。

    ❌ (C) 正確：實務見解認為，依法留設之法定空地及退縮地使用權，屬房地之從權利，買賣效力及於之。

    ❌ (D) 正確：民法第 68 條第 2 項主物之處分及於從物；主權利與從權利之關係亦類推適用。

    📚 出處：民法第 68 條（主物與從物）、第 799 條（區分所有建築物共有部分）

  3. 3甲乙是大四同班同學，甲平常騎乘其父丙所贈與之電動機車作為交通工具。某日乙向甲借用該部電 動機車，以接送其高中同學到學校所在地之風景名勝地區遊玩。下列有關甲乙間之契約關係的敘述 何者錯誤？

    1. (A) 甲乙間所訂立之契約為單務契約，乙之返還義務與甲之容忍使用義務間，無同時履行抗辯權之適用甲乙間所訂立之契約為要物契約，以物之交付為契約成立之特別要件，必待借用物之交付，契約始得成立甲乙間所訂立之契約為使用借貸契約，乙非經甲之同意，不得允許第三人使用該借用物，否則甲
    2. (B) 得終止契約

    4. (D) 的責任，乙因此瑕疵所受之損害，得向甲請求賠償

    2. (B) 典權之約定期限超過 15 年時，當事人間得附有到期不贖即作絕賣之條款
    3. (C) 典權人為典物支出有益費用，使典物增加價值，不論該增益之價值是否仍然存在，得請求出典人償還
    4. (D) 未定期限之典權，出典人得隨時以原典價回贖典物。但自出典後經過 30 年不回贖者，典權人即取得典物所有權

    正解：(C)

    3. (C) 丙得主張甲及其父母負連帶損害賠償責任
    4. (D) 乙賠償丙之損害後，得向甲求償

  31. 31就賣方甲與買方乙間訂立之買賣契約，下列敘述何者錯誤？

    2. (B) 該買賣標的物因不可歸責甲乙之事由而滅失，致給付不能者，甲得免除該物之給付義務
    3. (C) 該買賣標的物因不可歸責甲乙之事由而滅失，致給付不能者，乙得免除價金支付之義務
    4. (D) 該買賣標的物因可歸責乙之事由而滅失，致給付不能者，甲不得向乙請求價金之支付

  32. 32下列有關夫妻離婚後所生身分及財產上效力之說明，何者正確？

    1. (A) 夫妻離婚後，其子女對未享有親權之父母一方，喪失原本享有之法定繼承權
    2. (B) 夫妻離婚後，未享有親權之父母一方與其子女間，互相不負扶養之義務
    3. (C) 兩願離婚之場合，關於子女之親權，由夫任之
    4. (D) 夫妻無過失之一方，因判決離婚而限於生活困難者，他方縱無過失，亦應給予贍養費

  33. 33下列有關遺產分割之敘述，何者錯誤？

    1. (A) 繼承人請求分割遺產之不動產，性質上為處分行為，依民法第 759 條規定，於未辦妥繼承登記前，不得為之
    2. (B) 被繼承人之遺囑，定有分割遺產之方法，或託他人代定者，從其所定
    3. (C) 繼承人對被繼承人已屆清償期之債務，自遺產分割時起，15 年內仍負連帶責任
    4. (D) 繼承人之一所分得之土地持分短少，得向其他繼承人請求賠償短少分配之同額價金

  34. 34下列有關繼承之敘述，何者錯誤？

    1. (A) 奠儀於繼承發生時並不存在，非屬被繼承人所遺財產
    2. (B) 繼承人對於被繼承人之債務，以因繼承所得遺產為限，負清償責任
    3. (C) 債權人得單獨向法院聲請命繼承人於 3 個月內提出遺產清冊
    4. (D) 繼承人對於遺產全部為公同共有關係，無應有部分，故若逾越應繼分比例享有（行使）權利，毋須負返還義務

  35. 35下列有關意思表示之敘述，何者錯誤？

    1. (A) 因錯誤或被詐欺而締結契約者，在表意人依法撤銷其意思表示之前，契約效力未定
    2. (B) 當事人之意思表示未合致者，其契約自始未成立
    3. (C) 買賣為諾成契約，除當事人另有約定外，縱然未訂立書面，亦不影響契約之成立
    4. (D) 非定期行為之契約，當事人一方遲延給付者，他方當事人得定相當期限催告其履行，如債務人仍不履行時，債權人仍須另為解約之意思表示

  36. 36下列有關租賃契約之敘述，何者錯誤？

    1. (A) 租賃關係存續中，出租人未使租賃物合於約定使用收益狀態，致承租人未達租賃目的者，承租人得拒絕給付租金出租人將已交付承租人之租賃物的所有權讓與他人，承租人與受讓人間仍須另立租賃契約始發生租賃關係
    2. (B) 定有期限之租賃契約，當事人約定得提前終止者，於終止契約前應先期通知
    3. (C) 租賃契約經公證並附有逕受強制執行條款者，當承租人有不付租金、租期屆滿拒不搬遷，或房東
    4. (D) 不返還押租金時，當事人可直接申請強制執行

    正解：(B)

  37. 37下列有關抵押權之敘述，何者正確？

    1. (A) 以抵押權擔保之債權請求權，雖經時效消滅，債權人仍得於時效完成後 5 年內實行抵押權
    2. (B) 以建築物為抵押者，其附加部分亦為抵押權效力所及，應一律併付拍賣
    3. (C) 抵押權人聲請查封抵押物，惟該執行名義嗣後經抗告法院裁定予以廢棄確定時，抵押人可依法請求財產上及非財產上損害賠償
    4. (D) 抵押權人於債權清償期屆滿後，為受清償，不得訂立契約取得抵押物之所有權

    正解：(A)

  39. 39下列有關相鄰關係之敘述，何者錯誤？

    1. (A) 聲響之侵入係偶發、輕微或依地方習慣認為相當者，彼此仍應於合理程度範圍內忍受，不得請求
    2. (B) 損害賠償
    3. (C) 相鄰關係重在不動產利用人間權利義務關係之調和，不以各該不動產相互緊鄰為必要
    4. (D) 土地所有人拆除舊建物時，致相鄰樓房發生傾斜、龜裂等，應依民法第 184 條第 2 項負損害賠償責任土地所有人非因故意或重大過失建築房屋逾越疆界者，鄰地所有人無論何時均得提出異議，請求移去或變更其建築物

    正解：(D)

  40. 40下列有關人格權之敘述，何者錯誤？

    1. (A) 姓名乃用以區別人己之一種語言標誌，將人個別化，以確定其人之同一性
    2. (B) 法人在法令限制與性質範圍內，亦享有人格權
    3. (C) 公司名稱用以識別企業之主體性，此時姓名權等於商標權
    4. (D) 針對無涉公益之報導，若不當揭載足資識別當事人資料，侵害其名譽權者，得依民法第 18 條請求排除侵害

    正解：(C)
