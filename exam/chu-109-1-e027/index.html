初等考試　109 年 初等考試 交通行政大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1交通部道路交通安全督導委員會置主任委員一人，由交通部部長兼任；副主任委員三人，由那三個部的次長兼任？

    1. (A) 內政部、教育部、衛生福利部
    2. (B) 交通部、內政部、教育部
    3. (C) 交通部、衛生福利部、經濟部
    4. (D) 教育部、內政部、經濟部

    正解：(B)

  2. 2直轄市、縣（市）政府道路交通安全會報多久召開會議一次？

    1. (A) 1 個月
    2. (B) 2 個月
    3. (C) 3 個月
    4. (D) 6 個月

    正解：(A)

  3. 3公路修建經費負擔原則，下列敘述何者錯誤？

    1. (A) 國道由中央負擔
    2. (B) 省道由中央負擔
    3. (C) 縣道由縣（市）政府負擔
    4. (D) 鄉道由鄉鎮公所負擔

    正解：(D)

  4. 4航空器在機場及其附近活動時，不論是否位於機場交通地帶，應遵守下列規定，何者敘述錯誤？

    1. (A) 注意機場相關航情，以免發生碰撞
    2. (B) 與其他航空器所飛航之機場航線不一致者，應避讓之
    3. (C) 當進場降落時或起飛後一律向右轉彎，另有指示者不在此限
    4. (D) 除因安全、跑道配置或空中交通顧慮而決定一較佳之不同方向外，均應逆風起降

    正解：(C)

  5. 5用於一般施工的標誌體形為何？

    1. (A) 圓形
    2. (B) 菱形
    3. (C) 方形
    4. (D) 正等邊三角形

    正解：(B)

  6. 6標誌之顏色使用原則，下列敘述何者錯誤？

    1. (A) 黃色表示警告，用於安全方向導引標誌及警告性質告示牌之底色
    2. (B) 棕色表示觀光、文化設施之指示，用於觀光地區指示標誌、自行車路線指示標誌及自行車路線編號標誌之底色
    3. (C) 紅色表示禁制或警告，用於禁制或一般警告標誌之邊線、斜線或底色及禁制性質告示牌之底色
    4. (D) 藍色表示地名、路線、方向及里程等之行車指示，用於一般行車指示標誌及行車指示性質告示牌之底色

    正解：(D)

  7. 7強制汽車責任保險每次因汽車交通事故致每一人死亡給付、殘廢給付及傷害醫療費用給付之金額，合計最高以新臺幣多少元為限？

    1. (A) 220 萬元
    2. (B) 180 萬元
    3. (C) 150 萬元
    4. (D) 120 萬元

    正解：(A)

  8. 8交通事業人員得轉任交通行政機關相當職務，其轉任資格、年資提敘等事項之辦法，由那一個機關會同交通部定之？

    1. (A) 考選部
    2. (B) 內政部
    3. (C) 經濟部
    4. (D) 銓敘部

    正解：(D)

  9. 9設籍離島地區並於離島地區使用之車輛，汽車燃料使用費以百分之多少徵收？

    1. (A) 三十
    2. (B) 五十
    3. (C) 六十
    4. (D) 七十

    正解：(D)

  10. 10目前我國汽車燃料使用費，自用車及機車於每年那個月份採一次徵收方式辦理？

    1. (A) 4月
    2. (B) 7月
    3. (C) 9月
    4. (D) 12 月

    正解：(B)

  11. 11旅客無票或持用失效車票搭乘臺鐵，應補收票價，無正當理由者，並得加收票價之多少？

    1. (A) 百分之二十
    2. (B) 百分之三十
    3. (C) 百分之五十
    4. (D) 百分之六十

    正解：(C)

  12. 12大眾捷運系統營運機構兼營其他附屬事業，得經何種機關核准？

    1. (A) 交通部
    2. (B) 交通部公路總局
    3. (C) 交通部鐵道局
    4. (D) 地方主管機關

    正解：(D)

  13. 13下列何者為現行道路交通管理法規規定之違反道路交通管理事件的救濟方式？

    1. (A) 向管轄之地方法院提出行政訴訟
    2. (B) 向管轄地方法院聲明異議
    3. (C) 向上級機關提出訴願
    4. (D) 向監察院陳情

    正解：(A)

  14. 14目前我國國道計程收費方式，聯結車費率為小型車費率的幾倍？

    1. (A) 1倍
    2. (B) 1.25 倍
    3. (C) 1.5 倍
    4. (D) 2倍

    正解：(C)

  15. 15國內航線機場時間帶之規定，下列敘述何者錯誤？

    1. (A) 時間帶依冬、夏兩季班表協調使用
    2. (B) 冬季班表期間自每年十一月一日至翌年三月三十一日
    3. (C) 夏季班表期間自每年四月一日至同年十月三十一日
    4. (D) 時間帶之時段以每四小時為單位

    正解：(D)

  16. 16行車事故鑑定案件，申請或警（憲）機關移送之案件距肇事日期逾幾個月以上，不予受理鑑定？

    1. (A) 1 個月
    2. (B) 2 個月
    3. (C) 3 個月
    4. (D) 6 個月

    正解：(D)

  17. 17訴願決定書應附記，如不服決定，得於決定書送達之次日起幾個月內向行政法院提起行政訴訟？

    1. (A) 1 個月
    2. (B) 2 個月
    3. (C) 3 個月
    4. (D) 6 個月

    正解：(B)

  18. 18公務員在行政程序中，下列應自行迴避的情形，何者敘述錯誤？

    1. (A) 本人或其配偶、前配偶，就該事件與當事人有共同權利人或共同義務人之關係者
    2. (B) 本人或其配偶五親等內之血親或姻親者為事件之當事人時
    3. (C) 於該事件，曾為證人、鑑定人者
    4. (D) 現為或曾為該事件當事人之代理人、輔佐人者

    正解：(B)

  19. 19機車駕駛人行駛於道路時，以手持方式使用行動電話進行撥接、通話、數據通訊，處新臺幣多少元罰鍰？

    3. (C) 1000 元
    4. (D) 1800 元

    4. (D) 1200 元
