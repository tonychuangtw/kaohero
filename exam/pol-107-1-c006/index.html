警察特考　107 年 四等考試 法學知識　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

  1. 1依憲法前言，下列何者非制定中華民國憲法之目的？

    2. (B) 增進人民福利
    3. (C) 奠定社會安寧
    4. (D) 維護疆域完整

  2. 2依憲法增修條文之規定，省應承何機關之命，監督縣自治事項？

    2. (B) 省主席

  5. 5依憲法增修條文第 10 條之規定，關於原住民族之保障，下列敘述何者錯誤？

    1. (A) 要求員工逾百人之政府採購得標廠商，應進用一定比例原住民，不違反平等原則
    2. (B) 應進用一定比例原住民之政府採購得標廠商，可選擇以繳納代金取代之
    3. (C) 為保障原住民族的政治參與，國家不得保障其他特定族群之政治參與
    4. (D) 國家得立法保障原住民族之工作權

    正解：(C)

  6. 6依司法院大法官解釋意旨，下列有關人身自由之敘述，何者錯誤？

    1. (A) 基於遣送所需合理作業期間，對外國人暫時收容之處分，尚無須經由法院為之，合憲
    2. (B) 大陸地區人民受強制出境處分者，於強制出境前得暫予收容之規定，與法律明確性原則相符，合憲
    3. (C) 遣送所需合理作業期間之暫時收容部分，未賦予受暫時收容之外國人有即時之司法救濟，違憲
    4. (D) 逾越遣送所需合理作業期間，對外國人暫時收容之處分，非由法院審查決定，違憲

    正解：(B)

  7. 7下列關於人性尊嚴之敘述，何者錯誤？

    1. (A) 維護人性尊嚴與尊重人格發展，乃自由民主憲政秩序之核心價值
    2. (B) 每個人皆具有其獨特性與不可替代性，因此人之價值無法、亦不應被量化
    3. (C) 基於尊重人的自由意志，應保障被告緘默之自由
    4. (D) 為回復名譽而命加害人公開道歉，則應考量名譽受侵害之形式、程度定相當之方式，縱涉及加害人自我羞辱，亦非憲法所不許

    2. (B) 行政院應於該決議案送達行政院 10 日內，移請立法院覆議
    3. (C) 立法院對於行政院移請覆議案，應於送達 15 日內作成決議。如為休會期間，立法院應於 7 日內自行集會，並於開議 15 日內作成決議
    4. (D) 覆議時，如經全體立法委員二分之一以上決議維持原案，行政院院長應即接受該決議

  31. 31依中央法規標準法之規定，關於法規適用之敘述，下列何者錯誤？

    2. (B) 法規對某一事項規定適用或準用其他法規之規定者，其他法規修正後，適用或準用修正後之法規
    3. (C) 各機關受理人民聲請許可案件適用法規時，除依其性質應適用行為時之法規外，如在處理程序終結前，據以准許之法規有變更者，適用新法規。但舊法規有利於當事人而新法規未廢除或禁止所聲請之事項者，適用舊法規
    4. (D) 法規因國家遭遇非常事故，一時不能適用者，必須暫停適用其全部，不得暫停適用其一部

    正解：(D)

    4. (D) 正當法律程序

    正解：(A)

  42. 42甲出售並交付機器一部給乙，但甲未告知機器之特殊使用方法，導致乙因使用方法不當，引起機器爆破，乙之身體、機器和廠房受到損害。此際，甲對乙應負何種債務不履行之責任？

    1. (A) 給付不能之損害賠償責任
    2. (B) 給付遲延之損害賠償責任
    3. (C) 不完全給付之損害賠償責任
    4. (D) 受領遲延之損害賠償責任

    正解：(C)

  43. 43下列何種受僱人之行為，僱用人應負連帶賠償責任？

    1. (A) 郵局對郵差侵占包裹所生之損害
    2. (B) 客運公司因司機未阻止乘客間的互毆行為所生之損害
    3. (C) 保險公司對業務員和客戶太太的通姦行為所生之損害
    4. (D) 醫院對護理人員院外的竊盜行為所生之損害

    正解：(A)

  44. 44甲基於委任契約而授與乙代理權，擬由乙代理甲向丙購買並移轉登記位於臺北市之公寓 A 戶，下列敘述何者正確？

    1. (A) 為求省事，乙可以同時為丙之代理人，直接辦理 A 戶買賣與所有權移轉登記等事宜
    2. (B) 甲得以口頭，亦得以書面方式授與乙代理權辦理移轉登記
    3. (C) 甲與乙之委任契約，須以書面為之
    4. (D) 甲必須以書面方式授與乙代理權辦理移轉登記

    正解：(D)

  45. 45甲、乙為夫妻，約定分別財產制。生有一子丙（6 歲），其後乙又懷孕，有胎兒丁。甲、丙因交通事故同時死亡。甲身後留有積極財產新臺幣 150 萬元，丁依法可分得甲多少遺產？

    1. (A) 50 萬元
    2. (B) 75 萬元
    3. (C) 25 萬元
    4. (D) 35 萬元

    正解：(B)

  46. 46關於刑法之違背職務受賄罪，下列敘述何者正確？

    1. (A) 仲裁人非違背職務受賄罪之行為主體
    2. (B) 「性行為」也可以構成受賄罪中的不正利益
    3. (C) 目前實務見解認為，「職務行為」僅採法定職權之認定
    4. (D) 非公務員居中協助公務員收受賄賂不構成公務員受賄罪的共同正犯或幫助犯

    正解：(B)

  47. 47關於刑法第 21 條第 1 項，依法令行為不罰之規定，下列敘述何者錯誤？

    1. (A) 為維護整體法律秩序之一致性而設
    2. (B) 本條定位為阻卻犯罪行為之違法性
    3. (C) 為避免法律規定既允許又禁止之矛盾
    4. (D) 所依照之法令，不以明文規定為必要

    正解：(D)

  48. 48依勞動基準法規定，內政部所定應放假之紀念日、節日、勞動節稱為：

    1. (A) 例假日
    2. (B) 休息日
    3. (C) 休假日
    4. (D) 特別休假日

    正解：(C)

  49. 49家庭暴力防治法中所稱之保護令，分為那 3 種？

    1. (A) 危急保護令、臨時保護令、長期保護令
    2. (B) 緊急保護令、暫時保護令、通常保護令
    3. (C) 短期保護令、中期保護令、長期保護令
    4. (D) 緊急保護令、展延保護令、通常保護令

    正解：(B)

  50. 50甲為網路二手書籍賣家，在其拍賣網頁上以文字聲明「採貨到付款者，如經拆封，一律不辦理退貨」，該聲明之法律效果為何？

    1. (A) 該聲明有效，因二手書籍買賣已知交易物品內容，並非通訊交易
    2. (B) 該聲明無效，因此為通訊交易，適用消費者保護法第 19 條規定
    3. (C) 該聲明有效，因當事人特約應當首先尊重，無論是否為通訊交易
    4. (D) 該聲明無效，因此為訪問交易，適用消費者保護法第 19 條規定

    正解：(B)
