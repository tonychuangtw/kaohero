不動產經紀人　112 年 不動產經紀人 不動產經紀相關法規概要　考古題與詳解

  1. 1有關不動產經紀業營業保證金之敘述，下列何者錯誤？

    1. (A) 營業保證金由中華民國不動產仲介經紀業或代銷經紀業同業公會全國聯合會統一於指定之金融機構設置營業保證基金專戶儲存
    2. (B) 經紀業未依規定繳存營業保證金者，應予停止營業處分，其停止營業期間達一年者，應撤銷其許可
    3. (C) 營業保證金獨立於經紀業及經紀人員之外，除不動產經紀業管理條例另有規定外，不因經紀業或經紀人員之債務債權關係而為讓與、扣押、抵銷或設定負擔
    4. (D) 經紀業申請解散者，得自核准註銷營業之日滿一年後二年內，請求退還原繳存之營業保證金

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 錯誤。經紀業未依規定繳存營業保證金者，應予停止營業處分，停止營業期間達「六個月」者才撤銷（廢止）其許可，不是一年。

    ❌ (A) 正確。營業保證金由不動產仲介或代銷經紀業同業公會全國聯合會統一於指定金融機構設置營業保證基金專戶儲存。

    ❌ (C) 正確。營業保證金獨立於經紀業及經紀人員之外，不因其債權債務關係而讓與、扣押、抵銷或設定負擔，以確保專供賠償消費者。

    ❌ (D) 正確。經紀業申請解散者，得自核准註銷營業之日滿一年後二年內請求退還原繳存之營業保證金（不含孳息）。

    📚 出處：不動產經紀業管理條例第7條、第8條、第9條（營業保證金之繳存、管理與退還）

  2. 2有關外國人任職不動產經紀業之規定，下列何者正確？

    1. (A) 外國人得依中華民國法律參加營業員訓練，經內政部許可後得應不動產經紀人考試
    2. (B) 經內政部許可後，始得受僱於經紀業為經紀人員；如為大陸地區人民，尚須經大陸委員會許可
    3. (C) 經內政部或其認可之機構、團體舉辦不動產經紀營業員訓練合格或不動產經紀人考試及格，並向內政部指定之機構、團體登錄及領有不動產經紀營業員證明者，得充任不動產經紀營業員
    4. (D) 外國人經許可在中華民國充任經紀人員者，其有關業務上所為之文件、圖說，可不限以中華民國文字為之

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 正確。經主管機關或其認可之機構、團體舉辦之營業員訓練合格或經紀人考試及格，並向指定機構、團體登錄及領有營業員證明者，得充任經紀營業員；外國人取得資格後亦同。

    ❌ (A) 外國人得依我國法律直接應經紀人考試或參加營業員訓練，應考本身不須先經內政部許可。

    ❌ (B) 外國人領有及格證書或訓練合格證明後，須經中央主管機關許可始得受僱；條例並未規定另須經大陸委員會許可。

    ❌ (D) 外國人充任經紀人員，其業務上所為之文件、圖說應以中華民國文字為之。

    📚 出處：不動產經紀業管理條例第13條（經紀營業員資格）、第37條（外國人充任經紀人員）

  3. 3經營代銷業務者，下列何種文件不適用經紀業指派經紀人簽章規定？

    1. (A) 不動產說明書
    2. (B) 不動產廣告稿
    3. (C) 不動產租賃、買賣契約書
    4. (D) 不動產出租、出售委託契約書

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 應由經紀人簽章的文件有：出租出售委託契約書、承租承購要約書、定金收據、廣告稿、說明書、租賃買賣契約書；其中「委託契約書」與「要約書」兩款，於經營代銷業務者不適用。

    ❌ (A) 不動產說明書不論仲介或代銷，都應由經紀人簽章。

    ❌ (B) 不動產廣告稿不論仲介或代銷，都應由經紀人簽章。

    ❌ (C) 不動產租賃、買賣契約書不論仲介或代銷，都應由經紀人簽章。

    📚 出處：不動產經紀業管理條例第22條（應由經紀人簽章之文件）

  4. 4有關不動產說明書之敘述，下列何者正確？

    1. (A) 不動產之買賣、互易、租賃或代理銷售，如委由經紀業仲介或代銷者，不動產說明書應由經紀業指派經紀營業員簽章
    2. (B) 經紀人員應以不動產說明書向與委託人交易之相對人解說。提供解說前，應經委託人交易之相對人簽章
    3. (C) 雙方當事人簽訂租賃或買賣契約書時，經紀人應將不動產說明書交付與委託人交易之相對人
    4. (D) 不動產說明書應記載及不得記載事項，由所在地主管機關定之

    正解：(C)

  16. 16下列何者屬於限制競爭之行為，事業不得為之？

    3. (C) 事業以不當提供贈品、贈獎之方法，爭取交易之機會
    4. (D) 無正當理由，對他事業給予差別待遇之行為

  17. 17關於聯合行為，下列何者正確？

    1. (A) 事業不得為聯合行為。但為降低成本、改良品質或增進效率，而統一商品或服務之規格或型式，有益於個別經濟與股東利益，經申請主管機關許可者，不在此限
    2. (B) 許可應附期限，其期限不得逾三年
    3. (C) 事業對於主管機關就其聯合行為之許可及其有關之條件、負擔、期限，應主動公開
    4. (D) 聯合行為經許可後，因經濟情況變更者，主管機關得廢止該許可

    正解：(D)

  21. 21依消費者保護法規定，有關定型化契約應記載或不得記載事項之規定，下列何者正確？

    1. (A) 應公告後報請行政院備查
    2. (B) 中央主管機關為預防消費糾紛，保護消費者權益，促進定型化契約之公平化，得選擇特定行業擬訂之
    3. (C) 違反公告之定型化契約，其定型化契約條款不構成契約之內容。但消費者得主張該條款仍構成契約之內容
    4. (D) 中央主管機關公告應記載之事項，雖未記載於定型化契約，經消費者主張，仍構成契約之內容

    正解：(B)

  22. 22消費者保護團體依消費者保護法提起消費者損害賠償訴訟之要件，下列何者正確？

    1. (A) 消費者保護團體許可設立三年以上
    2. (B) 消費者保護團體申請行政院評定優良者
    3. (C) 得委任律師代理訴訟
    4. (D) 消費者保護團體不得向消費者請求報酬，但得請求預付或償還必要費用

  23. 23依消費者保護法之規定，關於小額消費爭議，當事人之一方無正當理由，不於調解期日到場者，下列何者錯誤？

    1. (A) 調解委員得審酌情形，依到場當事人一造之請求或依職權提出解決方案，此方案應經參與調解委員過半數之同意
    2. (B) 該解決方案之送達，不適用公示送達規定
    3. (C) 當事人對該解決方案，得於送達後十日之不變期間內，提出異議；未於異議期間內提出異議者，視為已依該解決方案成立調解
    4. (D) 當事人於異議期間提出異議，經調解委員另定調解期日，無正當理由不到場者，視為依該解決方案成立調解

    正解：(A)

  24. 24關於輸入商品或服務之企業經營者，下列何者錯誤？

    1. (A) 視為該商品之設計、生產、製造者或服務之提供者
    2. (B) 於提供商品流通進入市場，或提供服務時，應確保該商品或服務，符合當時科技或專業水準可合理期待之安全性
    3. (C) 消費者保護團體主張企業經營者不符合當時科技或專業水準可合理期待之安全性者，就其事實應負舉證責任
    4. (D) 企業經營者違反相關規定，致生損害於消費者或第三人時，應負連帶賠償責任

    正解：(C)

  25. 25關於消費者保護團體，下列何者正確？

    1. (A) 消費者保護團體以社團法人、財團法人或行政法人為限
    2. (B) 消費者保護團體之任務為監督消費者保護主管機關及指揮消費者保護官行使職權
    3. (C) 消費者保護團體從事商品或服務檢驗，發表檢驗結果而有錯誤時，應使相關企業經營者有澄清之機會
    4. (D) 消費者保護團體為商品或服務之調查、檢驗時，請求政府予以協助時，政府不應允許

    正解：(C)
