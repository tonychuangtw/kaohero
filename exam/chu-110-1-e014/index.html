初等考試　110 年 初等考試 財政學大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1對於總效用可能曲線（grand utility possibility frontier）上任何一點的敘述，下列何者正確？

    1. (A) 僅滿足生產的配置效率
    2. (B) 僅滿足消費的配置效率
    3. (C) 同時滿足生產與消費的配置效率
    4. (D) 均不滿足生產與消費的配置效率

    正解：(C)

  2. 2福利經濟學認為透過市場價格機能的正常運作，經濟體系的資源利用可以達成：

    1. (A) 配置效率
    2. (B) 公平分配
    3. (C) 所有權保障
    4. (D) 經濟成長

    正解：(A)

  3. 3在私有財配置過多而公共財配置過少的社會失衡情形下，下列何者正確？

    1. (A) 可能是財政幻覺（fiscal illusion）所導致
    2. (B) 可能是租稅由全體民眾負擔所導致
    3. (C) 可能是民眾隱藏其對公共財之消費偏好所導致
    4. (D) 可能是政府執行所得重分配政策，擴張公共支出所導致

    正解：(C)

  4. 4同時具備「敵對性」和「排他性」的財貨通常被稱為：

    1. (A) 公共財
    2. (B) 私有財
    3. (C) 俱樂部財
    4. (D) 地方公共財

    正解：(B)

  5. 5下列何者為兼顧短期資源合理利用及長期可獲取擴廠資金的公營事業訂價法？

    2. (B) 尖峰負荷訂價法
    3. (C) 邊際成本訂價法
    4. (D) 最大利潤訂價法

    正解：(B)

  6. 6下列關於金融外部性（pecuniary externality）之敘述，何者正確？

    1. (A) 基於公平原則，政府應介入干預
    2. (B) 和其他外部性一樣，會造成市場失靈
    3. (C) 政府必須介入干預，使價格機能正常運作
    4. (D) 不會降低資源配置效率，只是資源配置與所得分配狀態的改變

    正解：(D)

  7. 7產品消費時有外部利益，完全競爭市場所決定的價格（P）與數量（Q）和社會最適情況下之價格（P*）與數量（Q*）比較，下列何者正確？

    2. (B) P<P*，Q<Q*
    3. (C) P<P*，Q>Q*
    4. (D) P>P*，Q<Q*

    正解：(B)

  8. 8在完全競爭市場下，若有外部成本，則市場均衡產出水準：

    1. (A) 低於社會最適水準
    2. (B) 高於社會最適水準
    3. (C) 和社會最適水準一樣
    4. (D) 視廠商固定成本而定

    正解：(B)

  9. 9公共建設計畫的投資資金，完全來自私部門投資資金的移轉，在進行成本效益分析時，所使用的折現率為下列何者？

  15. 15下列有關稅式支出之敘述，何者正確？

    2. (B) 依據反需求彈性法則，政府應該對奢侈品課徵較高的稅率，而對民生必需品則課徵較低的稅率
    3. (C) 依據反需求彈性法則，政府應對受補償需求彈性大的財貨課徵較低的稅率
    4. (D) 為達到次佳（second best）的目標，對財貨稅率的訂定應依循雷姆斯法則
