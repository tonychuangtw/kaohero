警察特考　104 年 三等考試 社會學與社會工作　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1下列有關社會資本的論述，何者錯誤？

    1. (A) 社會資本為網絡關係，透過社會關係相互連結而形成
    2. (B) 信任關係強，社會資本則相互增強
    3. (C) 社會資本的形成，必須遵守規範
    4. (D) 社會資本與社會連帶關係不同

    正解：(D)

  2. 2關於福特模式（Fordism），下列何者正確？

    1. (A) 利用創新的技術來生產各種商品，開發新市場，重組新產業
    2. (B) 以大規模的機械生產及標準化零件與組裝，產生完全相同的產品
    3. (C) 指工作穩定、工資與福利較佳，在職訓練和升遷機會較好的工作模式
    4. (D) 指在分析經濟行為與制度時，應重視社會關係，經濟行為是鑲嵌在社會關係中

    正解：(B)

  3. 3下列有關符號消費（sign consumption）的概念何者正確？

    1. (A) 上流社會以購買昂貴和精緻商品，以展示其身分地位的手段
    2. (B) 以特殊商品來傳達社會文化的意涵，目的在做群體的區別
    3. (C) 係指因工作生產而致富的新貴階級的消費行為
    4. (D) 消費本身不是溫飽的需要，而是為了購買商品所代表的社會意涵及生活風格

    正解：(D)

  4. 4下列何者非屬社會結構（social structure）的重要概念？

    1. (A) 社會結構就像大樓中的骨架，界定人們在社會團體中與他人水平或垂直的社會關係
    2. (B) 在複雜社會關係中有許多不同的位置（position）或地位（status）
    3. (C) 每個位置被賦予相對的權利與義務
    4. (D) 在相對穩定的社會關係類型，亦會因不同職業、性別、年齡、教育程度、族群，而產生有意識的社會行動

    正解：(D)

  5. 5吉尼係數（Gini Coefficient）係用來衡量下列何種不平等程度的指標？

    1. (A) 就業
    2. (B) 社會階層
    3. (C) 性別
    4. (D) 所得

    正解：(D)

  6. 6下列何者為正確的第三者政府理論（The Third-Party Government Theory）的涵義？

    1. (A) 係指民間的非營利組織執行政府相關工作
    2. (B) 係指第三方政府論，為中立的第三方
    3. (C) 係指私人企業部門所從事非營利事業
    4. (D) 係指政府核准立案之社會福利機構

    正解：(A)

  7. 7下列有關韋伯科層組織的論述，何者錯誤？

    1. (A) 由規劃、法律、行政體系所決定的組織型態，必定成為現代組織的主流
    2. (B) 組織各職位，應按規章治事，認事不認人，此即「非私人原則」或「公正原則」
    3. (C) 官僚組織依領導者個人喜好決策或集體決策
    4. (D) 專門化趨勢

    正解：(C)

  8. 8以下那位學者的論述能對於「矯情」的議題在日常生活中進行分析？

    1. (A) 高夫曼（Erving Goffman）
    2. (B) 馬克思（Karl Marx）
    3. (C) 韋伯（Max Weber）
    4. (D) 涂爾幹（Emile Durkheim）

    正解：(A)

  9. 9首創社會學一詞，被稱為社會學之父的是以下那位學者？

    1. (A) 史賓賽（Herbert Spencer）
    2. (B) 涂爾幹（Emile Durkheim）
    3. (C) 孔德（Auguste Comte）
    4. (D) 韋伯（Max Weber）

    正解：(C)

  10. 10在科層體制中的升遷，主要是一個人在較低位置的優秀表現，而非依其能力是否能勝任升調後職位來決定，稱之為：

    1. (A) 彼得原理
    2. (B) 玻璃天花板
    3. (C) 雙元就業理論
    4. (D) 巴金森法則

    正解：(A)

  11. 11社區發展協會是屬於以下那一類型的組織？

    1. (A) 營利組織
    2. (B) 志願組織
    3. (C) 暴力組織
    4. (D) 強迫式組織

    正解：(B)

  12. 12社會學家在研究偏差行為時，所著重的重點是在？

    1. (A) 相信偏差行為是與生俱來的
    2. (B) 認為偏差行為就是沒有好好控制自己的潛意識
    3. (C) 認為偏差行為應著力於社會及社會結構
    4. (D) 認為是上輩子的罪孽

    正解：(C)

  13. 13下列有關社區工作（community work）的論述，何者錯誤？

    1. (A) 美國藍尼報告（The Lane Report）奠定了社區工作為社會工作三大方法
    2. (B) 社區工作的目標在於解決問題與能力培養
    3. (C) 社區工作既強調社區意識的凝聚，也重視社區資源的開發
    4. (D) 社區睦鄰運動係指社區鄰里互助的組織及睦鄰的運動

    正解：(D)

  14. 14當社區民眾廣泛參與社區事務，共同來決定社區的目標與行動分案，屬於羅斯曼（Rothman）何種社區模式？

    1. (A) 社會計畫模式（Social Planning Model）
    2. (B) 社會行動模式（Social Action Model）
    3. (C) 地方發展模式（Locality Development Model）
    4. (D) 社區組織模式（Community Organization Model）

    正解：(C)

  15. 15依社區發展工作綱要規定，社區的劃定為下列何者？

    1. (A) 社區居民召開會員大會自決
    2. (B) 社區所在地直轄市或縣（市）政府
    3. (C) 社區所在地鄉（鎮、市、區）公所
    4. (D) 衛生福利部統一劃定

    正解：(C)

  16. 16Samuel Barnett 於 19 世紀末建立的湯恩比館（Toynbee Hall），推動了以下那項社會工作專業的發展？

    1. (A) 慈善組織會社
    2. (B) 睦鄰運動
    3. (C) 伊莉莎白濟貧法案
    4. (D) 社會安全法案

    正解：(B)

  17. 17「社會工作強調個人與環境的相互協調與適應，並指出環境的介入是社會工作獨特的策略」，以上的描述是社會工作專業所稱的：

    1. (A) 人在情境中的觀點
    2. (B) 社會改革模式
    3. (C) 生態系統觀點
    4. (D) 雙元觀點

    正解：(C)

  18. 18一位 14 歲的青少年因為功課考不好擔心回家被處罰，於是找專業社工會談，並且和社工說他很想自殺，請社工幫忙保密，若社工不幫忙保密以後就不再來會談。如果你是社工，你會如何做？

    1. (A) 基於「生命至上」原則，不會幫忙保密，會儘速通報處理自殺防治的事宜
    2. (B) 基於和案主的關係建立，幫案主保密
    3. (C) 因為案主已經超過 12 歲了，所以就讓案主自決
    4. (D) 這是案主的隱私，因此不會涉入處理

    正解：(A)

  19. 19以下那個方式為不當的會談，是在進行專業會談時必須避免的？

    1. (A) 社工為確定服務對象的想法和所傳達的訊息，針對服務對象所描述的內容進行澄清
    2. (B) 在會談過程中服務對象因情緒激動而給予支持和同理
    3. (C) 在會談中很專注地傾聽服務對象所說的內容
    4. (D) 社工為了讓會談更順利，針對和服務對象有相同之處，分享社工個人的事情，讓服務對象覺得和社工是朋友

    正解：(D)

  20. 20下列何者非屬於優勢觀點之基本觀點？

    1. (A) 相信每個個體、家庭、社區都擁有優勢
    2. (B) 建立對等關係以協助案主
    3. (C) 相信每個環境都充滿資源
    4. (D) 認真看待服務對象所表達出來的期待與抱負

    正解：(B)

  21. 21家庭社會工作強調優勢和正面意見，Collins（2007）提出家庭社會工作四個原則，下列何者錯誤？

    1. (A) 幫助家庭最好的地方是社區
    2. (B) 充權家庭以增加其獨立性
    3. (C) 家庭的介入應該是個別化的
    4. (D) 先回應家庭立即需求，然後才是長期目標

    正解：(A)

  22. 22下列何者非屬於青少年社會工作原則？

    1. (A) 生活化原則
    2. (B) 發展性原則
    3. (C) 非主流化原則
    4. (D) 社區化原則

    正解：(C)

  23. 23下列何者非屬於現行專科社工師的分科類別？

    1. (A) 醫務
    2. (B) 社區
    3. (C) 老人、身心障礙
    4. (D) 心理衛生

    正解：(B)

  24. 24下列有關個案、團體、社區工作的論述，何者錯誤？

    1. (A) 個案工作的對象為有意願的案主，亦有非自願性案主
    2. (B) 團體工作對象為失功能或處於困難中的受助者
    3. (C) 社區工作的主要技術為方案規劃、動員及會議
    4. (D) 社區、團體及個案工作與社會工作專業人員，專業互動時間長短差距不大

    正解：(D)

  25. 25小瑛因為和先生長期衝突，一天憤而欲帶著兩個未滿 10 歲的小孩共赴黃泉，報復配偶，以下何者描述是正確的？

    1. (A) 這是別人的家務事，不需要去管太多
    2. (B) 小瑛的「攜子自殺」已經涉及到兒童虐待，應介入處理
    3. (C) 因為小瑛在會談時請社工要保密，所以社工不需要涉入
    4. (D) 因為小孩是父母的附屬品所以父母有權決定小孩的生存權

    正解：(B)
