營養師　105 年第一次 食品衛生與安全　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1依據食品安全衛生管理法之規定，罹患下列何種疾病之食品從業人員仍可僱用？

    1. (A) A 型肝炎
    2. (B) B 型肝炎
    3. (C) 開放性肺結核
    4. (D) 傷寒

    正解：(B)

  2. 2食品業者設置建築與設施時，下列何者不是洗手設備必備之設施？

    1. (A) 流動自來水
    2. (B) 清潔劑
    3. (C) 乾手器或擦手紙巾
    4. (D) 消毒設施

    正解：(D)

  3. 3依據食品安全衛生管理法之規定，醫療機構診治病人時發現有疑似食品中毒之情形，對當地主管機關應：

    1. (A) 立即通報
    2. (B) 12 小時內通報
    3. (C) 24 小時內通報
    4. (D) 視情況決定是否通報

    正解：(C)

  4. 4依據食品安全衛生管理法之規定，下列敘述何者錯誤？

    1. (A) 食品良好衛生規範準則之規範對象包括所有食品業者
    2. (B) 食品安全管制系統之規範對象包括所有食品業者
    3. (C) 食品良好衛生規範準則是有關食品作業場所、設施及品保制度之管理規定
    4. (D) 食品安全管制系統是有關食品從原料至餐桌過程衛生安全之確保

    正解：(B)

  5. 5依我國「食品良好衛生規範準則」，下列何者應冷藏儲存販售？

    1. (A) 吐司
    2. (B) 布丁派
    3. (C) 餅乾
    4. (D) 海苔頁次： 4－2

    正解：(B)

  6. 6控制微生物繁殖可延緩食品的腐敗，下列何種因素對控制微生物的繁殖最沒有影響？

    1. (A) 溫度
    2. (B) 酵素
    3. (C) 氧氣
    4. (D) 酸鹼值

    正解：(B)

  7. 7有關肉毒桿菌之特性，下列敘述何者正確？

    1. (A) 格蘭氏陽性菌
    2. (B) 會還原硝酸鹽
    3. (C) pH 4.5 以下會產生毒素
    4. (D) 致人體中毒之毒素型為 type A、B、F

    正解：(A)

  8. 8下列何者不是食品衛生安全指標菌之條件？

    1. (A) 容易在受檢食物中檢測出來
    2. (B) 在檢測過程中不受其他微生物生長繁殖之干擾
    3. (C) 指標菌之生長速率與致死速率都高於病原菌
    4. (D) 具有專一性

    正解：(C)

  9. 9大多數病原菌屬於下列何溫度範圍可生長的細菌？

    1. (A) 超高溫菌
    2. (B) 高溫菌
    3. (C) 中溫菌
    4. (D) 低溫菌

    正解：(C)

  10. 10造成食品腐敗或中毒之微生物，下列何者為兼性嫌氣菌？

    1. (A) Clostridium botulinum
    2. (B) Pseudomonas
    3. (C) Staphylococcus sp.
    4. (D) Streptococcus pyogenes

    正解：(C)

  11. 11每日攝取容許量（acceptable daily intake, ADI）的訂定，一般是由下列何種食品安全性評估之試驗所推估出來的結果？

    1. (A) 急性毒性試驗
    2. (B) 亞急性毒性試驗
    3. (C) 慢性毒性試驗
    4. (D) 致突變性試驗

    正解：(C)

  12. 12進行急性毒性試驗時，為了解毒性症狀、劑量與時間之關係，需持續觀察多少天？

    1. (A) 7
    2. (B) 14
    3. (C) 21
    4. (D) 28

    正解：(B)

  13. 13欲研究胚胎形成的過程中因化學物質之誘發，而可能導致胎兒在構造上或功能上之改變，下列何者為可進行之安全性評估試驗？

    1. (A) genotoxicity test
    2. (B) carcinogenicity test
    3. (C) teratogenicity test
    4. (D) reproduction test

    正解：(C)

  14. 14下列何種物質會造成甲狀腺刺激素分泌量增加，進而產生腺體癌化？

    1. (A) 一級致癌物
    2. (B) 二級致癌物
    3. (C) 致癌促進劑
    4. (D) 致突變物

    正解：(B)

  15. 15下列何者是做為決定食品添加物使用量的重要依據？

    1. (A) LD50
    2. (B) NOEL
    3. (C) ED50
    4. (D) VSD

    正解：(B)

  16. 16關於致畸胎性實驗所使用受試物質的中間劑量，下列敘述何者正確？

    1. (A) 最高劑量與最低劑量，相加後除以 2
    2. (B) 最高劑量與最低劑量，相乘後開其平方根
    3. (C) 最高劑量的平方與最低劑量的平方，相加後除以 2 後再開其平方根
    4. (D) 最高劑量的倒數與最低劑量的倒數，相加後除以 2 後再取其倒數

    正解：(B)

  17. 17餐具中烷基苯磺酸鹽（alkyl benzene sulfonate, ABS）殘留的檢測，主要是使用下列何種試液？

    1. (A) 碘試液
    2. (B) 花紺（azure A）和氯仿溶液試液
    3. (C) 蘇丹 III（sudan III）或蘇丹 IV（sudan IV）之酒精溶液試液
    4. (D) 寧海準（ninhydrin）之正丁醇溶液試液頁次：4－3

    正解：(B)

  18. 18甲、乙、丙、丁四種化學物質，其 LD50（mg/Kg）分別為 0.1、0.2、0.3、0.4，則何者的毒性最低？

    1. (A) 甲
    2. (B) 乙
    3. (C) 丙
    4. (D) 丁

    正解：(D)

  19. 19在中濕性食品（intermediate moisture food）中所加入的防腐劑，下列何者是其所抑制的微生物種類？

    1. (A) 細菌與酵母
    2. (B) 真菌與病毒
    3. (C) 黴菌與細菌
    4. (D) 黴菌與酵母

    正解：(D)

  20. 20下列添加物何者不屬於殺菌劑？

    1. (A) 次氯酸鈉液
    2. (B) 去水醋酸
    3. (C) 漂白粉
    4. (D) 過氧化氫

    正解：(B)

  21. 21下列何者不可添加在瓜子、蜜餞中作為甜味劑？

    1. (A) 甘精（dulcin）
    2. (B) 糖精（saccharin）
    3. (C) 環己基磺醯胺酸鹽（cyclamate）
    4. (D) 索馬甜（thaumatin）

    正解：(A)

  22. 22關於常使用於食品作為凝膠劑、增稠劑及安定劑的添加物，下列何者不是植物性來源？

    1. (A) 阿拉伯膠（Arabic gum）
    2. (B) 果膠（pectin）
    3. (C) 三仙膠（xanthan gum）
    4. (D) 刺槐豆膠（locust bean gum）

    正解：(C)

  23. 23顏色明顯偏黃之鹹魚或豆乾，可能與下列何種不合法添加物有關？

    1. (A) 皂黃（metanil yellow）
    2. (B) 合成色素黃色四號（tartrazine）
    3. (C) 鹽基性介黃（auramine）
    4. (D) 合成色素黃色二號（orange II）

    正解：(A)

  24. 24有關瘦肉精之敘述，下列何者錯誤？

    1. (A) 是一種乙型受體素
    2. (B) 2012 年 CODEX 通過萊克多巴胺（ractopamine）為動物用禁藥
    3. (C) 我國目前訂有牛肉萊克多巴胺之最高殘留量為 0.01 ppm
    4. (D) 在動物內臟之殘留較高

    正解：(B)

  25. 25有關神經性貝毒（neurotoxic shellfish poison, NSP），下列敘述何者正確？

    1. (A) 毒素主要是生長於黑潮中的貝類受藻類毒化所產生
    2. (B) 毒素不耐熱，一般之烹調溫度即可將其破壞
    3. (C) 會增強鉀離子對神經細胞的滲透性，導致神經性中毒症狀
    4. (D) 短裸甲藻毒素（brevetoxins）是其代表性毒素

    正解：(D)

  26. 26對人體之感染途徑而言，食品中存在之寄生蟲，何者是經由蔬菜類感染所發生？

    1. (A) 肺吸蟲
    2. (B) 蟯蟲
    3. (C) 廣節裂頭絛蟲
    4. (D) 旋毛蟲

    正解：(B)

  27. 27廚師刀傷化膿部位是由下列何種細菌感染所造成？

    1. (A) 大腸桿菌
    2. (B) 肉毒桿菌
    3. (C) 金黃色葡萄球菌
    4. (D) 沙門氏菌

    正解：(C)

  28. 28臺灣地區細菌性食物中毒，以下列何種病原菌發生率最高？

    1. (A) 沙門氏菌
    2. (B) 腸炎弧菌
    3. (C) 金黃色葡萄球菌
    4. (D) 仙人掌桿菌

    正解：(B)

  29. 29下列何者為存在於棉子中的黃色色素，於大量食用棉子油時可能造成食慾不振、心律不整和肺水腫等症狀？

    1. (A) gossypol
    2. (B) safrole
    3. (C) cycasin
    4. (D) dopamine頁次： 4－4

    正解：(A)

  30. 30下列何者是咖啡豆因貯存不當而可能出現，與腎病變有關之黴菌毒素？

    1. (A) 黃麴毒素（aflatoxin）
    2. (B) 赭麴毒素（ochratoxin）
    3. (C) 單端孢素（trichothecin）
    4. (D) 玉米赤黴酮（zearalenone）

    正解：(B)

  31. 31冷殺菌方法中，最常被使用的是紫外線，其具有殺菌效果之波長為 210～296 nm，在此範圍中最具有殺菌力的波長為多少 nm？

    1. (A) 210
    2. (B) 254
    3. (C) 265
    4. (D) 296

    正解：(C)

  32. 32有關自來水中三鹵甲烷的敘述，下列何者錯誤？

    1. (A) 三鹵甲烷是自來水加氯消毒的副產物
    2. (B) 飲用水標準規定三鹵甲烷的最大值是 0.08 毫克/公升以下
    3. (C) 主要成分中以氯仿出現頻率最高
    4. (D) 自來水煮沸後於加蓋情況下，繼續加熱 3 至 5 分鐘，可降低其含量

    正解：(D)

  33. 33下列何種微生物無法以常壓加熱方法來殺滅？

    1. (A) 仙人掌桿菌
    2. (B) 沙門氏菌
    3. (C) 金黃色葡萄球菌
    4. (D) 耶辛尼氏桿菌

    正解：(A)

  34. 34根據我國餐具衛生標準，下列何者是合格的？

    1. (A) 生菌數達 500 個，且大腸桿菌是呈陽性反應
    2. (B) 大腸桿菌與清潔劑皆呈陽性反應
    3. (C) 大腸桿菌是呈現陽性反應，但油脂、澱粉與清潔劑是陰性反應
    4. (D) 大腸桿菌與清潔劑等測試皆是陰性反應

    正解：(D)

  35. 35有關次氯酸鈉液（又稱漂白水）的敘述，下列何者錯誤？

    1. (A) 為強效殺菌劑，但對芽孢無效
    2. (B) 溫度高、殺菌力強，可用於 50℃以上熱水中
    3. (C) 對金屬具腐蝕性
    4. (D) 食品加工設備的使用濃度為 200 ppm

    正解：(B)

  36. 36與潛在危害性食物（potentially hazardous foods）所接觸的器具和器皿，於室溫下使用時，歷時多少小時即需洗滌一次？

    1. (A) 8
    2. (B) 6
    3. (C) 4
    4. (D) 2

    正解：(C)

  37. 37下列何者為常見於化學醬油的可能有害致癌物質？

    1. (A) 單氯丙二醇
    2. (B) 反式脂肪酸
    3. (C) 丙烯醯胺
    4. (D) 離胺丙胺酸

    正解：(A)

  38. 38關於有容器或包裝之食品添加物，下列何者不是現行之標示規定？

    1. (A) 須標示原產地（國）
    2. (B) 須標示「食品添加物」字樣
    3. (C) 須標示限量標準及使用限制
    4. (D) 單方及複方食品添加物皆應標示許可證字號

    正解：(D)

  39. 39用來認定基因改造食品具有「實質等同」的評估方法，主要取決於下列那兩項特性？

    1. (A) 遺傳表現型及組成分
    2. (B) 過敏原及標幟基因
    3. (C) 標幟基因及病原性
    4. (D) 病原性及遺傳表現型

    正解：(A)

  40. 40關於醬油產品中之 4-甲基咪唑（4-MEI），下列敘述何者錯誤？

    1. (A) 動物實驗發現 4-MEI 可能有致癌風險
    2. (B) 為焦糖色素製程中所產生之衍生物
    3. (C) 食品加熱過程中「梅納反應」自然產物
    4. (D) 產品中之 4-MEI 限量標準為 15 mg/kg

    正解：(D)
