物理治療師　107 年第一次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1將肩關節下壓、外展、外轉，再將肘關節伸直、前臂旋後並將腕關節伸直，再加上手指伸直的動作，最不可能測試到那一神經之張力（neural tension）？

    1. (A) 橈（radial）神經
    2. (B) 正中（median）神經
    3. (C) 腋（axillary）神經
    4. (D) 肌皮（musculocutaneous）神經

    正解：(A)

  2. 2下列何者不是椎動脈（vertebral artery）堵塞之常見臨床症狀？

    1. (A) 突發性跌倒（drop attacks）
    2. (B) 暫時性單眼失明（amaurosis fugax）
    3. (C) 幻覺（hallucination）
    4. (D) 臉頰或肢體有麻木感（numbness）

    正解：(C)

  3. 3關於疼痛的描述，下列何者錯誤？

    1. (A) 尖銳、鮮明、有燒灼感，為神經疼痛常見的描述
    2. (B) 較深層且擴散性的痛感屬於骨頭疼痛
    3. (C) 血管性疼痛較具疼痛感，且可能轉移到身體其他部位
    4. (D) 肌肉疼痛通常為鈍痛且很難定位，痠痛會因受傷加重，且可轉移到其他部位

    正解：(B)

  4. 4病人頸椎4、5 節之間的椎間盤突出壓迫神經根，下列何者正確？

    1. (A) 壓迫頸椎第5神經根，會發生棘上肌、棘下肌及三角肌無力現象
    2. (B) 壓迫頸椎第4神經根，會發生棘上肌、棘下肌及三角肌無力現象
    3. (C) 壓迫頸椎第5神經根，會發生肱二頭肌、旋前肌無力現象
    4. (D) 壓迫頸椎第4神經根，會發生肱二頭肌、旋前肌無力現象

    正解：(A)

  5. 5一位有明顯頸椎神經根症狀的個案，將上臂外展且將手掌或前臂輕輕置於頭頂時，疼痛症狀明顯增加，則其問題可能是下列何者？

    1. (A) C4～C5或C5～C6之椎間盤突出
    2. (B) C4～C5或C5～C6間椎孔狹窄
    3. (C) 硬脊髓膜靜脈壓迫
    4. (D) 斜角肌間三角區域壓力增加

    正解：(D)

  6. 6下列那一動作對右側椎動脈之血管阻斷的影響最大？

    1. (A) 頸部後伸及頭部往左旋轉
    2. (B) 頸部後伸及頭部往右旋轉
    3. (C) 頸部屈曲及頭部往左旋轉
    4. (D) 頸部屈曲及頭部往右旋轉

    正解：(A)

  7. 7下列那一項動作為矯正前位頭部（forward head）最適合的治療方式？

    1. (A) 頸椎與上胸椎軸向牽引（axial traction）
    2. (B) 頭頸軸向延伸（axial extension）運動
    3. (C) 斜方肌（trapezius）的肌肉能量技術（muscle energy technique）
    4. (D) 頸最長肌（longissimus cervicis）的肌筋膜放鬆術

    正解：(B)

  8. 8有關頸因性頭痛（cervicogenic headache）的臨床徵兆，下列敘述何者正確？

    1. (A) 疼痛部位為由頭傳向頸椎
    2. (B) 持久的頸椎姿勢或動作會使頭痛加劇
    3. (C) 上頸椎動作通常不受限
    4. (D) 和深頸屈肌張力過強有關

    正解：(B)

  9. 9一慢性頸痛患者接受物理治療時，自訴有慢性心臟病病史並裝有心律調節器，2年前曾有頸部馬鞭式傷害（whiplash injury）。目前主要抱怨是頸部疼痛和肌肉痙攣。下列那種治療不適用此患者？

    1. (A) 機械牽引
    2. (B) 脊椎關節鬆動術
    3. (C) 熱敷
    4. (D) 經皮神經電刺激

    正解：(D)

  10. 10下列有關顱頸屈曲測試（cranio-cervical flexion test）之敘述，何者錯誤？

    1. (A) 在啟始位置下，患者如有胸椎駝背情形，可在頸部後側與床面之間墊毛巾，讓頭頸部保持在正中姿勢
    2. (B) 測試時，請患者利用舌骨肌（hyoid）收縮，做出點頭動作，讓壓力回饋儀數值由20毫米汞柱慢慢上升到目標壓力值
    3. (C) 測試時，若頭頸部出現往後壓的動作，是一種錯誤的代償動作
    4. (D) 此為頸部之動作控制能力測試

    正解：(B)

  11. 11直膝抬腿測試（straight leg raise test）抬高至70度時產生疼痛，請問可用下列何種測試來區分腰部或薦髂關節問題？

    1. (A) 弓弦測試（bowstring test）
    2. (B) 駝背測試（slump test）
    3. (C) 俯臥屈膝測試（prone knee bending test）
    4. (D) 雙腿直膝抬腿測試（bilateral straight leg raise test）

    正解：(D)

  12. 12下列有關腰椎椎間盤的敘述，何者正確？

    1. (A) 腰椎單節之椎間盤高度比頸椎單節之椎間盤高度小
    2. (B) 腰椎的髓核（nucleus pulposus）位於椎間盤之中間偏前方的位置
    3. (C) 隨著年齡增加，環狀纖維（annulus fibrosus）會逐漸被髓核（nucleus pulposus）取代
    4. (D) 竇脊神經（sinuvertebral nerve）支配椎間盤之環狀纖維（annulus fibrosus）後側邊緣

    正解：(D)

  13. 13針對機械性下背痛（mechanical low back pain）的敘述，下列何者錯誤？

    1. (A) 疼痛的感覺通常只會侷限於腰椎，不會延伸到臀部或大腿
    2. (B) 在一天的過程中，疼痛的感覺通常會逐漸加劇
    3. (C) 早晨起床時通常會有僵硬或疼痛的感覺
    4. (D) 改變姿勢通常可以改變疼痛症狀

    正解：(A)

  14. 14針對椎間盤後向突出所導致的急性下背痛之治療，下列何者錯誤？

    1. (A) 病患衛教在這個時期是相當有效益的
    2. (B) 鼓勵病人坐馬桶時身體應該稍微後仰，並考慮加高馬桶坐墊
    3. (C) 病人行走時如果因故而固定在腰椎前彎姿，就應當鼓勵病人避免走路，以免增加椎間盤內壓
    4. (D) 急性期宜避免進行等長性腹肌收縮及骨盆後傾等動作

    正解：(C)

  15. 15關於腰椎相關的深部肌腱反射評估，下列敘述何者正確？①膝反射（knee jerk）可檢定L3／4之異常 ②踝反射（ankle jerk）檢定L5之異常 ③ 趾反射可檢定S1之異常 ④內側膕旁肌反射（hamstrings reflex）可檢定L5／S1之異常

    1. (A) 僅①②
    2. (B) 僅②③
    3. (C) 僅③④
    4. (D) 僅①④

    正解：(D)

  16. 16對於腰椎小面關節之滑液囊半月軟骨夾擠症狀的評估，下列敘述何者正確？①患者多半為腰椎活動度高的年輕人，常常發作於坐姿下轉身向後拿東西的動作 ②側彎遠離痛側時最為疼痛 ③痛側腳的直膝抬腿測試時，可於髂後上棘（PSIS）誘發急性疼痛 ④急性期通常合併有神經性症狀

    1. (A) 僅①②④
    2. (B) 僅②③
    3. (C) 僅②③④
    4. (D) 僅①③

    正解：(B)

  17. 17下背痛患者主訴為小腿外側和足部內側三腳趾出現痠、麻、刺痛，檢查時下列那些肌群最可能因神經根壓迫而呈現無力狀態？①腓骨肌群（peroneals） ②股四頭肌（quadriceps） ③伸 趾長肌（extensorhallucis longus） ④鵝掌肌群（pes anserinus）

    1. (A) 僅①②
    2. (B) 僅③④
    3. (C) 僅①③
    4. (D) 僅②④

    正解：(C)

  18. 18關節徒手技術施作於下背痛患者的療效研究中，下列敘述何者錯誤？

    1. (A) 不適用於急性期下背痛患者
    2. (B) 較不適用於非常恐懼疼痛與疼痛引起失能的心理現象之病人
    3. (C) 運用在至少有一個脊椎椎節活動不足的病人，效果較好
    4. (D) 運用在背痛且症狀沒有往下傳到小腿的病人，效果較好

    正解：(A)

  19. 19協助下背痛病人選擇適當的有氧運動，下列敘述何者錯誤？

    1. (A) 對屈曲導向（flexion bias）的背痛患者，長途騎腳踏車的活動，是為具挑戰的有氧運動項目
    2. (B) 跑步運動較有利於伸直導向（extension bias）類型的下背痛患者；但是對椎間盤受傷的病人，不宜勉強進行
    3. (C) 對屈曲導向（flexion bias）的背痛患者，最佳的有氧運動建議為蛙式游泳
    4. (D) 登階運動是合適的有氧運動選擇，但應同時執行脊椎穩定訓練

    正解：(C)

  20. 20執行駝背測試（slump test）時，下列何者為陽性反應？

    1. (A) 第7～8胸椎處緊繃不舒服
    2. (B) 再度引起患者原本的症狀
    3. (C) 無法主動背屈踝關節
    4. (D) 無法主動伸直膝關節

    正解：(B)

  21. 21造成功能性脊柱側彎（functional scoliosis）的原因不包含下列何者？

    3. (C) 肌肉不平衡

    正解：(B)

  22. 22一位下背痛病人，其職業為機場行李搬運工，工作時需重複搬動重達23～32公斤的行李。治療師應給予下列何種搬運方式建議？

    1. (A) 從地上搬起行李時，要兩腿膝蓋打直、雙腳併攏、腰背儘量彎曲，然後搬起
    2. (B) 左右手各提一行李箱，不應分次分批搬運
    3. (C) 雙手將重物搬起後，要儘量將貨物遠離軀幹
    4. (D) 儘量使用推車或堆高車來搬運貨物

    正解：(D)

  23. 23關於平背姿勢（flat back posture）之敘述，何者正確？

    4. (D) 膕旁肌群（hamstrings）通常會被拉長

    正解：(C)

  24. 24檢查骨盆時，物理治療師執行站立前彎測試（standing flexion test），下列那一肌肉過緊（tightness）會造成結果呈現偽陽性反應？

  25. 25物理治療師觸診骨盆之後，執行sacroiliac rocking（knee-to-shoulder）test。此測試可以檢查下列那一韌帶？

  26. 26下列那一個動作可作為選擇性組織張力測試（selective tissue tension test）中，同時測試內、外翼肌（pterygoid）是否為疼痛來源？

    4. (D) 張嘴

  27. 27背痛患者主訴為右側髂後上棘（PSIS）處有觸痛感，檢查時發現右側薦骨基部（sacral base）比左側深，且右側薦骨下外角（inferior lateral angle）比左側高，可據以判斷疼痛感與下列何種組織的問題有關？

  28. 28下列那一肌肉的轉移痛不會涵蓋到顳頜關節的周圍？

  29. 29有關胸椎的多裂肌等局部穩定肌肉的功能測試，當受測者於俯臥的姿勢進行測試時，下列敘述何者錯誤？

    1. (A) 受測者頭部位於中立位置，雙手平放在身旁
    2. (B) 測試時需提醒受測者不要有脊椎或骨盆的動作
    3. (C) 請受測者將一側肩部向背後抬起，測試者於抬起的肩部處施以阻力
    4. (D) 施測者輕壓棘突（spinous process）旁肌肉，請受測者用力鼓起輕壓處的肌肉，施測者感受肌肉的作用

    正解：(C)

  30. 30有關胸椎椎體與棘突或橫突間的相對位置，下列敘述何者正確？

    1. (A) 胸椎的棘突從第1節到第12節，從原本較接近水平方向，越往下棘突越朝下面
    2. (B) 第4節到第6節的胸椎，其棘突頂點約與本身的橫突位在同一高度
    3. (C) 進行胸椎關節測試時，將第8節胸椎的棘突往前推時，通常第9節胸椎的椎體也會往前移動
    4. (D) 胸椎第12節的棘突頂點約與腰椎第1節橫突一樣高

    正解：(C)

  31. 31一位軀幹關節活動度正常之駝背病患，出現肩峰下夾擠症候群，下列何者最適合改善病患的狀況？

  33. 33一位油漆師傅抱怨2個星期前開始出現肩痛，但無任何外傷，疼痛弧出現在上臂上舉60～120度。據此，物理治療師最可能進行下列那一測試？

  36. 36下列有關肩關節特殊測試之敘述，何者錯誤？

    3. (C) 可能有肺臟水腫、氣道阻塞、肺炎等致命性問題
    4. (D) 可能出現異位性骨化（heterotopic ossification），造成活動疼痛與障礙

    正解：(B)

  77. 77有關骨盆底腔脫垂（prolapse）的敘述，下列何者錯誤？

    2. (B) 以加強軀幹肌群肌力訓練為首要目標

    4. (D) 惡化時，可能影響排尿

  78. 78婦女在懷孕時期，姿勢與步態平衡上主要的變化，包含下列那些？①身體重心向下與向前移動 ②走路時步寬增加，且髖關節外轉 ③肩胛骨前突（protraction）與肩關節內轉 ④懷孕後期可能出現膝反曲（recurvatum）現象，導致壓力中心移向腳尖

    1. (A) 僅①②
    2. (B) 僅②③
    3. (C) 僅③④
    4. (D) 僅①④

    正解：(B)

  79. 79有關骨組織的代謝，下列敘述何者錯誤？

    1. (A) 骨組織巔峰量在20歲達到，此時骨吸收與骨形成作用呈現動態平衡
    2. (B) 當體內與飲食缺鈣時，噬骨細胞會被活化，讓骨頭被吸收而釋出鈣
    3. (C) 停經的婦女因為雌激素分泌下降，使骨吸收作用加速
    4. (D) 肌力訓練、阻力運動與載重運動會刺激骨形成作用

    正解：(A)
