  1. 1下列有關免疫球蛋白的敘述，何者錯誤？

    1. (A) 膜結合型（membrane-bound form）免疫球蛋白表現在B細胞
    2. (B) 分泌型（secreted form）免疫球蛋白由漿細胞製造
    3. (C) B細胞在適應性免疫反應中執行重要的功能
    4. (D) 免疫球蛋白對病原菌具有中和與直接毒殺的能力

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 說明：免疫球蛋白可中和病原與毒素、調理促進吞噬、活化補體，但不具「直接毒殺」能力；毒殺細胞是細胞毒T細胞與NK細胞的功能，故本敘述錯誤。

    ❌ (A) 膜結合型Ig（BCR）表現於B細胞表面，為B細胞辨識抗原的受體，敘述正確。

    ❌ (B) 分泌型Ig由分化後的漿細胞大量合成並分泌，敘述正確。

    ❌ (C) B細胞可分化為漿細胞產生抗體、並可呈獻抗原、分泌細胞激素，在適應性免疫中角色重要，敘述正確。

    📚 出處：Janeway's Immunobiology 抗體功能章節（中和、調理、補體活化）；Kuby Immunology 第 4 章 B 細胞與抗體。

  2. 2下列何種細胞不會表現主要組織相容性複合體（MHC）class I？

    1. (A) Red blood cells
    2. (B) Macrophages
    3. (C) Neutrophils
    4. (D) Kidney cells

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 說明：成熟紅血球無細胞核與胞器，不表現MHC class I；故Red blood cells為不表現者。

    ❌ (B) 巨噬細胞為有核細胞，表現MHC class I，並另表現class II呈獻抗原。

    ❌ (C) 嗜中性球為有核白血球，表現MHC class I。

    ❌ (D) 腎細胞等所有有核體細胞皆表現MHC class I，以利細胞毒T細胞監視。

    📚 出處：Janeway's Immunobiology MHC 表現分布章節；Kuby Immunology 第 6 章（MHC class I 表現於所有有核細胞）。

  3. 3下列有關T細胞的附屬分子（accessory molecules）與配體（ligand）的配對中，何者錯誤？

    1. (A) CD4：Class II MHC
    2. (B) CD8：Class I MHC
    3. (C) CD2（LFA-2）：CD58（LFA-3）
    4. (D) CD28：CD22

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 說明：CD28的配體為B7家族（CD80/CD86）；CD22屬B細胞抑制性受體，可與唾液酸配體結合，兩者並非配對，故錯誤。

    ❌ (A) CD4結合MHC class II，屬T細胞輔助受體，配對正確。

    ❌ (B) CD8結合MHC class I，屬T細胞輔助受體，配對正確。

    ❌ (C) CD2（LFA-2）與CD58（LFA-3）結合，提供T細胞黏附與共刺激訊號，配對正確。

    📚 出處：Janeway's Immunobiology T 細胞活化與附屬分子章節（CD28–B7、CD2–LFA-3）；Kuby Immunology 第 7 章。
