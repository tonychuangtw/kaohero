  43. 43依漁業法規定，漁船使用電氣或其他麻醉物採捕水產動植物，科處何徒刑？

    1. (A) 處 5 年以下有期徒刑
    2. (B) 處 3 年以上 10 年以下有期徒刑
    3. (C) 處 3 年以下有期徒刑
    4. (D) 處 6 月以下有期徒刑

    正解：(A)

  44. 44依海岸巡防法規定，巡防機關人員執行職務時，應穿著制服，制服制式由何機關定之？

    3. (C) 內政部
    4. (D) 行政院海岸巡防署

    正解：(D)

  45. 45行政院海岸巡防署與下列何機關訂定有協調聯繫辦法？

    3. (C) 外交部
    4. (D) 經濟部

    正解：(A)

  46. 46依公務人員行政中立法規定，所稱公務人員，下列何者正確？

    1. (A) 公立學校任用之義工
    2. (B) 私立學校任用之職員
    3. (C) 法定機關依法派用之有給專任人員
    4. (D) 法定機關依法聘用之有給專任人員

    正解：(C)

  47. 47依海岸巡防機關器械使用條例規定，巡防機關人員遭受武力危害，下令巡防機關人員使用砲者，下列何者正確？

    1. (A) 行政院海岸巡防署署長
    2. (B) 行政院海岸巡防署副署長
    3. (C) 行政院海岸巡防署海洋巡防總局總局長
    4. (D) 機動海巡隊隊長

    正解：(A)

  48. 48依中華民國領海及鄰接區法規定，對於在公海或中華民國領海及鄰接區以外其他海域之任何未經許可之廣播，得制定法令，由何機關公告之？

    1. (A) 總統府
    2. (B) 行政院
    3. (C) 內政部
    4. (D) 文化部

    正解：(B)

  49. 49依中華民國領海及鄰接區法規定，領海之基線及領海外界線下列何者正確？

    1. (A) 由行政院訂定，應分批公告之
    2. (B) 由內政部訂定，應分批公告之
    3. (C) 由行政院訂定，得分批公告之
    4. (D) 由內政部訂定，得分批公告之

    正解：(C)

  50. 50依海洋污染防治法規定，港口管理機關於必要時，得會同下列何機關查驗我國及外國船舶之海洋污染防止證明書或證明文件、操作手冊、油、貨紀錄簿？

    2. (B) 行政院環境保護署
    3. (C) 直轄市政府
    4. (D) 縣市政府
