警察特考　102 年 三等考試 行政學　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1著名的行政學者雷格斯（F. W. Riggs）曾提出農業型、工業型與中間型三種行政模式。其採取的主要研究方法為下列何者？

    1. (A) 法則研究法
    2. (B) 動態研究法
    3. (C) 批判研究法
    4. (D) 生態研究法

    正解：(D)

  2. 2下列何者為民主行政（Democratic administration）學派最為關注的公共行政價值？

    1. (A) 效率
    2. (B) 效能
    3. (C) 回應
    4. (D) 公平

    正解：(C)

  3. 3交易成本理論，其人性的假定係建立在那兩個概念之上？

    1. (A) 全然理性與投機主義
    2. (B) 全然理性與利他主義
    3. (C) 有限理性與投機主義
    4. (D) 有限理性與利他主義

    正解：(C)

  4. 4下列何者不是「非正式組織」常見的缺點或反功能？

    1. (A) 任務衝突
    2. (B) 傳播謠言
    3. (C) 反對改變
    4. (D) 社會控制

    正解：(D)

  5. 5「管理格道」（Managerial grid）理論中，表現出對於工作之要求很高，而對於員工需求卻甚少顧及，這樣的組織氣候是：

    1. (A) 無為型
    2. (B) 懷柔型
    3. (C) 業績中心型
    4. (D) 平衡型

    正解：(C)

  6. 6若將正式組織與非正式組織加以比較，非正式組織在「行為控制」方面的來源為何？

    1. (A) 來自於法令規章
    2. (B) 來自於人事獎懲
    3. (C) 來自於主管權力
    4. (D) 來自於團體壓力

    正解：(D)

  7. 7下列敘述中，何者對於權變理論的說明是錯誤的？

    1. (A) 組織是一個開放系統
    2. (B) 管理乃在考量達成對環境的調適
    3. (C) 相同的管理途徑，可以應用在不同的組織
    4. (D) 不同的環境型態下，需要不同的組織類型

    正解：(C)

  8. 8有關公務人員考試筆試錄取人員保留錄取資格之敘述，下列何者不符公務人員考試法的規定？

    1. (A) 服兵役者，保留期限不得逾法定役期
    2. (B) 進修碩士者，保留期限不得逾三年
    3. (C) 疾病、懷孕、生產、父母病危及有其他不可歸責事由者，保留期限不得逾二年
    4. (D) 列入候用名冊之增額錄取人員，因服兵役無法立即接受分發者，得檢具事證申請保留錄取資格至服完法定役期

    正解：(D)

  9. 9行政院所轄設有國軍退除役官兵輔導委員會及原住民族委員會，它們係屬下列何種分部化的方式？

    1. (A) 按功能分部化
    2. (B) 按程序分部化
    3. (C) 按服務對象分部化
    4. (D) 按地區分部化102年公務人員特種考試警察人員考試、

    正解：(C)

  10. 10依照我國預算法第 79 條規定，各機關得請求提出追加歲出預算的情事，下列何項錯誤？

    1. (A) 國家經濟重大變故
    2. (B) 依法增加業務致增加經費時
    3. (C) 依法律增設新機關時
    4. (D) 所辦事業因重大事故經費超過法定預算時

    正解：(A)

  11. 11依照憲法第 60 條規定，行政院於會計年度結束後幾個月內，應提出決算於監察院？

    1. (A) 3 個月
    2. (B) 4 個月
    3. (C) 5 個月
    4. (D) 6 個月

    正解：(B)

  12. 12行政機關之組織結構及能力是否足以承擔政策方案的執行工作，是指下列何者的分析？

    1. (A) 經濟可行性
    2. (B) 行政可行性
    3. (C) 技術可行性
    4. (D) 環境可行性

    正解：(B)

  13. 13若要成功採行理性廣博決策模式，下列那個情況或條件比較適合？

    1. (A) 快速變化的全球化環境
    2. (B) 無法獲得完整決策資訊的情況
    3. (C) 必須大幅縮減決策人力的情況
    4. (D) 決策者具有「經濟人」理性的情況

    正解：(D)

  14. 14下列何者為公共財（public goods）之特性之一？

    1. (A) 敵對性（rivalness）
    2. (B) 非排他性（unexcludability）
    3. (C) 不對稱性（asymmetry）
    4. (D) 獨占性（monopoly）

    正解：(B)

  15. 15政府是市場競爭規則的決定者，但企業往往會促使政府做出不利於競爭對手的規定，以獲取額外的利益，下列何者為企業此種作為最接近的形容詞？

    1. (A) 怠職
    2. (B) 遊說
    3. (C) 尋租
    4. (D) 分贓

    正解：(C)

  16. 16為了推動政府改造工程，我國政府於民國 99 年正式通過那項法律的修正案，影響行政院組織改造甚鉅？

    1. (A) 中央政府改造法
    2. (B) 中央行政機關組織基準法
    3. (C) 行政院組織法
    4. (D) 中央政府機關總員額法

    正解：(C)

  17. 17現代民主社會中的公民，面對不同政府所提供的政治服務，可以進行自由選擇適合自己的好政府並表達自己的喜好，下列何者為政治學中對此現象的比喻：

    1. (A) 用腳投票
    2. (B) 良禽擇木
    3. (C) 市場法則
    4. (D) 自由選擇

    正解：(A)

  18. 18下列何項並不屬於費德勒（F. E. Fiedler）建構權變領導理論的獨立變數？

    1. (A) 員工的情緒
    2. (B) 工作的結構
    3. (C) 領導者與部屬的關係
    4. (D) 領導者的職位權力

    正解：(A)

  19. 19下列何者係以知識及資訊作為生產力的決定性要素？

    1. (A) 知識組織
    2. (B) 知識管理
    3. (C) 知識資本
    4. (D) 知識經濟

    正解：(D)

  20. 20下列何者是決策支援系統的特性之一？

    1. (A) 不易使用
    2. (B) 能夠支援非結構化的決策
    3. (C) 只能支援部分決策過程
    4. (D) 對環境回應速度較慢

    正解：(B)

  21. 21主張政策規劃要能普及於一般人，而不是少數人，係屬於何種政策規劃的原則？

    1. (A) 最終受益是個人的原則
    2. (B) 分配普遍原則
    3. (C) 最劣者受益最大的原則
    4. (D) 公正原則

    正解：(B)

  22. 22下列何者為美國有關行政倫理規範最重要之法律？

    1. (A) 1883 年文官法（The Civil Service Act）
    2. (B) 1939 年赫奇法（The Hatch Act）
    3. (C) 1978 年政府倫理法（The Ethics in Government Act）
    4. (D) 1978 年文官改革法（The Civil Service Reform Act）

    正解：(C)

  23. 23下列那一個學派或觀點認為行政人員在政治系統中的運作是無法中立的？

    1. (A) 新公共管理
    2. (B) 新公共選擇
    3. (C) 新公共行政
    4. (D) 古典公共行政

    正解：(C)

  24. 24新公共行政學者強調，公共行政的本質，在其具有：

    1. (A) 合法性
    2. (B) 公共性
    3. (C) 政治性
    4. (D) 權威性

    正解：(B)

  25. 25管理學者傅麗德（Mary Parker Follett）認為協調是管理的核心，要做好協調應遵守某些原則，以下何者並非她所認定的原則之一？

    1. (A) 直接交涉原則
    2. (B) 互惠原則
    3. (C) 事緩則圓原則
    4. (D) 連續原則

    正解：(C)
