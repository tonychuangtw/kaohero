營養師　111 年第二次 食品衛生與安全　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1依據食品業者專門職業或技術證照人員設置及管理辦法，若因該等人員離職或資料更新等因素，食品業者應在幾日內於中央主管機關建立之登錄平台完成變更登錄？

    1. (A) 30 日
    2. (B) 45 日
    3. (C) 60 日
    4. (D) 75 日

    正解：(A)

  2. 2依據食品用洗潔劑衛生標準，利用次氯酸鈉做食品器具容器包裝的消毒使用時，使用濃度限量為總有效氯：

    1. (A) 1 ppm 以下
    2. (B) 2 ppm 以下
    3. (C) 20 ppm 以下
    4. (D) 200 ppm 以下

    正解：(D)

  3. 3依據食品良好衛生規範準則，下列敘述何者錯誤？

    1. (A) 食品工廠進行食品製程管理與品質管制中，成品應留樣保存至有效日期
    2. (B) 食品從業人員於從業期間，每兩年雇主須主動辦理至少一次健康檢查
    3. (C) 食品業者應保存產品原材料、半成品及成品之來源相關文件至少五年
    4. (D) 食品業者應依產業模式，建立產品原材料、半成品與成品來源與流向的追溯系統

    正解：(B)

  4. 4依據網路美食外送平台業者自主衛生管理指引，下列敘述何者錯誤？

    1. (A) 平台業者應依衛生福利部公告之定型化契約，於網路或應用軟體主動揭露食品資訊
    2. (B) 裝載於運輸用容器內的食品，應完整包覆以防止交叉污染
    3. (C) 外送員於從業期間，應定期接受食品安全與衛生之教育訓練
    4. (D) 外送平台得建立客訴管制，但因非餐飲業者而得不受回收管制之限頁次：4－2

    正解：(D)

  5. 5依據食品良好衛生規範準則，有關食品販賣業之倉儲作業應符合的規定，下列何者錯誤？

    1. (A) 販賣貯存作業，應遵行先進先出之原則
    2. (B) 原材料、半成品及成品倉庫，應分別設置或予以適當區隔
    3. (C) 販賣業者可依需要調整製造業者原來設定之食品保存溫度
    4. (D) 倉庫內物品應分類貯放於棧板、貨架或採取其他有效措施，不得直接放置地面

    正解：(C)

  6. 6依據餐具清洗良好作業指引，清潔之餐具若多少小時內未送至用餐場所，應予重新洗滌？

    1. (A) 24
    2. (B) 48
    3. (C) 72
    4. (D) 96

    正解：(C)

  7. 7二氧化碳抑制微生物生長的機制，下列敘述何者錯誤？

    1. (A) 抑制酵素的生合成
    2. (B) 抑制細胞壁的活性
    3. (C) 抑制細胞內部由酵素催化的反應
    4. (D) 降低微生物細胞內的 pH 值，導致生理傷害

    正解：(B)

  8. 8針對液態食品（例如：生乳）進行有限度加熱，以增加保存效果之加工方式為：

    1. (A) 紫外線殺菌
    2. (B) 高壓滅菌法
    3. (C) 紅外線殺菌
    4. (D) 巴斯德殺菌法

    正解：(D)

  9. 9瑞士乾酪中的丙酸桿菌所產生的丙酸會抑制下列那種微生物生長？

    1. (A) 乳酸菌
    2. (B) 酵母菌
    3. (C) 黴菌
    4. (D) 醋酸菌

    正解：(C)

  10. 10下列何種食品的水活性最低？

    1. (A) 巧克力
    2. (B) 牛肉乾
    3. (C) 麵包
    4. (D) 發酵香腸

    正解：(A)

  11. 11針對肉毒桿菌之特性，下列敘述何者錯誤？

    1. (A) 低酸性食品（pH＞4.6）可能發生
    2. (B) 在水活性大於 0.93 之食品容易生長
    3. (C) 魚與魚製品肉毒桿菌中毒，主要是 E 型肉毒桿菌所引起
    4. (D) 採取真空包裝可以防止肉毒桿菌孳生

    正解：(D)

  12. 12有關罐頭食品的腐敗，下列何者正確？

    1. (A) 罐頭食品在殺菌、冷卻後，罐頭內部會形成正壓，防止微生物滲入污染
    2. (B) 罐頭食品經殺菌處理，可無限期保存
    3. (C) 罐頭食品在冷卻過程中罐內會產生負壓，冷卻水可能因不良之二重捲封吸入而造成腐敗
    4. (D) 罐頭食品上部空隙愈大，可增加真空度，達到延長保存期限效果

    正解：(C)

  13. 13繁殖試驗可用於評估食品對生殖、繁殖、妊娠、生產、授乳、離乳等時期的作用，下列敘述何者錯誤？

    1. (A) 實驗動物通常為囓齒類
    2. (B) 至少要有三個以上的劑量組與一個陰性對照組
    3. (C) 實驗內容為觀察親世代與第一代的生長情況
    4. (D) 實驗動物包含雌、雄兩性，各劑量組要使用 40 隻以上（雄雌各半）

    正解：(C)

  14. 14在非傳統性食品原料申請作業指引中，所謂食用歷史（經驗）係指該原料食用時間達多少年以上？

    1. (A) 5年
    2. (B) 10 年
    3. (C) 15 年
    4. (D) 25 年

    正解：(D)

  15. 15有關致癌性試驗評估，下列那種結論可被判定為陰性？

    1. (A) 試驗組在腫瘤發生比例沒有比對照組高，但發生的時間較早
    2. (B) 試驗組所呈現的癌症型態是對照組沒有的
    3. (C) 發現有腫瘤的臟器或組織與對照組一樣
    4. (D) 實驗組腫瘤的發生機率顯著比對照組高

    正解：(C)

  16. 16使用紅麴原料製成之食品或紅麴色素應注意何種具有腎毒性的真菌毒素？

    1. (A) 黃麴毒素（aflatoxin）
    2. (B) 棒麴毒素（patulin）
    3. (C) 橘黴素（citrinin）
    4. (D) 麥角毒素（ergotoxin）

    正解：(C)

  17. 17卵磷脂為一種天然食材，使用在食品添加物之主要用途為何？

    1. (A) 抗氧化劑
    2. (B) 著色劑
    3. (C) 抗結塊劑
    4. (D) 乳化劑頁次：4－3

    正解：(D)

  18. 18下列那兩種重金屬在所有塑膠類食品包裝材質中的含量均必須小於 100 ppm？

    1. (A) 砷、鎘
    2. (B) 銅、錫
    3. (C) 砷、鉛
    4. (D) 鉛、鎘

    正解：(D)

  19. 19下列何種塑膠單體或合成材料較不具有致癌性？

    1. (A) 氯乙烯
    2. (B) 丙烯腈
    3. (C) 丙烯
    4. (D) 甲醛

    正解：(C)

  20. 20有關食品用洗潔劑標示時應注意之事項，下列敘述何者正確？

    1. (A) 食品用洗潔劑之原料係來自行政院農業委員會認證之有機農產品時，包裝上得置放有機標章圖案
    2. (B) 食品用洗潔劑之標示得使用「食品級」或「無毒」 等字樣
    3. (C) 食品用洗潔劑含有具食品添加物許可證字號之食品添加物時，包裝上得標示該字號
    4. (D) 專供外銷之食品用洗潔劑不強制須依我國食品安全衛生管理法之規定來進行標示

    正解：(D)

  21. 21下列何者是我國准用之食品添加物？

    1. (A) 過氧化氫
    2. (B) 順丁烯二酸酐
    3. (C) 硼砂
    4. (D) 甲醛

    正解：(A)

  22. 22有關塑化劑之敘述，下列何者錯誤？

    1. (A) 雙酚 A 即是一種塑化劑
    2. (B) PVC 薄膜含有塑化劑
    3. (C) 含塑化劑之包材不宜接觸高油脂食品
    4. (D) 為環境荷爾蒙來源之一

    正解：(A)

  23. 23未充分煮熟的淡水魚中，主要出現的寄生蟲為：

    1. (A) 旋毛蟲
    2. (B) 肺吸蟲
    3. (C) 中華肝吸蟲
    4. (D) 蟯蟲

    正解：(C)

  24. 24下列何者不會造成食因性疾病（foodborne illness）？

    1. (A) A 型肝炎病毒
    2. (B) 疱疹病毒
    3. (C) E 型肝炎病毒
    4. (D) 諾羅病毒

    正解：(B)

  25. 25關於沙門氏菌（Salmonella）之敘述，下列何者錯誤？

    1. (A) 屬於細菌性感染型食物中毒病原菌
    2. (B) 廣泛分布在禽類動物之腸道內
    3. (C) 其致病機制與孢子形成有關
    4. (D) 屬於革蘭氏陰性、通性嫌氣菌

    正解：(C)

  26. 26有關臺灣常見的姑婆芋食物中毒的敘述，下列何者錯誤？

    1. (A) 外型與芋頭類似，地下莖與葉均有毒
    2. (B) 其有毒成分來自不溶性草酸鈣、氰醣苷及生物鹼等
    3. (C) 誤食後會出現口腔食道黏膜灼傷與麻痺、吞嚥困難及腹痛等症狀
    4. (D) 送醫前應儘速自行催吐

    正解：(D)

  27. 27處理生鮮水產品時，手部被刺傷導致發燒、畏寒、患部紅腫熱痛等症狀，幾小時後演變成壞死性筋膜炎。可能是由下列何病原菌所導致？

    1. (A) Campylobacter jejuni
    2. (B) Bacillus cereus
    3. (C) Vibrio vulnificus
    4. (D) E. coli O157:H7

    正解：(C)

  28. 28下列有關單核球增多性李斯特菌（Listeria monocytogenes）特性之敘述，何者錯誤？

    1. (A) 為革蘭氏陽性菌，具鞭毛，不產生芽孢
    2. (B) 為常見毒素型食物中毒菌，能分泌李斯特菌溶血素（Listeriolysin O）
    3. (C) 能在低於 5℃下繁殖生長
    4. (D) 可在生鮮魚貝類及未充分殺菌的乳製品中發現

    正解：(B)

  29. 29下列何者無法抑制亞硝基化合物的形成？

    1. (A) 抗壞血酸
    2. (B) 咖啡酸
    3. (C) 阿魏酸
    4. (D) 硫氰酸鹽

    正解：(D)

  30. 30關於禽流感的敘述，下列何者錯誤？

    1. (A) 禽流感病毒可能藉由空氣或禽鳥糞便傳播
    2. (B) 禽流感病毒耐熱，禽肉煮熟仍具傳染力
    3. (C) 不在市場販售活禽有助於降低禽流感的傳播
    4. (D) 禽流感不容易人對人傳染頁次：4－4

    正解：(B)

  31. 31有關食物中天然毒素（natural toxins）的敘述，下列何者錯誤？

    1. (A) 十字花科蔬菜中所含的硫代配糖體（glucosinolates）降解成異硫氰酸鹽，可能造成甲狀腺病變
    2. (B) 棉籽油中的棉籽酚（gossypol）可經由油脂的精煉處理去除之
    3. (C) 鯖魚毒素中毒（scombroid poisoning）與腐敗魚體內形成的組織胺（histamine）有關
    4. (D) 河豚加熱煮熟後可去除其河豚毒素（tetrodotoxin）

    正解：(D)

  32. 32若攝入含過量重金屬之食物可能會造成人體健康上的危害，下列何者錯誤？

    1. (A) 汞（Hg）：水俁病（Minamata disease）
    2. (B) 鉛（Pb）：貧血（Anemia）
    3. (C) 鎘（Cd）：痛痛病（Itai-Itai disease）
    4. (D) 砷（As）：腳氣病（Beriberi）

    正解：(D)

  33. 33依據食品良好衛生規範準則，有關餐具三槽式洗滌及消毒之敘述，下列何者正確？

    1. (A) 消毒：水溫 43～49℃，可利用刷子輔助清潔
    2. (B) 沖洗：利用乾淨溫水，將洗潔劑沖洗掉
    3. (C) 清洗：可利用沸水煮沸 1 分鐘以上
    4. (D) 餐具洗淨後要用毛巾擦乾

    正解：(B)

  34. 34有關餐飲業預防食物中毒五要之敘述，下列何者錯誤？

    1. (A) 要洗手：最好的方式是濕、洗、刷、搓、沖、乾
    2. (B) 要新鮮：食材要新鮮，用水要衛生
    3. (C) 要生熟食分開：生熟食器具應分開
    4. (D) 要澈底加熱：食品中心溫度達到 60℃才安全

    正解：(D)

  35. 35餐具衛生檢查項目中使用油性辣椒紅試劑，檢查餐具何種殘留物？

    1. (A) 澱粉
    2. (B) 油脂
    3. (C) 烷基苯磺酸鹽
    4. (D) 過氧化氫

    正解：(B)

  36. 36依據學校外訂盒（桶）餐採購契約（範本）修正規定，有關教育部校園食材政策，下列何者錯誤？

    1. (A) 校園內禁止使用含有基因改造生鮮食材及其初級加工品
    2. (B) 校園團膳一律使用國產在地肉品
    3. (C) 全面鼓勵學校午餐採用「三章一 Q」食材
    4. (D) 蛋類以採用國產在地具 CAS 臺灣優良農產品標章之來源為限

    正解：(D)

  37. 37食物在危險溫度範圍（danger temperature zone）內的放置時間不宜超過多久？

    1. (A) 4 小時
    2. (B) 2 小時
    3. (C) 1 小時
    4. (D) 30 分鐘

    正解：(A)

  38. 38下列何者不是餐飲業主要管理之病媒？

    1. (A) 老鼠
    2. (B) 蟑螂
    3. (C) 蒼蠅
    4. (D) 螞蟻

    正解：(D)

  39. 39有關食品標示之規定，下列何者錯誤？

    1. (A) 營養宣稱須符合「市售包裝食品營養宣稱規範」
    2. (B) 咖啡因含量應清楚標示於「營養標示欄位」中
    3. (C) 果蔬汁含量 10%以上的包裝飲料應標示「果蔬汁含有率」
    4. (D) 甜味劑應標示食品添加物名稱及功能性

    正解：(B)

  40. 40有關食品用洗潔劑之特性，下列敘述何者正確？

    1. (A) 軟性洗潔劑對環境之影響較小
    2. (B) 硬性洗潔劑之半衰期一般較軟性者為短
    3. (C) 直鏈式烷基苯磺酸鹽是屬於硬性洗潔劑
    4. (D) 我國餐具之洗滌多使用硬性洗潔劑

    正解：(A)
