警察特考　107 年 四等考試 火災學概要　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1消防搶救時，考慮熱傳導現象而進行冷卻降溫，下列何者不是影響熱傳導的因素？

    1. (A) 體積
    2. (B) 溫度差
    3. (C) 熱傳導係數
    4. (D) 距離

    正解：(A)

  2. 2搶救鐵皮屋火警時，常利用上方開口，以自然熱對流原理進行排煙，有關自然熱對流的敘述，下列何者錯誤？

    1. (A) 開口越大，對流速度越快
    2. (B) 開口位置越高，對流速度越快
    3. (C) 燃燒越猛烈，對流速度越快
    4. (D) 開口越接近中性帶，對流速度越快

    正解：(D)

  3. 3常溫常壓下，進行可燃性液體圓形油池火災燃燒實驗時，若燃燒時直徑為 1 公尺，且熱釋率為 1.5 MW，依 Heskested的火焰高度計算公式，則該火焰大約會有多高？（已知：15002/5 =18.64, 15001/2 =38.73）

    1. (A) 1.6 公尺
    2. (B) 2.2 公尺
    3. (C) 3.2 公尺
    4. (D) 4.2 公尺

    正解：(C)

  4. 4火焰高度為 1 公尺，點火源模式下，距離火焰中心 4 公尺，所接受到輻射熱通量為 8 公尺位置的幾倍？

    1. (A) 2
    2. (B) 4
    3. (C) 16
    4. (D) 32

    正解：(B)

  5. 5界面活性系泡沫滅火藥劑，主要具有下列何種功能？

    1. (A) 在油面產生起泡作用
    2. (B) 遮斷連鎖反應
    3. (C) 在油面產生聚合作用
    4. (D) 在油面產生分解作用

    正解：(A)

  6. 6在體積 V 的空氣中（氧容積濃度約為 21%），加入 0.4 V 的不燃性氣體，氧容積濃度會降至約多少？

    1. (A) 13%
    2. (B) 15%
    3. (C) 17%
    4. (D) 19%

    正解：(B)

  7. 7下列何者物質燃燒範圍（即燃燒上下限之差值）最大？

    1. (A) 丙烷
    2. (B) 乙炔
    3. (C) 乙醇
    4. (D) 乙醚

    正解：(B)

  8. 8靜電放電導致火災或爆炸之前提條件，下列何者正確？

    1. (A) 放電能量小於可燃性物質之最小點火能量
    2. (B) 帶電體為導體，通常蓄積靜電能量均能化為放電能量
    3. (C) 帶電體為非導體者，通常蓄積靜電能量均能化為放電能量
    4. (D) 放電能量與帶電體是否為導體無關

    正解：(B)

  9. 9棉被悶燒屬於何種燃燒型態？

    1. (A) 快速燃燒
    2. (B) 混合燃燒
    3. (C) 無焰燃燒
    4. (D) 完全燃燒

    正解：(C)

  10. 10純物質從固態轉換成液態，或自液態轉換成氣態，吸收之熱量稱為：

    1. (A) 顯熱
    2. (B) 潛熱
    3. (C) 活化能
    4. (D) 輻射熱

    正解：(B)

  11. 11通風控制燃燒時，通風口面積增加 1 倍，通風口高度增加 3 倍，若仍維持通風控制燃燒，理論上燃燒速度會增加多少倍？

    1. (A) 1
    2. (B) 2
    3. (C) 3
    4. (D) 4

    正解：(D)

  12. 12研究火災特性時，一般學者經常會以熱釋放率來設計火源的大小，熱釋放率的單位為何？

    1. (A) 卡
    2. (B) 焦耳
    3. (C) 攝氏溫度
    4. (D) 瓦特

    正解：(D)

  13. 13火載量經常被拿來評估燃燒時間長短，以及建築物起火影響，下列何者為火載量的定義？

    1. (A) 單位面積的可燃物量
    2. (B) 單位體積的發熱量
    3. (C) 單位時間的燃燒量
    4. (D) 單位時間的可燃物量

    正解：(A)

  14. 14假設有一居室空間長 6 公尺、寬 5 公尺、高 3 公尺，該居室若有一開口尺寸寬 1 公尺、高 1.96 公尺，依據學者Thomas 的研究，則該居室發生閃燃所需之熱釋放率約為多少？（已知： 1.96 = 1.4 , 3 = 1.732 ）

    1. (A) 1.0 MW
    2. (B) 2.0 MW
    3. (C) 3.0 MW
    4. (D) 4.0 MW

    正解：(B)

  15. 15防火構造建築物外牆，具有相同面積不同開口型式，下列何種比例型式（即垂直高度：水平寬度）較容易形成火焰向上延燒？

    1. (A) 3：1
    2. (B) 1：3
    3. (C) 3：4
    4. (D) 4：3

    正解：(B)

  16. 16火場常見之有毒氣體中，同為 100 ppm 濃度下，下列何者對人體具有最強烈之毒性？

    1. (A) CO
    2. (B) HCN
    3. (C) HCl
    4. (D) NO2

    正解：(B)

  17. 17不同導體之間以導線結合，使二者之電位差消除，以防止放電的方法稱為：

    1. (A) 接地
    2. (B) 接線
    3. (C) 中和
    4. (D) 條狀放電

    正解：(B)

  18. 18液體油料使用管路輸送時，發生靜電的現象稱為：

    1. (A) 流動帶電
    2. (B) 電暈放電
    3. (C) 沿面放電
    4. (D) 撞擊帶電

    正解：(A)

  19. 19下列何者為液化天然氣（LNG）的主要成分？

    1. (A) 甲烷
    2. (B) 乙炔
    3. (C) 丙烯
    4. (D) 丁烷

    正解：(A)

  20. 20有關地下建築物的防火的相關措施或規劃，下列何者並不適當？

    1. (A) 嚴密的火源管理
    2. (B) 萬一停電，亦能維持最低限度的運作機能
    3. (C) 確認防火門上鎖，以預防火災時誤開啟
    4. (D) 設置與外氣相通的地下廣場

    正解：(C)

  21. 21海龍滅火藥劑因會破壞環境而被禁用，取代的 IG-541 潔淨滅火藥劑，比例最高的成分為何？

    1. (A) 氮氣
    2. (B) 氬氣
    3. (C) 二氧化碳
    4. (D) 一氧化碳

    正解：(A)

  22. 22重質油類火災所產生的沸溢（boilover），屬於下列何種現象？

    1. (A) 混合爆炸
    2. (B) 蒸氣爆炸
    3. (C) 分解爆炸
    4. (D) 化學爆炸

    正解：(B)

  23. 23處理高壓乙炔時，為防止其爆炸，通常以其他氣體稀釋，使乙炔濃度降低，下列敘述何者正確？

    1. (A) 稀釋用的氣體僅限於不活潑氣體
    2. (B) 稀釋的氣體分子熱愈小，其添加效果愈大
    3. (C) 工廠中使用的乙炔鋼瓶，常利用浸泡丙酮的多孔性物質，使乙炔溶解於其中以防止爆炸
    4. (D) 稀釋用的氣體無論任何種類，其界限壓力均相同

    正解：(C)

  24. 24通常粉塵之最小發火能量比可燃性氣體之最小發火能量：

    1. (A) 高
    2. (B) 低
    3. (C) 相同
    4. (D) 無法比較

    正解：(A)

  25. 25若一爆炸性粉塵需添加較多的不活潑性氣體，才能使其不爆炸時，即表示此粉塵爆炸性為：

    1. (A) 容易爆炸
    2. (B) 不容易爆炸
    3. (C) 不活潑
    4. (D) 無法判定

    正解：(A)
