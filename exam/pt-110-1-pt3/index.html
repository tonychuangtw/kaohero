物理治療師　110 年第一次 物理治療技術學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1受到60 Hz的家用電源電擊時，至少需要多大的電流強度會使肌肉強烈收縮，無法放開握在手上的電擊棒，又稱為無法放開的交流電強度？

    1. (A) 1 mA
    2. (B) 16 mA
    3. (C) 80 mA
    4. (D) 6 A

    正解：(B)

  2. 2下列何者不是經皮神經電刺激（TENS）的適應症？

    1. (A) 急性疼痛（acute pain）
    2. (B) 幻肢痛（phantom pain）
    3. (C) 術後疼痛（postoperative pain）
    4. (D) 未經診斷不明原因疼痛

    正解：(D)

  3. 3以神經肌肉電刺激進行肌力強化時，下列何者錯誤？

    1. (A) 常用的波形為脈波式雙相波形（pulsed biphasic waveform）
    2. (B) 開關比（on-off ratio）為1：3至1：5
    3. (C) 脈波頻率應介於5～10 pps
    4. (D) 肌肉收縮形式以等長收縮為主

    正解：(C)

  4. 4關於電刺激肌肉收縮與生理性肌肉收縮的差異，下列何者錯誤？

    1. (A) 電刺激收縮先活化第二型肌纖維
    2. (B) 生理性收縮先活化第一型肌纖維
    3. (C) 電刺激收縮比生理性收縮容易疲乏
    4. (D) 電刺激肌肉收縮通常是平順啟動，生理性肌肉收縮通常是快速抽動

    正解：(D)

  5. 5有關使用功能性電刺激治療脊柱側彎之敘述，何者正確？

    1. (A) 適合不明原因的脊柱側彎患者
    2. (B) 側彎角度要小於20度才能使用
    3. (C) 刺激時間一般由白天開始，晚上睡覺時讓病人休息
    4. (D) 刺激強度為最小肌肉收縮強度

    正解：(A)

  6. 6關於功能性電刺激的參數，下列敘述何者錯誤？

    1. (A) 電流強度的調整應在受刺激者可忍受範圍內
    2. (B) 引起肌肉收縮之理想波寬（pulse duration）為200至400微秒
    3. (C) 波頻（pulse rate）愈高，阻抗愈低，愈不容易造成疲乏
    4. (D) 對於中樞神經障礙病患，刺激週期（duty cycle）通常由1：5開始

    正解：(C)

  7. 7對於中頻干擾波（interferential currents）引起的肌肉收縮模式與應用，下列敘述何者正確？

    1. (A) 為同步收縮，可正確控制深層肌肉的收縮與放鬆時間比例
    2. (B) 為不同步收縮，可正確控制深層肌肉的收縮與放鬆時間比例
    3. (C) 為同步收縮，無法正確控制深層肌肉的收縮與放鬆時間比例
    4. (D) 為不同步收縮，無法正確控制深層肌肉的收縮與放鬆時間比例

    正解：(D)

  8. 8相較於其他低頻電刺激，下列何者是高壓間歇式直流電的特色？

    1. (A) 造成皮膚電阻降低，電流通過時會使電壓降低較多
    2. (B) 有較多電流密度經過皮膚而到達治療部位
    3. (C) 有較多的熱效應而使治療部位血管擴張
    4. (D) 電極片下會產生較多的化學反應

    正解：(B)

  9. 9關於高壓間歇式直流電（high-voltage pulsed current, HVPC），下列敘述何者正確？①屬於交流電 ②為雙尖峰的雙相波 ③相寬（phase duration）小於200微秒 ④電壓高於100伏特以上

    1. (A) ①②
    2. (B) ③④
    3. (C) ①③
    4. (D) ②④

    正解：(B)

  10. 10關於離子導入法的基本原理，下列敘述何者正確？

    2. (B) 欲打入之藥物，需為帶電荷或能轉變成為帶電荷之物質
    3. (C) 能使藥物滲透進入皮下5公分的深層組織
    4. (D) 真皮層脂肪越厚者，其離子導入法效果越差

    正解：(B)

  11. 11下列何者非一般肌電圖生物回饋系統所使用的訊號分析？

    2. (B) 濾波（filtering）
    3. (C) 翻正（rectification）
    4. (D) 頻譜分析（frequency analysis）

    4. (D) 電極不能擺放在肌腱上

    正解：(B)

  13. 13強度－時間曲線（strength-duration curve）檢查在損傷神經復原過程中會出現下列何種特徵？

    1. (A) 曲線向右下方移，彎折點（kink）出現
    2. (B) 曲線向左下方移，彎折點（kink）出現
    3. (C) 曲線向右下方移，彎折點（kink）消失
    4. (D) 曲線向左上方移，彎折點（kink）消失

    正解：(B)

  14. 14有關Hoffman反射（H-reflex）的電生理學檢查，下列敘述何者正確？

    1. (A) 類似深肌腱反射，都是檢查相位性牽張反射（phasic stretch reflex）路徑是否完整
    2. (B) M波反應與H波反應總是可以同步被記錄
    3. (C) M波反應出現的時間點通常晚於H波反應出現的時間點
    4. (D) 一般而言，M波振幅愈大，H波的振幅也愈大

    正解：(A)

  15. 15下列何種治療方式最無法完全包覆肢體末梢？

    1. (A) 蠟療
    2. (B) 微粒治療儀
    3. (C) 標準型熱敷袋
    4. (D) 冷熱交替療法

    正解：(C)

  16. 16對於多發性硬化症（multiple sclerosis）病患接受冷熱治療之療效，下列敘述何者正確？

    1. (A) 使用冷療反應較佳，提供冷療背心，可改善疲勞與無力症狀
    2. (B) 使用熱療反應較佳，提供紅外線照射，可改善血液循環問題
    3. (C) 使用水療反應較佳，提供高溫漩渦流，可增加軟組織延展性
    4. (D) 使用對比浴（contrast bath）反應較佳，提供冷熱交替，可改善疼痛問題

    正解：(A)

  17. 17治療急性網球肘，超音波治療參數何者最合適？

    1. (A) 頻率3 MHz，間歇性輸出，強度小於1 Watt/cm2
    2. (B) 頻率3 MHz，連續性輸出，強度大於1 Watt/cm2
    3. (C) 頻率1 MHz，連續性輸出，強度小於1 Watt/cm2
    4. (D) 頻率1 MHz，間歇性輸出，強度大於1 Watt/cm2

    正解：(A)

  18. 18關於水療池的治療原理，下列敘述何者正確？

    4. (D) 在水中行走時的阻力，與前進速度成正比

    正解：(D)

  19. 19有關水療桶的敘述，下列何者正確？①長桶多用於上肢 ②哈伯氏桶多用於全身 ③渦輪機用來打水 ④渦輪機的進水處應在水面下至少2英吋

  30. 30依據Norkin的方法，執行髖外展活動度的量測，下列敘述何者正確？

    2. (B) 關節量角尺的支點（fulcrum）對齊股骨大轉子
    3. (C) 關節量角尺的近端臂對齊骨盆外側中線
    4. (D) 關節量角尺的遠端臂對齊股骨外側中線

    正解：(A)

  31. 31依據Norkin的方法，執行距腿關節背屈（talocrural dorsiflexion）活動度的量測，下列敘述何者錯誤？

  33. 33關於增加關節活動度的牽張（stretch）方式，下列敘述何者錯誤？

  37. 37有關徒手肌力測試之敘述，下列何者正確？

    2. (B) 測試單關節肌肉肌力時，應先擺位於關節活動度之中間位置（mid range）再施予阻力
    3. (C) 測試肩胛動作之肌力時，阻力最好施於肩胛骨外側
    4. (D) 針對膝關節穩定度不足者，測試其髖外展肌力時，阻力應施於腳踝處

  38. 38以徒手肌力測試檢查髖外展動作之肌力，下列敘述何者正確？

    1. (A) 若於側躺、髖屈曲45度姿勢下測試，可檢查到縫匠肌之肌力
    2. (B) 若於側躺、髖稍微伸直姿勢下測試，可檢查到臀中肌之肌力
    3. (C) 若於側躺、髖關節位於0度位置、內轉姿勢下測試，可檢查到闊筋膜張肌之肌力
    4. (D) 若於側躺、髖關節位於0度位置、外轉姿勢下測試，可檢查到臀大肌之肌力

  39. 39針對一位65公斤且右大腿骨折打完骨釘術後4週的病人做肌力訓練，下列何者最適合？

    2. (B) 在手有支撐下做微半蹲（mini-squat），每天3回合，每回合10次，每次停5秒
    3. (C) 在手無支撐下做深蹲運動，每天3回合，每回合10次，每次停5秒
    4. (D) 在BAPS上做右腳單腳下蹲運動，每天3回合，每回合10次，每次停5秒

    正解：(B)

  40. 40有關核心穩定運動的相關肌群，下列敘述何者錯誤？
