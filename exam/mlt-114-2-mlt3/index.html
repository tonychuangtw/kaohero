醫事檢驗師　114 年第二次 生物化學與臨床生化學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1下列那一個測定儀器最常用於尿液試紙的臨床生化檢測？

    1. (A) 散射濁度計（nephelometer）
    2. (B) 透射濁度計（turbidimeter）
    3. (C) 分光光度計（spectrophotometer）
    4. (D) 反射光度計（reflectance photometer）

    正解：(D)

  2. 2有關 chemiluminescent immunoassay（LOCI）冷光免疫分析技術原理，下列何者最不適當？

    1. (A) 屬於一種異質性（heterogeneous assay）免疫分析法
    2. (B) 屬於一種非競爭型免疫分析法
    3. (C) 試劑中需製備光源激發物（sensitizer particle）
    4. (D) 試劑中需製備冷光標定物（chemiluminescent particle）

    正解：(A)

  3. 3根據臨床實驗室標準協會（Clinical and Laboratory Standards Institute, CLSI），臨床實驗室試劑水（Clinical Laboratory Reagent water, CLRW）規格，下列何者正確？

    4. (D) 總有機物＜600 ng/g

    正解：(C)

  4. 4MALDI-TOF 質譜儀較不適合用來鑑定或分析下列何種微生物或分子？

  5. 5針對特定疾病，下列何種分析最適合用於同時評估多個檢測標誌的優劣？

  6. 6有關隨機誤差的敘述，下列何者最不適當？

    正解：(C)
