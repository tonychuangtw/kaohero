  1. 1若採連鎖反應（Cascades）法，對外來鍵（Foreign Key）的參考對象做刪除或更新動作，當參考的外來鍵有相對匹配值時，下列何者正確？

    1. (A) 立即異動之，別管其他檔案的匹配值，以免會有連鎖反應
    2. (B) 將第一個匹配值改為 null，以防連鎖反應
    3. (C) 整個反應動作應該視為是一個完整的異動
    4. (D) 整個反應動作應該視為是一個對外來鍵欄名做刪除或更新的異動

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 連鎖（Cascade）刪除或更新會把父表的異動一路帶到所有參照它的子表資料列，這一串動作必須包在同一個交易（transaction）中，全部成功或全部回復，資料庫才不會留下半途而廢的不一致狀態。

    ❌ (A) 只改父表而不管子表，會留下指向不存在主鍵的孤兒記錄，違反參考完整性。

    ❌ (B) 把匹配值改成 null 是 SET NULL 選項的做法，不是 Cascade，且只改第一個匹配值更不合理。

    ❌ (D) Cascade 異動的是資料列的內容值，不是去刪除或更新外來鍵的欄位名稱。

    📚 出處：資料庫．參考完整性（ON DELETE/UPDATE CASCADE）

  2. 2在做資料處理時，常會對資料檔案使用 CRUD 的動作，試問要用 SQL 的什麼語言完成？

    1. (A) 資料定義語言
    2. (B) 資料操作語言
    3. (C) 資料控制語言
    4. (D) 資料分析語言

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) CRUD 是 Create、Read、Update、Delete，對應 SQL 的 INSERT、SELECT、UPDATE、DELETE，全部屬於資料操作語言（DML）。

    ❌ (A) 資料定義語言（DDL）用 CREATE TABLE、ALTER、DROP 定義資料庫結構，不處理資料列內容。

    ❌ (C) 資料控制語言（DCL）用 GRANT、REVOKE 管理存取權限。

    ❌ (D) SQL 並沒有「資料分析語言」這個分類。

    📚 出處：資料庫．SQL 語言分類（DDL／DML／DCL）

  3. 33NF 係指關聯表 T 必須符合 2NF，且所有非候選鍵的屬性，都不能彼此有下列何種關係？

    1. (A) 功能獨立
    2. (B) 多重值獨立
    3. (C) 功能相依
    4. (D) 多重值相依

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 第三正規化在符合 2NF 之外，還要消除遞移相依，也就是非候選鍵屬性之間不得互相存在功能相依（A→B→C 這種關係）。

    ❌ (A) 功能獨立正是 3NF 希望達到的狀態，不是要消除的關係。

    ❌ (B) 多重值獨立同樣不是 3NF 要排除的對象。

    ❌ (D) 消除多重值相依是第四正規化（4NF）的要求，層級不同。

    📚 出處：資料庫．正規化（3NF 與遞移相依）
