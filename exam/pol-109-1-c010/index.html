警察特考　109 年 四等考試 警察情境實務概要　考古題與詳解

本卷共 20 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（20 題，建議 60 分鐘）

  1. 1報載：「某甲騎機車因臉色紅潤，被警方攔檢酒測，但甲拒測，警方依法開單告發，甲不服一狀告到法院，法官發現警方開單前，並未告知甲拒測的法律效果，而是在開單後才『補通知』，執法程序有重大瑕疵，判決撤銷罰單。」有關拒絕酒測之取締程序，下列敘述何者錯誤？

    1. (A) 應全程錄音、錄影，蒐集相關事證
    2. (B) 應於告發拒測前，詳細逐一告知拒測所有的罰則，缺一不可
    3. (C) 檢測數值超過法定標準時，當事人有權要求依拒測處罰，以維程序正義
    4. (D) 製單舉發後，應當場移置保管其車輛及暫代保管其駕駛執照

    正解：(B)

  2. 2你是派出所員警，在受理民眾報案時，有關開立報案三聯單之處置，下列敘述何者錯誤？

    1. (A) 無刑案現場致不能勘察確認所報案情是否成案，而報案人堅持索取報案三聯單時，受理機關得以書函等書面文件，核實答覆
    2. (B) 立即偵破移送之案件，得免開立三聯單
    3. (C) 民眾單純提供犯罪線索或情資，不須開立報案三聯單
    4. (D) 告訴乃論案件，如不提告訴但報案人要求發給報案證明時，應開立刑案受理紀錄表交付之

    正解：(D)

  3. 3你執行路檢勤務時，經依警察職權行使法第 8 條之規定，攔停一部車輛開始盤查，在符合第 8 條之法定要件時，你得採取之職權措施，下列何者不適當？

    1. (A) 查證乘客之身分
    2. (B) 要求開啟引擎蓋
    3. (C) 要求駕駛人及乘客接受酒精濃度測試之檢定
    4. (D) 強制駕駛人及乘客離車

    正解：(C)

  4. 4你是警勤區員警，於執行勤區查察勤務時，依警勤區訪查作業規定執行該項勤務，下列敘述何者錯誤？

    1. (A) 治安顧慮人口拒絕查訪時，得以側訪或其他方式實施
    2. (B) 發覺可疑犯罪跡象或無法實施查訪時，得以間接方式觀察並記錄可疑處後，提供所長列為勤務規劃重點
    3. (C) 實施訪查勤務後，得提前 40 分鐘返所，將當日訪查概況註記於勤查系統之戶卡片副頁或記事卡副頁
    4. (D) 發現未設籍之他轄治安顧慮人口，應建立暫住人口戶卡片，依規定執行查訪

    正解：(C)

  5. 5你在執行勤區查察勤務時，有熱心民眾反應某戶出入複雜，且大門經常深鎖，可能對該社區有治安疑慮，經你現場觀察該住戶，卻未發現任何異狀，下列何項後續作為最適當？

    1. (A) 婉轉告知民眾自求多福，繼續家戶訪查工作
    2. (B) 商請民眾按鈴進入屋內，查看有無犯罪及不法行為，再視實際狀況作應有的反應
    3. (C) 返所立即清查該戶人口、車輛資料，請大樓管理員協助監控，並告知所長該戶的狀況
    4. (D) 直接敲該戶大門進入屋內，如有發現犯罪及不法行為立即以無線電通知支援警力到場加以逮捕

    正解：(C)

  6. 6甲女至派出所報案指稱：同事乙男對其表達愛慕之意，經其明確拒絕仍持續追求，昨日下班途中發現乙男尾隨，經勸阻仍跟隨至住家，因不堪其擾，請求警方查處。你受理本案，下列處置何者最正確？

    1. (A) 被害人自行勸阻符合社會秩序維護法第 89 條第 2 款「無正當理由，跟追他人，經勸阻不聽者」之勸阻要件，應即進行查處
    2. (B) 社會秩序維護法第 89 條第 2 款之勸阻須由員警以書面為之，提醒甲女注意己身安全，並於第一時間報案
    3. (C) 乙男並未碰觸到甲女身體，尚無不法，請甲女持續蒐證，如發現不法即刻報警
    4. (D) 乙男所為已妨害甲女行使權利，涉及刑法第 304 條強制罪，應報請檢察官核發拘票拘提到案，以避免再生危害

    正解：(A)

  7. 7你是分局偵查佐，發現有逃學逃家少年與犯罪習性之人交往，下列處置何者錯誤？

    1. (A) 依曝險少年移送該管少年法院處理
    2. (B) 依據兒童及少年福利與權益保障法進行通報
    3. (C) 可轉請學校依據學生輔導法提供輔導
    4. (D) 可轉請少年輔導委員會進行輔導

    正解：(A)

  8. 8你是分局偵查佐，偵辦少女裸照遭網友於網路平臺散布案，依據兒童及少年性剝削防制條例規定得請網路平臺業者保留，並提供警察機關調查的相關資料範圍，下列何者錯誤？

    1. (A) 犯罪網頁資料
    2. (B) 特定網友個人資料
    3. (C) 所有會員資料
    4. (D) 網路使用紀錄

    正解：(C)

  9. 9民眾報案，轄內有人在公園內鬧事，經查係甲號召乙、丙、丁至公園與戊、己、庚等 3 人談判後打群架，依刑法第 149 條規定，下列敘述何者錯誤？

    1. (A) 甲以社群通訊軟體號召乙丙丁共同前來，構成「聚集」行為
    2. (B) 如戊己庚等 3 人，持刀、棍、棒球棒等危險物品，現場叫囂，屬意圖為強暴脅迫行為，要加強蒐證
    3. (C) 員警到場處理，現場指揮官命令解散，其形式不拘，口頭命令解散即可
    4. (D) 3 次命令解散可以接續不斷地發布，不須間隔

    正解：(D)

  10. 10你為分局派出所巡邏員警，線上接獲通知轄內發生街頭聚眾鬥毆案件，你聯絡其他同事共同前往現場處理，下列處置作為何者錯誤？

    1. (A) 對現行犯以強制力加以逮捕法辦
    2. (B) 對於在現場未明顯違反刑法或社會秩序維護法者，非管束無法預防其傷害時，得依警察職權行使法予以管束
    3. (C) 如鬥毆致傷害而雙方不提告者，得讓渠等離去
    4. (D) 現場滋事份子全部帶回製作筆錄，離開現場者亦要迅速循線一一通知到案、追查到底

    正解：(C)

  11. 11你正偵辦一件詐欺集團案，經調閱集團犯嫌通信紀錄，你如何利用通聯分析研判犯嫌交往密切之對象？

    1. (A) 分析手機序號
    2. (B) 分析基地臺之位置及行經路徑
    3. (C) 通話次數多寡及通話時間之長短
    4. (D) 通話對象號碼之申租人年齡是否與犯嫌年齡相近

    正解：(C)

  12. 12你是分局偵查隊偵查佐，佈建線民（第三人）蒐集毒販販毒事證及幕後金主，下列處置作為何者錯誤？

    1. (A) 交付線民任務以前，給予必要之訓練
    2. (B) 書面報告警察分局長核准後實施
    3. (C) 線民之真實姓名以代號記錄，予以保密
    4. (D) 運用線民秘密蒐集資料之期間不得逾 1 年，且不得延長

    正解：(D)

  13. 13於新型冠狀病毒（COVID-19）防疫期間，有關警察執行取締酒後駕車交通稽查勤務時，內政部警政署為確保執勤同仁與民眾安全所採行因應的措施，下列敘述何者錯誤？

    1. (A) 暫停酒精檢知器（棒）之使用
    2. (B) 執勤員警全程配戴口罩、手套
    3. (C) 酒精檢測器使用後須以酒精消毒
    4. (D) 全面暫停取締酒駕勤務

    正解：(C)

  14. 14對於違反道路交通管理處罰條例案件，警察當場開單舉發違規，若遇被舉發人拒絕簽章或拒收罰單時，應於通知聯記載何事項，即可視為違規者已收受並具合法送達效力？

    1. (A) 於通知聯記載「當事人拒簽、拒收，已有告知相關規定」
    2. (B) 通知聯「記明事由」並記載「當事人拒簽、拒收」
    3. (C) 通知聯「記明事由」及「交付時間」，並記載「當事人拒簽、拒收」
    4. (D) 通知聯「記明事由」及「交付時間」並「告知其應到案時間及處所」，同時記載「當事人拒簽、拒收」

    正解：(D)

  15. 15你深夜正執行稽查酒後駕車勤務，發現駕駛人甲臉色潮紅，甲堅稱他的膚色本來就比較紅，絕無喝酒，且抱怨經常被攔下檢測非常不滿，當場提出異議，下列處置何者最不適當？

    1. (A) 暫停執行，依甲陳述理由，輔以其他徵候判斷，再決定是否實施呼氣檢測
    2. (B) 告知甲若不配合檢測，將依道路交通管理處罰條例第 35 條第 4 項拒絕檢測舉發
    3. (C) 強制將甲移由醫療或檢驗機構，實施抽血檢測
    4. (D) 告知甲這是警察職權行使法第 8 條之法令規定，請其配合檢測

    正解：(C)

  16. 16你與同事執行路檢勤務，經攔查一部車速忽快忽慢的可疑車輛，該車不聽攔停，反而加速逃逸，你與同事當下判斷予以進行追蹤稽查，並向勤務指揮中心報告，勤務指揮中心指示應注意終止追蹤稽查的時機，注意自身及用路人之安全，有關終止追蹤稽查的時機，下列敘述何者錯誤？

    1. (A) 交通違規稽查目的已達成時
    2. (B) 經該管勤務指揮中心、長官命令終止時或接獲其他任務時
    3. (C) 逃逸車輛速度過快、無法掌握逃逸車輛去向，或其他依當時情形認為目的無法達成，經員警判斷以停止實施為適當者
    4. (D) 騎乘普通重型機車追蹤稽查，遇逃逸車輛進入快速公路上，仍可繼續尾隨追蹤，直至無法掌握逃逸車輛去向時

    正解：(D)

  17. 17「道路交通事故」係指因汽車、動力機械或大眾捷運系統車輛在道路上行駛，致有人受傷或死亡，或致車輛、動力機械大眾捷運系統車輛、財物損壞之事故，下列有關交通事故定義之要件與適用範圍之敘述，何者錯誤？

    1. (A) 至少肇事一方是汽車或動力機械
    2. (B) 須有行駛的交通行為
    3. (C) 公寓大廈之地下停車場亦為道路範圍
    4. (D) 須出於過失或毫無過失之行為

    正解：(C)

  18. 18你擔任備勤勤務，奉派處理一件 A3 車禍，處理即將完成時，當事人詢問你相關資料的提供時程，下列敘述何者錯誤？

    1. (A) 事故現場得申請提供交通事故當事人登記聯單
    2. (B) 事故 7 日後，方得申請閱覽或提供現場圖
    3. (C) 事故 14 日後，方得申請閱覽或提供現場照片
    4. (D) 事故 30 日後，方得申請提供道路交通事故初步分析研判表

    正解：(C)

  19. 19你是派出所的備勤人員，經所長指示你整理派出所的寄存訴訟文書，將過期的訴訟文書依規定處理，你將相關訴訟文書區分成民事、刑事及行政等類後，下列敘述何者錯誤？

    1. (A) 行政訴訟文書逾 2 個月者，得逕予銷燬
    2. (B) 民事訴訟文書逾 2 個月者，得逕予銷燬
    3. (C) 刑事訴訟文書逾 2 個月者，得逕予銷燬
    4. (D) 訴訟文書封套加註其內為證物者，應退回原寄法院

    正解：(A)

  20. 20你為分局偵查隊偵查佐，偵辦販毒案時，拘提逮捕藥頭犯罪嫌疑人甲及乙，有關解送 2 名犯嫌作業，下列作為何者錯誤？

    1. (A) 與解送單位先行聯繫，確定解送交接事項
    2. (B) 對甲、乙搜身並上戒具
    3. (C) 檢查移送卷宗及贓證附件，避免錯漏
    4. (D) 為避免甲、乙勾串，令 1 名犯嫌坐於前座副駕駛座，1 名犯嫌坐於後座

    正解：(D)
