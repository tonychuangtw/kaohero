  1. 1有關電腦各類連接埠的敘述，下列何者正確？

    1. (A) HDMI 介面可同時傳送未經壓縮的視訊及音訊
    2. (B) D-Sub 和 DVI 均屬於視訊介面，D-Sub 傳送數位信號，DVI 則傳送類比信號
    3. (C) 通用序列匯流排（USB）雖支援熱插拔可即插即用，但最多只能同時插接 4 支隨身碟
    4. (D) USB 提供高速的雙向並列傳輸，可用於連接鍵盤、滑鼠、印表機等設備

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) HDMI 以單一線材同時傳送未經壓縮的數位視訊與音訊。

    ❌ (B) D-Sub（VGA）傳送類比訊號，DVI 主要傳送數位訊號，兩者敘述對調。

    ❌ (C) USB 透過集線器可連接的裝置數遠超過 4 個（理論上達 127 個）。

    ❌ (D) USB 是「序列」傳輸而非並列傳輸。

    📚 出處：計算機概論—常見輸出入介面（HDMI、DVI、VGA、USB）。

  2. 2有關電腦升級之敘述，下列何者錯誤？

    1. (A) 將機械式硬碟更換成固態硬碟來提升效能是常見的方式之一
    2. (B) 若要將 CPU 升級，大部分會同時升級主機板，其原因之一是 CPU 插槽型式會不同
    3. (C) 主機板上的 BIOS 會因升級而嚴重毀損，雖硬碟中的作業系統安好，仍可能會無法正常開機
    4. (D) DDR4 和 DDR5 引腳數均為 288 pins，所以 DDR4 的記憶體可以安裝於 DDR5 的主機板插槽上，可減少升級費用

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 錯誤：DDR4 與 DDR5 雖同為 288 pins，但缺口（key）位置與電氣規格不同，彼此不相容，無法互插。

    ❌ (A) 正確：以固態硬碟取代機械硬碟是最有感的升級方式之一。

    ❌ (B) 正確：CPU 插槽規格改變時，升級 CPU 往往須一併更換主機板。

    ❌ (C) 正確：BIOS／UEFI 更新失敗可能導致無法開機，與硬碟中的作業系統無關。

    📚 出處：計算機概論—電腦硬體升級與相容性。

  3. 3下列何者不是使用單一指令流多資料流（single instruction stream multiple data stream，SIMD）所具有的優勢？

    1. (A) 由多個執行單元來分擔控制單元的成本
    2. (B) 減少程式記憶體指令（memory instruction）的用量
    3. (C) 平行處理多筆資料以加速數值運算
    4. (D) 增加分支預測（branch prediction）之正確率

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) SIMD 的優勢在資料層級平行，與分支預測的正確率無關，密集的條件分支反而不利於 SIMD。

    ❌ (A) 多個執行單元共用一套控制單元，可分攤控制邏輯成本。

    ❌ (B) 一道指令同時處理多筆資料，可減少指令數量與擷取次數。

    ❌ (C) 平行處理多筆資料正是 SIMD 加速數值運算的關鍵。

    📚 出處：計算機組織—Flynn 分類與 SIMD 架構。
