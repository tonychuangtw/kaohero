警察特考　103 年 四等考試 警察情境實務概要　考古題與詳解

本卷共 20 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（20 題，建議 60 分鐘）

  1. 1張三因隔壁鄰居於夜間唱卡拉 OK，無法忍受噪音而報警處理，你是前往現場處理的員警，最為適當的處置方式為何？

    1. (A) 因噪音案件非屬警察機關權責，無論噪音大小直接要求環保機關到場查處
    2. (B) 除非是噪音管制區，否則可以不必確認是否為妨害公眾安寧
    3. (C) 如噪音確實傳於戶外，又經鄰居證實難以忍受，可認其為妨害公眾安寧
    4. (D) 不論有無違法情事，直接開具勸導單

    正解：(C)

  2. 2有位老婦人經營一家小雜貨店，當你巡邏經過時，她向你投訴最近有兩位青少年經常在她店面附近徘徊、鬼鬼祟祟，讓 她憂心不已，懷疑他們可能會搶劫，希望你將他們抓起來詢問。根據老婦人的投訴，你最先要採取的行動是什麼？

    1. (A) 告訴老婦人，你會進行調查並做適當的處理
    2. (B) 告訴老婦人，每個人都有行動的自由，你不能限制他們
    3. (C) 告訴老婦人，除非他們有搶劫行為，否則你不能逕行調查
    4. (D) 告訴老婦人，你會直接傳喚這兩位青少年

    正解：(A)

  3. 3你於執行值班勤務時，有一老翁甲前來派出所報案，稱鄰居乙盜摘他家波斯菊一株。你如何處置？

    1. (A) 屬情節輕微，應委婉告知，不予受理
    2. (B) 屬情節輕微，但仍依法受理偵辦
    3. (C) 屬情節輕微，通知兩造雙方和解
    4. (D) 屬情節輕微，斥罵後請其離開

    正解：(B)

  4. 4你是值班員警，民眾報案指稱，其子揚言自殺且已 2 天沒有回家、下落不明，你受理報案後下列何者為優先處置？

    1. (A) 應刊登失蹤人口通報
    2. (B) 應啟動緊急查尋
    3. (C) 應立即通報刑事單位
    4. (D) 應請家屬發動親友協尋

    正解：(B)

  5. 5你於擔任值班時，接獲民眾電話報案稱在某地發生交通事故，你應如何處置？

    1. (A) 先了解是否確為本轄區；如非本轄區內，請該民眾逕向管轄分駐（派出）所報案
    2. (B) 轉報交通隊車禍處理專責小組派員處理
    3. (C) 立即通知線上巡邏同仁先行前往了解，並通知所內備勤同仁待命出勤
    4. (D) 通報勤務指揮中心派遣交通隊車禍處理專責小組派員處理

    正解：(C)

  6. 6你擔服巡邏勤務，接獲通報前往取締違規案件，發現係一名喑啞老者正在商店前騎樓手持口香糖販賣。你應如何處理？

    1. (A) 依社會秩序維護法辦理
    2. (B) 按道路交通管理處罰條例舉發
    3. (C) 依刑法移送檢察機關偵辦
    4. (D) 妥予勸導離開

    正解：(D)

  7. 7你是派出所備勤員警，詢問富少酒駕肇事之 A1 案件，有關詢問筆錄之錄音、錄影事項，下列何者正確？

    1. (A) 應自告知其罪名及權利事項後開始錄
    2. (B) 詢問酒駕案件犯罪嫌疑人時不需錄音
    3. (C) 引起社會大眾關注之重大刑案詢問時應全程連續錄影
    4. (D) 詢問犯罪嫌疑人之錄音帶應保存在詢問單位，不需隨案移送

    正解：(C)

  8. 8你是派出所勤區警員，深夜執勤完畢駕車返家途中，在某科技公司圍牆外發現一部機車前踏板處放置 2 只麻袋，袋口 處露出電纜線，疑似行竊所得，此時有一名男子欲騎乘該機車，你如何處置最適當？

    1. (A) 出示證件表明身分，盤詰詢問該批電纜線來源
    2. (B) 上前搶走機車鑰匙，防止嫌犯騎乘機車逃逸
    3. (C) 因無犯罪證據，先記下機車車號日後需要再查
    4. (D) 打 110 向勤務指揮中心報案，續開車返家休息

    正解：(A)

  9. 9慣竊甲進入某大樓地下停車場，將樓梯間室內消防栓之「射水瞄子」放進隨身包包內，意圖變賣換錢花用，因包包只 能裝四只，手另拿一只準備離去，於大門口恰遇保全人員乙，其發現甲手上拿著消防瞄子，立刻攔下詢問，甲因竊行 曝光欲快速逃逸，乙強行抓住甲並報警。你受理本案，有關乙對甲強行控制行動之適法性，下列敘述何者最為正確？

    1. (A) 甲因犯罪實施中遭發現，有事實足認為犯罪嫌疑重大；係逕行拘提
    2. (B) 甲因有事實足認為其犯罪嫌疑重大，經被盤查而逃逸；係緊急拘提
    3. (C) 甲因在犯罪實施後即時遭發覺；係以現行犯予以逕行逮捕
    4. (D) 甲因持有贓物顯可疑為犯罪人；係準現行犯予以逕行逮捕

    正解：(D)

  10. 10甲與友人到 KTV 唱歌，離去時與乙因言語口角而遭毆傷，事後甲到派出所報案製作筆錄提出傷害告訴，隔天經警方 查證乙身分為大學生，甲為免影響乙前途於是接受和解，前往派出所表示要撤回對乙的傷害告訴並再次製作筆錄。你 是分局負責承辦本案之偵查佐，應如何處理？

    1. (A) 傷害為告訴乃論案件，當事人已明確表示撤回告訴，應即結案歸檔
    2. (B) 當事人雖撤回告訴，仍應將案卷保存 6 個月後再結案歸檔
    3. (C) 當事人雖撤回告訴，仍將案件函送管轄地檢署
    4. (D) 當事人雖撤回告訴，仍應追蹤完成和解再予結案歸檔

    正解：(C)

  11. 11你於巡邏時，接獲民眾報案，到達命案現場時，發現被害人已死亡，此時最優先處理之事項為何？

    1. (A) 搜索現場，發現證物
    2. (B) 翻找被害人衣服口袋，明瞭其身分
    3. (C) 退出並封鎖現場
    4. (D) 查訪附近民眾

    正解：(C)

  12. 12派出所值班人員接到民眾有關道路交通事故之電話報案後，指派備勤的你去處理，當你備妥處理事故裝備抵達事故現 場之後，面對事故現場之情境，下列何者是你應最優先做的工作？

    1. (A) 了解事故傷患嚴重狀況
    2. (B) 執行現場警戒措施
    3. (C) 排除現場阻塞車輛
    4. (D) 請求支援人力

    正解：(B)

  13. 13你正在執行路檢勤務，發現前方有一輛機車噪音頗大，攔停檢查該機車發現排氣管經過改裝，尾管角度明顯朝上（翹 管），你應如何處置？

    1. (A) 開具勸導單請其簽名後放行
    2. (B) 依道路交通管理處罰條例製單舉發
    3. (C) 扣留機車，通知監理機關派員檢查
    4. (D) 非警察權責，直接放行

    正解：(B)

  14. 14日前轄區發生 3 人死亡之重大交通事故，你是分局交通事故處理承辦人，辦理現地會勘，發現部分痕跡（如煞車痕） 與事故當日交通分隊處理員警繪製之現場（草）圖有所出入，會勘後作成紀錄，對於現場（草）圖你應如何處置最為 恰當？

    1. (A) 自行塗改修正現場圖與現場草圖
    2. (B) 自行重新繪製現場圖，並留存原現場草圖
    3. (C) 請交通分隊重新繪製現場圖，並留存原現場草圖
    4. (D) 請交通分隊重新繪製現場圖，並修正現場草圖

    正解：(C)

  15. 15你執行取締砂石車違規勤務，發現一砂石車疑似超載，予以攔停並前往過磅，該車核定總重量不得超過 42 公噸，經 測量結果該車輛為 55 公噸，超載 13 公噸，惟該地磅之有效測量上限為 50 公噸，此時你應如何處置最恰當？

    1. (A) 超載為既成事實，依過磅結果逕予製單舉發
    2. (B) 已超出地磅有效量測範圍，製單恐有爭議，不予舉發，人車放行
    3. (C) 超出地磅有效量測範圍部分，不予舉發，其餘超載重量正常舉發
    4. (D) 另以量測上限超過 55 公噸之合格地磅進行過磅，確認違規情形

    正解：(D)

  16. 16甲發生道路交通事故後，欲與對方和解，遂向警察機關申請閱覽及提供相關資料，你受理本案，下列選項何者敘述錯 誤？

    1. (A) 於事故當場得申請提供道路交通事故當事人登記聯單
    2. (B) 於事故 7 日後得申請閱覽或提供現場圖
    3. (C) 於事故 7 日後得申請閱覽或提供現場照片
    4. (D) 於事故 30 日後得申請提供道路交通事故證明書

    正解：(D)

  17. 17你於執行交通稽查勤務時，舉發汽車所有人、駕駛人或攤商違反道路交通管理事件，依規定須代保管物件時，下列選 項何者錯誤？

    1. (A) 已領有號牌而未懸掛或不依指定位置懸掛，應當場代保管其行車執照
    2. (B) 酒精濃度超過規定標準因而肇事致人死亡，當場暫代保管其駕駛執照
    3. (C) 拼裝車輛未經核准領用牌證行駛，當場暫代保管其車輛
    4. (D) 未經許可在道路擺設攤位，暫代保管其攤棚、攤架

    正解：(A)

  18. 18某公職人員選舉投票所設置在某國小教室內，你係該投票所之警衛人員，下列何者為應予管制進入之對象？

    1. (A) 配帶選舉委員會製發證件者
    2. (B) 身心障礙選舉人之陪同家屬
    3. (C) 該校校長
    4. (D) 依法執行職務之檢察官

    正解：(C)

  19. 19為利守望相助組織有效協助維護治安，可利用巡邏、勤查等機會對其訪視、聯繫及宣導，你是警勤區警員，下列何者 非宣導守望相助組織協助事項？

    1. (A) 協助巡邏守護
    2. (B) 提供犯罪線索
    3. (C) 奮力逮捕竊盜犯
    4. (D) 協助急難救護

    正解：(C)

  20. 20你擔服投票所警衛勤務，高齡選民甲領取選票並圈選後，因發現圈錯候選人，情急下即將該選票撕毀，此時你採取何 項處置最適當？

    1. (A) 交由主任監察員依權責決定是否送辦
    2. (B) 主任管理員交辦，並請支援員警予以帶案移送法辦
    3. (C) 念甲非出於不良意圖，擅自告誡後放行
    4. (D) 念甲高齡疏忽，再提供一張選票重新圈選

    正解：(B)
