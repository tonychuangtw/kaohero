營養師　104 年第二次 食品衛生與安全　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何種食物不屬於潛在危害性食品（potentially hazardous foods, PHF）？

    1. (A) 煮熟的牛排
    2. (B) 煮熟的米飯
    3. (C) 乾燥的麵粉
    4. (D) 截切的甜瓜

    正解：(C)

  2. 2根據民國 103 年 11 月 7 日訂定「食品良好衛生規範準則」之規定，消毒抹布時應以 100°C 沸水至少煮沸多少分鐘？

    1. (A) 1
    2. (B) 2
    3. (C) 5
    4. (D) 10

    正解：(C)

  3. 3依據民國 104 年 2 月 4 日修正「食品安全衛生管理法」之規定，屠宰場內畜禽屠宰及分切衛生檢查之主管機關為：

    1. (A) 行政院農業委員會
    2. (B) 衛生福利部食品藥物管理署
    3. (C) 縣市政府衛生局
    4. (D) 經濟部標準檢驗局

    正解：(A)

  4. 4從事繁殖實驗時，若以鼠或鼷鼠進行試驗，至少需要多少隻鼠或鼷鼠？

    1. (A) 20
    2. (B) 40
    3. (C) 80
    4. (D) 160

    正解：(D)

  5. 5下列何種方式可以防止糊化過的澱粉食品產生回凝現象？

    1. (A) 迅速脫水
    2. (B) 冷藏
    3. (C) 冷凍
    4. (D) 充氮氣頁次：4－2

    正解：(A)

  6. 6細菌在下列那一生長階段時，對消毒劑等化學藥品之感受性最高？

    1. (A) 誘導期（lag phase）
    2. (B) 指數期（log phase）
    3. (C) 定常期（stationary phase）
    4. (D) 死滅期（death phase）

    正解：(B)

  7. 7中濕性食品（intermediate moisture foods）的製作原理是利用高糖或高鹽降低食品水活性，以抑制微生物的生長，則中濕性食品的水活性是多少？

    1. (A) 0.20～0.40
    2. (B) 0.40～0.60
    3. (C) 0.60～0.85
    4. (D) 0.85～0.95

    正解：(C)

  8. 8酵素是造成食品劣變的重要因素之一，下列何者與酵素引起的劣變反應無關？

    1. (A) 未殺菁豌豆產生豆青味
    2. (B) 糙米貯藏期間酸敗
    3. (C) 牛排炭烤產生煙燻味
    4. (D) 蘋果削皮後變色

    正解：(C)

  9. 9下列何者不屬於飲料類的衛生標準檢測項目？

    1. (A) 生菌數
    2. (B) 大腸桿菌群
    3. (C) 大腸桿菌
    4. (D) 腸球菌屬

    正解：(D)

  10. 10有關低酸性罐頭平酸腐敗（flat sour spoilage）之敘述，下列何者正確？

    1. (A) 腐敗時，罐頭外觀無膨罐
    2. (B) 腐敗時，罐內食品無酸味
    3. (C) 酵母菌所造成
    4. (D) 乳酸菌所造成

    正解：(A)

  11. 11有關肉製品中添加亞硝酸鹽的危害／利益分析，下列敘述何者錯誤？

    1. (A) 可保持肉製品鮮紅的顏色
    2. (B) 可抑制肉製品中肉毒桿菌的生長
    3. (C) 過量添加亞硝酸鹽的肉製品會有致癌的可能性
    4. (D) 肉製品添加亞硝酸鹽目前並無用量限制

    正解：(D)

  12. 12何謂半致死劑量（median lethal concentration）？

    1. (A) 給予此劑量的 1/2 倍時，可導致 50%動物死亡
    2. (B) 給予此劑量時，可導致 50%之動物死亡
    3. (C) 給予此劑量時，可導致 100%之動物死亡
    4. (D) 給予此劑量的 2 倍時，可導致 100%之動物死亡

    正解：(B)

  13. 13在食品之安全性評估中，常用於致突變原試驗分析之安姆氏試驗法（Ames test）乃是利用一系列對於組胺酸合成有缺陷之何種微生物的變異株做為實驗菌株？

    1. (A) 大腸桿菌
    2. (B) 酵母菌
    3. (C) 沙門氏菌
    4. (D) 乳酸菌

    正解：(C)

  14. 14致癌性試驗通常可與下列何種試驗合併進行，可以看出測試物質之毒性與致癌性？

    1. (A) 亞急性毒性試驗
    2. (B) 慢性毒性試驗
    3. (C) 致畸胎試驗
    4. (D) 繁殖試驗

    正解：(B)

  15. 15健康食品安全性評估分類時，若產品之原料為傳統食用而非以通常加工食品形式供食者，其分類屬於下列何者？

    1. (A) 第一類
    2. (B) 第二類
    3. (C) 第三類
    4. (D) 第四類

    正解：(B)

  16. 16有關食品安全性評估之敘述，下列何者錯誤？

    1. (A) 一般而言，慢性毒性在試驗前須先進行 28 天或 90 天的短期重複劑量毒性試驗
    2. (B) 由最大無作用量（no observable effect level）可求得每日攝取安全容許量（acceptable daily intake）
    3. (C) 安姆氏試驗法（Ames test）時所使用的 S-9 mixture（S-9 microsomal fraction）是由哺乳類動物肝臟離心分離而來
    4. (D) 由致癌性實驗結果，會引起實驗動物致癌之物質表示一定會引起人類癌症的發生頁次：4－3

    正解：(D)

  17. 17有關洗潔劑（detergents）之敘述，下列何者錯誤？

    1. (A) 大多數洗潔劑之主要成分為界面活性劑
    2. (B) 我國目前家庭用洗潔劑以軟性洗潔劑為主
    3. (C) 軟性洗潔劑又稱為直鏈式烷基苯磺酸鹽（linear alkylbenzene sulfonate, LAS）
    4. (D) 軟式洗潔劑之生物毒性較硬式洗潔劑弱，且在環境中較不易受微生物分解

    正解：(D)

  18. 18俗稱的美耐皿樹脂係一種熱硬化性樹脂，其主要是由三聚氰胺和下列何者反應聚合而成？

    1. (A) 甲醇
    2. (B) 甲醛
    3. (C) 甲酸
    4. (D) 甲苯

    正解：(B)

  19. 19吊白塊（rongalite）曾被違法使用於米粉的漂白，其中因含有下列何種物質而會造成中毒症狀？

    1. (A) 乙醛
    2. (B) 硫酸鈉
    3. (C) 甲醛
    4. (D) 氫氧化鈉

    正解：(C)

  20. 20保麗龍容器在下列何種溫度以上，即會收縮變形，釋出單體？

    1. (A) 70°C
    2. (B) 80°C
    3. (C) 90°C
    4. (D) 160°C

    正解：(C)

  21. 21下列何者屬「氧化性漂白劑」？

    1. (A) 過氧化氫
    2. (B) 亞硝酸鹽
    3. (C) 苯甲酸
    4. (D) 矽藻土

    正解：(A)

  22. 22下列何者是目前最常做為工廠或家庭洗潔劑之界面活性劑種類？

    1. (A) 陰離子系（anionic）
    2. (B) 陽離子系（cationic）
    3. (C) 兩性系（amphoteric）
    4. (D) 非離子系（nonionic）

    正解：(A)

  23. 23關於「米糠油中毒事件」之敘述，下列何者錯誤？

    1. (A) 與多氯聯苯有關
    2. (B) 因熱媒管線破裂，導致油脂受污染
    3. (C) 曾於 1979 年發生在臺灣中部地區
    4. (D) 中毒者主要出現全身骨頭疼痛現象

    正解：(D)

  24. 24針對致癌性試驗結果的判定，下列何者無法據以判定為陽性反應？

    1. (A) 試驗組發現致癌現象較晚
    2. (B) 試驗組腫瘍面積較對照組大
    3. (C) 試驗組癌症型態較對照組多
    4. (D) 試驗組腫瘤發生頻率較對照組高

    正解：(A)

  25. 25關於重金屬與中毒事件，下列何者正確？

    1. (A) 汞－日本森永奶粉中毒事件
    2. (B) 銅－我國烏腳病事件
    3. (C) 鉛－我國綠牡蠣事件
    4. (D) 鎘－日本九州痛痛病事件

    正解：(D)

  26. 26下列何種胺基酸可能是食品加熱反應產物丙烯醯胺的主要前驅物質？

    1. (A) 離胺酸（lysine）
    2. (B) 半胱胺酸（cysteine）
    3. (C) 天門冬醯胺酸（asparagine）
    4. (D) 蘇胺酸（threonine）

    正解：(C)

  27. 27有關萊克多巴胺（ractopamine）的敘述，下列何者錯誤？

    1. (A) 常被添加於動物飼料中，為用來使家畜增長瘦肉的乙型交感神經受體致效劑
    2. (B) 我國規定牛肉中的萊克多巴胺最高容許量為 0.01 ppm
    3. (C) 我國規定豬肉中的萊克多巴胺最高容許量為 0.01 ppm
    4. (D) 萊克多巴胺主要會殘留於動物的肝臟與肺臟中頁次：4－4

    正解：(C)

  28. 28關於「戴奧辛（dioxin）」之敘述，下列何者錯誤？

    1. (A) 可經由垃圾、廢五金、廢電纜等燃燒而產生
    2. (B) 生物濃縮性高，容易經由食物鏈轉移至人體中
    3. (C) 大量食用高脂肪食物，則攝入多量戴奧辛的機率亦相對提高
    4. (D) 1955 年日本森永奶粉事件乃戴奧辛污染所造成

    正解：(D)

  29. 29可能存在鮑魚中腸腺中的 Pyropheophorbide a，歸屬於下列何類毒素？

    1. (A) 健忘性貝毒（amnesic shellfish poison, ASP）
    2. (B) 神經性貝毒（neurotoxic shellfish poison, NSP）
    3. (C) 光過敏毒素（photosensitizing toxin）
    4. (D) 麻痺性貝毒（paralytic shellfish poison, PSP）

    正解：(C)

  30. 30下列何者不是黴菌毒素？

    1. (A) aflatoxin
    2. (B) tetrodotoxin
    3. (C) tricothecene
    4. (D) ochratoxin

    正解：(B)

  31. 31下列何種 HACCP 監控方法是相對費時，對講求時效的監測目的來說，並非有效的監控方法？

    1. (A) 官能檢查
    2. (B) 物理檢驗
    3. (C) 化學檢驗
    4. (D) 微生物檢驗

    正解：(D)

  32. 32將 20 mL 含有 8%有效氯之漂白水，加入 20 公升之水中，所配成之消毒水其有效氯濃度為多少 ppm？

    1. (A) 200
    2. (B) 160
    3. (C) 120
    4. (D) 80

    正解：(D)

  33. 33依據民國 103 年 11 月 7 日訂定「食品良好衛生規範準則」之規定，承攬學校餐飲之餐飲業僱用之烹調從業人員應具有中餐烹調技術士證，其持證比例為多少%？

    1. (A) 90
    2. (B) 80
    3. (C) 70
    4. (D) 60

    正解：(C)

  34. 34針對鍋爐中的礦物成分沉積物的清洗，宜用下列何種洗潔劑？

    1. (A) 酸性洗潔劑
    2. (B) 中性洗潔劑
    3. (C) 鹼性洗潔劑
    4. (D) 強鹼性洗潔劑

    正解：(A)

  35. 35下列敘述，何者正確？

    1. (A) 與餐飲衛生安全有關之細菌，通常其耐熱性均較高
    2. (B) 紫外線殺菌又稱為冷殺菌法，最大之優點除了不會對食品產生熱破壞外，又可達到深度殺菌之效果
    3. (C) 煮沸是最早使用的消毒法之一，其可適用於任何大小型之容器、器具、餐具等之消毒
    4. (D) 濕熱法較乾熱法有較佳的殺菌功效

    正解：(D)

  36. 36當製程使用之調理機械生鏽時，可用下列何種方法除鏽後再使用？

    1. (A) 15%硝酸
    2. (B) 200 ppm 漂白水
    3. (C) 丙酮
    4. (D) 75%酒精

    正解：(A)

  37. 37102 年發生黑輪、粉圓、粄條等食品中使用違法化製澱粉事件，此違法原料澱粉是經下列何種物質處理？

    1. (A) 塑化劑
    2. (B) 三聚氰胺
    3. (C) 萊克多巴胺
    4. (D) 順丁烯二酸酐

    正解：(D)

  38. 38下列何者是我國收載的食品添加物？

    1. (A) GABA
    2. (B) rutin
    3. (C) biotin
    4. (D) glutathion

    正解：(C)

  39. 39我國於 100 年間爆發之起雲劑事件，係因非法添加何種物質至食品中引起社會譁然？

    1. (A) 鹼式磷酸鋁鈉（sodium aluminum phosphate, basic）
    2. (B) 單及雙脂肪酸甘油二乙醯酒石酸酯（diacetyl tartaric acid esters of mono-and diglycerides）
    3. (C) 阿拉伯膠（gum Arabic）
    4. (D) 鄰苯二甲酸二（2-乙基己基）酯（di-(2-ethylhexyl) phthalate）

    正解：(D)

  40. 40無鉤絛蟲（Taenia saginata）主要是經由畜肉感染的寄生蟲，其中間宿主是：

    1. (A) 人
    2. (B) 魚
    3. (C) 豬
    4. (D) 牛

    正解：(D)
