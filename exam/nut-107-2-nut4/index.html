營養師　107 年第二次 團體膳食設計與管理　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1某學生自助餐廳，每餐供應 1000 人份，每人可由主菜 4 選 1、半葷菜 10 選 2、蔬菜 5 選 1，試問主菜、半葷菜、蔬菜每道菜至少需製作多少人份？

    1. (A) 主菜 250 人份、半葷菜 200 人份、蔬菜 200 人份
    2. (B) 主菜 250 人份、半葷菜 150 人份、蔬菜 250 人份
    3. (C) 主菜 300 人份、半葷菜 200 人份、蔬菜 150 人份
    4. (D) 主菜 300 人份、半葷菜 100 人份、蔬菜 250 人份

    正解：(A)

  2. 2團膳設計應考慮食材的季節性，請問下列何者不適宜？

    1. (A) 冬季使用大白菜
    2. (B) 夏天使用空心菜
    3. (C) 夏季使用茼蒿
    4. (D) 冬天使用白蘿蔔

    正解：(C)

  3. 3空心菜 120 g（AP，生），廢棄物 20 g，煮後（EP，熟）80 g，則其煮熟後之膨脹收縮率（熟重/生重）為多少百分比？

    1. (A) 17%
    2. (B) 67%
    3. (C) 80%
    4. (D) 83%頁次： 4－2

    正解：(C)

  4. 4菜單設計中依食物的特性與搭配，下列何者較適當？

    1. (A) 炸肉排、黃椒炒肉絲、炒高麗菜
    2. (B) 糖醋雞丁、三椒炒肉絲、燙地瓜葉
    3. (C) 紅燒牛肉、苦瓜鹹蛋、滷海帶
    4. (D) 宮保雞丁、麻婆豆腐、炒空心菜

    正解：(B)

  5. 5有關麵食的製備，下列敘述何者正確？

    1. (A) 特高筋麵粉適合製作蛋糕類食品
    2. (B) 高筋麵粉適合製作小西餅食品
    3. (C) 中筋麵粉適合製作中式點心
    4. (D) 低筋麵粉適合製作麵包類食品

    正解：(C)

  6. 6依據食品良好衛生規範準則，食品業者之蓄水池（塔、槽）應保持清潔，設置地點應距污穢場所、化糞池等污染源多少公尺以上？

    1. (A) 15 公尺
    2. (B) 10 公尺
    3. (C) 6 公尺
    4. (D) 3 公尺

    正解：(D)

  7. 7依據經濟訂購量（EOQ, economic order quantity）法，下列那一項為食材採購時不需考慮之因素？

    1. (A) 預估總營業額
    2. (B) 每次訂購的花費成本
    3. (C) 單項食材的年度需要量與單價
    4. (D) 流通成本百分比

    正解：(A)

  8. 8豆干驗收 3 小時後才使用，應該如何處理？

    1. (A) 先貯存於乾料庫
    2. (B) 直接置放於製備區台面上
    3. (C) 先貯存於冷藏室
    4. (D) 用水浸泡存放於室溫

    正解：(C)

  9. 9關於盤存目的，下列敘述何者正確？①每天需要知道每一項目的數量 ②了解物品的生產地 ③提供食物成本掌控的數據 ④決定採購的需求

    1. (A) ①②
    2. (B) ①③
    3. (C) ②③
    4. (D) ③④

    正解：(D)

  10. 10食品存貨量最少時進行之盤點方式稱為：

    1. (A) 定期盤點（periodic inventory）
    2. (B) 下限盤點（lower limit inventory）
    3. (C) 永續盤點（perpetual inventory）
    4. (D) 全部盤點（all inventory）

    正解：(B)

  11. 11下列何種食品驗收時需要全數檢查？

    1. (A) 5 罐 9 頭鮑魚罐頭
    2. (B) 30 包 60 公斤圓糯米
    3. (C) 22 公斤小白菜
    4. (D) 30 箱 12 顆裝復興鄉水蜜桃

    正解：(A)

  12. 12關於驗收時間的安排，下列何種安排較佳？

    1. (A) 不同供應廠商，安排在同一時段驗收
    2. (B) 盒裝豆腐，可隨時驗收
    3. (C) 在同一時段驗收肉、魚、乾貨、蔬菜等食品
    4. (D) 常溫魚、肉驗收，安排在中午時刻

    正解：(B)

  13. 13秋刀魚用烤的作法較清蒸好吃，是因為：

    1. (A) 含油脂較高
    2. (B) 魚肉纖維細嫩
    3. (C) 含油脂較低
    4. (D) 魚肉纖維粗

    正解：(A)

  14. 14下列對麵粉的敘述，何者正確？

    1. (A) 麵粉筋度越高，蛋白質含量越低
    2. (B) 油條、春捲皮使用低筋麵粉製作
    3. (C) 需要酥性的餅乾、派皮使用低筋麵粉製作
    4. (D) 粉心麵粉蛋白質含量較低筋麵粉低

    正解：(C)

  15. 15下列何種蔬菜貯存於室溫中可以保存最久？

    1. (A) 冬瓜
    2. (B) 苦瓜
    3. (C) 絲瓜
    4. (D) 大黃瓜

    正解：(A)

  16. 16有關「全穀產品」之宣稱，下列敘述何者正確？

    1. (A) 產品原料需 100%為全穀者始可宣稱「全穀產品」
    2. (B) 產品所含全穀成分占配方總重量 51%以上者始可宣稱「全穀產品」
    3. (C) 全穀來源涵括可供人類食用之禾穀類、仿穀類及油脂種子類
    4. (D) 全穀係指包括胚芽及胚乳部位之穀類頁次：4－3

    正解：(B)

  17. 17米粉是用下列何種米漿混合玉米澱粉製作而成？

    1. (A) 在來米
    2. (B) 蓬萊米
    3. (C) 糯米
    4. (D) 綠豆澱粉

    正解：(A)

  18. 18關於烹製蔬菜之程序，下列敘述何者錯誤？

    1. (A) 同鍋川燙蔬菜時，應先加醋川燙白色蔬菜，後加鹽再川燙綠色蔬菜
    2. (B) 炒菜時應在早期先下鹽巴
    3. (C) 葉片較薄、莖較少之蔬菜，可不用川燙，直接分次炒熟
    4. (D) 青江菜炒製時，應將莖與葉分開炒熟，或先將莖炒至 5 分熟後，再下葉炒熟

    正解：(A)

  19. 19團膳機構菜餚留檢樣品的保存原則為：

    1. (A) 冷藏 7℃一天
    2. (B) 冷凍-18℃一天
    3. (C) 冷藏 7℃二天
    4. (D) 冷凍-18℃二天

    正解：(C)

  20. 20根據食品良好衛生規範準則，廚師證書有效期間為多久？期滿展延，每年至少需接受幾小時衛生講習？

    1. (A) 四年，8 小時
    2. (B) 四年，12 小時
    3. (C) 六年，8 小時
    4. (D) 六年，12 小時

    正解：(A)

  21. 21關於有效餘氯水之使用，下列敘述何者錯誤？

    1. (A) 洗手，200 ppm
    2. (B) 地板清潔，300～350 ppm
    3. (C) 碗盤消毒，200 ppm
    4. (D) 生菜洗滌，50～100 ppm

    正解：(B)

  22. 22做為裝飾用的生鮮食材，應先經過有效洗滌及減菌措施後擺飾，下列做法那些正確？①川燙、殺菁 ②以醋酸液清洗 ③以 50～100 ppm 之氯液清洗 ④浸泡鹽水清洗 ⑤以 RO 可生飲水清洗

    1. (A) ①②③
    2. (B) ①②⑤
    3. (C) ②③④
    4. (D) ③④⑤

    正解：(A)

  23. 23在團膳公司，一般微波爐放置在下列何處？

    1. (A) 前處理區
    2. (B) 製備區
    3. (C) 配膳區
    4. (D) 驗收區

    正解：(C)

  24. 24捕蚊燈應設置在下列何處？

    1. (A) 驗收區
    2. (B) 前處理區
    3. (C) 製備區
    4. (D) 餐具洗滌區

    正解：(A)

  25. 25洗滌蔬菜類的水槽，以下列何種為宜？

    1. (A) 深且寬大
    2. (B) 深且細窄
    3. (C) 淺且寬大
    4. (D) 淺且細窄

    正解：(A)

  26. 26關於食品作業場之廁所設置，下列敘述何者正確？

    1. (A) 化糞池與地下水水源至少應保持 12 公尺距離
    2. (B) 化糞池與蓄水池應距離 2 公尺以上
    3. (C) 廁所內牆壁應標示「如廁後請洗手」之字樣
    4. (D) 廁所不得正面開向食品作業場所

    正解：(D)

  27. 27下列有關建立團膳公司「工作說明書」與「工作詳細規範說明」的順序何者正確？

    1. (A) 任務分析→工作分析→工作說明書→工作詳細規範說明
    2. (B) 工作分析→任務分析→工作說明書→工作詳細規範說明
    3. (C) 工作詳細規範說明→工作說明書→任務分析→工作分析
    4. (D) 工作詳細規範說明→工作說明書→工作分析→任務分析

    正解：(A)

  28. 28明列一項職位所需完成的工作、負責的職掌和責任的是：

    1. (A) 工作說明
    2. (B) 工作績效
    3. (C) 職務規範
    4. (D) 組織規劃頁次： 4－4

    正解：(A)

  29. 29下列那一項團膳業的經營成本會隨著營業額高低而改變？

    1. (A) 保險費
    2. (B) 租金費
    3. (C) 食材費
    4. (D) 折舊費

    正解：(C)

  30. 30XYZ 餐廳今天銷售 500 份廣東粥，花了 15,000 元食物費用，經計算後獲得食物成本是 30%，請問每份廣東粥售價多少元？

    1. (A) 50
    2. (B) 100
    3. (C) 150
    4. (D) 200

    正解：(B)

  31. 31胡椒蝦餐廳每月之營業額為 300 萬，固定成本為 100 萬，利潤為 80 萬， 則變動成本率為多少%？

    1. (A) 40
    2. (B) 46
    3. (C) 52
    4. (D) 58

    正解：(A)

  32. 32團體膳食機構作菜單分析時，若一道菜的售價為 250 元，變動成本為 70 元，則此道菜的貢獻額（contribution margin）有多少元？

    1. (A) 120
    2. (B) 150
    3. (C) 180
    4. (D) 210

    正解：(C)

  33. 33下列何者不會因銷售量之變動而變動？

    1. (A) 固定成本
    2. (B) 食物成本
    3. (C) 變動成本
    4. (D) 利潤率

    正解：(A)

  34. 34為了避免病媒入侵，在學校廚房出入口應設置保護設施，下列何者除外？

    1. (A) 紗窗
    2. (B) 紗門
    3. (C) 空氣簾
    4. (D) 負壓系統設施

    正解：(D)

  35. 35從業人員之個人衛生亦包含員工的良好工作態度，則下列敘述何者錯誤？

    1. (A) 餐具掉落地上，應撿起擦拭後使用
    2. (B) 桌椅隨時刷洗或用布擦乾淨
    3. (C) 碗、碟、刀、叉應用托盤端送
    4. (D) 應用公筷母匙以免傳染細菌

    正解：(A)

  36. 36「自主衛生檢查」是指團膳業者應自動建立一套符合自己機構需求的檢查制度，以確保餐廳廚房的最佳衛生狀態，則下列敘述何者錯誤？

    1. (A) 對於調理用膳等場所衛生，加熱保溫食品不得低於 65℃
    2. (B) 對於餐盒業衛生管理中「調理」項目，熱藏溫度在 60℃以上，並有溫度指示裝置
    3. (C) 對於調理用膳等場所衛生，應有足夠而清潔之冷凍、冷藏設備，溫度須保持冷藏溫度在 0～10℃以上；冷凍－18℃以上
    4. (D) 對於餐盒業衛生管理中「調理」項目，冷藏溫度在 0～7℃以上；冷凍溫度在－18℃以下；並有溫度指示裝置

    正解：(C)

  37. 37我國國家標準定義「容器，指以任何形式將食品加以全部或部分包裝使成為販賣之用」，則下列何種原料的容器使用錯誤？

    1. (A) 聚乙烯質材可以包裹蔬菜與水果
    2. (B) 聚苯乙烯裝可樂、汽水
    3. (C) 陶瓷器裝高溫熱湯
    4. (D) 聚氯乙烯質材裝酒精、水

    正解：(D)

  38. 38下列何種方式為大量冷凍肉品之最佳解凍方式？

    1. (A) 熱水中解凍
    2. (B) 流水解凍
    3. (C) 冷藏庫解凍
    4. (D) 室溫解凍

    正解：(C)

  39. 39製作冰淇淋要達到細膩口感，需將蛋白打到那一個階段？

    1. (A) 起始擴展期
    2. (B) 濕性發泡期
    3. (C) 硬性發泡期
    4. (D) 乾性發泡期

    正解：(C)
