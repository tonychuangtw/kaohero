營養師　106 年第二次 食品衛生與安全　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1依據餐具清洗良好作業指引，經洗淨乾燥之餐具置於暫存區不得超過多少分鐘，然後應立即送至清潔區放置？

    1. (A) 30
    2. (B) 60
    3. (C) 90
    4. (D) 120

    正解：(A)

  2. 2依據健康食品管理法以及健康食品管理法施行細則之規定，健康食品應以中文及通用符號顯著標示其核准之功效於其容器、包裝或說明書上，上述核准之功效其字體之長度及寬度各不得小於多少毫米？

    1. (A) 2
    2. (B) 3
    3. (C) 4
    4. (D) 5

    正解：(A)

  3. 3依據我國 GHP 準則，食品製造業者若非使用自來水，應針對淨水或消毒之效果指定專人每日做下列那兩種測定，並做成紀錄？

    1. (A) 酸鹼值與總菌數量
    2. (B) 大腸桿菌群與有效餘氯量
    3. (C) 酸鹼值與有效餘氯量
    4. (D) 總菌數量與濁度

    正解：(C)

  4. 4依據食品安全衛生管理法之規定，有關食品標示管理之敘述，下列何者正確？

    1. (A) 鮮乳除須標示有效日期外，尚須標示保存期限及保存條件
    2. (B) 內容物名稱並不需要依含量多寡依序標示
    3. (C) 食品添加物若為二種以上混合物時，只需標示主成分
    4. (D) 進口食品或散裝食品不需標示原產地（國）頁次： 4－2

    正解：(A)

  5. 5食品加工環境的表面污染利用「擦抹試驗」及合併那一種方法得以做出及時評估？

    1. (A) 電阻抗法（electrical impedance methods）
    2. (B) 直接鏡檢數（direct microscopic count）
    3. (C) 平板計數法（plate counts）
    4. (D) ATP 光度測定法（ATP photometry）

    正解：(D)

  6. 6下列何者不是食品腐敗的現象？

    1. (A) 脂質氧化後的酸敗
    2. (B) 蔬果與空氣接觸後產生褐變
    3. (C) 水果經乾燥後體積縮小
    4. (D) 吐司片上長出綠色菌絲

    正解：(C)

  7. 7每公克、每毫升或每平方公分食品表面之微生物達到多少數量，可視為食品初期腐敗的階段？

    1. (A) 104 個菌
    2. (B) 105 個菌
    3. (C) 106 個菌
    4. (D) 107 個菌

    正解：(C)

  8. 8冷藏與冷凍是減少食品腐敗之重要方法，下列可抑制細菌生長及細菌繁殖的冷藏與冷凍溫度組合為何？

    1. (A) 1℃及-7℃
    2. (B) 4℃及-10℃
    3. (C) 5℃及-15℃
    4. (D) 7℃及-18℃

    正解：(D)

  9. 9下列何者為高靜水壓加工技術抑制微生物生長之原理？

    1. (A) 破壞細菌細胞中蛋白質及細胞膜組成
    2. (B) 減少食品中細菌細胞可利用之營養成分
    3. (C) 降低食品中之水活性
    4. (D) 降低食品中之 pH 值

    正解：(A)

  10. 10牛乳經巴氏殺菌後控制腐敗的方法，下列何者錯誤？

    1. (A) 改善充填環境
    2. (B) 冷藏保存
    3. (C) 無菌包裝
    4. (D) 真空包裝

    正解：(D)

  11. 11關於食品衛生安全指標菌之敘述，下列何者錯誤？

    1. (A) 指標菌之檢出量與受測食品品質呈正相關
    2. (B) 可代表食品受污染的程度和可能性
    3. (C) 可取代病原菌之檢測，以降低篩檢時間及人力耗費
    4. (D) 在食品中檢出指標菌超出標準，即表示該食品衛生狀態不良

    正解：(A)

  12. 12下列何種微生物不是我國包裝飲用水的衛生標準之指標菌？

    1. (A) 大腸桿菌群
    2. (B) 糞便性鏈球菌
    3. (C) 沙門氏菌
    4. (D) 綠膿桿菌

    正解：(C)

  13. 13在建構食品 HACCP 系統中，下列何項指標較適合作為避免微生物危害的管制界限？

    1. (A) pH 值
    2. (B) 水活性
    3. (C) 總菌數
    4. (D) 溫度與時間

    正解：(D)

  14. 14口服急性毒性試驗依 LD50 值等級分類，其 LD50 至少須大於下列何者濃度始可定義為相對無毒？

    1. (A) 10 g/kg
    2. (B) 15 g/kg
    3. (C) 20 g/kg
    4. (D) 25 g/kg

    正解：(B)

  15. 15依據我國現行健康食品管理法，健康食品安全性評估分類中，那一個類別產品不需檢具基因毒性試驗之測試資料？

    1. (A) 第一類
    2. (B) 第二類
    3. (C) 第三類
    4. (D) 第四類

    正解：(A)

  16. 16根據健康食品管理法，健康食品安全性評估中，產品之原料非屬傳統食用者，需檢附何種試驗資料？

    1. (A) 急性毒性試驗
    2. (B) 致癌性試驗
    3. (C) 繁殖性試驗
    4. (D) 致畸胎性試驗頁次：4－3

    正解：(D)

  17. 17食品安全性評估試驗中，樣品以單次管餵的體積至多應在多少 mL/kg 動物體重以下？

    1. (A) 50
    2. (B) 30
    3. (C) 10
    4. (D) 5

    正解：(C)

  18. 18在相同濃度劑量下，下列何者致癌性最強？

    1. (A) 苯并芘（benzo(α)pyrene）
    2. (B) 亞硝酸鉀（potassium nitrite）
    3. (C) 三甲胺（trimethylamine）
    4. (D) 糖精（saccharin）

    正解：(A)

  19. 19食品安全性評估中，有關慢性毒性試驗之敘述，下列何者錯誤？

    1. (A) 試驗中測試物質至少要有三個劑量組
    2. (B) 通常係根據亞急性毒性試驗結果再進一步進行之實驗
    3. (C) 測試物質之高劑量組不一定會引發試驗動物毒性變化
    4. (D) 測試物質之低劑量組為足以引起最低毒性作用

    正解：(B)

  20. 20有關不鏽鋼盒使用 200 系列之敘述，下列何者錯誤？

    1. (A) 成本較其他系列高
    2. (B) 錳含量較其他系列高
    3. (C) 較其他系列容易腐蝕溶出
    4. (D) 較容易有表面變黑現象

    正解：(A)

  21. 21依據食品添加物使用範圍及限量暨規格標準，下列何種食品添加物只能用於特殊營養食品？

    1. (A) L-肉酸（L-Carnitine）
    2. (B) L-麩胺酸（L-Glutamic acid）
    3. (C) L-二胺基己酸（L-Lysine）
    4. (D) L-抗壞血酸棕櫚酸酯（L-Ascorby1 palmitate）

    本題經考選部公告不計分。

  22. 22乙酸乙酯屬於法定食品添加物的那一類？

    1. (A) 食品工業用化學藥品
    2. (B) 調味劑
    3. (C) 香料
    4. (D) 載體

    正解：(C)

  23. 23下列何種化學消毒劑之熱安定性較佳？

    1. (A) 過氧化氫
    2. (B) 四級銨
    3. (C) 酒精
    4. (D) 次氯酸鈉

    正解：(B)

  24. 24以環氧樹脂作為金屬罐頭的塗料，容易釋出下列何者？

    1. (A) acrylonitrile
    2. (B) bisphenol A
    3. (C) phthalates
    4. (D) styrene

    正解：(B)

  25. 25依據食品器具容器包裝衛生標準，嬰幼兒奶瓶不得使用含下列何種物質之塑膠材質？

    1. (A) 氯乙烯（vinyl chloride）
    2. (B) 丙烯（propylene）
    3. (C) 乙烯（ethylene）
    4. (D) 雙酚 A（bisphenol A）

    正解：(D)

  26. 26下列何者與重金屬砷中毒無關？

    1. (A) 砒霜
    2. (B) 雄黃
    3. (C) 烏腳病
    4. (D) 痛痛病

    正解：(D)

  27. 27下列何種不是寄生蟲進入宿主的主要途徑？

    1. (A) 飛沫傳染
    2. (B) 食用未煮熟之食物
    3. (C) 飲用不潔之水
    4. (D) 赤足行走於土壤

    正解：(A)

  28. 28高蛋白質食物在下列何種情況中較易形成離胺丙胺酸？

    1. (A) 鹼性，加熱
    2. (B) 酸性，加熱
    3. (C) 中性，加熱
    4. (D) 酸性，煮沸頁次： 4－4

    正解：(A)

  29. 29食品安全性評估之最大無作用量（NOEL），可由下列何項試驗獲得？

    1. (A) 畸胎性試驗
    2. (B) 基因毒性試驗
    3. (C) 急性毒性試驗
    4. (D) 慢性毒性試驗

    正解：(D)

  30. 30有關醬油和味噌的製作，下列何者正確？

    1. (A) 醬油發酵時間較短
    2. (B) 味噌使用乾燥食鹽而非鹽水
    3. (C) 二者均全以豆類製麴
    4. (D) 醬油製作於裝瓶前，利用完全滅菌法殺菌

    正解：(B)

  31. 31下列何種色素經常被違法使用於水產養殖魚類的殺菌上？

    1. (A) 鹽基性介黃（auramine）
    2. (B) 鹽基性桃紅精（rhodamine B）
    3. (C) 孔雀綠（malachite green）
    4. (D) 橙色二號（orange II）

    正解：(C)

  32. 32有關食物中毒病原菌之敘述，下列何者錯誤？

    1. (A) 腸炎弧菌常見於海鮮食品之中毒
    2. (B) 肉毒桿菌屬於嫌氣性細菌
    3. (C) 溫度 60℃即可殺死所有細菌
    4. (D) 細菌最適生長之 pH 約在 5.0～8.0

    正解：(C)

  33. 33關於萊克多巴胺（ractopamine），下列敘述何者錯誤？

    1. (A) 是促進肌肉增長的動物用藥
    2. (B) 是一種乙型受體素
    3. (C) 攝食過量會產生血壓上升、心悸等症狀
    4. (D) 我國目前允許豬肉中的殘留容許量為 1 ppm

    正解：(D)

  34. 34裸麥受到 Claviceps purpurea 污染所產生的毒素，下列何者屬於此類毒素？

    1. (A) aflatoxin
    2. (B) bufotenin
    3. (C) ergometrine
    4. (D) tetrodotoxin

    正解：(C)

  35. 35有關 HACCP 管理制度的敘述，下列何者錯誤？

    1. (A) 能有效利用人力、物力資源
    2. (B) 強調最終產品檢驗的管理方式
    3. (C) 可作為國際食品相互認證的管理基準
    4. (D) 可以有效抑制食品污染與危害的發生

    正解：(B)

  36. 36針對無菌鋁箔包飲料之包裝材料，常以下列何種化學劑進行殺菌？

    1. (A) 酒精
    2. (B) 過氧化氫
    3. (C) 硼酸
    4. (D) 四級銨鹽

    正解：(B)

  37. 37下列何種試劑在長期使用下，會對設備產生腐蝕現象？

    1. (A) 酒精
    2. (B) 次氯酸鈉
    3. (C) 四級銨
    4. (D) LAS 界面活性劑

    正解：(B)

  38. 38依據食品安全衛生管理法，接受食品業者委託刊播之傳播業者，應自廣告之日起多久，保存委託刊播廣告者之姓名或名稱等相關資料，以備主管機關於必要時查驗？

    1. (A) 三個月
    2. (B) 六個月
    3. (C) 一年
    4. (D) 兩年

    正解：(B)

  39. 39依據食品添加物之管理規定，下列敘述何者錯誤？

    1. (A) 複方食品添加物業者須辦理查驗登記
    2. (B) 使用食品添加物秤量與投料應建立重複檢核制度
    3. (C) 製造或使用複方添加物，應確認配方單一品目為准用之食品添加物
    4. (D) 應確認使用食品對象、使用量、使用目的及食品中殘留量符合規定

    正解：(A)

  40. 40依據食品標示的規定，下列何種營養素必須以公克表示？

    1. (A) 鈉
    2. (B) 膽固醇
    3. (C) 飽和脂肪酸
    4. (D) 維生素 C

    正解：(C)
