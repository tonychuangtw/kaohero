營養師　103 年第一次 膳食療養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1病歷紀錄中「F/U」代表下列何者？

    1. (A) 持續追蹤
    2. (B) 給予液體
    3. (C) 轉診
    4. (D) 檢測

    正解：(A)

  2. 2江先生因食道癌造成進食量減少，入院時血中白蛋白（albumin）為 2.8 mg/dL，後經胃造口灌食後，攝食量改善很多，此時要測量下列何種營養評估指標，既簡單又能很快了解目前進食量是否適當？

    1. (A) albumin
    2. (B) prealbumin
    3. (C) blood urea nitrogen
    4. (D) transferrin

    正解：(B)

  3. 3有關皮下脂肪厚度（skin-fold thickness）的測量，下列敘述何者錯誤？

    1. (A) 通常是測量身體的右半邊
    2. (B) 測量時用大拇指和第二指將測量處的皮下皺摺捏起約 1 公分
    3. (C) 肱二頭肌皮脂厚度指測量肩喙突和鷹嘴突連線的中點厚度
    4. (D) 若由有經驗者進行測量，準確度高且價格便宜

    正解：(C)

  4. 4甘草萃取物中之甘草酸（glycyrrhizic acid）會拮抗下列何類藥物？

    1. (A) 降血脂藥物
    2. (B) 降血壓藥物
    3. (C) 抗巴金森氏症藥物
    4. (D) 抗生素頁次：4－2

    正解：(B)

  5. 5下列何種礦物質最不會與四環素類抗生素產生交互作用？

    1. (A) 鋅
    2. (B) 鋁
    3. (C) 鈣
    4. (D) 氟

    正解：(D)

  6. 6麻醉性藥物（narcotic agents）較容易引起下列何種副作用？

    1. (A) 口乾舌燥
    2. (B) 下痢
    3. (C) 脹氣
    4. (D) 便秘

    正解：(D)

  7. 7林先生中風後無法自行吞嚥進食，腸胃道功能正常，選擇其灌食配方考慮的因素，下列何者錯誤？

    1. (A) 配方的價格
    2. (B) 配方組成需經過水解
    3. (C) 林先生的臨床狀況
    4. (D) 林先生的營養需要

    正解：(B)

  8. 8脫離管灌食的患者開始由口進食時，如果患者吞嚥容易嗆到，應該如何處置？

    1. (A) 訓練患者從喝水開始
    2. (B) 將營養配方稀釋後給予
    3. (C) 儘量給予液體食物，不要給固體食物
    4. (D) 給予有稠度的糊狀食物

    正解：(D)

  9. 9下列何者不是 bulimia nervosa 患者常有的特徵？

    1. (A) 手指背結痂
    2. (B) 腮腺腫大
    3. (C) 牙齒琺瑯質腐蝕
    4. (D) 皮膚乾燥

    正解：(D)

  10. 10降血鈣素（calcitonin）的注射，最有可能是治療下列何種骨頭疾病？

    1. (A) 痛風
    2. (B) 骨質疏鬆
    3. (C) 風濕性關節炎
    4. (D) 退化性關節炎

    正解：(B)

  11. 11下列關於第一型骨質疏鬆症（type I osteoporosis）之敘述，何者錯誤？

    1. (A) 骨頭與骨礦物質密度（BMD）快速流失
    2. (B) 卵巢雌激素的分泌下降
    3. (C) 不會發生於男性
    4. (D) 增加手腕和脊椎的骨折

    正解：(C)

  12. 12下列有關體脂肪合成及分解的敘述，何者錯誤？

    1. (A) 高脂飲食會刺激肝臟進行脂肪合成，其所需消耗的能量是高碳水化合物飲食的 3 倍
    2. (B) 在脂肪組織中受到毒素等影響，semivolatile organic compounds（SVOCs）會堆積，並在減重期間大量釋出
    3. (C) 脂蛋白脂解酶（LPL）的功用主要是將血液中的脂肪分解，以便移至脂肪細胞形成三酸甘油酯儲存
    4. (D) 荷爾蒙敏感脂解酶（HSL）的功用主要是將三酸甘油酯分解為脂肪酸及甘油，以提供其他細胞能量

    正解：(A)

  13. 13對於肝硬化患者，下列何者是較可靠的營養評估指標？

    1. (A) 血清白蛋白濃度
    2. (B) 血清前白蛋白濃度
    3. (C) 三頭肌皮層厚度及中臂周緣
    4. (D) 身體質量指數（BMI）

    正解：(C)

  14. 14關於胃食道逆流的營養照護原則，下列敘述何者錯誤？

    1. (A) 吃低纖飲食
    2. (B) 戒菸、戒酒
    3. (C) 降低脂肪攝取量
    4. (D) 減緩進食速度

    正解：(A)

  15. 15酗酒超過 20 年之成年男子，現因吐血、胡言亂語、意識不清、失去方向感、有攻擊傾向而就診。經檢查發現體溫為攝氏 38.6 度、白血球計數為 23,000 cells/mL、血紅素 10.2 g/dL、生化檢驗值為：鈉 130 mEq/L、鉀 5.1 mEq/L、血中尿素氮 30 mg/dL、肌酸酐 2.3 mg/dL、白蛋白 2.2 g/dL、膽紅素總量 3.9 mg/dL、天門冬胺酸轉胺酶 260 U/L、丙胺酸轉胺酶 96 U/L、鹼性磷酸酶 203 U/L。在此階段對該患者營養治療，下列敘述何者最合宜？

    1. (A) 蛋白質每公斤體重 0.6 公克，來源以動物性為主
    2. (B) 蛋白質每公斤體重 0.6 公克，來源以植物性為主
    3. (C) 蛋白質每公斤體重 1.2 公克，來源以動物性為主
    4. (D) 蛋白質每公斤體重 1.2 公克，來源以植物性為主頁次：4－3

    正解：(D)

  16. 16嚴重腹瀉患者之營養照護，首要為：

    1. (A) 少量多餐
    2. (B) 供應低脂、低纖維飲食
    3. (C) 增加水溶性纖維含量高的食物
    4. (D) 補充流失的液體及電解質

    正解：(D)

  17. 17有一成年患者，因創傷產生「壓力型」潰瘍，其餵食策略以下列何者最為恰當？

    1. (A) 應持續採 TPN 給予營養支持
    2. (B) 應禁食讓腸道休息，以保持腸道黏膜的完整性
    3. (C) 儘量維持腸道營養，有利重建腸道正常生理功能
    4. (D) 可適量添加甘胺酸，有助腸道修復

    正解：(C)

  18. 18有關妊娠糖尿病，下列敘述何者錯誤？

    1. (A) 可於懷孕第 24～28 週進行血糖值篩檢，確診之
    2. (B) 懷孕期間空腹血糖之目標值 ≤ 95 mg/dL
    3. (C) 妊娠糖尿病之病因與懷孕前肥胖體態較有關
    4. (D) 懷孕期間餐後 2 小時血糖之目標值＜140 mg/dL

    正解：(D)

  19. 19關於糖尿病患適度飲酒可減少罹患冠狀動脈心臟病的危險，下列敘述何者正確？

    1. (A) 降低血中三酸甘油酯濃度
    2. (B) 增加血中 HDL-C 濃度
    3. (C) 降低血壓
    4. (D) 有助於減重

    正解：(B)

  20. 20有關葡萄糖恆定異常（impaired glucose homeostasis）的敘述，下列何者錯誤？

    1. (A) 空腹血糖值介於 100～125 mg/dL 之間
    2. (B) 餐後 2 小時血糖值介於 140～199 mg/dL 之間
    3. (C) 有 polyuria、polydipsia、polyphagia 的症狀
    4. (D) 注意飲食、適當運動可防止轉變成糖尿病

    正解：(C)

  21. 21下列何種胰島素，開始作用所需的時間最短？

    1. (A) insulin glargine（Lantus）
    2. (B) insulin lispro（Humalog）
    3. (C) NPH
    4. (D) regular insulin

    正解：(B)

  22. 22欲防止腎結石復發，不建議減少下列何種飲食成分之攝取量？

    1. (A) 鈉
    2. (B) 鉀
    3. (C) 果糖
    4. (D) 草酸

    正解：(B)

  23. 23在急性腎衰竭寡尿期最常造成血中何種離子過高？

    1. (A) 鉀
    2. (B) 磷
    3. (C) 鈉
    4. (D) 鈣

    正解：(A)

  24. 24與血液透析相較，使用腹膜透析的優點，下列敘述何者錯誤？

    1. (A) 可維持較久的剩餘腎臟功能
    2. (B) 病人較可維持正常生活
    3. (C) 血液生化值變化的幅度較小
    4. (D) 較能維持血糖恆定

    正解：(D)

  25. 25末期腎臟病（ESRD）患者的營養治療目標為：①攝取足夠的蛋白質及熱量 ②攝取足夠的維生素 ③控制水腫及電解質不平衡 ④補充鉀 ⑤補充鈣質及維生素 D

    1. (A) 僅①②③
    2. (B) 僅②③④
    3. (C) ②③④⑤
    4. (D) ①②③⑤

    正解：(D)

  26. 26關於初期高血壓的治療，下列敘述何者正確？

    1. (A) 若患者執行生活型態改變 6～12 個月，血壓仍未達到目標值則應藥物治療
    2. (B) 若以藥物治療則不需飲食控制
    3. (C) 控制體重務必降至理想體重才能使血壓下降
    4. (D) 採 DASH 飲食常會脹氣及腹瀉，建議口服健胃整腸藥頁次：4－4

    正解：(A)

  27. 27有關脂蛋白的敘述，下列何者正確？

    1. (A) lipoprotein lipase 可以水解脂蛋白中的膽固醇酯
    2. (B) HDL 上主要的蛋白質為 apo A-1
    3. (C) 空腹 12 小時後，血液中不含 VLDL
    4. (D) 周邊組織汲取 LDL 一定需要有 LDL 接受器（LDL receptor）

    正解：(B)

  28. 28下列何者是因 LDL 接受器單一基因缺陷導致的高血脂症狀？

    1. (A) 家族性高膽固醇血症
    2. (B) 家族性混合高血脂症
    3. (C) 家族性高三酸甘油酯血症
    4. (D) 家族性 β 脂蛋白異常

    正解：(A)

  29. 29下列何者沒有降低血膽固醇的功效？

    1. (A) cellulose
    2. (B) algal polysaccharides
    3. (C) pectins
    4. (D) plant stanols

    正解：(A)

  30. 30有關燒燙傷患者的熱量需要，下列敘述何者錯誤？

    1. (A) 以 indirect calorimetry 測量獲得之熱量最接近燒燙傷患者的實際需要
    2. (B) 臨床上常使用 Ireton-Jones equation 熱量估算公式來評估燒燙傷患者的熱量需要量
    3. (C) 燒燙傷患者的熱量需要量經常大於基礎代謝率 2 倍以上
    4. (D) 肥胖的燒燙傷患者在傷口癒合前的熱量給予應以維持原來體重為目標

    正解：(C)

  31. 31下列何者不是重症患者在疾病壓力下會產生的代謝反應？

    1. (A) 血糖濃度降低
    2. (B) 血清鐵濃度降低
    3. (C) 血清鋅濃度降低
    4. (D) 血液尿素氮濃度上升

    正解：(A)

  32. 32下列何者不是重症患者在嚴重損傷（injury）初期會產生的生理變化？

    1. (A) 降低心輸出量
    2. (B) 血壓上升
    3. (C) 休克
    4. (D) 體溫降低

    正解：(B)

  33. 33下列何種管灌食方式最適合胃排空障礙的重症患者？

    1. (A) nasogastric feeding
    2. (B) nasojejunal feeding
    3. (C) gastrostomy feeding
    4. (D) oral feeding

    正解：(B)

  34. 34治療肺結核之藥物 INH 與下列何者有拮抗作用？

    1. (A) pantothenic acid
    2. (B) biotin
    3. (C) folate
    4. (D) pyridoxine

    正解：(D)

  35. 35有關癌症病人每日水分需求量的計算基準，下列何者錯誤？

    1. (A) 1 ml/kcal of estimated needs
    2. (B) ＜55 歲者，30～40 ml/kg
    3. (C) body surface area（m ）×1500 ml
    4. (D) ＞65 歲者，30 ml/kg

    正解：(D)

  36. 36下列何者為肺泡分泌的物質，由蛋白質和磷脂質合成的化合物？

    1. (A) cephalin
    2. (B) mucus
    3. (C) lecithin
    4. (D) surfactant

    正解：(D)

  37. 37下列何者不是接受化療之癌症病人的營養狀況評估項目？

    1. (A) 食慾和進食量
    2. (B) 與營養相關之治療副作用
    3. (C) 體重流失狀況
    4. (D) 淋巴球計數

    正解：(D)

  38. 38白內障（cataract）是老年人常見的眼疾之一，而飲食中何種礦物質攝取過量可能增加其發生的危險性？

    1. (A) 鐵
    2. (B) 錳
    3. (C) 鋅
    4. (D) 鈉

    正解：(D)

  39. 39缺乏下列何種 B 群維生素，可能與老年性聽力喪失（presbycusis）有關？

    1. (A) 維生素 B1
    2. (B) 維生素 B6
    3. (C) 葉酸
    4. (D) 維生素 B12

    正解：(D)
