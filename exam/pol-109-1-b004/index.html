警察特考　109 年 三等考試 行政法　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1環保主管機關查獲某工廠違反水污染防治法，依法開罰並命其限期改善，詎料在限期尚未屆滿前，該機關又前來檢查並再次開罰。該行政行為主要違反下列那一項法律原則？

    1. (A) 平等原則
    2. (B) 過度禁止原則
    3. (C) 明確性原則
    4. (D) 誠實信用原則

    正解：(D)

  2. 2關於依法行政原則，下列敘述何者正確？

    1. (A) 法規命令與職權命令無明確區分
    2. (B) 主管機關得以行政規則規定罰鍰
    3. (C) 行政指導原則上仍受依法行政原則之拘束
    4. (D) 法律保留僅適用在行為法範圍

    正解：(C)

  3. 3司法院釋字第 469 號解釋稱：「法律規定之內容非僅屬授予國家機關推行公共事務之權限，而其目的係為保護人民生命、身體及財產等法益」。本句中所謂之「法律規定」在學理上稱之為下列何者？

    1. (A) 裁量規範
    2. (B) 羈束規範
    3. (C) 保護規範
    4. (D) 行為規範

    正解：(C)

  4. 4關於地方自治之敘述，下列何者正確？

    1. (A) 中央政府或其他上級政府對地方自治團體辦理自治事項，得為妥當性之監督
    2. (B) 立法院各委員會得邀請地方自治團體行政機關有關人員到會備詢，若拒絕備詢，立法院得以此為由刪減其中央補助款
    3. (C) 上級主管機關之行政處分若有損害地方自治團體之權利或法律上利益，其議會得代表地方自治團體提起行政訴訟
    4. (D) 中央與直轄市、縣（市）間，權限遇有爭議時，由立法院院會議決之

    正解：(D)

  5. 5關於行政機關管轄權之敘述，下列何者錯誤？

    1. (A) 行政機關之管轄權，依其組織法規或其他行政法規定之
    2. (B) 行政機關之組織法規變更管轄權之規定，而相關行政法規所定管轄機關尚未一併修正時，原管轄機關得會同組織法規變更後之管轄機關公告變更管轄之事項
    3. (C) 不能依行政機關之組織法規定土地管轄者，如涉及不動產之事件，應由不動產之所在地管轄
    4. (D) 同一事件，數行政機關依法均有管轄權者，應逕由各該機關協議定管轄之機關

    正解：(D)

  6. 6有關公務人員保障事件之復審代理人事實上之陳述，經到場之復審人本人即時撤銷或更正，其效力為何？

    1. (A) 效力不受影響
    2. (B) 效力未定
    3. (C) 由公務人員保障暨培訓委員會認定其效力
    4. (D) 不生效力

    正解：(D)

  7. 7有關法官之敘述，下列何者錯誤？

    1. (A) 法官依法審判，不受長官職務命令之拘束
    2. (B) 法官除經考試及格者出任外，可透過甄選程序，由律師轉任
    3. (C) 法官有評鑑制度，受評鑑範圍包括法官違法失職、遲誤辦案或違反法官倫理等
    4. (D) 法官之考核由司法院法官會議決定之

    正解：(D)

  8. 8關於委託行使公權力之敘述，下列何者錯誤？

    1. (A) 人民因受託事件請求國家賠償時，以委託機關為賠償義務機關
    2. (B) 人民與受委託行使公權力者因受託事件涉訟時，以委託機關為被告
    3. (C) 人民不服受委託行使公權力者所為之行政處分時，訴願由委託機關管轄
    4. (D) 受委託行使公權力所需之費用，除另有約定外，由委託機關支付

    正解：(B)

  9. 9公務員懲戒審判程序中，若懲戒處分牽涉犯罪是否成立者，下列處理方式何者正確？

    1. (A) 同一行為在刑事偵查或審判中者，應停止懲戒審理程序
    2. (B) 公務員懲戒委員會合議庭認有必要時，得裁定於第一審刑事判決前，停止懲戒審理程序
    3. (C) 公務員懲戒委員會合議庭認有必要時，得裁定於第二審刑事判決前，停止懲戒審理程序
    4. (D) 公務員懲戒委員會合議庭認有必要時，得裁定於刑事裁判確定前，停止懲戒審理程序

    正解：(B)

  10. 10依地方制度法規定，下列何者應以自治條例定之？

    1. (A) 直轄市政府所屬機關之設置依據
    2. (B) 執行上級機關委辦事項
    3. (C) 創設地方自治團體居民之權利義務
    4. (D) 直轄市議會之自律事項

    正解：(C)

  11. 11行政機關就公法上具體事件所為之決定，而對外直接發生法律效果之單方行政行為，稱為：

    1. (A) 行政調查
    2. (B) 行政處分
    3. (C) 行政指導
    4. (D) 行政執行

    正解：(B)

  12. 12民間汽車修護廠受主管機關委託汽車檢驗不合格之結果，該不合格之認定屬下列何種性質？

    1. (A) 民事契約行為
    2. (B) 行政契約行為
    3. (C) 行政處分
    4. (D) 事實行為

    正解：(C)

  13. 13主管機關准許日商公司在臺設廠，但禁止該公司所製造之商品於臺灣境內販售，如有販售情事，設廠許可失效。此等要求該當何種行政處分之附款？

    1. (A) 負擔
    2. (B) 期限
    3. (C) 條件
    4. (D) 保留廢止權

    正解：(C)

  14. 14下列何者非屬一般處分？

    1. (A) 對於違法集會之群眾所下達解散命令
    2. (B) 依據森林法將某樹木指定為保存樹木
    3. (C) 依法對於特定區域全部攤販要求於特定時間內搬遷
    4. (D) 國防部對於個別後備軍人所寄送之召集令

    正解：(D)

  15. 15下列何者非屬行政契約？

    1. (A) 臺北市與新北市關於捷運建設費用分擔之協議
    2. (B) 臺北市政府同意以徵收補償費抵銷土地所有人所欠繳之工程受益費之協議
    3. (C) 建設公司與行政機關間，承諾繳納特定代金以免除設置法定停車場義務之協議
    4. (D) 行政機關依僱傭契約僱用臨時人員

    正解：(D)

  16. 16下列何種類型之行政行為，其概念內涵中無「法律效力」之要素？

    1. (A) 行政契約
    2. (B) 行政事實行為
    3. (C) 行政私法契約
    4. (D) 行政規則

    正解：(B)

  17. 17依行政罰法第 2 條之規定，命令停工之處分，屬於下列何種行政罰？

    1. (A) 剝奪或消滅資格、權利之處分
    2. (B) 警告性處分
    3. (C) 影響名譽之處分
    4. (D) 限制或禁止行為之處分

    正解：(D)

  18. 18義務人對行政執行程序中之執行命令如有不服，於程序終結前，得向執行機關提出何種救濟？

    1. (A) 聲請申訴
    2. (B) 即時抗告
    3. (C) 訴願
    4. (D) 聲明異議

    正解：(D)

  19. 19依行政程序法之規定，下列有關期間計算之敘述，何者錯誤？

    1. (A) 期間之末日為星期日、國定假日或其他休息日者，以該日之次日為期間之末日
    2. (B) 期間以日、星期、月或年計算者，其始日不計算在內
    3. (C) 期間涉及人民之處罰或其他不利行政處分，其始日不計算在內
    4. (D) 期間以時計算者，即時起算

    正解：(C)

  20. 20依訴願法規定，有關情況決定之敘述，下列何者錯誤？

    1. (A) 制度目的在於避免因撤銷或變更原處分而對公益有重大損害
    2. (B) 情況決定之賠償協議，與國家賠償法之賠償協議具有同一效力
    3. (C) 原處分機關先行重新審查處分時，得作成情況決定並駁回訴願
    4. (D) 情況決定之作成，應斟酌訴願人所受損害、賠償程度、防止方法及其他一切情事

    正解：(C)

  21. 21關於行政訴訟被告提起反訴之敘述，下列何者錯誤？

    1. (A) 原告對於反訴，得復行提起反訴
    2. (B) 對於撤銷訴訟及課予義務訴訟，不得提起反訴
    3. (C) 反訴如專屬他行政法院管轄者，不得提起
    4. (D) 被告於言詞辯論終結前，原則上得在本訴繫屬之行政法院提起反訴

    正解：(A)

  22. 22行政法院就其受理訴訟之權限，如與普通法院確定裁判之見解有異，應如何處理？

    1. (A) 依職權逕為審判，不受影響
    2. (B) 裁定停止訴訟程序，聲請司法院大法官解釋
    3. (C) 尊重普通法院確定裁判，不宜變更
    4. (D) 以裁定停止訴訟程序，請求司法院院長召集協調

    正解：(B)

  23. 23下列何種爭議，由行政法院管轄？

    1. (A) 甲不服檢察官將其提起告訴之案件逕行簽結
    2. (B) 乙種植之林木因水庫洩洪受損請求賠償之訴訟
    3. (C) 丙向財政部國有財產署提出讓售國有土地之請求遭拒
    4. (D) 丁依國軍老舊眷村改建條例申請核發原眷戶資格證明遭拒

    正解：(C)

  24. 24公共設施因設置有欠缺，致人民生命受損害，國家應負損害賠償責任。其責任關係稱為：

    1. (A) 過失責任
    2. (B) 補償責任
    3. (C) 無過失責任
    4. (D) 違法舉證責任

    正解：(C)

  25. 25有審判或追訴職務之公務員，執行職務侵害人民權利，得否適用國家賠償法請求賠償？

    1. (A) 須該公務員就參與審判或追訴案件犯職務上之罪，經判決有罪確定者，始得適用國家賠償法
    2. (B) 須該公務員就參與審判或追訴案件犯職務上之罪，經檢察官起訴者，始得適用國家賠償法
    3. (C) 有審判或追訴職務之公務員，行使公權力時，因過失不法侵害人民權利，始得適用國家賠償法
    4. (D) 有審判或追訴職務之公務員，受公務員懲戒法懲戒者，其因故意不法侵害人民權利，始得適用國家賠償法

    正解：(A)
