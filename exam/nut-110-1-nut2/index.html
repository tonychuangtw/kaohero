營養師　110 年第一次 營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何種型式單糖存在食物中，可被人體消化代謝？

    1. (A) B-glucose
    2. (B) D-glucose
    3. (C) E-glucose
    4. (D) L-glucose

    正解：(B)

  2. 2下列何種酵素，不是人體消化醣類的相關酵素？

    1. (A) amylase
    2. (B) carbohydrase
    3. (C) esterase
    4. (D) glycosidase

    正解：(C)

  3. 3下列因子何者可促進肝醣合成（glycogenesis）？

    1. (A) 環腺苷單磷酸（cyclic AMP, cAMP）
    2. (B) 腎上腺素（epinephrine）
    3. (C) 升糖激素（glucagon）
    4. (D) 胰島素（insulin）

    正解：(D)

  4. 4關於果聚醣（fructans）特性的描述何者錯誤？

    1. (A) 被歸類為膳食纖維（dietary fiber），且為功能性纖維（functional fiber）
    2. (B) 可溶於水，且可在腸道中形成黏稠膠狀
    3. (C) 可被腸道菌發酵
    4. (D) Inulin 及 fructooligosaccharides 屬於果聚醣，常被用來作為食品添加物

    正解：(B)

  5. 5下列何者不是體內合成三酸甘油酯的原料？

    1. (A) 蔗糖
    2. (B) 果糖
    3. (C) 胺基酸
    4. (D) 膽固醇

    正解：(D)

  6. 6血中同半胱胺酸（homocysteine）濃度過高是因何種胺基酸代謝異常所致？

    1. (A) 苯丙胺酸（phenylalanine）
    2. (B) 色胺酸（tryptophan）
    3. (C) 異白胺酸（isoleucine）
    4. (D) 甲硫胺酸（methionine）

    正解：(D)

  7. 7尿液中何種物質的排出量可以反應健康成人肌肉蛋白質量的多少？

    1. (A) 尿酸
    2. (B) 普林
    3. (C) 肌酸酐
    4. (D) 尿素氮

    正解：(C)

  8. 8有關食物過敏的敘述，下列何者錯誤？

    1. (A) 過敏原多為蛋白質
    2. (B) 過敏原刺激體內產生免疫球蛋白引發過敏反應
    3. (C) 所有過敏原經烹煮後會喪失其致敏性
    4. (D) 食物過敏和食物不耐症引發的原因不同

    正解：(C)

  9. 9根據 2018 年衛生福利部國民健康署公告的每日飲食指南涵蓋的食物類別，下列何者錯誤？

    1. (A) 豆魚蛋肉類
    2. (B) 低脂乳品類
    3. (C) 全穀雜糧類
    4. (D) 蔬菜類頁次：3－2

    正解：(B)

  10. 10麩胱甘肽（glutathione）是由下列那些胺基酸組成？

    1. (A) 甘胺酸（glycine）、半胱胺酸（cysteine）、麩胺酸（glutamic acid）
    2. (B) 丙胺酸（alanine）、胱胺酸（cystine）、麩胺酸（glutamic acid）
    3. (C) 丙胺酸（alanine）、半胱胺酸（cysteine）、天門冬胺酸（aspartic acid）
    4. (D) 甘胺酸（glycine）、半胱胺酸（cysteine）、天門冬胺酸（aspartic acid）

    正解：(A)

  11. 11有關膽酸（鹽）的敘述，下列何者正確？

    1. (A) 一級膽酸（鹽）於肝臟生成，二級膽酸（鹽）為腸道菌生成
    2. (B) 不論一級或二級膽酸（鹽）皆是於肝臟生成
    3. (C) 只有一級膽酸（鹽）可藉腸肝循環再吸收
    4. (D) 膽酸（鹽）的再吸收發生在小腸的十二指腸部位

    正解：(A)

  12. 12下列那種生理狀況，容易造成血清游離脂肪酸的上升？

    1. (A) 剛吃完一頓高醣低脂餐
    2. (B) 剛吃完一頓高脂低醣餐
    3. (C) 剛吃完一頓高蛋白餐
    4. (D) 隔夜未進食

    正解：(D)

  13. 13有關 Malonyl-CoA 的作用，下列何者錯誤？

    1. (A) 合成脂肪酸的受質
    2. (B) 抑制 fatty acyl-CoA 進入粒線體
    3. (C) 促進食慾
    4. (D) 促進胰臟 β 細胞分泌胰島素

    正解：(C)

  14. 14有關脂蛋白代謝過程的敘述，下列何者錯誤？

    1. (A) 肝臟利用乳糜微粒的形式將脂肪運出
    2. (B) 脂肪以極低密度脂蛋白（VLDL）型式運出肝臟
    3. (C) 低密度脂蛋白源自 VLDL，將大部分膽固醇帶給細胞
    4. (D) 高密度脂蛋白將細胞的膽固醇帶給其他脂蛋白或肝臟

    正解：(A)

  15. 15麩胺酸（glutamic acid）經脫胺作用後轉變成下列何種物質？

    1. (A) Pyruvate
    2. (B) α-ketoglutarate
    3. (C) Oxaloacetate
    4. (D) Fumarate

    正解：(B)

  16. 16有關人體攝取食物後啟動飽足感之作用機轉，不包括下列何者？

    1. (A) 咀嚼促進神經傳導物質組織胺（histamine）之釋出，以作用於飽食中樞
    2. (B) 促進膽囊收縮素（cholecystokinin）之釋出，以降低飢餓感
    3. (C) 消化過程中，減少胜肽 YY3-36 之分泌，以降低飢餓感
    4. (D) 蛋白質消化時會抑制胃分泌飢餓素（ghrelin）之釋出，以促進飽足感

    正解：(C)

  17. 17在正常狀態下，輕度工作者的每日休息能量消耗（resting energy expenditure） ，約占總能量消耗之多少百分比？

    1. (A) 5-10%
    2. (B) 15-30%
    3. (C) 45-50%
    4. (D) 60-75%

    正解：(D)

  18. 18當攝取較多的精製糖或甜食後，容易造成體內脂肪組織累積過多的三酸甘油酯而導致肥胖。請問這過程主要與何種 lipoprotein 之合成有關？

    1. (A) chylomicron
    2. (B) VLDL
    3. (C) LDL
    4. (D) HDL

    正解：(B)

  19. 19色胺酸（tryptophan）代謝形成菸鹼醯胺腺嘌呤雙核苷酸（NAD）的過程中，需要那些營養素的參與？

    1. (A) 維生素 C、維生素 B6、葉酸
    2. (B) 維生素 B2、維生素 B6、鐵
    3. (C) 維生素 C、維生素 B2、維生素 B3
    4. (D) 維生素 B3、維生素 B12、鐵

    正解：(B)

  20. 20下列何者與飲食葉酸缺乏無關？

    1. (A) 受孕期間的胚胎生長發育
    2. (B) 骨髓腔紅血球母細胞的熟化作用
    3. (C) 血管內皮細胞的氧化傷害
    4. (D) 血基質鐵沉積的溶血作用

    正解：(D)

  21. 21下列何種酵素以葉酸與維生素 B12 為輔酶因子，以催化生化反應？

    1. (A) 甲硫胺酸合成酶（methionine synthase）
    2. (B) 胸苷酸合成酶（thymidylate synthase）
    3. (C) 亞甲基四氫葉酸還原酶（methylenetetrahydrofolate reductase）
    4. (D) 絲氨酸氫氧甲基轉移酶（serine hydroxymethyltransferase）

    正解：(A)

  22. 22下列何種食物的膽素含量最高？

    1. (A) 1 顆水煮蛋
    2. (B) 1 兩牛肉
    3. (C) 1 個橘子
    4. (D) 1 片全麥吐司

    正解：(A)

  23. 23有關 pantothenic acid 的敘述，下列何者錯誤？

    1. (A) 是輔酶 A 的重要成分，與能量產生有關
    2. (B) 可將膽素轉變為乙醯膽鹼，是重要神經傳導物質
    3. (C) 參與肝醣的合成
    4. (D) 合成膽固醇頁次：3－3

    正解：(C)

  24. 24下列何種情況會提升維生素 K 缺乏的風險？

    1. (A) 少日曬
    2. (B) 長期服用抗生素
    3. (C) 少運動
    4. (D) 長期服用控制血壓藥物

    正解：(B)

  25. 25骨骼健康與 vitamin D 關係密切，7-dehydrocholesterol 在身體那個組織被轉換成 cholecalciferol？

    1. (A) lung
    2. (B) kidney
    3. (C) skin
    4. (D) intestine

    正解：(C)

  26. 26下列何種缺乏症組合是由於飲食中長期缺乏維生素 A 所導致的結果？

    1. (A) 夜盲＋腳氣病（night blindness＋beriberi）
    2. (B) 皮膚乾燥＋巨紅血球貧血（xeroderma＋magaloblastic anemia）
    3. (C) 角質軟化＋心口灼熱（keratomalacia＋heart burn）
    4. (D) 夜盲＋角質軟化（night blindness＋keratomalacia）

    正解：(D)

  27. 27Chloride shift 是指氯離子與下列何者相互交換，以進出紅血球之細胞膜？

    1. (A) Na+
    2. (B) K+
    3. (C) HPO42-
    4. (D) HCO3-

    正解：(D)

  28. 28根據 102～105 年國民營養健康狀況變遷調查結果，下列何種礦物質是國人飲食攝取量最不足的第二位？

    1. (A) 硫
    2. (B) 鋅
    3. (C) 鎂
    4. (D) 鉀

    正解：(C)

  29. 29轉酮酶（transketolase）是五碳醣磷酸代謝途徑（pentose phosphate pathway）的關鍵性酵素，此酵素需要何種輔酶的協助？

    1. (A) 磷酸比哆醛（PLP）
    2. (B) 菸鹼醯胺腺嘌呤雙核苷酸磷酸（NADP）
    3. (C) 核黃素單核苷酸（FMN）
    4. (D) 硫胺雙磷酸（TDP）

    正解：(D)

  30. 30多攝取含鉀高的食物可以預防何種疾病？

    1. (A) 糖尿病
    2. (B) 骨質疏鬆症
    3. (C) 胃潰瘍
    4. (D) 高血壓

    正解：(D)

  31. 31下列何者是在兒童期因維生素 D 缺乏所導致之臨床疾病？

    1. (A) 骨質疏鬆症（osteoporosis）
    2. (B) 軟骨症（osteomalacia）
    3. (C) 佝僂症（rickets）
    4. (D) 高血鈣症（hypercalcemia）

    正解：(C)

  32. 32下列何種微量礦物質可經由非酵素催化的 Fenton reaction 產生氫氧自由基（hydroxyl radicals）？

    1. (A) 鋅
    2. (B) 銅
    3. (C) 錳
    4. (D) 鉻

    正解：(B)

  33. 33Cyclooxygenase 17 主要協助何種微量元素於細胞內的運送？

    1. (A) 鋅
    2. (B) 銅
    3. (C) 硒
    4. (D) 鉻

    正解：(B)

  34. 34缺鐵性貧血形成過程中，下列何者會降低？

    1. (A) 運鐵蛋白結合鐵的能力（transferrin iron-binding capacity）
    2. (B) 肝臟中鐵蛋白（ferritin）的量
    3. (C) 紅血球原卟啉（erythrocyte protoporphyrin）的量
    4. (D) 血清運鐵蛋白受體（transferrin receptors）的量

    正解：(B)

  35. 35在飲食均衡的狀況下，孕婦在懷孕的第幾期需要額外補充鐵質？

    1. (A) 第一期
    2. (B) 第二期
    3. (C) 第三期
    4. (D) 計畫懷孕前

    正解：(C)

  36. 36血液中同半胱胺酸濃度的增加，與老年人罹患心血管疾病、神經性退化、骨折之風險相關。可以增加下列那些營養素之攝取，以降低其風險？

    1. (A) 維生素 D、維生素 B12、維生素 C
    2. (B) 維生素 E、維生素 B2、菸鹼素
    3. (C) 維生素 C、維生素 E、類胡蘿蔔素
    4. (D) 維生素 B6、葉酸、維生素 B12

    正解：(D)

  37. 37體重 18 公斤的幼兒每日約需攝取多少毫升的水分？

    1. (A) 1,200
    2. (B) 1,400
    3. (C) 1,600
    4. (D) 1,800

    正解：(B)

  38. 38依據第七版「國人膳食營養素參考建議攝取量」 ，1～3 歲與 4～6 歲學齡前幼兒相比較，不需要增加下列何種維生素的攝取量？

    1. (A) 維生素 D
    2. (B) 維生素 K
    3. (C) 維生素 C
    4. (D) 葉酸

    正解：(A)

  39. 39有關果糖特色的敘述，下列何者正確？

    1. (A) 屬低升糖指數，因此適合糖尿病人使用
    2. (B) 在肝臟代謝，傾向合成三酸甘油酯
    3. (C) 含糖飲料是果糖唯一飲食來源
    4. (D) 市售高果糖玉米糖漿組成為 100%果糖

    正解：(B)

  40. 40氫化油常被提及對健康會有不良影響，主要是因為其中所含的何種成分所引起？

    1. (A) 過氧化物
    2. (B) 反式脂肪酸
    3. (C) 游離脂肪酸
    4. (D) 飽和脂肪酸

    正解：(B)
