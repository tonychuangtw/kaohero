  14. 14有關母乳哺育，下列敘述何者不適當？

  19. 19檢查新生兒是否有髖關節先天發育不良，其檢查方法何者正確？

    1. (A) 評估大腿與臀部皺褶之對稱性，兩側皺褶不對稱為正常現象
    2. (B) 執行歐特藍尼操作法（Ortolani’s maneuver），出現「卡答」聲為正常徵象
    3. (C) 仰臥時，膝關節呈屈曲狀，有髖關節脫臼或異位的患側股骨會較長
    4. (D) 執行巴羅操作法（Barlow’s maneuver），將大腿內收、膝部下壓，股骨頭會在關節囊內滑動，為異常現象

    正解：(D)

    4. (D) 若呼吸未改善則考慮插管，並執行氣管內胎便抽吸

    正解：(B)

    正解：(B)

  38. 38小芷，因發燒、感冒症狀就診，診斷為黴漿菌肺炎（mycoplasma pneumonia）而入院治療，下列敘述何者最適當？

    1. (A) 主要感染於 1～3 歲兒童
    2. (B) 輕微發燒，通常＜39℃
    3. (C) 傳染性低，不易傳染給其他家人
    4. (D) 使用 Azithromycin 治療約 10～14 天

    正解：(B)

  39. 39小玉，2 歲，因感冒罹患急性中耳炎（acute otitis media）住院治療，其返家之護理照護，下列敘述何者正確？

    1. (A) 二側鼻孔宜一起擤鼻涕，較易清除分泌物
    2. (B) 執行耳內給藥時，應將耳朵往下往後拉
    3. (C) 若行鼓膜切除引流時，宜臥向健側
    4. (D) 耳朵不痛時，即可停用抗生素，以免產生抗藥性

    正解：(B)

  40. 40何小妹，8 歲，罹患先天性心臟病，需服用毛地黃，母親詢問服藥注意事項，下列回答何者錯誤？

    1. (A) 多補充含鉀食物，如香蕉、深綠色蔬菜
    2. (B) 每日定時給藥，且空腹時給藥效果最好
    3. (C) 給藥前心尖脈＜70 次／分鐘，應暫停服藥
    4. (D) 如忘記服藥大於 6 小時，仍需補給一劑

    正解：(D)

  41. 41陳小妹，出生後診斷大血管轉位（transposition of the great arteries, TGA），醫囑服用前列腺素（ProstaglandinE1），有關此藥的使用目的，下列敘述何者正確？

    1. (A) 增加心肌收縮力
    2. (B) 維持動脈導管開放
    3. (C) 增加下肢靜脈血回流
    4. (D) 降低體循環的氧氣飽和度

    正解：(B)

  42. 42小傑，8 歲，診斷再生不良性貧血（aplastic anemia） ，因白血球、紅血球及血小板下降而入院接受治療，下列護理何者最適當？

    1. (A) 鼓勵戶外活動，以促進血循並增強肌力
    2. (B) 避免給予粗糙、堅硬的食物，以防口腔黏膜受損
    3. (C) 鼓勵並安排同學前來探訪會客，降低因同儕疏離而產生低自尊
    4. (D) 注意預防發燒，必要時給予 Aspirin 藥物降溫，以免增加感染機會

    正解：(B)

  43. 43吳小妹，2 個月大，診斷為先天性甲狀腺功能低下（congenital hypothyroidism） ，下列護理指導何者最適當？

    1. (A) 常出現腹瀉，著重臀部照護預防尿布疹
    2. (B) 減少日曬時間，預防皮膚出現紅斑病變
    3. (C) 常出現體溫過高，應保持低溫的環境
    4. (D) 應留意聽力發展，必要時安排聽力檢查

    正解：(D)

  44. 44林小妹，國小 5 年級，罹患第 1 型糖尿病（type 1 diabetes mellitus） ，有關糖尿病居家護理指導，下列敘述何者正確？

    1. (A) 注射胰島素後，按摩注射部位，增強胰島素作用
    2. (B) 注射胰島素後 60～90 分鐘再運動，運動前補充點心
    3. (C) 避免血糖大幅波動，不宜進行游泳、慢跑等有氧運動
    4. (D) 出現皮膚乾燥、腹痛、呼吸快且深，儘速進食甜食

    正解：(B)

  45. 45當 3 歲的腦瘤女童出現下列何種徵象時，護理師應進一步評估是否為顱內壓上升？

    1. (A) 心跳過快、血壓下降
    2. (B) 頻尿、尿量多
    3. (C) 頭痛、噴射狀嘔吐
    4. (D) 活動量大、貓哭聲

    正解：(C)

  46. 46高小弟，8 個月，診斷泌尿道感染（urinary tract infection），下列護理指導何者最適當？

    1. (A) 嬰兒泌尿道感染常出現不明發燒、食慾不振、餵食困難等症狀
    2. (B) 給予柑橘類果泥，促進酸化尿液，預防感染復發
    3. (C) 醫囑給予抗生素治療，考量抗生素副作用，症狀消失即可停藥
    4. (D) 依照醫囑完整服用抗生素並完成治療後，無須回診追蹤尿液培養

    正解：(A)

  47. 47諾羅病毒（norovirus）引起的急性腸胃炎，下列敘述何者正確？

    1. (A) 好發嬰幼兒且多見於夏季
    2. (B) 建議嬰兒儘早接受口服疫苗的接種
    3. (C) 以酒精及乾洗手消毒
    4. (D) 急性期採禁食和補充水分電解質

    正解：(D)

  48. 48張小弟，8 歲，騎單車跌倒導致右側肱骨骨折，上石膏住院治療，下列護理措施何者最適當？

    1. (A) 上石膏肢體出現蒼白、麻痺感，可做等長運動，促進血液循環
    2. (B) 患側未被石膏固定的關節，維持正常關節活動，減輕關節僵直
    3. (C) 石膏表面出現灼熱點或滲出液，屬正常現象，持續觀察即可
    4. (D) 石膏弄濕時，避免水分滲入，儘快以烤燈或吹風機加速乾燥

    正解：(B)

  49. 49林小妹，15 個月大，疑似腦膜炎住院，有關此疾病之敘述下列何者最適當？

    1. (A) 細菌性腦膜炎之脊髓液中蛋白質值明顯升高
    2. (B) 病毒性腦膜炎之脊髓液中葡萄糖值明顯升高
    3. (C) 細菌性腦膜炎症狀較輕，病程數天可改善
    4. (D) 身體評估會有明顯克爾尼格氏徵象（Kernig’s sign）

    正解：(A)

  50. 50小玉，1 歲 6 個月，罹患熱性痙攣，住院中突然痙攣發作，下列護理措施何者最適當？

    1. (A) 約束抽搐肢體，以防肢體受傷
    2. (B) 可強行於口腔放入壓舌板，以防舌頭受傷
    3. (C) 協助側臥使口中分泌物流出
    4. (D) 發作後會造成神經系統損傷

    正解：(C)
