  1. 1一般而言下列何種類型的機構，其館藏具有較多的複本並採行標準化作業？

    1. (A) 圖書館
    2. (B) 檔案館
    3. (C) 博物館
    4. (D) 藝術畫廊

    正解：(A)

  2. 2下列何種功能可以展現館藏中某一作品的所有版本？

    1. (A) 聚合
    2. (B) 查詢
    3. (C) 定位
    4. (D) 辨識

    正解：(A)

  3. 3為了節省工作時間，圖書館會從網路下載現有書目紀錄到本館系統，這種作業模式稱為：

    1. (A) 書目查核
    2. (B) 抄錄編目
    3. (C) 書目加工
    4. (D) 原始編目

    正解：(B)

  4. 4我國圖書館最常使用 MARC 21 的那一種格式？

    1. (A) 書目資料格式
    2. (B) 分類資料格式
    3. (C) 權威資料格式
    4. (D) 社區資料格式

    正解：(A)

  5. 5我國的機讀編目格式發展於那一年？

    1. (A) 民國 59 年
    2. (B) 民國 69 年
    3. (C) 民國 79 年
    4. (D) 民國 89 年

    正解：(B)

  6. 6依據《中國編目規則》，關於外國人名標目的著錄，若以傑西‧薛拉（Jesse H. Shera）為例，下列何者正確？

    1. (A) 傑西（Jesse H. Shera）
    2. (B) 薛拉（Shera, Jesse H.）
    3. (C) 傑西‧薛拉（Jesse H. Shera）
    4. (D) 薛拉‧傑西（Shera, Jesse H.）

    正解：(B)

  7. 7一書寬度 30.9 公分，長度 23.1 公分，依據《中國編目規則》，下列稽核項的著錄方式何者正確？

    1. (A) 23 公分 × 30 公分
    2. (B) 30.9 公分 × 23.1 公分
    3. (C) 23.1 公分 × 30.9 公分
    4. (D) 24 公分 × 31 公分

    正解：(D)

  8. 8依據《中國編目規則》，下列資料類型標示之著錄方式，何者錯誤？

    1. (A) 牛頓雜誌 [連續性出版品]
    2. (B) 釋迦佛陀 [藝術品原件]
    3. (C) 臺灣省拼圖 [遊戲用品]
    4. (D) 爪哇人頭骨模型 [模型]

    正解：(A)

  9. 9依據《中國編目規則》，會議名稱之標目格式，下列何者錯誤？

    1. (A) 全國大氣科學學術研討會（2：民 69：臺北市）
    2. (B) 師資培育國際學術研討會（民 102：國家圖書館）
    3. (C) 中華民國美術思潮研討會（民 80：臺北市立美術館）
    4. (D) 第一屆亞太地區圖書館學術研討會（民 72：臺北市）

    正解：(D)

  10. 10依據《中國編目規則》，編目機構考慮某一作品是否應使用劃一題名時，下列何者錯誤？

    1. (A) 該作品之知名度
    2. (B) 該作品不同版本及譯本之多寡
    3. (C) 該作品內容增修而題名有異
    4. (D) 該作品之原文是否為外文

    正解：(C)

  11. 11出版品預行編目（CIP）資料中，未提供下列何者？

    1. (A) ISBN
    2. (B) 分類號
    3. (C) 主題詞
    4. (D) 數量及高廣

    正解：(D)

  12. 12下列何者不是著錄資料類型標示（General material designation）的功能之一？

    1. (A) 用以標示作品之媒體類型

    3. (C) 提醒使用者準備相關播放設備
    4. (D) 統計各種資料類型典藏數量

    正解：(D)

  13. 13依據《中國編目規則》，題名及著者敘述項的主要著錄依據，下列何者錯誤？

    2. (B) 期刊最新一期之書名頁
    3. (C) 錄影資料之片頭
    4. (D) 錄音帶之標籤

    正解：(B)

  14. 14依據《中國編目規則》，有關我國的機關標目，下列何者錯誤？

    1. (A) 內政部營建署
    2. (B) 交通部中央氣象局
    3. (C) 行政院法務部
    4. (D) 行政院農業委員會

    正解：(C)

  15. 15根據《中國編目規則》之規定，對於相同的中國人名標目且又同屬相同朝代時，可在姓名之後加註下列那些文字置於圓括弧內加以區分之？①朝代年號 ②西元生卒年 ③性別 ④籍貫

    1. (A) ②②
    2. (B) ②②
    3. (C) ①②②
    4. (D) ②②②

  16. 16依據《中國編目規則》，若作品同時載有著者外文原名及中文譯名時，著者敘述應如何著錄？

    1. (A) 僅著錄外文原名
    2. (B) 僅著錄中文譯名
    3. (C) 兩者都著錄，中文譯名在前，外文原名在後
    4. (D) 兩者都著錄，外文原名在前，中文譯名在後

    正解：(C)

  17. 17依據《中國編目規則》，連續性出版品的主要著錄來源，若含有全名及縮寫兩種形式的題名，應如何著錄正題名？

    4. (D) 兩者都寫

  18. 18依據《中國編目規則》，作品若無出版年之記載，可依下列何種順序之年代著錄？①推定年代 ②印製年 ③序跋年 ④版權年

    2. (B) ②②②①
    3. (C) ②②②①
    4. (D) ①②②②

  19. 19有關《中文圖書分類法》（2007 年版）的使用原則，下列敘述何者錯誤？

  20. 20分類新進館的圖書時，若發現書庫已有 1 本完全相同的圖書，通常會在索書號中，加上何種符號以區隔之？
