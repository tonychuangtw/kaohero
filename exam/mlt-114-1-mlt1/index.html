醫事檢驗師　114 年第一次 臨床生理學與病理學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1心電圖出現下列結果，何者最可能被診斷為左心室肥厚？

    1. (A) V6 導程的 R 波＋V1 導程的 S 波為 30 mm
    2. (B) V5 導程的 R 波高度為 24 mm
    3. (C) V6 導程的 R 波高度為 28 mm
    4. (D) aVF 導程的 R 波高度達 15 mm

    正解：(C)

  2. 2某患者心電圖紀錄顯示，其房室傳導正臨界正常與第一級房室傳導阻滯（atrioventricular block）之間，下列敘述何者正確？

    4. (D) PR segment 橫跨心電圖紙剛好滿十個小格

    正解：(A)

    3. (C) 酒精（alcohol）
    4. (D) 膽紅素（bilirubin）

    正解：(D)

  49. 49有關酒精（乙醇）的敘述，下列何者錯誤？

    1. (A) 因為酒精為水溶性，所以主要由腎臟代謝及排出
    2. (B) 經常飲酒且過量可造成脂肪肝、肝硬化及慢性胰臟炎
    3. (C) 酒精傷害腸胃道黏膜及肝臟
    4. (D) 酒精可造成男性女乳症或睪丸萎縮的現象

  50. 50有關營養不良疾病之敘述，下列何者錯誤？

    2. (B) 小孩如果體重低於同年齡正常小孩體重的 80％，就被認為是營養不良
    3. (C) 小孩如果體重低於正常同年齡及同性別小孩體重的 60％，就被認為是消瘦症（marasmus）
    4. (D) 消瘦症（marasmus）對內臟影響較大，對骨骼肌影響較小

    正解：(D)

    4. (D) 可利用過碘酸希夫瓦染色（Periodic Acid-Schiff stain）偵測病理組織切片梅毒螺旋體的存在

    正解：(B)

    2. (B) 人類乳突瘤病毒（HPV）是一種 DNA 病毒，其致癌性與病毒的 E6 和 E7 蛋白有關

    4. (D) 人類乳突瘤病毒（HPV）疫苗可施打於男性及女性，施打三劑後則有終身的保護力
