警察特考　104 年 四等考試 警察法規概要（警察人員・行政警察人員組）　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1擬任警察機關、學校警察官人員之查核事項，由下列何者統一規劃其查核作業？

    1. (A) 行政院
    2. (B) 內政部
    3. (C) 法務部
    4. (D) 內政部警政署

    正解：(D)

  2. 2下列關於初任警察職務之試用與實習之敘述，何者錯誤？

    1. (A) 試用期滿成績及格，予以實授
    2. (B) 初任各官等警察人員，未具與擬任職務職責程度相當或低一官階之經驗 6 個月以上者，應先予試用 3 個月
    3. (C) 警察專科學校及警察學校學生經實習期滿畢業，考試及格分發任職者，免予試用
    4. (D) 試用期滿成績不及格，予以解職

    正解：(B)

  3. 3警械使用條例之法律性質為：

    1. (A) 警察組織法
    2. (B) 警察作用法
    3. (C) 警察任務法
    4. (D) 警察人事法

    正解：(B)

  4. 4依法令規定警察機關必要時得協調駐在單位，指定駐衛警察在其鄰近地區，協助維護治安、整理交通。有關其執行勤務守則，由下列何者訂定？

    1. (A) 內政部
    2. (B) 內政部警政署
    3. (C) 當地警察局
    4. (D) 當地警察分局

    正解：(C)

  5. 5下列關於警察人員使用警械應遵守規範之敘述，何者錯誤？

    1. (A) 警察人員使用警械時，應注意勿傷及其他之人
    2. (B) 警察人員使用警械時，如非情況急迫，應注意勿傷及其人致命之部位
    3. (C) 警察人員使用警械之原因已消滅者，應立即停止使用
    4. (D) 警察人員應依法合理使用槍械，得逾越必要程度

    正解：(D)

  6. 6關於行政執行之義務人對執行命令、執行方法等情事，得於執行程序終結前，向執行機關提出何種救濟主張？

    1. (A) 聲明異議
    2. (B) 要求申復
    3. (C) 立即抗告
    4. (D) 申請復查

    正解：(A)

  7. 7行政執行分署不服法院關於拘提、管收之裁定者，得提起抗告；有關其抗告之程序，準用下列何法律之規定？

    1. (A) 刑事訴訟法
    2. (B) 行政訴訟法
    3. (C) 行政程序法
    4. (D) 民事訴訟法

    正解：(D)

  8. 8警察行使職權，不得以引誘、教唆人民犯罪或其他違法之手段為之。此為何種原則之遵守？

    1. (A) 比例原則
    2. (B) 明確性原則
    3. (C) 誠信原則
    4. (D) 平等原則

    正解：(C)

  9. 9警察依規定，於查證人民身分之際，得採取之必要措施，不包括下列何者？

    1. (A) 令出示身分證明文件
    2. (B) 搜索其身體及所攜帶之物
    3. (C) 詢問姓名、出生年月日、出生地、國籍
    4. (D) 攔停人、車、船及其他交通工具

    正解：(B)

  10. 10警察實施查訪治安顧慮人口之相關項目，不包括下列何者？

    1. (A) 查訪對象之金錢運用情形
    2. (B) 查訪對象之生活情形
    3. (C) 查訪對象之交往情形
    4. (D) 查訪對象之工作情形

    正解：(A)

  11. 11警察因人民之生命有迫切之危害，非進入不能救護時，得進入住宅。本項職權之法律性質為：

    1. (A) 行政命令
    2. (B) 行政契約
    3. (C) 直接強制
    4. (D) 即時強制

    正解：(D)

  12. 12集會遊行法所稱主管機關，係指：

    1. (A) 集會、遊行所在地之派出所
    2. (B) 集會、遊行所在地之警察分局
    3. (C) 集會、遊行所在地之法院
    4. (D) 集會、遊行所在地之檢察署

    正解：(B)

  13. 13下列關於社會秩序維護法訊問、處罰及執行時效之敘述，何者錯誤？

    1. (A) 對停止營業、罰鍰之執行，自裁處確定之日起，逾 3 個月未執行，免予執行
    2. (B) 對拘留之執行，自裁處確定之日起，逾 6 個月未執行，免予執行
    3. (C) 違反行為有繼續狀態者，裁處期間自行為終了之日起算
    4. (D) 違反本法行為，逾 1 個月，警察機關不得訊問

    正解：(D)

  14. 14某甲有藉端滋擾住戶之行為，警察機關調查後，應如何處理？

    1. (A) 移送由警察分局裁處
    2. (B) 移送法院簡易庭裁定
    3. (C) 移送法院檢察署起訴
    4. (D) 移送由環保局裁罰

    正解：(B)

  15. 15下列何者並非公務人員行政中立法之立法目的？

    1. (A) 確保公務人員執行公正
    2. (B) 適度規範公務人員參與政治活動
    3. (C) 確保社會安全與秩序
    4. (D) 確保公務人員依法行政

    正解：(C)

  16. 16內政部警政署之次級機關中，何者係整併臺灣保安警察總隊、國家公園警察大隊及環保警察隊等而成立的機關？

    1. (A) 保安警察第一總隊
    2. (B) 保安警察第三總隊
    3. (C) 保安警察第五總隊
    4. (D) 保安警察第七總隊

    正解：(D)

  17. 17警員甲於執行路旁盤查勤務時，發現民眾乙疑似酒醉駕駛，甲要求酒測但遭拒絕，乃掏出警槍欲強制乙受測，但因誤觸扳機擊發導致乙因而受重傷。試問下列敘述何者符合警械使用條例規定之意旨？

    1. (A) 甲使用警械之時機符合警械使用條例規定要件
    2. (B) 甲使用警械之行為，為正當防衛之行為
    3. (C) 甲應將使用警械經過情形，即時報告該管長官
    4. (D) 甲應直接對乙支付醫療費或補償金

    正解：(C)

  18. 18依警察教育條例之分類，警察專科學校專科警員班之教育係屬：

    1. (A) 養成教育
    2. (B) 進修教育
    3. (C) 深造教育
    4. (D) 預備教育

    正解：(A)

  19. 19下列何者不屬警察職權行使法所明列職權類型之一？

    1. (A) 查證身分
    2. (B) 鑑識身分
    3. (C) 蒐集資料
    4. (D) 為民服務

    正解：(D)

  20. 20依社會秩序維護法規定，下列何者屬得減輕處罰之人？

    1. (A) 未滿 14 歲人
    2. (B) 教唆他人為違序行為之人
    3. (C) 滿 70 歲人
    4. (D) 為避免緊急危難出於不得已行為之人

    正解：(C)

  21. 21關於違反社會秩序維護法處罰之執行，下列敘述何者錯誤？

    1. (A) 處罰之執行，由警察機關為之
    2. (B) 違反社會秩序維護法案件之處罰，於裁處確定後執行
    3. (C) 裁定拘留確定，經通知執行，無正當理由不到場者，逕予易處罰鍰
    4. (D) 拘留，應在拘留所內執行之

    正解：(C)

  22. 22下列何者為行政執行法所稱之間接強制方法？

    1. (A) 怠金
    2. (B) 收繳、註銷證照
    3. (C) 扣留、收取交付、解除占有、處置、使用或限制使用動產、不動產
    4. (D) 斷絕營業所必須之自來水、電力或其他能源

    正解：(A)

  23. 23行政執行法所稱公法上金錢給付義務，不包括下列何者？

    1. (A) 罰鍰
    2. (B) 代履行費用
    3. (C) 罰金
    4. (D) 怠金

    正解：(C)

  24. 24公職候選人的配偶擔任公務人員，其所為的下列何種行為是公務人員行政中立法所不允許？

    1. (A) 公開為公職候選人站台
    2. (B) 公開為公職候選人助講
    3. (C) 公開為公職候選人遊行拜票
    4. (D) 在大眾傳播媒體具銜廣告

    正解：(D)

  25. 25「深夜喧嘩，妨害公眾安寧者」，依社會秩序維護法第 72 條得處新臺幣 6 千元以下罰鍰。本條所稱深夜，係指：

    1. (A) 午後 11 時至翌日午前 8 時
    2. (B) 凌晨零時至 5 時
    3. (C) 日沒後至日出前
    4. (D) 凌晨零時至 8 時

    正解：(B)
