初等考試　111 年 初等考試 勞工行政與勞工法規大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1甲君參加公務人員考試，經錄取分發至勞動部勞動條件及就業平等司任職，依據現行勞動部組織法及處務規程規定，下列何項非屬甲未來將會處理之事項？

    1. (A) 職業災害補償政策、法規與計畫之研析、規劃及協調
    2. (B) 勞動基準政策、法規與計畫之研析、規劃及協調
    3. (C) 職業災害勞工保護專款之監督及審核
    4. (D) 家事勞動保護政策、法規與計畫之研析、規劃及協調

    正解：(C)

  2. 2女性受僱者因生理日致工作有困難而提出生理假之申請，遭到雇主拒絕而有違反性別工作平等法第 14 條之規定時，受僱者若欲申訴，應向下列何者提出？

    2. (B) 各縣（市）政府
    3. (C) 勞動部勞動條件及就業平等司
    4. (D) 各地方法院

    正解：(B)

  3. 3依現行工會法之規定，下列何類人員，不得組織工會？

    1. (A) 現役軍人與國防部所屬及依法監督之軍火工業員工
    2. (B) 各級公立學校教師
    3. (C) 醫院之受僱者
    4. (D) 國防部及其所屬機關（構）、學校之勞工

    正解：(A)

  4. 4依現行工會法之規定，金融控股公司法所定金融控股公司與子公司內之勞工所組織之工會，為下列何種類型之工會？

    2. (B) 工會聯合組織
    3. (C) 企業工會
    4. (D) 職業工會

    正解：(C)

  5. 5依現行團體協約法之規定，下列何者為團體協約不得約定之事項？

    1. (A) 參與企業經營與勞資合作組織之設置及利用
    2. (B) 限制雇主採用新式機器
    3. (C) 職業災害補償之勞動條件
    4. (D) 非工會會員禁搭便車條款

    正解：(B)

  6. 6工會未與雇主約定由雇主給予一定時數之公假時，下列何種人員得於每月五十小時之範圍內，申請公假辦理會務？

    1. (A) 企業工會監事
    2. (B) 產業工會理事
    3. (C) 職業工會理事長
    4. (D) 企業工會會員代表

    正解：(A)

  7. 7依現行勞資爭議處理法之規定，醫院之受僱者若欲進行罷工，不需遵守下列何項規定？

    1. (A) 不得就權利事項之勞資爭議進行罷工
    2. (B) 應經目的事業主管機關同意，始得宣告罷工
    3. (C) 工會應經會員以直接、無記名投票且經全體過半數同意後，始得宣告罷工
    4. (D) 勞資雙方應約定必要服務條款，工會始得宣告罷工

    正解：(B)

  8. 8依現行勞資爭議處理法之規定，下列關於工會罷工時應遵守規定之敘述，何者錯誤？

    2. (B) 罷工時不得妨害公共秩序之安寧
    3. (C) 罷工期間，爭議當事人雙方應維持工作場所安全及衛生設備之正常運轉
    4. (D) 工會非經會員以直接、無記名投票且經全體過半數同意，不得宣告罷工及設置糾察線

    正解：(B)

  9. 9依現行勞資爭議處理法之規定，經法院核定之裁決有無效或得撤銷之原因者，當事人若欲向原核定法院提起宣告裁決無效或撤銷裁決之訴，最遲應於法院核定之裁決決定書送達後幾日內提起？

    1. (A) 10 日
    2. (B) 20 日
    3. (C) 30 日
    4. (D) 60 日

  10. 10依性別工作平等法之規定，雇主僱用受僱者幾人以上者，應訂定性騷擾防治措施、申訴及懲戒辦法，並在工作場所公開揭示？

    2. (B) 10 人
    3. (C) 30 人

  11. 11依性別工作平等法之規定，下列關於促進工作平等措施之敘述，何者錯誤？

    1. (A) 產檢假及陪產假期間，薪資照給
    2. (B) 女性受僱者因生理日致工作有困難者，每月得請生理假一日，薪資照給
    3. (C) 子女未滿二歲須受僱者親自哺（集）乳者，除規定之休息時間外，雇主應每日另給哺（集）乳時間六十分鐘，薪資照給
    4. (D) 受僱於僱用三十人以上雇主之受僱者，為撫育未滿三歲子女，得向雇主請求每天減少工作時間一小時；減少之工作時間，不得請求報酬

  12. 12依性別工作平等法之規定，雇主於女性受僱者分娩前後，應使其停止工作，給予產假幾星期？

    1. (A) 2 星期
    2. (B) 5 星期
    3. (C) 8 星期
    4. (D) 16 星期

    正解：(C)

  13. 13依性別工作平等法之規定，關於受僱者申請育嬰留職停薪，下列何者錯誤？

    1. (A) 受僱者任職滿六個月後，於每一子女滿三歲前，得申請育嬰留職停薪，期間至該子女滿三歲止，但不得逾二年
    2. (B) 同時撫育子女二人以上者，其育嬰留職停薪期間應合併計算，最長以最幼子女受撫育二年為限
    3. (C) 受僱者申請育嬰留職停薪期間，薪資照給
    4. (D) 受僱者於育嬰留職停薪期間，得繼續參加原有之社會保險，原由雇主負擔之保險費，免予繳納；原由受僱者負擔之保險費，得遞延三年繳納

    正解：(C)

  14. 14依勞動基準法之規定，下列關於派遣事業單位之敘述，何者錯誤？

    1. (A) 派遣事業單位是指從事勞動派遣業務之事業單位
    2. (B) 派遣事業單位與派遣勞工訂定之勞動契約，應為不定期契約
    3. (C) 派遣事業單位與派遣勞工簽訂勞動契約前，得邀請要派單位面試該派遣勞工
    4. (D) 要派單位使用派遣勞工發生職業災害時，要派單位應與派遣事業單位連帶負勞動基準法所定雇主應負職業災害補償之責任

    正解：(C)

  15. 15依勞動基準法之規定，雇主與勞工為離職後競業禁止之約定，應遵守下列何項規定？

    1. (A) 雇主於勞工工作期間，給付勞工未來將因不從事競業行為而可能所受損失之合理補償
    2. (B) 雇主為勞工進行專業技術培訓，並提供該項培訓費用
    3. (C) 基於企業經營上所必須，且不得有不當動機及目的
    4. (D) 勞工擔任之職位或職務，能接觸或使用雇主之營業秘密

    正解：(D)

  16. 16依勞動基準法之規定，下列何者非屬雇主得不經預告終止契約之事由？

    1. (A) 勞工受有期徒刑以上刑之宣告確定，而未諭知緩刑或未准易科罰金者
    2. (B) 勞工對於所擔任之工作確不能勝任時
    3. (C) 勞工故意損耗機器、工具、原料、產品，或其他雇主所有物品，或故意洩漏雇主技術上、營業上之秘密，致雇主受有損害
    4. (D) 勞工無正當理由繼續曠工三日，或一個月內曠工達六日

    正解：(B)

  17. 17依相關勞動法令之規定，勞工於下列何種未提供勞務期間，雇主不需繼續給付勞工工資？

    1. (A) 女性勞工受僱工作在六個月以上，於分娩前後之停止工作的產假期間
    2. (B) 勞工之特別休假期間
    3. (C) 受僱者於其家庭成員預防接種、發生嚴重之疾病或其他重大事故須親自照顧，而請家庭照顧假之期間
    4. (D) 受僱者妊娠期間，雇主應給予產檢假的五日期間

    正解：(C)

  18. 18依勞動基準法之規定，雇主有使勞工在正常工作時間以外工作之必要，且在一日不得超過十二小時的範圍內，下列何項規定非屬雇主應遵守者？

    1. (A) 雇主應經工會同意，如事業單位無工會者，應經勞資會議之同意
    2. (B) 雇主依勞工意願選擇補休並經雇主同意者，應依勞工工作之時數計算補休時數
    3. (C) 延長工作時間之工資，依勞動基準法第 24 條標準加給
    4. (D) 應報當地主管機關備查

    正解：(D)

  19. 19依職業災害勞工保護法之規定，勞工保險之被保險人，在保險有效期間，於本法施行後遭遇職業災害，不得向勞動部勞工保險局申請下列何種補助？

    1. (A) 勞工在醫療中不能工作時，依原領工資數額所請求之補償
    2. (B) 罹患職業疾病，喪失部分或全部工作能力，經請領勞工保險各項職業災害給付後，所欲請領之生活津貼
    3. (C) 因職業災害致遺存障害，必需使用輔助器具，且未依其他法令規定領取器具補助，所欲請領之器具補助
    4. (D) 因職業災害致喪失全部或部分生活自理能力，確需他人照顧，且未依其他法令規定領取有關補助，所欲請領之看護補助

    正解：(A)

  20. 20依勞動檢查法之規定，下列有關工會於勞動檢查中的敘述，何者錯誤？

    2. (B) 事業單位拒絕工會依申訴內容查證後，所提出之書面改善建議，工會得向勞動檢查機構申請實施檢查
    3. (C) 勞動檢查法所定告知工會陪同檢查人員身分範圍，限於受檢事業單位所僱勞工
    4. (D) 勞動檢查員執行職務時，得就勞動檢查範圍，對工會代表詢問，必要時並得製作談話紀錄或錄音

  36. 36職業災害勞工經醫療終止後，經公立醫療機構認定身心障礙不堪勝任工作，雇主終止勞動契約時，應依勞動基準法之規定，發給勞工何種給付？

    1. (A) 資遣費
    2. (B) 退休金
    3. (C) 離職金
    4. (D) 撫卹金

    正解：(B)

  37. 37勞工執行職務發現有立即發生危險之虞時，依職業安全衛生法，在不危及其他工作者安全情形下，可如何處理？

    1. (A) 徵得直屬主管同意後停止作業及退避至安全場所
    2. (B) 通知直屬主管後停止作業及退避至安全場所
    3. (C) 自行停止作業及退避至安全場所，並趕快公告周知
    4. (D) 自行停止作業及退避至安全場所，並立即向直屬主管報告

    正解：(D)

  38. 38聘僱外國留學生及僑生從事工作，除寒暑假外，每星期最長可工作幾小時？

    1. (A) 十二小時
    2. (B) 十八小時
    3. (C) 二十小時
    4. (D) 二十二小時

    正解：(C)

  39. 39關於技能檢定，下列敘述何者錯誤？

    1. (A) 技能檢定之職類，依其技能範圍及專精程度，分為甲、乙、丙三級
    2. (B) 技術士是指技能檢定合格者
    3. (C) 技能檢定僅可由中央主管機關辦理，不可委託辦理
    4. (D) 進用技術性職位人員，取得乙級技術士證者，得比照專科學校畢業程度遴用

    正解：(C)

  40. 40依現行工會法之規定，若美食外送員欲籌組職業工會，下列何項非屬籌組工會時應遵守之規定？

    1. (A) 結合相關職業技能之勞工以組織工會
    2. (B) 由勞工三十人以上之連署發起
    3. (C) 應以同一直轄市或縣（市）為組織區域
    4. (D) 依產業工會職業工會分業標準表為組織

    正解：(D)

  41. 41關於庇護性就業，下列敘述何者正確？

    1. (A) 對於具有就業意願及就業能力，而不足以獨立在競爭性就業市場工作之身心障礙者，提供庇護性就業服務
    2. (B) 雇主無須為身心障礙者辦理參加勞工保險、全民健康保險及其他社會保險
    3. (C) 庇護性就業之身心障礙者，得依其產能核薪
    4. (D) 對於具有就業意願，而就業能力不足，無法進入競爭性就業市場之身心障礙者，提供個別化就業安置、訓練及其他工作協助等支持性就業服務

    正解：(C)

  42. 42工廠、礦場或其他企業組織變賣下腳時，應通知下列何者派人參加？

    1. (A) 職工福利委員會
    2. (B) 企業工會
    3. (C) 產業工會
    4. (D) 職業工會

    正解：(A)

  43. 43下列何種工會不是單元式工會體系？

    3. (C) 廠場範圍之企業工會
    4. (D) 關係企業範圍之企業工會

    正解：(B)

  44. 44下列何種爭議，是屬調整事項之勞資爭議？

    1. (A) 退休準備金為足額提撥之爭議
    2. (B) 退休金提繳率 7%起之爭議
    3. (C) 加班費短少之爭議
    4. (D) 拒絕企業工會理事請會務公假之爭議

  45. 45下列何者非地方主管機關可處理之爭議？

    1. (A) 休息日工資短少之爭議

    3. (C) 無正當理由拒絕團體協商之爭議
    4. (D) 團體協約所訂違約金請求之爭議

    正解：(C)

  46. 46有關陪產假之敘述，下列何者錯誤？

    1. (A) 配偶分娩及流產，受僱者皆可請陪產假
    2. (B) 陪產假有五日
    3. (C) 陪產假之請假期間為配偶分娩當日及其前後合計十五日之期間內
    4. (D) 陪產假期間，薪資照給

    正解：(A)

  47. 47關於勞動部勞工保險局業務之敘述，下列何者正確？

    1. (A) 積欠工資墊償與保險無關，故非勞動部勞工保險局之業務
    2. (B) 因勞工保險有醫療給付，故健康保險是勞動部勞工保險局之業務
    3. (C) 勞工退休金與保險無關，故非勞動部勞工保險局之業務
    4. (D) 就業保險涉及勞工保險失業給付業務，為勞動部勞工保險局之業務

    正解：(D)

  48. 48職工福利委員會之工會代表，其比例不得少於：

    1. (A) 四分之一
    2. (B) 三分之一
    3. (C) 二分之一
    4. (D) 三分之二

    正解：(D)

  49. 49關於育嬰留職停薪，下列敘述何者正確？

    1. (A) 受僱者有未滿三歲之小孩，就可申請育嬰留職停薪
    2. (B) 育嬰留職停薪期間之健康保險保險費可由勞工保險予以補助
    3. (C) 育嬰留職停薪期滿後，雇主有法定事由並經主管機關同意時，可拒絕受僱者復職之申請
    4. (D) 雇主拒絕受僱者復職，應於十日前通知

    正解：(C)

  50. 50依勞工保險條例之規定，受僱於僱用勞工五人以上之民營工廠之員工，投保單位應為其負擔多少比例之職業災害保險費？
