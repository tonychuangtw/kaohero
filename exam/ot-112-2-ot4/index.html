職能治療師　112 年第二次 心理障礙職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1依據DSM-5對睡－醒障礙（Sleep-Wake Disorders）診斷標準，下列敘述何者正確？①在失眠症（InsomniaDisorder）準則A加入了對睡眠質量之抱怨和不滿意 ②不再區分原發性和繼發性 ③將非恢復性睡眠（nonrestorative sleep）歸類為失眠症之特質 ④將非恢復性睡眠（nonrestorative sleep）歸類為嗜睡症（Hypersomnolence Disorder）之特質

    1. (A) ①②③
    2. (B) ①②④
    3. (C) 僅①④
    4. (D) 僅②③

    正解：(B)

  27. 27思覺失調症常被外界誤解，有關此疾病的迷思與導正，下列描述何者錯誤？

    2. (B) 迷思：思覺失調症的個案既危險又暴力；觀念導正：個案較有可能攻擊他人，較少傷害自己
    3. (C) 迷思：此疾病屬人格分裂；觀念導正：人格分裂屬於解離性身份障礙症（Dissociative Identity Disorder），與此疾病無關
    4. (D) 迷思：個案罹病後會功能退化且需安置在機構療養；觀念導正：大部分個案與家人同住或安置在社區的機構，部分個案仍可就學或就業

    正解：(B)

  30. 30有關職能治療目標之擬訂，下列敘述何者錯誤？

    2. (B) 目標擬定需要服務使用者與治療師的共同合作，在過程中宜鼓勵與支持服務使用者對自己所設立的目標負責
    3. (C) 擬定目標有助於引導治療過程，將個案對於治療的願景與目標從模糊的概念到具體的步驟，宜兼具挑戰與可達成性

    3. (C) 治療活動中如需使用到尖銳的器具或具有潛在自我傷害的物品，經職能治療師評估判斷即可使用，不須在團隊會議中提出討論
    4. (D) 精神科急性個案的風險評估可等到個案急性精神症狀較為穩定後再行評估確認

    正解：(A)

  76. 76藥物治療能有效地減緩個案精神症狀或改善情緒，但部分個案會出現藥物副作用。在精神復健機構如康復之家從事社區復健服務之職能治療師可提供的策略中，下列何者錯誤？

    1. (A) 對於服用某些精神科藥物需要定期回診並做抽血及健康檢查的個案，治療師可教導其有關大眾運輸工具的使用，促使其規律回診
    2. (B) 治療師可在團隊會議中諮詢及討論個案用藥情形，以獲取正確處理藥物副作用之措施，不需熟知個案所使用之藥物
    3. (C) 治療師可幫助個案設定手機鬧鈴或在冰箱的門貼上便條紙，提醒個案按時服藥
    4. (D) 治療師可與其他醫療人員討論，在復健活動中加入運動及飲食建議，以改善其服用精神科藥物之副作用

    正解：(B)

  77. 77當精神個案有明顯的負性症狀，如緊張僵直的行為（catatonic behavior）、認知及動作反應遲緩、言語表達明顯退縮時，下列敘述何者錯誤？

    1. (A) 這類症狀容易在參加活動時誘發正性精神症狀出現，而導致個案活動參與困難，無法妥善組織職能工作
    2. (B) 職能治療師針對此類個案設計體能運動時，同時結合口語指令可成功鼓勵其參與活動
    3. (C) 職能治療師可將活動過程拆解成數個小步驟，教導個案逐步完成，可讓個案從中獲得成功的經驗並增加參與活動的動機
    4. (D) 職能治療師在治療活動中加入動作的刺激（motor stimulation），可提供此類個案的警覺反應（alertingresponse）

    正解：(A)

  78. 78有關復元模式（Recovery Model）的敘述，下列何者錯誤？

    1. (A) 復元模式最常運用在非機構式的環境，但亦可使用於嚴重精神疾病的住院個案上（例如美國的公立醫院）
    2. (B) 復元模式運用在精神個案的服務上，如灌輸希望、提供賦能（empowerment）、及促進個案的責任感
    3. (C) 職能治療師以醫療考量提供此服務模式，強調個案的共同需求及同儕服務
    4. (D) 此模式的治療介入鼓勵個案在生活中做出選擇，並支持其達到自我認同（self-identified）的目標

    正解：(C)

  79. 79在社區復健中心對個案拍照或錄影，以便保留個案活動資料或是在未來評鑑時呈現，則下列針對個案隱私保密之相關敘述，何者錯誤？

    1. (A) 為評鑑或教學使用，機構可以拍攝個案參與活動過程
    2. (B) 個案擁有自己的肖像權使用與否的權利
    3. (C) 任何可能拍攝到個案的活動，職能治療師需確認個案同意拍攝
    4. (D) 職能治療師與個案會談若需錄音，應先徵得個案同意

    正解：(A)

  80. 80在心理疾病職能治療的服務機構中，下列何種場所應最強調出院後計畫的擬定？

    1. (A) 會所（clubhouse）
    2. (B) 社區復健中心
    3. (C) 急性病房
    4. (D) 康復之家

    正解：(C)
