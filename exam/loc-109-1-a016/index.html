地方特考　109 年 三等 經濟學概論與財政學概論　考古題與詳解

  1. 1假設某項商品為正常財，且其市場結構為完全競爭市場。當大多數消費者的所得增加時，下列敘述，何者正確？

    1. (A) 市場需求曲線會往上移
    2. (B) 市場需求曲線會往下移
    3. (C) 市場供給曲線會往上移
    4. (D) 市場供給曲線會往下移

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 正常財的需求隨所得增加而增加，市場需求曲線整條往右上方移動。

    ❌ (B) 往左下方移動是所得減少或劣等財的情形。

    ❌ (C) 所得變動屬需求面因素，不移動供給曲線。

    ❌ (D) 供給曲線的移動取決於成本、技術等供給面因素。

    📚 出處：經濟學；需求的變動與正常財。

  2. 2假設某國汽油零售價格為20元，每年全國汽油的總支出約為2,000億元，而汽油的價格需求彈性則為−0.5。當每公升汽油價格增加0.2元時，下列敘述，何者正確？

    1. (A) 每年汽油的總消費量會增加，每年汽油的總支出會增加
    2. (B) 每年汽油的總消費量會下降，每年汽油的總支出會增加
    3. (C) 每年汽油的總消費量會增加，每年汽油的總支出會下降
    4. (D) 每年汽油的總消費量會下降，每年汽油的總支出會下降

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 需求彈性絕對值 0.5 小於 1，屬缺乏彈性；漲價使消費量減少的幅度小於價格上漲幅度，總支出因而增加。

    ❌ (A) 價格上漲會使消費量下降而非增加。

    ❌ (C) 消費量的方向與支出的方向都不正確。

    ❌ (D) 缺乏彈性下漲價會使總支出增加而非下降。

    📚 出處：經濟學；需求彈性與總支出。

  3. 3假設在一寡占市場中有兩家廠商（A 和 B），兩家廠商有相同的總成本函數，皆為 TC(Q)=3Q，其中 Q 為產量。市場需求函數為 Qd =10-P，其中 Qd 為市場總需求量，P 為市場價格。如果 A 和 B廠商採取價格競爭且同時出招，試求市場的均衡價格為何？

    1. (A) 0
    2. (B) 3
    3. (C) 6.5
    4. (D) 7

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 兩家廠商生產同質商品並同時決定價格（Bertrand 競爭），互相削價的結果是價格降至邊際成本 3。

    ❌ (A) 價格 0 低於邊際成本，廠商必然虧損而退出。

    ❌ (C) 6.5 為獨占的均衡價格。

    ❌ (D) 7 高於獨占價格，更非競爭結果。

    📚 出處：個體經濟學；Bertrand 價格競爭模型。

  4. 4假設某消費者的效用函數為 U(X,Y)=X2Y，其中 X 和 Y 為財貨的數量。下列有關該消費者需求函數（曲線）特性的敘述，何者錯誤？

    1. (A) X 財貨的需求曲線為負斜率
    2. (B) Y 財貨為正常財
    3. (C) 當 X 財貨的價格為1元以及所得為3元時，消費者對 X 財貨的需求量為2單位
    4. (D) 當僅有 Y 財貨的價格增加時，X 財貨的需求會減少

    正解：(D)
