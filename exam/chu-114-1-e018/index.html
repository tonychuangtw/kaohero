初等考試　114 年 初等考試 資料處理大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1電腦中有各式記憶單元，用於儲存處理單元進行運算時需要的資料或程式，下列何者位於 CPU 內？

    1. (A) 硬碟（Hard Disk）
    2. (B) 暫存器（Register）
    3. (C) 主記憶體（Main Memory）
    4. (D) 快取記憶體（Cache Memory）

    正解：(B)

  2. 2某電腦系統匯流排頻寬為 1.6 GB/s，匯流排寬度為 32 Bits，其傳輸頻率是多少？

    1. (A) 50 MHz
    2. (B) 51.2 MHz
    3. (C) 400 MHz
    4. (D) 409.6 MHz

    正解：(C)

  3. 3在 Windows 系統的命令提示字元中，下列那個指令可查詢本機 IP 位址？

    1. (A) configip
    2. (B) ipconfig
    3. (C) showip
    4. (D) ipshow

    正解：(B)

  4. 4相較於中央處理器（CPU），下列關於圖形處理器（GPU）的描述那個錯誤？

    1. (A) 核心的數量較多
    2. (B) 無法完全取代 CPU
    3. (C) 擅長平行處理
    4. (D) 專為通用運算而設計

    正解：(D)

  5. 5P1, P2, P3 三個程序所需處理時間依序為 10, 5, 15 毫秒，下列那個 CPU 排程有最短的平均等待時間？

    1. (A) P1→P2→P3
    2. (B) P2→P1→P3
    3. (C) P3→P1→P2
    4. (D) P3→P2→P1

    正解：(B)

  6. 6ARM 是一種常見的 CPU 架構，下列那個產品不是使用 ARM 架構？

    1. (A) AMD Ryzen
    2. (B) Apple M2
    3. (C) MediaTek Dimensity
    4. (D) Qualcomm Snapdragon

    正解：(A)

  7. 7Excel 中那個函數可以將數字四捨五入？

    1. (A) ABS
    2. (B) FACT
    3. (C) SIGN
    4. (D) ROUND

    正解：(D)

  8. 8下列那個是將 16 進位數字 A3.D16 轉換為二進位數字的結果？

    3. (C) 可以精準表示 10 進位小數
    4. (D) 由符號、偏移指數與尾數三部分組成

  10. 10下列常見音訊檔格式，那個採取無失真壓縮？

    1. (A) AAC
    2. (B) MP3
    3. (C) WMA

    3. (C) Gemini
    4. (D) Gamma

  13. 13相較於編譯程式（Compiler），下列針對直譯程式（Interpreter）的描述那個錯誤？

    1. (A) 需產生目的碼
    2. (B) 執行速度比較慢
    3. (C) 除錯難易度較低

  14. 14下列 C++程式執行後，i 與 x 的值分別為多少？int i=1, x=0;while (i<50){x=x+i;i=++i+2;}

    1. (A) 49; 400
    2. (B) 49; 425
    3. (C) 52; 400
    4. (D) 52; 425

    正解：(D)

  15. 15假設有 N 個不重複的整數，分別用環狀佇列、雜湊與 AVL 樹三種資料結構儲存，若要搜尋某個值 x 是否存在，則理論上搜尋速度由快到慢依序為何？

    1. (A) 環狀佇列，雜湊，AVL 樹
    2. (B) AVL 樹，環狀佇列，雜湊
    3. (C) 雜湊，AVL 樹，環狀佇列
    4. (D) AVL 樹，雜湊，環狀佇列

    正解：(C)

  16. 16適當使用演算法可以協助問題解決，迷宮問題、合併排序，分別適合使用什麼演算法技巧來解題？

    1. (A) Backtracking; Divide and Conquer
    2. (B) Divide and conquer; Dynamic Programming
    3. (C) Greedy; Dynamic Programming
    4. (D) Backtracking; Greedy

    正解：(A)

  17. 17圖形（Graph）的走訪有深度優先（Depth-First）與廣度優先（Breadth-First）兩種搜尋方法，通常分別使用什麼資料結構來實作？

    3. (C) Heap; Hash
    4. (D) Stack; Queue

  18. 18下列遞迴函數，輸入 x=5 時，回傳值是多少？int f(int x){if(x == 1) return 1;else if (x%2==0) return f(x/2);else return f(x-1)+f(x+1);}

    2. (B) 2
    3. (C) 3
