警察特考　115 年 三等考試 行政法　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1依司法院大法官解釋意旨，有關授權明確性原則之敘述，下列何者錯誤？

    1. (A) 裁罰性不利處分之構成要件與法律效果皆應於法律明定，不得授權以命令定之
    2. (B) 法律未就授權內容與範圍明確規定，但能透過法律整體解釋推知立法者是否有意授權者，不違反授權明確性原則
    3. (C) 可就授權條款與該法律其他條文之關聯性，運用法學解釋原則得出授權條款之內容、目的及範圍者，不違反授權明確性原則
    4. (D) 可從法律制定過程中所表現之整體追求目的，透過通常法學解釋原則得出授權條款之內容、目的及範圍者，不違反授權明確性原則

    正解：(A)

  2. 2關於行政法法律關係權利義務之變動，下列敘述何者錯誤？

    1. (A) 公務員請領退休金之權利可以讓與
    2. (B) 法務部行政執行署各分署於行政執行程序中科處甲怠金，甲死亡後，其繼承人乙不須繼承該怠金之繳納義務
    3. (C) 丙所有之違章建築，主管機關命其拆除，丙將該建物所有權移轉予丁，丁仍有拆除之義務
    4. (D) 戊有權向稅務主管機關申請退稅，戊死亡後，於請求權時效消滅前，其繼承人己可繼承該權利

    正解：(A)

  3. 3下列規定，何者未賦予行政機關裁量權限？

    1. (A) 所得稅法第 2 條第 1 項：「凡有中華民國來源所得之個人，應就其中華民國來源之所得，依本法規定，課徵綜合所得稅。」
    2. (B) 加值型及非加值型營業稅法第 48 條之 1 規定：「營業人對於應稅貨物或勞務之定價，未依第三十二條第二項規定內含營業稅，經通知限期改正，屆期未改正者，處新臺幣一千五百元以上一萬五千元以下罰鍰。」
    3. (C) 行政程序法第 93 條第 1 項前段規定：「行政機關作成行政處分有裁量權時，得為附款。」
    4. (D) 社會秩序維護法第 29 條第 1 項：「違反本法行為之情節可憫恕者，得減輕或免除其處罰。」

    正解：(A)

  4. 4依地方制度法規定，各該民選公職人員依法有應予解除其職權或職務之情事時，下列敘述何者錯誤？

    1. (A) 直轄市議員、直轄市長由行政院分別解除其職權或職務
    2. (B) 縣（市）議員、縣（市）長由內政部分別解除其職權或職務
    3. (C) 鄉（鎮、市）民代表、鄉（鎮、市）長由縣政府分別解除其職權或職務
    4. (D) 村（里）長由鄉（鎮、市）民代表會解除其職務

    正解：(D)

  5. 5關於獨立機關之敘述，下列何者正確？

    1. (A) 採首長制，但機關之委員依法律獨立行使職權，首長應予尊重
    2. (B) 行政院法規會屬於相當於二級機關之獨立機關
    3. (C) 公平交易委員會之組織，應以法律定之
    4. (D) 獨立機關成員均有任期保障，但可透過委員會過半數成員同意將其解職

    正解：(C)

  6. 6關於機關權限之敘述，下列何者錯誤？

    1. (A) 行政機關委任有隸屬關係之下級機關執行行政任務，應有法規之依據，並將其委任事項公告
    2. (B) 在直轄市經營旅館業務，依法應向直轄市政府申請登記領取登記證，對於未經領取登記證而經營旅館業務者之裁處，得由直轄市政府所屬機關以自己名義為之
    3. (C) 機關對特定事務具管轄權，但土地管轄不明時，依行政程序法第 12 條定之
    4. (D) 自治法規之主管機關為直轄市政府，如屬自治事項或團體委辦事項者，直轄市自治條例得明定其主管機關為直轄市政府所屬下級機關

    正解：(B)

  7. 7關於公務員懲戒法規定之上訴制度，下列敘述何者錯誤？

    1. (A) 懲戒法庭之上訴審為法律審
    2. (B) 監察院有上訴權，被付懲戒人之主管機關無上訴權
    3. (C) 上訴狀內未表明上訴理由者，上訴人應於提起上訴後 20 日內提出理由書於原懲戒法庭
    4. (D) 懲戒法庭第二審之判決，原則上應經言詞辯論為之

    正解：(B)

  8. 8行政機關依法將公務人員考績評定為丁等，並將其免職，依司法實務見解，下列敘述何者錯誤？

    1. (A) 免職權屬於行政權之行使，且為行政機關人事權之固有核心內容
    2. (B) 為鞏固行政權行使免職權之完整性，立法權不得制定免職事由及應遵守之法律程序
    3. (C) 公務人員之考績及免職，適合由行政機關行使並為第一次決定
    4. (D) 憲法第 77 條並不包含公務人員之懲處，且未蘊含懲戒一元化原則

    正解：(B)

  9. 9下列何者非屬依公務人員任用法依法任用之人員？

    1. (A) 新北市政府地政局科長
    2. (B) 外交部政務次長
    3. (C) 臺中市大甲地政事務所主任
    4. (D) 大陸委員會綜合規劃處科員

    正解：(B)

  10. 10關於法規命令之審查，下列敘述何者錯誤？

    1. (A) 上級機關得於核定法規命令時，予以審查
    2. (B) 法規命令發布後，應即送立法院審查
    3. (C) 立法院相關委員會未於法定期間完成審查者，法規命令失其效力
    4. (D) 考試院對於公務人員人事考銓之法規命令，擁有審查權

    正解：(C)

  11. 11為辦理智慧建築標章評定作業事宜，內政部訂定評定專業機構申請指定作業要點。下列敘述何者正確？

    1. (A) 規範對象為評定機構與著作權人
    2. (B) 作業要點為委任立法，屬於行政法法源之一
    3. (C) 因未經法律授權，違反法律保留原則
    4. (D) 人民得基於平等原則，主張有行政自我拘束

    正解：(D)

  12. 12建管機關甲於拆除違建時，預期將遭遇屋主的強力抵抗，遂請求警察機關乙提供協助，下列敘述何者錯誤？

    1. (A) 除情況緊急，甲機關應以書面請求乙機關提供協助
    2. (B) 乙機關如提供協助將嚴重妨害其自身職務之執行時，應拒絕提供協助
    3. (C) 乙機關於提供協助時，得代行甲機關之職權
    4. (D) 乙機關得向甲機關請求負擔提供協助所需之費用

    正解：(C)

  13. 13關於暫時性行政處分之敘述，下列何者錯誤？

    1. (A) 行政機關在事實調查終結前，先作成暫時性決定，但保留將來依據調查確定之事實作成新決定之可能
    2. (B) 暫時性處分於終局性處分作成時，無信賴保護之適用
    3. (C) 作成終局決定前，須先撤銷暫時性處分，方可作成終局性處分
    4. (D) 應有法律授權，始能作成侵益性暫時性處分

    正解：(C)

  14. 14有關行政事實行為，下列敘述何者正確？

    1. (A) 行政事實行為有公法性質與私法性質之分
    2. (B) 實施構成人民權利干涉之強制性措施，原則上不需要有明確法律依據
    3. (C) 事實行為並非法律行為，無從以一般法律原則拘束之
    4. (D) 對於事實行為，我國目前尚無行政救濟之途徑

    正解：(A)

  15. 15主管機關依法劃設水質水量保護區，於該區內取用地面水或地下水者，須繳交水源保育與回饋費；另對於該區內土地使用因而受限制之人民，主管機關應給予補償金，必要時得徵收其土地。下列何者為行政契約？

    1. (A) 通知繳交水源保育與回饋費
    2. (B) 土地限制使用補償金之協議
    3. (C) 土地徵收補償金之發放及領取
    4. (D) 劃設水質水量保護區

    正解：(B)

  16. 16有關行政指導之敘述，下列何者錯誤？

    1. (A) 直轄市山地原住民區區長甲對居民乙以口頭建議遷離現址住處，乙得要求甲與相關主管機關以書面為明示
    2. (B) 縣長丙勸告事業丁應捐獻鄉里回饋金，丁得要求縣政府應停止行政指導，並不得據此為不利之處置
    3. (C) 居民戊接受直轄市政府有關流動攤販營業之輔導、協助，惟戊未履行其承諾，該直轄市政府得逕以行政指導為行政執行名義
    4. (D) 人民接受行政機關之行政指導，仍受到信賴保護原則之保障，行政機關不得恣意為與指導內容相矛盾之舉措

    正解：(C)

  17. 17行政機關進行行政罰之裁處程序時，行使下列何項職權並無行使裁量權之可能？

    1. (A) 使用強制力排除行為人抗拒保全證據行為
    2. (B) 扣留可作為證據之物品
    3. (C) 對於扣留物品施加封緘
    4. (D) 因無法辨認行為人身分且情況急迫，命行為人至指定處所查證身分

    正解：(C)

  18. 18關於不服行政執行之救濟，依司法實務見解，下列敘述何者錯誤？

    1. (A) 不服法務部行政執行署之異議決定，應踐行訴願程序後，始得提起行政訴訟
    2. (B) 不服執行機關之扣押命令，得於執行程序終結前，向執行機關聲明異議
    3. (C) 行政執行原則上不因聲明異議而停止執行，但執行機關得於必要時依職權或申請停止之
    4. (D) 義務人或利害關係人未於執行程序中聲明異議，亦得依國家賠償法請求損害賠償

    正解：(A)

  19. 19依現行法及司法實務見解，有關政府資訊公開之敘述，下列何者錯誤？

    1. (A) 任何人民申請閱覽或複製政府資訊時，如該項資訊屬於已歸檔管理之檔案，應優先適用檔案法
    2. (B) 主管機關取得轄內未合法登記之民宿業者名稱、地址等資訊，因涉及個人隱私，未經該當事人同意，不得提供或主動公開
    3. (C) 刑事案件經偵查與審判確定後，其偵查與審判卷宗之閱覽，有檔案法及政府資訊公開法之適用
    4. (D) 政府機關以書面作成拒絕提供政府資訊之決定，應記載主旨、事實、理由及其法令依據，以說明其合法性

    正解：(B)

  20. 20對於下列行政處分不服者，何者須進行訴願程序？

    1. (A) 公務人員保障法之復審
    2. (B) 政府採購法之採購申訴審議判斷
    3. (C) 經依行政程序法之聽證後作成之處分
    4. (D) 稅捐稽徵法之復查

    正解：(D)

  21. 21關於訴願程序中原處分之停止執行，下列敘述何者錯誤？

    1. (A) 於訴願期間，原行政處分之執行，除法律另有規定外，不因提起訴願而停止
    2. (B) 受理訴願機關認為原行政處分之合法性顯有疑義者，可依職權命原處分機關停止執行
    3. (C) 於訴願期間，行政法院亦得依聲請停止執行
    4. (D) 於訴願期間，如原行政處分機關依申請停止執行，須就原行政處分全部予以停止執行

    正解：(D)

  22. 22關於行政救濟之敘述，下列何者正確？

    1. (A) 因都市計畫之性質屬法規命令，故無法提起行政訴訟
    2. (B) 對於違法行政處分，應提起一般確認訴訟
    3. (C) 對於行政事實行為，得提起課予義務訴訟
    4. (D) 對於行政契約所生爭議，得提起一般給付訴訟

    正解：(D)

  23. 23下列何種情形不得獨立提起行政訴訟？

    1. (A) 學生因無照駕駛機車受學校記大過一次
    2. (B) 學生因學校不准其跨學院加選課程
    3. (C) 役男不服徵兵體位判定結果
    4. (D) 人民請求承辦其申請案之公務員迴避遭駁回

    正解：(D)

  24. 24關於公務員執行職務行使公權力所生之國家賠償責任，下列敘述何者錯誤？

    1. (A) 甲員警指揮拖吊業者，拖離違停車輛時，該業者不小心刮傷車體，適用國家賠償法
    2. (B) 乙檢察官違法追訴當事人，造成被告權利受損，無論違法追訴罪判決確定與否，均適用國家賠償法
    3. (C) 丙公務員收賄後，違法變更土地所有權之登記，造成原所有權人受到損害，適用國家賠償法
    4. (D) 丁公務員因疏忽誤算人民應繳納之回饋金，致人民溢繳受到損害，適用國家賠償法

    正解：(B)

  25. 25公共設施因設置或管理有欠缺，致人民生命、身體、人身自由或財產受損害者，國家所負賠償責任之法律性質為何？

    1. (A) 自己責任說
    2. (B) 代位責任說
    3. (C) 中間責任說
    4. (D) 併合責任說

    正解：(A)
