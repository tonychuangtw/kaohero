  1. 1有關指令集架構（instruction set architecture, ISA）的敘述，下列何者錯誤？

    1. (A) 指令集架構為硬體與低階軟體（系統軟體）之間的抽象介面
    2. (B) 不同類型或廠牌的處理器，如：Intel 與 ARM 處理器，皆使用相同的指令集架構
    3. (C) 指令集架構的內容包括：指令格式、暫存器、記憶體存取、輸出與輸入等
    4. (D) 應用二進制介面（application binary interface, ABI）定義不同電腦間二進制可攜性的標準

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 此項錯誤：Intel 採 x86、ARM 採 ARM 指令集，不同廠牌處理器的指令集架構並不相同，這正是程式無法跨架構直接執行的原因。

    ❌ (A) 敘述正確，ISA 是硬體與系統軟體之間的抽象介面。

    ❌ (C) 敘述正確，ISA 涵蓋指令格式、暫存器、記憶體存取與 I/O。

    ❌ (D) 敘述正確，ABI 定義二進位層級的可攜性標準。

    📚 出處：計算機組織；指令集架構。

  2. 2有關處理器虛擬化的敘述，下列何者正確？

    1. (A) 處理器虛擬化所造成的額外負擔（overhead）與工作負載所執行的指令類型無關，無論是以運算為主或是 I/O 密集都相同
    2. (B) 當作業系統呼叫（system call）使用的頻率較少時，處理器虛擬化所造成的額外負擔一般也較少
    3. (C) 具頻繁輸入輸出的工作，因為需要等待裝置處理資料，其處理器虛擬化的額外負擔非常高
    4. (D) 以運算為主（processor-bound）的程式執行時，處理器虛擬化的額外負擔非常高

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 虛擬化的額外負擔主要來自特權指令與系統呼叫需經虛擬機監督器攔截處理，系統呼叫愈少，額外負擔愈小。

    ❌ (A) 額外負擔與工作負載的指令類型高度相關。

    ❌ (C) I/O 等待期間 CPU 可執行其他工作，等待本身不構成虛擬化負擔。

    ❌ (D) 純運算的指令多可直接在硬體執行，虛擬化負擔反而很低。

    📚 出處：作業系統；虛擬化的效能開銷。
