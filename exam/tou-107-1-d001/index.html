  1. 1雪霸國家公園所涵蓋的行政區域不包括下列那一個縣市？

    4. (D) 社會因素

    正解：(B)

  4. 4國立故宮博物院館藏的明初工藝器物的製作過程中，所謂「剔紅」應屬下列何種器物的工藝技法？

  7. 7下列有關「武陵農場」導覽解說與生態資源之敘述，何者錯誤？

    2. (B) 目前隸屬於行政院農業委員會管轄範圍
    3. (C) 動物資源包括冠羽畫眉、青背山雀、繡眼畫眉、盤古蟾蜍、大紅紋鳳蝶與雪螢等豐富的動物資源
    4. (D) 植物資源包括臺灣原生山櫻花與霧社櫻等，是臺灣原生種櫻樹最適合生長的地方

    4. (D) 採用一個大人對一個小朋友的方式，可幫助大人和小朋友更有效地專注在活動中

  15. 15下列何者不是解說的內涵？

  25. 25旅客如於參觀景點途中走失，下列何者不是領團人員應有的態度或方法？
