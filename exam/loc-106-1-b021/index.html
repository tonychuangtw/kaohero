  1. 1圖書館服務平臺（Library Service Platform，LSP）可謂次世代的整合式圖書館系統，下列有關於 LSP 特質的描述何者錯誤？

    1. (A) 提供封閉性的特定 API 以進行系統擴充和跨系統的互操作性
    2. (B) 整合跨資料與媒體格式的工作流程
    3. (C) 彈性運用的詮釋資料管理
    4. (D) 高度共享的資料模型

    正解：(A)

    逐題詳解（免費試讀）

    ✅ (A) 此項錯誤：LSP 的特質在於提供「開放」API 以利系統擴充與跨系統互操作。

    ❌ (B) 整合跨資料與媒體格式的工作流程為其特質。

    ❌ (C) 彈性運用的詮釋資料管理為其特質。

    ❌ (D) 高度共享的資料模型為其特質。

    📚 出處：圖書館服務平臺（LSP）。

  2. 2近年來，圖書館電子書的採購方式有轉向由讀者主導採購的趨勢，係由讀者先使用電子書後，再決定購買的方式，此種採購方式稱為：

    1. (A) Pay Per View
    2. (B) Approval Plan
    3. (C) Blanket Order
    4. (D) Patron Driven Acquisition

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 由讀者實際使用後才觸發採購者，為讀者主導採購（Patron Driven Acquisition）。

    ❌ (A) Pay Per View 為按次計費的使用模式。

    ❌ (B) Approval Plan 由書商依館方配置方案先行寄送。

    ❌ (C) Blanket Order 為概括訂購。

    📚 出處：館藏發展的採購模式。

  3. 3隨著 Flickr 等社會性書籤網站的興起與應用，產生所謂標籤機制，而形成俗民分類法（folksonomy），其主要特質並不包括：

    1. (A) 由下而上的組織方式
    2. (B) 是一種控制詞彙
    3. (C) 以使用者使用為中心
    4. (D) 結構不具有階層從屬關係

    正解：(B)

    逐題詳解（免費試讀）

    ✅ (B) 俗民分類法由使用者自由標記，並非控制詞彙。

    ❌ (A) 由下而上的組織方式為其特質。

    ❌ (C) 以使用者為中心為其特質。

    ❌ (D) 結構扁平、無階層從屬為其特質。

    📚 出處：folksonomy（社會性標記）。
