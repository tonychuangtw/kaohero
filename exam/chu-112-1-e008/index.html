初等考試　112 年 初等考試 社會工作大意　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1社會團體工作加入社會工作的實施方法初期，是因為有一些社會工作者開始以小團體的方式來幫助人，但常被認為是下列何種活動而引起爭議，不認為這是一種專業的實施方法？

    1. (A) 休閒活動
    2. (B) 治療活動
    3. (C) 聊天活動
    4. (D) 宗教活動

    正解：(A)

  2. 2社會工作專業在實現四個目標，對於這些社會工作目標的敘述，下列何者錯誤？

    1. (A) 幫助解決問題能力較低，或能力受限的人，增強或發展其能力
    2. (B) 連結人與環境體系，以獲得資源、服務與機會
    3. (C) 倡導更多的服務方案與機構，並為處於不利地位者的利益辯護
    4. (D) 解釋和說明政策，使處於不利地位者配合政策的要求

    正解：(D)

  3. 3「國民教育法」第 10 條明定達 55 班以上之學校由學校社會工作者進駐校園提供服務，但若人力不足，通常輔導諮商中心都會要求駐校社會工作者同時服務鄰近學校，以共享社會工作服務資源，此一服務模式屬於下列何者？

    2. (B) 駐區模式
    3. (C) 策略聯盟模式
    4. (D) 駐校模式

    正解：(C)

  4. 4若將社會工作者的基本角色歸納為直接服務或間接服務，下列關於社會工作者的角色和服務類型範疇的配對，何者正確？

    2. (B) 倡導者－直接服務
    3. (C) 團體催化者－間接服務
    4. (D) 調解者－直接服務

    正解：(D)

  5. 5認為社會工作應該聚焦於根本的社會政策議題，即「批發的社會福利」；而不是只著重於零星的個案救助，所謂的「零售的社會福利」。這段話描述的是社會工作專業教育發展過程中的何種爭議？

    3. (C) 改革與保守之爭
    4. (D) 專業與非專業之爭

  6. 6古林伍德（Greenwood, 1957）認為所有專業共享的特質，下列敘述何者正確？

    2. (B) 理論體系、專業權威、社區倡議、倫理守則、專業文化
    3. (C) 理論體系、專業文化、社區認可、倫理法規、主流專業
    4. (D) 理論體系、專業權威、社區倡議、倫理法規、主流專業

  7. 7依據現行的「社會工作師倫理守則」，當社會工作師面對不公平或不符合倫理規範之要求時，可向下列何者提出申訴？

  10. 10關於美國社會工作倫理守則中提及的使命，下列敘述何者錯誤？

  39. 39政府機關（構）及公營事業機構自行或委託辦理諮詢性電話服務工作，電話值機人數在 10 人以上者，應進用視障者達電話值機人數的比例，下列何者正確？

    1. (A) 1/10 以上
    2. (B) 1/15 以上
    3. (C) 1/20 以上
    4. (D) 1/25 以上

    正解：(A)

  40. 40依據「兒童及少年福利與權益保障法」，兒童因不當對待或未受適當照顧而有緊急安置必要時，除例外情形聲請法院裁定外，緊急安置至多不得超過幾小時？

    2. (B) 48 小時
    3. (C) 72 小時
    4. (D) 96 小時

  41. 41關於社會團體工作的敘述，不包括下列何者？

    3. (C) 目的取向
    4. (D) 一套工作方法

    正解：(A)

  42. 42關於家庭的功能，下列敘述何者錯誤？

    3. (C) 維繫社會穩定的次級團體
    4. (D) 養育、照顧與保護家庭成員

  44. 44OCD 是下列何種精神疾病的縮寫？

  45. 45精神醫療社會工作者必須具備社會心理評估的能力，下列敘述何者錯誤？

    1. (A) 評估是一個持續、動態的過程
    2. (B) 評估除了了解病人的負向部分外，還要評量案主的優勢與資源
    3. (C) 評估主要是了解病人有那些疾病、症狀及失功能的地方
    4. (D) 除了病人以外也可以邀請病人生活中的重要他人來進行評估

    正解：(C)

  46. 46在精神醫療社會工作的各種模式中，下列何者是社會模式（social model）所關注或強調的重點？

    1. (A) 關注疾病症狀的處理與治癒
    2. (B) 關注權力、壓迫和社會排除的議題
    3. (C) 認為基因、腦病變是主要病因而強調藥物治療
    4. (D) 強調明確的診斷以便讓病人了解疾病並願意接受治療

    正解：(B)

  47. 47下列何者不是輔導諮商中心的專業輔導人員？

    4. (D) 職能治療師

  48. 48依據美國社會工作教育委員會提出「災難管理與社會工作」課程中，下列何者不是社會工作者在災難救援工作的任務？

    1. (A) 投入災害現場搶救生命
    2. (B) 在災難與創傷事件發生前、救援中、復原後，將人們的文化多樣性與弱勢人口群的需求納入考量
    3. (C) 以知識與技巧來回應災難與創傷事件，以降低居民的創傷
    4. (D) 經由協調計畫、訓練以及其他行動，在災難發生前增強社區回應災難的效能

    正解：(A)

  49. 49若從施賑者（almoners）在醫院開始做救濟貧病的工作來論，健康照護社會工作源起於下列何時何地？

  50. 50關於「出院計畫」的敘述，下列何者正確？①是一個以病人為中心的跨專業團隊服務 ②社會工作者在協調社會資源轉介及運用，以促其順利執行照顧計畫 ③必要時，社會工作者亦可提供臨床照護指導④出院準備不只考慮病人，同時也須顧及家屬
