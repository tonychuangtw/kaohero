警察特考　111 年 三等考試 犯罪偵查　考古題與詳解

本卷共 50 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（50 題，建議 60 分鐘）

  1. 1下列對於毒品及裁罰的規定，何者錯誤？

    1. (A) PMMA 是 3 級毒品
    2. (B) 喵喵（4-甲基甲基卡西酮）是 3 級毒品
    3. (C) 查獲笑氣（一氧化二氮），可依毒性及關注化學物質管理法由環保單位裁罰
    4. (D) 犯製造毒品罪而混合 2 種以上之毒品者，適用其中最高級別毒品之法定刑，並加重其刑至 2 分之 1

    正解：(A)

  2. 2臺北市警察局刑事警察大隊為偵辦跨國性毒品犯罪，而實施「控制下交付」之偵查作為，應由下列何者核可後，核發偵查指揮書，方可進行？

    1. (A) 最高檢察署檢察總長
    2. (B) 臺灣臺北地方檢察署檢察長
    3. (C) 國安局局長
    4. (D) 警政署署長

    正解：(A)

  3. 3警察機關處理家庭暴力案件，下列何者正確？

    1. (A) 受理報案後，應於 48 小時內至警政婦幼案件管理系統通報
    2. (B) 同志關係暴力者，應填寫「臺灣親密關係暴力危險評估表」
    3. (C) 應由分局偵查隊協助被害人聲請保護令
    4. (D) 發現家庭暴力罪之現行犯時，應就其危險情狀判斷，不論被害人是否提出告訴，應逕行逮捕之

    正解：(D)

  4. 4性侵害犯罪防治法第 23 條規定，觸犯刑法第 224 條強制猥褻罪之加害人，其向警察機關登記、報到期間為何？

    1. (A) 10 年
    2. (B) 7年
    3. (C) 5年
    4. (D) 3年

    正解：(C)

  5. 5依「兒童及少年性剝削防制條例」第 2 條規定，下列何者不屬於「兒童或少年性剝削行為」？

    1. (A) 使兒童或少年為有對價之性交行為
    2. (B) 對兒童為猥褻之行為，但不供人觀賞
    3. (C) 拍攝、製造少年為性交行為之影片
    4. (D) 使兒童或少年坐檯陪酒行為

    正解：(B)

  6. 6有關跟蹤騷擾防制法之敘述，下列何者正確？

    1. (A) 中央主管機關為衛生福利部
    2. (B) 曾有親密關係之未同居伴侶間之跟蹤騷擾行為，適用本法關於保護令之規定
    3. (C) 跟蹤騷擾行為之犯罪嫌疑者，經警察機關書面告誡後 3 年內，再為跟蹤騷擾行為者，被害人得向法院聲請保護令
    4. (D) 攜帶凶器或其他危險物品而實施跟騷行為者嫌疑重大，有事實足認為有反覆實行之虞，而有羈押必要者，法官可實施預防性羈押

    正解：(D)

  7. 7依據刑事鑑識手冊規定，下列何項之鑑定，不屬於化學鑑識工作項目？

    1. (A) 人體血液內酒精濃度
    2. (B) 油漆
    3. (C) 纖維
    4. (D) 玻璃

    正解：(A)

  8. 8警察機關依據去氧核醣核酸採樣條例規定執行採樣時，下列敘述何者正確？

    1. (A) 刑法第 278 條之重傷害罪之犯罪嫌疑人屬於強制採樣之對象
    2. (B) 所採樣之去氧核醣核酸紀錄，應保管 10 年
    3. (C) 法醫研究所為被指定之專責單位
    4. (D) 受強制採樣人自行到場者，可以不必製作通知書並當場交付之

    正解：(A)

  9. 9警察機關執行搜索、扣押時，下列何者錯誤？

    1. (A) 應將搜索票正本交被搜索人留存
    2. (B) 於核發搜索票後因故未能執行者，應以函文敘明未能執行之事由，並將搜索票繳還核發之法院
    3. (C) 執行逕行搜索後，應於執行後 3 日內，將搜索扣押筆錄影本，以密件封緘並於信封上註明「逕行搜索」，同時分別函報該管檢察署檢察官及法院
    4. (D) 執行同意搜索案件，執行搜索人員應於執行後，對受搜索人製作筆錄

    正解：(A)

  10. 10居住在高雄市左營區（左營警察分局轄內）之甲男攜獵槍，邀約居住於新興區之乙男（新興警察分局轄內），開車赴屏東縣恆春鎮（恆春警察分局轄內）狩獵梅花鹿，二人在恆春鎮墾丁國家公園園區（保七總隊第八大隊轄區）狩獵時發生爭執，甲開槍將乙槍擊死亡，並將屍體丟棄於園區樹林中，為遊客發現向國家公園警察隊報案，則本殺人案之管轄責任應為：

    1. (A) 保七總隊第八大隊
    2. (B) 恆春警察分局
    3. (C) 新興警察分局
    4. (D) 左營警察分局

    正解：(B)

  11. 11警察人員對使用於網路犯罪之電腦執行搜索時，下列何者正確？

    1. (A) 應讓受搜索人使用電腦協助密碼輸入及搜尋檔案、下載
    2. (B) 搜索對象如為學校，應會同警察局少年警察隊員警執行之
    3. (C) 電腦檔案之證據應返回警察機關後列印，再請受搜索人簽名捺指印
    4. (D) 勿安裝或拷貝任何程式、檔案至受搜索人的電腦中

    正解：(D)

  12. 12依法拘提或逮捕之犯罪嫌疑人經令其出示相關身分證明文件，仍無法查驗身分，或無法出示相關證明文件，下列對其身分驗證作為何者錯誤？

    1. (A) 得命其立即設法通知其親友補送
    2. (B) 採取指紋，循個人身分識別系統（PID）查驗
    3. (C) 通知被害人、證人、或其他共犯指認
    4. (D) 請鑑識人員採取其 DNA 比對

    正解：(D)

  13. 13下列有關通訊保障及監察法的敘述，何者錯誤？

    1. (A) 執行機關應於執行監聽期間內，每 15 日至少作成 1 次以上之報告書，向檢察官及核發通訊監察書之法官說明監聽行為之進行情形
    2. (B) 執行機關除有正當理由者外，應至少每 10 日派員取回監錄內容
    3. (C) 司法警察官為偵辦詐欺案件而有需要時，得向檢察官聲請同意後，調取通信紀錄
    4. (D) 通訊監察監錄內容顯然與監察目的無關者，不得作成譯文

    正解：(B)

  14. 14依據警察偵查犯罪手冊規定，下述何項案件發生後，除立即偵破外，應訂定偵查計畫，以為偵查之準據，何者正確？

    2. (B) 損失 2 千元之機車搶奪案
    3. (C) 損失 20 萬元之電信詐欺案
    4. (D) 知名女星被跟蹤騷擾案

    正解：(B)

  15. 15有關爆裂物處理，下列何者正確？

    1. (A) 爆炸案件現場之指揮官為刑事警察局地區防爆隊隊長
    2. (B) 土製爆裂物、信號彈等證物應送刑事警察局鑑識科鑑定
    3. (C) 制式砲彈應先檢附證物照片函報刑事警察局，排定日期再送驗
    4. (D) 雷管若已與炸藥結合者，勿分離送鑑，以保持證物完整性

    正解：(C)

  16. 16有關警察執行通訊監察相關事項，下列何者正確？

    1. (A) 各警察機關於調取通信紀錄後，經法院核發調取票調取通信紀錄者，應將執行結果陳報許可之檢察官，並將調取票送繳檢察官
    2. (B) 辦理通訊監察聲請案件得先由業務單位主管代為決行後再補陳核閱，或逕予二層決行
    3. (C) 各警察機關之資訊單位應於每月五日前，將前一個月之調取統計數據，製作統計表並簽陳主官核閱，再將資料函送刑事警察局
    4. (D) 辦理調取通信紀錄時，承辦人應將調取票掃描圖檔後上傳通信紀錄調取管理系統，由主官或主管或授權審核人員於線上核准後，傳送電信業者辦理調取

    正解：(D)

  17. 17臺北市政府警察局大安分局針對轄內未破之重大刑案，所成立之專案小組，由下列何者負責統一指揮督導偵查工作？

    2. (B) 大安分局偵查隊隊長
    3. (C) 警察局局長
    4. (D) 刑警大隊大隊長

  18. 18警察機關受理民眾報案時，下列何者之被害人，應依據「刑案處理作業程序」實施慰問？

    1. (A) 被強盜價值 1 萬元手錶乙只案
    2. (B) 於市場遭扒手竊盜，失物總值 10 萬元案
    3. (C) 強制性交案
    4. (D) 妨害名譽案

  19. 19警察受理強盜殺人案件致被害人死亡案件，被害人家屬報案時，依據「警察機關關懷協助被害人實施計畫」有關被害人家屬關懷事宜，下列何者正確？

    1. (A) 應由派出所成立專責小組，擔任聯繫主責窗口
    2. (B) 被害人家屬逕至偵查隊報案時，應由隊長進行初步關懷慰問
    3. (C) 被害人家屬至派出所報案時，由值班員警進行初步關懷慰問
    4. (D) 警察局之犯罪被害關懷協助業務由刑事警察大隊辦理

    正解：(B)

  20. 20有關警察機關執行通訊保障及監察法相關敘述，下列何者正確？

    1. (A) 刑事警察局通訊監察科負責受理各級法院及檢察署對民營行動及固網電信之通訊監察投單作業
    2. (B) 對於私運管制物品案件而實施通訊監察期間，每次不得逾 3 月
    3. (C) 使用一張通訊監察書即可對同一案件之不同監察對象實施監察
    4. (D) 各單位派駐通訊監察科執行現譯快報人員，應集中於現譯室作業，不得擅入監察系統機房

    正解：(D)

  21. 21有關偵查隊與派出所偵辦案件之分工聯繫事項，下列敘述何者正確？

    1. (A) 派出所查獲現行犯案件，應立即通報勤務指揮中心，由勤務指揮中心視案情，決定是否指派刑事人員前往協助
    2. (B) 派出所逮捕到犯罪事證明確之普通竊盜嫌疑犯 1 名，應陳報偵查隊主辦
    3. (C) 分駐所或派出所員警偵辦案件之陳報案卷資料，應依序彙整 2 份，送偵查隊辦理移送作業
    4. (D) 派出所案件承辦員警應隨案至偵查隊為原則，以利偵查隊後續作業

    正解：(D)

  22. 22有關案情研判之敘述，下列何者錯誤？

    1. (A) 對於命案究明其為自殺、他殺或意外死亡為犯罪動機之研判
    2. (B) 從現場情況及犯罪所生損害情形，可判定犯罪嫌疑人之人數
    3. (C) 犯罪嫌疑人犯罪過程、進出路線之究明是屬於犯罪方法之研判
    4. (D) 常可從犯罪嫌疑人所使用之工具，判定其職業身分

    正解：(A)

  23. 23證人保護法之相關敘述，下列何者正確？

    1. (A) 依證人保護法保護之證人，只要在警詢階段到場作證，在檢察官偵查中或法院審理中，可以不必到場作證
    2. (B) 警察機關於調查刑事案件時，如認證人有受保護之必要時，得先採取必要之保護措施，並於 10 日內將其陳報檢察官或法院
    3. (C) 禁止或限定特定人接近證人之身體或住居所，應由法院或檢察官核發證人保護書禁止或限定之
    4. (D) 保護、安置證人之短期生活安置經費，應由法務部編列預算支應

    正解：(C)

  24. 24有關當舖業法相關事項，下列何者正確？

    1. (A) 所謂流當物，指滿當日屆滿後，仍未取贖或順延質當之質當物
    2. (B) 當舖業收當物品時，應查驗身分，並由持當人於當票副聯內捺印任一指之指紋，始可收當
    3. (C) 當舖收取質當物之利息，年利率不得超過百分之二十
    4. (D) 當舖業應備登記簿，登記持當人及收當物品等資料，每二星期以影印本 2 份送主管機關備查

    正解：(D)

  25. 25有關警察機關案件移送作業，下列敘述何者正確？

    1. (A) 臺北市警察局大安分局員警，於轄區查獲在新竹縣服役之甲（戶籍地為臺中市）吸食持有安非他命案，應將其姓名及案件類型通報新竹憲兵隊
    2. (B) 警察機關在戰時查獲官階為士官之現役軍人甲，其犯刑法第 150 條妨害秩序罪，應移送地方軍事法院檢察署
    3. (C) 移送案件時，如認為嫌犯有羈押之必要，應於移送書或報告書之「犯罪事實」欄內敘明理由
    4. (D) 告訴乃論案件，經撤回告訴，或尚未調查完竣，而告訴人已向檢察官告訴者，使用函送格式移送書

    正解：(D)

  26. 26有關各警察機關對於涉外案件之處理，下列何者錯誤？

    1. (A) 處理涉及國際刑案者，得請求內政部警政署刑事警察局協助偵辦
    2. (B) 發現外交代表涉有犯罪嫌疑者，未經其使領館館長、外國機構或國際組織負責人同意，不能進入代表之私人寓所進行偵查作為
    3. (C) 發現享有外交豁免權外國大使之家屬涉有犯罪嫌疑者，應即請示檢察官，並即陳報內政部警政署轉知外交部，不得逕予詢問、搜索或逮捕
    4. (D) 如無法確定外國人是否具外交豁免權身分者，應陳報內政部警政署刑事警察局國際刑警科通報駐外代表處查證

    正解：(D)

  27. 27根據「偵查不公開作業辦法」，下列敘述何者正確？

    1. (A) 基於偵查不公開，不得公開偵查內容，但為求破案效率得任意公開犯罪嫌疑人之個人資料
    2. (B) 所謂揭露，僅限於揭示、洩漏予特定人
    3. (C) 為維護公共利益或保護合法權益，得適度公開偵查內容，且可對犯罪行為作詳盡之敘述，保障民眾「知」的權利
    4. (D) 案件偵查中，不得任媒體拍攝，包括藉由監視器畫面拍攝

    正解：(D)

  28. 28根據「警察機關偵辦刑案及處理新聞遵守偵查不公開原則注意要點」，下列何者得出現於刑案新聞之畫面或內容？

    1. (A) 與犯罪嫌疑人查證之對話
    2. (B) 搜索贓證物之畫面
    3. (C) 受檢人出示身分證件內容之畫面
    4. (D) 查獲之贓證物

    正解：(D)

  29. 29根據「警察偵查犯罪手冊」，關於犯罪案件之管轄責任區分，下列敘述何者正確？

    1. (A) 涉及帳戶匯款之詐欺案件，以帳戶開立人現住地之警察機關單位負責偵辦
    2. (B) 境外犯罪，以被害人之居住地、家屬居住地、工作地，依序之警察機關為管轄機關
    3. (C) 未涉及帳戶匯款之詐欺案件，由發生地之警察機關負責偵辦
    4. (D) 保二總隊負責各機場與港口之通關作業，取締走私不法案件

    正解：(C)

  30. 30下列何者非「警察偵查犯罪手冊」明文列舉之重點諮詢地區？

    1. (A) 醫院

    正解：(D)

  31. 31依警察偵查犯罪手冊規定，下列何者非重大刑案？

    1. (A) 偽證案件
    2. (B) 重大恐嚇取財案件
    3. (C) 故意殺人案件
    4. (D) 搶奪案件

    正解：(A)

  32. 32根據「治安顧慮人口查訪辦法」規定，下列何者為得定期實施查訪之對象？

    1. (A) 曾犯刑法第 325 條至第 327 條之搶奪罪者
    2. (B) 曾犯刑法第 195 條至第 200 條之偽造貨幣罪者
    3. (C) 曾犯刑法第 277 條至第 287 條之傷害罪者
    4. (D) 曾犯刑法第 358 條至第 363 條之妨害電腦使用罪者

    正解：(A)

  33. 33根據「警察偵查犯罪手冊」聯繫配合之規定，下列敘述何者正確？

    1. (A) 接獲非屬管轄責任之犯罪案件，得不受理
    2. (B) 即便有犯罪偵查之需求，仍不得囑託他轄警察機關代為調查證據
    3. (C) 警察機關因偵查犯罪需要，得向刑事警察局查詢犯罪資料
    4. (D) 刑事警察局支援各警察機關時，刑事警察局應負責保全現場

    正解：(C)

  34. 34根據「警察偵查犯罪手冊」規定，關於刑案紀錄資料建檔之規定，刑案紀錄表應於受理刑案發生或破獲移送之時起，多少時間內填輸？

    1. (A) 48 小時
    2. (B) 24 小時
    3. (C) 36 小時
    4. (D) 72 小時

    正解：(A)

  35. 35關於刑事鑑識現場處理，下列敘述何者正確？

    1. (A) 現場為室內時，應注意犯罪嫌疑人進入和逃離現場之路線與方法
    2. (B) 首先應實施現場勘察、案情研判、提出偵查計畫，再探查現場是否有人受傷，救護傷患
    3. (C) 封鎖範圍以四道封鎖線為原則
    4. (D) 初期封鎖之範圍宜窄不宜廣，待初步觀察後，視實際需要再行界定封鎖範圍

    正解：(A)

  36. 36依刑事鑑識關於實施勘察採證，下列敘述何者正確？

    1. (A) 由低而高：由地面開始勘察，依次是門、窗、牆壁與天花板
    2. (B) 命案現場屍體之勘察，除初步了解身分及必要之紀錄外，應於檢察官到場前完成主要工作，待檢察官到場後可直接向檢察官報告，節省檢察官處理時間
    3. (C) 對勘察所知悉之事項，除必要者外，可適度與家人分享，以減輕執法人員身心壓力
    4. (D) 從戶內現場中心往戶外輻射性逐步勘察

    正解：(A)

  37. 37刑事鑑識關於現場測繪之要領，下列敘述何者正確？

    1. (A) 測繪順序先從現場周圍開始，其次為現場，最後為重要跡證之相關位置
    2. (B) 現場分散數個地方時，應集中測繪
    3. (C) 測繪時可移動現場物品，只要註明移動後之相關位置即可
    4. (D) 現場測繪圖應註明屋主姓名、地段地號及面積等資料，缺一不可

    正解：(A)

  38. 38關於子彈、彈頭證物之處理原則，下列敘述何者正確？

    1. (A) 若有供比對用之同廠牌子彈，應準備三顆以上送驗
    2. (B) 彈頭數顆宜以證物袋統一包裝在一袋，避免遺失
    3. (C) 採取現場彈頭宜記錄其採驗後狀態
    4. (D) 採取彈頭應避免以塑膠器具直接夾取而破壞其上痕跡

    正解：(A)

  39. 39刑事鑑識關於泥土證物之處理，下列敘述何者正確？

    1. (A) 採取比對檢體宜分區採取表面下一公分內之泥土，每區各項泥土檢體至少酌採 50 公克
    2. (B) 泥土內之夾雜物宜分別採取
    3. (C) 鞋底泥土之層次，可顯示嫌犯可能到過不同地方，宜分開採集、整雙包裝
    4. (D) 採集泥土檢體時，以鑷子採取，並封妥保存，以避免污染

    正解：(A)

  40. 40根據「警察偵查犯罪手冊」規定之偵查要領，下列何者不是「人之清查」中應特別注意之對象？

    1. (A) 案件發生後，關係人或可疑人突告失蹤者
    2. (B) 對本案特別表現關懷者
    3. (C) 案件發生後，忽然態度失常者
    4. (D) 案件發生後，忽然生活困頓者

    正解：(D)

  41. 41根據「警察偵查犯罪手冊」搜索之規定，下列敘述何者正確？

    1. (A) 任何處所皆不得進行夜間搜索
    2. (B) 搜索完畢得逕行離開，無須將搜索之處所恢復原狀
    3. (C) 基於偵查不公開原則，搜索時不得有任何第三人在場
    4. (D) 搜索女性身體，應由女性行之

    正解：(D)

  42. 42關於令狀原則，下列敘述何者正確？

    1. (A) 無緊急監察需求時，司法警察機關得逕行向法院聲請通訊監察書
    2. (B) 若同時有數對象需進行監察，僅需聲請一張通訊監察書
    3. (C) 有緊急監察需求時，得經該管檢察官口頭同意通知先予執行
    4. (D) 法院受理通訊監察書之聲請後，應於 24 小時內核復

    正解：(C)

  43. 43根據「警察職權行使法」關於盤查之規定，下列敘述何者正確？

    1. (A) 一旦受檢人不配合盤查作業，即得要求其同行至警察駐地進行盤查
    2. (B) 盤查作業自攔停起，不得逾 4 小時
    3. (C) 實施營業場所臨檢時，需製作臨檢紀錄表，並請在場負責人或使用人簽章
    4. (D) 實施盤查時僅需表明身分，無須出示證件

    正解：(C)

  44. 44關於搜索與扣押，下列敘述何者正確？

    1. (A) 搜索應保守秘密，關鍵是能否發現應扣押之物，搜索人名譽並非重點
    2. (B) 經搜索而未發現應扣押之物，應擇日另行搜索，應付與搜索筆錄於受搜索人
    3. (C) 軍事上應秘密之場所，經法官核發令狀後即可搜索，不需得到該管長官允許，以避免官官相護之情況發生
    4. (D) 得命所有人交付應扣押之物，若抗拒扣押，得使用強制力扣押之

    正解：(D)

  45. 45根據「警察偵查犯罪手冊」跟蹤、監視之規定，下列何者非執行時之注意事項？

    1. (A) 應隨身攜帶簡便偽裝衣物，以便快速掩飾改裝
    2. (B) 跟監通訊器材不得顯露於外
    3. (C) 避免穿戴引人注目之特殊物件
    4. (D) 執行人員應簡要記錄有關情報

    正解：(D)

  46. 46根據「警察偵查犯罪手冊」偵查辯護之規定，下列敘述何者正確？

    1. (A) 偵查中選任辯護人應以律師為限，且每一犯罪嫌疑人選任之辯護人不得逾三人
    2. (B) 辯護人得檢閱卷宗、證物等，以便其了解案件事實，協助犯罪嫌疑人
    3. (C) 證人指認犯罪嫌疑人時，該犯罪嫌疑人之辯護人不得在場
    4. (D) 辯護人得接見犯罪嫌疑人，但不得互通書信

    正解：(A)

  47. 47安全檢查及刑事搜索皆係對人身自由與財產權之限制，但兩者有諸多不同之處，下列敘述何者正確？

    1. (A) 兩者皆以發現犯罪證物為目的
    2. (B) 受安全檢查之對象必有違法行為
    3. (C) 安全檢查不需搜索票；刑事搜索需搜索票
    4. (D) 刑事搜索之強制效果為「間接強制型」

    正解：(C)

  48. 48關於槍殺案件之偵查要領，下列敘述何者正確？

    1. (A) 被槍彈擊中後，不一定立即死亡，可能行走若干步
    2. (B) 若屍體有數個槍傷，一定為他殺
    3. (C) 在屍體之衣服及皮膚上一定能找到煙暈與火藥微粒
    4. (D) 若只射擊一槍，只會有一處射入口及射出口

    正解：(A)

  49. 49以刀具自殺，其傷口通常位一定部位且有一定方向，下列敘述何者正確？

    1. (A) 可根據頭頸上刀痕數目，正確辨別是否為自殺
    2. (B) 傷口必在上手臂可及之處
    3. (C) 若傷口遍布於身體各處，不可能為自殺
    4. (D) 可根據傷口之形狀，正確辨別是否為自殺

    正解：(B)

  50. 50關於詢問性侵害案件之被害人，下列敘述何者正確？

    1. (A) 得逕行通知被害人家屬到場陪同
    2. (B) 警察人員應勸說被害人，將案情說得較嚴重，以確保犯罪者不被輕判
    3. (C) 為獲得完整事實，宜多次詢問被害人
    4. (D) 被害者如為兒童或少年，應多使用開放性問句詢問

    正解：(D)
