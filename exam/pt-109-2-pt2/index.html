  22. 22根據性別工作平等法，有關職場性騷擾之敘述，下列何者錯誤？

    2. (B) 所稱性騷擾，指雇主對受僱者或求職者為明示或暗示之性要求、具有性意味或性別歧視之言詞或行為，作為勞務契約成立、存續、變更或分發、配置、報酬、考績、陞遷、降調、獎懲等之交換條件

    4. (D) 性騷擾之防治，雇主於知悉受僱者遭受性騷擾之情形時，應儘速報警處理

    正解：(D)

    2. (B) 定期健檢發生異狀時，除需處理治療問題之外，尚需改善工作環境
    3. (C) 員工從事的工作，應不可使本人、同事及大眾的健康受到危害
    4. (D) 健檢的項目為工作中環境暴露發生的因素

    正解：(D)

  76. 76環境暴露物之中，液體因機械作用而產生之液體懸浮物，是屬於下列何種化學物分類？

    2. (B) 燻煙
    3. (C) 霧滴
    4. (D) 蒸氣

    正解：(C)

    1. (A) 全民健康保險的永續經營

    3. (C) 社會福利的公平性
    4. (D) 衛生所功能之改造

    正解：(C)

  78. 78我國當前的特殊健康照護體系，不包含下列何項？

    1. (A) 緊急護理照護體系
    2. (B) 精神疾病照護體系
    3. (C) 長期照護體系
    4. (D) 山地離島健康照護體系
