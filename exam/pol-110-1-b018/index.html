警察特考　110 年 三等考試 中華民國憲法與水上警察專業英文　考古題與詳解

本卷共 60 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（60 題，建議 180 分鐘）

  1. 1依憲法及司法院大法官解釋，有關依政黨比例代表制選出之代表，下列敘述何者錯誤？

    1. (A) 僅限於獲得百分之五以上政黨選舉票之政黨才能分配席位
    2. (B) 依政黨比例代表制產生之代表，仍得由選民罷免
    3. (C) 依政黨比例代表制產生之代表出缺後有遞補制度
    4. (D) 僅限於立法委員選舉才有政黨比例代表

    正解：(B)

  2. 2關於考試院之職權，下列敘述何者錯誤？

    1. (A) 公務人員之任用資格，應經考試院依法考選銓定之
    2. (B) 考試院職權之行使限制人民權利者，須有法律之依據，始得為之
    3. (C) 考試院就其所掌事項之法律案，有對立法院提案之權
    4. (D) 考試院對立法院通過之法律案，得經總統核可，移請立法院覆議

    正解：(D)

  3. 3依司法院大法官解釋之意旨，關於立法院文件調閱權，下列敘述何者錯誤？

    1. (A) 立法院使用調閱權所取得之資訊，於使用時應注意維護關係人之名譽隱私及營業秘密
    2. (B) 立法院不得調閱檢察機關偵查中之案件卷證
    3. (C) 立法院得調閱已偵查終結之所有案件之卷證
    4. (D) 立法院得立法對拒絕配合文件調閱者科處罰鍰

    正解：(C)

  4. 4下列何者非屬立法委員得主動提出之議案？

    1. (A) 預算案
    2. (B) 法律案
    3. (C) 憲法修正案
    4. (D) 總統罷免案

    正解：(A)

  5. 5關於總統特權，下列敘述何者正確？

    3. (C) 總統享有之國家機密特權，包括所有國家內政事項
    4. (D) 總統依其國家機密特權，就國家機密事項於刑事訴訟程序應享有拒絕證言權

  12. 12關於總統、副總統之缺位與繼任，下列敘述何者錯誤？

  16. 16依司法院大法官解釋，關於立法委員之質詢及政府人員之備詢，下列敘述何者錯誤？
