營養師　103 年第二次 營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何種糖的甜度最高？

    1. (A) 果糖
    2. (B) 葡萄糖
    3. (C) 蔗糖
    4. (D) 木醣醇

    正解：(A)

  2. 2下列何種情況的兒童最不可能是蛋白質攝取不足的高危險群？

    1. (A) 對於多種食物過敏的兒童
    2. (B) 吃純素的兒童
    3. (C) 食物取得有困難，例如弱勢家庭的兒童
    4. (D) 活潑好動的兒童

    正解：(D)

  3. 3下列有關攝取過多膳食纖維的敘述，何者錯誤？

    1. (A) 每天攝食的膳食纖維超過 50～60 克就有可能危害健康
    2. (B) 由於膳食纖維具有吸附水分和促進腸胃蠕動的特性，所以攝食過多也不會發生便秘
    3. (C) 會增加痔瘡發生機會
    4. (D) 會增加鐵、鈣等礦物質流失

    正解：(B)

  4. 4下列何種纖維，其主要生理功能與降低血液膽固醇的關連性較低？

    1. (A) pectins
    2. (B) cellulose
    3. (C) chitin
    4. (D) β -glucans

    正解：(B)

  5. 5關於寡糖（oligosaccharide）的敘述，下列何者錯誤？

    1. (A) 為 3～10 個單醣單位所組成之分子
    2. (B) 具水溶性
    3. (C) 具甜味
    4. (D) 可被人體消化酵素分解

    正解：(D)

  6. 6下列有關蛋白質功能的敘述，何者錯誤？製造核酸的主要碳源 維持體液的平衡 負責細胞生長及修復 幫助血液的凝固頁次：4－2

    正解：(A)

  7. 7下列何種食物可以提供人體需要的所有必需胺基酸？

    1. (A) 小麥
    2. (B) 大豆
    3. (C) 玉米
    4. (D) 牛奶

    正解：(D)

  8. 8下列何種方法無法造成蛋白質變性？

    1. (A) 加熱
    2. (B) 加酸
    3. (C) 加蛋白酶
    4. (D) 加水

    正解：(D)

  9. 9有關反式脂肪的敘述，下列何者錯誤？

    1. (A) 天然食物中的脂肪酸雙鍵大部分為順式（cis）雙鍵
    2. (B) 食用植物油進行氫化後，會增加反式之雙鍵結構，增加飽和度，減少油脂的酸敗機率
    3. (C) 反式脂肪大部分來自加工食品，天然食物中不含反式脂肪
    4. (D) 攝食過多的反式脂肪，可能會抑制必需脂肪酸的去飽和（desaturation）及鏈加長（elongation）反應

    正解：(C)

  10. 10下列何種食物的膽固醇最多？

    1. (A) 100 克鮪魚肉
    2. (B) 100 克豬瘦肉
    3. (C) 1 顆雞蛋（60 克）
    4. (D) 100 克豬肝

    正解：(D)

  11. 11下列有關高密度脂蛋白（HDL）的敘述，何者錯誤？

    1. (A) 血液中的 HDL，大部分是由肝臟和小腸製造
    2. (B) 四種脂蛋白中，HDL 的蛋白質比例最低，體積最小
    3. (C) HDL 膽固醇濃度高低和罹患心血管疾病的風險呈負相關
    4. (D) 負責將周邊組織的膽固醇回收，運送回肝臟

    正解：(B)

  12. 12下列有關膽酸（bile acid）的敘述，何者最正確？

    1. (A) 在膽囊中，由膽固醇轉化而成
    2. (B) 分泌至十二指腸後，可經由腸肝循環（enterohepatic circulation）回到肝臟
    3. (C) 腸道再吸收的膽酸，經由淋巴系統送回肝臟
    4. (D) 增加腸道膽酸的再吸收，將有助於減少血膽固醇濃度

    正解：(B)

  13. 13下列敘述何者錯誤？

    1. (A) 腰臀比與心血管疾病的發生率具相關性
    2. (B) 老年人的腰圍與體內胰島素的敏感性密切相關
    3. (C) 可利用 Deurenberg 公式預估體脂肪含量
    4. (D) 女性腰臀比大於 0.5 會增加罹患心血管疾病的機率

    正解：(D)

  14. 14有關瘦素（leptin）的敘述，下列何者錯誤？瘦素是白色脂肪組織所分泌重度肥胖者體內有高濃度的瘦素瘦素與位於中樞神經的受體結合後，刺激α -MSH（α -melanocyte-stimulating hormone）的釋放而抑制食慾飢餓狀態時瘦素濃度會上升

    正解：(D)

  15. 15當飲食中醣類攝取不足時，胺基酸會經由異化作用產生下列何種物質？

    1. (A) 乙醇
    2. (B) 酮體
    3. (C) 膽鹼
    4. (D) 草醋酸

    正解：(B)

  16. 16下列何種荷爾蒙（hormone）會促進食慾？

    1. (A) leptin
    2. (B) cholecystokinin（CCK）
    3. (C) ghrelin
    4. (D) peptide YY（PYY）

    正解：(C)

  17. 17關於四氫葉酸（tetrahydrofolate）於細胞內之生化代謝功能，下列敘述何者正確？接受及轉移胺基（NH2）與 CO2 結合形成尿素接受及轉移氫質子還原呼吸電子傳遞鍊酵素複合體以利 ATP 生成接受及轉移單碳以利胺基酸生合成接受及轉移酮基以利葡萄糖生合成頁次：4－3

    正解：(C)

  18. 18維生素 B2 在食物中除了以游離態的型式存在外，主要是以下列何種輔酶的型式存在？

    1. (A) 核黃素單核苷酸（FMN）及硫胺雙磷酸（TDP）
    2. (B) 核黃素單核苷酸（FMN）及核黃素腺嘌呤雙核苷酸（FAD）
    3. (C) 核黃素腺嘌呤雙核苷酸（FAD）及黃素蛋白（flavoproteins）
    4. (D) 核黃素腺嘌呤雙核苷酸（FAD）及核黃素激酶（flavokinase）

    正解：(B)

  19. 19晉小姐近日發現皮膚出現紅狀斑點、牙齦出血及小腿肌肉疼痛，可能與下列何種營養素缺乏有關？

    1. (A) 維生素 A
    2. (B) 維生素 E
    3. (C) 維生素 D
    4. (D) 維生素 C

    正解：(D)

  20. 20協助犬尿胺酸單加氧酶（kynurenine monooxygenase）將色胺酸轉換成菸鹼素的過程中，需要下列何種維生素擔任輔酶？硫胺 核黃素 磷酸比哆醛 維生素 C

    正解：(B)

  21. 21有關胡蘿蔔素的敘述，下列何者錯誤？

    1. (A) 胡蘿蔔素是維生素 A 的先質
    2. (B) 動植物均可合成胡蘿蔔素
    3. (C) 胡蘿蔔素的利用率受到脂質存在的影響
    4. (D) 胡蘿蔔素主要儲存在皮下脂肪

    正解：(B)

  22. 22下列何者是在視網膜中與視紫蛋白結合而產生視覺的維生素 A 衍生物？

    1. (A) 11-cis-retinal
    2. (B) 11-trans-retinol
    3. (C) 11-cis-retinol
    4. (D) 11-trans-retinal

    正解：(A)

  23. 23關於維生素 D 的單位換算，下列敘述何者正確？

    1. (A) 1 microgram＝400 international unit（IU）
    2. (B) 1 microgram＝40 international unit（IU）
    3. (C) 1 international unit（IU）＝400 microgram
    4. (D) 1 international unit（IU）＝40 microgram

    正解：(B)

  24. 24缺乏維生素 E 可能經由下列何種生化作用產生臨床症狀？

    1. (A) 促進軟組織鈣化作用，造成血栓
    2. (B) 抗凝血機制，造成出血性貧血
    3. (C) 增加氧化壓力，造成溶血性貧血
    4. (D) 抑制紅血球分化作用，造成巨球性貧血

    正解：(C)

  25. 25流行病學指出，食用黃豆製品可以預防骨質疏鬆症，下列何者是其可能的機制？

    1. (A) 抑制骨鈣質分解
    2. (B) 促進鈣質吸收
    3. (C) 含有類似雌激素的植物成分
    4. (D) 穩定腎臟對鈣質的吸收

    正解：(C)

  26. 26下列何種營養素組合會促進鈣質的吸收？

    1. (A) 葡萄糖＋脂質
    2. (B) 維生素 E＋維生素 C
    3. (C) 脂質＋維生素 A
    4. (D) 適量蛋白質＋維生素 D

    正解：(D)

  27. 27有關鉀的敘述，下列何者正確？

    1. (A) 促進胃酸分泌
    2. (B) 為細胞內液主要的電解質
    3. (C) 參與血液凝固
    4. (D) 協助鈣質的吸收

    正解：(B)

  28. 28有關鐵的敘述，下列何者正確？

    1. (A) albumin 是在血液中協助鐵運送的蛋白質
    2. (B) hemochromatosis 是指因鐵無法被吸收及運送所導致的疾病
    3. (C) ferritin 協助將鐵從脾臟運送到骨髓
    4. (D) transferrin 在血液中協助鐵運送到骨髓

    正解：(D)

  29. 29女性更年期後，由於下列何種荷爾蒙減少而容易發生 osteoporosis？

    1. (A) Insulin
    2. (B) Leptin
    3. (C) Testosterone
    4. (D) Estrogen

    正解：(D)

  30. 30Glucosamine 是老人常用的保健食品，它的主要保健功效為何？促進造骨作用 改善鈣及磷之間的平衡 緩和關節炎的疼痛 降低骨鈣質的流失頁次：4－4

    正解：(C)

  31. 31依據行政院衛生署（現為衛生福利部）2011 年修訂最新版「國人膳食營養素參考建議攝取量」，1 歲以下嬰兒的動物性蛋白攝取量在總蛋白質的比例，應占多少？1/2 1/3 2/3 1/4

    正解：(C)

  32. 32同重量的早產兒及一般標準的嬰兒配方奶粉的比較，下列敘述何者正確？

    1. (A) 早產兒配方奶粉提供的能量較多
    2. (B) 早產兒配方奶粉提供的蛋白質較少
    3. (C) 兩種配方奶粉提供的鈣質一樣多
    4. (D) 兩種配方奶粉提供的脂肪皆以植物油脂及中鏈油脂為主

    正解：(A)

  33. 33有關楓漿尿症（maple syrup urine disease）的新生兒，下列敘述何者錯誤？

    1. (A) 屬於衛生福利部國民健康署目前所提供補助之新生兒篩檢項目
    2. (B) 因體液和尿液會有楓樹糖漿的甜味因而命名
    3. (C) 屬於芳香族胺基酸代謝異常的罕見疾病
    4. (D) 配方奶粉應補充纈胺酸、白胺酸及異白胺酸

    正解：(C)

  34. 34花青素（anthocyanidins）為水溶性之天然色素，而前花青素（proanthocyanidins）之特色為何？

    1. (A) 無色，但於酸性下加以熱處理可以轉化為紅色
    2. (B) 前花青素遇到胃酸即可被轉化為花青素
    3. (C) 前花青素遇到膽汁即可被轉化為花青素
    4. (D) 前花青素為油溶性

    正解：(A)

  35. 35關於 sports anemia 的敘述，下列何者正確？

    1. (A) 並非真正的「iron-deficient」anemia
    2. (B) 必需長時間、給與高劑量鐵的治療
    3. (C) 主要是因高溫下大量流汗導致鐵的流失所造成的
    4. (D) 各類型的運動選手都會發生

    正解：(A)

  36. 36關於運動時，肌肉中肝醣的角色，下列敘述何者正確？

    1. (A) 是肌肉細胞之主要能量來源
    2. (B) 會釋放至血液中，作為腦細胞能量之來源
    3. (C) 會釋放至血液中，作為合成肝臟中肝醣的原料
    4. (D) 作為當進行高強度運動時，維持正常心臟及肺臟功能所需之能量來源

    正解：(A)

  37. 37植物固醇存在於植物性蔬果中，已被發現具有調降血膽固醇之功效，最主要可能原因為：

    1. (A) 植物固醇與膽固醇具有競爭性，可以減少膽固醇之吸收
    2. (B) 植物固醇可以抑制膽固醇之生合成
    3. (C) 植物固醇可以促進膽固醇之排泄
    4. (D) 植物固醇可以促進膽固醇之消化

    正解：(A)

  38. 38運動過程中，下列何種荷爾蒙主要作用在脂肪細胞並促使分解成為脂肪酸以作為能量之來源？

    1. (A) epinephrine
    2. (B) glucagon
    3. (C) leptin
    4. (D) neuropeptide-Y

    正解：(A)

  39. 39關於運動時脂質所扮演的角色，下列敘述何者最為正確？

    1. (A) 最接近肌肉的體脂肪層會先被氧化，當作能量的來源
    2. (B) 脂質是長時間進行中強度運動時最主要的能量來源
    3. (C) 隨著運動強度的增加，脂質氧化作為能量的比率也隨之增加
    4. (D) 脂質氧化的量，於進行高強度短時間運動比低強度長時間運動時來得多

    正解：(B)

  40. 40下列有關基礎代謝率（basal metabolic rate）的敘述，何者錯誤？

    1. (A) 休息狀態下維持生命所需的基本能量
    2. (B) 男性的基礎代謝率高於女性
    3. (C) 飢餓狀態下的基礎代謝率會增加
    4. (D) 懷孕期間的基礎代謝率會增加

    正解：(C)
