地方特考　114 年 三等 經濟學與財政學概論　考古題與詳解

  1. 1假設你今天的收入為 2,000 元，且銀行的年利率為 15%。若以今日消費金額為橫軸，一年後的消費金額為縱軸，你的預算線的斜率為：

    1. (A) -0.15
    2. (B) -0.85
    3. (C) -1
    4. (D) -1.15

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 跨期預算線的斜率為負的一加利率，即 −(1 ＋ 0.15) = −1.15。

    ❌ (A) −0.15 僅為利率。

    ❌ (B) −0.85 與公式不符。

    ❌ (C) −1 對應利率為零的情形。

    📚 出處：經濟學－跨期預算限制。

  2. 2假設小丁由休閒（leisure; L）及消費（consumption; C）所得到的滿足程度為 U(C, L)=C α L1-α ，其中 0 < α < 1。另外，小丁每週可用於休閒及工作的時間總數為 100 小時，且面對每小時 W 元的工資。以工資為縱軸，勞動小時數為橫軸，則追求滿足程度最大的小丁的勞動供給曲線為：

    1. (A) 正斜率的曲線
    2. (B) 負斜率的曲線
    3. (C) 先為正斜率，後為負斜率的曲線
    4. (D) 垂直線

    正解：(D)

    逐題詳解（免費試讀）

    ✅ (D) 柯布道格拉斯效用下休閒需求為總時間乘以固定比例，與工資無關，勞動供給恆為 100α 小時，故供給曲線為垂直線。

    ❌ (A) 所得效果與替代效果恰好相抵，不呈正斜率。

    ❌ (B) 亦非負斜率。

    ❌ (C) 不會出現後彎的形狀。

    📚 出處：經濟學－勞動供給與所得替代效果。

  3. 3小丁把他的所得全部花在購買 A 物品及 B 物品，且 B 物品的價格是 A 物品價格的 4 倍。假設小丁追求效用最大，則小丁對兩種物品的最適購買量會符合下列何種條件？

    1. (A) B 物品的最適購買量為 A 物品最適購買量的 4 倍
    2. (B) A 物品的最適購買量為 B 物品最適購買量的 4 倍
    3. (C) B 物品的邊際效用是 A 物品邊際效用的 4 倍
    4. (D) A 物品的邊際效用是 B 物品邊際效用的 4 倍

    正解：(C)

    逐題詳解（免費試讀）

    ✅ (C) 效用極大的條件為兩物品的邊際效用比等於價格比，故 B 的邊際效用為 A 的四倍。

    ❌ (A) 購買量的比例由偏好決定，非必為四倍。

    ❌ (B) 同樣無法由價格比直接推得數量比。

    ❌ (D) 邊際效用的比例方向相反。

    📚 出處：經濟學－消費者均衡條件。

  4. 4考慮一個兩人賽局，參賽者 1 可以選取 U，C 及 D，而參賽者 2 可以選取 L，M 及 R。參賽者 1 及 2 所對應的報酬如下表，以下賽局中，有幾個純粹策略的奈許均衡解（pure-strategyNash equilibrium）？L M RU 1, 1 5, 0 0, 01 C 0, 5 4, 4 0, 0D 0, 0 0, 0 3, 3
