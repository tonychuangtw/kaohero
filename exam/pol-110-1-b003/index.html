警察特考　110 年 三等考試 行政學　考古題與詳解

本卷共 25 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（25 題，建議 75 分鐘）

  1. 1主張政府施政將市場機制導入政府運作，將民眾視為購買產品的顧客，講究流程改造、企業化經營，政府盡可能將產出效率不高的服務或公共財交由私人營運。下列何者最符合此一治理模式的描述？

    1. (A) 傳統公共行政
    2. (B) 新公共管理
    3. (C) 新公共行政
    4. (D) 新公共治理

    正解：(B)

  2. 2下列何者非屬彼得斯（B. Guy Peters）所提出的四種政府未來治理模式？

    1. (A) 市場式政府
    2. (B) 參與式政府
    3. (C) 解制式政府
    4. (D) 大有為政府

    正解：(D)

  3. 3關於「行為科學」理論各項學說的共同特點，下列敘述何者錯誤？

    1. (A) 出現於傳統的官僚模型理論之後
    2. (B) 多數工作激勵理論被歸類為行為科學理論
    3. (C) 提出組織績效深受組織外部環境影響的觀點
    4. (D) 重視組織運作過程中員工的心理社會因素

    正解：(C)

  4. 4有些因素若在組織決策中所占比重越大，組織設計上就越可能偏向高層決策，下列敘述何者錯誤？

    1. (A) 決策對組織的未來（futurity）影響越大
    2. (B) 決策的可逆轉性（reversibility）越大
    3. (C) 決策對組織內其他功能運作的影響性（impact）越大
    4. (D) 事件的稀有性（rarity）越高

    正解：(B)

  5. 5有關公務人員是否可以兼職，在我國那一個法規中有清楚明確的規範？

    1. (A) 公務員服務法
    2. (B) 公務人員行政中立法
    3. (C) 公務員廉政倫理規範
    4. (D) 公職人員利益衝突迴避法

    正解：(A)

  6. 6下列何者違反公務人員行政中立法之規定？

    1. (A) 公務人員主持宗教團體舉辦的遊行活動
    2. (B) 公務人員請休假參選市議員
    3. (C) 公務人員為市議員候選人募款
    4. (D) 公務人員請休假為參加市議員選舉之配偶主持競選活動

    正解：(D)

  7. 7當政府不再嘗試自己去做每件事情，而是透過契約提供資金給其他組織（包括非營利組織、私部門等）來完成政府想要完成的工作，此一治理模式最接近下列那一種組織形式？

    1. (A) 科層組織
    2. (B) 事業型組織
    3. (C) 功能型組織
    4. (D) 網絡式組織

    正解：(D)

  8. 8下列何者是於危機發生之後，危機溝通主要進行的工作？

    1. (A) 在最短的時間內，傳送必要的資訊給各利害關係人
    2. (B) 針對組織可能的危機狀況進行研究與資訊蒐集的工作
    3. (C) 制訂危機管理計畫，決定危機管理的工作分配
    4. (D) 蒐集並組織相關的資訊，提供給危機管理團隊進行決策

    正解：(A)

  9. 9下列何者是屬於輔助（幕僚）部門？

    1. (A) 交通部路政司
    2. (B) 內政部戶政司
    3. (C) 經濟部總務司
    4. (D) 僑務委員會僑教處

    正解：(C)

  10. 10下列何者屬於信念層次的組織文化？

    1. (A) 組織的理念
    2. (B) 組織的結構
    3. (C) 組織的溝通
    4. (D) 組織的風險

    正解：(A)

  11. 11人力資源管理所欲達成的主要目標中，下列何者錯誤？

    1. (A) 找到對的人
    2. (B) 提升組織績效
    3. (C) 個人資訊公開化
    4. (D) 維持有效的勞動力

    正解：(C)

  12. 12有關人事分類制度的比較，下列何者最為正確？

    1. (A) 職位分類制較易產生人與事不相稱的現象
    2. (B) 品位分類制以資格地位的高低為分類基礎
    3. (C) 職位分類制較簡單易操作並富有彈性
    4. (D) 品位分類制的薪資係依據工作內容而定

    正解：(B)

  13. 13我國主計機關之核心業務不包括下列何者？

    1. (A) 會計
    2. (B) 審計
    3. (C) 歲計
    4. (D) 統計

    正解：(B)

  14. 14某個國家經濟狀況長期都很穩定，失業率非常低，民間消費與景氣亦是蓬勃，但政府的財政狀況總是入不敷出，此國政府最可能面臨下列何種類型的財政赤字？

    1. (A) 貿易赤字
    2. (B) 資本赤字
    3. (C) 循環性赤字
    4. (D) 結構性赤字

    正解：(D)

  15. 15按我國預算法之規定，為因應緊急情勢，在未經立法院審議完成之前，便可先行支付部分經費的是那一種預算？

    1. (A) 年度總預算
    2. (B) 分配預算
    3. (C) 追加預算
    4. (D) 特別預算

    正解：(D)

  16. 16公部門實施目標管理在衡量績效時，容易產生許多缺失，下列何者最不相關？

    1. (A) 員工狹隘界定工作範圍
    2. (B) 造成組織規模龐大
    3. (C) 以過程為焦點而非成果導向
    4. (D) 過於重視量化指標，而非品質

    正解：(B)

  17. 17轉換型領導（transformation leadership）的概念之所以在近代廣受矚目，主要在於有其獨具特色的構成要素，這些特色要素不包含下列何者？

    1. (A) 側重於員工的動機啟發與精神感召
    2. (B) 仰賴領導者與部屬間相互的影響關係
    3. (C) 強調生產要素之投入
    4. (D) 著重員工的個別關懷

    正解：(C)

  18. 18主管建立並落實職務代理人制度，以提升同仁能力與達成激勵效果，最符合下列那一項管理概念？

    1. (A) 分層授權
    2. (B) 目標管理
    3. (C) 工作豐富化
    4. (D) 工作擴大化

    正解：(D)

  19. 19下列那一個敘述最符合默會知識（tacit knowledge）的特性？

    1. (A) 通常可以用文字或數字來表達
    2. (B) 通常需透過較長時間的學習才能獲得
    3. (C) 屬於較為結構式或較為明確的知識
    4. (D) 通常比較容易被觀察到與被記錄下來

    正解：(B)

  20. 20政府針對奢侈品課稅的作法，屬於羅伊（T. Lowi）所界定的那一種政策類型？

    1. (A) 管制性政策
    2. (B) 自我管制政策
    3. (C) 分配性政策
    4. (D) 重分配政策

    正解：(D)

  21. 21關於林布隆（C. Lindblom）提出的漸進主義決策模型，下列敘述何者錯誤？

    1. (A) 採取人是有限理性的基本假定
    2. (B) 認為公共政策是不同政黨間相互調適的結果
    3. (C) 是一種「根」的研究途徑（root approach）
    4. (D) 漸進主義決策模式有助於維持政治系統的穩定

    正解：(C)

  22. 22有關我國公務人員培訓制度，下列敘述何者正確？

    1. (A) 總統府文官委員會為最高培訓主管機關
    2. (B) 「高階文官培訓飛躍方案」訓練及格者，取得陞任簡任官等資格
    3. (C) 各主管機關得視需要提供公務人員終身學習之機會
    4. (D) 公務人員考試錄取人員訓練由各用人機關辦理之

    正解：(C)

  23. 23有關提供公共服務的非營利組織，下列敘述何者錯誤？

    1. (A) 是政府的合作者或競爭者
    2. (B) 可強化政府與民間之聯繫
    3. (C) 等同社會企業
    4. (D) 需要企業化管理觀念與方法

    正解：(C)

  24. 24下列何者與參與式預算的學理依據無關？

    1. (A) 公共治理，強調政府、企業、社會團體與公民共同合作
    2. (B) 公民社會，強調公共性、民主審議
    3. (C) 漸進主義，可克服有限理性的缺點，提升政策延續性
    4. (D) 社群主義，透過公民關切社區、培育社區認同、具公共利益奉獻精神

    正解：(C)

  25. 25下列何者不是構成鐵三角關係（iron triangle）網絡結構的主要要素？

    1. (A) 民選代議士
    2. (B) 利益團體
    3. (C) 行政官僚
    4. (D) 公民

    正解：(D)
