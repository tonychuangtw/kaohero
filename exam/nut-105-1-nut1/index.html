營養師　105 年第一次 生理學與生物化學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列那一種離子對神經細胞的靜止膜電位（resting membrane potential）影響最大？

    1. (A) 鈉離子
    2. (B) 鉀離子
    3. (C) 氯離子
    4. (D) 鈣離子

    正解：(B)

  2. 2剛滿月的新生兒常哭鬧不停，餵奶後常見噴射狀吐奶並夾雜著胃酸，這是什麼原因造成？

    1. (A) 門脈狹窄
    2. (B) 賁門狹窄
    3. (C) 聲門狹窄
    4. (D) 幽門狹窄

    正解：(D)

  3. 3下列何者為消化系統最主要的功能？

    1. (A) 將喝入的水再吸收
    2. (B) 將喝入的酒全排出
    3. (C) 將吃入的食物分解
    4. (D) 將吃入的藥物代謝

    正解：(C)

  4. 4當體內鐵含量因失血而下降時，人體對鐵的恆定機制為何？

    1. (A) 尿液排出鐵下降
    2. (B) 小腸細胞內鐵蛋白合成下降
    3. (C) 進入血液的游離鐵減少
    4. (D) 小腸細胞對鐵的吸收減少

    正解：(B)

  5. 5Furosemide 為臨床上常用的利尿劑之一，下列何者是其主要的作用機轉？

    1. (A) 抑制近側腎小管對水分的再吸收
    2. (B) 抑制醛固酮（aldosterone）之作用
    3. (C) 抑制鈉離子在亨利氏環上行支後段之運送
    4. (D) 本身為高滲透度之溶質因而能吸引水分留存在管腔中頁次： 4－2

    正解：(C)

  6. 6人類的排尿中樞（micturition center）位於下列何處？

    1. (A) 延腦（medulla）
    2. (B) 橋腦（pons）
    3. (C) 小腦（cerebellum）
    4. (D) 下視丘（hypothalamus）

    正解：(B)

  7. 7有關副甲狀腺素（parathyroid hormone）在腎臟的作用，下列敘述何者正確？

    1. (A) 促進鈣離子在近側腎小管的吸收
    2. (B) 促進鉀離子在近側腎小管的吸收
    3. (C) 降低磷酸根離子在遠側腎小管的吸收
    4. (D) 促進 1,25-雙羥維生素 D3（1,25(OH)2D3）之形成

    正解：(D)

  8. 8下列何者會抑制胰島素（insulin）分泌？

    1. (A) 血糖上升
    2. (B) 血漿中胺基酸濃度上升
    3. (C) 副交感神經活化（parasympathetic activation）
    4. (D) 血漿中腎上腺素（epinephrine）上升

    正解：(D)

  9. 9下列何種荷爾蒙分泌至血液中循環需與攜帶蛋白質結合？

    1. (A) 雌激素（estrogen）
    2. (B) 胰島素（insulin）
    3. (C) 泌乳素（prolactin）
    4. (D) 副甲狀腺激素（parathyroid hormone）

    正解：(A)

  10. 10胎兒神經發育時缺乏下列何種荷爾蒙參與，將導致呆小症（cretinism）？

    1. (A) 雌激素（estrogen）
    2. (B) 生長激素（growth hormone）
    3. (C) 胰島素（insulin）
    4. (D) 甲狀腺激素（thyroid hormones）

    正解：(D)

  11. 11在休息狀態下，下列何種器官的血流速率最高？

    1. (A) 大腦
    2. (B) 心臟
    3. (C) 腸胃系統
    4. (D) 皮膚

    正解：(C)

  12. 12有關血管破損所產生的止血（hemostasis）機轉，下列敘述何者錯誤？

    1. (A) 血小板聚集活化
    2. (B) 前列環素（prostacyclin）分泌增加
    3. (C) 血管平滑肌收縮
    4. (D) 血小板栓（platelet plug）形成

    正解：(B)

  13. 13下列何者不是出血性低血壓的生理反應？

    1. (A) 心搏血量下降
    2. (B) 心跳上升
    3. (C) 周邊血管阻力上升
    4. (D) 心輸出量下降

    正解：(C)

  14. 14抗體與抗原結合後，可活化下列何者，以促進吞噬細胞（phagocyte）聚集進行吞噬作用？

    1. (A) 補體（complement）
    2. (B) 細胞激素（cytokines）
    3. (C) 介白素（interleukin）
    4. (D) 前列腺素（prostaglandin）

    正解：(A)

  15. 15承上題，此為下列何種作用？

    1. (A) 凝集作用（agglutination）
    2. (B) 補體活化（complement activation）
    3. (C) 中和作用（neutralization）
    4. (D) 調理作用（opsonization）

    正解：(D)

  16. 16當骨骼肌細胞接受單一動作電位刺激產生一次收縮（twitch）時，其等張收縮相較於等長收縮，下列敘述何者正確？

    1. (A) 有較短的延遲和收縮時間
    2. (B) 有較長的延遲和收縮時間
    3. (C) 有較長的延遲時間，但較短的收縮時間
    4. (D) 有較短的延遲時間，但較長的收縮時間

    正解：(C)

  17. 17白內障是指下列何者功能受損？

    1. (A) 瞳孔
    2. (B) 晶狀體
    3. (C) 角膜
    4. (D) 視網膜

    正解：(B)

  18. 18正常情況下，肺泡中的氧氣是藉由下列何種方式進入肺微血管血液中？

    1. (A) 主動運送
    2. (B) 過濾作用
    3. (C) 被動擴散
    4. (D) 次級主動運送

    正解：(C)

  19. 19有關婦女停經（menopause）的敘述，下列何者錯誤？

    1. (A) 停經後易產生骨質疏鬆，與黃體素分泌減少有關
    2. (B) 停經初期，黃體激素（LH）分泌會增加
    3. (C) 停經主要是因為卵巢的老化所造成
    4. (D) 停經初期，促性腺激素釋放激素（GnRH）分泌會增加頁次：4－3

    正解：(A)

  20. 20男性因不能製造精子而發生不孕，最可能的原因是血漿中：

    1. (A) 促性腺激素（gonadotrophin）太高
    2. (B) 濾泡刺激素（FSH）不足
    3. (C) 性釋素（GnRH）不足
    4. (D) 黃體激素（LH）太高

    正解：(B)

  21. 21有關半乳糖血症（galactosemia）之敘述，下列何者錯誤？

    1. (A) 腸道易有乳糖累積，而有乳糖不耐症（lactose intolerance）情況之發生
    2. (B) 伴隨心智發展遲緩、白內障及肝臟腫大等臨床症狀之發生
    3. (C) 飲食應排除奶類及奶製品之攝取
    4. (D) 缺乏 galactose-1-phosphate uridyltransferase 導致半乳糖代謝受阻

    正解：(A)

  22. 22有關巴斯德效應（Pasteur effect）之敘述，下列何者正確？

    1. (A) 當血液中 pH 值下降時會減低血紅蛋白（hemoglobin）和氧之結合力
    2. (B) 當細胞中 CO2 濃度增加時會降低血紅蛋白（hemoglobin）和氧之結合力
    3. (C) 當 O2 介入厭氧性細胞時會抑制細胞糖解反應（glycolysis）進行
    4. (D) 當細胞中 ATP 濃度增高時會抑制細胞糖解反應（glycolysis）進行

    正解：(C)

  23. 23下列反應何者屬於 substrate-level phosphorylation？

    1. (A) fructose-6-phosphate→fructose-1,6-bisphosphate
    2. (B) glucose→glucose-6-phosphate
    3. (C) 3-phosphoglycerate→2-phosphoglycerate
    4. (D) 1,3-bisphosphoglycerate→3-phosphoglycerate

    正解：(D)

  24. 24在運動中骨骼肌因糖解反應（glycolysis）所產生之 NADH 會被下列何種脫氫酶所氧化？

    1. (A) lactate dehydrogenase
    2. (B) succinate dehydrogenase
    3. (C) isocitrate dehydrogenase
    4. (D) pyruvate dehydrogenase

    正解：(A)

  25. 25LDL receptor 可藉由辨識 LDL 上的何種蛋白質來取得膽固醇？

    1. (A) 蛋白質激酶（protein kinase）
    2. (B) 原脂蛋白 B100（apolipoprotein B100）
    3. (C) ABC 轉運蛋白（ABC transporter）
    4. (D) 磷酸酶（phosphatase）

    正解：(B)

  26. 26關於飯後血糖上升，同時脂肪酸的代謝也會受到調節，下列敘述何者錯誤？

    1. (A) 細胞內的［NADH］／［NAD+］比例上升，會抑制 β-羥基乙醯－輔酶 A 去氫酶（β-hydroxyacyl-CoAdehydrogenase）進而抑制脂肪酸的 β-氧化作用
    2. (B) 丙二醯－輔酶 A（malonyl-CoA）的生成會抑制糖解作用之進行，過多的糖可轉成三酸甘油酯貯存起來
    3. (C) 胰島素的分泌具有活化乙醯－輔酶 A 羧化酶（acetyl-CoA carboxylase）之作用
    4. (D) 肉鹼醯基轉移酶（carnitine acyltransferase）會受抑制，以確保脂肪酸不會進入細胞質而進行氧化反應

    正解：(D)

  27. 27下列何種化合物可能是必需脂肪酸的代謝產物？

    1. (A) 油酸（oleic acid）
    2. (B) 棕櫚烯酸（palmitoleic acid）
    3. (C) 花生四烯酸（arachidonic acid）
    4. (D) 乳酸（lactic acid）

    正解：(C)

  28. 28細胞膜的結構特稱為流體鑲嵌模型（fluid mosaic model），關於此模型之敘述，下列何者錯誤？

    1. (A) 膜中的脂肪與蛋白質成分並存，並不會相互反應生成中間物質
    2. (B) 穿越細胞膜的蛋白質可在膜內外移動，且不具方向性
    3. (C) 蛋白質在脂雙層上，可以沿著膜作平面移動
    4. (D) 細胞膜的脂雙層可以進行橫向運動（lacteral motion）頁次： 4－4

    正解：(B)

  29. 29肝臟可以利用 amino acid oxidase 將 amino acids 轉變成對應的 keto acid，該酵素反應亦會產生下列何種產物？

    1. (A) ATP
    2. (B) H2O2
    3. (C) O2
    4. (D) NADH

    正解：(B)

  30. 30在 pH=13 的鹼性溶液中，glycine 的主要型式為下列何者？

    1. (A) NH2-CH2-COOH
    2. (B) NH2-CH2-COO-
    3. (C) NH3+-CH2-COOH
    4. (D) NH3+-CH2-COO-

    正解：(B)

  31. 31Taurine 是參與脂質消化吸收的重要化合物，在大多數的哺乳類動物中，下列何種胺基酸經三個酵素反應後可以合成 taurine？

    1. (A) valine
    2. (B) histidine
    3. (C) threonine
    4. (D) cysteine

    正解：(D)

  32. 32細胞內維生素 A 過多時會影響到維生素 D 的功能，其可能的原因是下列何者？

    1. (A) retinoic acid 與維生素 D 競爭結合相同的 nuclear receptor
    2. (B) retinoic acid receptor 與維生素 D receptor 競爭結合 RXR 以形成活化型 heterodimers
    3. (C) retinoic acid 與維生素 D 所調控之目標基因上的控制元件其核酸序列相同
    4. (D) retinoic acid 可促進維生素 D receptor 之 mRNA 降解

    正解：(B)

  33. 33若一雙股 DNA 的鳥糞嘌呤（guanine）占總鹼基含量為 20%，則其胸腺嘧啶（thymine）含量應為多少%？

    1. (A) 25
    2. (B) 30
    3. (C) 35
    4. (D) 40

    正解：(B)

  34. 34下列何種 RNA 分子會出現於剪接體（spliceosome）？

    1. (A) snRNA
    2. (B) tRNA
    3. (C) rRNA
    4. (D) triple-stranded RNA

    正解：(A)

  35. 35在哺乳動物中以下列何種 DNA 的型式存在居多？

    1. (A) 右旋 B 型
    2. (B) 左旋 B 型
    3. (C) 右旋 A 型
    4. (D) 左旋 A 型

    正解：(A)

  36. 36下列何者為非終止密碼子？

    1. (A) UAA
    2. (B) UGA
    3. (C) UAG
    4. (D) UGG

    正解：(D)

  37. 37丙酮酸去氫酶複合體（pyruvate dehydrogenase complex）催化反應時會打斷 lipoic acid 結構的何種鍵結？

    1. (A) 氫鍵
    2. (B) 離子鍵
    3. (C) 雙硫鍵
    4. (D) 糖苷鍵

    正解：(C)

  38. 38下列何者是電子於粒線體電子傳遞系統的正確流程？

    1. (A) NADH→FAD→FeS center→FMN→FeS center
    2. (B) FAD→FeS center→CoQ→Cyt a→Cyt c
    3. (C) FMN→NADH→FeS center→CoQ→FeS center
    4. (D) FAD→FeS center→CoQ→Cyt b→Cyt c

    正解：(D)

  39. 39某個酵素具有多個與基質鍵結的活化位置，並且抑制劑或活化劑可調節此酵素之活性，此酵素活性的調節特性是：

    1. (A) 同質性異位調節作用（homoallosteric regulation）
    2. (B) 受質層次控制（substrate-level control）
    3. (C) 異質性異位調節作用（heteroallosteric regulation）
    4. (D) 共價修飾（covalent modification）

    正解：(C)

  40. 40下列何者不是檸檬酸循環的主要速率調節酵素？

    1. (A) 蘋果酸去氫酶（malate dehydrogenase）
    2. (B) 檸檬酸合成酶（citrate synthase）
    3. (C) 異檸檬酸去氫酶（isocitrate dehydrogenase）
    4. (D) α-酮戊二酸去氫酶（α-ketoglutarate dehydrogenase）

    正解：(A)
