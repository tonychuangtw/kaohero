職能治療師　113 年第二次 小兒職能治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1依據自閉症者的優勢本位參考架構，下列何種做法無益於自閉症孩童發展自我決定？

    1. (A) 讓孩童在其愛好的領域發展
    2. (B) 讓孩童基於活動結果對他具重要性而參與一個活動
    3. (C) 滿足孩童的自主、效能及關係等三種心理需求
    4. (D) 正常化孩童的行為，使其更接近一般孩童

    正解：(D)

  2. 2根據Guralnick（2013）所提出的促進孩童的社會參與模式—Developmental Systems Approach，三個促進幼兒同儕相處效能改變的層次，不包括下列何者？

    1. (A) 孩童的社會與認知效能
    2. (B) 家庭互動樣式
    3. (C) 社會接納
    4. (D) 家庭資源

    正解：(C)

  3. 3下列關於促進學習的四象限模式之敘述，何者正確？

    1. (A) 使用Vygotsky理論中的鷹架概念
    2. (B) 此模式強調由間接提示逐漸進展到直接提示
    3. (C) 透過改變活動及常規練習來改善孩童的技巧
    4. (D) 當孩童不具備完成某任務的表現要素時，適合使用此介入模式

    正解：(A)

  4. 4神經發展治療以徒手操作技巧，在動作中同時增強體感覺輸入以啟動中樞神經系統的神經化學訊息，形成神經地圖與建立「動作檔案」，此採用那一項理論基礎？

    1. (A) 神經元群組選擇理論（Neuronal Group Selection Theory）
    2. (B) 感覺貢獻（Sensory Contributions to Motor Control）
    3. (C) 動態系統理論（Dynamic Systems Theory）
    4. (D) 動作學習（Motor Learning）

    正解：(A)

  5. 5當兒童社會意識不佳（poor social awareness），常誤解社會線索與社會事件，這最可能是焦慮與憂鬱學齡兒童參考架構中的那一項功能障礙指標？

    1. (A) 教室中的社會參與
    2. (B) 因應（coping）技巧
    3. (C) 學業能力
    4. (D) 自主發展能力

    正解：(A)

  6. 6下列何者是在兒童經過不良事件的生活經驗之後，能幫助兒童達到健康調適最顯著的重要因子？

    1. (A) 與具關懷且有能力的成人有正向關係
    2. (B) 兒童解決問題的能力
    3. (C) 具自我調整情緒的能力
    4. (D) 兒童在學業上的自我效能

    正解：(A)

  7. 7對於兒童健康與教育系統中所運用到的典範（paradigm），下列敘述何者正確？

    1. (A) 所有典範都是以治癒兒童疾病為目的
    2. (B) 治癒模式典範的思考模式為還原論，由個案決定與其生活及診斷相關的目標來進行介入
    3. (C) 緩和模式典範的介入依據為個案與家庭共識所決定的目標
    4. (D) 生態模式典範認為環境中有足夠的選項讓家庭／個案在社區中發揮功能

    正解：(D)

  8. 8有關俯臥楔型墊擺位，下列敘述何者錯誤？

    1. (A) 楔型墊前緣與地面的距離，可協助決定對肩帶的需求
    2. (B) 一個剛好讓前臂接觸到地面的楔型墊，可以減少肩部壓力，提供本體覺
    3. (C) 一個腰椎前凸的孩童，讓楔型墊的下緣落在孩童腰部，可以協助擺位
    4. (D) 一個很高的楔型墊可以消除上肢支撐體重的需求

    正解：(C)

  9. 9有關視知覺的環境調適策略，下列何者最合適？

    1. (A) 將照明光線開到最強，讓小孩可以看到視覺任務
    2. (B) 重複的練習，讓小孩熟悉視覺任務
    3. (C) 在桌面上放一個傾斜板促進垂直定向，可減少方向混淆
    4. (D) 讓小孩在背景複雜的桌面上，練習訓練前景－背景的視覺任務

    正解：(C)

  10. 10關於職能治療應用以實證為基礎的實務，下列敘述何者錯誤？

    1. (A) 需要花費很多時間學習與使用實證基礎實務
    2. (B) 許多臨床實務中所產生的問題缺乏可回答的實證
    3. (C) 只適用隨機分配、有控制的實證研究，因此質性研究不算實證
    4. (D) 實證基礎實務有助於臨床推理

    正解：(C)

  11. 11對職能治療師而言，在國際健康功能與身心障礙分類系統（International Classification ofFunctioning, Disability, and Health, ICF）中日常生活領域的9個項目，就是職能治療的那一個核心概念？

    1. (A) 職能
    2. (B) 個案因子
    3. (C) 表現型式
    4. (D) 情境

    正解：(A)

  12. 12根據同步發展理論（synactive theory of development）的內容，下列何種行為代表嬰幼兒正處於壓力狀態？

    1. (A) 警醒注意（focused alertness）
    2. (B) 五指張開（finger splays）
    3. (C) 兩腳挺直（leg and foot bracing）
    4. (D) 手碰嘴巴（hand to mouth）

    正解：(B)

  13. 13下列職能治療師對學習者的提問，何者運用了促進學習的四象限模式中的「低階提問（lower orderquestions）」？

    1. (A) 這裡可能有什麼問題？
    2. (B) 接下來你要做什麼？
    3. (C) 這為什麼會發生？
    4. (D) 喔噢，我想這可能有點問題。

    正解：(B)

  14. 14根據玻巴斯（Bobath）神經發展治療的理論基礎，下列敘述何者正確？

    1. (A) 手法與擺位技術僅聚焦於發展理論
    2. (B) 目前採用的動作發展理論是屬於階層發展論
    3. (C) 神經發展治療不強調與環境的互動
    4. (D) 治療優先目標為孩童每一階段所需要的功能，而非遵循發展順序的介入

    正解：(D)

  15. 15關於視覺空間知覺的敘述，下列何者錯誤？

    1. (A) 主要發生在下顳葉皮質區
    2. (B) 包含空間位置、空間關係、深度知覺及地形定向感
    3. (C) 空間位置對於早期方向語言（如：上下左右）的學習非常重要
    4. (D) 深度知覺可協助人察覺物體的距離，也幫助我們在空間中的移動，如下樓梯

    正解：(A)

  16. 16有關感覺統合理論基礎的假說，下列敘述何者錯誤？

    1. (A) 警醒狀態與適應性反應的產生有關
    2. (B) 提供具「最適挑戰」的活動有助於成長與發展
    3. (C) 針對孩童表現落後的特定技巧做訓練，以增進自尊與自信
    4. (D) 在職能治療師的引導下，孩童須是主動參與以產生感覺整合

    正解：(C)

  17. 17關於獲得參考架構的主要假設（assumptions），下列敘述何者正確？

    1. (A) 內在精神面向與環境塑造的行為密切相關
    2. (B) 職能治療師無條件接納孩童且不評判
    3. (C) 學習必須依照發展順序，一個技巧會成為另一個技巧的基礎
    4. (D) 在某一領域的表現缺損能預測另一個領域的表現缺損

    正解：(B)

  18. 18下列關於兒童職能治療實務關注領域與項目的配對，何者錯誤？

    1. (A) 移動：改變與維持身體姿勢
    2. (B) 家庭生活：照顧家中寵物
    3. (C) 自我照顧：準備餐食
    4. (D) 人際互動與關係：家庭關係

    正解：(C)

  19. 19有關站立架的使用，下列何者最不適切？

    1. (A) 仰式站立架不須使用骨盆束帶
    2. (B) 不論仰姿或趴姿，均須考慮膝關節是否有過度伸直狀況，須加墊或調整腳踝位置
    3. (C) 對於頭控差且伸直張力強的個案，建議提供趴式站立架
    4. (D) 站立架的長度決定於此輔具須提供軀幹多少支持

    正解：(C)

  20. 20關於結果知識（knowledge of results）的回饋，下列敘述何者最適切？

    1. (A) 你很棒
    2. (B) 你湯灑出來的比昨天少
    3. (C) 手再舉高一點就投進了
    4. (D) 再用力一點就可以拿到了

    正解：(B)

  21. 21職能治療師用來促進兒童產生舌頭往前後、側邊動作的策略，下列何者錯誤？

    1. (A) 將湯匙或食團置於兒童舌頭中線處，促進舌頭往側邊動作
    2. (B) 鼓勵兒童對鏡子扮鬼臉或者舔棒棒糖，促進舌頭前後動作
    3. (C) 鼓勵兒童用舌頭舔吃沾在嘴角的鮮奶油，促進相關動作
    4. (D) 採用口腔動作工具刺激臉頰內側，可促進舌頭側邊動作

    正解：(A)

  22. 22職能治療師評估身障兒童的社會參與包括兒童本身及家長（照顧者）的需求，下列那一個工具可以看到家長的需求？

    1. (A) 兒童生活功能量表（Pediatric Evaluation of Disability Inventory, PEDI）
    2. (B) 短版兒童職能量表（The Short Child Occupational Profile）
    3. (C) 早期適應技巧量表（The Early Coping Skill Inventory）
    4. (D) 加拿大職能表現測驗（Canadian Occupational Performance Measure, COPM）

    正解：(D)

  23. 23職能治療實務中所使用的動作學習策略，下列敘述何者最適當？

    1. (A) 讓孩童練習相關動作技巧之後，再給予示範（demonstration），是最好的回饋方式
    2. (B) 結果知識（knowledge of results）的回饋頻率達到至少50%，有助於學習新動作技巧
    3. (C) 練習時段長、頻率較低的練習比練習時段短、頻率增加的練習更有助於技巧學習
    4. (D) 心像練習（mental practice）有助於個案準備執行任務，延長練習時段將更有利表現

    正解：(B)

  24. 24下列那一個工具只有測量視覺接收（visual reception）技巧？

    4. (D) 職能治療師專用兒童視覺篩檢（Pediatric Clinical Vision Screening for Occupational Therapists）

    正解：(D)

  25. 25關於感覺過度反應（sensory hyperreactivity）之敘述，何者最不適當？

    3. (C) 起因於大腦杏仁核的過度活化
    4. (D) 導致交感神經系統的過度活動

    正解：(A)

  26. 26關於應用聲音辨識軟體（voice recognition software）來協助孩童寫字技巧的敘述，下列何者錯誤？

    4. (D) 系統功能在過去5年間有進步，校正花費的時間降低

    正解：(C)

  27. 27針對缺乏前臂旋後（forearm supination）、腕關節伸展（wrist extension）、掌指關節伸展（metacarpophalangeal extension）和拇指橈側外展（thumb radial abduction）動作的兒童手傷個案，建議使用下列那種裝具（orthosis）最合適？

  28. 28下列那項精細動作是在1～2歲階段開始出現？

  31. 31職能治療師運用促進社會參與參考架構來改善同儕互動的介入策略，下列何者正確？

  32. 32職能治療師幫助兒童減少個別字母和數字倒轉錯誤（reversal error）的介入方法，下列那一個最不適當？

    4. (D) 提供機會練習書寫字母和數字的活動，重點在注意字母相對方向的形態特色

    正解：(B)

  33. 33孩童在學校表現出攻擊和破壞性的行為，如果學校要搭乘遊覽車至動物園進行戶外教學，有關職能治療師建議老師使用的行為處理方法，下列何者最適當？

  36. 36下列何者非矯治式的介入方式？

    4. (D) 極重度（profound）智能障礙個案經常出現感覺和身體損傷，且與他人社交互動有困難

    正解：(B)

  74. 74下列關於職能治療對於外傷性腦損傷（traumatic brain injury, TBI）孩童的介入，何項錯誤？

    1. (A) 在加護病房時期，治療師或許可依據孩童的意識（consciousness）程度給予適當感覺刺激
    2. (B) 急性期時可進行神經肌肉再教育（neuromuscular reeducation），以協助動作功能的恢復
    3. (C) 住院期的認知表現是重要焦點，通常越早經歷腦損傷，其認知預後（prognosis）越佳
    4. (D) 門診期可採用視覺時間表、管理工具和環境改造等代償（compensatory）認知策略介入

    正解：(C)

  75. 75有關家有自閉症兒童對家庭的影響，下列敘述何者錯誤？

    1. (A) 自閉症兒童的家庭會遷就自閉症兒童的特殊習性而改變或限制生活型態
    2. (B) 自閉症兒童非典型的行為對於父親造成的心理壓力通常比母親要高
    3. (C) 在有自閉症兒童的家庭裡，祖父母常具備照顧上的重要角色
    4. (D) 自閉症兒童的手足容易嫉妒父母不同程度的對待，可能發生暴力行為

    正解：(B)

  76. 76下列有關注意力不足過動症（Attention Deficit Hyperactivity Disorder, ADHD）診斷的敘述，何者錯誤？

    1. (A) 其注意力不足、過動／衝動的症狀至少持續12個月以上
    2. (B) 兒童在12歲前即出現數種注意力不足或過動／衝動的症狀
    3. (C) 其注意力不足、過動／衝動症狀會影響兒童的社交或學業功能
    4. (D) 其注意力不足、過動／衝動症狀會出現在二種或更多的情境

    正解：(A)

  77. 77職能治療介入對於脊髓損傷孩童所提供的目的性活動，下列敘述何者錯誤？

    1. (A) 門診期不需透過神經肌肉再教育（neuromuscular reeducation）方式來協助動作功能的恢復
    2. (B) 住院期採用任務訓練（task training）或反覆練習同一任務的方式，將有助於增進動作功能
    3. (C) 住院期可採用電刺激（electrical stimulation）以回復協調性和力量，但須注意電燒傷的風險
    4. (D) 急性期動作功能的恢復需在有脊髓骨科（spinal orthopedic）設備下進行，但會影響獨立性

    正解：(A)

  78. 78有關孩童焦慮症的敘述，下列何者錯誤？

    1. (A) 常見的症狀為持續或過度的擔心或害怕
    2. (B) 進一步影響社交、學業表現及職能功能
    3. (C) 盛行率男生遠多於女生（約3：1）
    4. (D) 為孩童時期常見的障礙

    正解：(C)

  79. 79下列有關發展性協調障礙（developmental coordination disorder）兒童的敘述，何者錯誤？

    1. (A) 反應時間（reaction time）較慢，順序性動作困難
    2. (B) 動作障礙會影響生活自理及學業表現，但無法以智能障礙解釋
    3. (C) 節律性協調（rhythmic coordination）較差，執行功能（executive function）正常
    4. (D) 不會同時被診斷為腦性麻痺，但可能同時被診斷為注意力不足過動症

    正解：(C)

  80. 80下列有關學習障礙（learning disorders）個案的敘述，何者錯誤？

    1. (A) 學習障礙個案的智力多為正常或正常程度以上
    2. (B) 許多學習障礙個案同時有社交互動的困難
    3. (C) 當遇到人際衝突時，學習障礙個案較常選擇妥協或談判等策略
    4. (D) 個案數學運算能力佳，但遇到數學應用題則看不懂題目，可能是學習障礙中的閱讀障礙

    正解：(C)
