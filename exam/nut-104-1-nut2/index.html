營養師　104 年第一次 營養學　考古題與詳解

本卷共 40 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（40 題，建議 120 分鐘）

  1. 1下列何種人必須注意或避免食用代糖 Equal®？

    1. (A) 糖尿病患者
    2. (B) 高血脂患者
    3. (C) 高血壓患者
    4. (D) 苯丙酮酸尿患者

    正解：(D)

  2. 2關於維持血糖恆定的來源，下列敘述何者錯誤？

    1. (A) 飲食中之糖份或澱粉
    2. (B) 肝臟之肝醣分解
    3. (C) 肌肉之肝醣分解
    4. (D) 肝臟之糖質新生

    正解：(C)

  3. 3大豆容易在食用後產生脹氣的原因與下列何種成分關係最密切？

    1. (A) raffinose
    2. (B) amylose
    3. (C) amylopectin
    4. (D) triglycerides

    正解：(A)

  4. 4高纖維飲食的 phytate 或 phytic acid，最容易干擾下列那些營養素的吸收？

    1. (A) 維生素 C、維生素 B6
    2. (B) 鋅、銅
    3. (C) 葉酸、維生素 B6
    4. (D) 維生素 D、鈣

    正解：(B)

  5. 5當體內大量產生下列何種物質時會造成 nitrogen loss？

    1. (A) Oxyhemoglobin
    2. (B) Interleukin-6
    3. (C) DNA
    4. (D) Transferrin頁次：4－2

    正解：(B)

  6. 6穀類的限制胺基酸為下列何者？

    1. (A) 離胺酸（lysine）
    2. (B) 甲硫胺酸（methionine）
    3. (C) 半胱胺酸（cysteine）
    4. (D) 色胺酸（tryptophan）

    正解：(A)

  7. 7當處於正氮平衡時，下列何種荷爾蒙會增加，以刺激蛋白質的生合成？

    1. (A) 昇糖激素
    2. (B) 胰島素
    3. (C) 腎上腺素
    4. (D) 甲狀腺素

    正解：(B)

  8. 8志明的蛋白質攝取量為 100 公克，熱量攝取為 2000 仟卡，則志明的蛋白質攝取量約占總熱量的多少%？

    1. (A) 10
    2. (B) 15
    3. (C) 20
    4. (D) 25

    正解：(C)

  9. 9有關反式脂肪的敘述，下列何者錯誤？

    1. (A) 屬於不飽和脂肪酸
    2. (B) 反式脂肪酸可由油脂氫化加工產生
    3. (C) 富含於棕櫚油中
    4. (D) 影響血膽固醇濃度

    正解：(C)

  10. 10下列何者為前列腺素（prostaglandins）合成酵素之一，且其活性會受到 aspirin 或 acetaminophen 的抑制？

    1. (A) adenylate cyclase
    2. (B) phospholipase A2
    3. (C) cyclooxygenase
    4. (D) lipoxygenase

    正解：(C)

  11. 11下列食用油何者不屬於良好油酸供給來源？

    1. (A) 苦茶油
    2. (B) 椰子油
    3. (C) 橄欖油
    4. (D) 高油酸葵花籽油

    正解：(B)

  12. 12下列何者不是身體內膽固醇的衍生物？

    1. (A) bile acids
    2. (B) prostaglandins
    3. (C) vitamin D
    4. (D) cortisone

    正解：(B)

  13. 13張先生身高 172 公分，體重 82 公斤，依照衛生福利部的標準，他的體型屬於下列何者？

    1. (A) 正常
    2. (B) 過重
    3. (C) 輕度肥胖
    4. (D) 中度肥胖

    正解：(C)

  14. 14在下列那些情況中體內的酮體會大量生成？①長期禁食 ②低蛋白質飲食 ③低碳水化合物飲食 ④劇烈運動

    1. (A) ①②
    2. (B) ①③
    3. (C) ②③
    4. (D) ②④

    正解：(B)

  15. 15下列何者會增加靜態能量消耗（resting energy expenditure, REE）？

    1. (A) 老年人
    2. (B) 罹患厭食症的人
    3. (C) 舉重選手
    4. (D) 同體重的矮胖身型者

    正解：(C)

  16. 16下列有關食物產熱效應（thermic effect of food）的敘述，何者正確？

    1. (A) 碳水化合物高於蛋白質
    2. (B) 蛋白質高於碳水化合物
    3. (C) 脂肪高於蛋白質
    4. (D) 碳水化合物、蛋白質及脂肪一樣高

    正解：(B)

  17. 17下列何者是富含維生素 B12 的食物？

    1. (A) 柳丁汁
    2. (B) 綠色蔬菜
    3. (C) 葵花籽油
    4. (D) 豬肝

    正解：(D)

  18. 18人體的那些細胞對於葉酸缺乏營養狀態最為敏感，易於產生病變？①腸道表皮絨毛吸收細胞 ②骨髓腔紅血球母細胞 ③胚胎間葉幹細胞 ④成骨細胞

    1. (A) ①③④
    2. (B) ②③④
    3. (C) ①②③
    4. (D) ①②④頁次：4－3

    正解：(C)

  19. 19王先生因為肝硬化併發沃尼可腦病變（Wernicke's encephalopathy），臨床治療上會給予下列何種營養素？

    1. (A) 葉酸
    2. (B) 維生素 B1
    3. (C) 長鏈必需脂肪酸
    4. (D) 芳香族胺基酸

    正解：(B)

  20. 20人類因缺乏下列何種酵素，所以無法合成維生素 C，而必須依賴飲食攝取？

    1. (A) 葡萄糖-6-磷酸去氫酶（glucose-6-P dehydrogenase）
    2. (B) L-古洛糖酸內酯氧化酶（L-gulonolactone oxidase）
    3. (C) 醛糖酸内酯酶（aldonolactonase）
    4. (D) 磷酸酶（phosphatase）

    正解：(B)

  21. 21下列何者是可提高胡蘿蔔素吸收率的因子？

    1. (A) 纖維質
    2. (B) 其他胡蘿蔔素
    3. (C) 油脂
    4. (D) 維生素 B1

    正解：(C)

  22. 22下列何種組合營養素可能可以改善乾眼症之不適？

    1. (A) 維生素 D＋鈣
    2. (B) 維生素 C＋鐵
    3. (C) 維生素 A＋鋅
    4. (D) 維生素 K＋鎂

    正解：(C)

  23. 23下列何種脂溶性維生素，可部分內生成並具有類內分泌激素之功能？

    1. (A) 維生素 A
    2. (B) 維生素 D
    3. (C) 維生素 E
    4. (D) 維生素 K

    正解：(B)

  24. 24為防止骨質疏鬆症的發生，可建議增加下列何種營養素組合的攝取？

    1. (A) 銅和鉻
    2. (B) n-6 脂肪酸和水
    3. (C) 維生素 D 和 K
    4. (D) β-葡聚醣和維生素 A

    正解：(C)

  25. 25關於銅缺乏時會造成貧血之敘述，下列何者最正確？

    1. (A) 銅缺乏時血紅素無法合成
    2. (B) 銅在傷口癒合上扮演重要的角色，也可預防血液的流失
    3. (C) 會干擾到 protoporphyrin 之合成，進而影響鐵的吸收
    4. (D) 銅可清除自由基，避免紅血球受到破壞

    正解：(A)

  26. 26下列何者是血管壁中有過多鈣沉澱的主要原因？

    1. (A) 飲食中維生素 D 攝取過多
    2. (B) 飲食中維生素 A 攝取不足
    3. (C) 血中鈣離子濃度過低
    4. (D) 血中鈣離子濃度過高

    正解：(A)

  27. 27下列何種食物中含有大量的鈉？

    1. (A) 現採蘋果
    2. (B) 醃火腿
    3. (C) 無糖可樂
    4. (D) 臺灣啤酒

    正解：(B)

  28. 28下列那些礦物質的缺乏與引發貧血有關？

    1. (A) 碘、磷、鈣
    2. (B) 鋅、銅、鐵
    3. (C) 鎂、鈉、鐵
    4. (D) 氯、碘、鉀

    正解：(B)

  29. 29評估老年人的蛋白質狀態，下列何項指標最合適？

    1. (A) Serum albumin
    2. (B) Serum transferrin
    3. (C) Plasma prealbumin
    4. (D) Plasma total protein頁次：4－4

    正解：(A)

  30. 30依照民國 100 年「國人膳食營養素參考攝取量（DRIs）」修訂第七版的標準，13～15 歲的青少年，每日蛋白質的攝取建議量約為多少公克／公斤？

    1. (A) 0.6～0.7
    2. (B) 0.8～0.9
    3. (C) 1.7～2.0
    4. (D) 1.2～1.3

    正解：(D)

  31. 31下列敘述何者錯誤？

    1. (A) 青少年的快速生長有可能導致生理性貧血（physiologic anemia of growth）發生
    2. (B) 研究顯示體重過重的青少年比正常體重的同齡青少年，有較低的缺鐵機率
    3. (C) 缺鐵性貧血會影響到青少年的短期記憶功能
    4. (D) 懷孕的青少年是鐵缺乏的高危險群

    正解：(B)

  32. 32嬰兒出生後，建議應立即補充下列何種營養素？

    1. (A) 維生素 K
    2. (B) 維生素 D
    3. (C) 葉酸
    4. (D) 鈣

    正解：(A)

  33. 33研究顯示一天當中不吃那一餐的兒童，學習能力、記憶力及學業表現較差？

    1. (A) 早餐
    2. (B) 午餐
    3. (C) 點心
    4. (D) 晚餐

    正解：(A)

  34. 34孕婦若在懷孕第三期時出現高血壓、蛋白尿、水腫且有抽搐的症狀，可能是患有：

    1. (A) 妊娠糖尿病
    2. (B) 妊娠高血壓
    3. (C) 子癇症
    4. (D) 子癇前症

    正解：(C)

  35. 35下列何者為大豆中結構類似動情激素（estrogen）具生物活性之物質？

    1. (A) 花青素
    2. (B) 異黃酮
    3. (C) 黃酮醇
    4. (D) 前花青素

    正解：(B)

  36. 36芝麻具抗氧化、降膽固醇功能，除含生育醇外，其主要富含：

    1. (A) 木酚素
    2. (B) 果膠質
    3. (C) 亞麻油酸
    4. (D) 磷、鈣等礦物質

    正解：(A)

  37. 37魚肝油大量攝取為什麼會造成人體的潛在毒性？

    1. (A) 三酸甘油酯攝取過多
    2. (B) 維生素 A 攝取過多
    3. (C) 膽固醇攝取過多
    4. (D) 甘油攝取過多

    正解：(B)

  38. 38葉綠素（chlorophyll）經一般烹調加熱處理後之產物為何？

    1. (A) chlorin purpurins
    2. (B) pheophytin
    3. (C) pheophorbide
    4. (D) methyl chlorophyllide

    正解：(B)

  39. 39燕麥是常被推薦有益健康之食物，具有調降血脂等功效，可能之貢獻物為何？

    1. (A) 類黃酮
    2. (B) 類胡蘿蔔素
    3. (C) 多醣體
    4. (D) 特異性蛋白質

    正解：(C)

  40. 40下列何者是測定體組成／肥胖最準確的方法？

    1. (A) 水中秤重法（underwater weighing）
    2. (B) 皮下脂肪率（skinfold thickness）
    3. (C) 身體質量指數（body mass index, BMI）
    4. (D) 雙能量吸收光儀（dual energy X-ray absorptiometry, DEXA）

    正解：(A)
