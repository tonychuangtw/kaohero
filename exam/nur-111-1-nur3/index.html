護理師　111 年第一次 內外科護理學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1有關病人心智狀態評估內容的敘述，下列何者錯誤？

    1. (A) 可以利用簡易心智狀況量表（Mini Mental State Examination, MMSE）進行測試
    2. (B) 可以依判斷力、定向感、記憶力、注意力、抽象思考能力、計算力進行評估
    3. (C) 詢問病人有關「人、時、地」的確認能力，主要是評估注意力
    4. (D) 詢問老年病人年輕時的基本資料如求學、求職等，主要是評估遠期記憶力

    正解：(C)

  2. 2有關病人已出現顱內壓升高的護理處置，下列敘述何者錯誤？

    1. (A) 保持病人的頭頸在正中位置
    2. (B) 抬高床頭 30 度
    3. (C) 將抽痰、翻身拍背、擦澡等活動都集中一次完成
    4. (D) 應注意體溫的控制及維持排便正常

    正解：(C)

  3. 3有關腰椎椎間盤突出的敘述，下列何者錯誤？

    1. (A) 俗稱為「下背疼痛」，此種疼痛會向下延伸至臀部、大腿後側及小腿
    2. (B) 進行直舉腿試驗（straight leg raising test）可伸展到 90 度
    3. (C) 進行 Kernig sign 試驗，病人將小腿往上伸展會覺得有阻力且感到劇烈疼痛
    4. (D) 病人咳嗽、提重物、彎腰、長時間站立或坐著都會使疼痛加劇

    正解：(B)

  4. 4「走失」是阿茲海默氏症（Alzheimer’s Disease）病人，那一期重要臨床表徵？

    1. (A) 極早期
    2. (B) 早期
    3. (C) 中期
    4. (D) 末期

    正解：(C)

  5. 5有關巴金森氏症病人日常生活護理指導，下列何者錯誤？

    1. (A) 行走時可使用助行器來維持平衡
    2. (B) 衣服儘量選擇以魔鬼氈代替釦子
    3. (C) 儘量多休息以減少活動產生震顫
    4. (D) 馬桶可提高坐墊方便坐下或起身

    正解：(C)

  6. 6有關頭部創傷之敘述，下列何者正確？

    1. (A) 腦震盪是因外力造成暫時性的神經功能缺失，且腦組織有實質性的損傷
    2. (B) 腦挫傷是因沒有腦組織的實質性損傷，所以受傷後常會出現腦震盪症候群
    3. (C) 若出現鼻漏且確認是腦脊髓液，表示病人的硬腦膜受損
    4. (D) 有鼻漏或耳漏的病人通常要儘快用抽吸管抽吸乾淨

    正解：(C)

  7. 7有關腦波檢查的護理措施，下列何者錯誤？

    2. (B) 告知病人檢查前，需清洗頭髮
    3. (C) 確認腦波室內備有足夠的點滴及氧氣
    4. (D) 檢查後，留在頭皮及頭髮上的黏膠，可用丙酮清理

    正解：(A)

  8. 8有關脊髓損傷導致「自主神經反射過度」的敘述，下列何者正確？

    2. (B) 走路運動是可能的誘因
    3. (C) 出現嚴重的高血壓及搏動性頭痛
    4. (D) 心跳加速

    正解：(C)

  9. 9有關腸阻塞的臨床表徵，下列何者正確？①嘔吐 ②腹脹 ③腹部絞痛 ④腹瀉

  14. 14有關口腔炎的分類及臨床表徵，下列何者正確？

  15. 15有關癌症病人貧血問題之敘述，下列何者錯誤？

  18. 18有關腕隧道症候群的敘述，下列何者正確？
