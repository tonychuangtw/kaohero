物理治療師　112 年第一次 神經疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1正常年輕人在跨越身高10%高度的障礙物時，身體質量中心在不同方向之位移量相對於走路時的變化，下列敘述何者正確？

    1. (A) 前後與左右兩側之位移量皆增加
    2. (B) 前後與上下之位移量皆增加
    3. (C) 前後減少、左右兩側增加
    4. (D) 左右兩側減少、上下增加

  3. 3健康年輕人站在平衡桿上（雙肩與平衡桿平行），身體突然受到往前輕微的外力干擾，他最有可能採取的姿勢穩定策略為何？

    3. (C) 操作制約（operant conditioning）
    4. (D) 古典制約（classical conditioning）

  5. 5一位腦傷的患者無法用言語告訴治療師如何從家裡的客廳走到廚房，但他可以因為口渴毫不猶豫起身、走到廚房倒水喝了後再回到客廳。此位患者保留了那種記憶能力？

    4. (D) 可以用來區別肌肉張力細微的變化

  14. 1465歲的張先生四個月前出血性中風，目前下肢沒有任何主動動作，欲利用本體感覺神經肌肉誘發術來增加下肢承重的能力， 下列敘述何者正確？

    1. (A) 趴姿下利用髖關節彎曲伸直的重複收縮（repeated contractions）加強髖關節伸直的肌力
    2. (B) 側躺姿勢下，要求張先生做出髖關節伸直的動作，利用固定－放鬆（hold-relax）加強髖關節伸直的肌力
    3. (C) 平躺姿勢，利用D1伸直模式和節律性起始（rhythmic initiation）技巧來增加下肢承重能力
    4. (D) 雙手－雙膝跪姿（all-four），在骨盆利用節律性固定（rhythmic stabilization）的技巧，維持此姿勢的穩定性，來增加下肢承重

    正解：(D)

  15. 15有關本體感覺神經肌肉誘發術的執行，下列敘述何者正確？

    1. (A) 治療師的手接觸病人的肢體是為了支撐病人的肢體重量，所以病人能力改善時，接觸範圍也要減少
    2. (B) 沒有特定的治療動作模式，而且每一種治療技巧都可以用來增加病人的動作穩定性
    3. (C) 此技巧主要依靠治療師的口令和動作，若病人意識不清也能順利執行
    4. (D) 治療過程中的口令，可以分成準備、動作、矯正三部分

    正解：(D)

  16. 16下列關於收縮－放鬆（CR; contract-relax）及固定－放鬆（HR; hold-relax）手法的敘述，何者最為適當？

    1. (A) CR：用於沒有疼痛主訴但動作角度受限的患者；HR：用於有疼痛主訴但動作角度沒有受限的患者
    2. (B) CR：運用於作用肌；HR：運用於拮抗肌
    3. (C) CR：等張收縮；HR：等長收縮
    4. (D) CR：由治療師控制阻力大小；HR：由患者主動控制力量大小

    正解：(C)

    4. (D) 持續注視治療師的鼻子，治療師將其頭部往左右方向做小幅度、快速轉動，在頭部動作停止時，仍能將視線維持在治療師的鼻子

    正解：(A)

  71. 71下列關於前庭核之敘述何者錯誤？

    1. (A) 接收來自同側周邊前庭系統、視覺、體感覺和對側前庭核之神經輸入
    2. (B) 傳遞神經衝動引發前庭眼球反射和前庭脊髓反射
    3. (C) 和小腦、網狀組織及視丘均有神經連結
    4. (D) 此部位栓塞會造成平滑追視（pursuit）與跳視（saccade）異常

    正解：(D)

  72. 72在執行前庭功能測試時，當患者閉上眼睛，頭往前傾約30度，左右轉動頭部20次，再請患者張開眼睛，發現患者有水平眼球震顫，下列何者正確？

    1. (A) 前庭功能正常
    2. (B) 單側前庭功能受損
    3. (C) 雙側前庭功能受損
    4. (D) 中樞神經系統受損而影響前庭功能

    正解：(B)

  73. 73重症肌無力（myasthenia gravis）的病理位置發生在何處？

    1. (A) 下運動神經元
    2. (B) 周邊神經
    3. (C) 神經肌肉接合處
    4. (D) 肌肉

    正解：(C)

  74. 74基蘭－巴瑞氏症候群病患之處置方針何者較適當？

    1. (A) 病患急性期不應使用副木或吊帶，以免造成軟組織變性及關節攣縮
    2. (B) 亞急性期開始應以高強度訓練虛弱之肌肉，加速受損之周邊神經再生
    3. (C) 運動訓練後若肌肉出現持續疼痛及感覺異常，應立刻停止運動訓練
    4. (D) 配合疾病由遠端至近端發展，遠端肌肉之訓練強度應高於近端肌肉

    正解：(C)

  75. 75下列那一項動態步態指標（dynamic gait index）的測試項目與前庭功能最為相關？

    1. (A) 快速平地行走
    2. (B) 邊走邊轉頭
    3. (C) 繞過障礙物
    4. (D) 停下腳步轉身

    正解：(B)

  76. 76跌倒的發生與年齡、生理、心理狀態有關，關於跌倒的危險因子，下列敘述何者正確？

    1. (A) 為了增加姿勢穩定性，年長者會以減少肌肉共同收縮（muscle co-contraction）來因應
    2. (B) 憂鬱問題僅影響心理狀態，不會提升跌倒風險
    3. (C) 罹患尿失禁的長者，可能會有較高的跌倒風險
    4. (D) 害怕跌倒的心理會減少危險行為，長期下來可避免跌倒發生

    正解：(C)

  77. 77下列那一位長輩具有較高的跌倒風險？

    1. (A) 柏格氏平衡量表（The Berg Balance Scale）測試得分50分
    2. (B) 計時起走測試（Timed Up and Go）花費時間20秒
    3. (C) 功能性前伸測試（functional reach test）距離20公分
    4. (D) 四方格跨步測試（The four-square step test）花費時間10秒

    正解：(B)

  78. 78指導家屬為安寧照護個案進行被動性關節運動時，下列何者應優先考量？

    1. (A) 維持正常之全身肌肉長度
    2. (B) 減少肢體水腫與體液滯留
    3. (C) 維持照護所需之關節活動度
    4. (D) 維持個人對身體之形象

    正解：(C)

  79. 79下列何者不是高齡體適能檢測的評估項目？

    1. (A) 坐到站測試
    2. (B) 10公尺走路速度
    3. (C) 計時起走測試
    4. (D) 坐姿前伸測試

    正解：(B)

  80. 80老年人的各種感覺能力開始退化，對於環境改善調整建議，下列那一項較為適當？

    1. (A) 可在地板貼上不同的圖案花紋，做為引導方向的指示
    2. (B) 可加裝高音頻警示器，以提醒緊急狀況發生
    3. (C) 夜燈儘量使用白色的燈泡，以提供足夠的照明
    4. (D) 製作指示標籤，顏色採深底淺字會較淺底深字清楚

    正解：(D)
