物理治療師　112 年第二次 骨科疾病物理治療學　考古題與詳解

本卷共 80 題，其中 0 題附有本站自撰的逐題詳解。題目與標準答案取自考選部「考畢試題查詢平臺」的公開資料；詳解由本站撰寫並標註出處。本頁列出全部題目與標準答案，並免費試讀前 3 題的詳解；其餘詳解在線上作答時逐題顯示。

▶ 線上作答這一卷（80 題，建議 60 分鐘）

  1. 1正常情況下，當胸椎前彎時，胸椎及肋骨會一起產生動作，下列何者正確？①胸椎前彎時，胸椎小面關節會往上滑動 ②胸椎前彎時，胸椎小面關節會往下滑動 ③胸椎前彎時，肋骨會往前轉動 ④胸椎前彎時，肋骨會往後轉動

    1. (A) ①③
    2. (B) ②④
    3. (C) ①④
    4. (D) ②③

    正解：(A)

  2. 2有關頸椎最大壓迫測試（maximum cervical compression test）時，若將患者頭部先側彎到左側，再旋轉到左側，下列敘述何者錯誤？

    1. (A) 此時若有疼痛下傳至左手臂，則表示可能有神經根壓迫
    2. (B) 此時若感覺右邊的頸部肌肉有疼痛感，可能代表右邊頸部肌肉有拉傷
    3. (C) 若再將頸部帶到後伸位置，由頭頂部再施加垂直下壓力，患者左手臂若有症狀，可能會更嚴重
    4. (D) 若在頸部後伸的姿勢下維持30秒，患者出現頭暈噁心的現象，則可能是左側頸動脈受到壓迫

    正解：(D)

  3. 3下列何者最符合頸因性頭痛的敘述？

    1. (A) C5～C6 的活動度不正常
    2. (B) 單側上頸椎後側疼痛
    3. (C) 單側頭痛不會轉移到另一側、出現非劇烈疼痛且通常非搏動痛（nonthrobbing nature）
    4. (D) 單側額葉、顳葉位置頭痛、叢發性（clusterlike）、雷擊性（thunderclap）、無預兆偏頭痛

    正解：(C)

  4. 4一位頸痛個案主訴低頭時會有頭暈無力現象，如果用手頂住額頭症狀會消失，物理治療師觀察發現個案低頭時上頸椎後側有一腫塊，下列處置何者最恰當？

    1. (A) 訓練頸椎屈肌肌肉
    2. (B) 放鬆枕骨下肌肌肉
    3. (C) 視動協調訓練（oculomotor training）
    4. (D) 立即轉介醫師做進一步檢查與診斷

    正解：(D)

  5. 5枕骨下肌群（suboccipital muscles）中，那些肌肉有附著到樞椎（C2）之棘突？① 頭後直大肌（rectus capitisposterior major） ②頭後直小肌（rectus capitis posterior minor） ③上頭斜肌（obliquus capitis superior） ④下頭斜肌（obliquus capitis inferior）

    1. (A) ①③④
    2. (B) ②③④
    3. (C) ①④
    4. (D) ②③

    正解：(C)

  6. 6有關頸椎排列的敘述，下列何者錯誤？

    1. (A) 正常頸椎弧度為前凸（lordosis）30～40度
    2. (B) 正常頸椎弧度下，身體重力線會通過下頸椎椎體
    3. (C) 如果頸椎前凸弧度變小，則椎間盤受力會增加
    4. (D) 如果頸椎前凸弧度增加，則頸部後側韌帶所受之拉力增加

    正解：(D)

  7. 7顳頜關節的關節盤失序可能造成張口閉鎖（open lock）與閉口閉鎖（closed lock）兩種障礙，下列何者是常見原因？

    1. (A) 張口閉鎖是因為關節盤前脫位，閉口閉鎖是因為關節盤後脫位
    2. (B) 張口閉鎖是因為關節盤後脫位，閉口閉鎖是因為關節盤前脫位
    3. (C) 兩者皆因關節盤的前脫位
    4. (D) 兩者皆因關節盤的後脫位

    正解：(B)

  8. 8病人在張嘴動作初期發生下頜骨前突（early protrusion），下列敘述何者正確？

    1. (A) 原因為舌骨上肌與外翼肌之間動作不協調
    2. (B) 先教導病人舌頭頂住下排門牙後方，再練習張嘴
    3. (C) 針對下頜骨前突之運動訓練不應給予阻力
    4. (D) 舌頭頂住硬顎時，外翼肌會限制下頜往前滑行

    正解：(A)

  9. 9一位60歲婦女主訴右側手臂外側到右手大拇指、食指與中指疼痛，當頸部側彎到左側時疼痛增加，頸部側彎到右邊疼痛減輕，當手放在頭上時可緩解疼痛，則最有可能是：

    1. (A) 頸部神經根壓迫
    2. (B) 臂神經叢病變
    3. (C) 手臂腋網症候群
    4. (D) 頸部脊髓病變

    正解：(B)

  10. 10下列何者可測試椎動脈是否受壓迫？

    2. (B) 上肢張力測試（upper limb tension test）
    3. (C) 最大頸椎壓擠測試（maximum cervical compression test）
    4. (D) 夏普－波瑟測試（Sharp-Purser test）

    正解：(C)

  11. 11施行下列何方向的顳頜關節鬆動術時，物理治療師的手不需戴手套伸進病人嘴裡？

    1. (A) 向前滑動（anterior glide）
    2. (B) 尾向牽拉（caudal traction）
    3. (C) 頭側縱向滑動（longitudinal cephalad glide）
    4. (D) 向後滑動（posterior glide）

    正解：(A)

  12. 12當物理治療師執行評估時，要求患者將較無力的下肢（如下圖中的左腳）上抬，發現另一隻腳（如下圖中的右腳）沒有下壓的現象，下列敘述何者正確？

    1. (A) 這是禮貌的患者現象
    2. (B) 這是陰性反應，表示右下肢有足夠的力氣
    3. (C) 表示患者有可能裝病
    4. (D) 此測試稱為Burns test

    正解：(C)

  13. 13一位30歲腰痛患者，外觀彎腰駝背，從後側看有些微側彎，主訴反應咳嗽、久坐會造成症狀往大腿膝窩處延伸；平躺時，直膝抬腿會讓背部症狀加劇，有時走一走症狀會減輕。對此患者的建議，下列何者較為合適？

    1. (A) 建議完全躺平休息1～2週，直至症狀中心化（centralization）
    2. (B) 在急性期，建議採用持續性牽引（sustained traction）緩解，一次至少10分鐘以上，15分鐘以內
    3. (C) 坐姿下建議使用腳墊，增加髖關節屈曲角度，減少腰椎和骨盆壓力
    4. (D) 在急性期，建議使用馬桶座增高墊，緩解症狀發生

    正解：(D)

  14. 14在肌肉能量技巧（muscle energy technique）中，採用仰臥姿勢下，藉由股直肌收縮將髂骨旋轉的方式，可以處理下列那種失能傷害？

    1. (A) 恥骨向下切變（shear）失能
    2. (B) 髂骨後旋轉失能
    3. (C) 髂骨前旋轉失能
    4. (D) 髂骨內展（inflare）失能

    正解：(B)

  15. 15物理治療師治療慢性下背痛病人，依照2021年出版美國物理治療學會之下背痛物理治療臨床指引，下列何者並無強（strong）等級之證據支持？

    1. (A) 運動或徒手治療，同時教導病人疼痛神經科學之衛教
    2. (B) 主動治療如皮拉提斯運動及肌力訓練
    3. (C) 間歇性機械式腰椎牽引
    4. (D) 腰椎關節鬆動術

    正解：(C)

  16. 16根據Wells criteria，術後出現深層靜脈栓塞機率增加的因素，包括下列何者？①6個月內有惡性腫瘤治療②12週內有進行手術全身麻醉 ③術後出現全腿腫脹

    1. (A) 僅②③
    2. (B) 僅①③
    3. (C) 僅①②
    4. (D) ①②③

    正解：(D)

  17. 17下列有關腰椎問題與症狀之敘述，何者錯誤？

    1. (A) 胰臟腫瘤可造成下背部的牽連痛（referred pain）
    2. (B) 硬膜（dura）疼痛為非局部性且大面積的疼痛，但往下傳不會到大腿以下
    3. (C) 小面關節的骨性關節炎可造成早晨僵硬的情形
    4. (D) 如果仰躺會使下背痛增加，須懷疑是源於神經的疼痛或有椎間盤突出之空間占有型傷害（space-occupyinglesions）

    正解：(B)

  18. 18根據Janda和Jull所提出的骨盆交叉症候群（pelvic crossed syndrome），下列敘述何者正確？

    1. (A) 髂腰肌比臀肌短縮
    2. (B) 髂前上棘（ASIS）比髂後上棘（PSIS）高
    3. (C) 腹肌比豎棘肌短縮
    4. (D) 膕旁肌無力

    正解：(A)

  19. 19造成脊椎狹窄的原因，下列何者錯誤？

    2. (B) 骨刺增生
    3. (C) 脊椎滑脫
    4. (D) 肌肉痙攣

    正解：(D)

  20. 20根據Delitto原則，有關下背痛病人的運動治療，下列敘述何者錯誤？

    1. (A) 伸直導向（extension bias）之下背痛病人，即使脫離急性期，也應教導病人絕對避免彎腰動作與運動，以免背痛復發
    2. (B) 當病人呈現屈曲姿以避免誘發症狀，可能是屈曲導向（flexion bias）；這類病人在急性期可考慮穿戴護腰，以提供支持
    3. (C) 若病人身體稍微前彎時，疼痛就會傳至臀部與大腿，若保持直立就較舒服，則可能屬於伸直導向（extensionbias）；在急性期可以鼓勵病人走路做為治療方式，必要時可以撐枴杖
    4. (D) 若病人身體前傾會用兩手支撐體重以減緩疼痛，可能屬於無承重導向（non-weight bearing bias）；在急性期可以牽引治療減輕其症狀

    正解：(A)

  21. 21下列有關腰椎椎間盤病變的敘述，何者錯誤？

    1. (A) 椎間盤外層的環狀纖維（annulus fibrosus）撕裂後不可能再癒合
    2. (B) 30～45歲左右的青壯年人，發生椎間盤突出的危險性較高
    3. (C) 治療椎間盤突出時，若有軀幹橫向偏移（lateral shift）現象，則應先矯正
    4. (D) 若出現脊椎節間的不穩定（segmental instability），核心肌群訓練是重要的

    正解：(A)

  22. 22教導凸邊在左側之胸椎側彎（convex side on left thoracic）病人牽張運動，於其跪坐（heel-sitting）姿勢下，身體向前趴，並將雙手往前伸超過頭，接著做下列何種動作最為適合？

    4. (D) 主動軀幹旋轉向左

    正解：(B)

  23. 23下列關於脊柱側彎的敘述，何者正確？

    2. (B) 脊柱側彎多為額狀面與水平面之姿勢異常

    4. (D) 側彎凸側常因肌肉韌帶的疲乏或者造成脊神經根的損傷而引起症狀

    正解：(B)

  24. 24進行站立姿勢檢查兩腿平均承重時，物理治療師發現病患左側髂骨較高。下列何項檢查結果與此發現最不吻合？

    4. (D) 右側薦髂關節面較為水平

  25. 25有關肩關節SLAP損傷後做手術修復，術後一個月內的復健，下列處置何者最不恰當？

  26. 26下列何者為吹號手徵象（Hornblower's Sign）測試？

    4. (D) 患者手臂在身體旁邊，手肘屈曲90度。檢查者將患者的手臂由肩胛平面抬至90度，接著將肩關節被動外轉並請患者維持在此姿勢

    正解：(B)

  27. 27在肩外展0度下，被動肩外轉角度減少，且X光影像為正常。相較而言，下列何者是最有可能的問題？

  28. 28肩關節外展75度下，患者執行肩外轉動作，抵抗施測者施以內轉方向的阻力，是測試下列那條肌肉等長收縮能力？

  31. 31對於有肩夾擠症候群的過肩運動員之治療建議，下列何者最不適當？

  34. 34病患主訴在舉手的最後10～20度才會有疼痛，疼痛位於肩峰前方。若懷疑為肩鎖關節（acromioclavicularjoint）夾擠，可用下列何種測試來確定診斷？

  36. 36患者將所有的手指都向中指靠攏，做掌指關節內收動作時，出現小指無法內收之現象，下列敘述何者錯誤？

  74. 74在運動傷害的恢復期如需參與競技比賽，應注意預防再度傷害，下列何者較不宜在上場競技前使用？

    1. (A) 冰敷或冰按摩
    2. (B) 動態伸展運動
    3. (C) 淋巴引流按摩
    4. (D) 核心肌力訓練

    正解：(A)

  75. 75有關燒燙傷傷口治療原則之敘述，下列何者正確？

    1. (A) 可在2週內自行癒合的傷口，應讓其新生皮膚組織在日曬與生活環境中強化，增進皮膚健康
    2. (B) 可在2週內自行癒合的傷口，需要強調保濕，以保護新生皮膚組織
    3. (C) 超過3週癒合的傷口，不宜給與按摩，以免新生組織過度增生
    4. (D) 目前未有實證支持按摩治療可加速傷口癒合的成熟，在時間有限的情況下，可省略按摩，多做牽張與肌力強化運動

    正解：(B)

  76. 76有關燒燙傷傷口的壓力治療，下列敘述何者錯誤？

    1. (A) 彈性繃帶可讓植皮處血管得到支撐，並協助控制水腫與疤痕增生
    2. (B) 當癒合的傷口可承受壓力衣的摩擦力後，可開始整天穿戴壓力衣，至少穿1～1.5年以上的時間
    3. (C) 若傷口有滲血現象，需等傷口癒合良好，再穿壓力衣，以免傷口感染
    4. (D) 彈性繃帶與壓力衣可讓疤痕柔軟、減少敏感及搔癢的狀況，並預防疤痕增生

    正解：(C)

  77. 77下列何者不屬於完整減腫脹治療（complete decongestive therapy）之項目？

    1. (A) 肢體抬高
    2. (B) 皮膚照護
    3. (C) 壓縮治療
    4. (D) 肢體運動

    正解：(A)

  78. 78有關截肢後出現的幻肢痛（phantom limb pain）之敘述，下列那些正確？①盛行率可達80% ②最常出現灼熱痛（burning）、疼痛（aching）或抽筋感（cramping） ③不會因外在的刺激而引發 ④不可能隨時間而消失

    1. (A) ①②
    2. (B) ①③
    3. (C) ②③
    4. (D) ②④

    正解：(A)

  79. 79對於殘肢的照顧，下列敘述何者正確？①為使殘肢減少水腫，使用彈性繃帶時必須於肢段的近端加壓包紮②宜採8字型彈性繃帶包紮法 ③皮膚不可擦乳液以避免彈性繃帶脫落 ④初期需加強拍打殘肢，以降低敏感度

    1. (A) ①③
    2. (B) ②③
    3. (C) ②④
    4. (D) ①④

    正解：(C)

  80. 80有關截肢病人穿戴義肢的步態，下列敘述何者錯誤？

    1. (A) 繞行步態（circumduction gait）主要出現在擺盪期
    2. (B) 繞行步態（circumduction gait）可能和義肢過長有關
    3. (C) 若出現足跟向內或向外旋轉（medial or lateral whip），主要來自義肢本身的問題
    4. (D) 足跟著地時若出現義足旋轉，大多是因為踝蹠屈肌緩衝擋（plantar flexor bumper）阻力太低

    正解：(D)
