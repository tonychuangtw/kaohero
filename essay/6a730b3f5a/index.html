  4. 4

    請計算乙醇（C2H5OH）之完全燃燒熱，並由 Jones 燃燒界限化學計量公式（Stoichiometric equation）計算乙醇之燃燒上限與下限（假設其值為乙醇 25℃ 之條件值）；請再參照如下 Zabetakis 修正式評估乙醇於 50℃時之燃燒上限與下限值。（25 分）參考公式與條件：

    ⑴Jones 燃燒界限化學計量公式：LFL = 0.55Cst，UFL = 3.5Cst；

    ⑵燃燒界限會受到溫度影響，溫度上升常使爆炸範圍擴大，依據Zabetakis 修正式，可推估燃燒上下限與溫度關係：LFLT=LFL25*[1–(0.75/Hc)*(T–25)] UFLT=UFL25*[1+(0.75/Hc)*(T–25)]其中，LFLT 與 UFLT 分別為物質於 T℃ 之燃燒下限與上限、LFL25與 UFL25 分別為物質於 25℃ 之燃燒下限與上限、Hc :燃燒熱(kcal/mole)；

    ⑶物質生成熱：CO2 = –394 kJ/mol、H2O(l) = –286 kJ/mol、C2H5OH= –228 kJ/mol；

    ⑷1 kcal = 4.18 J；

    ⑸所有數值請四捨五入計算至小數點後一位。

    （25 分）

    參考架構・破題

    本題是三段串連的計算題：先用赫斯定律（生成熱）求乙醇燃燒熱，再以完全燃燒的化學計量濃度 Cst 套 Jones 公式求 25℃ 的燃燒上下限，最後以 Zabetakis 溫度修正式推估 50℃ 的上下限，並說明溫度上升使爆炸範圍擴大。每一步都要列出公式、代入值、單位與四捨五入結果。
