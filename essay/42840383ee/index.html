海上人命安全　申論題歷屆試題與參考架構

高考三級，民國 103～115 年共 12 份試卷、53 題，其中 53 題附參考答題架構。考這一科的類科：航海技術。本頁列出歷年全部題目，參考架構只列開頭的「破題」，完整的答題架構、關鍵字與作答提醒請到站內查看。

    請依據國際海上人命安全公約第三章，說明下列與救生設備相關專有名詞之定義。 （每小題 5 分，共 25 分）

    （一） Free-fall launching

    （二） Embarkation ladder

    （三） Rescue boat

    （四） Survival craft

    （五） Immersion suit

    （25 分）

    參考架構・破題

    本題考 SOLAS 第三章（救生設備與佈置）第 3 規則的名詞定義。作答重點是以「功能＋使用情境」精準界定各詞，每小題約 3～4 行即可，不必冗長。

  2. 2

    請說明國際海事組織（IMO）制訂「國際船舶及港口設施保全章程」 （ISPS Code）主要目的。（10 分）另外，依據該章程，船舶必須具備之保全設備及文件為何？（15 分）

    （25 分）

    參考架構・破題

    ISPS Code 是 SOLAS 第 XI-2 章的強制性配套章程，因應 2001 年 911 事件後的海事保全威脅而制訂。本題分兩段：目的（10 分）與船舶保全設備及文件（15 分）。

    完整答題架構與關鍵字：到站內看全文

  3. 3

    依據「國內航線船舶安全管理」（NSM）制度，船舶安全管理評鑑可區分為公司評鑑及船舶評鑑兩大類。請說明評鑑員實施船舶評鑑的程序。（20 分）

    （20 分）

    參考架構・破題

    國內航線船舶安全管理（NSM）是我國參考 ISM Code 精神，針對國內航線船舶所建立的安全管理制度。船舶評鑑是由評鑑員登船查核船舶是否確實落實公司安全管理制度。作答應依「事前、現場、事後」順序說明程序。

    完整答題架構與關鍵字：到站內看全文

  4. 4

    為增進海上人命安全，試述船旗國、沿海國及港口國應盡的義務。（30 分）

    （30 分）

    參考架構・破題

    海上人命安全涉及三方管轄：船旗國負責船舶的設計、建造、檢驗與發證；沿海國負責海岸水域的航行安全與搜救；港口國透過港口國管制查核外國船舶。作答以三者義務對照方式呈現。

    完整答題架構與關鍵字：到站內看全文

  1. 1

    請詳述海上人命安全國際公約（SOLAS）對於適用本公約之船舶如何實施監督（Control），以維海上人命安全。（25 分）

    （25 分）

    參考架構・破題

    SOLAS 對船舶的監督（Control）主要規範於第 I 章（一般規定）與第 XI-2 章等，包含締約國政府對本國船舶的檢驗發證，以及對他國船舶的港口國管制。作答應從證書、檢驗與管制三方面說明。

    （25 分）

    參考架構・破題

    SOLAS 第 XII 章「散裝船之追加安全措施」是為降低散裝貨輪因結構破壞而沉沒的風險所訂，起因於多起散裝船海難。作答應歸納其主要規範項目，並點出目的在結構強度、艙水偵測與載貨安全。

  3. 3

    國際安全管理章程（ISM Code）為船舶之安全管理營運及污染防止提供了國際標準，章程對於「指定人員（Designated Person, DP）」、「符合文件 （ Document of Compliance, DOC ）」 及 「 安 全 管 理 證 書 （ Safety Management Certificate, SMC」等三者作了相關的規定，請分別詳述此三者的意義。 （25 分）

    （25 分）

    參考架構・破題

    ISM Code 要求公司與船舶建立安全管理系統（SMS）。DP、DOC、SMC 分別代表岸上責任人、公司符合證明及船舶符合證明，三者構成 ISM 的責任與證書架構。
