    （一）請將下面程式改寫為尾遞迴（tail recursion）的形式。（15分）int recsum(int x){ if (x == 1) return(x); return(x + recsum(x - 1)); }

    （二）請問尾遞迴形式的優點為何？（10分）

    （25 分）

    參考架構・破題

    原函式在遞迴呼叫回來後還要做加法（x + recsum(x-1)），遞迴呼叫不是最後一個動作，所以不是尾遞迴。改寫的關鍵是加一個累加器參數，把「還沒做的加法」提前算進參數裡帶下去。
