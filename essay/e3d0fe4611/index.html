  1. 1

    近年來員工在家工作的需求量日益增加，因此企業建置 VPN，提供員工遠端登錄企業網路。請說明 VPN 所採用的 IPSEC 運作原理，以及如何管理 VPN 避免企業遭受攻擊。（25 分）

    （25 分）

    參考架構・破題

    VPN 的核心是在公共網路上建立「加密且經過認證」的私有通道。IPsec 在網路層（IP 層）提供機密性、完整性與來源認證，是企業遠端登錄最常用的 VPN 技術之一。作答需分兩大塊：IPsec 運作原理，以及 VPN 的管理與防護。

    完整答題架構與關鍵字：到站內看全文

  2. 2

    DNS 通訊協定並不安全，因此 IETF 提出 DNSSEC 期望改善其安全問題。請說明 DNSSEC 運作原理、所提供之安全服務、可防禦之攻擊以及無法防禦之攻擊。（25 分）

    （25 分）

    參考架構・破題

    DNS 原設計未提供來源認證與資料完整性，易遭快取污染（cache poisoning）與偽造回應。DNSSEC 以公開金鑰數位簽章為 DNS 資料加上「來源認證與完整性」，但不提供機密性。作答應涵蓋原理、提供的安全服務、可防與不可防的攻擊。

    完整答題架構與關鍵字：到站內看全文

  3. 3

    分散式阻斷服務（Distributed Denial of Service，簡稱 DDoS）攻擊可能造成網路無法使用，因此網管人員需採取一些防範措施，避免網路運作異常。DDoS 攻擊可分為三大類：流量為基礎之攻擊、通訊協定攻擊以及Layer 7 DDoS 攻擊。若某網站伺服器被 Layer 7 DDoS 攻擊，請舉例說明Layer 7 DDoS 攻擊，以及防禦方式。 （25 分）

    （25 分）

    參考架構・破題

    Layer 7（應用層）DDoS 利用看似合法的應用層請求耗盡伺服器 CPU、記憶體、資料庫連線等資源，流量不大但難以與正常使用者區分。作答以具體攻擊舉例，再依偵測、緩解、架構三層說明防禦。

    完整答題架構與關鍵字：到站內看全文

  4. 4

    HTTP 乃應用層通訊協定，但未提供資料安全性。目前網站多採用 HTTPS以保護資料安全性。請說明 HTTPS 之運作原理，以及可提供之安全服務。（25 分）

    （25 分）

    參考架構・破題

    HTTPS 即 HTTP over TLS（舊稱 SSL），在 TCP 與 HTTP 之間加入 TLS 層，提供伺服器認證、資料機密性與完整性。作答須說明 TLS 握手、金鑰建立與資料保護機制，再列出提供之安全服務。

    請說明博碼調變（pulse code modulation, PCM）與取樣理論（sampling（20分）theory）的原理。

    （20 分）

    參考架構・破題

    PCM 是把類比信號轉成數位位元流的標準方法，而取樣理論（Nyquist 取樣定理）決定「取樣要多快才能無失真還原」。作答應先講取樣定理，再把 PCM 拆成取樣、量化、編碼三步驟，最後用電話語音 64 kbps 做計算實例。

    （一）這三個子網路的 network ID 為何？（4 分）

    （二）這三個子網路的 Subnet mask 為何？（4 分）

    （三）這三個子網路的 Host ID 範圍為何？（4 分）

    （四）這三個子網路各有多少個可使用的 Host ID？（4 分）

    （五）這三個子網路的 broadcast ID 為何？（4 分）

  3. 3

    ARP poisoning 或稱 ARP spoofing 是利用 ARP 通訊協定發動的攻擊。

    （一）說明 ARP poisoning 或稱 ARP spoofing 之攻擊原理。 （10 分）

    （二）說明 ARP poisoning 或稱 ARP spoofing 攻擊之防範方法。 （10 分）

    （20 分）

    參考架構・破題

    ARP 把 IP 位址對應到 MAC 位址，但協定本身沒有任何身分驗證，主機會無條件接受甚至未曾請求的 ARP 回覆。攻擊者便能偽造回覆、竄改他人的 ARP 快取，達成中間人或阻斷服務。作答先講 ARP 正常運作，再講攻擊原理，最後分層提出防範。

    完整答題架構與關鍵字：到站內看全文

  4. 4

    網路是由許多區域網路（Local Area Network，簡稱 LAN）相連而成。

    （一）說明虛擬區域網路（Virtual Local Area Network，簡稱 VLAN）與 LAN的差異性。 （10 分）

    （二）說明 VLAN 優點。（10 分）

    （20 分）

    參考架構・破題

    VLAN 是在同一台（或多台）實體交換器上，以邏輯方式切出多個獨立的廣播網域，打破「一個 LAN 對應一組實體設備與位置」的限制。作答先比較兩者在劃分依據、廣播網域與運作機制上的差異，再分點說明優點。

    完整答題架構與關鍵字：到站內看全文

  5. 5

    網際網路傳輸資料不安全，因此可以利用虛擬私有網路（Virtual Private Network，簡稱 VPN）方式達到安全服務。

    （一） IPSec 可建立那一層的資料安全傳輸？說明如何使用 IPSec 通道模式（tunnel model）達到 VPN 功能。（10 分）

    （二）說明 IPSec tunneling 可以達到那些資料的安全服務。（10 分）

    （20 分）

    參考架構・破題

    IPSec 運作於網路層（第三層），可保護所有上層協定而不需修改應用程式。通道模式把整個原始 IP 封包加密後再包上新的 IP 標頭，在兩個安全閘道之間形成一條穿越網際網路的加密隧道，即為 site-to-site VPN 的基礎。
