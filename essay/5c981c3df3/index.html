115 年（考試時間 120 分鐘）　原卷 PDF

  1. 1

    在多重存取（multiple access）的技術中，衝撞偵測（collision detection, CD）與衝撞迴避（collision avoidance, CA）兩種方式被普遍使用，以提升區域網路的傳輸效能。

    （一）請敘述此兩種方式的基本工作原理。（8 分）

    （二）請敘述此兩種方式各自適合的傳輸媒介，並解釋其原因。 （8 分）

    （三）試以現有的區域網路標準來說明 CD 與 CA 的應用。（9 分）

    （25 分）

    參考架構・破題

    本題考媒體存取控制（MAC）層隨機存取家族中 CSMA/CD 與 CSMA/CA 的原理、媒介適用性與標準對應。作答主軸一句話帶出：CD 是「先送再偵測、撞到就停」，CA 是「事前避免、事後以 ACK 補救」，兩者分歧的根源在於有線與無線在「能否邊送邊聽」上的物理限制。

    完整答題架構與關鍵字：到站內看全文

  2. 2

    （一）試述多工（multiplexing）與展頻（spread spectrum）之差異。 （10 分）

    （二）敘述跳頻展頻 FHSS（Frequency Hopping Spread Spectrum）的工作原理。（10 分）

    （三）一 FHSS 系統共有 8 通道，其跳頻碼有 30 位元，請問每週期此 FHSS系統會跳躍頻道幾次？（5 分）

    （25 分）

    參考架構・破題

    本題把「多工」與「展頻」並列，關鍵在於兩者目的相反：多工是為了節省頻寬、讓多個訊號共用一條通道；展頻則是刻意犧牲頻寬換取抗干擾、抗竊聽與抗多路徑衰落的能力。第三小題是計算題，務必寫出算式與每一步的理由。

    完整答題架構與關鍵字：到站內看全文

  3. 3

    滑動視窗（sliding window）是流量控制普遍使用的機制。

    （一）請解釋 Go-back-N ARQ 中傳送端與接收端如何使用滑動視窗機制？（15 分）

    （二）試論滑動視窗大小與 ARQ 傳輸效能的關係。（10 分）

    （25 分）

    參考架構・破題

    本題考滑動視窗流量控制與 Go-back-N ARQ 的結合。第一小題要把傳送端視窗（已送出但未確認的訊框範圍）與接收端視窗（大小固定為 1）分開講清楚；第二小題要用視窗大小、通道利用率與頻寬延遲乘積的關係來論述，並點出錯誤率高時視窗過大反而不利。

  4. 4

    網際網路的網路層 IP 提供最大努力的服務（Best Effort Service）。

    （一）請敘述此 Best Effort Service 的內涵為何？（15 分）

    （二）請申論為何 IP 的 Best Effort Service 可以提供網際網路極大容錯的能力。（10 分）

    （25 分）

    參考架構・破題

    本題先要說清楚 IP 的盡力而為服務「不保證什麼」，再論述正因為網路層被簡化成無狀態、無承諾的轉送，複雜度與可靠度外移到端點，才造就網際網路面對節點與鏈路失效時的高容錯與高存活能力。核心理論是端到端原則與無狀態轉送。

  4. 4

    無線網路的服務品質最主要由訊號強度來決定。考慮在一個開放空間（Open Space） ，訊號傳輸端與接收端距離 1 公尺的時候，定義出 one-meter path loss 的數值。這個數值等於「傳輸端功率（Pt） 」與「接收端功率（Pr） 」的比值，也就是 Pt/Pr。請回答下列問題： （每小題 7 分，共 28 分）

    （一）何謂「分貝」？請用 Pt/Pr 為參數來寫出其定義之數學式子。

    （二）如果訊號強度隨著距離平方成反比，而且 one-meter path loss 為10（分貝） 。請問當訊號傳輸端與接收端距離 10 公尺的時候，10-meter的 path loss 是多少分貝？

    （三）承上述子題（二），請問當訊號傳輸端與接收端距離 1 公里的時候，1-kilometer 的 path loss 是多少分貝？

    （四）如果訊號強度隨著距離立方成反比，而且 one-meter path loss 為10（分貝） 。請問當訊號傳輸端與接收端距離 1 公里的時候，1-kilometer的 path loss 是多少分貝？

    （28 分）

    參考架構・破題

    本題是無線傳播的計算題，關鍵在兩件事：分貝是功率比取以 10 為底的對數再乘 10；以及路徑損失隨距離的次方變化，在分貝域會變成「加法」。只要把 one-meter path loss 當基準值再加上距離造成的額外損失（dB），四小題都能一致解出。

    （二）請描述 TDM。

    （10 分）

    參考架構・破題

    （一）試闡釋 Shannon’s Theorem 中決定網路效能的參數。 （10 分）

    （二）若傳送端訊號源的傳送功率為 30 dBm，傳送端與接收端以一傳輸線連接，此連接線頻寬為 100 MHz，衰減為 10 dB，傳輸線的熱感雜訊為0.1 mW，請問此通道理論上最高的傳輸速率為何？（5 分）

    （20 分）
