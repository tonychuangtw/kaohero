# 考古英雄 LINE 社群經營計畫

> 本檔只寫「要怎麼做」。過程、決策時間軸與跨檔待辦總表在 [`plan-log.md`](plan-log.md)。

> 2026-09-08 定案。Tony 要開 LINE 社群（OpenChat）替網站導流。
> 本文是我 + codex + agy（Gemini）三家意見的收斂結果，Tony 指名要三家合起來看。

## 一、加入機制：用「固定通行碼 + 自動驗證」，不是開放也不是人工審核

三家一開始給了三個答案，收斂如下：

| 方式 | 擋機器人 | 真人流失 | 站主工時 |
|---|---|---|---|
| 完全開放 | ✗ 公開群會被爬蟲鎖定 | 洗版後一次退掉一大批 | 事後清理，且清不完 |
| 人工審核 | ✓ | 高——考生是「刷題卡住的當下」才點進來，等幾小時就沒了 | 每天被通知打斷 |
| **固定通行碼** | ✓ 爬蟲只抓無密碼的群 | 幾乎為零，密碼就寫在網站上 | 0，系統自動驗 |

- 密碼設成網站上明寫的固定字串，跟著加入連結一起放。對真人不構成門檻，對自動爬蟲是硬牆。
- 我原先建議「完全不設門檻先衝量」是錯的：LINE OpenChat 的公開群會被爬蟲主動掃到，這跟 Facebook 社團不一樣。
- 同時開啟內建禁字過濾（投資、飆股、加賴、兼職、外送、喝茶、私訊…），觸發自動撤回。
- ⛔ **不要開「允許成員邀請」**。廣告帳號帶進來的是分身與同業廣告，不是考生；人數是假的，副作用是真的（洗版 → 真人退群 → 被檢舉 → 社群被官方降搜尋權重）。
- 切換時機：人數到 800–1,000 且有人工破解密碼進來洗版，才招 2–3 名常駐考生當副管理員並改人工審核。不到那個量不要提前關門。

## 二、0 → 500 人的順序

**主打醫師（12,760 題 100% 詳解）為第一波，律師（3,933 題 100%）為第二波，牙醫（93.6%）第三波。**
其餘考科只講「免費練題」並如實揭露詳解進度。⚠️「100% 有詳解」是覆蓋率，不可寫成「100% 正確」。

### 0→50：站內轉換（最高轉換率，0 成本）
- 詳解區下方放「這題詳解有疑問？進 LINE 群回報」按鈕——會點的都是高互動真實考生
- 交卷結算頁放社群連結，文案主打「找同科戰友」
- 群內先備好三份內容：操作指南、該科精選題、勘誤回報格式。新人進來立刻有東西看
- 邀請已回報過問題、稱讚過網站的人試用。10–20 個真的需要的人 > 100 個湊數親友

### 50→150：校系與讀書圈
- 列 10 個窗口，每週聯繫 3–5 個，不群發
- 醫師線找醫學系系學會、一階／二階班群；法律線找法律系系學會、司律讀書會
- 給對方一張操作圖 + 100 字介紹 + 對應考科入口，讓他不用代寫文案

### 150→300：挑兩個公開管道集中做（不要同時經營六個）
- **PTT**（medstudent / Lawyer / Examination / pharmacist）：`[情報]` 標題，表明個人獨立開發者身分，列成果，誠徵勘誤。發文前一定要先看板規——Examination 板規明禁廣告文與推文廣告連結
- **Threads**（擴散最快）：站主本人帳號每週 3 則，走「building in public」——「一個人手搓 12,760 題醫師國考逐題詳解，終於補齊」。連結放留言第一則
- **Dcard**：官方廣告規範限制品牌導流，個人免費不等於豁免。品牌宣傳優先放個人牆；看板發文須符合站規。必附 3–4 張實際刷題與詳解截圖
- **FB 備考社團**：不發宣傳文，改成「精準回覆」——有人問「這題怎麼解」時，貼該題在網站上的解析截圖

### 300→500：放大有效來源
- 看前期哪兩個來源帶來較多「留下來且會回站」的人，把時間集中過去
- 辦一輪 7 天、每天 10 題的自主練習活動（群內只在頭、中、尾提醒，不要每天幾百則打卡）

## 三、會傷品牌、絕對不做

1. **同日多板貼同一份範本** → PTT 多板水桶、Dcard 永久封鎖該網域，之後含這個網址的文都發不出去
2. **開小帳假裝路人推薦** → 台灣學生對業配極敏銳，穿幫不可逆。誠實講「個人獨立開發」反而拿到壓倒性支持
3. **潛入補習班群／競品群貼連結挖人** → 被公審
4. **買人頭、互加群、抽獎灌數、「拉三人才能看詳解」**
5. **前 500 人階段反覆提未來要收費** → 這階段的任務是累積信任與蒐集勘誤。付費規劃要講就如實講「目前免費，未來可能有付費進階功能」，不要承諾永久全功能免費，也不要送出尚未定義的終身權益

## 四、量測

- 「500 人」定義為**目前仍在群內**的人數，扣掉已踢除的廣告帳號；分群後不直接相加宣稱不重複人數
- 每週記錄：新增／退出／淨增／垃圾帳號／管理分鐘數／社群帶回網站的流量。退出與踢除要分開記
- 連兩週淨增接近零 → 改入口、內容或管道，不是加倍洗貼文
- ⚠️ 點擊加入 ≠ 成功入群；GitHub Pages 靜態託管不會自動提供跨 LINE 的入群追蹤

## 五、承諾要配合工時

每週兩次題目精選 + 一次勘誤／更新整理即可，可預先排定。回報集中處理，不承諾全天即時解題。
每則題目內容都要附對應網站入口，社群才會把人帶回站上練習。
