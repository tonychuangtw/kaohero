## 一、結論（兩家 AI ＋ 09-05 規劃書的交集，不要再推翻）

1. **護城河不是詳解文字本身**。AI 產詳解的邊際成本正在歸零，10 萬題詳解只是先發投入。真正的護城河是兩樣：
   - **考生的個人化錯題資產**（刷完幾百題後的轉移成本）
   - **可查證的品質**（標出處、標適用年度、有修訂紀錄、有回報入口）
2. **不做廣告**。1.5 萬人母數 × 刷題型頁面，年廣告收益只有數千元，還干擾專注。
3. **不做月租訂閱**。考生考完就走，月費會全部擠在考前一個月，還多出扣款失敗與退款爭議。
4. **做考季買斷（Exam Season Pass）**。心理錨點是「一本國考解析書 600～1,000 元」。
5. **B2B 授權延後**。要先有願付的教師或補習班，才值得做後台。

競品實價（codex 查證）：考古豹全部題目與詳解免費，付費方案 **1,288／1,888 元／185 天**，賣的是匯出、進度安排與個人化。→ 我們的價格要能說出「品質或複習體驗好在哪」，光說「我們有詳解」撐不住。

### 換正式網域時要一起做的事（照這三條就不會出事）
1. `js/config.js` 的 `API_BASE` 改成 `https://api.<新網域>`
2. 後端 `.env` 的 `EXTRA_ORIGINS` 加上新的前端網域（否則 CORS 擋）
3. Google Cloud Console 的 OAuth 用戶端加上新的 JavaScript 來源
⚠️ 換網域＝換 origin，localStorage 會整包歸零。所以登入同步必須先上線（已完成），
   使用者的錯題本才會留在雲端而不是隨著搬家消失。

## 二、執行順序（四階段，前一階段沒驗證完不要跳下一階段）

### 階段 0：技術前提（詳解完工後第一件事，約 1～2 週）

**目標：把付費詳解移出公開靜態檔，且不重寫整站。**

- [ ] 0-1 **題解分離**：`js/data/exam/*.js` 拆成「題目 + 選項 + 標準答案」（保持靜態）與「詳解」（移出）兩份。
      建 `tools/split-exp.js`：讀現有檔，把 `exp` 欄抽出成 JSON，原檔保留 `exp` 空字串或標記。
      ⚠️ 拆檔會動到 `test/test.js` 的守門邏輯與 `tools/build-index.js`，同批改。
- [ ] 0-2 **後端出題解**：在 LanExamMock backend 增 `GET /api/kgh/exp/:pid/:n`，
      依帳號 + 已購考科 + 到期日回傳單題詳解。加 IP rate limit（每分鐘 60 次）與 Referer 檢查，
      並記錄異常擷取（同一帳號短時間大量取詳解 → 告警）。
      資料先讀 JSON 檔即可，不必一開始就建 CMS。
- [ ] 0-3 **前端改 fetch**：`app.js` 在「看解析」時才打 API（改動預估數十行）。
      免費部分（題目、答案、試讀詳解）維持靜態，載不到 API 時要優雅降級不白畫面。
- [ ] 0-4 **登入與跨裝置同步**：沿用 chinese 站那套（app=kaoguhero），
      第一次登入把 localStorage 的錯題本與統計匯入雲端，之後跨裝置接續。**允許匯出**，不靠扣住資料留人。

⛔ 不做的事：前端混淆、禁右鍵、把解密金鑰藏在前端。已經公開送出的詳解收不回來，這些都是白工。

### 階段 1：做出一個「可信的付費考科包」（約 2～4 週）

**目標：不是「全站上線收費」，是先做完一個考科，證明有人願意付。**

- [ ] 1-1 **選考科**：依實際流量與可取得的審核資源選，不因中醫師正在寫就直接選它。
      先在站上加簡單的瀏覽計數（或看 GitHub Pages 流量），拿到數字再決定。
- [ ] 1-2 **公開覆蓋表**：該考科哪些年度／科目已有詳解、哪些沒有，明列在銷售頁。
      未完成的題數不列入已交付權益。
- [ ] 1-3 **品質工程**（這是護城河，不是文案）：
      - 詳解補上精確出處、適用年度、審核狀態、修訂紀錄
      - 加「題目回報」入口（表單即可），修正後在該題標記修訂日期
      - 高頻題與爭議題找該領域教師或合格人士審過
- [ ] 1-4 **免費試讀**：提供完整一回（80 題）的詳解免費看，讓人看得到品質再決定。

### 階段 2：每日錯題重練（與階段 1 可並行）

**目標：把「刷過的題」變成「每天回來的理由」。**

- [ ] 2-1 移植 K12Review 的 `bumpWrongSchedule`（1→3→7 天三關畢業），純前端即可先做。
- [ ] 2-2 依錯題與上次複習時間，每天產生 20 題（固定規則即可，不必先做演算法）。
- [ ] 2-3 免費保留現有刷題、錯題本、弱點統計；註冊送基本同步；**付費才給完整複習排程與進階練習**。
- [ ] 2-4 gemini 建議的階梯試讀可在此併入：近 2 年詳解免費、更早年份付費解鎖（或每日免費看 15 題）。
      ⚠️ 這條要等階段 0 做完才有意義，否則整包 JS 還是能抓走。

### 階段 3：上線一個價格方案，用真實付款驗證（約 2 週）

- [ ] 3-1 **定價**：先測 **單一考科 180 天 990 元**（codex 建議區間 790～1,290；
      gemini 建議單科 490～690、全科 890～1,280）。全科包等單科驗證過再說。
- [ ] 3-2 **金流**：綠界或藍新單次付款（信用卡／LINE Pay，不綁定期扣款）。
      ⚠️ **缺口**：有無公司或商業登記會決定能開企業帳號或只能個人戶（個人戶有每月收款上限）。
      這題要問 Tony，其他都可先做。
- [ ] 3-3 **試用**：7 天進階功能試用，讓人完成診斷 → 看過詳解 → 實際重練錯題，再出現升級入口。
- [ ] 3-4 **漏斗記錄**：完成試讀 → 使用複習 → 查看方案 → 開始結帳 → 付款，以及退款情況。
      先看前 100 位完成試讀的目標考生。
- [ ] 3-5 **判讀**：幾乎無人付款時，先查品質／價值／結帳障礙，**不要先降價或先擴寫題庫**。
